# 内容提要

在研究涉及含 $\mathrm{e}^x$ 或 $\ln x$ 这类结构的方程或不等式时，若直接求导分析较复杂，还可考虑用下面的两种变形处理方法来简化分析过程.

1. $\mathrm{e}^{x} + u(x)$ 结构的变形方法: 将其等价变形成 $\varphi(x)\mathrm{e}^{x}$ 或 $\frac{\varphi(x)}{\mathrm{e}^{x}}$ 这类结构 (也即让 $\mathrm{e}^{x}$ 与其余含 $x$ 的部分相乘或相除), 再求导分析.  
2. $u(x)\ln x$ 结构的变形方法：将其等价变形成 $\ln x + \varphi (x)$ 这类结构（也即将 $\ln x$ 孤立出来，求导后就没有 $\ln x$ 了），再求导分析.

# 类型I：含 $\mathrm{e}^x$ 结构的方程或不等式

【例1】证明：当 $x > 0$ 时， $\mathrm{e}^x >\frac{1}{2} x^2 +x + 1.$

证法1：（最常规的想法是直接作差构造函数求导分析，我们来试试看）

设 $f(x) = \mathrm{e}^{x} - \frac{1}{2} x^{2} - x - 1 (x > 0)$ ，则 $f'(x) = \mathrm{e}^{x} - x - 1$ ，（不易判断正负，故二次求导） $f''(x) = \mathrm{e}^{x} - 1 > 0$ ，所以 $f'(x)$ 在 $(0, +\infty)$ 上单调递增，又 $f'(0) = 0$ ，所以 $f'(x) > 0$ ，故 $f(x)$ 在 $(0, +\infty)$ 上单调递增，因为 $f(0) = 0$ ，所以 $f(x) > 0$ ，故当 $x > 0$ 时， $\mathrm{e}^{x} > \frac{1}{2} x^{2} + x + 1$ 成立.

证法2: (由内容提要1知, 可在要证的不等式两端同除以 $\mathrm{e}^{x}$ , 变为 $\frac{\varphi(x)}{\mathrm{e}^{x}}$ 这种结构, 时常更易分析) $\mathrm{e}^{x} > \frac{1}{2} x^{2} + x + 1 \Leftrightarrow \frac{x^{2} + 2x + 2}{\mathrm{e}^{x}} < 2$ , 所以要证 $\mathrm{e}^{x} > \frac{1}{2} x^{2} + x + 1$ , 只需证 $\frac{x^{2} + 2x + 2}{\mathrm{e}^{x}} < 2$ ,

设 $g(x) = \frac{x^2 + 2x + 2}{\mathrm{e}^x}$ ， $x > 0$ ，则 $g'(x) = -\frac{x^2}{\mathrm{e}^x} < 0$ ，所以 $g(x)$ 在 $(0, +\infty)$ 上单调递减，又 $g(0) = 2$ ，所以 $g(x) < 2$ ，即 $\frac{x^2 + 2x + 2}{\mathrm{e}^x} < 2$ ，故当 $x > 0$ 时， $\mathrm{e}^x > \frac{1}{2} x^2 + x + 1$ 成立.

【反思】尽管两种证法都证出了不等式，但和证法1相比，证法2可少求一次导，所以当不等式中有 $e^{x}$ 时，可考虑将其调整为 $e^{x}\varphi(x)$ 或 $\frac{\varphi(x)}{e^{x}}$ 这种结构，再证明，很多时候会变得更易分析（但也有例外）.

【变式】当 $x < 0$ 时，证明： $\mathrm{e}^{x + 1} + \frac{1}{x}\leq 0.$

分析: 若直接令 $f(x) = \mathrm{e}^{x + 1} + \frac{1}{x} (x < 0)$ , 则 $f'(x) = \mathrm{e}^{x + 1} - \frac{1}{x^2}$ , 不易判断正负, 再求导, $f''(x) = \mathrm{e}^{x + 1} + \frac{2}{x^3}$ , 仍然不易判断正负, 若继续求导, 依然不易判断正负, 这个思路就可以放弃了, 转为先变形再证.

证明：（要证的不等式中有 $\mathrm{e}^{x + 1}$ 这一结构，可考虑先两端乘以 $x$ ，转化为 $x$ 与 $\mathrm{e}^{x + 1}$ 相乘的形式再证）当 $x < 0$ 时， $\mathrm{e}^{x + 1} + \frac{1}{x} \leq 0 \Leftrightarrow x\mathrm{e}^{x + 1} + 1 \geq 0$ ，设 $f(x) = x\mathrm{e}^{x + 1} + 1 (x < 0)$ ，则 $f'(x) = (x + 1)\mathrm{e}^{x + 1}$ ，

所以 $f'(x) > 0 \Leftrightarrow -1 < x < 0$ ， $f'(x) < 0 \Leftrightarrow x < -1$ ，故 $f(x)$ 在 $(-\infty, -1)$ 上单调递减，在 $(-1, 0)$ 上单调递增，
所以 $f(x)_{\min}=f(-1)=0$ ，从而 $f(x)\geq0$ ，故 $e^{x+1}+\frac{1}{x}\leq0$ .

【总结】和例1相比，本题直接构造函数求导证明不等式较难，而两端同乘以 $x$ 后，再构造函数分析则很简单，再次说明了对于含 $\mathrm{e}^x$ 结构的方程或不等式，转化成 $\mathrm{e}^x\varphi (x)$ 或 $\frac{\varphi(x)}{\mathrm{e}^x}$ 来研究时常具有优越性.

# 类型 II：含 $\ln x$ 结构的方程或不等式

【例 2】证明：当 x > 1 时， $2x \ln x < x^{2} - 1$ .

证法1：（先试试直接作差构造）设 $f(x) = 2x\ln x - x^2 +1(x > 1)$ ，则 $f^{\prime}(x) = 2 + 2\ln x - 2x$

（不易直接判断 $f'(x)$ 的正负，故二次求导） $f''(x)=\frac{2}{x}-2=\frac{2(1-x)}{x}<0$ ，所以 $f'(x)$ 在 $(1,+\infty)$ 上单调递减，又 $f'(1)=0$ ，所以 $f'(x)<0$ ，故 $f(x)$ 在 $(1,+\infty)$ 上单调递减，结合 $f(1)=0$ 知 $f(x)<0$ ，所以 $2x\ln x<x^{2}-1$ 。

证法2：（目标不等式中有 $x \ln x$ ，可考虑两边同除以 $x$ ，将 $x$ 与 $\ln x$ 分离，再作差构造，方便求导分析） $2x \ln x < x^2 - 1 \Leftrightarrow 2 \ln x < x - \frac{1}{x} \Leftrightarrow 2 \ln x - x + \frac{1}{x} < 0$ ，所以要证 $2x \ln x < x^2 - 1$ ，只需证 $2 \ln x - x + \frac{1}{x} < 0$ ，

设 $g(x) = 2\ln x - x + \frac{1}{x} (x > 1)$ ，则 $g'(x) = -\frac{(x - 1)^2}{x^2} < 0$ ，所以 $g(x)$ 在 $(1, +\infty)$ 上单调递减，

又 $g(1) = 0$ ，所以当 $x > 1$ 时， $g(x) <   0$ ，即 $2\ln x - x + \frac{1}{x} <  0$ ，所以当 $x > 1$ 时， $2x\ln x <   x^2 -1$ 成立.

【反思】尽管两种证法都证出了不等式，但证法2无需二次求导，计算量更小，所以当不等式中有 $u(x)\ln x$ 这种结构时，可以考虑将其等价变形成 $\ln x + \varphi (x)$ 的形式，再构造函数证明.

【变式】已知函数 $f(x) = (x + 1)\ln (x + 1) - x^2 +2$ ，证明： $f(x)$ 在 $(0, + \infty)$ 上有唯一的零点.

证法1：（要研究零点，需先分析单调性，先试试直接求导分析）

由题意， $f'(x)=\ln(x+1)+(x+1)\cdot\frac{1}{x+1}-2x=\ln(x+1)+1-2x$ ，（不易直接判断正负，考虑二次求导）

所以 $f''(x)=\frac{1}{x+1}-2=-\frac{2x+1}{x+1}$ ，当 x>0 时， $f''(x)<0$ ，所以 $f'(x)$ 在 $(0,+\infty)$ 上单调递减，

(有了 $f'(x)$ 的单调性, 要判断其正负, 需先找到零点. 经尝试, 零点无法求出, 故通过取点论证)

又 $f^{\prime}(0) = 1 > 0$ ， $f^{\prime}(1) = \ln 2 - 1 <   0$ ，所以 $f^{\prime}(x)$ 在(0,1)上有唯一的零点 $x_0$

且当 $x \in (0, x_0)$ 时， $f'(x) > 0$ ， $f(x)$ 单调递增；当 $x \in (x_0, +\infty)$ 时， $f'(x) < 0$ ， $f(x)$ 单调递减；

因为 $f(0)=2>0$ ，所以 $f(x_{0})>0$ ，又 $f(5)=6\ln6-23<0$ ，所以 $f(x)$ 在 $(0,+\infty)$ 上有唯一的零点.

证法2: (观察发现 $f(x)$ 的解析式中有 $(x + 1)\ln (x + 1)$ , 故也可考虑在方程 $f(x) = 0$ 的两端同除以 $x + 1$ , 从而将 $\ln (x + 1)$ 孤立出来, 再求导分析)

由题意， $f(x) = 0\Leftrightarrow (x + 1)\ln (x + 1) - x^2 +2 = 0\Leftrightarrow \ln (x + 1) - \frac{x^2 - 2}{x + 1} = 0$ ①，

令 $g(x) = \ln (x + 1) - \frac{x^2 - 2}{x + 1} (x > 0)$ ，则 $g'(x) = \frac{1}{x + 1} - \frac{2x(x + 1) - (x^2 - 2)}{(x + 1)^2} = -\frac{x^2 + x + 1}{(x + 1)^2} < 0$

所以 $g(x)$ 在 $(0, +\infty)$ 上单调递减，又 $g(0) = 2 > 0$ ， $g(4) = \ln 5 - \frac{14}{5} < 0$ ，所以 $g(x)$ 有唯一的零点，

由①知 $f(x)$ 在 $(0,+\infty)$ 上的零点与 $g(x)$ 相同，所以 $f(x)$ 在 $(0,+\infty)$ 上有唯一的零点.

【总结】无论是方程还是不等式，遇到 $u(x)\ln x$ 这种结构时，若直接求导较麻烦，则可考虑将其等价变形成 $\ln x + \varphi (x)$ 的形式，再构造函数求导分析.
