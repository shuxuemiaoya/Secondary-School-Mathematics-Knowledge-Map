# 强化训练

1. (2024·天津卷·★★)

若 $a = 4.2^{-0.3}$ ， $b = 4.2^{0.3}$ ， $c = \log_{4.2}0.2$ ，则 $a,b,c$ 的大小关系为（）

A. $a > b > c$

B. $b > a > c$

C. $c > a > b$

D. $b > c > a$

1. B

解析：观察发现 $a$ ， $b$ 底数相同，可用指数函数的单调性来比较大小，因为 $4.2 > 1$ ，所以 $f(x) = 4.2^{x}$ 在 $\mathbf{R}$ 上 $\nearrow$ 又 $-0.3 < 0.3$ ，所以 $0 < f(-0.3) < f(0.3)$

从而 $0 < 4.2^{-0.3} < 4.2^{0.3}$ ，故 $0 < a < b$

又因为 $c = \log_{4.2}0.2 < 0$ ，所以 $c < a < b$ ，故 $b > a > c$

2. (2023·辽宁模拟·★★)

$a=2^{-0.1}$ ， $b=\log_{3}4$ ， $c=\log_{5}27$ ，则（）

A. $a < c < b$

B. $a < b < c$

C. $c < a < b$

D. $c < b < a$

2. B

解析：比较大小，先尝试估算，可将各数据估计在两个相邻的整数之间，看能否得出它们的大小，

$$
0 <   2 ^ {- 0. 1} <   2 ^ {0} \Rightarrow 0 <   a <   1, \log_ {3} 3 <   \log_ {3} 4 <   \log_ {3} 9 \Rightarrow 1 <   b <   2,
$$

$\log_525 < \log_527 < \log_5125 \Rightarrow 2 < c < 3$ ，所以 $a < b < c$ .

3. (2022·安徽模拟·★★★)

已知 $a = \log_34$ ， $b = \log_59$ ， $c = \frac{4}{3}$ ，则（）

A. $a < b < c$

B. $c < a < b$

C. $b < c < a$

D. $a < c < b$

3. D

解析：题干专门给了个 $c = \frac{4}{3}$ ，可能是中间量的提示，于是我们就把 $a$ 和 $b$ 跟 $c$ 比较一下，看能不能选出答案，因为 $c = \frac{4}{3} = \log_3 3^{\frac{4}{3}}$ ，所以要比较 $a$ 和 $c$ 的大小，

只需比较4和 $3^{\frac{4}{3}}$ 的大小，可将它们同时立方，

因为 $4^{3} = 64 < \left(3^{\frac{4}{3}}\right)^{3} = 3^{4} = 81$ ，所以 $4 < 3^{\frac{4}{3}}$

从而 $\log_34 < \log_33^{\frac{4}{3}} = \frac{4}{3}$ ，故 $a < c$ ；

又 $\frac{4}{3} = \log_55^{\frac{4}{3}}$ ，所以要比较 $b$ 和 $c$ 的大小，只需比较9和

$5^{\frac{4}{3}}$ 的大小，因为 $9^{3} = 729 > \left(5^{\frac{4}{3}}\right)^{3} = 5^{4} = 625$ ，所以 $9 > 5^{\frac{4}{3}}$

从而 $\log_59 > \log_55^{\frac{4}{3}} = \frac{4}{3}$ ，故 $b > c$ ，所以 $a < c < b$ 。

4. (2022·河南焦作三模·★★★)

若 $a^3 = 2$ ， $2^{b} = 6$ ， $3^{c} = 8$ ，则 $a, b, c$ 的大小关系为（）

A. $a < c < b$

B. $c < a < b$

C. $a < b < c$

D. $b < a < c$

4. A

解析：要比较 $a, b, c$ ，考虑先解出它们，并粗略估算范围，

由题意， $1 < a = \sqrt[3]{2} < 2$ ， $b = \log_26 > 2$ ， $1 < c = \log_38 < 2$ ，所以 $b$ 最大，

因为 $a, c$ 都在 1 和 2 之间，所以要比较 $a$ 和 $c$ 的大小，可以试试以 $\frac{3}{2}$ 作为中间量。考虑到 $a = \sqrt[3]{2} = 2^{\frac{1}{3}}$ ，为了将指数整数化，将其立方并与 $\left(\frac{3}{2}\right)^3$ 比较，

因为 $\left(\frac{3}{2}\right)^3 = \frac{27}{8} > a^3 = 2$ ，所以 $a < \frac{3}{2}$ ，

又 $c = \log_38 > \log_3(3\sqrt{3}) = \frac{3}{2}$ ，所以 $a < c$ ，故 $a < c < b$ 。

5. (2022·江西南昌模拟·★★★☆)

已知偶函数 $f(x)$ 在 $(0, +\infty)$ 上是增函数，若 $a = f\left(\log_2\frac{1}{5}\right)$ ， $b = f(\log_3 18)$ ， $c = f(2^{0.8})$ ，则 $a, b, c$ 的大小关系为（）

A. $a < b < c$

B. $b < a < c$

C. $c < b < a$

D. $c < a < b$

5. D

解析：条件给出 $f(x)$ 在 $(0, +\infty)$ 上 $\nearrow$ ，可考虑利用 $f(x)$ 为偶函数把自变量全部化到这个增区间上来，

$f(x)$ 为偶函数 $\Rightarrow a = f\left(\log_2\frac{1}{5}\right) = f(-\log_25) = f(\log_25)$

故要比较 $a, b, c$ 的大小，只需比较 $\log_2 5$ ， $\log_3 18$ ， $2^{0.8}$

因为 $2^{0.8} < 2$ ， $2 < \log_25 < 3$ ， $2 < \log_318 < 3$ ，所以 $2^{0.8}$ 最小，

而 $\log_25$ 和 $\log_318$ 都在(2,3)上，所以又可选择2.5作为中间量来试试，把2.5化成跟比较对象同底的对数来看，

因为 $2.5 = \log_22^{2.5} = \log_2(4\sqrt{2})$ ， $5 < 4\sqrt{2}$

所以 $\log_25 < \log_2(4\sqrt{2}) = 2.5$

又 $2.5 = \log_33^{2.5} = \log_3(9\sqrt{3})$ ， $18 > 9\sqrt{3}$

所以 $\log_318 > \log_3(9\sqrt{3}) = 2.5$ ，从而 $\log_25 < \log_318$

故 $2^{0.8} < \log_2 5 < \log_3 18$

所以 $f(2^{0.8}) < f(\log_25) < f(\log_318)$ ，故 $c < a < b$

6. (2024·广州一模·★★★☆)

已知 $a = \frac{3}{2}$ ， $3^{b} = 5$ ， $5^{c} = 8$ ，则（）

A. $a < b < c$

B. $a < c < b$

C. $c < b < a$

D. $b < c < a$

6. C

解析：注意到 $a$ 的大小很清晰，故先由所给指数式解出 $b$ 和 $c$ ，分别与 $a$ 比较大小，因为 $3^{b} = 5$ ，所以 $b = \log_35$

要比较 $b$ 与 $\frac{3}{2}$ 的大小，可将 $\frac{3}{2}$ 也化为以3为底的对数来看，

$a = \frac{3}{2} = \log_33^{\frac{3}{2}} = \log_33\sqrt{3}$ ，因为 $(3\sqrt{3})^2 = 27 > 25 = 5^2$

所以 $3\sqrt{3} > 5$ ，从而 $\log_3 3\sqrt{3} > \log_3 5$ ，故 $a > b$ ①;

因为 $5^{c} = 8$ ，所以 $c = \log_58$ ， $a = \frac{3}{2} = \log_55^{\frac{3}{2}} = \log_55\sqrt{5}$

因为 $(5\sqrt{5})^2 = 125 > 64 = 8^2$ ，所以 $5\sqrt{5} > 8$

从而 $\log_5 5\sqrt{5} > \log_5 8$ ，故 $a > c$ ，结合①可知 $a$ 最大，

故还需比较 $b, c$ 的大小，不难发现它们都在(1,1.5)上，数值比较接近，不方便通过估算比较大小，怎么办呢？ $b, c$ 虽然底数不同，但前者真数与后者底数相同，这时候常考虑作差化同底后结合基本不等式比较大小，过程如下，

$$
b - c = \log_ {3} 5 - \log_ {5} 8 = \frac {\ln 5}{\ln 3} - \frac {\ln 8}{\ln 5} = \frac {\ln^ {2} 5 - \ln 3 \times \ln 8}{\ln 3 \cdot \ln 5},
$$

故核心是看 $\ln^2 5 - \ln 3 \times \ln 8$ 的正负, 由于 $\ln 3 \times \ln 8$ 没有公式可用于计算, 但 $\ln 3 + \ln 8$ 有, 故考虑变乘为加, 怎么变? 用 $xy \leq \left(\frac{x + y}{2}\right)^2$ 即可,

因为 $\ln 3 \neq \ln 8$ ，所以 $\ln 3 \times \ln 8 < \left(\frac{\ln 3 + \ln 8}{2}\right)^2 = \left(\frac{\ln 24}{2}\right)^2$

$$
= \ln^ {2} \sqrt {2 4} <   \ln^ {2} \sqrt {2 5} = \ln^ {2} 5,
$$

所以 $\ln^2 5 - \ln 3\times \ln 8 > 0$ ，从而 $b - c > 0$ ，故 $b > c$

综上所述， $a > b > c$ ，即 $c < b < a$
