1. (2022·福建漳州期末（改）·★)

在 $\triangle ABC$ 中，内角 $A, B, C$ 的对边分别为 $a, b, c$ ，且 $\sqrt{3} a \cos B = b \sin A$ ，则 $B = (\quad)$

A. $\frac{\pi}{6}$

B. $\frac{\pi}{4}$

C. $\frac{\pi}{3}$

D. $\frac{2 \pi}{3}$

1. C

解析：所给等式有齐次的边，要求的是角，故边化角，

因为 $\sqrt{3} a\cos B = b\sin A$ ，所以 $\sqrt{3}\sin A\cos B = \sin B\sin A$

又 $0 < A < \pi$ ，所以 $\sin A > 0$ ，故 $\sqrt{3}\cos B = \sin B$

从而 $\tan B = \sqrt{3}$ ，结合 $0 < B < \pi$ 可得 $B = \frac{\pi}{3}$

2. (2022·福建闽侯县期末·★★)

在 $\triangle ABC$ 中，内角 $A, B, C$ 的对边分别为 $a, b, c$ ，且 $b = a\cos C$ ，则 $\triangle ABC$ 是（）

A. 等腰三角形

B. 直角三角形

C. 等腰直角三角形

D. 等边三角形

2. B

解法 1: 题干给出 $b = a \cos C$ , 可以考虑边化角或角化边,

先试试边化角， $b = a\cos C\Rightarrow \sin B = \sin A\cos C$

要进一步变形，应拆左边的 $\sin B$ ，

因为 $\sin B = \sin [\pi -(A + C)] = \sin (A + C) = \sin A\cos C+$

$\cos A \sin C$ ，所以 $\sin A \cos C + \cos A \sin C = \sin A \cos C$

故 $\cos A\sin C = 0$ ，因为 $0 < C < \pi$ ，所以 $\sin C > 0$

从而 $\cos A = 0$ ，结合 $0 < A < \pi$ 可得 $A = \frac{\pi}{2}$ ，故选B.

解法2：对于等式 $b = a\cos C$ ，也可利用余弦定理推论角化边，通过边的关系来判断三角形形状，

因为 $b = a\cos C$ ，所以 $b = a\cdot \frac{a^2 + b^2 - c^2}{2ab}$

整理得： $b^{2}+c^{2}=a^{2}$ ，所以 $\triangle ABC$ 为直角三角形.

3. (2022·安徽宣城开学·★★☆)

在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ ，若 $A = \frac{\pi}{3}$ ， $b = 2$ ， $c = 3$ ，则 $\frac{a - 2b + 2c}{\sin A - 2\sin B + 2\sin C}$ 的值等于（）

A. $\sqrt{21}$

B. $\frac{2\sqrt{21}}{3}$

C. $\frac{4\sqrt{7}}{3}$

D. $\frac{4\sqrt{3}}{3}$

3. B

解析：所求的式子中，分子都是边，分母都是角，应先将其统一，可用正弦定理边化角，

由正弦定理， $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$

所以 $a = 2R\sin A$ ， $b = 2R\sin B$ ， $c = 2R\sin C$

故 $\frac{a - 2b + 2c}{\sin A - 2\sin B + 2\sin C} =$

$$
\frac {2 R \sin A - 2 \times 2 R \sin B + 2 \times 2 R \sin C}{\sin A - 2 \sin B + 2 \sin C} = 2 R \quad ①,
$$

已知 $A$ , 求 $2 R$ 还差 $a$ . 已知 $b, c, A$ , 可用余弦定理求 $a$ ,

由余弦定理， $a^2 = b^2 + c^2 - 2bc\cos A = 4 + 9 - 2\times 2\times 3\times \cos \frac{\pi}{3}$

$= 7$ ，所以 $a = \sqrt{7}$ ，故 $2R = \frac{a}{\sin A} = \frac{\sqrt{7}}{\sin\frac{\pi}{3}} = \frac{2\sqrt{21}}{3}$

代入①得 $\frac{a - 2b + 2c}{\sin A - 2\sin B + 2\sin C} = \frac{2\sqrt{21}}{3}$

4.3

由余弦定理， $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，

将 $B = \frac{3\pi}{4}$ 和 $b = 6$ 代入可得 $a^2 + c^2 + \sqrt{2} ac = 36$

又由题意， $a^2 + c^2 = 2\sqrt{2} ac$

所以代入上式可得 $2\sqrt{2} ac + \sqrt{2} ac = 36$ ，从而 $ac = 6\sqrt{2}$

故 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{\sqrt{2}}{4} ac = 3.$

5. (2021·全国乙卷·★★☆)

记 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ , 面积为 $\sqrt{3}$ , $B = 60^{\circ}$ , $a^{2} + c^{2} = 3ac$ , 则 $b = \_$ .

5. $2 \sqrt{2}$

解析：先翻译面积条件，已知 B，用 $S=\frac{1}{2}ac\sin B$ 算面积，

因为 $B = 60^{\circ}$ ，所以 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{\sqrt{3}}{4} ac$

又 $\triangle ABC$ 的面积为 $\sqrt{3}$ ，所以 $\frac{\sqrt{3}}{4} ac = \sqrt{3}$ ，故 $ac = 4$ ，

有了 $ac$ ，结合条件 $a^2 + c^2 = 3ac$ ，想到对 $B$ 用余弦定理，

由余弦定理， $b^{2} = a^{2} + c^{2} - 2ac\cos B = a^{2} + c^{2} - ac$

$= 3ac - ac = 2ac = 8$ ，所以 $b = 2\sqrt{2}$

6. (2025·江苏无锡模拟（节选）·★★)

在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ ，且 $\frac{\sqrt{2}b - c}{a} = \sqrt{2}\cos C$ ，求角 $A$ 的大小.

6. 解法 1: (考虑的方向不外乎两个, 要么用正弦定理将左侧

边的齐次分式化角，要么用余弦定理推论将右边的 $\cos C$ 化边，我们先试试前者）

因为 $\frac{\sqrt{2}b - c}{a} = \sqrt{2}\cos C$ ，所以 $\frac{\sqrt{2}\sin B - \sin C}{\sin A} = \sqrt{2}\cos C$

故 $\sqrt{2}\sin B - \sin C = \sqrt{2}\sin A\cos C$ ①,

（涉及的角较多，考虑消元，消谁？注意到右边有 $\sin A\cos C$ ，拆掉左边的 $\sin B$ ，也会出现这一项，故考虑消 $B$ ）

$$
\begin{array}{l} \sin B = \sin [ \pi - (A + C) ] = \sin (A + C) \\ = \sin A \cos C + \cos A \sin C, \text {代入} ① \text {得} \\ \sqrt {2} (\sin A \cos C + \cos A \sin C) - \sin C = \sqrt {2} \sin A \cos C, \\ \end{array}
$$

化简得： $\sin C(\sqrt{2}\cos A - 1) = 0$ ②，

又 $0 < C < \pi$ ，所以 $\sin C > 0$

故式②可化为 $\sqrt{2}\cos A - 1 = 0$ ，解得： $\cos A = \frac{\sqrt{2}}{2}$

结合 $0 < A < \pi$ 得 $A = \frac{\pi}{4}$ .

解法 2: (再试试将 $\cos C$ 化边, 看能否从边的层面来求 $A$ )

由余弦定理推论， $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$

代入题干等式得 $\frac{\sqrt{2}b - c}{a} = \sqrt{2}\cdot \frac{a^2 + b^2 - c^2}{2ab}$

化简得： $b^{2} + c^{2} - a^{2} = \sqrt{2} bc$

(由上式的结构又联想到可用余弦定理推论求出 $\cos A$ ，进而得到角 A)

由余弦定理推论， $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{\sqrt{2}bc}{2bc} = \frac{\sqrt{2}}{2}$

结合 $0 < A < \pi$ 得 $A = \frac{\pi}{4}$ .

7.（2024·新课标Ⅱ卷·★★☆）

记 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ , 已知 $\sin A + \sqrt{3} \cos A = 2$ .

(1) 求 $A$ ;

(2) 若 a=2， $\sqrt{2}b\sin C=c\sin 2B$ ，求 $\triangle ABC$ 的周长.

所以 $\sin \left(A + \frac{\pi}{3}\right) = 1$ ①，又因为 $0 < A < \pi$ ，所以 $\frac{\pi}{3} < A + \frac{\pi}{3}$

$<\frac{4\pi}{3}$ ，结合式①可得 $A+\frac{\pi}{3}=\frac{\pi}{2}$ ，故 $A=\frac{\pi}{6}$ .

(2) 解法 1: (条件 $\sqrt{2} b \sin C = c \sin 2 B$ 怎样处理? 左右有齐次的边, 可考虑边化角分析)

因为 $\sqrt{2} b\sin C = c\sin 2B$ ，所以 $\sqrt{2}\sin B\sin C = \sin C\sin 2B$

故 $\sqrt{2}\sin B\sin C = 2\sin C\sin B\cos B$ ②，

又因为 $B, C \in (0, \pi)$ ，所以 $\sin B > 0$ ， $\sin C > 0$ ，

从而式②可化为 $\sqrt{2} = 2\cos B$ ，故 $\cos B = \frac{\sqrt{2}}{2}$

结合 $B \in (0, \pi)$ 可得 $B = \frac{\pi}{4}$ ，所以 $C = \pi - A - B = \pi - \frac{\pi}{6} - \frac{\pi}{4}$

$=\frac{7\pi}{12}$ ，（现已知三角一边，可用正弦定理求另外两边）

由正弦定理， $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{2}{\sin\frac{\pi}{6}} = 4$

所以 $b = 4\sin B = 4\sin \frac{\pi}{4} = 2\sqrt{2}$ ， $c = 4\sin C = 4\sin \frac{7\pi}{12}$

$$
= 4 \sin \left(\frac {\pi}{4} + \frac {\pi}{3}\right) = 4 \left(\sin \frac {\pi}{4} \cos \frac {\pi}{3} + \cos \frac {\pi}{4} \sin \frac {\pi}{3}\right)
$$

$$
= 4 \left(\frac {\sqrt {2}}{2} \times \frac {1}{2} + \frac {\sqrt {2}}{2} \times \frac {\sqrt {3}}{2}\right) = \sqrt {2} + \sqrt {6},
$$

故 $\triangle ABC$ 的周长 $L = 2 + 2\sqrt{2} +\sqrt{2} +\sqrt{6} = 2 + 3\sqrt{2} +\sqrt{6}$

解法2：（对于 $\sqrt{2} b\sin C = c\sin 2B$ ，观察发现若将 $\sin 2B$ 用二倍角公式展开，则左右有齐次的内角正弦值，故也可考虑用正弦定理角化边，消去相同项再分析）

因为 $\sqrt{2} b\sin C = c\sin 2B$ ，所以 $\sqrt{2} b\sin C = 2c\sin B\cos B$

从而 $\sqrt{2} bc = 2cb\cos B$ ，故 $\cos B = \frac{\sqrt{2}}{2}$ ，接下来同解法1.

8. (2023·湖北武汉四调（节选）·★★★)

设 $\triangle ABC$ 的内角 $A, B, C$ 所对的边分别为 $a, b, c$ ，且有 $2\sin \left(B + \frac{\pi}{6}\right) = \frac{b + c}{a}$ ，求角 $A$ .

(变量较多, 考虑消元, $A$ 是要求的, 不能消, $C$ 只出现一次, 故考虑消 $C$ )

\sin C = \sin [ \pi - (A + B) ] = \sin (A + B) = \sin A \cos B + \cos A \sin B,

9. (2024·广东模拟·★★★)

在 $\triangle ABC$ 中， $a, b, c$ 分别是内角 $A, B, C$ 的对边，且 $b^{2} + c^{2} = 5$ .

（1）若 $\sqrt{2}\sin B = \sqrt{3}\sin C$ ，且 $\triangle ABC$ 的面积为 $\frac{\sqrt{6}}{4}$ ，求 $A$

（2）若 $b + c = 3$ ， $\cos A = \frac{1}{4}$ ， $\sin B > \sin C$ ，求

$\overrightarrow{AC}\cdot\overrightarrow{CB}$

9. 解：（1）（等式 $\sqrt{2}\sin B = \sqrt{3}\sin C$ 左右两侧都有齐次的内角

正弦值，可考虑用正弦定理角化边，结合题干边的等式求边，再由面积已知求角 $A$

因为 $\sqrt{2}\sin B = \sqrt{3}\sin C$ ，所以 $\sqrt{2} b = \sqrt{3} c$

结合 $b^{2} + c^{2} = 5$ 可得 $b = \sqrt{3}$ ， $c = \sqrt{2}$

所以 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \frac{\sqrt{6}}{2}\sin A$

又 $S_{\triangle ABC} = \frac{\sqrt{6}}{4}$ ，所以 $\frac{\sqrt{6}}{2}\sin A = \frac{\sqrt{6}}{4}$ ，故 $\sin A = \frac{1}{2}$

结合 $A \in (0, \pi)$ 可得 $A = \frac{\pi}{6}$ 或 $\frac{5\pi}{6}$ .

（2）解法1： $\overrightarrow{AC}\cdot \overrightarrow{CB} = -\overrightarrow{CA}\cdot \overrightarrow{CB} = -|\overrightarrow{CA} |\cdot |\overrightarrow{CB} |\cos C$

$$
= - b a \cos C \quad ①,
$$

由 $\left\{ \begin{array}{l} b^{2} + c^{2} = 5 \\ b + c = 3 \end{array} \right.$ 可得 $\left\{ \begin{array}{l} b = 2 \\ c = 1 \end{array} \right.$ 或 $\left\{ \begin{array}{l} b = 1 \\ c = 2 \end{array} \right.,$

又因为 $\sin B > \sin C$ ，所以 $b > c$ ，故 $\left\{ \begin{array}{l} b = 2 \\ c = 1 \end{array} \right.$

(求式①还差 $a$ 和 $\cos C$ , 现已知 $b, c$ 和 $\cos A$ , 这是已知两边及夹角, 可用余弦定理求 $a$ )

由余弦定理， $a^2 = b^2 +c^2 -2bc\cos A$

$= 2^{2} + 1^{2} - 2 \times 2 \times 1 \times \frac{1}{4} = 4$ ，所以 $a = 2$ ②，

（三边都有了，又可用余弦定理推论求 $\cos C$ ）由余弦定理推论， $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{2^2 + 2^2 - 1^2}{2\times 2\times 2} = \frac{7}{8}$ ③，

将 $b = 2$ 和②③代入①得 $\overrightarrow{AC} \cdot \overrightarrow{CB} = -2 \times 2 \times \frac{7}{8} = -\frac{7}{2}$ .

解法2: (求 $a, b, c$ 的过程同解法1, 对于目标 $\overrightarrow{AC} \cdot \overrightarrow{CB}$ , 注意到将 $\overrightarrow{AB} = \overrightarrow{AC} + \overrightarrow{CB}$ 平方可产生三边以及 $\overrightarrow{AC} \cdot \overrightarrow{CB}$ , 三边刚好又已求得, 于是能直接求出 $\overrightarrow{AC} \cdot \overrightarrow{CB}$ )

因为 $\overrightarrow{AB}^2 = (\overrightarrow{AC} +\overrightarrow{CB})^2 = \overrightarrow{AC}^2 +\overrightarrow{CB}^2 +2\overrightarrow{AC}\cdot \overrightarrow{CB}$

所以 $c^2 = b^2 + a^2 + 2\overrightarrow{AC} \cdot \overrightarrow{CB}$

从而 $1^{2} = 2^{2} + 2^{2} + 2\overrightarrow{AC}\cdot \overrightarrow{CB}$ ，故 $\overrightarrow{AC}\cdot \overrightarrow{CB} = -\frac{7}{2}.$

解法3：（求 $b, c$ 的过程同解法1，注意到已知 $\cos A$ ，则容易求 $\overrightarrow{AC} \cdot \overrightarrow{AB}$ ，故可考虑把 $\overrightarrow{AC} \cdot \overrightarrow{CB}$ 中的 $\overrightarrow{CB}$ 拆分成 $\overrightarrow{CA} + \overrightarrow{AB}$ ，便于计算）

$$
\overrightarrow {A C} \cdot \overrightarrow {C B} = \overrightarrow {A C} \cdot (\overrightarrow {C A} + \overrightarrow {A B}) = - \overrightarrow {A C} ^ {2} + \overrightarrow {A C} \cdot \overrightarrow {A B}
$$

$$
= - b ^ {2} + b c \cos A = - 2 ^ {2} + 2 \times 1 \times \frac {1}{4} = - \frac {7}{2}.
$$

10.（2023·浙南名校联盟第一次联考·★★★☆）

记 $\triangle ABC$ 的内角 $A, B, C$ 所对的边分别为 $a, b, c$ , 已知 $c \sin (A - B) = b \sin (C - A)$ .

（1）若 $a^2 = bc$ ，求 $A$

（2）若 $a = 2$ ， $\cos A = \frac{4}{5}$ ，求△ABC的周长.

10. 解: (1) (若将题干的边角等式边化角, 则下一步按角化

简不易，故考虑将 $\sin (A - B)$ 和 $\sin (C - A)$ 展开再看）

因为 $c\sin (A - B) = b\sin (C - A)$ ，所以 $c(\sin A\cos B -$

$$
\cos A \sin B) = b (\sin C \cos A - \cos C \sin A) \quad ①,
$$

(观察发现有齐次的内角正弦值, 结合另一条件 $a^2 = bc$ 涉及的是边, 可考虑用正弦定理将式①角化边)

由①可得 $c(a\cos B - b\cos A) = b(c\cos A - a\cos C)$

化简得： $ac\cos B+ab\cos C=2bc\cos A$ ②，

(看到 $ac \cos B$ ， $ab \cos C$ ， $bc \cos A$ ，想到余弦定理)

由余弦定理， $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，

所以 $ac\cos B = \frac{a^2 + c^2 - b^2}{2}$

同理， $ab\cos C = \frac{a^2 + b^2 - c^2}{2}$ ， $bc\cos A = \frac{b^2 + c^2 - a^2}{2}$

代入②得 $\frac{a^2 + c^2 - b^2}{2} +\frac{a^2 + b^2 - c^2}{2} = 2\times \frac{b^2 + c^2 - a^2}{2}$

整理得： $2a^{2} = b^{2} + c^{2}$ ，又由题意， $a^2 = bc$

所以 $2bc = b^{2} + c^{2}$ ，从而 $(b - c)^{2} = 0$ ，故 $b = c$

结合 $a^2 = bc$ 可得 $a = b = c$

所以 $\triangle ABC$ 为正三角形，故 $A = \frac{\pi}{3}$

（2）（给了 $a$ ，第（1）问又得到了 $2a^{2} = b^{2} + c^{2}$ ，故只需对已知的 $A$ 用余弦定理，即可再得到一个边的方程，求出 $b$ 和 $c$ ）由余弦定理， $a^2 = b^2 +c^2 -2bc\cos A$

将 $a = 2$ ， $\cos A = \frac{4}{5}$ 代入化简得： $b^{2} + c^{2} - \frac{8}{5} bc = 4$ ③，

由（1）可得 $b^{2} + c^{2} = 2a^{2} = 8$ ，代入③得 $8 - \frac{8}{5} bc = 4$

所以 $bc = \frac{5}{2}$ ，又 $8 = b^{2} + c^{2} = (b + c)^{2} - 2bc$

所以 $(b + c)^2 = 8 + 2bc = 13$ ，故 $b + c = \sqrt{13}$

所以 $\triangle ABC$ 的周长为 $a + b + c = 2 + \sqrt{13}$ .
