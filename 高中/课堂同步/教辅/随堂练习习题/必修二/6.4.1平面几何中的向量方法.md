### 知识点01 ：平面几何中的向量方法
（1）向量在平面几何中的应用
① 平面两个向量的数量积：$\  \overrightarrow{a} \cdot \overrightarrow{b} = \  | \overrightarrow{a} | | \overrightarrow{b} | \cos \theta$；$\overrightarrow{a} \cdot \overrightarrow{b} = x_{1} x_{2} + y_{1} y_{2} .$
② 向量平行的判定: $\overset{a}{\rightarrow} / / \overset{b}{\rightarrow} ( \overset{b}{\rightarrow} \neq \overset{0}{\rightarrow} ) \Leftrightarrow \overset{a}{\rightarrow} = \lambda \overset{b}{\rightarrow}$ ； $\overrightarrow{a} / / \overrightarrow{b} \Leftrightarrow x_{1} y_{2} - x_{2} y_{1} = 0 .$
③向量平行与垂直的判定:$\overrightarrow{a} \bot \overrightarrow{b} \Leftrightarrow \overrightarrow{a} \cdot \overrightarrow{b} = 0$；$\overset{a}{\rightarrow} \bot \overset{b}{\rightarrow} \Leftrightarrow x_{1} x_{2} + y_{1} y_{2} = 0 .$
④平面内两点间![ ](122b0beb173fcdd38a696a3c2c16bb4a.png)的距离公式： $| A B | = \sqrt{( x_{1} - x_{2} )^{2} + ( y_{1} - y_{2} )^{2}}$（其中$A ( x_{1} , y_{1} )$，$B ( x_{2} , y_{2} )$）
⑤求模：$\left| \overrightarrow{a} \right| = \sqrt{\overrightarrow{a} \cdot \overrightarrow{a}}$；$\left| \overrightarrow{a} \right| = \sqrt{x^{2} + y^{2}}$ ；$\left| \overrightarrow{a} \right| = \sqrt{( x_{1} - x_{2} )^{2} + ( y_{1} - y_{2} )^{2}}$
⑥对于题目中遇到的有些平面图形(如长方形、正方形、直角三角形等)的计算求解问题,可通过建立平面直角坐标系,用坐标把向量表示出来,通过代数运算来解决(“形”转“数”).
（2）用向量解决平面几何问题的步骤
①建立平面几何与向量的联系,用向量表示问题中涉及的几何元素,将平面几何问题转化为向量问题；
②通过向量运算,研究几何元素之间的关系,如距离、夹角等问题；
③把运算结果“翻译”成几何关系.

### 知识点02 ：向量在物理中的应用举例
向量的定义有着丰富的物理背景,物理学中的位移、力、速度等都是既有大小又有方向的量,力所做的功就是向量的数量积的物理背景,因此,向量可以解决一些物理问题归纳.
（1）力学问题的向量处理方法
①解决此类问题必须用向量知识将力学问题转化为数学问题,即将力学各量之间的关系抽象成数学模型,再利用建立的数学模型解析或回答相关物理现象；
②向量是既有大小又有方向的量,表示向量的有向线段可以有共同的起点,也可以没有共同的起点.力是既有大小,又有方向的量.用向量知识解决共点力的问题,往往需要把向量平移到同一作用点上.
（2）速度、位移问题的向量处理方法
速度、加速度与位移的合成和分解,实质就是向量的加减运算,而运动的叠加也用到了向量的合成.
①向量在速度、加速度上的应用,实质是通过向量的线性运算解决物理问题,最后获得物理结果.
②用向量解决速度、加速度和位移等问题,用的知识主要是向量的加法、减法以及数乘,有时也可借助坐标来求解.
（3）功、动量问题的向量处理方法
物理上力做功的实质是力在物体前进方向上的分力与物体位移的乘积,它的实质是力$\overrightarrow{F}$与位移$\overrightarrow{s}$的数量积,即$W = \overrightarrow{F} \cdot \overrightarrow{s} = | \overrightarrow{F} | | \overrightarrow{s} | \cos \theta$ ($\theta$为$\overrightarrow{F}$与$\overrightarrow{s}$的夹角).功是一个标量,它可正,也可负.动量$m \overrightarrow{v}$实际上是数乘向量.
在解决问题时要注意数形结合
（4）利用向量法解决物理问题的步骤
用向量方法讨论物理学中的相关问题，一般来说分为四个步骤：
①问题转化，即把物理问题转化为数学问题.
②建立模型，即建立以向量为载体的数学模型.
③求解参数，即求向量的模、夹角、数量积等.
④回答问题，即把所得的数学结论回归到物理问题.

##### 题型01 利用向量解决平面几何中的平行（共线）问题
##### 【典例1】（2023·全国·高三专题练习）在四边形$A B C D$中，若$\overrightarrow{A C} = \overrightarrow{A B} + \overrightarrow{A D}$，且，则四边形$A B C D$是（ ）
$\quad$A．矩形 
$\quad$B．等腰梯形
$\quad$C．正方形 
$\quad$D．菱形
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>因为$\overrightarrow{A C} = \overrightarrow{A B} + \overrightarrow{A D}$，可得$\overrightarrow{A B} + \overrightarrow{B C} = \overrightarrow{A B} + \overrightarrow{A D}$，所以$\overrightarrow{B C} = \overrightarrow{A D}$，
