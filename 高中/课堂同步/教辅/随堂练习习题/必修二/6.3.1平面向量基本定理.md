### 知识点01 ：平面向量基本定理
（1）平面向量基本定理
如果$\overrightarrow{e_{1}}$,$\overrightarrow{e_{2}}$是同一平面内的两个不共线向量，那么对于这一平面内的任一向量$\overrightarrow{a}$,有且只有一对实数$\lambda_{1}$,$\lambda_{2}$,使$\overrightarrow{a} = \lambda_{1} \overrightarrow{e_{1}} + \lambda_{2} \overrightarrow{e_{2}}$.
若$\overrightarrow{e_{1}}$,$\overrightarrow{e_{2}}$不共线,我们把,$\{ \overrightarrow{e_{1}} , \overrightarrow{e_{2}} \}$叫做表示这一平面内所有向量的一个基底.
（2）对平面向量基本定理的理解
(1)这个定理告诉我们,平面内任意两个不共线向量都可以作为基底,一旦选定一组基底,则平面内的任一向量都可用该组基底唯一表示.
(2)对于确定的基底$\overrightarrow{e_{1}}$,$\overrightarrow{e_{2}}$,同一向量的分解式是唯一的,不同向量的分解式是不同的.
(3)同一个非零向量在不同的基底下分解式是不同的,零向量的分解式是唯一的,即$\overrightarrow{0} = \lambda_{1} \overrightarrow{e_{1}} + \lambda_{2} \overrightarrow{e_{2}}$,且$\lambda_{1} = \lambda_{2} = 0$.
(4)这个定理可推广为:平面内任意三个不共线的向量中,任何一个向量都可表示例示为其余两个向量的线性组合,且形式唯一.
### 知识点02 ：平面向量基本定理的有关结论
（1）设$\overrightarrow{e_{1}}$,$\overrightarrow{e_{2}}$是平面内一组基底，若$\overrightarrow{a} = \lambda_{1} \overrightarrow{e_{1}} + \lambda_{2} \overrightarrow{e_{2}}$，当$\lambda_{1} = 0$时，$\overrightarrow{a}$与$\overrightarrow{e_{2}}$共线；当$\lambda_{2} = 0$时，$\overrightarrow{a}$与$\overrightarrow{e_{1}}$共线；当$\lambda_{1} = \lambda_{2} = 0$时，$\overrightarrow{a} = \overrightarrow{0}$，同样的$\overrightarrow{a} = \overrightarrow{0}$时，$\lambda_{1} = \lambda_{2} = 0$.
（2）设$\overrightarrow{a} , \overrightarrow{b}$是同一平面内的两个不共线的向量，若$x_{1} \overrightarrow{a} + y_{1} \overrightarrow{b} = x_{2} \overrightarrow{a} + y_{2} \overrightarrow{b}$，则$\begin{cases} & x_{1} = x_{2} \\  & y_{1} = y_{2}\end{cases}$.

$= \frac{1}{5} ( 3 + \frac{2 n}{m} + \frac{m}{n} ) \geq \frac{1}{5} ( 3 + 2 \sqrt{\frac{2 n}{m} \cdot \frac{m}{n}} ) = \frac{3 + 2 \sqrt{2}}{5}$，当且仅当$\frac{2 n}{m} = \frac{m}{n}$，即$m = \sqrt{2} n = \frac{2 + \sqrt{2}}{5}$取等号，
所以当$m = \frac{2 + \sqrt{2}}{5} , n = \frac{1 + \sqrt{2}}{5}$时，$m + n$取得最小值$\frac{3 + 2 \sqrt{2}}{5}$.
故答案为：$2$；$\frac{3 + 2 \sqrt{2}}{5}$
