### 知识点03 ：$\mathbf{|} \mathbf{z}_{\mathbf{1}} \mathbf{-} \mathbf{z}_{\mathbf{2}} \mathbf{|}$ ($\mathbf{z}_{\mathbf{1}} \mathbf{,} \mathbf{z}_{\mathbf{2}} \mathbf{\in} \mathbf{C}$)的几何意义
在复平面内,设复数$z_{1} = a + b i$，$z_{2} = c + d i$（$a , b , c , d \in R$）对应的点分别是$Z_{1} ( a , b )$，$Z_{2} ( c , d )$,则$| Z_{1} Z_{2} | = \sqrt{( a - c )^{2} + ( b - d )^{2}}$.又复数$z_{1} - z_{2} = ( a + b i ) - ( c + d i ) = ( a - c ) + ( b - d ) i$.则$| z_{1} - z_{2} | = \sqrt{( a - c )^{2} + ( b - d )^{2}}$,故$| Z_{1} Z_{2} | = | z_{1} - z_{2} |$，即$| z_{1} - z_{2} |$表示复数$z_{1} , z_{2}$在复平面内对应的点之间的距离.
【即学即练3】（2023·福建福州·福建省福州第一中学校考三模）已知复数，$z_{2}$满足$z_{1} = i$，$\left| z_{1} - z_{2} \right| = 3$，则$\left| z_{2} \right|$的最大值为 .
<span class="fake-tag">答案</span>4
<span class="fake-tag">详解</span>设$z_{2} = a + b i ( a \in R , b \in R )$，
则$z_{1} - z_{2} = i - ( a + b i ) = - a + ( 1 - b ) i$，
所以$\left| z_{1} - z_{2} \right| = \sqrt{a^{2} + ( b - 1 )^{2}} = 3$，即$a^{2} + ( b - 1 )^{2} = 9$，$b \in [ - 2 , 4 ]$，
$\left| z_{2} \right| = \sqrt{a^{2} + b^{2}} = \sqrt{9 - ( b - 1 )^{2} + b^{2}} = \sqrt{2 b + 8}$，
当时，则$\left| z_{2} \right|$取得最大值，最大值为$\sqrt{2 \times 4 + 8} = 4$.

##### 题型03 与复数的模的几何意义有关的应用
##### 【典例1】（2023·江西·统考模拟预测）已知复数$z$满足$| z - i | = | z |$，则$| z |$的最小值为（ ）

$\therefore | z | = \sqrt{x^{2} + \frac{1}{4}} \geq \frac{1}{2}$（当且仅当$x = 0$时取等号），的最小值为$\frac{1}{2}$.
