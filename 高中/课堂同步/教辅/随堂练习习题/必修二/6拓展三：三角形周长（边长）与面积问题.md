##### 题型01三角形周长（边）定值问题
##### 【典例1】（2023上·山东·高三济南一中校联考期中）在$\bigtriangleup A B C$中，角所对的边分别为$a , b , c$，已知$\frac{\text{cos} B}{b} + \frac{\text{cos} C}{c} = \frac{1}{a}$，且$a = 2 \sqrt{2} , c > a > b$．
(1)求$b c$的值；
(2)若$\bigtriangleup A B C$的面积$S = \sqrt{7}$，求$b , c$的值．
<span class="fake-tag">答案</span>(1)$b c = 8$
(2)$b = 2 , c = 4$
<span class="fake-tag">详解</span>（1）由题意，将$\cos B = \frac{a^{2} + c^{2} - b^{2}}{2 a c} , \cos C = \frac{a^{2} + b^{2} - c^{2}}{2 a b}$ 代入$\frac{\text{cos} B}{b} + \frac{\text{cos} C}{c} = \frac{1}{a}$，
$\frac{a^{2} + c^{2} - b^{2}}{2 a b c} + \frac{b^{2} + a^{2} - c^{2}}{2 a b c} = \frac{1}{a}$，即$\frac{2 a^{2}}{2 a b c} = \frac{1}{a}$，所以$b c = a^{2} = \left( 2 \sqrt{2} \right)^{2} = 8$．
故$b c = 8$.
（2）由于$S_{\bigtriangleup A B C} = \frac{1}{2} b c \text{sin} A = 4 \text{sin} A = \sqrt{7} ， \therefore \text{sin} A = \frac{\sqrt{7}}{4}$，

所以$\begin{cases}b c = 8 \\ b + c = 6\end{cases}$，结合$c > a > b$解得$\begin{cases}b = 2 \\ c = 4\end{cases}$.
