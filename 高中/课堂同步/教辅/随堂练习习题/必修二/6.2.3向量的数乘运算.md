### 知识点01 ：向量的数乘
（1）向量数乘的定义
一般地,我们规定实数$\lambda$与向量$\overrightarrow{a}$的积是一个向量,这种运算叫做向量的数乘,记作$\lambda \overrightarrow{a}$.它的长度与方向规定如下：
①$| \lambda \overrightarrow{a} | = | \lambda | | \overrightarrow{a} |$
②当$\lambda > 0$时，$\lambda \overrightarrow{a}$的方向与$\overrightarrow{a}$的方向相同；当$\lambda < 0$时，$\lambda \overrightarrow{a}$的方向与$\overrightarrow{a}$的方向相反；当$\lambda = 0$时，$\lambda \overrightarrow{a} = \overrightarrow{0}$.
【即学即练1】（2023·全国·高一随堂练习）任作一向量，再作向量$\overrightarrow{O B} = 2 \overrightarrow{O A}$，$\overrightarrow{O C} = - \frac{1}{3} \overrightarrow{O A}$.
<span class="fake-tag">答案</span>答案见解析
<span class="fake-tag">详解</span>由$\overrightarrow{O B} = 2 \overrightarrow{O A}$知，$\overrightarrow{O B}$与同向，模长为模长的2倍，由此作出$\overrightarrow{O B}$；
由$\overrightarrow{O C} = - \frac{1}{3} \overrightarrow{O A}$知，$\overrightarrow{O C}$与方向相反，模长为模长的，由此作出$\overrightarrow{O C}$；
![@@@c0925676-dab1-451c-8a2c-5e71b2f9a10b](a31bccc4067597833054dbe0177936e0.png)
（2）向量数乘的几何意义
对于$\lambda \overrightarrow{a}$：①从代数角度看，$\lambda$是实数，$\overrightarrow{a}$是向量，它们的积仍然是向量．$\lambda \overrightarrow{a}$的条件是$\overrightarrow{a} = \overrightarrow{0}$或$\lambda = 0$．②从几何的角度看，对于长度来说，当$| \lambda | > 1$时，意味着表示向量$\overrightarrow{a}$的有向线段在原方向$( \lambda > 0 )$或相反方向$( \lambda < 0 )$上伸长了$| \lambda |$倍；当$0 < | \lambda | < 1$时，意味着表示向量$\overrightarrow{a}$的有向线段在原方向$( 0 < \lambda < 1 )$或反方向$( - 1 < \lambda < 0 )$上缩短了$| \lambda |$倍．
实数与向量可以求积，但不能进行加减运算，如$\lambda + \overrightarrow{a}$，$\lambda - \overrightarrow{a}$都无意义．
（3）向量数乘的运算律
实数与向量的积满足下面的运算律：设$\lambda$、$\mu$是实数，$\overrightarrow{a}$、$\overrightarrow{b}$是向量，则：
①结合律：$\lambda \left( \mu \overrightarrow{a} \right) = \lambda \mu \overrightarrow{a}$
②第一分配律：$( \lambda + \mu ) \overrightarrow{a} = \lambda \overrightarrow{a} + \mu \overrightarrow{a}$
③第二分配律：$\lambda \left( \overrightarrow{a} + \overrightarrow{b} \right) = \lambda \overrightarrow{a} + \lambda \overrightarrow{b}$
### 知识点02 ：向量的线性运算
向量的加、减、数乘运算统称为向量的线性运算.向量线性运算的结果仍是向量.
对于任意向量$\overrightarrow{a}$,$\overrightarrow{b}$,以及任意实数$\lambda$,$\mu_{1}$,$\mu_{2}$,恒有$\lambda ( \mu_{1} \overrightarrow{a} \pm \mu_{2} \overrightarrow{b} ) = \lambda \mu_{1} \overrightarrow{a} \pm \lambda \mu_{2} \overrightarrow{b}$.
### 知识点03 ：向量共线定理
（1）内容：向量$\overrightarrow{b}$与非零向量$\overrightarrow{a}$共线，则存在唯一一个实数$\lambda$，$\overrightarrow{b} = \lambda \overrightarrow{a}$.
（2）向量共线定理的注意问题：
①定理的运用过程中要特别注意$\overrightarrow{a} \neq \overrightarrow{0}$．
特别地，若$\overrightarrow{a} = \overrightarrow{b} = \overrightarrow{0}$，实数$\lambda$仍存在，但不唯一．
②定理的实质是向量相等，应从大小和方向两个方面理解，借助于实数$\lambda$沟通了两个向量$\overrightarrow{b}$与$\overrightarrow{a}$的关系．
③定理为解决三点共线和两直线平行问题提供了一种方法．要证三点共线或两直线平行，任取两点确定两个向量，看能否找到唯一的实数$\lambda$使向量相等即可．

<span class="fake-tag">详解</span>证明：因为$\overrightarrow{A D} = \overrightarrow{A B} + \overrightarrow{B C} + \overrightarrow{C D}$
