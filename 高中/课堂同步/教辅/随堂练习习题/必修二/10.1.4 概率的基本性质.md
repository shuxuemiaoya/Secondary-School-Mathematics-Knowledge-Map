### 知识点01 ：概率的基本性质（性质1、性质2、性质5）
性质1：对任意的事件$A$，都有$P ( A ) \geq 0$；
性质2：必然事件的概率为1，不可能事件的概率为0，即$P ( \Omega ) = 1$，$P ( \varnothing ) = 0$；
性质5：如果$A \subseteq B$，那么$P ( A ) \leq P ( B )$，由该性质可得，对于任意事件$A$，因为$\varnothing \subseteq A \subseteq \Omega$，所以$0 \leq P ( A ) \leq 1$.
### 知识点02 ：互斥事件的概率加法公式（性质3）
性质3：如果事件$A$与事件$B$互斥，那么$P ( A \cup B ) = P ( A ) + P ( B )$；
注意：只有事件$A$与事件$B$互斥，才可以使用性质3，否则不能使用该加法公式.
【即学即练1】（2024上·江西吉安·高一统考期末）已知事件*A*，*B*是互斥事件，$P ( A ) = \frac{1}{6}$，$P \left( \overline{B} \right) = \frac{2}{3}$，则$P ( A \cup B ) =$（ ）
$\quad$A．$\frac{1}{18}$ 
$\quad$B． 
$\quad$C．$\frac{1}{2}$ 
$\quad$D．
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>∵$P ( B ) = 1 - P \left( \bar{B} \right)$，$P \left( \bar{B} \right) = \frac{2}{3}$，
∴$P ( B ) = \frac{1}{3}$，
∵事件*A*，*B*是互斥事件，
∴$P ( A \cup B ) = P ( A ) + P ( B ) = \frac{1}{6} + \frac{1}{3} = \frac{1}{2}$．
故选：C
### 知识点03 ：对立事件的概率（性质4）
性质4：如果事件$A$与事件$B$互为对立事件，那么$P ( B ) = 1 - P ( A )$，$P ( A ) = 1 - P ( B )$；
【即学即练2】（2024上·广东·高三学业考试）将一颗骰子连续抛掷两次，至少出现一次6点向上的概率是（ ）
$\quad$A．$\frac{1}{18}$ 
$\quad$B．$\frac{11}{36}$ 
$\quad$C．$\frac{25}{36}$ 
$\quad$D．$\frac{1}{36}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>将一颗质地均匀的骰子先后抛掷一次，出现一次6点向上的概率为$\frac{1}{6}$，
所以先后抛掷2次，没有一次6点向上的概率为$( 1 - \frac{1}{6} )^{2} = \frac{25}{36}$，
所以至少出现一次6点向上的概率为$1 - \frac{25}{36} = \frac{11}{36}$.
故选：B.
### 知识点04 ：概率的一般加法公式（性质6）
性质6：设$A$，$B$是一个随机试验中的两个事件，有$P ( A \cup B ) = P ( A ) + P ( B ) - P ( A \cap B )$
【即学即练3】（2024·全国·模拟预测）设$A , B$是随机事件，且$P ( A ) = \frac{3}{8} , P ( B ) = \frac{3}{4} , P \left( A \cup \bar{B} \right) = \frac{1}{2}$，则$P \left( A \cap \bar{B} \right) =$ ．
<span class="fake-tag">答案</span>$\frac{1}{8}$/0.125
<span class="fake-tag">详解</span>因为$P ( B ) = \frac{3}{4}$，所以$P \left( \overline{B} \right) = 1 - P ( B ) = \frac{1}{4}$，
故$P \left( A \cap \bar{B} \right) = P ( A ) + P \left( \bar{B} \right) - P \left( A \cup \bar{B} \right) = \frac{3}{8} + \frac{1}{4} - \frac{1}{2} = \frac{1}{8}$．
故答案为：$\frac{1}{8}$

##### 题型01互斥事件与对立事件
##### 【典例1】（2023下·广东珠海·高一校考期末）某人在射击比赛中连续射击2次，事件“2次都不命中”的对立事件是（ ）
$\quad$A．至多有1次命中
$\quad$B．2次都命中
$\quad$C．只有1次命中
$\quad$D．至少有1次命中
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>记事件*A*为“2次都不命中”，事件*B*为“只有1次命中”，事件*C*“2次都命中”，
则样本空间为$A \cup B \cup C$，
对于选项A：至多有1次命中为$A \cup B$，与事件*A*不对立，故A错误；
对于选项B：2次都命中为$C$，与事件*A*不对立，故B错误；
对于选项C：只有1次命中$B$，与事件*A*不对立，故C错误；
对于选项D：至少有1次命中为$B \cup C$，与事件*A*对立，故D正确；
故选：D.

##### 题型02互斥事件概率加法公式的应用
##### 【典例1】（2023下·福建宁德·高一统考期末）设$A , B$为两个互斥事件，且$P ( A ) > 0$，$P ( B ) > 0$，则下列各式一定正确的是（ ）
