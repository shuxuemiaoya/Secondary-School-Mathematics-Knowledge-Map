### 知识点01 ：相互独立事件的概念
对任意两个事件$A$与$B$，如果$P ( A B ) = P ( A ) P ( B )$成立，则称事件$A$与事件$B$相互独立(mutually independent)，简称为独立．
性质1：必然事件$\Omega$、不可能事件$\varnothing$与任意事件相互独立
性质2：如果事件$A$与$B$相互独立，则$A$与$\overline{B}$，$\overline{A}$与$B$，$\overline{A}$与$\overline{B}$也相互独立
则：$P \left( A \overline{B} \right) = P ( A ) P \left( \overline{B} \right)$，$P \left( \overline{A} B \right) = P \left( \overline{A} \right) P ( B )$，$P \left( \overline{A} \overline{B} \right) = P \left( \overline{A} \right) P \left( \overline{B} \right)$

### 知识点02 ：相互独立事件概率的求法
已知两个事件$A$，$B$相互独立，它们的概率分别为$P ( A )$，$P ( B )$，则有
| 事件                         | 表示                                                                    | 概率                                                                                                                                                                                                                                                        |
|------------------------------|-------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| $A$，$B$同时发生         | $ A B $                                                               | $ P ( A B ) = P ( A ) P ( B ) $                                                                                                                                                                                                                           |
| $A$，$B$都不发生         | $ \overline{A} \overline{B} $                                         | $ P ( \overline{A} \overline{B} ) = P ( \overline{A} ) P ( \overline{B} ) = \lbrack 1 - P ( A ) \rbrack \lbrack 1 - P ( B ) \rbrack $                                                                                                                     |
| $A$，$B$恰有一个发生     | $ A \overline{B} \cup \overline{A} B $                                | $ P ( A \overline{B} \cup \overline{A} B ) = P ( A \overline{B} ) + P ( \overline{A} B ) = P ( A ) P ( \overline{B} ) + P ( \overline{A} ) P ( B ) $                                                                                                      |
| $A$，$B$中至少有一个发生 | $ A \overline{B} \cup \overline{A} B \cup A B $                       | $ P ( A \overline{B} \cup \overline{A} B \cup A B ) = P ( A \overline{B} ) + P ( \overline{A} B ) + P ( A B ) $ 或$P ( A \overline{B} \cup \overline{A} B \cup A B ) = 1 - P ( \overline{A} \overline{B} )$                                             |
| $A$，$B$中至多有一个发生 | $ A \overline{B} \cup \overline{A} B \cup \overline{A} \overline{B} $ | $ P ( A \overline{B} \cup \overline{A} B \cup \overline{A} \overline{B} ) = P ( A \overline{B} ) + P ( \overline{A} B ) + P ( \overline{A} \overline{B} ) $ 或$P ( A \overline{B} \cup \overline{A} B \cup \overline{A} \overline{B} ) = 1 - P ( A B )$ |
### 知识点03 ：互斥事件与相互独立事件的区别与联系
|          | 相互独立事件                                                  | 互斥事件                                                        |
|----------|---------------------------------------------------------------|-----------------------------------------------------------------|
| 判断方法 | 一个事件发生与否对另一个事件发生的概率没有影响                | 两个事件不可能同时发生， 即$A \cap B = \varnothing$           |
| 概率公式 | 事件$A$与$B$相互独立等价于$P ( A B ) = P ( A ) P ( B )$ | 事件$A$与$B$互斥， 则$P ( A \cup B ) = P ( A ) + P ( B )$ |

##### 题型01 相互独立事件的判断
##### 【典例1】（2024上·上海嘉定·高二上海市嘉定区第一中学校考期末）设$A$、$B$是两个事件，以下说法正确的是（ ）．
$\quad$A．若$P ( A ) + P ( B ) = 1$，则事件$A$与事件$B$对立
$\quad$B．若$P ( A ) + P ( B ) = 1$，则事件$A$与事件$B$互斥
$\quad$C．若$P ( A \cup B ) = P ( A ) + P ( B )$，则事件$A$与事件$B$互斥且不对立
$\quad$D．若$P ( A \cap B ) = P ( A ) P ( B )$，则事件$A$与事件$B$相互独立
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>对于A和B，例如抛掷一枚质地均匀的骰子，
记事件$A$为“出现偶数点”，事件$B$为“出现1点或2点或3点”，
则$P ( A ) = 0 . 5$，$P ( B ) = 0 . 5$，$P ( A ) + P ( B ) = 1$，
但事件$A$，$B$既不互斥也不对立，故A和B错误；
对于C，在不同的试验下，即使$P ( A \cup B ) = P ( A ) + P ( B )$，也不能说明事件$A$与事件$B$一定互斥， 故C错误；
对于D，根据相互独立事件的定义可知，若$P ( A \cap B ) = P ( A ) P ( B )$，
则事件$A$与事件$B$相互独立，故D正确；
故选：D

##### 题型02相互独立事件与互斥事件
##### 【典例1】（2024上·全国·高三专题练习）已知$P ( A \cup B ) = \frac{25}{32}$，$P \left( \overline{A} \right) = \frac{7}{8}$，$P ( B ) = \frac{3}{4}$，则事件$A$与$B$的关系是（ ）
$\quad$A．$A$与$B$互斥不对立 
$\quad$B．$A$与$B$对立
$\quad$C．$A$与$B$相互独立 
$\quad$D．$A$与$B$既互斥又独立
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>由$P \left( \overline{A} \right) = \frac{7}{8}$可得$P ( A ) = 1 - P \left( \overline{A} \right) = 1 - \frac{7}{8} = \frac{1}{8}$，
因为$P ( A ) + P ( B ) = \frac{7}{8} \neq P ( A \cup B )$，则$A$与$B$不互斥，不对立，
由$P ( A \cup B ) = P ( A ) + P ( B ) - P ( A \cap B )$可得$P ( A \cap B ) = \frac{3}{32}$，
因为$P ( A ) \times P ( B ) = \frac{3}{32} = P ( A \cap B )$，所以$A$与$B$相互独立
故选：C
