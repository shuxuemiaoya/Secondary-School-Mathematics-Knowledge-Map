### 知识点01 ： 平面与平面垂直的性质定理
（1）定理：两个平面垂直，则一个平面内垂直于交线的直线与另一个平面垂直．
(2)符号（图形）语言：$\mathbf{\alpha} \mathbf{\bot} \mathbf{\beta}$，$\alpha \cap \beta = l$，$a \subset \alpha , a \bot l$ $\Rightarrow a \bot \beta$.

(3)应用：①面面垂直$\Rightarrow$线面垂直 ②作平面的垂线.

$\quad$B．$B D \bot$平面$A B C$
$\quad$C．$A B \bot C D$ 
$\quad$D．$A O \bot$平面$B C D$

<span class="fake-tag">详解</span>因为平面$A B C \bot$平面$B C D$，平面$A B C \cap$平面$B C D = B C , B C \bot B D$，
所以$B D \bot$平面$A B C$，即B项正确；
因为$A C \subset$平面$A B C$，所以$B D \bot A C$，即A正确；

所以$B C \bot A O$，同理可得$A O \bot$平面$B C D$，即D正确；
因为$B D \bot$平面$A B C$，$A B \subset$平面$A B C$，所以$B D \bot A B$，
