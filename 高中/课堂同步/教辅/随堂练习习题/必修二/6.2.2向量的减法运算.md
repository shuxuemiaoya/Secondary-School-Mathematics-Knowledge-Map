### 知识点01 ：向量的减法
（1）相反向量
与向量$\overrightarrow{a}$长度相等,方向相反的向量,叫做$\overrightarrow{a}$的相反向量，记作$- \overrightarrow{a}$.
①零向量的相反向量仍是零向量
②任意向量与其相反向量的和是零向量，即:$\overrightarrow{a} + ( - \overrightarrow{a} ) = \overrightarrow{0}$
③若$\overrightarrow{a}$,$\overrightarrow{b}$互为相反向量,则$\overrightarrow{a} = - \overrightarrow{b}$，$\overrightarrow{b} = - \overrightarrow{a}$，$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{0}$.
（2）向量减法定义
向量$\overrightarrow{a}$加上$\overrightarrow{b}$的相反向量，叫做$\overrightarrow{a}$与$\overrightarrow{b}$的差，即$\overrightarrow{a} - \overrightarrow{b} = \overrightarrow{a} + ( - \overrightarrow{b} )$.
求两个向量差的运算叫做向量的减法.
向量减法的实质是向量加法的逆运算.利用相反向量的定义,可以把向量的减法转化为向量的加法进行运算.
（3）向量减法的几何意义

### 知识点02 ：向量三角不等式
①已知非零向量$\overrightarrow{a}$，$\overrightarrow{b}$，则$| | \overrightarrow{a} | - | \overrightarrow{b} | | \leq | \overrightarrow{a} + \overrightarrow{b} | \leq | \overrightarrow{a} | + | \overrightarrow{b} |$（当$\overrightarrow{a}$与$\overrightarrow{b}$反向共线时左边等号成立；当$\overrightarrow{a}$与$\overrightarrow{b}$同向共线时右边等号成立）；
②已知非零向量$\overrightarrow{a}$，$\overrightarrow{b}$，则$| | \overrightarrow{a} | - | \overrightarrow{b} | | \leq | \overrightarrow{a} - \overrightarrow{b} | \leq | \overrightarrow{a} | + | \overrightarrow{b} |$（当$\overrightarrow{a}$与$\overrightarrow{b}$同向共线时左边等号成立；当$\overrightarrow{a}$与$\overrightarrow{b}$反向共线时右边等号成立）；
记忆方式：（“符异”反向共线等号成立；“符同”同向共线等号成立）如$\mathbf{| |} \overrightarrow{\mathbf{a}} \mathbf{| - |} \overrightarrow{\mathbf{b}} \mathbf{| | \leq |} \overrightarrow{\mathbf{a}} \mathbf{+} \overrightarrow{\mathbf{b}} \mathbf{| \leq |} \overrightarrow{\mathbf{a}} \mathbf{| + |} \overrightarrow{\mathbf{b}} \mathbf{|}$中，$\mathbf{| |} \overrightarrow{\mathbf{a}} \mathbf{| - |} \overrightarrow{\mathbf{b}} \mathbf{| | \leq |} \overrightarrow{\mathbf{a}} \mathbf{+} \overrightarrow{\mathbf{b}} \mathbf{|}$中间连接号一负一正“符异”，故反向共线时等号成立；右如：$\mathbf{| |} \overrightarrow{\mathbf{a}} \mathbf{| - |} \overrightarrow{\mathbf{b}} \mathbf{| | \leq |} \overrightarrow{\mathbf{a}} \mathbf{+} \overrightarrow{\mathbf{b}} \mathbf{| \leq |} \overrightarrow{\mathbf{a}} \mathbf{| + |} \overrightarrow{\mathbf{b}} \mathbf{|}$中$\mathbf{| |} \overrightarrow{\mathbf{a}} \mathbf{+} \overrightarrow{\mathbf{b}} \mathbf{|} \mathbf{\leq} \mathbf{|} \overrightarrow{\mathbf{a}} \mathbf{| + |} \overrightarrow{\mathbf{b}} \mathbf{|}$中间链接号都是正号“符同”，故同向共线时等号成立；
