1、（传统法）核心技巧：平移使相交
具体操作，通过平移一条（或2条），使异面直线转化为相交直线，然后在三角形中利用余弦定理求角
2、（向量法）用向量运算求两条直线所成角
已知$a$，$b$为两异面直线，$A$，$C$与$B$，$D$分别是$a$，$b$上的任意两点，$a$，$b$所成的角为$\theta$，则
①$\cos < \overrightarrow{A C} , \overrightarrow{B D} > = \frac{\overrightarrow{A C} \cdot \overrightarrow{B D}}{| \overrightarrow{A C} | | \overrightarrow{B D} |}$
②
$\cos \theta = \left| \cos < \overrightarrow{AC}, \overrightarrow{BD} >\right|
= \frac{\left| \overrightarrow{AC} \cdot \overrightarrow{BD} \right|}
       {\left| \overrightarrow{AC} \right| \cdot \left| \overrightarrow{BD} \right|}.$

$\quad$A．$\frac{\sqrt{2}}{3}$ 
$\quad$B． 
$\quad$C．$\frac{\sqrt{2}}{6}$ 
$\quad$D．$\frac{\sqrt{3}}{6}$

<span class="fake-tag">分析</span>结合条件根据线面角的定义求得，连接$C_{1} D , D N$，根据异面直线夹角的定义，利用余弦定理求解即可.
<span class="fake-tag">详解</span>连接$A C$，因为$C_{1} C \bot$平面$A B C D$，所以$\angle C_{1} A C$为直线$A C_{1}$与平面$A B C D$所成角，
设$A B = B C = a , C C_{1} = h$，则$A C = \sqrt{2} a , A C_{1} = \sqrt{2 a^{2} + h^{2}}$，
所以$\sin \angle C_{1} A C = \frac{C_{1} C}{C_{1} A} = \frac{h}{\sqrt{2 a^{2} + h^{2}}} = \frac{\sqrt{5}}{5}$，所以$h = \frac{\sqrt{2}}{2} a$，
