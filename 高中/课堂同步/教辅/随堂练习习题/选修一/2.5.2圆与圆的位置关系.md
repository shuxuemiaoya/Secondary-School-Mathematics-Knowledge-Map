### 知识点01 ：圆与圆的位置关系
1、圆与圆的位置关系
(1)圆与圆相交，有两个公共点；
(2)圆与圆相切(内切或外切)，有一个公共点；
(3)圆与圆相离(内含或外离)，没有公共点.

2、圆与圆的位置关系的判定
##### 2.1几何法
设$\odot C_{1}$的半径为$r_{1}$，$\odot C_{2}$的半径为$r_{2}$，两圆的圆心距为$d = | C_{1} C_{2} |$.
①当$\left| r_{1} - r_{2} \right| < d < r_{1} + r_{2}$时，两圆相交；
![](124a15e74fbc1af510ca81c5dda6280d.wmf)
②当$r_{1} + r_{2} = d$时，两圆外切；
![](3d223a88efad9082a8ea6f6ebd69c50d.wmf)
③当$r_{1} + r_{2} < d$时，两圆外离；
![](1ebb20b6476c48608a79e8832fe62e0e.wmf)
![](124a15e74fbc1af510ca81c5dda6280d.wmf)④当$\left| r_{1} - r_{2} \right| = d$时，两圆内切；
⑤当$\left| r_{1} - r_{2} \right| > d$时，两圆内含.
![](124a15e74fbc1af510ca81c5dda6280d.wmf)
##### 2.2代数法
设$\odot C_{1}$:$( x - a_{1} )^{2} + ( y - b_{1} )^{2} = r_{1}^{2}\odot C_{2}$:$( x - a_{2} )^{2} + ( y - b_{2} )^{2} = r_{2}^{2}$
联立$\begin{cases} & ( x - a_{1} )^{2} + ( y - b_{1} )^{2} = r_{1}^{2} \\  & ( x - a_{2} )^{2} + ( y - b_{2} )^{2} = r_{2}^{2}\end{cases}$消去“$y$”得到关于“$x$”的一元二次方程$p x^{2} + q x + r = 0$，求出其$\Delta = q^{2} - 4 p r$
①$\Delta = q^{2} - 4 p r > 0 \Leftrightarrow \odot C_{1}$与设设$\odot C_{1}$相交
②$\Delta = q^{2} - 4 p r = 0 \Leftrightarrow \odot C_{1}$与设设$\odot C_{1}$相切（内切或外切）
③$\Delta = q^{2} - 4 p r < 0 \Leftrightarrow \odot C_{1}$与设设$\odot C_{1}$相离（内含或外离）

$\quad$A．相交 
$\quad$B．外离 
$\quad$C．外切 
$\quad$D．内含

<span class="fake-tag">分析</span>分别考虑$C_{1}$上两点$( 0 , - 2 )$和与$C_{2}$的位置关系，即可推知两圆的位置关系.
<span class="fake-tag">详解</span>由于点$( 0 , - 2 )$和都在圆$x^{2} + y^{2} + 6 y + 8 = 0$上，而$( 0 , - 2 )$在圆$x^{2} + y^{2} = 9$内部，
在圆$x^{2} + y^{2} = 9$外部，故两圆一定相交.

![](759644bd3a3480bc469890e7b358f1a5.png)知识点02：圆与圆的公共弦
1、圆与圆的公共弦
圆与圆相交得到的两个交点，这两点之间的线段就是两圆的公共弦.
2、公共弦所在直线的方程
设$\odot C_{1}$:$( x - a_{1} )^{2} + ( y - b_{1} )^{2} = r_{1}^{2}$
$\odot C_{2}$:$( x - a_{2} )^{2} + ( y - b_{2} )^{2} = r_{2}^{2}$
联立作差得到：$A x + B y + C = 0$即为两圆共线方程
3、公共弦长的求法
代数法：将两圆的方程联立，解出两交点的坐标，利用两点间的距离公式求其长．
几何法：求出公共弦所在直线的方程，利用勾股定理解直角三角形，求出弦长．
【即学即练2】（23-24高二下·贵州·阶段练习）已知圆与圆交于*A*，*B*两点，则$| A B | =$（ ）
$\quad$A．$\frac{\sqrt{15}}{2}$ 
$\quad$B．5 
$\quad$C．$\sqrt{26}$ 
$\quad$D．$3 \sqrt{3}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>求出两圆的公共弦所在直线方程，再求出弦长即可.
<span class="fake-tag">详解</span>圆$O_{1} : ( x + 1 )^{2} + y^{2} = 1 1$的圆心$O_{1} ( - 1 , 0 )$，半径$r_{1} = \sqrt{11}$，
圆$O_{2} : ( x - \frac{1}{2} )^{2} + ( y - \frac{3}{2} )^{2} = \frac{13}{2}$的圆心$O_{2} ( \frac{1}{2} , \frac{3}{2} )$，半径$r_{2} = \frac{\sqrt{26}}{2}$，
$| O_{1} O_{2} | = \frac{3 \sqrt{2}}{2} \in ( r_{1} - r_{2} , r_{1} + r_{2} )$，圆$O_{1}$与圆$O_{2}$相交，两圆方程相减得直线$A B$：$x + y = 2$，
显然点$O_{2} ( \frac{1}{2} , \frac{3}{2} )$在直线$A B$上，因此线段$A B$是圆$O_{2}$的直径，
所以$| A B | = \sqrt{26}$.
故选：C
### 知识点03 ：圆与圆的公切线
1、公切线的条数
与两个圆都相切的直线叫做两圆的公切线，圆的公切线包括外公切线和内公切线两种．
（1）两圆外离时，有2条外公切线和2条内公切线，共4条；
![](a5c1cbbf8201db0745f06bf270632bbe.wmf)
（2）两圆外切时，有2条外公切线和1条内公切线，共3条；
![](0c5bfcc96f05653bbc8adfa422e4f113.wmf)
（3）两圆相交时，只有2条外公切线；
![](f7238beb3931930f2e1be57e50e50e51.wmf)
![](af6161db2dbe4de056574b9d0a68dcef.wmf)（4）两圆内切时，只有1条外公切线；
（5）两圆内含时，无公切线．
![](af6161db2dbe4de056574b9d0a68dcef.wmf)
2、公切线的方程
核心技巧：利用圆心到切线的距离$d = r$求解
【即学即练3】（2024·河北张家口·三模）圆$C_{1} : ( x - 1 )^{2} + y^{2} = 1$与圆的公切线的方程为 ．
<span class="fake-tag">答案</span>$4 x + 3 y + 1 = 0$
<span class="fake-tag">分析</span>先判断两圆位置关系，然后将圆$C_{1} , C_{2}$化为一般式，两式相减可得.
<span class="fake-tag">详解</span>圆$C_{1}$的圆心为$( 1 , 0 )$，半径为1，圆$C_{2}$的圆心为$( 5 , 3 )$，半径为6，
因为$\left| C_{1} C_{2} \right| = \sqrt{( 5 - 1 )^{2} + ( 3 - 0 )^{2}} = 5 = 6 - 1$，所以两圆内切，只有一条公切线，
将圆$C_{1} , C_{2}$化为一般式得：
$C_{1} : x^{2} + y^{2} - 2 x = 0$，$C_{2} : x^{2} + y^{2} - 1 0 x - 6 y - 2 = 0$，
两式相减得$8 x + 6 y + 2 = 0$，即$4 x + 3 y + 1 = 0$，
所以圆$C_{1} , C_{2}$的公切线的方程为$4 x + 3 y + 1 = 0$.
故答案为：$4 x + 3 y + 1 = 0$
![](759644bd3a3480bc469890e7b358f1a5.png)知识点04：圆系方程
$( 1 )$ 以$( a , b )$为圆心的同心圆圆系方程：$( x - a )^{2} + ( y - b )^{2} = \lambda ( \lambda > 0 )$；
$( 2 )$ 与圆$x^{2} + y^{2} + D x + E y + F = 0$同心圆的圆系方程为$x^{2} + y^{2} + D x + E y + \lambda = 0$；
$( 3 )$ 过直线$A x + B y + C = 0$与圆$x^{2} + y^{2} + D x + E y + F = 0$交点的圆系方程为
$x^{2} + y^{2} + D x + E y + F + \lambda ( A x + B y + C ) = 0 ( \lambda \in R )$( 4 )$ 过两圆$x^{2} + y^{2} + D_{1} x + E_{1} y + F_{1} = 0$，圆$C_{2}$：$x^{2} + y^{2} + D_{2} x + E_{2} y + F_{2} = 0$交点的圆系方程为
$x^{2} + y^{2} + D_{1} x + E_{1} y + F_{1} + \lambda ( x^{2} + y^{2} + D_{2} x + E_{2} y + F_{2} ) = 0$（$\lambda \neq - 1$，此时圆系不含圆$C_{2}$：$x^{2} + y^{2} + D_{2} x + E_{2} y + F_{2} = 0$）特别地，当$\lambda = - 1$时，上述方程为一次方程.
两圆相交时，表示公共弦方程；两圆相切时，表示公切线方程.

##### 【典例1】（23-24高二下·浙江·开学考试）若圆$x^{2} - 2 a x + y^{2} = 0$与圆$x^{2} + y^{2} - 4 x - 2 y - 4 = 0$只有一个交点，则实数$a$的值可以是（ ）
