### 知识点04 ：直线与椭圆的位置关系
1、直线与椭圆的位置关系
将直线的方程$y = k x + b$与椭圆的方程$\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 ( a > b > 0 )$联立成方程组，消元转化为关于$x$或$y$的一元二次方程，其判别式为$\Delta$.
①$\Delta > 0 \Leftrightarrow$直线和椭圆相交$\Leftrightarrow$直线和椭圆有两个交点(或两个公共点）；
②$\Delta = 0 \Leftrightarrow$直线和椭圆相切$\Leftrightarrow$直线和椭圆有一个切点(或一个公共点)；
③$\Delta < 0 \Leftrightarrow$直线和椭圆相离$\Leftrightarrow$直线和椭圆无公共点．
【即学即练3】（23-24高二上·上海宝山·期中）若直线$y = k x - 1$与椭圆$\frac{x^{2}}{5} + \frac{y^{2}}{m} = 1$恒有公共点，则实数*m*的取值范围是 ．
<span class="fake-tag">答案</span>$m \geq 1$且$m \neq 5$

2、直线与椭圆的相交弦
直线与椭圆问题（韦达定理的运用）
（1）弦长公式：若直线$l : y = k x + b$与圆锥曲线相交与$A$、$B$两点，$A （ x_{1} , y_{1} ) , B ( x_{2} , y_{2} )$则：
弦长$| A B | = \sqrt{( x_{1} - x_{2} )^{2} + ( y_{1} - y_{2} )^{2}} = \sqrt{( x_{1} - x_{2} )^{2} + ( k x_{1} - k x_{2} )^{2}}$ $= \sqrt{1 + k^{2}} \left| x_{1} - x_{2} \right|$
$= \sqrt{1 + k^{2}} \sqrt{( x_{1} + x_{2} )^{2} - 4 x_{1} x_{2}}$
弦长$\sqrt{1 + \frac{1}{k^{2}}} \left| y_{1} - y_{2} \right|$
这里$| x_{1} - x_{2} | , | y_{1} - y_{2} | ,$的求法通常使用韦达定理，需作以下变形：
$| x_{1} - x_{2} | = \sqrt{( x_{1} + x_{2} )^{2} - 4 x_{1} x_{2}}$； $| y_{1} - y_{2} | = \sqrt{( y_{1} + y_{2} )^{2} - 4 y_{1} y_{2}}$
（2）结论1：已知弦$A B$是椭圆$\frac{\mathbf{x}^{\mathbf{2}}}{\mathbf{a}^{\mathbf{2}}} \mathbf{+} \frac{\mathbf{y}^{\mathbf{2}}}{\mathbf{b}^{\mathbf{2}}} \mathbf{= 1}$（$\mathbf{a > b > 0}$）的一条弦，中点$M$坐标为$( x_{0} , y_{0} )$，则$A B$的斜率为$- \frac{b^{2} x_{0}}{a^{2} y_{0}}$
运用点差法求$A B$的斜率，设$A ( x_{1} , y_{1} )$，$B ( x_{2} , y_{2} )$；$A$、$B$都在椭圆上，$\begin{cases} & \frac{x_{1}^{2}}{a^{2}} + \frac{y_{1}^{2}}{b^{2}} = 1 \\  & \frac{x_{2}^{2}}{a^{2}} + \frac{y_{2}^{2}}{b^{2}} = 1\end{cases}$
两式相减得：$\frac{x_{1}^{2} - x_{2}^{2}}{a^{2}} + \frac{y_{1}^{2} - y_{2}^{2}}{b^{2}} = 0$，$\frac{( x_{1} - x_{2} ) ( x_{1} + x_{2} )}{a^{2}} - \frac{( y_{1} - y_{2} ) ( y_{1} + y_{2} )}{b^{2}} = 0$
即 $\frac{y_{1} - y_{2}}{x_{1} - x_{2}} = - \frac{b^{2}}{a^{2}} \cdot \frac{x_{1} + x_{2}}{y_{1} + y_{2}} = - \frac{b^{2} x_{0}}{a^{2} y_{0}}$，故$k_{A B} = - \frac{b^{2} x_{0}}{a^{2} y_{0}}$
结论2：弦$A B$的斜率与弦中心$M$和椭圆中心$O$的连线的斜率之积为定值：$- \frac{b^{2}}{a^{2}}$
