### 知识点01 ：两条直线的交点坐标
直线$\mathbf{l}_{\mathbf{1}}$：$\mathbf{A}_{\mathbf{1}} \mathbf{x +} \mathbf{B}_{\mathbf{1}} \mathbf{y +} \mathbf{C}_{\mathbf{1}} \mathbf{= 0}$（$\mathbf{A}_{\mathbf{1}}^{\mathbf{2}} \mathbf{+} \mathbf{B}_{\mathbf{1}}^{\mathbf{2}} \mathbf{\neq} \mathbf{0}$）和$\mathbf{l}_{\mathbf{2}}$：$\mathbf{A}_{\mathbf{2}} \mathbf{x +} \mathbf{B}_{\mathbf{2}} \mathbf{y +} \mathbf{C}_{\mathbf{2}} \mathbf{= 0}$（$\mathbf{A}_{\mathbf{2}}^{\mathbf{2}} \mathbf{+} \mathbf{B}_{\mathbf{2}}^{\mathbf{2}} \mathbf{\neq} \mathbf{0}$）的公共点的坐标与方程组$\begin{cases}\mathbf{\&} \mathbf{A}_{\mathbf{1}} \mathbf{x +} \mathbf{B}_{\mathbf{1}} \mathbf{y +} \mathbf{C}_{\mathbf{1}} \mathbf{= 0} \\ \mathbf{\&} \mathbf{A}_{\mathbf{2}} \mathbf{x +} \mathbf{B}_{\mathbf{2}} \mathbf{y +} \mathbf{C}_{\mathbf{2}} \mathbf{= 0}\end{cases}$的解一一对应.
$\mathbf{l}_{\mathbf{1}}$与$\mathbf{l}_{\mathbf{2}}$相交$\mathbf{\Leftrightarrow}$方程组有唯一解，交点坐标就是方程组的解；
$\mathbf{l}_{\mathbf{1}}$与$\mathbf{l}_{\mathbf{2}}$平行$\mathbf{\Leftrightarrow}$方程组无解；
$\mathbf{l}_{\mathbf{1}}$与$\mathbf{l}_{\mathbf{2}}$重合$\mathbf{\Leftrightarrow}$方程组有无数个解.

(2)重合；
(3)平行.
<span class="fake-tag">分析</span>（1）联立方程求解，即可判断$l_{1}$与$l_{2}$关系；
（2）（3）根据各项系数比值关系，即可判断$l_{1}$与$l_{2}$关系.
<span class="fake-tag">详解</span>（1）由$\begin{cases}2 x + y + 3 = 0 \\ x - 2 y - 1 = 0\end{cases}$，解得$\begin{cases} & x = - 1 \\  & y = - 1\end{cases}$，所以交点坐标为，故$l_{1}$与$l_{2}$相交.

平面上任意两点$\mathbf{P}_{\mathbf{1}} \mathbf{(} \mathbf{x}_{\mathbf{1}} \mathbf{,} \mathbf{y}_{\mathbf{1}} \mathbf{)}$，$\mathbf{P}_{\mathbf{2}} \mathbf{(} \mathbf{x}_{\mathbf{2}} \mathbf{,} \mathbf{y}_{\mathbf{2}} \mathbf{)}$间的距离公式为$\mathbf{|} \mathbf{P}_{\mathbf{1}} \mathbf{P}_{\mathbf{2}} \mathbf{| =} \sqrt{\mathbf{(} \mathbf{x}_{\mathbf{2}} \mathbf{-} \mathbf{x}_{\mathbf{1}} \mathbf{)}^{\mathbf{2}} \mathbf{+ (} \mathbf{y}_{\mathbf{2}} \mathbf{-} \mathbf{y}_{\mathbf{1}} \mathbf{)}^{\mathbf{2}}}$
特别地，原点$\mathbf{O ( 0 , 0 )}$与任一点$\mathbf{P ( x , y )}$的距离$\mathbf{| O P | =} \sqrt{\mathbf{x}^{\mathbf{2}} \mathbf{+} \mathbf{y}^{\mathbf{2}}}$.
【即学即练2】（2024高二上·全国·专题练习）已知点$A ( 2 , m )$与点$B ( m , 1 )$间的距离是$\sqrt{13}$，则实数$m =$ .

∴$m^{2} - 3 m - 4 = 0$，解得$m = - 1$或$m = 4$；
故答案为：或$4$

### 知识点05 ：对称问题
1、点关于点对称问题(方法：中点坐标公式)
求点$P ( x_{1} , y_{1} )$关于点$A ( x_{0} , y_{0} )$的对称点$Q ( a , b )$
由：$\begin{cases}\mathbf{\&} \mathbf{x}_{\mathbf{0}} \mathbf{=} \frac{\mathbf{x}_{\mathbf{1}} \mathbf{+ a}}{\mathbf{2}} \\ \mathbf{\&} \mathbf{y}_{\mathbf{0}} \mathbf{=} \frac{\mathbf{y}_{\mathbf{0}} \mathbf{+ b}}{\mathbf{2}}\end{cases}$\begin{cases}\mathbf{\& a = 2} \mathbf{x}_{\mathbf{0}} \mathbf{-} \mathbf{x}_{\mathbf{1}} \\ \mathbf{\& b = 2} \mathbf{y}_{\mathbf{0}} \mathbf{-} \mathbf{y}_{\mathbf{1}}\end{cases}$
2、点关于直线对称问题（联立两个方程）
求点$P ( x_{1} , y_{1} )$关于直线$l$：$A x + B y + C = 0$的对称点$Q ( a , b )$
![](10a995d2c8886182c47c71f5311a3294.png)①设$P Q$中点为$A$利用中点坐标公式得$A ( \frac{x_{1} + a}{2} , \frac{y_{1} + b}{2} )$，将$A ( \frac{x_{1} + a}{2} , \frac{y_{1} + b}{2} )$代入直线$l$：$A x + B y + C = 0$中；
②$k_{P Q} \cdot k_{l} = - 1$
整理得：
$\begin{cases}\mathbf{\& A} \frac{\mathbf{x}_{\mathbf{1}} \mathbf{+ a}}{\mathbf{2}} \mathbf{+ B} \frac{\mathbf{y}_{\mathbf{1}} \mathbf{+ b}}{\mathbf{2}} \mathbf{+ C = 0} \\ \mathbf{\&} \frac{\mathbf{y}_{\mathbf{1}} \mathbf{-} \mathbf{b}}{\mathbf{x}_{\mathbf{1}} \mathbf{-} \mathbf{a}} \mathbf{\cdot} \mathbf{(} \mathbf{-} \frac{\mathbf{A}}{\mathbf{B}} \mathbf{) =} \mathbf{-} \mathbf{1}\end{cases}$
【即学即练5】（23-24高二上·北京西城·阶段练习）点$( 2 , 3 )$关于直线$y = x + 3$的对称点坐标为 .

<span class="fake-tag">分析</span>根据中点关系以及垂直斜率关系即可求解.
<span class="fake-tag">详解</span>设点$( 2 , 3 )$关于直线$y = x + 3$的对称点坐标为$( a , b )$，

所以对称点为$( 0 , 5 )$，
故答案为：$( 0 , 5 )$
3、直线关于点对称问题(求$\mathbf{l}_{\mathbf{1}}$关于点$\mathbf{P} \left( \mathbf{a , b} \right)$的对称直线$\mathbf{l}_{\mathbf{2}}$，则$\mathbf{l}_{\mathbf{1}} \mathbf{\parallel} \mathbf{l}_{\mathbf{2}}$）

<span class="fake-tag">详解</span>本题的关键是理解折线距离的定义．
（1）证明$\rho ( A , C ) + \rho ( C , B ) = \left| x - x_{1} \right| + \left| y - y_{1} \right| + \left| x_{2} - x \right| + \left| y_{2} - y \right|$
$\geq \left| x - x_{1} + x_{2} - x \right| + \left| y - y_{1} + y_{2} - y \right|$= \left| x_{2} - x_{1} \right| + \left| y_{2} - y_{1} \right| = \rho ( A , B )$．
所以$\rho ( A , C ) + \rho ( C , B ) \geq \rho ( A , B )$．
（2）先考虑相异两点*A*，*B*的特殊情况，当*A*，*B*两点横坐标或者纵坐标相同时，*AB*即是平行于*y*轴或者*x*轴的直线段，符合条件的*C*点即为*AB*的中点（这属于折线的特殊情况——直线）．当*A*，*B*两点的横、纵坐标各异，即$x_{1} \neq x_{2}$，$y_{1} \neq y_{2}$时，不妨设$x_{1} < x_{2}$，下面讨论$y_{1} < y_{2}$，$y_{1} > y_{2}$两种情况．
假设$y_{1} < y_{2}$，则由条件①可得$\left| x - x_{1} \right| + \left| y - y_{1} \right| + \left| x_{2} - x \right| + \left| y_{2} - y \right| = \left| x_{2} - x_{1} \right| + \left| y_{2} - y_{1} \right|$，
故$\left( x - x_{1} \right) \left( x_{2} - x \right) \geq 0$，$\left( y - y_{1} \right) \left( y_{2} - y \right) \geq 0$，即$x_{1} \leq x \leq x_{2}$，$y_{1} \leq y \leq y_{2}$．
又由条件②$\rho ( A , C ) = \rho ( C , B )$，即$\left| x - x_{1} \right| + \left| y - y_{1} \right| = \left| x_{2} - x \right| + \left| y_{2} - y \right|$，
去掉绝对值符号可得$x - x_{1} + y - y_{1} = x_{2} - x + y_{2} - y$，
即$x + y = \frac{x_{1} + x_{2} + y_{1} + y_{2}}{2}$，也即$y = - x + \frac{x_{1} + x_{2}}{2} + \frac{y_{1} + y_{2}}{2}$．
同理，假设$y_{1} > y_{2}$，当$x_{1} \leq x \leq x_{2}$，$y_{2} \leq y \leq y_{1}$时，
可得$x - y = \frac{x_{1} + x_{2}}{2} - \frac{y_{1} + y_{2}}{2}$．
【反思】取点$C ( x , y )$使，$y = \frac{y_{1} + y_{2}}{2}$，验知此时点$C ( x , y )$同时满足条件（ⅰ）、（ⅱ），则存在点*C*满足题意，且所有符合条件的点*C*是线段*AB*的中点$\left( \frac{x_{1} + x_{2}}{2} , \frac{y_{1} + y_{2}}{2} \right)$．
