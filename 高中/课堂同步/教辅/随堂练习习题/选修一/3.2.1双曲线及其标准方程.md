### 知识点01 ：双曲线的定义
1、定义:一般地,我们把平面内与两个定点$F_{1}$,$F_{2}$的距离的差的绝对值等于非零常数(小于$| F_{1} F_{2} |$)的点的轨迹叫做双曲线.
这两个定点叫做双曲线的焦点,两焦点间的距离叫做双曲线的焦距.
2、集合语言表达式
双曲线就是下列点的集合:$P = \{ M | | | M F_{1} | - | M F_{2} | | = 2 a , 0 < 2 a < | F_{1} F_{2} | \}$.
3、说明
若将定义中差的绝对值中的绝对值符号去掉,则点$M$的轨迹为双曲线的一支,具体是哪一支,取决于$| M F_{1} |$与$| M F_{2} |$的大小.
(1)若$| M F_{1} | > | M F_{2} |$,则$| M F_{1} | - | M F_{2} | > 0$,点$M$的轨迹是靠近定点$F_{2}$的那一支;
(2)若$| M F_{1} | < | M F_{2} |$,则$| M F_{2} | - | M F_{1} | > 0$,点$M$的轨迹是靠近定点$F_{1}$的那一支.
【即学即练1】（2024·福建莆田·三模）已知圆$C : ( x - 3 )^{2} + y^{2} = 1 6$，$A ( - 3 , 0 )$，*P*是圆*C*上的动点，线段$P A$的垂直平分线与直线$P C$（点*C*是圆*C*的圆心）交于点*M*，则点*M*的轨迹是（ ）
$\quad$A．圆 
$\quad$B．椭圆 
$\quad$C．双曲线 
$\quad$D．抛物线
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>利用双曲线的定义结合垂直平分线的性质判定即可.
<span class="fake-tag">详解</span>由题意可得圆心$C ( 3 , 0 )$，半径$r = 4$.
因为*M*是线段$P A$的垂直平分线，所以$| M A | = | M P |$，
则$| M A | - | M C | = \left| | M P | - | M C | \right| = | C P | = 4$.
因为$| A C | = 6 > | C P |$，所以点*M*的轨迹是以*A*，*C*为焦点的双曲线.
故选：C
### 知识点02 ：双曲线的标准方程
| 焦点位置                     | 焦点在$\mathbf{x}$轴上                                                                                                                                                  | 焦点在$\mathbf{y}$轴上                                                                                                                                                  |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 标准方程                     | $\frac{\mathbf{x}^{\mathbf{2}}}{\mathbf{a}^{\mathbf{2}}} \mathbf{-} \frac{\mathbf{y}^{\mathbf{2}}}{\mathbf{b}^{\mathbf{2}}} \mathbf{= 1}$（$\mathbf{a > 0 , b > 0}$） | $\frac{\mathbf{y}^{\mathbf{2}}}{\mathbf{a}^{\mathbf{2}}} \mathbf{-} \frac{\mathbf{x}^{\mathbf{2}}}{\mathbf{b}^{\mathbf{2}}} \mathbf{= 1}$（$\mathbf{a > 0 , b > 0}$） |
| 图象                         | ![](ac59a4a93d6778d3e22876dc2eb0a9de.jpeg)                                                                                                                                  | ![](7fdc9635459dff15e90ab915ef0544d5.jpeg)                                                                                                                                  |
| 焦点坐标                     | $\mathbf{F}_{\mathbf{1}} \mathbf{(} \mathbf{-} \mathbf{c , 0 )}$，$\mathbf{F}_{\mathbf{2}} \mathbf{( c , 0 )}$                                                            | $\mathbf{F}_{\mathbf{1}} \mathbf{( 0 ,} \mathbf{-} \mathbf{c )}$，$\mathbf{F}_{\mathbf{2}} \mathbf{( 0 , c )}$                                                            |
| $\mathbf{a , b , c}$的关系 | $ \mathbf{c}^{\mathbf{2}} \mathbf{=} \mathbf{a}^{\mathbf{2}} \mathbf{+} \mathbf{b}^{\mathbf{2}} $                                                                               |                                                                                                                                                                                   |
两种双曲线 $\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1$，$\frac{y^{2}}{a^{2}} - \frac{x^{2}}{b^{2}} = 1$ （$a > 0 , b > 0$）的相同点是:它们的形状、大小都相同,都有$a > 0 , b > 0$,$c^{2} = a^{2} + b^{2}$;不同点是:两种双曲线的位置不同,它们的焦点坐标也不同.
【即学即练2】（23-24高三下·四川德阳·期末）双曲线的焦点坐标是$\left( - \sqrt{5} , 0 \right)$和$\left( \sqrt{5} , 0 \right)$，实轴长是2，则其方程是（ ）
$\quad$A． 
$\quad$B．$x^{2} - \frac{y^{2}}{4} = 1$
$\quad$C．$x^{2} - 4 y^{2} = 1$ 
$\quad$D．$\frac{x^{2}}{4} - \frac{y^{2}}{16} = 1$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>确定$a , b , c$即可得双曲线方程.
<span class="fake-tag">详解</span>双曲线的焦点坐标是$\left( - \sqrt{5} , 0 \right)$和$\left( \sqrt{5} , 0 \right)$可得$c = \sqrt{5}$，
实轴长是2可得$a = 1$，
所以$b^{2} = c^{2} - a^{2} = 4$，
所以方程是$x^{2} - \frac{y^{2}}{4} = 1$.
故选：B.

##### 【典例1】（23-24高二上·湖北武汉·期中）平面内到两定点$A ( - 6 , 0 )$、的距离之差等于10的点的轨迹为（ ）

$\quad$D．以上选项都不对
<span class="fake-tag">答案</span>D

$\quad$A．椭圆

$\quad$C．双曲线 
$\quad$D．两条射线

<span class="fake-tag">详解</span>因为$\left| \left| M F_{1} \right| - \left| M F_{2} \right| \right| = 6$，$\left| F_{1} F_{2} \right| = 6$，

##### 题型02利用双曲线定义求方程
##### 【典例1】（2024高三·全国·专题练习）若动点$P ( x , y )$满足方程$\left| \sqrt{( x + 2 )^{2} + y^{2}} - \sqrt{( x - 2 )^{2} + y^{2}} \right| = 3$，则动点*P*的轨迹方程为（ ）
$\quad$A．$\frac{x^{2}}{\frac{9}{4}} - \frac{y^{2}}{\frac{7}{4}} = 1$ 
$\quad$B．$\frac{x^{2}}{\frac{9}{4}} + \frac{y^{2}}{\frac{7}{4}} = 1$ 
$\quad$C．$\frac{x^{2}}{8} + \frac{y^{2}}{4} = 1$ 
$\quad$D．$\frac{x^{2}}{16} - \frac{y^{2}}{12} = 1$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据双曲线定义得到点*P*的轨迹方程是以$A ( - 2 , 0 )$与$B ( 2 , 0 )$为焦点的双曲线，得到答案.
<span class="fake-tag">详解</span>由题意得点$P ( x , y )$到点$A ( - 2 , 0 )$与点$B ( 2 , 0 )$的距离之差的绝对值为3，且$4 > 3$，
故动点*P*的轨迹方程是以$A ( - 2 , 0 )$与$B ( 2 , 0 )$为焦点的双曲线，
故$2 a = 3 , c = 2$，
所以$a = \frac{3}{2} , b^{2} = c^{2} - a^{2} = 4 - \frac{9}{4} = \frac{7}{4}$，
所以双曲线的方程为$\frac{x^{2}}{\frac{9}{4}} - \frac{y^{2}}{\frac{7}{4}} = 1$.
故选：A.
##### 【典例2】（2024·山东青岛·一模）已知$A ( - 2 , 0 )$，$B ( 2 , 0 )$，设点*P*是圆$x^{2} + y^{2} = 1$上的点，若动点*Q*满足：$\overrightarrow{Q P} \cdot \overrightarrow{P B} = 0$，$\overrightarrow{Q P} = \lambda \left( \frac{\overrightarrow{Q A}}{| \overrightarrow{Q A} |} + \frac{\overrightarrow{Q B}}{| \overrightarrow{Q B} |} \right)$，则*Q*的轨迹方程为（ ）
$\quad$A．$x^{2} - \frac{y^{2}}{3} = 1$ 
$\quad$B． 
$\quad$C．$\frac{x^{2}}{5} + y^{2} = 1$ 
$\quad$D．$\frac{x^{2}}{6} + \frac{y^{2}}{2} = 1$

<span class="fake-tag">分析</span>根据题意，点$P$在$\angle B Q A$的平分线上且$Q P \bot P B$，由此作出图形，利用等腰三角形“三线合一”与三角形中位线定理，证出$| Q A | - | Q B | = 2$，从而得到$Q$的轨迹方程.
<span class="fake-tag">详解</span>由$\overrightarrow{Q P} \cdot \overrightarrow{P B} = 0$，可得$Q P \bot P B$，
而$\overrightarrow{Q P} = \lambda \left( \frac{\overrightarrow{Q A}}{\left| \overrightarrow{Q A} \right|} + \frac{\overrightarrow{Q B}}{\left| \overrightarrow{Q B} \right|} \right)$，可知点$P$在$\angle B Q A$的平分线上.

$\quad$A．充分不必要条件 
$\quad$B．必要不充分条件
$\quad$C．充要条件 
$\quad$D．既不充分也不必要条件
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据双曲线的标准方程，结合充分、必要条件的概念即可求解.
<span class="fake-tag">详解</span>若$m > 1$，则$m - 1 > 0 , m + 3 > 0$，所以方程$\frac{x^{2}}{m - 1} - \frac{y^{2}}{m + 3} = 1$表示双曲线；
若方程$\frac{x^{2}}{m - 1} - \frac{y^{2}}{m + 3} = 1$表示双曲线，则$( m - 1 ) ( m + 3 ) > 0$，解得$m < - 3$或$m > 1$，
