### 知识点01 ：直线的一般式方程
定义:关于$x$,$y$的二元一次方程都表示一条直线.我们把关于$x$,$y$的二元一次方程$A x + B y + C = 0$ (其中
$A$,$B$不同时为0$A^{2} + B^{2} \neq 0$)叫做直线的一般式方程,简称一般式.
说明：
##### 1．$A$、$B$不全为零才能表示一条直线，若$A$、$B$全为零则不能表示一条直线.
当$B \neq 0$时，方程可变形为$y = - \frac{A}{B} x - \frac{C}{B}$，它表示过点$\left( 0 , - \frac{C}{B} \right)$，斜率为$- \frac{A}{B}$的直线．
当$B = 0$，$A \neq 0$时，方程可变形为$A x + C = 0$，即$x = - \frac{C}{A}$，它表示一条与$x$轴垂直的直线．
由上可知，关于$x$、$y$的二元一次方程，它都表示一条直线．
##### 2．在平面直角坐标系中，一个关于$x$、$y$的二元一次方程对应着唯一的一条直线，反过来，一条直线可以对应着无数个关于$x$、$y$的一次方程.
##### 3.解题时,如无特殊说明,应把最终结果化为一般式.
【即学即练1】（多选）（23-24高二上·河北石家庄·阶段练习）下列命题中错误的是（ ）

$\quad$C．直线的一般式方程为$A x + B y + C = 0$ 
$\quad$D．任何一条直线至少要经过两个象限
<span class="fake-tag">答案</span>BCD
<span class="fake-tag">分析</span>利用直线倾斜角、斜率的意义判断AB；利用直线一般式方程的条件判断C；举例说明判断D.
<span class="fake-tag">详解</span>对于A，直线的倾斜角，则其斜率$k = \tan \alpha < 0$，A正确；
