### 知识点03 ：直线与双曲线的位置关系
1、代数法：设直线$l : y = k x + m$，双曲线$\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1 ( a > 0 , b > 0 )$联立解得：
$( b^{2} - a^{2} k^{2} ) x^{2} - 2 a^{2} m k x - a^{2} m^{2} - a^{2} b^{2} = 0$
（1）$m = 0$时，$- \frac{b}{a} < k < \frac{b}{a}$，直线与双曲线交于两点（左支一个点右支一个点）；
$k \geq \frac{b}{a}$，$k \leq - \frac{b}{a}$，或k不存在时，直线与双曲线没有交点；
（2）$m \neq 0$时，
$k$存在时，若$b^{2} - a^{2} k^{2} = 0$，$k = \pm \frac{b}{a}$，直线与双曲线渐近线平行，直线与双曲线相交于一点；
若$b^{2} - a^{2} k^{2} \neq 0$，$\Delta = ( - 2 a^{2} m k )^{2} - 4 ( b^{2} - a^{2} k^{2} ) ( - a^{2} m^{2} - a^{2} b^{2} ) = 4 a^{2} b^{2} ( m^{2} + b^{2} - a^{2} k^{2} )$\Delta > 0$时，$m^{2} + b^{2} - a^{2} k^{2} > 0$，直线与双曲线相交于两点；
$\Delta < 0$时，$m^{2} + b^{2} - a^{2} k^{2} < 0$，直线与双曲线相离，没有交点；
$\Delta = 0$时$m^{2} + b^{2} - a^{2} k^{2} = 0$，$k^{2} = \frac{m^{2} + b^{2}}{a^{2}}$直线与双曲线有一个交点；相切
$k$不存在，$- a < m < a$时，直线与双曲线没有交点；
$m > a 或 m < - a$直线与双曲线相交于两点；

### 知识点06 ：双曲线中点弦的斜率公式
