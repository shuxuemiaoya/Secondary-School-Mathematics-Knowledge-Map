### 知识点01 ：空间向量的有关概念
1、空间向量的有关概念
（1）概念：在空间，我们把具有大小和方向的量叫做空间向量，空间向量的大小叫做空间向量的长度或模；如空间中的位移速度、力等．
（2）几类特殊的空间向量![学科网 zxxk.com](d8ff2e643d345d5a33b5f0d77c811641.png)
| 名称   | 定义及表示                                                                                    |
| ---- | ---------------------------------------------------------------------------------------- |
| 零向量  | 长度为0的向量叫做零向量，记为$\overrightarrow{0}$                                                      |
| 单位向量 | 模为1的向量称为单位向量                                                                             |
| 相反向量 | 与向量$\overrightarrow{a}$长度相等而方向相反的向量，称为$\overrightarrow{a}$的相反向量，记为$- \overrightarrow{a}$ |
| 相等向量 | 方向相同且模相等的向量称为相等向量                                                                        |
2、空间向量的表示
表示方法：和平面向量一样，空间向量有两种表示方法：
（1）几何表示法：用有向线段$\overrightarrow{A B}$来表示，$A$叫向量的起点，$B$叫向量的终点；
（2）字母表示法：用$\overrightarrow{a} , \overrightarrow{b} , \overrightarrow{c}$表示．向量$\overrightarrow{a}$的起点是$A$，终点是$B$，则向量$\overrightarrow{a}$也可以记作$\overrightarrow{A B}$，其模记为$\left| \overrightarrow{a} \right|$或$\left| \overrightarrow{A B} \right|$.

### 知识点02 ：空间向量的加法、减法运算
1、空间向量的位置：已知空间向量$\overrightarrow{a} , \overrightarrow{b}$，可以把它们平移到同一平面$\alpha$内，以任意点$O$为起点，作向量$\overrightarrow{O A} = \overrightarrow{a}$，$\overrightarrow{O B} = \overrightarrow{b}$
![](1077d6d1065124128e52c22c332f6919.png)
2、空间向量的加法运算（首尾相接首尾连）：作向量$\overrightarrow{A C} = \overrightarrow{b}$，则向量$\overrightarrow{O C}$叫做向量$\overrightarrow{a} , \overrightarrow{b}$的和．记作$\overrightarrow{a} + \overrightarrow{b}$，即$\overrightarrow{O C} = \overrightarrow{A C} = \overrightarrow{a} + \overrightarrow{b}$
![](b155032a4452f505d015a51029c83559.png)
3、空间向量的减法运算（共起点，连终点，指向被减向量）：向量$\overrightarrow{B A}$叫做$\overrightarrow{a}$与$\overrightarrow{b}$!的差，记作$\overrightarrow{a} - \overrightarrow{b}$，即$\overrightarrow{B A} = \overrightarrow{O A} - \overrightarrow{O B} = \overrightarrow{a} - \overrightarrow{b}$
![](8427adba9e53b85ac0b0be7e3cb31628.png)
4、空间向量的加法运算律
（1）加法交换律：$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{b} + \overrightarrow{a}$
（2）加法结合律：$\overrightarrow{a} + \overrightarrow{b} + \overrightarrow{c} = \overrightarrow{a} + \left( \overrightarrow{b} + \overrightarrow{c} \right)$

### 知识点03 ：空间向量的数乘运算
1、定义：与平面向量一样，实数$\lambda$与空间向量$\overrightarrow{a}$的乘积仍然是一个向量，称为向量的数乘运算．
2：数乘向量与向量$\overrightarrow{\mathbf{a}}$的关系
| $\lambda$的范围  | 的方向                                                       | 的模  |                            |     |         |     |                    |     |
| ------------- | --------------------------------------------------------- | --- | -------------------------- | --- | ------- | --- | ------------------ | --- |
| $\lambda > 0$ | 与向量$\overrightarrow{a}$的方向相同                              | $   | \lambda \overrightarrow{a} | =   | \lambda |     | \overrightarrow{a} | $   |
| $\lambda = 0$ | $\lambda \overrightarrow{a} = \overrightarrow{0}$，其方向是任意的 |     |                            |     |         |     |                    |     |
| $\lambda < 0$ | 与向量$\overrightarrow{a}$的方向相反                              |     |                            |     |         |     |                    |     |
3、对数乘向量与向量$\overrightarrow{\mathbf{a}}$的关系的进一步理解：
（1）可以把向量$\overrightarrow{a}$!的模扩大（当$| \lambda | > 1$时），也可缩小（当$| \lambda | < 1$时）；可以不改变向量$\overrightarrow{a}$的方向（当$\lambda > 0$时），也可以改变向量$\overrightarrow{a}$的方向（当$\lambda < 0$时）．
（2）实数与向量的积的特殊情况：当$\lambda = 0$时，$\lambda \overrightarrow{a} = \overrightarrow{0}$；当$\lambda \neq 0$时，若$\overrightarrow{a} = \overrightarrow{0}$，则$\lambda \overrightarrow{a} = \overrightarrow{0}$．
（3）实数与向量可以求积，但是不能进行加减，例如，$\lambda + \overrightarrow{a}$，$\lambda - \overrightarrow{a}$没有意义，无法运算．

### 知识点04 ：共线向量与共面向量
1、共线（平行）向量的定义：若表示空间向量的有向线段所在的直线互相平行或重合，则这些向量叫做共线向量或平行向量，若$\overrightarrow{a}$与$\overrightarrow{b}$是共线向量，则记为$\overrightarrow{a} / / \overrightarrow{b}$．
在正确理解共线向量的定义时，要注意以下两点：
（1）零向量和空间任一向量是共线向量．
（2）共线向量不具有传递性，如$\overrightarrow{a} / / \overrightarrow{b} , \overrightarrow{b} / / \overrightarrow{c}$，那么$\overrightarrow{a} / / \overrightarrow{c}$不一定成立，因为当$\overrightarrow{b} = \overrightarrow{0}$时，虽然$\overrightarrow{a} / / \overrightarrow{b} , \overrightarrow{b} / / \overrightarrow{c}$，但$\overrightarrow{a}$不一定与$\overrightarrow{c}$共线（特别注意$\overrightarrow{0}$，$\overrightarrow{0}$与任何向量共线）．
2、共线向量定理：对空间任意两个向量$\overrightarrow{a} , \overrightarrow{b} ( b \neq \overrightarrow{0} )$，$\overrightarrow{a} \parallel \overrightarrow{b}$的充要条件是存在实数$\lambda$，使$\overrightarrow{a} = \lambda \overrightarrow{b}$．
##### 2.1共线向量定理推论：如果$l$为经过点$A$平行于已知非零向量$\overrightarrow{a}$的直线,那么对于空间任一点$O$,点$P$在直线$l$上的充要条件是存在实数$t$,使$\overrightarrow{O P} = \overrightarrow{O A} + t \overrightarrow{a}$①，若在$l$上取$\overrightarrow{A B} = \overrightarrow{a}$，则①可以化作：$\overrightarrow{O P} = \overrightarrow{O A} + t \overrightarrow{A B}$
![](48d30a3f29b3187e2f2f7ea9927b6de4.jpeg)
##### 2.2拓展(高频考点）：对于直线外任意点$O$，空间中三点$P , A , B$共线的充要条件是$\overrightarrow{O P} = \lambda \overrightarrow{O A} + \mu \overrightarrow{A B}$，其中$\lambda + \mu = 1$
3、共面向量定义：平行于同一个平面的向量，叫做共面向量．
##### 3.1共面向量定理：如果两个向量$\overrightarrow{a} , \overrightarrow{b}$不共线，那么向量$\overrightarrow{p}$与向量$\overrightarrow{a} , \overrightarrow{b}$共面的充要条件是存在唯一的有序实数对，使$\overrightarrow{p} = x \overrightarrow{a} + y \overrightarrow{b}$
##### 3.2空间共面向量的表示
如图空间一点$P$位于平面$A B C$内的充要条件是存在有序实数对，使$\overrightarrow{A P} = x \overrightarrow{A B} + y \overrightarrow{A C}$．
![](2905b2378748ca80d0781ac301ce2ff0.png)
或者等价于：对空间任意一点$O$，空间一点$P$位于平面$A B C$内（$P , A , B , C$四点共面）的充要条件是存在有序实数对，使$\overrightarrow{O P} = \overrightarrow{O A} + x \overrightarrow{A B} + y \overrightarrow{A C}$，该式称为空间平面$A B C$的向量表示式，由此可知，空间中任意平面由空间一点及两个不共线向量唯一确定．
##### 3.3拓展
对于空间任意一点$O$，四点$P , C , A , B$共面（其中$C , A , B$不共线）的充要条件是$\overrightarrow{O P} = x \overrightarrow{O C} + y \overrightarrow{O A} + z \overrightarrow{O B}$（其中$x + y + z = 1$）．
