### 知识点 二：累加法（叠加法）
若数列$\left\{ a_{n} \right\}$满足$a_{n + 1} - a_{n} = f ( n ) )_{}^{} ( n \in N^{*} )$，则称数列$\left\{ a_{n} \right\}$为“变差数列”，求变差数列$\left\{ a_{n} \right\}$的通项时，利用恒等式$a_{n} = a_{1} + ( a_{2} - a_{1} ) + ( a_{3} - a_{2} ) + \cdot \cdot \cdot + ( a_{n} - a_{n - 1} ) = a_{1} + f ( 1 ) + f ( 2 ) + f ( 3 ) + \cdot \cdot \cdot + f ( n - 1 )^{} ( n \geq 2 )$求通项公式的方法称为累加法。
具体步骤：
$a_{2} - a_{1} = f ( 1 )$
a_{3} - a_{2} = f ( 2 )
$a_{4} - a_{3} = f ( 3 )$
\vdots                                        \vdots
$a_{n} - a_{n - 1} = f ( n - 1 )$
将上述$n - 1$个式子相加（左边加左边，右边加右边）得：
$( a_{2} - a_{1} ) + ( a_{3} - a_{2} ) + ( a_{4} - a_{3} ) + \cdots + ( a_{n} - a_{n - 1} )$ =$f ( 1 ) + f ( 2 ) + f ( 3 ) + \cdots + f ( n - 1 )$
整理得：$a_{n} - a_{1}$=$f ( 1 ) + f ( 2 ) + f ( 3 ) + \cdots + f ( n - 1 )$
### 知识点 三：累乘法（叠乘法）

### 知识点 四：构造法
类型1： 用“待定系数法”构造等比数列
形如$a_{n + 1} = k a_{n} + p$（$k , p$为常数，$k p \neq 0$）的数列，可用“待定系数法”将原等式变形为$a_{n + 1} + m = k ( a_{n} + m )$（其中：$m = \frac{p}{k - 1}$），由此构造出新的等比数列$\left\{ a_{n} + m \right\}$，先求出$\left\{ a_{n} + m \right\}$的通项，从而求出数列$\left\{ a_{n} \right\}$的通项公式.
标准模型：$a_{n + 1} = k a_{n} + p$（$k , p$为常数，$k p \neq 0$）或$a_{n} = k a_{n - 1} + p$（$k , p$为常数，$k p \neq 0$）
类型2：用“同除法”构造等差数列
（1）形如$a_{n + 1} = q a_{n} + p \cdot q^{n + 1} ( n \in N^{*} )$，可通过两边同除$q^{n + 1}$，将它转化为$\frac{a_{n + 1}}{q^{n + 1}} = \frac{a_{n}}{q^{n}} + p$，从而构造数列$\left\{ \frac{a_{n}}{q^{n}} \right\}$为等差数列，先求出$\left\{ \frac{a_{n}}{q^{n}} \right\}$的通项，便可求得$\left\{ a_{n} \right\}$的通项公式.
（2）形如$a_{n + 1} = k a_{n} + q^{n + 1} ( n \in N^{*} )$，可通过两边同除$q^{n + 1}$，将它转化为$\frac{a_{n + 1}}{q^{n + 1}} = \frac{k}{q} \frac{a_{n}}{q^{n}} + 1$，换元令：$b_{n} = \frac{a_{n}}{q^{n}}$，则原式化为：$b_{n + 1} = \frac{k}{q} b_{n} + 1$，先利用构造法类型1求出$b_{n}$，再求出$\left\{ a_{n} \right\}$的通项公式.
（3）形如$a_{n} - a_{n + 1} = k a_{n + 1} a_{n} ( k \neq 0 )$的数列，可通过两边同除以$a_{n + 1} a_{n}$，变形为$\frac{1}{a_{n + 1}} - \frac{1}{a_{n}} = - k$的形式，从而构造出新的等差数列$\left\{ \frac{1}{a_{n}} \right\}$，先求出$\left\{ \frac{1}{a_{n}} \right\}$的通项，便可求得$\left\{ a_{n} \right\}$的通项公式.
### 知识点 五：倒数法
用“倒数变换法”构造等差数列
类型1：形如$a_{n + 1} = \frac{q a_{n}}{p a_{n} + q}$（$p , q$为常数，$p q \neq 0$）的数列，通过两边取“倒”，变形为$\frac{1}{a_{n + 1}} = \frac{1}{a_{n}} + \frac{p}{q}$，即：$\frac{1}{a_{n + 1}} - \frac{1}{a_{n}} = \frac{p}{q}$，从而构造出新的等差数列$\left\{ \frac{1}{a_{n}} \right\}$，先求出$\left\{ \frac{1}{a_{n}} \right\}$的通项，即可求得$a_{n}$.
类型2：形如$a_{n + 1} = \frac{k a_{n}}{p a_{n} + q}$（$p , q$为常数，$p \neq 0$，$q \neq 0$，$k \neq 0$）的数列，通过两边取“倒”，变形为$\frac{1}{a_{n + 1}} = \frac{q}{k} \frac{1}{a_{n}} + \frac{p}{k}$，可通过换元：$b_{n} = \frac{1}{a_{n}}$，化简为：$b_{n + 1} = \frac{q}{k} b_{n} + \frac{p}{k}$（此类型符构造法类型1： 用“待定系数法”构造等比数列：形如$a_{n + 1} = k a_{n} + p$（$k , p$为常数，$k p \neq 0$）的数列，可用“待定系数法”将原等式变形为$a_{n + 1} + m = k ( a_{n} + m )$（其中：$m = \frac{p}{k - 1}$），由此构造出新的等比数列$\left\{ a_{n} + m \right\}$，先求出$\left\{ a_{n} + m \right\}$的通项，从而求出数列$\left\{ a_{n} \right\}$的通项公式.）
