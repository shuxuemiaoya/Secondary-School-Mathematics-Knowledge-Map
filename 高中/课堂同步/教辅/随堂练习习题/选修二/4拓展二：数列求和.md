### 一、知识点归纳
### 知识点 一：倒序相加法
即如果一个数列的前$n$项中，距首末两项“等距离”的两项之和都相等，则可使用倒序相加法求数列的前$n$项和.![学科网 zxxk.com](e7a853e3a6713709573522ec186e88d3.png)
### 知识点 二：分组求和法
1如果一个数列可写成$c_{n} = a_{n} \pm b_{n}$![学科网 zxxk.com](e7a853e3a6713709573522ec186e88d3.png)的形式，而数列$\left\{ a_{n} \right\}$，$\left\{ b_{n} \right\}$是等差数列或等比数列或可转化为能够求和的数列，那么可用分组求和法.
2如果一个数列可写成$c_{n} = \begin{cases} & a_{n}                n 为 奇 数 \\  & b_{n}                 n 为 偶 数\end{cases}$![学科网 zxxk.com](e7a853e3a6713709573522ec186e88d3.png)的形式，在求和时可以使用分组求和法.
### 知识点 三：裂项相消法
1、等差型
①$\frac{1}{n ( n + k )} = \frac{1}{k} ( \frac{1}{n} - \frac{1}{n + k} )$
特别注意$k = 1 , \frac{1}{n ( n + 1 )} = \frac{1}{n} - \frac{1}{n + 1} ; k = - 1 , \frac{1}{n ( n - 1 )} = \frac{1}{n - 1} - \frac{1}{n}$
②$\frac{1}{( k n - 1 ) ( k n + 1 )} = \frac{1}{2} ( \frac{1}{k n - 1} - \frac{1}{k n + 1} )$
如：$\frac{1}{4 n^{2} - 1} = \frac{1}{2} ( \frac{1}{2 n - 1} - \frac{1}{2 n + 1} )$（尤其要注意不能丢前边的$\frac{1}{2}$）
2、无理型
①$\frac{1}{\sqrt{n + k} + \sqrt{n}} = \frac{1}{k} ( \sqrt{n + k} - \sqrt{n} )$
如：$\frac{1}{\sqrt{n + 1} + \sqrt{n}} = \sqrt{n + 1} - \sqrt{n}$
3、指数型
①$\frac{( a - 1 ) a^{n}}{( a^{n + 1} + k ) ( a^{n} + k )} = \frac{1}{a^{n} + k} - \frac{1}{a^{n + 1} + k}$
如：$\frac{2^{n}}{( 2^{n + 1} + k ) ( 2^{n} + k )} = \frac{1}{2^{n} + k} - \frac{1}{2^{n + 1} + k}$
4、通项裂项为“$\mathbf{+}$”型
如：①$( - 1 )^{n} \cdot \frac{2 n + 1}{n ( n + 1 )} = ( - 1 )^{n} \left( \frac{1}{n} + \frac{1}{n + 1} \right)$
②$( - 1 )^{n} \frac{( 3 n + 1 ) \cdot 2^{n}}{n ( n + 1 )} = ( - 1 )^{n} \left( \frac{2^{n}}{n} + \frac{2^{n + 1}}{n + 1} \right)$
本类模型典型标志在通项中含有$( - 1 )^{n}$乘以一个分式.
### 知识点 四：错位相减法
错位相减法求和：如果一个数列的各项是由一个等差数列和一个等比数列的对应项之积构成的，那么这个数列的前$n$项和即可用此法来求.$q$倍错位相减法：若数列$\left\{ c_{n} \right\}$的通项公式$c_{n} = a_{n} \cdot b_{n}$，其中$\left\{ a_{n} \right\}$、$\left\{ b_{n} \right\}$中一个是等差数列，另一个是等比数列，求和时一般可在已知和式的两边都乘以组成这个数列的等比数列的公比，然后再将所得新和式与原和式相减，转化为同倍数的等比数列求和．这种方法叫$q$倍错位相减法．
### 知识点 五：奇偶项讨论求和
1、通项公式分奇、偶项有不同表达式；例如：$c_{n} = \begin{cases} & a_{n}          n 为 奇 数 \\  & b_{n}            n 为 偶 数\end{cases}$
角度1：求$c_{n} = \begin{cases} & a_{n}          n 为 奇 数 \\  & b_{n}            n 为 偶 数\end{cases}$的前$2 n$项和$T_{2 n}$
角度2：求$c_{n} = \begin{cases} & a_{n}          n 为 奇 数 \\  & b_{n}            n 为 偶 数\end{cases}$的前$n$项和$T_{n}$
2、通项含有$( - 1 )^{n}$的类型；例如：$c_{n} = ( - 1 )^{n} a_{n}$
