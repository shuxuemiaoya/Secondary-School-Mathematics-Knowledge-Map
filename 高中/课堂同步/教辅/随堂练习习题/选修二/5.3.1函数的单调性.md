### 知识点01 ：函数的单调性与导数的关系（导函数看正负，原函数看增减）
函数$y = f ( x )$在区间$( a , b )$内可导，
(1)若$f^{'} ( x ) \geq 0$，则$f ( x )$在区间$( a , b )$内是单调递增函数；
(2)若$f^{'} ( x ) \leq 0$，则$f ( x )$在区间$( a , b )$内是单调递减函数；
(3)若恒有$f^{'} ( x ) \equiv 0$，则$f ( x )$在区间$( a , b )$内是常数函数．
注意：讨论函数的单调性或求函数的单调区间的实质是解不等式，求解时，要坚持“定义域优先”原则
| 条件                                         | 恒有                       | 结论                                       |
|----------------------------------------------|----------------------------|--------------------------------------------|
| 函数$y = f ( x )$在区间$( a , b )$上可导 | $ f^{'} ( x ) \geq 0 $   | $y = f ( x )$在$( a , b )$内单调递增   |
|                                              | $ f^{'} ( x ) \leq 0 $   | $y = f ( x )$在$( a , b )$内单调递减   |
|                                              | $ f^{'} ( x ) \equiv 0 $ | $y = f ( x )$在$( a , b )$内是常数函数 |

### 知识点02 ：求已知函数（不含参）的单调区间
①求$y = f ( x )$的定义域
②求$f^{'} ( x )$
③令$f^{'} ( x ) > 0$，解不等式，求单调增区间
④令$f^{'} ( x ) < 0$，解不等式，求单调减区间
注：求单调区间时，令$f^{'} ( x ) > 0$（或$f^{'} ( x ) < 0$）不跟等号.
【即学即练2】（2023下·四川资阳·高二统考期末）函数$f ( x ) = x - \ln x$的单调递减区间为（ ）
$\quad$A．$( 0 , 1 )$ 
$\quad$B． 
$\quad$C．$( 0 , + \infty )$ 
$\quad$D．$( 0 , 1 )$，$( 0 , + \infty )$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>因为$f ( x ) = x - \ln x$，所以函数$f ( x )$的定义域为$( 0 , + \infty )$，
所以，由$f^{'} ( x ) = 1 - \frac{1}{x} < 0$有：$x < 1$，
所以函数$f ( x ) = x - \ln x$的单调递减区间为$( 0 , 1 )$，故B，C，D错误.
故选：A.
### 知识点03 ：由函数$\mathbf{f} \left( \mathbf{x} \right)$的单调性求参数的取值范围的方法
1、已知函数$\mathbf{f} \left( \mathbf{x} \right)$在区间$\mathbf{D}$上单调
①已知$f ( x )$在区间$D$上单调递增$\Leftrightarrow \forall x \in D$，$f^{'} ( x ) \geq 0$恒成立.
②已知$f ( x )$在区间$D$上单调递减$\Leftrightarrow \forall x \in D$，$f^{'} ( x ) \leq 0$恒成立.
注：已知单调性，等价条件中的不等式含等号.
2、已知函数$\mathbf{f} \left( \mathbf{x} \right)$在区间$\mathbf{D}$上存在单调区间
①已知$f ( x )$在区间$D$上存在单调增区间$\Leftrightarrow \exists x \in D$使得$f^{'} ( x ) > 0$有解
②已知$f ( x )$在区间$D$上存在单调减区间$\Leftrightarrow \exists x \in D$使得$f^{'} ( x ) < 0$有解
3、已知函数$\mathbf{f} \left( \mathbf{x} \right)$在区间$\mathbf{D}$上不单调$\Leftrightarrow \exists x_{0} \in D$，使得$\mathbf{f}^{\mathbf{'}} \left( \mathbf{x}_{\mathbf{0}} \right) \mathbf{= 0}$有变号零点
【即学即练3】（2023上·新疆·高三校联考期中）已知函数$f ( x ) = e^{x} + a x$在区间$\left. 0 , + \infty )$上单调递增，则$a$的取值范围为 .
<span class="fake-tag">答案</span>$\left. - 1 , + \infty )$
<span class="fake-tag">详解</span>因为$f ( x )$在区间$\left. 0 , + \infty )$上单调递增，
所以当$x \in \left. 0 , + \infty )$时，$f^{'} ( x ) = e^{x} + a \geq 0$恒成立，
即$a \geq - e^{x}$在$\left. 0 , + \infty )$恒成立，
又$\left( - e^{x} \right)_{\text{max}} = - 1$，所以$a \geq - 1$.
故答案为：$\left. - 1 , + \infty )$.

### 知识点04 ：含参问题讨论单调性
第一步：求$y = f ( x )$的定义域
第二步：求$f^{'} ( x )$（导函数中有分母通分）
第三步：确定导函数有效部分，记为$g ( x )$
对于$y = f ( x )$进行求导得到$f^{'} ( x )$，对$f^{'} ( x )$初步处理（如通分），提出$f^{'} ( x )$的恒正部分，将该部分省略，留下的部分则为$f^{'} ( x )$的有效部分（如：$f^{'} ( x ) = \frac{e^{x} ( x^{2} - a x + 2 )}{x^{2}}$，则记$g ( x ) = x^{2} - a x + 2$为$f^{'} ( x )$的有效部分）.接下来就只需考虑导函数有效部分，只有该部分决定$f^{'} ( x )$的正负.
第四步：确定导函数有效部分$g ( x )$的类型：
①$g ( x )$为一次型（或可化为一次型）②$g ( x )$为二次型（或可化为二次型）
第五步：通过分析导函数有效部分，讨论$y = f ( x )$的单调性

##### 题型03已知函数$\mathbf{f} \left( \mathbf{x} \right)$在区间$\mathbf{D}$上单调，求参数
##### 【典例1】（2023上·广西·高三南宁三中校联考阶段练习）若函数$f ( x ) = 2 a x - ( x + 2 ) \text{ln} x$是$( 0 , + \infty )$上的减函数，则实数$a$的最大值为 ．
<span class="fake-tag">答案</span>$1 + l n \sqrt{2}$/$\ln \sqrt{2} + 1$
<span class="fake-tag">详解</span>由函数$f ( x ) = 2 a x - ( x + 2 ) \text{ln} x$是$( 0 , + \infty )$上的减函数，
则$f^{'} ( x ) = 2 a - \text{ln} x - \frac{x + 2}{x} \leq 0$在$( 0 , + \infty )$上恒成立，
即$2 a \leq \text{ln} x + \frac{x + 2}{x}$在$( 0 , + \infty )$上恒成立，
设$g ( x ) = \text{ln} x + 1 + \frac{2}{x}$，则$g^{'} ( x ) = \frac{1}{x} - \frac{2}{x^{2}} = \frac{x - 2}{x^{2}}$，
当$x \in ( 0 , 2 )$时，$g^{'} ( x ) < 0$，函数$g ( x )$单调递减
当$x \in ( 2 , + \infty )$时，$g^{'} ( x ) > 0$，函数$g ( x )$单调递增，
可得$g ( x )_{\text{min}} = g ( 2 ) = 2 + \text{ln} 2$，所以$a \leq 1 + \text{ln} \sqrt{2}$，即实数$a$的最大值为$1 + \text{ln} \sqrt{2}$．
故答案为：$1 + \text{ln} \sqrt{2}$.
##### 【典例2】（2023·海南·校联考模拟预测）设且$a \neq \frac{1}{2}$，若函数在$( 0 , + \infty )$上单调递增，则a的取值范围是 ．

<span class="fake-tag">详解</span>由题意知：$f^{'} ( x ) = \frac{1}{x \ln a} + \frac{1}{x \ln 2 a} = \frac{\ln a + \ln 2 a}{x \ln a \ln 2 a}$，

当$\frac{1}{2} < a < 1$时，$\ln a < 0$，$\ln 2 a > 0$，要使$f^{'} ( x ) > 0$，则$\ln a + \ln 2 a < 0$，整理得${\ln a}^{2} < \ln \frac{1}{2}$，
所以$0 < a^{2} < \frac{1}{2}$，解得$\frac{1}{2} < a < \frac{\sqrt{2}}{2}$．
故答案为：$\left( \frac{1}{2} , \frac{\sqrt{2}}{2} \right)$
