### 知识点01 、函数的极值
一般地，对于函数$y = f ( x )$，
（1）若在点$x = a$处有$f^{'} ( a ) = 0$，且在点$x = a$附近的左侧有$f \  ' ( x ) < 0$，右侧有$f \  ' ( x ) > 0$，则称$x = a$为$f ( x )$的极小值点，$f ( \frac{1}{k} ) > \frac{1}{k} - 1$叫做函数$f ( x )$的极小值.
（2）若在点$x = b$处有$f \  ' ( b ) = 0$，且在点$x = b$附近的左侧有$f \  ' ( x ) > 0$，右侧有$f \  ' ( x ) < 0$，则称$x = b$为$f ( x )$的极大值点，$f ( b )$叫做函数$f ( x )$的极大值．
（3）极小值点与极大值点通称极值点，极小值与极大值通称极值.
注：极大（小）值点，不是一个点，是一个数.
【即学即练1】（2023上·广东东莞·高三校考阶段练习）若函数$f ( x ) = x^{3} - 12 x^{2} + 3 6 x + 1$，则$f ( x )$的极大值点为 .
<span class="fake-tag">答案</span>2
<span class="fake-tag">详解</span>$f^{'} ( x ) = 3 x^{2} - 2 4 x + 3 6 = 3 ( x - 2 ) ( x - 6 )$，
令$f^{'} ( x ) = 0$，解得或6，
当$x < 2$或$x > 6$时，$f^{'} ( x ) > 0$，$f ( x )$单调递增，
当$2 < x < 6$时，$f^{'} ( x ) < 0$，$f ( x )$单调递减，
故$f ( x )$在取得极大值，故极大值点为2.
故答案为：2
### 知识点02 、函数的最大（小）值
一般地，如果在区间$\lbrack a , b \rbrack$上函数$y = f ( x )$的图象是一条连续不断的曲线，那么它必有最大值与最小值.
设函数$f ( x )$在$\lbrack a , b \rbrack$上连续，在$( a , b )$内可导，求$f ( x )$在$\lbrack a , b \rbrack$上的最大值与最小值的步骤为：
（1）求$f ( x )$在$( a , b )$内的极值；
（2）将函数$f ( x )$的各极值与端点处的函数值$f ( a )$，$f ( b )$比较，其中最大的一个是最大值，最小的一个是最小值.
【即学即练2】（2023下·湖北十堰·高二统考期末）已知函数$f ( x ) = x^{3} - 3 x - 1$在区间$[ - 3 , 2 ]$上的最大值为$M$，最小值为$N$，则 .
<span class="fake-tag">答案</span>$- 19$
<span class="fake-tag">详解</span>因为$f^{'} ( x ) = 3 x^{2} - 3 = 3 ( x - 1 ) ( x + 1 ) , x \in [ - 3 , 2 ]$，
$f^{'} ( x ) > 0$，$1 < x \leq 2$或$- 3 \leq x < - 1$，
$f^{'} ( x ) < 0$，$- 1 < x < 1$，
所以$f ( x )$在$\left. - 3 , - 1 ) , \left. 1 , 2 \right.$上单调递增，在$[ - 1 , 1 ]$上单调递减.
因为$f ( - 3 ) = - 1 9 , f ( - 1 ) = 1 , f ( 1 ) = - 3 , f ( 2 ) = 1$，
所以$M = 1 , N = - 19$，故$M N = - 19$.
故答案为：$- 19$
### 知识点03 、函数的最值与极值的关系
（1）极值是对某一点附近(即局部)而言，最值是对函数的定义区间$\lbrack a , b \rbrack$的整体而言；
（2）在函数的定义区间$\lbrack a , b \rbrack$内，极大（小）值可能有多个（或者没有），但最大（小）值只有一个（或者没有）；
（3）函数$f ( x )$的极值点不能是区间的端点，而最值点可以是区间的端点；
（4）对于可导函数，函数的最大(小)值必在极大(小)值点或区间端点处取得.
【即学即练3】（2023上·天津·高三统考期中）已知函数$f ( x ) = 4 x^{3} - 3 x^{2} - 1 8 x + 2 7 , x \in R$.
(1)求$f ( x )$的单调区间与极值；
(2)求$f ( x )$在区间$[ 0 , 3 ]$上的最大值与最小值.
<span class="fake-tag">答案</span>(1)答案见解析；
(2)最大值为54，最小值为$\frac{27}{4}$.
<span class="fake-tag">详解</span>（1）由题设$f^{'} ( x ) = 1 2 x^{2} - 6 x - 1 8 = 1 2 ( x + 1 ) ( x - \frac{3}{2} )$，令$f^{'} ( x ) = 0$，得$x = - 1$或$x = \frac{3}{2}$，
当$f^{'} ( x ) > 0$时，即$1 2 ( x + 1 ) ( x - \frac{3}{2} ) > 0$，解得$x > \frac{3}{2}$或$x < - 1$，单调递增区间为和$\left( \frac{3}{2} , + \infty \right)$.
当$f^{'} ( x ) < 0$时，即$1 2 ( x + 1 ) ( x - \frac{3}{2} ) < 0$，解得$- 1 < x < \frac{3}{2}$，单调递减区间为$\left( - 1 , \mspace{6mu} \frac{3}{2} \right)$.
函数$f ( x )$的极大值为$f ( - 1 ) = 3 8$，极小值为$f ( \frac{3}{2} ) = \frac{27}{4}$.
（2）由$\frac{3}{2} \in \lbrack 0 , 3 \rbrack$，$f ( 0 ) = 2 7$，$f ( 3 ) = 5 4$，则$f ( \frac{3}{2} ) < f ( 0 ) < f ( 3 )$
且$f ( x )$在区间$\left\lbrack 0 , \mspace{6mu} 3 \right\rbrack$上连续，函数$f ( x )$在区间$\left\lbrack 0 , \mspace{6mu} 3 \right\rbrack$内的最大值为54，最小值为$\frac{27}{4}$.
