### 知识点01 ：等差数列的前$\mathbf{n}$项和公式
1、首项为$a_{1}$，末项为$a_{n}$的等差数列的前$n$项和公式$S_{n} = \frac{n ( a_{1} + a_{n} )}{2}$
2、首项为$a_{1}$，公差为$d$的等差数列的前$n$项和公式$S_{n} = n a_{1} + \frac{n ( n - 1 )}{2} d$

### 知识点02 ：等差数列前$\mathbf{n}$项和公式的函数特征
等差数列前$n$项和公式可变形为$S_{n} = \frac{d}{2} n^{2} + ( a_{1} - \frac{d}{2} ) n$.当$d \neq 0$时，它是关于$n$的二次函数，表示为$S_{n} = A n^{2} + B n$ ($A$，$B$为常数)．
### 知识点03 ：等差数列前$\mathbf{n}$项和性质
(1)若数列$\{ a_{n} \}$是公差为$d$的等差数列,则数列$\{ \frac{S_{n}}{n} \}$也是等差数列,且公差为$\frac{d}{2}$
(2)设等差数列$\{ a_{n} \}$的公差为$d$,$S_{n}$为其前$n$项和,则$S_{m}$，$S_{2 m} - S_{m}$，$S_{3 m} - S_{2 m}$，$S_{4 m} - S_{3 m}$,…组成公差为$m^{2} d$的等差数列
(3)在等差数列$\{ a_{n} \}$，$\{ b_{n} \}$中，它们的前$n$项和分别记为$S_{n} , T_{n}$则$\frac{a_{n}}{b_{n}} = \frac{S_{2 n - 1}}{T_{2 n - 1}}$
(4)若等差数列$\{ a_{n} \}$的项数为$2 n$,则$S_{2 n} = n ( a_{n} + a_{n + 1} )$
$S_{偶} - S_{奇} = n d$*，*$\frac{S_{偶}}{S_{奇}} = \frac{a_{n + 1}}{a_{n}}$*。*
(5)若等差数列$\{ a_{n} \}$的项数为$2 n - 1$,则$S_{偶} = ( n - 1 ) a_{n}$*，*$S_{奇} = n a_{n}$*，*$S_{奇} - S_{偶} = a_{n}$*，*$\frac{S_{奇}}{S_{偶}} = \frac{n}{n - 1}$
