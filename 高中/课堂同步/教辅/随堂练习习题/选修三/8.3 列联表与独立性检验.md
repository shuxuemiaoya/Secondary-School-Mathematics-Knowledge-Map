### 知识点1 ：分类变量与列联表
(1)分类变量
为了方便,会使用一种特殊的随机变量,区别不同的现象或性质,这随机变量称为分类变量.
(2)$\mathbf{2} \mathbf{\times} \mathbf{2}$列联表
①2×2列联表给出了两个分类变量数据的交叉分类频数．
②定义一对分类变量$X$和$Y$，我们整理数据如下表所示：
| $ X $     | $ Y $     | 合计        |                         |
|-------------|-------------|-------------|-------------------------|
|             | $ y_{1} $ | $ y_{2} $ |                         |
| $ x_{1} $ | $ a $     | $ b $     | $ a + b $             |
| $ x_{2} $ | $ c $     | $ d $     | $ c + d $             |
| 合计        | $ a + c $ | $ b + d $ | $ n = a + b + c + d $ |
### 知识点2 ：独立性检验
(1)独立性检验定义:
利用$\chi^{2}$的取值推断分类变量$X$和$Y$是否独立的方法称为$\chi^{2}$独立性检验，读作“卡方独立性检验”．简称独立性检验．
(2)独立性检验公式：
$\chi^{2} = \frac{n ( a d - b c )^{2}}{( a + b ) ( c + d ) ( a + c ) ( b + d )}$其中$n = a + b + c + d$（注意使用公式时分子的平方不要忽略了）

|----------------|-------|-------|-------|--------|

##### 题型02 独立性检验的概念及辨析
##### 【典例1】（2024上·全国·高三专题练习）根据分类变量$x$与$y$的观测数据，计算得到$\chi^{2} = \text{3.974}$.依据$\alpha = \text{0.05}$的独立性检验，结论为（ ）
| $ \alpha $     | $ 0 . 1 $     | $ 0 . 0 5 $   | $ 0 . 0 1 $   | $ 0 . 0 0 5 $ | $ 0 . 0 0 1 $   |
|------------------|-----------------|-----------------|-----------------|-----------------|-------------------|
| $ x_{\alpha} $ | $ 2 . 7 0 6 $ | $ 3 . 8 4 1 $ | $ 6 . 6 3 5 $ | $ 7 . 8 7 9 $ | $ 1 0 . 8 2 8 $ |
$\quad$A．变量$x$与$y$不独立，这个结论犯错误的概率不超过$\text{0.01}$
$\quad$B．变量$x$与$y$不独立，这个结论犯错误的概率不超过$\text{0.05}$
$\quad$C．变量$x$与$y$独立，这个结论犯错误的概率不超过$\text{0.05}$
$\quad$D．变量$x$与$y$独立，这个结论犯错误的概率不超过$\text{0.01}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>因为$\alpha = \text{0.05}$时$x_{\alpha} \text{=3.841}$，所以$\chi^{2} = \text{3.974>} x_{\alpha} \text{=3.841}$，
