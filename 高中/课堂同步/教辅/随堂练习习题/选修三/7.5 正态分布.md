### 知识点1 ：正态曲线
（1）连续型随机变量
除了离散型随机变量外，还有大量问题中的随机变量不是离散型的，它们的取值往往充满某个区间甚至整个实轴，但取一点的概率为0，我们称这类随机变量为连续型随机变量.
（2）正态的曲线的定义
函数$f ( x ) = \frac{1}{\sigma \sqrt{2 \pi}} e^{- \frac{( x - \mu )^{2}}{2 \sigma^{2}}}$，其中$\mu \in R$,$\sigma > 0$为参数.
显然对于任意$x \in R$，$f ( x ) > 0$，它的图象在$x$轴的上方，可以证明$x$轴和曲线之间的区域的面积为1，我们称$f ( x )$为正态密度函数，称它的图象为正态分布密度曲线，简称正态曲线.
①函数的自变量为$x$,定义域为$R$
②解析式中含有两个常数$\pi$和$e$,这两个是无理数，其中$\pi$为圆周率，$e$为自然对数的底数
③解析式中含两个参数$\mu$和$\sigma$,其中$\mu$可取任意实数，$\sigma > 0$,不同的正态曲线$\mu$和$\sigma$的取值是不同的.
![](523d071394cd6623a47dbedd13f4dbdb.png)④解析式的前面是一个系数$\frac{1}{\sigma \sqrt{2 \pi}}$，后面是一个以$e$为底的指数函数的形式,指数为$- \frac{( x - \mu )^{2}}{2 \sigma^{2}}$,其中$\sigma$这个参数在解析式中的两个位置出现，注意保持一致.
（3）正态曲线的几何意义
由正态曲线，过点$( a , 0 )$和点$( b , 0 )$的两条$x$轴的垂线，及$x$轴所围成的平面图形（图中阴影部分）的面积，就是$X$落在区间$\lbrack a , b \rbrack$的概率的近似值.
（4）正态曲线的特点
①曲线位于$x$轴上方，与$x$轴不相交；
![北京四中网校www.etiantian.com](75450f09be43684c33102a3a99fc73a6.jpeg)②曲线是单峰的，它关于直线$x = \mu$对称；
③曲线在$x = \mu$时达到峰值$\frac{1}{\sigma \sqrt{2 \pi}}$；
④当$x < \mu$时，曲线上升；当$x > \mu$时，曲线下降.并且当曲线向左、右两边无限延伸时，以$x$轴为渐近线，向它无限靠近.
⑤曲线与$x$轴之间的面积为1；
⑥$\mu$决定曲线的位置和对称性；
当$\sigma$一定时，曲线的对称轴位置由$\mu$确定；如下图所示，曲线随着$\mu$的变化而沿$x$轴平移。
⑦$\sigma$确定曲线的形状；
当$\mu$一定时，曲线的形状由$\sigma$确定。$\sigma$越小，曲线越“高瘦”，表示总体的分布越集中；$\sigma$越大，曲线越“矮胖”，表示总体的分布越分散。
### 知识点2 ：正态分布
（1）正态分布
若随机变量$X$的概率密度函数为$f ( x ) = \frac{1}{\sigma \sqrt{2 \pi}} e^{- \frac{( x - \mu )^{2}}{2 \sigma^{2}}}$，($x \in R$,其中$\mu \in R$，$\sigma > 0$为参数)，称随机变量$X$服从正态分布，记为$X \sim N ( \mu , \sigma^{2} )$.

$\quad$A．0.2 
$\quad$B．0.7 
$\quad$C．0.8 
$\quad$D．0.9
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题意知，正态曲线的对称轴为$x = 4$，$m$与$8 - m$关于$x = 4$对称，

### 知识点3 ：正态分布的$\mathbf{3} \mathbf{\sigma}$原则：正态分布在三个特殊区间的概率值
![ ](57d2863e32b3593beba9c9a890cd12e2.jpeg)假设$X \sim N ( \mu \mspace{6mu} ， \mspace{6mu} \sigma^{2} )$，可以证明：对给定的$k \in N^{*} \mspace{6mu} ， \mspace{6mu} P ( \mu - k \sigma \leq X \leq \mu + k \sigma )$是一个只与$k$有关的定值.
特别地，$P ( \mu - \sigma \leq X \leq \mu + \sigma ) \approx 0 . 6 8 2 7$，
$P ( \mu - 2 \sigma \leq X \leq \mu + 2 \sigma ) \approx 0 . 9 5 4 5$，
$P ( \mu - 3 \sigma \leq X \leq \mu + 3 \sigma ) \approx 0 . 9 9 7 3$.
上述结果可用右图表示.
此看到，尽管正态变量的取值范围是$( - \infty , + \infty )$，但在一次试验中，$X$的值几乎总是落在区间$\lbrack \mu - 3 \sigma , \mu + 3 \sigma \rbrack$内，而在此区间以外取值的概率大约只有0.0027,通常认为这种情况几乎不可能发生.
在实际应用中，通常认为服从于正态分布$N ( \mu , \sigma^{2} )$的随机变量$X$只取$\lbrack \mu - 3 \sigma , \mu + 3 \sigma \rbrack$中的值，这在统计学中称为$3 \sigma$原则.
