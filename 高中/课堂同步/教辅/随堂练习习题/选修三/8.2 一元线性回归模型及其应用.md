### 知识点1 ：一元线性回归模型
（1）一元线性回归模型
我们称$\begin{cases}Y = b x + a + e \\ E ( e ) = 0 , D ( e ) = \sigma^{2}\end{cases}$
为$Y$关于$x$的一元线性回归模型，其中$Y$称为因变量或响应变量，$x$称为自变量或解释变量；$a$和$b$为模型的未知参数，$a$称为截距参数，$b$称为斜率参数；$e$是$Y$与$b x + a$之间的随机误差.
（2）随机误差
在线性回归模型$Y = b x + a + e$中，$a$和$b$为模型的未知参数，$e$是$Y$与$b x + a$之间的误差,通常$e$为随机变量，称为随机误差.它的均值$E ( e ) = 0$，方程$D ( e ) = \sigma^{2} > 0$.
线性回归模型的完整表达式为$\begin{cases}Y = b x + a + e \\ E ( e ) = 0 , D ( e ) = \sigma^{2}\end{cases}$ , 在此模型中，随机误差$e$的方差$\sigma^{2}$越小，用$b x + a$预报真实值$y$的精度越高.
### 知识点2 ：一元线性回归模型参数的最小二乘法
（1）经验回归方程的求解法：最小二乘法
回归直线方程过样本点的中心$( \overline{x} , \overline{y} )$，是回归直线方程最常用的一个特征；
我们将$\widehat{y} = \widehat{b} x + \widehat{a}$称为$Y$关于$x$的线性回归方程，也称经验回归函数或经验回归公式，其图形称为经验回归直线。这种求经验回归方程的方法叫做最小二乘法，求得的$\widehat{b} , \widehat{a}$，叫做$b$，$a$的最小二乘估计,其中$\widehat{b}$称为回归系数，它实际上也就是经验回归直线的斜率，$\widehat{a}$为截距.
其中$\begin{cases}\widehat{b} = \frac{\sum_{i = 1}^{n} {\left( x_{i} - \overline{x} \right) \left( y_{i} - \overline{y} \right)}}{\sum_{i = 1}^{n} \left( x_{i} - \overline{x} \right)^{2}} = \frac{\sum_{i = 1}^{n} {x_{i} y_{i} - n \overline{x} \overline{y}}}{\sum_{i = 1}^{n} {x_{i}^{2} - n \overline{x}^{2}}} \\ \widehat{a} = \overline{y} - \widehat{b} \overline{x}\end{cases}$

（3）经验回归方程的性质
①经验回归直线一定过点$( \overline{x} , \overline{y} )$,点$( \overline{x} , \overline{y} )$通常称为样本点的中心；
②一次函数$\widehat{y} = \widehat{b} x + \widehat{a}$的单调性由$\widehat{b}$的符号决定，函数递增的充要条件是$\widehat{b} > 0$；函数递减的充要条件是$\widehat{b} < 0$.这说明：$y$与$x$正相关的充要条件是$\widehat{b} > 0$；$y$与$x$负相关的充要条件是$\widehat{b} < 0$.
③在经验回归方程$\widehat{y} = \widehat{b} x + \widehat{a}$中，$\widehat{b}$是经验回归直线的斜率，$\widehat{a}$是截距.一般地，当回归系数$\widehat{b} > 0$时，说明两个变量呈正相关关系，它的意义是当$x$每增大一个单位时，$\widehat{y}$平均增大$\widehat{b}$个单位；当$\widehat{b} < 0$时，说明两个变量呈负相关关系，它的意义是当$x$每增大一个单位时，$\widehat{y}$平均减小$| \widehat{b} |$个单位.
### 知识点3 ：残差
（1）残差
对于响应变量$Y$，通过观测得到的数据称为观测值，通过经验回归方程得到的$\widehat{y}$称为预测值，观测值减去预测值称为残差.
（2）残差图
作图时纵坐标为残差，横坐标可以选为样本编号，或身高数据，或体重估计值等，这样作出的图形称为残差图．若残差点比较均匀地落在水平的带状区域内，带状区域越窄，则说明拟合效果越好.
（3）残差分析
残差是随机误差的估计结果，通过残差的分析可以判断模型刻画数据的效果，以及判断原始数据中是否存在可疑数据等，这方面工作称为残差分析.其步骤为：计算残差$\rightarrow$化残差图$\rightarrow$在残差图中分析残差特性.

### 知识点4 ：决定系数$\mathbf{R}^{\mathbf{2}}$
（1）残差平方和
残差平方和${\sum_{i = 1}^{n} \left( y_{i} - \widehat{y}_{i} \right)}^{2}$，残差平方和越小，模型拟合效果越好，残差平方和越大，模型拟合效果越差.
（2）决定系数$\mathbf{R}^{\mathbf{2}}$
决定系数$R$是度量模型拟合效果的一种指标，在线性模型中，它代表解释变量客户预报变量的能力.
$R^{2} = 1 - \frac{\sum_{i = 1}^{n} \left( y_{i} - \widehat{y}_{i} \right)^{2}}{\sum_{i = 1}^{n} \left( y_{i} - \overline{y} \right)^{2}}$，$R^{2}$越大，即拟合效果越好，$R^{2}$越小，模型拟合效果越差.

（3）决定系数$\mathbf{R}^{\mathbf{2}}$与相关系数$\mathbf{r}$的联系与区别
①相关系数$r$反映两个变量的相关关系的强弱及正相关或负相关，决定系数$R^{2}$反映回归模型的拟合效果.
②在含有一个解释变量的线性模型中，决定系数$R^{2}$的数值是相关系数$r$的平方，其变化范围为$\lbrack 0 , 1 \rbrack$，而相关系数的变化范围为$\lbrack - 1 , 1 \rbrack$.
③当相关系数$| r |$接近于1时，说明两变量的相关性较强，当$| r |$接近于0时，说明两变量的相关性较弱；而当$R^{2}$接近于1时，说明经验回归方程的拟合效果较好.
