### 知识点 一：常见函数模型
1、一次函数模型$\mathbf{f ( x ) = k x + b}$（$\mathbf{k \neq 0}$，$\mathbf{k , b}$为常数）
2、反比例函数模型$\mathbf{f ( x ) =} \frac{\mathbf{k}}{\mathbf{x}}$（$\mathbf{k} \mathbf{\neq} \mathbf{0}$）
3、二次函数模型$\mathbf{f ( x ) = a} \mathbf{x}^{\mathbf{2}} \mathbf{+ b x + c}$（$\mathbf{a} \mathbf{\neq} \mathbf{0}$）
4、指数函数模型$\mathbf{f ( x ) = k} \mathbf{a}^{\mathbf{x}} \mathbf{+ b}$（$\mathbf{a > 0}$且$\mathbf{a \neq 1}$，$\mathbf{k} \mathbf{\neq} \mathbf{0}$）
5、对数函数模型$\mathbf{f ( x ) = k} \mathbf{\log}_{\mathbf{a}}^{\mathbf{x}} \mathbf{+} \mathbf{b}$（$\mathbf{a > 0}$且$\mathbf{a \neq 1}$，$\mathbf{k} \mathbf{\neq} \mathbf{0}$）
6、幂函数模型$\mathbf{f ( x ) = k} \mathbf{x}^{\mathbf{\alpha}} \mathbf{+ b}$（$\mathbf{k \neq 0}$，$\mathbf{\alpha} \mathbf{\neq} \mathbf{1}$）
7、分段函数模型：两种或两种以上上述六种模型的综合
8、对勾函数模型：$\mathbf{f ( x ) = x +} \frac{\mathbf{a}}{\mathbf{x}} \mathbf{( a > 0 )}$
