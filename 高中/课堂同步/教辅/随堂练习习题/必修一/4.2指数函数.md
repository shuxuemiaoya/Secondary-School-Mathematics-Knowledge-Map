### 知识点01 ：指数函数的概念
1、一般地，函数$y = a^{x} ( a > 0 , 且 a \neq 1 )$叫做指数函数，其中指数$x$是自变量，底数$a$是一个大于0且不等于1的常量，定义域是$R$.
2、学习指数函数的定义，注意一下几点
（1）定义域为：$R$
（2）规定$a > 0 , 且 a \neq 1$是因为：
①若$a = 1$，则$y = a^{x} \equiv 1$（恒等于1）没有研究价值；
②若$a = 0$，则$x > 0$时，$y = a^{x} \equiv 0$（恒等于0），而当$x \leq 0$时，$a^{x}$无意义；
③若$a < 0$，则$a^{\frac{n}{m}}$中$m$为偶数，$n$为奇数时，$a^{\frac{n}{m}}$无意义.
只有当$0 < a < 1$或$a > 1$时，即$a > 0 , 且 a \neq 1$，$x$可以是任意实数.
（3）函数解析式形式要求：
指数函数只是一个新式定义，判断一个函数是指数函数的关键有三点：①$a^{x}$的系数必须为1；②底数为大于0且不等于1的常数，不能是自变量；③指数处只有一个自变量，而不是含自变量的多项式.

##### 2.1.底数$\mathbf{a}$与1的大小关系决定了指数函数$\mathbf{y =} \mathbf{a}^{\mathbf{x}} \mathbf{( a > 0} \mathbf{且} \mathbf{a} \mathbf{\neq} \mathbf{1 )}$图象的“升”与“降”.

在$y$轴右侧，图象从上到下相应的底数由大变小，即“底数大图象高”；
在$y$轴左侧，图象从上到下相应的底数由小变大，即“底数大图象低”；
### 知识点03 ：指数函数的定义域与值域
1、定义域：
（1）指数函数$y = a^{x} ( a > 0 且 a \neq 1 )$的定义域为$R$
（2）$y = a^{f ( x )} ( a > 0 且 a \neq 1 )$的定义域与函数$y = f ( x )$的定义域相同
（3）$y = f ( a^{x} )$的定义域与函数$y = f ( x )$的定义域不一定相同.
2、值域
（1）指数函数$y = a^{x} ( a > 0 且 a \neq 1 )$的值域为$( 0 , + \infty )$
（2）求形如$y = a^{f ( x )}$的函数的值域，先求$f ( x )$的值域，然后结合$y = a^{x} ( a > 0 且 a \neq 1 )$得性质确定$y = a^{f ( x )}$的值域
（3）求形如$y = f ( a^{x} )$的值域，转化为先求$t = a^{x} ( a > 0 且 a \neq 1 )$的值域，再将$t$的取值范围代入函数$y = f ( t )$中.
### 知识点04 ：指数函数的图象变换
已知函数$y = a^{x} ( a > 0 且 a \neq 1 )$
1、平移变换
①$y = a^{x} \overset{\quad 向 上 平 移 k 个 单 位 长 度 （ k > 0 ) \quad}{\rightarrow} y = a^{x} + k$
②$y = a^{x} \overset{\quad 向 下 平 移 k 个 单 位 长 度 （ k > 0 ) \quad}{\rightarrow} y = a^{x} - k$
③$y = a^{x} \overset{\quad 向 左 平 移 h 个 单 位 长 度 （ h > 0 ) \quad}{\rightarrow} y = a^{x + h}$
④$y = a^{x} \overset{\quad 向 右 平 移 h 个 单 位 长 度 （ h > 0 ) \quad}{\rightarrow} y = a^{x - h}$
2、对称变换
①$y = a^{x} \overset{\quad 关 于 y 轴 对 称 \quad}{\rightarrow} y = a^{- x}$
②$y = a^{x} \overset{\quad 关 于 x 轴 对 称 \quad}{\rightarrow} y = - a^{x}$
③$y = a^{x} \overset{\quad 关 于 原 点 对 称 \quad}{\rightarrow} y = - a^{- x}$
3、翻折变换
①$y = a^{x} \overset{\quad 去 左 留 右 右 翻 左 \quad}{\rightarrow} y = a^{| x |}$（去掉$y$轴左侧图象，保留$y$轴右侧图象；将$y$轴右侧图象翻折到$y$轴左侧）
②$y = a^{x} \overset{\quad 留 上 下 翻 上 \quad}{\rightarrow} y = | a^{x} |$（保留$x$轴上方的图象，将$x$轴下方的图象翻折到$x$轴上方）
