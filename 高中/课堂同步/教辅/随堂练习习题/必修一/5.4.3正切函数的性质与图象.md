$\quad$B．![@@@950c0027-db22-4e41-9683-6ec3e5e8346a](99b975f68c627c4174fe66394a3f6942.png)
$\quad$C．![@@@1bde25fd-3e67-4b32-9f66-11aa2557eb95](b6dc2c525f57665b25eacb7a2f5f6775.png) 
$\quad$D．![@@@3993fc25-2c9b-4d4e-a687-8cf33f4f8613](7ce362860ee9ec0e8f620e6dec12eb61.png)
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>根据函数奇偶性排除不符合的两个选项，再根据$f ( 1 )$的符号，即可得符合的函数图象.

### 知识点02 ：正切（型）函数的性质
|        | 正切函数$f ( x ) = \tan x$                                                   | 正切型函数$f ( x ) = A \tan ( \omega x + \varphi )$                                                                                                                             |
|--------|--------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 定义域 | $ \{ x | x \neq k \pi + \frac{\pi}{2} , k \in Z \} $                         | 由$\omega x + \varphi \neq k \pi + \frac{\pi}{2} \Rightarrow x \neq \frac{k \pi + \frac{\pi}{2} - \varphi}{\omega}$                                                             |
| 值域   | $ R $                                                                        | $ R $                                                                                                                                                                           |
| 周期性 | $ T = \pi $                                                                  | $ T = \frac{\pi}{| \omega |} $                                                                                                                                                  |
| 奇偶性 | 奇函数                                                                         | 当$\varphi = \frac{k \pi}{2}$时$f ( x ) = A \tan ( \omega x + \varphi )$是奇函数                                                                                              |
| 单调性 | 在$( k \pi - \frac{\pi}{2} , k \pi + \frac{\pi}{2} )$，$k \in Z$上单调递增 | 当$A > 0$,$\omega > 0$时，由$k \pi - \frac{\pi}{2} < \omega x + \varphi < k \pi + \frac{\pi}{2}$，解出单调增区间                                                            |
| 对称性 | 对称中心：$( \frac{k \pi}{2} , 0 ) k \in Z$；无对称轴                        | 令：$\omega x + \varphi = \frac{k \pi}{2} \Rightarrow x = \frac{\frac{k \pi}{2} - \varphi}{\omega}$，对称中心为：$( \frac{\frac{k \pi}{2} - \varphi}{\omega} , 0 )$，无对称轴 |

$\quad$A．$f ( x )$在定义域内是增函数 
$\quad$B．$f ( x )$是奇函数
$\quad$C．$f ( x )$的最小正周期是π 
$\quad$D．$f ( x )$图像的对称中心是$\left( \frac{k \pi}{4} - \frac{\pi}{6} , 0 \right)$，
<span class="fake-tag">答案</span>D

<span class="fake-tag">详解</span>（1）对于函数$f ( x ) = \ln \frac{1 - \tan x}{1 + \tan x}$，有$\frac{1 - \tan x}{1 + \tan x} > 0$，即$\frac{\tan x - 1}{\tan x + 1} < 0$，解得$- 1 < \tan x < 1$，
解得$k \pi - \frac{\pi}{4} < x < k \pi + \frac{\pi}{4} ( k \in Z )$，
所以，函数$f ( x )$的定义域为$\left( k \pi - \frac{\pi}{4} , k \pi + \frac{\pi}{4} \right) ( k \in Z )$，
$f ( - x ) = \ln \frac{1 - \tan ( - x )}{1 + \tan ( - x )} = \ln \frac{1 + \tan x}{1 - \tan x} = {\ln \left( \frac{1 - \tan x}{1 + \tan x} \right)}^{- 1} = - \ln \frac{1 - \tan x}{1 + \tan x} = - f ( x )$，
所以，函数$f ( x )$为奇函数；
（2）$\because g ( x ) = e^{f ( x )} - \frac{a \left( 1 - \tan x \right)}{\tan x} = \frac{1 - \tan x}{1 + \tan x} - \frac{a \left( 1 - \tan x \right)}{\tan x}$，
$\because - \frac{\pi}{4} < x < 0$，则$- 1 < \tan x < 0$，$1 - \tan x > 0$，所以，$0 < \tan x + 1 < 1$，
令$g ( x ) = 0$，可得$a = \frac{\tan x}{1 + \tan x} = \frac{\left( \tan x + 1 \right) - 1}{\tan x + 1} = 1 - \frac{1}{\tan x + 1} < 0$，
所以，实数$a$的取值范围是$( - \infty , 0 )$.

（1）直接法：直接求解方程得到方程的根，再通过解不等式确定参数范围；
（2）分离参数法：先将参数分离，转化成求函数的值域问题加以解决；
