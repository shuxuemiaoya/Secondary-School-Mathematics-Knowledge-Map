### 知识点01 一：幂函数的概念
1、定义：一般地，函数$y = x^{\alpha}$叫做幂函数，其中$x$是自变量，$\alpha$是常数.
2、幂函数的特征
①$y = x^{\alpha}$中$x^{\alpha}$前的系数为“1”
②$y = x^{\alpha}$中$x^{\alpha}$的底数是单个的自变量“$x$”
③$y = x^{\alpha}$中$\alpha$是常数
【即学即练1】（23-24高一上·新疆·阶段练习）下列函数中幂函数的是（ ）
$\quad$A．$y = 3 x$ 
$\quad$B．$y = x^{2} + 2$ 
$\quad$C．$y = ( x + 1 )^{2}$ 
$\quad$D．$y = \sqrt{x}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>根据幂函数的定义直接得出结果.
<span class="fake-tag">详解</span>A：函数$y = 3 x$为一次函数，故A不符合题意；
B：函数$y = x^{2} + 2$为二次函数，故B不符合题意；
C：函数为二次函数，故C不符合题意；
D：函数$y = \sqrt{x} = x^{\frac{1}{2}}$为幂函数，故D符合题意.
故选：D
### 知识点02 ：幂函数的图象与性质
1、五个幂函数的图象(记忆五个幂函数的图象）

$\mathbf{f ( x ) = x}$；$\mathbf{f ( x ) =} \mathbf{x}^{\mathbf{2}}$；$\mathbf{f ( x ) =} \mathbf{x}^{\mathbf{3}}$；$\mathbf{f ( x ) =} \mathbf{x}^{\frac{\mathbf{1}}{\mathbf{2}}}$；$\mathbf{f ( x ) =} \mathbf{x}^{\mathbf{-} \mathbf{1}}$

①$f ( x ) = x^{\alpha}$，当$\alpha > 0$时，$f ( x ) = x^{\alpha}$在$( 0 , + \infty )$单调递增；
