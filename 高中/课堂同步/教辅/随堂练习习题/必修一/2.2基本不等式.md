### 知识点 一：基本不等式（一正，二定，三相等，特别注意“一正”，“三相等”这两类陷阱）
基本不等式:$\mathbf{\forall} \mathbf{a > 0 , b > 0}$,$\mathbf{a + b} \mathbf{\geq} \mathbf{2} \sqrt{\mathbf{a b}}$,（当且仅当$\mathbf{a = b}$时，取“$\mathbf{=}$”号）其中$\sqrt{\mathbf{a b}}$叫做正数$\mathbf{a}$，$\mathbf{b}$的几何平均数；$\frac{\mathbf{a + b}}{\mathbf{2}}$叫做正数$\mathbf{a}$，$\mathbf{b}$的算数平均数．
如果$\forall a , b \in R$，有$a^{2} + b^{2} \geq 2 a b$（当且仅当$a = b$时，取“$=$”号）
特别的，如果$a > 0 , b > 0$,用$\sqrt{a} , \sqrt{b}$分别代替$a , b$,代入$a^{2} + b^{2} \geq 2 a b$，可得：$a + b \geq 2 \sqrt{a b}$，当且仅当$a = b$时，“$=$”号成立.
### 知识点 二：利用基本不等式求最值
①已知$x$，$y$是正数，如果积$x y$等于定值$P$，那么当且仅当$x = y$时，和$x + y$有最小值$2 \sqrt{P}$；
②已知$x$，$y$是正数，如果和$x + y$等于定值$S$，那么当且仅当$x = y$时，积$x y$有最大值$\frac{S^{2}}{4}$；
【即学即练1】（23-24高一上·广东潮州·期中）已知，则$x ( 2 - 3 x )$的最大值是（ ）
$\quad$A． 
$\quad$B．$\frac{1}{4}$ 
$\quad$C．$\frac{2}{9}$ 
$\quad$D．$\frac{1}{6}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>利用基本不等式凑和为定值直接求解.
<span class="fake-tag">详解</span>已知，
则$x ( 2 - 3 x ) = \frac{1}{3} \times ( 3 x ) ( 2 - 3 x )$
$\leq \frac{1}{3} \times \left( \frac{3 x + 2 - 3 x}{2} \right)^{2} = \frac{1}{3}$.
当且仅当$3 x = 2 - 3 x$，即$x = \frac{1}{3}$等号成立.
故$x ( 2 - 3 x )$的最大值是.
故选：A
### 知识点 三：基本不等式链
$\frac{2}{\frac{1}{a} + \frac{1}{b}} \leq \sqrt{a b} \leq \frac{a + b}{2} \leq \sqrt{\frac{a^{2} + b^{2}}{2}}$（其中$a > 0$，$b > 0$当且仅当$a = b$时，取“$=$”号）
### 知识点 四：三个正数的基本不等式
如果$a > 0$，$b > 0$，$c > 0$，那么$\frac{a + b + c}{3} \geq \sqrt[3]{a b c}$（当且仅当$a = b = c$时，取“$=$”号）

##### 【典例1】（23-24高一上·上海普陀·期中）下列不等式中等号可以取到的是（ ）
$\quad$A．$\sqrt{x^{2} + 5} + \frac{1}{\sqrt{x^{2} + 5}} \geq 2$ 
$\quad$B．$x^{2} + 2 + \frac{1}{x^{2} + 2} \geq 2$
$\quad$C．$x^{2} + \frac{1}{x^{2}} \geq 2$ 
$\quad$D．$| x | + 3 + \frac{1}{| x | + 3} \geq 2$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>根据基本不等式使用条件逐一检验取等条件即可得答案.
<span class="fake-tag">详解</span>解：对于A，因为$\sqrt{x^{2} + 5} > 0$，所以$\sqrt{x^{2} + 5} + \frac{1}{\sqrt{x^{2} + 5}} \geq 2 \sqrt{\sqrt{x^{2} + 5} \cdot \frac{1}{\sqrt{x^{2} + 5}}} = 2$，当且仅当$\sqrt{x^{2} + 5} = \frac{1}{\sqrt{x^{2} + 5}}$，即$x^{2} = - 4$，故等号不成立，故A不符合；

对于D，因为$| x | + 3 > 0$，所以$| x | + 3 + \frac{1}{| x | + 3} \geq 2 \sqrt{\left( | x | + 3 \right) \cdot \frac{1}{| x | + 3}} = 2$，当且仅当$| x | + 3 = \frac{1}{| x | + 3}$，即$| x | = - 2$，故等号不成立，故D不符合.
故选：C.

##### 题型03由基本不等式证明不等关系
