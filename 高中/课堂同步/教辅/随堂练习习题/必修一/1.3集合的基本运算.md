### 知识点01 ：并集
一般地，由所有属于集合$A$或属于集合$B$的元素组成的集合称为集合$A$与集合$B$的并集，记作 $A \cup B$（读作：$A$并$B$）.记作：$A \cup B = \left\{ x | x \in A 或 x \in B \right. \right\}$.
并集的性质：$A \cup B = B \cup A$,$A \subseteq A \cup B$,$B \subseteq A \cup B$,$A \cup A = A$,$A \cup \varnothing = A$.
高频性质：若$\mathbf{A} \mathbf{\cup} \mathbf{B = B} \mathbf{\Rightarrow} \mathbf{A} \mathbf{\subseteq} \mathbf{B}$.

![](02349c20d660f606b1d09bbd1cadd16c.jpeg)
对并集概念的理解
(1)$A \cup B$仍是一个集合,$A \cup B$由所有属于集合$A$或属于集合$B$的元素组成.
(2)并集符号语言中的“或”与生活中的“或”字含义有所不同.生活中的“或”是只取其一,并不兼存;而并集中的“或”连接的并列成分之间不一定是互斥的,“$x \in A$或$x \in B$”包括下列三种情况:①$x \in A$,且$x \notin B$;②$x \notin A$,且$x \in B$;③$x \in A$,且$x \in B$.可用下图所示形象地表示.

### 知识点02 ：交集
一般地，由既属于集合$A$又属于集合$B$的所有元素组成的集合即由集合$A$和集合$B$的相同元素组成的集合，称为集合$A$与集合$B$的交集，记作$A \cap B$（读作：$A$交$B$）.记作：$A \cap B = \left\{ x | x \in A 且 x \in B \right. \right\}$.
交集的性质：$A \cap B = B \cap A$,$A \cap B \subseteq A$,$A \cap B \subseteq B$,$A \cap A = A$,$A \cap \varnothing = \varnothing$.
高频性质：若$\mathbf{A} \mathbf{\cap} \mathbf{B = B} \mathbf{\Rightarrow} \mathbf{B} \mathbf{\subseteq} \mathbf{A}$.
图形语言
![](5c232e87c73d7f445d4c216df46faae1.jpeg)
对交集概念的理解
(1)$A \cap B$仍是一个集合,$A \cap B$由所有属于集合$A$且属于集合$B$的元素组成.
(2)对于“$A \cap B = \left\{ x | x \in A 且 x \in B \right. \right\}$”,包含以下两层意思:①$A \cap B$中的任一元素都是$A$与$B$的公共元素;②$A$与$B$的公共元素都属于$A \cap B$,这就是文字定义中“所有”二字的含义,如$A = \{ 1 , 2 , 3 , 4 \}$,$B = \{ 2 , 3 , 4 , 5 \}$,则$A \cap B = \{ 2 , 3 , 4 \}$,而不是$\{ 2 \}$或$\{ 3 \}$或$\{ 4 \}$.
(3)并不是任意两个集合总有公共元素,当集合$A$与集合$B$没有公共元素时,不能说集合$A$与集合$B$没有交集,而是$A \cap B = \varnothing$.
(4)当$A = B$时,$A \cap B = A$和$A \cap B = B$同时成立.

### 知识点03 ：全集与补集
全集：在研究某些集合的时候，它们往往是某个给定集合的子集，这个给定的集合叫做全集，常用$U$表示，全集包含所有要研究的这些集合.
补集：设$U$是全集，$A$是$U$的一个子集（即$A \subseteq U$）,则由$U$中所有不属于集合$A$的元素组成的集合，叫做$U$中子集$A$的补集，记作 $C_{U} A$，即$C_{U} A = \left\{ x | x \in U 且 x \notin A \right. \right\}$.
补集的性质：$A \cup C_{U} A = U$ , $A \cap C_{U} A = \varnothing$ , $C_{U} \left( C_{U} A \right) = A$.

### 知识点04 ：德摩根律
(1)$C_{U} ( A \cap B ) = ( C_{U} A ) \cup ( C_{U} B )$
(2)$C_{U} ( A \cup B ) = ( C_{U} A ) \cap ( C_{U} B )$
### 知识点05 ：容斥原理
一般地，对任意两个有限集$A$,$B$
$c a r d ( A \cup B ) = c a r d ( A ) + c a r d ( B ) - c a r d ( A \cap B )$
进一步的：
$c a r d ( A \cup B \cup C ) = c a r d ( A ) + c a r d ( B ) + c a r d ( C ) - c a r d ( A \cap B ) - c a r d ( A \cap C ) - c a r d ( B \cap C ) + c a r d ( A \cap B \cap C )$ ![](d657992b6524c34364a456da79695486.png)

##### 题型09容斥原理
##### 【典例1】（23-24高一上·湖南张家界·期末）学校先举办了一次田径运动会，某班有8名同学参赛，又举办了一次球类运动会，这个班有12名同学参赛，两次运动会都参赛的有3人。两次运动会中，这个班总共参赛的同学有（ ）

$\quad$C．15人 
$\quad$D．12人

<span class="fake-tag">分析</span>利用容斥原理$\text{card} ( A \cup B ) = \text{card} A + \text{card} B - \text{card} ( A \cap B )$可得.
<span class="fake-tag">详解</span>设参加田径运动的同学构成集合$A$，参加球类运动会的同学构成集合$B$，
则参加田径运动的同学人数$\text{card} A = 8$，
参加球类运动会的同学人数$\text{card} B = 1 2$，
两次运动会都参赛的同学人数$\text{card} ( A \cap B ) = 3$，
