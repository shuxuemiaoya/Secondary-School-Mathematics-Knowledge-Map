### 知识点01 ：函数的奇偶性
1、定义：
##### 1.1偶函数：一般地，设函数$f ( x )$的定义域为$I$，如果$\forall x \in I$，都有$- x \in I$，且$f ( - x ) = f ( x )$，那么函数$f ( x )$就叫做偶函数.
##### 1.2奇函数：一般地，设函数$f ( x )$的定义域为$I$，如果$\forall x \in I$，都有$- x \in I$，且$f ( - x ) = - f ( x )$，那么函数$f ( x )$就叫做奇函数.
>   2、函数奇偶性的判断
##### 2.1定义法：
（1）先求函数$f ( x )$的定义域$I$，判断定义域是否关于原点对称.
（2）求$f ( - x )$，根据$f ( - x )$与$f ( x )$的关系，判断$f ( x )$的奇偶性：
>   ①若$f ( - x ) + f ( x ) = 0 \Leftrightarrow f ( - x ) = - f ( x ) \Leftrightarrow f ( x )$是奇函数
>   ②若$f ( - x ) - f ( x ) = 0 \Leftrightarrow f ( - x ) = f ( x ) \Leftrightarrow f ( x )$是偶函数
>   ③若$\begin{cases} & f ( - x ) + f ( x ) = 0 \\  & f ( - x ) - f ( x ) = 0\end{cases} \Leftrightarrow \begin{cases} & f ( - x ) = - f ( x ) \\  & f ( - x ) = f ( x )\end{cases} \Leftrightarrow f ( x )$既是奇函数又是偶函数
>   ④若$\begin{cases} & f ( - x ) \neq - f ( x ) \\  & f ( - x ) \neq f ( x )\end{cases} \Leftrightarrow f ( x )$既不是奇函数也不是偶函数

$\quad$D．$f ( x ) = x^{4} + 2 x^{2}$

<span class="fake-tag">详解</span>对于A，因为$f ( x ) = x^{2} + 1$的定义域为$R$，且$f ( - x ) = ( - x )^{2} + 1 = x^{2} + 1 = f ( x )$，所以$f ( x ) = x^{2} + 1$为偶函数；
对于B，因为$f ( x ) = x^{3} - 1$的定义域为$R$，且$f ( - x ) = ( - x )^{3} + 1 = - x^{3} + 1 \neq - f ( x )$，所以$f ( x ) = x^{3} - 1$不是奇函数；
对于C，因为$f ( x ) = x^{3} + \frac{1}{x}$的定义域为$( - \infty , 0 ) \cup ( 0 , + \infty )$，且$f ( - x ) = ( - x )^{3} + \frac{1}{- x} = - x^{3} - \frac{1}{x} = - \left( x^{3} + \frac{1}{x} \right) = - f ( x )$，所以$f ( x ) = x^{3} + \frac{1}{x}$为奇函数；

故选：$C$.
##### 2.2图象法：
>   （1）先求函数$f ( x )$的定义域$I$，判断定义域是否关于原点对称.
（2）若$f ( x )$的图象关于$y$轴对称$\Leftrightarrow f ( x )$是偶函数
>   （3）若$f ( x )$的图象关于原点对称$\Leftrightarrow f ( x )$是奇函数

### 知识点02 ：奇函数，偶函数的性质
1、奇函数，偶函数的图象特征
>   设函数$f ( x )$的定义域为$I$
>   （1）$f ( x )$是偶函数$\Leftrightarrow f ( x )$的图象关于$y$轴对称；
>   （2）$f ( x )$是奇函数$\Leftrightarrow f ( x )$的图象关于原点对称；
>   （3）若$f ( x )$是奇函数且$0 \in I$，则$f ( 0 ) = 0$
2、函数的奇偶性与单调性的关系
>   （1）$f ( x )$是偶函数$\Leftrightarrow f ( x )$在关于原点对称区间上具有相反的单调性；
>   （2）$f ( x )$是奇函数$\Leftrightarrow f ( x )$在关于原点对称区间上具有相同的单调性；
3、函数的奇偶性与函数值及最值的关系
>   设函数$f ( x )$的定义域为$\lbrack - b , - a \rbrack \cup \lbrack a , b \rbrack$（其中$a b \geq 0$）
>   （1）$f ( x )$是偶函数，且$f ( x )$在$\lbrack a , b \rbrack$上单调，则$f ( x )$在$\lbrack - b , - a \rbrack$上有相反的单调性，此时函数的最大（小）值相同；
>   （2）$f ( x )$是奇函数，且$f ( x )$在$\lbrack a , b \rbrack$上单调，则$f ( x )$在$\lbrack - b , - a \rbrack$上有相同的单调性，此时函数的最值互为相反数；

>   知识点03：对称性
>   1、轴对称：
>   设函数$f ( x )$的定义域为$I$，且$x = a$是$f ( x )$的对称轴，则有：
>   ①$f ( a + x ) = f ( a - x )$；
>   ②$f ( x ) = f ( 2 a - x )$
>   ③$f ( - x ) = f ( 2 a + x )$
>   2、点对称
>   设函数$f ( x )$的定义域为$I$，且$( a , 0 )$是$f ( x )$的对称中心，则有：
>   ①$f ( a + x ) = - f ( a - x )$；
>   ②$f ( x ) = - f ( 2 a - x )$
>   ③$f ( - x ) = - f ( 2 a + x )$
>   3、拓展：
>   ①若$f ( a + x ) = f ( b - x )$，则$f ( x )$关于$x = \frac{b + a}{2}$对称；
>   ②若$f ( a + x ) = - f ( b - x )$，则$f ( x )$关于$( \frac{b + a}{2} , 0 )$对称；
