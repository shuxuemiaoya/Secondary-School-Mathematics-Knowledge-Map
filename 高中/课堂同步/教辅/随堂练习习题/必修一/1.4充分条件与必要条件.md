### 知识点01 ：充分条件与必要条件
一般地,“若$p$,则$q$”为真命题,就说$p$是$q$的充分条件,$q$是$p$的必要条件.记作：$p \Rightarrow q$
在逻辑推理中“$p \Rightarrow q$”的几种说法
(1)“如果$p$,那么$q$”为真命题.
(2)$p$是$q$的充分条件.
(3)$q$是$p$的必要条件.
(4)$p$的必要条件是$q$.
(5)$q$的充分条件是$p$.
这五种说法表示的逻辑关系是一样的,说法不同而已.
### 知识点2 ：充分条件、必要条件与充要条件的概念
（1）若$p \Rightarrow q$，则$p$是$q$的充分条件，$q$是$p$的必要条件；
（2）若$p \Rightarrow q$且$q \nRightarrow p$，则$p$是$q$的充分不必要条件；
（3）若$p \nRightarrow q$且$q \Rightarrow p$，则$p$是$q$的必要不充分条件；
（4） 若$p \Leftrightarrow q$，则$p$是$q$的充要条件；
（5）若$p \nRightarrow q$且$q \nRightarrow p$，则$p$是$q$的既不充分也不必要条件.

### 知识点3 ：从集合的角度理解充分与必要条件
若$p$以集合$A$的形式出现，$q$以集合$B$的形式出现，即$p$：$A = \{ x | p ( x ) \}$，$q$：$B = \{ x | q ( x ) \}$，则
（1）若$A \subseteq B$，则$p$是$q$的充分条件；
（2）若$B \subseteq A$，则$p$是$q$的必要条件；
（3）若，则$p$是$q$的充分不必要条件；
（4）若，则$p$是$q$的必要不充分条件；
（5）若$A = B$，则$p$是$q$的充要条件；
（6）若且，则$p$是$q$的既不充分也不必要条件.
### 知识点4 ：充分性必要性高考高频考点结构
（1）$p$是$q$的充分不必要条件$\Leftrightarrow p \Rightarrow q$且$q \nRightarrow p$（注意标志性词：“是”，此时$\mathbf{p}$与$\mathbf{q}$正常顺序）
（2）$p$的充分不必要条件是$q \Leftrightarrow q \Rightarrow p$且$p \nRightarrow q$（注意标志性词：“的”，此时$\mathbf{p}$与$\mathbf{q}$倒装顺序）

##### 题型03 根据充分性，必要性求参数
##### 【典例1】（23-24高一上·广西南宁·阶段练习）已知：$- 2 \leq x \leq 10$，$q$：$1 - m \leq x \leq 1 + m （ m > 0 ）$，若是$q$的必要不充分条件，则实数$m$的取值范围为（ ）

$\quad$C．$m < 3$

<span class="fake-tag">分析</span>将是$q$的必要不充分条件转化为$B$ $A$，然后根据集合间的包含关系列不等式求解即可.

所以$\begin{cases}m > 0 \\ 1 - m \geq - 2 \\ 1 + m \leq 10\end{cases}$，解得$0 < m \leq 3$，
当$m = 3$时，$B = \left\{ x | - 2 \leq x \leq 4 \right. \right\}$，成立，
所以$0 < m \leq 3$.
