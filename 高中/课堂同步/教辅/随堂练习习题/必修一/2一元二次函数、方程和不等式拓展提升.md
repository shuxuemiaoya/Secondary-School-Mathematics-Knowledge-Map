##### 题型01一元二次不等式（根与系数的关系）
##### 【典例1】（23-24高一上·重庆北碚·阶段练习）已知不等式$a x^{2} - b x - 1 \geq 0$的解集是$\left\{ x \left| - \frac{1}{2} \leq x \leq - \frac{1}{3} \right. \right\}$，则不等式$x^{2} - b x - a < 0$的解集是（ ）
$\quad$A．$\left\{ x | 2 < x < 3 \right. \right\}$ 
$\quad$B．$\left\{ x | x < 2 \right. \right.$或$\left. x > 3 \right\}$
$\quad$C．$\left\{ x \left| \frac{1}{3} < x < \frac{1}{2} \right. \right\}$ 
$\quad$D．$\left\{ x \left| x < \frac{1}{3} \right. \right.$或$\left. x > \frac{1}{2} \right\}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据一元二次不等式解集和一元二次方程的根的关系，利用韦达定理可求得$a , b$；将所求不等式变为$x^{2} + 5 x + 6 < 0$，根据一元二次不等式的解法可求得结果.
<span class="fake-tag">详解</span>的解集为$\left\{ x \left| - \frac{1}{2} \leq x \leq - \frac{1}{3} \right. \right\}$
$\therefore a < 0$且方程$a x^{2} - b x - 1 = 0$的两根为：$- \frac{1}{3}$和$- \frac{1}{2}$
$\therefore \begin{cases}\frac{b}{a} = - \frac{1}{3} + \left( - \frac{1}{2} \right) = - \frac{5}{6} \\ - \frac{1}{a} = \left( - \frac{1}{3} \right) \times \left( - \frac{1}{2} \right) = \frac{1}{6}\end{cases}$，解得：$\begin{cases}a = - 6 \\ b = 5\end{cases}$
即$x^{2} - 5 x + 6 < 0$，解得：$2 < x < 3$
$\therefore x^{2} - b x - a < 0$的解集为$\left\{ \left. x | 2 < x < 3 \right\}$
故选:$A$
【点睛】本题考查一元二次不等式的求解，关键是能够根据一元二次不等式的解集和一元二次方程的根的关系求得$a , b$的值.属于中档题.
