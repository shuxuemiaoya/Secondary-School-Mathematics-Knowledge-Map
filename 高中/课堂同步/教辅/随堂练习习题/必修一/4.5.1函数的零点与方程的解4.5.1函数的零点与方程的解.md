### 知识点01 ：函数零点的概念
1、函数零点的概念
对于一般函数$y = f ( x )$，我们把使$f ( x ) = 0$的实数$x$叫做函数$y = f ( x )$的零点.
几何定义:函数$y = f ( x )$的零点就是方程$f ( x ) = 0$的实数解,也就是函数$y = f ( x )$的图象与$x$轴的公共点的横坐标.
这样：方程$f ( x ) = 0$有实数解$\Leftrightarrow$函数$y = f ( x )$有零点$\Leftrightarrow$函数$y = f ( x )$的图象与$x$轴有公共点
2、已学基本初等函数的零点
①一次函数$f ( x ) = k x + b ( k \neq 0 )$只有一个零点$- \frac{b}{k}$；
②反比例函数$f ( x ) = \frac{k}{x} ( k \neq 0 )$没有零点；
③指数函数$f ( x ) = a^{x}$（$a > 0$且$a \neq 1$）没有零点；
④对数函数$f ( x ) = \log_{a}^{x} {}$（$a > 0$且$a \neq 1$）只有一个零点1；
⑤幂函数$f ( x ) = x^{\alpha}$当$\alpha > 0$时，有一个零点0；当$\alpha \leq 0$时，无零点。
### 知识点02 ：函数零点存在定理及其应用
1、函数零点存在定理
如果函数$y = f ( x )$在区间$\lbrack a , b \rbrack$上的图象是一条连续不断的曲线，且有$f ( a ) f ( b ) < 0$，那么函数$y = f ( x )$在区间$( a , b )$内至少有一个零点，即存在$c \in ( a , b )$，使得$f ( c ) = 0$，这个$c$也就是方程$f ( x ) = 0$的解.
说明：定理要求具备两个条件:①函数在区间$\lbrack a , b \rbrack$上的图象是连续不断的;②$f ( a ) f ( b ) < 0$.两个条件缺一不可.
2、函数零点的求法
①代数法：根据零点定义，求出方程$f ( x ) = 0$的实数解;
②数形结合法：作出函数图象，利用函数性质求解
