### 知识点01 ：两角和与差的余弦公式
两角和与差的余弦公式
（1）$\cos ( \alpha - \beta ) = \cos \alpha \cos \beta + \sin \alpha \sin \beta$
（2）$\cos ( \alpha + \beta ) = \cos \alpha \cos \beta - \sin \alpha \sin \beta$

②适用条件:公式中的角$\alpha$,$\beta$是任意角.

### 知识点03 ：两角和与差的正切公式
两角和与差的正切公式
（1）$\tan ( \alpha - \beta ) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}$
（2）$\tan ( \alpha + \beta ) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta}$
①简记符号:$S_{\alpha - \beta}$,$S_{\alpha + \beta}$.
②适用条件:公式中的角$\alpha$,$\beta$，$\alpha + \beta$，$\alpha - \beta \neq k \pi + \frac{\pi}{2}$，$k \in Z$.
③变形结论：
$\tan \alpha + \tan \beta = \tan ( \alpha + \beta ) ( 1 - \tan \alpha \tan \beta )$
\tan \alpha - \tan \beta = \tan ( \alpha - \beta ) ( 1 + \tan \alpha \tan \beta )
