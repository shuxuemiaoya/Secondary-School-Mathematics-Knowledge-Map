##### 1. 【单选题】已知  $f\Big(\frac{1 - x}{1 + x}\Big) = \frac{1 - x^2}{1 + x^2}$  则  $f(x)$  的解析式为（
$\quad$A.  $f_{(x)} = \frac{x}{1 + x^{2}} (x\neq -1)$  
$\quad$B.  $f_{(x)} = \frac{-2x}{1 + x^{2}} (x\neq -1)$  
$\quad$C.  $f_{(x)} = \frac{2x}{1 + x^{2}} (x\neq -1)$  
$\quad$D.  $f_{(x)} = \frac{-x}{1 + x^{2}} (x\neq -1)$
##### 2. 【单选题】已知  $f\Big(\frac{1}{x - 1}\Big) = x + 1$  ，则  $f(x)$  的解析式为（
$\quad$A.  $\frac{1}{x + 2} (x\neq -2)$  
$\quad$B.  $\frac{1 + x}{x} (x\neq 0)$  
$\quad$C.  $\frac{1}{x} +2(x\neq 0)$  
$\quad$D.  $\frac{1}{x} -1(x\neq 0)$
##### 3. 【单选题】已知  $f\Big(\frac{l}{x}\Big) = \frac{l}{x + 1}$  则  $f(x)$  的解析式为（
$\quad$A.  $f_{(x)} = \frac{l}{1 + x}$  
$\quad$B.  $f_{(x)} = \frac{l + x}{x}$  
$\quad$C.  $f_{(x)} = \frac{x}{1 + x} (x\neq 0)$  
$\quad$D.  $f_{(x)} = x + 1$
##### 4. 【单选题】已知函数  $f(x)$  满足  $f\Big(x - \frac{l}{x}\Big) = x^{2} + \frac{l}{x^{2}} (x\neq 0)$  ，则  $f(x)$  的解析式为（
$\quad$A.  $f(x) = x + \frac{1}{x}$  
$\quad$B.  $f(x) = x^{2} + 2$  
$\quad$C.  $f(x) = x^{2}$  
$\quad$D.  $f(x) = \left(x - \frac{1}{x}\right)^{2}$
