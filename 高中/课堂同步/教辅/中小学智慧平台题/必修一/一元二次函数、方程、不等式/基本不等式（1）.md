# 一、多选题（共2题）

1.【多选题】（多选题）已知正数 a, b 满足 $a^{2} + \frac{b^{2}}{4} = 1$ ，下列说法正确的有（）

A. $ab$ 的最大值为 1  
B. $a + \frac{b}{2}$ 的最大值为 $\sqrt{2}$   
C. $a \sqrt{2 + b^2}$ 的最大值为 $\frac{3}{2}$   
D. $\frac{l}{a^2} +\frac{l}{b^2}$ 的最小值为2

2.【多选题】（多选题）下列说法正确的有（

A. $\forall x\in R,x + \frac{1}{x} >2$   
B. 若正实数 $x, y$ 满足 $2x + y = 1$ ，则 $\sqrt{2x} + \sqrt{y}$ 的最大值为 $\sqrt{2}$   
C. 若 $a, b$ 均为正实数，则 $\frac{a}{4} + \frac{b}{a} + \frac{4}{ab}$ 的最小值为 2  
D. 若正实数 $x, y$ 满足 $x^{2} + y^{2} = 1 + xy$ ，则 $1 < x + y \leqslant 2$

# 二、复合题（共4题）

3.【复合题】设x>0，y>0，且 $x+2y=4$ .

(1)【问答题】求 xy 的最大值;  
(2)【问答题】求 $(x+1)(2y+1)$ 的最大值.

4.【复合题】已知实数 a, b, c 满足 a > 0 ， b > 0 ， c > 0 ，且 abc = 1 .

(1)【问答题】证明： $(1+a)(1+b)(1+c)\geqslant8$ ；  
(2)【问答题】证明： $\sqrt{a} +\sqrt{b} +\sqrt{c}\leqslant \frac{l}{a} +\frac{l}{b} +\frac{l}{c}$

5.【复合题】已知 a > 0 ， b > 0 ， $a + b = 1$ ，求证：

(1)【问答题】 $ab \leqslant \frac{1}{4}$ ;

(2)【问答题】 $\left(1+\frac{l}{a}\right)\left(1+\frac{l}{b}\right)\geqslant9$

6.【复合题】不等式证明：

(1)【问答题】已知 $a$ 、 $b$ 、 $c \in \mathsf{R}$ ，求证： $\sqrt{a^2 + b^2} + \sqrt{b^2 + c^2} + \sqrt{c^2 + a^2} \geqslant \sqrt{2}(a + b + c)$ ；  
(2)【问答题】若 0 < x < 1 ， a > 0， b > 0 ，求证： $\frac{a^{2}}{x} + \frac{b^{2}}{1 - x} \geqslant (a + b)^{2}$
