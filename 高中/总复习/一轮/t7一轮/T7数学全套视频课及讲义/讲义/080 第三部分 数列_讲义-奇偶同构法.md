# 【奇偶同构观】

对于前面所讲的两种数列递推关系结构：

①和式数列： $a_{n+1} + a_n = An + B$ ，②积式数列： $a_{n+1}a_n = q^{An+B}$

都可以转化到基本的两种递推结构：

$$
① \Rightarrow a _ {n + 2} - a _ {n} = A, ② \Rightarrow a _ {n + 2} = q ^ {A} \cdot a _ {n}
$$

而这两种结构都可以根据等差或等比数列来找到同构方法，不妨直接利用同构方法直接找到奇偶通项.

# 【和式数列】

型如 $a_{n + 1} + a_n = An + B$ 类型：

由 $a_{n + 1} + a_n = An + B\Rightarrow a_{n + 2} - a_n = A$

与 $a_{n + 2} - a_n = A$ 对比得 $x = \frac{A}{2}$

当 n 为奇数时, $a_{n}=a_{1}+\frac{A}{2}(n-1)$

综合有 $a_{n} = \left\{ \begin{array}{l}a_{1} + \frac{A}{2} (n - 1),n\text{为奇数}\\ a_{1} + \frac{A}{2} (n - 2),n\text{为偶数} \end{array} \right.$

或者直接利用待定系数法可直接得到通项：

设 $a_{n} = \frac{A}{2} n + x + y(-1)^{n}$ ，代入 $a_1, a_2$ 可求得 $x, y$ .

设 $a_{n + 2} - x(n + 2) = a_n - xn\Rightarrow a_{n + 2} - a_n = 2x$

则有 $a_{n + 2} - \frac{A}{2} (n + 2) = a_n - \frac{A}{2} n = a_1 - \frac{A}{2} = a_2 - A$

当 n 为偶数时, $a_{n}=a_{1}+\frac{A}{2}(n-2)$

# 【积式数列】

型如 $a_{n + 1}a_n = q^{An + B}$ 类型：

由 $a_{n + 1}a_n = q^{An + B}\Rightarrow a_{n + 2} = q^A a_n$

与 $a_{n + 2} = q^A a_n$ 对比得 $q^{A} = p^{2}$

当 $n$ 为奇数时， $a_{n} = a_{1} \cdot p^{\frac{A}{2}(n - 1)}$

综合有 $a_{n} = \left\{ \begin{array}{ll}a_{1}\cdot p^{\frac{A}{2}(n - 1)},n\text{为奇数}\\ a_{1}\cdot q^{\frac{A}{2}(n - 2)},n\text{为偶数} \end{array} \right.$

或者直接利用待定系数法可直接得到通项：

设 $a_{n} = q^{\frac{A}{2} n + x + y(-1)^{n}}$ ，代入 $a_1, a_2$ 可求得 $x, y$ .

设 $\frac{a_{n + 2}}{p^{n + 2}} = \frac{a_n}{p^n}\Rightarrow a_{n + 2} = p^2 a_n$

则有 $\frac{a_{n + 2}}{p^{n + 2}} = \frac{a_n}{p^n}\Rightarrow a_n = a_1\cdot p^{n - 1} = a_2\cdot p^{n - 2}$

当 n 为偶数时， $a_{n}=a_{1}\cdot q^{\frac{A}{2}(n-2)}$
