# 【性质三】通项底标特性:

若数列 $\{a_{n}\}$ 是以 $d$ 为公差的等差数列,则有以下特性

(1)若 $m + n = 2t$ ，则 $a_{m} + a_{n} = 2a_{t}$ .(递推结论： $a_{k},a_{k + m},a_{k + 2m},\ldots$ 仍为等差数列，且公差为 $md$ )  
(2) 若 $m + n = p + q$ ，则 $a_{m} + a_{n} = a_{p} + a_{q}$ 。（递推结论：在有穷等差数列中， $a_{1} + a_{n} = a_{2} + a_{n-1} = \ldots = a_{i} + a_{n+1-i} = u$ ）  
(3)若 $m + n + t = p + q + r$ ，则 $a_{m} + a_{n} + a_{t} = a_{p} + a_{q} + a_{r}$   
(4)若 $a_{n} = m, a_{m} = n$ ，则 $a_{m + n} = 0$ .

【例 7】在等差数列 $\{a_{n}\}$ 中, 已知 $a_{4} + a_{8} = 16$ , 则该数列前 11 项和 $S_{11} =$ \_\_\_\_ .

【性质四】多个等差数列运算性质:

若数列 $\{a_{n}\} ,\{b_{n}\}$ 分别是以 $d_{1},d_{2}$ 为公差的等差数列,则有以下数列运算性质:

(1) $\{a_{n} + C\}$ 是等差数列, 公差为 $d_{1}$ . (C 为任意常数)  
(2) $\{Ca_{n}\}$ 是等差数列, 公差为 $Cd_{1}.$ ( $C$ 为任意常数)  
(3) $\{a_{n} + a_{n + m}\}$ 是等差数列, 公差为 $md_{1}$ . (m 为常数, 且 $m \in N^{*}$ )  
(4) $\{Aa_{n} + Bb_{n}\}$ 是等差数列, 公差为 $Ad_{1} + Bd_{2}$ . (A, B 为常数)  
(5) $\{a_{n}b_{n}\}$ 不是等差数列.
