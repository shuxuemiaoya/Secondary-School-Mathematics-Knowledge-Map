# 【倒序相加】

倒序相加法: 在前 n 项和中, 等距离的两项之间有一定的加减运算关系时, 考虑将前 n 项和, 重新倒写, 并与原来的式子求和, 最后除 2 即可得到在前 n 项和.

【观点】数列抽象成的函数具有中心对称性

【例 6】设 $f(x)=\frac{\cos x}{\cos(60^{\circ}-x)}$ ，则 $f(1^{\circ})+f(2^{\circ})+\cdots+f(58^{\circ})+f(59^{\circ})=$ \_\_\_\_.

【例 7】设 $f(x)=x^{3}$ ，则 $f(-4)+f(-3)+\cdots+f(3)+f(4)=$ \_\_\_\_.

【例 8】设 $f(x)=\frac{4^{x}}{4^{x}+2}$ ，则 $f(\frac{1}{1001})+f(\frac{2}{1001})+\cdots+f(\frac{1000}{1001})=$ \_\_\_\_.

【例 9】求 $S = \sin^{2}1^{\circ} + \sin^{2}2^{\circ} + \sin^{2}3^{\circ} \cdots + \sin^{2}89^{\circ}$ .

【例 10】已知数列 $\{a_{n}\}$ 的满足 $a_{n}=n\cdot C_{100}^{n}$ ，求 $\{a_{n}\}$ 的前 100 项和 $S_{100}$ .
