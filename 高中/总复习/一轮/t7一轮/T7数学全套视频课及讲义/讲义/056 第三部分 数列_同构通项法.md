【观点】前面所讲述的八种构造模型, 在不同的方法下, 可以得到通项公式, 而这些方法却需要学习不同的操作手段, 但是如果有一种方法可以使这些求通项更加便捷, 那么就是以一破万的效果.

【关系】递推关系中存在着 $a_{n + 1}$ ， $a_{n}$ 间的关系，通过构造常数列的方式即可将通项一步求出.

从等差数列与等比数列的定义开始基本同构：

【推导一】等差与等比基本同构：

等差数列： $a_{n + 1} - a_n = d\Rightarrow a_{n + 1} - d(n + 1) = a_n - dn = a_1 - d\Rightarrow a_n = a_1 + d(n - 1)$

等比数列： $a_{n + 1} = q\cdot a_n\Rightarrow \frac{a_{n + 1}}{q^{n + 1}} = \frac{a_n}{q^n} = \frac{a_1}{q}\Rightarrow a_n = a_1\cdot q^{n - 1}$

【同构二】累加与累乘基本同构：

从累加法与累乘法开始基本同构：

# 【推导二】累加与累乘基本同构：

累加法： $a_{n + 1} - a_n = f(n)$ ，考虑到 $f(n) = g(n + 1) - g(n)\Rightarrow a_{n + 1} - a_n = g(n + 1) - g(n)\Rightarrow$

$$
a _ {n + 1} - g (n + 1) = a _ {n} - g (n) = a _ {1} - g (1) \Rightarrow a _ {n} = a _ {1} + g (n) - - g (1)
$$

累乘法： $a_{n + 1} = f(n)\cdot a_n$ ，考虑到 $f(n) = \frac{g(n + 1)}{g(n)}\Rightarrow a_{n + 1} = \frac{g(n + 1)}{g(n)} a_n\Rightarrow \frac{a_{n + 1}}{g(n + 1)} = \frac{a_n}{g(n)} = \frac{a_1}{g(1)}\Rightarrow a_n = \frac{a_1}{g(1)}\cdot g(n)$

【同构三】简单同构模型：

$$
① \frac {a _ {n + 1}}{a _ {n}} = \frac {n + q}{n + p}; ② (n + q) a _ {n + 1} = (n + p) a _ {n}; ③ a _ {n + 1} - a _ {n} = A n + B
$$

$$
① a _ {n + 1} = A a _ {n} + B (A \neq 0); ② a _ {n + 1} = A a _ {n} + B n + C (A B \neq 0); ③ a _ {n + 1} = A a _ {n} + B \cdot C ^ {n} (A B \neq 0, C \neq 1)
