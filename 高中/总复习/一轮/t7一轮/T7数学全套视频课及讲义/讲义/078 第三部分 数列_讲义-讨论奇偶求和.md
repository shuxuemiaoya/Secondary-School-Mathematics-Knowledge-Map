# 【隔四项出现规律】

对于数列 $\{a_{n}\}$ 满足 $a_{n + 1} + (-1)^{n}a_{n} = An + B$ ，则会有 $S_{4m + 4} - S_{4m}$ 成等差数列.

【例 16】已知数列 $\{a_{n}\}$ 满足 $a_{1}+a_{2}=0$ 且 $a_{n+2}+(-1)^{\frac{n(n+1)}{2}}a_{n}=2$ ，求数列 $\{a_{n}\}$ 的前2020项和.

# 【奇偶裂项】

对于数列 $\{a_{n}\}$ 能够变为 $a_{n}=c_{n}+c_{n+1}$ 时, 可知 $\{a_{n}\}$ 不能直接求和,

但如果他们像 $a_{n} = c_{n} - c_{n + 1}$ 时，可直接得到数列 $\{a_n\}$ 的前 $n$ 项和为 $S_{n} = c_{1} - c_{n + 1}$

那么让 $\{a_{n}\}$ 的通项变为 $a_{n} = (-1)^{n - 1}(c_{n} + c_{n + 1})$ 时， $\{a_{n}\}$ 可以分类求和.

当 $n$ 为奇数时， $S_{n} = c_{1} + c_{2} - (c_{2} + c_{3}) + c_{3} + c_{4} - (c_{4} + c_{5}) + \ldots - (c_{n-1} + c_{n}) + c_{n} + c_{n+1}$ 化简得 $S_{n} = c_{1} + c_{n+1}$ .

当 n 为偶数时， $S_{n}=c_{1}+c_{2}-(c_{2}+c_{3})+c_{3}+c_{4}-(c_{4}+c_{5})+\ldots+c_{n-1}+c_{n}-(c_{n}+c_{n+1})$ 化简得 $S_{n}=c_{1}-c_{n+1}$ .

# 【常见裂项】

① $a_{n}=(-1)^{n-1}\cdot\frac{2n+1}{n(n+1)}$ ;

$S_{n} = \left\{ \begin{array}{l}\frac{n + 2}{n + 1},n\text{为奇数}\\ \frac{n}{n + 1},n\text{为偶数} \end{array} \right.$

② $a_{n} = (-1)^{n - 1}\cdot \frac{4n}{(2n - 1)(2n + 1)}$

$S_{n} = \left\{ \begin{array}{l}\frac{2n + 2}{2n + 1},n\text{为奇数}\\ \frac{2n}{2n + 1},n\text{为偶数} \end{array} \right.$

③ $a_{n} = (-1)^{n - 1}\cdot \frac{4(n + 1)}{(2n + 1)(2n + 3)}$

$S_{n} = \left\{ \begin{array}{l}\frac{2n + 4}{2n + 3},n\text{为奇数}\\ \frac{2n + 2}{2n + 3},n\text{为偶数} \end{array} \right.$

④ $a_{n}=(-1)^{n-1}\cdot ln(n+1)n$ ;

⑤ $a_{n} = (-1)^{n - 1}\cdot \frac{4n^{2} + 4n - 1}{(2n - 1)(2n + 1)}$

$S_{n} = \left\{ \begin{array}{l}ln(n + 1),n\text{为奇数}\\ ln(\frac{1}{n + 1}),n\text{为偶数} \end{array} \right.$

$S_{n} = \left\{ \begin{array}{l} \frac{1}{2n + 1}, n \text{为奇数} \\ \frac{2n}{2n + 1}, n \text{为偶数} \end{array} \right.$
