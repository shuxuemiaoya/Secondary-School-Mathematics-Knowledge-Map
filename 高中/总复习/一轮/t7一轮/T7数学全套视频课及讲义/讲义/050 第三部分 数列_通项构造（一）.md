【构造模型一】 $a_{n+1}=Aa_{n}+B(A\neq0)$ 型构造

【模板一】 $a_{n+1}=Aa_{n}+B(A\neq0)$ 型构造推导：

当 $A \neq 1$ 时, 令 $a_{n+1} + x = A(a_n + x)$

当 $A = 1$ 时， $a_{n + 1} = a_n + B$

得 $a_{n + 1} = Aa_n + (A - 1)x$

变形为 $a_{n + 1} - a_n = B$ ，则 $\{a_n\}$ 为等差数列

对比 $a_{n + 1} = Aa_{n} + B$

有 $a_{n} = a_{1} + B(n - 1)$

有 $(A - 1)x = B$ ，解得 $x = \frac{B}{A - 1}$

则 $a_{n + 1} + \frac{B}{A - 1} = A(a_n + \frac{B}{A - 1})$

令 $b_{n}=a_{n}+\frac{B}{A-1}\Rightarrow b_{n+1}=Ab_{n}$

则 $b_{n}$ 是以 $A$ 为公比，以 $a_1 + \frac{B}{A - 1}$ 为首项的等比数列

则 $b_{n}=(a_{1}+\frac{B}{A-1})A^{n-1}=a_{n}+\frac{B}{A-1}$

解得 $a_{n} = (a_{1} + \frac{B}{A - 1})A^{n - 1} - \frac{B}{A - 1} = a_{1}\cdot A^{n - 1} + \frac{B}{A - 1}(A^{n - 1} - 1)$

【例 1】在数列 $\{a_{n}\}$ 中， $a_{1}=5$ ， $a_{n+1}=3a_{n}-4$ ，求数列 $\{a_{n}\}$ 的通项公式.

【例 2】在数列 $\{a_{n}\}$ 中， $a_{3}=2$ ， $a_{n+1}=2a_{n}-1$ ，求数列 $\{a_{n}\}$ 的通项公式.

【模板二】 $a_{n+1}=Aa_{n}+Bn+C(AB\neq0)$ 型构造推导：

当 $A \neq 1$ 时, 令 $a_{n+1} + x(n+1) + y = A(a_n + xn + y)$

解得 $b_{n} = \left[a_{1} + \frac{B + C}{A - 1} +\frac{B}{(A - 1)^{2}}\right]A^{n - 1}$

得 $a_{n + 1} = Aa_{n} + (A - 1)xn + (A - 1)y - x$

从而得到

对比 $a_{n + 1} = Aa_n + Bn + C(AB\neq 0)$

$$
a _ {n} = \left[ a _ {1} + \frac {B + C}{A - 1} + \frac {B}{(A - 1) ^ {2}} \right] A ^ {n - 1} - \frac {B n + C}{A - 1} - \frac {B}{(A - 1) ^ {2}}
$$

有方程组 $(A - 1)x = B$ ， $(A - 1)y - x = C$

当 A=1 时， $a_{n+1}=a_{n}+Bn+C(B\neq0)$

解得 $x = \frac{B}{A - 1}, y = \frac{B}{(A - 1)^2} + \frac{C}{A - 1}$

使用累加法可得到 $a_{n} = (n - 1)\left(\frac{B}{2} n + C\right) + a_{1}$

则 $a_{n + 1} + \frac{B}{A - 1} (n + 1) + \frac{B}{(A - 1)^2} +\frac{C}{A - 1} = A(a_n + \frac{B}{A - 1} n + \frac{B}{(A - 1)^2} +\frac{C}{A - 1})$

令 $b_{n}=a_{n}+\frac{B}{A-1}n+\frac{B}{(A-1)^{2}}+\frac{C}{A-1}\Rightarrow b_{n+1}=Ab_{n}$

则 $b_{n}$ 是以 A 为公比, 以 $a_{1}+\frac{B+C}{A-1}+\frac{B}{(A-1)^{2}}$ 为首项的等比数列

【构造模型三】 $a_{n+1}=Aa_{n}+Bn^{2}+Cn+D(AB\neq0)$ 型构造

【模板三】 $a_{n+1}=Aa_{n}+Bn^{2}+Cn+D(AB\neq0)$ 型构造推导(非必须学会):

当 $A \neq 1$ 时, 令 $a_{n+1} + x(n+1)^2 + yn + z = A(a_n + xn^2 + yn + z)$

得 $a_{n + 1} = Aa_{n} + (A - 1)\left[xn^{2} + yn + z\right] - x(2n + 1)$ 对比 $a_{n + 1} = Aa_{n} + Bn^{2} + Cn + D(AB\neq 0)$

得方程组 $(A-1)x=B$ ， $(A-1)y-2x=C$ ， $(A-1)z-x=D$

解得 $x = \frac{B}{A - 1}, y = \frac{C}{A - 1} + \frac{2B}{(A - 1)^2}, z = \frac{D}{A - 1} + \frac{B}{(A - 1)^2}$

$$
a _ {n + 1} + \frac {B}{A - 1} (n + 1) ^ {2} + \frac {C}{A - 1} + \frac {2 B}{(A - 1) ^ {2}} n + \frac {D}{A - 1} + \frac {B}{(A - 1) ^ {2}} = A \left[ a _ {n} + \frac {B}{A - 1} n ^ {2} + \frac {C}{A - 1} + \frac {2 B}{(A - 1) ^ {2}} n + \frac {D}{A - 1} + \frac {B}{(A - 1) ^ {2}} \right]
$$

令 $b_{n}=a_{n}+\frac{B}{A-1}n^{2}+\frac{C}{A-1}+\frac{2B}{(A-1)^{2}}n+\frac{D}{A-1}+\frac{B}{(A-1)^{2}},b_{1}=a_{1}+\frac{B}{A-1}+\frac{C}{A-1}+\frac{2B}{(A-1)^{2}}+\frac{D}{A-1}+\frac{B}{(A-1)^{2}}$

$\Rightarrow b_{n+1}=Ab_{n}$ ，则 $b_{n}$ 是以A为公比，以 $b_{1}$ 为首项的等比数列

解得 $b_{n}=b_{1}\cdot A^{n-1}$ ，从而得到 $a_{n}=b_{1}\cdot A^{n-1}-\left[+\frac{B}{A-1}n^{2}+\frac{C}{A-1}+\frac{2B}{(A-1)^{2}}n+\frac{D}{A-1}+\frac{B}{(A-1)^{2}}\right]$

$b_{1}=a_{1}+\frac{B}{A-1}+\frac{C}{A-1}+\frac{2B}{(A-1)^{2}}+\frac{D}{A-1}+\frac{B}{(A-1)^{2}}$ 当 A=1 时, 涉及了高考不要求的求和方法, 无需学会.

【构造模型四】 $a_{n+1}=Aa_{n}+B\cdot C^{n}+D(AB\neq0,C\neq1)$ 型构造

常考形式 $a_{n + 1} = Aa_{n} + B\cdot C^{n}(AB\neq 0,C\neq 1)$

【模板四】 $a_{n+1}=Aa_{n}+B\cdot C^{n}+D(AB\neq0,C\neq1)$ 型构造推导：

先处理 $D$ ，不看 $B\cdot C^n$ ，则有 $a_{n + 1} = Aa_n + D$

令 $a_{n+1} + x = A(a_n + x)$ ，整理并对比 $a_{n+1} = A a_n + D$

有 $(A - 1)x = D\Rightarrow x = \frac{D}{A - 1}\Rightarrow a_{n + 1} + \frac{D}{A - 1} = A(a_n + \frac{D}{A - 1})$

令 $b_{n}=a_{n}+\frac{D}{A-1}$ ，则 $b_{n+1}=Ab_{n}+B\cdot C^{n}(AB\neq0,C\neq1)$

变形得 $\frac{b_{n + 1}}{C^{n + 1}} = \frac{A}{C}\cdot \frac{b_n}{C^n} +\frac{B}{C}$

再令 $t_{n}=\frac{b_{n}}{C^{n}}\Rightarrow t_{n+1}=\frac{A}{C}\cdot t_{n}+\frac{B}{C}$ 转化到构造模型一

解得 $t_n = \frac{b_n}{C^n} = (\frac{b_1}{C} +\frac{B}{A - C})(\frac{A}{C})^{n - 1} - \frac{B}{A - C}$

整理得 $b_{n}=a_{n}+\frac{D}{A-1}=(b_{1}+\frac{BC}{A-C})A^{n-1}-\frac{B}{A-C}\cdot C^{n}$

最终 $a_{n} = (a_{1} + \frac{D}{A - 1} +\frac{BC}{A - C})A^{n - 1} - \frac{B}{A - C}\cdot C^{n} - \frac{D}{A - 1}$

对于 $a_{n+1}=Aa_{n}+B\cdot C^{n}+D(AB\neq0,C\neq1)$ 中含有 D 的题目, 并不多见, 所以建议学习以下模板:

$a_{n+1}=Aa_{n}+B\cdot C^{n}(AB\neq0,C\neq1)$ 型构造推导

变形原式 $\frac{a_{n + 1}}{C^{n + 1}} = \frac{A}{C}\cdot \frac{a_n}{C^n} +\frac{B}{C},$ 令 $b_{n} = \frac{a_{n}}{C^{n}}$

则 $b_{n+1}=\frac{A}{C}\cdot b_{n}+\frac{B}{C}$ 转化到构造模型一

解得 $b_{n}=\frac{a_{n}}{C^{n}}=(\frac{a_{1}}{C}+\frac{B}{A-C})(\frac{A}{C})^{n-1}-\frac{B}{A-C}$

最终 $a_{n} = (a_{1} + \frac{BC}{A - C})A^{n - 1} - \frac{B}{A - C}\cdot C^{n}$

【模板五】 $a_{n+1}=Aa_{n}^{r}(Ar\neq0,$ 且 $r\neq1)$ 型构造推导：
