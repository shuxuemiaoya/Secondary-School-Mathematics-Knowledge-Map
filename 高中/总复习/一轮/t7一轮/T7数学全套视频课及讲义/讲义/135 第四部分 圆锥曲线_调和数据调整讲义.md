# 一：轴点调和数据

过点 $M(x_{0},0)$ 的直线 l 与椭圆 $C:\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$ 交于 $A(x_{1},y_{1})$ ， $B(x_{2},y_{2})$ ，l 的斜率为 k

有以下调和数据调整：

① $\frac{1}{x_1 - x_0} +\frac{1}{x_2 - x_0} = \frac{2}{\frac{a^2}{x_0} - x_0};$ ② $\frac{1}{x_1 - \frac{a^2}{x_0}} +\frac{1}{x_2 - \frac{a^2}{x_0}} = \frac{2}{x_0 - \frac{a^2}{x_0}};$

对①②通分有 $(x_0 + \frac{a^2}{x_0})(x_1 + x_2) = 2(x_1x_2 + a^2)$

③ $\frac{y_1}{x_1 - \frac{a^2}{x_0}} +\frac{y_2}{x_2 - \frac{a^2}{x_0}} = 0;$ ④ $(\frac{a^2}{x_0} -x_0)(y_1 + y_2) = \frac{2}{k} y_1y_2;$

过点 $M(0, y_{0})$ 的直线 l 与椭圆 $C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1$ 交于 $A(x_{1}, y_{1})$ ， $B(x_{2}, y_{2})$ ，l 的斜率为 k

有以下调和数据调整：

① $\frac{1}{y_1 - y_0} +\frac{1}{y_2 - y_0} = \frac{2}{\frac{b^2}{y_0} - y_0};$ ② $\frac{1}{y_1 - \frac{b^2}{y_0}} +\frac{1}{y_2 - \frac{b^2}{y_0}} = \frac{2}{y_0 - \frac{b^2}{y_0}};$

对①②通分有 $(y_0 + \frac{b^2}{y_0})(y_1 + y_2) = 2(y_1y_2 + b^2)$

③ $\frac{y_1 - \frac{b^2}{y_0}}{x_1} +\frac{y_2 - \frac{b^2}{y_0}}{x_2} = 0;$ ④ $(\frac{b^2}{y_0} -y_0)(x_1 + x_2) = 2kx_1x_2$

# 二：非轴点调和数据调整

过点 $M(x_0, y_0)$ 的直线 $l$ 与椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 交于 $A(x_1, y_1)$ ， $B(x_2, y_2)$ ，记 $p(x, y) = \frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} - 1$ 设 $\overrightarrow{AM} = \lambda \overrightarrow{MB}$ ，有 $\left\{ \begin{array}{l} x_1 + \lambda x_2 = x_0 (1 + \lambda) \\ y_1 + \lambda y_2 = y_0 (1 + \lambda) \end{array} \right.$ ，根据定比点差法可得 $\frac{x_0 (x_1 - \lambda x_2)}{a^2} + \frac{y_0 (y_1 - \lambda y_2)}{b^2} = 1 - \lambda$ 联立解得 $\left\{ \begin{array}{l} 2\left(\frac{x_0x_1}{a^2} + \frac{y_0y_1}{b^2} - 1\right) = \left(\frac{x_0^2}{a^2} + \frac{y_0^2}{b^2} - 1\right)(1 + \lambda) \\ 2\left(\frac{x_0x_2}{a^2} + \frac{y_0y_2}{b^2} - 1\right) = \left(\frac{x_0^2}{a^2} + \frac{y_0^2}{b^2} - 1\right)\left(1 + \frac{1}{\lambda}\right) \end{array} \right.$ ，即对偶式 $\left\{ \begin{array}{l} p_1 = \frac{p_0}{2}(1 + \lambda) \\ p_2 = \frac{p_0}{2}(1 + \frac{1}{\lambda}) \end{array} \right.$

可得调整对偶式 $\left\{ \begin{array}{l} \frac{1}{p_1} + \frac{1}{p_2} = \frac{2}{p_0} \\ \frac{1}{p_1 - p_0} + \frac{1}{p_2 - p_0} = -\frac{2}{p_0} \end{array} \right.$ ，对下式变形 $\left\{ \begin{array}{l} p_1 - p_0 = \frac{x_0}{a^2}(x_1 - x_0) + \frac{y_0}{b^2}(y_1 - y_0) \\ p_2 - p_0 = \frac{x_0}{a^2}(x_2 - x_0) + \frac{y_0}{b^2}(y_2 - y_0) \end{array} \right.$

设 l 斜率为 k，可得方程组 $\left\{\begin{aligned}y_{1}-y_{0}&=k(x_{1}-x_{0})\\ y_{2}-y_{0}&=k(x_{2}-x_{0})\end{aligned}\right.$

代入斜率方程可得 $\left\{\begin{aligned}p_{1}-p_{0}&=(\frac{x_{0}}{a^{2}}+\frac{y_{0}k}{b^{2}})(x_{1}-x_{0})=(\frac{x_{0}}{a^{2}k}+\frac{y_{0}}{b^{2}})(y_{1}-y_{0})\\ p_{2}-p_{0}&=(\frac{x_{0}}{a^{2}}+\frac{y_{0}k}{b^{2}})(x_{2}-x_{0})=(\frac{x_{0}}{a^{2}k}+\frac{y_{0}}{b^{2}})(y_{2}-y_{0})\end{aligned}\right.$

代入变形式可得 $\left\{ \begin{array}{l} \frac{1}{x_1 - x_0} + \frac{1}{x_2 - x_0} = -\frac{2}{p_0} \left( \frac{x_0}{a^2} + \frac{y_0k}{b^2} \right) \\ \frac{1}{y_1 - y_0} + \frac{1}{y_2 - y_0} = -\frac{2}{p_0} \left( \frac{x_0}{a^2k} + \frac{y_0}{b^2} \right) \end{array} \right.$

另外对调整对偶式而言，有 $\frac{p_1}{p_1 - p_0} +\frac{p_2}{p_2 - p_0} = 0$ ，代入变形 $\left\{ \begin{array}{l}\frac{p_1}{x_1 - x_0} +\frac{p_2}{x_2 - x_0} = 0\\ \frac{p_1}{y_1 - y_0} +\frac{p_2}{y_2 - y_0} = 0 \end{array} \right.$
