# 等比数列概念与通项

# DENG BI SHU LIE GAI NIAN YU TONG XIANG

主讲人：暄尘

【概念二】等比数列:一般地, 如果一个数列从第 2 项起, 每一项与它的前一项的比等于同一个常数, 那么这个数列就叫做等比数列, 这个常数叫做公比, 公比通常用字母 $q$ 表示.

递推关系: $\frac{a_{n+1}}{a_n} = q$ 或 $\frac{a_n}{a_{n-1}} = q (n \in N^*$ 且 $n \geq 2)$

通项公式:1. 基本式 $a_{n}=a_{1}\cdot q^{n-1}$

2. 推广式 $a_{n}=a_{m}\cdot q^{n-m}$ (课本习题)  
3. 统一式 $a_{n} = p \cdot q^{n}$

等比数列中的基本量:1. $a_{1}$ 2. $a_{n}$ 3. q

知其中之二，可求剩余其一
