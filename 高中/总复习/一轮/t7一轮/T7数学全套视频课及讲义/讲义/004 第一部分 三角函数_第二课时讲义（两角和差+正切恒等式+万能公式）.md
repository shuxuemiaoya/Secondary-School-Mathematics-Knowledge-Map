# 二、正切恒等式

\text {当} A + B + C = k \pi \text {时,} \tan A + \tan B + \tan C = \tan A \tan B \tan C
$$

【证明】 $-\tan C = \tan (A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B},$

$$
\therefore \tan A + \tan B = - \tan C (1 - \tan A \tan B), \text {即} \tan A + \tan B + \tan C = \tan A \tan B \tan C.

# 三、万能公式与统一变量

$$
t = \tan {\frac {x}{2}}, \text {则} \sin x = {\frac {2 t}{t ^ {2} + 1}}, \cos x = {\frac {1 - t ^ {2}}{1 + t ^ {2}}}.
$$

【变形】 $\sin x = 2\sin \frac{x}{2}\cos \frac{x}{2} = \frac{2\sin\frac{x}{2}\cos\frac{x}{2}}{\sin^2\frac{x}{2} + \cos^2\frac{x}{2}} = \frac{2\tan\frac{x}{2}}{\tan^2\frac{x}{2} + 1};$

$$
\cos x = \cos^ {2} \frac {x}{2} - \sin^ {2} \frac {x}{2} = \frac {\cos^ {2} \frac {x}{2} - \sin^ {2} \frac {x}{2}}{\sin^ {2} \frac {x}{2} + \cos^ {2} \frac {x}{2}} = \frac {1 - \tan^ {2} \frac {x}{2}}{1 + \tan^ {2} \frac {x}{2}};
$$
