# 【求和公式】

累加法求和： $a_{n+1}-a_{n}=f(n)\Rightarrow a_{n+1}-a_{1}=f(1)+f(2)+f(3)+\cdots+f(n)$

等差数列求和： $a_{n} = a_{1} + d(n - 1)\Rightarrow S_{n} = \frac{n(a_{1} + a_{n})}{2} = na_{1} + \frac{n(n - 1)}{2}\cdot d = \frac{d}{2} n^{2} + (a_{1} - \frac{d}{2})n$

# 【分组求和一并项求和】

分组求和法: 将前 n 项和中的 n 个项分别分成几组, 对于分到同一组的几项, 他们之间存在着相同的通项结构, 且他们的几项和可以用公式求和, 或者容易求出.

并项求和法: 将前 n 项和中相同结构的项或运算结构上优化的项, 合并在一起, 提出他们都具有的特点, 然后再进行求和.

PS: 从大致方向上来看, 分组求和与并项求和其实是一样的, 都是将多个项放在一起进行求和.
