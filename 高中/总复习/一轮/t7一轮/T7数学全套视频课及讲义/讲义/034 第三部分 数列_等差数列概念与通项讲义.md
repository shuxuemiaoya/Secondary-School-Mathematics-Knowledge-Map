# 等差数列概念与通项

# DENG CHA SHU LIE GAI NIAN YU TONG XIANG

主讲人：暄尘

【概念一】等差数列:一般地, 如果一个数列从第 2 项起, 每一项与它的前一项的差等于同一个常数, 那么这个数列就叫做等差数列, 这个常数叫做公差, 公差通常用字母 $d$ 表示.

递推关系: $a_{n+1}-a_{n}=d$ 或 $a_{n}-a_{n-1}=d$ $(n\in N^{*}$ 且 $n\geq2)$

通项公式:1.基本式 $a_{n}=a_{1}+(n-1)d$

2. 推广式 $a_{n}=a_{m}+(n-m)d$ (课本习题)  
3. 统一式 $a_{n} = pn + q$

等差数列中的基本量: $1.a_{1}$ $2.a_{n}$ $3.d$

知其中之二，可求剩余其一
