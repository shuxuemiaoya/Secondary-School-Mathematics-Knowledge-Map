1. (★)

函数 $y = \frac{\sqrt{4 - x^2}}{\ln(x + 1)}$ 的定义域为（）

A. $[-2, 2]$

B. $(-1, 2]$

C. $(-1,0)\cup (0,2]$

D. $(-1,1)\cup (1,2]$

1. C

解析：由题意， $\left\{ \begin{array}{l}4 - x^{2}\geq 0\\ \ln (x + 1)\neq 0,\\ x + 1 > 0 \end{array} \right.$ 所以 $-1 <   x <   0$ 或 $0 <   x\leq 2$

2. (2022·四川遂宁期末·★★)

若函数 $f(x + 1)$ 的定义域为 $[-1,0]$ ，则 $f(\lg x)$ 的定义域为（）

A. [10,100]

B. [1,2]

C. [1,10]

D. $(0,1]$

2. C

解析： $f(x + 1)$ 定义域为 $[-1,0]\Rightarrow -1\leq x\leq 0\Rightarrow 0\leq x + 1\leq 1$

因为括号范围恒不变，所以 $0 \leq \lg x \leq 1$ ，从而 $1 \leq x \leq 10$

故 $f(\lg x)$ 的定义域是[1,10].

3. (2022·陕西临潼一模·★★☆)

已知 $f(x + 1) = \ln x^2$ ，则 $f(x) =$ （

A. $\ln (x + 1)^{2}$

B. $2 \ln (x + 1)$

C. $2\ln |x - 1|$

D. $\ln (x^{2} - 1)$

3. C

解析：设 $t = x + 1$ ，则 $x = t - 1$ ， $f(t) = \ln (t - 1)^2$

还可将 2 拿到前面，但 t-1 的正负不定，故需加绝对值，

所以 $f(t) = 2\ln |t - 1|$ ，故 $f(x) = 2\ln |x - 1|$

4. (2022·安徽四校联考·★★☆)

已知 $f(x)$ 的定义域为 $(0, +\infty)$ ，且 $f(x) = 2f\left(\frac{1}{x}\right) + \ln x$ ，则 $f(x) = \underline{\quad}$ .

4. $\frac{\ln x}{3}$

解析：在 $f(x) = 2f\left(\frac{1}{x}\right) + \ln x$ 中将 $x$ 换成 $\frac{1}{x}$ 可得

$f\left(\frac{1}{x}\right) = 2f(x) + \ln \frac{1}{x}$ ，所以 $\left\{ \begin{array}{ll}f(x) = 2f\left(\frac{1}{x}\right) + \ln x & ①\\ f\left(\frac{1}{x}\right) = 2f(x) + \ln \frac{1}{x} & ② \end{array} \right.$

① + 2 × ② 得 $f(x) + 2f\left(\frac{1}{x}\right) = 2f\left(\frac{1}{x}\right) + \ln x + 4f(x) +$

$$
2 \ln \frac {1}{x} \Rightarrow f (x) = \frac {1}{3} \left(- \ln x - 2 \ln \frac {1}{x}\right) = \frac {1}{3} (- \ln x + 2 \ln x) = \frac {\ln x}{3}.
$$

# 5. (★★★)

已知函数 $f(x)$ ， $g(x)$ 的定义域都是 $\mathbf{R}$ ，且 $f(x)$ 为偶函数， $g(x)$ 为奇函数， $f(x) - g(x) = e^{-x}$ ，则 $f(x)$ 的最小值为 \_\_\_\_.

5.1

解析: 欲求 $f(x)$ 的最小值, 需先求解析式. 已有一个关于 $f(x)$ 和 $g(x)$ 的方程, 考虑再构造一个, 可在所给方程中将 $x$ 换成 $-x$ , 结合奇偶性化为关于 $f(x)$ 和 $g(x)$ 的新方程,

因为 $f(x) - g(x) = \mathrm{e}^{-x}$ ，所以 $f(-x) - g(-x) = \mathrm{e}^x$

结合 $f(x)$ 为偶函数， $g(x)$ 为奇函数可得 $f(x) + g(x) = \mathrm{e}^x$

由 $\left\{ \begin{array}{l} f(x) - g(x) = \mathrm{e}^{-x}\\ f(x) + g(x) = \mathrm{e}^{x} \end{array} \right.$ 解得： $f(x) = \frac{\mathrm{e}^{-x} + \mathrm{e}^x}{2},$

观察发现已有“积定”，故直接用基本不等式求最小值，

所以 $f(x) = \frac{\mathrm{e}^{-x} + \mathrm{e}^x}{2}\geq \sqrt{\mathrm{e}^{-x}\cdot\mathrm{e}^x} = 1$

取等条件是 $\mathrm{e}^{-x} = \mathrm{e}^{x}$ ，即 $x = 0$ ，故 $f(x)$ 的最小值为1.

# 6. (★★)

函数 $f(x)=2^{x^{2}-2x}(0\leq x\leq3)$ 的值域是 \_\_\_\_.

6. $\left[\frac{1}{2}, 8\right]$

解析：观察可发现 $f(x)$ 由 $y = 2^{t}$ 与 $t = x^{2} - 2x$ 复合而成，有 $x$ 的范围，可先求 $t$ 的范围，

令 $t = x^{2} - 2x$ ，则 $t = (x - 1)^{2} - 1$ ，且 $f(x) = 2^t$

因为 $0 \leq x \leq 3$ ，所以 $-1 \leq t \leq 3$ ，从而 $\frac{1}{2} \leq 2^t \leq 8$

故 $f(x)$ 的值域是 $\left[\frac{1}{2}, 8\right]$ .

# 7. (2022·辽宁模拟·★★)

函数 $y=\frac{x^{2}+x+1}{x^{2}-x+1}$ 的值域为 \_\_\_\_.

7. $\left[\frac{1}{3}, 3\right]$

解法 1: 看到 “ $\frac{\text{二次函数}}{\text{二次函数}}$ ” 这种结构, 想到将分子的平方项按分母的形式配凑, 拆项化为 “ $\frac{\text{一次函数}}{\text{二次函数}}$ ”,

由题意， $y=\frac{x^{2}+x+1}{x^{2}-x+1}=\frac{(x^{2}-x+1)+2x}{x^{2}-x+1}=1+\frac{2x}{x^{2}-x+1}$

上下同除以 $x$ ，可化双勾函数模型，先看 $x = 0$ 的情形，

当 $x = 0$ 时， $y = 1$ ；当 $x \neq 0$ 时， $y = 1 + \frac{2}{x + \frac{1}{x} - 1}$ ，

由 $x + \frac{1}{x}\leq -2$ 或 $x + \frac{1}{x}\geq 2$ 得 $x + \frac{1}{x} -1\leq -3$ 或 $x + \frac{1}{x} -1\geq 1$

所以 $-\frac{2}{3} \leq \frac{2}{x + \frac{1}{x} - 1} < 0$ 或 $0 < \frac{2}{x + \frac{1}{x} - 1} \leq 2$

故 $\frac{1}{3} \leq y < 1$ 或 $1 < y \leq 3$

综上所述，函数 $y = \frac{x^2 + x + 1}{x^2 - x + 1}$ 的值域为 $\left[\frac{1}{3}, 3\right]$ .

解法2： $y = \frac{x^2 + x + 1}{x^2 - x + 1}\Rightarrow y(x^2 -x + 1) = x^2 +x + 1,$

整理得： $(y - 1)x^{2} - (y + 1)x + y - 1 = 0$ ①，

当 y=1 时，x=0；

当 $y \neq 1$ 时，方程①可以看成关于 $x$ 的一元二次方程，

其判别式 $\Delta = (y + 1)^2 - 4(y - 1)^2 \geq 0$ ，所以 $\frac{1}{3} \leq y \leq 3 (y \neq 1)$ ，

综上所述，函数 $y = \frac{x^2 + x + 1}{x^2 - x + 1}$ 的值域为 $\left[\frac{1}{3}, 3\right]$ .

8.（2022·江苏模拟·★★☆）

函数 $y=\frac{\sqrt{x^{2}+1}}{x^{2}+2}$ 的最大值为 \_\_\_\_.

8. $\frac{1}{2}$

解析：将 $\sqrt{x^{2}+1}$ 看成关于 x 的一次式，则为 “ $\frac{一次}{二次}$ ” 结构，可将 “一次” 换元成 t，再上下同除以 t 化基本不等式模型，

设 $t = \sqrt{x^2 + 1}$ ，则 $t\geq 1$ ，且 $y = \frac{\sqrt{x^2 + 1}}{x^2 + 2} = \frac{\sqrt{x^2 + 1}}{x^2 + 1 + 1}$

$= \frac{t}{t^2 + 1} = \frac{1}{t + \frac{1}{t}}\leq \frac{1}{2\sqrt{t\cdot\frac{1}{t}}} = \frac{1}{2}$ ，取等条件是 $t = \frac{1}{t}$ ，即 $t = 1$

此时 $x = 0$ ，所以函数 $y = \frac{\sqrt{x^2 + 1}}{x^2 + 2}$ 的最大值为 $\frac{1}{2}$

9. (2022·广西模拟·★★★)

函数 $y=\frac{2x-1}{\sqrt{x-1}+1}$ 的最小值为 \_\_\_\_.

9. $2 \sqrt{6} - 4$

解析：解析式中分母这部分最复杂，考虑将其整体换元，

设 $t = \sqrt{x - 1} + 1$ ，则 $t\geq 1$ ， $x = (t - 1)^{2} + 1$

所以 $y = \frac{2x - 1}{\sqrt{x - 1} + 1} = \frac{2[(t - 1)^2 + 1] - 1}{t} = \frac{2t^2 - 4t + 3}{t}$

$$
= 2 t + \frac {3}{t} - 4 \geq 2 \sqrt {2 t \cdot \frac {3}{t}} - 4 = 2 \sqrt {6} - 4,
$$

当且仅当 $2t = \frac{3}{t}$ ，即 $t = \frac{\sqrt{6}}{2}$ 时取等号，

故函数 $y = \frac{2x - 1}{\sqrt{x - 1} + 1}$ 的最小值为 $2\sqrt{6} - 4$ .
