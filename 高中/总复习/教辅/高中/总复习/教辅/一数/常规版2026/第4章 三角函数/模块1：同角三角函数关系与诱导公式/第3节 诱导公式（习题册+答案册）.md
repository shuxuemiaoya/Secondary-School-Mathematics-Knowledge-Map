# 强化训练

1. (2025·陕西模拟·★★)

已知角 $\alpha$ 的终边经过点 $P(-3,4)$ ，则 $\frac{\sin(\pi - \alpha) + \cos(3\pi + \alpha)}{\cos\left(\frac{3\pi}{2} + \alpha\right) - \sin\left(\frac{7\pi}{2} - \alpha\right)} = \underline{\hspace{2cm}}.$

1.7

解析：观察发现所求式能用诱导公式化简，故先化简，再看如何与已知条件联系起来，

由诱导公式， $\frac{\sin(\pi - \alpha) + \cos(3\pi + \alpha)}{\cos\left(\frac{3\pi}{2} + \alpha\right) - \sin\left(\frac{7\pi}{2} - \alpha\right)} = \frac{\sin\alpha - \cos\alpha}{\sin\alpha + \cos\alpha}$

$$
= \frac {\tan \alpha - 1}{\tan \alpha + 1} \quad ①,
$$

由三角函数定义， $\tan \alpha = \frac{4}{-3} = -\frac{4}{3}$

代入①得所求式 $= \frac{-\frac{4}{3} - 1}{-\frac{4}{3} + 1} = 7$

2. (2022·湖北襄阳模拟·★★)

已知函数 $f(x) = a\sin (\pi x + \alpha) + b\cos (\pi x + \beta)$ ，且 $f(3) = 3$ ，则 $f(2022)$ 的值为（）

A. -1

B. 1

C. 3

D. -3

2. D

解析：本题无法求出 $a, b, \alpha, \beta$ ，故先看看由 $f(3) = 3$ 能得到什么，和 $f(2022)$ 又有什么关系，

由题意， $f(3) = a\sin (3\pi +\alpha) + b\cos (3\pi +\beta)$

$$
= - a \sin \alpha - b \cos \beta = 3, \text {所以} a \sin \alpha + b \cos \beta = - 3,
$$

故 $f(2022) = a\sin (2022\pi +\alpha) + b\cos (2022\pi +\beta)$

$$
= a \sin \alpha + b \cos \beta = - 3.
$$

3. (2023·湖北武汉四调·★★)

已知 $\sin \left(\alpha +\frac{\pi}{3}\right) = \frac{3}{5}$ ，则 $\sin \left(2\alpha +\frac{\pi}{6}\right) =$ （

A. $\frac{24}{25}$

B. $-\frac{24}{25}$

C. $\frac{7}{25}$

D. $-\frac{7}{25}$

3. D

解析：给值求值问题，可尝试找求值角与已知角的联系，若看不出来，可将已知角换元，

设 $t = \alpha +\frac{\pi}{3}$ ，则 $\alpha = t - \frac{\pi}{3}$ ，且 $\sin t = \frac{3}{5}$

所以 $\sin \left(2\alpha +\frac{\pi}{6}\right) = \sin \left[2\left(t - \frac{\pi}{3}\right) + \frac{\pi}{6}\right] = \sin \left(2t - \frac{\pi}{2}\right)$

$$
= - \cos 2 t = - (1 - 2 \sin^ {2} t) = - \left[ 1 - 2 \times \left(\frac {3}{5}\right) ^ {2} \right] = - \frac {7}{2 5}.
$$

4. (2022·湖南模拟·★★☆)

已知 $\cos \left(\frac{5\pi}{12} +\alpha\right) = \frac{1}{3}$ ，且 $-\pi <  \alpha <  - \frac{\pi}{2}$ ，则 $\cos \left(\frac{\pi}{12} -\alpha\right) =$ （）

A. $\frac{2\sqrt{2}}{3}$

B. $\frac{1}{3}$

C. $-\frac{1}{3}$

D. $-\frac{2\sqrt{2}}{3}$

4. D

解析：设 $t = \frac{5\pi}{12} +\alpha$ ，则 $\alpha = t - \frac{5\pi}{12}$ ，且 $\cos t = \frac{1}{3}$

所以 $\cos \left(\frac{\pi}{12} -\alpha\right) = \cos \left[\frac{\pi}{12} -\left(t - \frac{5\pi}{12}\right)\right] = \cos \left(\frac{\pi}{2} -t\right) = \sin t$

已知 $\cos t$ 求 $\sin t$ ，得研究 $t$ 的范围，才能确定正负，

因为 $-\pi < \alpha < -\frac{\pi}{2}$ ，所以 $-\frac{7\pi}{12} < t < -\frac{\pi}{12}$ ，故 $\sin t < 0$ ，

所以 $\sin t = -\sqrt{1 - \cos^2 t} = -\frac{2\sqrt{2}}{3}$ ，故 $\cos \left(\frac{\pi}{12} - \alpha\right) = -\frac{2\sqrt{2}}{3}$ .

5. (2022·山西二模·★★★)

若 $\sin 10^{\circ} = a\sin 100^{\circ}$ ，则 $\sin 20^{\circ} =$ （

A. $\frac{a}{a^2 + 1}$

B. $-\frac{a}{a^2 + 1}$

C. $\frac{2a}{a^2 + 1}$

D. $-\frac{2a}{a^2 + 1}$

5. C

解析：注意到求值的角 $20^{\circ} = 2 \times 10^{\circ}$ ，所以将已知等式中的 $100^{\circ}$ 转换成 $10^{\circ}$ ，

由题意， $\sin 10^{\circ} = a\sin 100^{\circ} = a\sin (90^{\circ} + 10^{\circ}) = a\cos 10^{\circ}$

所以 $\tan 10^{\circ} = a$ ，故 $\sin 20^{\circ} = 2\sin 10^{\circ}\cos 10^{\circ}$

$$
= \frac {2 \sin 1 0 ^ {\circ} \cos 1 0 ^ {\circ}}{\sin^ {2} 1 0 ^ {\circ} + \cos^ {2} 1 0 ^ {\circ}} = \frac {2 \tan 1 0 ^ {\circ}}{\tan^ {2} 1 0 ^ {\circ} + 1} = \frac {2 a}{a ^ {2} + 1}.
$$

因为 $\sin1^{\circ}=\sin(90^{\circ}-89^{\circ})=\cos89^{\circ}$

$$
\sin 2 ^ {\circ} = \sin (9 0 ^ {\circ} - 8 8 ^ {\circ}) = \cos 8 8 ^ {\circ}, \dots ,
$$

$\sin 89^{\circ} = \sin (90^{\circ} - 1^{\circ}) = \cos 1^{\circ}$ ，代入式①得：

$$
\begin{array}{l} S = \cos^ {2} 8 9 ^ {\circ} + \cos^ {2} 8 8 ^ {\circ} + \cos^ {2} 8 7 ^ {\circ} + \dots + \cos^ {2} 1 ^ {\circ} \\ = \cos^ {2} 1 ^ {\circ} + \cos^ {2} 2 ^ {\circ} + \cos^ {2} 3 ^ {\circ} + \dots + \cos^ {2} 8 9 ^ {\circ} \quad ②, \\ \end{array}

(2) 分子为同底数对数相加, 可以合并, 故先合并,
