# 模块二 基本不等式

# 第1节 基本不等式的常见用法与拼凑技巧（★★☆）

# 内容提要

设 $a > 0, b > 0$ ，则 $\frac{a + b}{2} \geq \sqrt{ab}$ ，当且仅当 $a = b$ 时取等号。这一不等式叫做基本（均值）不等式，常用于求一些代数式的最大、最小值，其运用口诀可简记为“一正、二定、三相等”。

##### 1. 一正: $a, b$ 均为正数;

##### 2. 二定：用基本不等式求最值时应满足和为定值或积为定值。但需注意，若和或积不为定值，基本不等式仍然是成立的，只是求不出最值；

##### 3. 三相等：必须验证等号能取到，上述定值才是最值.

另外，基本不等式还可以推广到 $n$ 元的形式：

设 $x_{1}, x_{2}, \cdots, x_{n}$ 均为正数，则 $\frac{x_{1} + x_{2} + \cdots + x_{n}}{n} \geq \sqrt[n]{x_{1}x_{2}\cdots x_{n}}$ ，当且仅当 $x_{1} = x_{2} = \cdots = x_{n}$ 时取等号.

##### 例如，当 $n = 3$ 时，可得到三个正数 $x_{1}, x_{2}, x_{3}$ 满足 $\frac{x_{1} + x_{2} + x_{3}}{3} \geq \sqrt[3]{x_{1}x_{2}x_{3}}$ ，取等条件是 $x_{1} = x_{2} = x_{3}$ .

用 $n$ 元基本不等式求最值的原理, 与二元基本不等式类似, 此处不再赘述. 运用基本不等式求最值的难点在于 “凑定值”, 本节将归纳几类常见的凑 “和定”、“积定” 的方法.

# 类型Ⅰ：和定求积的最大值的基本方法

【例 1】已知 a > 0，b > 0，且 $2a + b = 1$ ，则 ab 的最大值为 \_\_\_\_.

<span class="fake-tag">解析</span> $a$ ， $b$ 均为正数，且已知 $2a$ 与 $b$ 的和为定值，故可直接用均值不等式求 $ab$ 的最大值，

由题意， $1 = 2a + b\geq 2\sqrt{2a\cdot b}$ ，所以 $ab\leq \frac{1}{8}$ ，当且仅当 $2a = b$ 时取等号，

结合 $2a + b = 1$ 可得此时 $a = \frac{1}{4}$ ， $b = \frac{1}{2}$ ，所以 $ab$ 的最大值为 $\frac{1}{8}$

<span class="fake-tag">答案</span> $\frac{1}{8}$

##### 【变式】已知 $a > 0$ ， $b > 0$ ，且 $4a + b = 1$ ，则 $\log_{\frac{1}{2}}a + \log_{\frac{1}{2}}b$ 的最小值为

<span class="fake-tag">解析</span>由对数运算性质， $\log_{\frac{1}{2}}a + \log_{\frac{1}{2}}b = \log_{\frac{1}{2}}(ab)$ ①，

注意到 $y = \log_{\frac{1}{2}} x$ 为减函数，故只需求 $ab$ 的最大值，条件中有和为定值，可用均值不等式求积的最大值，

由题意， $1 = 4a + b\geq 2\sqrt{4a\cdot b} = 4\sqrt{ab}$ ，所以 $ab\leq \frac{1}{16}$ ，当且仅当 $4a = b$ 时取等号，

结合 $4a + b = 1$ 可得此时 $a = \frac{1}{8}$ ， $b = \frac{1}{2}$ ，所以 $(ab)_{\max} = \frac{1}{16}$ ，结合①知 $\left(\log_{\frac{1}{2}} a + \log_{\frac{1}{2}} b\right)_{\min} = \log_{\frac{1}{2}} \frac{1}{16} = 4$ 。

<span class="fake-tag">答案</span>4

【例 2】（1）若 -6 < m < 3，则 $(3 - m)(m + 6)$ 的最大值是 \_\_\_\_；

（2） 若 $-3 < m < 3$ , 则 $(3 - m)(2m + 6)$ 的最大值是 \_\_\_\_.

<span class="fake-tag">解析</span>（1）3-m 与 $m+6$ 的和为定值，发现这一隐藏特征，就可用不等式 $ab \leq \left(\frac{a+b}{2}\right)^{2}$ 来求积的最大值， $(3-m)(m+6) \leq \left[\frac{(3-m)+(m+6)}{2}\right]^{2} = \frac{81}{4}$ ，当且仅当 $3-m=m+6$ ，即 $m=-\frac{3}{2}$ 时取等号，
所以 $(3-m)(m+6)$ 的最大值是 $\frac{81}{4}$ .

（2） $3 - m$ 与 $2m + 6$ 的和不再是定值了, 但观察发现可通过将 $2m + 6$ 提 2 来调整系数, 凑成和为定值, $(3 - m)(2m + 6) = 2(3 - m)(m + 3) \leq 2\left[\frac{(3 - m) + (m + 3)}{2}\right]^2 = 18$ , 当且仅当 $3 - m = m + 3$ , 即 $m = 0$ 时取等号, 所以 $(3 - m)(2m + 6)$ 的最大值是 18.

<span class="fake-tag">答案</span>（1） $\frac{81}{4}$ ；（2）18

【反思】若条件有和为定值（有时是隐藏的），则可考虑用不等式 $ab \leq \left(\frac{a + b}{2}\right)^2$ 来求积的最大值；若没有和为定值，则可尝试凑成和为定值，再用上述不等式求积的最大值.

##### 【变式】已知函数 $f(h)=\frac{2}{3}h^{2}(6-h)$ ， $h\in\left[\frac{3}{2},\frac{9}{2}\right]$ ，则 $f(h)$ 的最大值是 \_\_\_\_.

<span class="fake-tag">解析</span> $h^2 (6 - h)$ 可看成 $h\cdot h\cdot (6 - h)$ ，三项和不为定值，但可通过将 $6 - h$ 乘系数2，凑成和为定值，

$f(h) = \frac{1}{3} h\cdot h\cdot (12 - 2h)\leq \frac{1}{3}\cdot \left[\frac{h + h + (12 - 2h)}{3}\right]^3 = \frac{64}{3}$ ，取等条件是 $h = 12 - 2h$ ，即 $h = 4$ ，所以 $f(h)_{\mathrm{max}} = \frac{64}{3}$

<span class="fake-tag">答案</span>: $\frac{64}{3}$

【反思】①本题若改为求 $h \sqrt{6 - h}$ 的最大值，又怎么做？可将其化为 $\sqrt{h^2(6 - h)}$ ，再变成 $\sqrt{\frac{1}{2} h \cdot h \cdot (12 - 2h)}$ ，就可对 $h \cdot h \cdot (12 - 2h)$ 这部分用 $abc \leq \left(\frac{a + b + c}{3}\right)^3$ 来求最大值了；②从例2及其变式可以看出，对于和不为定值的两项（或三项）之积，在其中一项上乘个系数使它们的和为定值是常用的凑“和定”的方法.

##### 【例3】（多选）已知 $10^{a} = 2$ ， $10^{b} = 5$ ，则下列选项中正确的有（）

$\quad$A. $ab > \frac{1}{4}$

$\quad$B. $ab < \frac{1}{4}$

$\quad$C. $a^2 + b^2 < \frac{1}{2}$

$\quad$D. $a^2 + b^2 > \frac{1}{2}$

<span class="fake-tag">解析</span>要判断的不等式均与 $a, b$ 有关，故应分析它们的关系，可由已知条件解出 $a$ 和 $b$ 来看，

$10^{a} = 2 \Rightarrow a = \lg 2$ ， $10^{b} = 5 \Rightarrow b = \lg 5$ ，所以 $a + b = \lg 2 + \lg 5 = \lg (2 \times 5) = 1$

我们发现题目隐藏了和为定值, 要判断 A、B 两个选项, 直接用基本不等式即可,

因为 a > 0，b > 0，且 $a \neq b$ ，所以 $1 = a + b > 2\sqrt{ab}$ ，从而 $ab < \frac{1}{4}$ ，故 A 项错误，B 项正确；

选项 C、D 都与 $a^{2} + b^{2}$ 有关，前面已经得到了 $a + b = 1$ ，所以配方来看，

$a^2 + b^2 = (a + b)^2 - 2ab = 1 - 2ab$ ，由 $ab < \frac{1}{4}$ 可得 $1 - 2ab > 1 - 2 \times \frac{1}{4} = \frac{1}{2}$ ，所以 $a^2 + b^2 > \frac{1}{2}$ ，

故 C 项错误，D 项正确.

<span class="fake-tag">答案</span>: BD

【反思】这题和为定值隐藏得更深，需要变形才能发现。此外， $a^2 + b^2$ ， $a + b$ ， $ab$ 这三者之间可以通过配方结合基本不等式来相互转换，在本章这是常用的变形手段。

# 类型Ⅱ：积定求和的最小值的基本方法

【例 4】（1）已知 a > 1，则 $a + \frac{1}{a - 1}$ 的最小值是 \_\_\_\_；

（2）已知 $a > 1$ ，则 $2a + \frac{1}{a - 1}$ 的最小值是  
（3）已知 $a > 1$ ，则 $2a + \frac{4a}{a - 1}$ 的最小值是

<span class="fake-tag">解析</span>（1）积不是定值，要求和的最小值，应想办法凑“积定”，分母是 $a - 1$ ，故在前面的 $a$ 上也减1，

因为 $a > 1$ ，所以 $a - 1 > 0$ ，故 $a + \frac{1}{a - 1} = (a - 1) + \frac{1}{a - 1} + 1 \geq 2\sqrt{(a - 1) \cdot \frac{1}{a - 1}} + 1 = 3$

当且仅当 $a - 1 = \frac{1}{a - 1}$ 时取等号，结合 $a > 1$ 可得此时 $a = 2$ ，所以 $a + \frac{1}{a - 1}$ 的最小值为3.

（2） 要求和的最小值, 应先凑 “积定”, 分母是 $a - 1$ , 故把外面的 $a$ 也变成 $a - 1$ ,

因为 $a > 1$ ，所以 $a - 1 > 0$ ，故 $2a + \frac{1}{a - 1} = 2(a - 1) + \frac{1}{a - 1} + 2 \geq 2\sqrt{2(a - 1) \cdot \frac{1}{a - 1}} + 2 = 2\sqrt{2} + 2$

当且仅当 $2(a - 1) = \frac{1}{a - 1}$ 时取等号，结合 $a > 1$ 可得此时 $a = 1 + \frac{\sqrt{2}}{2}$ ，所以 $2a + \frac{1}{a - 1}$ 的最小值是 $2\sqrt{2} + 2$ 。

（3） 分子不再是常数，但观察发现可通过拆部分分式，将其化为常数，按前面两道题的方法处理，

由题意， $2a + \frac{4a}{a - 1} = 2a + \frac{4(a - 1) + 4}{a - 1} = 2a + 4 + \frac{4}{a - 1} = 2(a - 1) + \frac{4}{a - 1} +6\geq 2\sqrt{2(a - 1)\cdot\frac{4}{a - 1}} +6 = 4\sqrt{2} +6,$

当且仅当 $2(a - 1) = \frac{4}{a - 1}$ 时等号成立，结合 $a > 1$ 可得此时 $a = \sqrt{2} + 1$ ，所以 $2a + \frac{4a}{a - 1}$ 的最小值是 $4\sqrt{2} + 6$ .

<span class="fake-tag">答案</span>（1）3；（2） $2\sqrt{2}+2$ ；（3） $4\sqrt{2}+6$

【反思】在求两项之和的最小值时，若这两项之积不是定值，则可以考虑通过变形凑成积为定值，用不等式 $a + b \geq 2\sqrt{ab}$ 来求和的最小值.

##### 【变式1】已知 $2a - b = 2$ ，则 $9^{a} + \frac{1}{3^{b}}$ 的最小值是

<span class="fake-tag">解析</span>要求和的最小值，应寻找积为定值，先看看有无现成的“积定”， $9^{a} \cdot \frac{1}{3^{b}} = 3^{2a} \cdot 3^{-b} = 3^{2a - b} = 3^{2}$ ，有“积定”，故直接用均值不等式求和的最小值即可，

因为 $2a - b = 2$ ，所以 $9^{a} + \frac{1}{3^{b}}\geq 2\sqrt{9^{a}\cdot\frac{1}{3^{b}}} = 2\sqrt{3^{2a - b}} = 2\sqrt{3^2} = 6$ ，当且仅当 $9^{a} = \frac{1}{3^{b}}$ 时等号成立，

即 $3^{2a} = 3^{-b}$ ，也即 $2a = -b$ ，结合 $2a - b = 2$ 可得此时 $a = \frac{1}{2}$ ， $b = -1$ ，所以 $9^{a} + \frac{1}{3^{b}}$ 的最小值是6.

<span class="fake-tag">答案</span>: 6

##### 【变式2】已知 $4x^{4} + 9x^{2}y^{2} + 2y^{4} = 4$ ，则 $5x^{2} + 3y^{2}$ 的最小值为

<span class="fake-tag">解析</span>条件与所求看着似乎不好联系，咋办？一般这时候条件会有“猫腻”，观察发现条件可分解因式， $4x^{4} + 9x^{2}y^{2} + 2y^{4} = (4x^{2} + y^{2})(x^{2} + 2y^{2}) = 4$ ，可发现 $(4x^{2} + y^{2}) + (x^{2} + 2y^{2})$ 即为目标式，想到基本不等式， $5x^{2} + 3y^{2} = (4x^{2} + y^{2}) + (x^{2} + 2y^{2}) \geq 2\sqrt{(4x^{2} + y^{2})(x^{2} + 2y^{2})} = 4$ ，取等条件是 $4x^{2} + y^{2} = x^{2} + 2y^{2}$ ，结合 $4x^{4} + 9x^{2}y^{2} + 2y^{4} = 4$ 可得此时 $x^{2} = \frac{2}{7}$ ， $y^{2} = \frac{6}{7}$ ，满足题意，所以 $5x^{2} + 3y^{2}$ 的最小值为 4.

<span class="fake-tag">答案</span>: 4

【反思】有的题目积定隐藏在条件中，需要变形才能发现，上面的变式1、2就是如此.

【例 5】已知 a, b 都是正数，则 $\frac{5a}{2a+3b}+\frac{5b}{3a+2b}$ 的最小值是 \_\_\_\_.

<span class="fake-tag">解析</span>分母结构较复杂，不易看出如何变形求最值，这时可考虑将分母换元再看，

设 $\left\{ \begin{array}{l} x = 2a + 3b \\ y = 3a + 2b \end{array} \right.$ ，因为 $a, b$ 都是正数，所以 $x, y$ 也都是正数，且 $a = \frac{3y - 2x}{5}$ ， $b = \frac{3x - 2y}{5}$ ，

所以 $\frac{5a}{2a + 3b} +\frac{5b}{3a + 2b} = \frac{3y - 2x}{x} +\frac{3x - 2y}{y} = \frac{3y}{x} -2 + \frac{3x}{y} -2 = \frac{3y}{x} +\frac{3x}{y} -4\geq 2\sqrt{\frac{3y}{x}\cdot\frac{3x}{y}} -4 = 2$

取等条件是 $\frac{3y}{x} = \frac{3x}{y}$ ，化简得： $y = x$ ，结合 $\left\{ \begin{array}{l} x = 2a + 3b \\ y = 3a + 2b \end{array} \right.$ 可得 $a = b$ ，故 $\frac{5a}{2a + 3b} + \frac{5b}{3a + 2b}$ 的最小值是 2.

<span class="fake-tag">答案</span>: 2

【反思】当分母较复杂时，可尝试换元法，换元后往往更易观察出形式，换元法在基本不等式中非常重要.

##### 【变式】 $\frac{x^{2}+17}{4\sqrt{x^{2}+1}}$ 的最小值是\_\_\_\_.

<span class="fake-tag">解析</span>分母的根号部分较复杂，不易观察，故尝试将分母换元再看能否凑出积为定值，

令 $t = \sqrt{x^2 + 1} \geq 1$ ，则 $x^2 = t^2 - 1$ ，所以 $\frac{x^2 + 17}{4\sqrt{x^2 + 1}} = \frac{(t^2 - 1) + 17}{4t} = \frac{t^2 + 16}{4t} = \frac{1}{4}\left(t + \frac{16}{t}\right) \geq \frac{1}{4} \times 2\sqrt{t \cdot \frac{16}{t}} = 2$ ，

当且仅当 $t = \frac{16}{t}$ ，即 $t = 4$ 时等号成立，结合 $t = \sqrt{x^2 + 1}$ 可得 $x = \pm \sqrt{15}$ ，故 $\frac{x^2 + 17}{4\sqrt{x^2 + 1}}$ 的最小值是2.

<span class="fake-tag">答案</span>: 2

【总结】从上面几道题可以看出，用均值不等式求为正数的两项之和的最小值，找到或凑出积为定值是关键，常见的配凑方法有添项、拆项、换元等.

类型III：“1”的代换

【例 6】已知 $a + 6b = 2 (a > 0, b > 0)$ ，则 $\frac{4}{a} + \frac{6}{b}$ 的最小值为 \_\_\_\_.

<span class="fake-tag">解析</span>要求和的最小值，考虑凑出积为定值，这里涉及一个常用技巧，可把 $\frac{4}{a} + \frac{6}{b}$ 看成 $\left(\frac{4}{a} + \frac{6}{b}\right) \cdot 1$ ，其中 $1 = 2 \times \frac{1}{2}$ ，结合已知的等式，2 又可代换成 $a + 6b$ ，这样展开就有“积定”了，

因为 $a + 6b = 2(a > 0, b > 0)$ ，所以 $\frac{4}{a} + \frac{6}{b} = \left(\frac{4}{a} + \frac{6}{b}\right) \cdot 1 = \left(\frac{4}{a} + \frac{6}{b}\right) \cdot 2 \times \frac{1}{2} = \left(\frac{4}{a} + \frac{6}{b}\right)(a + 6b) \times \frac{1}{2}$

$= \left(\frac {2}{a} + \frac {3}{b}\right) (a + 6 b) = 2 + \frac {1 2 b}{a} + \frac {3 a}{b} + 1 8 = \frac {1 2 b}{a} + \frac {3 a}{b} + 2 0 \geq 2 \sqrt {\frac {1 2 b}{a} \cdot \frac {3 a}{b}} + 2 0 = 3 2,$

取等条件是 $\frac{12b}{a} = \frac{3a}{b}$ ，结合 $a + 6b = 2 (a > 0, b > 0)$ 可得 $a = \frac{1}{2}$ ， $b = \frac{1}{4}$ ，故 $\frac{4}{a} + \frac{6}{b}$ 的最小值为 32.

<span class="fake-tag">答案</span>: 32

【反思】“已知 $()a+()b=()$ ，让求 $\frac{()}{a}+\frac{()}{b}$ 的最小值（括号内可为任意正常数）”这类题，都可像本题这样通过“1”的代换，凑成积为定值。这是一个基本模型，很多更复杂的题，可通过换元转化成这种模型。

##### 【变式1】已知 $x, y$ 为正实数，且 $x + 2y = xy$ ，则 $x + 2y$ 的最小值是

<span class="fake-tag">解析</span>观察发现只要在 $x + 2y = xy$ 的两端同除以 $xy$ ，就和上一题类似了，

因为 $x + 2y = xy$ ，所以 $\frac{1}{y} +\frac{2}{x} = 1$ ，要求和的最小值，可用“1”的代换凑积为定值，

$x + 2 y = (x + 2 y) \cdot 1 = (x + 2 y) \left(\frac {1}{y} + \frac {2}{x}\right) = \frac {x}{y} + 2 + 2 + \frac {4 y}{x} = \frac {x}{y} + \frac {4 y}{x} + 4 \geq 2 \sqrt {\frac {x}{y} \cdot \frac {4 y}{x}} + 4 = 8,$

当且仅当 $\frac{x}{y} = \frac{4y}{x}$ 时取等号，结合 $\frac{1}{y} +\frac{2}{x} = 1$ 可得此时 $x = 4$ ， $y = 2$ ，所以 $x + 2y$ 的最小值是8.

<span class="fake-tag">答案</span>: 8

##### 【变式2】已知 $x, y$ 为正实数，且 $x + y = 1$ ，则 $\frac{1}{2x + y} + \frac{4}{y + 2}$ 的最小值为

<span class="fake-tag">解析</span>: $\frac{1}{2 x + y} + \frac{4}{y + 2}$ 与上面例 6 中的 $\frac{4}{a} + \frac{6}{b}$ 结构挺像, 故尝试通过换元化为例 6 的模型来处理,

令 $\left\{\begin{aligned}2x+y&=a\\ y+2&=b\end{aligned}\right.$ ，则由题意， $a+b=2(x+y)+2=4$ ，

于是问题即为在 $a + b = 4$ 的条件下，求 $\frac{1}{a} + \frac{4}{b}$ 的最小值，这是与例6相同的模型，用“1”的代换即可，

所以 $\frac{1}{2x + y} +\frac{4}{y + 2} = \frac{1}{a} +\frac{4}{b} = \left(\frac{1}{a} +\frac{4}{b}\right)\cdot 1 = \left(\frac{1}{a} +\frac{4}{b}\right)\cdot 4\times \frac{1}{4} = \left(\frac{1}{a} +\frac{4}{b}\right)(a + b)\times \frac{1}{4} = \frac{1}{4}\left(1 + \frac{b}{a} +\frac{4a}{b} +4\right) = \frac{1}{4}\left(\frac{b}{a} +\frac{4a}{b} +5\right)$

$\geq \frac{1}{4}\left(2\sqrt{\frac{b}{a} \cdot \frac{4a}{b}} + 5\right) = \frac{9}{4}$ ，当且仅当 $\frac{b}{a} = \frac{4a}{b}$ 时取等号，此时 $b = 2a$ ，结合 $a + b = 4$ 可得 $a = \frac{4}{3}$ ， $b = \frac{8}{3}$ ，

代入 $\left\{ \begin{array}{l} 2x + y = a \\ y + 2 = b \end{array} \right.$ 可得 $x = \frac{1}{3}$ , $y = \frac{2}{3}$ , 满足题意, 所以 $\frac{1}{2x + y} + \frac{4}{y + 2}$ 的最小值为 $\frac{9}{4}$ .

<span class="fake-tag">答案</span>: $\frac{9}{4}$

【反思】遇到分母较复杂、分子为常数的两个分式相加，让求其最小值这类题，可考虑将分母整体换元，看能否转化为例6的模型来处理.

【例 7】若 0 < a < 1，则 $\frac{2}{a^{2}} + \frac{1}{1 - a^{2}}$ 的最小值为 \_\_\_\_.

<span class="fake-tag">解析</span>观察发现分母之和为1，相当于隐藏了分母的“和定”，故换元后仍可化为例6的模型来处理，设 $\left\{ \begin{array}{l} x = a^2 \\ y = 1 - a^2 \end{array} \right.$ ，因为 $0 < a < 1$ ，所以 $0 < x < 1$ ， $0 < y < 1$ ，且 $x + y = 1$ ，

所以 $\frac{2}{a^2} +\frac{1}{1 - a^2} = \frac{2}{x} +\frac{1}{y} = \left(\frac{2}{x} +\frac{1}{y}\right)\cdot 1 = \left(\frac{2}{x} +\frac{1}{y}\right)(x + y) = 2 + \frac{2y}{x} +\frac{x}{y} +1 = \frac{2y}{x} +\frac{x}{y} +3\geq 2\sqrt{\frac{2y}{x}\cdot\frac{x}{y}} +3 = 2\sqrt{2} +3$

##### 【变式】若 $\frac{1}{4} < a < 1$ ，则 $\frac{1}{1 - a} + \frac{16a}{4a - 1}$ 的最小值为 \_\_\_\_.

<span class="fake-tag">解析</span>相比上一题， $\frac{16a}{4a-1}$ 的分子不是常数，但可通过拆项，将其化为常数，故先拆项，再观察形式，
