##### 1. (★★)

已知 $a > 0$ ，则 $(a^2 +3a + 1)\left(\frac{1}{a^2} +\frac{3}{a} +1\right)$ 的最小值为

##### 1. 25

<span class="fake-tag">解析</span>所给式子具有柯西不等式的结构特征，稍作变形即可用柯西不等式求出最小值，

由柯西不等式， $(a^{2} + 3a + 1)\left(\frac{1}{a^{2}} +\frac{3}{a} +1\right) =$

$[ a ^ {2} + (\sqrt {3 a}) ^ {2} + 1 ^ {2} ] \left[ \left(\frac {1}{a}\right) ^ {2} + \left(\sqrt {\frac {3}{a}}\right) ^ {2} + 1 ^ {2} \right]$

$\geq \left(a \cdot \frac {1}{a} + \sqrt {3 a} \cdot \sqrt {\frac {3}{a}} + 1 \times 1\right) ^ {2} = 2 5,$

取等条件是 $\frac{a}{\frac{1}{a}} = \frac{\sqrt{3a}}{\sqrt{\frac{3}{a}}} = \frac{1}{1}$ ，此时 $a = 1$ ，

所以 $(a^2 + 3a + 1)\left(\frac{1}{a^2} + \frac{3}{a} + 1\right)$ 的最小值为25.

##### 2. $\frac{2}{5}$

<span class="fake-tag">解析</span>求最值的目标涉及三项平方和，可考虑用三维形式的柯西不等式，需结合所给等式凑系数，

因为 $2x + y - \sqrt{5} z = 2$ ，所以 $x^{2} + y^{2} + z^{2} =$

$\frac {1}{1 0} [ 2 ^ {2} + 1 ^ {2} + (- \sqrt {5}) ^ {2} ] (x ^ {2} + y ^ {2} + z ^ {2}) \geq \frac {1}{1 0} (2 x + y - \sqrt {5} z) ^ {2} = \frac {2}{5},$

取等条件是 $\frac{x}{2} = \frac{y}{1} = \frac{z}{-\sqrt{5}}$ ，结合 $2x + y - \sqrt{5} z = 2$ 可得

$x = \frac{2}{5}, y = \frac{1}{5}, z = -\frac{\sqrt{5}}{5}$ ，故 $(x^{2} + y^{2} + z^{2})_{\min} = \frac{2}{5}$ .

##### 3. (★★★)

已知 x > 1，y > 1，xy = 10，则 $\frac{1}{\lg x} + \frac{4}{\lg y}$ 的最小值是 \_\_\_\_.

##### 3.9

<span class="fake-tag">解析</span>求两个分式和的最值，可考虑权方和不等式，观察所给式子可发现分母之和恰为定值，可直接用，

由权方和不等式， $\frac{1}{\lg x} +\frac{4}{\lg y} = \frac{1^2}{\lg x} +\frac{2^2}{\lg y}$

$\geq \frac{(1 + 2)^2}{\lg x + \lg y} = \frac{9}{\lg(xy)} = \frac{9}{\lg 10} = 9$ ，取等条件是 $\frac{1}{\lg x} = \frac{2}{\lg y}$

结合 $xy = 10$ 得 $x = 10^{\frac{1}{3}}$ ， $y = 10^{\frac{2}{3}}$ ，故 $\left(\frac{1}{\lg x} +\frac{4}{\lg y}\right)_{\min} = 9$

##### 4. $\frac{9}{4}$

<span class="fake-tag">解析</span>求两个分式和的最值，考虑权方和不等式，为了凑出分母和为定值，将 $\frac{2}{b + 1}$ 变成 $\frac{4}{2b + 2}$ ，

由权方和不等式， $\frac{1}{2a} +\frac{2}{b + 1} = \frac{1^2}{2a} +\frac{2^2}{2b + 2}$

$\geq \frac{(1 + 2)^2}{2a + 2b + 2} = \frac{9}{4}$ ，取等条件是 $\frac{1}{2a} = \frac{2}{2b + 2}$

结合 $a + b = 1$ 得 $a = \frac{2}{3}$ ， $b = \frac{1}{3}$ ，故 $\left(\frac{1}{2a} +\frac{2}{b + 1}\right)_{\min} = \frac{9}{4}.$

##### 5. (2023·全国乙卷·★★★)

已知实数 $x$ ， $y$ 满足 $x^{2} + y^{2} - 4x - 2y - 4 = 0$ ，则 $x - y$ 的最大值是（）

$\quad$A. $1 + \frac{3\sqrt{2}}{2}$

$\quad$B. 4

$\quad$C. $1 + 3\sqrt{2}$

$\quad$D. 7

##### 5. C

<span class="fake-tag">解析</span>所给等式可配方化为平方和结构，考虑三角换元，

$x ^ {2} + y ^ {2} - 4 x - 2 y - 4 = 0 \Rightarrow (x - 2) ^ {2} + (y - 1) ^ {2} = 9,$

令 $\left\{ \begin{array}{l} x = 2 + 3\cos \theta \\ y = 1 + 3\sin \theta \end{array} \right.$ ，则 $x - y = 2 + 3\cos \theta - 1 - 3\sin \theta$

$= 1 - 3 \sqrt {2} \sin \left(\theta - \frac {\pi}{4}\right), \quad \theta \in \mathbf {R},$

所以当 $\sin \left(\theta -\frac{\pi}{4}\right) = -1$ 时， $x - y$ 取得最大值 $1 + 3\sqrt{2}$

##### 6. (2020·清华强基试题·★★★☆)

若 $x^{2} + y^{2}\leq 1$ ，则 $x^{2} + xy - y^{2}$ 的取值范围为（）

$\quad$A. $\left[-\frac{\sqrt{3}}{2}, \frac{\sqrt{3}}{2}\right]$

$\quad$B. $[-1, 1]$

$\quad$C. $\left[-\frac{\sqrt{5}}{2}, \frac{\sqrt{5}}{2}\right]$

$\quad$D. $[-2, 2]$

##### 6. C

<span class="fake-tag">解析</span>本题给的是平方和不等式，不是等式，也可用三角换元，多引入一个变量即可，

设 $x^{2} + y^{2} = r^{2}$ ，则由 $x^{2} + y^{2}\leq 1$ 可得 $0\leq r^2\leq 1$

利用三角换元，可设 $\left\{\begin{aligned}x&=r\cos\theta\\ y&=r\sin\theta\end{aligned}\right.$

则 $x^{2} + xy - y^{2} = r^{2}\cos^{2}\theta +r^{2}\sin \theta \cos \theta -r^{2}\sin^{2}\theta$

$= r ^ {2} \left(\cos^ {2} \theta - \sin^ {2} \theta + \sin \theta \cos \theta\right) = r ^ {2} \left(\cos 2 \theta + \frac {1}{2} \sin 2 \theta\right)$

$= \frac{\sqrt{5}}{2} r^2\sin (2\theta +\varphi)$ ，因为 $-1\leq \sin (2\theta +\varphi)\leq 1$ ， $0\leq r^2\leq 1$

所以 $-\frac{\sqrt{5}}{2} \leq \frac{\sqrt{5}}{2} r^2 \sin (2\theta + \varphi) \leq \frac{\sqrt{5}}{2}$

故 $-\frac{\sqrt{5}}{2} \leq x^2 + xy - y^2 \leq \frac{\sqrt{5}}{2}$ .

# 7.（2022·新课标Ⅱ卷·★★★★）（多选）

若实数 $x$ ， $y$ 满足 $x^{2} + y^{2} - xy = 1$ ，则（）

$\quad$A. $x + y \leq 1$

$\quad$B. $x + y \geq -2$

$\quad$C. $x^{2} + y^{2}\geq 1$

$\quad$D. $x^{2} + y^{2}\leq 2$

# 7. BD

【解法1】所给等式中有 $x^{2}$ ， $y^{2}$ ， $xy$ ，可尝试将其配方，转化为平方和结构，用三角换元处理，

由 $x^{2} + y^{2} - xy = 1$ 可得 $\left(x - \frac{y}{2}\right)^2 +\left(\frac{\sqrt{3}}{2} y\right)^2 = 1$

所以可设 $\left\{ \begin{array}{l} x - \frac{y}{2} = \cos \theta \\ \frac{\sqrt{3}}{2} y = \sin \theta \end{array} \right.$ ，则 $\left\{ \begin{array}{l} x = \cos \theta + \frac{1}{\sqrt{3}} \sin \theta \\ y = \frac{2}{\sqrt{3}} \sin \theta \end{array} \right.$ ，

所以 $x + y = \sqrt{3}\sin \theta +\cos \theta = 2\sin \left(\theta +\frac{\pi}{6}\right),$

从而 $-2 \leq x + y \leq 2$ ，故A项错误，B项正确；

$x ^ {2} + y ^ {2} = \left(\cos \theta + \frac {1}{\sqrt {3}} \sin \theta\right) ^ {2} + \left(\frac {2}{\sqrt {3}} \sin \theta\right) ^ {2}$

$= \cos^ {2} \theta + \frac {1}{3} \sin^ {2} \theta + \frac {2}{\sqrt {3}} \sin \theta \cos \theta + \frac {4}{3} \sin^ {2} \theta = 1 + \frac {2}{3} \sin^ {2} \theta +$

$\frac {2}{\sqrt {3}} \sin \theta \cos \theta = 1 + \frac {1 - \cos 2 \theta}{3} + \frac {\sin 2 \theta}{\sqrt {3}} = \frac {4}{3} + \frac {2}{3} \sin \left(2 \theta - \frac {\pi}{6}\right),$

因为 $-1 \leq \sin \left(2\theta - \frac{\pi}{6}\right) \leq 1$ ，所以 $\frac{2}{3} \leq x^2 + y^2 \leq 2$

故 C 项错误，D 项正确.

【解法2】A、B两项判断的是与 $x + y$ 有关的不等式，可由已知的等式凑出这一结构，先配方，

由题意， $1 = x^{2} + y^{2} - xy = (x + y)^{2} - 3xy$

观察发现只需用 $xy \leq \left(\frac{x + y}{2}\right)^2$ 即可将结构统一成 $x + y$

所以 $1 = (x + y)^2 - 3xy \geq (x + y)^2 - 3\left(\frac{x + y}{2}\right)^2 = \frac{(x + y)^2}{4}$

从而 $-2 \leq x + y \leq 2$ ，当且仅当 $x = y$ 时取等号，

结合 $x^{2} + y^{2} - xy = 1$ 可得 $x = y = -1$ 或 $x = y = 1$

它们分别对应上述左、右两侧的取等条件，

所以 $x + y$ 的取值范围是[-2,2]，故A项错误，B项正确；

C、D 两项与 $x^{2} + y^{2}$ 有关，还是考虑统一结构，要把 xy 变成 $x^{2} + y^{2}$ ，可用 $-\frac{x^{2} + y^{2}}{2} \leq xy \leq \frac{x^{2} + y^{2}}{2}$ 来实现，

因为 $xy \leq \frac{x^2 + y^2}{2}$ ，所以 $1 = x^2 + y^2 - xy \geq x^2 + y^2 - \frac{x^2 + y^2}{2}$

$= \frac{x^2 + y^2}{2}$ ，故 $x^{2} + y^{2}\leq 2$ ，取等条件是 $x = y$

结合 $x^{2} + y^{2} - xy = 1$ 可得此时 $x = y = 1$ 或 $x = y = -1$

又 $xy \geq -\frac{x^2 + y^2}{2}$ ，所以 $1 = x^2 + y^2 - xy \leq x^2 + y^2 + \frac{x^2 + y^2}{2}$

$= \frac{3}{2} (x^{2} + y^{2})$ ，故 $x^{2} + y^{2}\geq \frac{2}{3}$ ，取等条件是 $y = -x$

结合 $x^{2} + y^{2} - xy = 1$ 可得此时 $\left\{ \begin{array}{l} x = \frac{\sqrt{3}}{3} \\ y = -\frac{\sqrt{3}}{3} \end{array} \right.$ 或 $\left\{ \begin{array}{l} x = -\frac{\sqrt{3}}{3} \\ y = \frac{\sqrt{3}}{3} \end{array} \right.$ ;

所以 $x^{2} + y^{2}$ 的取值范围是 $\left[\frac{2}{3}, 2\right]$ ，故C项错误，D项正确.

【反思】①这是当年的选择压轴题，通过此题我们发现若给出 $x, y$ 的二次齐次等式，可考虑通过配方化为平方和结构，再三角换元；②上述解法2用到了统一结构的思想，也是常规方法，其中用到的不等式 $-\frac{x^2 + y^2}{2} \leq xy \leq \frac{x^2 + y^2}{2}$ 源于 $\frac{a + b}{2} \geq \sqrt{ab}$ ，将 $a$ 换成 $x^2, b$ 换成 $y^2$ 可得 $\frac{x^2 + y^2}{2} \geq$

$\sqrt{x^{2}y^{2}}=|xy|$ ，去掉绝对值即得该不等式.
