# 专题16 数列的奇偶项讨论问题

# 【基本知识】

数列中的奇、偶项问题的常见题型

(1)数列中连续两项和或积的问题 $(a_{n}+a_{n+1}=f(n)$ 或 $a_{n}\cdot a_{n+1}=f(n))$ ;  
(2)通项公式分奇、偶项有不同表达式;  
(3)含有 $(-1)^{n}$ 的类型;  
(4)已知条件明确的奇偶项或含有三角函数问题.

考点一 $a_{n} + a_{n + 1} = f(n)$ 或 $a_{n}\cdot a_{n + 1} = f(n)$ 类型
