# 专题17 数列不等式的证明

数列不等式的证明常用到 “放缩法”，一是在求和中将通项 “放缩” 为 “可求和数列”；二是求和后再 “放缩”。

# 常见的放缩类型及方法  
（1）分式型：① $\frac{1}{k^{2}}<\frac{1}{k^{2}-1}=\frac{1}{2}\left(\frac{1}{k-1}-\frac{1}{k+1}\right)$ ; ② $\frac{1}{k}-\frac{1}{k+1}<\frac{1}{k^{2}}<\frac{1}{k-1}-\frac{1}{k}$ ;  
（2）根式型：① $2(\sqrt{n+1}-\sqrt{n})<\frac{1}{\sqrt{n}}<2(\sqrt{n}-\sqrt{n-1});$

② $\frac{1}{\sqrt{k + k + 1}} < \frac{1}{\sqrt{2k}} < \frac{1}{\sqrt{k + k - 1}};$

③ $\frac{1}{\sqrt{k}}>\frac{2}{\sqrt{k+1}+\sqrt{k}}=2(\sqrt{k+1}-\sqrt{k})$ .  
（3）分数型： $\frac{b}{a}>\frac{b+m}{a+m}(b>a>0,\ m>0),\ \frac{b}{a}<\frac{b+m}{a+m}(a>b>0,\ m>0);$  
（4）基本不等式型： $\frac{n}{n + 2} +\frac{n + 2}{n} >2\sqrt{\frac{n}{n + 2}\cdot\frac{n + 2}{n}} = 2;$  
（5）二项式定理型： $2^{n}-1\geq2n+1(n\geq3)$ .

注：在放缩法处理数列求和不等式时，放缩为等比数列和能够裂项相消的数列的情况比较多见，故优先考虑。对于数列求和不等式，要谨记“求和看通项”，从通项公式入手，结合不等号方向考虑放缩成可求和的通项公式。在放缩时要注意前几问的铺垫与提示，尤其是关于恒成立问题与最值问题所带来的恒成立不等式，往往提供了放缩数列的方向。放缩通项公式有可能会进行多次，要注意放缩的方向，朝着可求和的通项公式进行靠拢（等比数列，裂项相消等）。

# 考点一 先求和(裂项相消法)再放缩

[例 1] 设等差数列 $\{a_{n}\}$ 的前 n 项和为 $S_{n}$ ，已知 $a_{1}=9$ ， $a_{2}$ 为整数，且 $S_{n}\leq S_{5}$ .  
（1）求 $\{a_{n}\}$ 的通项公式;  
（2）设数列 $\left\{\frac{1}{a_{n}a_{n+1}}\right\}$ 的前n项和为 $T_{n}$ ，求证： $T_{n}\leq\frac{4}{9}$ .
解析 （1）由 $a_1 = 9$ ， $a_2$ 为整数可知，等差数列 $\{a_n\}$ 的公差 $d$ 为整数．又 $S_{n} \leq S_{5}$ ， $\therefore a_{5} \geq 0$ ， $a_{6} \leq 0$
于是 $9+4d\geq0,\quad9+5d\leq0$ ，解得 $-\frac{9}{4}\leq d\leq-\frac{9}{5}$ . ∵ d 为整数，∴ d=-2.
故 $\{a_{n}\}$ 的通项公式为 $a_{n}=11-2n$ .  
（2）由（1），得 $\frac{1}{a_na_{n + 1}} = \frac{1}{(11 - 2n)(9 - 2n)} = \frac{1}{2}\left[\frac{1}{9 - 2n} -\frac{1}{11 - 2n}\right],$
$\therefore T _ {n} = \frac {1}{2} \left(\frac {1}{7} - \frac {1}{9}\right) + \left(\frac {1}{5} - \frac {1}{7}\right) + \dots + \left(\frac {1}{9 - 2 n} - \frac {1}{1 1 - 2 n}\right) = \frac {1}{2} \left(\frac {1}{9 - 2 n} - \frac {1}{9}\right).$
令 $b_{n}=\frac{1}{9-2n}$ ，由函数 $f(x)=\frac{1}{9-2x}$ 的图象关于点(4.5,0)对称及其单调性，

知 $0 < b_{1} < b_{2} < b_{3} < b_{4}, b_{5} < b_{6} < b_{7} < \ldots < 0, \therefore b_{n} \leq b_{4} = 1. \therefore T_{n} \leq \frac{1}{2} \times \left(1 - \frac{1}{9}\right) = \frac{4}{9}.$

[例2] 在等比数列 $\{a_{n}\}$ 中，首项 $a_1 = 8$ ，数列 $\{b_n\}$ 满足 $b_{n} = \log_{2}a_{n}(n\in \mathbf{N}^{*})$ ，且 $b_{1} + b_{2} + b_{3} = 15$

解析 （1）由 $b_{n}=\log_{2}a_{n}$ 和 $b_{1}+b_{2}+b_{3}=15$ ，得 $\log_{2}(a_{1}a_{2}a_{3})=15$ ，∴ $a_{1}a_{2}a_{3}=2^{15}$
设等比数列 $\{a_{n}\}$ 的公比为q，∵ $a_{1}=8,\therefore a_{n}=8q^{n-1},\therefore8\cdot8q\cdot8q^{2}=2^{15}$ ，解得q=4，
$\therefore a_{n} = 8 \cdot 4^{n - 1}$ , 即 $a_{n} = 2^{2n + 1}(n \in \mathbf{N}^{*})$ .  
（2）由（1）得 $b_{n}=2n+1$ ，易知 $\{b_{n}\}$ 为等差数列，
$S _ {n} = 3 + 5 + \dots + (2 n + 1) = n ^ {2} + 2 n, \text {则} \frac {1}{S _ {n}} = \frac {1}{n (n + 2)} = \frac {1}{2} \left(\frac {1}{n} - \frac {1}{n + 2}\right),$

整理得 $2a_{n + 1} = a_{n + 1}^2 -a_n^2 +1$ ，所以 $a_{n}^{2} = (a_{n + 1} - 1)^{2}$ .所以 $a_{n} = a_{n + 1} - 1$ ，即 $a_{n + 1} - a_n = 1$
所以 $\{a_{n}\}$ 是以 1 为首项，1 为公差的等差数列．所以 $a_{n}=n$ .  
（2） $b_{n}=\frac{a_{n+2}}{2^{n+1}\cdot a_{n}\cdot a_{n+1}}=\frac{n+2}{2^{n+1}\cdot n\cdot(n+1)}=\frac{1}{2^{n}\cdot n}-\frac{1}{2^{n+1}\cdot(n+1)},$
所以 $T_{n}=\left(\frac{1}{2^{1}\cdot1}-\frac{1}{2^{2}\cdot2}\right)+\left(\frac{1}{2^{2}\cdot2}-\frac{1}{2^{3}\cdot3}\right)+\cdots+\left[\frac{1}{2^{n}\cdot n}-\frac{1}{2^{n+1}\cdot(n+1)}\right]=\frac{1}{2^{1}\cdot1}-\frac{1}{2^{n+1}\cdot(n+1)}<\frac{1}{2}.$

（2）若数列 $\{b_n\}$ 满足 $b_{n} = \frac{1}{\sqrt{S_{n} \cdot S_{n + 1}}}$ ，记数列 $\{b_{n}\}$ 的前 $n$ 项和为 $T_{n}$ ，证明： $T_{n} < 1$ 。

7. 已知数列 $\{a_{n}\}$ 满足 $a_1 = 1$ ， $S_{n} = 2a_{n + 1}$ ，其中 $S_{n}$ 为 $\{a_{n}\}$ 的前 $n$ 项和 $(n \in \mathbf{N}^{*})$ .

8. 数列 $\{a_{n}\}$ 中，前 $n$ 项和为 $S_{n}$ ， $S_{n} = \frac{na_{n}}{2} (a_{2}$ 是常数，且 $a_{2} \neq 0)$ .

（2）令 $b_{n} = \frac{S_{n + 2}}{S_{n + 1}} +\frac{S_{n + 1}}{S_{n + 2}}$ ，证明： $2n < b_{1} + b_{2} + \dots +b_{n} < 2n + 3$ .

(叠乘法)因为 $\frac{a_{n}}{a_{n-1}}=\frac{n-1}{n-2}(n\geqslant3)$ ，所以 $\frac{a_{3}}{a_{2}}=\frac{2}{1}$ ， $\frac{a_{4}}{a_{3}}=\frac{3}{2}$ ， $\cdots$ ， $\frac{a_{n}}{a_{n-1}}=\frac{n-1}{n-2}$

$（2） b _ {n} = \frac {\frac {(n + 2) (n + 1) a _ {2}}{2}}{\frac {(n + 1) n a _ {2}}{2}} + \frac {\frac {(n + 1) n a _ {2}}{2}}{\frac {(n + 2) (n + 1) a _ {2}}{2}} = \frac {n + 2}{n} + \frac {n}{n + 2},$

9. 已知数列 $\{a_{n}\}$ 的前 $n$ 项和 $S_{n}$ 满足： $2S_{n} + a_{n} = 1$ .  
（1）求数列 $\{a_{n}\}$ 的通项公式;  
（2）设 $b_{n} = \frac{2a_{n + 1}}{(1 + a_{n})(1 + a_{n + 1})}$ ，数列 $\{b_n\}$ 的前 $n$ 项和为 $T_{n}$ ，求证： $T_{n} < \frac{1}{4}$ .

9. 解析 （1） 因为 $2S_{n} + a_{n} = 1$ ，所以 $2S_{n+1} + a_{n+1} = 1$ ，

两式相减可得 $2a_{n+1} + a_{n+1} - a_{n} = 0$ ，即 $3a_{n+1} = a_{n}$ ，即 $\frac{a_{n+1}}{a_{n}} = \frac{1}{3}$ ,
又 $2S_{1} + a_{1} = 1$ ，所以 $a_1 = \frac{1}{3}$ ，所以数列 $\{a_n\}$ 是首项、公比均为 $\frac{1}{3}$ 的等比数列.
故 $a_{n} = \frac{1}{3}\cdot (\frac{1}{3})^{n - 1} = (\frac{1}{3})^{n}$ ，数列 $\{a_n\}$ 的通项公式为 $a_{n} = (\frac{1}{3})^{n}$  
（2）因为 $b_{n}=\frac{2a_{n+1}}{(1+a_{n})(1+a_{n+1})}$ ,
所以 $b_{n} = \frac{2\cdot(\frac{1}{3})^{n + 1}}{[1 + (\frac{1}{3})^{n}][1 + (\frac{1}{3})^{n + 1}]}$ $= \frac{\frac{2}{3^{n + 1}}}{\frac{3^n + 1}{3^n}\cdot\frac{3^{n + 1} + 1}{3^{n + 1}}} = \frac{2\cdot 3^n}{(3^n + 1)\cdot(3^{n + 1} + 1)} = \frac{1}{3^n + 1} -\frac{1}{3^{n + 1} + 1}.$
故 $T_{n} = b_{1} + b_{2} + \ldots +b_{n} = (\frac{1}{3^{1} + 1} -\frac{1}{3^{2} + 1}) + (\frac{1}{3^{2} + 1} -\frac{1}{3^{3} + 1}) + \ldots +(\frac{1}{3^{n} + 1} -\frac{1}{3^{n + 1} + 1}) = \frac{1}{4} -\frac{1}{3^{n + 1} + 1} < \frac{1}{4}.$
所以 $T_{n}<\frac{1}{4}$ .

$\because a_{1}=2,\quad a_{n}>0$ ，设 $\{a_{n}\}$ 的公比为q， $\therefore a_{1}q^{2}=8\Rightarrow q=2,\quad\therefore a_{n}=2\times2^{n-1}=2^{n}(n\in\mathbf{N}^{*})$

$\therefore T _ {n} = c _ {1} + c _ {2} + \dots + c _ {n} = \left(\frac {1}{2 ^ {1} - 1} - \frac {1}{2 ^ {2} - 1}\right) + \left(\frac {1}{2 ^ {2} - 1} - \frac {1}{2 ^ {3} - 1}\right) + \dots + \left(\frac {1}{2 ^ {n} - 1} - \frac {1}{2 ^ {n + 1} - 1}\right) = 1 - \frac {1}{2 ^ {n + 1} - 1},$

[例 12] (2021·全国乙)设 $\{a_{n}\}$ 是首项为1的等比数列，数列 $\{b_{n}\}$ 满足 $b_{n}=\frac{na_{n}}{3}$ . 已知 $a_{1}, 3a_{2}, 9a_{3}$ 成等差数列.  
（1）求 $\{a_{n}\}$ 和 $\{b_{n}\}$ 的通项公式;  
（2）记 $S_{n}$ 和 $T_{n}$ 分别为 $\{a_{n}\}$ 和 $\{b_{n}\}$ 的前 n 项和．证明： $T_{n}<\frac{S_{n}}{2}$ .
解析 （1） 设 $\{a_{n}\}$ 的公比为 q，则 $a_{n}=q^{n-1}$ .
因为 $a_{1}$ ， $3a_{2}$ ， $9a_{3}$ 成等差数列，所以 $1+9q^{2}=2\times3q$ ，解得 $q=\frac{1}{3}$
故 $a_{n} = \frac{1}{3^{n - 1}}, b_{n} = \frac{n}{3^{n}}.$  
（2）由（1）知 $S_{n} = \frac{1\times\left(1 - \frac{1}{3^{n}}\right)}{1 - \frac{1}{3}} = \frac{3}{2}\left(1 - \frac{1}{3^{n}}\right),$
$T _ {n} = \frac {1}{3} + \frac {2}{3 ^ {2}} + \frac {3}{3 ^ {3}} + \dots + \frac {n}{3 ^ {n}}, \tag {①}$
$\frac {1}{3} T _ {n} = \frac {1}{3 ^ {2}} + \frac {2}{3 ^ {3}} + \frac {3}{3 ^ {4}} + \dots + \frac {n - 1}{3 ^ {n}} + \frac {n}{3 ^ {n + 1}}, \tag {②}$

①-②得 $\frac{2}{3} T_n = \frac{1}{3} +\frac{1}{3^2} +\frac{1}{3^3} +\dots +\frac{1}{3^n} -\frac{n}{3^{n + 1}}$ ，即 $\frac{2}{3} T_n = \frac{\frac{1}{3}\left(1 - \frac{1}{3^n}\right)}{1 - \frac{1}{3}} -\frac{n}{3^{n + 1}} = \frac{1}{2}\left(1 - \frac{1}{3^n}\right) - \frac{n}{3^{n + 1}},$
整理得 $T_{n}=\frac{3}{4}-\frac{2n+3}{4\times3^{n}}$ ，则 $2T_{n}-S_{n}=2\left(\frac{3}{4}-\frac{2n+3}{4\times3^{n}}\right)-\frac{3}{2}\left(1-\frac{1}{3^{n}}\right)=-\frac{n}{3^{n}}<0$ ，故 $T_{n}<\frac{S_{n}}{2}$ .

[例 13] 已知数列 $\{a_{n}\}$ 的首项 $a_{1}=3$ ，前 n 项和为 $S_{n}$ ， $a_{n+1}=2S_{n}+3$ ， $n\in N^{*}$ .  
（1）求数列 $\{a_{n}\}$ 的通项公式;  
（2）设 $b_{n} = \log_{3}a_{n}$ ，求数列 $\left\{\frac{b_n}{a_n}\right\}$ 的前 $n$ 项和 $T_{n}$ ，并证明： $\frac{1}{3} \leqslant T_{n} < \frac{3}{4}$ .
解析 （1）由 $a_{n + 1} = 2S_n + 3$ ，得 $a_{n} = 2S_{n - 1} + 3(n\geq 2)$

两式相减得 $a_{n+1}-a_{n}=2(S_{n}-S_{n-1})=2a_{n}$ ，故 $a_{n+1}=3a_{n}(n\geq2)$ ,
所以当 $n \geq 2$ 时， $\{a_{n}\}$ 是以 3 为公比的等比数列.
因为 $a_{2}=2S_{1}+3=2a_{1}+3=9,\quad\frac{a_{2}}{a_{1}}=3$ ，所以 $\{a_{n}\}$ 是首项为 3，公比为 3 的等比数列， $a_{n}=3^{n}$ .  
（2） $a_{n}=3^{n}$ ，故 $b_{n}=\log_{3}a_{n}=\log_{3}3^{n}=n,\quad\frac{b_{n}}{a_{n}}=\frac{n}{3^{n}}=n\cdot\left(\frac{1}{3}\right)^{n}$
$T _ {n} = 1 \times \frac {1}{3} + 2 \times \left(\frac {1}{3}\right) ^ {2} + 3 \times \left(\frac {1}{3}\right) ^ {3} + \dots + n \times \left(\frac {1}{3}\right) ^ {n}, \tag {①}$
$\frac {1}{3} T _ {n} = 1 \times \left(\frac {1}{3}\right) ^ {2} + 2 \times \left(\frac {1}{3}\right) ^ {3} + 3 \times \left(\frac {1}{3}\right) ^ {4} + \dots + (n - 1) \times \left(\frac {1}{3}\right) ^ {n} + n \times \left(\frac {1}{3}\right) ^ {n + 1}. \tag {②}$

①-②，得 $\frac{2}{3} T_n = \frac{1}{3} +\left(\frac{1}{3}\right)^2 +\left(\frac{1}{3}\right)^3 +\dots +\left(\frac{1}{3}\right)^n -n\times \left(\frac{1}{3}\right)^{n + 1} = \frac{\frac{1}{3} - \left(\frac{1}{3}\right)^{n + 1}}{1 - \frac{1}{3}} -n\times \left(\frac{1}{3}\right)^{n + 1} = \frac{1}{2} -\frac{3}{2} +n\left(\frac{1}{3}\right)^{n + 1},$
所以 $T_{n}=\frac{3}{4}-\frac{1}{2}\left(\frac{3}{2}+n\right)\left(\frac{1}{3}\right)_{n}$ .
因为 $\left(\frac{3}{2}+n\right)\left(\frac{1}{3}\right)_{n}>0$ ，所以 $T_{n}<\frac{3}{4}$ 。又因为 $T_{n+1}-T_{n}=\frac{n+1}{3^{n+1}}>0$ ，
所以数列 $\{T_{n}\}$ 单调递增，所以 $(T_{n})_{\min}=T_{1}=\frac{1}{3}$ ，所以 $\frac{1}{3}\leq T_{n}<\frac{3}{4}$ .

即 $a_{n+1}=3a_{n}+2(n\geqslant1)$ . 所以 $a_{n+1}+1=3(a_{n}+1)$ ，即 $b_{n+1}=3b_{n}$ ，且 $b_{1}=3$ .
故 $\{b_{n}\}$ 是首项为3，公比为3的等比数列.  
（2）由（1）得 $b_{n}=3^{n}$ ， $nb_{n}=n\cdot3^{n}$ .
$T _ {n} = 1 \times 3 + 2 \times 3 ^ {2} + 3 \times 3 ^ {3} + \dots + n \times 3 ^ {n},$
$3 T _ {n} = 1 \times 3 ^ {2} + 2 \times 3 ^ {3} + 3 \times 3 ^ {4} + \dots + n \times 3 ^ {n + 1},$

两式相减，得 $-2T_{n}=3+3^{2}+3^{3}+\cdots+3^{n}-n\times3^{n+1}=\frac{3(1-3^{n})}{1-3}-n\times3^{n+1}$
化简得 $T_{n}=\left(\frac{3}{2}n-\frac{3}{4}\right)\times3^{n}+\frac{3}{4}.$  
（3）由 $\frac{1}{a_k} = \frac{1}{3^k - 1} >\frac{1}{3^k}$ 得 $\frac{1}{a_1} +\frac{1}{a_2} +\frac{1}{a_3} +\dots +\frac{1}{a_n} >\frac{1}{3} +\frac{1}{3^2} +\dots +\frac{1}{3^n} = \frac{\frac{1}{3}\left(1 - \frac{1}{3^n}\right)}{1 - \frac{1}{3}} = \frac{1}{2} -\frac{1}{2}\times \frac{1}{3^n}.$
又 $\frac{1}{a_k} = \frac{1}{3^k - 1} = \frac{3^{k + 1} - 1}{(3^k - 1)(3^{k + 1} - 1)} < \frac{3^{k + 1}}{(3^k - 1)(3^{k + 1} - 1)} = \frac{3}{2}\left[\frac{1}{3^k - 1} -\frac{1}{3^{k + 1} - 1}\right],$
所以 $\frac{1}{a_1} +\frac{1}{a_2} +\frac{1}{a_3} +\dots +\frac{1}{a_n} <  \frac{1}{2} +\frac{3}{2}\left[\left(\frac{1}{3^2 - 1} -\frac{1}{3^3 - 1}\right) + \left(\frac{1}{3^3 - 1} -\frac{1}{3^4 - 1}\right) + \dots +\right.$
$= \frac {1}{2} + \frac {3}{2} \left(\frac {1}{3 ^ {2} - 1} - \frac {1}{3 ^ {n + 1} - 1}\right) = \frac {1}{2} + \frac {3}{1 6} - \frac {3}{2} \times \frac {1}{3 ^ {n + 1} - 1} <   \frac {1 1}{1 6},$
故 $\frac{1}{2}-\frac{1}{2\times3^{n}}<\frac{1}{a_{1}}+\frac{1}{a_{2}}+\frac{1}{a_{3}}+\cdots+\frac{1}{a_{n}}<\frac{11}{16}.$

17. 已知数列 $\{a_{n}\}$ 满足 $a_1 = \frac{2}{5}, a_{n+1} = \frac{2a_n}{3 - a_n}, n \in \mathbf{N}^*$ .  
（1）求 $a_2$ ;  
（2）求 $\left\{\frac{1}{a_{n}}\right\}$ 的通项公式;  
（3）设 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ，求证： $\frac{6}{5} \left[ 1 - \left( \frac{2}{3} \right)^{n} \right] \leqslant S_{n} < \frac{21}{13}$ .

17. 解析 （1）由条件可得 $a_{2}=\frac{2a_{1}}{3-a_{1}}=\frac{4}{13}$ .  
（2）由 $a_{n + 1} = \frac{2a_n}{3 - a_n}$ 得 $\frac{1}{a_{n + 1}} = \frac{3}{2}\cdot \frac{1}{a_n} -\frac{1}{2},$ 所以 $\frac{1}{a_{n + 1}} -1 = \frac{3}{2}\left[\frac{1}{a_n} -1\right),$ 又 $\frac{1}{a_1} -1 = \frac{3}{2},$
所以 $\left\{\frac{1}{a_n} - 1\right\}$ 是以首项为 $\frac{3}{2}$ ，公比为 $\frac{3}{2}$ 的等比数列，因此， $\frac{1}{a_n} = \left(\frac{3}{2}\right)^n + 1$ 。  
（3）由（2）可得 $a_{n} = \frac{1}{\left(\frac{3}{2}\right)_{n + 1}}\geqslant \frac{1}{\left(\frac{3}{2}\right)_{n} + \left(\frac{3}{2}\right)_{n - 1}} = \frac{2}{5}\times \left(\frac{2}{3}\right)_{n - 1},$
所以 $S_{n}=a_{1}+a_{2}+\cdots+a_{n}\geqslant\frac{2}{5}+\frac{2}{5}\cdot\left(\frac{2}{3}\right)^{1}+\cdots+\frac{2}{5}\cdot\left(\frac{2}{3}\right)^{n-1}=\frac{6}{5}\left[1-\left(\frac{2}{3}\right)^{n}\right]$ .
又 $a_{n}=\frac{1}{\left(\frac{3}{2}\right)_{n+1}}<\frac{1}{\left(\frac{3}{2}\right)_{n}}=\left(\frac{2}{3}\right)_{n}$
所以 $S_{n}=a_{1}+a_{2}+a_{3}+\cdots+a_{n}<\frac{2}{5}+\frac{4}{13}+\left(\frac{2}{3}\right)^{3}+\cdots+\left(\frac{2}{3}\right)^{n}=\frac{46}{65}+\frac{8}{9}-\frac{8}{9}\cdot\left(\frac{2}{3}\right)^{n-2}<\frac{21}{13},\quad n\geqslant3,$
又 $S_{1} = \frac{2}{5} < \frac{21}{13}, S_{2} = \frac{46}{65} < \frac{21}{13}$ , 因此, $S_{n} < \frac{21}{13}, n \in \mathbb{N}^{*}$ .

综上， $\frac{6}{5}\left[1-\left(\frac{2}{3}\right)_{n}\right]\leqslant S_{n}<\frac{21}{13}.$
