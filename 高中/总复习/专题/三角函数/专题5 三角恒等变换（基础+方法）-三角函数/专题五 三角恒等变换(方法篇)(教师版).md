# 专题五 三角恒等变换(方法篇)

#### 1. 三角恒等变换的基本思想

三角恒等变换的基本思想是：高变低，复变单，多变一.

高变低就是高次的三角函数向低次的三角函数转化，特别是二次向一次转化；复变单就是复角的三角函数向单角的三角函数转化；多变一就是多种三角函数向单一三角函数转化.

#### 2. 三角恒等变换的基本公式

同角三角函数基本关系；诱导公式；和角公式；差角公式；二倍角公式和变形公式.

#### 3. 三角恒等变换的基本方法  
（1）变换函数角度：即分角变换．如 $\alpha=(\alpha+\beta)-\beta=\frac{\alpha+\beta}{2}+\frac{\alpha-\beta}{2}=(2\alpha+\beta)-(\alpha+\beta)$ ; $2\alpha=(\alpha+\beta)+(\alpha-\beta)$ 等等.  
（2）变换函数名称：即切化弦．主要用同角三角函数的商数关系 $\tan\alpha=\frac{\sin\alpha}{\cos\alpha}$ .  
（3）变换函数次数：即降幂与升幂．主要用降幂公式： $\cos^2\alpha = \frac{1 + \cos 2\alpha}{2}$ ， $\sin^2\alpha = \frac{1 - \cos 2\alpha}{2}$ ；升幂公式： $1 + \cos 2\alpha = 2\cos^2\alpha$ ， $1 - \cos 2\alpha = 2\sin^2\alpha$   
（4）变换整个式子: 将三角函数式 $a \sin x + b \cos x$ 变形成 $\sqrt{a^2 + b^2} \sin (x + \varphi)$ 的形式, 这里 $\varphi$ 被称为辅助角, 其大小由 $\tan \varphi$ 确定, 它的象限由 $a, b$ 的符号确定. 主要用辅助角公式. 有时还要逆用或变用公式. 如两角和的正切公式和余弦的二倍角公式.  
（5）变换式子中的常量：即常量变换．如“1”的代换有： $1=\sin^{2}\alpha+\cos^{2}\alpha,\quad1=\tan45^{\circ}$ 等等.

# 考点一 变换角度

# 【方法总结】

# 变换角度的解题策略

已知某些角的三角函数值，求另外一些角的三角函数值，要注意观察已知角与所求表达式中角的关系，即拆角与凑角.  
（1）当“已知角”有一个时, 此时应着眼于“所求角”与“已知角”与特殊角的和或差的关系, 然后把“所求角”变成“已知角”.   
（2）当“已知角”有两个时，“所求角”一般表示为两个“已知角”的和或差的形式.
由于和、差角与单角是相对的，因此解题过程中根据需要灵活地进行拆角或凑角的变换．常见角的变换有： $\alpha=(\alpha+\beta)-\beta=(\alpha-\beta)+\beta=\frac{\alpha+\beta}{2}+\frac{\alpha-\beta}{2}=(2\alpha+\beta)-(a+\beta)$ ; $2\alpha=(\alpha+\beta)+(\alpha-\beta)$ ; $15^{\circ}=45^{\circ}-30^{\circ}$ ; $\frac{\pi}{4}+\alpha=\frac{\pi}{2}-\left(\frac{\pi}{4}-\alpha\right)$ 等.

# 考点三 变换次数

# 【方法总结】
在三角函数式的化简中“次降角升”和“次升角降”是基本的规律，根号中含有三角函数式时，一般需要升次．三角函数式中含有二次式时，一般需要降次.  
（1）降幂公式： $\sin^{2}\alpha=\frac{1-\cos2\alpha}{2}$ ; $\cos^{2}\alpha=\frac{1+\cos2\alpha}{2}$ ; $\sin\alpha\cos\alpha=\frac{1}{2}\sin2\alpha.$  
（2）升幂公式： $1 + \cos \alpha = 2\cos \frac{2\alpha}{2};1 - \cos \alpha = 2\sin \frac{2\alpha}{2};1 + \sin \alpha = \left(\frac{\sin\alpha}{2} +\cos \frac{\alpha}{2}\right)^2;1 - \sin \alpha = \left(\frac{\sin\alpha}{2} -\cos \frac{\alpha}{2}\right)^2.$
