# 专题05 立体几何中的截面问题

# 【方法总结】

# 确定截面的主要依据

用一个平面去截几何体，此平面与几何体的交集叫做这个几何体的截面，利用平面的性质确定截面形状是解决截面问题的关键.

(1)平面的四个公理及推论．(2)直线和平面平行的判定和性质．(3)两个平面平行的性质．(4)球的截面的性质.
