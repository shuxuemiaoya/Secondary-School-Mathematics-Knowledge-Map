# 专题 16 已知核心方程(隐性)和未知核心方程直线过定点模型

# 题型一 已知核心方程(隐性)

先将隐性核心方程等价地转化为显性核心方程.

# 【方法总结】  
（1）单参数法: 设动直线 PM 方程为 $y=k(x-x_{0})+y_{0}$ ，联立直线与椭圆(抛物线)，解出点 M 的坐标为 $(A(k), B(k))$ ，同理(由核心方程代换)，得出点 N 的坐标为 $(C(k), D(k))$ ，然后写出动直线 MN 方程，即 $kf(x, y)+g(x, y)=0$ ，根据直线过定点时与参数没有关系(即方程对参数的任意值都成立)，得到方程组 $\left\{\begin{aligned}f(x, y)=0,\\ g(x, y)=0;\end{aligned}\right.$ 以方程组的解为坐标的点就是直线所过的定点.<center><img src="images/b7659eabef9e5a0da58c6f041762d493649e5318e999116ff138ce25c760ecb1.jpg" style="max-width:100%;"></center><center>图1</center><center><img src="images/8efda84bc8af0349a808cc800174f6cb9da7d29410d007c2705c9f8a3e0ff52b.jpg" style="max-width:100%;"></center><center>图2</center><center><img src="images/8be2e20f9dbd9040a39d54c0b0be8844a1aee3a310cf9a5bce1cec43d3ef3c70.jpg" style="max-width:100%;"></center><center>图3</center><center><img src="images/39157e0ff27ecb5021e2ab30da38b46391ef0043845bd92f67f536a73e08ce53.jpg" style="max-width:100%;"></center><center>图4</center>  
（2）双参数法：设动直线 MN 方程(斜率存在)为 $y=kx+t$ ，由核心方程得到 $f(k, t)=0$ ，把 t 用 k 表示或把 k 用 t 表示，即 $kf(x, y)+g(x, y)=0$ （或 $tf(x, y)+g(x, y)=0$ ），根据直线过定点时与参数没有关系(即方程对参数的任意值都成立)，得到方程组 $\left\{\begin{aligned}f(x, y)=0,\\ g(x, y)=0;\end{aligned}\right.$ 以方程组的解为坐标的点就是直线所过的定点.

# 【例题选讲】

[例1] 已知椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ 的右焦点 $F(\sqrt{3}, 0)$ ，长半轴长与短半轴长的比值为2.  
（1）求椭圆 C 的标准方程;  
（2）设不经过点 $B(0,1)$ 的直线 $l$ 与椭圆 $C$ 相交于不同的两点 $M,N$ ，若点 $B$ 在以线段 $MN$ 为直径的圆上，证明直线 $l$ 过定点，并求出该定点的坐标.

[例 2] 已知椭圆 O: $\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 的左、右顶点分别为 A, B，点 P 在椭圆 O 上运动，若 $\triangle PAB$ 面积的最大值为 $2\sqrt{3}$ ，椭圆 O 的离心率为 $\frac{1}{2}$ .  
（1）求椭圆 O 的标准方程;  
（2）过 B 点作圆 $E: x^{2}+(y-2)^{2}=r^{2}(0<r<2)$ 的两条切线，分别与椭圆 O 交于两点 C，D(异于点 B)，当 r 变化时，直线 CD 是否恒过某定点？若是，求出该定点坐标；若不是，请说明理由.

# 题型二 未知核心方程

单参数法：设出动点可动直线的方程为，解出点 M 的坐标为 $(A(k), B(k))$ ，解出点 N 的坐标为 $(C(k), D(k))$ ，然后写出动直线 MN 方程，即 $kf(x, y) + g(x, y) = 0$ ，根据直线过定点时与参数没有关系（即方程对参数的任意值都成立），得到方程组 $\left\{\begin{aligned}f(x, y)=0,\\ g(x, y)=0;\end{aligned}\right.$ 以方程组的解为坐标的点就是直线所过的定点.<center><img src="images/52ac8bb41d5edabc903ebccc4e711cc32e2e084933cd95e1adcd3af812371810.jpg" style="max-width:100%;"></center><center>图1</center><center><img src="images/5034957b3b9262ae37534409c89396ba4e54740ded0b3e45e6caf0db43559b69.jpg" style="max-width:100%;"></center><center>图2</center><center><img src="images/f7c4042c53020ff6c929cee54290472e5f7ff836145e3d122d5805445c595917.jpg" style="max-width:100%;"></center><center>图3</center><center><img src="images/0743c50f64a1eee29f003082955f844313d0cec5652cace98d0de453950d4022.jpg" style="max-width:100%;"></center><center>图4</center>

（1）求 E 的方程;
