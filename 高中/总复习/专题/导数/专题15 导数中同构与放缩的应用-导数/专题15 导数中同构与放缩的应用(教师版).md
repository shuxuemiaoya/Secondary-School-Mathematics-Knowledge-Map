# 专题 15 导数中同构与放缩的应用

同构法是将不同的代数式(或不等式、方程)通过变形，转化为形式结构相同或者相近的式子，通过整体思想或换元等将问题转化的方法，这体现了转化思想。此方法常用于求解具有对数、指数等混合式子结构的等式或不等式问题。

当然，用同构法解题，除了要有同构法的思想意识外，对观察能力，对代数式的变形能力的要求也是比较高的，

考点一 部分同构携手放缩法（同构放缩需有方，切放同构一起上）

# 【方法总结】

在学习指对数的运算时，曾经提到过两个这样的恒等式：

(1)当 $a > 0$ 且 $a\neq 1$ 时，有 $x = a^{\log_a x}$ ，(2)当 $a > 0$ 且 $a\neq 1$ 时，有 $x = \log_a a^x$

再结合指数与对数运算法则，可以得到下述结论(其中 x>0) (“e”三兄弟与“lnx”三姐妹)

(3) $x\mathrm{e}^{x}=\mathrm{e}^{x+\ln x},\quad x+\ln x=\ln(x\mathrm{e}^{x})$   
(4) $\frac{e^{x}}{x}=e^{x-\ln x},\quad x-\ln x=\ln\frac{e^{x}}{x}$   
(6) $\frac{x}{\mathrm{e}^x} = \mathrm{e}^{\ln x - x},\quad \ln x - x = \ln \frac{x}{\mathrm{e}^x}$

再结合常用的切线不等式： $e^{x} \geq x + 1$ ， $e^{x} \geq ex$ ， $\ln x \leq x + 1$ ， $\ln x \leq \frac{x}{e}$ 等，可以得到更多的结论

(7) $x\mathrm{e}^{x} = \mathrm{e}^{x + \ln x}\geq x + \ln x + 1,\quad x + \ln x = \ln (x\mathrm{e}^{x})\leq x\mathrm{e}^{x} - 1.$

$$
x \mathrm{e} ^ {x} = \mathrm{e} ^ {x + \ln x} \geq \mathrm{e} (x + \ln x), \quad x + \ln x = \ln \left(x \mathrm{e} ^ {x}\right) \leq \frac {x \mathrm{e} ^ {x}}{\mathrm{e}} = x \mathrm{e} ^ {x - 1}.
$$

(8) $\frac{\mathrm{e}^x}{x} = \mathrm{e}^{x - \ln x}\geq x - \ln x + 1,\quad x - \ln x = \ln \frac{\mathrm{e}^x}{x}\leq \frac{\mathrm{e}^x}{x} -1$

$$
\frac {\mathrm{e} ^ {x}}{x} = \mathrm{e} ^ {x - \ln x} \geq \mathrm{e} (x - \ln x), \quad x - \ln x = \ln \frac {\mathrm{e} ^ {x}}{x} \leq \frac {\mathrm{e} ^ {x - 1}}{x}
$$

(9) $\frac{x}{\mathrm{e}^x} = \mathrm{e}^{\ln x - x}\geq \ln x - x + 1,\quad \ln x - x = \ln \frac{x}{\mathrm{e}^x}\leq \frac{x}{\mathrm{e}^x} -1$

$$
\frac {x}{\mathrm{e} ^ {x}} = \mathrm{e} ^ {\ln x - x} \geq \mathrm{e} (\ln x - x), \quad \ln x - x = \ln \frac {x}{\mathrm{e} ^ {x}} \leq \frac {x}{\mathrm{e} ^ {x + 1}}
$$

(2)函数 $f(x)=\mathrm{e}^{x}-\frac{\ln x+1}{x}$ 的最小值是 \_\_\_\_.

答案 1 解析 $f(x) = \mathrm{e}^{x} - \frac{\ln x + 1}{x} = \frac{x\mathrm{e}^{x} - \ln x - 1}{x} = \frac{\mathrm{e}^{x + \ln x} - \ln x - 1}{x} \geq \frac{\ln x + x + 1 - \ln x - 1}{x} = 1$ (当且仅当 $x + \ln x = 0$ 取等号).

(3)函数 $f(x)=\frac{x^{2}e^{x}-2\ln x}{x+1}$ 的最小值是 \_\_\_\_.

[例 2] (1) 不等式 $xe^{x} - ax - \ln x - 1 \geq 0$ 恒成立，则实数 a 的最大值是 \_\_\_\_.

答案 1 解析 $x\mathrm{e}^{x} - ax - \ln x - 1 \geq 0$ 恒成立 $\Leftrightarrow a \leq \left(\frac{x\mathrm{e}^{x} - \ln x - 1}{x}\right)_{\min} \Leftrightarrow \frac{x\mathrm{e}^{x} - \ln x - 1}{x} = \frac{\mathrm{e}^{x + \ln x} - \ln x - 1}{x}$ $\geq \frac{x + \ln x + 1 - \ln x - 1}{x} = 1$ ，当且仅当 $x + \ln x = 0$ 等号成立.

(2)不等式 $xe^{x}-a(x+\ln x+1)\geq0$ 恒成立，则正数 a 的取值范围是 \_\_\_\_.

答案 $0 < a \leq 1$ 解析 $x\mathrm{e}^{x} - a(x + \ln x + 1) \geq 0 \Leftrightarrow x\mathrm{e}^{x} - a(x + \ln x + 1) \geq 0 \Leftrightarrow \mathrm{e}^{x + \ln x} \geq a(x + \ln x + 1)$ ，当 $x + \ln x + 1 \leq 0$ 时，原不等式恒成立，当 $x + \ln x + 1 > 0$ 时， $a \leq \frac{\mathrm{e}^{x + \ln x}}{x + \ln x + 1}$ ，由于 $\frac{\mathrm{e}^{x + \ln x}}{x + \ln x + 1} \geq \frac{x + \ln x + 1}{x + \ln x + 1} = 1$ ，当且仅当 $x + \ln x = 1$ 等号成立，所以 $a \leq 1$ ，故 $0 < a \leq 1$ 。

(3)不等式 $x\mathrm{e}^{x} - a(x + \ln x)\geq 0$ 恒成立，则正数 $a$ 的取值范围是

答案 $0 \leq a \leq e$ 解析 $x\mathrm{e}^{x} - a(x + \ln x) \geq 0 \Leftrightarrow x\mathrm{e}^{x} - a(x + \ln x) \geq 0 \Leftrightarrow \mathrm{e}^{x + \ln x} \geq a(x + \ln x) \Leftrightarrow \mathrm{e}^{t} \geq at$ (令

$$
t = x + \ln x) \Leftrightarrow \left\{ \begin{array}{l} a \geq \frac {\mathrm{e} ^ {t}}{t} (t <   0) \\ a \leq \frac {\mathrm{e} ^ {t}}{t} (t > 0) \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} a \geq 0 \\ a \leq \mathrm{e} \end{array} \right. \Leftrightarrow 0 \leq a \leq \mathrm{e}.
$$

(4)已知函数 $f(x) = x^{b}\mathrm{e}^{x} - a\ln x - x - 1(x > 1)$ ，其中 $b > 0$ ，若 $f(x)\geq 0$ 恒成立，则实数 $a$ 与 $b$ 的大小关系是 \_\_\_\_.

答案 $a \leq b$ 解析 $f(x) \geq 0 \Leftrightarrow x^b \mathrm{e}^x \geq a \ln x + x + 1 \Leftrightarrow \mathrm{e}^{x + b \ln x} - x - 1 \geq a \ln x \Leftrightarrow a \leq \frac{\mathrm{e}^{x + b \ln x} - x - 1}{\ln x}$ ，由于 $\frac{\mathrm{e}^{x + b \ln x} - x - 1}{\ln x} \geq \frac{x + b \ln x + 1 - x - 1}{\ln x} = b$ ，当且仅当 $x + b \ln x = 0$ 等号成立，所以 $a \leq b$ 。

(5)已知函数 $f(x)=ae^{x}-\ln x-1$ ，若 $f(x)\geq0$ 恒成立，则实数 a 的取值范围是 \_\_\_\_.

答案 $a \geq \frac{1}{\mathrm{e}}$ 解析 $a\mathrm{e}^{x} - \ln x - 1 \geq 0 \Leftrightarrow a \geq \frac{\ln x + 1}{\mathrm{e}^{x}}$ ，由于 $\ln x + 1 \leq x, \mathrm{e}^{x} \geq \mathrm{e}x$ ，两者都是当且仅当 $x = 1$ 等号成立，则 $\frac{\ln x + 1}{\mathrm{e}^{x}} \geq \frac{x}{\mathrm{e}x} = \frac{1}{\mathrm{e}}$ ，所以 $a \geq \frac{1}{\mathrm{e}}$ 。

(6)已知不等式 $e^{x}-1\geq kx+\ln x$ ，对任意的正数 x 恒成立，则实数 k 的取值范围是 \_\_\_\_.

答案 $k \leq e - 1$ 解析 $\mathrm{e}^{x} - 1 \geq kx + \ln x \Leftrightarrow k \leq \frac{\mathrm{e}^{x}}{x} - \frac{\ln x}{x}$ ，由于 $\mathrm{e}^{x} \geq \mathrm{e}x$ ， $\ln x \leq x$ ，两者都是当且仅当 $x = 1$ 等号成立，所以 $\frac{\mathrm{e}^{x}}{x} \geq \mathrm{e}$ ， $\frac{\ln x}{x} \leq 1$ 则 $\frac{\mathrm{e}^{x}}{x} - \frac{\ln x}{x} \geq \mathrm{e} - 1$ ，所以 $k \leq \mathrm{e} - 1$ 。

(7)已知不等式 $ax + x\mathrm{e}^{-ax} - \ln x - 1 \geq 0$ ，对任意的正数 $x$ 恒成立，则实数 $a$ 的取值范围是 \_\_\_\_.

答案 $(- \infty, \frac{1}{\mathrm{e}}]$ 解析 $x \mathrm{e}^{-ax} + ax - \ln x - 1 = \mathrm{e}^{-ax + \ln x} + ax - \ln x - 1 \geq -ax + \ln x + 1 + ax - \ln x - 1 = 0$ ，当且仅当 $-ax + \ln x = 0$ ，即 $a = \frac{\ln x}{x}$ 时等号成立，由 $a = \frac{\ln x}{x}$ 有解，易得 $a \leq \frac{1}{\mathrm{e}}$ 。

(8)已知函数 $f(x)=xe^{x}-a(x+\ln x)$ 有两个零点，则实数 a 的取值范围是 \_\_\_\_.

答案 (e, +∞) 解析 $f(x) = x\mathrm{e}^{x} - a(x + \ln x) = \mathrm{e}^{x + \ln x} - a(x + \ln x)$ ，令 $t = x + \ln x, t \in \mathbf{R}$ ，显然该函数单调递增，即 $\mathrm{e}^t - at = 0$ 有两个根，即 $a = \frac{\mathrm{e}^t}{t}$ 有两个根，令 $g(t) = \frac{\mathrm{e}^t}{t}$ ， $g(t)$ 在 $(-∞, 1)$ 单调递减，在 $(1, +∞)$ 单调递增．∴ $g(t)_{\min} = g(1) = \mathrm{e}$ ， $a > \mathrm{e}$ .

[例 3] (2020 届太原二模) 已知函数 $f(x)=\ln x+ax+1$ .

(1)若函数 $f(x)$ 有两个零点，求实数 a 的取值范围；  
(2)若 $f(x) \leq xe^{x}$ 恒成立，求实数 a 的取值范围.

解析 (1) $f(x)$ 定义域是 $(0, +\infty)$ ， $f'(x) = \frac{1}{x} + a$ ，

①当 $a \geq 0$ 时， $f'(x) > 0$ ， $f(x)$ 在定义域上单调递增，不可能有两个零点；

②当 a<0 时，由 $f'(x)=\frac{1}{x}+a=0$ ，得 $x=-\frac{1}{a}>0$ ，

当 $x \in (0, -\frac{1}{a})$ 时， $f'(x) > 0$ ， $f(x)$ 在定义域上单调递增，

当 $x \in (-\frac{1}{a}, +\infty)$ 时， $f'(x) < 0$ ， $f(x)$ 在定义域上单调递减，所以当 $x = -\frac{1}{a}$ 时， $f(x)$ 取得极大值.

当 $x \to 0$ 时， $f(x) \to -\infty$ ，当 $x \to +\infty$ 时， $f(x) \to -\infty$ ，因为 $f(x)$ 有两个零点，所以 $f(-\frac{1}{a}) > 0$ ，解得 -1 < a < 0。

(2)要使 $f(x) \leq xe^{x}$ 恒成立，只要 $\ln x + ax + 1 \leq xe^{x}$ 恒成立，只要 $a \leq \frac{xe^{x} - \ln x - 1}{x}$ 恒成立，

令 $g(x) = \frac{x\mathrm{e}^x - \ln x - 1}{x}$ ，则 $\frac{x\mathrm{e}^x - \ln x - 1}{x} = \frac{\mathrm{e}^{x + \ln x} - \ln x - 1}{x} \geq \frac{x + \ln x + 1 - \ln x - 1}{x} = 1$ ，当且仅当时取等号。所以 $f(x) \leq x\mathrm{e}^x$ 恒成立，实数 $a$ 的取值范围为 $a \leq 1$ 。

# 考点二 整体同构携手脱衣法

# 【方法总结】

在成立或恒成立命题中，很有一部分题是命题者利用函数单调性构造出来的，如果我们能找到这个函数模型（即不等式两边对应的同一个函数），无疑大大加快解决问题的速度，找到这个函数模型的方法，我们就称为整体同构法。如，若 $F(x) \geq 0$ 能等价变形为 $f[g(x)] \geq f[h(x)]$ ，然后利用 $f(x)$ 的单调性，如递增，再转化为 $g(x) \geq h(x)$ ，这种方法我们就可以称为同构不等式（等号成立时，称为同构方程），简称同构法。

1. 地位同等同构（主要针对双变量，合二为一泰山移）

(1) $\frac{f\quad x_{1}\quad-f\quad x_{2}}{x_{1}-x_{2}}>k(x_{1}<x_{2})\Leftrightarrow f(x_{1})-f(x_{2})<kx_{1}-kx_{2}\Leftrightarrow f(x_{1})-kx_{1}<f(x_{2})-kx_{2}\Leftrightarrow y=f(x)-kx$ 为增函数；  
(2) $\frac{f(x_{1}-f(x_{2})}{x_{1}-x_{2}}<\frac{k}{x_{1}x_{2}}(x_{1}<x_{2})\Leftrightarrow f(x_{1})-f(x_{2})>\frac{k(x_{1}-x_{2})}{x_{1}x_{2}}=\frac{k}{x_{2}}-\frac{k}{x_{1}}\Leftrightarrow f(x_{1})+\frac{k}{x_{1}}>f(x_{2})+\frac{k}{x_{2}}\Leftrightarrow y=f(x)+\frac{k}{x}$ 为减函数；

含有地位同等的两个变 $x_{1}$ ， $x_{2}$ 或 p，q 等的不等式，进行“尘化尘，土化土”式的整理，是一种常见变形，如果整理（即同构）后不等式两边具有结构的一致性，往往暗示单调性（需要预先设定两个变量的大小）

2. 指对跨阶同构（主要针对单变量，左同右同取对数）

(1)积型： $ae^{a}\leq b\ln b\xrightarrow{三种同构方式} \left\{\begin{aligned}&同左 &ae^{a}\leq(\ln b)e^{\ln b}\\&同右 &e^{a}\ln e^{a}\leq b\ln b\\&取对 &a+\ln a\leq\ln b+\ln(\ln b)\xrightarrow{构造函数}f(x)=x\ln x\end{aligned}\right.$

如， $2x^{3}\ln x\geq me^{\frac{m}{x}}\Leftrightarrow x^{2}\ln x^{2}\geq\frac{m}{x}e^{\frac{m}{x}}\Leftrightarrow x^{2}\ln x^{2}\geq e^{\frac{m}{x}}\ln e^{\frac{m}{x}}$ ，后面的转化同(1)

说明；在对“积型”进行同构时，取对数是最快捷的，同构出的函数，其单调性一看便知.

(2)商型： $\frac{e^{a}}{a}<\frac{b}{\ln b}\xrightarrow{\text{三种同构方式}}\left\{\begin{aligned}&\text{同左} & \frac{e^{a}}{a}<\frac{e^{\ln b}}{\ln b}\\&\text{同右} & \frac{e^{a}}{\ln e^{a}}<\frac{b}{\ln b}\\&\text{取对} & a-\ln a<\ln b-\ln(\ln b)\xrightarrow{\text{构造函数}}f(x)=\frac{x}{\ln x}\end{aligned}\right.$

(3)和差： $e^{a} \pm a > b \pm \ln b \xrightarrow{\text{两种同构方式}} \left\{ \begin{aligned} & \text{同左} \\ & \text{同右} \end{aligned} \right. \quad e^{a} \pm a > e^{\ln b} \pm \ln b \xrightarrow{\text{构造函数}} f(x) = e^{x} \pm x$

如； $\mathrm{e}^{ax} + ax > \ln(x+1) + x + 1 \Leftrightarrow \mathrm{e}^{ax} + ax > \mathrm{e}^{\ln(x+1)} + \ln(x+1) \Leftrightarrow ax > \ln(x+1)$ .

3. 无中生有同构（主要针对非上型，凑好形式是关键）

(1) $ae^{ax} > \ln x \xrightarrow{同乘x(无中生有)} axe^{ax} > x \ln x,$ 后面的转化同2(1);

(2) $\mathrm{e}^{x} > a\ln (ax - a) - a\Leftrightarrow \frac{1}{a}\mathrm{e}^{x} > \ln a(x - 1) - 1\Leftrightarrow \mathrm{e}^{x - \ln a} - \ln a > \ln (x - 1) - 1\xrightarrow{\text{同加}x(\text{无中生有})}\mathrm{e}^{x - \ln a} + x - \ln a>$ $\ln (x - 1) + x - 1 = \mathrm{e}^{\ln (x - 1)} + \ln (x - 1)\Leftrightarrow x - \ln a > \ln (x - 1);$

(3) $a^x > \log_a x \Leftrightarrow \mathrm{e}^{x\ln a} > \frac{\ln x}{\ln a} \Leftrightarrow (x\ln a)\mathrm{e}^{x\ln a} > x\ln x,$ 后面的转化同2(1).

7. 答案 $0 < a < \mathrm{e}^{2}$ 解析 $f(x) = \mathrm{e}^{x + 1} - a\ln ax + a > 0\Leftrightarrow \mathrm{e}^{x + 1} > a\ln ax - a\Leftrightarrow \mathrm{e}^{x + 1} > a(\ln ax - 1)\Leftrightarrow x\mathrm{e}^{x + 1}$ $>ax(\ln ax - 1)\Leftrightarrow \mathrm{e}(\ln ax - 1)\mathrm{e}^{\ln ax - 1},\therefore x\mathrm{e}^{x} > (\ln ax - 1)\mathrm{e}^{\ln ax - 1}$ ，令 $g(x) = x\mathrm{e}^x$ ，显然 $g(x)$ 为增函数，则原命题等价于 $g(x) > g(\ln ax - 1)\Leftrightarrow x > \ln ax - 1\Leftrightarrow \ln a <   x - \ln x + 1$ ，令 $h(x) = x - \ln x + 1$ ，则 $h^{\prime}(x) = \frac{x - 1}{x}$ 所以 $h(x)$ 在(0,1)上递减，在 $(1, + \infty)$ 上递增，则 $h(x)_{\min} = h(1) = 2$ ，所以 $\ln a <   2$ ，即得 $0 <   a <   \mathrm{e}^2$

8. 已知对任意 $x > 0$ ，不等式 $k(\mathrm{e}^{kx} + 1) - (1 + \frac{1}{x})\ln x > 0$ 恒成立，则实数 $k$ 的取值范围为 \_\_\_\_.

8. 答案 $\frac{1}{\mathrm{e}}, +\infty)$ 解析 $k(\mathrm{e}^{kx} + 1) - (1 + \frac{1}{x})\ln x > 0 \Leftrightarrow kx(\mathrm{e}^{kx} + 1) > (1 + x)\ln x \Leftrightarrow kx\mathrm{e}^{kx} + kx > x\ln x + x$ 即 $kx\mathrm{e}^{kx} + kx > \ln x\mathrm{e}^{\ln x} + \ln x$ 。令 $f(x) = x\mathrm{e}^x + x$ ，则 $f(x)$ 在 $(0, +\infty)$ 上递增，所以 $f(kx) > f(\ln x)$ ，所以 $kx > \ln x$ ，则 $\therefore k > \frac{\ln x}{x}$ ，由导数法易证 $\frac{\ln x}{x} < \frac{1}{\mathrm{e}}$ ，所以 $k > \frac{1}{\mathrm{e}}$ 。

9. 已知 $a < 0$ ，不等式 $x^{a + 1}\mathrm{e}^x + a\ln x \geq 0$ ，对任意的实数 $x > 1$ 恒成立，则实数 $a$ 的最小值是（）

A. $-\frac{1}{2e}$

B. $-\frac{1}{e}$

C. -e

D. -2e

9. 答案 C 解析 $x^{a+1}e^{x} + a\ln x \geq 0 \Leftrightarrow xe^{x} \geq \frac{-a\ln x}{x^{a}} = x^{-a}\ln x^{-a}$ ，即 $xe^{x} \geq \ln x^{-a}e^{\ln x^{-a}}$ ，令 $f(x) = xe^{x}$ ，则 $f(x)$ 在 $(1, +\infty)$ 单调递增，即 $f(x) \geq f(\ln x^{-a})$ ，即 $x \geq \ln x^{-a}$ ，∴ $-a \leq \frac{x}{\ln x}$ 。令 $g(x) = \frac{x}{\ln x}$ ，由导数法知 $g(x)_{\min} = g(e) = e$ ，∴ $a \geq -e$ 。故选 C。

10. 已知函数 $f(x) = 2x^{3}\ln x - (m - x)\mathrm{e}^{\frac{m}{x} - 1}$ ，当 $x \geq \mathbf{e}$ 时， $f(x) \geq 0$ 恒成立，则实数 $m$ 的取值范围为（）

A. $(- \infty, 4e]$

B. $(-∞, 3e]$

C. $(-∞, 2e]$

D. $(-∞,\frac{3e}{2}]$

10. 答案 解析 $f(x) \geq 0 \Leftrightarrow 2x^3 \ln x \geq (m - x)e^{\frac{m}{x} - 1} \Leftrightarrow 2x^2 \ln x \geq (\frac{m}{x} - 1)e^{\frac{m}{x} - 1} \Leftrightarrow x^2 \ln x^2 \geq (\frac{m}{x} - 1)e^{\frac{m}{x} - 1}$ ，即 $\ln x^{2}e^{\ln x^{2}} \geq (\frac{m}{x} - 1)e^{\frac{m}{x} - 1}$ ，令 $g(x) = xe^{x}$ ，则 $g(x)$ 在 $[e, +\infty)$ 单调递增，即 $g(\ln x^{2}) \geq g(\frac{m}{x} - 1)$ ，当 $m \leq 0$ 时， $\ln x^{2}e^{\ln x^{2}} \geq (\frac{m}{x} - 1)e^{\frac{m}{x} - 1}$ 恒成立，当 $m > 0$ 时， $\ln x^{2} \geq \frac{m}{x} - 1 \Rightarrow m \leq 2x \ln x + x$ ，令 $h(x) = 2x \ln x + x$ ，则

$h'(x)=2\ln x+3>0$ ，∴ $h(x)$ 在 $[e,+\infty)$ 上单调递增，∴ $h(x)_{\min}=h(e)=3e$ ．故选B.
