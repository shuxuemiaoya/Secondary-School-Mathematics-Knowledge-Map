# 专题三 三角形形状的判定问题

# 【方法总结】

# 利用正、余弦定理判断三角形形状的两种思路

(1)“角化边”：利用正弦、余弦定理把已知条件转化为只含边的关系，通过因式分解、配方等得出边的相应关系，从而判断三角形的形状.  
(2)“边化角”: 利用正弦、余弦定理把已知条件转化为只含内角的三角函数间的关系, 通过三角函数恒等变形, 得出内角的关系, 从而判断出三角形的形状, 此时要注意应用 $A + B + C = \pi$ 这个结论.

正(余)弦定理是转化的桥梁，无论使用哪种方法，都不要随意约掉公因式，要移项提取公因式，否则会有漏掉一种形状的可能．注意挖掘隐含条件，重视角的范围对三角函数值的限制．特别地，在 $\triangle ABC$ 中， $c$ 是最大的边，若 $c^{2}<a^{2}+b^{2}$ ，则 $\triangle ABC$ 是锐角三角形；若 $c^{2}=a^{2}+b^{2}$ ，则 $\triangle ABC$ 是直角三角形；若 $c^{2}>a^{2}+b^{2}$ ，则 $\triangle ABC$ 是钝角三角形．

# 【例题选讲】

[例 1](1)在 $\triangle ABC$ 中， $\cos^{2}\frac{B}{2}=\frac{a+c}{2c}(a,b,c$ 分别为角A，B，C的对边)，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 直角三角形

C. 等腰三角形或直角三角形

D. 等腰直角三角形

答案 B 解析 $\because\cos^{2}\frac{B}{2}=\frac{a+c}{2c},\therefore\frac{1+\cos B}{2}=\frac{a+c}{2c}$ ，即 $1+\cos B=\frac{a+c}{c}$ 。由余弦定理得 $1+\frac{a^{2}+c^{2}-b^{2}}{2ac}=\frac{a+c}{c}$ 。整理得 $c^{2}=a^{2}+b^{2}$ ，即 $\triangle ABC$ 为直角三角形。

(2)在 $\triangle ABC$ 中，若 $\tan A\tan B>1$ ，则 $\triangle ABC$ 是()

A. 锐角三角形

B. 直角三角形

C. 钝角三角形

D. 无法确定

答案 A 解析 因为 $A$ 和 $B$ 都为三角形中的内角，由 $\tan A\tan B > 1$ ，得 $1 - \tan A\tan B < 0$ ，且 $\tan A > 0$ ， $\tan B > 0$ ，即 $A, B$ 为锐角，所以 $\tan (A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B} < 0$ ，则 $A + B\in \left(\frac{\pi}{2},\pi\right)$ ，即 $C$ 为锐角，所以 $\triangle ABC$ 是锐角三角形.

(3)若 $\triangle ABC$ 的三个内角满足 $\sin A:\sin B:\sin C=5:11:13$ ,则 $\triangle ABC(\quad)$

A. 一定是锐角三角形

B. 一定是直角三角形

C. 一定是钝角三角形

D. 可能是锐角三角形，也可能是钝角三角形

答案 C 解析 根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，又 $\sin A: \sin B: \sin C = 5:11:13$ ， $\therefore a:b:c = 5:11:13$ ，设 $a = 5t, b = 11t, c = 13t (t \neq 0)$ ， $\because c^2 = a^2 + b^2 - 2ab\cos C$ ， $\therefore \cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{25t^2 + 121t^2 - 169t^2}{2\times 5t\times 11t} = -\frac{23}{110} < 0$ ， $\therefore$ 角 $C$ 为钝角．故选 C.

(4) $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，若 $a\cos B + a\cos C = b + c$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 锐角三角形

C. 钝角三角形

D. 直角三角形

答案 D 解析 法一：由余弦定理及已知得 $a \times \frac{a^{2} + c^{2} - b^{2}}{2ac} + a \times \frac{a^{2} + b^{2} - c^{2}}{2ab} = b + c$ ，所以 $a^{2}b + c^{2}b - b^{3} + a^{2}c + b^{2}c - c^{3} = 2b^{2}c + 2bc^{2}$ ，得 $b^{2} + c^{2} = a^{2}$ ，故 $A = 90^{\circ}$ ，所以 $\triangle ABC$ 为直角三角形.

法二:由正弦定理得 $a\cos B + a\cos C = b + c$ ，即 $\sin A\cos B + \sin A\cos C = \sin B + \sin C$ ，即 $\sin A\cos B + \sin A\cos C = \sin(A + C) + \sin(A + B)$ ，化简得 $\cos A(\sin B + \sin C) = 0$ ，在 $\triangle ABC$ 中， $\sin B + \sin C \neq 0$ ，则 $\cos A = 0$ ，所以 $\triangle ABC$ 为直角三角形.

(5)在 $\triangle ABC$ 中，若 $(a^{2}+b^{2})\sin(A-B)=(a^{2}-b^{2})\cdot\sin(A+B)$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形

答案 C 解析 $\because(a^{2}+b^{2})\sin(A-B)=(a^{2}-b^{2})\sin(A+B)$ ， $\therefore b^{2}[\sin(A+B)+\sin(A-B)]=a^{2}[\sin(A+B)-\sin(A-B)]$ ， $\therefore2\sin A\cos B\cdot b^{2}=2\cos A\sin B\cdot a^{2}$ ，即 $a^{2}\cos A\sin B=b^{2}\sin A\cos B$ .

方法一 由正弦定理知 $a = 2R\sin A, b = 2R\sin B, \therefore \sin^2 A\cos A\sin B = \sin^2 B\sin A\cos B$ ，又 $\sin A \cdot \sin B \neq 0, \therefore \sin A\cos A = \sin B\cos B, \therefore \sin 2A = \sin 2B$ 。在 $\triangle ABC$ 中， $0 < 2A < 2\pi, 0 < 2B < 2\pi, \therefore 2A = 2B$ 或 $2A = \pi - 2B, \therefore A = B$ 或 $A + B = \frac{\pi}{2}$ 。 $\triangle ABC$ 为等腰三角形或直角三角形。

方法二 由正弦定理、余弦定理得： $a^{2}b\frac{b^{2}+c^{2}-a^{2}}{2bc}=b^{2}a\frac{a^{2}+c^{2}-b^{2}}{2ac}, \therefore a^{2}(b^{2}+c^{2}-a^{2})=b^{2}(a^{2}+c^{2}-b^{2}),$ $\therefore(a^{2}-b^{2})(a^{2}+b^{2}-c^{2})=0,$ $\therefore a^{2}-b^{2}=0$ 或 $a^{2}+b^{2}-c^{2}=0$ ．即 a=b 或 $a^{2}+b^{2}=c^{2}$ ．∴△ABC 为等腰三角形或直角三角形.

(6)在 $\triangle ABC$ 中， $a, b, c$ 分别为内角 $A, B, C$ 的对边，若 $\tan A: \tan B = a^2: b^2$ ，则 $\triangle ABC$ 的形状为（）

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形

答案 C 解析 因为 $\frac{\sin A}{\cos A} : \frac{\sin B}{\cos B} = a^2 : b^2 = \sin^2 A : \sin^2 B$ ，所以 $\frac{\sin A \cos B}{\cos A \sin B} = \frac{\sin^2 A}{\sin^2 B}$ ，整理得 $\sin 2A = \sin 2B$ ，所以 $2A = 2B$ 或 $2A + 2B = \pi$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$ ，所以 $\triangle ABC$ 为等腰三角形或直角三角形.

(7)在 $\triangle ABC$ 中，若 $b^{2}\sin^{2}C+c^{2}\sin^{2}B=2bc\cos B\cdot\cos C$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形

答案 D 解析 法一：由 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ ，则条件化为： $4R^2\sin^2 C\cdot \sin^2 B + 4R^2\sin^2 C\cdot \sin^2 B = 8R^2\sin B\cdot \sin C\cdot \cos B\cdot \cos C$ 。又 $\sin B\cdot \sin C \neq 0$ ， $\therefore \sin B\cdot \sin C = \cos B\cos C$ ，即 $\cos (B + C) = 0$ 。又 $0^\circ < B + C < 180^\circ$ ， $\therefore B + C = 90^\circ$ ， $\therefore A = 90^\circ$ ，故 $\triangle ABC$ 为直角三角形。

法二：将已知等式变形为： $b^{2}(1-\cos^{2}C)+c^{2}(1-\cos^{2}B)=2bc\cos B\cdot\cos C$ ，即 $b^{2}+c^{2}-b^{2}\cdot\left(\frac{a^{2}+b^{2}-c^{2}}{2ab}\right)^{2}-c^{2}\cdot\left(\frac{a^{2}+c^{2}-b^{2}}{2ac}\right)^{2}=2bc\cdot\frac{a^{2}+c^{2}-b^{2}}{2ac}\cdot\frac{a^{2}+b^{2}-c^{2}}{2ab}$ ，即 $b^{2}+c^{2}=\frac{[(a^{2}+b^{2}-c^{2})+(a^{2}+c^{2}-b^{2})]^{2}}{4a^{2}}=\frac{4a^{4}}{4a^{2}}=a^{2},\therefore A=90^{\circ},$ ∴△ABC 为直角三角形.

(8)在 $\triangle ABC$ 中，已知 $(a+b+c)(a+b-c)=3ab$ ，且 $2\cos A\sin B=\sin C$ ，则 $\triangle ABC$ 的形状为()

A. 正三角形

B. 直角三角形

C. 等腰三角形

D. 等腰直角三角形

答案 A 解析 法一：由正弦定理得 $\frac{\sin C}{\sin B} = \frac{c}{b}$ ，由 $2\cos A\sin B = \sin C$ ，有 $\cos A = \frac{\sin C}{2\sin B} = \frac{c}{2b}$ 。又由余弦定理得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$ ，所以 $\frac{c}{2b} = \frac{b^2 + c^2 - a^2}{2bc}$ ，即 $c^2 = b^2 + c^2 - a^2$ ，所以 $a^2 = b^2$ ，所以 $a = b$ 。又因为 $(a + b + c)(a + b - c) = 3ab$ ，所以 $(a + b)^2 - c^2 = 3ab$ ，所以 $4b^2 - c^2 = 3b^2$ ，即 $b^2 = c^2$ 。所以 $b = c$ ，所以 $a = b = c$ 。所

以 $\triangle ABC$ 为等边三角形.

法二：因为 $A + B + C = 180^{\circ}$ ，所以 $\sin C = \sin (A + B)$ ，又因为 $2\cos A\sin B = \sin C$ ，所以 $2\cos A\sin B = \sin A\cos B + \cos A\sin B$ ，所以 $\sin (A - B) = 0$ 。又因为 $A$ 与 $B$ 均为 $\triangle ABC$ 的内角，所以 $A = B$ 。又由 $(a + b + c)(a + b - c) = 3ab$ 得 $(a + b)^{2} - c^{2} = 3ab$ ，所以 $a^2 +b^2 -c^2 +2ab = 3ab$ ，即 $a^2 +b^2 -c^2 = ab$ 。由余弦定理，得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{ab}{2ab} = \frac{1}{2}$ 又 $0^{\circ} <   C <   180^{\circ}$ ，所以 $C = 60^{\circ}$ 。所以 $\triangle ABC$ 为等边三角形。

(9)在 $\triangle ABC$ 中，已知 $2a\cos B=c$ ， $\sin A\sin B(2-\cos C)=\sin^{2}\frac{C}{2}+\frac{1}{2}$ ，则 $\triangle ABC$ 为( )

A. 等边三角形

B. 等腰直角三角形

C. 锐角非等边三角形

D. 钝角三角形

答案 B 解析 由 $2a\cos B = c \Rightarrow 2a \cdot \frac{a^2 + c^2 - b^2}{2ac} = c \Rightarrow a^2 = b^2$ ，所以 $a = b$ 。因为 $\sin A \sin B(2 - \cos C) = \sin^2 \frac{C}{2} + \frac{1}{2}$ ，所以 $2\sin A \sin B(2 - \cos C) - 2 + 1 - 2\sin^2 \frac{C}{2} = 0$ ，所以 $2\sin A \sin B(2 - \cos C) - 2 + \cos C = 0$ ，所以 $(2 - \cos C)(2\sin A \sin B - 1) = 0$ ，因为 $\cos C \neq 2$ ，所以 $\sin A \sin B = \frac{1}{2}$ ，因为 $a = b$ ，所以 $\sin^2 A = \frac{1}{2}$ ，所以 $A = B = \frac{\pi}{4}$ ，所以 $\triangle ABC$ 是等腰直角三角形，故选 B.

(10)已知 $a, b, c$ 分别是 $\triangle ABC$ 三个内角 $A, B, C$ 的对边．下列四个命题：

①若 $\tan A + \tan B + \tan C > 0$ ，则 $\triangle ABC$ 是锐角三角形；  
②若 $a \cos A = b \cos B$ ，则 $\triangle ABC$ 是等腰三角形；  
③若 $b \cos C + c \cos B = b$ ，则 $\triangle ABC$ 是等腰三角形；  
④若 $\frac{a}{\cos A}=\frac{b}{\cos B}=\frac{c}{\cos C}$ ，则 $\triangle ABC$ 是等边三角形.

其中正确的命题是\_\_\_\_．(填上所有正确命题的序号)

答案 ①③④ 解析 命题①: $\because \tan A + \tan B + \tan C = \tan A \tan B \tan C > 0, \therefore A, B, C$ 均为锐角, $\therefore$ ① 正确; 命题②: 由 $a \cos A = b \cos B$ , 可得 $\sin 2A = \sin 2B, \therefore A = B$ 或 $A + B = \frac{\pi}{2}, \therefore$ ② 错; 命题③: 可知 $\sin B \cos C + \sin C \cos B = \sin B, \therefore \sin A = \sin B, \therefore A = B, \therefore$ ③ 正确; 命题④: 由已知和正弦定理, 易知 $\tan A = \tan B = \tan C, \therefore$ ④ 正确.

# 【对点训练】

1. 在 $\triangle ABC$ 中， $\sin^2\frac{A}{2} = \frac{c - b}{2c}$ ，则 $\triangle ABC$ 的形状为（）

A. 正三角形

B. 直角三角形

C. 等腰直角三角形

D. 等腰三角形

1. 答案 B 解析 $\because \sin^{2}\frac{A}{2}=\frac{1-\cos A}{2}=\frac{c-b}{2c},\quad\therefore \cos A=\frac{b}{c}=\frac{b^{2}+c^{2}-a^{2}}{2bc},\quad\therefore a^{2}+b^{2}=c^{2}$ ，符合勾股定理．∴△ABC为直角三角形.

2. 在 $\triangle ABC$ 中， $\cos \frac{A}{2} = \sqrt{\frac{1 + \cos B}{2}}$ ，则 $\triangle ABC$ 一定是（）

A. 等腰三角形

B. 直角三角形

C. 等腰直角三角形

D. 无法确定

2. 答案 A 解析 由已知得 $\cos^2\frac{A}{2} = \frac{1 + \cos B}{2}$ , $\therefore 2\cos^2\frac{A}{2} - 1 = \cos B$ , $\therefore \cos A = \cos B$ , 又 $0 < A, B < \pi$ , $\therefore A = B$ , $\therefore \triangle ABC$ 为等腰三角形.

3. 在 $\triangle ABC$ 中，角 $A, B, C$ 所对的边分别为 $a, b, c$ ，若 $\frac{c}{b}<\cos A$ ，则 $\triangle ABC$ 为( )

A. 钝角三角形

B. 直角三角形

C. 锐角三角形

D. 等边三角形

3. 答案 A 解析 根据正弦定理得 $\frac{c}{b} = \frac{\sin C}{\sin B} < \cos A$ ，即 $\sin C < \sin B \cos A$ ， $\because A + B + C = \pi$ ， $\therefore \sin C = \sin (A + B) < \sin B \cos A$ ，整理得 $\sin A \cos B < 0$ ，又三角形中 $\sin A > 0$ ， $\therefore \cos B < 0$ ， $\frac{\pi}{2} < B < \pi$ 。 $\therefore \triangle ABC$ 为钝角三角形.

4. 在 $\triangle ABC$ 中, $a\cos A = b\cos B$ , 则这个三角形的形状为( )

A. 等腰三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形

4. 答案 等腰三角形或直角三角形 解析 由正弦定理，得 $\sin A\cos A = \sin B\cos B$ ，即 $\sin 2A = \sin 2B$ 所以 $2A = 2B$ 或 $2A = \pi - 2B$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$ ，所以这个三角形为等腰三角形或直角三角形.

5. 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ . 已知 $2\sin A\cos B=\sin C$ ，则 $\triangle ABC$ 的形状为( )

A. 等边三角形

B. 等腰三角形

C. 直角三角形

D. 等腰直角三角形

5. 答案 B 解析 $\because 2\sin A\cos B = \sin C = \sin (A + B), \therefore 2\sin A\cos B = \sin A\cos B + \cos A\sin B, \therefore \sin (A - B) = 0.$ 又 $A, B$ 为 $\triangle ABC$ 的内角. $\therefore A = B, \therefore \triangle ABC$ 为等腰三角形.

6. 在 $\triangle ABC$ 中， $\sin A: \sin B: \sin C=2:4:5$ ，则 $\triangle ABC$ 的形状为( )

A. 钝角三角形

B. 直角三角形

C. 锐角三角形

D. 等边三角形

6. 答案 A 解析 因为 $a:b:c=\sin A:\sin B:\sin C=2:4:5$ ，所以可令 a=2k, b=4k, $c=5k(k>0)$ .
c 最大， $\cos C=\frac{(2k)^{2}+(4k)^{2}-(5k)^{2}}{2\times2k\times4k}<0$ ，所以 C 为钝角，从而三角形为钝角三角形.

7. 在 $\triangle ABC$ 中, $\lg (\sin A + \sin C) = 2\lg \sin B - \lg (\sin C - \sin A)$ , 则 $\triangle ABC$ 的形状为( )

A. 等边三角形

B. 等腰三角形

C. 直角三角形

7. 答案 C 解析 由已知条件，得 $\lg (\sin A + \sin C) + \lg (\sin C - \sin A) = \lg \sin^2 B$ 。 $\therefore \sin^2 C - \sin^2 A = \sin^2 B$ ，由正弦定理可得 $c^2 = a^2 + b^2$ 。故三角形为直角三角形。

9. 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ . 已知三个向量 $m = \left(a, \cos \frac{A}{2}\right)$ , $n = \left(b, \cos \frac{B}{2}\right)$ , $p = \left(c, \cos \frac{C}{2}\right)$ 共线，则 $\triangle ABC$ 的形状为（）

10. (2013·陕西)设 $\triangle ABC$ 的内角 $A, B, C$ 所对的边分别为 $a, b, c$ , 若 $b\cos C + c\cos B = a\sin A$ , 则 $\triangle ABC$ 的形状为( )

11. 在 $\triangle ABC$ 中, 若 $c - a\cos B = (2a - b)\cos A$ , 则 $\triangle ABC$ 的形状为( )

D. 直角三角形

11. 答案 C 解析 $\because c - a\cos B = (2a - b)\cos A, C = \pi - (A + B), \therefore$ 由正弦定理得 $\sin C - \sin A\cos B = 2\sin A\cos A - \sin B\cos A, \therefore \sin A\cos B + \cos A\sin B - \sin A\cos B = 2\sin A\cos A - \sin B\cos A, \therefore \cos A(\sin B - \sin A) = 0, \therefore \cos A = 0$ 或 $\sin B = \sin A, \therefore A = \frac{\pi}{2}$ 或 $B = A$ 或 $B = \pi - A$ (舍去), $\therefore \triangle ABC$ 为等腰或直角三角形.

12. 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ ．已知 $a^{2}+b^{2}-c^{2}=ab$ ，且 $2\cos A\sin B=\sin C$ ，则 $\triangle ABC$ 的形状为( )

A. 等边三角形

B. 等腰三角形

C. 直角三角形

D. 等腰直角三角形

12. 答案 A 解析 $\because a^{2} + b^{2} - c^{2} = ab, \therefore \cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} = \frac{1}{2}$ , 又 $0 < C < \pi, \therefore C = \frac{\pi}{3}$ , 又由 $2\cos A\sin B = \sin C$ 得 $\sin (B - A) = 0, \therefore A = B$ , 故 $\triangle ABC$ 为等边三角形.

13. 在 $\triangle ABC$ 中，内角 $A, B, C$ 所对的边分别是 $a, b, c$ ，若直线 $bx + y\cos A + \cos B = 0$ 与 $ax + y\cos B + \cos A = 0$ 平行，则 $\triangle ABC$ 一定是（）

A. 锐角三角形

B. 等腰三角形

C. 直角三角形

D. 等腰或者直角三角形

13. 答案 C 解析 由两直线平行可得 $b \cos B - a \cos A = 0$ ，由正弦定理可知 $\sin B \cos B - \sin A \cos A = 0$ ，即 $\frac{1}{2} \sin 2A = \frac{1}{2} \sin 2B$ ，又 $A, B \in (0, \pi)$ ，且 $A + B \in (0, \pi)$ ，所以 $2A = 2B$ 或 $2A + 2B = \pi$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$ 。若 $A = B$ ，则 $a = b$ ， $\cos A = \cos B$ ，此时两直线重合，不符合题意，舍去，故 $A + B = \frac{\pi}{2}$ ，则 $\triangle ABC$ 是直角三角形。故选 C.

14. 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ ，若 $\frac{\sin A}{\sin B} = \frac{a}{c}, (b + c + a)(b + c - a) = 3bc$ ，则 $\triangle ABC$ 的形状为（）

A. 直角三角形

B. 等腰非等边三角形

C. 等边三角形

D. 钝角三角形

14. 答案 C 解析 因为 $\frac{\sin A}{\sin B} = \frac{a}{c}$ ，所以 $\frac{a}{b} = \frac{a}{c}$ ，所以 b = c。又 $(b + c + a)(b + c - a) = 3bc$ ，所以 $b^{2} + c^{2} - a^{2} = bc$ ，所以 $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = \frac{bc}{2bc} = \frac{1}{2}$ 。因为 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ ，所以 $\triangle ABC$ 是等边三角形。

15. 在 $\triangle ABC$ 中， $\sin^{2}A=\sin^{2}B+\sin^{2}C$ ，且 $\sin A=2\sin B\cdot\cos C$ ，则 $\triangle ABC$ 的形状为( )

A. 等边三角形

B. 等腰三角形

C. 直角三角形

D. 等腰直角三角形

15. 答案 D 解析 由正弦定理，得 $\sin A = \frac{a}{2R}$ ， $\sin B = \frac{b}{2R}$ ， $\sin C = \frac{c}{2R}$ ， $\because \sin^2 A = \sin^2 B + \sin^2 C$ ， $\therefore \left(\frac{a}{2R}\right)^2$

$= \left(\frac{b}{2R}\right)^2 + \left(\frac{c}{2R}\right)^2$ ，即 $a^2 = b^2 + c^2$ ，故 $A = 90^\circ$ ， $\therefore C = 90^\circ - B$ ， $\cos C = \sin B$ 。 $\therefore 2\sin B \cdot \cos C = 2\sin^2 B = \sin A = 1$ 。 $\therefore \sin B = \frac{\sqrt{2}}{2}$ 。 $\therefore B = 45^\circ$ 或 $B = 135^\circ (A + B = 225^\circ > 180^\circ$ ，故舍去)， $\therefore \triangle ABC$ 是等腰直角三角形.

16. 在 $\triangle ABC$ 中，若 $\frac{b\cos C}{c\cos B} = \frac{1 + \cos 2C}{1 + \cos 2B}$ ，则 $\triangle ABC$ 为（）

A. 锐角三角形

B. 等腰三角形

C. 直角三角形

D. 等腰或者直角三角形

16. 答案 D 解析 由已知 $\frac{1 + \cos 2C}{1 + \cos 2B} = \frac{2\cos^2 C}{2\cos^2 B} = \frac{\cos^2 C}{\cos^2 B} = \frac{b\cos C}{c\cos B}$ 得 $\frac{\cos C}{\cos B} = \frac{b}{c}$ ，以下可有两种解法：

法一：(利用正弦定理边化角)由正弦定理得 $\frac{b}{c}=\frac{\sin B}{\sin C},\quad\therefore\frac{\cos C}{\cos B}=\frac{\sin B}{\sin C}$ ，即 $\sin C\cos C=\sin B\cos B$ ，即 $\sin 2C=\sin 2B,\because B、C$ 均为 $\triangle ABC$ 的内角， $\therefore2C=2B$ 或 $2C+2B=180^{\circ}$ . $\therefore B=C$ 或 $B+C=90^{\circ}$ ， $\therefore\triangle ABC$ 为等腰三角形或直角三角形.

法二：(利用余弦定理角化边)由余弦定理得 $\frac{(a^{2}+b^{2}-c^{2})\cdot2ac}{(a^{2}+c^{2}-b^{2})\cdot2ab}=\frac{b}{c}$ ，即 $a^{2}(b^{2}-c^{2})=(b^{2}+c^{2})(b^{2}-c^{2})$ ，解得 $a^{2}=b^{2}+c^{2}$ 或 $b^{2}=c^{2}$ (即b=c)，

17. 在 $\triangle ABC$ 中，内角 $A, B, C$ 所对的边分别为 $a, b, c$ ，若 $a^{2}=b^{2}+c^{2}-bc$ ，且 $\sin B=\sqrt{3}\cos C$ ，则下列结论中正确的是( )

A. $A=\frac{\pi}{6}$

B. $c = 2a$

C. $C=\frac{\pi}{2}$

D. $\triangle ABC$ 是等边三角形

17. 答案 D 解析 在 $\triangle ABC$ 中，由 $a^2 = b^2 + c^2 - bc$ ，得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{1}{2}$ ， $\therefore A = 60^\circ$ 。 $\because \sin B = \sqrt{3} \cos C, \therefore \sin (120^\circ - C) = \sqrt{3} \cos C$ ，可得 $\frac{\sqrt{3}}{2} \cos C + \frac{1}{2} \sin C = \sqrt{3} \cos C$ ，即 $\tan C = \sqrt{3}$ . $\therefore C = 60^\circ$ 。 $\therefore \triangle ABC$ 是等边三角形.

18. 已知 $\triangle ABC$ 的三个内角 $A, B, C$ 的对边分别为 $a, b, c$ , 若 $\frac{\cos A}{\cos B} = \frac{b}{a} = \sqrt{2}$ , 则该三角形的形状是( )

A. 直角三角形

B. 等腰三角形

C. 等边三角形

D. 钝角三角形

18. 答案 A 解析 因为 $\frac{\cos A}{\cos B} = \frac{b}{a}$ ，由正弦定理得 $\frac{\cos A}{\cos B} = \frac{\sin B}{\sin A}$ ，所以 $\sin 2A = \sin 2B$ 。由 $\frac{b}{a} = \sqrt{2}$ ，可知 $a \neq b$ ，所以 $A \neq B$ 。又 $A, B \in (0, \pi)$ ，所以 $2A = 180^{\circ} - 2B$ ，即 $A + B = 90^{\circ}$ ，所以 $C = 90^{\circ}$ ，于是 $\triangle ABC$ 是直角三角形。故选 A。

19. 已知 $\triangle ABC$ 中, 内角 $A 、 B 、 C$ 成等差数列, 其对边为 $a 、 b 、 c$ , 若 $a 、 b 、 c$ 成等比数列, 则 $\triangle ABC$ 的形状为 ( )

A. 等腰三角形

B. 等边三角形

C. 直角三角形

D. 钝角三角形

19. 答案 B 解析 ∵ 内角 A、B、C 成等差数列，∴ $A + C = 2B$ 。又 $A + B + C = \pi$ 。∴ $B = \frac{\pi}{3}$ ，由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac \cdot \cos B = a^{2} + c^{2} - ac$ 。又 $b^{2} = ac$ ，∴ $a^{2} + c^{2} - ac = ac$ ，即 $(a - c)^{2} = 0$ ，∴ a = c，又 $B = \frac{\pi}{3}$ ，∴ $\triangle ABC$ 为等边三角形；选 B。

20. 如果 $\triangle A_{1}B_{1}C_{1}$ 的三个内角的余弦值分别等于 $\triangle A_{2}B_{2}C_{2}$ 的三个内角的正弦值，则（ ）
