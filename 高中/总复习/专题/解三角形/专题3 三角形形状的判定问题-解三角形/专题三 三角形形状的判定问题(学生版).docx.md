# 专题三 三角形形状的判定问题

# 【方法总结】

# 利用正、余弦定理判断三角形形状的两种思路  
（1）“角化边”：利用正弦、余弦定理把已知条件转化为只含边的关系，通过因式分解、配方等得出边的相应关系，从而判断三角形的形状.  
（2）“边化角”: 利用正弦、余弦定理把已知条件转化为只含内角的三角函数间的关系, 通过三角函数恒等变形, 得出内角的关系, 从而判断出三角形的形状, 此时要注意应用 $A + B + C = \pi$ 这个结论.

正(余)弦定理是转化的桥梁，无论使用哪种方法，都不要随意约掉公因式，要移项提取公因式，否则会有漏掉一种形状的可能．注意挖掘隐含条件，重视角的范围对三角函数值的限制．特别地，在 $\triangle ABC$ 中， $c$ 是最大的边，若 $c^{2}<a^{2}+b^{2}$ ，则 $\triangle ABC$ 是锐角三角形；若 $c^{2}=a^{2}+b^{2}$ ，则 $\triangle ABC$ 是直角三角形；若 $c^{2}>a^{2}+b^{2}$ ，则 $\triangle ABC$ 是钝角三角形．

A. 锐角三角形

B. 直角三角形

C. 钝角三角形

D. 无法确定  
（3）若 $\triangle ABC$ 的三个内角满足 $\sin A:\sin B:\sin C=5:11:13$ ,则 $\triangle ABC(\quad)$

A. 一定是锐角三角形

B. 一定是直角三角形

C. 一定是钝角三角形

D. 可能是锐角三角形，也可能是钝角三角形  
（4） $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，若 $a\cos B + a\cos C = b + c$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 锐角三角形

C. 钝角三角形

D. 直角三角形
答案 D 解析 法一：由余弦定理及已知得 $a \times \frac{a^{2} + c^{2} - b^{2}}{2ac} + a \times \frac{a^{2} + b^{2} - c^{2}}{2ab} = b + c$ ，所以 $a^{2}b + c^{2}b - b^{3} + a^{2}c + b^{2}c - c^{3} = 2b^{2}c + 2bc^{2}$ ，得 $b^{2} + c^{2} = a^{2}$ ，故 $A = 90^{\circ}$ ，所以 $\triangle ABC$ 为直角三角形.  
（5）在 $\triangle ABC$ 中，若 $(a^{2}+b^{2})\sin(A-B)=(a^{2}-b^{2})\cdot\sin(A+B)$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形  
（6）在 $\triangle ABC$ 中， $a, b, c$ 分别为内角 $A, B, C$ 的对边，若 $\tan A: \tan B = a^2: b^2$ ，则 $\triangle ABC$ 的形状为（）

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形
答案 C 解析 因为 $\frac{\sin A}{\cos A}:\frac{\sin B}{\cos B}=a^{2}:b^{2}=\sin^{2}A:\sin^{2}B$ ，所以 $\frac{\sin A\cos B}{\cos A\sin B}=\frac{\sin^{2}A}{\sin^{2}B}$ ，整理得 $\sin 2A=\sin 2B$ ，所以 2A=2B 或 $2A+2B=\pi$ ，即 A=B 或 $A+B=\frac{\pi}{2}$ ，所以 $\triangle ABC$ 为等腰三角形或直角三角形.  
（7）在 $\triangle ABC$ 中，若 $b^{2}\sin^{2}C+c^{2}\sin^{2}B=2bc\cos B\cdot\cos C$ ，则 $\triangle ABC$ 的形状为()

A. 等边三角形

B. 等腰直角三角形

C. 等腰三角形或直角三角形

D. 直角三角形  
（8）在 $\triangle ABC$ 中，已知 $(a+b+c)(a+b-c)=3ab$ ，且 $2\cos A\sin B=\sin C$ ，则 $\triangle ABC$ 的形状为()

A. 正三角形

B. 直角三角形

C. 等腰三角形

D. 等腰直角三角形  
（9）在 $\triangle ABC$ 中，已知 $2a\cos B=c$ ， $\sin A\sin B(2-\cos C)=\sin^{2}\frac{C}{2}+\frac{1}{2}$ ，则 $\triangle ABC$ 为( )

A. 等边三角形

B. 等腰直角三角形

C. 锐角非等边三角形

D. 钝角三角形  
（10）已知 a, b, c 分别是 $\triangle ABC$ 三个内角 A, B, C 的对边．下列四个命题：

①若 $\tan A + \tan B + \tan C > 0$ ，则 $\triangle ABC$ 是锐角三角形；  
②若 $a \cos A = b \cos B$ ，则 $\triangle ABC$ 是等腰三角形；  
③若 $b \cos C + c \cos B = b$ ，则 $\triangle ABC$ 是等腰三角形；  
④若 $\frac{a}{\cos A}=\frac{b}{\cos B}=\frac{c}{\cos C}$ ，则 $\triangle ABC$ 是等边三角形.
