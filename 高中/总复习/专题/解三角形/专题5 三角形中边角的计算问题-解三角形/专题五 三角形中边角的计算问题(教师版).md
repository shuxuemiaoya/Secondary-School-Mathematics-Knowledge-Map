# 专题五 三角形中边角的计算问题

三角形中基本量的计算问题主要考查正弦定理、余弦定理及三角形面积公式，最简单的问题是只用正弦定理或余弦定理即可解决。中等难度的问题要结合三角恒等变换再用正弦定理或余弦定理即可解决。难度较大的问题要结合三角恒等变换并同时用正弦定理、余弦定理和面积公式才能解决。

# 【方法总结】

# 三角形中基本量的计算问题的解题技巧
在处理三角形中的边角关系时，一般全部化为角的关系，或全部化为边的关系。若出现边的一次式一般采用到正弦定理，出现边的二次式一般采用到余弦定理。若已知条件同时含有边和角，但不能直接使用正弦定理或余弦定理得到答案，要选择“边化角”或“角化边”，变换原则如下：  
（1）若式子中含有正弦的齐次式，优先考虑正弦定理“角化边”，然后进行代数式变形；  
（2）若式子中含有 a, b, c 的齐次式，优先考虑正弦定理“边化角”，然后进行三角恒等变换；  
（3）若式子中含有余弦的齐次式，优先考虑余弦定理“角化边”，然后进行代数式变形；  
（4）含有面积公式的问题，要考虑结合余弦定理求解；  
（5）同时出现两个自由角（或三个自由角）时，要用到三角形的内角和定理.

# 【例题选讲】

[例 1](2020·天津)在 $\triangle ABC$ 中，角 A, B, C 所对的边分别为 a, b, c. 已知 $a=2\sqrt{2}$ , b=5, $c=\sqrt{13}$ .  
（1）求角 C 的大小;  
（2）求 $\sin A$ 的值；  
（3）求 $\sin \left(2A + \frac{\pi}{4}\right)$ 的值.
解析 （1）在 $\triangle ABC$ 中，由余弦定理及 $a=2\sqrt{2}$ ， $b=5$ ， $c=\sqrt{13}$ ，得 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=\frac{\sqrt{2}}{2}$ . 又因为 $C\in(0,\pi)$ ，所以 $C=\frac{\pi}{4}$ .  
（2）在 $\triangle ABC$ 中，由正弦定理及 $C=\frac{\pi}{4}$ ， $a=2\sqrt{2}$ ， $c=\sqrt{13}$ ，可得 $\sin A=\frac{a\sin C}{c}=\frac{2\sqrt{13}}{13}$ .  
（3）由 $a < c$ 及 $\sin A = \frac{2\sqrt{13}}{13}$ ，可得 $\cos A = \sqrt{1 - \sin^2 A} = \frac{3\sqrt{13}}{13}$ ，
进而 $\sin2A=2\sin A\cos A=\frac{12}{13}$ ， $\cos2A=2\cos^{2}A-1=\frac{5}{13}$ .
所以 $\sin\left(2A+\frac{\pi}{4}\right)=\sin2A\cos\frac{\pi}{4}+\cos2A\sin\frac{\pi}{4}=\frac{12}{13}\times\frac{\sqrt{2}}{2}+\frac{5}{13}\times\frac{\sqrt{2}}{2}=\frac{17\sqrt{2}}{26}.$

[例 2](2019·全国 I )△ABC 的内角 A, B, C 的对边分别为 a, b, c. 设 $(\sin B-\sin C)^{2}=\sin^{2}A-\sin B\sin C$ .  
（1）求 $A$ ;   
（2）若 $\sqrt{2} a + b = 2c$ ，求 $\sin C$
解析 （1）由已知得 $\sin^{2}B + \sin^{2}C - \sin^{2}A = \sin B \sin C$ ，故由正弦定理得 $b^{2} + c^{2} - a^{2} = bc$ .
由余弦定理得 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{1}{2}$ . 因为 $0^{\circ}<A<180^{\circ}$ ，所以 $A=60^{\circ}$ .  
（2）由（1）知 $B=120^{\circ}-C$ ，由题设及正弦定理得 $\sqrt{2}\sin A+\sin(120^{\circ}-C)=2\sin C$ ,
即 $\frac{\sqrt{6}}{2} +\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C = 2\sin C$ ，可得 $\underline{\cos(C + 60^{\circ}) = -\frac{\sqrt{2}}{2}}$ ，因为 $0^{\circ} <   C <   120^{\circ}$ ，所以 $\underline{\sin(C + 60^{\circ}) = \frac{\sqrt{2}}{2}}$ 故 $\sin C = \sin (C + 60^{\circ} - 60^{\circ}) = \underline{\sin(C + 60^{\circ})\cos 60^{\circ} - \cos(C + 60^{\circ})\sin 60^{\circ}} = \frac{\sqrt{6} + \sqrt{2}}{4}.$

[例 3] (2018·天津) 在 $\triangle ABC$ 中，内角 $A, B, C$ 所对的边分别为 $a, b, c$ . 已知 $b \sin A = a \cos \left( B - \frac{\pi}{6} \right)$ .  
（1）求角 B 的大小;  
（2）设 $a = 2$ ， $c = 3$ ，求 $b$ 和 $\sin (2A - B)$ 的值.
解析 （1） 在 $\triangle ABC$ 中，由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，得 $b \sin A = a \sin B$
又由 $b\sin A = a\cos\left(\frac{B - \pi}{6}\right)$ ，得 $a\sin B = a\cos\left(\frac{B - \pi}{6}\right)$ ，即 $\sin B = \cos\left(\frac{B - \pi}{6}\right)$ ，可得 $\tan B = \sqrt{3}$ .
又因为 $B \in (0, \pi)$ ，可得 $B = \frac{\pi}{3}$ .  
（2）在 $\triangle ABC$ 中，由余弦定理及 $a=2$ ， $c=3$ ， $B=\frac{\pi}{3}$ ，有 $b^{2}=a^{2}+c^{2}-2ac\cos B=7$ ，故 $b=\sqrt{7}$ .
由 $b\sin A = a\cos \left(B - \frac{\pi}{6}\right)$ ，可得 $\sin A = \frac{\sqrt{3}}{\sqrt{7}}$ . 因为 $a < c$ ，故 $\cos A = \frac{2}{\sqrt{7}}$ .
因此 $\sin2A=2\sin A\cos A=\frac{4\sqrt{3}}{7}$ ， $\cos2A=2\cos^{2}A-1=\frac{1}{7}$ .
所以， $\sin(2A-B)=\sin2A\cos B-\cos2A\sin B=\frac{4\sqrt{3}}{7}\times\frac{1}{2}-\frac{1}{7}\times\frac{\sqrt{3}}{2}=\frac{3\sqrt{3}}{14}.$

[例 4]在 $\triangle ABC$ 中，角 $A$ ， $B$ ， $C$ 所对的边分别是 $a$ ， $b$ ， $c$ ，且 $\frac{\cos A}{a}+\frac{\cos B}{b}=\frac{\sin C}{c}$ .  
（1）证明： $\sin A\sin B=\sin C;$  
（2）若 $b^{2}+c^{2}-a^{2}=\frac{6}{5}bc$ ，求 $\tan B$ .
解析 （1）根据正弦定理，可设 $\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=k(k>0)$ ,
则 $a=k\sin A,\quad b=k\sin B,\quad c=k\sin C$ ，代入 $\frac{\cos A}{a}+\frac{\cos B}{b}=\frac{\sin C}{c}$ 中，有
$\frac{\cos A}{k \sin A} + \frac{\cos B}{k \sin B} = \frac{\sin C}{k \sin C}$ , 变形可得 $\sin A \sin B = \sin A \cos B + \cos A \sin B = \sin (A + B)$ .
在 $\triangle ABC$ 中，由 $A + B + C = \pi$ ，有 $\sin (A + B) = \sin (\pi -C) = \sin C$ 。所以 $\sin A\sin B = \sin C$  
（2）由已知， $b^{2}+c^{2}-a^{2}=\frac{6}{5}bc$ ，根据余弦定理，有 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{3}{5}$ .
所以 $\sin A=\sqrt{1-\cos^{2}A}=\frac{4}{5}$ . 由（1）知， $\sin A\sin B=\sin A\cos B+\cos A\sin B$ ,
所以 $\frac{4}{5}\sin B=\frac{4}{5}\cos B+\frac{3}{5}\sin B.$ 故 $\tan B=\frac{\sin B}{\cos B}=4.$

[例 5]在 $\triangle ABC$ 中，角 A, B, C 的对边分别为 a, b, c，已知 $c(1+\cos B)=b(2-\cos C)$ .  
（1）求证： $2b=a+c;$  
（2）若 $B=\frac{\pi}{3}$ ， $\triangle ABC$ 的面积为 $4\sqrt{3}$ ，求 b.
解析 （1） $\because c(1 + \cos B) = b(2 - \cos C)$ , $\therefore$ 由正弦定理可得 $\sin C + \sin C\cos B = 2\sin B - \sin B\cos C$ , 可得 $\sin C\cos B + \sin B\cos C + \sin C = 2\sin B$ , $\sin (B + C) + \sin C = 2\sin B$ , $\therefore \sin A + \sin C = 2\sin B$ , $\therefore a + c = 2b$ .  
（2） $\because B=\frac{\pi}{3},\quad\therefore\triangle ABC$ 的面积 $S=\frac{1}{2}ac\sin B=\frac{\sqrt{3}}{4}ac=4\sqrt{3},\quad\therefore ac=16.$
由余弦定理可得 $b^{2}=a^{2}+c^{2}-2ac\cos B=a^{2}+c^{2}-ac=(a+c)^{2}-3ac.$
$\because a+c=2b,\quad\therefore b^{2}=4b^{2}-3\times16,$ 解得 b=4.

[例6]在 $\triangle ABC$ 中， $a,b,c$ 分别为内角 $A,B,C$ 的对边，且 $\frac{1}{a + b} +\frac{1}{a + c} = \frac{3}{a + b + c}$  
（1）求角 A 的大小;  
（2）若 $\frac{c}{b} = \frac{1}{2} +\sqrt{3}$ ， $a = \sqrt{15}$ ，求 $b$ 的值.
解析 （1）由题意，可得 $\frac{a + b + c}{a + b} +\frac{a + b + c}{a + c} = 3$ ，即 $\frac{c}{a + b} +\frac{b}{a + c} = 1$ ，整理得 $b^{2} + c^{2} - a^{2} = bc$
由余弦定理知， $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{1}{2}$ ，因为 $0<A<\pi$ ，所以 $A=\frac{\pi}{3}$ .  
（2）根据正弦定理，得 $\frac{c}{b} = \frac{\sin C}{\sin B} = \frac{\sin(A + B)}{\sin B} = \frac{\sin A\cos B + \cos A\sin B}{\sin B} = \frac{\sin A}{\tan B} +\cos A = \frac{\sqrt{3}}{2\tan B} +\frac{1}{2} = \frac{1}{2} +\sqrt{3},$ 解得 $\tan B = \frac{1}{2}$ ，所以 $\sin B = \frac{\sqrt{5}}{5}$ .由正弦定理得， $b = \frac{a\sin B}{\sin A} = \frac{\sqrt{15}\times\frac{\sqrt{5}}{5}}{\frac{\sqrt{3}}{2}} = 2.$

[例 7] (2017·全国 II)△ABC 的内角 A, B, C 的对边分别为 a, b, c, 已知 $\sin(A+C)=8\sin^{2}\frac{B}{2}$ .  
（1）求 $\cos B$ ;   
（2）若 $a+c=6$ ， $\triangle ABC$ 的面积为 2，求 b.
解析 （1）由题设及 $A + B + C = \pi$ 得 $\sin B = 8\sin^2\frac{B}{2}$ ，即 $\sin B = 4(1 - \cos B)$ ，
故 $17\cos^2 B - 32\cos B + 15 = 0$ ，解得 $\cos B = \frac{15}{17}$ ， $\cos B = 1$ （舍去）.  
（2）由 $\cos B=\frac{15}{17}$ ，得 $\sin B=\frac{8}{17}$ ，故 $S_{\triangle ABC}=\frac{1}{2}ac\sin B=\frac{4}{17}ac$ 。又 $S_{\triangle ABC}=2$ ，则 $ac=\frac{17}{2}$ 。
由余弦定理及 $a + c = 6$ 得 $b^{2} = a^{2} + c^{2} - 2ac\cos B = (a + c)^{2} - 2ac(1 + \cos B) = 36 - 2\times \frac{17}{2}\times \left(1 + \frac{15}{17}\right) = 4.$
所以 b=2.

[例 8]在 $\triangle ABC$ 中，角 A, B, C 的对边分别为 a, b, c，且满足 $(2a+b)\cos C+c\cos B=0$ .  
（1）求角 C;  
（2）若 $\triangle ABC$ 的面积 $S = 8\sqrt{3}$ ，其外接圆的半径 $R = \frac{4\sqrt{21}}{3}$ ，求 $\triangle ABC$ 的周长.
解析 （1） $(2a+b)\cos C+c\cos B=0$ ，由正弦定理得 $2\sin A\cos C+\sin B\cos C+\cos B\sin C=0$ .
即 $2\sin A\cos C = -\sin(B + C) = -\sin A$ ，又 $\sin A \neq 0$ ，故 $\cos C = -\frac{1}{2}$ ，又 $0 < C < \pi$ ，所以 $C = \frac{2\pi}{3}$ .  
（2）由 $C=\frac{2\pi}{3}$ ， $R=\frac{4\sqrt{21}}{3}$ 及 $c=2R\sin C$ ，可得 $c=4\sqrt{7}$ ，又 $S=\frac{1}{2}ab\sin\frac{2\pi}{3}=\frac{1}{2}ab\times\frac{\sqrt{3}}{2}=8\sqrt{3}$ ，即 ab=32，
由余弦定理 $c^{2}=a^{2}+b^{2}-2ab\cos C$ ，得 $a^{2}+b^{2}-2ab\cos\frac{2\pi}{3}=(4\sqrt{7})^{2}$ ，即 $a^{2}+b^{2}+ab=(a+b)^{2}-ab=112$
又 $ab = 32$ ，故 $a + b = 12$ ，所以 $a + b + c = 12 + 4\sqrt{7}$ ，即 $\triangle ABC$ 的周长为 $12 + 4\sqrt{7}$

# 【对点训练】

1. 设 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c, a = b\tan A$ .  
（1）证明： $\sin B=\cos A;$   
（2）若 $\sin C - \sin A \cos B = \frac{3}{4}$ ，且 B 为钝角，求 A, B, C.

1. 解析 （1）证明 由正弦定理知 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R, \therefore a = 2R\sin A, b = 2R\sin B$ ，代入 $a = b\tan A$ 得 $\sin A = \sin B \cdot \frac{\sin A}{\cos A}$ ，又 $\because A \in (0, \pi), \therefore \sin A > 0, \therefore 1 = \frac{\sin B}{\cos A}$ ，即 $\sin B = \cos A$ .  
（2） 解 由 $\sin C - \sin A\cos B = \frac{3}{4}$ 知， $\sin (A + B) - \sin A\cos B = \frac{3}{4}$ ， $\therefore \cos A\sin B = \frac{3}{4}$ .
由（1）知， $\sin B=\cos A,\quad\therefore\cos^{2}A=\frac{3}{4}$ ，由于B是钝角，故 $A\in\left(0,\frac{\pi}{2}\right)$ ， $\therefore\cos A=\frac{\sqrt{3}}{2},\quad A=\frac{\pi}{6}.$
$\sin B = \frac {\sqrt {3}}{2}, B = \frac {2 \pi}{3}, \therefore C = \pi - (A + B) = \frac {\pi}{6}.$

2. 已知 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c, a^2 + b^2 = \lambda ab$ .  
（1）若 $\lambda = \sqrt{6}$ , $B = \frac{5\pi}{6}$ , 求 $\sin A$ ;   
（2）若 $\lambda=4$ ， $AB$ 边上的高为 $\frac{\sqrt{3}c}{6}$ ，求 $C$ .

2. 解析 （1）由已知 $B = \frac{5\pi}{6}$ , $a^2 + b^2 = \sqrt{6}ab$ , 结合正弦定理得 $4\sin^2 A - 2\sqrt{6}\sin A + 1 = 0$ . 解得 $\sin A = \frac{\sqrt{6} \pm \sqrt{2}}{4}$ . 因为 $0 < A < \frac{\pi}{6}$ , 所以 $\sin A < \frac{1}{2}$ , 所以 $\sin A = \frac{\sqrt{6} - \sqrt{2}}{4}$ .  
（2）由题意可知 $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{\sqrt{3}}{12} c^2$ ，得 $\frac{1}{2} ab\sin C = \frac{\sqrt{3}}{12} (a^2 + b^2 - 2ab\cos C) = \frac{\sqrt{3}}{12} (4ab - 2ab\cos C)$ . 化简，得 $\sqrt{3}\sin C + \cos C = 2$ ，即 $\sin \left(C + \frac{\pi}{6}\right) = 1$ 。又因为 $\frac{\pi}{6} < C + \frac{\pi}{6} < \frac{7\pi}{6}$ ，所以 $C + \frac{\pi}{6} = \frac{\pi}{2}$ ，解得 $C = \frac{\pi}{3}$ .

3. 在 $\triangle ABC$ 中，内角 $A, B, C$ 所对的边分别为 $a, b, c$ . 已知 $a \sin A = 4b \sin B, ac = \sqrt{5} (a^2 - b^2 - c^2)$ .  
（1）求 $\cos A$ 的值;  
（2）求 $\sin (2B - A)$ 的值.

3. 解析 （1） 由 $a \sin A = 4b \sin B$ ，及 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，得 $a = 2b$ 。由 $ac = \sqrt{5}(a^2 - b^2 - c^2)$ ，

及余弦定理，得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{-\frac{\sqrt{5}}{5}ac}{ac} = -\frac{\sqrt{5}}{5}.$  
（2）由（1）及 $A \in (0, \pi)$ ，可得 $\sin A = \frac{2\sqrt{5}}{5}$ ，代入 $a\sin A = 4b\sin B$ ，得 $\sin B = \frac{a\sin A}{4b} = \frac{\sqrt{5}}{5}$ .
由（1）知，A 为钝角，所以 $\cos B=\sqrt{1-\sin^{2}B}=\frac{2\sqrt{5}}{5}$ .
于是 $\sin2B=2\sin B\cos B=\frac{4}{5},\quad\cos2B=1-2\sin^{2}B=\frac{3}{5},$
故 $\sin(2B-A)=\sin2B\cos A-\cos2B\sin A=\frac{4}{5}\times\left(-\frac{\sqrt{5}}{5}\right)-\frac{3}{5}\times\frac{2\sqrt{5}}{5}=-\frac{2\sqrt{5}}{5}.$

4. 在 $\triangle ABC$ 中，内角 $A, B, C$ 所对的边分别为 $a, b, c$ ，已知 $a - c = \frac{\sqrt{6}}{6} b$ ， $\sin B = \sqrt{6}\sin C$ .  
（1）求 $\cos A$ 的值;  
（2）求 $\cos \left(2A - \frac{\pi}{6}\right)$ 的值.

4. 解析 （1） 在 $\triangle ABC$ 中，由 $\frac{b}{\sin B} = \frac{c}{\sin C}$ 及 $\sin B = \sqrt{6}\sin C$ ，可得 $b = \sqrt{6} c$ ，又由 $a - c = \frac{\sqrt{6}}{6} b$ ，有 $a = 2c$ 所以 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{6c^2 + c^2 - 4c^2}{2\sqrt{6}c^2} = \frac{\sqrt{6}}{4}$ .  
（2）在 $\triangle ABC$ 中，由 $\cos A=\frac{\sqrt{6}}{4}$ ，可得 $\sin A=\frac{\sqrt{10}}{4}$ ，于是 $\cos 2A=2\cos^{2}A-1=-\frac{1}{4}$ ， $\sin 2A=2\sin A\cdot\cos A=\frac{\sqrt{15}}{4}$ 。所以 $\cos\left(2A-\frac{\pi}{6}\right)=\cos 2A\cos \frac{\pi}{6}+\sin 2A\sin \frac{\pi}{6}=\left(-\frac{1}{4}\right)\times\frac{\sqrt{3}}{2}+\frac{\sqrt{15}}{4}\times\frac{1}{2}=\frac{\sqrt{15}-\sqrt{3}}{8}$ 。

5. 已知 $a, b, c$ 是 $\triangle ABC$ 中角 $A, B, C$ 的对边，且 $3\cos \cos + 2 = 3\sin \sin C + 2\cos^2 A$ .  
（1）求角 A 的大小;  
（2）若 $\triangle ABC$ 的面积 $S=5\sqrt{3}$ , $b=5$ , 求 $\sin B\sin C$ 的值.

5. 解析 （1）由 $3\cos B\cos C + 2 = 3\sin B\sin C + 2\cos^2 A$ ，得 $3\cos (B + C) + 2 = 2\cos^2 A$
即 $2\cos^{2}A + 3\cos A - 2 = 0$ ，即 $(2\cos A - 1)(\cos A + 2) = 0$ ，
解得 $\cos A=\frac{1}{2}$ 或 $\cos A=-2$ (舍去). 因为 $0<A<\pi$ ，所以 $A=\frac{\pi}{3}$ .  
（2）由 $S=\frac{1}{2}bc\sin A=\frac{\sqrt{3}}{4}bc=5\sqrt{3}$ ，得 bc=20，因为 b=5，所以 c=4.
由余弦定理 $a^{2}=b^{2}+c^{2}-2bc\cos A$ ，得 $a^{2}=25+16-2\times20\times\frac{1}{2}=21$ ，故 $a=\sqrt{21}$ .
根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，得 $\sin B\sin C = \frac{b}{a}\sin A \times \frac{c}{a}\sin A = \frac{5}{7}$ .

6. (2013·北京)在 $\triangle ABC$ 中， $a=3$ ， $b=2\sqrt{6}$ ， $B=2A$ .  
（1）求 $\cos A$ 的值;
