# 【解题方法总结】

1、判断不等式是否恒成立，需要给出推理或者反例说明.

4.1 (多选题)(2024·重庆·统考模拟预测)已知a>b>c,ac>0,则下列关系式一定成立的是()

A. $c^2 >bc$

B. $bc(a - c) > 0$

C. $a + b > c$

D. $\frac{c}{b} +\frac{b}{c} >2$

【答案】BD

【解析】因为 ac > 0，所以 a > b > c > 0 或 0 > a > b > c，

当 $a > b > c > 0$ 时， $bc > c^2$ ，A 不成立， $bc(a - c) > 0, a + b > c$

由 $\frac{c}{b} > 0, \frac{b}{c} > 0$ ，故 $\frac{c}{b} + \frac{b}{c} \geqslant 2\sqrt{\frac{c}{b} \cdot \frac{b}{c}} = 2$ ，当且仅当 $\frac{c}{b} = \frac{b}{c}$ ，即 $b = c$ 时，等号成立，

因为 b > c，故等号不成立，故 $\frac{c}{b} + \frac{b}{c} > 2$ ;

当 0 > a > b > c 时, $bc < c^{2}$ , $bc(a - c) > 0$ ,

不妨设 0 > -1 > -2 > -3，则 $a + b = c$ ，故此时 C 不成立，

由 $\frac{c}{b}>0,\frac{b}{c}>0$ , 故 $\frac{c}{b}+\frac{b}{c}\geqslant2\sqrt{\frac{c}{b}\cdot\frac{b}{c}}=2$ , 当且仅当 $\frac{c}{b}=\frac{b}{c}$ , 即 b=c 时, 等号成立,

因为 b > c，故等号不成立，故 $\frac{c}{b} + \frac{b}{c} > 2$ ;

综上: BD 一定成立.

故选: BD

42 (多选题)(2024·山东·校联考二模)已知实数a,b,c满足a>b>c，且 $a+b+c=0$ ，则下列说法正确的是()

A. $\frac{1}{a-c}>\frac{1}{b-c}$

B. $a - c > 2b$

C. $a^2 > b^2$

D. $ab + bc > 0$

【答案】BC

【解析】对于 A, ∵ a > b > c, ∴ a - c > b - c > 0, ∴ $\frac{1}{a - c} < \frac{1}{b - c}$ , A 错误;

对于 B, $\because a > b > c, a + b + c = 0, \therefore a > 0, c < 0, \therefore b + c = -a < 0, a - b > 0,$

$\therefore a-b>b+c$ , 即 a-c>2b, B 正确;

对于 C, $\because a-b>0, a+b=-c>0, \therefore a^{2}-b^{2}=(a+b)(a-b)>0$ , 即 $a^{2}>b^{2}$ , C 正确;

对于 D, $ab + bc = b(a + c) = -b^{2} \leqslant 0$ , D 错误.

故选: BC.

43 (多选题)(2024·全国·校联考模拟预测)若 $a > 0 > b > c$ ，则下列结论正确的是 （）

A. $\frac{a}{c}>\frac{a}{b}$

B. $b^{2a} > c^{2a}$

C. $\frac{a-b}{a-c}>\frac{b}{c}$

D. $a - c \geqslant 2\sqrt{(a - b)(b - c)}$

【答案】ACD

【解析】∵ a > 0 > b > c，则 b - c > 0，bc > 0，∴ $\frac{a}{c} - \frac{a}{b} = \frac{a(b - c)}{bc} > 0$ ，即 $\frac{a}{c} > \frac{a}{b}$ ，A 正确；

例如 a=1, b=-2, c=-3, $b^{2a}=(-2)^{2}=4$ , $c^{2a}=(-3)^{2}=9$ ，显然 4<9，B 错误；

由 $a > 0 > b > c$ 得 $c - b < 0, a - c > 0, \therefore \frac{a - b}{a - c} - \frac{b}{c} = \frac{a(c - b)}{c(a - c)} > 0$ ，即 $\frac{a - b}{a - c} > \frac{b}{c}, C$ 正确；

易知 a-c>0, a-b>0, b-c>0,

$$
a - c - 2 \sqrt {(a - b) (b - c)} = (a - b) + (b - c) - 2 \sqrt {(a - b) (b - c)} = (\sqrt {a - b} - \sqrt {b - c}) ^ {2} \geqslant 0,
$$

$\therefore a-c\geqslant2\sqrt{(a-b)(b-c)}$ , D 正确;

故选: ACD.

# 2 题型二: 比较数 (式) 的大小与比较法证明不等式

# 【解题方法总结】

比较数(式)的大小常用的方法有比较法、直接应用不等式的性质、基本不等式、利用函数的单调性.

比较法又分为作差比较法和作商比较法.

作差法比较大小的步骤是：

(1) 作差; (2) 变形; (3) 判断差式与 0 的大小; (4) 下结论.

作商比较大小(一般用来比较两个正数的大小)的步骤是:

(1) 作商；(2) 变形；(3) 判断商式与 1 的大小；(4) 下结论.

其中变形是关键,变形的方法主要有通分、因式分解和配方等,变形要彻底,要有利于0或1比较大小.

作差法是比较两数(式)大小最为常用的方法,如果要比较的两数(式)均为正数,且是幂或者因式乘积的形式,也可考虑使用作商法,作商法比较大小的原理是:

若 $a > 0, b > 0$ ，则 $\frac{b}{a} > 1 \Leftrightarrow b > a; \frac{b}{a} < 1 \Leftrightarrow b < a; \frac{b}{a} = 1 \Leftrightarrow b = a;$

若 $a < 0, b < 0$ ，则 $\frac{b}{a} > 1 \Leftrightarrow b < a; \frac{b}{a} < 1 \Leftrightarrow b > a; \frac{b}{a} = 1 \Leftrightarrow b = a.$

(2024·全国·高三专题练习)若 0 < a < b, $a + b = 1$ ，则将 $a, b, \frac{1}{2}, 2ab, a^{2} + b^{2}$ 从小到大排列为 \_\_\_\_.

【答案】 $a<2ab<\frac{1}{2}<a^{2}+b^{2}<b$

【解析】∵0<a<b,a+b=1,不妨令 $a=\frac{1}{3},b=\frac{2}{3}$ ,

则有 $2ab=\frac{4}{9},a^{2}+b^{2}=\frac{5}{9}$ ,

∴有 $b > a^{2} + b^{2} > \frac{1}{2} > 2ab > a$ ,

即 $a < 2ab < \frac{1}{2} < a^{2} + b^{2} < b.$

故答案为: $a < 2ab < \frac{1}{2} < a^{2} + b^{2} < b.$

# 题型三: 已知不等式的关系, 求目标式的取值范围

# 【解题方法总结】

在约束条件下求多变量函数式的范围时,不能脱离变量之间的约束关系而独立分析每个变量的范围,否则会导致范围扩大,而只能建立已知与未知的直接关系.

48 (多选题)(2024·全国·高三专题练习)已知实数 x, y 满足 $-3 < x + 2y < 2, -1 < 2x - y < 4$ , 则 ( )

A. $x$ 的取值范围为 $(-1,2)$

B. $y$ 的取值范围为 $(-2,1)$

C. $x + y$ 的取值范围为 $(-3, 3)$

D. $x - y$ 的取值范围为 $(-1,3)$

【答案】ABD

【解析】因为 -1 < 2x - y < 4，所以 -2 < 4x - 2y < 8。因为 -3 < x + 2y < 2，所以 -5 < 5x < 10，则 -1 < x < 2，故 A 正确；

因为 $-3 < x + 2y < 2$ ，所以 $-6 < 2x + 4y < 4.$ 因为 $-1 < 2x - y < 4$ ，所以 $-4 < -2x + y < 1$ ，所以 $-10 < 5y < 5$ ，所以 $-2 < y < 1$ ，故B正确；

因为 $-3 < x + 2y < 2, -1 < 2x - y < 4$ ，所以 $-\frac{9}{5} < \frac{3}{5}(x + 2y) < \frac{6}{5}, -\frac{1}{5} < \frac{1}{5}(2x - y) < \frac{4}{5}$ ，则 $-2 < x + y < 2$ ，故C错误；

因为 $-3 < x + 2y < 2, -1 < 2x - y < 4$ ，所以 $-\frac{2}{5} < -\frac{1}{5}(x + 2y) < \frac{3}{5}, -\frac{3}{5} < \frac{3}{5}(2x - y) < \frac{12}{5}$ ，则 $-1 < x - y < 3$ ，故D正确.

故选: ABD.

49 (2024·广东·高三校联考期末)已知 $1 \leqslant a - b \leqslant 3, 3 \leqslant a + b \leqslant 7$ ，则 $5a + b$ 的取值范围为（）

A. [15,31]

B. $[14,35]$

C. [12,30]

D. [11,27]

【答案】D

【解析】设 $5a + b = m(a - b) + n(a + b) = (m + n)a + (n - m)b$ ，所以 $\left\{\begin{aligned}m+n=5\\ n-m=1\end{aligned}\right.\Rightarrow$

$$
\left\{ \begin{array}{l} m = 2 \\ n = 3 \end{array} \right.,
$$

则 $5a + b = 2(a - b) + 3(a + b)$ ，又 $1 \leqslant a - b \leqslant 3, 3 \leqslant a + b \leqslant 7$

所以 $2 \leqslant 2(a - b) \leqslant 6, 9 \leqslant 3(a + b) \leqslant 21$ ，由不等式的性质得： $11 \leqslant 2(a - b) + 3(a + b) \leqslant 27$ ，

则 $5a + b$ 的取值范围为 [11,27].

故选：D.

51 (2024·全国·高三专题练习)已知三个实数 a、b、c，当 c > 0 时， $b \leqslant 2a + 3c$ 且 $bc = a^{2}$ ，则 $\frac{a - 2c}{b}$ 的取值范围是 \_\_\_\_.

【答案】 $\left(-\infty,\frac{1}{9}\right]$

【解析】当 c>0 时满足: $b \leqslant 2a + 3c$ 且 $bc = a^{2}$ ,

$\therefore \frac{a^2}{c} \leqslant 2a + 3c$ ，即 $a^2 - 2ac - 3c^2 \leqslant 0$ ，进而 $\left(\frac{a}{c}\right)^2 - 2 \cdot \frac{a}{c} - 3 \leqslant 0$ ，解得 $-1 \leqslant \frac{a}{c} \leqslant 3$ .

所以 $\frac{c}{a} \geqslant \frac{1}{3}$ 或 $\frac{c}{a} \leqslant -1$ ,

$$
\frac {a - 2 c}{b} = \frac {a c - 2 c ^ {2}}{a ^ {2}} = \frac {c}{a} - 2 \left(\frac {c}{a}\right) ^ {2} = f \left(\frac {c}{a}\right),
$$

令 $\frac{c}{a} = t, t \in \left[\frac{1}{3}, +\infty\right) \cup (-\infty - 1]$ ,

$$
\therefore f (t) = - 2 t ^ {2} + t = - 2 \left(t - \frac {1}{4}\right) ^ {2} + \frac {1}{8},
$$

由于 $t \in \left[\frac{1}{3}, +\infty\right) \cup (-\infty - 1]$

所以 $f(t)$ 在 $t \in (-\infty, -1]$ 单调递增，在 $t \in \left[\frac{1}{3}, +\infty\right)$ 单调递减，

当 $t = \frac{1}{3}$ 时， $f\left(\frac{1}{3}\right) = \frac{1}{9}$ ，当 $t = -1$ 时， $f(-1) = -3$

所以 $f(t)\leqslant \frac{1}{9}$

故答案为: $\left(-\infty,\frac{1}{9}\right]$ .

52 (多选题)(2024·河北衡水·高三河北衡水中学校考阶段练习)已知a>0,b>0,且满足 $a\geqslant\frac{4}{a}+\frac{1}{b},b\geqslant\frac{5}{b}+\frac{1}{a}$ .则 $a^{2}+b^{2}$ 的取值可以为()

A. 10

B. 11

C. 12

D. 20

【答案】CD

【解析】因为 $a \geqslant \frac{4}{a} + \frac{1}{b}, b \geqslant \frac{5}{b} + \frac{1}{a}$ ,

所以 $a^2 \geqslant 4 + \frac{a}{b}, b^2 \geqslant 5 + \frac{b}{a}$

故 $a^2 + b^2 \geqslant 4 + \frac{a}{b} + 5 + \frac{b}{a} \geqslant 9 + 2\sqrt{\frac{a}{b} \cdot \frac{b}{a}} = 11$

当 $a^{2}=4+\frac{a}{b}$ ， $b^{2}=5+\frac{b}{a}$ 且 $\frac{a}{b}=\frac{b}{a}$ ，而 a=b 时 $a^{2}\neq b^{2}$ ，即等号不能同时成立，

所以 $a^{2}+b^{2}>11$ ，故 AB 错误，CD 正确.

故选: CD.

53 (多选题)(2024·全国·高三专题练习)已知 $x^{2}(y^{2} + 1) = 1$ ，则 （）

A. $xy < 1$

B. $x^{2}y \geqslant -\frac{1}{2}$

C. $x + xy \leqslant 1$

D. $x^{2} + xy\leqslant \frac{5}{4}$

【答案】ABD

【解析】由 $x^{2}(y^{2}+1)=1$ 得 $x^{2}=\frac{1}{y^{2}+1}$ ， $x^{2}=1-x^{2}y^{2}$ ，由于 $y^{2}\geqslant0$ ，所以 $0<x^{2}\leqslant1$ ，

所以 $x^{2}y^{2}=1-x^{2}\in[0,1)$ ，因此 -1<xy<1 且 $xy\neq0$ ，故 A 正确，

$x^{2}y=\frac{y}{y^{2}+1}$ ，当 y<0 时， $x^{2}y=\frac{y}{y^{2}+1}=\frac{1}{y+\frac{1}{y}}$ ，由于 $y+\frac{1}{y}\leqslant-2$ ，当且仅当 y=-1 时，

等号成立,故 $0 > \frac{1}{y + \frac{1}{y}} \geqslant -\frac{1}{2}$ , 当 $y \geqslant 0$ 时, $x^{2}y \geqslant 0$ , 所以 $x^{2}y \geqslant -\frac{1}{2}$ , 故 B 正确,

$x^{2}(1 + y)^{2} = x^{2}(1 + 2y + y^{2}) = x^{2}(y^{2} + 1) + 2x^{2}y = 1 + 2x^{2}y \leqslant 1 + x^{2}(1 + y^{2}) = 2$ ，当且仅当 $2y = 1 + y^{2} \Rightarrow y = 1, x^{2} = \frac{1}{2}$ 时取等号，故 $-\sqrt{2} \leqslant x(1 + y) = x + xy \leqslant \sqrt{2}$ ，所以C错误，

$x^{2} + xy = 1 - x^{2}y^{2} + xy = -\left(xy - \frac{1}{2}\right)^{2} + \frac{5}{4} \leqslant \frac{5}{4}$ , 当且仅当 $xy = \frac{1}{2}$ 取等号, 又 $x^{2}(y^{2} + 1) = 1$ , 所以 $x = \frac{\sqrt{3}}{2}, y = \frac{\sqrt{3}}{3}$ 或者 $x = -\frac{\sqrt{3}}{2}, y = -\frac{\sqrt{3}}{3}$ 等号成立,

故选: ABD

54 (多选题)(2024·全国·模拟预测)已知实数 $a, b$ 满足 $\frac{1}{\sqrt{a}} > \frac{1}{\sqrt{b}}$ ，则 （）

A. $\log_{0.2023}a < \log_{0.2023}b$

B. $a^3 < b^3$

C. $\frac{b}{a}>\frac{b+1}{a+1}$

D. $ab + \frac{1}{ab + 1}$ 的最小值为1

【答案】BC

【解析】由 $\frac{1}{\sqrt{a}} > \frac{1}{\sqrt{b}}$ 可知 a > 0, b > 0，由不等式的性质可知 $\frac{1}{a} > \frac{1}{b}$ ，则 0 < a < b.

# 5 题型五:糖水不等式

【解题方法总结】

糖水不等式: 若 a > b > 0, m > 0, 则一定有 $\frac{b + m}{a + m} > \frac{b}{a}$ , 或者 $\frac{a + m}{b + m} < \frac{a}{b}$ .

56 (多选题)(2024·全国·高三专题练习)已知bg糖水中含有ag糖(b>a>0)，若再添加mg糖完全溶解在其中，则糖水变得更甜了(即糖水中含糖浓度变大)，根据这个事实，下列不等式中一定成立的有()

A. $\frac{a}{b}<\frac{a+m}{b+m}$

B. $\frac{a + m}{b + m} < \frac{a + 2^m}{b + 2^m}$

C. $(a + 2m)(b + m) < (a + m)(b + 2m)$

D. $\frac{2}{3^{b}-1}<\frac{1}{3^{a-1}}$

【解析】对于 A, 由题意可知 $\frac{a}{b} < \frac{a+m}{b+m}$ , 正确;

对于B, 因为 $m < 2^{m}$ , 所以 $\frac{a + m}{b + m} < \frac{a + m + 2^{m} - m}{b + m + 2^{m} - m} = \frac{a + 2^{m}}{b + 2^{m}}$ , 正确;
