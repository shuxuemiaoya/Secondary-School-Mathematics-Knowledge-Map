# (1) 基本性质

<table><tr><td>性质</td><td>性质内容</td></tr><tr><td>对称性</td><td> $a > b \Leftrightarrow b < a; a < b \Leftrightarrow b > a$ </td></tr><tr><td>传递性</td><td> $a > b, b > c \Rightarrow a > c; a < b, b < c \Rightarrow a < c$ </td></tr><tr><td>可加性</td><td> $a > b \Leftrightarrow a + c > b > c$ </td></tr><tr><td>可乘性</td><td> $a > b, c > 0 \Rightarrow ac > bc; a > b, c < 0 \Rightarrow ac < bc$ </td></tr><tr><td>同向可加性</td><td> $a > c, c > d \Rightarrow a + c > b + d$ </td></tr><tr><td>同向同正可乘性</td><td> $a > b > 0, c > d > 0 \Rightarrow ac > bd$ </td></tr><tr><td>可乘方性</td><td> $a > b > 0, n \in \mathbb{N}^{*} \Rightarrow a^{n} > b^{n}$ </td></tr></table>

# 【解题方法总结】

1、应用不等式的基本性质,不能忽视其性质成立的条件,解题时要做到言必有据,特别提醒的是在解决有关不等式的判断题时,有时可用特殊值验证法,以提高解题的效率.  
2、比较数(式)的大小常用的方法有比较法、直接应用不等式的性质、基本不等式、利用函数的单调性.

比较法又分为作差比较法和作商比较法.

作差法比较大小的步骤是：

(1) 作差; (2) 变形; (3) 判断差式与 0 的大小; (4) 下结论.

作商比较大小(一般用来比较两个正数的大小)的步骤是:

(1) 作商；(2) 变形；(3) 判断商式与 1 的大小；(4) 下结论.

其中变形是关键,变形的方法主要有通分、因式分解和配方等,变形要彻底,要有利于0或1比较大小.

作差法是比较两数(式)大小最为常用的方法,如果要比较的两数(式)均为正数,且是幂或者因式乘积的形式,也可考虑使用作商法.

# 2 题型二: 比较数 (式) 的大小与比较法证明不等式

# 【解题方法总结】

比较数 (式) 的大小常用的方法有比较法、直接应用不等式的性质、基本不等式、利用函数的单调性.

比较法又分为作差比较法和作商比较法.

作差法比较大小的步骤是：

(1) 作差; (2) 变形; (3) 判断差式与 0 的大小; (4) 下结论.

作商比较大小(一般用来比较两个正数的大小)的步骤是:

(1) 作商；(2) 变形；(3) 判断商式与 1 的大小；(4) 下结论.

其中变形是关键,变形的方法主要有通分、因式分解和配方等,变形要彻底,要有利于0或1比较大小.

作差法是比较两数(式)大小最为常用的方法,如果要比较的两数(式)均为正数,且是幂或者因式乘积的形式,也可考虑使用作商法,作商法比较大小的原理是:

若 $a > 0, b > 0$ ，则 $\frac{b}{a} > 1 \Leftrightarrow b > a; \frac{b}{a} < 1 \Leftrightarrow b < a; \frac{b}{a} = 1 \Leftrightarrow b = a;$

若 $a < 0, b < 0$ ，则 $\frac{b}{a} > 1 \Leftrightarrow b < a; \frac{b}{a} < 1 \Leftrightarrow b > a; \frac{b}{a} = 1 \Leftrightarrow b = a.$

# 题型五:糖水不等式

# 【解题方法总结】

糖水不等式: 若 a > b > 0, m > 0, 则一定有 $\frac{b + m}{a + m} > \frac{b}{a}$ , 或者 $\frac{a + m}{b + m} < \frac{a}{b}$ .

A. $\frac{a}{b}<\frac{a+m}{b+m}$
