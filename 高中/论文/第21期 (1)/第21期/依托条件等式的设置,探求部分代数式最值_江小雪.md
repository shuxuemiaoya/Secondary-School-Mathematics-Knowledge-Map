# 1 一次线性代数式的最值(或取值范围)

借助题设条件中等式的设置,确定“部分代数式”为一次线性代数式的最值(或取值范围),是此类代数式最值应用中最为常见的一种基本类型,也是基本不等式等巧妙放缩与应用的一个重要场景.

例 1 若 a > 0, b > 0, $2ab + a + 2b = 3$ ，则 $a + 2b$ 的最小值是（）.

A. $\frac{\sqrt{2}}{2}$

B.1

C.2

D. $\frac{3\sqrt{2}}{2}$

解法 1: 整体思维法.

依题，由于 $a > 0, b > 0, 2ab + a + 2b = 3$ ，利用基本不等式，可得 $3 = 2ab + a + 2b \leqslant \left(\frac{a + 2b}{2}\right)^2 + (a + 2b)$ ，当且仅当 $a = 2b$ 时等号成立.

因此 $(a+2b)^{2}+4(a+2b)-12\geqslant0$ ，因式分解可得 $(a+2b+6)(a+2b-2)\geqslant0$ ，解得 $a+2b\geqslant2$ 。

所以当 $a=1, b=\frac{1}{2}$ 时， $a+2b$ 取得最小值 2.

解法 2: 消元法.

因为 $a > 0, b > 0, 2ab + a + 2b = 3$ ，所以 $a = \frac{3 - 2b}{2b + 1}$ $(0 < b < \frac{3}{2})$ 。利用基本不等式，可得 $a + 2b = -1 + \frac{4}{2b + 1} + 2b = \frac{4}{2b + 1} + (2b + 1) - 2 \geqslant 2\sqrt{4} - 2 = 2$ ，当且仅当 $\frac{4}{2b + 1} = 2b + 1$ ，即 $b = \frac{1}{2}, a = 1$ 时等号成立。所以 $a + 2b$ 的最小值为 2。

解法 3: 因式分解法.

由 $a > 0, b > 0, 2ab + a + 2b = 3$ ，得 $(2b + 1) \cdot$

$(a + 1) = 4.$ 利用基本不等式，可得 $a + 2b = (2b + 1) + (a + 1) - 2 \geqslant 2\sqrt{(2b + 1)(a + 1)} - 2 = 2$ ，当且仅当 $2b + 1 = a + 1$ ，即 $b = \frac{1}{2}, a = 1$ 时等号成立.所以 $a + 2b$ 的最小值为2.

解法 4: 换元法.

设 $a + 2b = t$ ，结合 $2ab + a + 2b = 3$ 可得 $a \cdot 2b = 3 - t$ . 所以 $a$ 与 $2b$ 是方程 $x^{2} - tx + 3 - t = 0$ 的两个正实数根.

所以 $\left\{\begin{aligned}t&>0,\\ 3-t&>0,\\ \Delta&=(-t)^{2}-4(3-t)\geqslant0,\end{aligned}\right.$ 解得 $2\leqslant t<3$ ,

当 t=2 时, a=2b=1, 即 $a=1, b=\frac{1}{2}$ .

所以 $a+2b$ 取得最小值 2.

点评:在处理条件等式中“部分代数式”的最值(或取值范围)问题时,特别对于一次线性代数式的最值(或取值范围)问题,解题的关键是首先应用基本不等式(或变形)把“等式”转化为“不等式”,问题“求什么”就在不等式中“留什么”,仍要注意“一正、二定、三相等”三个条件,其次把所求“部分代数式”视为一个整体,最终利用一元二次不等式解决问题.

# 2 二次代数式的最值(或取值范围)

借助题设条件中等式的设置,确定“部分代数式”为二次代数式的最值(或取值范围),对问题的分析与挖掘要更加深入,可以通过基本不等式等进行巧妙放缩,也可以利用函数与方程、三角函数、函数与导数的应用等思维来综合应用.

例 2 已知 $ab > 0, a^{2} + ab + 2b^{2} = 1$ ，则 $a^{2} + 2b^{2}$ 的最小值为（）.

A. $\frac{8-2\sqrt{2}}{7}$

B. $\frac{2\sqrt{2}}{3}$

C. $\frac{3}{4}$

D. $\frac{7-2\sqrt{2}}{8}$

解法 1: 基本不等式法.

依题 $ab > 0, a^2 + ab + 2b^2 = 1$ ，结合基本不等式，可得 $1 = a^2 + ab + 2b^2 = a^2 + 2b^2 + \frac{1}{\sqrt{2}}a \times \sqrt{2}b \leqslant a^2 +$

$2b^{2}+\frac{1}{\sqrt{2}}\times\frac{a^{2}+2b^{2}}{2}=\frac{2\sqrt{2}+1}{2\sqrt{2}}(a^{2}+2b^{2})$ ，则有 $a^{2}+2b^{2}\geqslant\frac{2\sqrt{2}}{2\sqrt{2}+1}=\frac{8-2\sqrt{2}}{7}$ ，当且仅当 $a=\sqrt{2}b$ ，即 $b^{2}=\frac{4-\sqrt{2}}{14}$ ， $a^{2}=\frac{4-\sqrt{2}}{7}$ 时， $a^{2}+2b^{2}$ 的最小值为 $\frac{8-2\sqrt{2}}{7}$ .

解法 2: 判别式法.

设 $a^2 + 2b^2 = t$ ，结合 $ab > 0, a^2 + ab + 2b^2 = 1$ ，可知 $0 < t < 1$ . 将 $a^2 + 2b^2 = t$ 代入 $a^2 + ab + 2b^2 = 1$ 中，整理可得 $a = \frac{1 - t}{b}$ ，代入 $a^2 + 2b^2 = t$ 中有 $\left(\frac{1 - t}{b}\right)^2 + 2b^2 = t$ ，整理有 $2b^4 - tb^2 + (1 - t)^2 = 0$ . 由于以上关于 $b^2$ 的方程有实数解，则有判别式 $\Delta = t^2 - 8(1 - t)^2 \geqslant 0$ ，即 $t \geqslant 2\sqrt{2}(1 - t)$ ，解得 $t \geqslant \frac{8 - 2\sqrt{2}}{7}$ . 当 $t = \frac{8 - 2\sqrt{2}}{7}$ 时， $b^2 = \frac{t}{4}$ ，即 $b^2 = \frac{4 - \sqrt{2}}{14}, a^2 = \frac{4 - \sqrt{2}}{7}$ 时， $a^2 + 2b^2$ 的最小值为 $\frac{8 - 2\sqrt{2}}{7}$ .

解法 3: 三角换元法.

设 $a^2 + 2b^2 = t$ ，结合 $ab > 0, a^2 + ab + 2b^2 = 1$ ，可知 $0 < t < 1$ . 三角换元可设 $a = \sqrt{t} \cos \theta, \sqrt{2}b = \sqrt{t} \sin \theta$ ，结合 $ab > 0$ ，二者同号，不失一般性取两者均为正数。设 $\theta \in \left(0, \frac{\pi}{2}\right)$ ，代入 $a^2 + ab + 2b^2 = 1$ 中，整理可得 $t + \frac{\sqrt{2}}{2} t \sin \theta \cos \theta = 1$ ，则可得 $t = \frac{1}{1 + \frac{\sqrt{2}}{2} \sin \theta \cos \theta} = \frac{2\sqrt{2}}{2\sqrt{2} + \sin 2\theta} \geqslant \frac{2\sqrt{2}}{2\sqrt{2} + 1} = \frac{8 - 2\sqrt{2}}{7}$ ，当且仅当 $\sin 2\theta = 1$ ，即 $2\theta = \frac{\pi}{2}$ ，亦即 $\theta = \frac{\pi}{4}$ 时，等号成立。此时 $a = \sqrt{2}b$ ，即 $b^2 = \frac{4 - \sqrt{2}}{14}, a^2 = \frac{4 - \sqrt{2}}{7}$ 时， $a^2 + 2b^2$ 的最小值为 $\frac{8 - 2\sqrt{2}}{7}$ 。

解法 4: 齐次化法.

依题 $ab > 0, a^2 + ab + 2b^2 = 1$ ，齐次化可得 $a^2 + 2b^2 = \frac{a^2 + 2b^2}{a^2 + ab + 2b^2} = \frac{1 + 2\left(\frac{b}{a}\right)^2}{1 + \frac{b}{a} + 2\left(\frac{b}{a}\right)^2}$ . 设 $t = \frac{b}{a} > 0$ ，则 $a^2 + 2b^2 = \frac{1 + 2t^2}{1 + t + 2t^2}$ . 构建函数 $f(t) = \frac{1 + 2t^2}{1 + t + 2t^2}, t > 0$ ，求导有 $f'(t) = \frac{2t^2 - 1}{(1 + t + 2t^2)^2}$ . 由 $f'(t) = 0$ 解得 $t =$

$\frac{\sqrt{2}}{2}$ （负值舍去）.于是当 $t\in\left(0,\frac{\sqrt{2}}{2}\right)$ 时， $f'(t)<0$ ，函数 $f(t)$ 单调递减；当 $t\in\left(\frac{\sqrt{2}}{2},+\infty\right)$ 时， $f'(t)>0$ ，函数 $f(t)$ 单调递增.所以 $f(t)_{\min}=f\left(\frac{\sqrt{2}}{2}\right)=\frac{8-2\sqrt{2}}{7}$ ，当且仅当 $t=\frac{\sqrt{2}}{2}$ ，可得 $a=\sqrt{2}b$ ，即 $b^{2}=\frac{4-\sqrt{2}}{14}$ ， $a^{2}=\frac{4-\sqrt{2}}{7}$ 时， $a^{2}+2b^{2}$ 的最小值为 $\frac{8-2\sqrt{2}}{7}$ .

点评:在处理条件等式中“部分代数式”的最值(或取值范围)问题时,特别对于二次代数式的最值(或取值范围)问题,在基本不等式等巧妙放缩应用的基础上,还可以借助方程思维、三角函数思维以及函数与导数思维等,利用相应的技巧与方法来确定二次代数式的最值(或取值范围).
