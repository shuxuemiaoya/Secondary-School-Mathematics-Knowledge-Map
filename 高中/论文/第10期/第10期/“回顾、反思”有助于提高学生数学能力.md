# 一、探究极值定理，初步理解

课堂上先复习基本不等式: 若 a > 0, b > 0, 则 $\frac{a + b}{2} \geqslant \sqrt{ab}$ , 当且仅当 a = b 时取等号.

分析基本不等式:这是关于两个正数的均值不等式;反映的关系是:两个正数的算术平均数大于等于这两个正数的几何平均数.

由此可得：

当两个正数的算术平均数 $\frac{a+b}{2}$ 确定时,这两个正数的几何平均数 $\sqrt{ab}$ 有最大值;

当两个正数的几何平均数 $\sqrt{ab}$ 确定时, 这两个正数的算术平均数 $\frac{a+b}{2}$ 有最小值.

再进一步引导学生得出两个极值定理：

(1) 若 $a > 0, b > 0, ab = T$ 为定值，则 $a + b \geqslant 2\sqrt{ab} = 2\sqrt{T}$ ，当且仅当 $a = b$ 时， $a + b$ 取到最小值 $2\sqrt{T}$ .  
(2) 若 $a > 0, b > 0, a + b = S$ 为定值，则 $ab \leqslant \frac{(a + b)^2}{4} = \frac{S^2}{4}$ ，当且仅当 $a = b$ 时， $ab$ 取到最大值 $\frac{S^2}{4}$ .

简单总结: 积定和最小, 和定积最大; 取最值的条件: 一正(两个数都是正数)、二定(两个数的和或积是定值)、三相等(两个正数能取到相等).

# 二、应用极值定理，加深理解

先讨论了两个直接应用极值定理求最值的问题，然后探究如下例题：

已知 x > 0, y > 0, $x + 2y + 2xy = 8$ , 求 $x + 2y$ 的最小值.

# 1. 创造条件,应用极值定理解题

分析 1: 本题是一个求两个正数的和 $x + 2y$ 最小的问题, “积定和最小”, 那就要求有相关的两个正数的乘积是定值,问题就在于题目条件是否给出了两个相关正数的“积定”.

条件 $x+2y+2xy=8$ 能写成乘积是定值的形式吗?

很快有学生发现: 只要等式两边加 1 后就能因式分解! $(x+1)(2y+1)=9$ .

要求最小值的式子 $x + 2y$ 能用 $(x + 1)$ 和 $(2y + 1)$ 的和表示吗?

容易发现: $x+2y=(x+1)+(2y+1)-2.$

$$
\begin{array}{l} x + 2 y = (x + 1) + (2 y + 1) - 2 \geqslant \\ 2 \sqrt {(x + 1) (2 y + 1)} - 2 = 4. \\ \end{array}
$$

当且仅当 $x+1=2y+1$ 时，即 x=2, y=1 时， $x+2y$ 取最小值 4.

反思小结解题方法: 要求和最小, 只要思考是否有积定; 当然要求积最大时, 只要思考是否有和定.

数学教育家波利亚在《怎样解题》中这样写道:我们应该懂得并且传授给学生下述看法:没有任何问题是可以解决得十全十美的.总剩下些工作要做.经过充分的探讨与钻研,我们能够改进这个解答.

# 2. 转化问题,应用已学知识解题

你能用不同的方法解题吗?

分析2: 不等式 $x + 2y + 2xy = 8$ 是一个含有两个正数的和 $x + 2y$ ，并且有这两个正数的积 $x \cdot 2y$ 的等式。想求 $x + 2y$ 的最小值，如果能运用基本不等式把条件等式转化为关于 $x + 2y$ 的不等式，通过解关于 $x + 2y$ 的不等式，求出 $x + 2y$ 的取值范围，也应该可以得到 $x + 2y$ 的最小值。你能化积为和吗？

运用基本不等式得: $x \cdot (2y) \leqslant \left(\frac{x+2y}{2}\right)^{2}$ .

因此 $x + 2y = 8 - x \cdot (2y) \geqslant 8 - \left(\frac{x + 2y}{2}\right)^2$ ，整理得 $(x + 2y)^2 + 4(x + 2y) - 32 \geqslant 0$ ，即 $(x + 2y - 4)(x + 2y + 8) \geqslant 0$ . 又 $x + 2y > 0$ ，所以 $x + 2y \geqslant 4$ .

当且仅当 x=2y 时，即 x=2, y=1 时， $x+2y$ 取最小值 4.

分析 3: 再次研究例题, 是一个求两个正数的和 $x + 2y$ 最小值的问题, 有一个条件等式 $x + 2y + 2xy = 8$ , 我们知道: 通常有一个等式, 就可以帮助消去一个 “元”, 本题能否消元转化为关于一个变量的函数来求

最值呢?

$$
x + 2 y + 2 x y = 8 \Rightarrow y = \frac {8 - x}{2 + 2 x}.
$$

同学们注意到消元的“动作要领”了吗？为了保证消元前后等价，“动作要领”是：要由旧元的范围得出新元的范围。

由 x > 0, y > 0, 得 0 < x < 8.

则 $x + 2y = x + 2 \times \frac{8 - x}{2 + 2x} = x + \frac{9 - (1 + x)}{1 + x} = (1 + x) + \frac{9}{1 + x} - 2 \geqslant 2\sqrt{9} - 2 = 4.$

当且仅当 $x+1=3$ 时，即 x=2, y=1 时， $x+2y$ 取最小值 4.

再思则明,上述三种不同的分析,得到了相同的结论,我们对结论确信无疑,那么这三种方法哪个更优?通过变式题来分析比较上述三种方法.

# 三、回顾定理应用，变题再析

变式题: 已知 x > 0, y > 0, $x + 2y + 2xy = 8$ , 求 $2x + 3y$ 的最小值.

分析 1 中的方法“运用积定和最小”依然可行：

$$
x + 2 y + 2 x y = 8 \Rightarrow (x + 1) (2 y + 1) = 9.
$$

$$
2 x + 3 y = 2 (x + 1) + \frac {3}{2} (2 y + 1) - \frac {7}{2} \geqslant
$$

$$
2 \sqrt {3 (x + 1) (2 y + 1)} - \frac {7}{2} = 6 \sqrt {3} - \frac {7}{2}.
$$

当且仅当 $2(x + 1) = \frac{3}{2} (2y + 1) = 3\sqrt{3}$ 时，即 $x = \frac{3\sqrt{3}}{2} - 1, y = \sqrt{3} - \frac{1}{2}$ 时， $2x + 3y$ 取最小值 $6\sqrt{3} - \frac{7}{2}$ .

但分析 2 中的方法将无法进行, 因为不能转化为关于 $2x + 3y$ 的一元二次不等式.

分析 3 中的方法显然能解变式题.

$$
2 x + 3 y = 2 (x + 1) + \frac {3}{2} \cdot \frac {9}{x + 1} - \frac {7}{2} \geqslant
$$

$$
2 \sqrt {3 (x + 1) \cdot \frac {9}{x + 1}} - \frac {7}{2} = 6 \sqrt {3} - \frac {7}{2}.
$$

看来分析 1、分析 3 中的方法应用更广.

# 四、反思解题经历,提出新问题

回顾、反思:能把这些方法用于某个其他问题吗?

比较分析三种解法后,顺着变式题的思路提出:

拓展题: 若 a > 0, b > 0, 已知 x > 0, y > 0, $x + 2y + 2xy = 8$ , 求 $ax + by$ 的最小值.

分析 1 中的方法可解: $x + 2y + 2xy = 8 \Rightarrow (x + 1)(2y + 1) = 9$ .

$$
\begin{array}{l} a x + b y = a (x + 1) + \frac {b}{2} (2 y + 1) - \left(a + \frac {b}{2}\right) \geqslant \\ \begin{array}{l} 2 \sqrt {a \cdot \frac {b}{2} (x + 1) (2 y + 1)} - \left(a + \frac {b}{2}\right) = 3 \sqrt {2 a b} - \\ \left(a + \frac {b}{2}\right). \end{array} \\ \end{array}
$$

当且仅当 $a(x + 1) = \frac{b}{2} (2y + 1) = \frac{b}{2} \cdot \frac{9}{x + 1} \Rightarrow x + 1 = \sqrt{\frac{9b}{2a}} \Rightarrow x = \sqrt{\frac{9b}{2a}} - 1$ 时， $ax + by$ 取最小值 $3\sqrt{2ab} - \left(a + \frac{b}{2}\right)$ .

分析 3 中的方法也可解: $x + 2y + 2xy = 8 \Rightarrow y = \frac{8 - x}{2 + 2x}$ ; 由 x > 0, y > 0, 得 0 < x < 8.

$$
\begin{array}{l} a x + b y = a x + b \times \frac {8 - x}{2 + 2 x} = a x + \frac {b}{2} \cdot \frac {9 - (1 + x)}{1 + x} \\ = a (1 + x) + \frac {b}{2} \cdot \frac {9}{1 + x} - a - \frac {b}{2} \geqslant 2 \sqrt {\frac {9 a b}{2}} - a - \frac {b}{2} \\ = 3 \sqrt {2 a b} - \left(a + \frac {b}{2}\right). \\ \end{array}
$$

当且仅当 $a(x + 1) = \frac{b}{2} \cdot \frac{9}{x + 1} \Rightarrow x + 1 = \sqrt{\frac{9b}{2a}} \Rightarrow x = \sqrt{\frac{9b}{2a}} - 1$ 时， $ax + by$ 取最小值 $3\sqrt{2ab} - (a + \frac{b}{2})$ .

对拓展题的反思: 上述拓展题的解法真的正确吗? 是否有问题?

细心的学生必然注意到: $x=\sqrt{\frac{9b}{2a}}-1$ 未必大于0!

要解决拓展题,需要对 $\sqrt{\frac{9b}{2a}}-1$ 是否为正数分类讨论:

当 $\sqrt{\frac{9b}{2a}} > 1$ 时，当且仅当 $a(x + 1) = \frac{b}{2} \cdot \frac{9}{x + 1} \Rightarrow x + 1 = \sqrt{\frac{9b}{2a}} \Rightarrow x = \sqrt{\frac{9b}{2a}} - 1$ 时， $ax + by$ 取最小值 $3\sqrt{2ab} - \left(a + \frac{b}{2}\right)$ .

当 $0 < \sqrt{\frac{9b}{2a}} \leqslant 1$ 时， $ax + by = ax + b \times \frac{8 - x}{2 + 2x} = ax + \frac{b}{2} \cdot \frac{9 - (1 + x)}{1 + x} = a(1 + x) + \frac{b}{2} \cdot \frac{9}{1 + x} - a - \frac{b}{2}$ ，在 $ax + by$ 在 $x \in (0, +\infty)$ 时单调递增，无最小值. (下转第23页)

所以 $a_{n}=-4[(n-1)+3(n-2)+\cdots+3^{n-2}]+3^{n}=-(3^{n}-2n-1)+3^{n}=2n+1$ ，所以数列 $\{a_{n}\}$ 的通项公式为 $a_{n}=2n+1$ .

方法 5:(数学归纳法) 当 n=1 时, $a_{1}=3$ , 结论成立.

假设当 $n=k(k\in\mathbf{N}^{*})$ 时，结论成立，即 $a_{k}=2k+1$ ，当 $n=k+1$ 时，有 $a_{k+1}=3a_{k}-4k=3(2k+1)-4k=2k+3=2(k+1)+1$ ，即当 $n=k+1$ 时结论也成立.

综上分析,对于任意的 $n \in N^{*}$ , $a_{n} = 2n + 1$ , 所以数列 $\{a_{n}\}$ 的通项公式为 $a_{n} = 2n + 1$ .

点评:根据条件确定数列的前三项,进而猜想得到对应数列的通项公式,而证明视角多种多样.可以利用数列的递推关系式进行待定系数法处理与变形,进而结合迭代法转化或结合等差数列的定义转化;可以利用数列的递推关系式进行恒等变形,通过裂项法转化为常数列来求解或通过累加法转化进行求解(只是这里要利用错位相减法进行数列求和,过程比较繁杂);可以利用数学归纳法来加以证明,这也充分体现数列问题破解中的“观察—归纳—猜想—证明”这一系列过程.

# (2) 方法 1: (错位相减法)

由(1)得 $a_{n}=2n+1$ ，令 $b_{n}=2^{n}\cdot a_{n}=(2n+1)\cdot2^{n}$ ，则 $S_{n}=b_{1}+b_{2}+\cdots+b_{n-1}+b_{n}=3\times2^{1}+5\times2^{2}+\cdots+(2n-1)\cdot2^{n-1}+(2n+1)\cdot2^{n}$ ，而 $2S_{n}=3\times2^{2}+5\times2^{2}+\cdots+(2n-1)\cdot2^{n}+(2n+1)\cdot2^{n+1}$ ，两式对应相减，可得 $-S_{n}=3\times2+2\times2^{2}+\cdots+2\cdot2^{n}-(2n+1)\cdot2^{n+1}=6+2\times\frac{4(1-2^{n-1})}{1-2}-(2n+1)\cdot2^{n+1}$

整理化简可得 $S_{n}=(2n-1)\cdot2^{n+1}+2$ ，所以数列 $\{2^{n}\cdot$ $a_{n}\}$ 的前 $n$ 项和 $S_{n} = (2n - 1)\cdot 2^{n + 1} + 2.$

# 方法 2: (裂项相消法)

由(1)得 $a_{n}=2n+1$ ，令 $b_{n}=2^{n}\cdot a_{n}=(2n+1)\cdot2^{n}=(-2n+3)\cdot2^{n}-(-2n+1)\cdot2^{n+1}$ ，则 $S_{n}=b_{1}+b_{2}+\cdots+b_{n}=1\times2^{1}-(-1)\cdot2^{2}+(-1)\cdot2^{2}-(-3)\cdot2^{3}+\cdots+(-2n+3)\cdot2^{n}-(-2n+1)\cdot2^{n+1}=1\times2^{1}-(-2n+1)\cdot2^{n+1}=(2n-1)\cdot2^{n+1}+2$ ，所以数列 $\{2^{n}\cdot a_{n}\}$ 的前n项和 $S_{n}=(2n-1)\cdot2^{n+1}+2$ .

点评:根据条件(1)所确定的数列 $\{a_{n}\}$ 的通项公式,结合所求解数列的通项公式的特征,错位相减法进行数列求和是破解此类问题中的常规方法.破解时要合理对齐相应类似的项,方便进行作差化简.而结合所求解数列的通项公式的裂项处理,借助裂项相消法进行数列求和也是一种不错的技巧方法,关键就是要对通项公式进行有针对性地裂项处理,这是破解的重点与难点所在.

# 三、解后反思

破解此类数列问题,不再是熟悉的等差数列或等比数列的定义、通项公式和求和公式等,而是要充分理解数列的递推关系式的内涵与实质,识别不同“汤碗”中的“相同药”,在原有知识的基础上充分理解与掌握,渗透能力,提升思维.对于以上这个典型的数列高考真题,要不断挖掘试题的潜在功能,不能只是做过就放一边,要有针对性地加以进一步的理解与掌握,探究与拓展,从而在数学知识、数学能力、数学方法和数学思想等不同层面得以更高的提升,知识应用能力也能在更深层次上得到创新与发展. $^{F}$

# 五、总结

以上分析告诉我们:“回顾、反思”是问题解决的重要环节,通过“回顾、反思”已完成的解答,通过重新考虑、重新检查这个结果和得出这一结果的方法,可以:

帮助学生用不同的方法得到结论,以便用更简单的解法得到结论,优化解题方法.

帮助学生提高自己对这个解答的深度理解.

帮助学生巩固相关的知识和发展解题的能力.

帮助学生发展提出问题的能力.

帮助学生知道用这些知识和方法还可干些什么别的,以及下次如何能干得同样好.设想一些情况(提出一个新的问题),在哪些情况下,能再一次利用所使用的办法,或者应用所得到的结果.

经常进行解题后“回顾、反思”，定能加深对数学知识结构和关系的理解，做到触类旁通，提高数学能力. F
