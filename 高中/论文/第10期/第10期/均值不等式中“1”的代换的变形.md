虽然“1”很简单,但是在高考数学中有很多与“1”有关的式子和结论.在解题中,我们要善于联想,灵活地用“1”代换和变换,将问题化繁为简.均值不等式是高中阶段数学知识中的重要组成部分,同时也是高考中的重要考点,难度时大时小.为了使学生能够更好地理解“1”的代换,教师可以通过例题的方式来鼓励学生探究,引导学生自主总结,形成科学的认识,并且将知识灵活应用,学会迁移变形.本文主要对均值不等式中“1”的代换做丰富的变形.

引例: 已知 x > 0, y > 0, 且 $\frac{1}{x} + \frac{9}{y} = 1$ , 求 $x + y$ 的最小值.

$$
\begin{array}{l} \text { 解 }: \text { 因为   } x > 0, y > 0, \text { 所以   } x + y = (x + y) \times 1 \\ = (x + y) \cdot \left(\frac {1}{x} + \frac {9}{y}\right) = \frac {9 x}{y} + \frac {y}{x} + 1 0 \geqslant 2 \sqrt {\frac {9 x}{y} \cdot \frac {y}{x}} \\ + 1 0 = 1 6. \\ \end{array}
$$

当且仅当 $\frac{9x}{y}=\frac{y}{x}$ ，即 $\left\{\begin{aligned}x=4,\\ y=12\end{aligned}\right.$ 时等号成立。所以 $x+y$ 的最小值为16。

此题是均值不等式中典型的“1”的代换的题目. 在不等式解题过程中, 常常将不等式“乘以 1”、“除以 1”或将不等式中的某个常数用等于 1 的式子代替. “1”的代换有很多变形, 本文列举一些它的变形.

变形 1: 已知 x > 0, y > 0, 且 $x + y = 1$ , 求 $\frac{1}{x} + \frac{9}{y}$ 的最小值.

$$
\begin{array}{l} 1 = \left(\frac {1}{x} + \frac {9}{y}\right) \cdot (x + y) = \frac {9 x}{y} + \frac {y}{x} + 1 0 \geqslant 2 \sqrt {\frac {9 x}{y} \cdot \frac {y}{x}} \\ + 1 0 = 1 6. \\ \end{array}
$$

解: 因为 x > 0, y > 0, 所以 $\frac{1}{x} + \frac{9}{y} = \left( \frac{1}{x} + \frac{9}{y} \right) \cdot$

当且仅当 $\frac{9x}{y}=\frac{y}{x}$ ，即 $\left\{\begin{aligned}x&=\frac{1}{4},\\ y&=\frac{3}{4}\end{aligned}\right.$ 时等号成立。所以

$\frac{1}{x}+\frac{9}{y}$ 的最小值为 16.

此变形是把引例中条件和结论对调. 数学中有很多题目都是把条件和结论对调一下又成为一个新的题目.

此变形就是对已知条件 $\frac{1}{x}+\frac{9}{y}=1$ 的简单变形.
虽然此变形看似简单,但有些同学就是没有想到.

变形 5: 已知 x > 0, y > 0, 且 $\frac{1}{x + 1} + \frac{9}{y + 3} = 1$ , 求 $x + y$ 的最小值.

解:对比 $\frac{1}{x}+\frac{9}{y}=1$ 和 $\frac{1}{x+1}+\frac{9}{y+3}=1$ ，容易想到用换元.令 $\left\{\begin{aligned}x+1&=a,\\ y+3&=b,\end{aligned}\right.$ 则 $\left\{\begin{aligned}x&=a-1,\\ y&=b-3,\end{aligned}\right.$ 所以原等式变形为 $\frac{1}{a}+\frac{9}{b}=1$ ，其中 $\left\{\begin{aligned}a&>1,\\ b&>3,\end{aligned}\right.$ 所以 $x+y=a+b-4=(a+b)\cdot1-4=(a+b)\cdot\left(\frac{1}{a}+\frac{9}{b}\right)-4=\frac{9a}{b}+\frac{b}{a}+6\geqslant2\sqrt{\frac{9a}{b}\cdot\frac{b}{a}}+6=12.$

当且仅当 $\frac{9a}{b} = \frac{b}{a}$ ，即 $\left\{ \begin{array}{l}a = 4,\\ b = 12 \end{array} \right.$ 时等号成立，此时 $\left\{ \begin{array}{l}x = 3,\\ y = 9. \end{array} \right.$

整体代换思想即换元法,是一种重要的数学思想方法.在解题时要注意仔细观察题目中式子的结构,进行适当的整体代换来提升解题的效率.

变形 6: 已知 x > 0, y > 0, 且 $\frac{1}{x} + \frac{9}{y} = 2$ , 求 $x + y$ 的最小值.

分析:变形6是把引例中的“1”改为“2”,方法同引例1一样,只需把 $x+y$ 乘上2,然后2用 $\frac{1}{x}+\frac{9}{y}$ 反代即可,最后记得再除以2.

变形7:已知 x>0,y>0, $x+2y=3$ ,求 $\frac{x^{2}+3y}{xy}$ 的最小值.

分析: $\frac{x^{2}+3y}{xy}=\frac{x}{y}+\frac{3}{x}=\frac{x}{y}+\frac{x+2y}{x}=\frac{x}{y}+\frac{2y}{x}+1\geqslant2\sqrt{\frac{x}{y}\cdot\frac{2y}{x}}+1=2\sqrt{2}+1.$ 此变形也可以理解为“1”的变形,比之前的变形稍难,“1”的代换没有那么明显.

变形 9: 已知 $x + y = \frac{1}{x} + \frac{4}{y} + 8 (x > 0, y > 0)$ ，求 $x + y$ 的最小值.

分析: 引例中是 $\frac{a}{x} + \frac{b}{y}$ 这种类型的式子和 $cx + dy$ 分开. 而变形 9 把它们放在同一个等式中, 又该如何去求呢? 有了引例的基础, 只需要对 $x + y = \frac{1}{x} + \frac{4}{y} + 8 (x > 0, y > 0)$ 两边同时乘以 $x + y$ 即可.

解: 因为 $x + y = \frac{1}{x} + \frac{4}{y} + 8$ ，两边同时乘以 $x + y$ 得 $(x + y)^{2} = \left(\frac{1}{x} + \frac{4}{y}\right)(x + y) + 8(x + y) = \frac{4x}{y} + \frac{y}{x} + 5 + 8(x + y) \geqslant 2\sqrt{\frac{4x}{y} \cdot \frac{y}{x}} + 5 + 8(x + y) = 9 + 8(x + y)$ ，即 $(x + y)^{2} - 8(x + y) - 9 \geqslant 0$ ，因式分解得 $(x + y + 1)(x + y - 9) \geqslant 0$ ，而 $x + y + 1 > 0$ ，只需 $x + y - 9 \geqslant 0$ ，所以 $x + y \geqslant 9$ 。
