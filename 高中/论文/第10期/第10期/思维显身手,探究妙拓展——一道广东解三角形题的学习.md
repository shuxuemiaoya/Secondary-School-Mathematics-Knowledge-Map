# 一、问题呈现

【问题】(2020届广东省华南师大附中、实验中学、广雅中学、深圳中学高三上期末联考·16)在 $\triangle ABC$ 中，角A、B、C所对的边分别为a、b、c， $2b^{2}=2a^{2}+c^{2}$ ，当 $\tan(B-A)$ 取最大值时，角A的值为\_\_\_\_.

此题以三角形为问题背景,借助解三角形的灵活运用,综合三角形的特征以及三角恒等变换公式、基本不等式等来考查最值问题.破解本题可以从直接推理思维、三角恒等变换思维、解三角形思维、坐标转化思维以及平面几何思维等角度切入,结合三角形的性质、三角恒等变换公式以及基本不等式等知识来综合应用,考查数学知识与数学能力,具有较大的选拔性与区分度.

# 二、问题破解

# 思维视角一: 直接推理思维

方法 1:(三角恒等变换 + 直接推理法)

解析:由于 $2b^{2}=2a^{2}+c^{2}$ ，结合正弦定理，可得 $\sin^{2}B-\sin^{2}A=\frac{1}{2}\sin^{2}C$ ，而 $\sin^{2}B-\sin^{2}A=\sin^{2}B-\sin^{2}A\sin^{2}B-\sin^{2}A+\sin^{2}A\sin^{2}B=\sin^{2}B(1-\sin^{2}A)-\sin^{2}A(1-\sin^{2}B)=\sin^{2}B\cos^{2}A-\sin^{2}A\cos^{2}B=(\sin B\cos A+\cos B\sin A)(\sin B\cos A-\cos B\sin A)=\sin(B+A)\sin(B-A)=\sin C\sin(B-A)=\frac{1}{2}\sin^{2}C$ 则知 $\sin (B - A) = \frac{1}{2}\sin C\leqslant \frac{1}{2}$ ，可得 $(B - A)\in$ $\left(0,\frac{\pi}{6}\right]\cup \left[\frac{5\pi}{6},\pi\right).$ 由于 $2b^{2} = 2a^{2} + c^{2}$ ，则知 $2b^{2} >$

$2a^{2}$ ，即 b > a，亦即 B > A。又 $2b^{2} = 2a^{2} + c^{2} < 2a^{2} + 2c^{2}$ ，即 $b^{2} < a^{2} + c^{2}$ ，则知 $B < \frac{\pi}{2}$ ，即 $A < B < \frac{\pi}{2}$ ，可得 B - A 为锐角，所以当 $\tan(B - A)$ 取最大值时， $B - A = \frac{\pi}{6}$ ，此时不等式 $\sin(B - A) = \frac{1}{2}\sin C \leqslant \frac{1}{2}$ 中的等号成立，则有 $C = \frac{\pi}{2}$ 。由 $B - A = \frac{\pi}{6}$ 与 $B + A = \frac{\pi}{2}$ ，解得 $A = \frac{\pi}{6}$ ，故填答案： $\frac{\pi}{6}$ 。

# 思维视角二:三角恒等变换思维

方法 2:(三角恒等变换 + 基本不等式法 1)

解析:由于 $2b^{2}=2a^{2}+c^{2}$ ，结合正弦定理，可得 $2\sin^{2}B-2\sin^{2}A=\sin^{2}C$ ，即 $2(\sin B+\sin A)(\sin B-\sin A)=\sin^{2}C$ ，利用和差化积公式，可得 $2\times2\sin\frac{B+A}{2}\cos\frac{B-A}{2}\times2\cos\frac{B+A}{2}\sin\frac{B-A}{2}=\sin^{2}C$ ，即 $2\sin(B+A)\sin(B-A)=\sin^{2}C=\sin^{2}(B+A)$ ，而 $\sin(B+A)\neq0$ ，可得 $2\sin(B-A)=\sin(B+A)$ ，展开有 $2(\sin B\cos A-\cos B\sin A)=\sin B\cos A+\cos B\sin A$ ，整理可得 $\sin B\cos A=3\cos B\sin A$ ，化简可得 $\tan B=3\tan A$ ，显然 A 为锐角，所以 $\tan(B-A)=\frac{\tan B-\tan A}{1+\tan B\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}\leqslant$

$\frac{2}{2\sqrt{\frac{1}{\tan A}\times 3\tan A}} = \frac{\sqrt{3}}{3}$ ，当且仅当 $3\tan A = \frac{1}{\tan A}$ 即 $\tan A = \frac{\sqrt{3}}{3}$ ，亦即 $A = \frac{\pi}{6}$ 时等号成立，故填答案： $\frac{\pi}{6}$

方法 3:(三角恒等变换 + 基本不等式法 2)

解析:由于 $2b^{2}=2a^{2}+c^{2}$ ，结合正弦定理，可得 $2\sin^{2}B-2\sin^{2}A=\sin^{2}C$ ，结合二倍角公式可得 $1-\cos2B-(1-\cos2A)=\sin^{2}C$ ，即 $\cos2A-\cos2B=\sin^{2}C$ ，合理配凑可得 $\cos[(B+A)-(B-A)]-\cos[(B+A)+(B-A)]=\sin^{2}C$ ，展开整理可得

$2\sin(B+A)\sin(B-A)=\sin^{2}C=\sin^{2}(B+A)$ ，而 $\sin(B+A)\neq0$ ，可得 $2\sin(B-A)=\sin(B+A)$ ，展开有 $2(\sin B\cos A-\cos B\sin A)=\sin B\cos A+\cos B\sin A$ ，整理可得 $\sin B\cos A=3\cos B\sin A$ ，化简可得 $\tan B=3\tan A$ ，显然A为锐角，所以 $\tan(B-A)=\frac{\tan B-\tan A}{1+\tan B\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}\leqslant$ $\frac{2}{2\sqrt{\frac{1}{\tan A}\times 3\tan A}} = \frac{\sqrt{3}}{3}$ ，当且仅当 $3\tan A = \frac{1}{\tan A}$ 即$\tan A=\frac{\sqrt{3}}{3}$ ，亦即 $A=\frac{\pi}{6}$ 时等号成立，故填答案： $\frac{\pi}{6}$ .

# 思维视角三: 解三角形思维

方法 4:(解三角形 + 基本不等式法 1)

解析:由于 $2b^{2}=2a^{2}+c^{2}$ ，结合余弦定理，可得 $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，则有 $2a^{2}+2c^{2}-4ac\cos B=2b^{2}=2a^{2}+c^{2}$ ，整理可得 $c=4a\cos B$ ，结合正弦定理有 $\sin C=4\sin A\cos B$ ，显然 B 为锐角，则有 $\sin C=\sin(A+B)=4\sin A\cos B$ ，展开有 $\sin A\cos B+\cos A\sin B=4\sin A\cos B$ ，整理可得 $\cos A\sin B=3\sin A\cos B$ ，化简可得 $\tan B=3\tan A$ ，显然 A 为锐角，所以 $\tan(B-A)=\frac{\tan B-\tan A}{1+\tan B\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}\leqslant$

$\frac{2}{2\sqrt{\frac{1}{\tan A}\times 3\tan A}} = \frac{\sqrt{3}}{3}$ ，当且仅当 $3\tan A = \frac{1}{\tan A}$ 即$\tan A=\frac{\sqrt{3}}{3}$ ，亦即 $A=\frac{\pi}{6}$ 时等号成立，故填答案： $\frac{\pi}{6}$ .

方法 5:(解三角形 + 基本不等式法 2)

解析:由于 $2b^{2}=2a^{2}+c^{2}$ ，可得 $b^{2}-a^{2}=\frac{1}{2}c^{2}$ ，由余弦定理可得 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{\frac{3}{2}c^{2}}{2bc}=\frac{3c}{4b}=\frac{3\sin C}{4\sin B}$ ，则有 $4\cos A\sin B=3\sin C=3\sin(A+B)=3\sin A\cos B+3\cos A\sin B$ ，整理可得 $\cos A\sin B=3\sin A\cos B$ ，化简可得 $\tan B=3\tan A$ ，显然 A 为锐角，所以 $\tan(B-A)=\frac{\tan B-\tan A}{1+\tan B\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}\leqslant\frac{2}{2\sqrt{\frac{1}{\tan A}\times3\tan A}}=\frac{\sqrt{3}}{3}$ ，当且仅当

$3\tan A=\frac{1}{\tan A}$ ，即 $\tan A=\frac{\sqrt{3}}{3}$ ，亦即 $A=\frac{\pi}{6}$ 时等号成立，
故填答案： $\frac{\pi}{6}$ .

# 三、探究总结

【结论 1】在斜 $\triangle ABC$ 中，角 A、B、C 所对的边分别为 a、b、c，若 $\lambda b^{2} = \lambda a^{2} + c^{2}, \lambda > 0$ 且 $\lambda \neq 1$ ，则有 $\tan B = \frac{\lambda + 1}{\lambda - 1} \tan A.$

证明:由于 $\lambda b^{2}=\lambda a^{2}+c^{2},\lambda>0$ 且 $\lambda\neq1$ ，结合余弦定理可得 $\lambda(a^{2}+c^{2}-2ac\cos B)=\lambda a^{2}+c^{2}$ ，整理可得 $(\lambda-1)c^{2}=2ac\lambda\cos B$ ，则有 $\frac{\lambda-1}{\lambda}=\frac{2a\cos B}{c}=\frac{2\sin A\cos B}{\sin C}=\frac{2\sin A\cos B}{\sin(A+B)}=\frac{2\sin A\cos B}{\sin A\cos B+\cos A\sin B}=\frac{2\tan A}{\tan A+\tan B}$ ，整理可得 $\tan B=\frac{\lambda+1}{\lambda-1}\tan A$ .

【变式 1】在 $\triangle ABC$ 中，角 A、B、C 所对的边分别为 a、b、c， $2b\cos A = 2a\cos B + c$ ，当 $\tan(B - A)$ 取最大值时，角 A 的值为 \_\_\_\_.

解析:由于 $2b\cos A=2a\cos B+c$ ，结合正弦定理可得 $2\sin B\cos A-2\sin A\cos B=\sin C$ ，则有 $2\sin B\cos A-2\sin A\cos B=\sin C=\sin(A+B)=\sin A\cos B+\cos A\sin B$ ，整理可得 $\sin B\cos A=3\sin A\cos B$ ，化简可得 $\tan B=3\tan A$ ，显然 A 为锐角，所以 $\tan(B-A)=\frac{\tan B-\tan A}{1+\tan B\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}\leqslant$ $\frac{2}{2\sqrt{\frac{1}{\tan A}\times 3\tan A}} = \frac{\sqrt{3}}{3}$ ，当且仅当 $3\tan A = \frac{1}{\tan A}$ 即 $\tan A = \frac{\sqrt{3}}{3}$ ，亦即 $A = \frac{\pi}{6}$ 时等号成立，故填答案： $\frac{\pi}{6}$
