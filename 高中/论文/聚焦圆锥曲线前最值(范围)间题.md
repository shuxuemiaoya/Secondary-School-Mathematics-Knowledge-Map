# 基本策略一、利用定义和几何关系

例 1 已知点 P 在离心率为 2 的双曲线 $\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1$ 的左支上， $A(0, 4\sqrt{3})$ ，F 是双曲线的右焦点，若 $\triangle PAF$ 周长的最小值是 20，则此时 $\triangle PAF$ 的面积为（）。

A. $6 \sqrt{3}$

B. $10 \sqrt{3}$

C. $14 \sqrt{3}$

D. 18

解析:设左焦点为 $F_{1}$ ，由题意可得：

$$
| P F | - | P F _ {1} | = 2 a, | P F | = 2 a + | P F _ {1} | \text {。}
$$

$$
\begin{array}{r l} & {\triangle P A F \text {的周长} = | A P | + | P F | + | A F |} \\ & {= | A P | + | P F _ {1} | + | A F | + 2 a \geqslant | A F _ {1} | +} \\ & {| A F | + 2 a.} \end{array}
$$

当且仅当 A, P, $F_{1}$ 三点共线时取等号，所以 $\left|AF_{1}\right| + \left|AF\right| + 2a = 20$ 。

因此， $\left\{ \begin{array}{l}2\sqrt{48 + c^2} +2a = 20,\\ \frac{c}{a} = 2,\\ c^2 = a^2 +b^2, \end{array} \right.$ 解得

$\left\{ \begin{array}{l}a = 2,\\ b = 2 / 3,\\ c = 4. \end{array} \right.$ 于是双曲线的方程为 $\frac{x^2}{4} -\frac{y^2}{12} = 1$ 。

直线 $AF_{1}$ 的斜率 $k_{AF_1} = \frac{4\sqrt{3}}{4} = \sqrt{3}$ ，直线 $AF_{1}$ 的方程为 $y = \sqrt{3} x + 4\sqrt{3}$ 。

由 $\left\{ \begin{array}{l} \frac{x^2}{4} - \frac{y^2}{12} = 1, \\ y = \sqrt{3} x + 4\sqrt{3} \end{array} \right. \Rightarrow 3x^2 - (\sqrt{3} x +$

$4\sqrt{3}$ ) $^{2}$ -12=0，解得 $x=-\frac{5}{2}$ 。

代入 $y = \sqrt{3} x + 4\sqrt{3}$ ，得 $y = \frac{3\sqrt{3}}{2}$ ，所以 $P$ 点坐标为 $\left(-\frac{5}{2}, \frac{3\sqrt{3}}{2}\right)$ 。 $S_{\triangle PAF} = S_{\triangle AF_1F} - S_{\triangle PF_1F} = \frac{1}{2} \times 8 \times 4\sqrt{3} - \frac{1}{2} \times 8 \times \frac{3\sqrt{3}}{2} = 10\sqrt{3}$ 。故选 B。

点评:遇见椭圆和双曲线中的最值问题,常把到左焦点的距离转化为到右焦点的距离，反之也可以；遇见抛物线中的最值问题，常把到焦点的距离转化为到准线的距离，反之亦可。

# 基本策略二、利用基本不等式

例2 已知椭圆 $C_1: \frac{x^2}{a_1^2} + \frac{y^2}{b_1^2} = 1 (a_1 > b_1 > 0)$ 与双曲线 $C_2: \frac{x^2}{a_2^2} - \frac{y^2}{b_2^2} = 1 (a_2 > 0, b_2 > 0)$ 有相同的焦点 $F_1, F_2$ ，点 $P$ 是椭圆 $C_1$ 与双曲线 $C_2$ 的一个公共点， $e_1, e_2$ 分别是椭圆 $C_1$ 和双曲线 $C_2$ 的离心率，若 $PF_1 \perp PF_2$ ，则 $4e_1^2 + e_2^2$ 的最小值为（ ）。

A. $\frac{9}{2}$

B. 4

C. $\frac{5}{2}$

D. 9

解析:由题意设焦距为 2c, 椭圆长轴长为 $2a_{1}$ , 双曲线实轴长为 $2a_{2}$ 。

不妨令 P 在双曲线的右支上，由双曲线的定义知 $\left|PF_{1}\right|-\left|PF_{2}\right|=2a_{2}$ 。①

由椭圆定义知 $|PF_{1}|+|PF_{2}|=2a_{1}$ 。②

又因 $PF_{1} \perp PF_{2}$ , 故 $|PF_{1}|^{2} + |PF_{2}|^{2} = 4c^{2}$ 。③

① $^{2}$ +② $^{2}$ ，整理得 $\left|PF_{1}\right|^{2}+\left|PF_{2}\right|^{2}=2a_{1}^{2}+2a_{2}^{2}$ 。④

将④代入③，得 $a_{1}^{2}+a_{2}^{2}=2c^{2}$ 。

故 $4e_{1}^{2} + e_{2}^{2} = \frac{4c^{2}}{a_{1}^{2}} +\frac{c^{2}}{a_{2}^{2}} = \frac{5}{2} +\frac{2a_{2}^{2}}{a_{1}^{2}} +\frac{a_{1}^{2}}{2a_{2}^{2}}\geqslant$ $\frac{5}{2} +2 = \frac{9}{2}$ ，选A。

点评: 当欲求的表达式中出现两个变量且求最值时, 利用基本不等式解题是首选。

# 基本策略三、利用函数思想

例 3 已知过抛物线 $y^{2}=2px$ (p>0) 的焦点 F 的直线与抛物线交于 A, B 两点，且 $\overrightarrow{AF}=3\overrightarrow{FB}$ ，抛物线的准线 l 与 x 轴交于 C, $AA_{1}\perp l$ 于点 $A_{1}$ ，且四边形 $AA_{1}CF$ 的面积为 $6\sqrt{3}$ 。过 $K(-1,0)$ 的直线 $l'$ 交抛物线于 M, N 两点，且 $\overrightarrow{KM}=\lambda\overrightarrow{KN}(\lambda\in(1,2])$ ，点 G 为线段 MN 的垂直平分线与 x 轴的交点，则点 G 的横坐标 $x_{0}$ 的取值范围为（）。

A. $\left(3,\frac{13}{4}\right]$

B. $\left(2,\frac{9}{4}\right]$

C. $\left(3,\frac{9}{2}\right]$

D. $\left(\frac{11}{2},7\right]$

解析: 过 B 作 $BB_{1} \perp l$ 于 $B_{1}$ 。设直线 AB 与准线 l 的交点为 D，由抛物线的性质可知 $AA_{1} = AF, BB_{1} = BF, CF = p$ 。

设 $BD = m, BF = n$ ，则 $\frac{BD}{AD} = \frac{BB_1}{AA_1} = \frac{BF}{AF} = \frac{1}{3}$ ，即 $\frac{m}{m + 4n} = \frac{1}{3}$ ，解得 $m = 2n$ 。

又 $\frac{BB_1}{CF} = \frac{BD}{DF}$ 则 $\frac{n}{p} = \frac{m}{m + n} = \frac{2}{3}, n = \frac{2p}{3}$ ，即 $DF = m + n = 2p$ ，故 $\angle ADA_1 = 30^\circ$ 。

又 $AA_{1} = 3n = 2p, CF = p$ ，故 $A_{1}D = 2\sqrt{3} p, CD = \sqrt{3} p$ ，即 $A_{1}C = \sqrt{3} p$ 。

则直角梯形 $AA_{1}CF$ 的面积为 $\frac{1}{2}(2p + p) \cdot \sqrt{3} p = 6\sqrt{3}$ ，解得 $p = 2$ ，故 $y^{2} = 4x$ 。

设 $M(x_{1},y_{1}),N(x_{2},y_{2})$ 。

因为 $\overrightarrow{KM}=\lambda\overrightarrow{KN}$ ，所以 $y_{1}=\lambda y_{2}$ 。

设直线 $l^{\prime}: x=my-1$ ，代入到 $y^{2}=4x$ 中得， $y^{2}-4my+4=0$ 。故 $y_{1}+y_{2}=4m, y_{1}y_{2}=4$ 。则 $x_{1}+x_{2}=m(y_{1}+y_{2})-2=4m^{2}-2$ 。

由以上式子可得， $4m^{2}=\frac{(1+\lambda)^{2}}{\lambda}=\lambda+\frac{1}{\lambda}+2$ 。

判断可知，当 $1 < \lambda \leqslant 2$ 时， $y = \lambda + \frac{1}{\lambda} + 2$ 单调递增，则 $4m^2 \in \left(4, \frac{9}{2}\right]$ ，即 $m^2 \in \left(1, \frac{9}{8}\right]$ 。

又 MN 的中点为 $(2m^{2}-1,2m)$ ，故直线 MN 的垂直平分线的方程为 $y-2m=-m(x-2m^{2}+1)$ 。

令 $y = 0$ ，得 $x_0 = 2m^2 +1\in \left(3,\frac{13}{4}\right]$ ，选A。

点评: 函数思想就是把圆锥曲线的最值或取值范围问题转化为函数的最值或值域问题, 采用这种策略的关键是合理引入参数建立函数关系式, 并确定参数的取值范围。

# 基本策略四、利用不等式

例 4 已知椭圆 $C: \frac{x^{2}}{4} + \frac{y^{2}}{3} = 1 (a >$

$b > 0)$ 的一个焦点是 $F(1,0), O$ 为坐标原点，过点 $H(3,0)$ 的直线交椭圆 $C$ 于点 $A, B$ 。假设 $P$ 为椭圆上一点，且满足 $\overrightarrow{OA} + \overrightarrow{OB} = t\overrightarrow{OP}$ ，当 $|\overrightarrow{PA} - \overrightarrow{PB}| < \sqrt{3}$ 时，求实数 $t^2$ 的取值范围。

解析: 设 $P(x, y)$ , $A(x_{1}, y_{1})$ , $B(x_{2}, y_{2})$ , AB 的直线方程为 $y = k(x - 3)$ 。

联立 $\left\{\begin{aligned}y&=k(x-3),\\ \frac{x^{2}}{4}&+\frac{y^{2}}{3}=1,\end{aligned}\right.$ 整理得：

$$
(3 + 4 k ^ {2}) x ^ {2} - 2 4 k ^ {2} x + 3 6 k ^ {2} - 1 2 = 0 。
$$

由 $\Delta > 0$ ，得 $k^2 < \frac{3}{5}$ 。 $x_1 + x_2 = \frac{24k^2}{3 + 4k^2}$ ， $x_1x_2 = \frac{36k^2 - 12}{3 + 4k^2}$ 。

$$
\text {   故   } \overrightarrow {O A} + \overrightarrow {O B} = (x _ {1} + x _ {2}, y _ {1} + y _ {2}) = t (x, y) 。
$$

则 $x = \frac{1}{t} (x_1 + x_2) = \frac{24k^2}{t(3 + 4k^2)}, y = \frac{1}{t} (y_1 + y_2) = \frac{-18k}{t(3 + 4k^2)}$ 。

因点 $P$ 在椭圆上，故 $\frac{(24k^2)^2}{4t^2(3 + 4k^2)^2} + \frac{(-18k)^2}{3t^2(3 + 4k^2)^2} = 1$ ，化简得 $36k^{2} = t^{2}(3 + 4k^{2})$ 。

因为 $|\overrightarrow{PA} -\overrightarrow{PB}| <   \sqrt{3}$ ，所以 $\sqrt{1 + k^2}\cdot$ $|x_{1} - x_{2}| <   \sqrt{3}$ ，即 $(1 + k^{2})\cdot [(x_{1} + x_{2})^{2}-$ $4x_{1}x_{2}] <   3$ 。

也即（1 + $k^{2}$ ） $\left[\frac{(24k^{2})^{2}}{(3+4k^{2})^{2}}-\frac{4(36k^{2}-12)}{3+4k^{2}}\right]<3$ ，则 $96k^{4}+56k^{2}-39>0$ ，解得 $k^{2}>\frac{\sqrt{283}-7}{24}$ 。

因此， $\frac{\sqrt{283}-7}{24}<k^{2}<\frac{3}{5}$ 。

因为 $36k^{2} = t^{2}(3 + 4k^{2})$ ，所以 $t^2 = \frac{36k^2}{3 + 4k^2} = 9 - \frac{27}{3 + 4k^2}$

所以 $20 - \sqrt{283} < t^{2} < 4$ ，即 $t^{2}$ 的取值范围为 $(20 - \sqrt{283}, 4)$ 。

点评: 最值或取值范围问题, 本质上体现了一种不等关系, 因此利用题中的代数和几何关系(如角度、向量、斜率等)或判别式, 建立不等式也是求解圆锥曲线最值或取值范围问题的一种基本方法。(责任编辑 徐利杰)
