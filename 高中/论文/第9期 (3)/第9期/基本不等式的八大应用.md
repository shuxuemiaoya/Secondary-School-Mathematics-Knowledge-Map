# 一、求最值

例 1 若 a > 0, b > 0，且 $ab = a + b + 3$ ，则 ab 的最小值为（）。

A. 9

B. -9

C. 3

D.-3

解:由 $ab=a+b+3\geqslant2\sqrt{ab}+3$ ，可得 $ab-2\sqrt{ab}-3\geqslant0$ ，解得 $\sqrt{ab}\geqslant3$ 或 $\sqrt{ab}\leqslant-1$ （舍去），所以 $ab\geqslant9$ ，当且仅当 a=b=3 时取等号，即 ab 的最小值为 9。应选 A。

评注:应用基本不等式求最值要满足三个条件,即“一正,二定,三相等”,忽略某个条件,就容易出错。

# 二、求参数的值

例 2 当 x > a 时, $2x + \frac{8}{x - a}$ 的最小值为 10, 则 $a = (\quad)$ 。

A. 1

B. $\sqrt{2}$

C. $2\sqrt{2}$

D. 4

解: 因为 x > a，所以 x - a > 0，所以 $2x + \frac{8}{x - a} = 2(x - a) + \frac{8}{x - a} + 2a \geqslant 2\sqrt{2(x - a) \times \frac{8}{x - a}} + 2a = 8 + 2a$ ，当且仅当 $2(x - a) = \frac{8}{x - a}$ 时取等号，所以 $8 + 2a = 10$ ，所以 a = 1。应选 A。

评注:本题不能直接利用基本不等式求最值,需要凑项求最值。

# 三、利用基本不等式比较大小

例 3 小王从甲地到乙地往返的时速分别为 a 和 b (a < b)，其全程的平均时速为 v，则（）。

A. $a <   v <   \sqrt{ab}$

B. $v = \sqrt{ab}$

C. $\sqrt{ab} < v < \frac{a + b}{2}$

D. $v = \frac{a + b}{2}$

解:设甲、乙两地的距离为 s，则 $v=\frac{2s}{\frac{s}{a}+\frac{s}{b}}=\frac{2}{\frac{1}{a}+\frac{1}{b}}$ 。因为 a<b，所以 $\frac{1}{a}+\frac{1}{b}<$

$\frac{2}{a}$ , 所以 $v > a$ 。又因为 $\frac{1}{a} + \frac{1}{b} > 2\sqrt{\frac{1}{ab}}$ , 所以 $v < \sqrt{ab}$ 。故 $a < v < \sqrt{ab}$ 。应选 A。

评注:利用基本不等式解题的关键是弄清基本不等式成立时取等号的条件。

# 四、利用基本不等式解决恒成立问题

例 4 已知 a>0, b>0, 若不等式 $\frac{2}{a}+\frac{1}{b}$ $\geqslant\frac{m}{2a+b}$ 恒成立，则 m 的最大值等于（）。

A. 10

B. 9

C. 8

D. 7

解: 因为 a>0, b>0, 所以 $2a+b>0$ 。要使 $\frac{2}{a}+\frac{1}{b}\geqslant\frac{m}{2a+b}$ 恒成立，只需 $m\leqslant(2a+b)\left(\frac{2}{a}+\frac{1}{b}\right)$ 恒成立。而 $(2a+b)\left(\frac{2}{a}+\frac{1}{b}\right)=4+\frac{2a}{b}+\frac{2b}{a}+1\geqslant5+2\sqrt{\frac{2a}{b}\times\frac{2b}{a}}=5+4=9$ ，当且仅当 a=b 时等号成立，所以 $m\leqslant9$ ，即 m 的最大值等于 9。应选 B。

评注：若 $a > f(x)$ 恒成立，则 $a > f(x)_{\mathrm{max}}$ ；若 $a < f(x)$ 恒成立，则 $a < f(x)_{\mathrm{min}}$ 。

# 五、利用基本不等式解决能成立问题

例 5 若正实数 x, y 满足 $x + y = 1$ ，且不等式 $\frac{4}{x + 1} + \frac{1}{y} < 1 + \frac{3}{2} m$ 有解，则实数 m 的取值范围是 \_\_\_\_。

解:因为正实数 x, y 满足 $x + y = 1$ ，所以 $(x + 1) + y = 2$ ，所以 $\frac{4}{x + 1} + \frac{1}{y} = \frac{1}{2}[(x + 1) + y] \cdot \left(\frac{4}{x + 1} + \frac{1}{y}\right) = \frac{1}{2} \left(5 + \frac{4y}{x + 1} + \frac{x + 1}{y}\right) \geqslant \frac{1}{2} \left(5 + 2\sqrt{\frac{4y}{x + 1} \times \frac{x + 1}{y}}\right) = \frac{9}{2}$ ，当且仅当 $\left\{\begin{aligned}&\frac{4y}{x+1}=\frac{x+1}{y},\\&x+y=1,\end{aligned}\right.$ 即 $\left\{\begin{aligned}&x+1=2y,\\ &x+y=1,\end{aligned}\right.$ 也即 $\left\{\begin{aligned}&x=\frac{1}{3},\\ &y=\frac{2}{3}\end{aligned}\right.$ 时

等号成立,所以 $\frac{4}{x+1}+\frac{1}{y}$ 的最小值为 $\frac{9}{2}$ 。

因为不等式 $\frac{4}{x + 1} +\frac{1}{y} <  1 + \frac{3}{2} m$ 有解，所以 $1 + \frac{3}{2} m > \frac{9}{2}$ ，解得 $m > \frac{7}{3}$ ，即实数 $m$ 的取值范围是 $\left(\frac{7}{3}, + \infty\right)$ 。

评注：若 $a > f(x)$ 能成立，则 $a > f(x)_{\min}$ ；若 $a < f(x)$ 能成立，则 $a < f(x)_{\max}$ 。

# 六、无附加条件的不等式证明

例6 已知 $a, b, c$ 都是正数，求证： $a + b + c - \sqrt{ab} - \sqrt{bc} - \sqrt{ac} \geqslant 0$ 。

证明: 因为 a, b, c 都是正数, 所以 $a + b \geqslant 2\sqrt{ab}$ , $b + c \geqslant 2\sqrt{bc}$ , $a + c \geqslant 2\sqrt{ac}$ , 所以 $a + b + b + c + a + c \geqslant 2(\sqrt{ab} + \sqrt{bc} + \sqrt{ac})$ , 所以 $a + b + c \geqslant \sqrt{ab} + \sqrt{bc} + \sqrt{ac}$ , 即 $a + b + c - \sqrt{ab} - \sqrt{bc} - \sqrt{ac} \geqslant 0$ , 当且仅当 a = b = c 时等号成立, 所以 $a + b + c - \sqrt{ab} - \sqrt{bc} - \sqrt{ac} \geqslant 0$ 成立。

评注:抓住题中表达式具有的轮换对称关系,利用表达式的相加即可得解。

# 七、有附加条件的不等式证明

例 7 已知 a>0, b>0, c>0，且 $a+b+c=1$ ，求证： $\left(\frac{1}{a}-1\right)\left(\frac{1}{b}-1\right)\left(\frac{1}{c}-1\right)\geqslant8$ 。

证明: 因为 a > 0, b > 0, c > 0, 且 $a + b + c = 1$ , 所以 $\frac{1}{a} - 1 = \frac{1 - a}{a} = \frac{b + c}{a} \geqslant \frac{2\sqrt{bc}}{a}$ 。

同理可得， $\frac{1}{b}-1\geqslant\frac{2\sqrt{ac}}{b},\frac{1}{c}-1\geqslant\frac{2\sqrt{ab}}{c}$ 。

上述三个不等式两边均为正值,分别相乘可得, $\left(\frac{1}{a}-1\right)\left(\frac{1}{b}-1\right)\left(\frac{1}{c}-1\right)\geqslant\frac{2\sqrt{bc}}{a}\cdot\frac{2\sqrt{ac}}{b}\cdot\frac{2\sqrt{ab}}{c}=8$ ,当且仅当 $a=b=c=\frac{1}{3}$ 时等号成立,所以 $\left(\frac{1}{a}-1\right)\left(\frac{1}{b}-1\right)\left(\frac{1}{c}-1\right)\geqslant8$ 。

评注:从所证不等式和已知条件出发,借助不等式的性质和有关定理,经过逻辑推理,最后转化为所求证的问题,其特征是以“已 知”看“可知”，逐步推向“未知”。

# 八、利用基本不等式解决实际问题

例 8 某商场预计全年分批购入每台2000元的电视机共3600台。每批都购入x台(x是自然数)且每批均需付运费400元。贮存购入的电视机全年所需付的保管费与每批购入电视机的总价值(不含运费)成正比。若每批购入400台,则全年需用去运输和保管总费用43600元。现在全年只有24000元资金可以支付这笔费用,则每批购入\_\_\_\_台,使资金够用。

解:设总费用为 y 元 $(y>0)$ ，且将题中的正比例函数的比例系数设为 k，则 $y=\frac{3600}{x}\times400+k(2000x)$ 。

依题设条件可得, 当 x = 400 时, y = 43600, 可得 k = 0.05, 所以 $y = \frac{1440000}{x} + 100x \geqslant 2\sqrt{\frac{1440000}{x} \times 100x} = 24000$ (元), 当且仅当 $\frac{1440000}{x} = 100x$ , 即 x = 120 时取等号。所以只需每批购入 120 台, 可使资金够用。

评注:利用基本不等式解决实际问题,要注意题中字母的取值范围。

# 感悟与教育

函数 $f(x) = \frac{x^2 + 3x + 3}{x + 1} (x \geqslant 1)$ 的最小值是 \_\_\_\_。

提示: 令 $x+1=t(t \geqslant 2)$ ，则 x=t-1，所以原函数等价于函数 $g(t)=\frac{t^{2}+t+1}{t}=t+\frac{1}{t}+1(t \geqslant 2)$ 。由对钩函数的性质知函数 $g(t)$ 在 $[2, +\infty)$ 上单调递增，所以当 t=2，即 x=1 时函数 $g(t)$ 取得最小值 $\frac{7}{2}$ ，所以函数 $f(x)$ 的最小值为 $\frac{7}{2}$ 。
