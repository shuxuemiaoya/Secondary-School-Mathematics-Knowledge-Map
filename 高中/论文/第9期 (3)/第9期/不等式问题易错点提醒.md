# 不等式问题易错点提醒

# ■傅欣飞

# 易错点一:忽略不等式成立的前提条件

例 1 若 $a, b, c \in R$ ，且 a > b，则下列不等式中成立的是（）。

A. $\frac{1}{a} < \frac{1}{b}$

B. $a^2 > b^2$

C. $\frac{a}{c^2 + 1} >\frac{b}{c^2 + 1}$

D. $a \mid c \mid > b \mid c \mid$

剖析: 若忽略 a, b 是否同号, 容易错选 A; 若忽略 a, b 不一定都大于零, 容易错选 B; 若忽略 c 是否为零, 容易错选 D。

解:对于 A, B, 取 a=1, b=-1, 满足 a>b, 显然 $\frac{1}{a}<\frac{1}{b}$ 和 $a^{2}>b^{2}$ 不成立, A, B 错误。对于 C, 因为 $\frac{1}{c^{2}+1}>0$ , 所以 $\frac{a}{c^{2}+1}>\frac{b}{c^{2}+1}$ , C 正确。对于 D, 取 c=0, 显然 $a|c|>b|c|$ 不成立, D 错误。应选 C。

提醒:不等式的真假判断问题,可以利用特殊值排除,也可以利用不等式的性质进行推理判断。

# 易错点二: 解含参数不等式讨论不全面出错

例 2 （多选题）对于给定实数 a，关于 x 的一元二次不等式 $(ax-1)(x+1)<0$ 的解集可能是（）。

A. $\{x\mid -1 <   x <   \frac{1}{a}\}$

B. $\{x\mid x\neq-1\}$

C. $\left\{x\mid \frac{1}{a} <  x <   - 1\right\}$

D. $\mathbf{R}$

剖析: 分类讨论时, 容易忽略 a = 0 和 a = -1, 以及两个根的大小而出错。

解:由 $(ax-1)(x+1)<0$ ,可对a进行分类讨论。

当 $a > 0$ 时，可得 $-1 < x < \frac{1}{a}$ ；当 $a = 0$ 时，可得 $x > -1$ ；当 $-1 < a < 0$ 时，可得 $x < \frac{1}{a}$ 或 $x > -1$ ；当 $a = -1$ 时，可得 $x \neq -1$ ；当

a<-1 时, 可得 x<-1 或 $x>\frac{1}{a}$ 。结合选项知 A, B 适合, 应选 AB。

提醒:求解含参数的一元二次不等式,抓住三点就可以避免失误:一是二次项系数是否需要讨论;二是方程根的存在性是否需要讨论;三是根的大小关系是否需要讨论。

# 易错点三: 多变量不等式中混淆主元出错

例 3 已知对任意的 $m \in [1,3]$ , $mx^{2} - mx - 1 < -m + 5$ 恒成立，则实数 x 的取值范围是（）。

A. $\left(\frac{6}{7},+\infty\right)$

B. $\left(-\infty,\frac{1-\sqrt{5}}{2}\right)\cup\left(\frac{1+\sqrt{5}}{2},+\infty\right)$

C. $\left(-\infty,\frac{6}{7}\right)$

D. $\left(\frac{1-\sqrt{5}}{2},\frac{1+\sqrt{5}}{2}\right)$

剖析:题设条件中含有两个变量,容易因分不清主元而出错。

解:对任意的 $m \in [1,3]$ ，不等式 $mx^{2} - mx - 1 < -m + 5$ 恒成立，即对任意的 $m \in [1,3]$ ， $m(x^{2} - x + 1) < 6$ 恒成立，所以对任意的 $m \in [1,3]$ ， $x^{2} - x + 1 < \frac{6}{m}$ 恒成立，所以对任意的 $m \in [1,3]$ ， $x^{2} - x + 1 < \left(\frac{6}{m}\right)_{\min} = 2$ ，所以 $x^{2} - x + 1 < 2$ ，解得 $\frac{1 - \sqrt{5}}{2} < x < \frac{1 + \sqrt{5}}{2}$ 。故实数 x 的取值范围是 $\left(\frac{1 - \sqrt{5}}{2}, \frac{1 + \sqrt{5}}{2}\right)$ 。应选 D。

提醒:解决恒成立问题,一定要清楚选谁为主元,谁是参数。一般情况下,知道谁的范围,就选谁当主元,求谁的范围,谁就是参数。
