集合是高考的必考内容之一,高考主要考查集合的基本概念,以及集合语言和集合思想的运用。由于集合里的概念较多,逻辑性较强,关系复杂,因此同学们在学习过程中常常会不知不觉地出错。下面对集合问题中常见的错误进行分类剖析。

# 一、忽视代表元素的特征

例 1 已知集合 $A=\{y \mid y=x^{2}, x \in R\}$ ， $B=\{y \mid y=3x-2, x \in R\}$ ，求 $A \cap B$ 。

错解 1: 由方程组 $\left\{\begin{aligned}y&=x^{2},\\ y&=3x-2,\end{aligned}\right.$ 解得 $\left\{\begin{aligned}x_{1}&=1,\\ y_{1}&=1\end{aligned}\right.$ 或 $\left\{\begin{aligned}x_{2}&=2,\\ y_{2}&=4,\end{aligned}\right.$ 所以 $A\cap B=\{(1,1),(2,4)\}$ 。

错解 2: 由 $x^{2}=3x-2$ ，可得 $x_{1}=1, x_{2}=2$ ，所以 $y_{1}=1, y_{2}=4$ ，所以 $A \cap B = \{1, 2, 4\}$ 。

分析:集合 $\{(x,y)\mid y=f(x),x\in\mathbf{R}\}$ 表示函数 $f(x)$ 图像上的点组成的集合,集合 $\{y\mid y=f(x),x\in\mathbf{R}\}$ 表示函数 $f(x)$ 的函数值的取值范围(即函数 $f(x)$ 的值域)。

正解:由题意得集合 $A=\{y \mid y \geqslant 0\}$ ， $B=\{y \mid y \in R\}=R$ ，所以 $A \cap B=\{y \mid y \geqslant 0\}$ 。

# 二、忽视元素的互异性

例 2 已知集合 $A=\{1,3,x\}$ , $B=\{x^{2},1\}$ , $A \cup B=\{1,3,x\}$ , 求 x 的值。

错解: 由 $A \cup B = A$ ，可知 $B \subseteq A$ ，所以 $x^{2} \in A$ 。若 $x^{2} = 1$ ，则 $x = \pm 1$ ；若 $x^{2} = 3$ ，则 $x = \pm \sqrt{3}$ ；若 $x^{2} = x$ ，则 x = 0 或 x = 1。所以 x 的值为 $-\sqrt{3}, -1, 0, 1, \sqrt{3}$ 。

分析: 若 $x = \pm 1$ ，则 $B = \{1, 1\}$ ， $A = \{1, 3, 1\}$ ，这时不满足集合元素的互异性。

正解:由分析可知,应舍去 $x=\pm1$ , 所以 x 的值为 $-\sqrt{3},0,\sqrt{3}$ 。

# 三、忽视对参数的讨论

例 3 已知集合 $A = \{x \mid mx - 1 = 0\}$ , $B = \{x \mid x^2 - 3x + 2 = 0\}$ , 若 $A \subseteq B$ , 则 $m =$ \_\_\_\_。

错解: 易得 $A=\left\{\frac{1}{m}\right\}, B=\{1,2\}$ 。因为 $A \subseteq B$ ，所以 $\frac{1}{m}=1$ 或 $\frac{1}{m}=2$ ，解得 m=1 或 $m=\frac{1}{2}$ 。故 m 的值是 $1,\frac{1}{2}$ 。

# 四、忽视补集的含义

例 4 已知全集 I = R，集合 M = $\{x \mid x^{2} - x < 0\}$ ，集合 $N = \left\{x \mid \frac{1}{x} \leqslant 1\right\}$ ，则下列关系正确的是（）。

A. $M \subseteq C_{I} N$   
B. $M \supseteq \complement_{I} N$   
C. $M = \complement_{I}N$   
D. $(\complement_{I}M)\cup N = \mathbf{R}$

错解:由题意得 $M=\{x \mid 0 < x < 1\}$ 。因为 $N=\left\{x \mid \frac{1}{x} \leqslant 1\right\}$ ，所以 $C_{I}N=\left\{x \mid \frac{1}{x} > 1\right\}=\{x \mid 0 < x < 1\}$ 。应选 C。

分析:上述解法认为 $A=\{x \mid f(x) \leqslant 0\}$ 的补集为 $C_{I}A=\{x \mid f(x) > 0\}$ 。事实上，对于全集 I，由补集的定义得 $A \cup (C_{I}A) = I$ 。

正解：由题意得 $N = \left\{x\mid \frac{1}{x}\leqslant 1\right\} =$ $\left\{x\mid \frac{x - 1}{x}\geqslant 0\right\} = \{x\mid x <   0$ 或 $x\geqslant 1\}$ ，所以 $C_I N = \{x\mid 0\leqslant x <   1\}$ 。而 $M = \{x\mid 0 <   x <$ $1\}$ ，所以 $M\subseteq C_I N$ 。应选A。
