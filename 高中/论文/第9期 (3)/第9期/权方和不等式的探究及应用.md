# 一、权方和不等式的探究及证明

权方和不等式: 若 a, b, x, y > 0, 则 $\frac{a^{2}}{x} + \frac{b^{2}}{y} \geqslant \frac{(a+b)^{2}}{x+y}$ ，当且仅当 $\frac{a}{x} = \frac{b}{y}$ 时取等号。

证明如下: 由 a, b, x, y > 0, $\frac{a^{2}}{x} + \frac{b^{2}}{y} \geqslant \frac{(a+b)^{2}}{x+y}$ ，变形得 $(x+y)\left(\frac{a^{2}}{x} + \frac{b^{2}}{y}\right) \geqslant (a + b)^{2}$ 。因为 $(x+y)\left(\frac{a^{2}}{x} + \frac{b^{2}}{y}\right) = a^{2} + b^{2} + \left(\frac{ya^{2}}{x} + \frac{xb^{2}}{y}\right) \geqslant a^{2} + b^{2} + 2ab = (a+b)^{2}$ ，即 $(x+y)\left(\frac{a^{2}}{x} + \frac{b^{2}}{y}\right) \geqslant (a+b)^{2}$ ，所以 $\frac{a^{2}}{x} + \frac{b^{2}}{y} \geqslant \frac{(a+b)^{2}}{x+y}$ ，当且仅当 $\frac{a}{x} = \frac{b}{y}$ 时取等号。

推广 1: 若 a, b, c, x, y, z > 0，则 $\frac{a^{2}}{x} + \frac{b^{2}}{y} + \frac{c^{2}}{z} \geqslant \frac{(a + b + c)^{2}}{x + y + z}$ ，当且仅当 $\frac{a}{x} = \frac{b}{y} = \frac{c}{z}$ 时等号成立。

推广 2: 若 $a_{i}>0, b_{i}>0$ ，则 $\frac{a_{1}^{2}}{b_{1}}+\frac{a_{2}^{2}}{b_{2}}+\cdots+\frac{a_{n}^{2}}{b_{n}}\geqslant\frac{(a_{1}+a_{2}+\cdots+a_{n})^{2}}{b_{1}+b_{2}+\cdots+b_{n}}$ ，当且仅当 $a_{i}=\lambda b_{i}(i\in\mathbf{N}^{*})$ 时等号成立。

# 二、权方和不等式的应用

1. 两变量与两变量的倒数和有一个为定值可求另一个的最小值

例 1 已知正数 x, y 满足 $\frac{4}{x} + \frac{9}{y} = 1$ ，则 $\frac{4}{2x^{2} + x} + \frac{9}{y^{2} + y}$ 的最小值为 \_\_\_\_。

$$
\begin{array}{r l} & {\text {解}: \frac {4}{2 x ^ {2} + x} + \frac {9}{y ^ {2} + y} = \frac {4 ^ {2}}{4 (2 x ^ {2} + x)} +} \\ & {\frac {9 ^ {2}}{9 (y ^ {2} + y)} = \frac {\frac {4 ^ {2}}{x ^ {2}}}{8 + \frac {4}{x}} + \frac {\frac {9 ^ {2}}{y ^ {2}}}{9 + \frac {9}{y}} \geqslant \frac {\left(\frac {4}{x} + \frac {9}{y}\right) ^ {2}}{\frac {4}{x} + \frac {9}{y} + 1 7} =} \end{array}
$$

$\frac{1}{18}$ ，当且仅当 $\frac{\frac{4}{x}}{8+\frac{4}{x}}=\frac{\frac{9}{y}}{9+\frac{9}{y}}$ 时取等号。由

$\left\{ \begin{array}{l} \frac{4}{x} + \frac{9}{y} = 1, \\ \frac{\frac{4}{x}}{8 + \frac{4}{x}} = \frac{\frac{9}{y}}{9 + \frac{9}{y}}, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} x = \frac{17}{2}, \\ y = 17. \end{array} \right.$ 故当 $\left\{ \begin{array}{l} x = \frac{17}{2}, \\ y = 17. \end{array} \right.$ 时， $\frac{4}{2x^2 + x} + \frac{9}{y^2 + y}$ 的最小值为 $\frac{1}{18}$ 。

体验:权方和不等式揭示了正数范围内的两变量 x, y 和正常数 a, b 满足不等式 $\frac{a^{2}}{x} + \frac{b^{2}}{y} \geqslant \frac{(a + b)^{2}}{x + y}$ ，当且仅当 $\frac{a}{x} = \frac{b}{y}$ 时不等式取等号。当一端为定值时，另一端可求最值。

2. 两变量倒数和为定值探究两变量和的最小值

例 2 已知 a > b > 0，且满足 $\frac{2}{a + 2} + \frac{1}{a + 2b} = 1$ ，则 $a + b$ 的最小值为 \_\_\_\_。

解:由权方和不等式知 $\frac{2}{a+2}+\frac{1}{a+2b}\geqslant\frac{(\sqrt{2}+\sqrt{1})^{2}}{(a+2)+(a+2b)}$ 。因为 $\frac{2}{a+2}+\frac{1}{a+2b}=1$ ，
所以 $1 \geqslant \frac{(\sqrt{2} + \sqrt{1})^{2}}{(a+2) + (a+2b)}$ ，所以 $a + b \geqslant \frac{1}{2} + \sqrt{2}$ ，当且仅当 $\frac{\sqrt{2}}{a+2} = \frac{1}{a+2b}$ ，即 $a = \sqrt{2}$ ， $b = \frac{1}{2}$ 时取等号，所以 $a + b$ 的最小值为 $\frac{1}{2} + \sqrt{2}$ 。

体验:解答本题的关键是权方和不等式的灵活应用。

3. 凑出两变量的和为定值求两变量的倒数和的最小值

例 3 权方和不等式作为基本不等式的一个变化,在求二元变量最值时有很广泛的应用。根据权方和不等式,求函数 $f(x)=\frac{3}{x}+\frac{1}{2-3x}\left(0<x<\frac{2}{3}\right)$ 的最小值。

解: 利用权方和不等式求最小值。因为 $0 < x < \frac{2}{3}$ ，即 2 - 3x > 0，所以 $f(x) = \frac{3}{x} + \frac{1}{2 - 3x} = \frac{3^2}{3x} + \frac{1^2}{2 - 3x} \geqslant \frac{(3 + 1)^2}{3x + (2 - 3x)} = 8$ ，当且仅当 $\frac{3}{3x} = \frac{1}{2 - 3x}$ ，即 $x = \frac{1}{2}$ 时等号成立，所以函数 $f(x) = \frac{3}{x} + \frac{1}{2 - 3x} \left(0 < x < \frac{2}{3}\right)$ 的最小值为 8。

体验: 将给定函数式表示为权方和不等式的左边结构特征是解答本题的关键。

4. 两种思维方法探究二元变量的最大值问题

例 4 已知 x > 0, y > 0，且满足 $4x^{2} + 9y^{2} + 6xy - 3 = 0$ ，则 $2x + 3y$ 的最大值为 \_\_\_\_。

解法1:对题设条件进行变形,构建基本不等式求最大值。由 $4x^{2}+9y^{2}+6xy-3=0$ ,可得 $4x^{2}+9y^{2}+12xy=3+6xy$ 。结合基本不等式得 $(2x+3y)^{2}=3+2x\cdot3y\leqslant3+\left(\frac{2x+3y}{2}\right)^{2}$ ,所以 $\frac{3}{4}(2x+3y)^{2}\leqslant3$ ,所以 $2x+3y\leqslant2$ ,当且仅当2x=3y时取等号。由方程组 $\left\{\begin{aligned}&2x=3y,\\ &4x^{2}+9y^{2}+6xy-3=0,\end{aligned}\right.$ 解得 $x=\frac{1}{2}$ , $y=\frac{1}{3}$ ,即当 $x=\frac{1}{2},y=\frac{1}{3}$ 时不等式取等号。故 $2x+3y$ 的最大值为2。

解法 2: 对题设条件变形凑定值, 利用权方和不等式求最大值。由 $4x^{2} + 9y^{2} + 6xy - 3 = 0$ , 可得 $(x^{2} + 9y^{2} + 6xy) + 3x^{2} = (x + 3y)^{2} + 3x^{2} = 3$ 。已知 x > 0, y > 0, 由权方和不等式得 $3 = \frac{(x + 3y)^{2}}{1} + \frac{x^{2}}{\frac{1}{3}} \geqslant \frac{(x + 3y + x)^{2}}{1 + \frac{1}{3}}$ , 即 $4 \geqslant (2x + 3y)^{2}$ , 所以 $2x + 3y \leqslant 2$ , 当且仅当 $\frac{x + 3y}{1} = \frac{x}{\frac{1}{3}}$ , 即 2x = 3y 时取

等号。由方程组 $\left\{ \begin{array}{l} 2x = 3y, \\ 4x^2 + 9y^2 + 6xy - 3 = 0, \end{array} \right.$ 解得 $x = \frac{1}{2}, y = \frac{1}{3}$ , 即当 $x = \frac{1}{2}, y = \frac{1}{3}$ 时不等式取等号。故 $2x + 3y$ 的最大值为 2。

体验:两种方法都需要凑出定值,构建不等式求最值。解法1利用 $(2x+3y)^{2}=3+2x\cdot3y\leqslant3+\left(\frac{2x+3y}{2}\right)^{2}$ 求出最大值;解法2利用 $(x^{2}+9y^{2}+6xy)+3x^{2}=(x+3y)^{2}+3x^{2}=3$ ,结合权方和不等式求出最大值。

5. 多元权方和不等式的应用

例 5 已知 $x + 2y + 3z + 4u + 5v = 30$ ，则 $x^{2} + 2y^{2} + 3z^{2} + 4u^{2} + 5v^{2}$ 的最小值为 \_\_\_\_。

解: 利用五元权方和不等式求最小值。

因为 $x^{2} + 2y^{2} + 3z^{2} + 4u^{2} + 5v^{2} = \frac{x^{2}}{1} +$ $\frac{(2y)^2}{2} +\frac{(3z)^2}{3} +\frac{(4u)^2}{4} +\frac{(5v)^2}{5}\geqslant$ $\frac{(x + 2y + 3z + 4u + 5v)^2}{1 + 2 + 3 + 4 + 5} = \frac{30^2}{15} = 60$ ，当且仅当 $x = y = z = u = v$ 时取等号，所以 $x^{2}+$ $2y^{2} + 3z^{2} + 4u^{2} + 5v^{2}$ 的最小值为60。

体验: 利用二元权方和不等式, 可推出多元权方和不等式, 同学们要注意灵活运用。

函数 $f(x) = \frac{3}{x} +\frac{16}{1 - 3x}\left(0 <   x <   \frac{1}{3}\right)$ 的最小值为（ ）。

A. 16

B. 25

C. 36

D. 49

提示: 因为 $0 < x < \frac{1}{3}$ ，即 1 - 3x > 0，所以 $f(x) = \frac{3^{2}}{3x} + \frac{4^{2}}{1 - 3x} \geqslant \frac{(3 + 4)^{2}}{3x + (1 - 3x)} = 49$ ，当且仅当 $\frac{1}{x} = \frac{4}{1 - 3x}$ ，即 $x = \frac{1}{7}$ 时取等号，所以函数 $f(x) = \frac{3}{x} + \frac{16}{1 - 3x} \left(0 < x < \frac{1}{3}\right)$ 的最小值为 49。应选 D。
