# 考法一:集合的子集、真子集及参数问题

例 1 设集合 $A = \{r_1, r_2, \cdots, r_n\} \subseteq \{2, 3, 4, \cdots, 36, 37\} (n \geqslant 2, n \in \mathbb{N})$ ，且 $A$ 中任意两数之和不能被 5 整除，则 $n$ 的最大值为 \_\_\_\_。

解:根据除以 5 的余数,可将集合 A 分为 5 组:

$A_{0}=\{5,10,15,20,25,30,35\}$ ，则 $\mathrm{card}(A_{0})=7$ 。

$A_{1}=\{6,11,16,21,26,31,36\}$ ，则 $\mathrm{card}(A_{1})=7$ 。

$A_{2}=\{2,7,12,17,22,27,32,37\}$ ，则 $\mathrm{card}(A_{2})=8$ 。

$A_{3}=\{3,8,13,18,23,28,33\}$ ，则 $\mathrm{card}(A_{3})=7$ 。

$A_{4}=\{4,9,14,19,24,29,34\}$ ，则 $\mathrm{card}(A_{4})=7$ 。

因为 A 中的任意两个数之和不能被 5 整除, 所以 $A_{1}$ 和 $A_{4}, A_{2}$ 和 $A_{3}$ 中不能同时取数, 且 $A_{0}$ 中最多取一个, 所以最多的取法是取 $A_{1}, A_{2}$ 中的所有元素和 $A_{0}$ 中的一个元素, 可得 $\text{card}(A)_{\max}=7+8+1=16$ 。故 n 的最大值为 16。

点睛:两数之和能被5整除,则这两数分别除以5的余数之和能被5整除。

# 考法二: 集合的交集、并集、补集运算及参数问题

例 2 设集合 $P=\{x \mid -2 < x < 3\}$ ，集合 $Q=\{x \mid 3a < x \leqslant a + 1\}$ 。

(1) 若 $Q \subseteq P$ ，求实数 a 的取值范围。  
(2) 若 $P \cap Q = \varnothing$ ，求实数 a 的取值范围。

解:(1)当 $Q=\varnothing$ 时,由 $3a\geqslant a+1$ , 解得 $a\geqslant\frac{1}{2}$ , 满足题意; 当 $Q\neq\varnothing$ 时, 由 $Q\subseteq P$ , 可

得 $\left\{\begin{aligned}3a&\geqslant-2,\\ a+1&<3,\end{aligned}\right.$ 解得 $-\frac{2}{3}\leqslant a<\frac{1}{2}$ 。

综上所述,实数 a 的取值范围为 $\left[-\frac{2}{3}, +\infty\right)$ 。

(2) 当 $Q = \varnothing$ 时，由 $3a \geqslant a + 1$ ，解得 $a \geqslant \frac{1}{2}$ ，满足题意；当 $Q \neq \varnothing$ 时，由 $P \cap Q = \varnothing$ ，可得 $\left\{\begin{aligned} a+1 &\leqslant-2, \\ 3a &<a+1 \end{aligned}\right.$ 或 $\left\{\begin{aligned}3a &\geqslant3, \\ 3a &<a+1,\end{aligned}\right.$ 解得 $a \leqslant -3$ 。

综上所述,实数 a 的取值范围为 $(-∞, -3]∪\left[\frac{1}{2}, +∞\right)$ 。

点睛: 解答本题的关键是对 $Q = \varnothing$ 和 $Q \neq \varnothing$ 这两种情况进行讨论。

# 考法三:集合中的新定义问题

例3 定义集合 $P = \{x \mid a \leqslant x \leqslant b\}$ 的“长度”是 $b - a$ ，其中 $a, b \in \mathbb{R}$ 。已如集合 $M = \left\{x \mid m \leqslant x \leqslant m + \frac{1}{2}\right\}, N = \left\{x \mid n - \frac{3}{5} \leqslant x \leqslant n\right\}$ ，且 $M, N$ 都是集合 $\{x \mid 1 \leqslant x \leqslant 2\}$ 的子集，则集合 $M \cap N$ 的“长度”的最小值是 \_\_\_\_。

解:由题意得 $\left\{\begin{aligned}m&\geqslant1,\\ m+\frac{1}{2}&\leqslant2,\end{aligned}\right.$ 解得 $1\leqslant m\leqslant \frac{3}{2}$ 。由题意得 $\left\{\begin{aligned}n-\frac{3}{5}&\geqslant1,\\ n&\leqslant2,\end{aligned}\right.$ 解得 $\frac{8}{5}\leqslant n\leqslant2$ 。

要使 $M \cap N$ 的“长度”最小, 只有当 m 取最小值、n 取最大值或 m 取最大值、n 取最小值时才成立。

当 $m = 1, n = 2$ 时， $M \cap N = \left\{x \mid \frac{7}{5} \leqslant x \leqslant \frac{3}{2}\right\}$ ，则“长度”为 $\frac{3}{2} - \frac{7}{5} = \frac{1}{10}$ ；当 $m = \frac{3}{2}$ ， $n = \frac{8}{5}$ 时， $M \cap N = \left\{x \mid \frac{3}{2} \leqslant x \leqslant \frac{8}{5}\right\}$ ，则“长度”为 $\frac{8}{5} - \frac{3}{2} = \frac{1}{10}$ 。

故集合 $M \cap N$ 的“长度”的最小值是 $\frac{1}{10}$ 。

点睛:解答本题的关键是充分理解“长度”的定义,根据交集、并集的含义得到不等式组,再结合分类讨论思想求解。
