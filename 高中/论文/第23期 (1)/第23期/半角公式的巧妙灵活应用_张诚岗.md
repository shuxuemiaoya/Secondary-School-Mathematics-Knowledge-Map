# 半角公式的巧妙灵活应用

# 四川省蓬溪中学校 张诚岗

结合三角函数的二倍角公式,合理恒等变形,可以用单角 $\alpha$ 的三角函数式表示半角 $\frac{\alpha}{2}$ 的三角函数式,即为三角函数的半角公式.三角函数的半角公式在实际解答三角函数问题中有着很大的应用.

# 1 回归教材,构建公式

人民教育出版社2019年国家教材委员会专家委员会审核通过的《数学》(A版必修第一册)第五章三角函数中“5.5三角恒等变换”的例7有结果： $\sin \frac{\alpha}{2} =$ $\pm \sqrt{\frac{1 - \cos\alpha}{2}}$ ， $\cos \frac{\alpha}{2} = \pm \sqrt{\frac{1 + \cos\alpha}{2}}$ ， $\tan \frac{\alpha}{2} =$ $\pm \sqrt{\frac{1 - \cos\alpha}{1 + \cos\alpha}}$ （符号由 $\frac{\alpha}{2}$ 所在象限决定），第226页练习的第1题“求证： $\tan \frac{\alpha}{2} = \frac{\sin\alpha}{1 + \cos\alpha} = \frac{1 - \cos\alpha}{\sin\alpha}$ ”.

以上几组公式都涉及到求半角的三角函数值,往往将以上这些公式统称为半角公式.

(1) 半角公式的有理表达式: $\tan\frac{\alpha}{2}=\frac{\sin\alpha}{1+\cos\alpha}=\frac{1-\cos\alpha}{\sin\alpha}$ ，其中 $\tan\frac{\alpha}{2}$ 的符号由 $\sin\alpha$ 的符号确定，而无需讨论，应用非常方便.  
(2) 半角公式的无理表达式包括: $\sin \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{2}}, \cos \frac{\alpha}{2} = \pm \sqrt{\frac{1 + \cos \alpha}{2}}, \tan \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{1 + \cos \alpha}}$ , 其中根号前的符号 (正负) 由对应角 $\frac{\alpha}{2}$ 的三角函数值的符号确定.

# 2 考题呈现,巧妙破解

考题（2024年九省普通高考适应性测试数学试卷·7）已知 $\theta \in \left(\frac{3\pi}{4},\pi\right),\tan 2\theta = -4\tan \left(\theta +\frac{\pi}{4}\right)$ ，则 $\frac{1 + \sin 2\theta}{2\cos^2\theta + \sin 2\theta} = (\quad)$

A. $\frac{1}{4}$

B. $\frac{3}{4}$

C.1

D. $\frac{3}{2}$

分析:结合二倍角的正切值与两角和的正切值之间的关系式,进而求解与单角、二倍角三角函数值有

关的分式的值,合理建立条件与结论中的三角关系式之间的联系,综合应用三角函数中的相关公式加以综合与应用,从不同思维视角切入,合理变形转化,巧妙求值应用.

解法 1: 化“切”为“弦”法.

依题，由 $\tan 2\theta = -4\tan \left(\theta +\frac{\pi}{4}\right)$ ，可得 $\frac{\sin 2\theta}{\cos 2\theta} =$ $-4\times \frac{1 - \cos\left(2\theta + \frac{\pi}{2}\right)}{\sin\left(2\theta + \frac{\pi}{2}\right)}$ ，即 $\frac{\sin 2\theta}{\cos 2\theta} = -4\times \frac{1 + \sin 2\theta}{\cos 2\theta},$ 亦即 $\sin 2\theta = -\frac{4}{5}.$

又 $\theta \in \left(\frac{3\pi}{4},\pi\right)$ ，可知 $2\theta \in \left(\frac{3\pi}{2},2\pi\right)$ ，则有 $\cos 2\theta =$ $\sqrt{1 - \sin^2 2\theta} = \frac{3}{5}$ ，从而可以得到 $\frac{1 + \sin 2\theta}{2\cos^2\theta + \sin 2\theta} =$ $\frac{1 + \sin 2\theta}{1 + \cos 2\theta + \sin 2\theta} = \frac{1 - \frac{4}{5}}{1 + \frac{3}{5} - \frac{4}{5}} = \frac{1}{4}.$

反思:根据题设条件中的三角函数关系式的结构特征,利用同角三角函数基本关系式中的商的关系,以及半角公式 $\tan\frac{\theta}{2}=\frac{\sin\theta}{1+\cos\theta}=\frac{1-\cos\theta}{\sin\theta}$ , 合理化“切”为“弦”,通过化同角变形与转化,进而综合三角函数中的相关知识加以分析与应用.

解法 2: 化同角法.

依题，由 $\tan 2\theta = -4\tan \left(\theta +\frac{\pi}{4}\right)$ ，可得 $\frac{2\tan\theta}{1 - \tan^2\theta} =$ $-4\times \frac{\tan\theta + 1}{1 - \tan\theta}$ 整理有 $2\tan^2\theta +5\tan \theta +2 = 0$ ，解得 $\tan \theta = -2$ 或 $\tan \theta = -\frac{1}{2}$

又 $\theta \in \left(\frac{3\pi}{4},\pi\right)$ ，则知 $\tan \theta = -\frac{1}{2}$

所以 $\frac{1+\sin2\theta}{2\cos^{2}\theta+\sin2\theta}=\frac{(\sin\theta+\cos\theta)^{2}}{2\cos\theta(\cos\theta+\sin\theta)}=$ $\frac{\sin\theta+\cos\theta}{2\cos\theta}=\frac{1}{2}(\tan\theta+1)=\frac{1}{2}\left(-\frac{1}{2}+1\right)=\frac{1}{4}.$

反思:根据题设条件中的三角函数关系式的结构特征,利用二倍角的正切公式以及两角和的正切公式加以化同角处理,通过方程的建立与求解,以及角的取值限制来确定对应角的正切值,结合所求三角关系式的同角化变形与转化来分析与求解.

解法 3: 齐次化法.

以上部分同解法 2, 可得 $\tan\theta=-\frac{1}{2}$ .

所以 $\frac{1 + \sin 2\theta}{2\cos^2\theta + \sin 2\theta} = \frac{\sin^2\theta + \cos^2\theta + 2\sin\theta\cos\theta}{2\cos^2\theta + 2\sin\theta\cos\theta} =$

$$
\frac {\tan^ {2} \theta + 1 + 2 \tan \theta}{2 + 2 \tan \theta} = \frac {\frac {1}{4} + 1 - 1}{2 - 1} = \frac {1}{4}.
$$

反思:根据题设条件中的三角函数关系式的结构特征,在求得单角的正切值的情况下,通过所求三角函数关系式的齐次化处理,合理三角恒等变形转化,对于三角函数值的求解也是一种比较基本解题思维.

# 3 思路总结,特别提醒

# 3.1 解题思路

利用三角函数的半角公式求解三角函数值的基本思路：

(1) 看角: 若已知三角函数式中的角是待求三角函数式中角的两倍, 则求解时常常借助半角公式求解.  
(2) 明范围: 用半角公式求值常涉及符号问题, 因此求解时需依据角的范围, 求出相应半角的范围.  
(2)选公式:涉及半角公式的正切值时,经常选用 $\tan\frac{\alpha}{2}=\frac{\sin\alpha}{1+\cos\alpha}=\frac{1-\cos\alpha}{\sin\alpha}$ ,其优点是计算时可避免因开方带来的求角的范围问题;涉及半角的正弦值、余弦值时,通常先利用 $\sin^{2}\frac{\alpha}{2}=\frac{1-\cos\alpha}{2},\cos^{2}\frac{\alpha}{2}=\frac{1+\cos\alpha}{2}$ 计算.

# 4 开拓思维,综合应用

例1 已知 $\sin 2\theta = \frac{3}{5}$ , 其中 $0 < 2\theta < \frac{\pi}{2}$ , 则

$$
\frac {2 \cos^ {2} \frac {\theta}{2} - \sin \theta - 1}{\sqrt {2} \sin \left(\theta + \frac {\pi}{4}\right)} = \underline {{{}}}.
$$

解析: 易得 $\frac{2\cos^{2}\frac{\theta}{2}-\sin\theta-1}{\sqrt{2}\sin\left(\theta+\frac{\pi}{4}\right)}=\frac{\cos\theta-\sin\theta}{\sin\theta+\cos\theta}=$

$$
\frac {1 - \frac {\sin \theta}{\cos \theta}}{\frac {\sin \theta}{\cos \theta} + 1} = \frac {1 - \tan \theta}{\tan \theta + 1}.
$$

由 $\sin 2\theta = \frac{3}{5}, 0 < 2\theta < \frac{\pi}{2}$ , 可得 $\cos 2\theta = \frac{4}{5}$ , 所以

利用半角公式有 $\tan\theta=\frac{\sin2\theta}{1+\cos2\theta}=\frac{\frac{3}{5}}{1+\frac{4}{5}}=\frac{1}{3}$ .

故 $\frac{2\cos^2\frac{\theta}{2} - \sin\theta - 1}{\sqrt{2}\sin\left(\theta + \frac{\pi}{4}\right)} = \frac{1 - \tan\theta}{\tan\theta + 1} = \frac{1 - \frac{1}{3}}{\frac{1}{3} + 1} = \frac{1}{2}.$

点评:借助题设条件与所求三角关系式的结构特征,合理加以恒等变形与转化,综合应用二倍角公式、两角和正弦公式、同角三角函数基本关系式、半角公式等,是三角函数求值问题中的综合应用,全面考查三角函数模块的基本知识与基本能力.

例 2 证明: $\tan\frac{\alpha}{2}=\frac{1+\sin\alpha-\cos\alpha}{1+\sin\alpha+\cos\alpha}.$

证明:由半角公式 $\tan\frac{\alpha}{2}=\frac{\sin\alpha}{1+\cos\alpha}=\frac{1-\cos\alpha}{\sin\alpha}$ ，结合比例中的合分比定理，得 $\frac{\sin\alpha}{1+\cos\alpha}=\frac{1-\cos\alpha}{\sin\alpha}=\frac{\sin\alpha+(1-\cos\alpha)}{1+\cos\alpha+\sin\alpha}=\frac{1+\sin\alpha-\cos\alpha}{1+\sin\alpha+\cos\alpha}=\tan\frac{\alpha}{2}$ .

故原等式成立.

点评:证明以上三角关系式成立的一般思维是通过等式右边中相关二倍角公式的转化来证明,而利用半角公式的有理表达式与合分比定理,结合等式两边的差异与构成,合理变形与转化,更加快捷方便.

三角函数的半角公式,是依托三角恒等变换公式,并在此基础上的深入探究与拓展应用.熟练理解并掌握相应的三角函数半角公式及其两种不同形式(有理表达式与无理表达式),对于解决三角函数中的综合应用问题有奇效.正确构建公式,挖掘问题内涵,熟悉公式应用,巧妙灵活应用.Z
