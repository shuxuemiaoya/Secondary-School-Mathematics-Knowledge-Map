# 关注两个切线不等式的解题应用

# - 江苏省通州高级中学 龚小敏

摘要: 结合几则例题, 分类讨论两个切线不等式的应用, 以提高学生的解题能力, 发展学生的数学思维, 培养学生的核心素养.

关键词: 切线; 不等式; 应用; 高中数学

高中数学中,学习导数之后,易知曲线 $y=\ln x$ 在点(1,0)处的切线方程为 y=x-1,从而结合图象可得切线不等式 $\ln x\leqslant x-1$ ;同时也易知曲线 $y=e^{x}$ 在点(0,1)处的切线方程为 $y=x+1$ ,从而结合图象可得切线不等式 $e^{x}\geqslant x+1$ .

# 1 运用切线不等式 $\ln x \leqslant x - 1$ 解题

一般地，当涉及自然对数时，可考虑切线不等式 $\ln x \leqslant x - 1$ （当且仅当 $x = 1$ 时不等式取等号）及其变式 $\ln (x + 1) \leqslant x$ （当且仅当 $x = 0$ 时不等式取等号）的灵活运用.

# 1.1 求值

例 1 已知存在正实数 x, y 使得不等式 $\ln x - x^{2} + 1 \geqslant \ln y + \frac{4}{y^{2}} - \ln 4$ 成立，则 $x + y$ 的值等于 \_\_\_\_.

解析:由不等式 $\ln x - x^{2} + 1 \geqslant \ln y + \frac{4}{y^{2}} - \ln 4$ ,
变形可得不等式 $\ln\frac{4x}{y}+1\geqslant x^{2}+\frac{4}{y^{2}}.$

根据“切线不等式 $\ln x \leqslant x - 1$ ”，可得 $\ln \frac{4x}{y} \leqslant \frac{4x}{y} - 1$ ，即 $\ln \frac{4x}{y} + 1 \leqslant \frac{4x}{y}$ ，当且仅当 $\frac{4x}{y} = 1$ ，即 y = 4x 时，不等式取等号。另一方面，根据基本不等式可得 $x^{2} + \frac{4}{y^{2}} \geqslant 2\sqrt{x^{2} \cdot \frac{4}{y^{2}}} = \frac{4x}{y}$ ，即 $x^{2} + \frac{4}{y^{2}} \geqslant \frac{4x}{y}$ ，当且仅当 $x^{2} = \frac{4}{y^{2}}$ ，即 xy = 2 时，不等式取等号。综上，可知 $\frac{4x}{y} \geqslant \ln \frac{4x}{y} + 1 \geqslant x^{2} + \frac{4}{y^{2}} \geqslant \frac{4x}{y}$ ，从而必有 $\ln \frac{4x}{y} + 1 = \frac{4x}{y}$ 且 $x^{2} + \frac{4}{y^{2}} = \frac{4x}{y}$ ，因此 y = 4x 与 xy = 2 同时成立，解得 $x = \frac{\sqrt{2}}{2}, y = 2\sqrt{2}$ 。故 $x + y = \frac{5\sqrt{2}^{[1]}}{2}$ 。

评注: 本题设计较好, 侧重考查了切线不等式 $\ln x \leqslant x - 1$ 与基本不等式满足的取等条件在解题中的综合运用能力以及逻辑推理能力.

# 1.2 证明数列类不等式

例 2 已知 n 为正整数, 求证: $\frac{1^{2}+1+1}{1^{2}+1}\cdot\frac{2^{2}+2+1}{2^{2}+2}\cdot\frac{3^{2}+3+1}{3^{2}+3}\cdot\cdots\cdot\frac{n^{2}+n+1}{n^{2}+n}<e.$

证明: 易知本题即证 $\ln\frac{1^{2}+1+1}{1^{2}+1}+\ln\frac{2^{2}+2+1}{2^{2}+2}+\ln\frac{3^{2}+3+1}{3^{2}+3}+\cdots+\ln\frac{n^{2}+n+1}{n^{2}+n}<1.$

因为根据切线不等式的变式 $\ln(x+1)\leqslant x$ （当且仅当 x=0 时不等式取等号），可知 $\ln\frac{n^{2}+n+1}{n^{2}+n}=\ln\left(1+\frac{1}{n^{2}+n}\right)<\frac{1}{n^{2}+n}=\frac{1}{n}-\frac{1}{n+1}$ ，则 $\ln\frac{n^{2}+n+1}{n^{2}+n}<\frac{1}{n}-\frac{1}{n+1}$ ，所以，可知 $\ln\frac{1^{2}+1+1}{1^{2}+1}+\ln\frac{2^{2}+2+1}{2^{2}+2}+\ln\frac{3^{2}+3+1}{3^{2}+3}+\cdots+\ln\frac{n^{2}+n+1}{n^{2}+n}<\left(1-\frac{1}{2}\right)+\left(\frac{1}{2}-\frac{1}{3}\right)+\left(\frac{1}{3}-\frac{1}{4}\right)+\cdots+\left(\frac{1}{n}-\frac{1}{n+1}\right)=1-\frac{1}{n+1}<1$ ，从而可得不等式 $\ln\frac{1^{2}+1+1}{1^{2}+1}+\ln\frac{2^{2}+2+1}{2^{2}+2}+\ln\frac{3^{2}+3+1}{3^{2}+3}+\cdots+\ln\frac{n^{2}+n+1}{n^{2}+n}<1$ 成立。故得证。

评注:上述证明结合了分析法,解题关键在于灵活运用切线不等式的变式 $\ln(x+1)\leqslant x$ ,获得不等式 $\ln\frac{n^{2}+n+1}{n^{2}+n}<\frac{1}{n}-\frac{1}{n+1}$ ,据此可通过“放缩”加以巧妙证明.

# 1.3 证明函数类不等式

例3 已知函数 $f(x) = 2\ln x + x^2 - 1$ ，若 $x_1, x_2$ 是两个不相等的正数，且满足 $f(x_1) + f(x_2) = 0$ ，求

证： $x_{1} + x_{2} > 2$

证明：因为 $f(x_{1}) + f(x_{2}) = 0$ ，所以可得 $2\ln x_{1} + x_{1}^{2} - 1 + 2\ln x_{2} + x_{2}^{2} - 1 = 0$ ，再变形得 $2\ln (x_1x_2) + (x_1 + x_2)^2 -2x_1x_2 - 2 = 0$ ，即 $2\ln (x_1x_2) - 2x_1x_2 = 2 - (x_1 + x_2)^2.$ 根据“切线不等式 $\ln x\leqslant x - 1$ ”可知， $\ln (x_{1}x_{2})\leqslant x_{1}x_{2} - 1$ ，所以 $2\ln (x_{1}x_{2}) - 2x_{1}x_{2}\leqslant -2.$ 从而可得 $2 - (x_{1} + x_{2})^{2}\leqslant -2$ ，即 $(x_{1} + x_{2})^{2}\geqslant 4$ ，当且仅当 $x_{1}x_{2} = 1$ 且 $x_{1}^{2} + x_{2}^{2} = 2$ ，即 $x_{1} = x_{2} = 1$ 时，不等式取等号，这显然与题意“ $x_{1},x_{2}$ 是两个不相等的正数”矛盾，因此 $(x_{1} + x_{2})^{2}\geqslant 4$ 中的等号实际上取不到，所以 $(x_{1} + x_{2})^{2} > 4.$ 又 $x_{1},x_{2} > 0$ ，故 $x_{1} + x_{2} > 2.$

评注:本题证明的关键在于根据“切线不等式 $\ln x\leqslant x-1$ ”,将已知的含有两个变量 $x_{1},x_{2}$ 的等式 $f(x_{1})+f(x_{2})=0$ 转化为不等式 $2-(x_{1}+x_{2})^{2}\leqslant-2$ .此外,还需要关注化简所得不等式 $(x_{1}+x_{2})^{2}\geqslant4$ 中的“等号”实际上能否取到.

# 2 运用切线不等式 $\mathbf{e}^x \geqslant \mathbf{x} + 1$ 解题

一般地, 当涉及以无理数 e 为底的指数时, 可考虑切线不等式 $e^{x} \geqslant x + 1$ (当且仅当 x = 0 时不等式取等号) 及其变式 $e^{x} \geqslant ex$ (当且仅当 x = 1 时不等式取等号) 的灵活运用.

# 2.1 求参数的取值范围

例 4 对任意 x>0，不等式 $xe^{x}>\ln x+x+a$ 恒成立，则实数 a 的取值范围是 \_\_\_\_.

解析: 根据 $xe^{x} > \ln x + x + a$ ，变形得 $e^{\ln x + x} > \ln x + x + a$ ，所以 $e^{\ln x + x} - (\ln x + x) \geqslant a$ .

由“切线不等式 $e^{x} \geqslant x + 1$ ”，可知 $e^{\ln x + x} \geqslant \ln x + x + 1$ ，所以 $e^{\ln x + x} - (\ln x + x) \geqslant 1$ ，当且仅当 $\ln x + x = 0$ 时，不等式取等号。于是，结合不等式 $e^{\ln x + x} - (\ln x + x) \geqslant a$ 对任意 x > 0 恒成立，得 $a \leqslant 1$ 。

故所求实数 a 的取值范围是 $(-∞,1]$ .

评注:本题求解的关键在于两点.一是将已知不等式参变分离变形为 $\mathrm{e}^{\ln x+x}-(\ln x+x)\geqslant a$ ;二是根据“切线不等式 $e^{x}\geqslant x+1$ ”求解获得 $\mathrm{e}^{\ln x+x}-(\ln x+x)$ 的最小值为 1.

# 2.2 证明函数类不等式

例 5 对任意 x > 0，求证： $e^{x} + 4x^{4}\ln x \geqslant x^{5} + x^{4}$ .

证明:由于 x>0，因此要证 $e^{x}+4x^{4}\ln x\geqslant x^{5}+x^{4}$ ，即证 $x^{-4}e^{x}+4\ln x\geqslant x+1$ ，即证 $e^{x+\ln x^{-4}}+4\ln x\geqslant x+1$ ，即证 $e^{x-4\ln x}\geqslant x-4\ln x+1$ 。根据“切线不等式 $e^{x}\geqslant x+1$ ”，可知 $e^{x-4\ln x}\geqslant x-4\ln x+1$ 成立。故得证。

评注:上述证明过程灵活运用了分析法,关键在于对求证式的等价变形一定要到位,这样才便于顺利获证.此外,需注意“对任意 x>0,有 $x=e^{ln x}$ ”及“对任意 $x\in R$ ,有 $x=\ln e^{x}$ ”.

# 3 综合运用切线不等式 $\mathrm{e}^x \geqslant x + 1$ 和 $\ln x \leqslant x - 1$ 解题

一般地,当试题中同时涉及自然对数和以无理数e为底的指数时,可综合考虑切线不等式 $\ln x\leqslant x-1$ (当且仅当x=1时不等式取等号)和 $e^{x}\geqslant x+1$ (当且仅当x=0时不等式取等号)在解题中的的灵活、综合运用 $^{[2]}$ .

# 3.1 比较大小

例 6 已知 $a=\ln\frac{3}{2}$ , $b=\frac{2}{3}$ , $c=e^{-\frac{1}{2}}$ ，则 a, b, c 的大小关系为（）.

$$
\mathrm{A}. a <   b <   c
$$

$$
\mathrm{B}. b <   c <   a
$$

$$
\mathrm{C.} c <   a <   b
$$

$$
\mathrm{D}. a <   c <   b
$$

解析:根据“切线不等式 $\ln x \leqslant x - 1$ (当且仅当 x = 1 时不等式取等号)”，可知 $\ln \frac{3}{2} < \frac{3}{2} - 1 = \frac{1}{2}$ ，所以 $a < \frac{1}{2}$ 。根据“切线不等式 $e^{x} \geqslant x + 1$ (当且仅当 x = 0 时不等式取等号)”，可知 $e^{-\frac{1}{2}} > -\frac{1}{2} + 1 = \frac{1}{2}$ ，所以 $c > \frac{1}{2}$ ；同时可知 $e^{\frac{1}{2}} > \frac{1}{2} + 1 = \frac{3}{2}$ ，所以 $e^{-\frac{1}{2}} < \frac{2}{3}$ ，即 c < b。综上，可得 a < c < b。

故选:D.

评注:本题通过综合运用两个切线不等式,并借助中间桥梁“ $\frac{1}{2}$ ”,可巧妙比较大小.此外,若利用切线不等式 $e^{x}\geqslant x+1$ 的变式 $e^{x}\leqslant\frac{1}{1-x}(x<1)$ ,亦可获得 $e^{-\frac{1}{2}}<\frac{2}{3}$ ,即c<b.

# 3.2 证明不等式

例 7 对任意 x>0，求证： $e^{2x-2}-e^{x-1}\ln x-x\geqslant0.$

证法 1: 要证明 $e^{2x-2}-e^{x-1}\ln x-x\geqslant0$ ，即证明 $e^{x}-\mathrm{e}\ln x-\frac{x}{\mathrm{e}^{x-2}}\geqslant0$ 。根据“切线不等式 $\ln x\leqslant x-1$ ”，可知 $\mathrm{e}\ln x+\mathrm{e}\leqslant\mathrm{e}x$ 。根据“切线不等式 $e^{x}\geqslant x+1$ ”的变式，可知 $e^{x}\geqslant ex$ 。

于是，由不等式的传递性可得 $\mathrm{e}^x\geqslant \mathrm{eln}x + \mathrm{e}$ ，变形可得 $\mathrm{e}^x -\mathrm{eln}x\geqslant \mathrm{e}.$ 又由“切线不等式 $\mathrm{e}^x\geqslant x + 1$ ”，可知 $\mathrm{e}^{x - 1}\geqslant x$ ，再变形得 $\mathrm{e}\geqslant \frac{x}{\mathrm{e}^{x - 2}}.$ 因此，由不等式的传递性

知 $\mathrm{e}^x -\mathrm{e}\ln x\geqslant \frac{x}{\mathrm{e}^{x - 2}}$ ，即 $\mathrm{e}^x -\mathrm{e}\ln x - \frac{x}{\mathrm{e}^{x - 2}}\geqslant 0.$ 故得证.

证法2: 要证 $e^{2x-2}-e^{x-1}\ln x-x\geqslant0$ ，即证 $e^{x-1}-\ln x-\frac{x}{e^{x-1}}\geqslant0$ 。根据“切线不等式 $e^{x}\geqslant x+1$ ”，可知 $e^{x-1}\geqslant x$ ；根据“切线不等式 $\ln x\leqslant x-1$ ”，可知 $-\ln x\geqslant1-x$ ；根据“切线不等式 $e^{x}\geqslant x+1$ ”的变式可知 $e^{x}\geqslant ex$ ，则有 $1\geqslant\frac{x}{e^{x-1}}$ ，所以 $-\frac{x}{e^{x-1}}\geqslant-1$ 。于是，可得 $e^{x-1}-\ln x-\frac{x}{e^{x-1}}\geqslant x+(1-x)+(-1)=0$ （当且仅当 x=1 时取等号）。故得证。

评注:证法1的关键在于灵活运用两个切线不等式(或其变式)以及不等式的传递性;证法2的关键在于先等价转化求证式,再灵活运用同向不等式可相加理论加以巧妙证明,同时亦可获得求证式取等号的充要条件(三个式子均满足当且仅当x=1时不等式取等号).

一般地, 当所求证不等式中同时含有“ $e^{x}$ ”和“ $\ln x$ ”时，可在等价转化（即实施适当的变形）的基础上，灵活运用切线不等式 $\ln x \leqslant x - 1$ 和 $e^{x} \geqslant x + 1$ 加以思考、分析，往往可获得目标不等式的巧妙证明.

此外,还需特别提醒的是:作为解答题,在具体考试时,需要先证明切线不等式,再灵活运用切线不等式;否则,若直接利用切线不等式,则会被适当扣分.

总之，关注切线不等式 $\ln x \leqslant x - 1$ 和 $\mathrm{e}^x \geqslant x + 1$ 及其变式在解题中的灵活、综合运用，往往有利于帮助我们迅速获得具体的解题思路，进而给出简洁、明了的解答过程，同时可提高处理此类相关数学问题的技能技巧，也有利于较好地提升数学运算与逻辑推理方面的核心素养.
