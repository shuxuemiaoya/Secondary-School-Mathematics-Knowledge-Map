关键词：“同构”；数列；通项公式

对于传统的求数列通项公式的方式我们已经很熟悉,但有的题目通过“同构”解法解决起来更简单快捷.下面笔者通过三个题目来说明“同构”解法在求数列通项公式中的应用.

# 1 例题分析

例 1 已知数列 $\{a_{n}\}$ 满足 $a_{n+2}=3a_{n+1}-2a_{n}$ ，且 $a_{1}=1, a_{2}=3$ ，求数列 $\{a_{n}\}$ 的通项公式.

本题常规解法是通过对题干中的递推公式 $a_{n+2}=3a_{n+1}-2a_{n}$ 变形,然后构造等比数列,再通过累加法求通项公式.

解法 1: 累加法.

因为 $a_{n+2}=3a_{n+1}-2a_{n}$ ，则有 $a_{n+2}-a_{n+1}=2a_{n+1}-2a_{n}$ ，也即 $a_{n+2}-a_{n+1}=2(a_{n+1}-a_{n})$ ，所以可得 $\{a_{n+1}-a_{n}\}$ 是以 2 为公比， $a_{2}-a_{1}=2$ 为首项的等比数列。所以 $a_{n+1}-a_{n}=2\times2^{n-1}=2^{n}$ 。当 $n\geqslant2$ 时， $a_{2}-a_{1}=2^{1},a_{3}-a_{2}=2^{2},\cdots,a_{n}-a_{n-1}=2^{n-1}$ ，上述各式相加得 $a_{n}-a_{1}=\frac{2(1-2^{n-1})}{1-2}=2^{n}-2$ ，则 $a_{n}=2^{n}-1(n\geqslant2)$ ，经检验 n=1 也适合。

故 $a_{n} = 2^{n} - 1$

“同构”解法是通过对题干中的递推公式 $a_{n+2} = 3a_{n+1} - 2a_n$ 变形，通过递推得到 $a_{n+1} - a_n = 2^n$ ，然后通过拆项同构出左右两侧结构相同的形式进而构造常数列，解决问题.

解法 2: 同构法.

因为 $a_{n + 2} = 3a_{n + 1} - 2a_n$ ，所以 $a_{n + 2} - a_{n + 1} = 2a_{n + 1} - 2a_n$ ，则有

$$
\begin{array}{r l} a _ {n + 2} - a _ {n + 1} & = 2 (a _ {n + 1} - a _ {n}) = 2 ^ {2} (a _ {n} - a _ {n - 1}) = \dots \dots = \\ 2 ^ {n} (a _ {2} - a _ {1}) & = 2 ^ {n + 1}. \end{array}
$$

所以 $a_{n + 1} - a_n = 2^n = 2^{n + 1} - 2^n$ ，则有

$$
a _ {n + 1} - 2 ^ {n + 1} = a _ {n} - 2 ^ {n}.
$$

所以 $a_{n} - 2^{n} = a_{n - 1} - 2^{n - 1} = \dots\dots = a_{2} - 2^{2} = a_{1} - 2^{1} = -1$ ，所以 $\{a_n - 2^n\}$ 是常数列.

故 $a_{n} = 2^{n} - 1$

评注:对比两种解法,我们发现,常规解法思路比较清晰,方法传统,易于普通学生掌握,但是运算量也比较大,需要有较好的运算功底.“同构”解法的主要思路是构造出左右两侧结构相同的形式,通过递推关系解决问题,易于拔尖学生掌握,对“同构”变形的要求比较高,但运算量很小,能够快速解题.

例 2 已知数列 $\{a_{n}\}$ 中， $a_{n+1}=4a_{n}+3n+2,a_{1}=2$ ，求 $\{a_{n}\}$ 的通项公式.

本题的常规解法是通过对题干中的递推公式 $a_{n+1}=4a_{n}+3n+2$ 变形,构造等比数列求通项公式.

解法 1: 构造数列法.

因为 $a_{n+1}=4a_{n}+3n+2$ ，则有 $a_{n+1}+n+2=4a_{n}+4n+4$ ，也即 $a_{n+1}+n+2=4(a_{n}+n+1)$ ，所以 $\{a_{n}+n+1\}$ 是以 4 为公比， $a_{1}+1+1=4$ 为首项的等比数列，则 $a_{n}+n+1=4^{n}$ 。所以 $a_{n}=4^{n}-n-1$ 。

“同构”解法是通过对题干中的递推公式 $a_{n+1}=4a_{n}+3n+2$ 变形，将两边同除以 $4^{n+1}$ ，得 $\frac{a_{n+1}}{4^{n+1}}=\frac{a_{n}}{4^{n}}+\frac{3n+2}{4^{n+1}}$ ，然后通过拆项同构出左右两侧结构相同的形式进而构造常数列，解决问题.

解法 2: 同构法.

将 $a_{n + 1} = 4a_{n} + 3n + 2$ 的两边同除以 $4^{n + 1}$ ，得

$$
\frac {a _ {n + 1}}{4 ^ {n + 1}} = \frac {a _ {n}}{4 ^ {n}} + \frac {3 n + 2}{4 ^ {n + 1}}.
$$

整理，得 $\frac{a_{n + 1}}{4^{n + 1}} +\frac{n + 2}{4^{n + 1}} = \frac{a_n}{4^n} +\frac{n + 1}{4^n}.$

所以数列 $\left\{\frac{a_n}{4^n} +\frac{n + 1}{4^n}\right\}$ 是常数列，可得 $\frac{a_n}{4^n} +\frac{n + 1}{4^n} =$ $\frac{a_{n - 1}}{4^{n - 1}} +\frac{n}{4^{n - 1}} = \dots \dots = \frac{a_1}{4} +\frac{2}{4} = 1$ ，从而得 $a_{n} = 4^{n} - n - 1.$

例 3 已知数列 $\{a_{n}\}$ 满足 $na_{n+1}=3S_{n}$ ，且 $a_{1}=1$ ，求数列 $\{a_{n}\}$ 的通项公式.

本题常规解法是通过对题干中的关系式 $na_{n+1}=3S_{n}$ 进行处理，消掉 $S_{n}$ ，进而得到 $a_{n+1}$ 与 $a_{n}$ 的递推关系式，再通过累乘法求通项公式.

解法 1: 累乘法.

由 $na_{n+1}=3S_{n}$ ，得 $(n-1)a_{n}=3S_{n-1}(n\geqslant2)$ ，两式相减得 $na_{n+1}=(n+2)a_{n}$ ，则 $\frac{a_{n+1}}{a_{n}}=\frac{n+2}{n}$ ，所以 $\frac{a_{3}}{a_{2}}=\frac{4}{2}$ ， $\frac{a_{4}}{a_{3}}=\frac{5}{3}$ ，……， $\frac{a_{n}}{a_{n-1}}=\frac{n+1}{n-1}$ ，又 $\frac{a_{2}}{a_{1}}=\frac{3}{1}$ ，上述各式相乘得 $\frac{a_{n}}{a_{1}}=\frac{n(n+1)}{2}(n\geqslant2)$ ，而 n=1，也适合.

所以 $a_{n}=\frac{n(n+1)}{2}$ .

“同构”解法也是先通过对题干中的关系式 $na_{n+1}=3S_{n}$ 进行处理，消掉 $S_{n}$ ，进而得到 $a_{n+1}$ 与 $a_{n}$ 的递推关系式，然后通过同除某一项同构出左右两侧结构相同的形式进而构造常数列，解决问题。

解法 2: 同构法.

由 $na_{n + 1} = 3S_n$ ，得 $(n - 1)a_{n} = 3S_{n - 1}(n\geqslant 2)$ ，两式相减得 $na_{n + 1} = (n + 2)a_{n}$ ，则 $\frac{a_{n + 1}}{n + 2} = \frac{a_n}{n}$ .进而可得 $\frac{a_{n + 1}}{(n + 1)(n + 2)} = \frac{a_n}{(n + 1)n}$ ，所以 $\frac{a_n}{(n + 1)n} = \frac{a_{n - 1}}{n(n - 1)} =$ $\frac{a_{n - 2}}{(n - 1)(n - 2)} = \dots\dots = \frac{a_2}{3\times 2} = \frac{1}{2}$ ，又 $\frac{a_1}{2\times 1} = \frac{1}{2}$ ，所以 $n = 1$ 也适合.

故 $a_{n} = \frac{n(n + 1)}{2}$

评注:对比两种解法,我们发现,常规解法与“同构”解法的优缺点和例1是一样的,常规解法适合普通学生,“同构”解法适合拔尖学生.

# 2 方法总结

利用“同构”解法求数列通项公式的思路：

对于 $a_{n}$ 与 $S_{n}$ 的混合型题目, 需要先消掉 $S_{n}$ , 得到与 $a_{n}$ 有关的递推关系式.

(1) 如果此递推公式有 $a_{n+2}$ , $a_{n+1}$ 和 $a_{n}$ 三项, 则通过左右两侧“同构”出 $a_{n+2}$ 与 $a_{n+1}$ 以及 $a_{n+1}$ 与 $a_{n}$ 的关系, 借助递推得到 $a_{n+1}$ 与 $a_{n}$ 的关系.  
(2) 如果 $a_{n+1}$ 与 $a_n$ 的关系与等比数列有关, 通常通过拆项的方法“同构”得到常数列求出数列的通项公式.  
(3) 如果 $a_{n+1}$ 与 $a_{n}$ 的关系与等差数列有关, 通常通过同除某一项进而拆项的方法“同构”得到常数列求出数列的通项公式.  
(4) 如果 $a_{n+1}$ 与 $a_{n}$ 的关系与分式数列有关, 通常通过同除某一项的方法“同构”得到常数列求出数列的通项公式.

# 3 高考链接

你能利用常规解法和“同构”解法解决下面这道高考试题的第(1)问吗？

(2022 全国新高考Ⅰ卷第 17 题) 记 $S_{n}$ 是数列 $\{a_{n}\}$ 的前 n 项和, 已知 $a_{1}=1, \left\{\frac{S_{n}}{a_{n}}\right\}$ 是公差为 $\frac{1}{3}$ 的等差数列.

(1) 求 $\{a_{n}\}$ 的通项公式；  
(2) 略.

评注:第(1)问,可以根据题意先求出 $\left\{\frac{S_{n}}{a_{n}}\right\}$ 的通项公式.由于是 $a_{n}$ 与 $S_{n}$ 的混合型问题,因此可先消掉 $S_{n}$ 得到 $(n-1)a_{n}=(n+1)a_{n-1}$ .常规解法是变形得到 $\frac{a_{n}}{a_{n-1}}=\frac{n+1}{n-1}$ ,进而通过累加法得到 $a_{n}=\frac{n(n+1)}{2}$ .“同构”解法是变形得到 $\frac{a_{n}}{n+1}=\frac{a_{n-1}}{n-1}$ ,因为 $a_{n+1}$ 与 $a_{n}$ 的关系与等差数列有关,所以两侧同除以n“同构”得到 $\frac{a_{n}}{n(n+1)}=\frac{a_{n-1}}{(n-1)n}$ ,进而通过递推得到 $\frac{a_{n}}{n(n+1)}=\frac{a_{n-1}}{(n-1)n}=\cdots\cdots=\frac{a_{1}}{1\times2}=\frac{1}{2}$ ,从而求出 $a_{n}=\frac{n(n+1)}{2}$ .

平时教学中求数列通项公式的常规方法是所有学生都需要掌握的,但是对于拔尖学生,可以渗透“同构”解法,开拓学生的思维.另外,“同构”解法在拔尖学生参加“强基计划”测试时也会用到,所以这种解法可以在选做作业中教给拔尖学生.这样既考虑到了解法传授的全面性,又考虑到了学生水平不同的分层性,从而让所有学生都有所提高和发展.Z
