# 问题驱动 变中求本 提升能力

# 甘肃省武威市天祝一中 补芳玲

摘要: 好的数学教学不是直接将知识灌输给学生, 而是提供机会让学生去发现、去探索、去交流, 从而真正认识知识、方法的本质, 实现知识的融会贯通. 文中从学生的解题错误出发, 根据实际创设问题, 让学生在问题的驱动下主动求“变”, 以此揭示问题的本质, 培养学生应用意识, 提升学生数学能力和数学素养.

关键词:本质;问题;应用意识

# 1 问题呈现

例 1 已知函数 $f(x)=\sqrt{x}-\ln x$ ，试证明： $f(x)$ 在 $x=x_{1}, x_{2} (x_{1}\neq x_{2})$ 处导数相等，则 $f(x_{1})+f(x_{2})>8-8\ln 2$ .

例1难度不大，思路简单，不过很多学生因为解题中忽视了求 $\sqrt{x_1x_2}$ 的取值范围，以致解题失败。从解题过程来看，大多学生从“导数相等”这一条件出发，求得 $\frac{1}{2\sqrt{x_1}} -\frac{1}{x_1} = \frac{1}{2\sqrt{x_2}} -\frac{1}{x_2}$ 又 $x_{1}\neq x_{2}$ ，所以 $\frac{1}{\sqrt{x_1}} +\frac{1}{\sqrt{x_2}} = \frac{1}{2}$ 即 $\sqrt{x_1x_2} = 2(\sqrt{x_1} +\sqrt{x_2})$ .由题意， $f(x_{1}) + f(x_{2}) = \sqrt{x_{1}} +\sqrt{x_{2}} -\ln (x_{1}x_{2})$ ，于是 $f(x_{1}) + f(x_{2}) = \frac{1}{2}\sqrt{x_{1}x_{2}} -\ln (x_{1}x_{2}).$ 令 $\sqrt{x_1x_2} = t,$ 则即求 $\frac{1}{2} t - \ln t$ 的取值范围。从以上证明过程可以看出，解题思路清晰，方法得当，但是却犯了一个典型性错误，就是没有真正思考 $\sqrt{x_1x_2}$ 的取值范围。

# 2 问题分析

在日常教学中,类似于 $\sqrt{x_{1}x_{2}}=2(\sqrt{x_{1}}+\sqrt{x_{2}})$ 这种二元等式,求其相关代数式的取值范围是之前重点研究并重点练习过的问题,当时学生可以合理地运用基本不等式求其取值范围,然而在综合应用时,却没有达到预期.从现实反馈来看,学生缺乏不等意识,对二元等式中蕴含的不等关系的理解不够深刻,所以不能主动且灵活地从这些二元等式中得到常见的代数式的取值范围.

# 3 问题解决

可见,如何化被动为主动,让学生自主发现并探索常见的代数式的取值范围是课堂教学的一个重点.笔者认为,变式教学就是一个行之有效的教学方法,但是这里的“变”并不是简单的变题目,而是要从根本上改变“教”与“学”的方式.教学中,教师不要急于告诉学生“做什么”“怎么做”,而是要提供机会让学生主动挖掘二元等式中蕴含的不等关系,利用已有知识求出一些有价值的代数式的取值范围.这样一方面可以夯实基础,提升解题技能;另一方面可以提升学生由“等式”转化为“不等式”的意识.当然,培养学生这种不等意识是一个长期的过程,需要在日常教学实践中不断地渗透、不断地积累.

# 3.1 理性分析

问题 1 在证明例 1 的过程中,大家明明已经形成了完整的证明思路,为什么没有达到预期的结果?问题到底出现在哪里呢?

教师预留时间让学生思考,但学生并未找到失败的原因.

师:很多学生证明过程中求得 $f(x_{1}) + f(x_{2}) = \frac{1}{2}\sqrt{x_{1}x_{2}} - \ln(x_{1}x_{2})$ ，然后对其进行整体换元，令 $\sqrt{x_{1}x_{2}} = t$ ，这里的新元 t 是否只要满足大于 0 就可以了呢？ $\sqrt{x_{1}x_{2}}$ 的取值范围与什么有关？

(在问题的引领下,学生很快就有了发现.)

生 1: 由基本不等式可得 $\sqrt{x_{1}x_{2}}=2(\sqrt{x_{1}}+\sqrt{x_{2}})>2\cdot2\sqrt{\sqrt{x_{1}}\cdot\sqrt{x_{2}}}$ ，即 $\frac{1}{2}\sqrt{x_{1}x_{2}}=\sqrt{x_{1}}+\sqrt{x_{2}}>2\sqrt[4]{x_{1}x_{2}}$ ，解得 $x_{1}x_{2}>256$ 。所以 t>16。

点评:教师提供时间让学生反思回顾,以便学生自己发现问题的症结,有效规避或减少类似错误的发生 $^{[1]}$ .在此过程中,教师根据课堂反馈进行及时的启发和指导,让学生发现确定 $\sqrt{x_{1}x_{2}}$ 的取值范围是解题的关键,潜移默化地渗透不等意识,增强学生转化意识,培养学生思维的严谨性、深刻性.

问题 2 大家已经找到了问题所在,并顺利地求出了 $\sqrt{x_1x_2}$ 的取值范围，但是为什么等式中蕴含相关代数式的取值范围呢？

问题给出后,学生积极思考,教师启发学生从方程的角度进行分析.

生2:等式 $\sqrt{x_{1}x_{2}}=2(\sqrt{x_{1}}+\sqrt{x_{2}})$ 实质是关于 $x_{1},x_{2}$ 的二元方程，而这个二元方程有无数组解，也就是说关于 $x_{1},x_{2}$ 的代数式的值是不确定的，这里既可以求代数式 $\sqrt{x_{1}x_{2}}$ 的值，还可求 $\sqrt{x_{1}}+\sqrt{x_{2}},x_{1}+x_{2}$ 等代数式的取值范围.

师:说得很好,你还有其他发现吗?

生 3: 若 $\sqrt{x_{1}} = a, \sqrt{x_{2}} = b$ ，则等式可以转化为 $ab = 2(a + b)$ .

师:非常棒的发现!

点评:通过理性分析揭示一类数学题的本质,有效提高学生的认知水平和举一反三的能力.在日常教学中,教师要适度放慢脚步,重视引导学生挖掘知识背后的原因,揭示问题的本质,有效提升学生分析和解决问题的能力.

# 3.2 变式探索

问题 3 已知 $\frac{1}{a} + \frac{1}{b} = \frac{1}{2}$ ，其中 a > 0, b > 0，试求 $a^{2} + b^{2}$ 的取值范围.

问题给出后,教师让学生分组交流,部分小组遇到障碍.

师:如果将 $a^{2}+b^{2}$ 变为 $a+2b$ ，如何求它的取值范围？

生4:由题意,得 $a+2b=2(a+2b)\left(\frac{1}{a}+\frac{1}{b}\right)=$ $2\left(3+\frac{2b}{a}+\frac{a}{b}\right)\geqslant2\left(3+2\sqrt{\frac{2b}{a}\cdot\frac{a}{b}}\right)=6+4\sqrt{2}.$

师:你是如何想到的?

生 $4:(a+2b)\left(\frac{1}{a}+\frac{1}{b}\right)$ 是关于 a,b 的一次式与倒数和的积, 其结果是关于 a,b 的齐次分式, 转化后就可以利用基本不等式求解了.

师:那么 $a^{2}+b^{2}$ 又该如何转化呢?

生 $5:a^{2}+b^{2}=4(a^{2}+b^{2})\left(\frac{1}{a}+\frac{1}{b}\right)^{2}$ ，由此可以将所求转化为二次齐次分式，这样也可以利用基本不等式求取值范围.

师:很好,请大家按照这一思路求解.(过程略.)

点评:在平时解题过程中,学生习惯于机械地套用,而通过追问学生能进一步思考蕴含其中的道理,以此打通相关题目的内在联系,提高解题能力 $^{[2]}$ .

问题 4 以上我们以等式 $ab=2(a+b)$ 为条件，研究了一些代数式的取值范围,除 $ab=2(a+b)$ 这一条件外,你还能想到一些其他等式吗?

生 6: 若将等式变为 $ab + 2a + b = 6$ 呢?

师: 是个不错的问题, 它还能否转化为倒数和的结构呢?

生齐声答:不能.

师:在此前提下,如何求 $a+2b$ 的取值范围?(生积极思考.)

生 7: 可以尝试利用消元法.

师:具体说说你的解题思路.

生 7: 将已知变形为 $b=\frac{6-2a}{a+1}\geqslant0$ ，所以 $a+2b=a+2\times\frac{6-2a}{a+1},0<a<3$ ，从而将问题转化为求一元函数的值域问题.

师:很好,还有其他解法吗?

生8: 将 $ab + 2a + b = 6$ 变形为 $(a + 1)(b + 2) = 8$ ，于是 $(a + 1)(2b + 4) = 16 \leqslant \frac{(a + 1 + 2b + 4)^{2}}{4}$ ，由此可求得 $a + 2b$ 的最小值.

点评:通过“变等式”进一步强化学生的转化意识,积累解题经验.同时,在求解过程中,教师鼓励学生尝试应用不同的方法求解,以此发散学生的数学思维,优化学生的知识结构,提高学生数学能力.

# 4 结束语

在高中教学过程中,当学生出现错误时,教师不要急于纠正,而是要分析出现错误的真正原因,以便采取有效的措施进行修正,从而帮助学生形成正确的认知,有效提高学生的解题能力.另外,在课堂上,教师应将主动权交给学生,让学生“变”,以此提高学生参与课堂的积极性,培养学生主动学习和善于应用的意识,提升学生数学素养 $^{[3]}$ .

总之，在学习过程中，教师要合理地运用错误，并提供一些机会让学生进行变式探索，从而通过“变”认识问题的本质，掌握解决问题的方法，切实提高学生解决问题的能力。
