# 同构思想指导下对一道数列题目的思考\*

# 山东省平度市第九中学 范应彬

摘要: 解题活动是在学生已有认知的基础上进行的思维活动. 教师有时会讲一些学生从来想不到的方法, 这样的方法若学生没有真正掌握, 那么以后遇到类似的问题还是不会解决. 因此, 教师们总是花很多精力思考怎样讲题才能让学生想得自然. 本文中给出了一种解决“想得自然”的途径, 就是在发现学生不规范解法的基础上给出规范解法, 并在学生已有经验的基础上进一步深耕“想得自然”的解法, 这样学生更易于接受和掌握.

关键词: 同构思想; 数列; 通项公式

# 1 问题提出

近期遇到这样一道考试题：

题目 已知数列 $\{a_{n}\}$ 满足 $a_{n+1} + a_{n} = 2n + 7$ ，且 $a_{1} = 4$ ，求数列 $\{a_{n}\}$ 的通项公式.

答案解法: 因为 $a_{n+1} + a_{n} = 2n + 7$ ，所以 $a_{n} + a_{n-1} = 2n + 5, n \geqslant 2$ .

当 $n \geqslant 2$ 时，上述两式相减得 $a_{n+1} - a_{n-1} = 2$ ，所以 $\{a_n\}$ 的奇数项与偶数项分别成等差数列，且公差均为2.由 $a_1 = 4$ ，得 $a_2 = 5$ .所以 $a_{2n-1} = a_1 + 2(n-1) = 2n + 2 = 2n - 1 + 3$ ，即 $a_n = n + 3$ （ $n$ 为奇数）； $a_{2n} = a_2 + 2(n-1) = 2n + 3$ ，即 $a_n = n + 3$ （ $n$ 为偶数）.故 $a_n = n + 3$

而大部分学生给出的解法却是下面这样的.

学生解法: 因为 $a_{n+1} + a_{n} = 2n + 7 = n + 4 + n + 3$ ，所以 $a_{n} = n + 3$ .

很显然,学生的解法有猜测的成分,不能作为规范解答.但是答案的解法也确实繁琐,学生几乎想不到.因此笔者思考,能否将学生的解法优化,既让学生容易想到,又不像答案那样繁琐呢?笔者发现,学生的解法虽然是猜出来的,但也是变形后观察左右两侧的结构形式得到的,而这种结构形式不是可以通过“同构”来解决吗?

笔者解法: 因为 $a_{n+1} + a_{n} = 2n + 7 = n + 4 + n + 3$ ，所以 $a_{n+1} - (n + 4) = -[a_{n} - (n + 3)]$ ，所以 $a_{n} - (n + 3) = -[a_{n-1} - (n + 2)] = (-1)^{2}[a_{n-2} - (n + 1)] = \cdots = (-1)^{n-1}(a_{1} - 4) = 0$ ，故 $a_{n} = n + 3$ .

这样,笔者通过同构得到左右两侧结构相同的式子,之后再通过递推就可以求出数列 $\{a_{n}\}$ 的通项公式,既是对学生解法的优化与规范,又避免了答案解法的想不到.因此,笔者考虑:将 $a_{n+1} + a_{n} = 2n + 7$ 改编一下,是不是其他的题目也可以通过同构的思想来解决呢?

# 2 几点思考

笔者引导学生进行如下思考活动.

思考 1 将 $a_{n+1} + a_{n} = 2n + 7$ 中的“ $2n + 7$ ”这种等差型换成等比型呢？

学生给出改编后的变式 1.

变式 1 已知数列 $\{a_{n}\}$ 满足: $a_{n+1} + a_{n} = 3 \cdot 2^{n}$ ，且 $a_{1} = 2$ ，求数列 $\{a_{n}\}$ 的通项公式.

解：因为 $a_{n + 1} + a_n = 3\cdot 2^n = 2^{n + 1} + 2^n$ ，所以 $a_{n + 1} - 2^{n + 1} = -(a_n - 2^n)$ ，所以 $a_{n} - 2^{n} = -(a_{n - 1} - 2^{n - 1}) = (-1)^{2}(a_{n - 2} - 2^{n - 2}) = \dots\dots = (-1)^{n - 1}(a_1 - 2) = 0$ ，故 $a_{n} = 2^{n}$

学生解释此变式不能简单地改成等比型,还需要配凑一个系数,从而构造出同构的形式解决问题.

思考 2 将 $a_{n+1} + a_{n} = 3 \cdot 2^{n}$ 中的加法换成减法呢?

学生给出针对变式 1 改编后的变式 2.

变式 2 已知数列 $\{a_{n}\}$ 满足 $a_{n+1}-a_{n}=2^{n}$ ，且 $a_{1}=2$ ，求数列 $\{a_{n}\}$ 的通项公式.

解: 因为 $a_{n+1}-a_{n}=2^{n}=2^{n+1}-2^{n}$ ，所以 $a_{n+1}-2^{n+1}=a_{n}-2^{n}$ ，所以 $a_{n}-2^{n}=a_{n-1}-2^{n-1}=a_{n-2}-2^{n-2}=\cdots\cdots=a_{1}-2=0$ ，故 $a_{n}=2^{n}$ .

学生解释此题也可以用累加法解决,而本文重点探讨同构思想下的解题方法.由于加法改成了减法,所以需要继续变换等比数列前面的系数才能构造出同构的形式解决问题.

思考 3 将 $a_{n+1}-a_{n}=2^{n}$ 中的减法换成除法呢?

学生给出针对变式 2 改编后的变式 3.

变式 3 已知数列 $\{a_{n}\}$ 满足 $\frac{a_{n+1}}{a_{n}} = \frac{n+1}{n}$ ，且 $a_{1} = 1$ ，求数列 $\{a_{n}\}$ 的通项公式.

解: 因为 $\frac{a_{n+1}}{a_{n}} = \frac{n+1}{n}$ ，所以 $\frac{a_{n+1}}{n+1} = \frac{a_{n}}{n}$ ，所以 $\frac{a_{n}}{n} = \frac{a_{n-1}}{n-1} = \cdots = \frac{a_{1}}{1} = 1$ ，故 $a_{n} = n$ 。

学生解释此题也可以用累乘法解决,而本文重点探讨同构思想下的解题方法.由于减法改成了除法,所以等式右侧需要变换成分式型才能构造出同构的形式解决问题.

思考4 将 $\frac{a_{n + 1}}{a_n} = \frac{n + 1}{n}$ 中的除法换成乘法呢？

变式 4 已知数列 $\{a_{n}\}$ 满足 $a_{n+1} \cdot a_{n} = 2^{2n+1}$ ，且 $a_{1} = 2$ ，求数列 $\{a_{n}\}$ 的通项公式.

解: 因为 $a_{n+1} \cdot a_{n} = 2^{2n+1} = 2^{n+1} \cdot 2^{n}$ ，所以 $\frac{a_{n+1}}{2^{n+1}} = \frac{2^{n}}{a_{n}} = \left(\frac{a_{n}}{2^{n}}\right)^{-1}$ ，所以 $\frac{a_{n}}{2^{n}} = \left(\frac{a_{n-1}}{2^{n-1}}\right)^{-1} = \left(\frac{a_{n-2}}{2^{n-2}}\right)^{(-1)^{2}} = \cdots = \left(\frac{a_{1}}{2}\right)^{(-1)^{n-1}} = 1$ ，故 $a_{n} = 2^{n}$ .

学生解释由于除法改成了乘法,因此等式右侧再用分式型显然不行了,变换成等比型才能更合适构造出同构的形式解决问题.

# 3 方法总结

改编数列递推公式使其能够采用“同构”思想解决问题的思路：

(1) 如果左侧是 $a_{n+1}$ 与 $a_{n}$ 相加的关系, 右侧不管是等差型还是等比型, 都可以构造出同构的形式解决问题.  
(2) 如果左侧是 $a_{n+1}$ 与 $a_{n}$ 相减的关系, 右侧若是等差型则不太好构造, 若是等比型则比较好构造出同构的形式解决问题.  
(3) 如果左侧是 $a_{n+1}$ 与 $a_{n}$ 相乘的关系, 右侧若是等差型则不太好构造, 若是等比型则比较好构造出同构的形式解决问题.  
(4) 如果左侧是 $a_{n+1}$ 与 $a_{n}$ 相除的关系, 右侧如果是等差型或者等比型则都不太好构造, 如果是分式型则比较好构造出同构的形式解决问题.

# 5 反思

# 5.1 解题要先让学生想得到

教师给学生讲题不能仅仅根据答案照本宣科，而丝毫不考虑学生是否能够想得到。因为这样即使教师讲了，下次学生再做时可能还是不会或者还是按照原来的做法做错。究其原因就是答案的解法并不是学生自然想到的。当然，教师可以在答案的基础上，通过抛出问题让解法变得自然。如果能在学生不规范的解法上进行优化，相信学生的记忆会更加深刻，因为这个方法本来就是学生自然想到的，只是方法得到了改良而已，学生在已有的知识基础上更容易接受这种改良的方法，而不是那种自身不熟悉的突兀的解法。

# 5.2 想到后要让学生想得深

想到规范的简单解法后,不能就此打住,而是要深挖此种解法是否可以解决其他类似的问题.因为如果只能解决这一个问题,那就技巧性太强,不利于推广,因此这就需要教会学生如何进行深度思考.传统的思考虽然也是一题多变,但基本都是基于母题的不断变式,是一种“平行结构”的思维提升.而笔者此次教会学生的思考是“变中变”的不断变式,是一种“螺旋结构”的思维提升.

变式 1 中的 $a_{n+1} + a_{n} = 3 \cdot 2^{n}$ 是在母题中 $a_{n+1} + a_{n} = 2n + 7$ 基础上的变式，由等差数列想到等比数列，并且需要修正系数才能运用同构思想解决问题；变式 2 中的 $a_{n+1} - a_{n} = 2^{n}$ 是在变式 1 中 $a_{n+1} + a_{n} = 3 \cdot 2^{n}$ 基础上的变式，由加法想到同级运算的减法，需要再次修正系数才能运用同构思想解决问题，变式 3 中的 $\frac{a_{n+1}}{a_{n}} = \frac{n + 1}{n}$ 是在变式 2 中 $a_{n+1} - a_{n} = 2^{n}$ 基础上的变式，由减法想到“升级”运算的除法，同时将等比数列改成分式型才能运用同构思想解决问题；变式 4 中的 $a_{n+1} \cdot a_{n} = 2^{2n + 1}$ 是在变式 3 中 $\frac{a_{n+1}}{a_{n}} = \frac{n + 1}{n}$ 基础上的变式，由除法又想到同级运算的乘法，同时将分式型再改成等比型才能运用同构思想解决问题。这样在上一个变式环境中思考下一个变式的维度，并且需要不断变换等式右侧对应的数列，是一种“螺旋结构”的思维提升，更能有效拓宽学生思维的深度与广度。Z
