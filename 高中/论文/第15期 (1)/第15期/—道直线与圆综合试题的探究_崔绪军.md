# 一道直线与圆综合试题的探究

# ● 江苏省淮州中学 崔绪军

直线与圆是初中平面几何中的两类基本平面图形,又是高中平面解析几何中的两类最简单的基本图形.特别是涉及直线与圆的位置关系问题,巧妙链接起初中与高中阶段的相关数学知识,同时涵盖了数形结合、函数与方程等数学思想方法,涉及直观想象、逻辑推理以及数学运算等核心素养,成为每年高考数学试卷中命题的基本点之一,备受各方关注.

特别在解决直线与圆的位置关系的综合问题时，可以从自身的代数属性或内涵的几何特征等不同思维视角切入，很好发散数学思维与拓展技巧策略，又巧妙吻合高考“在知识交汇点处”命题的基本指导精神，创新新颖，常考常新.

# 1 问题呈现

问题 过原点的直线 $l: y = kx$ 与圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ 交于 $A, B$ 两点，且 $|OA| = |AB|$ ，则 $k = (\quad)$ .

A.1 B.2 C. $\frac{1}{2}$ D. $\sqrt{2}$

此题借助含参直线方程与已知圆的方程的创设，利用两线段之间的长度关系设置场景，进而确定对应的参数值问题。问题比较熟悉，难度也比较适中，充分考查了直线的方程、圆的方程、直线与圆的位置关系等基础知识与基本能力。

在实际解答时,可以从不同思维视角切入,通过不同的技巧方法与思维策略来突破与分析实现问题的分析与处理.

# 2 问题破解

解法 1: 方程法.

将直线 l: y = kx 代入圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ ，整理可得 $(1 + k^{2})x^{2} - (6 + 6k)x + 16 = 0$ .

设 $A(x_{1},y_{1})$ ，结合 $|OA|=|AB|$ ，得 $B(2x_{1},2y_{1})$ 。根据韦达定理，可得到 $x_{1}+2x_{1}=\frac{6+6k}{1+k^{2}}$ ， $x_{1}\cdot2x_{1}=\frac{16}{1+k^{2}}$ ，化简可得 $x_{1}=\frac{2+2k}{1+k^{2}}$ ，且 $x_{1}^{2}=\frac{8}{1+k^{2}}$ ，则有 $\left(\frac{2+2k}{1+k^{2}}\right)^{2}=\frac{8}{1+k^{2}}$ ，整理得 $k^{2}-2k+1=0$ ，解得 k=1。

反思:在解决直线与圆的位置关系问题中,方程思维是解决问题时比较常用的一种技巧方法.借助点或直线的设置,与圆的方程联立,转化为对应的二次方程,结合韦达定理的应用,建立与交点坐标相关的关系式,为问题的突破与求解提供条件.利用方程法解题时,往往要注意方程有解的隐含条件.

解法 2: 勾股定理法.

由圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ ，配方可得圆 $(x - 3)^{2} + (y - 3)^{2} = 2$ ，则圆心 $C(3,3)$ ，半径 $r = \sqrt{2}$ $|OC| = 3\sqrt{2}$ .设圆心 $C(3,3)$ 到直线 $l$ 的距离为 $d$ ，线段 $AB$ 的中点为 $D$ ，结合 $|OA| = |AB|$ ，可得 $|OD| =$ $3|AD|$ .结合 $|OD| = \sqrt{|OC|^2 - d^2} = \sqrt{18 - d^2}$ ，而 $|AD| = \sqrt{|AC|^2 - d^2} = \sqrt{2 - d^2}$ ，所以 $\sqrt{18 - d^2} =$ $3\sqrt{2 - d^2}$ ，解得 $d = 0$ ，则知直线 $l$ 经过圆心 $C(3,3)$

而 $k_{oc}=1$ ，所以 k=1。

反思: 在解决直线与圆的位置关系问题中, 经常借助圆心、弦心距、半径等相关元素之间的数据信息, 合理通过勾股定理构建对应的关系式, 给问题的突破与解决开拓更加宽广的空间. 勾股定理法是解决直线与圆的位置关系问题中最为常用的一种技巧方法之一, 特别是涉及线段的长度、参数的取值等问题.

解法 3: 向量的中线定理法.

由圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ ，配方可得圆 $(x - 3)^{2} + (y - 3)^{2} = 2$ ，则圆心 $C(3,3)$ ，半径 $r = \sqrt{2}$ $|OC| = 3\sqrt{2}$ .而 $|OA| = |AB|$ ，则知点 $A$ 是线段OB的中点，从而 $\overrightarrow{CO} +\overrightarrow{CB} = 2\overrightarrow{CA}$ ，两边平方可得 $\overrightarrow{CO^2}+$ $2\overrightarrow{CO}\cdot \overrightarrow{CB} +\overrightarrow{CB^2} = 4\overrightarrow{CA}^2$ ，即 $18 + 12\cos \angle OCB + 2 =$ 8，解得 $\cos \angle OCB = -1$ ，可知 $O,C,B$ 三点共线.而 $k_{OC} = 1$ ，所以 $k = 1$

反思:在解决平面解析几何中涉及线段的比例关系(或等分点等)问题中,向量法思维可以有效建立相应的关系式,为问题的突破与求解奠定基础.特别解决涉及线段的中点问题时,经常利用平面向量的中线定理来建立向量的线性关系式,给问题的解决拓展思维,成为向量法解决平面解析几何问题中的常态.

解法 4: 阿波罗尼奥斯中线定理法.

由圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ ，配方可得圆 $(x - 3)^{2} + (y - 3)^{2} = 2$ ，则圆心 $C(3,3)$ ，半径 $r = \sqrt{2}$ $|OC| = 3\sqrt{2}$ .结合 $|OA| = |AB|$ ，利用阿波罗尼奥斯中线定理，可得 $|OC|^2 +|CB|^2 = 2(|CA|^2 +|AB|^2)$ 即 $18 + 2 = 2(2 + |AB|^2)$ ，解得 $|AB| = 2\sqrt{2} = 2r$ ，则知

A, C, B 三点共线. 而 $k_{oc}=1$ , 所以 k=1.

反思:在三角形问题中,出现对应的中线时,往往可以借助阿波罗尼奥斯中线定理——“三角形一条中线两侧所对的边平方和等于底边的一半平方与该边中线平方和的2倍”,巧妙构建对应线段长的关系式,为问题的突破与求解拓展思维.阿波罗尼奥斯中线定理作为课外的一个拓展与提升知识点,可以简化解题过程,优化解题效益.

解法 5: 对称性法.

由圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ ，配方可得圆 $(x - 3)^{2} + (y - 3)^{2} = 2$ ，则知圆心 $C(3,3)$ ，半径 $r = \sqrt{2}$

若直线 l: y=kx 不过圆的圆心 C，根据直线与圆的位置关系的对称性，可知这样的直线有两条，与条件中的单项选择题不吻合，则只能是直线 l: y=kx 过圆的圆心 C，所以 $k=k_{oc}=1$ .

反思:抓住直线与圆的位置关系,结合圆的对称性,从逆向思维切入,并结合单选题的特征,实现问题的巧妙突破,解答起来更加简单快捷,甚至达到“秒杀”的效果.对称性法只是解决此类平面解析几何问题中直观想象与数形结合的一个基本思维,在实际应用中要合理构建.该对称性法只针对一些特殊场景下的问题应用,不具有推广性与普遍性.

总结: 在以上解法中, 解法 1 与解法 2 是借助平面解析几何思维来分析与处理, 解法 3 是借助平面向量思维来分析与处理, 解法 4 是借助平面几何思维来分析与处理, 这几种方法都是解决平面解析几何问题中比较常见的“通性通法”; 而解法 5 是借助特殊设置场景下的一种“巧技妙法”, 具有一定的直观形象思维与数形结合思想. 不同的技巧方法展示不同的数学思维与应用技巧, 开拓一个更加发散的思维空间与应用场景.

# 3 变式拓展

改变原问题中两线段的比例关系(由原来两线段相等的关系变成其他的倍数关系),使得问题更具一般性,得到以下相应的变式问题.

变式 1 过原点的直线 l: y = kx 与圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ 交于 A, B 两点，且 $|OA| = 4|AB|$ ，则 k = \_\_\_\_.

解析:由圆 $x^{2}-6x+y^{2}-6y+16=0$ 配方可得圆 $(x-3)^{2}+(y-3)^{2}=2$ ，则知圆心 $C(3,3)$ ，半径 $r=\sqrt{2},|OC|=3\sqrt{2}$ 。设圆心 $C(3,3)$ 到直线 l 的距离为 d，线段 AB 的中点为 D，结合 $|OA|=4|AB|$ ，可得 $|OD|=9|AD|$ 。

结合 $|OD| = \sqrt{|OC|^2 - d^2} = \sqrt{18 - d^2}$ ，而 $|AD| = \sqrt{|AC|^2 - d^2} = \sqrt{2 - d^2}$ ，所以 $\sqrt{18 - d^2} = 9\sqrt{2 - d^2}$ ，解得 $d = \frac{3\sqrt{5}}{5}$ . 所以利用点到直线的距离公

式有 $d = \frac{|3k - 3|}{\sqrt{k^2 + 1}} = \frac{3\sqrt{5}}{5}$ ，变形可得 $2k^2 - 5k + 2 = 0$ ，解得 $k = \frac{1}{2}$ 或2.

变式 2 （多选题）过原点的直线 l: y = kx 与圆 $x^{2} - 6x + y^{2} - 6y + 16 = 0$ 交于 A, B 两点，则（）.

A. 若 $\left|OA\right|=\left|AB\right|$ ，则 k=1  
B. 若 $\left|OA\right|=4\left|AB\right|$ ，则 $k=\frac{1}{2}$ 或 2  
C. $k$ 的取值范围为 $\left(\frac{9 - 4\sqrt{2}}{7},\frac{9 + 4\sqrt{2}}{7}\right)$   
D. 弦 AB 长度的最大值为 $\sqrt{2}$

解析:选项 A 中, 其就是原问题, 故选项 A 正确; 选项 B 中, 其就是变式 1 中的问题, 故选项 B 正确; 选项 C 中, 设圆心 $C(3,3)$ 到直线 l 的距离为 d, 利用点到直线的距离公式有 $d=\frac{|3k-3|}{\sqrt{k^{2}+1}}<r=\sqrt{2}$ , 变形可得 $7k^{2}-18k+7<0$ , 解得 $\frac{9-4\sqrt{2}}{7}<k<\frac{9+4\sqrt{2}}{7}$ , 故选项 C 正确; 选项 D 中, 弦 AB 长度的最大值为圆的直径 $2r=2\sqrt{2}$ , 故选项 D 错误. 因此选: ABC.
