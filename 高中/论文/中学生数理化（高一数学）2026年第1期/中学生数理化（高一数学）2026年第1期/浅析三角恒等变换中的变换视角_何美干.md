# 浅析三角恒等变换中的变换视角

■何美干

在三角恒等变换中，离不开三角公式，如两角和与差的公式、二倍角公式、辅助角公式等，通过变换三角函数式中的角、函数名称、式子结构，以消除差异，达到化“未知”为“已知”，化“复杂”为“简单”的目的。下面结合例题，浅谈三角恒等变换中的变换视角。

# 视角一:变换角

例 1 已知 $\alpha, \beta$ 为锐角， $\tan\alpha=\frac{4}{3}, \cos(\alpha+\beta)=-\frac{\sqrt{5}}{5}$ 。

(1) 求 $\cos 2\alpha$ 的值。  
(2) 求 $\tan(\alpha-\beta)$ 的值。

解析:(1) 因为 $\tan \alpha = \frac{4}{3}$ ，又 $\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$ ，所以 $\sin \alpha = \frac{4}{3} \cos \alpha$ 。

又因为 $\sin^{2}\alpha + \cos^{2}\alpha = 1$ ，所以 $\cos^{2}\alpha = \frac{9}{25}$ ，所以 $\cos 2\alpha = 2\cos^{2}\alpha - 1 = -\frac{7}{25}$ 。

(2)由 $\alpha, \beta$ 为锐角，可得 $\alpha + \beta \in (0, \pi)$ 。因为 $\cos (\alpha + \beta) = -\frac{\sqrt{5}}{5}$ ，所以 $\sin (\alpha + \beta) = \sqrt{1 - \cos^2 (\alpha + \beta)} = \frac{2\sqrt{5}}{5}$ ，所以 $\tan (\alpha + \beta) = \frac{\sin (\alpha + \beta)}{\cos (\alpha + \beta)} = -2$ 。

又因为 $\tan \alpha = \frac{4}{3}$ ，所以 $\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha} = -\frac{24}{7}$ ，所以 $\tan (\alpha -\beta) = \tan [2\alpha -$ $(\alpha +\beta)] = \frac{\tan 2\alpha - \tan(\alpha + \beta)}{1 + \tan 2\alpha\tan(\alpha + \beta)} = -\frac{2}{11}$ 。

点评: 进行角变换时, 通过仔细观察, 明确题目中各个角之间的差异, 将各个角进行拼凑, 使二者为“和”“差”“倍”“半”等关系, 将已知角向所求角靠拢, 这样便于明确解题的目标, 实现问题的圆满解决。

# 视角三:变换次数

例 3 函数 $f(x)=\sin^{2}x+\sqrt{3}\sin x\cos x$ 的图像在 $[0,m)$ 上恰有两个最大值点，则 $\sin m$ 的取值范围为 \_\_\_\_。

解析: 函数 $f(x)=\sin^{2}x+\sqrt{3}\sin x\cos x=\frac{1}{2}(1-\cos 2x)+\frac{\sqrt{3}}{2}\sin 2x=\sin\left(2x-\frac{\pi}{6}\right)+\frac{1}{2}$ 。由 $x\in[0,m)$ ，可得 $2x-\frac{\pi}{6}\in\left[-\frac{\pi}{6},2m-\frac{\pi}{6}\right)$ 。因为函数 $f(x)=\sin\left(2x-\frac{\pi}{6}\right)+\frac{1}{2}$ 的图像在 $[0,m)$ 上恰有两个最大值点，所以 $2m-\frac{\pi}{6}\in\left(\frac{5\pi}{2},\frac{9\pi}{2}\right)$ ，即 $m\in\left(\frac{4\pi}{3},\frac{7\pi}{3}\right)$ ，所以 $\sin m\in\left[-1,\frac{\sqrt{3}}{2}\right]$ 。

或者，由 $\sin\left(2x-\frac{\pi}{6}\right)=1$ ，可得 $2x-\frac{\pi}{6}=2k\pi+\frac{\pi}{2}, k\in Z$ ，即 $x=k\pi+\frac{\pi}{3}, k\in Z$ 。当 x>0 时，函数 $f(x)$ 的第一、二、三个最大值点分别是 $\frac{\pi}{3}, \frac{4\pi}{3}, \frac{7\pi}{3}$ 。因为函数 $f(x)$ 在 $[0, m)$ 上恰有两个最大值点，所以 $\frac{4\pi}{3}<m\leqslant\frac{7\pi}{3}$ ，所以 $\sin m\in\left[-1,\frac{\sqrt{3}}{2}\right]$ 。

# 函数的对称性赏析

■张付坤 $^{1}$ 李晓茹 $^{2}$

![](images/f8fd1e9ea3f78c4b077ce9cf68e51370154b189658a3c6cfa2128b54f697fb84.jpg)

函数的对称性体现了数学的对称美, 函数的对称性可分为自对称和互相对称。自对称是函数图像自身关于某一条直线或某一个点对称, 如 $y=\frac{1}{x}$ 关于坐标原点对称; 互相对称是两个函数图像关于某一个点或某一条直线对称, 如 $y=2^{x}$ 与 $y=\log_{2}x$ 关于直线 y=x 对称。

# 一、自对称中的轴对称问题

例1 已知函数 $f(x) = \sin x + \frac{1}{\sin x}$ ，则（ ）。

A. $f(x)$ 的最小值为2  
B. $f(x)$ 的图像关于 y 轴对称  
C. $f(x)$ 的图像关于直线 $x=\pi$ 对称  
D. $f(x)$ 的图像关于直线 $x=\frac{\pi}{2}$ 对称

解:由 $\sin x \neq 0$ ，可得函数 $f(x)$ 的定义域为 $\{x \mid x \neq k\pi, k \in Z\}$ ，即定义域关于原点对称。设 $\sin x = t$ ，则原函数等价于函数 $y = t + \frac{1}{t}, t \in [-1, 0) \cup (0, 1]$ 。由对钩函数的图像与性质得 $y \leqslant -2$ 或 $y \geqslant 2$ ，A 错误。因为$f(-x)=\sin(-x)+\frac{1}{\sin(-x)}=-\left(\sin x+\frac{1}{\sin x}\right)=-f(x)$ ，且定义域关于原点对称，所以 $f(x)$ 是奇函数，所以函数 $f(x)$ 的图像关于原点中心对称，B错误。因为 $f(2\pi-x)=\sin(2\pi-x)+\frac{1}{\sin(2\pi-x)}=-\left(\sin x+\frac{1}{\sin x}\right)\neq f(x)$ ，所以 $f(2\pi-x)\neq f(x)$ ，可知 $f(x)$ 的图像不关于直线 $x=\pi$ 对称，C错误。因为 $f\left(\frac{\pi}{2}+x\right)=\sin\left(\frac{\pi}{2}+x\right)+\frac{1}{\sin\left(\frac{\pi}{2}+x\right)}= \cos x+\frac{1}{\cos x},f\left(\frac{\pi}{2}-x\right)=\sin\left(\frac{\pi}{2}-x\right)+\frac{1}{\sin\left(\frac{\pi}{2}-x\right)}=\cos x+\frac{1}{\cos x}$ ，即 $f\left(\frac{\pi}{2}+x\right)=f\left(\frac{\pi}{2}-x\right)$ ，且定义域为 $\{x|x\neq k\pi,k\in Z\}$ ，所以函数 $f(x)$ 的图像关于直线 $x=\frac{\pi}{2}$ 对称，D正确。应选D。

# 视角四:变换常数

例 4 若 $\alpha\in\left(\frac{\pi}{2},\pi\right)$ ，且 $\cos^{2}\alpha-\sin2\alpha=\frac{3}{10}$ ，则 $\tan\alpha=(\quad)$ 。

A.-7 B. $\frac{1}{3}$ C. $-\frac{1}{7}$ D.-7或 $\frac{1}{3}$

解析: 因为 $\cos^{2}\alpha - \sin 2\alpha = \frac{3}{10}$ ，所以

$\frac{\cos^{2}\alpha-\sin 2\alpha}{1}=\frac{\cos^{2}\alpha-2\sin\alpha\cos\alpha}{\sin^{2}\alpha+\cos^{2}\alpha}=\frac{3}{10}$ ，所以 $\frac{1-2\tan\alpha}{\tan^{2}\alpha+1}=\frac{3}{10}$ ，可得 $3\tan^{2}\alpha+20\tan\alpha-7=0$ ，解得 $\tan\alpha=-7$ 或 $\tan\alpha=\frac{1}{3}$ 。

又 $\alpha \in \left(\frac{\pi}{2},\pi\right)$ ，所以 $\tan \alpha = -7$ 。应选A。

点评:解答本题主要利用了弦切变换及 $\sin^{2}\alpha+\cos^{2}\alpha=1$ 的逆向变换。
