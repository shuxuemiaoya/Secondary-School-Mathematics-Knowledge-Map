# 题型 1: 合理变形后利用“1”的代换求最值

例 1 已知正数 x, y 满足 $\sqrt{4x^{2}-1} + \sqrt{4y^{2}-1} = 4xy$ ，则 $x^{2} + 3y^{2}$ 的最小值为 \_\_\_\_。

解: 利用换元法探索 x, y 的关系, 结合常数代换法求 $x^{2} + 3y^{2}$ 的最小值。已知 x, y 为正数, 且 $\sqrt{4x^{2}-1} + \sqrt{4y^{2}-1} = 4xy$ , 两边平方得 $4x^{2} + 4y^{2} + 2\sqrt{(4x^{2}-1)(4y^{2}-1)} - 2 = 16x^{2}y^{2}$ , 即 $2\sqrt{(4x^{2}-1)(4y^{2}-1)} = 16x^{2}y^{2} - 4x^{2}-4y^{2} + 2 = (4x^{2}-1)(4y^{2}-1) + 1$ 。

设 $t=\sqrt{(4x^{2}-1)(4y^{2}-1)}$ ，则 $2t=t^{2}+1$ ，解得 t=1，所以 $(4x^{2}-1)(4y^{2}-1)=1$ ，可得 $16x^{2}y^{2}=4x^{2}+4y^{2}$ ，即 $\frac{1}{x^{2}}+\frac{1}{y^{2}}=4$ 。

因为 $x^{2} + 3y^{2} = \frac{1}{4}\left(\frac{1}{x^{2}} +\frac{1}{y^{2}}\right)(x^{2} + 3y^{2})$ $= \frac{1}{4}\left(4 + \frac{3y^2}{x^2} +\frac{x^2}{y^2}\right)\geqslant \frac{1}{4}\left(4 + 2\sqrt{\frac{3y^2}{x^2}\cdot\frac{x^2}{y^2}}\right) =$ $\frac{4 + 2\sqrt{3}}{4} = 1 + \frac{\sqrt{3}}{2}$ ，当且仅当 $\left\{ \begin{array}{l} \frac{1}{x^2} +\frac{1}{y^2} = 4,\\ \frac{3y^2}{x^2} = \frac{x^2}{y^2}, \end{array} \right.$ 即

$\left\{ \begin{array}{l} x^{2} = \frac{1 + \sqrt{3}}{4}, \\ y^{2} = \frac{\sqrt{3} + 3}{12} \end{array} \right.$ 时等号成立，所以 $x^{2} + 3y^{2}$ 的

最小值为 $1+\frac{\sqrt{3}}{2}$ 。

点睛:解答本题的关键是利用题设条件,通过换元化归,构造“1”的代换求出最小值。

# 题型 2: 多元变量关系中的消元法求最值

例 2 已知 $a, b \in R_{+}$ ，且 $ab + 2a + b - 3 = 0$ ，则 $a + b$ 的最小值为（）。

A. $\frac{3}{2}$

B. $\frac{5}{3}$

C. $2 \sqrt{5} - 3$

D. $2 \sqrt{6} - 3$

解:由 $ab + 2a + b - 3 = 0$ ，可得 a =

$\frac{3 - b}{b + 2}$ , 所以 $a + b = \frac{3 - b}{b + 2} + b = \frac{5}{b + 2} + b - 1 = \frac{5}{b + 2} + (b + 2) - 3 \geqslant 2\sqrt{5} - 3$ , 当且仅当 $a = \sqrt{5} - 1, b = \sqrt{5} - 2$ 时等号成立, 所以 $a + b$ 的最小值为 $2\sqrt{5} - 3$ 。应选 C。

点睛:解答本题的关键是消元、凑出“积为常数”的形式,求出最小值。

# 题型 3: 整体换元化归为对钩型求最值

例 3 已知正数 a, b 满足 $\frac{5a+2b}{a(a+2b)}=4$ ，则 $a+b$ 的最小值为（）。

A. $\frac{3}{4}$

B. $\frac{7}{8}$

C. $\frac{9}{8}$

D. $\frac{3}{2}$

解:已知正数 a, b 满足 $\frac{5a+2b}{a(a+2b)}=4$ ，则 $5a+2b=4a^{2}+8ab$ ，可得 $2b(1-4a)=4a^{2}-5a$ ，即 $b=\frac{4a^{2}-5a}{2(1-4a)}$ 。因为 a, b>0，所以 $\frac{4a^{2}-5a}{2(1-4a)}>0$ ，所以 $\frac{(4a-5)a}{2(1-4a)}>0$ 等价于 $(4a-5)(4a-1)<0$ ，解得 $\frac{1}{4}<a<\frac{5}{4}$ 。易得 $a+b=a+\frac{4a^{2}-5a}{2(1-4a)}=\frac{2a-8a^{2}+4a^{2}-5a}{2(1-4a)}=\frac{-4a^{2}-3a}{2(1-4a)}$ 。令 1-4a=t，则 $t\in(-4,0)$ ，即 t<0，所以 $a+b=\frac{-4\left(\frac{1-t}{4}\right)^{2}-3\left(\frac{1-t}{4}\right)}{2t}=\frac{-\frac{1}{4}t^{2}+\frac{5}{4}t-1}{2t}=\left(-\frac{1}{8}t-\frac{1}{2t}\right)+\frac{5}{8}\geqslant2\sqrt{\left(-\frac{1}{8}t\right)\cdot\left(-\frac{1}{2t}\right)}+\frac{5}{8}=\frac{9}{8}$ ，当且仅当 $-\frac{1}{8}t=-\frac{1}{2t}$ ，即 t=-2，也即 $a=\frac{3}{4}$ ， $b=\frac{3}{8}$ 时等号成立，所以 $a+b$ 的最小值为 $\frac{9}{8}$ 。应选 C。

点睛:解答本题的关键是挖掘 $\frac{1}{4}<a<\frac{5}{4}$ ，令1-4a=t，则 $a+b=\left(-\frac{1}{8}t-\frac{1}{2t}\right)+\frac{5}{8}$ ，且在 $t\in(-4,0)$ 上求最小值。

题型 4: 双换元化归为“常数代换法”求最值

例 4 已知正数 a, b, c 满足 $2a + b + 3c = 8$ ，则 $\frac{a + b + 2c}{b + c} + \frac{1}{a + c}$ 的最小值为 \_\_\_\_。

解: 正数 a, b, c 满足 $2a + b + 3c = 8$ ，则 $2(a + c) + (b + c) = 8$ 。令 $a + c = m, b + c = n$ ，则 $2m + n = 8, m > 0, n > 0$ ，所以 $\frac{a + b + 2c}{b + c} + \frac{1}{a + c} = \frac{a + c + b + c}{b + c} + \frac{1}{a + c} = \frac{a + c}{b + c} + \frac{1}{a + c} + 1 = \frac{m}{n} + \frac{1}{m} + 1 = \frac{8 - n}{2n} + \frac{1}{m} + 1 = \frac{4}{n} + \frac{1}{m} + \frac{1}{2}$ 。因为 $\frac{4}{n} + \frac{1}{m} = \frac{1}{8}\left(\frac{4}{n} + \frac{1}{m}\right)(2m + n) = \frac{1}{8}\left(\frac{8m}{n} + 4 + 2 + \frac{n}{m}\right) \geqslant \frac{1}{8}\left(6 + 2\sqrt{\frac{8m}{n} \cdot \frac{n}{m}}\right) = \frac{3 + 2\sqrt{2}}{4}$ ，当且仅当 $\frac{8m}{n} = \frac{n}{m}$ ，即 $m = 4\sqrt{2} - 4$ ， $n = 16 - 8\sqrt{2}$ 时等号成立，所以 $\frac{4}{n} + \frac{1}{m} + \frac{1}{2} \geqslant \frac{3 + 2\sqrt{2}}{4} + \frac{1}{2} = \frac{5 + 2\sqrt{2}}{4}$ ，即 $\frac{a + b + 2c}{b + c} + \frac{1}{a + c}$ 的最小值为 $\frac{5 + 2\sqrt{2}}{4}$ 。

点睛:解答本题的关键是双换元后构造常数“1”的代换求出最小值。

题型 5: 已知条件等式, 利用基本不等式求最值

例 5 已知 x>0, y>0，且 $x+y-xy+3=0$ ，则下列说法正确的是（）。

A. $3 < xy \leqslant 12$   
B. $x + y \geqslant 3$   
C. $x^{2} + y^{2} \geqslant 18$   
D. $0 < \frac{1}{x} + \frac{1}{y} \leqslant \frac{1}{3}$

解: 对于 A, 由 $xy - 3 = x + y \geqslant 2\sqrt{xy}$ , 可得 $xy - 3 \geqslant 2\sqrt{xy}$ (当且仅当 x = y 时等号成立), 所以 $(\sqrt{xy})^{2} - 2\sqrt{xy} - 3 \geqslant 0$ , 解得

$\sqrt{xy} \geqslant 3$ ，即 $xy \geqslant 9$ ，A 不正确。对于 B，由 $x + y + 3 = xy \leqslant \left(\frac{x + y}{2}\right)^2$ ，可得 $x + y + 3 \leqslant \left(\frac{x + y}{2}\right)^2$ （当且仅当 $x = y$ 时等号成立），所以 $(x + y)^2 - 4(x + y) - 12 \geqslant 0$ ，解得 $x + y \geqslant 6$ 或 $x + y \leqslant -2$ （舍去），B 错误。对于 C， $x^2 + y^2 = (x + y)^2 - 2xy = (x + y)^2 - 2(x + y + 3) = (x + y)^2 - 2(x + y) - 6$ ，令 $t = x + y$ ，由 B 得 $t \geqslant 6$ ，所以 $x^2 + y^2 = t^2 - 2t - 6 = (t - 1)^2 - 7 \geqslant (6 - 1)^2 - 7 = 18$ ，即 $x^2 + y^2 \geqslant 18$ ，C 正确。对于 D， $\frac{1}{x} + \frac{1}{y} = \frac{x + y}{xy} = \frac{xy - 3}{xy} = 1 - \frac{3}{xy}$ ，令 $t = xy$ ，由 A 得 $t \geqslant 9$ ，则 $\frac{1}{x} + \frac{1}{y} = 1 - \frac{3}{t} \geqslant 1 - \frac{3}{9} = \frac{2}{3}$ ，即 $\frac{1}{x} + \frac{1}{y} \geqslant \frac{2}{3}$ ，D 不正确。应选 C。

点睛:解答本题的关键是寻找条件等式和所求不等式之间的关系,利用基本不等式求出最值。

# 题型 6:两次运用基本不等式求最值

例 6 已知 a 为非零实数, b, c 均为正实数, 则 $\frac{a^{2}b+a^{2}c}{4a^{4}+b^{2}+c^{2}}$ 的最大值为()。

A. $\frac{1}{2}$

B. $\frac{\sqrt{2}}{4}$

C. $\frac{\sqrt{2}}{2}$

D. $\frac{\sqrt{3}}{4}$

解: 已知 a 为非零实数, 则  \( a^{2} > 0 \) 。结合 b, c 均为正实数, 可得  \( \frac{a^{2}b + a^{2}c}{4a^{4} + b^{2} + c^{2}} = \frac{b + c}{4a^{2} + \frac{b^{2} + c^{2}}{a^{2}}} \leqslant \frac{b + c}{2\sqrt{4a^{2} \cdot \frac{b^{2} + c^{2}}{a^{2}}}} = \frac{b + c}{4\sqrt{b^{2} + c^{2}}} = \frac{1}{4}\sqrt{\frac{b^{2} + 2bc + c^{2}}{b^{2} + c^{2}}} = \frac{1}{4}\sqrt{1 + \frac{2bc}{b^{2} + c^{2}}} \leqslant \frac{1}{4}\sqrt{1 + \frac{2bc}{2bc}} = \frac{\sqrt{2}}{4} \text {, 当且仅当 } 4a^{2} = \frac{b^{2} + c^{2}}{a^{2}} \text { 且 } b = c \text {, 即 } \sqrt{2} a^{2} = b = c \text { 时取等号, 所以 } \frac{a^{2}b + a^{2}c}{4a^{4} + b^{2} + c^{2}} \text { 的最大值为 } \frac{\sqrt{2}}{4} \text {。应选 B。

点睛: 当多次运用基本不等式时, 要注意不等式取等号的条件。
