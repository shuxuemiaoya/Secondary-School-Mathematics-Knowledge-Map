# 一、集合问题

例 1 （多选题）集合 A, B 是实数集 R 的子集，定义 $A - B = \{x \mid x \in A \text{ 且 } x \notin B\}$ ，若集合 $A = \{y \mid y = (x - 1)^2 + 1, 0 \leqslant x \leqslant 3\}$ ， $B = \{y \mid y = x^2 + 1, 1 \leqslant x \leqslant 3\}$ ，则下列关系正确的是（）。

A. $A=[-1,5]$

B. $B = [2,10]$

C. $A - B = [1, 2)$

D. $B - A = (5,10]$

解析:由 $A=\{y\mid y=(x-1)^{2}+1,0\leqslant x\leqslant3\}=\{y\mid1\leqslant y\leqslant5\}=[1,5],B=\{y\mid y=x^{2}+1,1\leqslant x\leqslant3\}=\{y\mid2\leqslant y\leqslant10\}=[2,10]$ ，结合 $A-B=\{x\mid x\in A$ 且 $x\notin B\}$ 得 $A-B=\{y\mid1\leqslant y<2\}=[1,2),B-A=\{y\mid5<y\leqslant10\}=(5,10]$ 。应选 BCD。

评注:用描述法表示集合时,要理解集合中的代表元素,要注意“且”与“或”的区别。

# 二、指数函数问题

例 2 已知函数 $f(x)=\left(\frac{1}{2025}\right)^{ax^{2}-2x+2a}$ 的最大值为 2025，则 a 的值为 \_\_\_\_。

解析: 令函数 $y=\left(\frac{1}{2025}\right)^{t}$ ，且 $t=ax^{2}-2x+2a$ 。因为函数 $y=\left(\frac{1}{2025}\right)^{t}$ 单调递减，又函数 $f(x)=\left(\frac{1}{2025}\right)^{ax^{2}-2x+2a}$ 的最大值为 2025，所以函数 $t=ax^{2}-2x+2a$ 的最小值为 -1，所以 a>0，且当 $x=-\frac{-2}{2a}=\frac{1}{a}$ 时， $t_{\min}=\frac{8a^{2}-4}{4a}=-1$ ，即 $2a^{2}+a-1=0$ ，解得 $a=\frac{1}{2}$ 或 a=-1（舍去），所以 $a=\frac{1}{2}$ 。

评注:复合函数中,内层函数的值域是外层函数的定义域。解答本题的关键是利用函数 $f(x)=\left(\frac{1}{2025}\right)^{ax^{2}-2x+2a}$ 的最大值为 2025, 得到函数 $t=ax^{2}-2x+2a$ 的最小值为 -1。

# 三、不等式问题

例 3 已知函数 $f(x)=\left\{\frac{1}{2}x+1,x\leqslant0,\right.$ 使得 $f(x)\geqslant-1$ 成立的 $-(x-1)^{2},x>0,$ x 的取值范围为 \_\_\_\_。

解析：由题意得 $\left\{\begin{aligned}x&\leqslant0,\\ \frac{1}{2}x+1&\geqslant-1\end{aligned}\right.$ 或 $\left\{\begin{aligned}x&>0,\\ -(x-1)^{2}&\geqslant-1,\end{aligned}\right.$ 解得 $-4\leqslant x\leqslant0$ 或 $0<x\leqslant2$ ，故使得 $f(x)\geqslant-1$ 成立的 x 的取值范围是 $[-4,2]$ 。

评注: 分段函数问题, 应注意各段函数式满足的条件。

# 四、三角函数问题

例 4 已知函数 $f(x)=\sin x+\cos x+2\sin x\cos x+2$ ，则函数 $f(x)$ 的最大值是（）。

A. $3 + \sqrt{2}$

B. $3 - \sqrt{2}$

C. $2 + \sqrt{2}$

D. $2 - \sqrt{2}$

解析: 设 $t = \sin x + \cos x$ ，则 $\sin x \cos x = \frac{(\sin x + \cos x)^{2} - 1}{2} = \frac{t^{2} - 1}{2}$ ，且 $t = \sin x + \cos x = \sqrt{2} \sin \left( x + \frac{\pi}{4} \right) \in [-\sqrt{2}, \sqrt{2}]$ 。

所以函数 $f(x)$ 等价于函数 $g(t) = t + t^2 - 1 + 2 = \left(t + \frac{1}{2}\right)^2 + \frac{3}{4}, t \in [-\sqrt{2}, \sqrt{2}]$ 。故当 $t = \sqrt{2}$ 时， $g(t)$ 有最大值 $g(t)_{\max} = \sqrt{2} + 2 + 1 = 3 + \sqrt{2}$ ，所以 $f(x)_{\max} = 3 + \sqrt{2}$ 。应选 A。

评注:正余弦函数的“三姊妹”关系 $\sin \alpha \pm \cos \alpha$ 、 $\sin \alpha \cos \alpha$ ，可“知一求二”。
