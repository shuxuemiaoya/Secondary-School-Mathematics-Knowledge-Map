# 一、求函数的解析式

例 1 已知 $f(1 - \sin x) = \cos^{2}x$ ，则 $f(x) =$ \_\_\_\_ 。

解析: 设 $1 - \sin x = t, t \in [0, 2]$ ，则 $\sin x = 1 - t$ 。因为 $f(1 - \sin x) = \cos^{2}x = 1 - \sin^{2}x$ ，所以 $f(t) = 1 - (1 - t)^{2} = 2t - t^{2}, t \in [0, 2]$ ，即函数 $f(x) = 2x - x^{2}, x \in [0, 2]$ 。

评注: 利用换元法解题时要注意换元后新元的取值范围。

# 二、求函数的值

例 2 已知函数 $f(x)$ 是定义在 $(0, +\infty)$ 上的单调函数，且 $\forall x \in (0, +\infty)$ ，都有 $f\left(f(x) + \frac{2}{x}\right) = -1$ ，则 $f(1) = (\quad)$ 。

A.-4

B.-3

C.-1

D. 0

解析:由题意设 $f(x)+\frac{2}{x}=k$ ，显然 k>0。因为 $f\left(f(x)+\frac{2}{x}\right)=f(k)=-1$ ，所以 $f(k)=k-\frac{2}{k}=-1$ ，解得 k=1（负值舍去），所以 $f(1)=-1$ 。应选 C。

评注:本题涉及两个变量 x, k, 它们的取值范围相同, 其含义是不同的。

# 三、求函数的最值

例 3 设 $b \in R$ ，若函数 $f(x) = 4^{x} - 2^{x+1} + b$ 在 $[-1, 1]$ 上的最大值是 3，则函数 $f(x)$ 在 $[-1, 1]$ 上的最小值是（）。

A. 2

B. 1

C. 0

D.-1

解析: 函数 $f(x)=4^{x}-2^{x+1}+b=(2^{x})^{2}-2\cdot2^{x}+b$ 。设 $2^{x}=t$ ，由 $x\in[-1,1]$ ，可得 $t\in\left[\frac{1}{2},2\right]$ 。所以函数 $f(x)$ 等价于 $y=t^{2}-2t+b=(t-1)^{2}+b-1$ ，所以 $y_{\min}=b-1$ 。由 $y_{\max}=(2-1)^{2}+b-1=3$ ，可得 b=3。故 $f(x)_{\min}=y_{\min}=2$ 。应选 A。

评注：函数 $y = t^2 - 2t + b$ 在 $\left[\frac{1}{2}, 1\right]$ 上单

调递减，在[1,2]上单调递增。

# 四、求参数的值

例4（多选题）已知函数 $f(x) = \left\{ \begin{array}{ll}x^{2} + 2x + 1, & x\leqslant 0,\\ -x^{2}, & x > 0, \end{array} \right.$ 满足 $f(f(a)) = -1$ 的 $a$ 的值可以为（ ）。

A. 0

B. 1

C.-1

D.-2

解析: 设 $t = f(a)$ ，则 $f(t) = -1$ 。

若 t>0，则 $-t^{2}=-1$ ，解得 t=1 或 t=-1（舍去），所以 $f(a)=1$ 。当 a>0 时，则 $-a^{2}=1$ ，这时方程无解；当 $a\leqslant0$ 时，则 $a^{2}+2a+1=1$ ，解得 a=0 或 a=-2，满足条件。所以 A，D 满足题意。

若 $t \leqslant 0$ ，则 $t^{2} + 2t + 1 = -1$ ，即 $t^{2} + 2t + 2 = 0$ ，这时 $\Delta = 2^{2} - 4 \times 2 = -4 < 0$ ，即此方程无解，可知没有满足题意的 a 值。

故选 AD。

评注:解答本题的关键是对参数 a, t 的分类讨论。

# 五、求代数式的值

例 5 若函数 $f(x)=ae^{x}+b\sin x+\cos 2x$ 的值域为 $\left[-3,\frac{3}{2}\right]$ ，则 $a+b=$ （）。

A. $\frac{3}{2}$

B. $\pm\frac{3}{2}$

C. 2

D. $\pm2$

解析: 当 $a<0, x\to+\infty$ 时, $f(x)\to-\infty$ , 则 $f(x)$ 不存在最小值, 不符合题意; 当 $a>0, x\to+\infty$ 时, $f(x)\to+\infty$ , 则 $f(x)$ 不存在最大值, 不符合题意。所以只有 a=0 。所以函数 $f(x)=b\sin x+\cos 2x=-2\sin^{2}x+b\sin x+1$ 。

令 $t = \sin x$ ，可得 $t\in [-1,1]$ ，所以函数 $f(x)$ 等价于函数 $g(t) = -2t^2 +bt + 1$ ，其对称轴为直线 $t = \frac{b}{4}$ 。易得 $g(-1) = -1 - b$ $g(1) = -1 + b$ 。

当 $t = \frac{b}{4} \geqslant 1$ ，即 $b \geqslant 4$ 时， $g(t)$ 在 $t \in [-1, 1]$ 上单调递增，则 $g(-1) = -1 - b = -3, g(1) = -1 + b = \frac{3}{2}$ ，这时不存在符合题意的 $b$ 值；当 $t = \frac{b}{4} \leqslant -1$ ，即 $b \leqslant -4$ 时， $g(t)$ 在 $t \in [-1, 1]$ 上单调递减，则 $g(-1) = -1 - b = \frac{3}{2}, g(1) = -1 + b = -3$ ，这时不存在符合题意的 $b$ 值。

当 $-1 < t = \frac{b}{4} < 1$ ，即 $-4 < b < 4$ 时，由 $g\left(\frac{b}{4}\right) = \frac{3}{2}$ ，即 $-2\left(\frac{b}{4}\right)^2 + b\left(\frac{b}{4}\right) + 1 = \frac{3}{2}$ ，化简整理得 $b^2 = 4$ ，解得 $b = \pm 2$ 。当 $b = 2$ 时，函数的最小值为 $g(-1) = -3$ ，符合题意；当 $b = -2$ 时，函数最小值为 $g(1) = -3$ ，符合题意。

故 $a+b=\pm2$ 。应选 D。

评注:解答本题的关键是根据题意确定a=0。

# 六、求三角函数式的值

例 6 $\sin^{2}20^{\circ}+\cos^{2}80^{\circ}+\sqrt{3}\sin20^{\circ}\cdot\cos80^{\circ}$ 的值等于 \_\_\_\_。

$$
\begin{array}{l} \sqrt {3} \cos 2 0 ^ {\circ} \sin 8 0 ^ {\circ}, \text {则} x + y = 1 + 1 - \sqrt {3} \sin 6 0 ^ {\circ} \\ = \frac {1}{2}, x - y = - \cos 4 0 ^ {\circ} + \cos 1 6 0 ^ {\circ} + \\ \sqrt {3} \sin 1 0 0 ^ {\circ} = - 2 \sin 1 0 0 ^ {\circ} \sin 6 0 ^ {\circ} + \sqrt {3} \sin 1 0 0 ^ {\circ} \\ + \cos^ {2} 8 0 ^ {\circ} + \sqrt {3} \sin 2 0 ^ {\circ} \cos 8 0 ^ {\circ} = \frac {1}{4} 。 \\ \end{array}
$$

解析:由题意设 $x=\sin^{2}20^{\circ}+\cos^{2}80^{\circ}+\sqrt{3}\sin20^{\circ}\cos80^{\circ},\quad y=\cos^{2}20^{\circ}+\sin^{2}80^{\circ}-$

=0。据上可得， $x=y=\frac{1}{4}$ ，所以 $x=\sin^{2}20^{\circ}$

评注:利用换元法构造对偶式是解答本题的点睛之笔。

# 七、解不等式

例 7 已知函数 $f(x)=3^{x-2}-3^{2-x}$ ，则满足 $f(x)+f(8-3x)>0$ 的 x 的取值范围是（）。

A. $(-∞,4)$

B. $(-∞,2)$

C. $(2,+\infty)$

D. $(-2,2)$

解析:设函数 $g(x)=3^{x}-3^{-x}, x \in \mathbf{R}$ ，则 $g(-x)=3^{-x}-3^{x}=-g(x)$ ，即 $g(x)$ 为奇函

数。因为 $f(x)=3^{x-2}-3^{2-x}=3^{x-2}-3^{-(x-2)}=g(x-2)$ ，所以 $f(x)$ 的图像是由 $g(x)$ 的图像向右平移 2 个单位长度得到，所以 $f(x)$ 图像的对称中心为 $(2,0)$ ，所以 $f(x)+f(4-x)=0$ 。因为 $y=3^{x}$ 在 R 上单调递增， $y=3^{-x}$ 在 R 上单调递减，所以 $g(x)=3^{x}-3^{-x}$ 在 R 上单调递增，则 $f(x)$ 在 R 上单调递增。由 $f(x)+f(8-3x)>0=f(x)+f(4-x)$ ，可得 $f(8-3x)>f(4-x)$ ，所以 $8-3x>4-x$ ，解得 x<2，即满足 $f(x)+f(8-3x)>0$ 的 x 的取值范围为 $(-∞,2)$ 。应选 B。

评注:解答本题的关键是构造函数 $g(x)=3^{x}-3^{-x}$ ，从而找出 $f(x)$ 与 $g(x)$ 图像的联系，使得问题顺利获解。

# 八、求参数的取值范围

例 8 已知函数 $f(x)=2a \cdot 4^{x}-2^{x}-1$ 有零点，则实数 a 的取值范围是 \_\_\_\_。

解析: 函数 $f(x)=2a \cdot 4^{x}-2^{x}-1$ 有零点, 则方程 $2a \cdot 4^{x}-2^{x}-1=0$ 有解, 所以 $2a=\frac{2^{x}+1}{4^{x}}=\left(\frac{1}{2}\right)^{x}+\left(\frac{1}{4}\right)^{x}$ 。

令 $\left(\frac{1}{2}\right)^{x}=t$ ，由 $x\in R$ ，可得t>0。令 $m(x)=\left(\frac{1}{2}\right)^{x}+\left(\frac{1}{4}\right)^{x}$ ，则 $m(x)$ 等价于 $g(t)=t+t^{2}=\left(t+\frac{1}{2}\right)^{2}-\frac{1}{4}$ 。因为 $g(t)$ 在 $(0,+\infty)$ 上为增函数，其值域为 $(0,+\infty)$ ，即 $g(t)>0$ ，所以2a>0，即实数a的取值范围是 $(0,+\infty)$ 。

评注: 函数的零点即对应方程的根。本题是通过分离参数, 结合换元法求解的。
