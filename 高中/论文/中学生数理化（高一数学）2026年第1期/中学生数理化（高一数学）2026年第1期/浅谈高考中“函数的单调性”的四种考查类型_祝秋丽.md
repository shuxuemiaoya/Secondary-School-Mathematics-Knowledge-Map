函数的单调性是函数的重要性质之一，是每年高考的常考点，备受命题者的青睐，因此要引起同学们的高度重视。

# 一、“文字语言”型,即通过题设得到函数的单调性或单调区间

例 1 已知奇函数 $f(x)$ 在 $(-∞,+∞)$ 上单调递增，若 $a=-f\left(\log_{2}\frac{1}{5}\right)$ ， $b=f(\log_{2}4.1)$ ， $c=f(2^{0.8})$ ，则 a, b, c 的大小关系是（）。

A. a < b < c

B. $b < a < c$

C. c < b < a

D. $c < a < b$

解:由题意得 $a=f\left(-\log_{2}\frac{1}{5}\right)=f(\log_{2}5)$ 。因为 $f(x)$ 在 $(-∞,+∞)$ 上单调递增，且 $\log_{2}5>\log_{2}4.1>2^{0.8}$ ，所以 $f(\log_{2}5)>f(\log_{2}4.1)>f(2^{0.8})$ ，即 a,b,c 的大小关系是 a>b>c。应选 C。

# 二、“图形语言”型,即通过图像得到函数的单调性或单调区间

例 2 已知函数 $f(x)=\left\{\begin{aligned}&2^{-x},&x\leqslant0,\\ &1,&x>0,\end{aligned}\right.$ 若 $f(x+1)<f(2x)$ ，则实数 x 的取值范围是 \_\_\_\_。

解:由 $f(x)$ 的图像(图略)知函数 $f(x)$ 在区间 $(-∞,0]$ 上单调递减。当 $x+1≤0$ ， $2x≤0$ 时， $f(x+1)<f(2x)$ 等价于 $\left\{\begin{aligned}&x+1\leqslant0,\\ &2x\leqslant0,\quad 解得 x\leqslant-1; 当 2x<0,x+1> \\ &x+1>2x,\end{aligned}\right.$

0 时, $f(2x)>1,f(x+1)=1$ ,满足 $f(x+1)<f(2x)$ ,可得-1<x<0。

综上可得,实数 x 的取值范围是 $(-∞,-1]∪(-1,0)=(-∞,0)$ 。

# 三、“符号语言”型,即通过函数满足的条件得到函数的单调性或单调区间

例3 已知 $f(x)$ 是定义在 $\mathbf{R}$ 上的奇函数，对任意两个不等正数 $x_{1}, x_{2}$ ，都有 $\frac{x_{2}f(x_{1}) - x_{1}f(x_{2})}{x_{1} - x_{2}} < 0$ ，记 $a = \frac{f(4.1^{0.2})}{4.1^{0.2}}$ ， $b = \frac{f(0.4^{2.1})}{0.4^{2.1}}$ , $c = \frac{f(\log_{0.2}4.1)}{\log_{0.2}4.1}$ ，则（ ）。

A. a<c<b

B. a < b < c

C. c < b < a

D. $b < c < a$

解: 设 $0 < x_{1} < x_{2}$ ，由题设得 $x_{2}f(x_{1}) - x_{1}f(x_{2}) > 0$ ，即 $\frac{f(x_{1})}{x_{1}} > \frac{f(x_{2})}{x_{2}}$ ，所以函数 $g(x) = \frac{f(x)}{x}$ 在 $(0, +\infty)$ 上单调递减。易得 $a = \frac{f(4.1^{0.2})}{4.1^{0.2}} = g(4.1^{0.2}) < g(1)$ ， $b = \frac{f(0.4^{2.1})}{0.4^{2.1}} = g(0.4^{2.1}) > g(0.4^{2}) > g\left(\frac{1}{2}\right)$ 。因为 $4.1^{2} > 5$ ，所以 $\frac{1}{2} < \log_{5}4.1 < 1$ ，所以 $g(1) < g(\log_{5}4.1) < g\left(\frac{1}{2}\right)$ 。因为 $f(x)$ 是奇函数，所以 $g(x) = \frac{f(x)}{x}$ 是 $(-∞, 0) ∪ (0, +∞)$ 上的偶函数，所以 $c = \frac{f(\log_{0.2}4.1)}{\log_{0.2}4.1} = g(\log_{0.2}4.1) = g(-\log_{0.2}4.1) = g(\log_{5}4.1) ∈ (g(1), g\left(\frac{1}{2}\right))$ 。故 a < g(1) < c < g $\left(\frac{1}{2}\right) < b$ ，即 a < c < b。应选 A。

一元二次不等式的恒成立与存在性问题是高考的考查热点之一。这类问题综合性强，涉及分类讨论、参数分离、变换主元等方法。下面通过典型例题剖析五类常见题型，帮助同学们开阔解题思路，提升逻辑推理与转化能力。

题型一:一元二次不等式在实数集上的恒成立问题

例 1 若不等式 $2(a-1)x^{2}+(a-1)x-\frac{3}{4}<0$ 对一切实数 x 都成立，则实数 a 的取值范围为 \_\_\_\_。

分析: 利用一元二次不等式在实数集上的恒成立, 分类求出 a 的范围。

解: 当 a=1 时, 原不等式可化为 $-\frac{3}{4}<0$ , 此不等式对一切实数 x 都成立; 当 $a\neq1$ 时, 由 $\left\{\begin{aligned}&2(a-1)<0,\\ &(a-1)^{2}-4\times2(a-1)\times\left(-\frac{3}{4}\right)<0,\end{aligned}\right.$ 解得 -5<a<1。

综上得实数 a 的取值范围为 $(-5,1]$ 。

评注: 解决一元二次不等式在实数集上的恒成立问题, 若二次项系数含有参数, 则需对二次项系数是否为 0 进行分类讨论。
