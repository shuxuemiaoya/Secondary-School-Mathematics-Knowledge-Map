# 三角恒等变换题型总结

# ■陈海峰

# 一、和角公式的应用

例 1 已知 $\tan \alpha \tan \beta = 2, \cos (\alpha - \beta) = \frac{1}{3}$ ，则 $\cos (\alpha + \beta) =$ \_\_\_\_ 。

解析: 因为 $\tan\alpha\tan\beta=\frac{\sin\alpha\cdot\sin\beta}{\cos\alpha\cdot\cos\beta}=2$ ，
所以 $\sin\alpha\sin\beta=2\cos\alpha\cos\beta.$ ①

又 $\cos (\alpha -\beta) = \cos \alpha \cos \beta +\sin \alpha \sin \beta =$ $3\cos \alpha \cos \beta = \frac{1}{3}$ ，所以 $\cos \alpha \cos \beta = \frac{1}{9}$ 。 ②

将②代入①得 $\sin\alpha\sin\beta=\frac{2}{9}$ 。故 $\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta=-\frac{1}{9}$ 。

点评:本题主要考查两角和与差的三角函数公式的灵活应用。

# 二、倍角公式的应用

例2 已知 $\cos \left(\frac{\pi}{4} - x\right) = \frac{5}{13}, 0 < x < \frac{\pi}{4}$ , 求 $\frac{\cos 2x}{\sin x + \cos x}$ 的值。

解析: 易得 $\sin\left(\frac{\pi}{4}+x\right)=\cos\left(\frac{\pi}{4}-x\right)=$ $\frac{5}{13}, \cos 2x = \sin \left( \frac{\pi}{2} + 2x \right) = 2 \sin \left( \frac{\pi}{4} + x \right) \cdot$

$$
\cos \left(\frac {\pi}{4} + x\right), \sin x + \cos x = \sqrt {2} \sin \left(\frac {\pi}{4} + x\right) 。
$$

因为 $0 < x < \frac{\pi}{4}$ , 所以 $\frac{\pi}{4} < x + \frac{\pi}{4} < \frac{\pi}{2}$ 。故

$$
\frac {\cos 2 x}{\sin x + \cos x} = \frac {2 \sin \left(\frac {\pi}{4} + x\right) \cos \left(\frac {\pi}{4} + x\right)}{\sqrt {2} \sin \left(\frac {\pi}{4} + x\right)} =
$$

$\sqrt{2} \cos \left( \frac{\pi}{4} + x \right) = \sqrt{2} \sqrt{1 - \sin^2 \left( \frac{\pi}{4} + x \right)} = \frac{12\sqrt{2}}{13}$ 。

点评: 在解决三角函数问题中, 若将二倍角的正弦、余弦公式与它们的变通公式联合应用, 则会降低解题难度, 使问题轻松获解。

# 三、三角函数的求值

例3 已知 $\sin \left(\alpha +\frac{\pi}{6}\right) + \cos \alpha = \frac{4\sqrt{3}}{5}$ ，则$\sin\left(\alpha+\frac{\pi}{3}\right)$ 的值为()。

A. $\frac{4}{5}$

B. $\frac{3}{5}$

C. $\frac{\sqrt{3}}{2}$

D. $\frac{\sqrt{3}}{5}$

解析:由 $\sin\left(\alpha+\frac{\pi}{6}\right)+\cos\alpha=\frac{4\sqrt{3}}{5}$ ，可得 $\frac{\sqrt{3}}{2}\sin\alpha+\frac{1}{2}\cos\alpha+\cos\alpha=\frac{4\sqrt{3}}{5}$ ，所以 $\frac{\sqrt{3}}{2}\sin\alpha+\frac{3}{2}\cos\alpha=\frac{4\sqrt{3}}{5}$ ，所以 $\frac{1}{2}\sin\alpha+\frac{\sqrt{3}}{2}\cos\alpha=\frac{4}{5}$ ，所以 $\cos\frac{\pi}{3}\sin\alpha+\sin\frac{\pi}{3}\cos\alpha=\frac{4}{5}$ ，即 $\sin\left(\frac{\pi}{3}+\alpha\right)=\frac{4}{5}$ 。应选 A。

点评:本题主要考查两角和与差的正弦公式的灵活应用。

# 四、三角恒等变换与函数性质的交汇

例4 函数 $f(x) = \sin 2x + 2\sqrt{2}\cos \left(\frac{\pi}{4} + x\right) + 3$ 的最小值是 \_\_\_\_。

解析: $f(x)=\sin2x+2\sqrt{2}\cos\left(\frac{\pi}{4}+x\right)+3=\cos\left(2x-\frac{\pi}{2}\right)+2\sqrt{2}\cos\left[\frac{\pi}{2}-\left(\frac{\pi}{4}-x\right)\right]+3=1-2\sin^{2}\left(x-\frac{\pi}{4}\right)+2\sqrt{2}\sin\left(\frac{\pi}{4}-x\right)+3=4-\left[2\sin^{2}\left(x-\frac{\pi}{4}\right)+2\sqrt{2}\sin\left(x-\frac{\pi}{4}\right)+1\right]+1=5-\left[\sqrt{2}\sin\left(x-\frac{\pi}{4}\right)+1\right]^{2}$ 。

因为 $\sin\left(x-\frac{\pi}{4}\right)\in[-1,1]$ ，所以函数 $f(x)=\sin2x+2\sqrt{2}\cos\left(\frac{\pi}{4}+x\right)+3$ 的最小值为 $5-(\sqrt{2}+1)^{2}=2-2\sqrt{2}$ 。

点评:本题主要考查三角恒等变换与正弦型函数在闭区间上的最值问题。解题时,先利用三角恒等变换把所求函数转化为 $f(x)=A\sin(\omega x+\theta)$ 的形式,再研究函数的最值。
