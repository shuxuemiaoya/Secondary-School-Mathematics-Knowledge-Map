题目（2024年高考北京卷）已知 $(x_{1},y_{1}),(x_{2},y_{2})$ 是函数 $y=2^{x}$ 图像上不同的两点，则下列不等式正确的是()。

A. $\log_2\frac{y_1 + y_2}{2} >\frac{x_1 + x_2}{2}$   
B. $\log_2\frac{y_1 + y_2}{2} <  \frac{x_1 + x_2}{2}$   
C. $\log_2\frac{y_1 + y_2}{2} >x_1 + x_2$   
D. $\log_{2}\frac{y_{1}+y_{2}}{2}<x_{1}+x_{2}$

解法1：(对数函数、指数函数的单调性+赋值法)由基本不等式及对数函数的单调性可判断A，B；利用赋值法可判断C，D。不妨设 $x_{1} < x_{2}, x_{1}, x_{2} \in \mathbb{R}$ ，因为函数 $y = 2^{x}$ 是增函数，所以 $0 < 2^{x_{1}} < 2^{x_{2}}$ ，即 $0 < y_{1} < y_{2}$ 。对于A，B，由 $\frac{2^{x_1} + 2^{x_2}}{2} > \sqrt{2^{x_1} \cdot 2^{x_2}} = 2^{\frac{x_1 + x_2}{2}}$ ，可得 $\frac{y_1 + y_2}{2} > 2^{\frac{x_1 + x_2}{2}} > 0$ ，结合函数 $y = \log_2 x$ 单调递增得 $\log_2 \frac{y_1 + y_2}{2} > \log_2 2^{\frac{x_1 + x_2}{2}} = \frac{x_1 + x_2}{2}$ ，A正确，B错误。对于C，不妨取 $x_{1} = 0, x_{2} = 1$ ，则 $y_{1} = 1, y_{2} = 2$ ，可得 $\log_2 \frac{y_1 + y_2}{2} = \log_2 \frac{3}{2} \in (0, 1)$ ，即 $\log_2 \frac{y_1 + y_2}{2} < 1 = x_1 + x_2$ ，C错误。对于D，不妨取 $x_{1} = -2, x_{2} = -1$ ，结合 $y = 2^{x}$ 得 $y_{1} = \frac{1}{4}, y_{2} = \frac{1}{2}$ ，所以 $\log_2 \frac{y_1 + y_2}{2} = \log_2 \frac{3}{8} = \log_2 3 - 3 \in (-2, -1)$ ，即 $\log_2 \frac{y_1 + y_2}{2} > -3 = x_1 + x_2$ ，D错误。应选A。

解法 2: (对数函数、指数函数的单调性 + 作差法) 利用作差法, 结合指对数互换及对数函数的单调性即可判断。不妨设 $x_1 < x_2$ , 对于 A, B, 由题意得 $\log_2 \frac{y_1 + y_2}{2} - \left( \frac{x_1 + x_2}{2} \right) = \log_2 \frac{2^{x_1} + 2^{x_2}}{2} - \log_2 2^{\frac{x_1 + x_2}{2}} = \log_2 \frac{2^{x_1} + 2^{x_2}}{2 \cdot 2^{\frac{x_1 + x_2}{2}}} = \log_2 \frac{1}{2} (2^{\frac{x_1 - x_2}{2}} + 2^{\frac{x_2 - x_1}{2}}) > \log_2 1 = 0$ , A 正确, B 错误。对于 C, D, 由题意得 $\log_2 \frac{y_1 + y_2}{2} - (x_1 + x_2) = \log_2 \frac{y_1 + y_2}{2} - (\log_2 y_1 + \log_2 y_2) = \log_2 \frac{y_1 + y_2}{2y_1y_2} = \log_2 \frac{1}{2} \left( \frac{1}{y_1} + \frac{1}{y_2} \right)$ , 注意到当 $y_1 > 0, y_2 > 0$ 且 $y_1 \neq y_2$ 时, $\frac{1}{2} \left( \frac{1}{y_1} + \frac{1}{y_2} \right)$ 与 1 的大小不确定, 即 $\frac{1}{y_1} + \frac{1}{y_2}$ 与 2 的大小不确定, 因此 C, D 不正确。应选 A。

解法3:(赋值法+排除法)利用函数 $y=2^{x}$ ，取不同的特殊值代入选项即可判断。不妨设 $x_{1}<x_{2}$ ，依题意取 $\left\{\begin{aligned}x_{1}&=-1,\\ y_{1}&=\frac{1}{2},\end{aligned}\right.\left\{\begin{aligned}x_{2}&=0,\\ y_{2}&=1,\end{aligned}\right.$ 代入各选项检验得 $\log_{2}\frac{y_{1}+y_{2}}{2}>\frac{x_{1}+x_{2}}{2}$ 成立， $\log_{2}\frac{y_{1}+y_{2}}{2}>x_{1}+x_{2}$ 成立；依题意取 $\left\{\begin{aligned}x_{1}&=0,\\ y_{1}&=1,\end{aligned}\right.\left\{\begin{aligned}x_{2}&=1,\\ y_{2}&=2,\end{aligned}\right.$ 代入各选项检验得 $\log_{2}\frac{y_{1}+y_{2}}{2}>\frac{x_{1}+x_{2}}{2}$ 成立， $\log_{2}\frac{y_{1}+y_{2}}{2}<x_{1}+x_{2}$ 成立。综上得A成立。应选A。

解法 4: (数形结合法) 利用指数函数图像的凹凸性即可判断。作出函数 $y=2^{x}$ 的大致图像(图略)。

由图可知， $\frac{y_{1}+y_{2}}{2}>2^{\frac{x_{1}+x_{2}}{2}}$ ，两边取以2为底的对数得 $\log_{2}\frac{y_{1}+y_{2}}{2}>\frac{x_{1}+x_{2}}{2}$ 。应选A。
