# 坐标系辅助法破解三角函数周期性与对称性综合题

廖少卫(广东省茂名市第十六中学 525200)

【摘 要】 坐标系辅助法是解决三角函数周期性与对称性综合问题的有效策略,其核心在于利用坐标系直观揭示函数的周期规律与对称特征.周期性体现为函数值沿 x 轴按固定间隔重复出现,如正弦函数 $y=\sin x$ 的周期为 $2\pi$ ,正切函数的周期为 $\pi$ .对称性则分为轴对称(如余弦函数关于 y 轴对称)和中心对称(如正弦函数关于原点对称).通过坐标系标注关键点(如最值点、零点)和对称轴中心,可快速定位函数的最小正周期、对称轴方程(如 $x=k\pi+2$ )及对称中心(如 $(k\pi,0)$ ).该方法将抽象性质转化为几何直观,显著简化复杂问题,尤其在处理含绝对值或复合型三角函数时,能高效整合周期压缩与对称变换,为解题提供系统路径.

【关键词】三角函数;坐标系辅助法;高中数学

# 1 三角函数周期性与对称性的理论基础

# 1.1 核心概念梳理

三角函数的周期性指函数值以固定间隔重复出现的特性,其数学定义为:若存在非零常数 $\pi$ 使得对所有定义域内的 x 满足 $f(x+T)=f(x)$ , 则 T 称为周期.例如,正弦函数 $\sin x$ 和余弦函数 $\cos x$ 的最小正周期为 $2\pi$ , 而正切函数的最小正周期为 $\pi$ . 对称性则分为两类:轴对称指函数图象关于直线 x=a 对称, 满足 $f(a+x)=f(a-x)$ . 例如 $\cos x$ 关于 $x=k\pi$ 对称; 中心对称指函数图象关于点 $(a,b)$ 对称, 满足 $f(a+x)+f(a-x)=2b$ . 例如 $\sin x$ 关于点 $(k\pi,0)$ 对称.

周期性源于角度旋转的循环性,对称性与函数奇偶性相关,如 $\sin x$ 为奇函数, $\cos x$ 为偶函数.这些概念是解决综合题目的基石.

# 1.2 单位圆与三角函数线的几何意义

单位圆是三角函数的几何载体: 圆上任意点 P 的坐标 $(\cos\theta, \sin\theta)$ 直接对应角度 $\theta$ 的余弦值和正弦值. 三角函数线则是从几何角度描述函数值的线段: 正弦线是从点 P 向 x 轴作垂线, 长度为 $|\sin\theta|$ ,符号由 y 轴方向决定；余弦线是从点 P 向 y 轴作垂线，长度为 $\left|\cos\theta\right|$ ，符号由 x 轴方向决定；正切线是过单位圆与 x 轴正半轴的交点作切线，终边或其延长线与切线交点的线段长度对应 $\tan\theta$ 。例如， $\theta=\frac{\pi}{4}$ 时，正弦线与余弦线长度均为 $\frac{\sqrt{2}}{2}$ ，正切线长度为 1。这种表示方式将抽象函数值转化为直观几何量，便于分析周期性（终边旋转一周函数值重复）和对称性（如 $\sin(-\theta)=-\sin\theta$ 体现原点对称）。在坐标系中，三角函数线成为连接代数与几何的桥梁。

# 2 坐标系辅助法的解题模型构建

# 2.1 坐标系建模的基本步骤

坐标系建模的核心是将函数性质映射为几何特征,通过以下四步实现周期性、对称性的可视化分析:第一,建立坐标系并标注关键参数点;第二,识别基本对称单元;第三,进行周期延拓与对称复制;第四,综合验证函数性质.

# 2.2 典型函数类型的坐标系分析

# 2.2.1 含绝对值的三角函数

含绝对值的三角函数在周期和对称性方面具有独特的特点.

例 1 求函数 $f(x)=\left|\sin2x\right|+\cos|x|$ 的周期.

分析 这道例题旨在考查含绝对值的三角函数的周期性. 首先, 拆分函数, 分别求各部分周期; 其次, 求各部分周期的最小公倍数; 最后, 验证周期的正确性. 具体解题步骤如下:

设 $g(x)=\left|\sin2x\right|$ : 因为正弦函数 $y=\sin2x$ 的周期为 $T_{1}=\frac{2\pi}{2}=\pi$ ，加绝对值后，三角函数图象“上翻”，周期减半。所以 $g(x)=\left|\sin2x\right|$ 的周期 $T_{0}=\frac{\pi}{2}$ 。设 $h(x)=\cos|x|$ ：因为余弦函数是偶函数，即

$\cos\left|x\right|=\cos x$ ，所以 $h(x)=\cos\left|x\right|$ 的周期为 $T_{0}=2\pi.$

综上， $f(x)=g(x)+h(x)$ 的周期为 $g(x)$ 和 $h(x)$ 周期的最小公倍数.

所以计算 $\frac{\pi}{2}$ 与 $2\pi$ 的最小公倍数，先忽略 $\pi$ ，求 $\frac{1}{2}$ 和2的最小公倍数为2，再乘以 $\pi$ ，得 $T = 2\pi$ .最后，代入 $f(x = 2x) = |\sin 2(x + 2\pi)| + \cos |x + 2\pi | =$ $|\sin (2x + 4\pi)| + \cos (x + 2\pi) = |\sin 2x| + \cos x =$ $f(x)$ ，满足周期的定义.

# 2.2.2 相位复合型函数

对于相位复合型函数,分析其对称性时要注意对称轴和对称中心的关系.

例 2 求函数 $f(x)=2\sin\left(2x+\frac{\pi}{3}\right)$ 的对称轴方程.

解析 因为正弦函数 $y = \sin u$ 的对称轴 $u = \frac{\pi}{2} + k\pi (k \in \mathbf{Z})$ ，即函数取得最值（最大值1或最小值-1）时的自变量取值。所以令 $u = 2x + \frac{\pi}{3}$ ，则 $f(x) = 2\sin u, 2x + \frac{\pi}{3} = \frac{\pi}{2} + k\pi (k \in \mathbf{Z})$ 。因为 $2x = \frac{\pi}{2} - \frac{\pi}{3} + k\pi, 2x = \frac{\pi}{6} + k\pi$ ，所以对称轴方程为 $x = \frac{\pi}{12} + \frac{k\pi}{2} (k \in \mathbf{Z})$ 。

# 2.2.3 混合型函数

处理包含不同三角函数的混合型函数.

例3 求函数 $f(x) = \sin 2x + \cos 2x$ 的对称轴方程.

分析 混合型三角函数(如 $\sin ax + \cos ax$ ) 需先通过“辅助角公式”转化为单一相位复合型三角函数(如 $A \sin(ax + \varphi)$ 或 $A \cos(ax + \varphi)$ ), 再利用单一三角函数的对称轴性质求解.

解析 因为辅助角公式: $a \sin x + b \cos x = \sqrt{a^{2} + b^{2}} \sin(x + \varphi) \left( \tan \varphi = \frac{b}{a} \right)$ .

对 $f(x)=\sin2x+\cos2x,a=1,b=1,$

所以 $\sqrt{1^2 + 1^2} = \sqrt{2}$ ，取 $\varphi = \frac{\pi}{4}$

化简得 $f(x)=\sqrt{2}\sin\left(2x+\frac{\pi}{4}\right)$ .

因为正弦函数 $y = \sin u$ 的对称轴为 $u = \frac{\pi}{2} + k\pi (k \in \mathbf{Z})$ ,

令 $u=2x+\frac{\pi}{4}$ ,

所以 $2x + \frac{\pi}{4} = \frac{\pi}{2} + k\pi (k \in \mathbf{Z})$

因为 $2x = \frac{\pi}{2} -\frac{\pi}{4} +k\pi ,2x = \frac{\pi}{4} +k\pi ,$

所以对称轴方程为 $x=\frac{\pi}{8}+\frac{k\pi}{2}(k\in\mathbf{Z})$ .

# 3 结语

坐标系辅助法通过将抽象三角函数的周期性与对称性转化为直观的几何特征,实现了复杂性质的视觉化解构.该方法以坐标系为桥梁,将函数图象的关键点标注、对称单元识别、周期延拓等步骤可视化,显著降低了代数推理的复杂度.例如,含绝对值的三角函数通过象限镜像映射展现周期减半规律,相位复合型函数通过特征点平移揭示对称轴偏移特性,混合型函数则借助辅助角公式统一为单一模式分析.这种几何化思维不仅使周期性对应图象的平移不变性、对称性对应反射/旋转不变性的本质得以凸显,更在高考真题中验证了其高效性——解题效率显著提升.掌握坐标系建模的核心逻辑,即能快速破解大部分周期对称综合难题,为高阶数学学习奠定坚实的思维基础.
