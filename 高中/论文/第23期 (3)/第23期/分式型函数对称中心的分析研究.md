【摘 要】 分式型函数是高中阶段的常考内容,本文从一道课本习题出发,重点研究“分式型指数函数”与“分式型对数函数”的对称中心,并分析其具有对称中心的原因,帮助学生加深对这两类函数的理解,掌握相关解题策略.

【关键词】 分式函数;对称性;高中数学

函数的对称性是函数基础且重要的性质,不仅能简化函数分析,还能为解决复杂问题提供直观的工具.在高考中,对称性结合周期性、单调性等其他函数性质的题目屡见不鲜,这类题目兼具综合性与创新性,能有效考查学生的数学素养.人教A版必修第一册教材中有一道经典课后习题,下面将从这道习题展开,研究这类函数的对称中心.

# 1 追根溯源

（人教 A 版必修第一册 161 页第 12 题节选）对于函数 $f(x) = a - \frac{2}{2^x + 1} (a \in \mathbf{R})$ ，是否存在实数 $a$ 使函数 $f(x)$ 为奇函数？

解析 由于 $f(x)$ 的定义域为 $\mathbf{R}$ , 故 $f(x)$ 为奇函数的必要条件为 $f(0) = 0$ , 从而 $a = 1$ . 而当 $a = 1$ 时, $f(x) = 1 - \frac{2}{2^x + 1} = \frac{2^x - 1}{2^x + 1}$ , 容易验证 $f(-x) = -f(x)$ . 故 $a = 1$ 时, 函数 $f(x)$ 为奇函数.

点评 本题难度不大,只需利用奇函数的定义即可解决,但在教学实践中常有学生感到困惑:一般指数型函数本身不具有对称性,为何放在分母上构成分式形式时具有对称性?接下来将具体研究这类“分式型指数函数”与“分式型对数函数”的对称中心,并给出明确结论.

# 2 分式型指数函数与分式型对数函数的对称中心

对于形如 $y = \frac{n}{a^x + m} (a > 0, a \neq 1, mn \neq 0)$ 的

函数,其对称中心为 $\left(\log_{a}|m|,\frac{n}{2m}\right)$ .

证明 设 $f(x) = \frac{n}{a^x + m}$ 的对称中心为 $(s, t)$ ，从而 $f(x + s) - t$ 为奇函数，记 $g(x) = f(x + s) - t$ ，则 $g(x) + g(-x) = n\left(\frac{1}{a^{x + s} + m} + \frac{1}{a^{-x + s} + m}\right) - 2t = 0$ 恒成立，化简得： $(n - 2mt)a^s (a^{2x} + 1) + 2[mn - t(a^s + m^2)]a^x = 0.$

故 $\left\{ \begin{array}{l} n = 2mt, \\ mn = t(a^s + m^2), \end{array} \right.$ 解得 $\left\{ \begin{array}{l} s = \log_a|m|, \\ t = \frac{n}{2m}, \end{array} \right.$ 即 $f(x) = \frac{n}{a^x + m}$ 的对称中心 $\left(\log_a|m\mid ,\frac{n}{2m}\right)$ .

当 m=1, n=-2, a=2 时， $y=\frac{-2}{2^{x}+1}$ 的对称中心为 $(0,-1)$ ，故教材第 161 页第 12 题中的函数 $f(x)=a-\frac{2}{2^{x}+1}$ 若为奇函数，需满足 a=1.

这种函数具有对称性的原因其实很容易理解，由于 $y = a^{x} - a^{-x}$ 是奇函数， $y = a^{x} + a^{-x}$ 是偶函数，故 $y = \frac{a^{x} - a^{-x}}{a^{x} + a^{-x}}$ 是奇函数，化简得： $y = \frac{a^{2x} - 1}{a^{2x} + 1} = 1 - \frac{2}{a^{2x} + 1}$ . 若再求该函数的反函数，可得 $y = \log_{a^2} \frac{1 + x}{1 - x}$ ，于是形如 $y = \log_a \frac{px + q}{rx + s}$ （其中 $ps \neq qr, rs \neq 0, a > 0, a \neq 1$ ）的函数也具有对称性，对称中心为 $\left(-\frac{1}{2}\left(\frac{s}{r} + \frac{q}{p}\right), \log_a \left|\frac{p}{r}\right|\right)$ ，当 $q = s, p = -r$ 时该函数为奇函数，证明类似，不再赘述.

例 1 某机构根据逻辑斯蒂增长模型结合过去15年的数据,对2010年—2040年我国新能源汽车的市场渗透率进行了模拟和预测,得到我国新能源汽车的市场渗透率 $f(x)$ 与时间 $x$ （单位：年，规定 $x = 0$ 表示2010年初）的函数关系为 $f(x) = \frac{1}{1 + \mathrm{e}^{-0.5(x - 15)}}$ （ $0 \leqslant x \leqslant 30$ ），则下列结论正确的是（）（参考数据： $\ln 3 \approx 1.1$ ）

(A) $f(x)$ 的图象关于点 $\left(15,\frac{1}{2}\right)$ 中心对称.

(B) $f(x)$ 的图象关于直线x=15对称.

(C)2022 年初新能源汽车的市场渗透率不足 25%.  
(D) 预计 2030 年初我国新能源汽车的市场渗透率超过 90%.

解析 这里只给出(A)(B)选项的判断,常规方法为利用中心对称及轴对称的定义进行判断,由

$$
f (x) + f (3 0 - x) = \frac {1}{1 + \mathrm{e} ^ {\frac {1 5 - x}{2}}} + \frac {1}{1 + \mathrm{e} ^ {\frac {x - 1 5}{2}}} =
$$

$\frac{2 + \mathrm{e}^{\frac{15 - x}{2}} + \mathrm{e}^{\frac{x - 15}{2}}}{(1 + \mathrm{e}^{\frac{15 - x}{2}})(1 + \mathrm{e}^{\frac{x - 15}{2}})} = \frac{2 + \mathrm{e}^{\frac{15 - x}{2}} + \mathrm{e}^{\frac{x - 15}{2}}}{2 + \mathrm{e}^{\frac{15 - x}{2}} + \mathrm{e}^{\frac{x - 15}{2}}} = 1$ ，可得函数 $f(x)$ 关于 $\left(15, \frac{1}{2}\right)$ 对称. 故(A)正确，(B)错误.

点评 $f(x) = \frac{1}{1 + \mathrm{e}^{-\frac{x - 15}{2}}}$ 可看成由函数 $g(x) = \frac{1}{1 + \mathrm{e}^{-\frac{x}{2}}}$ 向右平移15个单位得到，而 $g(x)$ 的对称中心为 $\left(0,\frac{1}{2}\right)$ ，故容易得到 $f(x)$ 的对称中心为 $\left(15,\frac{1}{2}\right)$

例 2 （2024 新课标 I 卷 18(2)）已知函数 $f(x)=\ln\frac{x}{2-x}+ax+b(x-1)^{3}$ ，证明：曲线 $y=f(x)$ 是中心对称图形.

# 解析 解法1

$f(x) = \ln \frac{x}{2 - x} + ax + b(x - 1)^{3}$ 的定义域为(0,2)，考虑到定义域的对称性，可猜想对称中心应为 $(1,a)$ ，下面证明猜想：

设 $P(m,n)$ 是 $y=f(x)$ 图象上任意一点，点 P 关于 $(1,a)$ 的对称点 Q 的坐标为 $(2-m,2a-n)$ ，只需证明点 Q 也在 $y=f(x)$ 的图象上.

下面进行验证：

$f(2 - m) = \ln \frac{2 - m}{m} + a(2 - m) + b(1 - m)^3 =$ $-\left[\ln \frac{m}{2 - m} + am + b(m - 1)^3\right] + 2a = 2a - n$ ，故得证.由于点 $P$ 的任意性，可知曲线 $y = f(x)$ 关于点 $(1,a)$ 呈中心对称.

# 解法 2

经计算容易验证 $f(x)+f(2-x)=2a$ ，故 $y=f(x)$ 的图象关于点 $(1,a)$ 中心对称.

点评 本题中的函数 $y = \ln \frac{x}{2 - x}$ 由 $y = \ln \frac{1 + x}{1 - x}$ 向右平移1个单位得到，而后者显然为奇函数，教师只有在复习时对这些常见函数的对称性进行深入总结，学生在考场上才能读懂这些“隐含条件”，快速找到解题思路.
