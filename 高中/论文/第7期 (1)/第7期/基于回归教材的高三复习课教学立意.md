# 基于回归教材的高三复习课教学立意

● 浙江省杭州第四中学 顾文铨

当下，高三复习临考的教学现状堪忧，不少教师仍以“题海战术”作为备考的主旋律，学生苦不堪言。作为一名基层教师，笔者迫切希望可以改善这一“高耗低效”的教学模式。事实上，纵观近几年高考数学卷，可以发现不少试题源于教材的改编，这同时也说明了数学复习需“回归课本”，并“吃透”教材，才能达到提升复习效能的作用。笔者经过对高三复习课的多年追踪，认为教师需整合教材资源，做到回归教材，有效强化学生对基础知识的理解和掌握，即以夯实基础为立意，达到融会贯通之效能。如何达成，笔者认为需借助以下的抓手：

# 一、重概念，通基础，达到夯实之效

在复习的过程中,很多教师喜欢追求难题,崇尚课堂教学的高容量;不少学生不注重夯实基础,对教材中的概念、公式、定理等没有一个明晰的认识,却还是疏于对基础知识的理解和识记,仅仅是埋头做题,导致了解题出错,丢掉基础分值.事实上,即使是到了高三,不少学生对基础知识也未能理解透彻.明晰教材中的概念、公式和定理是解题达成的必要条件,所以要成功解题首先要从基础入手,识记基础知识.

例 1 已知函数 $f(x)$ 的定义域是 $(0,1)$ ，试求出函数 $f(x+1)$ 的定义域.

不少学生易形成以下错解: 据函数 $f(x)$ 的定义域是 $(0,1)$ ，则 0 < x < 1，可得 $1 < x + 1 < 2$ ，所以函数 $f(x+1)$ 的定义域为 $(1,2)$ .

评析:从知识的角度着手可以看出,这些学生由于没有明晰函数 $f(x+1)$ 的自变量依然是 x,错误地将 $x+1$ 中 x 的范围视为 0<x<1,从而造成错误.事实上,求函数 $f(x+1)$ 的定义域本质上是需求 $f(x+1)$ 中 x 的取值.产生以上错误的根源在于:对应法则的符号理解得不够透彻;定义域的内涵没有厘清.在解答本题时,必须明确以下问题:抽象函数的定义域就是指 x 的取值范围;被对应法则 $f(x)$ 制约的量的取值范围在“已知”与“求”中需具有一致性,从而得出以下正解:

解: 据函数 $f(x)$ 的定义域是 $(0,1)$ ，进一步可得 0$<x+1<1$ , 解得 $-1<x<0$ , 从而得出函数 $f(x+1)$ 的定义域是 $(-1,0)$ .

为了深化学生的理解,笔者进行了如下变式训练:

变式:已知函数 $f(x+1)$ 的定义域为 $(0,1)$ ，试求出函数 $f(x)$ 和 $f(x-3)$ 的定义域.

解: 据 0 < x < 1, 可得 $1 < x + 1 < 2$ , 所以函数 $f(x)$ 的定义域是 $(1, 2)$ ; 根据抽象函数定义域可得 1 < x - 3 < 2, 即 4 < x < 5, 所以函数 $f(x - 3)$ 的定义域是 $(4, 5)$ .

例 2 已知 $f(x)=2+\log_{3}x, x\in[1,9]$ ，求函数 $y=[f(x)]^{2}+f(x^{2})$ 的值域.

学生易形成以下错解: $f(x)=2+\log_{3}x$ 的定义域是 $[1,9]$ , $y=(2+\log_{3}x)^{2}+2+\log_{3}x^{2}=(\log_{3}x+3)^{2}-3$ . 因为 $x\in[1,9]$ ，所以 $\log_{3}x\in[0,2]$ ，所以 $y_{\min}=(0+3)^{2}-3=6$ , $y_{\max}=(2+3)^{2}-3=22$ ，所以函数 $y=[f(x)]^{2}+f(x^{2})$ 的值域是 $[6,22]$ .

评析: 观察学生的错解可以发现, 产生错解的原因在于定义域识别不力, 对函数 $y = [f(x)]^{2} + f(x^{2})$ 定义域的理解不合理, 导致陷入命题者所设圈套之中, 致使函数 $y = [f(x)]^{2} + f(x^{2})$ 的讨论范围变大了. 事实上, 解决这一问题的基本程序就是认真审题, 细致分析, 对以下问题有一个细致的把握: ① $f(x)$ 的定义域; ② $y = [f(x)]^{2} + f(x^{2})$ 的定义域与 $f(x)$ 的定义域之间的不同; ③ 求 $y = [f(x)]^{2} + f(x^{2})$ 定义域的方法, 从而用无穷的智慧和夯实的基础代替反复繁杂的操作.

解: $f(x)$ 的定义域是[1,9], 若使得 $y = [f(x)]^2 + f(x^2)$ 有意义, 须有 $1 \leqslant x \leqslant 9$ 且 $1 \leqslant x^2 \leqslant 9$ , 所以 $1 \leqslant x \leqslant 3$ . 所以 $y = [f(x)]^2 + f(x^2)$ 的定义域是[1,3], $y = (\log_3 x + 3)^2 - 3$ . 因为 $x \in [1,3]$ , 所以 $\log_3 x \in [0,1]$ , 所以 $y_{\min} = (0 + 3)^2 - 3 = 6, y_{\max} = (1 + 3)^2 - 3 = 13$ , 所以函数 $y = [f(x)]^2 + f(x^2)$ 的值域是[6,13].

中学生的“双基”和审题能力是影响学生成绩的重要因素,且具有较高程度的正相关.以上所犯错误都是函数知识中的易错点,大部分学生还没有养成良好的总结和提炼的习惯,其深层原因是学生对知识的深入和巩固不足,学到的是“死”的教材知识,遇到相关问题时不会将知识与技能实现按需分配.因此,我们在函数教学的过程中,既需关注到概念与性质的理解,引领学生适时总结相关性质,及时辨析模糊概念,巩固对教材知识的理解,又需教会学生认真审题的方法,提升学生的审题能力.

# 二、重精练，通习题，强化迁移能力

当下，不少数学教师无视教材，热衷于在“鱼龙混杂”的各种资料中游弋。对照近几年高考试题，可以清楚地发现几乎每一道都可以从教材中找寻到“源头”，它们或是课本习题的简单变式，或是重组，又或是拓展等，清楚地呈现出“题在书外，根在书中”，大有回归教材的趋势。课本上的例习题是对基本知识的考查，是教材中每一个概念、每一个公式、每一个定理的检验依据。由此可见，要想打赢高考战，训练必不可少，通过精练教材例习题，强化例习题的迁移能力，达到积累和优化解题方法的目的，深化对基础知识的理解和应用。

例 3 已知函数 $f(x)=ax^{3}-bx+1, a, b \in \mathbb{R}$ ，若 $f(-2)=-1$ ，求 $f(2)$ .

评析:本题是教材中的一道习题,是对函数奇偶性的性质的考查,解决本题的关键在于通过构造奇函数 $g(x)=ax^{3}-bx$ ,再借助函数性质去求 $f(2)$ 的值.

解: 令 $g(x)=ax^{3}-bx$ ，则有 $f(x)=g(x)+1$ 。又 $g(-x)=-ax^{3}+bx=-g(x)$ ，所以 $g(x)=ax^{3}-bx$ 为奇函数。所以 $f(-2)=g(-2)+1=-g(2)+1=-1$ ，所以 $g(2)=2,f(2)=g(2)+1=3$ 。

例 4 设函数 $f(x)$ 为定义在 R 上的函数, $f(x)$ 的值不恒为零, 对于任意的 $x, y \in R$ 恒有 $f(x + y) = f(x) + f(y)$ 成立, 那么函数 $f(x)$ 是().

A. 奇函数

B. 偶函数

C. 既奇又偶函数

D. 非奇非偶函数

评析:本题又是一道抽象函数题,也是一道典型的好题.本题的考查目标不仅仅要看学生对抽象函数的相关性质的活用程度,更是考查学生对“恒成立”的理解是否透彻,能否灵活转化为所需结构,以及对学生思维过程和思维能力的考查.不少学生由于对抽象函数性质的理解不够,从而思维卡壳,无法实现一般到特殊或是从特殊到一般思维的转变.如何才能根据条件得出 $f(-x)=f(x)$ 或 $f(-x)=-f(x)$ 呢?事实上,对于抽象函数的性质,我们可以通过“令x,y为特值”来实现.

解: 令 x = y = 0，则 $f(0) = f(0) + f(0)$ ，所以 $f(x) = 0$ ；再令 y = -x，则 $f(0) = f(x) + f(-x)$ ，所以 $f(-x) = -f(x)$ 。又 $f(x)$ 的值不恒为零，所以 $f(x)$ 是奇函数，故选 A.

以上两个问题虽然简单,但其中所用到的基本知识却是解决这一类问题中必不可少的. 学生只有理清和明晰解决这一类问题“背后的故事”，才能真正意义上做到知其然并知其所以然，进而提升解题能力.

# 三、重拓展，通教材，实现融会贯通

在复习时,教师只有牢牢把握教材内容,充分挖掘教材中的例题和习题,积极强化其迁移能力,关注一题多解或一题多变等多个角度的重新审视,从更高的角度去实施该知识点的博大精深,以命题者的视角对试题进行“再加工”,引发学生的“再创造”,加深学生的理解和应用,在夯实基础的同时提升解题能力,实现融会贯通.

例5 设 $f(x) = \frac{1 + x^2}{1 - x^2}$ ，求证：(1) $f(-x) = f(x)$ ; (2) $f\left(\frac{1}{x}\right) = -f(x)$ . (解略)

变式:设定义在 R 上的函数 $f(x)$ 满足: $f(\tan x) = \frac{1}{\cos 2x}$ ，试求出 $f(2) + f(3) + \cdots + f(2012) + f\left(\frac{1}{2}\right) + f\left(\frac{1}{3}\right) + \cdots + f\left(\frac{1}{2012}\right)$ 的值.

解：由 $f(\tan x)=\frac{1}{\cos2x}=\frac{\cos^{2}x+\sin^{2}x}{\cos^{2}x-\sin^{2}x}=$ $\frac{1+\tan^{2}x}{1-\tan^{2}x}$ ，可得 $f(x)=\frac{1+x^{2}}{1-x^{2}}$ ，所以 $f(x)+f\left(\frac{1}{x}\right)=0$ ，所以 $f(2)+f(3)+\cdots+f(2012)+f\left(\frac{1}{2}\right)+f\left(\frac{1}{3}\right)+\cdots+f\left(\frac{1}{2012}\right)=0.$

本例中从题目本身角度进行变式改编,变式从函数向三角函数过渡,最终又回到函数问题,凸显了思维的广阔性和知识的连续性,同时关注到基础知识的整合.

例6 已知 $a + b = 1 (a > 0, b > 0)$ ，试求出函数 $y = \frac{1}{a} + \frac{1}{b}$ 的最小值.

解: $y=\left(\frac{1}{a}+\frac{1}{b}\right)(a+b)=2+\frac{b}{a}+\frac{a}{b}=4.$ 当且仅当 $a=b=\frac{1}{2}$ 时等号成立.

变式1: 设 a > 0, b > 0, 若 $\sqrt{3}$ 为 $3^{a}$ 和 $3^{b}$ 的等比中项, 试求出 $\frac{1}{a} + \frac{1}{b}$ 的最小值.

解: 据题意, 可得 $3^{a} \cdot 3^{b} = 3$ , 即 $3^{a+b} = 3$ , 所以 $a + b = 1$ . 因为 a > 0, b > 0, 所以 $\frac{1}{a} + \frac{1}{b} = \left( \frac{1}{a} + \frac{1}{b} \right) (a + b) = 2 + \frac{b}{a} + \frac{a}{b} \geqslant 2 + 2\sqrt{\frac{b}{a} \cdot \frac{a}{b}} = 4$ , 当且仅当 a

$= b = \frac{1}{2}$ 时等号成立.

变式2:试求出 $y=\frac{1}{a}+\frac{1}{1-a}(0<a<1)$ 的最小值.

解: 因为 $a+(1-a)=1$ ，所以 $y=\left(\frac{1}{a}+\frac{1}{1-a}\right)\cdot\left[a+(1-a)\right]=2+\frac{1-a}{a}+\frac{a}{1-a}$ 。因为 $\frac{1-a}{a}>0$ ， $\frac{a}{1-a}>0$ , 所以 $y \geqslant 2 + 2\sqrt{\frac{1-a}{a} \cdot \frac{a}{1-a}} = 4$ , 当且仅当 $\frac{1-a}{a} = \frac{a}{1-a}$ ，即 $a = \frac{1}{2}$ 时等号成立.

变式 3: 已知 $0 < x < \frac{\pi}{2}, t > 0$ ，若 $f(x) = \frac{1}{\sin x} + \frac{t}{1 - \sin x}$ 的最小值是 9，则 t = \_\_\_\_.（解略）

这样的变式训练,其立意就是学生思维能力的培养.学生完成每一道变式,应该说让学生的解题能力得到充分的提升,让学生在“过程”中有效地夯实基础、获取技能、发展思维、形成能力.总之,教材是几代人智慧的凝聚,具有较强的指导性和权威性.只要我们从基础知识、解题方法和心理因素等方面出发,引导学生回归课本,充分发挥教材的引领作用,有效夯实基础知识,注重课本例习题的挖掘,探索问题的引申、推广、变通和拓展,才能让学生从真正意义上跳出“题海”,有效复习,在高考中取得满意的成绩.
