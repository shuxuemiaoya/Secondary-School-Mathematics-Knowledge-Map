# 基于联系观点求解条件代数式的最值问题\*

# 徐海周 （上海外国语大学三亚附属中学 571700）

摘 要 求解条件代数式的最值问题一直是一个难题,阻碍解题思路的卡点是缺少基本不等式或其他不等式成立的代数式之间的等量关系.若从“联系”的观点出发,利用不同的变换手段积极创造代数式之间“联系”的等量关系,则可以使此类问题迎刃而解,解法也丰富多样.

关键词 条件代数式;联系观点;最值问题

文章编号 1004-1176(2024)05-0070-03

条件代数式的最值问题是“基本不等式”一节中一类比较常见的问题，命题者往往会在代数式的形式上不断进行创新。尽管已经学习了一些利用基本不等式求解此类问题的方法，但面对一些形式上不断创新的代数式时，大部分学生依然是束手无策。究其原因，这样的代数式往往由两个变化的“子代数式”构成，学生找不到这两个“子代数式”之间的联系，导致思路搁浅。若引导学生从“联系”的角度出发，通过各种不同的变换手段积极创设两个“子代数式”之间的联系，然后再利用它们之间的这种联系及其他条件促成基本不等式成立，则可以使问题迎刃而解，解法也丰富多样。其实，利用基本不等式求代数式最值的方法本身就是建立在变量 $a$ 与 $b$ 之间的联系“ $ab = P$ ”或“ $a + b = S$ ”的前提之下的一种求解最值的方法。笔者今就一道此类问题，基于“联系”的观点进行剖析，多角度探索其解法，以期来探寻解决此类问题的规律。

问题 已知 0 < x < 1，则 $\frac{1}{2x} + \frac{2}{1 - x}$ 的最小值为（）.

A. 2 B. $\frac{5}{2}$ C. 4 D. $\frac{9}{2}$

# 1 “一元换元”基本不等式法

对于条件代数式 $\frac{1}{2x}+\frac{2}{1-x}(0<x<1)$ ，学生的第一想法就是通分，但是面对通分后的代数式 $\frac{3x+1}{-2x^{2}+2x}$ ，学生仍然一筹莫展。这时可以引导学生将 $3x+1$ 设为t，通过“一元换元”的手段将通分后的代数式等价转化为代数式 $\frac{t}{-\frac{2t^{2}}{9}+\frac{10t}{9}-\frac{8}{9}}$ ，然

后再将这个代数式变形为 $\frac{1}{-\frac{2t}{9}-\frac{8}{9t}+\frac{10}{9}}$ . 此时若
能发现分母中的两个子代数式 $\frac{2t}{9}$ 与 $\frac{8}{9t}$ 之间存在 $\frac{2t}{9}\times\frac{8}{9t}=\frac{16}{81}$ 这样的联系，再加上这两个子代数式也具备使用基本不等式的条件，就可以利用基本不等式求解此题，具体的解题过程如下：

解法 1 $\frac{1}{2x} + \frac{2}{1-x} = \frac{1-x+4x}{2x(1-x)} = \frac{3x+1}{-2x^{2}+2x}$ ，设 $3x + 1 = t$ ，则 $x = \frac{t-1}{3}$ ，原式 $=\frac{t}{-2 \times \left(\frac{t-1}{3}\right)^{2} + 2 \times \frac{t-1}{3}} = \frac{t}{-\frac{2t^{2}}{9} + \frac{10t}{9} - \frac{8}{9}} = \frac{1}{-\frac{2t}{9} - \frac{8}{9t} + \frac{10}{9}}$ 。由 0 < x < 1，得 1 < t < 4，故 $\frac{2t}{9} + \frac{8}{9t} \geqslant \frac{8}{9}$ ，从而 $-\frac{2}{9}t - \frac{8}{9t} \leqslant -\frac{8}{9}$ ，因此原式 $\geqslant \frac{1}{-\frac{8}{9} + \frac{10}{9}} = \frac{1}{\frac{2}{9}} = \frac{9}{2}$ 。选 D.

其实,对于条件代数式 $\frac{1}{2x}+\frac{2}{1-x}(0<x<1)$ ,
不通分照样可以用换元法求解其最小值. 因为这个代数式的两个子代数式 $\frac{1}{2x}$ 与 $\frac{2}{1-x}$ 均含有变量x，
所以它们之间必定存在着某种联系. 若设 $\frac{1}{2x}=t$ ，则 $\frac{2}{1-x}=\frac{4t}{2t-1}$ ，于是就有 $\frac{1}{2x}+\frac{2}{1-x}=t+\frac{4t}{2t-1}=$

$t+\frac{2}{2t-1}+2=t-\frac{1}{2}+\frac{1}{t-\frac{1}{2}}+\frac{5}{2}.$ 此时代数式中

两个子代数式 $t - \frac{1}{2}$ 与 $\frac{1}{t - \frac{1}{2}}$ 之间明显存在 $\left(t - \frac{1}{2}\right)\times \frac{1}{t - \frac{1}{2}} = 1$ 这样的联系，再加上这两个子

代数式也具备使用基本不等式的条件,因此也可以利用基本不等式求解此题.具体的解题过程如下:

解法2 设 $\frac{1}{2x} = t$ ，则 $x = \frac{1}{2t}$ ，原式 $= t + \frac{2}{1 - \frac{1}{2t}} =$

$$
t + \frac {4 t}{2 t - 1} = t + \frac {2}{2 t - 1} + 2 = t - \frac {1}{2} + \frac {1}{t - \frac {1}{2}} + \frac {5}{2}. \text {由}
$$

0 < x < 1, 得 $t > \frac{1}{2}$ , 故 $t - \frac{1}{2} > 0$ , 从而 $t - \frac{1}{2} + \frac{1}{t - \frac{1}{2}} \geqslant 2$ , 因此原式 $\geqslant \frac{9}{2}$ .

既然可以设 $\frac{1}{2x} = t$ ，使用一元换元法解决此题，同样也可以设 $\frac{2}{1 - x} = t$ 来使用一元换元法解题。设 $\frac{2}{1 - x} = t$ ，则 $\frac{1}{2x} = \frac{t}{2t - 4}$ ，于是就有 $\frac{1}{2x} + \frac{2}{1 - x} = \frac{t}{2t - 4} + t = \frac{t - 2}{2t - 4} + \frac{2}{2t - 4} + t = t + \frac{1}{t - 2} + \frac{1}{2} = t - 2 + \frac{1}{t - 2} + \frac{5}{2}$ 。此时代数式中两个子代数式 $t - 2$ 与 $\frac{1}{t - 2}$ 之间明显存在 $(t - 2)\left(\frac{1}{t - 2}\right) = 1$ 这样的联系，再加上这两个子代数式也具备使用基本不等式的条件，因此依然可以利用基本不等式求解此题。具体的解题过程如下：

解法3 设 $\frac{2}{1 - x} = t$ ，则 $x = 1 - \frac{2}{t}$ ，原式 $= \frac{1}{2 - \frac{4}{t}} + t = \frac{t}{2t - 4} + t = \frac{t - 2}{2t - 4} + \frac{2}{2t - 4} + t = t - 2 +$

$\frac{1}{t - 2} + \frac{5}{2}$ . 由 $0 < x < 1$ , 得 $t > 2$ , 故 $t - 2 > 0$ , 从而 $t - 2 + \frac{1}{t - 2} \geqslant 2$ , 因此原式 $\geqslant \frac{9}{2}$ .

# 2 “二元换元”基本不等式法

注意到条件代数式 $\frac{1}{2x} +\frac{2}{1 - x} (0 <   x <   1)$ 中的两个子代数式 $\frac{1}{2x}$ 与 $\frac{2}{1-x}$ 的分母之间明显存在 $2x+2(1-x)=2$ 的联系，若设2x=a,1-x=b进行二元换元，则有 $a+2b=2$ ，此时的代数式 $\frac{1}{2x}+\frac{2}{1-x}$ 就可以转化为代数式 $\frac{1}{a}+\frac{2}{b}$ ，再结合变量a与b之间的联系 $a+2b=2$ ，就可以将代数式 $\frac{1}{a}+\frac{2}{b}$ 变形为 $\frac{1}{2}\left(\frac{1}{a}+\frac{2}{b}\right)\times(a+2b)=\frac{1}{2}\left(\frac{2b}{a}+\frac{2a}{b}+5\right)$ .变形后的代数式中两个子代数式 $\frac{2b}{a}$ 与 $\frac{2a}{b}$ 之间明显存在 $\frac{2b}{a}\times\frac{2a}{b}=4$ 这样的联系，再加上这两个子代数式也具备使用基本不等式的条件，因此仍然可以利用基本不等式求解此题.其具体的解题过程如下：

解 设 2x=a,1-x=b,则 $a+2b=2,\frac{1}{2x}+\frac{2}{1-x}=\frac{1}{a}+\frac{2}{b}$ . 又 $a+2b=2$ , 故 $\frac{1}{a}+\frac{2}{b}=\frac{1}{2}\times\left(\frac{1}{a}+\frac{2}{b}\right)(a+2b)=\frac{1}{2}\left(\frac{2b}{a}+\frac{2a}{b}+5\right)$ . 由 0<x<1, 得 a>0, b>0, 故 $\frac{2b}{a}>0,\frac{2a}{b}>0$ , 从而 $\frac{2b}{a}+\frac{2a}{b}\geqslant4$ , 因此原式 $\geqslant\frac{1}{2}(4+5)=\frac{9}{2}$ .

# 3 “分离配凑”基本不等式法

虽然条件代数式 $\frac{1}{2x}+\frac{2}{1-x}(0<x<1)$ 中的两个子代数式 $\frac{1}{2x}$ 与 $\frac{2}{1-x}$ 之间并没有明显的联系可循，但是可以通过“分离配凑”的手段配凑出两个子代数式 $\frac{1-x}{2x}$ 与 $\frac{2x}{1-x}$ ，很明显这两个子代数式之间存在 $\frac{1-x}{2x}\times\frac{2x}{1-x}=1$ 这样的联系，再加上这两个子代数式也具备可使用基本不等式的条件，因此照样可以利用基本不等式求解此题。其具体的解题过程如下：

解 $\frac{1}{2x} +\frac{2}{1 - x} = \frac{1 - x + x}{2x} +\frac{2x + 2 - 2x}{1 - x} =$ $\frac{1 - x}{2x} +\frac{1}{2} +\frac{2x}{1 - x} +2 = \frac{1 - x}{2x} +\frac{2x}{1 - x} +\frac{5}{2}.$ 由 $0<$ $x <   1$ ，得 $1 - x > 0$ ，故 $\frac{1 - x}{2x} >0,\frac{2x}{1 - x} >0$ ，从而 $\frac{1 - x}{2x} +\frac{2x}{1 - x}\geqslant 2$ ，因此原式 $\geqslant 2 + \frac{5}{2} = \frac{9}{2}.$

# 4 配凑权方和不等式法

换一种思路,若将条件代数式 $\frac{1}{2x}+\frac{2}{1-x}(0<x<1)$ 中的两个子代数式 $\frac{1}{2x}$ 与 $\frac{2}{1-x}$ 分别变形为 $\frac{1^{2}}{2x}$ 与 $\frac{2^{2}}{2(1-x)}$ ,则它们的分子的底数存在 $1+2=3$ 这样的联系,而它们的分母又存在 $2x+2(1-x)=2$ 那样的联系,再加上子代数式2x与 $2(1-x)$ 均为正数,于是此时的代数式就满足了权方和不等式的条件,因此可以利用权方和不等式求解此题.其具体的解题过程如下:

解 $\frac{1}{2x} + \frac{2}{1 - x} = \frac{1}{2x} + \frac{4}{2(1 - x)} = \frac{1^2}{2x} + \frac{2^2}{2(1 - x)}$ ，由 $0 < x < 1$ ，得 $2x > 0, 2(1 - x) > 0$ ，故由权方和不等式得，原式 $\frac{1^2}{2x} + \frac{2^2}{2(1 - x)} \geqslant \frac{(1 + 2)^2}{2x + 2(1 - x)} = \frac{9}{2}$ .

附:(权方和不等式)已知 $a,b,x,y\in(0,+\infty)$ ，则 $\frac{a^{2}}{x}+\frac{b^{2}}{y}\geqslant\frac{(a+b)^{2}}{x+y}$ ，当且仅当 $\frac{a}{x}=\frac{b}{y}$ 时，取“=”.

# 5 配凑柯西不等式法

再换一种思路,若将条件代数式 $\frac{1}{2x}+\frac{2}{1-x}(0<x<1)$ 变形为 $\frac{\left(\frac{1}{2x}+\frac{2}{1-x}\right)[2x+2(1-x)]}{2}$ ,在0<x<1的条件下,则可将该式的分子变形为 $\left[\left(\sqrt{\frac{1}{2x}}\right)^{2}+\left(\sqrt{\frac{2}{1-x}}\right)^{2}\right]\left[(\sqrt{2x})^{2}+(\sqrt{2-2x})^{2}\right]$ ,

此时代数式中的子代数式 $\sqrt{\frac{1}{2x}}, \sqrt{\frac{2}{1 - x}}, \sqrt{2x}$ 与 $\sqrt{2 - 2x}$ 存在 $\sqrt{\frac{1}{2x}} \times \sqrt{2x} + \sqrt{\frac{2}{1 - x}} \times \sqrt{2(1 - x)} = 3$ 这样的联系，再加上这些子代数式均为正数，于是此时的代数式也就满足了柯西不等式的条件，因此可以利用柯西不等式求解此题。其具体的解题过程如下：

解 $\frac{1}{2x} +\frac{2}{1 - x} = \frac{\left(\frac{1}{2x} + \frac{2}{1 - x}\right)\left[2x + 2(1 - x)\right]}{2},$

由 0 < x < 1，得 2x > 0, 1 - x > 0，故 $\left(\frac{1}{2x}+\frac{2}{1-x}\right)(2x+2-2x)=$ $\left[\left(\sqrt{\frac{1}{2x}}\right)^{2}+\left(\sqrt{\frac{2}{1-x}}\right)^{2}\right]\left[(\sqrt{2x})^{2}+(\sqrt{2-2x})^{2}\right]\geqslant$ $\left(\sqrt{\frac{1}{2x}}\times\sqrt{2x}+\sqrt{\frac{2}{1-x}}\times\sqrt{2-2x}\right)^{2}=(1+2)^{2}=9$ ，因此原式 $\geqslant\frac{9}{2}$

附：(柯西不等式)已知 $a, b, c, d \in \mathbf{R}$ ，则 $(a^2 + b^2)(c^2 + d^2) \geqslant (ac + bd)^2$ ，当且仅当 $ad = bc$ 时，取“=”.

# 6 结语

纵观以上 7 种求解条件代数式最值的方法, 它们均是建立在若干个子代数式之间的联系(即等量关系)的基础之上的方法, 所以在求解其他条件代数式的最值时, 务必要从事物“联系”的观点出发, 积极构造代数式之间“联系”的等量关系, 再结合其他条件, 营造能够使用常见不等式需要的条件, 最后就可以利用这些常见不等式轻松求解此类问题.
