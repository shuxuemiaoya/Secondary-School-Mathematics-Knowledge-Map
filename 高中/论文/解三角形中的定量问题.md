高考试卷中关于“解三角形”的解答题多以三角形作为命题背景，重点考查以正弦定理、余弦定理为工具计算求解三角形的边、角、周长或面积等问题，突出考查同学们的数学运算能力。但“数学运算”并不是简单的数学计算，主要是对运算对象、运算法则、运算思路、运算方法的理解、掌握、探究和选择。近几年高考中的解三角形大题主要考查正弦定理、余弦定理及三角恒等变换公式的灵活应用。下面就解三角形中的一些定量问题进行分析。

# 题型一、三角形中的角度问题

例 1 （2024 年重庆巴蜀中学高三一模）已知 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，且 $\frac{a}{b+c} + \frac{b\sin B}{b\sin A + c\sin B} = 1$ 。

(1)求角 C 的大小;  
(2) 若 a=2, b=4, D 为 AB 的中点，求 $\tan\angle ACD$ 的值。

解析:(1)已知 $\frac{a}{b+c}+\frac{b\sin B}{b\sin A+c\sin B}=$

1, 由正弦定理可得 $\frac{a}{b + c} + \frac{b^2}{ab + bc} = \frac{a}{b + c} + \frac{b}{a + c} = 1$ ，整理得 $a^2 + b^2 - c^2 = ab$ 。

由余弦定理可得 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=$ $\frac{ab}{2ab}=\frac{1}{2}$ 。

又因为 $C \in (0, \pi)$ ，所以 $C = \frac{\pi}{3}$ 。

(2)由(1)可得 $a^2 + b^2 - c^2 = ab$ ，又 $a = 2, b = 4$ ，则 $c^2 = a^2 + b^2 - ab = 12$ ，即 $c = 2\sqrt{3}$ 。

所以 $b^{2}=a^{2}+c^{2}$ ，即 $B=\frac{\pi}{2}$ ，可得 BD= $\sqrt{3}$ ， $\tan\angle BCD=\frac{BD}{BC}=\frac{\sqrt{3}}{2}$ 。

所以 $\tan \angle ACD = \tan (\angle ACB -$

$$
\begin{array}{l} \angle B C D) = \frac {\tan \angle A C B - \tan \angle B C D}{1 + \tan \angle A C B \cdot \tan \angle B C D} = \\ \frac {\sqrt {3} - \frac {\sqrt {3}}{2}}{1 + \sqrt {3} \times \frac {\sqrt {3}}{2}} = \frac {\sqrt {3}}{5} 。 \\ \end{array}
$$

点评:本题第(1)问根据题意先利用正弦定理将角转化成边,整理得边的二次齐次式,然后利用余弦定理求解角。在第(2)问中,根据(1)中的关系可得 $c=2\sqrt{3}$ , 进而可知 $B=\frac{\pi}{2}$ , 利用两角和差公式运算求解。三角形中的角度问题一般出现在解答题的第(1)问。在恒等变形和化简求角中,有如下经验:注意 $\sin C=\sin(A+B)=\sin A\cos B+\cos A\sin B$ 的正用和逆用。若条件式是边的齐次式,则用正弦定理转化为角的正弦;若条件式含有 a,b,c 的二次齐次式,则优先考虑余弦定理,“角化边”;若条件式是面积和 a,b,c 的二次齐次式,可构造余弦定理;若条件式含正切型,可以“切化弦”,转化为分式型,再进行化简求角。

# 题型二、三角形中的长度问题

例 2 （2024 年江苏泰州中学高三一模）已知 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，且满足 $\frac{b}{c} = \frac{\sin 2B}{2\sin A + \sin B}$ 。

(1)求角 C 的大小。  
(2) 若点 D 在边 AB 上, b=2, CD=1, 请在下列两个条件中任选一个, 求边长 AB。

①CD 为 $\triangle ABC$ 的角平分线；

②CD 为 $\triangle ABC$ 的中线。

解析:(1)在 $\triangle ABC$ 中,由正弦定理知 $\frac{b}{c}=\frac{\sin B}{\sin C}=\frac{\sin 2B}{2\sin A+\sin B}=\frac{2\sin B\cos B}{2\sin A+\sin B}$ 。

又因为 $B \in (0, \pi)$ , 所以 $\sin B > 0$ , 所以 $\frac{1}{\sin C} = \frac{2\cos B}{2\sin A + \sin B}$ , 即 $2\sin A + \sin B =$

$2\cos B\sin C$ 。

又 $A = \pi -(B + C)$ ，所以 $2\sin (B + C) +$ $\sin B = 2\cos B\sin C$ ，所以 $2\sin B\cos C+$ $2\cos B\sin C + \sin B = 2\cos B\sin C$ ，化简得 $2\sin B\cos C + \sin B = 0$ ，即 $\cos C = -\frac{1}{2}$ 。

又因为 $C \in (0, \pi)$ ，所以 $C = \frac{2\pi}{3}$ 。

(2)选①。

因为 CD 为 $\triangle ABC$ 的角平分线，所以 $S_{\triangle ABC} = S_{\triangle ACD} + S_{\triangle BCD}$ ，所以 $\frac{1}{2}CA \cdot CB \cdot \sin \angle ACB = \frac{1}{2}CA \cdot CD \cdot \sin \angle ACD + \frac{1}{2}CB \cdot CD \cdot \sin \angle BCD$ ，即 $\frac{1}{2}b \cdot a \cdot \frac{\sqrt{3}}{2} = \frac{1}{2}b \cdot 1 \cdot \frac{\sqrt{3}}{2} + \frac{1}{2}a \cdot 1 \cdot \frac{\sqrt{3}}{2}$ ，化简得 $a + b = ab$ 。

又因为 b=2，所以 a=2。

在 $\triangle ABC$ 中，由余弦定理可得 $c^{2}=a^{2}+b^{2}-2ab\cos C=2^{2}+2^{2}-8\cos\frac{2\pi}{3}=12$ ，所以 $AB=c=2\sqrt{3}$ 。

选②。

因为 CD 为 $\triangle ABC$ 的中线，所以 $\overrightarrow{CA} + \overrightarrow{CB} = 2\overrightarrow{CD}$ ，两边分别平方得 $\overrightarrow{CA}^{2} + \overrightarrow{CB}^{2} + 2\overrightarrow{CA} \cdot \overrightarrow{CB} = 4\overrightarrow{CD}^{2}$ ，所以 $b^{2} + a^{2} + 2ab\cos C = 4 \times 1^{2}$ ，所以 $a^{2} + b^{2} - ab = 4$ 。

又因为 b=2，所以 a=2。

在 $\triangle ABC$ 中，由余弦定理可得 $c^{2}=a^{2}+b^{2}-2ab\cos C=2^{2}+2^{2}-8\cos\frac{2\pi}{3}=12$ ，所以 $AB=c=2\sqrt{3}$ 。

点评:本题第(1)问可根据正弦定理将边转化成角,结合二倍角公式及两角和的正弦公式求得 $\cos C$ ,再由 C 的取值范围可得答案。在第(2)问中,选①,由 $S_{\triangle ABC}=S_{\triangle ACD}+S_{\triangle BCD}$ ,利用等面积法根据三角形的面积公式求得 a,由余弦定理得 AB;选②,由图形关系结合向量得 $\overrightarrow{CA}+\overrightarrow{CB}=2\overrightarrow{CD}$ ,平方后利用向量的运算可得 a,由余弦定理得 AB。求线段的长度往往归结为求三角形的边长,解决此类问题要恰当地选择或构造三角形,然后利用正、余弦定理求解。

# 题型三、三角形中的周长问题

例 3 （2024 年唐山模拟）已知 $\triangle ABC$ 的内角 A, B, C 的对边分别为 a, b, c，向量 $\boldsymbol{m} = (a, a)$ , $\boldsymbol{n} = \left( \cos C, \frac{\sqrt{3}}{3} \sin C \right)$ , $m \cdot n = b$ 。

(1)求角 A 的大小;

(2) 若 a=2，点 D 在 BC 边上，AD 平分 $\angle BAC$ ，且 $AD=\frac{\sqrt{2}}{3}$ ，求 $\triangle ABC$ 的周长。

解析:(1)由题意知 $m \cdot n = a \cos C + \frac{\sqrt{3}}{3} a \sin C = b$ 。

由正弦定理得 $\sin A \cos C + \frac{\sqrt{3}}{3} \sin A \cdot \sin C = \sin B$ 。

在 $\triangle ABC$ 中， $\sin B = \sin (A + C) = \sin A \cos C + \cos A \sin C$ ，则 $\frac{\sqrt{3}}{3} \sin A \sin C = \cos A \sin C$ 。

因为 $C \in (0, \pi)$ ，所以 $\sin C \neq 0$ ，所以 $\tan A = \sqrt{3}$ 。

又因为 $A \in (0, \pi)$ , 所以 $A = \frac{\pi}{3}$ 。

(2)依题意得 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ACD}$ ，即 $\frac{1}{2}bc \sin \angle BAC = \frac{1}{2}AD \cdot c \cdot \sin \angle BAD + \frac{1}{2}AD \cdot b \cdot \sin \angle CAD$ ，化简得 $\sqrt{3}bc = \frac{\sqrt{2}}{3} \cdot (b + c)$ 。

由余弦定理得 $4 = b^{2} + c^{2} - bc$ ，所以 $(b + c)^{2} - \frac{\sqrt{2}}{\sqrt{3}} (b + c) = 4$ ，解得 $b + c = \sqrt{6}$ 。

所以 $\triangle ABC$ 的周长为 $\sqrt{6} + 2$ 。

点评:本题第(1)问先利用向量数量积得到边角关系,再根据正弦定理将边转化成角,结合和差角公式及三角形的内角和求得 $\tan A$ ,再由A的取值范围可得答案。第(2)问利用等面积法结合余弦定理求得 $b+c$ ,从而求得三角形的周长。求三角形的周长本质是找寻三角形的三边之和。一般情况下题目会已知一边或两边再结合已知角,基本思想是利用正余弦定理求剩余边。其中在已知一边的情况下，也可以利用等面积法或向量法进行求解。

# 题型四、三角形中的面积问题

例 4 （2024 年南京高三开学检测）记 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，且 $a \sin B + \sqrt{3} b \cos A = 0$ 。

(1)求角 A 的大小;

(2) 若 $a = 3, \sin B \sin C = \frac{1}{4}$ ，求 $\triangle ABC$ 的面积。

解析:(1)已知 $a \sin B + \sqrt{3} b \cos A = 0$ ，由正弦定理得 $\sin A \sin B + \sqrt{3} \sin B \cos A = 0$ 。

因为 $B \in (0, \pi)$ , 所以 $\sin B \neq 0$ , 所以 $\sin A + \sqrt{3} \cos A = 0$ , 即 $\tan A = -\sqrt{3}$ 。

又因为 $A \in (0, \pi)$ ，所以 $A = \frac{2\pi}{3}$ 。

(2)解法1:由正弦定理 $\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}$ ，可得 $\frac{b}{\sin B}=\frac{c}{\sin C}=\frac{3}{\frac{\sqrt{3}}{2}}=2\sqrt{3}$ ，所以 $b=2\sqrt{3}\sin B,c=2\sqrt{3}\sin C$ 。

因为 $a = 3, \sin B \sin C = \frac{1}{4}$ , 所以 $bc = (2\sqrt{3})^2 \sin B \sin C = 3$ 。

所以 $\triangle ABC$ 的面积 $S = \frac{1}{2} bc \sin A = \frac{1}{2} \times 3 \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}$ 。

解法 2: 因为 $\sin B\sin C=\frac{1}{4}$ ，且 $B=\pi-A-C=\frac{\pi}{3}-C$ ，所以 $\sin\left(\frac{\pi}{3}-C\right)\sin C=\left(\frac{\sqrt{3}}{2}\cos C-\frac{1}{2}\sin C\right)\sin C=\frac{\sqrt{3}}{2}\sin C\cos C-\frac{1}{2}\sin^{2}C=\frac{\sqrt{3}}{4}\sin 2C-\frac{1}{2}\cdot\frac{1-\cos 2C}{2}=\frac{\sqrt{3}}{4}\sin 2C+\frac{1}{4}\cos 2C-\frac{1}{4}=\frac{1}{2}\cos\left(2C-\frac{\pi}{3}\right)-\frac{1}{4}=\frac{1}{4}$ ，所以 $\cos\left(2C-\frac{\pi}{3}\right)=1$ 。

又 $C \in (0, \pi)$ , 则 $2C - \frac{\pi}{3} \in \left(-\frac{\pi}{3}, \frac{\pi}{3}\right)$ , 所以 $2C - \frac{\pi}{3} = 0$ , 所以 $C = \frac{\pi}{6}$ 。

所以 $B = \frac{\pi}{3} - C = \frac{\pi}{6}$ , 所以 $b = c$ 。

因为 a=3，由余弦定理得 $a^{2}=b^{2}+c^{2}-2bc\cos A$ ，即 $9=b^{2}+b^{2}-2b^{2}\cos\frac{2\pi}{3}=3b^{2}$ ，解得 $b=\sqrt{3}$ ，即 $b=c=\sqrt{3}$ 。

所以 $\triangle ABC$ 的面积 $S = \frac{1}{2} bc\sin A = \frac{1}{2}\times \sqrt{3}\times \sqrt{3}\times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}$ 。

点评:本题第(1)问可根据正弦定理将边转化成角,求得 $\tan A$ , 由 A 的取值范围可得答案。第(2)问中的解法 1, 由正弦定理结合条件式得 bc 的值, 再利用三角形的面积公式求得三角形的面积; 解法 2, 由条件式结合三角形的内角和求得 $\cos\left(2C-\frac{\pi}{3}\right)$ , 从而求得角 C, B, 再利用余弦定理可得 b, c, 最后利用三角形的面积公式求得三角形的面积。三角形面积公式的选取取决于三角形中哪个角已知或可求, 或三角形中哪个角的正弦值可求。在解决三角形问题时, 面积公式 $S_{\triangle ABC}=\frac{1}{2}ab\sin C=\frac{1}{2}ac\sin B=\frac{1}{2}bc\sin A$ 最常用, 因为公式中既有角又有边, 容易和正弦定理、余弦定理联系起来应用。

总之,处理解三角形问题的关键在于灵活运用各种定理和公式,同时结合题目给出的条件进行推理和计算。在解题过程中,同学们需要注意以下几点技巧:①准确理解题意,明确已知条件和未知量;②合理选择使用正弦定理、余弦定理或其他相关公式;③善于利用三角形的内角和定理和边长比例关系;④对于特殊类型的三角形,尝试使用特殊解法;⑤在解题过程中保持耐心和细心,避免计算错误。通过掌握这些解题技巧和方法,同学们可以更好地解决各种三角形问题,提高数学解题能力。
