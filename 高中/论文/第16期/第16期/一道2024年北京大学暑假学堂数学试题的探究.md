# 1 题目呈现与解答

题目 （2024年北京大学暑假学堂数学试题第1题）已知正实数 a, b, c 满足 $a + b + c = 1$ ，求 $\frac{a}{a^{2} + 1} + \frac{b}{b^{2} + 1} + \frac{c}{c^{2} + 1}$ 的最大值.

解法 1 由均值不等式, 得

$$
a ^ {2} + 1 = a ^ {2} + 9 \times \frac {1}{9} \geqslant 1 0 \sqrt [ 1 0 ]{a ^ {2} \cdot (\frac {1}{9}) ^ {9}} = \frac {1 0 \sqrt [ 5 ]{a}}{\sqrt [ 1 0 ]{9 ^ {9}}}.
$$

于是 $\frac{a}{a^2 + 1} \leqslant \frac{\sqrt[10]{9^9} a}{10\sqrt[5]{a}} = \frac{9\sqrt[5]{a^4}}{10\sqrt[10]{9}}.$

又由 $a + a + a + a + \frac{1}{3} \geqslant 5\sqrt[5]{a^4 \cdot \frac{1}{3}}$ ，可得

$$
a ^ {\frac {4}{5}} \leqslant \frac {4 a + 1 / 3}{5 \times \sqrt [ 5 ]{1 / 3}} = \frac {\sqrt [ 5 ]{3} (4 a + 1 / 3)}{5}.
$$

从而，有 $\frac{a}{a^2 + 1} \leqslant \frac{9\sqrt[5]{a^4}}{10\sqrt[10]{9}} = \frac{(9 / 5) \times \sqrt[5]{3}(4a + 1 / 3)}{10\sqrt[10]{9}}$ $= \frac{\sqrt[5]{3}(36a + 3)}{50\sqrt[10]{9}} = \frac{36a + 3}{50}$ ，当 $a = \frac{1}{3}$ 时，等号成立.

同理, 得 $\frac{b}{b^{2}+1} \leqslant \frac{36b+3}{50}, \frac{c}{c^{2}+1} \leqslant \frac{36c+3}{50}.$

故 $\frac{a}{a^2 + 1} +\frac{b}{b^2 + 1} +\frac{c}{c^2 + 1}\leqslant \frac{36a + 3}{50} +\frac{36b + 3}{50} +$ $\frac{36c + 3}{50} = \frac{36(a + b + c) + 9}{50} = \frac{9}{10}.$

所以当 $a = b = c = \frac{1}{3}$ 时， $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的最大值为 $\frac{9}{10}$ .

解法 2 由均值不等式, 得

$$
\begin{array}{l} \frac {a}{a ^ {2} + 1} = \frac {a}{a ^ {2} + 1 / 9 + 8 / 9} \leqslant \frac {a}{2 \sqrt {a ^ {2} / 9} + 8 / 9} \\ = \frac {a}{2 a / 3 + 8 / 9} = \frac {3}{2} \cdot \frac {3 a}{3 a + 4} = \frac {3}{2} (1 - \frac {4}{3 a + 4}). \\ \end{array}
$$

同理, 得 $\frac{b}{b^{2}+1} \leqslant \frac{3}{2}(1 - \frac{4}{3b+4})$ ,

\frac {c}{c ^ {2} + 1} \leqslant \frac {3}{2} (1 - \frac {4}{3 c + 4}).
$$

结合权方和不等式,得

$$
\begin{array}{l} \frac {a}{a ^ {2} + 1} + \frac {b}{b ^ {2} + 1} + \frac {c}{c ^ {2} + 1} \leqslant \frac {3}{2} (1 - \frac {4}{3 a + 4}) + \frac {3}{2} (1 \\ \left. - \frac {4}{3 b + 4}\right) + \frac {3}{2} \left(1 - \frac {4}{3 c + 4}\right) \\ = \frac {9}{2} - \frac {3}{2} \left(\frac {4}{3 a + 4} + \frac {4}{3 b + 4} + \frac {4}{3 c + 4}\right) \\ \leqslant \frac {9}{2} - \frac {3}{2} \cdot \frac {(2 + 2 + 2) ^ {2}}{3 a + 4 + 3 b + 4 + 3 c + 4} \\ = \frac {9}{2} - \frac {3}{2} \cdot \frac {3 6}{3 + 1 2} = \frac {9}{1 0}. \\ \end{array}
$$

所以当 $a = b = c = \frac{1}{3}$ 时， $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的最大值为 $\frac{9}{10}$ .

解法3 设 $f(a, b, c) = \frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1} + \lambda (a + b + c - 1)$ , 则

$$
\left\{ \begin{array}{l} \frac {\partial f}{\partial a} = \frac {1 - a ^ {2}}{\left(a ^ {2} + 1\right) ^ {2}} + \lambda = 0, \\ \frac {\partial f}{\partial b} = \frac {1 - b ^ {2}}{\left(b ^ {2} + 1\right) ^ {2}} + \lambda = 0, \\ \frac {\partial f}{\partial c} = \frac {1 - c ^ {2}}{\left(c ^ {2} + 1\right) ^ {2}} + \lambda = 0, \end{array} \right.
$$

则 $\lambda = \frac{a^2 - 1}{(a^2 + 1)^2}, \lambda = \frac{b^2 - 1}{(b^2 + 1)^2}, \lambda = \frac{c^2 - 1}{(c^2 + 1)^2}$ .

于是 a=b=c，结合 $a+b+c=1$ ，解得 $a=b=c=\frac{1}{3}$ .

从而有 $\frac{a}{a^2 + 1} +\frac{b}{b^2 + 1} +\frac{c}{c^2 + 1} = \frac{1 / 3}{1 / 9 + 1}\times 3 = \frac{9}{10}.$

所以当 $a = b = c = \frac{1}{3}$ 时， $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的最大值为 $\frac{9}{10}$ .

解法4 先证: 当 $x \in (0,1]$ 时, $\frac{x}{x^{2}+1} \leqslant \frac{18}{25}(x - \frac{1}{3}) + \frac{3}{10}$ . 因为 $\frac{x}{x^{2}+1} - \left[\frac{18}{25}(x - \frac{1}{3}) + \frac{3}{10}\right] = \frac{(3x-1)^{2}(4x+3)}{-50(x^{2}+1)} \leqslant 0$ , 所以 $\frac{x}{x^{2}+1} \leqslant \frac{18}{25}(x - \frac{1}{3}) + \frac{3}{10}$ , 当 $x = \frac{1}{3}$ 时, 等号成立.

由 $a, b, c$ 是正实数，且 $a + b + c = 1$ ，可得 $a \in (0,1], b \in (0,1], c \in (0,1]$ .

于是,可得 $\frac{a}{a^{2}+1}\leqslant\frac{18}{25}(a-\frac{1}{3})+\frac{3}{10}$ ,

$$
\begin{array}{l} \frac {b}{b ^ {2} + 1} \leqslant \frac {1 8}{2 5} (b - \frac {1}{3}) + \frac {3}{1 0}, \\ \frac {c}{c ^ {2} + 1} \leqslant \frac {1 8}{2 5} \left(c - \frac {1}{3}\right) + \frac {3}{1 0}. \\ \end{array}
$$

所以 $\frac{a}{a^2 + 1} +\frac{b}{b^2 + 1} +\frac{c}{c^2 + 1}\leqslant \frac{18}{25}(a - \frac{1}{3}) + \frac{3}{10}$

$$
\begin{array}{l} + \frac {1 8}{2 5} (b - \frac {1}{3}) + \frac {3}{1 0} + \frac {1 8}{2 5} (c - \frac {1}{3}) + \frac {3}{1 0} = \frac {1 8}{2 5} (a + b + c \\ - 1) + \frac {9}{1 0} = \frac {9}{1 0}. \\ \end{array}
$$

所以当 $a = b = c = \frac{1}{3}$ 时， $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的最大值为 $\frac{9}{10}$ .

评注 解法4的解题思路是切线放缩:设 $f(x)=\frac{x}{x^{2}+1},x\in(0,1]$ ，则 $f'(x)=-\frac{x^{2}-1}{(x^{2}+1)^{2}},f''(x)=\frac{2x(x^{2}-3)}{(x^{2}+1)^{3}}<0.$ 故 $f(x)$ 在 $(0,1]$ 上是上凸函数，且 $f'(\frac{1}{3})=\frac{18}{25},f(\frac{1}{3})=\frac{3}{10}.$ 从而 $f(x)$ 在 $(\frac{1}{3},\frac{3}{10})$ 处的切线为 $y=\frac{18}{25}(x-\frac{1}{3})+\frac{3}{10}.$ 所以恒有 $\frac{x}{x^{2}+1}\leqslant\frac{18}{25}(x-\frac{1}{3})+\frac{3}{10}.$ 切线放缩是解答与凸函数有关问题的常用做法，解法巧妙、自然 $^{[1]}$ .

# 2 试题的变式

变式 已知非负实数 $a, b, c$ 满足 $a + b + c = 1$ , 求 $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的取值范围.

解析 由 $a, b, c$ 是非负实数，且 $a + b + c = 1$ ，可得 $a \in [0,1], b \in [0,1], c \in [0,1]$ .

先证: 当 $x \in [0,1]$ 时, $\frac{x}{x^{2}+1} \geqslant \frac{1}{2}x$ .

因为 $\frac{x}{x^{2}+1}\geqslant\frac{1}{2}x\Leftrightarrow\frac{1}{x^{2}+1}\geqslant\frac{1}{2}\Leftrightarrow x^{2}+1\leqslant2\Leftrightarrow x^{2}\leqslant$ 1, 得证, 当 x=0 或 x=1 时, 等号成立.

从而, 可得 $\frac{a}{a^{2}+1}+\frac{b}{b^{2}+1}+\frac{c}{c^{2}+1}\geqslant\frac{1}{2}a+\frac{1}{2}b+\frac{1}{2}c=\frac{1}{2}(a+b+c)=\frac{1}{2}.$

故当 a, b, c 中有两个为 0，且另一个为 1 时， $\frac{a}{a^{2}+1}+\frac{b}{b^{2}+1}+\frac{c}{c^{2}+1}$ 的最小值为 $\frac{1}{2}$ . 结合原题，可知 $\frac{a}{a^{2}+1}+\frac{b}{b^{2}+1}+\frac{c}{c^{2}+1}$ 的最大值为 $\frac{9}{10}$ .

所以 $\frac{a}{a^2 + 1} + \frac{b}{b^2 + 1} + \frac{c}{c^2 + 1}$ 的取值范围为 $[\frac{1}{2}, \frac{9}{10}]$ .

# 3 试题的拓展

拓展1 已知正实数 $a, b, c$ 满足 $a + b + c = 1$ , 求 $\frac{a^2}{a + 1} + \frac{b^2}{b + 1} + \frac{c^2}{c + 1}$ 的最小值.

解析 先证: 当 $x \in (0,1]$ 时, $\frac{x^{2}}{x+1} \geqslant \frac{7}{16}(x - \frac{1}{3}) + \frac{1}{12}$ .

因为 $\frac{x^{2}}{x+1}-\left[\frac{7}{16}(x-\frac{1}{3})+\frac{1}{12}\right]=\frac{(3x-1)^{2}}{16(x+1)}\geqslant0,$

所以 $\frac{x^{2}}{x+1}\geqslant\frac{7}{16}(x-\frac{1}{3})+\frac{1}{12}$ ，当 $x=\frac{1}{3}$ 时，等号成立.

由 $a, b, c$ 是正实数，且 $a + b + c = 1$ ，可得 $a \in (0,1], b \in (0,1], c \in (0,1]$ .

所以 $\frac{a^2}{a + 1} \geqslant \frac{7}{16} (a - \frac{1}{3}) + \frac{1}{12}$ ,

$$
\frac {b ^ {2}}{b + 1} \geqslant \frac {7}{1 6} (b - \frac {1}{3}) + \frac {1}{1 2},
$$

$$
\frac {c ^ {2}}{c + 1} \geqslant \frac {7}{1 6} (c - \frac {1}{3}) + \frac {1}{1 2}.
$$

$$
\begin{array}{l} + \frac {7}{1 6} (b - \frac {1}{3}) + \frac {1}{1 2} + \frac {7}{1 6} (c - \frac {1}{3}) + \frac {1}{1 2} = \frac {7}{1 6} (a + b + c \\ - 1) + \frac {1}{4} = \frac {1}{4}. \\ \end{array}
$$

所以 $\frac{a^2}{a + 1} +\frac{b^2}{b + 1} +\frac{c^2}{c + 1}\geqslant \frac{7}{16}(a - \frac{1}{3}) + \frac{1}{12}$

所以当 $a = b = c = \frac{1}{3}$ 时， $\frac{a^2}{a + 1} + \frac{b^2}{b + 1} + \frac{c^2}{c + 1}$ 的最小值为 $\frac{1}{4}$ .

拓展2 已知非负实数 $a, b, c$ 满足 $a + b + c$ $= 1$ ，求 $\frac{1}{a + 1} +\frac{1}{2b + 1} +\frac{1}{3c + 1}$ 的取值范围.

解析 由 $a, b, c$ 是非负实数，且 $a + b + c = 1$ ，可得 $a \in [0,1], b \in [0,1], c \in [0,1]$ .

由权方和不等式,可得

$$
\begin{array}{l} \frac {1}{a + 1} + \frac {1}{2 b + 1} + \frac {1}{3 c + 1} = \frac {6}{6 a + 6} + \frac {3}{6 b + 3} + \frac {2}{6 c + 2} \\ \geqslant \frac {(\sqrt {6} + \sqrt {3} + \sqrt {2}) ^ {2}}{6 (a + b + c) + 6 + 3 + 2} \\ = \frac {(\sqrt {6} + \sqrt {3} + \sqrt {2}) ^ {2}}{1 7}. \\ \end{array}
$$

先证: 当 $x \in [0,1]$ 时, $\frac{1}{x+1} \leqslant 1 - \frac{1}{2}x$ .

因为 $\frac{1}{x+1}-(1-\frac{1}{2}x)=\frac{x(x-1)}{2(x+1)}\leqslant0$ ，所以 $\frac{1}{x+1}\leqslant1-\frac{1}{2}x$ ，当x=0或x=1时，等号成立.

所以 $\frac{1}{a + 1} +\frac{1}{2b + 1} +\frac{1}{3c + 1}\leqslant \frac{1}{a + 1} +\frac{1}{b + 1} +\frac{1}{c + 1}$

$$
\leqslant 1 - \frac {1}{2} a + 1 - \frac {1}{2} b + 1 - \frac {1}{2} c = 3 - \frac {1}{2} (a + b + c) = \frac {5}{2},
$$

当 a=1, b=c=0 时, 等号成立.

所以 $\frac{1}{a + 1} +\frac{1}{2b + 1} +\frac{1}{3c + 1}$ 的取值范围为 $[\frac{(\sqrt{6} + \sqrt{3} + \sqrt{2})^2}{17},\frac{5}{2} ]$
