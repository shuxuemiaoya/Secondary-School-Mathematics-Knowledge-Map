# 一、问题呈现

【问题】(江苏省扬州市2020届高三第一次模拟考试·13) 在 $\triangle ABC$ 中，若 $\sin B + \cos B = \sqrt{2}$ ，则 $\frac{\sin 2A}{\tan B + \tan C}$ 的最大值为 \_\_\_\_.

此题以三角形为问题背景,根据题目给出的条件,第一时间结合辅助角公式或平方关系求出角 B;然后把角 A 用角 C 的三角函数关系式表示出来,转化成关于角 C 的一个三角函数式,求出相应三角函数式的最值即可,可利用三角恒等变换转化为正弦型(或余弦型)函数再利用三角函数的图像与性质求出函数的最大值,可借助换元法思维再用基本不等式求出函数的最大值,也可借助换元法思维再利用导数求出函数的最大值.

# 二、问题破解

# 思维视角一:三角恒等变换思维

方法 1:(三角恒等变换法 1)

解析：由题中条件可得 $\sin B + \cos B = \sqrt{2}\sin\left(B + \frac{\pi}{4}\right) = \sqrt{2}$ ，即 $\sin\left(B + \frac{\pi}{4}\right) = 1$ ，可得 $B + \frac{\pi}{4} = \frac{\pi}{2}$ ，解得 $B = \frac{\pi}{4}$ ，那么 $\frac{\sin 2A}{\tan B + \tan C} = \frac{\sin 2A}{\frac{\sin B}{\cos B} + \frac{\sin C}{\cos C}} =$

$$
\frac {\sin 2 A}{\frac {\sin B \cos C + \cos B \sin C}{\cos B \cos C}} = \frac {\sin 2 A}{\frac {\sin (B + C)}{\cos B \cos C}} = \frac {2 \sin A \cos A}{\frac {\sin A}{\cos B \cos C}} =
$$

$$
2 \cos A \cos B \cos C = \sqrt {2} \cos A \cos C = \sqrt {2} \cos \left(\frac {3 \pi}{4} - C\right) \cos C
$$

$$
= \frac {\sqrt {2}}{2} \left[ \cos \frac {3 \pi}{4} + \cos \left(\frac {3 \pi}{4} - 2 C\right) \right] = \frac {\sqrt {2}}{2} \cos \left(\frac {3 \pi}{4} - 2 C\right) -
$$

$\frac{1}{2}$ , 由 $C = \frac{3\pi}{4} - A \in \left(0, \frac{3\pi}{4}\right)$ , 可得 $\left(\frac{3\pi}{4} - 2C\right) \in \left(-\frac{3\pi}{4}, \frac{3\pi}{4}\right)$ , 则知当 $\frac{3\pi}{4} - 2C = 0$ , 即 $C = \frac{3\pi}{8}$ 时,

$\frac{\sin 2A}{\tan B + \tan C} = \frac{\sqrt{2}}{2}\cos \left(\frac{3\pi}{4} -2C\right) - \frac{1}{2}$ 取得最大值 $\frac{\sqrt{2}}{2} -$ $\frac{1}{2} = \frac{\sqrt{2} - 1}{2}$ ，所以 $\frac{\sin 2A}{\tan B + \tan C}$ 的最大值为 $\frac{\sqrt{2} - 1}{2}$ ，故填答案： $\frac{\sqrt{2} - 1}{2}$

方法 2: (三角恒等变换法 2)

解析:由题中关系式 $\sin B + \cos B = \sqrt{2}$ ，两边平方整理可得 $1 + 2\sin B\cos B = 2$ ，则有 $2\sin B\cos B = 1$ ，即 $\sin 2B = 1$ ，可得 $2B = \frac{\pi}{2}$ ，解得 $B = \frac{\pi}{4}$ ，那么

$$
\begin{array}{l} \frac {\sin 2 A}{\tan B + \tan C} = \frac {\sin \left(\frac {3 \pi}{2} - 2 C\right)}{1 + \tan C} = - \frac {\cos 2 C}{1 + \tan C} = \\ - \frac {\cos^ {2} C - \sin^ {2} C}{1 + \frac {\sin C}{\cos C}} = (\sin C - \cos C) \cos C = \sin C \cos C - \\ \end{array}
$$

$$
\cos^ {2} C = \frac {1}{2} \sin 2 C - \frac {1}{2} (1 + \cos 2 C) = \frac {1}{2} (\sin 2 C - \cos 2 C)
$$

$-\frac{1}{2}=\frac{\sqrt{2}}{2}\sin\left(2C-\frac{\pi}{4}\right)-\frac{1}{2}$ ，由 $C=\frac{3\pi}{4}-A\in\left(0,\frac{3\pi}{4}\right)$ ，可得 $\left(2C-\frac{\pi}{4}\right)\in\left(-\frac{\pi}{4},\frac{5\pi}{4}\right)$ ，则知当 $2C-\frac{\pi}{4}=\frac{\pi}{2}$ ，即 $C=\frac{3\pi}{8}$ 时， $\frac{\sin2A}{\tan B+\tan C}=\frac{\sqrt{2}}{2}\cdot\sin\left(2C-\frac{\pi}{4}\right)-\frac{1}{2}$ 取得最大值 $\frac{\sqrt{2}}{2}-\frac{1}{2}=\frac{\sqrt{2}-1}{2}$ ，所以 $\frac{\sin2A}{\tan B+\tan C}$ 的最大值为 $\frac{\sqrt{2}-1}{2}$ ，故填答案： $\frac{\sqrt{2}-1}{2}$ .

# 思维视角二:换元思维

方法 3:(基本不等式法)

解析：由题中条件可得 $\sin B + \cos B = \sqrt{2}\sin \left(B + \frac{\pi}{4}\right) = \sqrt{2}$ ，即 $\sin \left(B + \frac{\pi}{4}\right) = 1$ ，可得 $B + \frac{\pi}{4} = \frac{\pi}{2}$ ，解得 $B = \frac{\pi}{4}$ ，那么 $\frac{\sin 2A}{\tan B + \tan C} = \frac{\sin\left(\frac{3\pi}{2} - 2C\right)}{1 + \tan C}$

$$
= - \frac {\cos 2 C}{1 + \tan C} = - \frac {1 - \tan^ {2} C}{(1 + \tan^ {2} C) (1 + \tan C)} =
$$

$\frac{\tan C - 1}{1 + \tan^2 C}$ . 令 $t = \tan C - 1$ , 即 $\tan C = t + 1$ , 可得

$$
\frac {\tan C - 1}{1 + \tan^ {2} C} = \frac {t}{1 + (t + 1) ^ {2}} = \frac {t}{t ^ {2} + 2 t + 2} = \frac {1}{t + \frac {2}{t} + 2} \leqslant
$$

$\frac{1}{2\sqrt{t\times\frac{2}{t}}+2}=\frac{1}{2\sqrt{2}+2}=\frac{\sqrt{2}-1}{2}$ , 当且仅当 $t=\frac{2}{t}$ ,

即 $t=\tan C-1=\sqrt{2}$ ，亦即 $\tan C=\sqrt{2}+1$ 时等号成立，所以 $\frac{\sin 2A}{\tan B+\tan C}$ 的最大值为 $\frac{\sqrt{2}-1}{2}$ ，故填答案： $\frac{\sqrt{2}-1}{2}$ .

方法 4:(导数法)

解析:由题中关系式 $\sin B + \cos B = \sqrt{2}$ ，两边平方整理可得 $1 + 2\sin B\cos B = 2$ ，则有 $2\sin B\cos B = 1$ ，即 $\sin 2B = 1$ ，可得 $2B = \frac{\pi}{2}$ ，解得 $B = \frac{\pi}{4}$ ，那么

$$
\frac {\sin 2 A}{\tan B + \tan C} = \frac {\sin \left(\frac {3 \pi}{2} - 2 C\right)}{1 + \tan C} = - \frac {\cos 2 C}{1 + \tan C} =
$$

$-\frac{1-\tan^{2}C}{(1+\tan^{2}C)(1+\tan C)}=\frac{\tan C-1}{1+\tan^{2}C}.$ 令 $t=\tan C,$

由 $C = \frac{3\pi}{4} - A \in \left(0, \frac{3\pi}{4}\right)$ ，可得 $t = \tan C \in (-\infty, -1) \cup (0, +\infty)$ ，可得 $f(t) = \frac{\tan C - 1}{1 + \tan^2 C} = \frac{t - 1}{1 + t^2}$ ，求

导有 $f'(t)=\frac{-t^{2}+2t+1}{(1+t^{2})^{2}}$ . 令 $f'(t)=0$ , 即 $-t^{2}+2t+1=0$ , 解得 $t=1+\sqrt{2}$ (其中 $t=1-\sqrt{2}$ 舍去), 则有 $f(t)_{\max}=f(1+\sqrt{2})=\frac{\sqrt{2}-1}{2}$ , 所以 $\frac{\sin2A}{\tan B+\tan C}$ 的最大值为 $\frac{\sqrt{2}-1}{2}$ , 故填答案: $\frac{\sqrt{2}-1}{2}$ .

点评:破解三角形问题中的最值问题,基本思维方式就是:(1)借助三角恒等变换,把相应的三角函数关系式转化为正弦型(或余弦型)函数,再利用三角函数的图像与性质来处理;(2)利用基本不等式、导数法等工具来确定相应的最值问题.无论从哪个思维角度切入,都要充分利用题目条件、三角形中的隐含条件以及所求结果之间的有效联系与转化,合理构建起必要的桥梁,从而得以合理转化与应用,再利用三角函数、基本不等式或导数等相应的工具来分析与求解.

探究:结合以上问题的破解过程,回归本源,简化关系式,可得以下变式:

【变式】在 $\triangle ABC$ 中，若 $\sin B + \cos B = \sqrt{2}$ ，则 $2\cos A\cos B\cos C$ 的最大值为 \_\_\_\_.

解析：由题中条件可得 $\sin B + \cos B = \sqrt{2}\sin\left(B + \frac{\pi}{4}\right) = \sqrt{2}$ ，即 $\sin\left(B + \frac{\pi}{4}\right) = 1$ ，可得 $B + \frac{\pi}{4} = \frac{\pi}{2}$ ，解得 $B = \frac{\pi}{4}$ ，那么 $2\cos A\cos B\cos C = \sqrt{2}\cos A\cos C$

$$
= \sqrt {2} \cos \left(\frac {3 \pi}{4} - C\right) \cos C = \frac {\sqrt {2}}{2} \left[ \cos \frac {3 \pi}{4} + \cos \left(\frac {3 \pi}{4} - 2 C\right) \right] =
$$

$\frac{\sqrt{2}}{2}\cos\left(\frac{3\pi}{4}-2C\right)-\frac{1}{2}$ . 由 $C=\frac{3\pi}{4}-A\in\left(0,\frac{3\pi}{4}\right)$ ，可得 $\left(\frac{3\pi}{4}-2C\right)\in\left(-\frac{3\pi}{4},\frac{3\pi}{4}\right)$ ，则知当 $\frac{3\pi}{4}-2C=0$ ，即 $C=\frac{3\pi}{8}$ 时， $2\cos A\cos B\cos C=\frac{\sqrt{2}}{2}\cos\left(\frac{3\pi}{4}-2C\right)-\frac{1}{2}$ 取得最大值 $\frac{\sqrt{2}}{2}-\frac{1}{2}=\frac{\sqrt{2}-1}{2}$ ，所以 $2\cos A\cos B\cos C$ 的最大值为 $\frac{\sqrt{2}-1}{2}$ ，故填答案： $\frac{\sqrt{2}-1}{2}$ .
