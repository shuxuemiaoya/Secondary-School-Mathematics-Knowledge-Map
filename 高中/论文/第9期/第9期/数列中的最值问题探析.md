# 一、数列项的最值问题

对于函数来说,有的函数不存在最大值或最小值,有的函数却有最大值或最小值,数列也是如此,在有些数列的所有项中,存在最大项或最小项.那么如何求数列中项的最值呢?一般有两种方法:一种是比较法,如依据不等式组 $\left\{\begin{aligned}a_{n}&\geqslant a_{n-1},\\ a_{n}&\geqslant a_{n+1}\end{aligned}\right.$ ( $n\geqslant2$ ),就可确定数列的最大项,依据不等式组 $\left\{\begin{aligned}a_{n}&\leqslant a_{n-1},\\ a_{n}&\leqslant a_{n+1}\end{aligned}\right.$ ( $n\geqslant2$ ) 就可确定数列的最小项;另一种方法是单调性法,即利用函数的单调性或利用数列单调性来求出数列的最大项或最小项.

例 1 （1）已知数列 $\{a_{n}\}$ 的通项是 $a_{n} = \frac{n - \sqrt{2019}}{n - \sqrt{2020}}$ ，那么这个数列的前 2020 项中，最大项与最小项分别为（）.

$$
\mathrm{A.} a _ {1}, a _ {5 0} \quad \mathrm{B.} a _ {1}, a _ {4 4} \quad \mathrm{C.} a _ {4 5}, a _ {4 4} \quad \mathrm{D.} a _ {4 5}, a _ {5 0}
$$

(2) 设等差数列 $\{a_{n}\}$ 满足 $a_{3} + a_{7} = 36, a_{4}a_{6} = 275$ ，且 $a_{n}a_{n+1}$ 有最小值，那么这个最小值是 \_\_\_\_.

解析：（1）因为 $a_{n}=\frac{n-\sqrt{2019}}{n-\sqrt{2020}}=1+\frac{\sqrt{2020}-\sqrt{2019}}{n-\sqrt{2020}}$ ，所以当 $n\in[1,44]$ 时，数列 $\{a_{n}\}$ 为单调递减数列，而当 $n\in[45,2020]$ 时，数列 $\{a_{n}\}$ 也为

单调递减数列，于是可结合函数 $f(x)=1+\frac{\sqrt{2020}-\sqrt{2019}}{x-\sqrt{2020}}$ 的图像(此略)，就可找到该数列的最大项是 $a_{45}$ ，最小项是 $a_{44}$ ，故选 C.

(2) 因为数列 $\{a_{n}\}$ 是等差数列，且 $a_{3} + a_{7} = 36$ ，所以 $a_{4} + a_{6} = 36$ 。因为 $a_{4}a_{6} = 275$ ，所以 $a_{4}, a_{6}$ 是一元二次方程 $t^{2} - 36t + 275 = 0$ 的二根，由 $t^{2} - 36t + 275 = 0$ 得 $(t - 25)(t - 11) = 0$ ，所以 $t_{1} = 25$ 或 $t_{2} = 11$ 。当 $a_{4} = 25, a_{6} = 11$ 时， $d = \frac{a_{6} - a_{4}}{6 - 4} = \frac{11 - 25}{2} = -7$ ，所以 $a_{n} = a_{4} + (n - 4)d = -7n + 53$ ，当 $a_{n} > 0, a_{n+1} < 0$ 时， $a_{n}a_{n+1}$ 取得最小值，由 $\left\{\begin{aligned}-7n + 53 &>0, \\-7(n + 1) &+53 < 0\end{aligned}\right.$ 解得 $\frac{46}{7} < n < \frac{53}{7}$ ，所以 n = 7 时， $a_{n}a_{n+1}$ 取得最小值，此时 $a_{7} = 4, a_{8} = -3, (a_{n}a_{n+1})_{\min} = -12$ ；当 $a_{4} = 11, a_{6} = 25$ 时， $d = \frac{a_{6} - a_{4}}{6 - 4} = \frac{25 - 11}{2} = 7$ ，所以 $a_{n} = a_{4} + (n - 4)d = 7n - 17$ ，当 $a_{n} < 0, a_{n+1} > 0$ 时， $a_{n}a_{n+1}$ 取得最小值，由 $\left\{\begin{aligned}7n - 17 &< 0, \\7(n + 1) &-17 > 0\end{aligned}\right.$ 解得 $\frac{10}{7} < n < \frac{17}{7}$ ，所以 n = 2 时， $a_{n}a_{n+1}$ 取得最小值，此时 $a_{2} = -3, a_{3} = 4, (a_{n}a_{n+1})_{\min} = -12$ 。故本题答案为 -12。

# 二、数列前 n 项和的最值问题

对于这类问题,公差不为0的等差数列的前n项和的最值问题,出现的频率最高,有客观题,也有主观题,难度一般不大.这类问题的求解主要有以下三种方法:(1)依据数列 $\{a_{n}\}$ 中项的单调性,求出它的靠近零的正项与负项,简称通项分析法;(2)利用二次函数的性质,考查等差数列的前n项和 $S_{n}=An^{2}+Bn$ (字母A与B为常数)的图像的对称轴;(3)采用比较法,利用不等式组 $\left\{\begin{aligned}S_{n}&\geqslant S_{n-1},\\ S_{n}&\geqslant S_{n+1}\end{aligned}\right.$ 直接求出 $S_{n}$ 的最值.

例 2 （1）在等差数列 $\{a_{n}\}$ 中， $\frac{a_{7}}{a_{6}} < -1$ ，若它的前 n 项和 $S_{n}$ 有最大值，则当 $S_{n} > 0$ 时，n 的最大值为（）.

A. 11

B. 12

C. 13

D. 14

(2) 在等差数列 $\{a_{n}\}$ 中, $S_{n}$ 为其前 n 项和, 且 $S_{7}$ 最大, $|a_{7}| < |a_{8}|$ , 试求使 $S_{n} > 0$ 的最大的正整数 n 的值.

解析:(1) 数列 $\{a_{n}\}$ 为等差数列, $S_{n}$ 有最大值,若 $\frac{a_{7}}{a_{6}}<-1$ ,则 $\frac{a_{7}+a_{6}}{a_{6}}<0$ ,可得d<0,所以 $a_{6}>0,a_{7}+a_{6}<0,a_{7}<0$ ,所以 $a_{1}+a_{11}=2a_{6}>0,S_{11}>0$ ,所以 $a_{1}+a_{12}=a_{7}+a_{6}<0,S_{12}<0$ ,故当 $S_{n}>0$ 时,n的最大值为11,本题选A.

(2) 因为 $S_{7}$ 最大, 所以有 $a_{7} \geqslant 0$ 且 $a_{8} < 0$ .

因为 $\left|a_{7}\right|<\left|a_{8}\right|$ ，所以 $a_{7}<-a_{8}$ ，即 $a_{7}+a_{8}<0$ ，所以 $a_{1}+a_{14}=a_{7}+a_{8}<0$ 。

所以 $S_{14}=\frac{14(a_{1}+a_{14})}{2}=7(a_{1}+a_{14})<0.$

若 $a_{7} \neq 0$ ，即 $a_{7} > 0$ ，则 $S_{13} = 13a_{7} > 0$ ，即 $S_{n} > 0$ 的最大的正整数 n = 13.

若 $a_{7}=0$ ，则 $a_{6}>0, S_{13}=13a_{7}=0, S_{12}=6(a_{6}+a_{7})=6a_{6}>0$ ，即 $S_{n}>0$ 的最大的正整数 n=12.

综上所述, 当 $a_{7} \neq 0$ 时, 使 $S_{n} > 0$ 的最大正整数 n 为 13; 当 $a_{7} = 0$ 时, 使 $S_{n} > 0$ 的最大正整数 n 为 12.

# 三、求满足条件的参数的最值

与数列有关的参数最值问题,通常出现在含参数列不等式的恒成立问题中,解答这类问题可仿照函数不等式恒成立问题处理,一般可采用参变量分离法,最终转化为数列的最值问题,即转化为 $\lambda>f(n)_{\max}$ 或 $\lambda<f(n)_{\min}$ ( $\lambda$ 为参数),有时还需要对n的奇偶性加以讨论,如出现 $\lambda<(-1)^{n}f(n)$ 时.

例 3 已知等差数列 $\{a_{n}\}$ 的通项公式为 $a_{n}=n$ ，前 n 项和为 $S_{n}$ ，若不等式 $2S_{n+1}\leqslant M(n+a_{32})a_{n+2}^{2}(n\in\mathbf{N}^{*})$ 恒成立，则 M 的最小值为 \_\_\_\_.

解析：根据已知条件得， $S_{n}=\frac{n(n+1)}{2}\Rightarrow$ $2\frac{(n+1)(n+2)}{2}\leqslant M(n+32)(n+2)^{2}$ 恒成立，即 $\frac{n+1}{(n+32)(n+2)}\leqslant M$ 恒成立.

设 $t = n + 1$ ，于是有 $\frac{n + 1}{(n + 32)(n + 2)} = \frac{t}{(t + 31)(t + 1)} = \frac{t}{t^2 + 32t + 31} = \frac{1}{t + \frac{31}{t} + 32}.$

因为函数 $t + \frac{31}{t}$ 在 $(0, \sqrt{31})$ 上单调递减，在 $(\sqrt{31}, +\infty)$ 上单调递增，又 $f(5) = \frac{56}{5}$ ， $f(6) = \frac{67}{6} < \frac{56}{5}$ ，所以 $t + \frac{31}{t} + 32 \geqslant 43 \frac{1}{6} = \frac{259}{6}$ ，所以 M 的最小值是 $\frac{6}{259}$ .

# 四、有关数列的其他最值问题

与数列有关的其他最值问题,一般出现在数列与其他数学知识综合的问题中,如数列与基本不等式的综合、数列与函数的综合,数列与三角函数的综合等.求解这类问题的基本策略与求函数的最值问题一致,只需注意等号取到时 n 是否取到正整数,否则对 n 的取值进行适当调整,通过比较第 n-1 项与第 $n+1$ 项的值的大小来确定相关最值.

例 4 设 $\triangle A_{n}B_{n}C_{n}$ 的三边长分别为 $a_{n}, b_{n}, c_{n}, n = 1, 2, 3, \cdots$ ，若 $b_{1} > c_{1}, b_{1} + c_{1} = 2a_{1}, a_{n+1} = a_{n}, b_{n+1} = \frac{a_{n} + c_{n}}{2}, c_{n+1} = \frac{a_{n} + b_{n}}{2}$ ，则 $\angle A_{n}$ 的最大值是 \_\_\_\_.

解析:由 $b_{n+1}=\frac{a_{n}+c_{n}}{2}, c_{n+1}=\frac{a_{n}+b_{n}}{2}$ ，得 $b_{n+1}+c_{n+1}=\frac{a_{n}+c_{n}}{2}+\frac{a_{n}+b_{n}}{2}=\frac{1}{2}(b_{n}+c_{n})+a_{n}$ ，又 $a_{n+1}=a_{n}=a_{1}$ ，所以 $b_{n+1}+c_{n+1}-2a_{1}=\frac{1}{2}(b_{n}+c_{n}-2a_{1})$ ，而 $b_{1}+c_{1}=2a_{1}$ ，所以 $b_{n}+c_{n}=2a_{1}$ ，故 $\cos A_{n}=\frac{b_{n}^{2}+c_{n}^{2}-a_{n}^{2}}{2b_{n}c_{n}}=\frac{(b_{n}+c_{n})^{2}-a_{n}^{2}-2b_{n}c_{n}}{2b_{n}c_{n}}=\frac{3a_{1}^{2}}{2b_{n}c_{n}}-1\geqslant\frac{3a_{1}^{2}}{2\left(\frac{b_{n}+c_{n}}{2}\right)^{2}}-1=\frac{3a_{1}^{2}}{2a_{1}^{2}}-1=\frac{1}{2}$ 。所以 $\angle A_{n}$ 的最大值是 $\frac{\pi}{3}$ 。

以上四类数列的最值问题,在数列试题中最为常见.从上述四个例题的分析,我们不难发现,它的基本解题策略就是转化为函数问题或不等式问题.所以说,函数思想和不等式的恰当转化,是解决这类问题最基本的方法,我们必须掌握.F
