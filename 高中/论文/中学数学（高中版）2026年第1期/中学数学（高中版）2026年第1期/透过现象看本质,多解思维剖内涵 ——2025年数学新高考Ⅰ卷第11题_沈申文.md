# 1 真题呈现

(2025年数学新高考Ⅰ卷第11题)(多选题)已知 $\triangle ABC$ 的面积为 $\frac{1}{4}$ ,若 $\cos 2A+\cos 2B+2\sin C=2$ , $\cos A\cos B\sin C=\frac{1}{4}$ ,则().

$$
\mathrm{A.} \sin C = \sin^ {2} A + \sin^ {2} B \quad \mathrm{B.} A B = \sqrt {2}
$$

$$
\mathrm{C.} \sin A + \sin B = \frac {\sqrt {6}}{2} \quad \mathrm{D.} A C ^ {2} + B C ^ {2} = 3
$$

该题以解三角形为问题场景,借助三角形中三内角所满足的两个三角关系式 $\cos 2A + \cos 2B + 2\sin C = 2$ , $\cos A \cos B \sin C = \frac{1}{4}$ , 以及三角形的面积数值,通过三角形三内角的关系式判断、线段的长度确定及线段的关系式等为选项来设计,借助多选题的设置来综合与应用.

# 2 真题破解

解决问题的关键在于从三角关系式 $\cos 2A +$ $\cos 2B+2\sin C=2$ 切入,由此转化并得到对应的关系式 $\sin C=\sin^{2}A+\sin^{2}B$ ,并通过不同的数学思维方式与解题技巧、方法,分析并探究 $C=\frac{\pi}{2}$ ,为进一步结合相关条件分析与判断对应的选项创造条件.

本题数学思维的发散就在于基于三角关系式 $\sin C=\sin^{2}A+\sin^{2}B$ ，从相关的思维方式切入与应用，采用反证法，或三角恒等变换法，或分类讨论法解决问题. $C=\frac{\pi}{2}$ 的确定，成为问题突破与解决的重要节点.

解法 1: 反证法.

由 $\cos 2A + \cos 2B + 2\sin C = 2$ ，结合二倍角公式可得 $1 - 2\sin^2 A + 1 - 2\sin^2 B + 2\sin C = 2$ ，整理可得 $\sin^2 A + \sin^2 B = \sin C$ ，故选项A正确.

利用正弦定理可得 $a^2 + b^2 = \frac{c^2}{\sin C} \geqslant c^2$ ，当且仅当 $\sin C = 1$ ，即 $C = \frac{\pi}{2}$ 时等号成立.

利用余弦定理可得 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}\geqslant0$ , 可得 $0<C\leqslant\frac{\pi}{2}$ .

若 $0 < C < \frac{\pi}{2}$ , 则 $A + B > \frac{\pi}{2}$ , 即 $A > \frac{\pi}{2} - B$ , 可得 $\sin A > \sin \left( \frac{\pi}{2} - B \right) = \cos B$ , 由此 $\sin C = \sin^2 A + \sin^2 B > \cos^2 B + \sin^2 B = 1$ , 这与 $0 < \sin C < 1$ 矛盾, 所以 $C = \frac{\pi}{2}, B = \frac{\pi}{2} - A$ .

结合 $\cos A \cos B \sin C = \frac{1}{4}$ ，可以得到 $\cos A \cdot$

$\cos\left(\frac{\pi}{2}-A\right)=\frac{1}{4}$ ，即 $\cos A \sin A=\frac{1}{4}$ .

所以 $S_{\triangle ABC}=\frac{1}{2}ab\sin C=\frac{1}{2}ab=\frac{1}{4}$ ，即 $ab=\frac{1}{2}$ ，则 $ab=c\sin A\cdot c\cos A=c^{2}\sin A\cos A=\frac{1}{4}c^{2}=\frac{1}{2}$ ，解得 $c^{2}=2$ ，即 $AB=\sqrt{2}$ ，故选项 B 正确.

由 $C = \frac{\pi}{2}, B = \frac{\pi}{2} - A, (\sin A + \sin B)^2 = \left[\sin A + \sin \left(\frac{\pi}{2} - A\right)\right]^2 = (\sin A + \cos A)^2 = 1 +$ $2\sin A\cos A=\frac{3}{2}$ ，解得 $\sin A+\sin B=\frac{\sqrt{6}}{2}$ ，故选项 C 正确.

结合 $C=\frac{\pi}{2}$ ，利用勾股定理，有 $AC^{2}+BC^{2}=AB^{2}=2$ ，故选项 D 错误.

故选择答案: ABC.

点评:该解法中,利用余弦定理得到 $0 < C \leqslant \frac{\pi}{2}$ , 而通过条件 $0 < C < \frac{\pi}{2}$ 下三角关系式的变形与转化, 利用三角函数的单调性及相关的三角关系式, 得到相应矛盾的结论, 利用反证法思维可知该条件不成立, 由此得到 $C = \frac{\pi}{2}$ .

解法 2: 三角恒等变换法.

同解法 1 得选项 A 正确.

而 $\sin^{2}A + \sin^{2}B = \sin C \geqslant \sin^{2}C$ ，当且仅当 $\sin C = 1$ ，即 $C = \frac{\pi}{2}$ 时等号成立，进而结合正弦定理有 $a^{2} + b^{2} \geqslant c^{2}$ .

利用余弦定理, 可得 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} \geqslant 0$ , 可得 $0 < C \leqslant \frac{\pi}{2}$ .

由 $\cos A\cos B\sin C=\frac{1}{4}>0$ , 可知 A, B 为锐角.

由 $\cos 2A + \cos 2B + 2\sin C = 2$ ，可以得到 $\cos [(A + B) + (A - B)] + \cos [(A + B) - (A - B)]+$ $2\sin C = 2$ ，展开并整理可得 $\cos (A + B)\cos (A - B)+$ $\sin C = 1$ ，则 $\sin C = 1 + \cos C\cos (A - B)\geqslant 1$ ，又因为 $\sin C\leqslant 1$ ，所以 $\sin C = 1$ ，即 $C = \frac{\pi}{2},B = \frac{\pi}{2} -A.$

以下同解法 1, 可知选项 B 正确, 选项 C 正确, 选项 D 错误.

故选择答案: ABC.

点评:该解法中,由 $2A=(A+B)+(A-B)$ ,

$2B=(A+B)-(A-B)$ 来拆分,利用两角和与差的三角恒等变换公式来转化与应用,并利用两个不同不等式中等号成立的条件来确定,得以求解 $C=\frac{\pi}{2}$ .

解法 3: 分类讨论法.

同解法 1 得选项 A 正确.

$\sin^{2}A+\sin^{2}B=\sin C=\sin(A+B)=\sin A\cos B+\cos A\sin B$ ，整理可得 $\sin A(\sin A-\cos B)=\sin B\cdot(\cos A-\sin B)$ .

因为 $\sin A > 0, \sin B > 0$ ，所以 $\sin A - \cos B$ 与 $\cos A - \sin B$ 同号或同时为 0.

若 $\left\{\begin{aligned}\sin A-\cos B>0,\\ \cos A-\sin B>0,\end{aligned}\right.$ 则可得 $\left\{\begin{aligned}\sin A>\cos B,\\ \cos A>\sin B,\end{aligned}\right.$ 以上两不等式两边平方并同向相加有 1>1，显然矛盾；

若 $\left\{\begin{aligned}\sin A-\cos B&<0,\\ \cos A-\sin B&<0,\end{aligned}\right.$ 则可得 $\left\{\begin{aligned}\sin A<\cos B,\\ \cos A<\sin B,\end{aligned}\right.$ 以上两不等式两边平方并同向相加有 1<1，显然矛盾；

若 $\sin A - \cos B = \cos A - \sin B = 0$ ，则 $A + B = \frac{\pi}{2}$ ，符合题意，所以 $C = \frac{\pi}{2}$ ， $B = \frac{\pi}{2} - A$ 。

以下同解法 1, 可知选项 B 正确, 选项 C 正确, 选项 D 错误.

故选择答案: ABC.

点评:该解法中,利用两角和的正弦公式加以合理展开,并通过三角关系式的拆分与转化,推理得到 $\sin A-\cos B$ 与 $\cos A-\sin B$ 同号或同时为零,进而借助不同取值情况来合理分类讨论,并讨论在对应取值条件下是否成立,从而确定 $C=\frac{\pi}{2}$ .

# 3 变式拓展

变式 已知在 $\triangle ABC$ 中, 满足 $\cos 2A + \cos 2B + 2\sin C = 2$ (或 $\sin^{2}A + \sin^{2}B = \sin C$ ), 求证: $C = \frac{\pi}{2}$ .
