# 1 解题教学的现状与问题

解题教学在中学课堂中的比重较大,其作用和价值影响深远.笔者观察和访谈了很多老师和学生,发现在数学解题教学中,往往关注技能和技巧,通过大量“刷题”来巩固各种技巧,这样的教学带来的弊端初见端倪.

很多学生虽然经过高三长期复习,做了大量的习题,然而迁移和应用能力堪忧,尤其惧怕新题型,面对表面上从未做过的题目就“缴械投降”.为什么会出现这些现象呢?归根到底源于教学过于注重解题技巧,而忽视了思想方法层面的感悟和提炼,更缺乏哲学观念上的启发.理念是行动的先导,没有理念的指引,就没有指导学生解决难题的思想武器,这在一定程度上影响了教学实效.

# 2 对立统一原理与数学解题教学

对立统一原理是唯物辩证法的实质和核心,揭示了事物内部及事物之间的对立统一关系,这是事物联系和发展的根本动力.这种规律从根本上解释了事物为什么会发展,即事物内部的矛盾性是推动其发展的根本原因.

恩格斯说：“有了变数，运动进入了数学，有了变数，辩证法进入了数学。”列宁也有类似的观点，“高等数学的主要基础之一，就是矛盾，就是初等数学，也充满着矛盾”。何为解题教学中的矛盾？以三角恒等变换为例，大量的习题中充斥着差异，如函数名称的差异，单角和倍角的差异，幂指数的差异，这些差异的本质就是矛盾。

从差异的视角看矛盾,解题教学中存在着大量的矛盾.首先是已知与未知的矛盾,其次从知识类型看,同一问题中可能有函数与方程的矛盾、函数A与函数B的矛盾、超越函数与代数函数的矛盾等.从更上位的视角看,同一问题中还有结构形式的矛盾(如和与积）、数与形的矛盾、整体与局部的矛盾、一般与特殊的矛盾、有限与无限的矛盾、归纳与演绎的矛盾……

一切数学问题的解决,本质就是处理上述所谈的各种矛盾,将已知和未知关联起来,最终实现从对立到统一,矛盾统一即问题解决.

# 3 对立统一原理应用案例

案例 1 “ $2a+3b>0$ ”是“ $\forall x\in(0,1)$ ，总有 $ax+b>0$ ”的（）.

A. 充分非必要条件  
B. 必要非充分条件  
C. 充分必要条件  
D.既非充分也非必要条件

分析: 案例 1 中已知和结论都是以不等式的形式呈现的, 这是“统一”的一面; 但是仔细辨识发现, 不等号左侧存在“ $2a+3b$ ”和“ $ax+b$ ”形式的差异, 这是“对立”的一面. 如何消除这种对立, 构造函数 $f(x)=ax+b$ 能否将“对立”统一在函数观点之下呢?

发现无论 $x(0<x<1)$ 取何值，函数值都不等于 $2a+3b$ ，于是将 $2a+3b>0$ 进行等价转化得到 $\frac{2}{3}a+b>0$ ，而 $f\left(\frac{2}{3}\right)=\frac{2}{3}a+b$ ，这样借助函数将对立双方统一起来。显然 $f\left(\frac{2}{3}\right)>0$ ，对于 $\forall x\in(0,1)$ ， $f(x)$ 未必都大于 0，而对于 $\forall x\in(0,1)$ ， $f(x)>0$ ，必有 $f\left(\frac{2}{3}\right)>0$ 。故选择：B.

案例2 已知 $f(x) = \sin \left(x - \frac{\pi}{4}\right), g(x) = \cos x, h(x) = f(x) + \sqrt{2}g(x)$ ，若关于 $x$ 的方程 $f\left(x + \frac{\pi}{4}\right)g(x) + kh(x) = 0$ 在 $x \in \left[0, \frac{\pi}{2}\right]$ 上有解，求实数 $k$ 的取值范围.

分析: 先将问题条件进行综合, 得到 $h(x)=$

$f(x)+\sqrt{2}g(x)=\frac{\sqrt{2}}{2}(\sin x+\cos x)$ ，由 $f\left(x+\frac{\pi}{4}\right)\cdot g(x)+kh(x)=0$ ，转化为 $\sin x\cos x+\frac{\sqrt{2}k}{2}(\sin x+\cos x)=0$ 在 $x\in\left[0,\frac{\pi}{2}\right]$ 上有解，参变分离得到 $\sqrt{2}k=\frac{-2\sin x\cos x}{\sin x+\cos x}$ ，若尝试对右侧函数进行求导处理，则过于繁琐且不易解决.

观察发现方程 $\sqrt{2} k = \frac{-2\sin x\cos x}{\sin x + \cos x}$ 中存在两种函数——正弦和余弦，两种结构——积与和，即存在两种差异，存在对立的两类事物，统一函数名称显然有些复杂，统一结构成为优先选项.

借助什么工具实现结构统一呢？

想到公式 $(\sin x + \cos x)^2 = 1 + 2\sin x\cos x$ ，于是得到 $2\sin x\cos x = (\sin x + \cos x)^2 -1$ ，所以 $\sqrt{2} k = \frac{1 - (\sin x + \cos x)^2}{\sin x + \cos x}$ ，从而实现了结构上的统一.再利用整体思想，令 $t = \sin x + \cos x$ ，将问题转化为 $\sqrt{2} k = \frac{1}{t} -t$ 在 $t\in [1,\sqrt{2} ]$ 上有解.由函数 $y = \frac{1}{t} -t$ 在 $t\in$ $[1,\sqrt{2} ]$ 上单调递减，进而得到 $k\in \left[-\frac{\sqrt{2}}{2},0\right].$

该案例中本质上存在两类矛盾,一类是结构差异造成的矛盾,另一类是复杂与简洁的矛盾,借助公式 $(\sin x+\cos x)^{2}=1+2\sin x\cos x$ ,实现了结构的统一,借助整体换元思想,实现了复杂与简洁的统一.

案例 3 已知一个圆台的轴截面面积为 6，轴截面的一个底角为 $30^{\circ}$ ，则这个圆台的侧面积是（）.

A. $6\sqrt{3}\pi$

B. $12\pi$

C. $2\sqrt{3}\pi$

D. $2\pi$

分析: 这是一道选择题, 如何追求效益最大化呢? 从对立统一的观点看问题, 圆台和圆锥是可以互相转化的, 当圆台的上底面收缩成一点时, 圆台就演变为圆锥, 可见此问题虽然研究的是圆台问题, 但是把圆台看成是上底面面积为 0 的圆锥, 是不影响问题解决的, 从而简化了问题.

设该圆锥底面半径为 r，高为 h，由轴截面的一个底角为 $30^{\circ}$ ，可知 $r = \sqrt{3}h$ ，由轴截面面积为 6，得 $\frac{1}{2} \times 2r \times h = 6$ ，也即 rh = 6，所以圆锥的侧面积 $S = \pi rl = \pi r \sqrt{r^{2} + h^{2}} = 2\pi rh = 12\pi$ 。故选择答案：B.

该案例没有直接求解圆台问题,基于对圆台和圆锥是两类有既有差异又有联系的图形的认识,巧妙借助极限思想,将圆锥和圆台统一起来,从而简化了运算过程,可见对立统一是普遍存在的,关键要有辩证思维的意识.

案例 4 $\forall m\in[-2,2]$ ，不等式 $x^{2}+mx+1>2x+m$ 恒成立，求实数 x 的取值范围.

分析: 将已知不等式进行等价转化, 即 $\forall m \in [-2, 2]$ , $x^{2} + mx - 2x - m + 1 > 0$ 恒成立, 表面上是不等式问题, 实际上可以进一步转化为函数问题.

题目存在两个变量 x 和 m，选择以 x 为主元构造函数，还是选择以 m 为主元构造函数，存在主元和辅元的差异（对立），思维惯性上往往不假思索地选择以 x 为主元构造函数 $f(x)=x^{2}+mx-2x-m+1$ ，然后对 m 进行分类讨论，但这个方案比较繁琐。

若以 m 为主元构造函数 $g(m)=(x-1)m+x^{2}-2x+1$ ，当 x=1 时，显然不符合题意，所以 $g(m)$ 是关于 m 的一次函数，只要满足 $g(-2)>0, g(2)>0$ 即可，解得 x>3 或 x<-1.

该案例中存在主元和辅元的对立,选择两种不同的函数会带来复杂和简洁的差异,从辩证的视角看待问题,抓住主要矛盾,实现了以简驭繁的目的.从对立统一的视角看,条件和结论之间存在显著差异,借助一次函数调和了条件和结论之间的对立,从而解决了问题.

# 4 反思与总结

对立统一原理的普遍性在于它适用于各个领域和层面,无论是自然界、社会领域还是思维领域,都能够体现出对立面的相互依存和相互转化,推动事物的发展和进步.

在数学解题教学中,应用对立统一原理的关键是抓住差异,在某种意义上而言,差异即矛盾.问题中存在形形色色的差异需要关注,微观上既要关注条件与结论之间的差异,也要关注条件之间的差异,中观上要关注结构上的差异,宏观上要关注思想方法之间的差异,善于在整体与部分、一般与特殊、数与形、有限与无限等差异中寻找连接点,转化这些差异,就是在对立与矛盾中寻求统一.另外,数学问题中可能存在多种对立因素,还要能够抽丝剥茧,发现主要矛盾,事物的性质是由主要矛盾决定的,抓住主要矛盾方能高效解决问题.

解题技巧是要有的,而且要熟练运用.但是只有解题技巧而没有思想武器,就会在技巧丛林中迷失方向,用辩证法武装学生的头脑是解决上述问题的重要利器! Z
