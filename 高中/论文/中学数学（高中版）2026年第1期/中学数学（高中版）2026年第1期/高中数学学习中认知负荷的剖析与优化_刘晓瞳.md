# 高中数学学习中认知负荷的剖析与优化

# ● 哈尔滨师范大学教师教育学院 刘晓瞳

摘要:首先介绍负荷一词的来源,说明认知负荷一词的分类,并基于认知负荷理论分析学生在高中数学学习过程中遇到的认知负荷.然后通过具体例子对高中生学习所产生的认知负荷进行分析,说明认知负荷理论对高中数学教学的重要作用.最后根据学生在学习过程中不同负荷的来源提出优化学生认知负荷的相关策略,为未来更多教学模式提供新视角.

关键词: 负荷; 认知负荷; 数学教学; 优化策略

# 1 认知负荷理论背景

# 1.1 认知负荷的来源

负荷一词在古籍中早有记载，《左传·昭公七年》中有：“其子弗克负荷。”这里的负荷有“背负、肩担”的意思。《浣纱记·送饯》中有：“扁舟北济，痛黎民负荷有谁？”这里负荷解释为承担的压力和痛苦。在人类社会中，各方面研究都存在着负荷，如：电力负荷、计算负荷、心理负荷等。本文中研究的是负荷与教育心理学和认知科学的结合体，即认知负荷。简单来说，认知负荷是指在处理信息时，大脑所承担的认知任务量，这里的任务量是指人们在进行思考、学习、解决问题和记忆等活动时所需的注意力、工作记忆和处理能力。

# 1.2 认知负荷的分类

在学习活动中,学习者产生的认知负荷是由不同方面共同影响的,是多个不同类型的认知负荷的总和.研究者们认为学生认知负荷的主要来源有很多,如学习材料的复杂程度、学习者原有的知识储备、学习材料的呈现方式等.但学习者的认知负荷总量是有限的,将来自各方面的认知负荷归纳处理能够有效提升学习者的学习能力.所以,“Sweller等人根据认知负荷不同来源的性质,将学习者在学习中产生的认知负荷分为内在认知负荷、外在认知负荷以及相关认知负荷,三种认知负荷的和就构成了认知负荷总量.”[1]

# (1) 内在认知负荷

内在认知负荷是由学习材料本身引起的,学习材料越复杂,学习材料的知识体系越完整,对学习者的知识经验要求就越高,增加了学习者的内在认知负荷.反之,相对于简单的学习材料所引发的认知负荷相对较少.但是,学生的先前经验与认知负荷并不是呈正相关的关系,运用迁移理论来解释,就是要促使先前的知识经验对学习者的认知产生正向迁移,才能有效减少学生的内在认知负荷.

# (2)外在认知负荷

外在认知负荷是由于信息的呈现形式以及学习

者对学习活动的需求造成的.这里的学习活动需求包括知识获取需求、学习方式需求、学习动力需求，如学习内容的准确度和深度、知识的系统性和完整性、学习活动的趣味性以及个性化的学习节奏.通常，当教学传递方式不正确，或教学环节设计不合理时，外部认知负荷就会明显增加，因此这种负荷被视为“无效认知负荷”.此外，在学习过程中，学习者还需要投入其他的时间和精力处理信息的呈现方式，如数学语言的呈现有歧义或难以理解，就会增加学生的外在认知负荷，学习效率就会降低.所以，教师需要利用现代教学设备，满足学生的学习方式需求，使课堂更具吸引力，做到有效控制影响学生的外在负荷因素，减少学习者外在认知负荷的产生，使得学习者能高效利用已有的学习资源，达到外在负荷的最小化.所以教学的传递方式显得尤为重要，在设计教学环节时，要注意数学语言的表征方式，也就是要选取简洁易懂的数学语言的呈现方式.数学语言表征方式的多样性，也影响着学生的外在认知负荷的产生.因此，教师运用好数学对象的表征方式是有效减少学生外在认知负荷的手段.此外，影响外在认知负荷的因素也有很多，不同性别、不同年级的学习者也有显著差别[2].

# (3) 相关认知负荷

Sweller 等认为，“相关认知负荷并不是由学习材料引起的，相关认知负荷是指学习者在完成一项任务时，把没使用完的认知资源转移到与之相关的信息处理过程中所产生的认知负荷。”[3] 学习者头脑中的认知资源是有限的，内在和外在认知负荷会占用大量有限的工作记忆资源，导致学习者没有剩余的认知资源去进行能产生相关认知负荷的深度加工。因此，增加学习者相关认知负荷至关重要。所以，想要优化学生的认知负荷，需适当降低内在认知负荷和外在认知负荷所占的认知资源，增加相关认知负荷比例，使增加的相关负荷能落在学生的已有经验的基础上，帮助学生构建相应的图示，从而提高学习者的学习水平。

# 2 认知负荷理论对教学的作用

“认知负荷理论是由澳大利亚认知心理学家约翰·斯威勒(John Sweller)于1988年首先提出来的，它以Miller等人早期的研究为基础。”[4]认知负荷理论为教学的优化提供了理论基础.自认知负荷理论提出以来，国内外学者进行了大量的实证研究，探索其在不同学习情境下的应用效果.认知负荷理论在教学中有非常重要的作用，主要呈现在以下几个方面：

# 2.1 教学内容的呈现

利用认知负荷理论合理组织教学内容结构,教师可以按照学生的认知规律来组织教学内容.比如:在讲解立体几何这一单元知识时,引导学生回顾以往学过的简单几何体,回忆平面几何中各元素之间的关系,再逐步过渡到复杂几何元素间的位置关系.让学生从不同角度学会将几何体分类,培养学生逻辑推理、空间想象等核心素养,从而让学生关注几何体的线、面各元素之间的位置关系,从而减少学生的内部认知负荷.除此,教学内容的呈现还要突出关键信息:运用不同的字体、颜色、字号等来突出重点性质.例如:在函数单调性的习题中,首先要求出函数定义域,再根据函数单调性的定义判断函数的单调性,因此在讲授函数单调性的定义时,要对“函数 $f(x)$ 的定义域为 D”作特殊标记,让学生能将认知资源集中在关键信息上,从而降低外部认知负荷.

# 2.2 教学方法的选择

教学时可以引用样例教学法,样例教学法的核心是通过向学生提供具有代表性的例子,帮助他们学习新知识、新技能或者解决问题.在样例中,通常会展示完整的解题步骤、操作流程或者任务完成过程.如:求函数 $y=\ln(x-3)+\sqrt{x+7}$ 的定义域.向学生展示步骤,令对数函数中 x-3>0,同时令偶次根号下的式子 $x+7\geqslant0$ ,综合两个条件,取交集,得到函数的定义域为 $\{x|x>3\}$ ;学生通过这个样例可以学会分别考虑函数中不同部分对函数定义域的要求来确定最终定义域的方法.除样例教学法外,还可以采用小组合作学习等方法,学生在小组中分工合作,分担认知任务,每个成员所承担的认知负荷就会降低,同时还能通过交流讨论整合信息.

# 2.3 学习效果的提升

认知负荷理论有利于促进知识的长期保持即有利于将短时记忆转化为长时记忆.通过合理控制认知负荷,学生能够更好地将知识整合到长时记忆中.例如:在学习完三角函数和向量的加法法则后,可以帮助学生按照逻辑体系梳理向量的相关概念及运算法则,使学生能够有效建立知识图式,在后续学习正弦定理和余弦定理时能更方便从长时记忆中提取相关知识.同时认知负荷理论还能增强学生学习的迁移能力:当学生在合适的认知负荷下学习知识时,更容易将所学知识迁移到新的情境中.比如:在学习了向量的三角形法则和平行四边形法则之后,能够将这些知识应用到物理学中力的分解与合成的学习中,也有助于学科之间的融合与交叉.

# 3 优化认知负荷的策略

# 3.1 提升学生的学习能力

在高中阶段,学生面临着复杂抽象的数学内容,所以提升学生的数学学习能力是有效降低内在负荷的有效措施,而学生的学习能力与学生的元认知、学习效率有着密不可分的联系.最早对数学元认知进行研究的是美国弗吉尼亚大学的乔·加罗法洛 $^{[5]}$ ,他认为数学元认知需要有意识地进行,学习者在数学活动的过程中对自己的行为要进行有意识的控制和调节,提高数学元认知能力也有利于减少相应的认知障碍,提高自我调节和自我监控的能力,减少无用信息的积累,提高学习效率,达到夯实基础、巩固提升、减少内在认知负荷的目的.

# 3.2 提高教师的教学水平

外在认知负荷大部分来源于教学设计环节不合理,教学层次不鲜明,教学手段单一,所以对于教师来说,应提升有效教学方式.课堂的呈现应分为明线和暗线两大主线同时进行,明线即教学内容按照知识的逻辑顺序,有条理、有程序地逐步呈现.暗线为贯穿整堂课的数学研究思路和思想方法,以及学生数学核心素养的培养,这就要求教师对每个环节的设计要臻于至善,用最简练的语言提炼最精炼的内容和方法,从而减少外在的无效认知负荷,使得认知负荷总量小于学生头脑的记忆总量,有效避免出现认知负荷过载的现象.所以有的学者认为,翻转课堂教学模式之所以能推动深度学习,是因为其自身的教学模式、结构化的任务设计和信息技术的支持,能够在一定程度上控制认知负荷在合理的范围内.

# 3.3 分解教学资料,寻找学习材料的关联性,提高相关认知负荷

教师可以通过合理组织教学内容,将复杂的知识分解为较小的、相互关联的小单元.例如:在导数中,对于复杂的导数综合问题,把函数性质、图象和导数性质的各个元素按逻辑关系逐步呈现,避免学生在面对综合题型时由于两部分知识相互关联的较多而产生交错混乱的现象,通过梳理两部分知识的逻辑结构使知识更易被学生理解和吸收.同时,也要注意教学材料的呈现方式,尽可能减少无关信息的干扰.而教学材料的呈现方式与学生的年龄特征有关,比如针对高中生,在设计数列单元课件时,设计对比栏、类比板块、双向箭头、将数列单元的通项公式与一次函数进行对比学习.如果是文字材料,在使用简单易懂的语言来表述,避免出现句子歧义的现象.如果教学对象是较低年级的学生,可以设计一些活动的、具体的或者动画形式的教学材料吸引学生.

由于高中的数学内容以板块模式呈现,导致学生容易忽略知识之间的联系,相关认知负荷过低.比如在做函数部分的习题时,会出现求函数最值的问题,但因为当下所学的内容为函数的概念与相关性质,所以大部分学生的思维局限于当下所学的知识范围,而忽略了与前一章不等式知识的联系.所以,应合理安排教学内容,寻找知识间的关联性,引导学生体会学习材料的共同要素,促进新知识的理解与吸收.

综上,认知负荷理论揭示了内在、外在和相关认知负荷对学生学习的影响情况.这一理论在教学实践中能展现出强大的指导价值,通过提升学生学习能力,提高教师有效教学水平,以及分解教学资料、挖掘知识关联性等优化策略,能够科学地优化学生的认知负荷,为学生创造更高效的学习环境.

认知负荷理论为教育领域带来了新的研究视角与实践方法,随着教育环境的不断变化和学习需求的日益多元化,该理论仍有广阔的发展空间.未来,还需进一步探索其在不同学科、不同学习阶段以及新兴教学模式中的应用,以持续完善和拓展这一理论体系,为教育教学改革提供更坚实的理论支撑与实践指导.

# 3 教学反思

# 3.1 体系的连贯性与数学视野的拓展

任何一个新内容都应该讲一下知识之间的联系，以及这些新概念从何而来，有什么用，学什么，怎么学。本节课在开篇就紧扣核心，对其进行简要介绍，以便让学生对此有个大致的了解。这样的教学方式能够帮助学生更好地理解和掌握数列的概念，为后续学习打下坚实的基础，这是其一。其二，数学教育不能仅是培养学生解题能力，还应拓展学生数学视野。基于这种想法,本节课选择了三个极具代表性的例子,涉及国学的“一尺之棰,日取其半,万世不竭”、毕达哥拉斯学派的形数、极具影响力的斐波那契数列.其三,本节课的难点不是数列的定义,而是数列相关符号的理解.基于此,本节课设置了“知识的深层次理解”这一环节,抓住学生的问题所在,突破难点.

# 3.2 注重知识的背景,渗透思想、发展能力

“数学的产生和发展,始终与人类社会的生产、生活有着密不可分的联系.任何一个概念的引入,总有它的现实或数学理论发展的需要.”因此,在新授课时,我们务必要阐明知识的深厚背景与广泛应用价值,让学生深刻理解数学概念、方法及思想的自然起源与合理发展.特别是章节起始课,更应清晰揭示知识的诞生历程、背景故事,并巧妙融入数学思想,旨在提升学生的特定能力.

华东师范大学崔允漷教授精炼地概括了“好课”的三大标准:教学高效、学习愉悦、考核理想.本节课正是这一理念的生动实践,不仅激发了学生的学习兴趣,还确保了教学的有效性.所选例题与练习,均兼具代表性与深度,旨在锤炼学生的抽象数学思维,同时培养其分析、观察与归纳的综合能力.
