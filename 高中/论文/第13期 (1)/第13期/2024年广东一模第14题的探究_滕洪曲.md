# 2024 年广东一模第 14 题的探究

# 山东省威海市第二中学 滕洪曲

涉及直线与圆锥曲线的综合问题,问题设置形式创新多变,经常融入“动”与“静”之间的变化与转化过程,这其中巧妙融合了“动点”与“定点”的变形转化、“常值”与“最值”的合理过渡.而此类“动”“静”结合创新问题,同时兼备“数”的本质属性与“形”的几何特征,可以较好全面考查学生的“四基”与“四能”,具有较高的区分度,是培养数学核心素养的一个重要载体.

# 1 问题呈现

问题 已知直线 l 与椭圆 $C: \frac{x^{2}}{3} + \frac{y^{2}}{2} = 1$ 在第一象限交于 P, Q 两点, l 与 x 轴, y 轴分别交于 M, N 两点, 且满足 $\frac{|PM|}{|QM|} + \frac{|QM|}{|PM|} = \frac{|PN|}{|QN|} + \frac{|QN|}{|PN|}$ , 则 l 的斜率为 \_\_\_\_.

此题以“动”直线与“定”椭圆之间的位置关系为问题情境来合理创设，结合“动”直线所对应的四个“动”点所满足的“定值”比例式，进而确定“动”直线的斜率问题。“动”中取“静”，“动”“静”结合，构勒出一幅完美的画卷，成为一道典型解析几何题，值得好好品鉴与深入探究。

实际解答时,我们可以尝试从直接思维、特殊思维以及函数与方程思维等视角切入,在各自不同思维场景下,抓住问题的实质来合理发散思维,由此展开各自精彩的数学思维与技巧方法,实现问题的突破与解答.

# 2 问题破解

# 2.1 直接思维

解法 1: 齐次化法.

设 $P(x_{1},y_{1}),Q(x_{2},y_{2})$ ，依题 $\frac{|PM|}{|QM|} +\frac{|QM|}{|PM|} =$ $\frac{|PN|}{|QN|} +\frac{|QN|}{|PN|}$ 结合比例性质可得 $\frac{y_1}{y_2} +\frac{y_2}{y_1} = \frac{x_1}{x_2} +\frac{x_2}{x_1}$ 则有 $\frac{y_1^2 + y_2^2}{y_1y_2} = \frac{x_1^2 + x_2^2}{x_1x_2}$ .利用比例性质可得 $\frac{(y_1 + y_2)^2}{y_1y_2} =$ $\frac{(x_1 + x_2)^2}{x_1x_2}$ ，则有 $\frac{(y_1 + y_2)^2}{(x_1 + x_2)^2} = \frac{y_1y_2}{x_1x_2}$ 设线段 $PQ$ 的中

点 $H(x_0, y_0)$ ，则有 $\frac{(y_1 + y_2)^2}{(x_1 + x_2)^2} = \frac{y_1y_2}{x_1x_2} = \frac{y_0^2}{x_0^2}$ .

设直线 PQ 的斜率为 k，由椭圆的“中点弦定理”可得 $k \cdot \frac{y_{0}}{x_{0}} = -\frac{b^{2}}{a^{2}} = -\frac{2}{3}$ ，则 $\frac{y_{1}y_{2}}{x_{1}x_{2}} = \frac{y_{0}^{2}}{x_{0}^{2}} = \frac{4}{9k^{2}}$ .

设直线 PQ 的方程为 $mx + ny = 1$ ，则有 $k = -\frac{m}{n}$ ， $m^{2} = k^{2} n^{2}$ 。将 $mx + ny = 1$ 代入椭圆方程 $2x^{2} + 3y^{2} - 6 = 0$ ，齐次化处理为 $2x^{2} + 3y^{2} - 6 (mx + ny)^{2} = 0$ ，整理可得 $(3 - 6n^{2}) y^{2} + (2 - 6m^{2}) x^{2} - 12mnxy = 0$ ，即 $(3 - 6n^{2}) \left( \frac{y}{x} \right)^{2} - 12mn \cdot \frac{y}{x} + (2 - 6m^{2}) = 0$ 。利用韦达定理得 $k^{2}(2 - 6m^{2}) = \frac{4}{9} (3 - 6n^{2})$ ，即 $k^{2} \left( m^{2} - \frac{1}{3} \right) = \frac{4}{9} \left( n^{2} - \frac{1}{2} \right)$ ，消去 $m^{2}$ ，可得到 $k^{2} \left( k^{2} n^{2} - \frac{1}{3} \right) = \frac{4}{9} \left( n^{2} - \frac{1}{2} \right)$ ，整理可得 $\left( k^{4} - \frac{4}{9} \right) n^{2} = \frac{1}{3} \left( k^{2} - \frac{2}{3} \right)$ ，则有 $k^{2} = \frac{2}{3}$ ，解得 $k = -\frac{\sqrt{6}}{3}$ （依题意，正值舍去）。

所以 l 的斜率为 $-\frac{\sqrt{6}}{3}$ . 故填答案: $-\frac{\sqrt{6}}{3}$ .

解法 2: 韦达定理法(1).

以上部分同解法 1.

设直线 PQ 的方程为 $y = kx + m$ ，代入椭圆 C： $\frac{x^{2}}{3}+\frac{y^{2}}{2}=1$ ，整理有 $(2+3k^{2})x^{2}+6kmx+3m^{2}-6=0.$

由韦达定理，得 $x_{1} + x_{2} = -\frac{6km}{2 + 3k^{2}}, x_{1}x_{2} = \frac{3m^{2} - 6}{2 + 3k^{2}}$ ，则有 $y_{1}y_{2} = \frac{2m^{2} - 6k^{2}}{2 + 3k^{2}}, y_{1} + y_{2} = \frac{4m}{2 + 3k^{2}}.$

所以 $\frac{4}{9k^2} = \frac{y_1y_2}{x_1x_2} = \frac{2m^2 - 6k^2}{3m^2 - 6}$ 整理得 $\frac{2}{3k^2} = \frac{m^2 - 3k^2}{m^2 - 2}$ 则有 $3k^{2} = 2$ ，解得 $k = -\frac{\sqrt{6}}{3}$ （正值舍去）.

余略.

解法 3: 韦达定理法(2).

以上部分同解法 2.

将 $y_{1} + y_{2}, y_{1}y_{2}$ 代入 $\frac{(y_{1} + y_{2})^{2}}{y_{1}y_{2}} = \frac{(x_{1} + x_{2})^{2}}{x_{1}x_{2}}$ ，整

理有 $\frac{16m^{2}}{2m^{2}-6k^{2}}=\frac{36k^{2}m^{2}}{3m^{2}-6}$ ，即 $\frac{2}{m^{2}-3k^{2}}=\frac{3k^{2}}{m^{2}-2}$ ，则有 $3k^{2}=2$ ，解得 $k=-\frac{\sqrt{6}}{3}$ （正值舍去）.余略.

总结:根据直线与椭圆的位置关系,借助直线与椭圆的方程联立,巧妙结合方程的转化,利用韦达定理来变形与转化,是解决此类问题中最为常用的直接思维.而齐次化法以及韦达定理法(1)显得比较繁杂,倒是韦达定理法(2)是解答该问题中比较直接有效的一种严谨逻辑推理方法.而作为填空题,直接思维解决起来显得都比较复杂,有优化与简化的空间.

# 2.2 特殊思维

解法 4: 特殊值法.

借助特殊思维,取 $|QN|=|PM|$ .

设线段 PQ 的中点为 H，则 H 也是 MN 的中点.

设直线 $PQ$ 的方程为 $y = kx + m$ ，可得 $H\left(-\frac{m}{2k}, \frac{m}{2}\right)$ 则有 $k_{OH} = \frac{\frac{m}{2}}{-\frac{m}{2k}} = -k.$ 由椭圆的“中点弦定理”可得 $k \cdot k_{OH} = -\frac{b^2}{a^2} = -\frac{2}{3}$ ，则 $-k^2 = -\frac{2}{3}$ ，即 $k^2 = \frac{2}{3}$ ，解得 $k = -\frac{\sqrt{6}}{3}$ （正值舍去）.余略.

解法 5: 极限思维法(1).

由极限思维可知，点 $P, Q$ 无限接近时，假设 $P, Q$ 两点重合.

结合题设条件 $\frac{|PM|}{|QM|} +\frac{|QM|}{|PM|} = \frac{|PN|}{|QN|} +\frac{|QN|}{|PN|}$ 可知， $P$ （或 $Q$ )是线段 $MN$ 的中点.

设直线 MN 的方程为 $\frac{x}{m} + \frac{y}{n} = 1 (m > 0, n > 0)$ ，可得 P（或 Q）的坐标为 $\left(\frac{m}{2}, \frac{n}{2}\right)$ 。由椭圆的“中点弦定理”可得 $k_{MN} \cdot k_{OP} = -\frac{2}{3}$ ，即 $-\frac{n}{m} \times \frac{\frac{n}{2}}{\frac{m}{2}} = -\frac{2}{3}$ ，即 $\frac{n^{2}}{m^{2}} = \frac{2}{3}$ ，解得 $\frac{n}{m} = \frac{\sqrt{6}}{3}$ （负值舍去）。余略。

解法 6: 极限思维法(2).

设椭圆 C 的右顶点为 A，上顶点为 B，由极限思维可知，点 M 与 P（或 Q）→A，点 N 与 Q（或 P）→B，满足 $\frac{|PM|}{|QM|} + \frac{|QM|}{|PM|} = \frac{|PN|}{|QN|} + \frac{|QN|}{|PN|}$ . 此时 $k_{PQ} =$

$k_{AB}=-\frac{\sqrt{2}}{\sqrt{3}}=-\frac{\sqrt{6}}{3}.$ 余略.

总结:根据直线与椭圆的位置关系,以及其中动点、动直线的变化情况,特殊思维有时也是解决此类小题(选择题或填空题)时比较常用的一种“巧技妙法”.其中特殊值法恰好就是该问题成立时的条件,对于问题的解决尤其快速有效.解法5与解法6中的极限思维就是借助动点与动直线运动变化时所对应的两个极端情况,由极端位置来处理一般性问题,成为解决一般性问题的一种技巧方法,简捷快速.

# 2.3 函数与方程思维

解法 7: 方程法.

不失一般性,不妨设点 P 更靠近点 M, 设 $\frac{|PM|}{|QM|}=$ $\lambda\in(0,1),\frac{|QN|}{|PN|}=\mu\in(0,1).$

结合题设 $\frac{|PM|}{|QM|} +\frac{|QM|}{|PM|} = \frac{|PN|}{|QN|} +\frac{|QN|}{|PN|}$ ，可得 $\lambda +\frac{1}{\lambda} = \frac{1}{\mu} +\mu$ ，整理得 $(\lambda -\mu)\left(1 - \frac{1}{\lambda\mu}\right) = 0.$ 而 $\lambda ,\mu \in$ (0,1)，可得 $\lambda = \mu$ ，所以 $\frac{|PM|}{|QM|} = \frac{|QN|}{|PN|}$ .利用比例性质可得 $\frac{|PM|}{|QM| - |PM|} = \frac{|QN|}{|PN| - |QN|}$ ，则有 $\frac{|PM|}{|PQ|} =$ $\frac{|QN|}{|PQ|}$ ，亦即 $|PM| = |QN|$ .接下来部分同解法4，解得 $k = -\frac{\sqrt{6}}{3}$ .余略

总结:根据直线与椭圆的位置关系,通过线段的比例引入对应的参数,结合函数与方程思维的转化来确定两线段长度相等,这就是以上解法4中的特殊法的严谨推理过程.解法7中的方程法可以巧妙地将题设条件中的关系式加以比例变形,进而确定两线段之间的相等关系,为进一步深入分析与求解奠定基础,也是该方法的亮点之一.
