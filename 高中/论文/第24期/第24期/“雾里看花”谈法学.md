# “雾霾看花” 谈法学

近几年来,文科生报考的热门方向一直集中在金融学、法学、会计学、汉语言文学、财务管理等专业上,法学专业更是文科生报考的热点。本期我们就谈谈什么是法学专业,法学院校及专业方向有哪些,法学的就业领域有哪些,报考该专业要注意什么问题,等等。

# 专业解析:什么是法学?

谈到法学,很多人首先想到的是影视作品中的律师形象。他们是智慧、正义、理想、财富的完美结合,他们唇枪舌剑、口若悬河地守护正义,维护着当事人的利益。不少人当初选择法学专业就是抱着这样的想法。

法学(又称法律学或法律科学)是研究法、法的现象,以及与法相关问题的专门学问,是关于法律问题的知识和理论体系,是社会科学的一门重要学科。

法学本科阶段的学习重在学习一种语言方式,即法律语言。同学们通过学习,了解法的形式是什么,法学的研究方法,法是如何运用和发挥效力的。该专业的主干课程有法理学、宪法学、民法、刑法、中国法律史、商法、知识产权法、经济法、民事诉讼法、行政法与行政诉讼法,以及刑事诉讼法、国际法、国际私法、国际经济法等。

# 法学院校及专业方向

说起法学的院校,不得不提五院四系,五院指的是中国政法大学、华东政法大学、中南财经政法大学、西南政法大学、西北政法大学;四系指的是北京大学法学院、中国人民大学法学院、武汉大学法学院、吉林大学法学院。目前，全国开设法学类专业的高等院校有600多所，其中既包括老牌的法学类院校和开设法学专业的名校，也包括了一些名气虽不大，但法学专业具有一定实力和特色的院校。比如清华大学，民商法是清华法学院最具实力的专业，大师云集，名师荟萃，在民商法领域形成了清华大学与中国社会科学院大学、中国人民大学三足鼎立的格局。再如上海海事大学法学院设有民商法、经济法、国际法、海商法、海上保险法、海事国际私法等，非常符合学校的专业特色。除此之外，像中山大学、厦门大学、复旦大学、浙江大学、南京大学、对外经济贸易大学、云南大学、上海大学、大连海事大学、中国海洋大学、中央民族大学、湖南大学、华中科技大学、安徽大学、郑州大学等院校的法学专业也各具特色。

# 法学专业与就业情况: 报考火爆, 就业遇冷

近几年来,法学专业一直是文科生报考的热门,但据教育部阳光高考信息平台近三年的统计数据显示,该专业的就业率在70%至80%之间,实际就业情况并非与填报志愿时一样“火爆”。

法学专业虽然是文科中的报考热门专业,但毕业生严峻的就业形势在上个世纪末就已显现。由于法学专业投入少成本小,有师资就可以开展教学活动,有条件的学校基本都开设了法学专业。1977年恢复法学教育时,全国只有3所大学设有法律系,每年招收200多人。2001年,全国设有法学本科专业的高等学校为292所,2005年增长到559所,如今全国已有600多所高校开设法学专业。据悉2024年法学专业全国普通高校毕业生超过12万人。

传统观念认为,法学专业毕业的学生,会从事法官、检察官等社会地位高、收入高的职业。因此,很多家长和考生偏爱法学专业,认为毕业后能从事法官、检察官、高校教师等职业。实际上,这些工作对院校背景或学历水平都有相当高的要求。

# 主要就业领域

# 一、公务员

公务员主要包括检察官、法官、行政机关公务员等。由于国家统一法律职业资格考试制度的设立，使得本科生要想成为法官、检察官，必须在毕业后通过法律职业资格考试。“毕业证”绝对不是“职业准入证”。法律职业资格考试可以说是法学专业毕业生最重要的考试，这个考试的过关率在 $30\%$ 左右。当然，毕业生想进入公安机关、检察院、法院这样的单位，除了需要通过法律职业资格考试，还要通过公务员考试。

# 二、律师

律师既不像公务员队伍那样难进,又是法学专业的对口领域,是很多毕业生的主要选择。当然,律师是个经验型行业,收入参差不齐。根据工作经验、能力大小和所涉法律领域的不同,律师的收入有很大差别。目前我国对律师的从业资格采取的是严格准入制度,必须要通过法律职业资格考试。

# 三、公司法务人员

公司法务人员也是目前法学专业毕业生就业较集中的一个领域，主要服务于企业的法律事务部、法律咨询部及知识产权部等。例如，各大国企、银行、外企、一些大型的私企内部都会设法务部门，专门处理企业所涉及的法律事务。还有一部分毕业生供职于政府的法律事务部门，但一般政府部门对学历和工作能力的要求较高，不是普通本科生能达到的。

# 四、其他相关领域

除了以上的主要就业方向,社会其他领域对具有“复合型知识结构”的法律人才也有

需求,如企业中的文秘、人力资源管理、市场营销等岗位对既有经济管理基本知识,又具有法律专业知识的人才较为青睐。一些法学专业毕业生也会从事会计、审计、证券业、环境评估、司法鉴定、职业中介、房地产咨询、法治宣传等工作。

如果你具备以下这些特质,法学或许正是适合你的舞台:1.逻辑清晰,善于思辨;2.热爱阅读,文字表达能力强;3.有正义感和社会责任感;4.性格坚韧,能够承受压力。

当然,也要意识到法学学习需要投入大量时间阅读厚重的文献,通过“天下第一考”的法律职业资格考试更需要持续努力。

选择法学,不仅是选择一份职业,更是承担一份社会责任。于个人层面,法律是维护自身权益的强大武器;于社会层面,法学人才是建设市场经济、维护社会公平的基石;于国家层面,全面依法治国需要大批高素质法学人才。

在改革开放深入和“一带一路”倡议推进的背景下，中国对具有国际视野的法学人才的需求前所未有。从完善市场经济法律体系到应对数字经济挑战，从参与全球治理规则制定到推动社会公平正义，处处都需要法学人才的智慧。

从选择专业方向和就业的角度来说,民商法、经济法都是法学专业中比较好就业的方向。由于法学院校众多,各批次均有开设该专业的院校,同学们在选择院校时要结合自己的实际情况、院校在各省份往年的录取分数、院校招生章程等综合考虑。

亲爱的同学,法学是理性的艺术,是温情的规则,是让社会变得更好的工具。如果你愿意用智慧守护正义,用理性建构秩序,那么法学世界正等待你的到来。这里不仅有职业发展的广阔天地,更有一份“为生民立命,为法治奠基”的时代使命。愿你在这个伟大的时代,找到与自己内心共鸣的方向,在法治中国的宏伟画卷中,描绘一笔属于你的浓墨重彩。
