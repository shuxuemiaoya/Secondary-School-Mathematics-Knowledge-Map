# ——2025年新高考全国Ⅰ卷数学第18题评析

# ■郑州市第七高级中学

2025 年新高考数学试卷在命题理念上进一步更新,强调对数学基础的深化、题型的创新及思维能力的考查。压轴题部分尤其注重综合性、创新性与思维深度,强化对高水平考生的区分与选拔功能。解析几何作为高中数学的核心内容,在培养同学们的逻辑思维与综合能力方面具有不可替代的作用,是高考必考内容之一。2025 年新高考全国 I 卷数学第 18 题以圆锥曲线为背景,突破传统“联立—消元—韦达定理”的解题模式,通过设计具有具体数量关系的三点共线问题,考查同学们的创新思维与综合能力。下面对该题的解法进行深入分析。

# 一、题目呈现

已知椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ 的离心率为 $\frac{2\sqrt{2}}{3}$ , 下顶点为 $A$ , 右顶点为 $B, |AB| = \sqrt{10}$ 。

(1)求椭圆 C 的方程。

(2)已知动点 P 不在 y 轴上, 点 R 在射线 AP 上, 且满足 $\left|AP\right| \cdot \left|AR\right| = 3$ 。

(i) 设 $P(m, n)$ ，求点 R 的坐标（用 m, n 表示）；

(ii)设 O 为坐标原点, Q 是椭圆 C 上的动点, 直线 OR 的斜率为直线 OP 的斜率的 3 倍, 求 $\left|PQ\right|$ 的最大值。

# 二、试题分析

本题以解析几何中的轨迹与最值问题为

# 魏祖新 聂爱琳

载体,第(1)问考查椭圆的基本性质与标准方程的求解,涉及顶点坐标、离心率等基础知识的应用。第(2)问则具有较强的综合性与创新性,要求同学们在动态几何情境中建立代数关系,并通过几何直观与代数运算相结合的方式解决问题。

第(2)(i)问要求根据向量条件确定点 P 的坐标,考查代数运算与几何意义的结合;第(2)(ii)问则通过斜率关系建立约束条件,进一步转化为圆上的点与椭圆上的点的距离的最大值问题,最终通过函数求最值解答,体现了化归与转化思想的应用。

# 三、试题解析与点评

# (一)第(1)问解析

由题意可知 $A(0,-b)$ , $B(a,0)$ , 所以

$$
\left\{ \begin{array}{l} \sqrt {a ^ {2} + b ^ {2}} = \sqrt {1 0}, \\ e = \frac {c}{a} = \frac {2 \sqrt {2}}{3}, \\ c ^ {2} = a ^ {2} - b ^ {2} 。 \end{array} \right.
$$

解得 $a^{2}=9, b^{2}=1, c^{2}=8$ 。

故椭圆 C 的标准方程为 $\frac{x^{2}}{9} + y^{2} = 1$ 。

点评:本问比较基础,考查对椭圆基本量与标准方程的掌握,属于常规题型。

# (二)第(2)(i)问解析与多解思路

思路一: 直接代入法。

设 $R(x_0,y_0)$ ，易知 $m\neq 0$ 。

所以 $k_{AP} = \frac{n + 1}{m}$ ，故 $\frac{y_0 + 1}{x_0} = \frac{n + 1}{m}$ ，且

$$
m x _ {0} > 0 \text { 。 }
$$

因为 $A(0, -1), |AR| \cdot |AP| = 3$ ，所以 $\sqrt{x_0^2 + (y_0 + 1)^2} \cdot \sqrt{m^2 + (n + 1)^2} = 3$ 。

整理得 $\left[1 + \left(\frac{n + 1}{m}\right)^2\right]x_0m = 3$ 。

解得 $x_0 = \frac{3m}{m^2 + (n + 1)^2}$ 。

所以 $y_{0}=\frac{n+2-m^{2}-n^{2}}{m^{2}+(n+1)^{2}}$ 。

因此点 $R$ 的坐标为 $\left(\frac{3m}{m^2 + (n + 1)^2}, \frac{n + 2 - m^2 - n^2}{m^2 + (n + 1)^2}\right)$ 。

思路二: 参数法。

先求出 $\overrightarrow{AP}$ ，再使用点 R 在射线 AP 上，设 $\overrightarrow{AR} = \lambda \overrightarrow{AP}$ ，然后由 $|AP| \cdot |AR| = 3$ 这一条件解出 $\lambda$ ，最后求出点 R 的坐标，过程如下。

由（1）知 $A(0, -1)$ ，故 $\overrightarrow{AP} = (m, n + 1)(m \neq 0)$ 。

设 $\overrightarrow{AR} = \lambda \overrightarrow{AP},\lambda >0$ ，则 $\overrightarrow{AR} = \lambda \overrightarrow{AP} =$ $(\lambda m,\lambda n + \lambda)$ 。由 $|AR|\cdot |AP| = 3$ ，可得 $\lambda [m^2 +(n + 1)^2 ] = 3$

所以 $\lambda=\frac{3}{m^{2}+(n+1)^{2}}$ 。

因此 $\overrightarrow{AR} = \lambda \overrightarrow{AP} = \lambda (m, n + 1) = \left(\frac{3m}{m^2 + (n + 1)^2}, \frac{3(n + 1)}{m^2 + (n + 1)^2}\right)$ 。

故点 R 的坐标为 $\left(\frac{3m}{m^{2}+(n+1)^{2}},\frac{n+2-m^{2}-n^{2}}{m^{2}+(n+1)^{2}}\right)$ 。

思路三:共线向量法。

先求出 $\left|AP\right|$ 和 $\left|AR\right|$ ，再利用 $\overrightarrow{AR}$ 与 $\overrightarrow{AP}$ 共线且同向来求出 $\overrightarrow{AR}$ ，然后求出点 R 的坐标，过程如下。

由(1)知 $A(0,-1)$ ，故 $\overrightarrow{AP}=(m,n+1)$ $(m\neq0)$ ，故 $|AP|=\sqrt{m^{2}+(n+1)^{2}}$ 。

由 $|AP| \cdot |AR| = 3$ ，得 $|AR| = \frac{3}{\sqrt{m^2 + (n + 1)^2}}$ 。

因 $\overrightarrow{AR}$ 与 $\overrightarrow{AP}$ 共线且同向，故 $\overrightarrow{AR} = |\overrightarrow{AR}|\cdot$ $\frac{\overrightarrow{AP}}{|\overrightarrow{AP}|} = \left(\frac{3m}{m^2 + (n + 1)^2},\frac{3(n + 1)}{m^2 + (n + 1)^2}\right)$ 。

故 $R\left(\frac{3m}{m^2 + (n + 1)^2}, \frac{3(n + 1)}{m^2 + (n + 1)^2} - 1\right)$ ,

即 $R\left(\frac{3m}{m^{2}+(n+1)^{2}},\frac{n+2-m^{2}-n^{2}}{m^{2}+(n+1)^{2}}\right)$ 。

点评:第(2)(i)问是求定直线上满足某条件的点的坐标问题,考查了同学们的代数运算能力及数形结合思想。在这一问中,适当的假设会使计算量变小。这需要同学们挖掘条件中的几何特征,并选择简捷的表达形式,考查了同学们对数学中符号化思想的理解和运用,体现试题“多想少算”的设计理念。如果直接假设点R的坐标为 $(x,y)$ ,列出两个方程,那么求解过程会相当复杂。

本问考查向量共线定理与坐标表示,若能灵活运用向量比例关系,则可显著简化运算,体现“多想少算”的命题理念。

(三)第(2)(ii)问解析与最值求解

结合(2)(i)可知 $k_{OR}=\frac{\frac{n+2-m^{2}-n^{2}}{m^{2}+(n+1)^{2}}}{\frac{3m}{m^{2}+(n+1)^{2}}}$ $\frac{n+2-m^{2}-n^{2}}{3m}, k_{OP}=\frac{n}{m}$

由 $k_{OR} = 3k_{OP}$ ，可得 $\frac{3n}{m} = \frac{n + 2 - m^2 - n^2}{3m}$

化简可得 $m^2 + n^2 + 8n - 2 = 0$ ，即 $m^2 + (n + 4)^2 = 18 (m \neq 0)$ 。

所以点 P 在以 $N(0,-4)$ 为圆心， $3\sqrt{2}$ 为半径的圆上（除去 $(0,-4-3\sqrt{2})$ 和 $(0,-4+3\sqrt{2})$ 两个点）。

思路一:不妨设 $Q(3\cos\theta,\sin\theta)$ 。

所以 $|QN|^{2}=(3\cos\theta)^{2}+(\sin\theta+4)^{2}$ $=9\cos^{2}\theta+\sin^{2}\theta+8\sin\theta+16$ $=8\cos^{2}\theta+1+8\sin\theta+16$ $=8(1-\sin^{2}\theta)+8\sin\theta+17$ $=-8\sin^{2}\theta+8\sin\theta+25$ $=-8\left(\sin\theta-\frac{1}{2}\right)^{2}+27\leqslant27$ ，当且仅当 $\sin\theta=\frac{1}{2}$ 时取等号。

故 $|PQ|_{\max}=|QN|_{\max}+r=3(\sqrt{3}+\sqrt{2})$ 。

思路二: 设 $Q(x_{Q}, y_{Q})$ ，则 $\frac{x_{Q}^{2}}{9} + y_{Q}^{2} = 1$ 。

$$
\begin{array}{l} \mid Q N \mid^ {2} = x _ {Q} ^ {2} + (y _ {Q} + 4) ^ {2} \\ = 9 - 9 y _ {Q} ^ {2} + y _ {Q} ^ {2} + 8 y _ {Q} + 1 6 \\ \end{array}
$$

$$
= - 8 y _ {Q} ^ {2} + 8 y _ {Q} + 2 5
$$

$$
= - 8 \left(y _ {Q} - \frac {1}{2}\right) ^ {2} + 2 7 \leqslant 2 7, \text {当且仅当} y _ {Q}
$$

$= \frac{1}{2}$ 时取等号。

$$
\mathrm{故} \left| P Q \right| _ {\max} = \left| Q N \right| _ {\max} + r = 3 (\sqrt {3} + \sqrt {2}) 。
$$

点评:第(2)(ii)问是求定圆与定椭圆上点的距离的最值问题,同学们若意识到“定圆”能够通过三角形不等式转化为“定点”,就能将问题化简,并最终转化为求二次函数在给定区间上的最值问题。这一问中的解题思路体现了数学中的化归思想、方程与函数思想,也体现了试题“多想少算”的设计理念,考查解析几何中的“化繁为简”思想,也是对高中解析几何备考的良好导向。

本问综合性强,涉及轨迹识别、距离转化与函数最值求解,充分体现了解析几何中“数形结合”“化归与转化”的思想,对同学们的综合素养提出较高要求。

# 四、备考建议

2024 年新课标全国 I 卷解析几何试题“二小一大”共 26 分, 2025 年新高考全国 I 卷解析几何试题“三小一大”共 33 分, 结合近两年全国卷解析几何的考题, 给同学们提供如下备考建议, 旨在帮助同学们系统提升数学素养与应试能力。

# 1. 夯实基础, 强化双基

圆锥曲线作为高考解析几何的核心内容,对其基础概念与性质的掌握至关重要。同学们应牢记椭圆、双曲线、抛物线的定义,掌握标准方程及其几何特征,特别是离心率、焦点、准线、渐近线等高频考点。在日常训练中,同学们需注重对基本量与基本关系的推导与记忆,避免因概念模糊而导致失分。此外,要加强对参数意义和几何直观的对应理解,做到“既会算,也要懂”。

# 2. 通性通法,专题突破

直线与圆锥曲线的综合问题历来是高考解答题考查的重点。同学们应系统掌握这类问题的基本解法流程:设直线的方程(注意斜率存在性讨论),联立消元,判别式验证,韦达定理应用,条件翻译与代数变形。建议通过

专题训练,对不同设问方式(如定点、定值、取值范围、最值等)进行分类总结,掌握其典型的处理策略。同时,要注重运算合理性的选择,避免盲目计算,提升解题效率。

# 3. 融合多元知识, 提升综合能力

从近几年命题趋势看,单一方法的应用逐渐减少,更多题目强调向量、平面几何、函数与不等式等多模块知识与解析几何的融合。例如,利用向量处理共线、垂直、比例等问题,可简化代数运算;借助平面几何性质(如相似、对称、圆幂定理等)直观揭示几何关系,实现“巧解”。

因此,同学们在学习中要有意识地打破知识壁垒,培养综合运用工具解决问题的能力,增强应对创新题型的适应性。

# 4. 回归教材,构建知识体系

教材是高考命题的根本依据,其例题、习题及拓展材料中蕴含丰富的思想方法。同学们应重新审视教材,不仅关注结论,更要重视重要公式与定理的推导过程,理解其来龙去脉。例如,椭圆标准方程的推导、离心率的几何解释、切线方程的推导等,都是高考试题的重要来源。同时,教材中的“探究”“阅读”等内容往往涉及数学思想的拓展与应用,值得大家深入研习,以形成系统、连贯的知识网络。

# 五、总结与展望

2025 年新高考数学试题通过创新题型与开放条件设计,显著加强了对逻辑推理、综合应用与创新意识的考查。试题不再局限于传统套路,而是强调真实情境下的数学建模与问题解决能力。在未来备考中,同学们除了需要夯实基础,更应注重知识的跨模块整合与思维的灵活性训练,主动探究问题的本质,提升数学核心素养。只有这样,才能适应高考从“知识立意”向“能力立意、素养导向”转变的新要求,在选拔性考试中脱颖而出。
