# 一、题目考法与特点

2025年新高考全国Ⅰ卷第18题以解析几何中的轨迹和最值问题为载体，考查同学们熟悉的椭圆、直线和圆。试题的背景是“反演点”，考查恒等变形、整体代入等代数运算能力，以及解析几何中的数形结合、化繁为简等思想，是一道较为综合、难度较高的题目。试题虽然是解析几何问题，但其中加入了平面几何和二次函数的元素，希望同学们在面对具体问题时，能将自己学习到的各个板块的知识有机结合进行应用，体现了试题的综合性、灵活性及全面性，有助于选拔具有科学素养、能够举一反三、进行自主探究的拔尖创新型人才。

# 二、真题呈现及方法探究

题目 （2025 年新高考全国 I 卷第 18 题）已知椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ 的离心率为 $\frac{2\sqrt{2}}{3}$ ，下顶点为 $A$ ，右顶点为 $B, |AB| = \sqrt{10}$ 。

(1)求椭圆 C 的方程。

(2)已知动点 P 不在 y 轴上, 点 R 在射线 AP 上, 且满足 $\left|AR\right| \cdot \left|AP\right| = 3$ 。

①设 $P(m,n)$ ，求 R 的坐标（用 m,n 表示）；

②设 O 为坐标原点, Q 是 C 上的动点, 直线 OR 的斜率是直线 OP 的斜率的 3 倍, 求 $\left|PQ\right|$ 的最大值。

分析:在第(1)问中,利用已知条件转化为a,b或a,c的方程,直接求解;第(2)问的第①小问先求出 $|AP|$ 和 $|AR|$ ,然后利用 $\overrightarrow{AR}$ 和 $\overrightarrow{AP}$ 共线同向来求出 $\overrightarrow{AR}$ ,再求出点R的坐标,或先求出 $\overrightarrow{AP}$ ,然后使用点R在射线AP上这一条件假设 $\overrightarrow{AR}=\lambda\overrightarrow{AP}$ ,再利用 $|AR|\cdot|AP|=3$ 解出 $\lambda$ ,从而求出点R的坐标。第②小问使用三角形不等式或三角换

元将定圆和定椭圆上点的距离最大值问题转化为定椭圆上点到定圆圆心的距离最大值问题,最后用整体代入转化为二次函数的最值问题来求解。

解析:(1)由题意知, $A(0,-b)$ , $B(a,0)$ ,所以 $|AB|=\sqrt{a^{2}+b^{2}}=\sqrt{10}$ ,所以 $a^{2}+b^{2}=10$ 。

由 $e = \frac{c}{a} = \frac{2\sqrt{2}}{3}$ ，得 $c = \frac{2\sqrt{2}}{3} a$ ，所以 $c^2 = a^2 - b^2 = \frac{8}{9} a^2$ ，即 $a^2 = 9b^2$ 。结合 $a^2 + b^2 = 10$ ，解得 $b^2 = 1, a^2 = 9$ 。

所以椭圆 $C$ 的方程为 $\frac{x^2}{9} + y^2 = 1$ 。

(2) ① 方法一: 设点 $P(m, n), m \neq 0$ , $R(x, y)$ , 由题意知, $A(0, -1)$ 。

故 $\left\{\begin{aligned}\frac{y+1}{x}&=\frac{n+1}{m},\\\sqrt{x^{2}+(y+1)^{2}}&\cdot\sqrt{m^{2}+(n+1)^{2}}=3,\end{aligned}\right.$

解得 $\left\{\begin{aligned}x&=\frac{3m}{m^{2}+(n+1)^{2}},\\ y&=\frac{-m^{2}-n^{2}+n+2}{m^{2}+(n+1)^{2}}.\end{aligned}\right.$ 所以点R的坐

标为 $\left(\frac{3m}{m^2 + (n + 1)^2}, \frac{-m^2 - n^2 + n + 2}{m^2 + (n + 1)^2}\right)$ 。

方法二:设点 $P(m,n), m \neq 0, R(x,y)$ ，由题意知， $A(0,-1)$ ，则 $\overrightarrow{AP} = (m, n+1)$ 。

因为点 R 在射线 AP 上, 且满足 $\left|AR\right| \cdot \left|AP\right| = 3$ , 所以存在 $\lambda$ , 使得 $\overrightarrow{AR} = \lambda \overrightarrow{AP}$ , 且 $\lambda > 0$ 。

因为 $|\overrightarrow{AR}|\cdot |\overrightarrow{AP}| = \lambda |\overrightarrow{AP}|^2 = \lambda [m^2 + (n + 1)^2 ] = 3$ ，所以 $\lambda = \frac{3}{m^2 + (n + 1)^2}$ 。

因为 $\overrightarrow{OR} = \overrightarrow{OA} +\overrightarrow{AR} = \overrightarrow{OA} +\lambda \overrightarrow{AP} =$ $(0, - 1) + \frac{3}{m^2 + (n + 1)^2}$ （ $m,n + 1)$

$\left(\frac{3m}{m^2 + (n + 1)^2}, \frac{-m^2 - n^2 + n + 2}{m^2 + (n + 1)^2}\right)$ , 所以点 $R$

的坐标为 $\left(\frac{3m}{m^2 + (n + 1)^2}, \frac{-m^2 - n^2 + n + 2}{m^2 + (n + 1)^2}\right)$ 。

②方法一:(三角形不等式法)由①知 $k_{OR}=\frac{-m^{2}-n^{2}+n+2}{3m},\quad k_{OP}=\frac{n}{m}$ ，所以 $\frac{-m^{2}-n^{2}+n+2}{3m}=\frac{3n}{m}$ ，即 $m^{2}+(n+4)^{2}=18$ ，所以点 P 在以 $T(0,-4)$ 为圆心， $3\sqrt{2}$ 为半径的圆上，但要除去 $(0,-4+3\sqrt{2})$ 和 $(0,-4-3\sqrt{2})$ 两点。

设 $Q(x,y)$ ，因为 $Q$ 为椭圆 $x^{2} + 9y^{2} = 9$ 上一点，所以 $|PQ|\leqslant |QT| + |PT| =$ $\sqrt{x^2 + (y + 4)^2} +3\sqrt{2} = \sqrt{9 - 9y^2 + (y + 4)^2}$ $+3\sqrt{2} = \sqrt{-9\left(y - \frac{1}{2}\right)^2 + 27} +3\sqrt{2}$ 。

因为 $-1 \leqslant y \leqslant 1$ ，所以当 $y = \frac{1}{2}$ 时， $|PQ|$ 取得最大值为 $3\sqrt{3} + 3\sqrt{2}$ 。

方法二:(三角换元设点法)因为 Q 是椭圆 C 上的动点,所以可设 $Q(3\cos\theta,\sin\theta)$ 。

结合方法一可知 $|QT|^2 = (3\cos \theta)^2 + (\sin \theta + 4)^2 = 9\cos^2\theta + \sin^2\theta + 8\sin \theta + 16 = -8\sin^2\theta + 8\sin \theta + 25$ 。

令 $\mu = \sin \theta$ ，则 $h(\mu) = -8\mu^2 + 8\mu + 25 = -8\left(\mu - \frac{1}{2}\right)^2 + 27, \mu \in [-1, 1]$ ，所以当 $\mu = \frac{1}{2}$ 时， $h(\mu)_{\max} = 27$ ，所以 $|QT|_{\max} = 3\sqrt{3}$ ，所以 $|PQ|$ 取得最大值为 $3\sqrt{3} + 3\sqrt{2}$ 。

点评:本题第(2)问的第②小问是求动直线的最大值,方法一联想到“三角形两边之和大于第三边”,注意到 $|PQ|$ 取最大值时必过圆心,于是以圆心T作为三角形顶点,接下来只需要计算 $|QT|$ 的长度即可;方法二通过点P在椭圆上运动,可以考虑三角换元设点,从而实现“减元设点”,为接下来求最值做准备,这种方法在2024年全国乙卷的解析几何问题中也有体现。

# 三、高考溯源

题源 （2014 年福建高考理科数学第 9 题）设 P, Q 分别为圆 $x^{2} + (y - 6)^{2} = 2$ 和椭圆 $\frac{x^{2}}{10} + y^{2} = 1$ 上的点，则 P, Q 两点间的最大

距离是( )。

A. $5\sqrt{2}$

B. $\sqrt{46} + \sqrt{2}$

C. $7 + \sqrt{2}$

D. $6 \sqrt{2}$

解析: 设圆 $x^{2}+(y-6)^{2}=2$ 的圆心为 $M(0,6)$ ，半径为 $r=\sqrt{2}$ 。

设 $Q(x_0, y_0)$ ，则 $\frac{x_0^2}{10} + y_0^2 = 1$ ，且 $-1 \leqslant y_0 \leqslant 1$ ，点 $Q$ 到圆心 $M(0,6)$ 的距离为 $|QM| = \sqrt{x_0^2 + (y_0 - 6)^2} = \sqrt{10(1 - y_0^2) + (y_0 - 6)^2} = \sqrt{-9(y_0 + \frac{2}{3})^2 + 50}$ ，所以当 $y_0 = -\frac{2}{3}$ 时， $|QM|_{\max} = 5\sqrt{2}$ ，所以 $|PQ|_{\max} = |QM|_{\max} + |PM| = 5\sqrt{2} + \sqrt{2} = 6\sqrt{2}$ 。故选 D。

点评:本题与2025年新高考全国Ⅰ卷第18题第(2)问的思路和方法基本一致,充分体现高考试题的经典性和延续性,所以同学们在平时做题时,要注意对高考试题的研究和思考,探寻命题的规律和思维路径。

# 四、备考方略

新高考试卷强调对思维能力的考查,解题时要多想少算,对于解析几何专题主要体现在:通过挖掘几何信息,加强几何转换,优化繁难运算,一般来讲,几何信息挖掘得越透彻,代数运算就会越简单。

在复习备考过程中,同学们要规范答题,踩准得分点,减少过失性失分。在答题过程中,针对不同位置的解析几何问题要力争做好以下几点:

(1)容易题争取不丢分——规范解答少跳步；  
(2) 中等题争取少丢分——得分点处写清楚；  
(3)较难题争取多拿分——知道一点写一点,一道高考题做不出来,不等于一点想法都没有,应尽量将自己知道的写出来;

(4)克服“会而不对,对而不全”的问题。

解答题一般都设置了层次分明的“台阶”，入手易，解到底难，因此看似容易的题也会有“咬手”的关卡，看似难做的题也有可得分之处，所以尽量做到中等题少丢分，难题多得分。（责任编辑 王福华）
