# 椭圆中的最值问题易错点探秘

■山东省莘县实验高级中学 赵广祥

圆锥曲线是高中数学中的核心知识,其中与最值相关的问题属于考查热点,更是易错点。本文基于一轮备考复习,对椭圆中的最值问题进行了全面梳理,分析各种题型的答题措施,并对答题过程中容易出现的错误进行梳理,旨在帮助同学们突破椭圆中的最值问题,并能举一反三,推广到双曲线和抛物线当中进行应用。

# 一、到定点的距离问题

此类问题属于基础性问题,主要考查两点间的距离公式: $|AB|=\sqrt{(x_{1}-x_{2})^{2}+(y_{1}-y_{2})^{2}}$ 。解决方法主要是三角代换。若定点在坐标轴上,则可以结合椭圆方程转化为一元二次函数来求最值。解题时的易错点主要有:一是设点的形式;二是转化为什么函数;三是利用函数求最值的方式。

由题意知椭圆的右焦点为 $F(\sqrt{3},0)$ ，若 $x = \frac{4}{t} = \sqrt{3}$ ，则 $t = \frac{4\sqrt{3}}{3}$ 。

故当直线 MN 过椭圆的右焦点时, $t = \frac{4\sqrt{3}}{3}$ 。

点评:该题是在两条直线与椭圆相交的情境下,求证交点弦直线过椭圆的焦点,属于直线过定点问题,只不过此时定点的坐标已经确定,只要证明 t 存不存在,若存在,则直线 MN 过椭圆的右焦点;若不存在,则直线 MN 不过椭圆的右焦点。在这类问题的解答中,一般思路是将交点坐标求出来,利用直线的两点式方程求直线方程,再利用含参直线求定点的方法求出定点坐标即可。本题中,因为点 M、N 的坐标比较复杂,没有明确把直线方程求出来,而是根据要判断直线是否过椭圆的焦点,所以直接令 y=0,求出横坐标,从而求得参数 t 的值。

总之,本文系统地探讨了圆锥曲线中直线过定点问题的三大转化策略,通过典型例

例 1 已知椭圆 $C: \frac{x^{2}}{4} + y^{2} = 1, B$ 是椭圆 C 上的动点，点 A(4,0)，求 $|AB|$ 的最大值。

解法一：（三角代换法）依题意可设 $B(2\cos\alpha,\sin\alpha)(\alpha\in[0,2\pi))$ ，则 $|AB|=$ $\sqrt{(2\cos\alpha-4)^{2}+(\sin\alpha-0)^{2}}$ $\sqrt{4\cos^{2}\alpha-16\cos\alpha+16+\sin^{2}\alpha}$ $\sqrt{3\cos^{2}\alpha-16\cos\alpha+17}$

因为 $\alpha \in [0,2\pi)$ ，所以 $\cos \alpha \in [-1,1]$ 所以 $\sqrt{3\cos^2\alpha - 16\cos\alpha + 17} \leqslant \sqrt{3\times(-1)^2 - 16\times(-1) + 17} = 6$ 。

故 $|AB|$ 的最大值为6。

解法二:(消元代换法)设点 $B(x,y)(x \in [-2,2])$ ，则 $|AB| = \sqrt{(x-4)^{2} + (y-0)^{2}} = \sqrt{x^{2} - 8x + 16 + y^{2}}$ 。

题展示了切点弦转化、斜率之积转化和相交弦转化的具体应用，并提出各种方法的易错点。文章只是通过题目探讨了三大类问题的转化，在实际解题中要灵活处理，有很多题目相应的已知条件会有所变化，如斜率之积转化题型中，有的题目会直接告诉 $k_{1} \cdot k_{2} = m$ （ $m$ 为常数）。文章给出的解题策略具有普适性：先建立含参直线方程，再通过代数变形消参，最终锁定定点坐标。这些方法不仅适用于椭圆，经适当调整后也可推广至双曲线和抛物线的情形。建议同学们在掌握核心方法的基础上，进一步关注解题过程中参数范围的讨论及几何意义的验证。在解题实践中，需根据条件特征灵活选取最优路径，特别注意易错点，通过“代数运算规范化、几何意义可视化”提升解题效率与严谨性。正如数学大师希尔伯特所言：“数学的演进本质是不断寻找更优的转化路径。”掌握这些策略，实则是掌握解析几何中“动中寻静”的思维精髓。

因为点 B 在椭圆 C 上, 所以 $y^{2}=1-\frac{x^{2}}{4}$ , 代入 $\sqrt{x^{2}-8x+16+y^{2}}$ , 得 $\sqrt{x^{2}-8x+16+1-\frac{x^{2}}{4}}$ $=\sqrt{\frac{3}{4}x^{2}-8x+17}$ 。

又 $x \in [-2, 2]$ ，则 $\sqrt{\frac{3}{4} x^2 - 8x + 17} \leqslant \sqrt{\frac{3}{4} \times (-2)^2 - 8 \times (-2) + 17} = 6$ 。

故 $|AB|$ 的最大值为6。

点评:该题为了体现两种方法,在情景设置上选定了定点在 x 轴上的情况。第一种方法是通用方法,将焦点在 x 轴上的椭圆上的任意点设为 $A(a\cos\alpha,b\sin\alpha)(\alpha\in[0,2\pi))$ , 利用平面中两点间的距离公式得 $\left|AB\right|=\sqrt{(2\cos\alpha-4)^{2}+(\sin\alpha-0)^{2}}$ , 化简为一个关于 $\cos\alpha$ 或 $\sin\alpha$ 的二次函数, 求最值即可; 第二种方法只针对定点在坐标轴上的情况, 思路和第一种方法类似, 唯一区别在于设点为 $B(x,y)(x\in[-a,a])$ 。

# 二、到定直线的距离问题

此类问题是教材中提出的问题,需要同学们着重关注。解题方法主要有两种:一是三角代换法;二是平行切线法。

例 2 已知 A 是椭圆 $C: \frac{x^{2}}{3} + y^{2} = 1$ 上的一个动点, 求点 A 到直线 l: y = x - 3 的最大距离。

解法一: (三角代换法) 由题意可设 $A(\sqrt{3} \cos \alpha, \sin \alpha) (\alpha \in [0, 2\pi))$ ，点 $A$ 到直线 $l: y = x - 3$ 的距离为 $d$ ，利用点到直线的距离公式得 $d = \frac{|\sqrt{3} \cos \alpha - \sin \alpha - 3|}{\sqrt{2}} = \left| 2 \cos \left( \alpha + \frac{\pi}{3} \right) - 3 \right|}{\sqrt{2}}$ 。

因为 $\alpha \in [0, 2\pi)$ ，所以 $\alpha + \frac{\pi}{3} \in \left[\frac{\pi}{3}, \frac{7\pi}{3}\right)$ ，则 $\cos \left(\alpha + \frac{\pi}{3}\right) \in [-1, 1]$ ，因此 $\frac{|2\cos \left(\alpha + \frac{\pi}{3}\right) - 3|}{\sqrt{2}} \leqslant \frac{|2 \times (-1) - 3|}{\sqrt{2}} =$

$\frac{5\sqrt{2}}{2}$ 。

所以点 A 到直线 l: y = x - 3 的最大距离为 $\frac{5\sqrt{2}}{2}$ 。

解法二:(平行切线法)设与直线 l:y = x - 3 平行,且与椭圆 $C:\frac{x^{2}}{3} + y^{2} = 1$ 相切的直线方程为 $l_{1}:y = x + m$ 。

联立 $\left\{ \begin{array}{l} y = x + m, \\ \frac{x^2}{3} + y^2 = 1, \end{array} \right.$ 消去 $y$ 整理得 $4x^{2} + 6mx + 3m^{2} - 3 = 0$ 。

因为直线 $l_{1}$ 与椭圆 $C$ 相切，所以 $\Delta = (6m)^{2} - 4 \times 4 \times (3m^{2} - 3) = -12m^{2} + 48 = 0$ 解得 $m = -2$ 或 $m = 2$ 。

因为要取得最大值,所以直线 $l_{1}$ 与 l 应该在椭圆 C 的异侧,则 m=2, 即 $l_{1}: y=x+2$ 。

利用平行直线间的距离公式得 $d = \frac{|2 - (-3)|}{\sqrt{2}} = \frac{5\sqrt{2}}{2}$ , 故点 $A$ 到直线 $l: y = x - 3$ 的最大距离为 $\frac{5\sqrt{2}}{2}$ 。

点评:该题是求椭圆上的动点到定直线的最大距离,是基础性问题。上面提供了两种方法,第一种方法是三角代换法,基本步骤是:第一步设点,将焦点在x轴上的椭圆上的任意点设为 $A(a\cos\alpha,b\sin\alpha)(\alpha\in[0,2\pi))$ ,这里同学们不仅需要注意点的坐标形式,还要注意 $\alpha$ 的取值范围。第二步求距离,利用点到直线的距离公式 $d=\frac{|Ax_{0}+By_{0}+C|}{\sqrt{A^{2}+B^{2}}}$ 代入,这里的易错点比较抽象,很多同学认为求最值与距离无关,所以到这里走不下去了。第三步转化为三角函数求最值,这里的易错点是三角函数的化简和求三角函数的最值方法。第二种方法是利用平行切线法,即根据几何直观,取得最大距离时,该点是与已知直线平行,且与椭圆相切的切点,从而转化为求平行直线间的距离问题。基本步骤是:第一步设与已知直线平行,且与椭圆相切的直线方程,这里的易错点是设直线方程的形式。第二步联立方程组,消元,利用判别式等于

0, 求出截距 $m$ , 这里的易错点是没想到利用判别式去求截距 $m$ 。第三步利用平行直线间的距离公式求出距离的最值, 这里的易错点主要有两点: ①没想到用平行直线间的距离公式; ②不会确定最大值和最小值。

# 三、与椭圆定义有关的最值问题

对于这种题型,同学们容易将椭圆的定义(椭圆上任意一点 A, 均有 $\left|AF_{1}\right| + \left|AF_{2}\right| = 2a$ ) 与基本不等式的应用搭上关系。解题时的易错点主要有:一是没有想到利用基本不等式;二是对椭圆的定义不清;三是不会使用基本不等式。

例 3 已知椭圆 $C: \frac{x^{2}}{16} + \frac{y^{2}}{b^{2}} = 1 (0 < b < 4)$ ， $F_{1}, F_{2}$ 为椭圆 C 的左焦点和右焦点，以原点 O 为圆心， $OF_{1}$ 为半径的圆 O 与椭圆 C 相交于点 A，求 $\triangle AF_{1}F_{2}$ 面积的最大值。

解析:由点 A 在椭圆 C 上,可根据椭圆的定义知 $\left|AF_{1}\right| + \left|AF_{2}\right| = 2a = 8$ 。

因为圆 O 是以原点为圆心, $OF_{1}$ 为半径, 所以 $AF_{1} \perp AF_{2}$ , 故 $S_{\triangle AF_{1}F_{2}} = \frac{1}{2} \cdot |AF_{1}| \cdot |AF_{2}|$ 。

因为 $|AF_{1}|+|AF_{2}|=8$ ，所以根据基本不等式有 $|AF_{1}|\cdot|AF_{2}|\leqslant\frac{(|AF_{1}|+|AF_{2}|)^{2}}{4}=$ $\frac{64}{4}=16$ 。

所以 $(S_{\triangle AF_1F_2})_{\mathrm{max}} = \frac{1}{2} |AF_1| \cdot |AF_2| \leqslant \frac{1}{2} \times 16 = 8$ 。

点评:该题是利用椭圆的定义 $\left|AF_{1}\right|+\left|AF_{2}\right|=2a$ ，结合基本不等式求 $\triangle AF_{1}F_{2}$ 面积的最大值。在解决问题时，要时刻记住椭圆的定义，这是易错的地方。另外，要根据基本不等式的“和”“积”形式确定使用不等式的形式。

# 四、与椭圆第二定义有关的最值问题

考查椭圆第二定义时,容易出现的题型是求椭圆上的动点到定点的距离与到焦点的距离之和的最小值。解题时的易错点主要有:一是对椭圆第二定义不清楚;二是不会对定点进行转移。

例 4 已知 B 是椭圆 M: $\frac{x^{2}}{4} + \frac{y^{2}}{3} = 1$ 上的动点, 点 $A\left(-\frac{1}{2},1\right)$ ，设 $F_{1}, F_{2}$ 分别是椭圆 M 的左焦点和右焦点，求 $|AB| + |BF_{2}|$ 的最小值。

解析:设点 B 到椭圆右准线的距离为 d。

由题意知 $F_{2}(1,0)$ ，椭圆的离心率 $e = \frac{c}{a} = \frac{1}{2}$ ，椭圆的右准线 $l:x = \frac{a^2}{c} = 4$ ，根据椭圆的第二定义得 $\frac{|BF_2|}{d} = e = \frac{1}{2}$ 所以 $|BF_{2}| = \frac{1}{2} d$ ，则 $|AB| + |BF_{2}| = |AB| + \frac{1}{2} d$ 。

当 $y = 1$ 时，代入椭圆 $M: \frac{x^2}{4} + \frac{y^2}{3} = 1$ ，得 $x = \pm \frac{2\sqrt{6}}{3}$ ，所以 $B\left(\frac{2\sqrt{6}}{3}, 1\right)$ 。

因此 $|AB| + |BF_2| = |AB| + \frac{1}{2} d \geqslant \left(\frac{2\sqrt{6}}{3} + \frac{1}{2}\right) + \frac{1}{2}\left(4 - \frac{2\sqrt{6}}{3}\right) = \frac{\sqrt{6}}{3} + \frac{5}{2}$ 。

故当点 B 的坐标为 $\left(\frac{2\sqrt{6}}{3},1\right)$ 时， $|AB|+BF_{2}|$ 取得最小值 $\frac{\sqrt{6}}{3}+\frac{5}{2}$ 。

点评:要求两个定点和一个动点组成的两条线段之和的最小值,必须满足两个条件:一是三点共线;二是动点必须处于两个定点之间。在解决问题的过程中,若两个条件均不满足,则采用椭圆的第二定义,将定点 $F_{2}$ 转移到椭圆的准线上,可以顺利解决问题。同时需要特别注意椭圆的第二定义及椭圆的准线方程,根据三角形的形成条件,对其中的定点进行转移,使其达到三点共线,且动点处于定点之间。

总之，椭圆的最值问题是千变万化的，但归根结底都是围绕着以上几个方面展开的，只有将以上椭圆方面的最值进行融会贯通，才能使得椭圆中的最值问题得以突破，并清楚各种题型在处理时的易错点。同时，文章是以椭圆为例展开的探究，以上很多情境可以推广到双曲线和抛物线当中，甚至解决方法都是一样的。（责任编辑 王福华）
