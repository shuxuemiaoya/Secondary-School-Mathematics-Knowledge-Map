# 圆锥曲线中直线过定点问题的转化策略易错点分析

# ■甘肃省陇南市西和县第二中学 黄莉莉

圆锥曲线作为高中数学的核心内容,其综合题型常体现几何与代数的深度交融。其中,“直线过定点”问题因涉及动态分析与定点锁定的双重思维,成为经典题型。解决此类问题的核心思想是“构造含参直线方程,通过消除参数锁定定点坐标”。参数通常体现为斜率或截距,而解题关键在于将原始问题转化为含参直线方程求定点问题。基于此,本文系统归纳三大转化策略——切点弦转化法、斜率之积转化法、相交弦转化法,结合典型案例剖析其应用逻辑与操作路径,并分析各种方法中易错的地方,供同学们复习时参考。

# 一、切点弦转化法

该类问题的特征是过曲线外一点作两条切线,求证两切点所连直线(切点弦)恒过定点。可利用切线方程的对称性求解(当点 P 在两条切线上时,其坐标同时满足两条切线方程,而这两个方程可整合为切点弦的直线方程形式)。解题时的易错点主要有:①不能快速得到切线方程;②得到两条切线方程后,不能根据方程形式抽象出切点弦方程。

例 1 过直线 $x=\frac{4\sqrt{3}}{3}$ 上任意点 M 作椭圆 C: $\frac{x^{2}}{4}+y^{2}=1$ 的两条切线，切点分别记为 A, B。求证直线 AB 过定点，并求出定点坐标。

证明: 设 $M\left(\frac{4\sqrt{3}}{3}, y_{0}\right) (y_{0} \in \mathbb{R})$ , $A(x_{1}, y_{1})$ , $B(x_{2}, y_{2})$ , 则切线 MA 的方程为 $\frac{x_{1}x}{4} + y_{1}y = 1$ , 切线 MB 的方程为 $\frac{x_{2}x}{4} + y_{2}y = 1$ 。

因为点 $M\left(\frac{4\sqrt{3}}{3},y_0\right)$ 在直线 $MA,MB$ 上，所以 $\frac{\sqrt{3}}{3} x_1 + y_0y_1 = 1,\frac{\sqrt{3}}{3} x_2 + y_0y_2 = 1$

从直线 $MA, MB$ 方程的形状可以知道，直线 $AB$ 的方程为 $\frac{\sqrt{3}}{3} x + y_0y = 1$ ，即 $x +$

$\sqrt{3}y_{0}y-\sqrt{3}=0$ ，其中 $y_{0}$ 为参数，所以直线AB过定点 $(\sqrt{3},0)$ 。

点评:该题是求证切点弦过定点问题。将切点弦转化为含有参数的直线方程的策略是:首先,根据过点引曲线的切线方法,把切线方程求出来,方法有两个:一是利用判别式 $\Delta=0$ ,求出斜率,则切线方程可得。二是利用二级结论,过一点 $P(m,n)$ 作切线时,切线方程为 $\frac{mx}{a^{2}}+\frac{ny}{b^{2}}=1$ (椭圆); $\frac{mx}{a^{2}}-\frac{ny}{b^{2}}=1$ (双曲线); $ny=p(x+m)$ (抛物线); $(m-a)(x-a)+(n-b)(y-b)=r^{2}$ (圆)。其次,将该点代入切线方程,会得到两个形式一样的方程,则为切点弦的方程,如 $\frac{\sqrt{3}}{3}x_{1}+y_{0}y_{1}=1$ , $\frac{\sqrt{3}}{3}x_{2}+y_{0}y_{2}=1$ ,则切点弦的方程为 $\frac{\sqrt{3}}{3}x+y_{0}y=1$ ,这是转化的关键。

# 二、斜率之积转化法

该类问题的特征是一条动直线交曲线于点 A, B, 存在定点 Q 使得 $k_{AQ} \cdot k_{BQ} = m$ (m 为常数), 求证动直线过定点。一般思路是将斜率之积的代数式转化为直线的参数方程, 通过解参数关系锁定定点。解题时的易错点主要有: ① 不知道借助 $k_{AQ} \cdot k_{BQ} = m$ , 将直线的截距转化为斜率的处理思路; ② 没有掌握求含参直线过定点的方法。

例 2 已知椭圆 $M: \frac{x^{2}}{4} + \frac{y^{2}}{3} = 1$ 的右顶点为 C，若椭圆 M 上两点 A, B 满足 $\overrightarrow{AC} \perp \overrightarrow{BC}$ ，求证直线 AB 过定点，并求出定点坐标。

证明:由题意知 $C(2,0)$ ，设 $A(x_{1},y_{1})$ ， $B(x_{2},y_{2})$ ，直线 AB 的方程为 $y=kx+m$ 。

联立 $\left\{ \begin{array}{l} y = kx + m, \\ \frac{x^2}{4} + \frac{y^2}{3} = 1, \end{array} \right.$ 消去 $y$ 整理得（3+ $4k^{2})x^{2} + 8mkx + 4(m^{2} - 3) = 0$ 。

因为直线 $AB$ 与椭圆 $M$ 交于两点，所以$\Delta=64m^{2}k^{2}-16(3+4k^{2})(m^{2}-3)>0$ ，解得 $3+4k^{2}-m^{2}>0$ 。

由根与系数的关系得 $x_{1} + x_{2} = -\frac{8mk}{3 + 4k^{2}}$ $x_{1}x_{2} = \frac{4(m^{2} - 3)}{3 + 4k^{2}}$

所以 $y_{1}y_{2} = (kx_{1} + m)(kx_{2} + m) =$ $k^2 x_1x_2 + mk(x_1 + x_2) + m^2 = \frac{3(m^2 - 4k^2)}{3 + 4k^2}$

因为 $\overrightarrow{AC} \perp \overrightarrow{BC}$ , 所以 $\overrightarrow{AC} \cdot \overrightarrow{BC} = (2 - x_1, -y_1)(2 - x_2, -y_2) = 4 - 2(x_1 + x_2) + x_1x_2 + y_1y_2 = 4 + \frac{16mk}{3 + 4k^2} + \frac{4(m^2 - 3)}{3 + 4k^2} + \frac{3(m^2 - 4k^2)}{3 + 4k^2} = 0$ , 整理得 $7m^2 + 16mk + 4k^2 = 0$ , 解得 $m = -2k$ 或 $m = -\frac{2k}{7}$ , 两个结果都满足不等式 $3 + 4k^2 - m^2 > 0$ 。

当 $m = -2k$ 时，直线 $AB$ 的方程为 $y = kx - 2k$ ，则直线 $AB$ 过定点(2,0)，与已知条件矛盾，舍去；

当 $m = -\frac{2k}{7}$ 时，直线 $AB$ 的方程为 $y = kx - \frac{2k}{7}$ ，则直线 $AB$ 过定点 $\left(\frac{2}{7}, 0\right)$ 。

综上可知, 直线 AB 过定点, 定点坐标为 $\left(\frac{2}{7}, 0\right)$ 。

点评:对于由直线斜率之积为定值,求证直线过定点问题,若已知条件中没有直接告知斜率之积为定值,则可以通过某种手段转化得到这种形式。其解题步骤为:第一步,将涉及的点坐标和直线的方程设出来;第二步,将直线和曲线的方程联立,求出判别式并大于零,同时写出根与系数的关系;第三步,根据斜率之积转化得出直线斜率与截距的关系式,并代入直线方程中;第四步,根据含参直线求定点的方法,求出定点坐标。

# 三、相交弦转化法

该类问题的特征是两条动直线分别交曲线于两点,求证两交点所连直线(相交弦)恒过定点。一般思路是分别求出两条动直线与曲线的交点坐标,用两点式表示相交弦方程,再分离参数确定定点。当交点坐标复杂时,可结合曲线方程消元化简;若定点已知(如焦点),可将坐标代入相交弦方程反解参数。解题时的易错点主要有:①求点的坐标时计算量比较大,要讲究处理技巧;②由于本身点比较复杂,因此直线方程也不简单,需要根据实际情况进行简化处理。

例 3 已知 P 是直线 $x=t(t>2)$ 上异于 x 轴上的一点，椭圆 $C:\frac{x^{2}}{4}+y^{2}=1$ 的左、右顶点分别是 $A_{1}, A_{2}$ ，直线 $A_{1}P$ 与 $A_{2}P$ 分别与椭圆 C 交于点 M, N（异于 $A_{1}, A_{2}$ ）。当直线 MN 过椭圆的右焦点时，求 t 的值。

解析: 设 $M(x_{1}, y_{1})$ , $N(x_{2}, y_{2})$ , $P(t, y_{P})$ ，直线 $A_{1}P$ 与 $A_{2}P$ 的方程分别为 $y = k_{1}(x + 2)$ , $y = k_{2}(x - 2)$ 。

联立 $\left\{ \begin{array}{l} y = k_{1}(x + 2), \\ \frac{x^{2}}{4} + y^{2} = 1, \end{array} \right.$ 消去 $y$ 整理得 $(1 + 4k_{1}^{2})x^{2} + 16k_{1}^{2}x + 16k_{1}^{2} - 4 = 0$ 。因为-2和 $x_{1}$ 是该方程的两根，所以 $-2x_{1} = \frac{16k_{1}^{2} - 4}{1 + 4k_{1}^{2}}$ 即 $x_{1} = \frac{2 - 8k_{1}^{2}}{1 + 4k_{1}^{2}}$

所以 $y_{1} = k_{1}(x_{1} + 2) = \frac{4k_{1}}{1 + 4k_{1}^{2}}$ ，则 $M\left(\frac{2 - 8k_1^2}{1 + 4k_1^2},\frac{4k_1}{1 + 4k_1^2}\right)$ 。

同理得 $N\left(\frac{8k_{2}^{2}-2}{1+4k_{2}^{2}},-\frac{4k_{2}}{1+4k_{2}^{2}}\right)$ 。

利用点斜式求得直线 $MN$ 的方程为 $y - \frac{4k_1}{1 + 4k_1^2} = \frac{k_1 + k_2}{1 - 4k_1k_2}\left(x - \frac{2 - 8k_1^2}{1 + 4k_1^2}\right)$ 。

令 $y = 0$ ，求得 $x = \frac{2(k_2 - k_1)}{k_2 + k_1}$

因为 $k_{1} = k_{PA_{1}} = \frac{y_{P}}{t + 2}, k_{2} = k_{PA_{2}} = \frac{y_{P}}{t - 2}$ 所以 $k_{1}(t + 2) = k_{2}(t - 2)$ ，即 $\frac{k_1}{t - 2} = \frac{k_2}{t + 2}$ 。

令 $\frac{k_{1}}{t-2}=\frac{k_{2}}{t+2}=m$ ，则 $k_{1}=(t-2)m$ ， $k_{2}=(t+2)m$ ，代入 $x=\frac{2(k_{2}-k_{1})}{k_{2}+k_{1}}$ ，得 $x=\frac{8m}{2mt}=\frac{4}{t}$ 。

# 椭圆中的最值问题易错点探秘

■山东省莘县实验高级中学 赵广祥

圆锥曲线是高中数学中的核心知识,其中与最值相关的问题属于考查热点,更是易错点。本文基于一轮备考复习,对椭圆中的最值问题进行了全面梳理,分析各种题型的答题措施,并对答题过程中容易出现的错误进行梳理,旨在帮助同学们突破椭圆中的最值问题,并能举一反三,推广到双曲线和抛物线当中进行应用。

# 一、到定点的距离问题

此类问题属于基础性问题,主要考查两点间的距离公式: $|AB|=\sqrt{(x_{1}-x_{2})^{2}+(y_{1}-y_{2})^{2}}$ 。解决方法主要是三角代换。若定点在坐标轴上,则可以结合椭圆方程转化为一元二次函数来求最值。解题时的易错点主要有:一是设点的形式;二是转化为什么函数;三是利用函数求最值的方式。

由题意知椭圆的右焦点为 $F(\sqrt{3},0)$ ，若 $x = \frac{4}{t} = \sqrt{3}$ ，则 $t = \frac{4\sqrt{3}}{3}$ 。

故当直线 MN 过椭圆的右焦点时, $t = \frac{4\sqrt{3}}{3}$ 。

点评:该题是在两条直线与椭圆相交的情境下,求证交点弦直线过椭圆的焦点,属于直线过定点问题,只不过此时定点的坐标已经确定,只要证明 t 存不存在,若存在,则直线 MN 过椭圆的右焦点;若不存在,则直线 MN 不过椭圆的右焦点。在这类问题的解答中,一般思路是将交点坐标求出来,利用直线的两点式方程求直线方程,再利用含参直线求定点的方法求出定点坐标即可。本题中,因为点 M、N 的坐标比较复杂,没有明确把直线方程求出来,而是根据要判断直线是否过椭圆的焦点,所以直接令 y=0,求出横坐标,从而求得参数 t 的值。

总之,本文系统地探讨了圆锥曲线中直线过定点问题的三大转化策略,通过典型例

例 1 已知椭圆 $C: \frac{x^{2}}{4} + y^{2} = 1, B$ 是椭圆 C 上的动点，点 A(4,0)，求 $|AB|$ 的最大值。

解法一：（三角代换法）依题意可设 $B(2\cos\alpha,\sin\alpha)(\alpha\in[0,2\pi))$ ，则 $|AB|=$ $\sqrt{(2\cos\alpha-4)^{2}+(\sin\alpha-0)^{2}}$ $\sqrt{4\cos^{2}\alpha-16\cos\alpha+16+\sin^{2}\alpha}$ $\sqrt{3\cos^{2}\alpha-16\cos\alpha+17}$

因为 $\alpha \in [0,2\pi)$ ，所以 $\cos \alpha \in [-1,1]$ 所以 $\sqrt{3\cos^2\alpha - 16\cos\alpha + 17} \leqslant \sqrt{3\times(-1)^2 - 16\times(-1) + 17} = 6$ 。

故 $|AB|$ 的最大值为6。

解法二:(消元代换法)设点 $B(x,y)(x \in [-2,2])$ ，则 $|AB| = \sqrt{(x-4)^{2} + (y-0)^{2}} = \sqrt{x^{2} - 8x + 16 + y^{2}}$ 。

题展示了切点弦转化、斜率之积转化和相交弦转化的具体应用，并提出各种方法的易错点。文章只是通过题目探讨了三大类问题的转化，在实际解题中要灵活处理，有很多题目相应的已知条件会有所变化，如斜率之积转化题型中，有的题目会直接告诉 $k_{1} \cdot k_{2} = m$ （ $m$ 为常数）。文章给出的解题策略具有普适性：先建立含参直线方程，再通过代数变形消参，最终锁定定点坐标。这些方法不仅适用于椭圆，经适当调整后也可推广至双曲线和抛物线的情形。建议同学们在掌握核心方法的基础上，进一步关注解题过程中参数范围的讨论及几何意义的验证。在解题实践中，需根据条件特征灵活选取最优路径，特别注意易错点，通过“代数运算规范化、几何意义可视化”提升解题效率与严谨性。正如数学大师希尔伯特所言：“数学的演进本质是不断寻找更优的转化路径。”掌握这些策略，实则是掌握解析几何中“动中寻静”的思维精髓。
