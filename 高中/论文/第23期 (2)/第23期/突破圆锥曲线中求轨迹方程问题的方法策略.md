# 突破圆锥曲线中求轨迹方程问题的

# 方法策略

在圆锥曲线中,求动点的轨迹方程是一个难点问题,主要原因是问题具有高度的抽象性。解答这类问题通常需要从具体问题情境中直观出曲线轨迹问题,从而顺利地把问题求解出来。基于此,文章归纳出常见的求圆锥曲线的轨迹方程的方法策略,旨在帮助同学们突破这一难点。

# 一、定义法

在求动点 P 的轨迹方程时,根据动点 P 的运动规律,判断轨迹是否符合某种已知曲线(椭圆、双曲线、抛物线等)的定义。若符合,则可直接按照曲线定义进行求解。

例 1 已知两个定圆 $O_{1}:(x+2)^{2}+y^{2}=36$ , $O_{2}:(x-2)^{2}+y^{2}=1$ , 动圆 O 与两个定圆 $O_{1},O_{2}$ 都相切。求动圆 O 的圆心轨迹方程。

解析: 设 $O(x, y)$ ，动圆半径为 r。由定圆 $O_{1}:(x+2)^{2}+y^{2}=36$ , $O_{2}:(x-2)^{2}+y^{2}=1$ ，可知圆 $O_{2}$ 在圆 $O_{1}$ 内，则动圆 O 只能与圆 $O_{2}$ 外切，与圆 $O_{1}$ 内切。由条件知，圆 $O_{1}$ 的圆心为 $O_{1}(-2,0)$ ，半径为 6；圆 $O_{2}$ 的圆心为 $O_{2}(2,0)$ ，半径为 1。因为三个圆的半径不变，所以 $\left|OO_{1}\right|+\left|OO_{2}\right|=6-r+1+r=7$ ，这符合椭圆的定义，所以动圆 O 的圆心轨迹为椭圆，故可设方程为 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$ 。可知 $O_{1}, O_{2}$ 为椭圆的左焦点和右焦点，则 c=2。根据 $\left|OO_{1}\right|+\left|OO_{2}\right|=2a=7$ ，得 $a=\frac{7}{2}$ ，所以 $b^{2}=a^{2}-c^{2}=\frac{49}{4}-4=\frac{33}{4}$ ，故动圆 O 的圆心轨迹方程为 $\frac{4x^{2}}{49}+\frac{4y^{2}}{33}=1$ 。

点评:本题是典型的动圆与两个定圆相切的问题,根据圆的位置关系知,圆O与圆 $O_{2}$ 外切,与圆 $O_{1}$ 内切,则有 $|OO_{2}|=6-r$ , $|OO_{1}|=1+r$ ,所以 $|OO_{1}|+|OO_{2}|=6-r+$

$1 + r = 7$ ，满足椭圆的定义。由 $\left|OO_{1}\right| + \left|OO_{2}\right| = 2a = 7$ 求出 $a$ 。结合已知焦点，可知 $c = 2$ 。根据 $b^{2} = a^{2} - c^{2}$ ，求出 $b$ 。从而确定椭圆的方程。同学们在日常学习过程中要注重巩固基础，深入理解常见曲线的定义，加大抽象思维能力的培养和训练。

# 二、代入法

该方法针对的题型主要是:题目有两个动点,一个是要求的轨迹方程的动点,另外一个是在已知曲线上运动。解题的基本思路是:根据动点和定点之间的关系,将已知曲线上的动点坐标用要求轨迹方程的动点坐标代换,即可得到要求的轨迹方程。

例 2 在平面直角坐标系中, A 是圆 $O: x^{2} + y^{2} = 4$ 上一点, 过点 A 作 x 轴的垂线, 垂足记为 M, AM 的中点为 C。求点 C 的轨迹方程。

解析: 设 $C(x, y)$ , $A(x_{0}, y_{0})$ ，由题意知 $M(x_{0}, 0)$ 。因为 C 是 AM 的中点，所以 $\left\{\begin{aligned}x &= x_{0}, \\ y &= \frac{y_{0}}{2}\end{aligned}\right.$ 即 $\left\{\begin{aligned}x_{0} &= x, \\ y_{0} &= 2y,\end{aligned}\right.$ 代入圆 O: $x^{2} + y^{2} = 4$ ，得 $x^{2} + (2y)^{2} = 4$ ，整理得 $\frac{x^{2}}{4} + y^{2} = 1$ 。所以点 C 的轨迹方程为 $\frac{x^{2}}{4} + y^{2} = 1$ 。

点评:该题是利用代入法求动点的轨迹方程。与其他方法一样,先是设点,把动点C的坐标设为 $(x,y)$ 。与此同时,动点A也需要,但是不知道,所以也设为 $A(x_{0},y_{0})$ 。然后根据中点坐标公式得 $\left\{\begin{aligned}x&=x_{0},\\ y&=\frac{y_{0}}{2},\end{aligned}\right.$ 变换得 $\left\{\begin{aligned}x_{0}&=x,\\ y_{0}&=2y,\end{aligned}\right.$ 将其代入圆的方程中,即可得到点

C 的轨迹方程为 $\frac{x^{2}}{4} + y^{2} = 1$ 。

# 三、参数法

该方法主要适用于动点的坐标本身依赖于一个或多个参数(如角度 $\theta$ 、斜率 k、长度 d 等)的情形。解题时需要引入参数来表示动点坐标,建立参数满足的方程,然后消去参数得到仅含 x 和 y 的轨迹方程。

例 3 已知在平面直角坐标系中, 点 $A\left(\frac{t}{4},1\right)(t \in \mathbf{R})$ , 动点 $P$ 满足 $\overrightarrow{OP} = t\overrightarrow{OA}$ 。求动点 $P$ 的轨迹方程。

解析: 设点 $P(x, y)$ ，则 $\overrightarrow{OP} = (x, y)$ 。因为 $A\left(\frac{t}{4}, 1\right) (t \in \mathbb{R})$ ，所以 $\overrightarrow{OA} = \left(\frac{t}{4}, 1\right)$ 。由 $\overrightarrow{OP} = t\overrightarrow{OA}$ ，得 $(x, y) = t\left(\frac{t}{4}, 1\right) = \left(\frac{t^{2}}{4}, t\right)$ ，所以 $\begin{cases} x = \frac{t^{2}}{4}, \\ y = t \end{cases}$ （t 为参数），进行消参得 $y^{2} = 4x$ 。故动点 P 的轨迹方程为 $y^{2} = 4x$ 。

点评:因为该题中的已知点 $A\left(\frac{t}{4},1\right)(t\in\mathbf{R})$ 中原本含参数,所以选择采用参数方程,通过消参的方式得到动点的轨迹方程。参数法的核心思想是引入辅助变量(参数)来表示动点坐标。虽然课程体系中关于参数方程的专门知识有所调整,但这种利用参数建立关系并消参求轨迹的思想方法仍是重要的解题工具。解题的一般步骤是:先设点坐标,然后根据已知条件至少建立两个方程,两个方程均包含参数、x和y,最后通过消参化简即可。消参的过程类似于解方程组消元,常用代入消参、加减消参、三角恒等式消参等。关键目标是彻底消除参数,得到仅含变量x和y的方程。

# 四、交轨法

当所求轨迹上的点是两条动曲线(通常含有共同的参数)的交点时,可采用此法。解决这类问题时,通常采用联立方程组,通过解方程组的方法把交点坐标求出来,然后按照参数法求轨迹方程的方式处理即可。

例 4 在平面直角坐标系中, 已知椭圆

$C:\frac{x^{2}}{4}+\frac{y^{2}}{3}=1$ 的左、右顶点分别为 A、B，点 P、Q 在椭圆 C 上且关于 x 轴对称。若直线 AP 与 BQ 相交于点 M，求动点 M 的轨迹方程。

解析: 设 $M(x, y)$ , $P(x_{0}, y_{0})$ ，则 $Q(x_{0}, -y_{0})$ 。由题意知， $A(-2, 0)$ , $B(2, 0)$ ，则直线 AP 的方程为 $y = \frac{y_{0}}{x_{0} + 2}(x + 2)$ 。同理，直线 BQ 的方程为 $y = \frac{-y_{0}}{x_{0} - 2}(x - 2)$ 。两式相乘得 $y^{2} = \frac{-y_{0}^{2}}{x_{0}^{2} - 4}(x^{2} - 4)$ 。又因为 P、Q 在椭圆 C 上且关于 x 轴对称，所以 $\frac{x_{0}^{2}}{4} + \frac{y_{0}^{2}}{3} = 1$ ，代入 $y^{2} = \frac{-y_{0}^{2}}{x_{0}^{2} - 4}(x^{2} - 4)$ ，得 $y^{2} = \frac{3}{4}(x^{2} - 4)$ ，即 $\frac{x^{2}}{4} - \frac{y^{2}}{3} = 1$ 。故动点 M 的轨迹方程为 $\frac{x^{2}}{4} - \frac{y^{2}}{3} = 1$ 。

点评:该题是典型的利用交轨法求动点轨迹方程的题目。解题的一般步骤是:第一步,设出动点的坐标;第二步,利用斜截式把直线AP、BQ的方程求出来;第三步,两式相乘,这里乘的目的是为了与 $\frac{x_{0}^{2}}{4}+\frac{y_{0}^{2}}{3}=1$ 的次数统一,以备消元处理;第四步,联立方程组,进行消元处理;第五步,化简、整理,得出动点的轨迹方程。

总之,求曲线的轨迹方程是圆锥曲线中的重点题型,也是难点。为了高考复习备考,文章对求曲线的轨迹方程的题型进行梳理,根据题型进行分析得出求轨迹方程的方法,分别是:定义法、代入法、参数法和交轨法。文章将这些方法适用的题型、题型的识别、方法的主要依据、方法的操作过程,以及注意事项等展开了详细的描述,旨在帮助同学们突破求曲线的轨迹方程题型。
