# 函数问题巧同构,比较大小妙应用

# ● 江苏省常熟市浒浦高级中学 林琦

在解决函数及其相关的综合应用问题时,往往可以借助原关系式、不等式、方程等中相关式子的结构特征,进行合理恒等变形或转化,找出不等式(或等式)两边具有相同结构的代数式,寻找同型或共性,巧妙同构函数,利用新同构函数及其对应的基本性质(单调性、奇偶性或最值等)的确定,来解决对应的函数及其相关的综合问题.

# 1 双变量同构

一些含有地位相同的双变量的不等式(或等式)问题,通过对应代数式的恒等变形与转化,探寻不等式(或等式)两边结构的同型或共性,借助同构函数,结合函数、不等式等数学思维来分析与处理问题.

例 1 （2020 年高考数学全国Ⅰ卷理科第 12 题）若 $2^{a} + \log_{2}a = 4^{b} + 2\log_{4}b$ ，则（）.

A.a>2b

B.a<2b

C. $a>b^{2}$

D. $a < b^{2}$

分析:根据题设条件,通过等式两边的同变量化、同结构化处理等变形与转化,合理同构函数,借助函数的基本性质确定同构函数的单调性,并结合不等式的性质等加以应用,实现变量及其关系式的大小关系的判断.

解析:依题,可得 $2^{a}+\log_{2}a=4^{b}+2\log_{4}b=2^{2b}+\log_{2}b$ .

同构函数 $f(x)=2^{x}+\log_{2}x(x>0)$ ，结合函数的基本性质可知 $f(x)$ 在 $(0,+\infty)$ 上单调递增.

而 $f(2b) = 2^{2b} + \log_22b = 2^{2b} + \log_2b + 1 > 2^{2b} + \log_2b = 2^a +\log_2a = f(a)$ ，所以 $2b > a$

故选择答案:B.

点评:用同构法解决函数及其相关的综合问题时,当题设条件中出现两个变量(有时是多个变量)时,可以通过移项、同乘或同除等运算加以恒等变形与转化,巧妙将同一变量的关系式变化到不等式(或等式)的同一边,进而借助不等式(或等式)的两边具有相同的结构特征,合理寻找并同构函数.

# 2 “指对”同构

在解决一些同时涉及指数函数 $e^{x}$ 与对数函数 $\ln x$ 的相关“指对”混合不等式(或等式)问题时, 可以灵活运用对数恒等式 $a=\mathrm{e}^{\ln a}(a>0)$ ， $a=\ln e^{a}$ 进行变形，结合和差、积、商等不同形式（和差型形式： $e^{a}\pm a>b\pm\ln b$ ，积型形式如 $ae^{a}\leqslant b\ln b$ ，商型形式如 $\frac{e^{a}}{a}<\frac{b}{\ln b}$ 等）的运算类型加以巧妙同构函数，用来分析与解决相应的函数及其相关的综合问题.

例 2 [2023 年重庆外国语学校高三(上)期中数学试卷] 设 a, b 都为正数, e 为自然对数的底数, 若 $ae^{a+1} + b < b \ln b$ , 则().

A. $ab > \mathrm{e}$

B. $b>\mathrm{e}^{a+1}$

C.ab<e

D. $b < e^{a + 1}$

分析:根据题设条件,先对不等式进行合理的恒等变形与转化,抓住不等式两边的结构特征的不同视角,可从同构函数 $f(x)=xe^{x}, f(x)=x\ln x, f(x)=\ln x+x$ 等形式入手来分析,通过导数确定相应同构函数的单调性,利用单调性及题设条件确定相应的不等关系.

解析:依题知 a>0, b>0, 而由 $ae^{a+1}+b<b\ln b$ ,
移项可得 $ae^{a+1}<b(\ln b-1)=b\ln\frac{b}{e}$ .

变形整理,可得 $ae^{a}<\frac{b}{e}\ln\frac{b}{e}$ .

以下通过不同的同构法思维来判断.

法一: 同构左侧形式函数.

由于 $a\mathrm{e}^a < \frac{b}{\mathrm{e}}\ln \frac{b}{\mathrm{e}} = \ln \frac{b}{\mathrm{e}}\cdot \mathrm{e}^{\ln \frac{b}{\mathrm{e}}}$ ，同构函数 $f(x) = x\mathrm{e}^{x}$ ，则有 $f(a) <   f\left(\ln \frac{b}{\mathrm{e}}\right)$ ，而 $a > 0,\ln \frac{b}{\mathrm{e}} >0.$

当 x>0 时， $f'(x)=\mathrm{e}^{x}+xe^{x}>1>0$ ，所以 $f(x)$ 在 $(0,+\infty)$ 上单调递增.

所以 $a < \ln \frac{b}{\mathrm{e}}$ ，即 $\mathrm{e}^a < \frac{b}{\mathrm{e}}$ ，亦即 $\mathrm{e}^{a + 1} < b$ 。

故选择答案:B.

法二: 同构右侧形式函数.

由于 $\mathrm{e}^a\ln \mathrm{e}^a = a\mathrm{e}^a < \frac{b}{\mathrm{e}}\ln \frac{b}{\mathrm{e}}$ ，同构函数 $f(x) = x\ln x$ ，则有 $f(\mathrm{e}^a) < f\left(\frac{b}{\mathrm{e}}\right)$ ，而 $\mathrm{e}^a > 1$ ，且 $\ln \frac{b}{\mathrm{e}} > 0$ ，即 $\frac{b}{\mathrm{e}} > 1.$

当 x>1 时， $f'(x)=\ln x+1>0$ ，所以 $f(x)$ 在 $(1,+\infty)$ 上单调递增.

所以 $e^{a}<\frac{b}{e}$ ，即 $e^{a+1}<b$ 。故选择答案：B.

法三: 同构取对数形式函数.

易得 $\mathrm{e}^{\ln a + a} = a\mathrm{e}^{a} <   \frac{b}{\mathrm{e}}\ln \frac{b}{\mathrm{e}} = \mathrm{e}^{\ln (\ln \frac{b}{\mathrm{e}}) + \ln \frac{b}{\mathrm{e}}}.$

两边同取对数，有 $\ln a + a < \ln \left(\ln \frac{b}{\mathrm{e}}\right) + \ln \frac{b}{\mathrm{e}}$ ，同构函数 $f(x) = \ln x + x$ ，则有 $f(a) < f\left(\ln \frac{b}{\mathrm{e}}\right)$ ，而 $a > 0, \ln \frac{b}{\mathrm{e}} > 0.$

当 x>0 时， $f'(x)=\frac{1}{x}+1>0$ ，所以 $f(x)$ 在 $(0,+\infty)$ 上单调递增.

所以 $a < \ln \frac{b}{\mathrm{e}}$ ，即 $\mathrm{e}^a < \frac{b}{\mathrm{e}}$ ，亦即 $\mathrm{e}^{a + 1} < b$ 。

故选择答案:B.

点评:涉及指对同构法解决函数及其相关的综合问题时,关键就是借助“指(数)对(数)”混合不等式(或等式、方程等)加以恒等变形,此时参变分离的难度比较大,可侧重于指数或对数,目的都是构建同型或共性,不同视角的变形对应不同的函数形式,往往同构函数并不单一,但殊途同归,都能实现问题的突破与解决.

# 3 放缩同构

在解决一些涉及指数或对数不等式(或等式、方程等)问题时,经常要借助常见的切线不等式 $e^{x}\geqslant x+1$ (当且仅当x=0时等号成立), $\ln x\leqslant x-1$ (当且仅当x=1时等号成立)等对应“二级结论”加以放缩处理,在此基础上进行有针对性的同构,实现问题的巧妙解决.

例 3 （2022 届江苏省南京市、盐城市高三年级第二次模拟考试数学试卷）已知实数 $a, b \in (1, +\infty)$ ，且 $2(a + b) = e^{2a} + 2\ln b + 1$ ，e 为自然对数的底数，则（）.

A.1<b<a

B. $a < b < 2a$

C.2a<b<e $^{a}$

D. $e^{a}<b<e^{2a}$

分析:根据题设条件,结合代数关系式的恒等变形,并通过基本不等式、切线不等式的放缩处理进行“两边夹”构建,合理同构函数,借助函数的单调性判断与性质应用,结合不等式的性质与求解来转化与判断相关代数式的大小关系.

解析:依题 $a, b \in (1, +\infty)$ ，将 $2(a + b) = \mathrm{e}^{2a} + 2\ln b + 1$ 变形得 $e^{2a} - 2a + 1 = 2b - 2\ln b$ .

利用基本不等式, 可得 $2b - 2\ln b < b^{2} + 1 - 2\ln b = b^{2} - \ln b^{2} + 1$ (这里取不到等号);

又利用切线不等式,可得 $2b-2\ln b=(b-\ln b)+(b-\ln b)>b-\ln b+1$ (这里也取不到等号).

所以 $b - \ln b + 1 < e^{2a} - 2a + 1 = 2b - 2\ln b < b^{2} - \ln b^{2} + 1.$

同构函数 $f(x)=\mathrm{e}^{x}-x+1,x>0$ ，则以上不等式转化为 $f(\ln b)<f(2a)<f(\ln b^{2})$ .

而 $f'(x)=\mathrm{e}^{x}-1>0$ ，则知 $f(x)$ 在 $(0,+\infty)$ 上单调递增.

所以 $\ln b<2a<\ln b^{2}$ ，即 $b<e^{2a}<b^{2}$ ，可得 $e^{a}<b$ 。

综合可得 $e^{a}<b<e^{2a}$ . 故选择答案: D.

例 4 （广东省 2024 届普通高中毕业班第二次调研考试数学试题）已知函数 $f(x)=x\left(\mathrm{e}^{x-1}-2a\right)-\ln x$ 的最小值为 0，则实数 a 的值为 \_\_\_\_.

分析:根据题设条件,结合函数解析式的结构特征,通过函数关系式的同构法处理,利用函数切线不等式“ $e^{x}\geqslant x+1$ ,当且仅当x=0时等号成立”,合理放缩处理,借助等号成立时的条件来确定参数的值.

解析:由函数 $f(x)=x\left(\mathrm{e}^{x-1}-2a\right)-\ln x$ 的最小值为 0, 结合切线不等式, 可知

$$
\begin{array}{c} f (x) = x \mathrm{e} ^ {x - 1} - 2 a x - \ln x = \mathrm{e} ^ {\ln x + x - 1} - 2 a x - \\ \ln x \geqslant (\ln x + x) - 2 a x - \ln x = (1 - 2 a) x \geqslant 0, \end{array}
$$

当且仅当 $\left\{\begin{aligned}\ln x+x-1=0,\\ 1-2a=0\end{aligned}\right.$ 时，函数 $f(x)$ 取得最小值0，此时 $x=1,a=\frac{1}{2}$ .

故填答案: $\frac{1}{2}$ .

点评: 涉及利用放缩同构法解决函数及其相关的综合问题时, 往往离不开重要的切线不等式以及其他不等式(基本不等式等)及其性质的放缩处理, 通过合理的放缩变形, 才能更加有效地寻找不等式(或等式)的同型或共性, 为下一步同构函数指明方向并提供条件, 实现问题的巧妙解决.

利用同构函数法解决函数及其相关的综合问题，其实质就是通过等价变形使得不等式(或等式)两边的式子结构相同，从而将两边看成是同一个函数的两个函数值，借助该同构函数的单调性转化不等式(或等式)，从而解决问题。利用同构函数法时，在学会利用同构变形，掌握思想与方法的过程中不断形成知识体系，形成敏锐的观察能力。巧妙的恒等变形等都是同构函数法的根本要求，在很好考查考生“四基”的同时，对于考生的数学建模、数学抽象以及数学运算等核心素养也有很好的涉及，有效提升数学的优良品质，提高数学思维能力。Z
