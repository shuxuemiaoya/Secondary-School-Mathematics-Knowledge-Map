# 三角形中的最值或范围问题

# ● 贵州省望谟民族中学 陈军

在高中数学知识体系中,三角形中的最值(范围)问题占据重要地位.这类问题常常紧密结合三角形的边角关系、三角函数、函数与不等式等知识,全面考查学生对多方面知识的综合运用能力与数学思维水平.

三角形中的最值(范围)问题是一类重要且具挑战性的题型.它不仅综合考查三角函数、函数与不等式等多方面知识,还对学生的数学思维与解题能力有较高要求.求解此类问题,需灵活运用各种数学方法与技巧.学生在面对此类问题时,往往因涉及知识众多、解题方法灵活多变而感到困难.本文中将详细介绍利用三角函数的性质、构造新元函数以及运用基本不等式这三种常用方法.

# 1 利用三角函数的性质求最值(范围)

例 1 在 $\triangle ABC$ 中, 角 A, B, C 的对边分别为 a, b, c, 已知 $\cos 2A + \cos 2B - \cos 2C = 1 - 2\sin A\sin B$ .

(1)求角 C 的大小;

(2) 求 $\sin A + \sin B + \sin C$ 的取值范围.

解:(1) 因为 $\cos 2A + \cos 2B - \cos 2C = 1 - 2\sin A \sin B$ , 所以

$$
\begin{array}{c} 1 - 2 \sin^ {2} A + 1 - 2 \sin^ {2} B - (1 - 2 \sin^ {2} C) = 1 - \\ 2 \sin A \sin B. \end{array}
$$

整理, 得 $\sin^{2}A + \sin^{2}B - \sin^{2}C = \sin A \sin B.$

由正弦定理，得 $a^{2}+b^{2}-c^{2}=ab$ .

由余弦定理, 得 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=\frac{1}{2}$ .

又 $C \in (0, \pi)$ , 所以 $C = \frac{\pi}{3}$ .

(2)由(1)，可得

$$
\begin{array}{l} \sin A + \sin B + \sin C = \sin A + \sin \left(\frac {2 \pi}{3} - A\right) + \\ \frac {\sqrt {3}}{2} = \sin A + \sin \frac {2 \pi}{3} \cos A - \cos \frac {2 \pi}{3} \sin A + \frac {\sqrt {3}}{2} = \frac {3}{2} \sin A + \\ \frac {\sqrt {3}}{2} \cos A + \frac {\sqrt {3}}{2} = \sqrt {3} \sin \left(A + \frac {\pi}{6}\right) + \frac {\sqrt {3}}{2}. \\ \end{array}
$$

在 $\triangle ABC$ 中，由 $C=\frac{\pi}{3}$ ，得 $0<A<\frac{2\pi}{3}$ .

所以 $\frac{\pi}{6} < A + \frac{\pi}{6} < \frac{5\pi}{6}$ , 则 $\frac{1}{2} < \sin \left(A + \frac{\pi}{6}\right) \leqslant 1$ , 可

得 $\sqrt{3} < \sqrt{3}\sin \left(A + \frac{\pi}{6}\right) + \frac{\sqrt{3}}{2} \leqslant \frac{3\sqrt{3}}{2}$ .

所以 $\sin A + \sin B + \sin C$ 的取值范围为 $\left(\sqrt{3},\frac{3\sqrt{3}}{2}\right]$

点评:先利用正弦定理化角为边,再利用三角形内角和定理和辅助角公式,将目标函数转化为只含一个角的三角函数,最后利用三角函数的性质求解.

例 2 在 $\triangle ABC$ 中, 内角 A, B, C 所对的边分别是 a, b, c, $\frac{\sqrt{2}\sin A+1}{1-\sqrt{2}\cos A}=\frac{\sin C}{\cos C}$ .

(1) 若 $B=\frac{\pi}{6}$ ，求 C；  
(2) 若 $B \in \left[\frac{\pi}{6}, \frac{\pi}{4}\right)$ , 求 $\frac{c}{b}$ 的取值范围.

解:(1) 因为 $\frac{\sqrt{2}\sin A+1}{1-\sqrt{2}\cos A}=\frac{\sin C}{\cos C}$ ，所以可知 $\left\{\begin{aligned}\cos C&\neq0,\\ \cos A&\neq\frac{\sqrt{2}}{2},\end{aligned}\right.$ 即 $\left\{\begin{aligned}C\neq\frac{\pi}{2},\\ A\neq\frac{\pi}{4}.\\\end{aligned}\right.$

所以 $\sqrt{2}\sin A\cos C + \cos C = \sin C - \sqrt{2}\cos A\sin C$ 即 $\sqrt{2}\sin (A + C) = \sin C - \cos C.$

又 $A + B + C = \pi$ ，所以 $\sqrt{2}\sin B = \sqrt{2}\sin \left(C - \frac{\pi}{4}\right)$

所以 $B=C-\frac{\pi}{4}$ 或 $B+C-\frac{\pi}{4}=\pi$ (舍去)，当 $B=\frac{\pi}{6}$ 时， $C=\frac{5\pi}{12}$ .

(2)由(1)结合正弦定理,得

$$
\begin{array}{l} \frac {c}{b} = \frac {\sin C}{\sin B} = \frac {\sin \left(B + \frac {\pi}{4}\right)}{\sin B} = \frac {\frac {\sqrt {2}}{2} (\sin B + \cos B)}{\sin B} = \\ \frac {\sqrt {2}}{2} \left(1 + \frac {1}{\tan B}\right). \\ \end{array}
$$

因为 $B \in \left[\frac{\pi}{6}, \frac{\pi}{4}\right)$ , 所以 $\tan B \in \left[\frac{\sqrt{3}}{3}, 1\right)$ .

因为函数 $y = \frac{\sqrt{2}}{2}\left(1 + \frac{1}{x}\right)$ 在 $\left[\frac{\sqrt{3}}{3}, 1\right)$ 上单调递减，

所以 $\frac{c}{b}$ 的取值范围为 $\left(\sqrt{2}, \frac{\sqrt{6} + \sqrt{2}}{2}\right]$ .

# 2 构造转化为新元函数求最值(范围)

例 3 $\triangle ABC$ 的三个内角为 A, B, C，求当 A 为何值时， $\cos A + 2\cos \frac{B + C}{2}$ 取得最大值，并求出这个最大值.

解：由 $A + B + C = \pi$ ，得 $\frac{B + C}{2} = \frac{\pi}{2} -\frac{A}{2}$ ，则 $\cos \frac{B + C}{2} = \sin \frac{A}{2}.$

所以 $\cos A + 2\cos \frac{B + C}{2} = \cos A + 2\sin \frac{A}{2} = 1 - 2\sin^2\frac{A}{2} + 2\sin \frac{A}{2}$ .

令 $t = \sin \frac{A}{2}$ ，由 $0 < A < \pi$ ，得 $0 < \frac{A}{2} < \frac{\pi}{2}$ ，则 $t \in (0,1)$ ，所以原式可看作关于 $t$ 的二次函数，即

$$
y = - 2 \left(t - \frac {1}{2}\right) ^ {2} + \frac {3}{2}.
$$

故当 $t=\frac{1}{2}$ ，即 $\sin\frac{A}{2}=\frac{1}{2}, A=\frac{\pi}{3}$ 时， $\cos A+2\cos\frac{B+C}{2}$ 取得最大值，最大值为 $\frac{3}{2}$ .

点评:利用换元法构造关于新元且熟知的函数(如一次函数,二次函数,指数函数,对数函数等),在新元所在的区间内求最值(范围),有时也可利用导数求最值(范围).

# 3 运用基本不等式求最值(范围)

例 4 在 $\triangle ABC$ 中, 内角 A, B, C 所对的边分别为 a, b, c, 已知 $\sqrt{3}(a^{2}+c^{2}-b^{2})=-2ab\sin C$ .

(1) 求角 B;

(2) 若 D 为 AC 的中点, 且 BD = 2, 求 $\triangle ABC$ 面积的最大值.

解:(1)由 $\sqrt{3}(a^{2}+c^{2}-b^{2})=-2ab\sin C$ ，可以得到 $\sqrt{3}(a^{2}+c^{2}-b^{2})=-2ac\sin B$ ，即

$$
\frac {\sqrt {3} \left(a ^ {2} + c ^ {2} - b ^ {2}\right)}{2 a c} = - \sin B.
$$

由余弦定理, 得 $\sqrt{3}\cos B = -\sin B$ .

因为 $\cos B \neq 0$ ，所以 $\tan B = -\sqrt{3}$ .

又 $0 < B < \pi$ ，所以 $B = \frac{2\pi}{3}$

(2)由 $\overrightarrow{BD}=\frac{1}{2}(\overrightarrow{BA}+\overrightarrow{BC})$ ，可得

$$
\overrightarrow {B D} ^ {2} = \frac {1}{4} \overrightarrow {B A} ^ {2} + \frac {1}{2} \overrightarrow {B A} \cdot \overrightarrow {B C} + \frac {1}{4} \overrightarrow {B C} ^ {2}.
$$

所以 $\frac{1}{4} c^2 +\frac{1}{2} ac\cos \frac{2\pi}{3} +\frac{1}{4} a^2 = 4$ ，即

$$
a ^ {2} + c ^ {2} - a c = 1 6.
$$

又 $a^2 + c^2 \geqslant 2ac$ ，所以 $ac \leqslant 16$ .

所以 $S_{\triangle ABC}=\frac{1}{2}ac\sin\frac{2\pi}{3}\leqslant\frac{1}{2}\times16\sin\frac{2\pi}{3}=4\sqrt{3}$ ，当且仅当 a=4, c=4 时取等号.

故 $\triangle ABC$ 面积的最大值为 $4\sqrt{3}$ .

点评:在解三角形问题中,常利用 $a+b\geqslant2\sqrt{ab}$ (a,b>0,当且仅当 a=b 时取等号)及其变形来求解最值,解题时需注意满足“一正二定三相等”条件.

例 5 记 $\triangle ABC$ 的内角 A, B, C 的对边分别为 a, b, c，已知 $\cos C + (\cos B - 2\sqrt{2}\sin B)\cos A = 0$ .

(1) 求 $\cos A$ 的值；

(2) 若 $b + c = 1$ ，求 a 的取值范围.

解:(1)由 $\cos C+(\cos B-2\sqrt{2}\sin B)\cos A=0$ ，及 $\cos C=-\cos(A+B)=-\cos A\cos B+\sin A\sin B$ ，可得

$-\cos A\cos B + \sin A\sin B + \cos A\cos B - 2\sqrt{2}\sin B\cos A = 0.$

整理, 得 $\sin A \sin B - 2\sqrt{2} \sin B \cos A = 0$ .

又因为 $0 < B < \pi, 0 < A < \pi$ ，则 $\sin B \neq 0$ ，所以 $\sin A = 2\sqrt{2} \cos A > 0$ 。结合 $\sin^2 A + \cos^2 A = 1$ ，可得 $9\cos^2 A = 1$ ，又 $A$ 为锐角，所以 $\cos A = \frac{1}{3}$ 。

(2)由余弦定理,知

$$
a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos A = (b + c) ^ {2} - \frac {8}{3} b c.
$$

因为 $bc \leqslant \left(\frac{b + c}{2}\right)^2$ ，所以 $a^2 \geqslant \frac{1}{3} (b + c)^2 = \frac{1}{3}$ ，于是 $a \geqslant \frac{\sqrt{3}}{3}$ ，当且仅当 $b = c = \frac{1}{2}$ 时，等号成立。

又 $a < b + c = 1$ ，所以 $a$ 的取值范围为 $\left[\frac{\sqrt{3}}{3}, 1\right)$ .

利用三角函数性质,关键在于准确把握三角函数的有界性与单调性,通过边与角的相互转化构建与三角函数相关的表达式,进而求解最值(范围).构造新元函数方法,需要依据三角形的边长或角度关系,巧妙引入新变量,将复杂的几何问题转化为函数问题,借助函数的各种性质来确定最值(范围).基本不等式的应用则着重于对其条件的精准把握和灵活变形,通过对三角形边或角关系的分析,合理运用基本不等式及其变形公式来得出最值(范围).Z
