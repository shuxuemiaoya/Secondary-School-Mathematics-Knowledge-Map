不等式是数学抽象、逻辑思维、代数推理的重要载体，能很好地综合考查学生的数学抽象、数学思维与数学运算等数学核心素养，是历年高考的重要考查内容，一般是综合性较强的难题，对学生的要求较高。但是，即便综合性很强，这里边有一个基本的重要的东西，就是基本不等式，只要我们吃透它，灵活运用基本不等式，有一定的“基本不等式情结”，往往可以顺利解决问题。

两个非负数的算术平均数不小于它们的几何平均数，即 $\frac{a + b}{2} \geqslant \sqrt{ab} (a \geqslant 0, b \geqslant 0)$ 称为基本不等式，人教版教材称之为“重要不等式”。无论是“基本不等式”，还是“重要不等式”，都足以说明这个不等式的基础性与重要性，它有多种变形与推广，是很多常用不等式的特例，基本不等式是高考的重点考查对象。下面以一道不等式为例，具体说明证明、加强与推广。

# 一、试题呈现

已知 $a, b, c$ 为正数，且满足 $abc = 1$ ，证明：

(1) $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \leqslant a^2 + b^2 + c^2$ ;   
(2) $(a + b)^{3} + (b + c)^{3} + (c + a)^{3} \geqslant 24$ .

# 二、不等式的证明

# 1. 第(1)小问的证明

证法1: 因为 $abc = 1$ , 所以 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = \frac{abc}{a} + \frac{abc}{b} + \frac{abc}{c} = bc + ac + ab$ . 由基本不等式可得 $bc \leqslant \frac{b^2 + c^2}{2}, ac \leqslant \frac{a^2 + c^2}{2}, ab \leqslant \frac{a^2 + b^2}{2}$ , 于是得到 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \leqslant \frac{b^2 + c^2}{2} + \frac{a^2 + c^2}{2} + \frac{a^2 + b^2}{2} = a^2 + b^2 + c^2$ . (当且仅当 $a = b = c = 1$ 时, 不等式等号成立)

证法 2: 因为 abc = 1, 由基本不等式得 $a^{2} + b^{2} \geqslant 2ab = \frac{2}{c}, b^{2} + c^{2} \geqslant 2bc = \frac{2}{a}, c^{2} + a^{2} \geqslant 2ca = \frac{2}{b}$ , 三式

相加得 $2(a^{2} + b^{2} + c^{2})\geqslant \frac{2}{a} +\frac{2}{b} +\frac{2}{c}$ 即 $a^2 +b^2+$ $c^2\geqslant \frac{1}{a} +\frac{1}{b} +\frac{1}{c}$ （当且仅当 $a = b = c = 1$ 时，不等式等号成立）

评注:以上证法中,证法1是运用基本不等式 $ab \leqslant \frac{a^{2} + b^{2}}{2}$ ,从左边证到右边;证法2是运用基本不等式 $a^{2} + b^{2} \geqslant 2ab$ ,从右边证到左边.这两种证法都是运用基本不等式,体现了“基本不等式情结”.

# 2. 第(2) 小问的证明

证法1:由基本不等式得到 $a+b\geqslant2\sqrt{ab}\Rightarrow(a+b)^{3}\geqslant8(ab)^{\frac{3}{2}}$ , $b+c\geqslant2\sqrt{bc}\Rightarrow(b+c)^{3}\geqslant8(bc)^{\frac{3}{2}}$ , $c+a\geqslant2\sqrt{ac}\Rightarrow(c+a)^{3}\geqslant8(ac)^{\frac{3}{2}}$ ，于是得到 $(a+b)^{3}+(b+c)^{3}+(c+a)^{3}\geqslant8[(ab)^{\frac{3}{2}}+(bc)^{\frac{3}{2}}+(ac)^{\frac{3}{2}}]\geqslant8\times3\sqrt[5]{(ab)^{\frac{3}{2}}(bc)^{\frac{3}{2}}(ca)^{\frac{3}{2}}}=24.$ （当且仅当a=b=c=1时，不等式等号成立）

证法2:由均值不等式得 $(a+b)^{3}+(b+c)^{3}+(c+a)^{3}\geqslant3(a+b)(b+c)(c+a)\geqslant3\times2\sqrt{ab}\times2\sqrt{bc}\times2\sqrt{ca}=24abc=24.$ （当且仅当a=b=c=1时，不等式等号成立）

证法3: 因为 $(a+b)^{3}=(a^{3}+b^{3})+3ab(a+b),(b+c)^{3}=(b^{3}+c^{3})+3bc(b+c),(c+a)^{3}=(c^{3}+a^{3})+3ca(c+a)$ ，三式相加得 $(a+b)^{3}+(b+c)^{3}+(c+a)^{3}=2(a^{3}+b^{3}+c^{3})+3[ab(a+b)+bc(b+c)+ca(c+a)]=2(a^{3}+b^{3}+c^{3})+3[a(b^{2}+c^{2})+b(c^{2}+a^{2})+c(a^{2}+b^{2})]\geqslant2\times3abc+3(2abc+2abc+2abc)=24abc=24.$ （当且仅当a=b=c=1时，不等式等号成立）

评注:以上证法中,证法1是把基本不等式两边三次方,得到所要证明的目标: $a+b\geqslant2\sqrt{ab}\Rightarrow(a+b)^{3}\geqslant8(ab)^{\frac{3}{2}}$ ,然后再相加处理,最后运用三个非负数的算术平均数不小于其几何平均数的均值不等式证得;而证法2与证法1刚好反过来,是先用基本不等式,再用均值不等式;证法3则是把所要证的目标展开相加 $(a+b)^{3}=(a^{3}+b^{3})+3ab(a+b)$ ,并重新组合,再运用基本不等式证明 $2(a^{3} + b^{3} + c^{3}) + 3[a(b^{2} + c^{2}) + b(c^{2} + a^{2}) + c(a^{2} + b^{2})]\geqslant 2\times 3abc + 3(2abc + 2abc$ $+2abc) = 24abc = 24.$

这三种证法无一例外地运用了基本不等式，再一次体现了“基本不等式情结”.

# 四、不等式的推广

# 1. 第(1)小问的推广

推广1: 若 a, b, c, d 为正数, 且满足 abcd = 1, 则

$$
\begin{array}{l} \frac {1}{a b} + \frac {1}{b c} + \frac {1}{c a} \leqslant a ^ {2} + b ^ {2} + c ^ {2} + d ^ {2} - \\ 2 \sqrt {\left| (a - b) (b - c) (c - d) (d - a) \right|}. \\ \end{array}
$$

推广2: 若 $a_{1}, a_{2}, a_{3}, \cdots, a_{n}$ 为正数(其中 n 为正整数)，且满足 $a_{1}a_{2}a_{3}\cdots a_{n}=1$ ，则

$$
\begin{array}{l} \frac {1}{a _ {1} a _ {2} \cdots a _ {n - 2}} + \frac {1}{a _ {2} a _ {3} \cdots a _ {n - 1}} + \frac {1}{a _ {n} a _ {1} \cdots a _ {n - 3}} \leqslant a _ {1} ^ {2} + a _ {2} ^ {2} \\ + \dots + a _ {n} ^ {2} - \frac {n}{2} \sqrt [ n ]{(a _ {1} - a _ {2}) ^ {2} (a _ {2} - a _ {3}) ^ {2} \cdots (a _ {n} - a _ {1}) ^ {2}}. \\ \end{array}
$$

# 2. 第(2) 小问的推广

推广1: 若 a, b, c 为正数, 且满足 abc = 1, $\lambda > 0$ , 则 $(a + b)^{\lambda + 2} + (b + c)^{\lambda + 2} + (c + a)^{\lambda + 2} \geqslant 3 \times 2^{\lambda + 2} + (a + b)^{\lambda + 2}(a - b)^{2} + (b + c)^{\lambda + 2}(b - c)^{2} + (c + a)^{\lambda + 2}(c - a)^{2}$ .

推广2: 若 $a_{1}, a_{2}, a_{3}, \cdots, a_{n}$ 为正数(其中 n 为正整数)，且满足 $a_{1}a_{2}a_{3}\cdots a_{n}=1, \lambda>0$ ，则 $(a_{1}+a_{2})^{\lambda+2}+(a_{2}+a_{3})^{\lambda+2}+\cdots+(a_{n}+a_{1})^{\lambda+2}\geqslant3\times2^{\lambda+2}+(a_{1}+a_{2})^{\lambda+2}(a_{1}-a_{2})^{2}+(a_{2}+a_{3})^{\lambda+2}(a_{2}-a_{3})^{2}+\cdots+(a_{n}+a_{1})^{\lambda+2}(a_{n}-a_{1})^{2}$ .

评注: 第(1)小问的推广是把 a, b, c 推广到 $a_{1}$ , $a_{2}$ , $a_{3}$ , $\cdots$ , $a_{n}$ ，是 $a_{n}$ 个数上的推广，第(2)小问的推广不仅仅是 $a_{n}$ 个数上的推广，还有次数上的推广.

以上这道不等式,无论是其证明、加强,还是推广,都离不开基本不等式 $\frac{a+b}{2}\geqslant\sqrt{ab}(a\geqslant0,b\geqslant0)$ 及其变形公式的运用,而且自始至终体现了代数式中元素可轮换之美,可谓“美轮美奂”.F
