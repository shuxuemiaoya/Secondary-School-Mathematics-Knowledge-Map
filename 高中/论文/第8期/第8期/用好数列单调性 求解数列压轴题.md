# 用好数列单调性 求解数列压轴题

# ● 江苏省盱眙中学 陈海波

在研究函数的性质的问题中, 函数的单调性地位举足轻重. 因为有了函数的单调性就可以研究函数的极值、最值等其他的性质. 那么在研究数列的问题中, 数列的单调性的作用同样重要, 因为数列本身就是一种特殊的函数. 有了数列的单调性, 同样可以研究数列的极值和最值等其他性质.

数列 $\{a_{n}\}$ 中，若对任意 $n\in \mathbf{N}^*$ ，都有 $a_{n + 1} - a_n >$ $0(<  0)$ 成立，则称数列 $\{a_{n}\}$ 单调递增(递减)；若对任意 $n\in \mathbf{N}^*$ ，都有 $a_{n + 1} - a_n\geqslant 0(\leqslant 0)$ 成立，则称数列 $\{a_{n}\}$ 单调不减(不增).

高中数列问题中，对于等差数列 $\{a_{n}\}$ 来说， $d > 0$ 时， $\{a_{n}\}$ 单调递增； $d < 0$ 时， $\{a_{n}\}$ 单调递减。对于等比数列 $\{a_{n}\}$ 且 $a_{1} > 0$ 来说， $q > 1$ 时， $\{a_{n}\}$ 单调递增； $q = 1$ 时， $\{a_{n}\}$ 为常数列； $0 < q < 1$ 时， $\{a_{n}\}$ 单调递增； $-1 < q < 0$ 时， $\{a_{2n}\}$ 单调递减， $\{a_{2n-1}\}$ 单调递增； $q = -1$ 时， $\{a_{2n}\}, \{a_{2n-1}\}$ 均为常数列； $q < -1$ 时， $\{a_{2n}\}$ 单调递增， $\{a_{2n-1}\}$ 单调递减。等比数列 $\{a_{n}\}$ 且 $a_{1} < 0$ 时的单调性问题同样研究。对于数列 $f(n)(n \in \mathbf{N}^{*})$ 来说，单调性可以对比函数 $f(x)$ 来研究；对于等差数列、等比数列、二次型数列的加减乘除型的单调性问题的研究，常常在数列的压轴题中出现。本文结合例题谈谈数列单调性在压轴题中的应用。

# 一、求解数列中的不定方程问题

例1 已知 $n \in \mathbf{N}^*$ , 数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$ , 且 $S_n = a_{n+1} - a_1$ ; 数列 $\{b_n\}$ 的前 $n$ 项和为 $T_n$ , 且满足 $T_n + b_n = n + \frac{1}{2} n (1 + b_n)$ , 且 $a_2 = b_4 = 4$ .

(1) 求数列 $\{a_{n}\}$ 的通项公式.

(2) 求数列 $\{b_{n}\}$ 的通项公式.

(3) 设 $c_{n}=\frac{a_{n}}{b_{n}}$ ，问：数列 $\{c_{n}\}$ 中是否存在不同两项 $c_{i}, c_{j} (1 \leqslant i < j, i, j \in \mathbf{N}^{*})$ ，使 $c_{i} + c_{j}$ 仍是数列 $\{c_{n}\}$ 中的项？若存在，请求出 i, j；若不存在，请说明理由.

解析:(1)(2)略.

(3) 因为 $c_{n}=\frac{2^{n}}{n}$ ，假设存在 i,j,k ( $1\leqslant i\leqslant j$ )，使得 $c_{i}+c_{j}=c_{k}$ .

因为 $c_{n + 1} - c_n = \frac{2^{n + 1}}{n + 1} -\frac{2^n}{n} = \frac{2^n(n - 1)}{n(n + 1)}\geqslant 0$ ，得 $c_{1}$ $= c_{2} <   c_{3} <   \dots <  c_{n}$ ，所以 $c_{k} > c_{j}\geqslant c_{i}$ 即 $k > j\geqslant i.$

① 当 $k \geqslant j + 3$ 时， $\frac{2^{j+1}}{j} \geqslant \frac{2^i}{i} + \frac{2^j}{j} = \frac{2^k}{k} \geqslant \frac{2^{j+3}}{j + 3}$ ，即 $\frac{2^{j+1}}{j} \geqslant \frac{2^{j+3}}{j + 3}$ ，解得 $j \leqslant 1$ 舍去；

② 当 $k = j + 2$ 时， $\frac{2^{j+1}}{j} \geqslant \frac{2^i}{i} + \frac{2^j}{j} = \frac{2^k}{k} \geqslant \frac{2^{j+2}}{j + 2}$ ，即 $\frac{2^{j+1}}{j} \geqslant \frac{2^{j+3}}{j + 3}$ ，解得 $j \leqslant 2$ ，因为 $i = 1, j = 2, k = 4$ 时， $c_i + c_j = c_k$ 成立，所以 $i = 1, j = 2$ 满足；

③ 当 $k = j + 1$ 时， $\frac{2^{j+1}}{j + 1} = \frac{2^i}{i} + \frac{2^j}{j}$ ，即 $i2^{j-i} = \frac{j(j + 1)}{j - 1}$ ，因为 $\frac{j(j + 1)}{j - 1}$ 是正整数， $j$ 的值只能为3，又 $j = 3$ 时，有 $\frac{2^i}{i} = \frac{4}{3}$ 无整数解，舍去.

综上: i=1, j=2.

点评:本题中,关键步骤是对于 $k \geqslant j + 3$ 情况的讨论,其实这种情况是基于数列 $\left\{\frac{2^{n}}{n}\right\}$ 单调性的特征,它的单调性随着 n 的变大增长的越来越快, $\{2^{n}\}$ 的单调性起决定作用,当 $k \geqslant j + 3$ 时, $c_{i} + c_{j}$ 已经不足以和 $c_{k}$ 相等了.

# 二、求解数列中的子数列问题

例 2 若数列 $\{a_{n}\}$ 同时满足①对于任意的正整数 $n, a_{n+1} \geqslant a_{n}$ 恒成立；②对于给定的正整数 $k, a_{n-k} + a_{n+k} = 2a_{n}$ 对于任意的正整数 $n (n > k)$ 恒成立，则称数列 $\{a_{n}\}$ 是“ $R(k)$ 数列”.

(1) 已知 $a_{n}=\left\{\begin{aligned}&2n-1,n\text{为奇数},\\ &2n,n\text{为偶数},\end{aligned}\right.$ 判断数列 $\{a_{n}\}$ 是否为“R(2) 数列”，并说明理由；  
(2) 已知数列 $\{b_{n}\}$ 是 “R(3) 数列”，且存在整数 p (p > 1)，使得 $b_{3p-3}, b_{3p-1}, b_{3p+1}, b_{3p+3}$ 成等差数列，证明： $\{b_{n}\}$ 是等差数列.

解析:根据题意 $b_{n-3} + b_{n+3} = 2b_{n}$ ，则数列 $\{b_{3n-2}\}$ ， $\{b_{3n-1}\}, \{b_{3n}\}$ 是等差数列，设 $b_{3n-2} = b_{1} + (n-1)d_{1}$ ， $b_{3n-1} = b_{2} + (n-1)d_{2}, b_{3n} = b_{3} + (n-1)d_{3}$ .

因为 $b_{n}\leqslant b_{n + 1}$ ，所以 $b_{3n + 1}\leqslant b_{3n + 2}\leqslant b_{3n + 4}$

所以 $b_{1} + nd_{1}\leqslant b_{2} + nd_{2}\leqslant b_{1} + (n + 1)d_{1},$

所以 $n(d_{2} - d_{1})\geqslant b_{1} - b_{2}$ ， ①

且 $n(d_{2} - d_{1})\leqslant b_{1} - b_{2} + d_{1}$ ②

若 $d_{2} - d_{1} < 0$ ，则当 $n > \frac{b_1 - b_2}{d_2 - d_1}$ 时，①不成立；

若 $d_{2} - d_{1} > 0$ ，则当 $n > \frac{b_1 - b_2 + d_1}{d_2 - d_1}$ 时，②不成立；

若 $d_{2}=d_{1}$ 时，①② 成立；

所以 $d_{1} = d_{2}$

同理 $d_{2} = d_{3}$ ，即 $d_{1} = d_{2} = d_{3}$ ，令 $d_{1} = d_{2} = d_{3} = d$

设 $b_{3p - 1} - b_{3p - 3} = b_{3p + 1} - b_{3p - 1} = b_{3p + 3} - b_{3p + 1} = \lambda$ 则 $b_{3n - 1} - b_{3n - 2} = b_{3p - 1} + (n - 1)d - (b_{3p + 1} + (n - p - 1)d) = b_{3p - 1} - b_{3p + 1} + d = d - \lambda .$

同理可得 $b_{3n} - b_{3n - 1} = b_{3n + 1} - b_{3n} = d - \lambda$ ，所以 $b_{n + 1} - b_n = d - \lambda$ ，所以 $\{b_n\}$ 是等差数列.

点评:本题中,因为 $\{a_{n}\}$ 是单调不减的,所以 $\{a_{n}\}$ 的三个子数列的 $\{a_{3n}\},\{a_{3n-1}\},\{a_{3n-2}\}$ 公差肯定相等,否则将会推翻 $\{a_{n}\}$ 的单调不减性质.

# 三、求解数列中的参数值(范围)问题

例 3 定义首项为 1 且公比为正数的等比数列为 “M—数列”.

(1) 已知等比数列 $\{a_{n}\}$ 满足 $a_{2}a_{4}=a_{5}, a_{3}-4a_{2}+4a_{1}=0$ ，求证：数列 $\{a_{n}\}$ 为“M-数列”.  
(2) 已知数列 $\{b_{n}\}$ 满足 $b_{1} = 1, \frac{1}{S_{n}} = \frac{2}{b_{n}} - \frac{2}{b_{n+1}}$ , 其中 $S_{n}$ 为数列 $\{b_{n}\}$ 的前 $n$ 项和.

① 求数列 $\{b_{n}\}$ 的通项公式；  
② 设 $m$ 为正整数，若存在“ $M-$ 数列” $\{c_{n}\}$ ，对任意正整数 $k$ ，当 $k \leqslant m$ 时，都有 $c_{k} \leqslant b_{k} \leqslant c_{k+1}$ 成立，求 $m$ 的最大值.

解析:(1)(2)①略.

$$
② b _ {k} = k, k \in \mathbf {N} ^ {*}.
$$

因为数列 $\{c_{n}\}$ 为“M-数列”，设公比为q，所以 $c_{1}=1,q>0.$

因为 $c_{k} \leqslant b_{k} \leqslant c_{k+1}$ ，所以 $q^{k-1} \leqslant k \leqslant q^{k}$ ，其中 $k = 1, 2, \cdots, m$ .

当 $k = 1$ 时，有 $q \geqslant 1$ ;

当 $k=1,2,\cdots,m$ 时，有 $\frac{\ln k}{k}\leqslant\ln q\leqslant\frac{\ln k}{k-1}$ .

设 $f(x) = \frac{\ln x}{x} (x > 1)$ ，则 $f'(x) = \frac{1 - \ln x}{x^2}$ .

令 $f'(x) > 0$ ，得 $x \in (0, e)$ ; $f'(x) < 0$ ，得 $x \in (\mathrm{e}, +\infty)$ ; 所以在 $x \in (0, \mathrm{e})$ 上单调递增，在 $x \in (\mathrm{e}, +\infty)$ 上单调递减.

又因为 $\frac{\ln 2}{2} = \frac{\ln 8}{6} < \frac{\ln 9}{6} = \frac{\ln 3}{3}$

所以 $f(k)_{\max}=f(3)=\frac{\ln3}{3}.$

取 $q = \sqrt[3]{3}$ ，当 $k = 1,2,3,4,5$ 时， $\frac{\ln k}{k}\leqslant \ln q$ ，即 $k\leqslant q^k$

经检验知, $q^{k-1}\leqslant k$ 也成立.

因此所求 $m$ 的最大值不小于5.

若 $m \geqslant 6$ ，分别取 $k = 3, 6$ ，得 $3 \leqslant q^3$ ，且 $q^5 \leqslant 6$ ，从而 $q^{15} \geqslant 243$ ，且 $q^{15} \leqslant 216$ ，所以 $q$ 不存在。因此所求 $m$ 的最大值小于6。

综上,所求 m 的最大值为 5.

点评:本题中,题目立意是根据数列的单调性质,因为数列 $\{n\}$ 和 $\{q^{n}\}$ 都单调递增时,存在q>1对于不等式 $1\leqslant1\leqslant q\leqslant2\leqslant q^{2}\leqslant3\leqslant\cdots\leqslant q^{m-1}\leqslant m\leqslant q^{m}$ 时恒成立时,m只能是很小正整数的,因为 $\{q^{n}\}$ 递增速度比 $\{n\}$ 快得多,所以m只能在很小的时候才有不等式 $1\leqslant1\leqslant q\leqslant2\leqslant q^{2}\leqslant3\leqslant\cdots\leqslant q^{m-1}\leqslant m\leqslant q^{m}$ 成立.F
