# 纸上得来终觉浅,绝知此事要躬行

——一堂高三数学复习课的实践与反思

● 江苏省常州市北郊高级中学 沈 凯

# 一、背景阐述

以三角形为载体,通过三角恒等变换等一些代数变形,利用基本不等式研究几何量以及代数式的最值或者范围问题,是近些年江苏高考的热点.在知识的交汇处命题,旨在培养学生数学综合素养,考查数学综合能力.

这类问题主要涉及的知识点和方法有: 解三角形、三角恒等变换、代数变形和基本不等式. 其中, 三角恒等变换中的两角和与差的正弦、余弦和正切公式以及基本不等式都是江苏高考 C 级要求考查的内容, 解三角形是 B 级要求的知识点. 代数化简变形无处不在, 贯穿在整个数学教学和解题过程之中. 而学生解决此类综合问题往往束手无策, 无从下笔, 或者考虑问题不全面、不细致导致全盘皆输. 以下, 笔者结合近期开设的一节高三数学三角复习课, 引领学生就此类问题展开探讨, 力求突破重点难点, 并进行深入的教后探究与反思.

# 二、课堂实录

课堂开始,教师呈现一道例题.

例 1 在锐角三角形 ABC 中, 角 A 所对的边为 a, 若此三角形的面积为 $\frac{a^{2}}{4}$ , 则 $\tan A \tan B \tan C$ 的最小值为 \_\_\_\_.

作为高三复习课的第一个例题,应该起到开门见山、抛砖引玉的作用.笔者利用问题串的形式引导学生分析条件与结论,结合所学知识点,师生共同研讨,力求解决问题.

师:从解三角形这个角度看,“三角形的面积为 $\frac{a^{2}}{4}$ ”这个条件可以怎么处理?

生 1: 我觉得可以利用面积公式得到边与角之间的等量关系.

师:怎么跟结论“ $\tan A\tan B\tan C$ ”建立联系?

生 2: 可以将条件的弦化切.

生 3: 可以将结论的切化弦.

师:两位同学的想法都很好！就本题条件结论的形式,大家感觉哪一种方法可行性大?

生 4：还是将条件的弦化为正切，因为将 $\tan A \tan B \tan C$ 化为弦感觉式子比较麻烦.

分析至此,师生共同尝试完成解答.

呈现解答过程: 因为三角形的面积为 $\frac{a^{2}}{4}$ ，所以 $\frac{a^{2}}{4} = \frac{1}{2}bc\sin A$ ，即 $a^{2} = 2bc\sin A$ ，由正弦定理可得 $\sin^{2}A = 2\sin B\sin C\sin A$ .

由于 A 是三角形的内角, 所以 $\sin A > 0$ , 两边约去 $\sin A$ , 得 $\sin A = 2\sin B\sin C$ , 所以 $\sin(B + C) = 2\sin B\sin C$ , 即 $\sin B\cos C + \cos B\sin C = 2\sin B\sin C$ .

因为锐角三角形 ABC，所以 $\cos B\cos C > 0$ ，两边同除以 $\cos B\cos C$ ，得 $\tan B + \tan C = 2\tan B\tan C$ .

所以 $\tan A\tan B\tan C = -\tan (B + C)\tan B\tan C =$ $\frac{\tan B + \tan C}{\tan B\tan C - 1}\tan B\tan C = \frac{2(\tan B\tan C)^2}{\tan B\tan C - 1}.$

令 $t=\tan B\tan C-1$ ，由锐角三角形可知，t>0.

所以 $\tan A\tan B\tan C = \frac{2(t + 1)^2}{t} = 2\left(t + \frac{1}{t} +2\right)\geqslant$ $2\left(2\sqrt{t\cdot\frac{1}{t}} +2\right) = 8$ ，当且仅当 $t = \frac{1}{t}$ ，即 $t = 1$ ，即 $\tan B\tan C = 2$ 时取到等号.

在问题导入的形式下,师生共同完成例 1. 至此分析和解答看似已经全部结束,学生并没有提出异议. 笔者在此基础之上直接给出例题 2,且不作分析和提示,学生独立思考完成后直接投影其解题过程.

例 2 在锐角三角形 ABC 中, 角 A 所对的边为 a, 若此三角形的面积为 $\frac{\sqrt{3}}{4}a^{2}$ , 则 $\tan A\tan B\tan C$ 的最小值为 \_\_\_\_.

生 5 投影展示其解题过程: $\sqrt{3}(\tan B + \tan C) =$

$2\tan B\tan C$ ，则 $\tan A\tan B\tan C = \frac{\tan B + \tan C}{\tan B\tan C - 1}$ $\tan B\tan C = \frac{2}{\sqrt{3}} \cdot \frac{(\tan B\tan C)^{2}}{\tan B\tan C - 1}$ ，令 $t = \tan B\tan C - 1$ ，

由锐角三角形可知，t > 0，所以 $\tan A\tan B\tan C = \frac{2}{\sqrt{3}} \cdot \frac{(t+1)^{2}}{t} = \frac{2}{\sqrt{3}}\left(t + \frac{1}{t} + 2\right) \geqslant \frac{2}{\sqrt{3}}\left(2\sqrt{t \cdot \frac{1}{t}} + 2\right) = \frac{8\sqrt{3}}{3}$ ，当且仅当 $t = \frac{1}{t}$ ，即 t = 1，即 $\tan B\tan C = 2$ 时取到等号.

师:大家看一下,这位同学的做法对吗?

生 6: 我认为是正确的, 因为例 2 类比例 1 只是更改了数据, 方法没有变化.

生7:我猜答案是 $3\sqrt{3}$ ，是根据面积是 $\frac{\sqrt{3}}{4}a^{2}$ 和对称性，猜想最值应该是等边三角形的时候取到。但是跟同学5的结果就不一样了。

师:同学都比较有想法,那同学6的猜想是不是有道理呢?到底是谁的结果是正确的呢?可能出现的问题的地方在哪里?我们一起从同学的解题过程中找原因.

生8:我发现等号成立的条件不是 $\tan B\tan C=2$ ,
而应该是 $\left\{\begin{aligned}\tan B\tan C&=2,\\ \tan B+\tan C&=\frac{4}{\sqrt{3}}\end{aligned}\right.$ ，从而得到 $\tan B,\tan C$ 是一元二次方程 $x^{2}-\frac{4}{\sqrt{3}}x+2=0$ 的两根，但是这个一元二次方程的 $\Delta=\left(-\frac{4}{\sqrt{3}}\right)^{2}-4\times2=-\frac{8}{3}<0$ ，说明这个一元二次方程无解，也就是进一步说明实际上等号取不到。最小值就不对了。

生 9: 那会不会例 1 的等号就是取不到的？是不是也有问题？

师:请同学们再回过去验算一下例 1 的最小值 8 能否取到?

生10: 例1的等号当且仅当 $\left\{\begin{aligned}\tan B&=2+\sqrt{2},\\\tan C&=2-\sqrt{2}\end{aligned}\right.$ 或 $\left\{\begin{aligned}\tan C&=2+\sqrt{2},\\\tan B&=2-\sqrt{2}\end{aligned}\right.$ 时取到，所以最小值8是正确的.

师:很好！那我们再来看同学 5 的做法问题到底出在哪里？

生11:肯定是变量t的范围出了问题,之前的都是代数恒等变换,每一步都是等价的.那么最值出现问题,因为使用了基本不等式,那问题就在变量的取值范围上了.

师:同学们能再仔细思考一下,能求出 t 的准确范围到底是什么吗?

同学们陷入沉思之中. 教师留时间给学生充分思考.

生 12: 应该从 $\sqrt{3}(\tan B + \tan C) = 2\tan B\tan C$ 这个等量关系入手.

因为 $2\tan B\tan C = \sqrt{3} (\tan B + \tan C)\geqslant 2\sqrt{3}$ $\sqrt{\tan B\tan C}$ ，即 $\tan B\tan C\geqslant 3$ ，当且仅当 $\tan B = \tan C$ $= \sqrt{3}$ 时取到等号，即 $t\geqslant 2$

师:难怪同学5的做法最后的等号取不到,看来还是变量范围出问题了.那接下来应该怎么处理或者修改呢?

生 13: $\tan A \tan B \tan C = \frac{2}{\sqrt{3}} \cdot \frac{(t+1)^{2}}{t} = \frac{2}{\sqrt{3}} \cdot (t + \frac{1}{t} + 2)$ ，根据“对钩”函数的单调性，目标函数在 $[2, +\infty)$ 上单调递增。所以当 t = 2 时， $\tan A \tan B \tan C$ 取到最小值 $3\sqrt{3}$ 。

对于例2的设置,笔者只改动了条件的一个数据,整个问题的题型结构相对第一个例题来说没有发生变化.目的在于,一方面在例1师生已经共同分析完成的基础之上,让学生能够独立分析,作类比处理.另一方面,是让学生能在类比探究中发现问题,寻找原因,从而解决更深层次或者更细节关键的问题.课堂上,当学生5呈现出他的解题过程及结果后,教师并未轻易判定正误,而是提问其他学生,期待大家能参与课堂,来共同探讨.因为利用基本不等式求最值的问题,学生往往只关注最后的结果,也就是能不能得到那个“定值”,而很容易忽略其一前一后“一正二定三相等”的使用条件.想要学生对数学公式定义的理解真正通透,并能运用它们来解决其他问题.这往往不是靠教师在课堂上反复的提醒和重复,更有效的途径是能够引导学生对概念和同类问题进行反思优化.这样,经过学生积极的课堂参与、讨论和思考,不仅发现并解决了例2的问题,更可贵的是能够对看似已经完成的例1做到再反思,再验证.举一反三,触类旁通.至此,趁热打铁,笔者给出本节课的第三个也是最后一个题例.问题的条件结论形式上依旧与前两道例题非常相似,但又有细微变动,旨在进一步引导学生加深对此类问题的理解,力求对重难点予以突破.

例 3 在钝角三角形 ABC 中, 角 A 的对边为 a, 若此三角形的面积为 $\frac{a^{2}}{4}$ , 则 $\tan A + \tan B \tan C$ 的最大值

为\_\_\_\_。

生14: 条件化为 $\tan B + \tan C = 2\tan B\tan C$ ，故 $\tan A + \tan B\tan C = \frac{\tan B + \tan C}{\tan B\tan C - 1} + \tan B\tan C = \frac{2\tan B\tan C}{\tan B\tan C - 1} + \tan B\tan C$ ，令 $t = \tan B\tan C - 1$ ，根据 $2\tan B\tan C = (\tan B + \tan C) \geqslant 2\sqrt{\tan B\tan C}$ ，即 $\tan B\tan C \geqslant 1$ ，当且仅当 $\tan B = \tan C = 1$ 时取到等号，但是此时 $\triangle ABC$ 是直角三角形，所以等号取不到，则 $\tan B\tan C > 1$ ，即 t > 0。

所以 $\tan A + \tan B\tan C = \frac{2(t + 1)}{t} +t + 1 = t + \frac{2}{t}$ $+3\geqslant 2\sqrt{t\cdot\frac{2}{t}} +3 = 2\sqrt{2} +3.$

师:请大家来看看这次出现的新问题又是什么原因?同学14求出了最小值,却没有顺利求出最大值.

生 15: 同学 14 的做法里面用基本不等式求 t 的范围那一步不对. 使用基本不等式求最值要满足“一正, 二定, 三相等”, “一正”也就是“t > 0”这个范围应该是有问题的.

师:很好！基本不等式的使用一定要满足“一正，二定，三相等”.之前例2我们就是在“三相等”上出了问题.那这个题目里面 $\tan B$ 和 $\tan C$ 都是正的吗？显然这个题目的背景跟前两题不同，变成了钝角三角形.那么问题就变成了需要去考虑 $\triangle ABC$ 中哪个角是钝角呢?

生16:我是这么想的. 最后要能求出目标函数的最大值, 变量 $t$ 的取值应该能取到负值. 也就是说角 $B$ 或者角 $C$ 中应该有一个是钝角. 我用反证法思考了一下: 假设角 $A$ 是钝角, 则角 $B$ 和角 $C$ 都是锐角, 那么 $2 \tan B \tan C = (\tan B + \tan C) \geqslant 2 \sqrt{\tan B \tan C}$ , 即 $\tan B \tan C \geqslant 1$ , 当且仅当 $\tan B = \tan C = 1$ 时取到等号, 但是此时 $\triangle ABC$ 是直角三角形, 所以等号取不到, 则 $\tan B \tan C > 1$ 这一步就对了, 但是 $\tan A = \frac{\tan B + \tan C}{\tan B \tan C - 1} > 0$ , 这与假设矛盾, 所以角 $A$ 一定不是钝角. 那么角 $B$ 或者角 $C$ 中应该有一个是钝角, 此时, 不妨设角 $B$ 是钝角, 则 $\tan B \tan C < 0$ , 那么 $t < -1$ , 所以 $\tan A + \tan B \tan C = \frac{2(t + 1)}{t} + t + 1 = -\left[(-t) + \left(\frac{2}{-t}\right)\right] + 3 \leqslant 3 - 2\sqrt{(-t) \cdot \left(\frac{2}{-t}\right)} = 3 - 2\sqrt{2}$ , 当且仅当 $-t = \frac{2}{-t}$ , 即 $t = -\sqrt{2}$ , 即$\left\{ \begin{array}{l} \tan B \tan C = 1 - \sqrt{2}, \\ \tan B + \tan C = 2 - 2\sqrt{2} \end{array} \right.$ 时取到等号，此时 $\tan B, \tan C$ 是一元二次方程 $x^{2} - (2 - 2\sqrt{2})x + 1 - \sqrt{2} = 0$ 的两个根， $\Delta = (2 - 2\sqrt{2})^{2} - 4 \times (1 - \sqrt{2}) = 8 - 4\sqrt{2} > 0.$ 根据韦达定理，这个一元二次方程一定有符号相异的两个实根. 所以能取到等号.

故 $\tan A + \tan B\tan C$ 的最大值为 $3 - 2\sqrt{2}$

师:同学16的回答非常好！考虑问题既全面又细致.

至此，本节课围绕利用基本不等式解决三角形中有关最值问题的三个同类型例已经全部呈现，并在师生共同参与下得到讨论深化和解决。除了例1是在笔者设计的问题串形式下直接引导学生完成，其他两个问题均是学生进行类比分析后独立完成。暴露问题，发现问题，并且解决问题。当然，本节课所呈现的问题旨在从基本不等式这个角度切入，强化其在其他问题情景中利用基本不等式求最值时，“一正二定三相等”这个条件的使用要求、限制条件和细节规范。教师还可以考虑换个角度和途径，从其他方面引导学生对本节课所呈现的问题再作探究，在此不再赘述。

# 三、教后反思

叶澜教授说：“把课堂还给学生，让课堂充满生机和活力；把班级还给学生，让班级充满成长气息。”一节好的数学课，教师的主导作用主要体现在对课堂教学的把控和对学生学习活动的组织上。课堂应该是学生的，教师要厘清哪些内容需要教师自己讲解，哪些内容需要交还给学生自主考虑和讨论。在这样的课堂上，学生的主体地位得到尊重，主观能动性能够完全被激发出来，从而以一个积极的态度和活跃的思维来参与课堂活动，收获知识成长。课堂时间有限，在有限的时间中，能尽量留时间和空间给学生展示和发挥，让学生在自己的实践和尝试中理解问题，解决问题。

作为数学教师, 笔者认为, 我们更多的是要思考数学这门课到底要教给学生的是什么. 我们要关注的是学生长久的发展, 而不是一次考试的成绩. 正所谓 “授人以鱼不如授人以渔”, 帮助学生提升逻辑思维能力, 引导学生主动探究反思才是我们教学的目标, 也是数学这门课的意义所在. 作为教师要能够根据课程的重点及难点, 在教学的过程中注重学生逻辑思维能力的训练, 从而实现学生能力的提升, 以达到教学育人的目的. F
