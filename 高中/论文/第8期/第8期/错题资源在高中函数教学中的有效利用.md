# 错题资源在高中函数教学中的有效利用

● 江苏省南京市第九中学 张晨

# 一、问题的提出

《普通高中数学课程标准(2017年版)》明确提出：“数学教学过程中恰当地使用数学课程资源，将在很大程度上提高学生从事数学活动的水平和教师从事教学活动的质量。”这就要求教师在教学过程中有意识、有目的地开发和利用各种课程资源。皮亚杰的建构主义指出学习的含义和学习方法，并强调：“学生对教师所授予的知识并不只是被动的接受，而是在已有的知识和经验基础上主动建构的。”学生在自主、建构的课堂模式中开展学习活动，必然会出现各种错误。这些错误是课程资源的重要组成部分，存在于教学过程之中，游离于教师学生之间，恰是教育的契机，具有潜在的教育价值和意义。通过对学生错误资源的开发和利用，不仅可以丰富课程资源，还对课堂教学改革具有推动作用，形成注重生成、注重互动的现代化课堂。

# 二、函数中的典型错题类型与错因分析

函数是在数学的各部分内容中都有渗透,它是一个重要的基本概念.在关于方程、不等式、解析几何等知识学习中,函数的性质都是最有力的工具.函数思想在高中数学中起到了横向联系和纽带的主干作用.因此笔者以函数内容为例,探讨学生产生错误的主要类型并分析其原因.

波利亚在《怎样解题》中阐述解题的四步：“第一，弄清问题；第二，找出已知数和未知数的关系，得到解题思路，拟定解题计划；第三，实现求解计划；第四，检验所求的解，回顾反思。”学生在解题的过程中，错误可能在不同的阶段都会产生，并对最终的解题结果造成影响。鉴于此，笔者将高中函数部分的错题也归为以下四类：理解题意的错误、拟定计划的错误、实现计划的错误、回顾反思的错误。

# 1. 理解题意的错误

审题是数学解题的第一步,也是最重要的一步.所谓审题,就是经过深入的思考和反复的推敲,以求理解题意.在实际的教学过程中,笔者发现很多学生在查找错误原因时,经常将原因归结为审题缺乏耐心，在没有看清题目条件的情况下就开始做题.

例 1 已知函数 $f(x)=x^{2}, x \in \{-1,2\}$ ，则 $f(x)$ 的值域为 \_\_\_\_.

很多学生觉得题目简单,按照思维定式误将定义域:集合 $\{-1,2\}$ 看成区间 $[-1,2]$ ,从而产生错误.

正确理解数学概念是解题的基础,如果学生缺乏准确理解,把握不住概念的适用范围,对概念之间的区别和联系模糊不清,似是而非地理解数学概念等不仅会造成学生的解题失误,而且将阻碍学生数学能力的发展.

例 2 函数 $f(x)=x^{2}-2$ 的零点为 \_\_\_\_.

有不少学生在刚学习函数零点概念时,错误地将函数的零点理解为一个点.而其实不管是从方程的角度,还是从图象的角度,函数的零点都应该是一个数.学生在此处理解有误将直接影响后续对于函数零点的所有问题.

# 2. 拟定计划的错误

在准确理解题目意思后,学生就要根据已学的认知规律,拟定解题计划,不断尝试和重复不同的思想方法和解题方法从而达到确定解题计划的目的.若拟定的计划方案无法验证或执行下去或者太过复杂的,则需要重新思考从而拟定一个新的解题计划.

例 3 已知函数 $f(x)=\mathrm{e}^{x}-\mathrm{e}^{-x}-2x$ ，则不等式 $f(x^{2}-4)+f(3x)>0$ 的解集为 \_\_\_\_.

如果学生将 $(x^{2} - 4)$ 和 $(3x)$ 直接代入 $f(x)$ 的函数关系式，强行求解关于 $x$ 的不等式，那么这个超越函数不等式对于高中生来说是不可能解决的，从而产生错误.所以就需要更改解题方案，从函数本身出发，使用函数的奇偶性和单调性解决函数不等式

例4 已知函数 $f(x) = \sin x - ax \leqslant 0$ 对任意 $x \in (0, +\infty)$ 恒成立，求实数 $a$ 的取值范围.

已知不等式恒成立求解参数范围的问题,一般都是有两个基本做法:一个是分离参数,另一个是含参讨论.本题如果学生选择分离参数的话,最后函数的最值是取不到的一个极限值,因此答案是无法得到的.所以就需要及时更改解题策略,通过对参数a的讨论,研究原函数的单调性和最值.

# 3. 实现计划的错误

所谓实现计划, 就是在拟定计划方案之后, 按照规范要求将过程表述出来. 它既是解题过程中的书面操作, 更是评价学习的重要依据. 很多学生解题思维和方法很好, 但在形成解题过程或者解题步骤中很可能因为计算失误或其他原因而出错.

例5 化简： $\frac{\sqrt{a^3b^2\cdot\sqrt[3]{ab^2}}}{\left(a^{\frac{1}{4}}b^{\frac{1}{2}}\right)^4a^{-\frac{1}{3}}b^{\frac{1}{3}}} (a > 0,b > 0).$

本题化简的基本思路学生们都很清晰,应该是先把根式换成分数指数幂,然后通过分数指数幂的公式进行化简.但是在真正操作时,学生却经常在运算过程中出现各种错误,成为一个难点.

# 4. 回顾反思的错误

在整个解题过程中,检验是最后的一个重要环节,一方面可以保证结果的正确性,避免出现漏解或错解;另一方面解题后的有效反思可以帮助学生更好地应对同类型问题,形成解题思路和体系,适当地整理反思的过程是主动学习和有效学习的一种途径.

例 6 已知函数 $y=ax^{2}-x-1$ 只有一个零点，则实数 a 的取值集合为 \_\_\_\_.

在解题时不少学生看到所给的形式中 x 的最高次项是二次的, 所以直接把函数当成二次函数, 考虑二次函数只有一个零点的对应条件, 而忽略了当 a = 0 时, 函数也可能是一次函数的情况, 从而出现了漏解的错误.

本题学生在求解过程中最容易犯的错误是利用 $x = -1$ 时的导数值和函数值解出 $a$ 和 $b$ 的两组解，忽视了回头检验函数在 $x = -1$ 两边导数值是否异号，所以没有舍根。而该检验过程恰好蕴含的是函数极值的概念，极值点处导数值为0，但导数为0的点却不一定是极值点。

# 三、错题资源在教学中有效利用的策略

在课堂教学中,学生不可避免地会发生错误. 只要有认知活动,就会有错误发生,错误是学生在学习过程中的相伴产物. 学生的错误可以作为学生的学习资源和教师的教学资源,因为它们来源于真实的学习活动本身而不一定是按计划生成的,它是附着在学习活动中生长起来的. 如果能充分、合理地利用好错题资源,不仅能让学生感受到自己在解题过程中的成败,还能让其发现成败的原因并进行合理准确的纠正,从而促进学生认知、能力与情感的发展.

# 1. 故设“错误”，激活思维

学起于思,疑问是思维的“激活剂”.因此,在教学中教师可以故意设计一些错误,制造一点矛盾.不仅能让学生对某些易错问题提高关注程度,还能让学生在发现错误的过程中有自主的理解和辨析,让其经历从错误认识走向正确认识的过程中,提升反思能力、唤醒学习潜能.

例如，在学习《利用导数研究函数单调性》时，可以归纳出导数与函数单调性之间的关系。此时给出一个“错误”：函数 $f(x) = \frac{1}{x}$ 的导数 $f'(x) = -\frac{1}{x^2} < 0$ 恒成立，则函数在定义域上应该是单调递减的。然而通过反比例函数的图像，可以直观地看出该函数的单调性并非如此，这个错误是新知识在学习过程中与已有经验之间的矛盾，更容易激发学生的学习动机和探索精神。通过对“错误”的讨论，明确“任取”的含义，强化函数单调性的概念，实现旧知和新知的融合与提升。

# 2. 诱导“错误”，引发思考

建构主义中提出,教师的教学应该在学生认知范围内又高于认知范围,让他跳一跳能够到,所以可以认为设置低能“陷阱”,诱导学生犯错,再引导学生能轻易从错误的迷茫中走出来,从而培养学生的质疑精神以及提升探究能力.

# 3. 巧用“错误”，促进生成

当教学中出现错误时,教师要能及时发现并有效把握教学生长点.在错误的基础上因势利导,让学生进行自我反思、辨析,促进课堂的动态生成.

例如,在学习《函数的极值》时,有一道练习:求函数 $f(x)=x+\frac{1}{x}$ 的极大值和极小值.当学生们利用单调性求出两个极值后,有一个学生提出疑问:“为什么极大值小于极小值?这里好像错了.”作为教师,首先要肯定学生敢于质疑,接下来带领学生重温极值的概念,引领学生自己发现问题,让学生对极值是函数局部性质有更进一步的理解.

“错误”是一种宝贵的教学资源, 是学生在自主学习状态下最真实的探究形成的, 把握住出错的时间和机会, 促进错误的生成. 怎样来对待错误成为新课程大背景下又一可持续研究的新课题, “自主、合作、探究”的学习模式让课堂中出现大量错误, 通过挖掘错误中蕴含的思想冲突, 方法多元, 帮助学生突破思维定式, 灵活地纠正错误, 让学生在错误中反思, 提升主动学习的意识, 才能真正意义上不怕出错、少出错. F
