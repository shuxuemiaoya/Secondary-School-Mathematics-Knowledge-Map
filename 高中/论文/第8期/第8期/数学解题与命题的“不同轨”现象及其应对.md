# 数学解题与命题的“不同轨”现象及其应对

● 华中师范大学第一附属中学 周龙虎  
● 华 中 师 范 大 学 刘师妤

波利亚说：“掌握数学就意味着善于解题。”解题作为数学学习中最主要的巩固性与检测性活动，其效益与命题息息相关。问题以试题的形式出现，就宛如一面镜子，既能照出答题者的学业水平，又能照出命题者的命题能力。但结合实际情况来看，数学解题与命题之间总会出现一些“不同轨”的现象，如解题者所答不是命题者所欲，命题者所考不是解题者所思。

# 一、数学解题与命题的“不同轨”现象的表现

如果说从数学问题的单一设问或者表征形式上都难以揣度命题者的意图,那么不同轨现象也就司空见惯了.但对于多设问的数学问题,命题者格外强调设问之间的层递性,这恰巧也是问题思考的方向所在,而解题者却鲜有领会,自然就会遭遇思路不同轨的尴尬境地,先通过下述具体案例呈现之.

例题 已知 $f(x)$ 是在 $(0, +\infty)$ 上每一处可导的函数，若 $xf'(x) > f(x)$ 在 $(0, +\infty)$ 上恒成立.

(1) 求证: 函数 $g(x)=\frac{f(x)}{x}$ 在 $(0,+\infty)$ 上单调递增;  
(2) 当 $x_{1}>0, x_{2}>0$ 时，证明： $f(x_{1})+f(x_{2})<f(x_{1}+x_{2})$ ;  
(3) 已知不等式 $\ln(x+1)<x$ 在 x>-1 且 $x\neq0$ 时恒成立，证明： $\frac{1}{2^{2}}\ln2^{2}+\frac{1}{3^{2}}\ln3^{2}+\frac{1}{4^{2}}\ln4^{2}+\cdots+\frac{1}{(n+1)^{2}}\ln(n+1)^{2}>\frac{n}{2(n+1)(n+2)}(n\in\mathbf{N}^{*})$ .

先看(3)的解答过程,便可明白该题的设计意图.

证明:由(2)可知,若 $g(x)=\frac{f(x)}{x}$ 在 $(0,+\infty)$ 上单调递增,则 $f(x_{1})+f(x_{2})<f(x_{1}+x_{2})(x_{1}>0,x_{2}>0)$ 恒成立,由数学归纳法易证:当 $x_{i}>0(i=1,2,3,\cdots,n)$ 时,有 $f(x_{1})+f(x_{2})+f(x_{3})+\cdots+f(x_{n})<f(x_{1}+x_{2}+x_{3}+\cdots+x_{n})(n\geqslant2)$ 恒成立.

构造 $f(x)=x\ln x$ ，经验证符合条件，则当 $x_{i}>$ $0(i = 1,2,3,\dots ,n)$ 时，有 $x_{1}\ln x_{1} + x_{2}\ln x_{2} + x_{3}\ln x_{3}+$ $\cdots +x_{n}\ln x_{n} <   (x_{1} + x_{2} + x_{3} + \dots +x_{n})\ln (x_{1} + x_{2}$ $+x_{3} + \dots +x_{n})(n\geqslant 2)$ 恒成立.

令 $x_{n}=\frac{1}{(n+1)^{2}}$ ，记 $S_{n}=x_{1}+x_{2}+\cdots+x_{n}=\frac{1}{2^{2}}+\frac{1}{3^{2}}+\cdots+\frac{1}{(n+1)^{2}}$ ，则 $S_{n}<\frac{1}{1\times2}+\frac{1}{2\times3}+\cdots+$

$$
\begin{array}{l} \frac {1}{n (n + 1)} = 1 - \frac {1}{n + 1}, S _ {n} > \frac {1}{2 \times 3} + \frac {1}{3 \times 4} + \dots + \\ \frac {1}{(n + 1) (n + 2)} = \frac {1}{2} - \frac {1}{n + 2}. \\ \end{array}
$$

因为 $\ln(x+1)<x(x>-1$ 且 $x\neq0)$ ，故 $(x_{1}+x_{2}+x_{3}+\cdots+x_{n})\ln(x_{1}+x_{2}+x_{3}+\cdots+x_{n})<(x_{1}+x_{2}+x_{3}+\cdots+x_{n})$

$$
+ x _ {2} + x _ {3} + \dots + x _ {n}) \ln \left(1 - \frac {1}{n + 1}\right) <   - \frac {1}{n + 1} (x _ {1} +
$$

$$
\begin{array}{l} x _ {2} + \dots + x _ {n}) <   - \frac {1}{n + 1} \left(\frac {1}{2} - \frac {1}{n + 2}\right) = \\ - \frac {n}{2 (n + 1) (n + 2)}. \\ \end{array}
$$

由上式知， $\frac{1}{2^2}\ln \frac{1}{2^2} +\frac{1}{3^2}\ln \frac{1}{3^2} +\frac{1}{4^2}\ln \frac{1}{4^2} +\dots +$

$$
\frac {1}{(n + 1) ^ {2}} \ln \frac {1}{(n + 1) ^ {2}} <   - \frac {n}{2 (n + 1) (n + 2)},
$$

即 $\frac{1}{2^{2}}\ln2^{2}+\frac{1}{3^{2}}\ln3^{2}+\frac{1}{4^{2}}\ln4^{2}+\cdots+\frac{1}{(n+1)^{2}}\ln(n+1)^{2}>\frac{n}{2(n+1)(n+2)}.$

命题者设计此题旨在考查导数的应用、构造函数证明不等式的技巧，尤其要注意三问之间的联系，层层递进、前者为后者服务。也有学生绕开“构造函数”从函数单调性的视角切入，不等式的右边为关于 $n$ 的减函数。若令 $\varphi(n) = \frac{n}{2(n + 1)(n + 2)}$ ，易得 $\varphi(n + 1) - \varphi(n) \leqslant 0$ 。而不等式左边是关于关于 $n$ 的增函数，只需证明 $n = 1$ 时，左边 $>$ 右边即可，故原不等式成立。同为函数视角，但显然学生整体观念下直接研究两个函数的做法要简明快捷得多。

# 二、产生“不同轨”现象的原因分析

无论是选拔人才还是培育人才,命题都要且都应基于对学生能力或素养的测评,这一过程需要通过学生的解题活动体现出来.简言之,测评的效度和信度(即测量的准确性和可靠性)不会总维持在非常理想的一个范围内,即本质上反映出解题与命题的“不同轨”现象.

产生“不同轨”现象的原因大致有两个,其一是命题者和解题者逻辑起点及思维方式的不同;其二是他们两者在有效角色互动机制上的缺失.

# (一) 逻辑起点及思维方式的不同

命题的逻辑起点是试题所承载的考查目标, 是目标导向下的问题设计. 具体地, 命题者一般会优先思考考查何种数学核心素养或数学能力乃至数学观念, 其次便是选择合适的考查载体及考查方式. 命题人关注的是问题本身的内在属性及价值, 而不是狭隘地考虑问题是否得到解决, 尽管最终是以此作为评测的主要依据. 目标驱动下的问题设计往往包括问题情境的创设及问题设问方式的设计, 前者要求情境具备问题的针对性及探究性、难度的适宜性等, 后者则强调设问的层次性及考查的整体性. 因而, 试题会呈现两种样态, 即经过“深加工、多次包装”的目标内隐的试题样态和直白、浅显的目标外显式试题样态. 无论是哪一种样态, 命题者都期许解题者如同“条件反射”式的发掘问题的本质, 迅速找到解决问题的策略.

# （二）有效角色互动机制上的缺失

社会角色互动理论认为, 互动的产生和维持有赖于自我和他人角色的萌发与确认, 每一角色都倾向于建构为回应一个或更多其他相关角色的全面的渠道. 也即命题者和解题者要清晰地认识到自己在整个教学和评价系统中的位置及两者间的促进协调和互相掣肘关系. “解题与命题同根生”“更高质量的解题势必走向自发地命题”等都精辟地概括了解题与命题之间的关系. 已形成共识的是, 科学的解题观需要以高屋建瓴的命题观为指引, 命题观念的养成与重构则需要优化解题的思维过程, 善于解题. 教学实践表明, 解题与命题“两层皮”的现象呈现愈演愈烈之势, 尤其是当教师和学生的探究水平和探究能力不高的情形下. 因此, 为促进命题与解题两种角色的良性互动 (即不自觉的角色获得), 教育专家尤其是命题专家深入到了一线教学中掌握第一手的教情和学情资料, 教师也对学生进行了命题相关的培训. 但遗憾的是, 这并未成为一项常态工作.

# 三、“不同轨”现象的应对策略

为消解命题者与解题者之间的视角分歧,数学教学应加强两者之间的有效交互,具体体现为:以命题观指导解题观,改善解题教学样式;以丰富问题解决策略为抓手,创新参考答案制定规范;以社会互动理论为依据,构建和完善数学教学常态机制.

# （一）以命题观指导解题观，改善解题教学样式

受教学功利化思想的影响,解题教学中师生极易陷入解题者的孤立主义视角,关注的莫非是“问题的题眼在哪?”“此题怎么解?”“有几种解法”“条件与结论之间怎么转化”“卡壳后应转向何种思路?”等解题要素.殊不知,囿于解题的限制中对于理解问题的本质是没有益处的,这就好比植株不借助根系吸收养分是难以长成参天大树的.这一孤立视角带来的最大害处是原本用来培育命题观的空间和时间被占据了,“题海战术”便应运而生.尽管题海战术有利有弊,但它试图通过超量的训练达到熟能生巧的地步,并最终发展学生的创造力的出发点是站不住脚的,也是必然要被淘汰的教学样式.解题这一实践活动要遵循一定的操作规则,如波利亚的“怎样解题表”,也要基于某些“大观念”,如对问题考查内容(核心概念的理解、公式定理的灵活运用等)的初步判断以及对典型问题常规策略的优选等.换言之,以命题者的视角指导解题,能让解题更具方向感,更能增添解题的底气.

# （二）以丰富问题解决策略为抓手，创新参考答案制定规范

答案设置合理应是一套合格的试题的必备条件，但出现了如上种种答题者的“另样生成”，我们是一味批评命题者“欠考虑”，没有把握好学情，还是应该思索如何制定参考答案并实现其最大教育效果呢？

数学复习课是以优质的试题、透彻的分析、扎实的训练为奠基的，命题就成为了检测与考查的缘起，如若设计的问题的解决思路不能为大多数的学生所洞悉，就会招致评价者的质疑甚至否定。试问命题者不在学生最近发展区内设置问题，又如何寻求其进一步的数学发展呢？我们不禁要问：对于不同的数学问题确实各有解决的套路与方法，难道一块水稻田里就不能长出其他的作物吗？数学问题多是相似的，对于入口宽的问题的解答可能“正中命题者下怀”，对指定内容起到了考查的目的；也可能“节外生枝”，甚至“花枝招展”，且也格外绚烂。难不成要背上“欠考虑”的说道吗？因此作为新课程标准的践行者，我们要充分认识到学生的主体地位，即肯定解题背后的无限可能性。

之所以有上述想法，皆因部分老师对2015年武汉二月高三调考的最后一题的“非议”而起。对于该调考题的解法，裴光亚老师通过两个追问“参考答案的想法是如何来的？”与“不依赖于前一小问，可以另辟蹊径吗？”阐明了追问的必要，也指出了命题者设计的基本结构是可循套路的，也是可颠覆套路的。感兴趣的读者不妨一读，在此不再赘述。

命题者的意图往往以参考答案呈现出来, 明确是答案的最基本特征. 查阅资料, 实难觅得数学参考答案的制定标准, 但有两点原则是大家都认可的: 多解与多踩分点.

能有效地检测学生的数学核心素养的高低，“入口多”是试题应有的首要特征。一题多解是自然思路的必然结果，尽量现如今还未能根据不同的解题方式和策略评判出不同等级的得分，但规定时间内用不同的解题方式会直接决定解题效率及正确性。因而解答题的参考答案要适当多给一些解法。以笔者亲身参加或了解的各省份高考数学阅卷为例，在正式阅卷前都有试阅卷这一环节，主要有两个目的。一是找到阅卷节奏，对全体考生做到评判上的一视同仁；二是由教师视角转向学生视角，进一步完备解法的多样性。但即使有这个操作环节，也很难预想到学生所有可能的思路或想法，因为随着阅卷量的增大，总会有新奇的又合乎情理的解答出现，并非所有的阅卷教师都能在极短的时间内明了它，因而阅卷前的研题、研参考答案就显得尤为必要了！实质上，将“标准答案”修正为“参考答案”就是对解题思路与方法的不确定性的生动突出，更是对学生的主体性地位的认可。

# （三）以社会互动理论为依据，构建和完善数学教学常态机制

社会互动理论强调有效互动是在特定情境下进行的,即需要营造一定的情境让解题与命题两种视角交互甚至交融.社会互动理论认为互动可以是面对面的,也可以在非面对面的场合下发生,即应立足常态化以构建解题与命题两种角色的互动机制.社会互动的主要形式包括交换、合作和冲突等.交换指的是角色交换以及引起的行为交换.命题与解题在同轨道进行表明这一活动是指向能力乃至素养的知识检测,实现解题与命题同轨化的要义在于模糊解题者与命题者的角色界限.

一方面,解题者(尤指学生)要主动体验命题者的角色.解题的成就感不仅在于问题的成功解决,还在于解题者与命题者的思维进行了碰撞.高水平的数学解题绝不是孤立、狭隘地运用诸多解题技巧解题,它往往需要对问题的表征形式及本质加以洞悉. 前者是解构的话, 后者便是重新建构, 建构就需熟谙一些常见的命题技巧、命题规律等. 常见的命题技巧有推广引申、引进数学问题(选材于高等数学或其他学科中的一些命题)、命题改造(利用四种命题之间的关系, 代数与几何之间的转化)等. 一般地, 命题规律包括命题的开放性(尤指条件选择及结论的多样性)、命题的整体性(知识、难度等的选择及调配)、问题的情境性(问题应立足于情境, 如现实情境、科学情境、数学情境等). 也应注意到, 命题不能总局限于现有试题的“门框内”, 要“开疆扩土”, 才能孕育好的、新的试题. 试题的编制虽要经历考试目标的确定、双向细目表的制定以及具体试题的编制等一系列流程, 但具体的试题还是应产生于具体的问题、有价值的问题情境中. 章建跃博士认为, 有价值的问题可从同一数学学科内在的逻辑发展必然性中产生, 或从不同数学学科的联系中产生. 有此一般思想观念的引领, 新手命题者发现和提出问题更加自如.

著名数学教育家波利亚曾说到：“如果一个学生从来没有机会解答一道由他自己创造的题目，他的数学经验就是不完整的。”学生亲历命题的整个过程，可从中体会到创作的乐趣。为保证试题的有效性，教师还应多向学生展示命题的全过程并对学生进行针对性命题培训，适时给予机会进行命题意图的展示与交流，使之成为数学学习活动中的一部分。

另一方面，命题者要常到教学一线中走动。重大型考试的命题者多是高考命题中心组专家及各省市区的教研员，他们都是具备深厚的数学教学功底、有着丰硕的理论与实践成果、远见卓识的教育家。他们的命题素材来源于数学课程标准，来源于国家教材，来源于学生的数学学习实际，还来源于对教师的教学诊断。

探讨解题与命题的同轨化问题,其主要旨趣并非是考试效益的博弈,而是真实推测出学生的数学发展水平,并有效地促进学生的发展.我们希望看到,解题者与命题者能更加“心意相通”,教学改革与评价才能走深走实.
