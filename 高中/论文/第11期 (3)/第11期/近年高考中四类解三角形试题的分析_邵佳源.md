# 近年高考中四类解三角形试题的分析

# 南京市第二十九中学 邵佳源

在解决解三角形问题的过程中,要牢牢抓住两块基石:正弦定理与余弦定理.如果问题比较复杂,还可以借助诱导公式、倍角公式、半角公式、三角形面积公式以及相应的函数性质来解决问题.本文中结合近年高考数学试题中常出现的解三角形的四类题型进行分析求解.

# 1 类型一: 面积问题

例 1 （2021 年新高考Ⅱ卷第 18 题）在三角形 ABC 中，角 A, B, C 所对的边分别为 a, b, c. 其中 $b = a + 1$ , $c = a + 2$ . 若 $2\sin C = 3\sin A$ ，求 $\triangle ABC$ 的面积.

分析: 这是一道考查三角形面积的题目. 想要利用面积公式解决问题, 需要先用正弦定理求出三边, 然后利用余弦定理求出角的余弦, 用同角的三角函数关系求出角的正弦值, 最后利用面积公式即可顺利求解.

解:由正弦定理及 $2\sin C=3\sin A$ ，得 2c=3a.

由 $c=a+2$ ，得 a=4, c=6，则 b=5。

由余弦定理，得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{1}{8}$ . 又 $C \in (0, \pi)$ ，所以 $\sin C = \frac{3\sqrt{7}}{8}$ .

故 $\triangle ABC$ 的面积为 $\frac{1}{2} ab\sin C = \frac{15\sqrt{7}}{4}$ .

# 2 类型二: 周长问题

例 2 （2021 年上海卷第 18 题）在三角形 ABC 中，角 A, B, C，所对的边分别为 a, b, c，已知 a = 3, b = 2c.

(1) 若 $A=\frac{2\pi}{3}$ ，求三角形 ABC 的面积；

(2) 若 $2\sin B - \sin C = 1$ ，求三角形 ABC 的周长.

分析:这里略去第(1)问.对于第(2)问,可以利用正弦定理求角B、角C的正弦值.要求三角形周长,就需要求出b与c的长度,可以有两种解法.

解法1,由于可以确定角 $C$ 为锐角,因此可以确定角 $C$ 的余弦值.又知道 $a$ 的长度和 $b,c$ 之间的关系,所以可以利用余弦定理得到一个关于 $c$ 的二次方程,求得 $c$ 的长度,进而求出三角形的周长.

解法 2 是利用正弦定理、诱导公式及三角形三角关系求出 $\sin A$ ，需要用到角 B、角 C 的正弦值和余弦值。因为角 B 的度数不确定，所以需要进行分类讨论。

第(2)问的解法如下.

(2) 解法 1: 由正弦定理及 b=2c，得 $\sin B=2\sin C$ . 又 $2\sin B-\sin C=1$ ，所以可得

$$
\sin B = \frac {2}{3}, \sin C = \frac {1}{3}.
$$

由 C 为锐角, 得 $\cos C = \frac{2\sqrt{2}}{3}$ .

所以 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}==\frac{3c^{2}+9}{12c}=\frac{2\sqrt{2}}{3}.$

解得 $c=\frac{4\sqrt{2}\pm\sqrt{5}}{3}$ ，从而得 $b=\frac{8\sqrt{2}\pm2\sqrt{5}}{3}(b,c$ 同时取“+”或取“-”）.

所以，三角形 ABC 的周长为 $3 + 4\sqrt{2} \pm \sqrt{5}$ .

解法 2: 由正弦定理及 b=2c，可得 $\sin B=2\sin C$ .
又 $2\sin B - \sin C = 1$ ，所以可求得

$$
\sin B = \frac {2}{3}, \sin C = \frac {1}{3}.
$$

因为 b=2c，所以 B>C，故角 B 分为两种情况，即 $\cos B=\pm\frac{\sqrt{5}}{3}$ .

当 $\cos B = -\frac{\sqrt{5}}{3}$ 时，又 $\cos C = \frac{2\sqrt{2}}{3}$ ，所以 $\sin A = \sin (B + C) = \sin B\cos C + \cos B\sin C = \frac{4\sqrt{2} - \sqrt{5}}{9}$ .

由 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，可得

$$
c = \frac {4 \sqrt {2} + \sqrt {5}}{3}, b = \frac {8 \sqrt {2} + 2 \sqrt {5}}{3}.
$$

当 $\cos B = \frac{\sqrt{5}}{3}$ 时，又 $\cos C = \frac{2\sqrt{2}}{3}$ ，所以 $\sin A = \sin (B + C) = \sin B\cos C + \cos B\sin C = \frac{4\sqrt{2} + \sqrt{5}}{9}$ .

由 $\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}$ ，得

$$
c = \frac {4 \sqrt {2} - \sqrt {5}}{3}, b = \frac {8 \sqrt {2} - 2 \sqrt {5}}{3}.
$$

所以三角形周长为 $3+4\sqrt{2}\pm\sqrt{5}$ .

比较两种解法会发现解法 1 思路清晰, 过程简洁, 只需要知道 $\cos C$ 为正即可, 不需要分类讨论. 解法 2 计算步骤复杂, 同时需要对角 B 进行分类讨论, 容易遗漏某种情况导致答案不完整, 运算要求比较高.

对于条件 $2\sin B - \sin C = 1$ ，可能有学生想到边角关系转换得到新的等式为 2b - c = 1，这是解三角形问题中经常容易出错的地方。

# 3 类型三: 最值问题

例 3 （2022 年新高考 I 卷第 18 题）记 $\triangle ABC$ 的内角 A, B, C 的对边分别为 a, b, c，已知 $\frac{\cos A}{1 + \sin A} = \frac{\sin 2B}{1 + \cos 2B}$ .

(1) 若 $C=\frac{2\pi}{3}$ ，求 B；  
(2)求 $\frac{a^{2}+b^{2}}{c^{2}}$ 的最小值.

分析:(1)根据二倍角公式以及两角差的余弦公式,可将 $\frac{\cos A}{1+\sin A}=\frac{\sin 2B}{1+\cos 2B}$ 化成 $\cos(A+B)=\sin B$ ,再结合 $0<B<\frac{\pi}{2}$ ,即可求出B;

(2)由(1)知, $C=\frac{\pi}{2}+B$ , $A=\frac{\pi}{2}-2B$ ,再利用正弦定理以及二倍角公式,将 $\frac{a^{2}+b^{2}}{c^{2}}$ 化成 $4\cos^{2}B+\frac{2}{\cos^{2}B}-5$ ,然后利用基本不等式即可解出.

解:(1)由 $\frac{\cos A}{1+\sin A}=\frac{\sin 2B}{1+\cos 2B}=\frac{2\sin B\cos B}{2\cos^{2}B}=\frac{\sin B}{\cos B}$ ，可得 $\sin B=\cos A\cos B-\sin A\sin B=\cos(A+B)=-\cos C=\frac{1}{2}$ .

又 $0 < B < \frac{\pi}{2}$ , 所以 $B = \frac{\pi}{6}$ .

(2)由(1)知 $\sin B = -\cos C > 0$ ，所以 $\frac{\pi}{2} < C < \pi$ 则 $0 < B < \frac{\pi}{2}$

又 $\sin B = -\cos C = \sin \left(C - \frac{\pi}{2}\right)$ 所以 $C = \frac{\pi}{2} + B$ 则 $A = \frac{\pi}{2} - 2B$ .

故 $\frac{a^2 + b^2}{c^2} = \frac{\sin^2A + \sin^2B}{\sin^2C} = \frac{\cos^22B + 1 - \cos^2B}{\cos^2B} =$ $\frac{(2\cos^2B - 1)^2 + 1 - \cos^2B}{\cos^2B} = 4\cos^2 B + \frac{2}{\cos^2B} -5\geqslant$ $2\sqrt{8} -5 = 4\sqrt{2} -5$ ，当且仅当 $\cos^2 B = \frac{\sqrt{2}}{2}$ 时等号成立.

所以 $\frac{a^{2}+b^{2}}{c^{2}}$ 的最小值为 $4\sqrt{2}-5$ .

解决三角函数最值问题的关键是从已知条件寻找切入点,利用三角函数对条件进行合理变形.需要注

意三角形中隐含角、边的限制条件及角度的范围.有时,还需要用到三角形边角关系变换和辅助角公式,将不同角的三角函数转换成一个角的三角函数.转换过程中需要注意已知角与未知角、函数名称、次数、系数之间的关系.利用诱导公式和三角函数基本关系式进行转化,能将新问题变为熟悉的问题.

# 4 类型四: 开放性问题

例 4 （2021 年北京卷第 16 题）在三角形 ABC 中，角 A, B, C，所对的边分别为 a, b, c，已知 $c = 2b \cos B, C = \frac{2\pi}{3}$ .

(1)求角 B 的大小;

(2) 在① $c = 2b$ ，②周长为 $4 + 2\sqrt{3}$ ，③ $S_{\triangle ABC} = \frac{3\sqrt{3}}{4}$ 这三个条件中任选一个作为已知条件，使三角形 $ABC$ 存在且唯一确定，并求 $BC$ 边上中线的长度.

分析:本题第(2)问需要在给定的条件中选择一个作为补充,然后进行求解.这属于开放性问题,需要发散思维,根据不同条件进行运算、判断和求解.

解:(1)略.

(2)由(1)可求得 $B=\frac{\pi}{6}$ ，又 $C=\frac{2\pi}{3}$ ，所以 $A=\pi-(C+B)=\frac{\pi}{6}$ ，则三角形 ABC 为等腰三角形.

选①c=2b 时，由题可知 $c=2b\cos B=\sqrt{3}b$ ，矛盾，所以三角形 ABC 不存在.

选②周长为 $4 + 2\sqrt{3}$ 时，由题知 $a = b, c = \sqrt{3}b$ ，所以三角形ABC周长为 $b + b + \sqrt{3}b = 4 + 2\sqrt{3}$ ，求得 $b = 2 = a, c = 2\sqrt{3}$ . 此三角形存在且唯一.

设 BC 边的中点为 D，则

$$
A D ^ {2} = b ^ {2} + \left(\frac {a}{2}\right) ^ {2} - 2 b \cdot \frac {a}{2} \cos C = 7.
$$

所以 $AD=\sqrt{7}$ ，即 BC 边上的中线长为 $\sqrt{7}$ .

选③ $S_{\triangle ABC}=\frac{3\sqrt{3}}{4}$ 时，由 $S_{\triangle ABC}=\frac{1}{2}ab\sin C=\frac{\sqrt{3}b^{2}}{4}=$ $\frac{3\sqrt{3}}{4}$ ，得 $b=a=\sqrt{3}, c=3$ 。此三角形存在且唯一。

设 BC 边的中点为 D，则

$$
A D ^ {2} = b ^ {2} + \left(\frac {a}{2}\right) ^ {2} - 2 b \cdot \frac {a}{2} \cos C = \frac {2 1}{4}.
$$

所以 $AD=\frac{\sqrt{21}}{2}$ ，即 BC 边上的中线长为 $\frac{\sqrt{21}}{2}$ .

观察高考题发现,解三角形问题经常在简答题的基础题中出现.求解时常用到正弦定理、余弦定理、面积公式及其他知识,例如边角关系转换、三角函数的诱导公式、两角和差公式、倍角公式等.解三角形问题的基本解题思路是根据题目条件及相关边、角特征灵活运用适当的公式进行转化.Z
