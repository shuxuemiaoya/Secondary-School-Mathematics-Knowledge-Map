# 同构变形在函数问题中的应用

田鹏

(重庆市长寿中学)

在函数问题中,有一部分问题是利用函数的单调性构造出来的,如果能够将这类问题中隐藏的函数模型呈现出来,不仅会加快解题者解决问题的速度,更有助于看清问题的本质.一般而言,若 $F(x) \geqslant 0$ 能够变形成 $f(g(x)) \geqslant f(h(x))$ 的形式,则可利用 $f(x)$ 的单调性得到 $g(x) \geqslant h(x)$ (或 $g(x) \leqslant h(x)$ ),这种变形的方法称为同构变形.

# 1 两个引理

引理 1 设函数 $f_{1}(x)=xe^{x}$ ， $f_{2}(x)=\frac{e^{x}}{x}$

$f_{3}(x) = \frac{x}{\mathrm{e}^{x}}, f_{4}(x) = x\ln x, f_{5}(x) = \frac{\ln x}{x}, f_{6}(x) = \frac{x}{\ln x}$ . 则有以下结论: $f_{1}(\ln x) = f_{4}(x), f_{2}(\ln x) = f_{6}(x), f_{3}(\ln x) = f_{5}(x), f_{4}(\mathrm{e}^{x}) = f_{1}(x), f_{6}(\mathrm{e}^{x}) = f_{2}(x), f_{5}(\mathrm{e}^{x}) = f_{3}(x)$ .

证明 因为 $f_{1}(\ln x) = \mathrm{e}^{\ln x}\ln x = x\ln x = f_{4}(x)$ ，故 $f_{1}(\ln x) = f_{4}(x)$ 成立，同理，可证其余各式.

注 该引理指出这六个函数的内在联系,这是含指数函数与对数函数同构变形的原理.

引理 2 （1）对任意的 $x \in R, e^{x} \geqslant x + 1$ 恒成立，当且仅当 x = 0 时等号成立；

(2)对任意的 $x \in (0, +\infty)$ , $\ln x \leqslant x - 1$ 恒成立，当且仅当 $x = 1$ 时等号成立.

证明 (1) 设函数 $f(x) = \mathrm{e}^{x} - x - 1$ ，则 $f'(x) = \mathrm{e}^x - 1$ ，易知 $f'(x)$ 在 $\mathbf{R}$ 上单调递增，且 $f'(0) = 0$ . 当 $x \in (-\infty, 0)$ 时， $f'(x) < 0$ ；当 $x \in (0, +\infty)$ 时， $f'(x) > 0$ ，故 $f(x) \geqslant f(0) = 0$ ，即 $f(x) \geqslant 0$ 在 $\mathbf{R}$ 上恒成立，即对任意的 $x \in \mathbf{R}, \mathrm{e}^x \geqslant x + 1$ 恒成立，得证. 仿照 (1) 的证明方法，易证得 (2) 成立.

# 2 双变量问题

# 2.1 双变量方程

![](images/07e4ff80521c61b03e9755f7f916a832fc4ccfbb1e816381d65ff284e9656230.jpg)

例 1 已知实数 $x_{1}, x_{2}$ 满足 $x_{1}e^{x_{1}} = e^{3}$ ,

$x_{2}(\ln x_{2}-2)=\mathrm{e}^{5}$ ，则 $x_{1}x_{2}=$ \_\_\_\_.

分析 $x_{2}(\ln x_{2}-2)=\mathrm{e}^{5}$ 可转化为 $\mathrm{e}^{\ln x_{2}-2}(\ln x_{2}-2)=\mathrm{e}^{3}$ ，进而构造函数解决问题.

解 $x_{2}(\ln x_{2} - 2) = \mathrm{e}^{5}$ 可转化为 $\mathrm{e}^{\ln x_2 - 2}(\ln x_2 - 2) = \mathrm{e}^3$ ，设函数 $f(x) = x\mathrm{e}^x$ ，则 $f^{\prime}(x) = (x + 1)\mathrm{e}^{x}$ .当 $x\in (-\infty , - 1)$ 时， $f^{\prime}(x) <   0$ ，当 $x\in (-1, + \infty)$ 时， $f^{\prime}(x) > 0$ ，所以 $f(x)$ 在 $(-\infty , - 1)$ 上单调递减，在 $(-1, + \infty)$ 上单调递增.又 $f(x_{1}) = f(\ln x_{2} - 2) =$ $\mathrm{e}^3 >0$ ，则 $x_{1} = \ln x_{2} - 2$ ，故

$$
x _ {1} x _ {2} = x _ {2} (\ln x _ {2} - 2) = \mathrm{e} ^ {5}.
$$

![](images/8e4f78ed310ea76c7544f04f4910d68dbe8ee145482364521b6ce276a598aa34.jpg)

由条件 $x_{1}\mathrm{e}^{x_{1}} = \mathrm{e}^{3}, x_{2}(\ln x_{2} - 2) = \mathrm{e}^{5}$ ，对比两式的结构特征，将 $x_{2}(\ln x_{2} - 2) = \mathrm{e}^{5}$ 同构而通过构造函数解决问题.

![](images/71fe171de0d859b8b701b9f8c295d9cf43ea529a549ce98120cea68d68cc84d4.jpg)

例2 已知函数 $f(x) = x\mathrm{e}^{x}, g(x) = x\ln x$ ，若

$f(x_{1})=g(x_{2})=t(t>0)$ ，则 $\frac{\ln t}{x_{1}x_{2}}$ 的最大值为\_\_\_\_.

分析 由引理1知 $g(x) = f(\ln x)$ ，同构变形构造函数，利用函数单调性求解.

解 因为 $g(x)=f(\ln x)$ ，由 $f(x_{1})=g(x_{2})=t$ ，可得 $f(x_{1})=g(x_{2})=f(\ln x_{2})>0$ 。又易知 $f(x)$ 在 $(0,+\infty)$ 上单调递增，故有 $x_{1}=\ln x_{2}$ ，由 $f(x_{1})=g(x_{2})=t$ ，可得 $x_{1}e^{x_{1}}=x_{2}\ln x_{2}=t$ ，故 $x_{1}x_{2}=x_{2}\ln x_{2}=t$ ，则 $\frac{\ln t}{x_{1}x_{2}}=\frac{\ln t}{t}$ 。设 $h(t)=\frac{\ln t}{t}$ ，则 $h'(t)=\frac{1-\ln t}{t^{2}}$ ，故当 $t\in(0,e)$ 时， $h'(t)>0$ ，当 $t\in(e,+\infty)$ 时， $h'(t)<0$ ，所以 $h(t)$ 在 $(0,e)$ 上单调递增，在 $(e,+\infty)$ 上单调递减，故 $h(t)\leqslant h(e)=\frac{1}{e}$ ，即 $\frac{\ln t}{x_{1}x_{2}}$ 的最大值为 $\frac{1}{e}$ 。

![](images/1a32fa06864591f6b9c5ec86785c0c88d2a4e2457b8e97b726aea61e16f715ec.jpg)

点评 通过 $g(x) = f(\ln x)$ 可将方程 $f(x_{1}) = g(x_{2})$ 变为同构方程，从而导出关系式 $x_{1} =$ $\ln x_{2}$ ，又由 $x_{1}e^{x_{1}}=x_{2}\ln x_{2}=t$ 可推导出 $x_{1}x_{2}=t$ ，进而构造函数求解问题.

# 2.2 双变量不等式

例 3 已知 $f(x)=\frac{1}{2}x^{2}-ax+(a-1)\ln x$ ，证明：当 1<a<5 时，对任意 $x_{1}, x_{2} \in (0, +\infty)$ ，且 $x_{1} \neq x_{2}$ ，有 $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}} > -1$ .

分析 由 $x_{1}, x_{2}$ 的任意性, 可假设 $x_{1} < x_{2}$ , 将 $\frac{f(x_{1}) - f(x_{2})}{x_{1} - x_{2}} > -1$ 等价变形为 $f(x_{1}) - f(x_{2}) < x_{2} - x_{1}$ , 进而构造函数解决问题.

证明 不妨设 $x_{1} < x_{2}$ , 则 $\frac{f(x_{1}) - f(x_{2})}{x_{1} - x_{2}} > -1$ 可变为 $f(x_{1}) - f(x_{2}) < x_{2} - x_{1}$ , 即 $f(x_{1}) + x_{1} < f(x_{2}) + x_{2}$ . 设 $g(x) = f(x) + x = \frac{1}{2} x^{2} + (1 - a)x + (a - 1)\ln x$ , 则问题转化为证明 $g(x)$ 在 $(0, +\infty)$ 上单调递增. 因 $g'(x) = x + \frac{a - 1}{x} + 1 - a \geqslant 2\sqrt{x \cdot \frac{a - 1}{x}} + 1 - a = 2\sqrt{a - 1} + 1 - a$ , 而 $2\sqrt{a - 1} + 1 - a = -(a - 1) + 2\sqrt{a - 1} = -(\sqrt{a - 1} - 1)^{2} + 1 \in (0, 1]$ , 故 $g'(x) > 0$ , 则 $g(x)$ 在 $(0, +\infty)$ 上单调递增得证.

点评 $f(x_{1}) + x_{1} < f(x_{2}) + x_{2}$ ，不等式两边具有相同的结构，因而构造函数 $g(x) = f(x) + x$ ，则问题转化为证明 $g(x)$ 在 $(0, + \infty)$ 上单调递增.事实上，若 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} > m (x_1 < x_2)$ 或 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} < m (x_1 < x_2)$ ，则可通过同构变形构造函数解决.此外，常见的式子还有 $\frac{f(x_1) - f(x_2)}{x_1 - x_2}>$ $\frac{m}{x_1x_2} (x_1 <   x_2)$ 或 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} <  \frac{m}{x_1x_2} (x_1 <   x_2).$

例4 已知函数 $f(x) = a^2 \ln x, g(x) = -\frac{(a + 1)e^x}{x + 1}, a$ 为常数，且 $a \neq 0$ .

(1)令 $h(x)=f(x)-\frac{(a+1)(x-1)}{x}$ ，求 $h(x)$ 的单调区间；

(2) 设 $a > 0$ ，且当 $x_{1}, x_{2} \in (0,1], x_{1} \neq x_{2}$ 时，都有 $|f(x_{1}) - f(x_{2})| > |g(x_{1}) - g(x_{2})|$ 成立，求实数 $a$ 的取值范围.

分析 第(2)问根据函数 $f(x)$ 和 $g(x)$ 的单调性，可将 $\left|f(x_{1}) - f(x_{2})\right| > \left|g(x_{1}) - g(x_{2})\right|$ 的绝对值去掉,进而同构变形,然后构造函数,再利用函数的单调性解题.

解（1）函数 $h(x)$ 的单调递增区间为 $(\frac{a + 1}{a^2}, +\infty)$ ，单调递减区间为 $(0, \frac{a + 1}{a^2})$ （求解过程略）.

(2) 易知函数 $f(x)$ 在 (0,1] 上单调递增，又 $g'(x) = -\frac{a + 1}{(x + 1)^2} x \mathrm{e}^x$ ，因为 $a > 0$ ，所以 $g'(x) < 0$ ，故 $g(x)$ 在 $x \in (0,1]$ 上单调递减。不妨设 $0 < x_1 < x_2 \leqslant 1$ ，则 $f(x_1) < f(x_2), g(x_1) > g(x_2)$ 。因此 $|f(x_1) - f(x_2)| > |g(x_1) - g(x_2)|$ 可变形为 $f(x_2) - f(x_1) > g(x_1) - g(x_2)$ ，即 $f(x_2) + g(x_2) > f(x_1) + g(x_1)$ 。令 $F(x) = f(x) + g(x) = a^2 \ln x - \frac{a + 1}{x + 1} \mathrm{e}^x$ ，则有 $F(x_2) > F(x_1), F(x)$ 在 (0,1] 上单调递增，故 $F'(x) = \frac{a^2}{x} - \frac{a + 1}{(x + 1)^2} x \mathrm{e}^x \geqslant 0$ 对任意的 $x \in (0,1]$ 恒成立，即 $\frac{a + 1}{a^2} \leqslant \frac{(x + 1)^2}{x^2 \mathrm{e}^x}$ 对任意的 $x \in (0,1]$ 恒成立。设 $G(x) = \frac{(x + 1)^2}{x^2 \mathrm{e}^x}$ ，则 $G'(x) = -\frac{(x + 1)(x^2 + x + 2)}{x^3 \mathrm{e}^x} < 0$ ，故 $G(x)$ 在 (0,1] 上单调递减，故 $G(x) \geqslant G(1) = \frac{4}{\mathrm{e}}$ ，所以 $\frac{a + 1}{a^2} \leqslant \frac{4}{\mathrm{e}}$ ，解得 $a \leqslant \frac{\mathrm{e} - \sqrt{\mathrm{e}^2 + 16\mathrm{e}}}{8}$ 或 $a \geqslant \frac{\mathrm{e} + \sqrt{\mathrm{e}^2 + 16\mathrm{e}}}{8}$ ，又 $a > 0$ ，所以实数 $a$ 的取值范围为 $[\frac{\mathrm{e} + \sqrt{\mathrm{e}^2 + 16\mathrm{e}}}{8}, +\infty)$ 。

点评 将 $|f(x_{1})-f(x_{2})|>|g(x_{1})-g(x_{2})|$ 同构变形为 $f(x_{2})+g(x_{2})>f(x_{1})+g(x_{1})$ ，再构造函数 $F(x)=f(x)+g(x)=a^{2}\ln x-\frac{a+1}{x+1}e^{x}$ .
从而问题转化为函数 $F(x)$ 在 $(0,1]$ 上单调递增，最后转化为恒成立问题处理。事实上，针对这一类含双变量的问题，只要仔细观察式子的结构特征，有效转化式子，然后构造函数，就能利用函数的单调性解决。

# 3 单变量问题

# 3.1 恒成立问题

例 5 已知 a<0，不等式 $x^{a+1}\cdot e^{x}+a\ln x\geqslant0$ 对任意的实数 x>1 恒成立，则实数 a 的最小值为 \_\_\_\_.

分析 $x^{a + 1}\cdot \mathrm{e}^x +a\ln x\geqslant 0$ 等价于 $x^{a + 1}\cdot \mathrm{e}^x\geqslant -a\ln x$ ，进一步变形为 $x\cdot \mathrm{e}^x\geqslant x^{-a}\ln x^{-a}$ ，由引理1可知不等式两边可化为具有相同的结构形式.

解 因为 $x^{a + 1}\cdot \mathrm{e}^x +a\ln x\geqslant 0$ 等价于 $x^{a + 1}\cdot \mathrm{e}^x\geqslant$ $-a\ln x$ ，即 $x\cdot \mathrm{e}^x\geqslant x^{-a}\ln x^{-a}$ .设 $f(x) = x\mathrm{e}^{x}(x>$ 1)，由引理1知 $x^{-a}\ln x^{-a} = f(\ln x^{-a})$ ，则不等式变形为 $f(x)\geqslant f(\ln x^{-a})$ .易知 $f(x)$ 在 $(1, + \infty)$ 上单调递增，又 $a <   0$ ，故 $\ln x^{-a} = -a\ln x > 0$ ，故 $x\geqslant$ $\ln x^{-a}$ ，即 $-a\leqslant \frac{x}{\ln x}$ .设 $g(x) = \frac{x}{\ln x} (x > 1)$ ，则 $g^{\prime}(x) = \frac{\ln x - 1}{(\ln x)^{2}}$ ，当 $x\in (1,\mathrm{e})$ 时， $g^{\prime}(x) <   0$ ，当 $x\in$ $(\mathrm{e}, + \infty)$ 时， $g^{\prime}(x) > 0$ ，所以 $g(x)$ 在(1,e)上单调递减，在(e， $+\infty)$ 上单调递增，则 $g(x)\geqslant g(\mathrm{e}) = \mathrm{e}$ ，故 $-a\leqslant \mathrm{e}$ ，即 $a\geqslant -\mathrm{e}$ ，所以实数 $a$ 的最小值为一e.

![](images/f3323ef0d05ef557fd915f61c9c7f72efff16d0cd8c55581d9c5169f269cc71f.jpg)

事实上,常见的含指数函数和对数函数的不等式问题主要有以下几种类型:1)若 $x_{1}e^{x_{1}}\geqslant$ $x_{2}\ln x_{2}$ ，则可构造函数 $f(x)=xe^{x}$ ， $f(x)=x\ln x$ 或 $f(x)=x+\ln x$ ; 2) 若 $\frac{e^{x_{1}}}{x_{1}}\geqslant\frac{x_{2}}{\ln x_{2}}$ ，则可构造函数 $f(x)=\frac{e^{x}}{x}$ ， $f(x)=\frac{x}{\ln x}$ 或 $f(x)=x-\ln x$ ; 3) 若 $e^{x_{1}}\pm x_{1}\geqslant x_{2}\pm\ln x_{2}$ ，则可构造函数 $f(x)=x\pm\ln x$ 或 $f(x)=e^{x}\pm x$ 。以上这些类型皆可结合指数函数与对数函数的关系以及引理 1 进行证明，留给读者自证。

A. $(0,e]$

B. $(0,e^{2})$

C. $\left[1,e^{2}\right]$

D. $(1,e^{2})$

解 由 $f(x) > 0$ ，可得 $\mathrm{e}^x - a\ln (ax - a) + a > 0$ ，即 $\mathrm{e}^x > a\ln a + a\ln (x - 1) - a$ ，即 $\mathrm{e}^{x - \ln a} - \ln a > \ln (x - 1) - 1$ ，两边同时加上自变量 $x$ ，可得 $\mathrm{e}^{x - \ln a} + x - \ln a > \ln (x - 1) + x - 1.$ 设函数 $h(x) = \mathrm{e}^x + x$ ，则不等式变为 $h(x - \ln a) > h(\ln (x - 1))$ ，易知 $h(x)$ 在 $\mathbf{R}$ 上单调递增，有 $x - \ln a > \ln (x - 1)$ ，即 $\ln a < x - \ln (x - 1)$ . 设 $g(x) = x - \ln (x - 1)$ ，则 $g'(x) =$

$1-\frac{1}{x-1}$ ，由题知 x>1，当 $x\in(1,2)$ 时， $g'(x)<0$ ，当 $x\in(2,+\infty)$ 时， $g'(x)>0$ ，所以 $g(x)$ 在 $(1,2)$ 上单调递减，在 $(2,+\infty)$ 上单调递增，故 $g(x)\geqslant g(2)=2$ ，则 $\ln a<2$ ，解得 $0<a<e^{2}$ ，选 B.

例 7 已知函数 $f(x)=\ln x+x-x\mathrm{e}^{x+1}$ ，则函 $(x)$ 的最大值为 \_\_\_\_.

分析 若直接求导分析函数 $f(x)$ 的单调性, 不仅运算量大, 而且会遇到导数零点不可解的情况. 因此, 可利用同构变形解题.

解 因为 $f(x)=\ln x+x-x\mathrm{e}^{x+1}=\ln x+x-\mathrm{e}^{\ln x+x+1}$ ，由引理2知 $e^{\ln x+x+1}\geqslant\ln x+x+2$ ，当且仅当 $\ln x+x+1=0$ 时等号成立（事实上，存在 $x_{0}\in(0,+\infty)$ ，使得 $\ln x_{0}+x_{0}+1=0$ 成立，读者可自行证明）。所以 $f(x)\leqslant\ln x+x-(\ln x+x+2)=-2$ ，故函数 $f(x)$ 的最大值为 -2。

![](images/424cac14f250846408682421391f7e065fe5907d1614bf0ff3e5380fa475f445.jpg)

点评 $x\mathrm{e}^{x + 1}$ 可变形为 $\mathrm{e}^{\ln x + x + 1}$ ，则函数 $f(x)$ 变为 $f(x) = \ln x + x - \mathrm{e}^{\ln x + x + 1}$ ，结合引理2，利用$\mathrm{e}^{x}\geqslant x + 1$ 可得 $\mathrm{e}^{\ln x + x + 1}\geqslant \ln x + x + 2.$ 当然，本题也可直接求导分析导函数的正负，从而得到函数 $f(x)$ 的单调性，进而求得最值.不过，其中涉及隐零点的代换且运算量较大，感兴趣的读者可查阅关于隐零点问题的相关文献.事实上，由引理2可导出更多的不等式，例如，对任意的 $x\in \mathbf{R},\mathrm{e}^x\geqslant \mathrm{ex}$ 恒成立；对任意的 $x\in (-1, + \infty),\ln (x + 1)\leqslant x$ 恒成立.

例8 已知函数 $f(x) = x\mathrm{e}^{x} - ax^{2}, g(x) =$ $\ln x + x - x^{2} + 1 - \frac{e}{a}$ ，且 a > 0，若关于 x 的不等式 $f(x) - ag(x) \geqslant 0$ 恒成立，则实数 a 的取值范围为 \_\_\_\_.

# 导数与三角“交会型”试题演绎出来的精彩

巨小鹏
