# 突破“懂而不会”，提升解题效率

# ●江苏省通州高级中学 邵春燕

在解数学题时,学生通常是概念、定理背得滚瓜烂熟,章节训练题做得得心应手,然而在综合考试时却常出现“懂而不会”的现象.究其原因,其很大程度上是学生在解题时找不到问题的切入点,进而感觉无从下手,故很难找到问题的突破口,也就无法成功解决问题.那么,如何找到解题的切入点呢?笔者从以下几方面进行了阐述,供参考!

# 1 常用解题策略

# 1.1 回归定义

数学概念是数学学习的基石,是数学解题的关键.然学生应用概念解题时却显得格外生疏,其主要原因是学生对概念的学习仅停留于文字的记忆,对其内涵和外延挖掘得较少,使得学生在解题时往往忽视基本概念,故将解题复杂化,浪费宝贵的解题时间.因此,要提升解题效率,应注意定义的回归.

例 1 已知数列 $\{a_{n}\}$ 中, $a_{1}=1$ , $\frac{1}{a_{n+1}}=\frac{1}{a_{n}}+\frac{1}{3}$ ,
则 $a_{100}=$ \_\_\_\_.

解析: 求解时若根据 $\{a_{n}\}$ 的递归公式进行逐一计算, 显然步骤繁琐, 计算量过大. 由已知 $\frac{1}{a_{n+1}} = \frac{1}{a_{n}} + \frac{1}{3}$ , 得 $\frac{1}{a_{n+1}} - \frac{1}{a_{n}} = \frac{1}{3}$ , 转化后容易联想到等差数列. 根据等差数列定义, 可判断 $\left\{\frac{1}{a_{n}}\right\}$ 是以 $\frac{1}{a_{1}}$ 为首项, $\frac{1}{3}$ 为公差的等差数列, 分析至此就找到了解题的切入点. 所以, $\left\{\frac{1}{a_{n}}\right\}$ 的通项公式 $\frac{1}{a_{n}} = \frac{1}{a_{1}} + (n-1) \times \frac{1}{3} = \frac{n+2}{3}$ , 于是可得 $\frac{1}{a_{100}} = 34$ , 故 $a_{100} = \frac{1}{34}$ .

根据已知条件变形,找到了满足等差数列成立的条件,联想等差数列的概念和通项公式,问题也就迎刃而解了.另外,高中数学知识分为不同的模块,每个模块都涉及不同的概念,若将概念进行串联,往往可以找到各个模块间的联系,进而有助于知识体系的建构和解题能力的提升.

# 1.2 应用公式

公式套用法是高中数学解题的常用方法之一,其往往更加直接、高效.然高中数学题型多变,若想应用好公式,学生在记忆公式时也应多关注公式的变形及公式的生成过程,以便在解题时能够及时捕捉有用信息,利用公式为已知和未知建桥铺路.

例 2 已知 $\cos\alpha=\frac{1}{7},\cos(\alpha+\beta)=-\frac{11}{14}$ ，且 $\alpha,\beta$ 均为锐角，求 $\beta$ 的值.

解析:本题已知条件中给出了角 $\alpha$ 和 $\alpha + \beta$ 的余弦值, 结论为求 $\beta$ 的值, 将已知和未知建立联系有 $\beta = (\alpha + \beta) - \alpha$ , 于是很容易联想到三角函数的差角公式, 进而有 $\cos \beta = \cos [(\alpha + \beta) - \alpha] = \cos (\alpha + \beta) \cos \alpha + \sin (\alpha + \beta) \sin \alpha$ . 这样问题的突破点就被发现了. 由已知相应的余弦值及角的取值范围, 容易求得 $\sin \alpha = \frac{4\sqrt{3}}{7}$ , $\sin (\alpha + \beta) = \frac{5\sqrt{3}}{14}$ , 然后求出 $\cos \beta = \frac{1}{2}$ , 最后由 $\beta$ 为锐角, 求得 $\beta = \frac{\pi}{3}$ .

三角公式众多,如果单凭记忆而不会分析,那么不仅很难发挥公式法直接、高效的作用,而且容易因公式混淆而出现错解.因此,在学习时要引导学生关注公式的推理过程,让学生多理解和掌握常规公式的变形,进而应用时可以得心应手.

# 1.3 化繁为简

化繁为简顾名思义就是将复杂问题简单化,从而使思路更加清晰,步骤更加简单,求解更加容易,解题更加高效.那么,在简化的过程中,学生要善于找到问题的本质,切勿被复杂的表象所吓倒.很多数学问题看似复杂,然若根据蛛丝马迹找准切入点,问题便会迎刃而解.

例 3 已知直线 $l:(2a+1)x+(a+1)y=7a+4$ ，圆 $C:(x-1)^{2}+(y-2)^{2}=258$ ，求证：不论 a 取何实数，直线 l 与圆 C 都有两个交点.

解析:本题如果运用代数法,根据根的判别式进行求解,显然困难重重,若用几何法显然也非常复杂,因此在解题时需要先从全局出发,将问题简单化.由于直线 l 为含字母参数 a 的动直线,动直线是否恒过一定点呢?如果恒过的定点正好为圆 C 内的一点,那么就很容易得出结论.分析至此,可以将题目转化为“求证直线 l 恒过圆 C 内的一定点”,显然转化后题目变得更加简单明了.

将直线方程 $(2a + 1)x + (a + 1)y = 7a + 4$ 转化为 $(2x + y - 7)a + (x + y - 4) = 0$ ，由 $a$ 的任意性，可得 $2x + y - 7 = 0,$ 解得直线 $l$ 恒过定点(3,1)，显然定点 $x + y - 4 = 0.$

(3,1)为圆 C 内的一点. 故不论 a 取何实数, 直线 l 与圆 C 都有两个交点.

学生在遇到动点问题或含参问题时,常会出现畏难情绪,此类问题若用常规方法求解,往往步骤繁琐,计算复杂.因此,解题时需要找到准确的切入口,将问题化繁为简.

# 1.4 化陌生为熟悉

数学题目虽然多变,但仔细推敲大多可以根据题目特点找到解题的通性通法.对于一些综合性较强、条件较隐藏的问题,要善于将其转化为典型的、熟悉的数学模型.利用典型的、熟悉的数学模型求解,更有利于调动学生原认知,提高解题效率.

例 4 已知圆的方程为 $x^{2} + y^{2} = 1$ ，点 $M(x, y)$ 是这个圆上的任意一点，当点 M 在何位置时 $x + y$ 或 xy 取最大值，并求出此时的最大值.

解析:根据已知条件将结论转化为 $x + y = x + \sqrt{1 - x^{2}}$ , $xy = x \sqrt{1 - x^{2}}$ ，那么不仅要求出两函数的最大值，还要求出此时 M 的位置，求解复杂，难以入手，故该方法不可取，需要另辟蹊径。根据圆的方程 $x^{2} + y^{2} = 1$ 容易联想到 $\sin^{2}\theta + \cos^{2}\theta = 1$ ，故将其转化为参数方程 $\left\{\begin{aligned}x &= \cos\theta, \\ y &= \sin\theta\end{aligned}\right.$ （θ为参数），则问题转化为三角函数问题，即 $x + y = \cos\theta + \sin\theta = \sqrt{2}\sin(\theta + \frac{\pi}{4})$ ， $xy = \cos\theta\sin\theta = \frac{1}{2}\sin2\theta$ 。又因为 $\sin\theta$ 的最大值为 1，问题也就不难解决了。

该问题充分利用了 $x^{2}+y^{2}=1$ 这一关键信息，进而将题目转化为三角函数问题。数学学习中要关注知识点间的联系，善于建构完整的知识体系，只有这样才能敏锐地找出问题的切入点，从而通过迁移和转化顺利求解。

# 1.5 逆向推理

在培养学生数学解题能力时,要重视培养其思维的变通性和双向性.当从“正面”求解找不到突破口时,可以尝试从反面解决;当“顺势”推理碰壁时,可以“逆势”而行;当存在太多“可能”时,可以从“不可能”入手,以此找到解题的切入点.

例 5 已知 x 为实数, $a = x^{2} + \frac{1}{2}$ , b = 2 - x, c = $x^{2} - x - 1$ , 证明: a, b, c 中至少有一个不小于 1.

解析:本题若从正面求解需要分多种情况,难度较大,故可从反面出发,逆向思考.从结论“至少有一个”进行分析,若假设a,b,c都小于1,证明将更加容易,应用反证法规避了分类讨论,使得证明思路更加清晰.

假设 $a, b, c$ 都小于1，则有 $a + b + c < 3$ 。而由已知，得 $a + b + c = x^2 + \frac{1}{2} + 2 - x + x^2 - x + 1 = 2x^2 -$

$2x+\frac{7}{2}=2\left(x-\frac{1}{2}\right)^{2}+3\geqslant3$ ，与假设矛盾，故假设不成立。所以a,b,c中至少有一个不小于1。

# 1.6 化抽象为具体

抽象的数学问题往往会使学生产生畏难心理,然很多抽象的数学问题大多源于生活,因此,求解题时将抽象的问题具体化、形象化,有助于学生深入理解题意,进而找到问题的切入点,轻松解决问题.

例 6 集合 A 和集合 B 各含 12 个元素, $A \cap B$ 含有 4 个元素. ① $C \subseteq (A \cup B)$ , 且 C 含有 3 个元素; ② $C \cap A \neq \varnothing$ . 试求同时满足 ① 和 ② 两个条件的集合 C 的个数.

解析:题目较为抽象,不易于理解,解题时可以将其转化为具体模型.设某班数学竞赛组为集合A,物理竞赛组为集合B,数学和物理竞赛组各有12名成员,其中有4人同时参加两个竞赛组 $(A\cap B)$ .现在要从这些学生中选取3人(集合C)参加年级竞赛,按照规定,3人中至少有1人是数学竞赛组的成员,求共有多少种选法.

根据题意可知，两组共有20人，其中有8人只参加了物理竞赛，所以共有 $C_{20}^{3}-C_{8}^{3}=1084$ 种选法.

本题显然是一个集合中的计数问题,但是题目较抽象,理解较为困难.为了找到解决问题的切入点,将集合赋予形象化的内容,使问题变得更加具体,进而通过领悟现实问题来体验集合中的容斥原理,使问题更加简单形象,解题思路更加清晰.

# 2 反思与感悟

学生常感觉数学题目灵活多变,不易求解,其主要有以下两个原因:一是基础知识不扎实.部分学生在学习概念、公式、定理时常走马观花,感觉只要会解例习题就是学会了,对其内涵、外延的认识不够,故不能理解其中隐含的数学知识和数学思想,以致于不能将各知识点相串联,对知识的把握过于简单化、形式化,进而影响知识的迁移.因此,在教学中应根据学生特点采取行之有效的方案,如通过背诵、抄写等形式强化学生对基础知识的记忆,同时通过总结、归纳、反思将各板块内容进行梳理,从而形成网络,为解题提供知识保障.二是缺乏解题经验,找不到解题的切入点.部分学生虽然有着丰富的知识储备,但其分析能力较弱,解题时不知该从何做起,不能找到解决问题的切入点,为此应加强训练,通过多听(听教师讲解)、多看(观察题目特征)、多想(类比、联想提升分析能力,总结归纳积累解题方法)来提升应用数学知识的能力.

教师要重视对学生双基的培养,重视解题方法和解题技巧的积累,以培养学生良好的审题习惯和分析能力,进而根据题目的“蛛丝马迹”,找到解题的切入点,从而提升解题能力. Z
