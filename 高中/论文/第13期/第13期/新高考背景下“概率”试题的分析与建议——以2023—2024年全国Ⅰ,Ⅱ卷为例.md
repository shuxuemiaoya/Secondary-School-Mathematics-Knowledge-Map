# 新高考背景下“概率”试题的分析与建议

——以 2023—2024 年全国 I，Ⅱ卷为例

(哈尔滨师范大学教师教育学院, 黑龙江 哈尔滨 150000)

摘 要:文章以2023—2024年全国卷典型试题为切入点,以考促学,探索概率命题特点及趋势,并提出四条教学建议:应用生活案例,创造概率情境;设置问题层次,培养学生核心素养;注重解题过程,发展学生概率思维;基于整体关联性,引导学生构建知识体系.

高考具有立德树人、服务选才、引导教学的核心功能. 准确把握高考的考查内容和考查要求,有利于发挥高考对素质教育的促进作用 $^{[1]}$ . 概率部分的教学内容灵活性较强,与实际生活联系较为紧密,新高考改革后,考试命题更加灵活,更侧重实际应用. 因此,有必要在新课改的背景下对近几年新高考全国卷中概率试题的命题特点、思想方法进行分析,用命题指导教学,从而提出相应的教学建议.

# 1 试题特点分析

# 1.1 总体统计与分析

近几年高考中,概率部分除考查随机事件、古典概型、几何概型等基础知识外,还强化了与统计、数列、几何等知识交互的综合性,从核心素养的考查需求出发,相关题目在命题形式上不断创新,呈现出与数学文化、社会生活紧密渗透和联系的特点.此外,该部分在试卷中的题量及所占分值较为稳定.

可见,概率是高考必考专题,考点稳定.在填选题中,主要考查条件概率、古典概型及概率计算等;解答题侧重考查概率与其他知识的综合运用、知识整合及实际应用.对数学核心素养的考查聚焦于数学抽象、逻辑推理、数学建模和数学运算.试题贴合高中生的知识水平与生活体验,立足基础又高于基础,既强调对基本概念的深入理解和灵活运用,也注重综合能力,落实核心素养.

# 1.2 具体试题分析

# 1.2.1 试题情境真实新颖,在具体情境中抽象数学关系

例 1 （2023 年新高考Ⅱ卷 12 题）在信道内传输 0,1 信号，信号的传输相互独立。发送 0 时，收到 1 的概率为 $\alpha(0<\alpha<1)$ ，收到 0 的概率为 $1-\alpha$ ；发送 1 时，收到 0 的概率为 $\beta(0<\beta<1)$ ，收到 1 的概率为 $1-\beta$ 。考虑两种传输方案：单次传输和三次传输。单次传输是指每个信号只发送 1 次，三次传输是指每个信号重复发送 3 次。收到的信号需要译码，译码规则如下：单次传输时，收到的信号即为译码；三次传输时，收到的信号中出现次数最多的即为译码（例如，若依次收到 1,0,1，则译码为 1）。则（）.

A. 采用单次传输方案, 若依次发送 1,0,1, 则依次收到 1,0,1 的概率为 $(1-\alpha)(1-\beta)^{2}$   
B. 采用三次传输方案, 若发送 1, 则依次收到 1, 0, 1 的概率为 $\beta(1-\beta)^{2}$   
C. 采用三次传输方案, 若发送 1, 则译码为 1 的概率为 $\beta(1-\beta)^{2}+(1-\beta)^{3}$   
D. 当 $0 < \alpha < 0.5$ 时, 若发送 0, 则采用三次传输方案译码为 0 的概率大于采用单次传输方案译码为 0 的概率

本题以信号传输为情境考查二项分布及其应用,设计单次传输和三次传输两种方式,研究各方式下得到正确信号的概率,考查对新知识的理解和探究能力. A, B 选项考查概率计算, C, D 选项考查概率思维,涉及不同位置关系构成的基本事件. 重点考查学生对概率基本事件的处理能力,注重逻辑推理、数学运算和数学抽象素养,反映高考数学命题注重理论联系实际,借生活实例渗透核心素养与概率思想.

# 1.2.2 问题设定逐级深入,由浅入深考查核心素养水平

例 2 （2023 年新高考 I 卷 21 题）甲乙两人投篮，每次由其中一人投篮，规则如下：若命中则此人继续投篮，若未命中则换为对方投篮。无论之前投篮情况如何，甲每次投篮的命中率均为 0.6，乙每次投篮的命中率均为 0.8，由抽签确定第一次投篮的人选，第一次投篮的人选甲、乙的概率各为 0.5。

(1)求第2次投篮的人是乙的概率;  
(2) 求第 i 次投篮的人是甲的概率;  
(3) 已知: 若随机变量 $X_{i}$ 服从两点分布, 且 $P(X_{i}=1)=1-P(X_{i}=0)=q, i=1,2,\cdots,n$ , 则 $E(\sum_{i=1}^{n}X_{i})=\sum_{i=1}^{n}q_{i}$ , 记前 n 次 (即从第 1 次到第 n 次) 投篮中甲投篮的次数为 Y, 求 $E(Y)$ .

第(1)问考查简单概率计算;第(2)问从第二次投篮起,投篮人选与上一次投篮的人密切相关,如果学生能联想到马尔可夫链知识,解题就非常容易了,从与数列知识关联角度可以发现, $P_{i}$ 与等比数列有关,通过配凑可以得到 $\left\{P_{i}-\frac{1}{3}\right\}$ 是一个等比数列;第(3)问则需熟练运用两点分布和期望公式.

本题综合性较强,问题层层递进,第(2)问嵌套上一问,由浅入深地考查学科核心素养,契合课标所划分的三个水平.解决第(2)问需在充分理解题意和第(1)问的基础上进行,题目难度由浅入深,主要考查概率积事件、概率计算、马尔可夫链、等比数列、二项分布等知识,通过合理设置问题,按照不同水平考查学生的数学抽象、逻辑推理等核心素养.

# 1.2.3 试题突出数学思维考查,注重整体关联性

例 3 （2024 年新高考 I 卷 19 题）设 m 为正整数，数列 $a_{1}, a_{2}, a_{3}, \cdots, a_{4m+2}$ 是公差不为 0 的等差数列，若从中删去两项 $a_{i}$ 和 $a_{j} (i < j)$ 后剩余的 4m 项可被平均分成 m 组，且每组的 4 个数都能构成等差数列，则称数列 $a_{1}, a_{2}, a_{3}, \cdots, a_{4m+2}$ 是 $(i, j)$ —可分数列.

(1) 写出所有的 $(i,j)$ , $1 \leqslant i < j \leqslant 6$ , 使数列 $a_{1}$ , $a_{2}, \cdots, a_{6}$ 是 $(i,j)$ —可分数列;  
(2) 当 $m \geqslant 3$ 时, 证明: 数列 $a_{1}, a_{2}, \cdots, a_{4m+2}$ 是 (2,13)—可分数列;  
(3)从 $1,2,3,\cdots,4m+2$ 中一次任取两个数 i 和 $j(i<j)$ ，记数列 $a_{1},a_{2},a_{3},\cdots,a_{4m+2}$ 是 $(i,j)$ —可分数列的概率为 $P_{m}$ ，证明： $P_{m}>\frac{1}{8}$ .

本题以等差数列为载体,是一道集组合数论、组合构造与概率于一体的综合性题目.第(3)问在新定义的背景下考查概率计算,知识点源于课本基础,但对学生的数学思维与解题能力要求很高.学生可以自主选择递推法、数学归纳法、枚举法等策略解题,需在前两问基础上进行一般化推广,体现从具体到抽象的思维过程.解题时,上一次的结果影响下一次的结果,需通过递推、迭代等发现规律,重点考查逻辑推理素养,要求学生整合知识、细致观察、合理变形,综合运用知识,突出知识之间的整体关联性,凸显了对学生创新能力和创新意识的考查.

# 2 教学建议

# 2.1 应用生活案例,创造概率情境

近年来,高考真题的情境性不断增强,概率部分与生活实际联系愈发紧密,如2020年Ⅰ卷19题体育比赛、2021年Ⅰ卷18题“一带一路”知识竞赛、2022年Ⅰ卷20题卫生习惯与患病关系等.因此概率教学也应置于实际情境中,搭建概率知识与现实世界的桥梁.选择符合学生认知发展且蕴含时代气息的生活案例,利用与时俱进、恰当合理的情境,化解抽象概率知识带来的思维障碍,激发学生求知欲,助力学生构建清晰的概率基础知识表象,深化理解.

# 2.2 设置问题层次,培养学生核心素养

新课标新高考背景下，“核心素养”成为教师教学质量评价标准. 根据对概率试题的统计与分析发现, 概率部分主要从数学抽象、逻辑推理、数学建模和数学运算等四个维度考查核心素养,且在相关例题中呈现出由浅入深、分层次考查核心素养水平的特点.可见,概率教学要落实核心素养,需依据具体问题,按照核心素养的三个水平设置递进式问题,将课堂归还给学生,让其自主研究问题的解决方法,培养学生从数学的角度去发现问题、研究问题的能力,感悟数学思想,积累思维经验 $^{[2]}$ .

# 2.3 注重解题过程,发展学生概率思维

由 1.2.3 节的分析可知,概率教学应注重让学生体验知识的发生过程,课堂教学要遵循课程标准,结合学情教材进行创新设计与实施,以“一般方法”指导解题教学,教会学生数学思维,使学生在面对新颖情境、陌生问题时能独立找到解决方法,提升独立分析和解决新情境问题的能力.

习题训练时,教师可开展变式训练,引导学生选择适合自己的方法,培养发散思维,还要注重引导学生利用数形结合思想将抽象的概率题目信息转化为直观的图表,辅助解题.

# 2.4 基于整体关联性,引导学生构建知识体系

高考试题的综合性和创新性持续提升,概率考题不再局限于概率本身,常与统计、数列、函数等知识紧密相连.因此,教师教学时要注重知识关联.概率是概率论和数理统计的基本概念,是高中数学的重要分支,为学生后续的学习打基础.同时,概率的学习依赖学生已掌握的基础知识与思想方法,具有承上启下的作用.教师应基于知识的整体关联性,引导学生构建完整的知识体系.
