# 1 试题解析

题目 (2024 年新高考 I 卷第 4 题) 已知 $\cos(\alpha)$ $+\beta)=m,\tan\alpha\tan\beta=2$ ,则 $\cos(\alpha-\beta)=(\quad)$ .

A. $-3m$

B. $-\frac{m}{3}$

C. $\frac{m}{3}$

D. 3m

解法 1 因为 $\cos(\alpha+\beta)=m$ ,

所以 $\cos\alpha\cos\beta-\sin\alpha\sin\beta=m.$

又 $\tan\alpha\tan\beta=2$ ,所以 $\sin\alpha\sin\beta=2\cos\alpha\cos\beta.$

故 $\cos\alpha\cos\beta-2\cos\alpha\cos\beta=m.$

即 $\cos\alpha\cos\beta = -m.$

从而 $\sin\alpha\sin\beta = -2m.$

故 $\cos(\alpha-\beta)=-3m.$ 故选 A.

解法 2 由积化和差公式得到

$$
\cos \alpha \cos \beta = \frac {1}{2} [ \cos (\alpha + \beta) + \cos (\alpha - \beta) ],
$$

$$
\sin \alpha \sin \beta = - \frac {1}{2} [ \cos (\alpha + \beta) - \cos (\alpha - \beta) ].
$$

因为 $\tan \alpha \tan \beta = 2$ ，所以 $\sin \alpha \sin \beta = 2\cos \alpha \cos \beta .$

# 2 拓展延伸,深入思考

变式 1 已知 $\cos(\alpha + \beta) = m, \cos(\alpha - \beta) = -3m$ ，则 $\tan\alpha\tan\beta =$ \_\_\_\_ .

解析 $\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta=m,$

$$
\cos (\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta = - 3 m,
$$

所以 $\cos\alpha\cos\beta=-m,\sin\alpha\sin\beta=-2m.$

则 $\tan \alpha \tan \beta = \frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta} = 2.$

评析 将高考试题中的条件与结论交换位置，利用两角和与差的余弦公式展开得到 $\cos\alpha\cos\beta = -m, \sin\alpha\sin\beta = -2m$ ，从而顺利解决问题.

变式2 已知 $\alpha, \beta \in (0, \frac{\pi}{2})$ , $\sin \alpha - \sin \beta = -\frac{1}{2}$ , $\cos \alpha - \cos \beta = \frac{1}{2}$ , 则 $\tan \alpha + \tan \beta =$ \_\_\_\_.

解法1 因为 $\sin \alpha - \sin \beta = -\frac{1}{2}, \cos \alpha - \cos \beta = \frac{1}{2}$ , 所以 $\sin \alpha - \sin \beta = -(\cos \alpha - \cos \beta)$ . 所以 $\sin \alpha + \cos \alpha = \sin \beta + \cos \beta$ . 所以 $\sqrt{2} \sin (\alpha + \frac{\pi}{4}) = \sqrt{2} \sin (\beta + \frac{\pi}{4})$ . 所以 $\sin (\alpha + \frac{\pi}{4}) = \sin (\beta + \frac{\pi}{4})$ .

因为 $\alpha,\beta\in(0,\frac{\pi}{2})$ ，所以 $\alpha+\frac{\pi}{4},\beta+\frac{\pi}{4}\in(\frac{\pi}{4},\frac{3\pi}{4})$ .

所以 $\alpha + \frac{\pi}{4} = \beta + \frac{\pi}{4}$ 或者 $(\alpha + \frac{\pi}{4}) + (\beta + \frac{\pi}{4}) = \pi.$

所以 $\alpha = \beta$ 或者 $\alpha +\beta = \frac{\pi}{2}.$

因为 $\sin\alpha - \sin\beta = -\frac{1}{2}$ ，所以 $\alpha + \beta = \frac{\pi}{2}$ .

所以 $\sin \alpha -\sin \beta = \sin \alpha -\sin (\frac{\pi}{2} -\alpha) = \sin \alpha$ $-\cos \alpha = -\frac{1}{2}.$ 即 $(\sin \alpha -\cos \alpha)^2 = 1 - 2\sin \alpha \cos \alpha = \frac{1}{4}.$

所以 $\sin\alpha\cos\alpha=\frac{3}{8}.$

所以 $\tan \alpha +\tan \beta = \tan \alpha +\tan \left(\frac{\pi}{2} -\alpha\right) = \tan \alpha$ $+ \frac{1}{\tan\alpha} = \frac{\sin\alpha}{\cos\alpha} +\frac{\cos\alpha}{\sin\alpha} = \frac{1}{\sin\alpha\cos\alpha} = \frac{8}{3}.$

解法2 因为 $\sin \alpha - \sin \beta = -\frac{1}{2}, \cos \alpha - \cos \beta = \frac{1}{2}$ , 所以 $\sin \alpha - \sin \beta = -(\cos \alpha - \cos \beta)$ . 所以 $\sin \alpha + \cos \alpha = \sin \beta + \cos \beta$ . 所以 $(\sin \alpha + \cos \alpha)^2 = (\sin \beta + \cos \beta)^2$ .

所以 $1 + 2\sin\alpha\cos\alpha = 1 + 2\sin\beta\cos\beta.$

所以 $\sin2\alpha=\sin2\beta.$

因为 $2\alpha, 2\beta \in (0, \pi)$ , 所以 $2\alpha = 2\beta$ 或 $2\alpha + 2\beta = \pi$ .

所以 $\alpha = \beta$ 或 $\alpha +\beta = \frac{\pi}{2}.$

因为 $\sin\alpha - \sin\beta = -\frac{1}{2}$ ，所以 $\alpha + \beta = \frac{\pi}{2}$ .

所以 $\sin \alpha -\sin \beta = \sin \alpha -\sin \left(\frac{\pi}{2} -\alpha\right) = \sin \alpha$ $-\cos \alpha = -\frac{1}{2}.$ 所以 $\sin \alpha = \cos \alpha -\frac{1}{2}.$

所以 $1 - \cos^{2}\alpha = \cos^{2}\alpha - \cos\alpha + \frac{1}{2}$ .

因为 $\alpha \in (0, \frac{\pi}{2})$ ，所以 $\cos \alpha = \frac{1 + \sqrt{7}}{4}$ .

所以 $\tan\alpha=\frac{\left(\sqrt{7}-1\right)^{2}}{6}.$

所以 $\tan \alpha +\tan \beta = \tan \alpha +\tan \left(\frac{\pi}{2} -\alpha\right) = \tan \alpha$ $+ \frac{1}{\tan\alpha} = \frac{8}{3}.$

解法 3 由万能公式可知

$$
\sin \alpha - \sin \beta = \frac {2 \tan (\alpha / 2)}{1 + \tan^ {2} (\alpha / 2)} - \frac {2 \tan (\beta / 2)}{1 + \tan^ {2} (\beta / 2)}
$$

$$
= - \frac {1}{2}, \tag {①}
$$

$$
\begin{array}{l} \cos \alpha - \cos \beta = \frac {1 - \tan^ {2} (\alpha / 2)}{1 + \tan^ {2} (\alpha / 2)} - \frac {1 - 2 \tan^ {2} (\beta / 2)}{1 + \tan^ {2} (\beta / 2)} \\ = - \frac {1}{2}. \tag {②} \\ \end{array}
$$

因为 $\alpha,\beta\in(0,\frac{\pi}{2})$ ，所以 $\frac{\alpha}{2},\frac{\beta}{2}\in(0,\frac{\pi}{4})$ .

所以 $\tan\frac{\alpha}{2}>0,\tan\frac{\beta}{2}>0.$ ③

联立①②③,得

$$
\frac {\tan \alpha}{2} = \frac {\sqrt {7} - 2}{3}, \frac {\tan \beta}{2} = \sqrt {7} - 2.
$$

所以 $\tan\alpha + \tan\beta = \frac{2\tan(\alpha/2)}{1 - \tan^{2}(\alpha/2)}$

$$
+ \frac {2 \tan (\beta / 2)}{1 - \tan^ {2} (\beta / 2)} = \frac {8 8 - 3 2 \sqrt {7}}{3 3 - 1 2 \sqrt {7}} = \frac {8}{3}.
$$

评析 法1通过三角函数值的关系找到角之间关系从而解决问题;法2利用同角三角函数关系和二倍角公式找到角之间的关系从而建立解题思路;法3利用万能公式建立 $\tan\frac{\alpha}{2}$ 与 $\tan\frac{\beta}{2}$ 的方程,再利用二倍角公式得到结果 $^{[1]}$ .

变式 3 已知 $x, y \in R, \sin x + \cos y = \frac{2}{3}, \cos x + \sin y = \frac{1}{3}$ ，则 $\sin(x - y) =$ \_\_\_\_.

解法1 因为 $(\sin x + \cos y)^2 + (\cos x + \sin y)^2 = 2 + 2\sin (x + y) = \frac{5}{9}$ , 所以 $\sin (x + y) = -\frac{13}{18}$ .

所以 $(\sin x + \cos y)^2 - (\cos x + \sin y)^2 = 2(\sin^2 x - \sin^2 y) + 2\sin (x - y) = \frac{1}{3}$ .

又因为 $\sin^{2}x - \sin^{2}y = \sin(x - y)\sin(x + y)$ ,

所以 $\sin(x-y)=\frac{1}{6}\div\frac{5}{18}=\frac{3}{5}.$

解法2 $\sin x + \cos y = \sin x + \sin \left(\frac{\pi}{2} -y\right)$

$$
= 2 \sin \left(\frac {\pi}{4} + \frac {x - y}{2}\right) \cos \left(\frac {x + y}{2} - \frac {\pi}{4}\right), \cos x + \sin y = \cos x
$$

$+\cos\left(\frac{\pi}{2}-y\right)=2\cos\left(\frac{\pi}{4}+\frac{x-y}{2}\right)\cos\left(\frac{x+y}{2}-\frac{\pi}{4}\right)$ ，所

以 $\tan \left(\frac{\pi}{4} +\frac{x - y}{2}\right) = 2,\cos \left(\frac{\pi}{2} +x - y\right) = -\frac{3}{5}.$

所以 $\sin(x-y)=\frac{3}{5}.$

解法3 $\sin [ (x - y) + y] + \cos [ x - ( x - y ) ]$ $= \sin (x - y)(\cos y + \sin x) + \cos (x - y)(\sin y + \cos x)$

$\cos [ (x - y) + y] + \sin [ x - (x - y) ] = \cos (x - y) (\cos y + \sin x) - \sin (x - y) (\sin y + \cos x)$ ,

所以 $2\sin(x-y)+\cos(x-y)=2$ ,

$$
2 \cos (x - y) - \sin (x - y) = 1.
$$

解得 $\sin(x-y)=\frac{3}{5}$ .

评析 变式 3 在变式 2 的基础上进一步提升问题的复杂度, 将条件中的同名三角函数的关系转化为异名三角函数的关系, 将问题中的正切值转换成正弦值.
