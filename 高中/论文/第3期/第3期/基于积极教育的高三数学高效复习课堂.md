# 基于积极教育的高三数学高效复习课堂

● 江苏省口岸中学 石广亮

基于积极教育的高三数学高效复习课应以创新教学为立意,具体来说就是要创新复习导入,创新变式拓展,创新合作探究,从而以积极教育的推进来建构高效数学课堂.

# 一、问题的提出

高三数学复习课是高中数学教学的一个重心,它是学生完成中学所有学习内容后进行的一次全面系统的回顾与整合,以达到有机整合各部分知识,建构数学知识结构体系的目的.从而,高三复习课通常存在“大容量、快节奏”的特征.笔者一直在思考,能不能以积极教育的推进来建构高效数学课堂.

# 二、对于积极教育与高效课堂的理论认识

积极教育是一个崭新的教育教学理念, 就是以学生潜在的积极力量和品质为着力点, 以增强学生的积极体验为着手点, 以促进学生全面发展的积极心理品质为落脚点的一种新型教育方式. 积极教育是对教育的重新定位, 可以强有力地帮助学生掌握知识, 获得学业的成功, 并适应现代社会教育的新观念.

所谓“高效课堂”，就是在有限的课堂40分钟内完美完成教学任务，实现教育教学的三维目标，以求取得课堂教学效益的最大化、课堂效率的最优化和课堂效果的最好化。高效课堂整体可概括为：低消耗、高质量、全维度。

# 三、基于积极教育，构建高三高效复习课堂的实践

就高三的复习课而言,在积极教育的指导下如何建设?笔者认为需从以下几个方面入手:

# 1. 创新复习导入

传统高三复习课中,教师习惯于直接复习概念,或是对知识产生的过程进行简单回顾,又或是反复刷题,这些都让学生觉得枯燥无味,积极教育下的复习课堂需要创新复习导入,让学生感觉复习是源于自身的学习需求,让学生积极主动参与复习,建构已是自然,高效也是必然.

# 案例 1 以“圆锥曲线”的复习导入为例

在复习本节内容时,笔者以歌曲“圆锥曲线之小苹果”导入课堂,在课堂伊始播放,使学生在愉悦中获得充分的学习体验.

歌词如下:我画了一个圆锥面,接着平面去截面,各种情况都很有趣,椭圆、抛物线、双曲线,每条曲线都能看得见,还有定义为你转……多么迷人的圆锥曲线,在科技与生活中广泛应用,人们对它的研究连绵不断,三维解析几何也随之腾飞.

通过这样富有创意的复习导入,充分调动了学生的积极性,让学生在一种愉悦轻松的氛围中获得知识,让课堂充满趣味性、知识性和人文性,这才是我们所追求的高效课堂.

# 2. 创新变式拓展

巩固式训练的新意一般表现在题目的创新之上，大部分复习课都侧重于解题研究，学案所需解决的题型繁多、内容杂乱，若一一讲解必然给学生带来不好的学习体验。这就需要我们教学过程中，重新整合和重组学案，创新变式拓展，呈现环环相扣和层次清晰的创新变式题组，以彰显积极教育下课堂的创造性，利于学生认知结构的重构，利于学生思维能力的提升，提升课堂教学效益。

# 案例 2 以“不等式”的复习片段为例

解不等式: $x^{2}-9x+20\leqslant0.$

变式 1: 解不等式 $\frac{x-5}{x-4} \geqslant 0$ ;

变式 2: 解不等式 $x^{4}-9x^{2}+20\leqslant0$ ;

变式 3: 求函数 $y = \sqrt{x^{2} - 9x + 20}$ 的定义域;

变式 4: 求函数 $y = \lg(x^{2} - 9x + 20)$ 的定义域;

变式 5: 解关于 x 的不等式 $(x - a)(x - 4) \leqslant 0$ ;

变式 6: 解关于 x 的不等式 $x^{2}+(a-5)x-5a \leqslant 0$ ;

变式7:若关于x的不等式 $ax^{2}+bx+c\leqslant0$ 的解集为 $\{x\mid4\leqslant x\leqslant5\}$ ，求a,b,c；

变式8:若关于x的不等式 $ax^{2}+6x+5\geqslant0$ 恒成立,求a的取值范围;

变式9: 当 $x \in (1,2)$ 时, 关于 x 的不等式 $x^{2} + ax + 5 < 0$ 恒成立, 求 a 的取值范围.

思考:请试着编一编以上类似题目.

目标明确、系统连贯、相互联系的知识更利于学生的理解和掌握。以上案例中，以一个简单的一元二次不等式展开变式拓展，一步步地加大难度，加深讨论，由解不等式到不等式恒成立问题，再到函数与不等式的沟通等，然而万变不离其宗，其本质依然是借助不等式解题。对学生来说，本课中所呈现的题目既熟悉又陌生，更侧重于知识的沟通和方法的训练，能力层次要求较高，学生在一题多变的研究中有了积极的学习体验，有了困难的挑战，有了高效的建构。

# 3. 创新合作探究

新课标中明确合作交流是学习数学的一种重要方式.但当下合作探究中存在以下问题:很多时候流于形式,教师不敢真正放手给学生去合作、去探究;很多时候受时间的制约,受到材料或资料的限制,从而使得小组合作无法高效.因此,通过创新式小组合作学习可以有效激发学生积极参与探究活动,提升学习效率,培养创新能力,创设高效课堂.

案例3“由数列的递推关系求通项公式”的教学片断

教师在课前将本班学生分为 8 个小组, 并布置如下作业:

(1) 查阅资料,了解数列在近几年高考中的地位;  
(2) 探究由数列的递推关系求通项公式的基本题型及方法.

师:下面请各组开始你们的展示.

组 1:请欣赏我们小组制作的 PPT.（该组将研究成果制作为 PPT, 主要展示了数列在高考中所占比例和递推关系式在高考中的运用）

师:课程标准及考试说明中并未提及数列的递推关系,高考中为什么还会考到呢?该问题哪个小组研究过?

组 2: 等差或等比数列可视为特殊的递推数列模型, 在“高考说明”中为 C 级要求, 将递推关系作为灵活运用的载体, 从而更好地考查逻辑推理能力.  
组 3: 递推关系是等差或等比数列的迁移应用. 我们组经过探究一致认为递推关系会成为高考的一个热点问题一直延续下去.  
师:前面三个小组是对作业(1)展开的探究,对问题(2),哪个小组来展示呢?

组 4: 常用模型有:

① $a_{n+1}-a_{n}=f(n),f(n)$ 易求和；(叠加法)

② $\frac{a_{n+1}}{a_n} = f(n), f(n)$ 易求积；(叠乘法)   
③ $a_{n+1}=pa_{n}+1(p\neq1)$ .(待定系数法)

组 5: 我们组在探究中, 也遇到与 $a_{n+1}=pa_{n}+1(p \neq 1)$ 类似的关系式、分式递推关系式和同时含有 $a_{n}$ , $S_{n}$ 关系的递推式, 可以利用转化法和迭代法来求解.

组 6: 我们组经过探究发现, 这么多方法的本质均为构造一个新的等差或等比数列.

师:你们的总结都很精彩,下面进入下一个环节:展示不同题型和方法.

●●●●●●

以上案例中,在课前,教师明确研究方向,给予了学生充足的时间和空间去查阅资料和合作研究,有效地激发了学生的探究兴趣;在课上,通过师生互动和生生交流,激活思维动力,增长思维活力,让学生充分感受成功的喜悦.这样的学习远比教师直接将探究结果告诉学生更加有效;这样的合作学习,使学生积极主动进入学习状态,获得更加全面而深刻的认知,获取有深度的问题体验,实现了高效学习.

# 四、一点感悟

积极教育如何才能实现“积极”和“高效”？复习课的落脚点就是提升学生的数学素养，那么自然就需要研究学生、研究教案、研究教材。在教学设计时，需要创新设计过程，目标与过程再也不能仅仅着眼于学生当前的感受，需思考从哪个环节着手充分调动学生、吸引学生；需考虑以哪一个独特的知识点去感染学生，引发思维碰撞；需想好从哪里延展开去，引起学生课后思维活动的继续，欲罢不能。在课堂上，需要在复习的关键性过程上下足功夫，创新设计教学过程，将课堂交给学生，给予一种积极的引导，让学生形成表达和展示的意识，使学生养成积极学习的态度和主动思维的习惯，实现高效建构。

总之，要使高三复习真正高效，我想需要我们教师重新认识学生学习的意义，重新认识教学内容，重新认识教师的价值，努力在基于积极教育的角度创新复习导入，创新变式拓展，创新合作探究，以求得教学的最高境界，去鼓励学生、调动学生、激励学生，实现高效教与学的完美融合。
