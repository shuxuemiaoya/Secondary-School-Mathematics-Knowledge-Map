# 巧角度证明,妙思维拓展

—— 一道不等式证明题的探究

# ● 安徽省宣城中学 程会海

不等式的证明是数学问题中的一个重点与难点，其证明过程没有固定的模式程序与规律方法可循，证明的技巧性强，推理性杂，证明方法又千变万化，一直是学生掌握较为薄弱的一类重要题型。特别地，多元（三元及以上）不等式的证明更是其中的一个代表性难点，很多学生感觉无从下手，普遍反映理解与掌握不理想，是学习与复习过程中必须强化与提升的一个重要环节。

# 一、问题呈现

问题:(2020届安徽省合肥市高三二模数学理科·23)若三个正实数a,b,c满足 $a+b+c=1$ ,证明: $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+a^{2}}{b}+\frac{a^{2}+b^{2}}{c}\geqslant2.$

此题涉及三元不等式的证明问题, 是不等式应用中具有一定典型性的一类问题. 此题的破解关键是巧妙利用条件 $a + b + c = 1$ , 通过合理转化与变形, 进而可以合理利用均值不等式、均值不等式变式、柯西不等式、权方和不等式、排序不等式等重要不等式来分析与应用的形式, 注意对应重要不等式应用的限制与条件, 并在证明的基础上, 可以合理探究, 变式拓展, 提升能力, 培养素养.

# 二、问题破解

$$
\begin{array}{l} \frac {a ^ {2} + b ^ {2}}{c} \geqslant \frac {2 b c}{a} + \frac {2 c a}{b} + \frac {2 a b}{c} = \frac {2}{a b c} (b ^ {2} c ^ {2} + c ^ {2} a ^ {2} + a ^ {2} b ^ {2}) \\ = \frac {1}{a b c} \left[ \left(a ^ {2} b ^ {2} + b ^ {2} c ^ {2}\right) + \left(b ^ {2} c ^ {2} + c ^ {2} a ^ {2}\right) + \left(c ^ {2} a ^ {2} + a ^ {2} b ^ {2}\right) \right] \\ \geqslant \frac {1}{a b c} (2 a b ^ {2} c + 2 b c ^ {2} a + 2 c a ^ {2} b) = \frac {2 a b c}{a b c} (a + b + c) = 2, \\ \end{array}
$$

证法1:根据均值不等式,可得 $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+a^{2}}{b}+$

当且仅当 $a = b = c = \frac{1}{3}$ 时等号成立.

证法2:根据均值不等式,可得 $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+a^{2}}{b}+\frac{a^{2}+b^{2}}{c}\geqslant\frac{2bc}{a}+\frac{2ca}{b}+\frac{2ab}{c}=a\left(\frac{c}{b}+\frac{b}{c}\right)+b\left(\frac{c}{a}+\frac{a}{c}\right)+c\left(\frac{a}{b}+\frac{b}{a}\right)\geqslant2a\cdot\sqrt{\frac{c}{b}\cdot\frac{b}{c}}+2b\cdot\sqrt{\frac{c}{a}\cdot\frac{a}{c}}+2c\cdot\sqrt{\frac{a}{b}\cdot\frac{b}{a}}=2(a+b+c)=2$ ,当且仅当 $a=b=c=\frac{1}{3}$ 时等号成立.

证法3:根据均值不等式变式,可得 $\frac{b^{2}}{a}+a\geqslant2b$ ,即 $\frac{b^{2}}{a}\geqslant2b-a$ ,当且仅当a=b时等号成立,同理可得 $\frac{c^{2}}{a}\geqslant2c-a,\frac{c^{2}}{b}\geqslant2c-b,\frac{a^{2}}{b}\geqslant2a-b,\frac{a^{2}}{c}\geqslant2a-c,\frac{b^{2}}{c}\geqslant2b-c$ ,将以上六个不等式同向相加,可得 $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+a^{2}}{b}+\frac{a^{2}+b^{2}}{c}\geqslant4(a+b+c)-2(a+b+c)=2(a+b+c)=2$ ,当且仅当 $a=b=c=\frac{1}{3}$ 时等号成立.

点评:证法1、2中对应的分子利用均值不等式,并加以通分或重新组合,再利用拆项二次运用均值不等式来处理,思路简单,方法较常规,也是高考范围中不等式应用常见的不等式类型,只是证明书写过程比较麻烦;证法3通过均值不等式的变式加以切入,再利用不等式的性质来处理,比较简单.

# 三、变式拓展

探究 1: 根据以上不等式及其相应的证明过程, 通过简化, 可得以下相应的变式与拓展问题.

变式1:若三个正实数a,b,c满足 $a+b+c=1$ ,证

明: $\frac{b^{2}}{a}+\frac{c^{2}}{b}+\frac{a^{2}}{c}\geqslant1.$

证明:根据均值不等式变式,可得 $\frac{b^{2}}{a}+a\geqslant2b$ ,即 $\frac{b^{2}}{a}\geqslant2b-a$ ,当且仅当a=b时等号成立,同理可得 $\frac{c^{2}}{b}\geqslant2c-b,\frac{a^{2}}{c}\geqslant2a-c$ ,将以上三个不等式同向相加,可得 $\frac{b^{2}}{a}+\frac{c^{2}}{b}+\frac{a^{2}}{c}\geqslant2(a+b+c)-(a+b+c)=a+b+c=1$ ,当且仅当 $a=b=c=\frac{1}{3}$ 时等号成立.

探究 2: 根据以上不等式及相应的证明过程, 放宽对应的条件, 可得以下相应的变式与拓展问题.

变式 2: 若 a, b, c 为三个正实数, 证明: $\frac{b^{2} + c^{2}}{a} + \frac{c^{2} + a^{2}}{b} + \frac{a^{2} + b^{2}}{c} \geqslant 2(a + b + c)$ .

具体的证明过程可以参照原来不等式的证明过程.

探究 3: 在原来不等式的基础上, 进一步变化所要证明不等式的复杂度, 可得以下相应的变式与拓展问题.

变式3:若三个正实数a,b,c满足 $a+b+c=1$ ,证明: $\frac{b^{2}+c}{a+c}+\frac{c^{2}+a}{b+a}+\frac{a^{2}+b}{c+b}\geqslant2.$

证明:由于三个正实数 a, b, c 满足 $a + b + c = 1$ ，要证明 $\frac{b^{2} + c}{a + c} + \frac{c^{2} + a}{b + a} + \frac{a^{2} + b}{c + b} \geqslant 2$ ，即证明 $\left(\frac{b^{2} + c}{a + c} + b\right) + \left(\frac{c^{2} + a}{b + a} + c\right) + \left(\frac{a^{2} + b}{c + b} + a\right) \geqslant 3$ ，整理即为 $\frac{b(a + b + c) + c}{a + c} + \frac{c(a + b + c) + a}{b + a} + \frac{a(a + b + c) + b}{c + b} \geqslant 3$ ，亦即 $\frac{b + c}{a + c} + \frac{c + a}{b + a} + \frac{a + b}{c + b} \geqslant 3$ ，而结合均值不等式，可得 $\frac{b + c}{a + c} + \frac{c + a}{b + a} + \frac{a + b}{c + b} \geqslant 3\sqrt[3]{\frac{b + c}{a + c} \cdot \frac{c + a}{b + a} \cdot \frac{a + b}{c + b}} = 3$ ，当且仅当 $a = b = c = \frac{1}{3}$ 时等号成立，所以原不等式成立.

探究 4: 在原来三元不等式的基础上, 进一步拓展到四元不等式问题, 可得到以下两个类似的变式与拓

展问题.

变式4:若四个正实数a,b,c,d满足 $a+b+c+d=1$ ,证明： $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+d^{2}}{b}+\frac{d^{2}+a^{2}}{c}+\frac{a^{2}+b^{2}}{d}\geqslant2.$

证明:根据均值不等式变式,可得 $\frac{b^{2}}{a}+a\geqslant2b$ ,即 $\frac{b^{2}}{a}\geqslant2b-a$ ,当且仅当a=b时等号成立.同理可得 $\frac{c^{2}}{a}\geqslant2c-a,\frac{c^{2}}{b}\geqslant2c-b,\frac{d^{2}}{b}\geqslant2d-b,\frac{d^{2}}{c}\geqslant2d-c,\frac{a^{2}}{c}\geqslant2a-c,\frac{a^{2}}{d}\geqslant2a-d,\frac{b^{2}}{d}\geqslant2b-d$ ,将以上八个不等式同向相加,可得 $\frac{b^{2}+c^{2}}{a}+\frac{c^{2}+d^{2}}{b}+\frac{d^{2}+a^{2}}{c}+\frac{a^{2}+b^{2}}{d}\geqslant4(a+b+c+d)-2(a+b+c+d)=2(a+b+c+d)=2$ ,当且仅当a=b=c=d= $\frac{1}{4}$ 时等号成立.

变式5:若四个正实数a,b,c,d满足 $a+b+c+d=1$ ，证明 $\frac{b^{2}+c^{2}+d^{2}}{a}+\frac{c^{2}+d^{2}+a^{2}}{b}+\frac{d^{2}+a^{2}+b^{2}}{c}+\frac{a^{2}+b^{2}+c^{2}}{d}\geqslant3.$

该变式的证明可参照以上变式 3 的证明过程.

点评:其实,通过以上不等式的证明与探究拓展,关键在于仔细分析,认真研究,一题多解,一题多思,深入探究,变式拓展,可以在以上探究与变式的基础上不断加以分析,可以进一步加以探究与变式,可以对不等式加以证明,也可以与解不等式、不等式性质等问题加以合理融合.
