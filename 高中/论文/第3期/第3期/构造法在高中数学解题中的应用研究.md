在高中数学解题中,影响学生解题效果的一个重要因素就是解题方法,一种好的解题方法能够让学生的解题事半功倍,能够提高学生的数学考试成绩.构造法作为高中数学解题的一种重要的思想方法,能够辅助学生完成解题,提高学生的解题效率.

# 一、数学构造法概述

在高中数学解题中,我们会经常遇到这样的问题,通过常规的解题思路不能够顺利完成解题,需要我们通过一个新的角度去分析问题,将题目中原有条件和结论进行细致地分析,将题目中原有的数量、结构进行新的调整,使其转化为自己熟悉的数学模型,从而构造出一座新的解题桥梁,使其能够顺利达到解题的目的.数学构造法是一种解题方法,也是一种解题思想,是高中数学解题过程中必不可少的知识.

# 二、构造法在高中数学解题中的应用实例

# 1. 构造函数解题

函数是高中数学的重要组成部分,有时候在解题过程中遇到难以解决的问题,我们可以从构造函数方面入手.构造函数法就是通过添加函数的方式,利用函数的值域、单调性、奇偶性等特点来解决某种数学问题的方法.例如,我们在证明某一不等式时,可以通过构造与该不等式具有相同取值范围和值域的函数来辅助证明.通常情况下,构造函数的解题方法一般应用于解方程、求最值、证明不等式、求数列等类型的题目当中.

第一,通过构造一次函数来解题.例如:设 a,b,c $\in R$ ,并且它们的绝对值不大于1,求证: $ab+bc+ca+1\geqslant0$ .如果我们直接去证明这一问题,就会感觉无从下手.如果我们认真观察这一不等式就会发现可以通过构造 $f(a)=(b+c)a+bc+1$ 的函数来进行证明.那么原题就会转变成求证:“当 $|a|\leqslant1$ 时, $f(a)\geqslant0$ 成立,然后再通过一次函数性质来加以证明.”

第二,通过构造二次函数来解题.例如:如果0<a< $\frac{1}{k}$ , $k\geqslant2(k\in\mathbf{Z})$ , $a^{2}<a-b$ ,求证: $b<\frac{1}{k+1}$ .

通过观察题目中的已知条件我们不难发现 $a^2 < a - b$ 可以变形为 $b < a - a^2, 0 < a < \frac{1}{k}$ , 题目中要证明 $b < \frac{1}{k + 1}$ , 就可以构造一个 $f(a) = a - a^2$ 的函数, 再利用二次函数的单调性来解决问题.

第三，通过构造分式函数来解题.例如：已知关于 $x$ 实数系数的二次方程 $x^{2} + ax + b = 0$ 的两个实数根分别为 $\alpha ,\beta$ ，求证：如果 $|\alpha | <   2,|\beta | <   2$ ，那么 $2|\alpha | <   4 + b,|b| <   4.$ 通过观察题目可以发现 $|b| =$ $|\alpha \beta | <   4,4 + b > 0$ ，从而构造函数 $f(x) = \frac{x + 2a}{4 + b}$ 那么 $f(x) = \frac{x + 2(\alpha + \beta)}{4 + \alpha\beta}$ 是一个单调递增函数.取 $x_{1}$ $= 2(\alpha +\beta) - (4 + \alpha \beta) = -(2 - \alpha)\times (2 - \beta) <   0,x_{2}$ $= 2(\alpha +\beta) + (4 + \alpha \beta) = (2 + \alpha)\times (2 - \beta) > 0,f(x_{1})$ $= -1,f(x_{2}) = 1$ ，根据函数单调性就可以得出 $-1 =$ $f(x_{1}) <   f(0) <   f(x_{2}) = 1, - 1 <   \frac{2a}{4 + b} <  1,$ 变形可得一 $(4 + b) <   2a <   4 + b$ ，所以 $2|\alpha | <   4 + b.$

第四,通过构造三角函数来解题.例如:如果0<A,B,C≤π,求证 $\sin\frac{A+B+C}{3}\geqslant\frac{\sin A+\sin B+\sin C}{3}$ .通过对题目的观察可以发现,要证明的不等式的形式具有三角形重心坐标的特点,在证明的过程中可以通过构造三角形重心的角度去解决问题.设 $f(x)=\sin x,P(A,\sin A),Q(B,\sin B),R(C,\sin C)$ ,那么 $\triangle PQR$ 的重心为 $G\left(\frac{A+B+C}{3},\frac{\sin A+\sin B+\sin C}{3}\right)$ ,通过观察函数的图像会发现,函数 $f(x)=\sin x$ 图像在 $(0,\pi)$ 是向上突起的,那么 $\triangle PQR$ 的重心纵坐标满足条件 $\frac{\sin A+\sin B+\sin C}{3}\leqslant f\left(\frac{A+B+C}{3}\right)$ ,所以 $\sin\frac{A+B+C}{3}\geqslant\frac{\sin A+\sin B+\sin C}{3}$ .

# 2. 构造方程解题

方程是高中数学学习的重要组成部分,也是解题的一种重要思想.在数学解题中,除我们直接进行计算求解以外,还可以通过方程的形式来求解.例如,求取值范围、证明不等式、根与系数的关系等问题,都可以通过构造方程租的方式来求解.通常情况下,我们可以通过构造方程的方式来解决下列类型的问题:当题目中条件和结论中出现两个数之和或者两个数之积时,就可以利用韦达定理来构造一元二次方程.题目中包含对数问题、几何问题、简化与证明问题时,可以构建方程进行求解.

第一,构造一次方程来解题.例如:已知 $x=\frac{a}{b+c}=\frac{b}{c+a}=\frac{c}{a+b}$ ，求 x 的值.根据题意我们可以得出 $a=(b+c)x, b=(a+c)x, c=(a+b)x$ ，将这三个式子相加可以得出 $a+b+c=2(a+b+c)x$ ，然后进行分类讨论.当 $a+b+c\neq0$ 时， $x=\frac{1}{2}$ ;当 $a+b+c=0$ 时， $a+b=-c, x=\frac{c}{a+b}=-1$ .

第二,构造函数方程来解题.例如:已知 $af(x-1)+bf(1-x)=cx$ , 求 $f(x)$ . 我们先用 $(x-1)$ 来替换 x, 那么 1-x 就转换成 -x, 那么 $af(x)+bf(-x)=c(1+x)$ . 用 $(x-1)$ 来替换 -x, 那么 1-x 就转换成 x, 那么 $af(-x)+bf(x)=c(1-x)$ . 然后根据不同情况, 分类讨论来解方程: 当 $a^{2}\neq b^{2}, c\neq0$ 时, $f(x)=\frac{c}{a-b}x+\frac{c}{a+b}$ ; 当 $a^{2}\neq b^{2}, c=0$ 时, $f(x)$ 值不存在; 当 a=b, 且 c=0 时, $f(x)$ 为任意奇函数; 当 a=-b, 且 c=0 时, $f(x)$ 为任意偶函数.

第三，构造方程组来解题. 当我们遇到的问题中，包含两个及两个以上的变量或两个及两个以上的参数时，就需要通过构造方程组来解决问题了. 例如：如果 $f(x) = a^2 + bx, 1 \leqslant f(-1) \leqslant 2, 2 \leqslant f(1) \leqslant 4$ ，证明： $5 \leqslant f(-2) \leqslant 10$ . 根据题意 $f(-2) = 4a - 2b$ ，然后构造出 $f(-1)$ 和 $f(1)$ 的方程组，并用 $f(-1)$ 和 $f(1)$ 表示出 $a$ 和 $b$ 的值. 整理得 $f(-2) = 4a - 2b = 2[f(1) + f(-1)] - [f(1) - f(-1)] = f(1) + 3f(-1)$ . 又因为 $2 \leqslant f(1) \leqslant 4, 3 \leqslant 3f(-1) \leqslant 6$ ，整理就可以得出 $5 \leqslant f(-2) \leqslant 10$ .

# 3. 构造数列解题

数列作为高中数学的重要组成部分,从一定程度上来说也可以作为解题的一种重要的工具.我们可以将求值、化简、证明等问题,通过构造数列的方式完成求解.

第一,构造等差数列来解题.例如:在 $\triangle ABC$ 中,内角A,B,C存在这样的数量关系 $A+C=2B$ ,并且

$\frac{1}{\cos A} + \frac{1}{\cos C} = -\frac{\sqrt{2}}{\cos B}$ , 那么 $\cos \frac{A - C}{2}$ 的值是多少? 根据题意可设 $B = 60^{\circ}, \cos B = \frac{1}{2}, A = 60^{\circ} + \alpha, C = 60^{\circ} - \alpha (-60^{\circ} < \alpha < 60^{\circ})$ , 由此可得 $\frac{1}{\cos (60^{\circ} + \alpha)} + \frac{1}{\cos (60^{\circ} - \alpha)} = -2\sqrt{2}$ , 化简可得 $\cos \alpha = -\sqrt{2} (\cos 120^{\circ} + \cos 2\alpha)$ , 则 $2\sqrt{2}\cos^{2}\alpha + \cos \alpha - \frac{3\sqrt{2}}{2} = 0$ , 可得 $\cos \alpha = \frac{\sqrt{2}}{2}$ 或者 $\cos \alpha = -\frac{3}{2\sqrt{2}}$ (舍去), 所以 $\cos \frac{A - C}{2} = \cos \alpha = \frac{\sqrt{2}}{2}$ .

第二，构造等比数列来证明不等式.例如： $a_0 = 1$ $a_{n} = \frac{\sqrt{1 + a_{n - 1}^{2}} - 1}{a_{n - 1}} (n\in \mathbf{N}^{+}),q$ 求证： $a_{n} > \frac{\pi}{2^{n + 2}}.$ 通过对题目的观察我们可以看出，题目中含有 $\pi$ 和 $\sqrt{1 + a_{n - 1}^2}$ ，因为 $a_{n} > 0$ ，我们就可以构建一个数列 $\{a_n\}$ ，然后令 $a_{n} = \tan a_{n},a_{n}\in \left(0,\frac{\pi}{2}\right)$ ，化简可得 $\tan a_n = \frac{\sqrt{1 + \tan^2a_{n - 1}}}{\tan a_{n - 1}} = \frac{1 - \cos a_{n - 1}}{\sin a_{n - 1}} = \tan \frac{a_n - 1}{2}$ 那么 $a_{n} = \frac{a_{n} - 1}{2}$ .因为 $a_0 = 1,a_1 = \sqrt{2} -1 = \tan \frac{\pi}{8}$ .由此可得，数列 $\{a_n\}$ 为首项为 $\frac{\pi}{8}$ ，公比为 $\frac{1}{2}$ 的等比数列，则 $a_{n} = \left(\frac{1}{2}\right)^{n - 1}\cdot \frac{\pi}{8} = \frac{\pi}{2^{n + 2}}$ 当 $x\in \left(0,\frac{\pi}{2}\right)$ 时， $\tan x > x$ 所以 $a_{n} = \tan \frac{\pi}{2^{n + 2}} >\frac{\pi}{2^{n + 2}}.$

# 三、小结

构造法是高中数学解题的一种重要的解题方法，当面对无从下手的题目时，学生可以转变思维，通过构造函数、方程、数列等方法找到解题的突破口，从而完成解题。在数学教学中，教师有意识地教授学生构造法，能够提升学生的数学解题能力，为数学思维的发展奠定基础。
