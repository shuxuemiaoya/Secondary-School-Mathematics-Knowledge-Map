# 不等式证明的一些方法与技巧\*

# ● 海南省海南中学 唐盛彪

不等式是高中数学的重要内容之一,也是数学竞赛的热点之一.不等式的证明难度较大,没有固定的程序,方法因题而异,灵活性强,技巧要求很高.下面介绍证明不等式的一些方法与技巧.

# 一、配凑

有些对称不等式可以根据等号成立的条件,寻求匹配因子,凑出可以利用均值不等式的形式,进而获得简捷的证明.

例 1 （第 36 届 IMO 试题）设 a, b, c 为正数，且满足 abc = 1.

求证： $\frac{1}{a^3(b + c)} +\frac{1}{b^3(a + c)} +\frac{1}{c^3(a + b)}\geqslant \frac{3}{2}.$

分析:这是一个对称不等式,当a=b=c=1时,等号成立.此时 $\frac{1}{a^{3}(b+c)}=\frac{a(b+c)}{4}=\frac{1}{2}$ .

证明： $\frac{1}{a^3(b + c)} +\frac{a(b + c)}{4}\geqslant 2\sqrt{\frac{1}{a^3(b + c)}\cdot\frac{a(b + c)}{4}}$ $= \frac{1}{a}.$

同理 $\frac{1}{b^3(a + c)} +\frac{b(a + c)}{4}\geqslant \frac{1}{b},\frac{1}{c^3(a + b)} +$ $\frac{c(a + b)}{4}\geqslant \frac{1}{c}.$

联立以上三式，得 $\frac{1}{a^3(b + c)} +\frac{1}{b^3(a + c)} +$ $\frac{1}{c^3(a + b)} +\frac{2(ab + bc + ca)}{4}\geqslant \frac{1}{a} +\frac{1}{b} +\frac{1}{c},$ 所以 $\frac{1}{a^3(b + c)} +\frac{1}{b^3(a + c)} +\frac{1}{c^3(a + b)}\geqslant \frac{1}{2}\Big(\frac{1}{a} +\frac{1}{b} +$ $\frac{1}{c}\Big)\geqslant \frac{3}{2}\sqrt[3]{\frac{1}{abc}} = \frac{3}{2}.$

# 二、代换

有些不等式变量多、结构复杂，可以适当引入新的变量，通过代换，简化结构，实现变通，使新变量关系明朗化.

例 2 （第 3 届(2004 年)女子数学奥林匹克试题改编）设 $a, b, c \in R^{+}$ . 求证: $\frac{a + 3c}{a + 2b + c} + \frac{4b}{a + b + 2c} - \frac{8c}{a + b + 3c} \geqslant -17 + 12\sqrt{2}$ .

分析:本题的难点是分母较复杂,可通过代换把分母变为单项式.

证明: 设 $x = a + 2b + c, y = a + b + 2c, z = a + b + 3c.$ 则 $a = 5y - x - 3z, b = x + z - 2y, c = z - y.$ 于是 $\frac{a + 3c}{a + 2b + c} + \frac{4b}{a + b + 2c} - \frac{8c}{a + b + 3c} = \frac{2y - x}{x} + \frac{4(x + z - 2y)}{y} - \frac{8(z - y)}{z} = -17 + 2\left(\frac{y}{x} + \frac{2x}{y}\right) + 4\left(\frac{z}{y} + \frac{2y}{z}\right) \geqslant -17 + 12\sqrt{2}.$

# 三、化幂

有些不等式左、右两边的次数不同,可通过升幂或降幂使得不等式两边的次数相同,再进一步证明之.

例3（1984年列宁格勒数学竞赛试题）设 $a, b, c \in \mathbf{R}^{+}, a + b + c = 1$ 。求证： $a^3 b + b^3 c + c^3 a \geqslant abc$ .

分析: 待证的不等式左边的次数是 4, 右边的次数是 3, 为使不等式保持次数上的平衡, 右边升幂, 即 $abc = abc (a + b + c)$ .

证明:由于 $a+b+c=1$ ，因此只需证 $a^{3}b+b^{3}c+c^{3}a\geqslant abc(a+b+c)$ ，即 $a^{3}b+b^{3}c+c^{3}a\geqslant a^{2}bc+ab^{2}c+abc^{2}$ .

因为 $a^3 b + abc^2 \geqslant 2a^2 bc, b^3 c + a^2 bc \geqslant 2ab^2 c, c^3 a + ab^2 c \geqslant 2abc^2$ ，所以 $a^3 b + abc^2 + b^3 c + a^2 bc + c^3 a + ab^2 c \geqslant 2a^2 bc + 2ab^2 c + 2abc^2$ ，即 $a^3 b + b^3 c + c^3 a \geqslant a^2 bc + ab^2 c + abc^2$ 。故原不等式成立。

# 四、通分

有些分式不等式, 可通过适当放缩, 使各项的分

母化为相同,称之为不等式通分.

例4（第26届美国数学奥林匹克试题）设 $a, b, c \in \mathbf{R}^{+}$ ，求证： $\frac{1}{a^3 + b^3 + abc} + \frac{1}{b^3 + c^3 + abc} + \frac{1}{c^3 + a^3 + abc} \leqslant \frac{1}{abc}$ .

分析:这是一个分式不等式,各项分母都不相同,可利用放缩法进行通分.

证明: 易知 $a^{3}+b^{3}\geqslant a^{2}b+ab^{2}$ (用比较法可证), 则 $\frac{abc}{a^{3}+b^{3}+abc}\leqslant\frac{abc}{a^{2}b+ab^{2}+abc}=\frac{c}{a+b+c}$ .

同理 $\frac{abc}{b^3 + c^3 + abc} \leqslant \frac{a}{a + b + c}, \frac{abc}{c^3 + a^3 + abc} \leqslant \frac{b}{a + b + c}$ .

联立以上三式，得 $\frac{abc}{a^3 + b^3 + abc} +\frac{abc}{b^3 + c^3 + abc}$ $+\frac{abc}{c^3 + a^3 + abc}\leqslant 1.$

因此 $\frac{1}{a^3 + b^3 + abc} + \frac{1}{b^3 + c^3 + abc} + \frac{1}{c^3 + a^3 + abc} \leqslant \frac{1}{abc}$ .

# 五、配对

对于有些“准”对称不等式 $A \geqslant M (A \leqslant M)$ ，其中 $M$ 为常数，可以构造表达式 $A$ 的对偶式 $B$ ，通过 $A - B = 0, A + B = 2A$ 证明.

例5 设 $a, b, c \in \mathbf{R}^{+}, a + b + c = 1$ . 求证：

$$
\begin{array}{c} \frac {a ^ {4}}{a ^ {3} + a ^ {2} b + a b ^ {2} + b ^ {3}} + \frac {b ^ {4}}{b ^ {3} + b ^ {2} c + b c ^ {2} + c ^ {3}} + \\ \frac {c ^ {4}}{c ^ {3} + c ^ {2} a + c a ^ {2} + a ^ {3}} \geqslant \frac {1}{4}. \end{array}
$$

分析:考察 $\frac{a^{4}}{a^{3}+a^{2}b+ab^{2}+b^{3}}$ ，分母是关于a,b的对称式，分子只含a，其对偶式是 $\frac{b^{4}}{a^{3}+a^{2}b+ab^{2}+b^{3}}$ .通过配对可证之.

证明：令 $A = \frac{a^4}{a^3 + a^2b + ab^2 + b^3} + \frac{b^4}{b^3 + b^2c + bc^2 + c^3} + \frac{c^4}{c^3 + c^2a + ca^2 + a^3},$

$$
\begin{array}{c} B = \frac {b ^ {4}}{a ^ {3} + a ^ {2} b + a b ^ {2} + b ^ {3}} + \frac {c ^ {4}}{b ^ {3} + b ^ {2} c + b c ^ {2} + c ^ {3}} + \\ \frac {a ^ {4}}{c ^ {3} + c ^ {2} a + c a ^ {2} + a ^ {3}}. \end{array}
$$

$$
A - B = \frac {a ^ {4} - b ^ {4}}{(a ^ {2} + b ^ {2}) (a + b)} + \frac {b ^ {4} - c ^ {4}}{(b ^ {2} + c ^ {2}) (b + c)} +
$$

$\frac{c^4 - a^4}{(c^2 + a^2)(c + a)} = (a - b) + (b - c) + (c - a) = 0,$ 故 $A = B = \frac{1}{2} (A + B) = \frac{1}{2}\Big[\frac{a^4 + b^4}{(a^2 + b^2)(a + b)} +$ $\frac{b^4 + c^4}{(b^2 + c^2)(b + c)} +\frac{c^4 + a^4}{(c^2 + a^2)(c + a)}\Big].$

因为 $a^4 + b^4 \geqslant \frac{1}{2} (a^2 + b^2)^2, a^2 + b^2 \geqslant \frac{1}{2} (a + b)^2$ ，所以 $\frac{a^4 + b^4}{a^3 + a^2b + ab^2 + b^3} \geqslant \frac{1}{4} (a + b)$ .

同理 $\frac{b^4 + c^4}{b^3 + b^2c + bc^2 + c^3} \geqslant \frac{1}{4}(b + c),$ $\frac{c^4 + a^4}{c^3 + c^2a + ca^2 + a^3} \geqslant \frac{1}{4}(c + a).$

故 $\frac{a^4}{a^3 + a^2b + ab^2 + b^3} +\frac{b^4}{b^3 + b^2c + bc^2 + c^3} +$ $\frac{c^4}{c^3 + c^2a + ca^2 + a^3}\geqslant \frac{1}{2}\Big[\frac{1}{4} (a + b) + \frac{1}{4} (b + c) +$ $\frac{1}{4}(c + a)\Big] = \frac{1}{4}.$

# 六、算两次

算两次是指同一个量,从两个方面去表示它,然后综合起来得到一个关系式.在证明不等式时,可选择一个适当的量,从不同的角度去考虑它,建立一个不等式.从而问题得到解决.

例6 设实数 $a, b, c$ 满足 $a^2 + b^2 + c^2 = 1$ . 证明： $|a - b|, |b - c|, |c - a|$ 中必有一个不超过 $\frac{\sqrt{2}}{2}$ .

分析:由于是对称式,于是可优化假设 $a\geqslant b\geqslant c$ . $\left|a-b\right|$ , $\left|b-c\right|$ , $\left|c-a\right|$ 三者中 $\left|c-a\right|$ 最大, 只需 $\left|a-b\right|$ , $\left|b-c\right|$ 中有一个不超过 $\frac{\sqrt{2}}{2}$ 即可. 可从两个方面去考察式子 $(a-b)^{2}+(b-c)^{2}+(c-a)^{2}$ .

证明:不妨设 $a \geqslant b \geqslant c$ ，记 $m = \min\{|a - b|, |b - c|, |c - a|\} = \min\{|a - b|, |b - c|\}$ .

$$
\begin{array}{c} \mid c - a \mid = a - c = (a - b) + (b - c) = \mid a - b \mid + \\ \mid b - c \mid \geqslant m + m = 2 m. \end{array}
$$

一方面， $(a - b)^2 + (b - c)^2 + (c - a)^2 = 3(a^2 + b^2 + c^2) - (a + b + c)^2 \leqslant 3$ ；另一方面， $(a - b)^2 + (b - c)^2 + (c - a)^2 \geqslant m^2 + m^2 + (2m)^2 = 6m^2$ 。因此 $6m^2 \leqslant 3$ ，则 $m \leqslant \frac{\sqrt{2}}{2}$ 。故 $|a - b|, |b - c|, |c - a|$ 中必有一个不超过 $\frac{\sqrt{2}}{2}$ 。
