# 错题资源在高中数学教学中的有效应用策略

● 甘肃省临泽县职教中心 李蓉芳

高中学生在数学学习的过程中,对于灵活性的掌握还不到位,在做习题时会经常出现错误,这种现象是非常正常的事情,对于优秀的数学老师来说,不会因学生做错题而过分地去批评学生,进而打消学生的学习自信心,而是会找出错题的错误根源,有针对性地开展教学活动,完善学生对数学知识的理解.初中数学教师应加强错题教学意识,将错题资源整合,引导学生充分利用错题资源,成为学生在学习过程中的垫脚石,进而在教学效果上达到教学目标,提高教学质量.

失败乃是成功之母，学习过程中的错误是正常的，而且也是一种需要，因为有的时候能从错误中发现学习中的缺陷，有利于更好的学习。无论是在初中数学课堂内还是在课堂外，产生错题是由多种原因引起的，教师教学方面也是有原因的，不只是学生这一方面。作为初中教师一定要善用错题资源来引导学生学习中的误区，根据具体情况针对性地制定数学错题教学方案，以求达到点石成金的效果，让学生找到正确的解析数学题的方法，塑造学生养成正确的数学思维习惯。本文旨在从以下几个方面入手来探讨错题资源在初中数学中的有效应用策略。

# 一、初中数学题容易出错的主要原因

# 1. 基础知识掌握不牢

初中数学逐渐增加难点并且具有较复杂性，学生的年龄也处在人们常说的叛逆期，这个时期会产生一定的学困生，尤其是数学基础还比较薄弱，基础知识学习不到位，不能够解决各种变化的题型，在解题的方法运用上不够灵活，从而在数学解题过程中出错。教师要在教学中将错题资源作为工具，及时查漏补缺，利用错题开展专门的复习，能够有效地提高学生基础知识点的掌握能力。

# 2. 审题不严

高中数学解题过程中,解析问题的思路、答案不一定单一,学生在审题时不够细心,有些问题可能会重复性犯错,不能很好地进行错题总结,与缺乏良好的学习习惯有关.审题出现错误会直接导致后面解析数学题的难度,这些错误是可以避免的,但往往因为学生的粗心大意造成的,所以教师需要通过错题引导学生避免这样的坏习惯.

# 3. 计算能力较弱

有一小部分学生,会做也足够细心,但是在计算能力上的弱化导致了解题的错误,或者因为速度过慢导致完不成规定时间内的试卷、习题内容,学生的解题准确性和解题速度受到了极大的限制.

# 二、错题的整理及应用

# 1. 对错题进行科学的整理和分类

在实践中,对错题的有效整理和分类不仅能让学生对错题的思路进行反思和回顾,还可以让学生以后对此类错题有更深刻的理解和认识.然而,对错题的整理不仅需要科学的方法,还需要对错题的类型进行准确的划分,以充分利用错题带来的思考,让错题资源发挥更高效的作用.

对错题的整理首先要考虑做错的根源在哪里.例如：计算 $(-10^{2})^{3}$ 的结果，在做这道题时，学生的错误答案是 $-10^{5}$ ，但其实正确答案是 $-10^{6}$ .对于这道题的错误原因，很多学生在看到正常答案都会归结为马虎、粗心，其实则不然，学生之所以会做错，究其深层次的原因是对绝对值的概念掌握不透彻、概念的核心没有完全领会，是将同底数幂的乘法运算弄混淆了，两种运算的公式是不一样的，如果对幂的乘方公式掌握得到位，那么这种错误是完全可以避免的.所以对于这样的错误，学生需要明确原因，不能以粗心这样的借口敷衍了事，要挖掘出深层次的问题根源.另外在明确做错题原因之后，学生可以按做错题的原因进行合理分类，例如：对概念核心掌握不牢导致的错误可以归结为一类，对由于计算失误造成的错误可以归结为一类.学生也可以按照错题主要考查的知识点进行分类，例如：把有关有理数的错题归为一类，把与方程有关的错题归为一类等.在此基础上对错题的整理和分类，便于学生日后对此类问题的再复习和强化，对错题的主要集中点更有针对性，大大提高学生以后的做题效率，充分发挥错题

的积极作用.

# 2. 对错题的有效利用

对错题进行有效的整理和分类之后，要进行有效的利用。有些学生对基础知识的掌握还比较薄弱，严谨的思维方式和良好的学习习惯还没有形成，那么此时，有效的整理错题会有针对性地在学生的学习中发挥作用。错题能够帮学生检查自己在知识掌握中出现的盲点和漏洞，以便对知识系统及时进行查缺补漏和完善。教师应正确引导学生对待错题的认知观，要鼓励学生勇于发现问题，主动回顾错题，正视自己的不足，吸取经验和教训，保持良好心态，在纠错改错的过程中降低自己做错的效率及技巧。例如：已知 $x$ 为锐角，求函数 $y = \frac{a^2}{\cos^2 x} + \frac{b^2}{\sin^2 x} (a > b > 0)$ 的最小值。常规性错解：因为 $\cos^2 x + \frac{a^2}{\cos^2 x} \geqslant 2\sqrt{\cos^2 x \cdot \frac{a^2}{\cos^2 x}} = 2a, \sin^2 x + \frac{b^2}{\sin^2 x} \geqslant 2\sqrt{\sin^2 x \cdot \frac{b^2}{\sin^2 x}} = 2b$ ，由二者相加可得 $\cos^2 x + \frac{a^2}{\cos^2 x} + \sin^2 x + \frac{b^2}{\sin^2 x} \geqslant 2a + 2b$ ，即 $\frac{a^2}{\cos^2 x} + \frac{b^2}{\sin^2 x} \geqslant 2a + 2b - 1$ ，所以 $y = \frac{a^2}{\cos^2 x} + \frac{b^2}{\sin^2 x} (a > b > 0)$ 的最小值为 $2a + 2b - 1$ 。从错题的样题引起学生思维的碰撞，教师可进行相关知识点的设问，比如基本不等式等号成立的条件是什么？是否符合使用条件还是需要进行变换来求解。利用错题强化基础知识和定理的本质含义，打破教科书固有教学模式，引发学生自主地对数学进行探究，极大地提高教学的有效性。

通过对错题的分析可以使学生以后认真思考，仔细审题。在初中数学的实践中，不乏由于马虎、不认真导致的错题，此类错误随处可见，但这样的错误是可以通过反复审题来避免的。那么对此类由于马虎而导致错题的回顾和整理，会让学生以后更谨慎，不会让粗心大意成为学习的障碍。此时教师应利用此类错题进行适当干预和疏导，提高学生自我反思能力，认真审题，留有更多的精力和时间去积极探索多样化的解决问题的路径。

对错题的有效总结可以提高和改善学生的思考问题的能力. 有些题目的问题点偏冷, 思考方式比较生僻, 这样会使一些基础知识稍差的学生觉得不适应, 做错题后会使学生丧失信心, 打消积极性. 教师应充分利用此类脑筋急转弯类似的题目, 打破传统的、固有的思维模式, 让学生勇于开拓创新, 适当的头脑风暴让学生发散思维, 寻求另一种思维模式, 另辟蹊径, 提高学生对数学问题的思考能力, 使其不再局限于固有的思维模式.

# 三、巧用错题，举一反三

利用错题扩展思路，提升学生解析数学题的能力，既达到错题的修正又能牵引新题，使得错题资源在中学教学中的应用达到举一反三的效果。例如：已知数列 $\{a_{n}\}$ 和 $\{b_{n}\}$ 都是等差数列， $S_{n}$ 和 $T_{n}$ 分别是它们的前n项的和，若 $\frac{S_{n}}{T_{n}}=\frac{4n+3}{2n+5}$ ，求得 $\frac{a_{8}}{b_{8}}$ 。学生错题解法：因为 $\frac{S_{n}}{T_{n}}=\frac{4n+3}{2n+5}$ ，可设 $S_{n}=4n+3,T_{n}=2n+5$ ，于是 $a_{8}=S_{8}-S_{7}=(4\times8+3)-(4\times7+3)=4,b_{8}=T_{8}-T_{7}=(2\times8+5)-(2\times7+5)=2$ ，故 $\frac{a_{8}}{b_{8}}=\frac{2}{1}$ 。此题学生犯了偷换题设的错误，关键问题是学生对等差数列的基础认识不到位。正确的解法是：设 $S_{n}=k(4n+3),T_{n}=k(2n+5)$ ，表明了数列 $\{a_{n}\}$ 和 $\{b_{n}\}$ 的前n项的和都是n的一次式，它们的前n项和 $S_{n}$ 是一个形如 $an^{2}+bn$ 的二次式，从而得到 $a^{8}=S_{8}-S_{7}=k\times8(4\times8+3)-k\times7(4\times7+3)=63k,b_{8}=T_{8}-T_{7}=k\times8(2\times8+5)-k\times7(2\times7+5)=35k$ ，结果 $\frac{a_{8}}{b_{8}}=\frac{9}{5}$ 。这道题还有另一种正确而简单的解法： $\frac{a_{8}}{b_{8}}=\frac{2a_{8}}{2b_{8}}=\frac{a_{8}+a_{8}}{b_{8}+b_{8}}=\frac{a_{1}+a_{15}}{b_{1}+b_{15}}=\frac{15\cdot\frac{a_{1}+a_{15}}{2}}{15\cdot\frac{b_{1}+b_{15}}{2}}=\frac{S_{15}}{T_{15}}=\frac{4\times15+3}{2\times15+5}=\frac{9}{5}$ 。这样的解题思路是将等差数列的通项在已知与未知之间架起桥梁。通过例题我们发现错题资源的应用能够拓展思路，培养学生一题多解的思路，教师在错题资源应用中多加牵引新题，使得错题资源充分地发挥利用。

# 四、结束语

中学数学教师应该积极地整理错题的案例,挖掘错题资源的潜在价值和意义,合理利用错题资源并在教学过程中灵活应用,一定会提高学生学习数学的兴趣和提高应试成绩.同时,教师通过错题资源在教学中的应用,能够直观地掌握学生在学习中产生的困惑与阻碍,教师可进行针对性的指导,帮助学生掌握正确的解题思路和解题技巧,促进学生的自主学习能力的提高,实现教学目标.F
