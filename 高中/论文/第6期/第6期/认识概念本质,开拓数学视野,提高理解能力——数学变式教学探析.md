# 认识概念本质,开拓数学视野,提高理解能力

—— 数学变式教学探析

江苏省通州高级中学 邵春燕

在课改推进的过程中,不少数学教师都会感受到“时间紧,任务重”.为了争取更多宝贵时间,部分教师则采用了满堂灌的教学方式,教学效果也是可想而知的.因此,对于广大数学教师来说,变式教学在数学课堂教学中的应用就变得举足轻重了,只有让每位学生通过一道题目的解决掌握一类问题的解法,才能促进学生思维的整合,学会融会贯通,才能真正意义上实现数学教学的育人目标.

基于此,笔者立足于新课程改革背景下尝试引入变式教学,有意识地引导学生从变化的现象中找寻到不变的本质,从本质中探求到一般规律,进而概括出一般属性.在平时的解题教学中使用变式教学,以期达到以少胜多的目的,创设理想的教学效果.

# 一、设计概念性问题的变式活动，厘清概念本质

每个数学概念有着深刻的内涵及丰富的外延. 因此, 在讲解概念的过程中, 教师可以引入变式教学, 引导学生在分析和讨论问题的过程中, 厘清复杂的命题, 认识抽象的数学概念, 实现对概念的摄取和理解, 将掌握的概念及时印入头脑中, 以便在需要时能及时提取和运用. 通过这种教学方式, 可以让学生更深刻地理解和认识概念本质, 开拓数学视野, 提高学生的理解能力, 扩展学生的思维深度.

案例 1 “双曲线” 概念的变式教学.

在学习“双曲线”定义后，笔者通过以下变式题组对 $\left|\left|MF_{1}\right|-\left|MF_{2}\right|\right|=2a(2a<\left|F_{1}F_{2}\right|)$ 进行变式教学：

变式1: 若将定义中的“ $2a < |F_{1}F_{2}|$ ”变为“ $2a = |F_{1}F_{2}|$ ”, 其余条件均不改变, 则动点轨迹会是什么呢?

变式2:若将定义中的“ $2a<|F_{1}F_{2}|$ ”变为“ $2a>|F_{1}F_{2}|$ ”,其余条件均不改变,则动点轨迹会是什么呢?

变式 3: 若将绝对值去掉, 其余条件均不改变, 则动点轨迹又会是什么呢？

变式 4: 若令 2a = 0, 则动点轨迹又会如何?

变式 5: 若将定义中的“ $2a < |F_{1}F_{2}|$ ”去掉, 其余条件均不改变, 则动点轨迹又会如何?

设计意图：本案例中，笔者从定义出发设计 $\left|\left|MF_{1}\right|-\left|MF_{2}\right|\right|=2a\left(2a<\left|F_{1}F_{2}\right|\right)$ 的变式题组，呈现题组的变化过程，深入挖掘概念的内涵与外延，帮助学生厘清概念本质，求得对概念的理性把握.

在概念教学中,通过变式教学来建构概念深化的环节,来扩展概念的外延,使学生对概念的理解从直观感知上升到理性抽象,进而完整建构整个概念,以便顺利运用概念解决实际问题.学生脑海中一旦形成完整的概念体系,不仅有助于存储与检索,还对新概念的理解和吸收起到助推作用.

# 二、设计例、习题的变式活动，开拓解题思路

教材中的例、习题都是编者精心编制而成，并以静态的模式呈现，具有示范的作用和开采的潜能。通过对例、习题的教学，可以帮助学生深化对概念的认识，加强对原理的应用，提高解题技巧，由此可见，例、习题是至关重要的。若是单一地解决它，也仅仅是完成了单个问题的解决而已，无法发挥其典型和示范作用。此时，教师可以将变式教学应用于其中，对其进行变通和推广，对它的条件或结论进行引申或推广，变有限为无限，变静态为动态。这样一来，不仅开阔了学生的视野和思路，帮助学生养成多角度思考的思维习惯，还有助于探究精神和创新意识的培养，提升学生思维的深刻性，达到事半功倍的奇效。

案例 2 “均值不等式”的变式教学.

问题: 已知 x > 0, 试求出函数 $f(x) = x + \frac{1}{x}$ 的最小值.

变式1: 当 $x \in R$ 时, 试求出函数 $f(x) = x + \frac{1}{x}$ 的

最小值.

变式2: 已知 x > 3，试求出函数 $f(x) = x + \frac{1}{x - 3}$ 的最小值.

变式 3: 已知 x > 3，试求出函数 $f(x) = 2x + \frac{1}{x - 3}$ 的最小值.

变式 4: 已知 x > 3，那么函数 $f(x) = x + \frac{1}{x}$ 的最小值是 2 吗？

设计意图: 原题对于大部分学生来说难度不大, 也很基础. 笔者将这个题目稍作变动, 引领学生积极参与, 使“均值不等式”中一道单一问题变得丰富多彩, 学生在这样开放性的问题情境之下思维也逐渐活跃, 并积极投入到问题的解决之中, 推动探究的再深入, 驱动深度学习, 并达到触类旁通的目的.

这样的变式训练, 尽可能多地将知识串联起来, 让问题拓宽、延伸、变化, 让学生头脑中隐藏的解题思维可视化、显性化, 培养学生思维的发散性、逻辑性、广阔性、流畅性, 提高学生的解题信心, 提高了解题的自主性和正确性, 为高效课堂创造生机和活力.

# 三、设计解题方法的变式活动,积累解题经验

题海训练往往是大部分数学教师惯用的教学手段,但其效果往往仅仅是“就题论题”.长此以往,不少学生则会身心俱疲,心生厌恶心理,并陷入“重负、低质、低效”的恶性循环之中,逐步丧失学习兴趣和学习动力.若教师对解题方法进行变式教学,往往可以克服这一缺点,通过对一道习题解题方法的归纳、类比,有效克服思维的盲目性和肤浅性,达到开拓解题思路的效果.

案例 3 已知圆 $C: x^{2} + (y - 3)^{2} = 9$ ，过原点作圆的弦 OP，试求出弦 OP 的中点 Q 的轨迹方程.

放手让学生去探究,学生经过自主思考和合作探究,生成了以下多种多样的解决方法:

解法 1: 直接法(详解略);

解法 2: 参数法(详解略);

解法 3: 代入法(详解略);

解法 4: 定义法(详解略);

解法 5: 点差法(详解略).

设计意图:通过本题的设计,引导学生多方位、多角度地分析和解决问题,培养学生从数学角度观察、认识、发现、思考和解决问题的能力,进一步对解题方法的优劣性进行分析,总结方法的获取路径,进而获得简捷的解法,积累解题经验.

从以上案例来看,从变式教学的角度来组织解题教学,可以让整节课聚焦于对问题的思考、探究、讨论、感悟,以及思维的运作.在解题活动中,带动了学生的思维活跃度,落实了数学学习的过程性,让学生在知识增长的同时增长经验,在经验增长的同时增长智慧,在解决问题的过程中始终渗透对学生核心素养的培养.

# 四、设计教法的变式活动，激发创造性思维

有序的课堂教学可以建立良好的教学秩序,可以建构有效的学习环境,可以提高课堂教学质量.在课堂教学中,教师有意识地设计变式教学活动,除了有助于问题本身的解决,还可以为学生提供更多的服务,就是通过变式活动探寻之路,充分发挥学生的主体地位,激发创造性思维,增强学习成就感.

案例 4 已知直线 $l: y = kx + 2$ ，圆 $O: x^{2} + y^{2} = 1$ ，直线 l 与圆 O 相交于点 A 和 B。若 $OA \perp OB$ ，试求出直线 l 的方程。

给出例题并完成解题,之后教师进行以下变式:

变式: 已知直线 $l: y = kx + 2$ ，圆 $O: x^{2} + y^{2} = 1$ ，直线 l 与圆 O 相交于点 A 和 B。若 $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$ ，试求出直线 l 的方程。

教师以示范变式为学生的自主变式打下了良好的伏笔,学生完成变式练习后,进行自主变式,并生成以下结论:

变式 1: 已知直线 $l: y = kx + 2$ ，圆 $O: x^{2} + y^{2} = 1$ ，直线 l 与圆 O 相交于点 A 和 B。是否存在直线 l，使以 AB 为直径的圆刚好过原点？

变式 2: 已知直线 $l: y = kx + 2$ ，圆 $O: x^{2} + y^{2} = 1$ ，直线 l 与圆 O 相交于点 A 和 B。若 $\overrightarrow{OA} \cdot \overrightarrow{OB} > 0$ ，试求出 k 的取值范围。

变式 3: 已知直线 $l: y = kx + 2$ ，圆 $O: x^{2} + y^{2} = 1$ ，直线 l 与圆 O 相交于点 A 和 B。若 $\overrightarrow{OA}$ 与 $\overrightarrow{OB}$ 间所成夹角为锐角，试求出 k 的取值范围。

设计意图:以教师的编题为思路层层推进,让学生感受到可变式、找变式、优化变式的过程,有效拓展学生的思维,同时积累解决问题的经验.

总之，高中数学变式教学要强调知识的全面性和典型性，既要关注到学科价值和思想内涵，注重思想性的渗透，尤其是需注重数学核心素养的渗透，同时也需注重授课的细节和学生思维的运用。只有这样，才能让学生体验到更多的成功，让学生学习数学的正向情感、态度和价值观得到有效增强的同时，让学生的能力和方法得到可持续发展。W
