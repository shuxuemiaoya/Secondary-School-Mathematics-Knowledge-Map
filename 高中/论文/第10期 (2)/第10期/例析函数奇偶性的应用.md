# 例析函数奇偶性的应用

<details>
<summary>text_image</summary>

函数的奇偶性是函数的重要性质,也是每年高考的常考内容,下面举例说明函数奇偶性的应用,供大家学习与参考。

# 一、求函数的解析式

例 1 函数 $f(x)$ 为 R 上的奇函数, 当 x > 0 时, $f(x) = -2x^{2} + 3x + 8$ , 则函数 $f(x) =$ \_\_\_\_。

解: 设 x<0，则 -x>0，所以 $f(-x)=-2(-x)^{2}+3(-x)+8=-2x^{2}-3x+8$ 。因为 $f(x)$ 是 R 上的奇函数，所以 $f(x)=-f(-x)$ ，所以 $f(x)=2x^{2}+3x-8$ ，即当 x<0 时， $f(x)=2x^{2}+3x-8$ 。又 $f(x)$ 为 R 上的奇函数，所以 $f(0)=0$ 。综上可得，函数

$$
f (x) = \left\{ \begin{array}{l} - 2 x ^ {2} + 3 x + 8, x > 0, \\ 0, x = 0, \\ 2 x ^ {2} + 3 x - 8, x <   0. \end{array} \right.
$$

评注: 若 $f(x)$ 的定义域内含有 0 且为奇函数, 则必有 $f(0)=0$ 。

# 二、求函数的值

例 2 已知函数 $f(x)=x^{5}+ax^{3}+bx-8$ ，且 $f(-2)=10$ ，则 $f(2)$ 等于（）。

A. -26

B. -18

C. -10

D. 10

解:设函数 $g(x)=x^{5}+ax^{3}+bx$ ，则函数 $g(x)$ 的定义域为 R。因为 $g(-x)=(-x)^{5}+a(-x)^{3}+b(-x)=-x^{5}-ax^{3}-bx=-g(x)$ ，所以 $g(x)$ 为奇函数。

又因为 $f(-2) = g(-2) - 8 = 10$ ，所以 $g(-2) = 18$ ，所以 $g(2) = -g(-2) = -18$ 所以 $f(2) = g(2) - 8 = -18 - 8 = -26$ 。应选A。

评注: 若 $f(x)$ 是奇函数, 则 $f(-x)=$

$-f(x)$ ; 若 $f(x)$ 是偶函数, 则 $f(-x)=f(x)$ 。

# 三、求参数的值

例 3 若 $f(x)=(m-1)x^{2}+6mx+2$ 是偶函数，则 m= \_\_\_\_。

解: 因为 $f(x)$ 是偶函数, 所以 $f(-x)=f(x)$ 恒成立, 即 $(m-1)x^{2}-6mx+2=(m-1)x^{2}+6mx+2$ 恒成立, 也即 12mx=0 恒成立。又因为 $x\in R$ , 所以 m=0 。

评注: 若 $f(x)$ 在 $x \in R$ 上是偶函数, 则 $f(-x) = f(x)$ 对 $x \in R$ 恒成立。

# 四、比较大小

例 4 已知函数 $f(x)$ 是 $[-5,5]$ 上的偶函数，在 $[0,5]$ 上是单调函数，且 $f(-4) < f(-2)$ ，则下列不等式一定成立的是（）。

A. $f(-1) < f(3)$

B. $f(2) < f(3)$

C. $f(-3) < f(5)$

D. $f(0) > f(1)$

解: 因为 $f(x)$ 在 $[-5,5]$ 上是偶函数, 且 $f(-4) < f(-2)$ , 所以 $f(4) < f(2)$ 。又 $f(x)$ 在 $[0,5]$ 上是单调函数, 所以 $f(x)$ 在 $[0,5]$ 上单调递减, 所以 $f(0) > f(1)$ 。应选 D。

评注:比较大小的两种方法:自变量在同一单调区间上时,直接利用函数的单调性比较大小;自变量不在同一单调区间上时,先利用函数的奇偶性把自变量转化到同一单调区间上,再利用单调性比较大小。

# 五、解不等式

例 5 已知函数 $f(x)$ 是定义在 $(-2,2)$ 上的奇函数，又是增函数，则关于 t 的不等式 $f(t-1)+f(2t-3)<0$ 的解集为 \_\_\_\_。

解: 因为 $f(x)$ 为 $(-2,2)$ 上的奇函数, 所以 $f(t-1)+f(2t-3)<0$ 可化为 $f(t-1)<f(3-2t)$ 。又因为 $f(x)$ 在 $(-2,2)$ 上是增函数, 所以 -2<t-1<3-2t<2, 解得 $\frac{1}{2}<t<\frac{4}{3}$ 。故关于 t 的不等式 $f(t-1)+f(2t-3)<0$ 的解集为 $\left(\frac{1}{2},\frac{4}{3}\right)$ 。

评注:解答本题的关键是不能忽视 t-1 与 3-2t 都在区间 $(-2,2)$ 上。
