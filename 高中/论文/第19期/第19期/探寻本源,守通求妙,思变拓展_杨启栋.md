# 1 探寻本源

探寻本源就是分析对应数学问题的本质与根源，全面剖析问题的题设条件，挖掘问题的内涵，探寻问题的切入点，联系数学基础知识、数学思想方法等，构建数学知识体系，为问题的解决打好基础、作好准备。

问题 设 a, b, c 均为正数, 若一元二次方程 $ax^{2} + bx + c = 0$ 有实根, 则().

A. $\max \{a,b,c\} \geqslant \frac{1}{2} (a + b + c)$   
B. $\max \{a,b,c\} \geqslant \frac{4}{9} (a + b + c)$   
C. $\max \{a,b,c\} \leqslant \frac{1}{4} (a + b + c)$   
D. $\max \{a,b,c\} \leqslant \frac{1}{3} (a + b + c)$

该问题,以函数与方程、不等式为基本问题场景,结合创新定义来设置,通过剖析三变元以及对应的代数式来判断大小关系.

# 2 守通求妙

守通求妙就是理解并掌握破解对应数学问题的“通技通法”，并在此基础上探寻“巧技妙解”。从数学知识、得分技巧、教研视角等不同层面来切入，结合不同方法视角来应用，得到不同求解技巧与方法。

# 2.1 得分视角

解法 1: (排除法) 由于一元二次方程 $ax^{2} + bx + c = 0$ 有实根，则有判别式 $\Delta = b^{2} - 4ac \geqslant 0$ .

取特殊值 $a = 3, b = 4, c = \frac{5}{4}$ , 满足以上不等式, 此时 $\max \{a, b, c\} = 4, \frac{1}{2} (a + b + c) = \frac{33}{8}$ , 由于 $4 < \frac{33}{8}$ , 故选项 A 错误.

取特殊值 a=c=1, b=100，满足以上不等式，此时 $\max\{a,b,c\}=100,\frac{1}{4}(a+b+c)=\frac{51}{2}$ ，而 $100>\frac{51}{2}$ ，故选项 C 错误；又 $\frac{1}{3}(a+b+c)=34$ ，由于 100>34，故选项 D 错误.

综上所述,排除选项 ACD. 故选择答案:B.

解后反思:根据一元二次方程有实根的题设条件,合理构建涉及判别式的不等式,从得分视角切入,结合特殊值的选取,代入验证,排除错误选项,进而得到正确答案.特殊值思维,排除法验证,这是破解单项选择题中比较常用的一种技巧与策略,特别是对一些比较陌生、复杂的问题,往往可以采用此思维方法进行尝试与应用.

# 2.2 教研视角

解法 2: (分类讨论法) 由于一元二次方程 $ax^{2} + bx + c = 0$ 有实根，则有判别式 $\Delta = b^{2} - 4ac \geqslant 0$ .

令 $a + b + c = t(t > 0)$ ，若 $b\geqslant \frac{4}{9} t$ ，选项B成立.

若 $b < \frac{4}{9} t$ ，则由 $b^{2} - 4ac\geqslant 0$ ，可得

$$
a c \leqslant \frac {1}{4} b ^ {2} <   \frac {4}{8 1} t ^ {2}. \tag {①}
$$

又 $a + c = t - b > t - \frac{4}{9} t = \frac{5}{9} t$ ，即 $c > \frac{5}{9} t - a$ ，则由①得 $\frac{4}{81} t^2 > ac > a\left(\frac{5}{9} t - a\right)$ ，即 $a^2 - \frac{5}{9} ta + \frac{4}{81} t^2 > 0$ ，解得 $a < \frac{1}{9} t$ 或 $a > \frac{4}{9} t$ .

若 $a > \frac{4}{9} t$ ，选项B已成立；

若 $a < \frac{1}{9} t$ ，则 $c > \frac{5}{9} t - a\frac{4}{9} t$ ，选项B也成立.

综上所述， $\max\{a,b,c\}\geqslant\frac{4}{9}(a+b+c)$ .故选：B.

解后反思:根据一元二次方程有实根的题设条件,合理构建涉及判别式的不等式,对三变元和式运用整体换元处理,结合变量的不同取值情况进行分类讨论,并结合不等式的性质等来综合与应用.在处理多变元问题时,经常以其中一个变元为“主元”,其他变元为“辅元”，进而通过不同取值情况的分类讨论来分析与应用.

解法 3: (换元法) 由于一元二次方程 $ax^{2} + bx + c = 0$ 有实根，则有 $\Delta = b^{2} - 4ac \geqslant 0$ ，即 $b^{2} \geqslant 4ac$ .

不妨设 $a = mb, b = nc (m \geqslant 1, n \geqslant 1)$ ，则有 $n^2 c^2 \geqslant 4mnc^2$ ，所以 $n \geqslant 4m$ 。

而 $\frac{a + b + c}{a} = \frac{mnc + nc + c}{mnc} = 1 + \frac{n + 1}{mn}$ , 令 $k = \frac{n + 1}{mn}$ , 可得 $n = \frac{1}{mk - 1} (mk > 1)$ , 则有 $n = \frac{1}{mk - 1} \geqslant 4m$ .

整理得 $4km^{2}-4m-1\leqslant0$ ，解得 $m\leqslant\frac{1+\sqrt{1+k}}{2k}$ .

而 $m \geqslant 1$ ，则 $1 \leqslant \frac{1 + \sqrt{1 + k}}{2k}$ ，解得 $0 < k \leqslant \frac{5}{4}$ .

所以 $a + b + c = a + \frac{a}{m} +\frac{a}{mn} = a\left(1 + \frac{n + 1}{mn}\right) =$ $a(1 + k)\leqslant \frac{9}{4} a.$ 故 $\max \{a,b,c\} \geqslant \frac{4}{9} (a + b + c).$

解后反思:根据一元二次方程有实根的题设条件,合理构建涉及判别式的不等式,结合变元之间的关系引入参数进行换元法处理,利用不等式的变形与求解以及代数式的恒等变形,通过不等式的性质来确定参数的取值情况,进而得以判断与求解.换元法处理的根本就是利用变元之间的关系,巧妙引入参数进行合理换元,通过合理的逻辑推理与数学运算解决问题.

高考真题1（2024年高考数学新高考Ⅱ卷·8）设函数 $f(x) = (x + a)\ln (x + b)$ ，若 $f(x)\geqslant 0$ ，则 $a^2 +b^2$ 的最小值为（ ）.

A. $\frac{1}{8}$ B. $\frac{1}{4}$ C. $\frac{1}{2}$ D.1

解析:依题意,由于不等式 $f(x) \geqslant 0$ 恒成立,则对函数 $f(x) = (x + a) \ln(x + b)$ 而言,有如下两种情况.

当 $x + a \geqslant 0$ 时，可知 $x \geqslant -a$ ，此时必须满足 $\ln (x + b) \geqslant 0$ ，即 $x \geqslant 1 - b$ ；而当 $x + a \leqslant 0$ 时，可知 $x \leqslant -a$ ，此时必须满足 $\ln (x + b) \leqslant 0$ ，即 $x \leqslant 1 - b$ .

综上分析,要使得不等式 $f(x) \geqslant 0$ 恒成立,即 $x + a$ 与 $\ln(x + b)$ 始终同号,则必须满足 -a = 1 - b, 即 b - a = 1.

所以可得, $a^{2}+b^{2}=\frac{1}{2}\left[(a-b)^{2}+(a+b)^{2}\right]\geqslant\frac{1}{2}(a-b)^{2}=\frac{1}{2}$ ，当且仅当 $(a+b)^{2}=0$ ，即 $a=-\frac{1}{2}$ ， $b=\frac{1}{2}$ 时等号成立。所以 $a^{2}+b^{2}$ 的最小值为 $\frac{1}{2}$ 。故选：C.
