# 基于曲线方程的直线斜率和与积处理的一种通法

●武汉大学附属中学 方喜平

摘要:根据近几年全国数学高考Ⅰ卷解析几何解答题命题特点,主要研究圆锥曲线中因直线运动而产生的斜率和与积的相关问题,通过对此类问题的研究,找到解决此类问题明确有效的方法.

关键词: 圆锥曲线; 斜率; 一元二次方程

数与形是数学中两大基本概念,可以说数学知识大体上都是围绕这两个基本概念的提炼、演变和发展而展开的,而高中数学解析几何部分更是如此,因为解析几何的本质就是用代数的方法来研究几何问题.纵观新高考近三年的试题,不难发现有关直线斜率和与积的相关问题是考查的热点.本文中用齐次化联立的方法揭示解析几何中直线斜率和与积问题的本质,用“数”准确澄清“形”的模糊,用“形”直观启迪“数”的运算,形成对此类问题明确有效的一般结论,以形成此类问题统一的解决方法和思路.

# 1 两个结论

结论 1 设 $A(x_{0}, y_{0})$ 是椭圆 $C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 上一定点，AP, AQ 为椭圆的任意两弦， $k_{AP}, k_{AQ}$ 分别为 AP, AQ 所在直线的斜率，则当 $k_{AP} + k_{AQ} = t (t$ 为定值) 时，直线 PQ 过定点 $\left( x_{0} - \frac{2}{t} y_{0}, -\frac{2b^{2}}{a^{2}t} x_{0} - y_{0} \right)$ ，或 $k_{PQ} = \frac{b^{2}x_{0}}{a^{2}y_{0}}$ ，或直线 PQ 垂直于 x 轴.

证明:设直线 PQ 的方程为 $m(x-x_{0})+n(y-y_{0})=1(m,n\in\mathbf{R})$ .

椭圆 C 的方程可化为 $b^{2}\left[(x-x_{0})+x_{0}\right]^{2}+a^{2}\left[(y-y_{0})+y_{0}\right]^{2}-a^{2}b^{2}=0$ ，整理得 $b^{2}(x-x_{0})^{2}+a^{2}(y-y_{0})^{2}+2b^{2}x_{0}(x-x_{0})+2a^{2}y_{0}(y-y_{0})=0$ ，则 $b^{2}(x-x_{0})^{2}+a^{2}(y-y_{0})^{2}+\left[2b^{2}x_{0}(x-x_{0})+2a^{2}y_{0}(y-y_{0})\right]\left[m(x-x_{0})+n(y-y_{0})\right]=0.$

设 $k = \frac{y - y_0}{x - x_0}$ ，则有 $(a^2 + 2a^2y_0n)k^2 + 2(b^2x_0n + a^2y_0m)k + (b^2 + 2b^2x_0m) = 0.$

故 $k_{AP} + k_{AQ} = -\frac{2(a^2y_0m + b^2x_0n)}{a^2(1 + 2y_0n)} = t.$

（Ⅰ）当 t=0 时，若直线 PQ 的斜率存在，即 $n\neq0$ 时， $k_{PQ}=-\frac{m}{n}=\frac{b^{2}x_{0}}{a^{2}y_{0}}$ ；当 n=0 时，显然直线 PQ 垂直于 x 轴。

（Ⅱ）当 $t \neq 0$ 时，则有 $ta^2(1 + 2y_0n) + 2(a^2y_0m + b^2x_0n) = 0$ ，化简得 $m\left(-\frac{2}{t} y_0\right) - n\left(\frac{2b^2x_0}{a^2t} + 2y_0\right) = 1$ ，即 $m\left(x_0 - \frac{2}{t} y_0 - x_0\right) + n\left[\left(-y_0 - \frac{2b^2x_0}{a^2t}\right) - y_0\right] = 1.$

所以直线 PQ 过定点 $\left(x_{0}-\frac{2}{t}y_{0},-\frac{2b^{2}}{a^{2}t}x_{0}-y_{0}\right)$ .

结论 2 设 $A(x_{0}, y_{0})$ 是双曲线 $C: \frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1 (a > 0, b > 0)$ 上一定点，AP, AQ 为双曲线的任意两弦， $k_{AP}, k_{AQ}$ 分别为 AP, AQ 所在直线的斜率，则当 $k_{AP} + k_{AQ} = t (t \text{ 为定值})$ 时，直线 PQ 过定点 $\left( x_{0} - \frac{2}{t} y_{0}, -\frac{2b^{2}}{a^{2}t} x_{0} - y_{0} \right)$ ，或 $k_{PQ} = -\frac{b^{2}x_{0}}{a^{2}y_{0}}$ ，或直线 PQ 垂直于 x 轴.

结论 2 的证明同结论 1.

# 3 结论推广

将上述结论推广到抛物线有：

结论3 设点 $A(x_0, y_0)$ 为抛物线 $C: y^2 = 2px$ 上一定点， $AP, AQ$ 为抛物线的任意两弦， $k_{AP}, k_{AQ}$ 分别为 $AP, AQ$ 所在直线的斜率，则当 $k_{AP} + k_{AQ} = t$ （ $t$ 为定值）时，直线 $PQ$ 过定点 $\left(x_0 - \frac{2}{t} y_0, \frac{2p}{t} - y_0\right)$ ，或 $k_{PQ} = -\frac{y_0}{p}$ ，或直线 $PQ$ 垂直于 $x$ 轴.

还可以得到斜率和的更多结论以及与斜率积有关的类似结论：

结论4 设 $A(x_0, y_0)$ 是椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ 上一定点， $AP, AQ$ 为椭圆的任意两弦， $\alpha_1, \alpha_2$ 分别为 $AP, AQ$ 所在直线的倾斜角，且所在直线斜率存在分别为 $k_1, k_2$ ，则当 $k_1 k_2 = \tan \alpha_1 \tan \alpha_2 = t (t$ 为定值）时，直线 $PQ$ 过定点 $\left(\frac{a^2 t + b^2}{a^2 t - b^2} x_0, -\frac{a^2 t + b^2}{a^2 t - b^2} y_0\right)$ ，或 $k_{PQ} = -\frac{y_0}{x_0}$ ，或直线 $PQ$ 垂直于 $x$ 轴.

已知椭圆 $C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 的离心率为 $\frac{\sqrt{2}}{2}$ ，且过点 A(2,1).

(1) 求 $C$ 的方程:  
(2) 点 M, N 在 C 上, 且 $AM \perp AN, AD \perp MN, D$ 为垂足. 证明: 存在定点 Q, 使得 $|DQ|$ 为定值.

解析:(1)略.

(2)由(1)知椭圆方程为 $\frac{x^{2}}{6}+\frac{y^{2}}{3}=1.$

由结论4知直线MN过定点 $P\left(\frac{2}{3}, - \frac{1}{3}\right)$

令 Q 为 AP 的中点，即 $Q\left(\frac{4}{3}, \frac{1}{3}\right)$ ，若点 D 与 P 不重合，则由题设知 AP 是 Rt△ADP 的斜边，所以 $|DQ| = \frac{1}{2} |AP| = \frac{2\sqrt{2}}{3}$ 。若点 D 与 P 重合，也满足 $|DQ| = \frac{1}{2} |AP|$ 。故存在点 $Q\left(\frac{4}{3}, \frac{1}{3}\right)$ ，使得 $|DQ|$ 为定值。

结论 5 设点 $A(x_{0}, y_{0})$ 是椭圆 $C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 上一定点，AP, AQ 为椭圆的任意两弦， $\alpha_{1}, \alpha_{2}$ 分别为 AP, AQ 所在直线的倾斜角，则当 $\alpha_{1} + \alpha_{2} = \theta (\theta$ 为定值）时，直线 PQ 过定点 $\left(\frac{a^{2} + b^{2}}{a^{2} - b^{2}} x_{0} - \frac{2a^{2}}{(a^{2} - b^{2})\tan\theta} y_{0}, -\frac{2b^{2}}{(a^{2} - b^{2})\tan\theta} x_{0} - \frac{a^{2} + b^{2}}{a^{2} - b^{2}} y_{0}\right)$ 或 $\left(\frac{a^{2} + b^{2}}{a^{2} - b^{2}} x_{0}, -\frac{a^{2} + b^{2}}{a^{2} - b^{2}} y_{0}\right)$ ，或 $k_{PQ} = \frac{b^{2}x_{0}}{a^{2}y_{0}}$ ，或直线 PQ 垂直于 x 轴.

结论6 设 $A(x_0, y_0)$ 是双曲线 $C: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 (a > 0, b > 0)$ 上一定点， $AP, AQ$ 为双曲线的任意两弦， $\alpha_1, \alpha_2$ 分别为 $AP, AQ$ 所在直线的倾斜角，且所在直线斜率存在分别为 $k_1, k_2$ ，则当 $k_1 \cdot k_2 = \tan \alpha_1 \cdot \tan \alpha_2 = t (t$ 为定值）时，直线 $PQ$ 过定点 $\left( \frac{a^2 t - b^2}{a^2 t + b^2} x_0, -\frac{a^2 t - b^2}{a^2 t + b^2} y_0 \right)$ ，或 $k_{PQ} = -\frac{y_0}{x_0}$ ，或直线 $PQ$ 垂直于 $x$ 轴.

再将上述定理推广到抛物线有：

结论 7 设 $A(x_{0}, y_{0})$ 是抛物线 $C: y^{2} = 2px$ 上一定点, AP, AQ 为抛物线的任意两弦, $k_{AP}, k_{AQ}$ 分别为 AP, AQ 所在直线的斜率, 则当 $k_{AP} \cdot k_{AQ} = t$ (t 为定值) 时, 直线 PQ 过定点 $\left(x_{0} - \frac{2}{t}y_{0}, \frac{2p}{t} - y_{0}\right)$ , 或 $k_{PQ} = -\frac{y_{0}}{p}$ , 或直线 PQ 垂直于 x 轴.

# 4 延伸与启示

基于斜率和与积问题统一的解决方法和思路,通过椭圆和双曲线第三定义,亦可将斜率商的问题转化为符合我们探求的几何模型,进而推证直线过定点等相关问题(如2020年全国卷1).

因此，在平时的教学活动中，教师要有意识地引导学生学会探索、归纳、梳理、总结圆锥曲线中的一些典型问题，以不变应万变，切实提高学生的解题能力与信心，从而巩固“四基”和提升“四能”.Z
