# 一、求值问题

借助辅助角公式的构造与变换,合理转化相应的三角函数关系式,为进一步三角函数化简或求值提供条件,简化过程,提升效益.

例 1 （2017年浙江卷第18题第(1)问）已知函数 $f(x)=\sin^{2}x-\cos^{2}x-2\sqrt{3}\sin x\cos x(x\in\mathbf{R})$ . 求 $f\left(\frac{2\pi}{3}\right)$ 的值.

分析:结合三角恒等变换公式的应用,利用二倍角公式与辅助角公式来转化相应的三角函数关系式,再通过代入来处理三角函数的求值问题.

解:由于函数 $f(x)=\sin^{2}x-\cos^{2}x-2\sqrt{3}\cdot$ $\sin x \cos x = -\sqrt{3} \sin 2x - \cos 2x = -2 \sin \left( 2x + \frac{\pi}{6} \right)$ ，所以 $f\left(\frac{2\pi}{3}\right) = -2 \sin \left( 2 \times \frac{2\pi}{3} + \frac{\pi}{6} \right) = -2 \sin \frac{3\pi}{2} = 2.$

# 二、求角问题

借助辅助角公式的构造与变换,合理转化相应的三角函数关系式,与对应的三角函数值加以对应,并结合题目条件来确定对应的角的取值问题, 直接联系, 简单有效.

例 2 （2019 年全国卷 I 理科第 17 题第(2)问） $\triangle ABC$ 的内角 A, B, C 的对边分别为 a, b, c. 设 $(\sin B - \sin C)^{2} = \sin^{2}A - \sin B\sin C.$ 若 $\sqrt{2}a + b = 2c$ ，求 $\sin C.$

分析:结合条件以及正弦定理、余弦定理来确定角 A 的值,利用题设关系式与正弦定理的综合来转化关系式,结合三角恒等变换公式的应用,合理借助辅助角公式来处理,进而确定角 C 的大小,从而得以进行合理的三角函数求值.

解:由已知得 $\sin^{2}B + \sin^{2}C - \sin^{2}A = \sin B \sin C$ ，由正弦定理，得 $b^{2} + c^{2} - a^{2} = bc$ ；由余弦定理，得 $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = \frac{1}{2}$ 。因为 $0^{\circ} < A < 180^{\circ}$ ，所以 $A = 60^{\circ}$ ，由题设 $\sqrt{2}a + b = 2c$ 及正弦定理，得 $\sqrt{2}\sin A + \sin B = 2\sin C$ ，则有 $\sqrt{2}\sin A + \sin(A + C) = 2\sin C$ ，整理可得 $\frac{\sqrt{6}}{2} + \sin(60^{\circ} + C) = 2\sin C$ ，展开并化简可得 $\frac{\sqrt{3}}{2}\sin C - \frac{1}{2}\cos C = \frac{\sqrt{2}}{2}$ ，结合辅助角公式，可得 $\sin(C - 30^{\circ}) = \frac{\sqrt{2}}{2}$ ，由于 $0^{\circ} < C < 120^{\circ}$ ，则有 $-30^{\circ} < C - 30^{\circ} < 90^{\circ}$ ，所以 $C - 30^{\circ} = 45^{\circ}$ ，可得 $C = 75^{\circ}$ ，故 $\sin C = \sin 75^{\circ} = \sin(30^{\circ} + 45^{\circ}) = \frac{\sqrt{6} + \sqrt{2}}{4}$ 。

# 四、参数问题

借助辅助角公式的构造与变换,合理转化相应的三角函数关系式,结合含参的三角关系式、含参的区间、含参的取值等条件加以链接,结合三角函数的图像与性质来综合,等价转化,合理应用.

例4（2018年全国卷Ⅱ理科第10题）若 $f(x) = \cos x - \sin x$ 在 $[-a, a]$ 上是减函数，则 $a$ 的最大值是（ ）.

A. $\frac{\pi}{4}$

B. $\frac{\pi}{2}$

C. $\frac{3\pi}{4}$

D. $\pi$

分析: 观察函数 $f(x)=\cos x-\sin x$ ，引入辅助角公式，利用三角恒等变换公式加以应用，结合余弦函数的单调性，并利用条件中三角函数的单调减区间来分析与判断.

解: 结合辅助角公式, 可得 $f(x)=\cos x-\sin x=\sqrt{2}\cos\left(x+\frac{\pi}{4}\right)$ ，由 $2k\pi\leqslant x+\frac{\pi}{4}\leqslant2k\pi+\pi,k\in\mathbf{Z}$ ，解得 $2k\pi-\frac{\pi}{4}\leqslant x\leqslant2k\pi+\frac{3\pi}{4}, k\in\mathbf{Z}$ ，则函数 $f(x)$ 的单调递减区间为 $\left[2k\pi-\frac{\pi}{4},2k\pi+\frac{3\pi}{4}\right], k\in\mathbf{Z}$ ，则知当 k=0 时，函数的单调递减区间为 $\left[-\frac{\pi}{4},\frac{3\pi}{4}\right]$ ，所以要使得 $f(x)$ 在 $[-a, a]$ 是减函数，只需满足 0 < a $\leqslant\frac{\pi}{4}$ ，则 a 的最大值是 $\frac{\pi}{4}$ .

故选 A.

# 五、三角函数的图像与性质问题

借助辅助角公式的构造与变换,合理转化相应的三角函数关系式,使之成为一个角的正弦型或余弦型函数,利用正弦函数或余弦函数的相关图像与性质来解决相关问题,是解决此类问题的基本思维与方法.

例 5 （2017 年北京卷文科第 16 题）已知函数 $f(x)=\sqrt{3}\cos\left(2x-\frac{\pi}{3}\right)-2\sin x\cos x.$

(1) $f(x)$ 的最小正周期；  
(2) 求证: 当 $x \in \left[-\frac{\pi}{4}, \frac{\pi}{4}\right]$ 时, $f(x) \geqslant -\frac{1}{2}$ .

分析:结合三角恒等变换公式加以展开与化简,再利用辅助角公式加以转化,从而得到对应的正弦型函数,利用正弦函数的图像与性质来确定最小正周期以及给定区间的不等式恒成立问题.

解:(1)由题意可得 $f(x)=\sqrt{3}\cos\left(2x-\frac{\pi}{3}\right)-2\sin x\cos x=\frac{\sqrt{3}}{2}\cos2x+\frac{3}{2}\sin2x-\sin2x=\frac{1}{2}\sin2x+\frac{\sqrt{3}}{2}\cos2x=\sin\left(2x+\frac{\pi}{3}\right)$ ，所以 $f(x)$ 的最小正周期 $T=\frac{2\pi}{2}=\pi.$

(2) 当 $x \in \left[-\frac{\pi}{4}, \frac{\pi}{4}\right]$ 时，可得 $2x + \frac{\pi}{3} \in \left[-\frac{\pi}{6}, \frac{5\pi}{6}\right]$ ，则知 $\sin \left(2x + \frac{\pi}{3}\right) \geqslant \sin \left(-\frac{\pi}{6}\right) = -\frac{1}{2}$ ，所以当 $x \in \left[-\frac{\pi}{4}, \frac{\pi}{4}\right]$ 时， $f(x) \geqslant -\frac{1}{2}$ .
