# 一、真题呈现

高考真题:(2020年高考数学全国卷Ⅲ第23题)设 $a,b,c\in\mathbf{R},a+b+c=0,abc=1$ .

(1) 证明: $ab + bc + ca < 0$ ;   
(2) 用 $\max\{a, b, c\}$ 表示 $a, b, c$ 中的最大值，证明： $\max\{a, b, c\} \geqslant \sqrt[3]{4}$ .

此题以三个变量为背景,结合三个变量的和与积的关系式来展开相应不等式的证明,巧妙融入创新元素.其中,第一小问通过关系式的平方处理,结合不等式的性质即可加以证明;第二小问通过定义型创新题的设置,即定义了新运算——最大值,结合不等式的相关性质来应用与证明.

# 二、真题破解

第(1)问相对简单,给出证明过程如下:

证明:(1)由于 $a+b+c=0$ ,则有 $(a+b+c)^{2}=a^{2}+b^{2}+c^{2}+2ab+2bc+2ca=0$ ,可得 $ab+bc+ca=-\frac{1}{2}(a^{2}+b^{2}+c^{2})$ ,由于abc=1,则a,b,c均不为0,则有 $a^{2}+b^{2}+c^{2}>0$ ,所以 $ab+bc+ca=-\frac{1}{2}(a^{2}+b^{2}+c^{2})<0$ .

本文主要围绕第(2)问的证明展开,多视角展现思维过程,供读者参考.

# 思维视角(一):基本不等式思维

证法1:不失一般性,不妨设 $\max\{a,b,c\}=a$ ,由$a+b+c=0,abc=1$ ，可知a>0,b<0,c<0，且 $a=-b-c,a=\frac{1}{bc}$ ，所以 $a^{3}=a^{2}\cdot a=(-b-c)^{2}\cdot\frac{1}{bc}=\frac{(b+c)^{2}}{bc}=\frac{b^{2}+c^{2}+2bc}{bc}\geqslant\frac{2bc+2bc}{bc}=4$ ，当且仅当b=c时，等号成立，解得 $a\geqslant\sqrt[3]{4}$ ，即 $\max\{a,b,c\}\geqslant\sqrt[3]{4}$ .

点评: 不失一般性, 假设给出三个数 a, b, c 的最大值为 a, 结合条件分别确定 a 关于 b, c 的关系式, 通过关系式 $a^{3} = a^{2} \cdot a$ 的转化与代换, 并利用基本不等式和不等式的求解来证明相应的不等式成立.

证法2: 不失一般性, 不妨设 $\max\{a,b,c\}=a$ , 由 $a+b+c=0, abc=1$ , 可知 a>0, b<0, c<0, 且 a=-b-c, $a=\frac{1}{bc}$ , 而 $-b-c\geqslant2\sqrt{(-b)(-c)}=2\sqrt{bc}$ , 当且仅当 b=c 时, 等号成立, 则有 $a\geqslant2\sqrt{\frac{1}{a}}$ , 解得 $a\geqslant\sqrt[3]{4}$ , 即 $\max\{a,b,c\}\geqslant\sqrt[3]{4}$ .

点评: 不失一般性, 假设给出三个数 a, b, c 的最大值为 a, 结合条件分别确定 a 关于 b, c 的关系式, 利用基本不等式建立关于“-b-c”的取值范围, 通过代换以及不等式的求解来证明相应的不等式成立.

# 思维视角(二):方程思维

证法3: 不失一般性, 不妨设 $\max\{a, b, c\} = a$ , 由 $a + b + c = 0$ , abc = 1, 可知 a > 0, b < 0, c < 0, 且 $b + c = -a$ , $bc = \frac{1}{a}$ , 所以 b, c 可以看作一元二次方程 $x^{2} + ax + \frac{1}{a} = 0$ 的两个负实数根. 设函数 $f(x) = x^{2} + ax + \frac{1}{a}$ , 其对称性为 $x = -\frac{a}{2} < 0$ , 且 $f(0) = \frac{1}{a} > 0$ , 要使得 $f(x) = 0$ 的解为负实数, 只需判别式 $\Delta = a^{2} - \frac{4}{a} \geqslant 0$ 成立即可, 解得 $a \geqslant \sqrt[3]{4}$ , 即 $\max\{a,$

$$
b, c \} \geqslant \sqrt [ 3 ]{4}.
$$

点评: 不失一般性, 假设给出三个数 a, b, c 的最大值为 a, 结合条件分别确定 b, c 的和与积所对应的关系式, 从而转化为一元二次方程问题, 结合函数的图像与性质, 确定对应方程的解为负实数时只要满足判别式非负即可, 结合不等式的求解来证明相应的不等式成立.

证法 4: 不失一般性, 不妨设 $\max\{a, b, c\} = a$ , 由 $a + b + c = 0$ , 可知 a > 0, b < 0, c < 0, 且 b = -a - c, 将 b = -a - c 代入 abc = 1, 整理可得 $ac^{2} + a^{2}c + 1 = 0$ . 设函数 $f(c) = ac^{2} + a^{2}c + 1$ , 其对称性为 $x = -\frac{a}{2} < 0$ , 且 $f(0) = 1 > 0$ , 要使得一元二次方程 $ac^{2} + a^{2}c + 1 = 0$ 的解为负实数, 只需判别式 $\Delta = a^{4} - 4a \geqslant 0$ 即可, 解得 $a \geqslant \sqrt[3]{4}$ , 即 $\max\{a, b, c\} \geqslant \sqrt[3]{4}$ .

点评: 不失一般性, 假设给出三个数 a, b, c 的最大值为 a, 结合条件确定 b 关于 a, c 的关系式, 并代入 abc = 1, 整理成关于参数 c 的一元二次方程, 结合函数的图像与性质, 确定对应方程的解为负实数时只要满足判别式非负即可, 结合不等式的求解来证明相应的不等式成立.

# 思维视角(三):三角函数思维

证法5: 不失一般性, 不妨设 $\max\{a, b, c\} = a$ , 由 $a + b + c = 0$ , abc = 1, 可知 a > 0, b < 0, c < 0, 且 a = -b - c, bc = $\frac{1}{a}$ , 则有 $a^{2} = (-b - c)^{2} = b^{2} + c^{2} + 2bc$ , 即 $b^{2} + c^{2} = a^{2} - 2bc = a^{2} - \frac{2}{a}$ . 设 $-b = \sqrt{a^{2} - \frac{2}{a}} \cdot \cos\theta$ , $-c = \sqrt{a^{2} - \frac{2}{a}} \cdot \sin\theta$ , $\theta \in \left(0, \frac{\pi}{2}\right)$ , 所以 $a = -b - c = \sqrt{a^{2} - \frac{2}{a}} \cdot \cos\theta + \sqrt{a^{2} - \frac{2}{a}} \cdot \sin\theta = \sqrt{a^{2} - \frac{2}{a}} (\cos\theta + \sin\theta) = \sqrt{a^{2} - \frac{2}{a}} \cdot \sqrt{2} \sin\left(\theta + \frac{\pi}{4}\right) \leqslant \sqrt{a^{2} - \frac{2}{a}} \cdot \sqrt{2}$ , 当且仅当 $\cos\theta = \sin\theta$ , 即 b = c 时, 等号成立, 解得 $a \geqslant \sqrt[3]{4}$ , 即 $\max\{a, b, c\} \geqslant \sqrt[3]{4}$ .

点评: 不失一般性, 假设给出三个数 a, b, c 的最大值为 a, 结合条件分别确定 a 关于 b, c 的关系式, 利用平方关系的展开以及运算来建立关于 $b^{2} + c^{2}$ 的关系式, 借助三角换元法的应用, 结合 a = -b - c 的转化与辅助角公式的应用,利用三角函数的图像与性质建立不等式,并利用不等式的求解来证明相应的不等式成立.

# 思维视角(四):推理与证明思维

证法6: 不失一般性, 不妨设 $a \leqslant b < 0 < c < \sqrt[3]{4}$ , 由 $a + b + c = 0$ , abc = 1, 可知 $ab = \frac{1}{c} > \frac{1}{\sqrt[3]{4}}$ , -a - b = c < $\sqrt[3]{4}$ , 而 $-a - b \geqslant 2\sqrt{(-a)(-b)} = 2\sqrt{ab} > \frac{2}{\sqrt[6]{4}} = \sqrt[3]{4}$ , 这与 $-a - b < \sqrt[3]{4}$ 产生矛盾, 所以原来假设不成立, 即 $\max\{a, b, c\} \geqslant \sqrt[3]{4}$ .

点评:给出三个数之间的大小关系,并假设三个数a,b,c中的最大值小于 $\sqrt[3]{4}$ ,结合条件以及基本不等式分别确定“-a-b”的取值范围,进而推出矛盾结论,从而得以利用反证法来证明相应的不等式成立.

# 三、链接教材

普通高中课程标准实验教科书《数学·选修4—5·A版》(人民教育出版社,2007年1月第2版)习题1.1第11页第15题:

问题: 已知 a > 0, b > 0, 且 $h = \min\left\{a, \frac{b}{a^{2} + b^{2}}\right\}$ ,
求证： $h \leqslant \frac{\sqrt{2}}{2}$ .

证明:由于a>0,b>0,且 $h=\min\left\{a,\frac{b}{a^{2}+b^{2}}\right\}$ ，则有 $0<h\leqslant a,0<h\leqslant\frac{b}{a^{2}+b^{2}}$ ，利用不等式的性质，可得 $h^{2}\leqslant a\cdot\frac{b}{a^{2}+b^{2}}=\frac{ab}{a^{2}+b^{2}}\leqslant\frac{ab}{2ab}=\frac{1}{2}$ ，当且仅当a=b时，等号成立，解得 $h\leqslant\frac{\sqrt{2}}{2}$ .
