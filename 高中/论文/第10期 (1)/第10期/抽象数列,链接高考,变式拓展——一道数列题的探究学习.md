我们知道，在函数中，不给出具体的解析式，只给出函数的特殊条件或特征的函数就是抽象函数。类似地，在数列中，不给出具体的通项公式，只给出数列的特殊条件或特征的数列就是抽象数列。破解此类抽象数列时，关键就是正确分析，从抽象数列的特殊条件或特征入手，结合抽象数列的递推关系式进行巧妙赋值，合理转化，从中做“文章”，化抽象为具体，转化为特殊数列（常数列、等差数列或等比数列等）或确定数列，利用具体数列的定义、特征或性质、通项公式或求和公式等来巧妙处理。

# 一、问题呈现

问题:(2021届江苏省常州市高三期中数学试卷第16题)已知数列 $\{a_{n}\}$ 中, $a_{1}=\frac{1}{2}$ ，且对任意正整数m,n,m>n，都有等式 $2a_{m}a_{n}=a_{m+n}+a_{m-n}$ 成立，那么 $a_{2020}=$ \_\_\_\_.

此题通过抽象数列的首项以及递推关系式的给出,合理设置抽象数列的特征,巧妙把数列的周期性这一本质特征隐藏其中,借助巧妙赋值或参数转化等方式加以展示,进而来确定该抽象数列中的具体项的取值问题.合理借助抽象数列的递推关系式,抽象关系式的应用,可以很好考查学生的数学知识与数学技能,数学运算能力和化归与转化能力,以及相应的数学思维能力等.

# 二、链接高考

抽象数列的考查在 2020 年高考数学试卷中闪亮登场,以抽象数列为背景,结合等比数列的定义、性质与求和公式来合理设置,试题难度中等.

高考真题:(2020年高考数学全国卷Ⅱ理科第6题)在数列 $\{a_{n}\}$ 中, $a_{1}=2,a_{m+n}=a_{m}a_{n}$ ，若 $a_{k+1}+a_{k+2}+\cdots+a_{k+10}=2^{15}-2^{5}$ ，则 $k=(\quad)$ .

A. 2

B. 3

C. 4

D. 5

解析:由于 $a_{1}=2,a_{m+n}=a_{m}a_{n}$ ，令m=1，可得 $a_{n+1}$

$= a_{1}a_{n} = 2a_{n}$ ，则数列 $\{a_{n}\}$ 是以 $a_1 = 2$ 为首项，公比 $q = 2$ 的等比数列，可得 $a_{n} = 2^{n}$ ，而由 $a_{k + 1} + a_{k + 2} + \dots + a_{k + 10} = \frac{2^{k + 1}(1 - 2^{10})}{1 - 2} = 2^{15} - 2^5$ ，可得 $2^{k + 1} = \frac{2^{15} - 2^5}{2^{10} - 1} = \frac{2^5(2^{10} - 1)}{2^{10} - 1} = 2^5$ ，则 $k + 1 = 5$ ，解得 $k = 4$

故选C.

点评:本题巧妙地把抽象数列与特殊的等比数列加以合理融合,化抽象为具体,并合理借助等比数列的定义、性质与求和公式来分析与处理问题,把数学知识与数学能力有效整合,充分考查考生各方面的能力与素质.题目难度中等,背景新颖,极具创新性,具有较好的选拔性与区分性.

# 三、问题破解

解法1:(赋值归纳法)由于 $a_{1}=\frac{1}{2}$ ，当m>n时，等式 $2a_{m}a_{n}=a_{m+n}+a_{m-n}$ 成立，所以 $2a_{2}a_{1}=a_{3}+a_{1}$ ，则 $a_{2}=a_{3}+a_{1}$ ，所以 $a_{3}-a_{2}=-a_{1}=-\frac{1}{2}$ .

由于 $2a_{3}a_{1} = a_{4} + a_{2}$ ，则 $a_3 = a_4 + a_2$ ，所以 $a_4 = a_3 - a_2 = -\frac{1}{2}$

由于 $2a_{4}a_{1} = a_{5} + a_{3}$ ，则 $a_4 = a_5 + a_3$ ，所以 $a_3 + a_5 = a_4 = -\frac{1}{2}$

由于 $2a_{5}a_{1} = a_{6} + a_{4}$ ，则 $a_5 = a_6 + a_4$ ，所以 $a_6 - a_5 = -a_4 = \frac{1}{2}$

由于 $2a_{6}a_{1} = a_{7} + a_{5}$ ，则 $a_{6} = a_{7} + a_{5}$ ，所以 $a_{7} = a_{6} - a_{5} = \frac{1}{2}\dots$

归纳可知数列 $\{a_{n}\}$ 是以6为周期的周期函数，所以 $a_{2020} = a_{336\times 6 + 4} = a_4 = -\frac{1}{2}$

故填答案: $-\frac{1}{2}$ .

点评: 结合已知条件中的抽象数列的递推关系式, 通过对参数 m, n 直接赋值, 利用赋值法逐一分析与求解, 通过前面有限个特殊项之间的数值的关系, 结合不完全归纳得出抽象数列的周期性, 这是破解问题的关键所在, 最后再利用数列的周期性来分析与求解数列的相应的项的值问题. 以上问题的解析过程中, 在不完全归纳下, 当得到 $a_{4} = -\frac{1}{2}$ , 也可以直接归纳 $a_{4} = -a_{1}$ , 则有 $a_{7} = -a_{4} = a_{1}$ , 从而归纳可知数列 $\{a_{n}\}$ 是以 6 为周期的周期函数. 该方法不完全归纳, 不具有科学性与正确性, 但在处理选择题或填空题中, 经常用来特殊化解决相关问题.

解法2：(特殊参数转化法)由于 $a_1 = \frac{1}{2}, 2a_m a_n = a_{m+n} + a_{m-n}$ ，令 $n = 1$ ，可得 $2a_m a_1 = a_{m+1} + a_{m-1}$ ，即 $a_m = a_{m+1} + a_{m-1}$ 。而由 $a_m = a_{m+1} + a_{m-1}$ ，可得 $a_{m+1} = a_{m+2} + a_m$ ，以上两式相应代入并整理可得 $a_{m+2} = -a_{m-1}$ ，即 $a_{m+3} = -a_m$ ，所以 $a_{m+6} = -a_{m+3} = a_m$ 。因此数列 $\{a_n\}$ 是以6为周期的周期函数，所以 $a_{2020} = a_{336 \times 6+4} = a_4 = -a_1 = -\frac{1}{2}$ 。

故填答案: $-\frac{1}{2}$ .

点评:结合已经条件中的数列递推关系式,利用特殊参数来转化处理,巧妙设置其中一参数值为1,并结合所得的数列递推关系式的变形与转化,借助代数运算与整理,得以确定数列更为直接的递推关系式,从而利用数列的周期性来确定其相应的周期问题,最后利用数列的周期性来分析与求解数列的相应的项的取值问题.

# 四、变式拓展

探究 1: 通过改变原来高考真题中抽象数列的给出方式, 变递推理关系式中的“积式”为“商式”, 合理改变相关条件, 得到以下相应的变式问题. 考查的数学知识点与数学能力基本一致, 难度与原高考真题相当.

变式 1: 在数列 $\{a_{n}\}$ 中, $a_{1}=\frac{1}{2}$ , 且对任意正整数 m, n, n > m, 都有等式 $a_{m+n}=\frac{a_{n}}{a_{m}}$ 成立, 若 $a_{k+1}+a_{k+2}+\cdots+a_{k+10}=2^{15}-2^{5}$ , 则 $k=(\quad)$ .

A. 3

B. 4

C. 5

D. 6

解析:由于 $a_{1}=\frac{1}{2}$ ，且对任意正整数m,n,n>m，
都有等式 $a_{m+n}=\frac{a_{n}}{a_{m}}$ 成立，令m=1，可得 $a_{n+1}=\frac{a_{n}}{a_{1}}=2a_{n}$ ，则数列 $\{a_{n}\}$ 是以 $a_{1}=\frac{1}{2}$ 为首项，公比q=2的等比数列，可得 $a_{n}=2^{n-2}$ ，而由 $a_{k+1}+a_{k+2}+\cdots+a_{k+10}=\frac{2^{k-1}(1-2^{10})}{1-2}=2^{15}-2^{5}$ ，可得 $2^{k-1}=\frac{2^{15}-2^{5}}{2^{10}-1}=\frac{2^{5}(2^{10}-1)}{2^{10}-1}=2^{5}$ ，则k-1=5，解得k=6.

故选D.

探究 2: 通过改变原来模拟题中抽象数列的给出方式, 变递推关系式中的“和式”为“积式”, 合理改变相关条件, 得到以下相应的变式问题. 考查的数学知识点与数学能力基本一致, 难度与原题相当.

变式2:已知数列 $\{a_{n}\}$ 中, $a_{1}=\frac{1}{2},a_{n}\neq0$ ,且对任意正整数m,n,m>n,都有等式 $2a_{m}a_{n}=a_{m+n}\cdot a_{m-n}$ 成立,那么 $a_{2020}=$ \_\_\_\_.

解析:由于 $a_{1}=\frac{1}{2},2a_{m}a_{n}=a_{m+n}\cdot a_{m-n}$ ,

令 $n = 1$ ，可得 $2a_{m}a_{1} = a_{m + 1}\cdot a_{m - 1}$

即 $a_{m} = a_{m + 1}\cdot a_{m - 1}$

而由 $a_{m} = a_{m + 1}\cdot a_{m - 1}$ ，可得 $a_{m + 1} = a_{m + 2}\cdot a_m$

以上两式相应代入并整理可得 $a_{m + 2}\cdot a_{m - 1} = 1$

即 $a_{m + 3}\cdot a_m = 1$

所以 $a_{m + 6} = \frac{1}{a_{m + 3}} = a_m$

即数列 $\{a_{n}\}$ 是以6为周期的周期函数，

所以 $a_{2020}=a_{336\times6+4}=a_{4}=\frac{1}{a_{1}}=2.$

故填答案:2.

# 五、解后反思
