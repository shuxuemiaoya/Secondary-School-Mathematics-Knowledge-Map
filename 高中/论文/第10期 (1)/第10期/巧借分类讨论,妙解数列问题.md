分类讨论思想是中学数学中最重要的解题思想方法之一, 主要针对含参的数学问题, 对参数进行必要的分类讨论, 训练人的思维条理性和概括性, 具有明显的逻辑性、综合性、探索性、创新性等. 特别地, 在数列问题中, 涉及数列的通项 $a_{n}$ 与前 $n$ 项和 $S_{n}$ 的关系, 等比数列前 $n$ 项和公式中 $q = 1$ 与 $q \neq 1$ 的区别, 数列中项数 $n$ 决定相应的通项与前 $n$ 项和等问题, 结合项数 $n$ 的奇偶情况、整除性情况等进行分类讨论, 结合不同情况下对应的通项或前 $n$ 项和等加以应用.

# 一、项数 $n$ 的分类讨论

例 1 （2020 年高考数学全国卷 I 文科第 16 题）数列 $\{a_{n}\}$ 满足 $a_{n+2} + (-1)^{n}a_{n} = 3n - 1$ ，前 16 项和为 540，则 $a_{1} =$ \_\_\_\_ .

分析:利用题目条件中数列 $\{a_{n}\}$ 的通项公式分奇偶项n的分类讨论,分析奇偶项之间的和式表达式,结合列举法的应用,发现规律后再归纳总结,进而进行合理列式,灵活求解相应的项.

解析:由于 $a_{n+2} + (-1)^{n}a_{n} = 3n - 1$ ,

当 $n$ 为奇数时， $a_{n+2} = a_n + 3n - 1$ ;

当 n 为偶数时， $a_{n+2} + a_n = 3n - 1$ .

设数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ,

$$
\begin{array}{l} \text { 那么 } S _ {1 6} = a _ {1} + a _ {2} + a _ {3} + a _ {4} + \dots + a _ {1 6} = a _ {1} + a _ {3} \\ + a _ {5} + \dots + a _ {1 5} + (a _ {2} + a _ {4}) + (a _ {6} + a _ {8}) + \dots + (a _ {1 4} + \\ a _ {1 6}) = a _ {1} + (a _ {1} + 2) + (a _ {1} + 2 + 8) + (a _ {1} + 2 + 8 + 1 4) \\ + \left(a _ {1} + 2 + 8 + 1 4 + 2 0\right) + \left(a _ {1} + 2 + 8 + 1 4 + 2 0 + 2 6\right) \\ + \left(a _ {1} + 2 + 8 + 1 4 + 2 0 + 2 6 + 3 2\right) + \left(a _ {1} + 2 + 8 + 1 4 \right. \\ + 2 0 + 2 6 + 3 2 + 3 8) + 5 + 1 7 + 2 9 + 4 1 = 8 a _ {1} + 4 8 4 \\ = 5 4 0, \text { 解得 } a _ {1} = 7. \\ \end{array}
$$

故填答案:7.

点评:利用条件对数列中的递推公式、通项公式或项数n分奇偶数项加以分类讨论,得到相应的递推关系式,结合数列类型的判断,再由递推关系式表达出含有首项的和式,进而解出首项即可.

# 二、公比 q 的分类讨论

例2（2018年高考数学浙江卷第10题）已知 $a_1, a_2, a_3, a_4$ 成等比数列，且 $a_1 + a_2 + a_3 + a_4 = \ln (a_1 + a_2 + a_3)$ . 若 $a_1 > 1$ ，则（ ）.

A. $a_1 < a_3, a_2 < a_4$

B. $a_1 > a_3, a_2 < a_4$

C. $a_1 < a_3, a_2 > a_4$

D. $a_1 > a_3, a_2 > a_4$

分析:根据等比数列的性质确定相应的项的符号,设出数列的公比q,结合条件 $a_{1}>1$ ,通过对公比q的分类讨论:q>0,q=-1,q<-1的分析,结合条件确定关系式 $a_{1}+a_{2}+a_{3}+a_{4}=\ln(a_{1}+a_{2}+a_{3})$ 不成立,从而得到-1<q<0,进而确定相应项的大小关系.

解析:由于 $a_{1}, a_{2}, a_{3}, a_{4}$ 成等比数列,根据等比数列的性质可知,奇数项符号相同,偶数项符号相同,又 $a_{1} > 1$ ,设公比为 q,

当 q > 0 时， $a_{1} + a_{2} + a_{3} + a_{4} > a_{1} + a_{2} + a_{3}$ ，此时 $a_{1} + a_{2} + a_{3} + a_{4} = \ln(a_{1} + a_{2} + a_{3})$ 不成立，那么 $a_{1} < a_{3}, a_{2} < a_{4}$ 或 $a_{1} > a_{3}, a_{2} > a_{4}$ 不成立，排除选项 A, D;

当 $q = -1$ 时，可得 $a_1 + a_2 + a_3 + a_4 = 0, \ln (a_1 + a_2 + a_3) > 0$ ，此时 $a_1 + a_2 + a_3 + a_4 = \ln (a_1 + a_2 + a_3)$ 不成立，所以 $q \neq -1$

当 q<-1 时， $a_{1}+a_{2}+a_{3}+a_{4}<0,\ln(a_{1}+a_{2}+a_{3})>0$ ，此时 $a_{1}+a_{2}+a_{3}+a_{4}=\ln(a_{1}+a_{2}+a_{3})$ 不成立；

当 $-1 < q < 0$ 时， $a_1 > a_3 > 0, a_2 < a_4 < 0$ ，并且 $a_1 + a_2 + a_3 + a_4 = \ln (a_1 + a_2 + a_3)$ 成立.

综上分析,可得 $a_{1}>a_{3},a_{2}<a_{4}$ .

故选 B.

点评:利用条件中数列 $\{a_{n}\}$ 的公比q的不同取值情况加以分类讨论,并在公比q的不同情况下结合条件加以分析与讨论,从而确定数列中的通项、前n项和以及数列与不等式等的交汇问题.

# 三、关系式中的分类讨论

例3（2020年高考数学浙江卷第7题）已知等差数列 $\{a_{n}\}$ 的前 $n$ 项和 $S_{n}$ ，公差 $d \neq 0, \frac{a_{1}}{d} \leqslant 1$ . 记 $b_{1} = S_{2}, b_{n+1} = S_{2n+2} - S_{2n}, n \in \mathbf{N}^{*}$ ，下列等式不可能成立的是（ ）.

A. $2a_{4} = a_{2} + a_{6}$

B. $2b_{4} = b_{2} + b_{6}$

C. $a_4^2 = a_2a_8$

D. $b_{4}^{2} = b_{2}b_{8}$

分析:根据题目条件先确定数列 $\{b_{n}\}$ 的类型,并确定相应的通项公式,结合等差数列的性质来确定选项A与B;再分类讨论,结合不同关系式成立的条件,代入对应的通项公式,确定 $a_{1}$ 与d的关系,与条件相对比来分析与判断.

解析:设等差数列 $\{a_{n}\}$ 的通项公式为 $a_{n}=a_{1}+(n-1)d$ ，结合 $b_{n+1}=S_{2n+2}-S_{2n}$ ，可得 $b_{n+1}-b_{n}=(S_{2n+2}-S_{2n})-(S_{2n}-S_{2n-2})=a_{2n+2}+a_{2n+1}-(a_{2n}+a_{2n-1})=4d(n\geqslant2)$ .

又 $b_{2} - b_{1} = (S_{4} - S_{2}) - S_{2} = 4d, b_{1} = S_{2} = a_{1} + a_{2} = 2a_{1} + d,$

所以数列 $\{b_{n}\}$ 是以 $b_{1}=2a_{1}+d$ 为首项，4d为公差的等差数列，

则有 $b_{n} = b_{1} + (n - 1)4d = 2a_{1} + (4n - 3)d$

结合等差数列的性质, 可知选项 A、B 正确;

对于选项 C, 若 $a_{4}^{2}=a_{2}a_{8}$ 成立,

则有 $(a_{1} + 3d)^{2} = (a_{1} + d)(a_{1} + 7d)$

整理可得 $a_1 = d$ ，满足 $\frac{a_1}{d} \leqslant 1$

可知选项 C 正确；

对于选项 D, 若 $b_{4}^{2}=b_{2}b_{8}$ 成立,

则有 $(2a_{1} + 13d)^{2} = (2a_{1} + 5d)(2a_{1} + 29d)$

整理可得 $a_1 = \frac{3}{2} d$ ，不满足 $\frac{a_1}{d}\leqslant 1$

可知选项 C 错误.

故选D.

点评:结合数列背景中不同选项所对应的数列关系式,借助不同选项的分类讨论,利用数列的通项公式的变形与转化,确定相应的数列关系式,与条件加以对比分析来确定满足条件的关系式.

# 四、综合问题中的分类讨论

例 4 （2020年高考数学北京卷第8题）在等差数列 $\{a_{n}\}$ 中， $a_{1}=-9,a_{3}=-1$ 。记 $T_{n}=a_{1}a_{2}\cdots a_{n}(n=1,2,\cdots)$ ，则数列 $\{T_{n}\}()$ 。

A. 有最大项, 有最小项

B. 有最大项, 无最小项

C. 无最大项,有最小项

D. 无最大项, 无最小项

分析: 结合等差数列的通项公式的确定以及各项的正负取值情况, 通过最大项与最小项的不同情况进行分类讨论, 并结合不等式的性质来确定数列 $\{T_{n}\}$ 中的正项与负项情况, 进而得以正确分析与判断.

解析:设等差数列 $\{a_{n}\}$ 的公差为d,

由题意可知， $d = \frac{a_5 - a_1}{5 - 1} = \frac{-1 + 9}{5 - 1} = 2,$

则其通项公式为 $a_{n} = a_{1} + (n - 1)d = 2n - 11$

可知 $a_{1}<a_{2}<a_{3}<a_{4}<a_{5}<0<a_{6}=1<a_{7}<\cdots,$

那么对于 $T_{n}=a_{1}a_{2}\cdots a_{n}(n=1,2,\cdots)$ ,

可得 $T_{5} < 0$ 且 $T_{i} < 0 (i \geqslant 6, i \in \mathbb{N})$ ,

而由 $\frac{T_i}{T_{i - 1}} = a_i > 1 (i \geqslant 7, i \in \mathbf{N})$ ，可知数列 $\{T_n\}$ 不存在最小项；

而数列 $\{T_{n}\}$ 中的正项只有有限项： $T_{2} = (-9)(-7) = 63, T_{4} = (-9)(-7)(-5)(-3) = 945$ ，可知数列 $\{T_{n}\}$ 存在最大项 $T_{4}$ ；所以数列 $\{T_{n}\}$ 中有最大项，无最小项。

故选 B.

点评:结合创新数列中的正项与负项的不同取值情况进行分类讨论,综合数列的定义、通项公式、求和公式或数列性质,合理融合不等式的相关知识来合理交汇,通过数列与不等式的综合应用来分析与解决问题.
