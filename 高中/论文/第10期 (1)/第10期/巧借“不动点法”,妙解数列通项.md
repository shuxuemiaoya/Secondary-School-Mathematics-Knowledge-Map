在函数与方程问题中, 对于一个函数 $f(x)$ , 我们经常把满足方程 $f(x) = x$ 的 $x$ 值称为函数 $f(x)$ 的“不动点”. 而数列作为函数的一个特例, 函数的“不动点”也是满足且适用数列中的相关问题, 在具体破解一些复杂的相关数列的通项公式求解问题时, 经常利用“不动点法”来构造新数列, 从而得以确定数列的通项公式. 巧思妙解, 优化解题过程, 减少代数运算, 程序化强, 方便记忆与操作.

# 一、一阶不动点法

若函数 $f(x) = ax + b (a \neq 0,1)$ , 数列 $\{a_{n}\}$ 满足 $a_{n+1} = f(a_{n})$ , 若 $p$ 是函数 $f(x)$ 的一个不动点, 则有 $a_{n+1} - p = a (a_{n} - p)$ , 即数列 $\{a_{n} - p\}$ 是一个公比为 $a$ 的等比数列. 一阶不动点法主要适用于有关数列的一次线性递推关系式问题.

例1 在数列 $\{a_{n}\}$ 中，若 $a_1 = 1$ ，且满足 $a_{n + 1} = \frac{1}{2} a_n + 1$ ，试求数列 $\{a_{n}\}$ 的通项公式.

分析:根据条件中的数列递推关系式构造相应的函数,建立相应的方程,求得对应的一个不动点,进而变形与转化相应的数列递推关系式,结合等比数列的定义加以转化,利用等比数列的通项公式建立关系式,从而得以确定相应数列的通项公式.

解: 设函数 $f(x)=\frac{1}{2}x+1$ ，令 $f(x)=x$ ，即 $\frac{1}{2}x+1=x$ ，解得 x=2，所以 x=2 是函数 $f(x)=\frac{1}{2}x+1$ 的不动点，可得 $a_{n+1}-2=\frac{1}{2}(a_{n}-2)$ ，所以数列 $\{a_{n}-2\}$ 是以 -1 为首项，以 $\frac{1}{2}$ 为公比的等比数列，所以 $a_{n}-2=-1\times\left(\frac{1}{2}\right)^{n-1}$ ，即 $a_{n}=2-\left(\frac{1}{2}\right)^{n-1}, n\in\mathbf{N}^{*}$ .

点评:有关比较复杂的数列的一次线性递推关系式问题,经常可以借助“一阶不动点法”来合理构造对应的函数与方程,利用方程的求解,进而确定相应的一个不动点,有效转化与变形相应的数列递推关系式,从而结合等比数列的定义与通项公式来转化与确定相应的数列通项公式问题.

例2 已知数列 $\{a_{n}\}$ 满足 $a_1 = 0, a_2 = 1, a_{n+2} = \lambda a_{n+1} + \frac{1}{2} a_n, n \in \mathbf{N}^*, \lambda \in \mathbf{R}$ .

(1) 令 $b_{n} = a_{n + 1} + a_{n}$ , 是否存在实数 $\lambda$ 的值, 使得 $\{b_{n}\}$ 是等比数列? 若存在, 求出 $\lambda$ 的值; 若不存在, 请说明理由.  
(2) 在(1)的条件下, 求 $\{a_{n}\}$ 的通项公式.

分析:(1)假设数列 $\{b_{n}\}$ 是等比数列,并设出公比q,结合等比数列的定义建立相应的关系式,通过转化与题目条件加以对比,进而建立相应的方程组,确定对应的参数值是否存在就可以判断存在性问题;(2)根据(1)的结论得到 $b_{n}=a_{n+1}+a_{n}=\left(\frac{1}{2}\right)^{n-1}$ ,根据该递推关系式的变形与转化,通过换元处理,并建立相应的函数与方程,确定相应的一个不动点,结合等比数列的定义与通项公式来转化与确定相应的数列通项公式问题.

解:(1) 假设数列 $\{b_{n}\}$ 是等比数列,且其公比为q,结合等比数列的定义,可得 $\frac{b_{n+1}}{b_{n}}=\frac{a_{n+2}+a_{n+1}}{a_{n+1}+a_{n}}=q$ ,整理可得 $a_{n+2}+a_{n+1}=qa_{n+1}+qa_{n}$ ,则有 $a_{n+2}=(q-1)a_{n+1}+qa_{n}$ ,与已知条件中的关系对比,则有 $\left\{\begin{aligned}q-1&=\lambda,\\ q&=\frac{1}{2},\end{aligned}\right.$ 解得 $\lambda=-\frac{1}{2}$ ,所以存在 $\lambda=-\frac{1}{2}$ ,使得数列 $\{b_{n}\}$ 是等比数列.

(2) 由(1)得 $b_{1} = a_{2} + a_{1} = 1 + 0 = 1, q = \frac{1}{2}$ ，可得 $b_{n} = a_{n+1} + a_{n} = \left(\frac{1}{2}\right)^{n-1}$ ，即 $a_{n+1} + a_{n} = \left(\frac{1}{2}\right)^{n-1}$ ，该式两边同时除以 $\left(\frac{1}{2}\right)^{n+1}$ ，可得 $\frac{a_{n+1}}{\left(\frac{1}{2}\right)^{n+1}} + \frac{2a_{n}}{\left(\frac{1}{2}\right)^{n}} = 4$ . 设

$c_{n} = \frac{a_{n}}{\left(\frac{1}{2}\right)^{n}}$ ，则有 $c_{n + 1} + 2c_n = 4$ ，即 $c_{n + 1} = -2c_n + 4.$ 设函数 $f(x) = -2x + 4$ ，令 $f(x) = x$ ，即 $-2x + 4 = x$ 解得 $x = \frac{4}{3}$ ，所以 $x = \frac{4}{3}$ 是函数 $f(x) = -2x + 4$ 的不动点，可得 $c_{n + 1} - \frac{4}{3} = -2\left(c_n - \frac{4}{3}\right)$ ，所以数列 $\left\{c_n - \frac{4}{3}\right\}$ 是首项 $c_{1} - \frac{4}{3} = -\frac{4}{3}$ ，公比为-2的等比数列，所以 $c_{n} - \frac{4}{3} = -\frac{4}{3}\cdot (-2)^{n - 1} = \frac{a_n}{\left(\frac{1}{2}\right)^n} -\frac{4}{3}$ ，解得 $a_{n} = \frac{2}{3}\cdot (-1)^{n} + \frac{4}{3}\cdot \left(\frac{1}{2}\right)^{n}.$

点评: 在处理一些复杂的数列递推关系式问题时, 经常借助相应的代数运算, 并综合换元、变形等等价处理, 转化为数列的一次线性递推关系式问题, 再结合“一阶不动点法”来分析与处理, 从而得以巧妙转化, 合理破解.

# 二、二阶不动点法

设函数 $f(x) = \frac{ax + b}{cx + d} (c \neq 0, ad - bc \neq 0)$ ，数列 $\{a_n\}$ 满足 $a_{n+1} = f(a_n)$ ，且 $a_1 \neq f(a_1)$ . 若函数 $f(x)$ 有两个相异的不动点 $p, q$ ，则有 $\frac{a_{n+1} - p}{a_{n+1} - q} = k \cdot \frac{a_n - p}{a_n - q}$ （此处 $k = \frac{a - pc}{a - qc}$ ，具体求解不用死记公式，结合已知的递推关系式加以转化与求解），即数列 $\left\{\frac{a_n - p}{a_n - q}\right\}$ 是一个公比为 $k$ 的等比数列. 二阶不动点法主要适用于有关数列的一次分式递推关系式问题.

# 1). 求数列 $\{b_{n}\}$ 的通项公式.

分析:先根据题目条件中的数列递推关系式转化为有关数列的一次分式递推关系式问题,进而构造相应的函数,建立相应的方程,求得对应的两个不动点,结合“二阶不动点法”设出数列的递推关系式，并根据题目条件中的递推关系式代入变形与转化来确定参数的值，结合等比数列的定义加以转化，利用等比数列的通项公式建立关系式，从而得以确定相应数列的通项公式.

解:由已知 $8a_{n+1}a_{n}-16a_{n+1}+2a_{n}+5=0$ ，整理可得 $a_{n+1}=\frac{2a_{n}+5}{-8a_{n}+16}$ 。设函数 $f(x)=\frac{2x+5}{-8x+16}$ ，令 $f(x)=x$ ，即 $x=\frac{2x+5}{-8x+16}$ ，化简可得 $8x^{2}-14x+5=0$ ，解得 $x_{1}=\frac{1}{2}$ 或 $x_{2}=\frac{5}{4}$ ，所以有 $\frac{a_{n+1}-\frac{1}{2}}{a_{n+1}-\frac{5}{4}}=\frac{2a_{n}+5}{-8a_{n}+16}-\frac{1}{2}\frac{2a_{n}+5}{-8a_{n}+16}-\frac{1}{4}=\frac{1}{2}\cdot\frac{a_{n}-\frac{1}{2}}{a_{n}-\frac{5}{4}}$ ，所以数列 $\left\{\frac{a_{n}-\frac{1}{2}}{a_{n}-\frac{5}{4}}\right\}$ 是首项为 $\frac{a_{1}-\frac{1}{2}}{a_{1}-\frac{5}{4}}=-2$ ，公比为 $\frac{1}{2}$ 的等比数列，所以 $\frac{a_{n}-\frac{1}{2}}{a_{n}-\frac{5}{4}}=-2\times\left(\frac{1}{2}\right)^{n-1}=-\frac{4}{2^{n}}$ ，整理并解得 $a_{n}=\frac{2^{n-1}+5}{2^{n}+4}$ ，故 $b_{n}=\frac{1}{a_{n}-\frac{1}{2}}=\frac{2^{n}+4}{3}, n\in N^{*}$ 。

点评:在处理一些复杂的数列递推关系式问题时,经常借助相应的代数运算加以合理变形与转化,从而转化为数列的一次分式递推关系式问题,再结合“二阶不动点法”来分析与处理,合理转化,巧妙处理.
