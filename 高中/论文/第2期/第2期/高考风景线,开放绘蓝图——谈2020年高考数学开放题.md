数学开放题通常是指没有确定的题目条件、解题方法、结论答案等形式的问题, 是创新意识与应用意识的进一步深入与拓展. 近年高考数学试题中也对数学开放题做了一些尝试, 成为考生突破的难点. 特别是 2020 年高考中, 数学开放题成为一大亮点, 开放类型层出不穷, 灵活多变.

# 一、开放结论，精彩纷呈

开放结论的数学开放题是在确定条件的基础上，得到的结论往往不唯一，只要确定一个满足条件的答案即达目的。破解时可直接分析，也可“投机取巧”，方法多样，策略多变。

例 1 （2020 年北京卷第 14 题）若函数 $f(x)=\sin(x+\varphi)+\cos x$ 的最大值为 2，则常数 $\varphi$ 的一个取值为 \_\_\_\_.

分析: 可以直接利用三角关系式的三角恒等变换, 转化为正弦型函数, 结合函数的最大值来建立关系式, 进而求解满足条件的三角关系式, 得以确定 $\varphi$ 的关系式; 也可以直接选取比较熟知的特殊值 $\varphi = \frac{\pi}{2}$ , 代入并恒等变换, 得到相应的三角函数解析式满足条件, 从而确定所求常数 $\varphi$ 的一个取值即可.

解析: 由于函数 $f(x)=\sin(x+\varphi)+\cos x=\sin x\cos\varphi+\cos x\sin\varphi+\cos x=\cos\varphi\sin x+(\sin\varphi+1)\cos x=\sqrt{\cos^{2}\varphi+(\sin\varphi+1)^{2}}\sin(x+\alpha)$ ，而函数 $f(x)=\sin(x+\varphi)+\cos x$ 的最大值为 2，则有 $\sqrt{\cos^{2}\varphi+(\sin\varphi+1)^{2}}=2$ ，整理有 $\sin\varphi=1$ ，则有 $\varphi=2k\pi+\frac{\pi}{2}, k\in Z$ 。取常数 $\varphi$ 的一个取值为 $\frac{\pi}{2}$ 。(答案不唯一)

故填答案: $\frac{\pi}{2}$ (答案不唯一, $2k\pi+\frac{\pi}{2}(k\in\mathbf{Z})$ 中的一个k的值对应的答案即可).

点评:对于此类开放结论的数学开放题,相比常规的破解方法,巧妙借助特殊值的选取,破解起来更为快捷简单,省去三角恒等变换的复杂过程,特殊值易确定,简单易操作.当然此类开放性问题的答案不唯一,借助特殊值的选取只能确定其中一个取值,无法完整解答所有满足条件的常数的取值情况.

# 二、开放条件，层出不穷

开放条件的数学开放题是根据可供选择的条件或按要求完善的条件等,通过题中给出的其他条件联合起来解答相关的问题.破解时要把对应选择的条件或完善的条件作为已知条件之一,合理推理,正确剖析.

例 2 （2020 年北京卷第 17 题）在 $\triangle ABC$ 中， $a + b = 11$ ，再从条件①、条件②这两个条件中选择一个作为已知，求：

(I) $a$ 的值.

(Ⅱ) $\sin C$ 和 $\triangle ABC$ 的面积.

条件 ①: c = 7, $\cos A = -\frac{1}{7}$ ; 条件 ②: $\cos A = \frac{1}{8}$ , $\cos B = \frac{9}{16}$ .

注:如果选择条件①和条件②分别解答,按第一个解答计分.

分析: 若选择条件 ①, 此时一角三边(包括两边之和), 通过余弦定理的转化得到一边的值, 从而得到三边的值; 在此基础上通过三角函数的平方关系以及正弦定理的应用, 即可求解 $\sin C$ 的值, 为进一步求解三角形的面积提供条件; 而若选择条件 ②, 此时两角两边(包括两边之和), 通过三角函数的平方关系以及正弦定理的应用得到一边的值; 在此基础上通过三角恒等变换公式的应用即可求解 $\sin C$ 的值, 为进一步求解三角形的面积提供条件.

解析:选择条件①,解答如下:

（Ⅰ）在 $\triangle ABC$ 中，由于 $a+b=11$ ，则有b=11-

a，又由于 $c = 7$ ， $\cos A = -\frac{1}{7}$ 根据余弦定理 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{(11 - a)^2 + 7^2 - a^2}{2(11 - a)\times 7} = -\frac{1}{7}$ 解得 $a = 8.$

（Ⅱ）在 $\triangle ABC$ 中，由于 $\cos A = -\frac{1}{7}$ ，则有 $\sin A = \sqrt{1 - \cos^2 A} = \frac{4\sqrt{3}}{7}$ ，又由于 $c = 7, a = 8$ ，根据正弦定理 $\frac{a}{\sin A} = \frac{c}{\sin C}$ ，即 $\frac{8}{\frac{4\sqrt{3}}{7}} = \frac{7}{\sin C}$ ，解得 $\sin C = \frac{\sqrt{3}}{2}$ .

又 $b = 11 - a = 3$ ，所以 $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{1}{2}\times$ $8\times 3\times \frac{\sqrt{3}}{2} = 6\sqrt{3}.$

选择条件 ②,解答如下:

（Ⅰ）在 $\triangle ABC$ 中，由于 $\cos A = \frac{1}{8}$ ， $\cos B = \frac{9}{16}$ ，则有 $\sin A = \sqrt{1 - \cos^{2}A} = \frac{3\sqrt{7}}{8}$ ， $\sin B = \sqrt{1 - \cos^{2}B} = \frac{5\sqrt{7}}{16}$ ，又由于 $a + b = 11$ ，则有 b = 11 - a，根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，得 $\frac{a}{\frac{3\sqrt{7}}{8}} = \frac{11 - a}{\frac{5\sqrt{7}}{16}}$ ，解得 a = 6。

（Ⅱ）在 $\triangle ABC$ 中，由（I）得 $a = 6, b = 11 - a = 5$ ，又由于 $A + B + C = \pi$ ，所以 $\sin C = \sin (A + B) = \sin A\cos B + \cos A\sin B = \frac{3\sqrt{7}}{8}\times \frac{9}{16} +\frac{1}{8}\times \frac{5\sqrt{7}}{16} = \frac{\sqrt{7}}{4},$ 所以 $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{1}{2}\times 6\times 5\times \frac{\sqrt{7}}{4} = \frac{15\sqrt{7}}{4}.$

点评:破解此类开放条件的数学开放题,要结合自己所擅长的知识,合理进行选择条件或完善条件,当条件确定后,根据题目信息加以合理应用,正确求解.若条件确定后,分析之后觉得有点困难或无法切入,可考虑改变条件再进行分析与处理.虽然条件是可供选择或自我完善的,但不能频繁地加以改变,有效的考试时间不能随便浪费.

# 三、开放全部，自由飞翔

开放全部的数学开放题是开放条件或结论不明显,通过可供选择的条件或按要求完善的条件等,再来解决一些相关的探究性、存在性等开放问题.破解时经常先对已知条件进行合理分析,结合所推导的结论,综合相应选择的条件或完善的条件等,再作出合理的探究或判断,综合度高,探究性强.

例 3 （2020 年新高考山东卷第 17 题）在 ①ac = $\sqrt{3}$ ，② $c\sin A = 3$ ，③ $c = \sqrt{3}b$ 这三个条件中任选一个，补充在下面问题中，若问题中的三角形存在，求 c 的值；若问题中的三角形不存在，说明理由.

问题:是否存在 $\triangle ABC$ ,它的内角A,B,C的对边分别为a,b,c,且 $\sin A=\sqrt{3}\sin B,C=\frac{\pi}{6}$ ,\_\_\_\_?

注:如果选择多个条件分别解答,按第一个解答计分.

分析:结合题目已有的条件,利用正弦定理进行角化边,得到边a,b之间的比例关系,根据比例关系,再通过余弦定理进行转化,进而确定b、c之间的相等关系,进而确定三角形各角的大小,根据自己选择的条件进行分析判断和求解.

解析: 由 $\sin A = \sqrt{3} \sin B$ 及正弦定理, 可得 $a = \sqrt{3} b$ , 根据余弦定理可得 $c^{2} = a^{2} + b^{2} - 2ab \cos C = 3b^{2} + b^{2} - 2\sqrt{3} b^{2} \times \frac{\sqrt{3}}{2} = b^{2}$ , 即 b = c, 于是 $B = C = \frac{\pi}{6}$ , $A = \frac{2\pi}{3}$ , 若选择 ① $ac = \sqrt{3}$ , 则有 $\left\{\begin{aligned}a &= \sqrt{3} b = \sqrt{3} c, \\ ac &= \sqrt{3},\end{aligned}\right.$ 解得 c = 1, 所以这样的 $\triangle ABC$ 存在, 且 c = 1.

若选择 ② $c\sin A=3$ ，由 $A=\frac{2\pi}{3}$ 解得 $c=2\sqrt{3}$ ，所以这样的 $\triangle ABC$ 存在，且 $c=2\sqrt{3}$ .

若选择 ③ $c=\sqrt{3}b$ ，这与 b=c 矛盾，所以这样的 $\triangle ABC$ 不存在.

点评:处理此类开放全部的数学开放题,要有效综合已知条件所推导出来的结论,综合相应选择的条件或完善的条件等进行综合与应用.此类问题是在对已知条件所推导出来的结论进行合理分析,有针对性地选择相应的条件,为进一步的探究与应用提供动力,从而得以合理推理,正确探究.

数学开放题的解答能够帮助教师有效地关注到学生的学习过程与思维过程. 重视学生的主体性作用, 教师应引导学生在解题过程中不断反思, 可以培养学生勤于思考、善于思考的习惯, 提高学生的数学情趣和学习积极性, 形成克服困难的毅力等良好品质, 提升数学建模能力、逐步形成创新意识. 数学开放题要求教师在教学过程中重视教学的整体性与思考性, 强调解决问题的过程(思路与策略) 而不单单是问题的答案. F
