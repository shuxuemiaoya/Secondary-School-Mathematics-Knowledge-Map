中学数学教材中的例题或习题经常出现一些二级结论,虽然这些结论不是教材指定的定理或性质,但对我们启迪思维大有帮助,尤其是在解答选择题或填空题时能帮助我们大大提高解题效率.本文列举解三角形中的一个二级结论加以说明.

结论 在斜 $\triangle ABC$ 中,求证:

$$
\tan A + \tan B + \tan C = \tan A \tan B \tan C.
$$

证明 因为 $\tan(A+B)=\frac{\tan A+\tan B}{1-\tan A\cdot\tan B}$ ，所以

$\tan A + \tan B = \tan(A + B)(1 - \tan A \tan B)$ ,
又 $\tan(A+B)=\tan(\pi-C)=-\tan C$ ，所以

$$
\tan A + \tan B + \tan C =
$$

$$
\tan (A + B) (1 - \tan A \tan B) + \tan C =
$$

$$
- \tan C (1 - \tan A \tan B) + \tan C = - \tan C +
$$

$$
\tan A \tan B \tan C + \tan C = \tan A \tan B \tan C.
$$

该结论告诉我们,在斜三角形中,三个内角的正切值之和与正切值之积是相等的,这个结论对我们解相关的题目有很大的帮助.

# 1 判断三角形的形状

在三角形中最多有 1 个钝角,于是根据 $\tan A \cdot \tan B \tan C$ 的正负,可以判断该三角形是锐角三角形还是钝角三角形.

![](images/22590ece2f292c68fae575e2855b77cfb9f622e4d971a2e96a1588ff3ea09b47.jpg)

例 1 （多选题）在 $\triangle ABC$ 中，角 A, B, C 所对的边分别为 $a, b, c$ ，则下列结论正确的是（ ）.

A. 若 $\sin A > \sin B$ ，则 $A > B$   
B. 若 $\triangle ABC$ 为锐角三角形, 则 $\sin A > \cos B$   
C. 若 $a \cos B - b \cos A = c$ ，则 $\triangle ABC$ 一定为直角三角形  
D. 若 $\tan A + \tan B + \tan C > 0$ ，则 $\triangle ABC$ 可以是钝角三角形

![](images/ad9544ed612e0bd2662794856d6b94e367931b834bafc69378cab4f0f586e31f.jpg)

析

对于 A, 因为 $\sin A > \sin B$ , 所以由正弦定理可知 $a > b$ ，又在三角形中大角对大边，所以A>B, 故 A 正确.

对于 B, 因为 $\triangle ABC$ 为锐角三角形, 所以 A +

$B = \pi - C > \frac{\pi}{2}$ , 即 $A > \frac{\pi}{2} - B$ , 则 $\sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B$ , 故 B 正确.

对于 C, 由正弦定理可得 $\sin C = \sin A \cos B - \sin B \cos A = \sin (A - B)$ ，则 $C + A - B = \pi$ （舍）或 C = A - B，所以 $A = B + C = \pi - A$ ，即 $A = \frac{\pi}{2}$ ，则 $\triangle ABC$ 一定为直角三角形，故 C 正确.

对于 D, 由二级结论可知 $\tan A + \tan B + \tan C = \tan A \tan B \tan C > 0$ , 又因为最多只有 1 个角为钝角, 所以 $\tan A > 0, \tan B > 0, \tan C > 0$ , 即 3 个角都为锐角, 从而 $\triangle ABC$ 为锐角三角形, 故 D 错误.

综上,选 ABC.

![](images/d6e5518ef5306bac835ccb027cc8d891c7a26547be9e25d8723803a8f007b587.jpg)

点评

由二级结论 $\tan A + \tan B + \tan C = \tan A \cdot$

$\tan B\tan C$ , 可知当 $\tan A + \tan B + \tan C$ 的值为正时, $\triangle ABC$ 为锐角三角形;当 $\tan A+\tan B+\tan C$ 的值为负时, $\triangle ABC$ 为钝角三角形.

# 2 对照二级结论求角

当题目中出现与二级结论相似的等式时,只需与这个二级结论对照,就可求出相应的角.

例 2 (1) 在 $\triangle ABC$ 中, $\tan A + \tan B + \tan C =$ $\tan B\tan C$ ，则 $\frac{B + C}{A} =$

(2) 在 $\triangle ABC$ 中, 三个内角 $A, B, C$ 满足 $A > B > C$ , 且 $\tan A, \tan B, \tan C$ 的数值都是整数, 则 $\tan A = \_$ .

![](images/987eaeb0f307af0289d1ffc57563b054050b7a5289d6c035cf140636facbec58.jpg)

析

(1) 因为 $\tan A \tan B \tan C = \tan A + \tan B +$ $\tan C$ ，而 $\tan A + \tan B + \tan C = \tan B\cdot$ $\tan C$ ，所以 $\tan A = 1.$ 又 $A\in (0,\pi)$ ，所以 $A = \frac{\pi}{4}$ ，则

$$
B + C = \pi - A = \frac {3 \pi}{4}, \text {故} \frac {B + C}{A} = 3.
$$

(2) 当 $A < 90^{\circ}$ 时, 由 A > B > C, 可得 $\tan A > \tan B > \tan C > 0$ , 所以

$\tan A + \tan B + \tan C = \tan A\tan B\tan C <   3\tan A$ 即 $\tan B\tan C <   3.$ 因为 $\tan B,\tan C$ 的值都是整数，所以 $\tan B = 2,\tan C = 1$ ，则 $\tan A = 3.$ 当 $A > 90^{\circ}$ 时，由

$$
\begin{array}{l} \tan A = \tan [ \pi - (B + C) ] = - \tan (B + C) = \\ - \frac {\tan B + \tan C}{1 - \tan B \tan C} <   0, \\ \end{array}
$$

可得 $1 - \tan B\tan C > 0$ ，即 $\tan B\tan C < 1.$ 因为 $\tan B,\tan C$ 的值都是整数，此时无解，则 $\tan A = 3.$

![](images/e42c3795f74356d4db4636f70f57ebeb5361213453f39241a6b714581ea3daa5.jpg)

在斜 $\triangle ABC$ 中， $\tan A + \tan B + \tan C = \tan A \tan B \tan C$ 是个恒等式，在求三角形内角的正切值时,通常可以把它当成一个“隐形”的方程,求解相关问题时,可采依据已知条件,利用方程思想求出有关的角.

# 3 求最值

因为二级结论 $\tan A + \tan B + \tan C = \tan A \cdot \tan B \tan C$ 中出现 $\tan A \tan B \tan C, \tan A + \tan B + \tan C$ , 所以这个结论可以起到消元或整体代换的作用.

![](images/a5386d497e54038c11d3f8bcf0063eb7aa777f4c9035205656bafaba9ed4730a.jpg)

例 3 在锐角 $\triangle ABC$ 中, 若 $\sin A = 2\sin B\sin C$ .

(1)求 $\frac{1}{\tan B}+\frac{1}{\tan C}$ 的值；  
(2) 求 $\tan A \tan B \tan C$ 的最小值.

![](images/b155758fa7c0caa0ff12f807d5b7e5f18d50fcaa46375ed09006b636b48a5e22.jpg)

(1)在 $\triangle ABC$ 中，有 $\sin A = \sin [\pi - (B + C)] = \sin (B + C) = \sin B\cos C + \cos B\cdot$

$\sin C$ ，于是由 $\sin A = 2\sin B\sin C$ ，可得

$$
\sin B \cos C + \cos B \sin C = 2 \sin B \sin C. \tag {①}
$$

又 $\triangle ABC$ 是锐角三角形，所以 $\cos C > 0, \cos B > 0$ 。在①两边同时除以 $\cos C\cos B$ ，可得

$$
\tan B + \tan C = 2 \tan B \tan C,
$$

则 $\frac{1}{\tan B}+\frac{1}{\tan C}=2.$

(2) 又 $\tan A = -\tan [\pi - (B + C)] = -\tan (B + C) = -\frac{\tan B + \tan C}{1 - \tan B \tan C}$ , 则

$\tan A\tan B\tan C=\tan A+\tan B+\tan C,$

且 $\tan A > 0, \tan B > 0, \tan C > 0$ ，结合(1)可得

$$
\tan A + \tan B + \tan C = \tan A + 2 \tan B \tan C \geqslant
$$

$$
2 \sqrt {2 \tan A \tan B \tan C},
$$

所以 $\tan A \tan B \tan C \geqslant 8$ ，当且仅当 $\tan A = 2 \tan B \cdot \tan C$ 时，等号成立，故 $\tan A \tan B \tan C$ 的最小值

为8.

![](images/e3dc92390d3524a5bf22c3e254e98f5e5503e391233887bd4f9a2b2a098c56b8.jpg)

点评

本例属于解答题,所以二级结论不可以直接应用,需加以证明,否则考试时会扣分.

例 4 在锐角 $\triangle ABC$ 中, 角 A, B, C 所对的边分 a, b, c, 若 $c = 3b \sin A$ , 则 $\tan A + \tan B + \tan C$ 小值是 \_\_\_\_.

![](images/5277acd44fd6e5480d58ff81deb6d1ee02e93edbe12d66c50a24393fd7214b22.jpg)

析

由正弦定理可得 $\sin C = 3\sin B\sin A$ ，故

$$
\sin (A + B) = \sin A \cos B + \cos A \sin B =
$$

$$
3 \sin B \sin A,
$$

所以 $\frac{\sin A\cos B + \cos A\sin B}{\cos A\cos B} = \frac{3\sin B\sin A}{\cos A\cos B}$ 即

$$
\tan A + \tan B = 3 \tan A \tan B.
$$

又

$$
\tan A + \tan B + \tan C = \tan A \tan B \tan C =
$$

$$
- \tan A \tan B \tan (A + B) =
$$

$$
- \tan A \tan B \frac {\tan A + \tan B}{1 - \tan A \tan B} = \frac {- 3 \tan^ {2} A \tan^ {2} B}{1 - \tan A \tan B},
$$

令 $\tan A\tan B = t$ ，则

$$
\tan A + \tan B + \tan C = \frac {3 t ^ {2}}{t - 1} =
$$

$$
\frac {3 (t - 1) ^ {2} + 6 (t - 1) + 3}{t - 1} = 3 (t - 1) + \frac {3}{t - 1} + 6.
$$

因为 $\triangle ABC$ 为锐角三角形, 所以 $-\tan C = \tan (A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B} < 0$ , 则 $\tan A\tan B > 1$ , 即 $t > 1$ , 所以 $t - 1 > 0$ , 故

$$
\tan A + \tan B + \tan C = 3 (t - 1) + \frac {3}{t - 1} + 6 \geqslant
$$

$$
2 \sqrt {3 (t - 1) \cdot \frac {3}{t - 1}} + 6 = 1 2,
$$

当且仅当 $3(t-1)=\frac{3}{t-1}$ ，即 $t=\tan A\tan B=2$ 时，
等号成立，所以

$$
(\tan A + \tan B + \tan C) _ {\min} = 1 2.
$$

![](images/5e19239838fcd2c479d05bf5100cfbb806bbfa7457d9d00302e6cb804f220d24.jpg)

点评

本题考查正弦定理、两角和差正切公式、基本不等式的应用，解题关键是能够将所求式

子利用两角和差正切公式进行化简,进而采用换元法将原问题转化为函数的最值问题.

综上所述,二级结论在数学解题中应用广泛.因此,在数学学习中,我们应该意识到知识在于积累,只有具备充裕的知识储备,才能让知识融会贯通,才能让二级结论发挥作用.
