# 1 含单角三角函数的最值问题

含单角三角函数的最值问题是三角函数最值问题中较为基础的一类,通常可以利用三角函数的有界性或通过配方等方法求解.

# 1.1 利用正弦、余弦函数的有界性

正弦函数 $y=\sin x$ 和余弦函数 $y=\cos x$ 的值域均为 $[-1,1]$ ，这一有界性是解决许多三角函数最值问题的关键.

例 1 求函数 $y = 2 \sin x + 3$ 的最大值和最小值.

解析 因为 $\sin x$ 的取值范围是 $[-1,1]$ ，所以当 $\sin x = 1$ 时，y 取得最大值， $y_{\max} = 2 \times 1 + 3 = 5$ ；当 $\sin x = -1$ 时，y 取得最小值， $y_{\min} = 2 \times (-1) + 3 = 1$ .

# 1.2 二次函数型的三角函数最值问题

对于形如 $y = a\sin^2 x + b\sin x + c$ 或 $y = a\cos^2 x + c$ $b\cos x + c (a \neq 0)$ 的函数, 可以通过换元法将其转化为二次函数, 再利用二次函数的性质求解最值.

例2 求函数 $y = 2\cos^2 x + 2\cos x - 1$ 在 $x \in [0, \pi]$ 上的最值.

解析 因为 $x \in [0, \pi]$ , 所以 $\cos x \in [-1, 1]$ .

令 $t = \cos x$ ，则 $t\in [-1,1]$ ，原函数变为 $y = 2t^2 +2t - 1.$

此二次函数对称轴为 $t = -\frac{2}{2 \times 2} = -\frac{1}{2}$ ，开口向上，

则在区间 $\left[-1, -\frac{1}{2}\right]$ 上，函数单调递减；

在 $\left[-\frac{1}{2},1\right]$ 上，函数单调递增.

$$
\begin{array}{c} {\text {当} t = - \frac {1}{2} \text {时}, y _ {\min} = 2 \times \left(- \frac {1}{2}\right) ^ {2} + 2 \times \left(- \frac {1}{2}\right) -} \\ {1 = 2 \times \frac {1}{4} - 1 - 1 = \frac {1}{2} - 2 = - \frac {3}{2};} \end{array}
$$

当 t=1 时， $y=2\times1^{2}+2\times1-1=2+2-1=$ 3;

当 t = -1 时， $y = 2 \times (-1)^{2} + 2 \times (-1) - 1 = 2 - 2 - 1 = -1.$

所以函数的最大值为 3, 最小值为 $-\frac{3}{2}$ .

小结 含单角三角函数的最值问题需先判断类型.一次函数型可依托正弦、余弦函数取值范围，根据三角函数系数正负确定最值对应关系：系数为正，三角函数最值与函数最值一致；系数为负，则相反.二次函数型可通过换元将三角函数转为新变量，其取值范围由原三角函数确定，转化后分析二次函数对称轴与新变量范围的位置关系，对称轴在范围内时，一最值在对称轴处，另一个在端点；对称轴在范围外时，函数单调，最值在两端点.

# 2 含多角三角函数的最值问题

含多角三角函数的最值问题相对复杂,需要利用三角函数的两角和与差公式、二倍角公式等进行化简,再求解最值.

# 2.1 利用二倍角公式化简

例 3 求函数 $y = \sin x \cos x + \sin^{2} x$ 的最值.

解析 利用二倍角公式 $\sin 2x = 2\sin x\cos x$ ，即 $\sin x\cos x = \frac{1}{2}\sin 2x;\sin^2 x = \frac{1 - \cos 2x}{2}$ .则原函数可化简为： $y = \frac{1}{2}\sin 2x + \frac{1 - \cos 2x}{2} = \frac{1}{2}\sin 2x-$ $\frac{1}{2}\cos 2x + \frac{1}{2}$ ，再根据辅助角公式 $a\sin \alpha +b\cos \alpha =$ $\sqrt{a^2 + b^2}\sin (\alpha +\varphi)\left(\text{其中}\tan \varphi = \frac{b}{a}\right)$ 对其进一步化简： $y = \frac{\sqrt{2}}{2}\sin \left(2x - \frac{\pi}{4}\right) + \frac{1}{2},$ 因为 $\sin \left(2x - \frac{\pi}{4}\right)\in [-1,1]$ ，所以 $\frac{\sqrt{2}}{2}\sin \left(2x - \frac{\pi}{4}\right)\in$ $\left[-\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2}\right]$ ，则 $y\in \left[\frac{1 - \sqrt{2}}{2},\frac{1 + \sqrt{2}}{2}\right].$

因此，函数的最大值为 $\frac{1 + \sqrt{2}}{2}$ ，最小值为 $\frac{1 - \sqrt{2}}{2}$ .

# 2.2 利用两角和与差公式化简

例4 求函数 $y = \sin x + \cos \left(x + \frac{\pi}{6}\right)$ 的最大值.

解析 根据两角和的余弦公式 $\cos(A+B)=\cos A\cos B-\sin A\sin B$ ，将 $\cos\left(x+\frac{\pi}{6}\right)$ 展开，即 $\cos\left(x+\frac{\pi}{6}\right)=\cos x\cos\frac{\pi}{6}-\sin x\sin\frac{\pi}{6}=\frac{\sqrt{3}}{2}\cos x-\frac{1}{2}\sin x$ ，则原函数 $y=\sin x+\frac{\sqrt{3}}{2}\cos x-\frac{1}{2}\sin x=\frac{1}{2}\sin x+\frac{\sqrt{3}}{2}\cos x$ ，又由辅助角公式可得 $y=\sin\left(x+\frac{\pi}{3}\right)$ ，因为 $\sin\left(x+\frac{\pi}{3}\right)$ 的最大值为 1，所以函数 y 的最大值为 1.

小结 含多角三角函数的最值问题,先选合适公式进行化简,依据角的关系用二倍角、两角和与差等公式将多角转化为单角形式,过程中注意角的合并与函数名称统一,再参照单角问题解法结合有界性或辅助角公式求最值.

# 3 复合三角函数的最值问题

复合三角函数通常是由三角函数与其他函数复合而成,如与指数函数、对数函数等复合,解决这类问题需要综合考虑内外层函数的性质.

例 5 求函数 $y=\log_{\frac{1}{2}}(\cos x+2)$ 的最值.

解析 令 $t = \cos x + 2$ ，因为 $\cos x \in [-1, 1]$ ，所以 $t \in [1, 3]$ 。又因为对数函数 $y = \log_{\frac{1}{2}} t$ 在 $(0, +\infty)$ 上单调递减，则当 $t = 1$ 时， $y_{\max} = \log_{\frac{1}{2}} 1 = 0$ ；当 $t = 3$ 时， $y_{\min} = \log_{\frac{1}{2}} 3 = -\log_2 3$ 。

小结 复合三角函数的最值问题,先明确内外层函数,内层多为三角函数,外层可为指数、对数等函数,确定内层取值范围后分析外层在该范围内的单调性,外层单调递增时,复合函数最值与内层一致;外层单调递减时,则相反.

# 4 易错点分析

（1）换元法中易忽略新元的取值范围.此种情况常见于二次函数型问题.换元后，忽略新元的取值范围受原三角函数的约束，直接按照二次函数在全体实数上的最值求解，会得出与实际不符的结果.(2）公式记忆错误.运用三角函数公式化简时，对公式的结构、符号等记忆出现偏差.(3）运算失误.包括在展开、合并同类项等步骤中出现计算错误.(4)处理复合函数时，判断内外层函数单调性容易出现偏差.

# 5 结语

总之,三角函数的最值问题是学生必须掌握的一类题型.在解题教学过程中,教师要引导学生选择正确的解题方法,对求各类三角函数最值问题做到熟能生巧,进而提高解题效率和数学素养.
