# 1 引言

在高考数学中,极值点偏移问题作为导数综合应用的难点,常以高难度压轴题形式出现.比值代换法作为解决此类问题的有力工具,能够突破复杂问题的表象,找到解题关键.

# 2 比值代换法解答极值点偏移问题(一题多解)

例题 已知函数 $f(x) = \mathrm{e}^{x - a} - \frac{1}{2} (x - a)^2 - \ln (x - a + 1) (a \in \mathbb{R})$ ，若存在 $x_1, x_2 (x_1 < x_2)$ ，满足 $f(x_1) + f(x_2) = 2$ ，且 $x_1 + x_2 - 2a < \frac{2}{x_1 - a + 1} + \frac{2}{x_2 - a + 1}$ ，证明： $(x_1 - a)(x_2 - a) < 1$ .

# 解题指导 方法 1

令 $m = x_{1} - a, n = x_{2} - a, g(t) = e^{t} - \frac{1}{2} t^{2} - \ln(t + 1)$ ，且 $g(m) + g(n) = 2, m + n < \frac{2}{m + 1} + \frac{2}{n + 1}$ ，要证 mn < 1。求导得 $g'(t) = e^{t} - t - \frac{1}{t + 1}$ ，再次求导得 $g''(t) = e^{t} - 1 + \frac{1}{(t + 1)^{2}}$ 。

因为 t > -1 时， $e^{t} > 0, -1 + \frac{1}{(t+1)^{2}} > -1$ ,

所以 $g''(t) > 0, g'(t)$ 在 $(-1, +\infty)$ 上单调递增.

又 $g'(0)=\mathrm{e}^{0}-0-\frac{1}{0+1}=0,$

所以当-1<t<0时, $g'(t)<0$ , $g(t)$ 单调递减；

当 t > 0 时， $g'(t) > 0$ ， $g(t)$ 单调递增， $g(t)$ 在 t = 0 处取得极小值，

由 $g(m)+g(n)=2$ , $g(0)=1$ , 不妨设 -1 < m < 0 < n,

所以 $g(m) > g(0) = 1, g(n) = 2 - g(m) < 1 = g(0)$ .

比值代换法 设 $t = \frac{n}{m} (t < -1)$ ，由单调性可知 $n > -m$ ，两边同时除以 $m(m < 0)$ ，得 $\frac{n}{m} < -1$ ，即 $t = \frac{n}{m} < -1$ 。则 $n = mt$ 。将 $n = mt$ 代入 $g(m) + g(n) = 2$ 可得： $g(m) + g(mt) = e^m - \frac{1}{2} m^2 - \ln(m + 1) + e^{mt} - \frac{1}{2}(mt)^2 - \ln(mt + 1) = 2$ 。证 $m^2 t < 1$ 。由 $g(m) + g(n) = 2$ ，进行变形： $e^m (1 + e^{m(t-1)}) - \frac{1}{2} m^2 (1 + t^2) - \ln(m^2(t + 1) + m(t + 1)) = 2$ 。

构造函数 $h(t)=\mathrm{e}^{m}(1+\mathrm{e}^{m(t-1)})-\frac{1}{2}m^{2}(1+t^{2})-\ln(m^{2}(t+1)+m(t+1))-2$ ，求导得 $h'(t)=m\mathrm{e}^{m}\mathrm{e}^{m(t-1)}-m^{2}t-\frac{m^{2}+m}{m^{2}(t+1)+m(t+1)}$ .

因为 $-1 < m < 0, t < -1$ ，分析 $h'(t)$ 的正负性： $m \mathrm{e}^{m} \mathrm{e}^{m(t-1)} < 0, -m^{2} t > 0, -\frac{m^{2} + m}{m^{2}(t+1) + m(t+1)} > 0$ ，进一步分析可得 $h'(t) < 0$ ，所以 $h(t)$ 在 $(- \infty, -1)$ 上单调递减。又因为当 $t \to -1$ 时，$h(t) \rightarrow +\infty$ ，所以 $h(t) > 0$ ，即 $\mathrm{e}^{m}(1 + \mathrm{e}^{m(t-1)}) - \frac{1}{2} m^{2}(1 + t^{2}) - \ln(m^{2}(t+1) + m(t+1)) > 2.$

而 $\mathrm{e}^{m}(1 + \mathrm{e}^{m(t - 1)}) - \frac{1}{2} m^{2}(1 + t^{2}) -$ $\ln (m^2 (t + 1) + m(t + 1)) = 2$ 时， $t <   - 1$ ，所以 $m^2 t$ $<  1$ ，即 $mn <   1$ ，故 $(x_{1} - a)(x_{2} - a) <   1$ 得证.

# 方法 2

令 m = x - a，则 $y = e^{m} - \frac{1}{2} m^{2} - \ln(m + 1)$ .
已知 $g(m)+g(n)=2, g(0)=1$ ，可变形为 $g(m)-1+g(n)-1=0$ ，即 $g(m)-g(0)+g(n)-g(0)=0$ ．考虑函数 $y=g(m)$ 与 $y=g(-m)$ ，对 $g(-m)$ 求导: $g'(-m)=-\mathrm{e}^{-m}+m-\frac{1}{-m+1}$

则 $g(m)+g(-m)=\mathrm{e}^{m}-\frac{1}{2}m^{2}-\ln(m+1)+$ $e^{-m}-\frac{1}{2}m^{2}-\ln(-m+1)=\mathrm{e}^{m}+\mathrm{e}^{-m}-m^{2}-\ln(1-m^{2})$ ,

令 $F(m)=\mathrm{e}^{m}+\mathrm{e}^{-m}-m^{2}-\ln(1-m^{2})$ , $(-1<m<1)$ ，对 $F(m)$ 求导：

$$
F ^ {\prime} (m) = \mathrm{e} ^ {m} - \mathrm{e} ^ {- m} + \frac {2 m ^ {3}}{(1 - m) (1 + m)}.
$$

当 -1 < m < 0 时, $e^{m} - e^{-m} < 0$ , $\frac{2m^{3}}{(1-m)(1+m)} < 0$ , 所以 $F'(m) < 0$ , $F(m)$ 单调递减；当 0 < m < 1 时, $e^{m} - e^{-m} > 0$ , $\frac{2m^{3}}{(1-m)(1+m)} > 0$ , 所以 $F'(m) > 0$ , $F(m)$ 单调递增, $F(m) \geqslant F(0) = 2$ , 即 $g(m) + g(-m) \geqslant 2$ , 当且仅当 m = 0 时等号成立.

因为 $g(m)+g(n)=2$ ，且 -1<m<0<n，所以 n>-m。

比值代换法 设 $t = \frac{n}{m} (t < -1)$ ，则 $n = mt$ ， $mt > -m$ ，因为 $m < 0$ ，两边同时除以 $m$ 得 $t < -1$ .证 $m^{2}t<1$ ，因为 $m^{2}>0$ ，所以只需证 $t<\frac{1}{m^{2}}$ 。由 $m+n<\frac{2}{m+1}+\frac{2}{n+1}$ ，将 n=mt 代入并化简： $m(1+t)(m^{2}t+m+mt+1)-2(mt+1)-2(m+1)<0.$

构造函数 $\varphi(t)=m(1+t)(m^{2}t+m+mt+1)-2(mt+1)-2(m+1)$ ，对 $\varphi(t)$ 求导： $\varphi'(t)=2m^{3}t+2m^{2}t+m^{3}+3m^{2}-m$ .

因为-1<m<0,t<-1,分析 $\varphi^{\prime}(t):2m^{3}t>0,2m^{2}t<0,m^{3}<0,3m^{2}>0,-m>0$ ,进一步分析可得 $\varphi^{\prime}(t)<0$ ,所以 $\varphi(t)$ 在 $(-∞,-1)$ 上单调递减.

又因为当 $t \to -1$ 时， $\varphi(t) \to +\infty$ ，所以 $\varphi(t) > 0$ ，即 $m(1+t)(m^2 t+m+mt+1)-2(mt+1)-2(m+1)>0$ ，整理可得 $t < \frac{1}{m^2}$ ，所以 $m^2 t < 1$ ，即 $(x_1-a)(x_2-a)<1$ 得证.

解后反思 比值代换法是解决含双变量不等式问题的常用方法,核心是通过引入比值参数将双变量转化为单变量函数问题.具体步骤为:先识别适用题型(含双变量且结构具有对称性或可变形为含比值/差值的不等式),再设定比值参数,接着构造关于t的单变量函数,最后通过求导分析函数的单调性、极值等性质证明不等式.运用这一方法时需注意变量范围、不等式对称性变形,灵活选择代换方式并结合其他方法.该方法能有效将双变量问题转化为单变量函数的导数问题,是处理对称型不等式的重要手段.

# 3 结语

高难度的极值点偏移问题虽然复杂,但通过比值代换法,结合对函数性质的深入分析,仍能够找到解题的突破口.通过对多种解法的探讨,可以更深入地理解比值代换法的应用技巧和本质内涵.
