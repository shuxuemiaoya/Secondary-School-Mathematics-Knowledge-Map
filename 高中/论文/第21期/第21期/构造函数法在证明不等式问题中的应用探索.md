# 2 构造函数解决不等式证明问题

# 2.1 移项法构造函数

有时函数不等式的两侧含有多个单项式,此时需将不等式两侧的式子移项,并将一侧或两侧的式子视为函数式,使其变形为 $f(x) > 0$ 、 $f(x) < 0$ 、 $f(x) > g(x)$ 、 $f(x) < g(x)$ ,接着通过分析所构造函数的单调性、极值等性质来证明不等式成立.

例 1 已知函数 $f(x)=\ln(x+1)-x$ ，求证：
当 x > -1 时，恒有 $1 - \frac{1}{x + 1} \leqslant \ln(x + 1) \leqslant x$ .

分析 本题是双边不等式,其右边直接从已知函数证明, 左边构造函数 $g(x)=\ln(x+1)+\frac{1}{x+1}-1$ , 从其导数入手即可证明. 此外, 如果 $f(a)$ 是函数 $f(x)$ 在区间上的最大 (小) 值, 则有 $f(x)\leqslant f(a)(f(x)\geqslant f(a))$ , 只要证函数的最大值不超过 0 就可得证.

小结 该方法适用于结构清晰、变量单一且移项后函数易于求导分析的问题,若移项后函数过于复杂,求导分析难度会显著增大,需结合其他方法辅助解决.对于多变量不等式或隐式结构,移项构造法往往难以直接应用,则需结合比值换元或主元化等策略转化后再应用.

# 2.2 换元法构造函数

对于含有两个变量的函数不等式问题,通常需引入新变量,用其替换问题中具有特定关联的变量,将双变量问题转化为单变量问题来处理,达到消元、简化结构的效果,进而构造出单变量新函数.

例 2 已知函数 $f(x)=\mathrm{e}^{x}-\frac{1}{2}ax^{2}+1$ 有两个极值点 $x_{1}, x_{2}$ ，求证： $\frac{x_{1}+x_{2}}{2}<\ln a$ .

分析 本题根据已知条件 $\mathrm{e}^{x_1} - ax_1 = \mathrm{e}^{x_2} - ax_2 = 0$ ，由此得到 $a = \frac{\mathrm{e}^{x_1} - \mathrm{e}^{x_2}}{x_1 - x_2}$ ，结合已知不等式利用差值换元构造新函数，最后通过分析法寻求不等式成立的等价条件.

例 3 若 $x_{1}, x_{2} > 0$ ，且 $x_{1} < x_{2}$ ，求证： $(\ln x_{1} - \ln x_{2})(x_{1} + 2x_{2}) \leqslant 3(x_{1} - x_{2})$ .

分析 这道题目的关键在于通过巧妙的比值换元, 将含有两个变量 $x_{1}$ 和 $x_{2}$ 的不等式转化为只含有一个变量 t 的不等式, 即令 $t = \frac{x_{1}}{x_{2}}$ , 将原问题构造成单变量函数 $f(t)$ , 利用函数的单调性来证明不等式.

小结 利用换元法构造函数适用于当不等式中存在多个变量,且这些变量之间存在明确的比例关系或其他可转化的关系;其次当函数表达式较为复杂但有规律时,经过换元能呈现出更简洁的函数形式,从而便于利用已知函数的性质来解决问题.但并非所有不等式都能进行换元,部分不等式中的变量关系复杂且无明显规律,强行换元可能会使问题更复杂.与此同时,在换元过程中变量的取值范围会发生变化,若处理不当易导致结果错误,因此对新变量的取值范围要严格把控.

# 2.3 利用同构式构造函数

利用同构式构造函数即观察所要比较的各个函数式的结构特征,先找出它们的相同结构和差异部分,对结构存在差异的函数式进行适当变形,转化为结构相同、形式相似的同构式,再根据同构式的结构特征构造出与之相应的函数模型,最后通过分析该函数的单调性对原不等式中的量进行比较.

# 2.3.1 指对同构

此类同构式最基础的形式为 $x = a^{\log_{a}^{x}} = \log_{a}^{a^{x}}$ ，变形后，令 a = e，有 $x = e^{\ln x} = \ln e^{x}$ ，这便是指对同构中的两个最常用的形式。其他的常用形式有 $x e^{x}$ 和 $x \ln x$ ，即 $x e^{x} = e^{\ln x + x}, x \ln x = (\ln x) e^{\ln x}$ ；还有 $x + e^{x}$ 和 $x + \ln x$ ，即 $x + e^{x} = e^{\ln x} + e^{x}, x + \ln x = e^{\ln x} + \ln x$ 。

例 4 证明: 当 x > 0 时, $\ln(x + 1) > \frac{x^{2}}{\mathrm{e}^{x} - 1}$ .

分析 观察题目中给出的不等式右侧出现了 $x^{2}$ , 想要进行指对同构首先要考虑将 $x^{2}$ 拆分到不等式的两侧, 不等式左侧得到 $\frac{\ln(x + 1)}{x}$ , 将其视为最终要同构的函数, 则需要将不等式右侧的分母 $\mathrm{e}^{x} - 1$ 视为一个整体, 并将分子 $x$ 转化为对数的形式, 经过整理后原不等式转化为了同构型不等式, 再将不等式两侧构造为新函数即可得证.

# 2.3.2 朗博同构

所谓“朗博同构”，通常是指借助切线不等式 $e^{x}\geqslant x+1,e^{x}\geqslant ex,\ln x\leqslant x-1,\ln x\leqslant\frac{x}{e}$ 等，对常见同构式进行变形的一种方式.例如， $x\mathrm{e}^{x}=\mathrm{e}^{x+\ln x}$

$$
\geqslant x + \ln x + 1, x + \ln x = \ln (x \mathrm{e} ^ {x}) \leqslant x \mathrm{e} ^ {x} - 1 \text {等}.
$$

例 5 证明: $x - x \ln x \leqslant e^{-x} + x^{2}$ .

分析 通过观察已知不等式可以发现如果想构造朗博同构的形式,那么不等式右侧的 $e^{-x}$ 就不能单独出现,因此不等式两侧同除 x,利用对数恒等式得到 $\frac{e^{-x}}{e^{\ln x}}$ ,整理后得到朗博同构的形式,结合指数切线放缩来构造函数,即可证明原不等式成立.

小结 利用同构式构造函数适用于当不等式两边的式子结构相似或具有对称结构时,可通过变形化为同一函数形式,且有些不等式虽不直接呈现同构特征,但经过对数、指数运算等变形后可化为同构式.其局限性在于,构造同构式需要较高的结构分析技巧和细节观察力,其次对于多变量或复杂结构,难以通过单一同构式构造函数解决.

# 3 结语

在不等式证明的问题中,构造函数法是一种极具灵活性和创造性的工具.通过移项法可以将复杂的不等式转化为易于分析的函数形式;换元法则通过变量替换来简化问题结构;此外,利用同构式构造函数则通过挖掘式子的相似结构,可以将问题转化为已知函数模型.这些方法不仅丰富了不等式证明的理论体系,也为解决实际问题提供了多样化的思路,但需要注意根据不同的题型和题目要求选取合适的方法构造函数.未来,随着对不等式研究的深入,将进一步拓展构造函数法在不等式证明中的应用场景,为数学问题的解决注入更多创新与活力.
