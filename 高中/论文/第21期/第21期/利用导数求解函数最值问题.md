# 1 导数与函数极值的基本关系

# 1.1 导数的几何意义

导数的本质是精准刻画函数在某一点处的瞬时变化率. 从几何视角来看, 它对应的是函数图象在该特定点处的切线斜率. 当函数图象在某点处的切线斜率为零时, 意味着函数在这一点附近的变化趋势出现了特殊情况, 函数可能正处于“峰顶”位置, 即函数值在此处达到局部的最大值; 或者处于“谷底”位置, 也就是函数值在此处达到局部的最小值, 这样的点我们称之为极值点. 这一几何特性为我们探寻函数的极值提供了极为直观且重要的依据, 使我们能够借助函数图象的切线情况, 初步判断函数可能存在的极值的位置.

# 1.2 极值的必要条件

若函数在某一点处可导并且在该点取得极值，那么必然有该点处的导数为零，这一重要条件被命名为“费马定理”。它明确指出，函数的极值点必定是驻点（也称作临界点）。然而，需要特别注意的是，虽然极值点一定是驻点，但驻点却不一定就是极值点。若函数 $y = x^{3}$ ，对其求导可得 $y' = 3x^{2}$ ，当 x = 0 时， $y' = 0$ ，即 x = 0 是驻点，但在 x = 0 的两侧，导数 $y'$ 的符号均为正，函数单调递增，所以 x = 0 并非极值点。这提醒我们在利用驻点寻找极值点时，不能仅仅依据导数为零就轻易判定该点为极值点，还需要进一步深入分析。

# 1.3 极值的充分条件

一阶导数检验法:若函数上的某点 $x_{0}$ 的两侧,导数的符号发生明显改变,那么 $x_{0}$ 即为函数的极值点. 具体来说, 如果在 $x_{0}$ 的左侧导数为正, 右侧导数为负, 这表明函数在 $x_{0}$ 左侧单调递增, 右侧单调递减, 所以 $x_{0}$ 为极大值点; 反之, 如果在 $x_{0}$ 的左侧导数为负, 右侧导数为正, 即函数在 $x_{0}$ 左侧单调递减, 右侧单调递增, 那么 $x_{0}$ 为极小值点.

# 2 闭区间上连续函数的最值求解

在实际的数学问题以及众多实际应用场景中，函数常常被定义在一个闭区间 $[a,b]$ 上.根据极值定理，在闭区间上的连续函数必定能够取得最大值和最小值.其具体的求解步骤如下：

(1) 求导找临界点: 对给定的函数 $y = f(x)$ ，得到导函数 $f'(x)$ ，然后解方程 $f'(x) = 0$ ，求出在区间 $[a, b]$ 内所有使得导数为零的点，这些点即为驻点.  
（3）比较端点与临界点函数值: 分别计算函数在区间端点 a 和 b 处的函数值 $f(a)$ , $f(b)$ ，以及所有驻点处的函数值.  
（3）确定最值：将上述计算得到的所有函数值进行比较，其中最大的函数值即为函数在闭区间 $[a,b]$ 上的最大值，最小的函数值则为函数在该区间上的最小值.

# 3 导数在优化问题中的典型应用

# 案例 最大矩形面积问题

用长为 L 的篱笆围成一个矩形菜地,靠墙一面不需篱笆,并且在与墙平行的一边上要预留一个宽度为 $a\left(0<a<\frac{L}{2}\right)$ 的门(门不需要篱笆),求长宽各为多少时面积最大.

问题分析 本题是在实际应用中求矩形面积的最大值. 已知篱笆长度 L 以及门的宽度 a, 需要通过合理设未知数, 建立面积函数, 再利用导数知识来求解函数的最大值, 从而确定矩形的长和宽.

建模 设矩形垂直于墙的一边(即宽)为 x，由于靠墙一边有宽度为 a 的门且门不需要篱笆，那么矩形平行于墙的一边(即长)所用篱笆长度是总篱笆长 L 加上门宽 a 后，减去两倍的宽，所以长为 $L + a - 2x$ 。根据矩形面积公式 S = 长 × 宽，可得面积函数 $S(x) = x (L + a - 2x) = -2x^{2} + (L + a)x$ ，因为矩形的宽 x 必须大于 0，且长 $L + a - 2x > 0$ （长度不能为负），解 $L + a - 2x > 0$ 可得 $x < \frac{L + a}{2}$ ，所以 x 的取值范围是 $0 < x < \frac{L + a}{2}$ 。

求解 求一阶导数.

根据求导公式 $(X^{n})^{\prime}=nX^{n-1}$ 以及 $(u+v)^{\prime}=u^{\prime}+v^{\prime}(u,v$ 为关于X的函数），

对 $S(x)=-2x^{2}+(L+a)x$ 求导. 对于 $-2x^{2}$ 求导, 可得 $(-2x^{2})'=-2\cdot2x=-4x$ ; 对 $(L+a)x$ 求导, 可得 $((L+a)x)'=(L+a)\cdot1=L+a$ . 所以 $S'(x)=-4x+(L+a)$ .

求驻点 $S'(x)=0$ ，令引文函数在极值点处的导数为0，即 $-4x+(L+a)=0$ ，通过移项求解 x： $-4x+(L+a)=0,-4x=-(L+a),x=\frac{L+a}{4}.$

再求二阶导数 $S''(x) = -4 < 0$ ，所以 $x = \frac{L + a}{4}$ 为极大值点.

此时矩形的长 $= L + a - 2 \cdot \frac{L + a}{4} = \frac{L + a}{2}$ .

结论 当矩形的宽为 $\frac{L+a}{4}$ 、长为 $\frac{L+a}{2}$ 时，围成的矩形菜地面积最大.

# 4 特殊情形下的最值问题处理

# 4.1 不可导点的处理

若函数在给定区间内存在不可导点,例如分段函数的衔接点、绝对值函数的折点等情况,这些点不能被常规的求导方法所忽略.我们需要单独计算这些点的函数值,并将其与通过导数求出的驻点处的函数值进行比较,以此确定函数在整个区间内的最值.例如函数 $y=|x|$ ,在x=0处不可导,但从函数图象可以直观地看出,在x=0处函数取得极小值0.

# 4.2 无界区间的最值问题

对于定义在开区间或无限区间上的函数,求解最值时需要结合极限深入分析函数的变化趋势.例如，求函数 $y = \frac{1}{x} + x$ 在区间 $[0, +\infty)$ 上的最大值时，首先对函数求导得 $y' = 1 - \frac{1}{x^2}$ ，令 $y' = 0$ ，解得 $x = 1 (x = -1$ 舍去，因为不在给定区间内).然后考查当 $x \to 0^+$ 和 $x \to +\infty$ 时函数的渐近行为，当 $x \to 0^+$ 时， $y \to +\infty$ ；当 $x \to +\infty$ 时， $y \to +\infty$ .而在 $x = 1$ 处， $y = 2$ ，所以函数在该区间内没有最大值，但有最小值2.

# 5 常见错误与注意事项

（1）忽略定义域限制: 在实际问题中, 变量往往受到物理等条件的严格约束. 比如在涉及长度、面积、产量等实际量时, 它们通常具有非负的限制条件. 因此, 在求解函数最值问题之前, 务必明确定义域, 确保所求结果在实际意义上是合理可行的.  
(2) 误判极值类型:有些同学在解题过程中,仅仅依据一阶导数为零就草率地断定该点为极值点,而忽略了验证二阶导数或者导数符号的变化情况.这种错误的判断可能导致得出错误的最值结果,所以在确定极值点时一定要严谨细致.   
(3) 计算错误: 在多项式求导过程中, 容易出现系数处理不当的问题. 例如对 $x^{n}$ 求导时, 正确的结果应该是 $nx^{n-1}$ , 但有的同学会错误地写成 $nx^{n}$ . 这种看似微小的计算错误, 可能会对整个解题过程产生严重的影响, 因此在计算过程中要格外小心谨慎.
