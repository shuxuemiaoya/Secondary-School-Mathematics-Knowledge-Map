# 1 反思问题源由,有效追根溯源

在解题教学过程中,回归教材,注重对教材中的基本概念、基本定理、基本性质等数学知识的深刻理解,理解数学的本质,抓住这些内容的本质,才能根本性地解决问题,真正提升学生的数学核心素养.基于问题缘由进行反思,回归本质,追根溯源,培养思维的理论性和本质性.

例 1 （2025 届辽宁省沈阳市东北育才学校高三（下）开学数学试卷（六模））定义双曲余弦函数表达式为 $\cosh x = \frac{e^{x} + e^{-x}}{2}$ ，定义双曲正弦函数表达式为 $\sinh x = \frac{e^{x} - e^{-x}}{2}$ 。设函数 $f(x) = \frac{\sinh x}{\cosh x}$ ，若实数 m 满足不等式 $f(m - 12) + f(m^{2}) > 0$ ，则 m 的取值范围为（）

(A)(-4,3).   
(B) $(-3,4)$ .   
(C) $(-∞,-4)∪(3,+∞)$ .   
(D) $(-∞,-3)∪(4,+∞)$ .

解析 依题, 函数 $f(x)=\frac{\sinh x}{\cosh x}=\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$ , 易知其定义域为 R.

由于 $f(-x)=\frac{\mathrm{e}^{-x}-\mathrm{e}^{x}}{\mathrm{e}^{-x}+\mathrm{e}^{x}}=-\frac{\mathrm{e}^{x}-\mathrm{e}^{-x}}{\mathrm{e}^{x}+\mathrm{e}^{-x}}=-f(x)$ ，
则知函数 $f(x)$ 为奇函数；

又由于 $f(x)=\frac{\mathrm{e}^{x}-\mathrm{e}^{-x}}{\mathrm{e}^{x}+\mathrm{e}^{-x}}=\frac{\mathrm{e}^{2x}-1}{\mathrm{e}^{2x}+1}=1-\frac{2}{\mathrm{e}^{2x}+1}$ ，而函数 $y=e^{2x}+1$ 是 R 上的增函数，且 y>1 恒成立，则函数 $f(x)$ 在 R 上为增函数.

则由 $f(m-12)+f(m^{2})>0$ ,

可得 $f(m^{2}) > -f(m-12) = f(12-m)$ ,

则有 $m^2 > 12 - m$ ，即 $m^2 + m - 12 > 0$

解得 m < -4 或 m > 3，即 m 的取值范围为 $(-∞, -4) ∪ (3, +∞)$ . 故选择答案(C).

以上新定义问题,来源于教材中的相关例(习)题,出自人教版2019年版必修第一册《数学》第160页复习参考题4中的“综合应用”部分第6题,在此基础上,合理加以变式应用与创新定义.

# 2 反思考查本质,积累解题经验

在解题教学过程中,挖掘内涵,从问题条件中剖析相关信息,把握所求结论的本质,合理构建条件与结论之间的联系,从中探寻问题的本质,借助相关的基础知识点与基本方法来分析与应用.对本质的剖析与内涵的挖掘,是解题经验积累的重要途径,基于考查本质的反思,挖掘内涵,积累经验,训练思维的敏捷性和深刻性.

例 2 （2025 届广东省华南师大附中高三模拟测试（4 月）数学试卷）若实数 a, b, c 满足条件： $\mathrm{e}^{a-b+c}+\mathrm{e}^{a+b-c}=2\mathrm{e}^{2}(a-1)$ ，则 $\frac{abc}{a^{4}+b^{4}+c^{4}}$ 的最大值是 \_\_\_\_.

解析: 依题, 利用基本不等式, 可得 $e^{a-b+c} + e^{a+b-c} \geqslant 2\sqrt{e^{a-b+c} \times e^{a+b-c}} = 2e^{a}$ , 当且仅当 $e^{a-b+c} = e^{a+b-c}$ , 即 b = c 时等号成立.

则有 $2\mathrm{e}^2 (a - 1)\geqslant 2\mathrm{e}^a$ ，整理可得 $\mathrm{e}^{a - 1}\leqslant \mathrm{e}(a - 1)$

又利用指数切线不等式 $\left(\mathrm{e}^{x}\geqslant\mathrm{e}x\right)$ ，可得 $e^{a-1}\geqslant$

$\mathrm{e}(a-1)$ ，当且仅当a-1=1，即a=2时等号成立；

所以 $\mathrm{e}^{a-1}=\mathrm{e}(a-1)$ ，易知 2 是方程 $\mathrm{e}^{a-1}=\mathrm{e}(a-1)$ 的唯一实数根.

所以 $\mathrm{e}^{2 - b + c} + \mathrm{e}^{2 + b - c} = 2\mathrm{e}^2$ ，即 $\mathrm{e}^{c - b} + \mathrm{e}^{b - c} = 2.$

又利用基本不等式，

可得 $\mathrm{e}^{c - b} + \mathrm{e}^{b - c}\geqslant 2\sqrt{\mathrm{e}^{c - b}\times\mathrm{e}^{b - c}} = 2,$

当且仅当 $\mathrm{e}^{c - b} = \mathrm{e}^{b - c}$ ，即 $b = c$ 时等号成立.

所以当 b=c 时， $e^{c-b} + e^{b-c} = 2$ ，

所以 b=c.

所以 $\frac{abc}{a^4 + b^4 + c^4} = \frac{2c^2}{16 + 2c^4} = \frac{c^2}{8 + c^4} = \frac{1}{\frac{8}{c^2} + c^2}\leqslant$

$$
\frac {1}{2 \sqrt {\frac {8}{c ^ {2}} \times c ^ {2}}} = \frac {\sqrt {2}}{8}, \text {当且仅当} \frac {8}{c ^ {2}} = c ^ {2},
$$

即 $a = 2, b = c = \sqrt[4]{8}$ 时等号成立．所以 $\frac{abc}{a^4 + b^4 + c^4}$ 的最大值是 $\frac{\sqrt{2}}{8}$ . 故填答案： $\frac{\sqrt{2}}{8}$ .

以上问题中,基于问题中的指数方程,由此衍生出两个方程 $\left(\mathrm{e}^{a-1}=\mathrm{e}(a-1),\mathrm{e}^{c-b}+\mathrm{e}^{b-c}=2\right)$ 和关联三个不等式 $\left(\mathrm{e}^{a-b+c}+\mathrm{e}^{a+b-c}\geqslant2\sqrt{\mathrm{e}^{a-b+c}\times\mathrm{e}^{a+b-c}}\right.$ ， $\left.\mathrm{e}^{a-1}\geqslant\mathrm{e}(a-1),\mathrm{e}^{c-b}+\mathrm{e}^{b-c}\geqslant2\sqrt{\mathrm{e}^{c-b}\times\mathrm{e}^{b-c}}\right)$ .这才是问题的本质所在,挖掘出问题的本质,给问题的求解指明方向,提供思路.

# 3 反思问题变式,实现举一反三

在解题教学过程中,基于考查本质的反思,发散思维,进而举一反三,培养思维的发散性和创新性.

例 3 （2025 届山东省潍坊市高考模拟考试（2025 年 3 月 • 一模）数学试题）已知同一平面内的单位向量 $e_{1}, e_{2}, e_{3}$ ，则 $(e_{1} - e_{2}) \cdot e_{3}$ 的最小值是 \_\_\_\_；若 $e_{1} + e_{2}$ 与 $e_{3}$ 不共线， $|e_{1} + e_{2} + e_{3}| = 1, x, y, z \in R, xe_{1} + ye_{2} + ze_{3} = 0, x + y + z = 2025$ ，则 $\frac{z}{x + y} + \frac{y}{x + z} + \frac{x}{y + z} =$ \_\_\_\_ .

解析 依题,要使得 $(e_{1}-e_{2})\cdot e_{3}$ 取得最小值,只需让 $e_{1}-e_{2}$ 的模最大,且 $e_{1}-e_{2}$ 与 $e_{3}$ 的夹角为 $\pi$ 即可.

易知 $e_{1}-e_{2}$ 的模的最大值为 2，故 $(e_{1}-e_{2})\cdot e_{3}$ 的最小值是 -2；

而由 $|\pmb{e}_1 + \pmb{e}_2 + \pmb{e}_3| = 1$ ，两边平方并整理可得 $3 + 2(\pmb {e}_1\cdot \pmb {e}_2 + \pmb {e}_2\cdot \pmb {e}_3 + \pmb {e}_3\cdot \pmb {e}_1) = 1,$

即 $e_{1} \cdot e_{2} + e_{2} \cdot e_{3} + e_{3} \cdot e_{1} = -1.$

又由于 $e_{1} + e_{2}$ 与 $e_{3}$ 不共线，

且 $xe_{1} + ye_{2} + ze_{3} = 0$ ,

所以 $e_{1}$ 与 $e_{2}$ 不共线，且 $z \neq 0$ ，

故 $e_{3}=-\frac{xe_{1}+ye_{2}}{z}.$

将其代入 $e_{1} \cdot e_{2} + e_{2} \cdot e_{3} + e_{3} \cdot e_{1} = -1$ 中，

整理可得 $(z-x-y)\boldsymbol{e}_{1}\cdot\boldsymbol{e}_{2}=x+y-z=-(z-x-y)$ .

由于 $e_1$ 与 $e_2$ 不共线，故 $e_1 \cdot e_2 \neq -1$

所以 $x + y - z = 0$ ，即 $z = x + y$ 。

结合 $x + y + z = 2025$ ,

解得 $z=\frac{2025}{2}, x+y=\frac{2025}{2}.$

又由于 $xe_{1} + ye_{2} + (x + y)e_{3} = 0$ ,

可得 $x(\boldsymbol{e}_{1}+\boldsymbol{e}_{3})+y(\boldsymbol{e}_{2}+\boldsymbol{e}_{3})=\boldsymbol{0}$ ,

故必有 $e_1 + e_3 = 0$ 或 $e_2 + e_3 = 0$ 恰有一个成立.

不妨设 $e_1 + e_3 = 0$ ，则 $e_2 + e_3 \neq 0$

从而 y=0，进而 $x=\frac{2025}{2}$ .

所以 $\frac{z}{x + y} +\frac{y}{x + z} +\frac{x}{y + z} = \frac{\frac{2025}{2}}{\frac{2025}{2} + 0} +$

$$
\frac {0}{\frac {2 0 2 5}{2} + \frac {2 0 2 5}{2}} + \frac {\frac {2 0 2 5}{2}}{0 + \frac {2 0 2 5}{2}} = 1 + 0 + 1 = 2.
$$

故填答案：-2;2.

特别地,基于以上问题,可以合理发散思维,反思问题变式,得到以下对应的变式问题.

变式 1 已知同一平面内的单位向量 $e_{1}, e_{2}, e_{3}$ ，则 $(e_{1}-e_{2}) \cdot e_{3}$ 的最大值是 \_\_\_\_；若 $e_{1} + e_{2}$ 与 $e_{3}$ 不共线， $|e_{1} + e_{2} + e_{3}| = 1, x, y, z \in R, xe_{1} + ye_{2} + ze_{3} = 0, x + y + z = 2025$ ，则 $\frac{z}{x + y} + \frac{y}{x + z} + \frac{x}{y + z} =$ \_\_\_\_ .

答案:2;2.

变式 2 已知同一平面内的单位向量 $e_{1}, e_{2}, e_{3}$ ，则 $(e_{1} - e_{2}) \cdot e_{3}$ 的取值范围是 \_\_\_\_；若 $e_{1} + e_{2}$ 与 $e_{3}$ 不共线， $|e_{1} + e_{2} + e_{3}| = 1, x, y, z \in R, xe_{1} + ye_{2} + ze_{3} = 0, x + y + z = 2025$ ，则 $\frac{z}{x + y} + \frac{y}{x + z} + \frac{x}{y + z} =$ \_\_\_\_.

答案: $[-2,2]$ ;2.
