【摘 要】 高中数学测试题类型多样,内容丰富,对学生的解题能力提出了一定的要求.本文以具体测试题为例,探讨题目的解题方法,为高中数学测试题的解答提供参考.

【关键词】高中数学;测试题;解题技巧

在解答高中数学测试题时,学生需结合所学的课程知识,巧妙运用题目条件以得出答案.下面结合具体习题进行分析.

例 1 已知正数 a, b 满足 $ab = 2a + b + 2$ .

(1) 求 ab 的最小值;

(2) 求 $a + 2b$ 的最小值.

解析 （1）结合题意，将 $ab = 2a + b + 2$ 中的 $2a + b \geqslant 2\sqrt{2ab}$ 转化为只含 ab 的式子，解不等式后，即可得出答案；（2）将 $ab = 2a + b + 2$ 转化为 $b = \frac{2a + 2}{a - 1} (a > 1)$ ，代入 $a + 2b$ ，将 $a + 2b$ 转变为用 a 表示的函数，将其代入题目条件即可得出函数的最值.

解 (1) $ab = 2a + b + 2 \geqslant 2\sqrt{2ab} + 2$

设 $\sqrt{ab} = t$

因此 $t^2 - 2\sqrt{2} t - 2 \geqslant 0$

解得 $t \geqslant 2 + \sqrt{2}$ ,

因此 ab 的最小值是 $6 + 4\sqrt{2}$ ，在 b = 2a，即 $a = \sqrt{2} + 1$ 时取最小值.

(2) 结合题意, 有 $b=\frac{2a+2}{a-1}(a>1)$ .

因此 $a + 2b = a + \frac{4a + 4}{a - 1} = a - 1 + \frac{8}{a - 1} +5\geqslant$ $4\sqrt{2} +5,$

即 $a + 2b$ 的最小值为 $4\sqrt{2} + 5$ ，当 $a - 1 = \frac{8}{a - 1}$

即 $a=2\sqrt{2}+1$ 时取最小值.

小结 本题主要考查高中数学中“均值不等式求最值”知识点,结合高中数学不等式的理论知识,对题目条件进行整理变形,利用均值不等式推导得出答案. 均值不等式是解决此类问题的关键工具, 在解题中注意均值不等式取等号的条件. 在变量替换和等式转化中将复杂问题简化为更易于处理的形式. 解不等式是求解最值问题的重要步骤, 在得出结果后, 需代入原式检验是否符合题目条件和要求. 解答此题过程中, 可以深刻体会到均值不等式在解决最值问题中的重要作用, 理解变量替换、等式转化等数学技巧的应用.

例 2 已知直线 l 过定点 A(4,0)，且与抛物线 C: $y^{2}=2px$ (p>0) 交于 P, Q 两点，若以 PQ 为直径的圆经过原点，求该抛物线的方程.

解 根据题意,设直线 l 的方程为 $x=my+4$ , 将其代入 $y^{2}=2px$ ,

有 $y^{2}-2pmy-8p=0$ ,

设 $P(x_{1},y_{1}), Q(x_{2},y_{2})$ ,

有 $y_{1}y_{2}=-8p$ ，

则 $x_{1}x_{2}=\frac{y_{1}^{2}}{2p}\cdot\frac{y_{2}^{2}}{2p}=\frac{(y_{1}y_{2})^{2}}{4p^{2}}=16$

由题意可知 $OP \perp OQ$ ，则 $\overrightarrow{OP} \cdot \overrightarrow{OQ} = 0$ ，

得出 $x_{1}x_{2}+y_{1}y_{2}=16-8p=0$ ,

因此抛物线的方程为 $y^{2}=4x$ .

小结 本题主要考查了直线与抛物线的交点问题、韦达定理的应用与圆的性质. 解题时, 基于题目要求, 采取设立方程、联立求解、应用数学定理与几何性质等步骤, 顺利求得抛物线的方程. 在解题过程中, 需耐心化简, 进而得出答案.

在解决此类问题时,应根据题目条件设立合适的方程.本题中,直线方程和抛物线方程是解题的基础.将直线方程代入抛物线方程,得到一个二次方程,利用韦达定理得出交点纵坐标之和与积.题目中给出的“直线与抛物线 $C:y^{2}=2px\ (p>0)$ 交于P、Q两点”是一个重要的几何条件,据此可建立关于交点坐标的方程.在得到方程后,需要进行化简、求解,得出正确的答案.

例 3 $P_{1}(x_{1},y_{1}),P_{2}(x_{2},y_{2}),\cdots,P_{n}(x_{n},y_{n}),\cdots$ 为函数 $y = 3x + \frac{13}{4}$ 的图象上的点，点的横坐标构成一组等差数列 $\{x_{n}\}$ ，数列 $\{x_{n}\}$ 的公差为 -1，首项是 $-\frac{5}{2}$ ，结合题意求解以下内容：

(1) 点 $P_{n}$ 的坐标；  
(2) 若抛物线 $C_{1}, C_{2}, C_{3}, \cdots, C_{n}, \cdots$ 中的每一条对称轴均与 x 轴垂直， $n \in N^{*}$ ，第 n 条抛物线 $C_{n}$ 的顶点是 $P_{n}$ ，抛物线 $C_{n}$ 经过点 $D_{n}(0, n^{2} + 1)$ ，在 $D_{n}(0, n^{2} + 1)$ 的切线的斜率是 $k_{n}$ ，请问是否能够得出 $\frac{1}{k_{1}k_{2}} + \frac{1}{k_{2}k_{3}} + \cdots + \frac{1}{k_{n-1}k_{n}} < \frac{1}{10}$ ，若能，请证明，反之请说明理由.

解 （1）结合题意， $P_{n}$ 的横坐标构成以 $-\frac{5}{2}$ 为首项，-1 为公差的等差数列，可得 $x_{n}=x_{1}+(n-1)d=-\frac{5}{2}-(n-1)=-n-\frac{3}{2}.P_{n}(x_{n},y_{n})$ 在函数 $y=3x+\frac{13}{4}$ 的图象上，则有 $y_{n}=3x_{n}+\frac{13}{4}=3\left(-n-\frac{3}{2}\right)+\frac{13}{4}=-3n-\frac{5}{4}.$

因此，点 $P_{n}(x_{n},y_{n})$ 的坐标是

$$
\left(- n - \frac {3}{2}, - 3 n - \frac {5}{4}\right).
$$

(2) 证明: 抛物线 $C_n$ 的方程可表示为: $y = \alpha_n (x - x_n)^2 + y_n$ ,

有 $y = \alpha_{n}\left(x + n + \frac{3}{2}\right)^{2} - 3n - \frac{5}{4}.$

抛物线 $C_{n}$ 过点 $D_{n}(0, n^{2} + 1)$ ,

得出 $n^2 + 1 = \alpha_n\left(n + \frac{3}{2}\right)^2 - 3n - \frac{5}{4}$ .

有 $\alpha_{n} = 1, y = \left(x + n + \frac{3}{2}\right)^{2} - 3n - \frac{5}{4}$ .

因此

$$
k _ {n} = y ^ {\prime} \left| _ {x = 0} = 2 (x + n + \frac {3}{2}) \right| _ {x = 0} = 2 n + 3.
$$

得出 $\frac{1}{k_{n - 1}k_n} = \frac{1}{(2n + 1)(2n + 3)}$

$$
= \frac {1}{2} \left(\frac {1}{2 n + 1} - \frac {1}{2 n + 3}\right) (n \geqslant 2),
$$

结合 $\frac{1}{k_1k_2} +\frac{1}{k_2k_3} +\dots +\frac{1}{k_{n - 1}k_n} =$

$$
\frac {1}{2} \left[ \left(\frac {1}{5} - \frac {1}{7}\right) + \left(\frac {1}{7} - \frac {1}{9}\right) + \dots + \left(\frac {1}{2 n + 1} - \frac {1}{2 n + 3}\right) \right]
$$

$$
= \frac {1}{2} \left(\frac {1}{5} - \frac {1}{2 n + 3}\right).
$$

因此有 $\frac{1}{k_{1}k_{2}} + \frac{1}{k_{2}k_{3}} + \cdots + \frac{1}{k_{n-1}k_{n}} = \frac{1}{2}\left(\frac{1}{5} - \frac{1}{2n+3}\right) < \frac{1}{10}.$

小结 本题主要考查了等差数列的性质、一次函数的解析式、抛物线的标准方程及性质、导数的几何意义等知识点。解题时，需根据题目给出的等差数列的首项和公差，利用等差数列的通项公式，将求得的横坐标代入一次函数 $y = 3x + \frac{13}{4}$ 中，对抛物线方程求导，从而得到抛物线的导数函数，即切线的斜率。利用点斜式方程，求出切线方程。学生在整个解题过程中，需熟练掌握等差数列的性质和通项公式，能够灵活运用。同时，掌握一次函数和抛物线的标准方程及性质，能够根据已知条件求出未知量。此外，理解导数的几何意义，利用导数求出切线的斜率；熟练掌握点斜式方程，根据已知点和斜率求出直线方程。在解题过程中，巩固对等差数列、一次函数、抛物线和导数等知识点的理解，在实践中进一步培养数学思维能力。
