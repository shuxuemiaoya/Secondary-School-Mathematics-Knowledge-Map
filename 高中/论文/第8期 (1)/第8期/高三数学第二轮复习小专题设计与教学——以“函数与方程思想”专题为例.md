# 高三数学第二轮复习小专题设计与教学

—— 以“函数与方程思想”专题为例

\- 四川省攀枝花市第三高级中学校 冯蓉波

# 一、高三数学复习阶段的划分

第一轮复习:纵向复习(双基);

第二轮复习:横向复习(思想);

第三轮复习:强化训练,反思问题;

第四轮复习: 回归教材, 查漏补缺.

通过第一轮复习,学生已经具备基本知识、基本能力,第二轮复习的主要目标是提升能力、提升高度、转变视角(站得高、看得远)、定点突破,达到驾驭高考题的目的.

# 二、高考试题解题过程分析

从函数与方程的视角,高考试题中除了纯概念类题,一般都可以转化为方程、函数、不等式进行求解.不等式与方程具有灵活多变的特点;不等式的问题通常转化为函数与方程问题来解决,方程的主要作用就是求解未知量与消元;函数具有很强的解决问题的能力,函数的主要作用就是通过对应关系对两个变量间的值的范围进行转化,不等式与方程的问题通常可以转化为函数问题来解决.不等式、方程、函数间的关系相当于排球比赛中的一传、二传和主攻.波利亚在《怎样解题》中将解题过程分为四个阶段,即弄清问题、拟定计划、实现计划、反思回顾.

# 1. 弄清问题(审题)

感知问题, 即从问题情境中分离出问题的起点(条件)和目标(结论).

(1) 已知条件: 通过阅读寻找或挖掘已知条件(相等关系、不等关系、几何关系).  
(2) 结论(相等关系、不等关系、几何关系).

重点:学会用函数方程视角审题.

难点:隐含条件的挖掘.

# 2. 拟定计划(思题)

需要对问题的数量关系和空间结构进行分拆、组合和映射等操作,从而进一步感知问题的关键结构,进行问题结构表征的转换,从中发现熟悉的模型结构,确定适合解决问题的策略. 将相等关系、不等关系、几何关系坐标化,转化为若干个函数、方程、不等式,然后将这些函数、方程、不等式进行整合,通过变形、化简与消元,将条件不断地向结论靠近,同时寻求结论成立或求解所需的充分条件,使得该充分条件向条件靠近,最后通过对接,将条件与结论之间的路连通,完成解题思路的设计.

重点:(1) 厘清函数、方程、不等式间的关系;  
(2) 找到等价转化、消元、构造函数的途径.   
难点:方程与方程间转化时的障碍消除.

# 3. 实现计划(解题)

根据设计好的解题思路, 将方程化简或联立消元, 或转化为函数问题计算求解得出结论.

重点: 解题步骤的规范书写.

难点: 运算的准确性.

# 4. 反思回顾(总结)

对以上步骤作元认知(对认知活动进行认知),形成自己的认知方法,构建知识与方法小模块(解题工具).

# 三、整合函数、方程、不等式的三个维度

# 1. 方程的个数

已知条件中存在几个方程,通过转化是否可以求解或证明结论,如果不能,说明方程个数不够,应进一步挖掘已知条件,让所有方程(函数、不等式)浮出水面.

# 2. 元的个数

每个方程存在几个元,一个方程只能消去一个元(整体消元除外),要想证明或求解,主要看是否完成消元、分解等.

# 3. 元的次数

对方程的次数分析往往可以找到切入点,如三角方程中的齐次式,代数方程中的因式分解等.

# 四、二轮小专题的选题

# 1. 高考的热点问题(广度)

主要目标是基本知识与基本方法归类;主要对象是三角函数、数列、概率与统计、解析几何、立体几何中的基本问题等.

# 2. 高考中思维度要求高的问题(高度)

主要目标是提高学生的抽象思维、逻辑推理、数学运算、数据处理等能力。主要对象是解析几何、函数导数、数据处理与分析中复杂的数据关系。学生在训练过程中有些问题思维障碍不能跨跃，有些问题是运算方法不简洁而造成运算过于集中。基本方法是以学生解题时思路受阻的问题为对象，集中力量找到思路受阻的原因，厘清题目中函数、方程、不等式间的关系、师生交流共同建立数学小模块形成方法。

# 3. 学生屡做屡错的问题(精度)

审题不细、思题不严、算题不准等“会而不对”的问题. 需要对题设陷阱、易错点归类训练, 运算方法优化训练来提升考试分数.

# 五、小专题的操作步骤

# 1. 教师设计题组,课前学生完成题组

每个专题所选题组应具备典型性(通性)、新颖性、覆盖性(不是用题目类型覆盖考试试题,而是核心知识、核心思想方法的覆盖),每个题组根据学生的层次具体确定作业量,小组学科长检查并收集问题.

# 2. 生交流设计解题思路

通过课堂小组讨论,每个小组作出例题的解题思路的思维导图,收集解题过程中遇到的问题,暴露学生的思维.

# 3. 课堂展示思路设计

小组展示思维导图,讲解设计思路,提出解题过程中遇到的问题.其他小组补充展示不同思路,提出解题过程中遇到的问题.

# 4. 对生成的问题再讨论

教师对学生生成的问题引导思考,再次讨论,并提出解决方案.

# 5. 教师评价与总结

对小组的展示进行评价,对问题归类、思想与方法提炼升华.

# 6. 学生建立模块

学生总结归类,形成方法(解题工具),构建自己的小模块,并规范书写题组.

# 7. 反思

教师反思题组的选择是否恰当、解题思路是否优化、学生的问题是否已经解决. 学生反思思想方法是否掌握, 小模块建立是否完善, 归类的方法是否能应用.

# 六、小专题实例分析

# 1. 高考的热点问题(广度)(以三角函数、解三角形为例)

三角形中的基本量:三条边、三个角、面积、外接圆半径等.

基本定理:内角和定理、正弦定理、余弦定理.

例 1 △ABC 的内角 A, B, C 的对边分别为 a, b, c，已知 △ABC 的面积为 $\frac{a^{2}}{3\sin A}$ .

(Ⅰ) 求 $\sin B \sin C$ ;   
(Ⅱ) 若 $6\cos B\cos C=1, a=3$ ，求 $\triangle ABC$ 的周长.

第一步:找方程

题干方程 $S_{\triangle ABC}=\frac{a^{2}}{3\sin A}.$ ①

第(Ⅱ)问的方程 $6\cos B\cos C=1$ . ②

$$
a = 3. \quad ③
$$

第二步:整合方程(设计思路)

$$
\frac {1}{2} a c \sin B = \frac {a ^ {2}}{3 \sin A}. \quad ④
$$

特征:边的次数相等,用正弦定理转化为

$$
\frac {1}{2} \sin C \sin B = \frac {\sin A}{3 \sin A}. \quad ⑤
$$

$$
\sin B \sin C = \frac {2}{3}. \quad ⑥
$$

结合 ②⑥ 及内角和定理得

$$
\cos (B + C) = - \frac {1}{2} \Rightarrow A = \frac {\pi}{3}. \quad ⑦
$$

由 ③⑦ 知三角形一边及其对角欲求周长方程个数不够, 找到方程 ④ 可转化成 bc = 8. ⑧

由 ③⑦⑧ 结合余弦定理即可求解.

通过对方程的个数、次数与元特征分析,找到了整合方程、转化方程的有效途径.

# 2. 高考中思维度要求高的问题(高度、难度)(以函数、导数为例)

例 2 （2018年全国Ⅰ卷21题）已知函数 $f(x)=\frac{1}{x}-x+a\ln x.$

(I) 讨论 $f(x)$ 的单调性;

（Ⅱ）若 $f(x)$ 存在两个极值点 $x_{1}, x_{2}$ ，证明： $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}}<a-2.$

第一步:分析条件和讨论

此题条件与结论都非常简洁,分析函数 $f(x)=\frac{1}{x}-x+a\ln x$ .

(1) 结构: 反比例函数、一次函数、对数函数的和差的形式;

(2) 量: 主元 x, 参数 a.

第(Ⅱ)问中的条件:“ $f(x)$ 存在两个极值点 $x_{1}$ ， $x_{2}$ ”; 结论 $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}}<a-2$ 需要的充分条件是什么?

第二步:整合方程,设计思路(学生小组展讲)

第（Ⅰ）问思路常规，用导函数的符号来判断，需分类讨论.

第(Ⅱ)中结论 $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}}<a-2$ 需要的充分条件是什么？怎样由“ $f(x)$ 存在两个极值点 $x_{1}$ ， $x_{2}$ ”转化出来.

由条件 $f'(x)=-\frac{1}{x^{2}}-1+\frac{a}{x}=-\frac{x^{2}-ax+1}{x^{2}}$ $f(x)$ 存在两个极值点 $x_{1}, x_{2}$ 等价于方程 $x^{2}-ax+1=0(*)$ 有两个不等的正根.

所以 $x_{1}x_{2}=1$ ，①

$$
x _ {1} + x _ {2} = a, \quad ②
$$

$$
a > 2. \quad ③
$$

对结论成立寻找充分条件:不妨设 $x_{1}<x_{2}$ ，则 $x_{2}>1$ .

$$
\frac {f \left(x _ {1}\right) - f \left(x _ {2}\right)}{x _ {1} - x _ {2}} = - \frac {1}{x _ {1} x _ {2}} - 1 + a \frac {\ln x _ {1} - \ln x _ {2}}{x _ {1} - x _ {2}}
$$

(将解析式代入) $= -2 + a\frac{\ln x_1 - \ln x_2}{x_1 - x_2}$ （由方程 ① 消去 $x_{1}x_{2}) = -2 + a\frac{\ln\frac{1}{x_{2}^{2}}}{\frac{1}{x_{2}} - x_{2}}$ （由方程 ① 消去 $x_{1}$ ，实现了第一次消元). 即证明 $-2 + a \frac{-2 \ln x_{2}}{\frac{1}{x_{2}} - x_{2}} < a - 2 \Rightarrow a \left( \frac{-2 \ln x_{2}}{\frac{1}{x_{2}} - x_{2}} - 1 \right) < 0 \Rightarrow \frac{-2 \ln x_{2}}{\frac{1}{x_{2}} - x_{2}} < 1.$ (结合③消去 a,实现了第二次消元）即 $\frac{1}{x_{2}}-x_{2}+2\ln x_{2}<0.$ （成功实现统一元的目标，可以构造函数了）

设函数 $g(x)=\frac{1}{x}-x+2\ln x(x>1)$ ，证明 $g(x)>0$ 即可.

学生生成的问题：

(1) 由方程 ①② 得 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} = -\frac{1}{x_1x_2} - 1$

$+a\frac{\ln x_{1}-\ln x_{2}}{x_{1}-x_{2}}$ 可以消去 $x_{1}, x_{2}, a$ 中的两个元，为什么这里要留 $x_{2}$ ？而不是留 $x_{1}, a$ 呢？

(2) 消去参数 a 是通过不等式中两边同时除以 a 消去的, 如果不能约去, 又能消去参数吗?

(3) 两个极值点问题通常是以 $\frac{x_1}{x_2}$ 为主元构造函数, 此题可以用 $\frac{x_1}{x_2}$ 作为主元吗?

(4) 用以下思路: 由 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} = a - 2 \Rightarrow f(x_1) - f(x_2) > (a - 2)(x_1 - x_2) \Rightarrow f(x_1) - (a - 2)x_1 > f(x_2) - (a - 2)x_2.$ ④

④ 成立的充分条件是 $h(x)=f(x)-(a-2)x$ 在 $(0,+\infty)$ 上单调递减.

$h(x)=\frac{1}{x}-(a-1)x+a\ln x$ ，只需 $h'(x)=$ $-\frac{[(a-1)x-1](x-1)}{x^{2}}\leqslant0$ 在 $(0,+\infty)$ 上恒成立.

而 $\left[(a-1)x-1\right](x-1)\geqslant0$ 在 $(0,+\infty)$ 上并非恒成立，事实上注意到a>2在 $(1,+\infty)$ 上恒成立；当x<1时， $x\in\left[\frac{1}{a-1},1\right)$ 成立， $x\in\left(0,\frac{1}{a-1}\right)$ 不成立，原因是什么？

通过小组讨论,学生展讲,老师引导解决新生成的问题:

(1) 从方程的角度, 留 $x_{1}, a$ 是可以的. 由于 $x_{1}$ 与 $x_{2}$ 具有对称性, 由方程①知, $\frac{-2\ln x_{2}}{\frac{1}{x_{2}} - x_{2}} < 1 \Rightarrow \frac{2\ln x_{1}}{x_{1} - \frac{1}{x_{1}}} < 1$ .

同样可以构造函数. 若要用 a 作为主元, 则要用方程 (\*) 解出 $x_{1}, x_{2}$ , 式子较大, 化简很难, 不宜采用.

(2) 从方程消元的功能来看, 消去 a 的手段不仅仅是约去, 由①②知, $a = x_{1} + \frac{1}{x_{1}} = x_{2} + \frac{1}{x_{2}}$ , 代入消元也可, 但本题中约去效果最好.

(3) 若令 $\frac{x_1}{x_2} = t (0 < t < 1)$ , 则由方程 ①②, 得 $x_1 = \sqrt{t}, x_2 = \frac{1}{\sqrt{t}}, -2 + a \frac{\ln x_1 - \ln x_2}{x_1 - x_2} < a - 2 \Rightarrow \frac{\ln t}{\sqrt{t} - \frac{1}{\sqrt{t}}} < 1 \Rightarrow \ln t - \sqrt{t} + \frac{1}{\sqrt{t}} > 0.$

构造函数 $h(t)=\ln t-\sqrt{t}+\frac{1}{\sqrt{t}}(0<t<1)$ 即可解决问题.

# 六、教学反思

# 1. 小题小做

在每年的高考中,向量问题都是以选择、填空形式出现,承担着考查学生思维品质的重要任务,因此,解题的正确率和灵活性就显得尤为重要.我们应该寻求最简洁、最方便的做法,即小题小做.在平时的教学中,教师要有意识地挖掘和培养,对于此问题的外延与内涵要加以强化,从而提升学生的思维品质.

# 2. 方法优化

有些问题虽然没有直接用向量作为已知条件,但如果运用向量知识来解决,会显得自然、简便,极大地简化了运算.涉及三点共线、长度乘积、面积等形式,利用向量知识来解决具有极大的优越性.我们在复习时要注重知识间的相互联系,挖掘隐性知识,学会用不同的视角观察问题、分析问题、解决问题.

平面向量时常作为工具在使用,建立向量运算与几何图形之间的关系后,把对图形的研究推进到运算的水平,向量运算的应用则把向量与几何、代数有机地联系在了一起.

# 3. 提炼本质

《普通高中数学课程标准(实验)》中指出：“高中数学课程应该返璞归真，努力揭示数学概念、法则、结论的发展过程和本质。数学课程要讲逻辑，更要讲道理，通过典型例题的分析和学生自主探索活动，使学生理解数学概念、结论逐步形成的过程，体会蕴涵在其中的思想方法，追寻数学发展的历史足迹，把数学的学术形态转化为学生易于接受的教育形态。”我们高三复习课要强调本质。这里的本质指的是概念的本质和思想方法的本质。我们高三教师一定要在凸显概念本质和提炼思想方法本质的教学上狠下功夫，使学生掌握问题的本质，从而实现会一题、通一类、连一片多题一解的目的，让更多的学生脱离题海战术。
