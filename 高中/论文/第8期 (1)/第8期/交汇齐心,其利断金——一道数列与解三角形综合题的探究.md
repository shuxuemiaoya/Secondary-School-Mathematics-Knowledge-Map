# 交汇齐心,其利断金

—— 一道数列与解三角形综合题的探究

● 黑龙江省大庆第一中学 李世明

对于高中数学相关知识点之间的交汇，在高考大纲中的考查要求中明确指出：从学科的整体高度和思维价值的高度考虑问题，在知识网络交汇点处设计试题，是对数学基础知识的考查达到必要的深度。特别地，知识网络交汇处的问题，是创新问题的更深层次，其地位在高考中将越来越重要。而数列与解三角形的交汇问题是两个相应知识点的重点所在，也是高考中的亮点与创新点。此类问题往往以三角形为问题背景，借助相关边、角等元素成等差数列或等比数列来交汇，进而考查综合运用数列的性质、公式以及解三角形的相关知识解决问题的能力。

# 一、问题呈现

问题:(2019届江苏省高三12月联合调研测试·13)已知 $\triangle ABC$ 的三边长a,b,c成等差数列,且 $a^{2}+b^{2}+c^{2}=63$ ,则实数b的取值范围是\_\_\_\_.

本题结合三角形的三边长成等差数列以及三边长的平方和,进而来确定实数b的取值范围.巧妙整合数列与解三角形,综合三角形的性质、数列、解三角形等相关知识来解决问题.

# 二、多解思维

思维角度 1: (不等式法) 结合题目条件, 建立相应的关系式, 分别从基本不等式角度与三角形的性质角度来建立涉及参数 b 的二次不等式, 进而通过求解相应的不等式法来确定实数 b 的取值范围.

解法1:由于 $\triangle ABC$ 的三边长a,b,c成等差数列,不妨设 $a\leqslant b\leqslant c$ ,且 $2b=a+c,a+b>c$ ,由 $a^{2}+b^{2}+c^{2}=63$ ,可得 $a^{2}+c^{2}=63-b^{2}$ ,根据基本不等式可得 $\frac{a+c}{2}\leqslant\sqrt{\frac{a^{2}+c^{2}}{2}}$ ,则有 $b\leqslant\sqrt{\frac{63-b^{2}}{2}}$ ,解得 $b\leqslant\sqrt{21}$ ,当且仅当 $a=b=c=\sqrt{21}$ 时等号成立.

又 $a + b > c$ ，即有 $c - a < b$ ，两边平方可得 $(c -$ $a)^{2}<b^{2}$ ，以上不等式两边对应加上 $(a+c)^{2}=4b^{2}$ ，整理可得 $2(a^{2}+c^{2})<5b^{2}$ ，则有 $2(a^{2}+c^{2})=2(63-b^{2})<5b^{2}$ ，解得 $b>3\sqrt{2}$ .

综上可知， $3\sqrt{2}<b\leqslant\sqrt{21}$ . 故填答案： $(3\sqrt{2},\sqrt{21}]$ .

思维角度 2: (函数法) 已知三角形三边长成等差数列, 利用等差数列的性质, 引入参数公差 d, 结合条件确定参数 d 的取值范围, 通过题目条件建立涉及参数 $b^{2}$ 关于参数 d 的关系式, 结合二次函数的图像与性质确定函数 $b^{2}=f(d)$ 的值域, 进而来确定实数 b 的取值范围.

解法2:设 $\triangle ABC$ 的三边长 a, b, c 所成等差数列的公差为 d，则有 a = b - d, c = b + d. 不失一般性，假定 $a \leqslant b \leqslant c$ ，则 $d \geqslant 0$ ，结合三角形的性质可得 $a + b > c$ ，则有 $b - d + b > b + d$ ，整理可得 $d < \frac{b}{2}$ ，则有 $0 \leqslant d < \frac{b}{2}$ . 由 $a^{2} + b^{2} + c^{2} = 63$ ，整理可得 $b^{2} = 21 - \frac{2}{3}d^{2}$ ，而由 $d \in \left[0, \frac{b}{2}\right)$ 可知， $b^{2} = f(d) = 21 - \frac{2}{3}d^{2}$ ，所以 $21 - \frac{1}{6}b^{2} < b^{2} \leqslant 21$ ，解得 $3\sqrt{2} < b \leqslant \sqrt{21}$ . 故填答案： $(3\sqrt{2}, \sqrt{21}]$ .

思维角度 3: (等差数列法) 利用三角形三边长成等差数列的性质, 引入参数公差 d, 建立涉及参数 b 与 d 的方程, 利用参数 d 的取值情况来确定 b 的最大值; 再结合三角形的性质建立相应的不等式, 结合不等式的求解来确定实数 b 的取值范围.

解法 3: 设 $\triangle ABC$ 的三边长 a, b, c 所成等差数列的公差为 d，则有 a = b - d, $c = b + d$ ，代入 $a^{2} + b^{2} + c^{2} = 63$ ，整理可得 $3b^{2} + 2d^{2} = 63$ ，则当 d = 0 时，b 有最大值 $\sqrt{21}$ ，即 $b \leqslant \sqrt{21}$ ，当 $a = b = c = \sqrt{21}$ 时等号成立.

结合三角形的性质可得 $a + b > c$ ，则有 $b - d + b > b + d$ ，整理可得 $b > 2d$ ，代入 $3b^{2} + 2d^{2} = 63$ ，可得 $3b^{2} + 2\left(\frac{b}{2}\right)^{2} > 63$ ，解得 $b > 3\sqrt{2}$

综上可知， $3\sqrt{2}<b\leqslant\sqrt{21}$ . 故填答案： $(3\sqrt{2},\sqrt{21}]$ .

思维角度 4: (线性规划法) 利用题目条件, 结合等差数列的性质以及三角形的性质建立对应的不等式组, 从而问题就转化为在第一象限内存在点 $P(x, y)$ , 满足 $\begin{cases} x^2 + y^2 = 63 - b^2, \\ x + y = 2b, \\ y - x < b, \end{cases}$ 求此时正数 $b$ 的取值范围问题, 利用数形结合思想, 借助线性规划法来确定对应的取值范围问题.

解法4:由于 $\triangle ABC$ 的三边长a,b,c成等差数列，满足 $a^{2}+b^{2}+c^{2}=63$ ，且 $2b=a+c,a+b>c$ ，将b视作已知量, 则有 $\left\{\begin{aligned}a^{2}+c^{2}&=63-b^{2},\\ a+c&=2b,\\ c-a&<b,\end{aligned}\right.$ 那么转化为在第一象限内存在点 $P(x,y)$ ，满足 $\left\{\begin{aligned}x^{2}+y^{2}&=63-b^{2},\\ x+y&=2b,\\ y-x&<b,\end{aligned}\right.$

求此时正数 b 的取值范围问题, 数形结合可知, 当直线 $x + y = 2b$ 与圆 $x^{2} + y^{2} = 63 - b^{2}$ 相切时, 正数 b 取得最大值, 此时有圆心 O 到直线的距离 $d = \frac{2b}{\sqrt{2}} = \sqrt{63 - b^{2}}$ , 解得 $b = \sqrt{21}$ , 则有 $b \leqslant \sqrt{21}$ , 当 a = b = c = $\sqrt{21}$ 时等号成立.

当直线 $x + y = 2b$ 与直线 $y - x = b$ 的交点 $\left(\frac{b}{2},\frac{3b}{2}\right)$ 在圆 $x^{2} + y^{2} = 63 - b^{2}$ 上时，正数 $b$ 取得最小值（由于 $y - x < b$ ，此时最小值取不到），此时有 $\left(\frac{b}{2}\right)^2 +\left(\frac{3b}{2}\right)^2 = 63 - b^2$ ，解得 $b = 3\sqrt{2}$

综上可知， $3\sqrt{2}<b\leqslant\sqrt{21}$ . 故填答案： $(3\sqrt{2},\sqrt{21}]$ .

# 三、变式探究

探究 1: 保留原问题的条件, 改变求解的结果, 变 “实数 b 的取值范围” 为 “实数 b 的最大值”, 在原题难度基础上有所减小, 同时简化过程, 从而得到变式 1:

变式1:已知 $\triangle ABC$ 的三边长a,b,c成等差数列,且 $a^{2}+b^{2}+c^{2}=63$ ，则实数 b 的最大值是 \_\_\_\_.

解析:设 $\triangle ABC$ 的三边长 a, b, c 成等差数列的公差为 d，则有 a=b-d, c=b+d，代入 $a^{2}+b^{2}+c^{2}=63$ ，整理可得 $3b^{2}+2d^{2}=63$ ，则当 d=0 时，b 有最大值 $\sqrt{21}$ ，即 $b\leqslant\sqrt{21}$ ，此时当 $a=b=c=\sqrt{21}$ 时等号成立，所以实数 b 的最大值是 $\sqrt{21}$ 。故填答案： $\sqrt{21}$ 。

探究 2: 保留原问题的条件, 增加一般三角形的条件为锐角三角形, 使得问题更特殊, 在原题难度基础上有所增加, 知识点也有所增加, 从而得到变式 2:

变式 2: 已知锐角 $\triangle ABC$ 的三边长 a, b, c 成等差数列，且 $a^{2} + b^{2} + c^{2} = 63$ ，则实数 b 的取值范围是 \_\_\_\_.

解析:设锐角 $\triangle ABC$ 的三边长 a, b, c 所成等差数列的公差为 d. 不失一般性, 假定 $a \leqslant b \leqslant c$ , 则 $d \geqslant 0$ , 则有 a = b - d, $c = b + d$ , 代入 $a^{2} + b^{2} + c^{2} = 63$ , 整理可得 $3b^{2} + 2d^{2} = 63$ , 则当 d = 0 时, b 有最大值 $\sqrt{21}$ , 即 $b \leqslant \sqrt{21}$ , 此时当 a = b = c = $\sqrt{21}$ 时等号成立.

结合三角形的性质可得 $a + b > c$ ，则有 $b - d + b > b + d$ ，整理可得 b > 2d，代入 $3b^{2} + 2d^{2} = 63$ ，可得 $3b^{2} + 2\left(\frac{b}{2}\right)^{2} > 63$ ，解得 $b > 3\sqrt{2}$ .

由 $\triangle ABC$ 为锐角三角形，结合余弦定理可知 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} > 0$ ，即 $a^2 + b^2 - c^2 > 0$ ，则有 $(b - d)^2 + b^2 - (b + d)^2 > 0$ ，解得 $b > 4d$ .代入 $3b^{2} + 2d^{2} = 63$ ，可得 $3b^{2} + 2\left(\frac{b}{4}\right)^{2} > 63$ ，解得 $b > \frac{6\sqrt{14}}{5}$

综上可知， $\frac{6\sqrt{14}}{5}<b\leqslant\sqrt{21}$ . 故填答案： $\left(\frac{6\sqrt{14}}{5},\sqrt{21}\right]$ .

# 四、规律总结

数列与解三角形的巧妙综合与交汇,不仅考查了等差数列的定义与性质,三角形的基本性质,解三角形的相关定理等相关知识,还考查了化归与转化思想,分类讨论思想,数形结合思想等,综合不等式、函数、线性规划等问题加以综合处理.根据多知识点之间的交汇,加强对相关内容的有效综合与合理转化,进而加以正确理解与掌握相关的知识与破解方法,有助于数学解题能力与应用能力的提高,真正提升数学能力,拓展数学素养.F
