# 谈培养高中生数学表达能力之我见

# 山东省淄博第六中学 李菁华

在新课改的推动下,数学教学中更加关注学生合作能力的培养,然若要保障合作顺利进行就需要学生运用严谨、规范的数学语言表达自己的见解,进而使沟通更加顺畅,合作更加高效 $^{[1]}$ .可见,无论是为了提升数学学习力,还是提升数学素养,培养学生数学表达能力都势在必行.为此,在日常教学中,教师应该将培养学生数学表达能力视为教学的一个重点.那么,何为数学表达能力?又应如何培养呢?笔者结合教学实践,提出了几点行之有效的教学策略.

# 1 何为数学表达能力

顾名思义,数学表达就是将数学内容和数学思想方法运用数学语言表达出来,而数学表达能力就是将自己解决问题的方法、过程、观点与建议用恰当的语言精准、顺畅地表达出来的能力.无论是书面表达还是口头表达,数学表达都应该做到以下几点:①表达清晰、准确;②语言严谨,逻辑性强;③通俗易懂;④简洁精炼.只有这样才能保证表达更准确,沟通更顺畅,进而发展学生数学思维,形成数学能力.

# 2 如何培养数学表达能力

数学表达是师生间进行知识传输和情感交流的纽带, 是知识生成和建构的“催化剂”. 为了更好地传递和沟通, 教师首先要建立一个和谐、平等的自由表达的环境, 让学生敢于表达, 愿意表达, 有机会表达; 其次, 教师要结合学情设计教学活动, 让学生参与到教学活动中来, 进而有内容可以交流和表达; 最后, 教师要充分发挥其示范作用, 用精准精炼的数学语言组织教学活动. 另外, 也要发挥其引领作用, 当学生出现表达不准确或表达错误时要及时纠正, 进而保证数学表达的科学性、合理性. 其实, 学生之所以考试时出现表达不顺畅的情况, 这与日常教学息息相关, 在教学中教师为了赶进度, 对一些数学表达中的“小问题”常置之不理, 久而久之, 这些“小问题”就成为了数学沟通障碍, 阻碍了学生思维发展. 那么, 在日常教学中应如何培养学生的数学表达能力呢?

# 2.1 注重数学阅读

大多数师生认为数学教学就是数学解题教学,解题是教学的重中之重,殊不知,数学教学也是数学语言教学,解题是数学语言的一种最直接的表达形式.对于数学语言的培养亦是教学的重点,而培养数学语言离不开数学阅读.值得注意的是,阅读并不是走马观花的“看”,那样会因为阅读缺乏深度而难以提炼出有价值的内容.在教学中,教师应有计划地对阅读方法进行指导,如:如何咬文嚼字、如何联想、如何批注、如何做提纲等,只有掌握了科学的阅读方法才能真正发挥阅读的价值.另外,教师可以组织师生共读或生生共读等阅读活动,并在阅读后组织学生进行交流,以此培养学生的表达能力,当然也要引导学生进行模仿,进而使表达更严谨、更规范.

# 案例1 函数的零点

对于“函数的零点”这一概念,很多学生并不重视,常认为零点就是图象与坐标轴的交点,为此教师引导学生进行咬文嚼字,从而挖掘概念的本质.

师:请大家阅读定义后,指出函数 $f(x)=x^{2}-2x-3$ 的零点.

生 1: 函数 $f(x)$ 的零点为 $(-1,0)$ 和 $(3,0)$ . (生 1 的答案给出后, 大多学生表示赞同.)

师:你是如何求的呢?

生 1: 函数 $f(x)=x^{2}-2x-3$ 的图象与 x 轴的交点.

生 2: 这样的说法不对, 零点并不是点。(大多学生投来诧异的眼神)

师:不是点,应该是什么呢?(教师追问)

生 2: 应该是实数. 我们把使函数 $y = f(x)$ 的值为 0 的实数 x 称之为函数 $y = f(x)$ 的零点.

师:生 2 说得很好.阅读得非常仔细.除了生 2 强调的“实数”外,其实还要注意一点,“零点”前面还有一个修饰语,即函数,谈到零点一定要知道其是针对函数而言的.

师:那么函数 $f(x)=x^{2}-2x-3$ 的零点应该是什么呢?

生 3: 零点为 -1 和 3, 即函数 $f(x)=x^{2}-2x-3$ 的图象与 x 轴交点的横坐标.

师:说得很好.那么联系方程,你有什么发现呢?

生 4: 它们是方程 $x^{2}-2x-3=0$ 的实根.

生 4 给出结论后,学生惊喜地发现,函数的零点其实质就是方程的根,这样新知就转化为学生熟悉的内容了.通过对定义的阅读引导学生分析和掌握概念中的关键词,进而准确把握其内涵,与此同时通过师生互动交流,深化了对概念的理解,也挖掘出了概念的本质特征.这样既让学生掌握了新知,又发现了数学知识间的关联性,有利于认知体系的完善与优化.

# 2.2 加强多元表征

正确的数学语言表征为更好地理解数学、应用数学提供了必要的前提。在学习中应重视不同形式间的相互转换，进而通过多元表征来寻找解决问题的切入点，挖掘出正确的解题思路。在教学中，教师要为学生提供一个进行多元表征的平台，引导学生注意文字语言、符号语言、图形语言等不同数学语言互译的要领，通过多元表征来凸显问题本质，进而优化学生的认知结构，提升数学表达能力 $^{[3]}$ 。

# 案例 2 复习等差数列的概念

师:等差数列的定义大家都背得滚瓜烂熟,那么如何用符号语言来表达呢?（教师预留时间让学生组织符号语言表述概念）

生 $1:a_{n+1}-a_{n}=d(n\in\mathbf{N}^{*},d$ 为常数).

师:还有其他的形式吗?

生2: 还可以用 $2a_{n}=a_{n+1}+a_{n-1}(n\geqslant2$ 且 $n\in N^{*}$ 表示.

生 3: 还可以用 $a_{n}=kn+b(k,b$ 为常数) 表示.

师:非常好,三位同学的表述都非常准确.

师:在数学中,如果借助“形”会使问题更直观,那么,等差数列是否可以用“形”来表达呢?(学生陷入沉思)

生 4: 如果数列 $\{a_{n}\}$ 是等差数列, 则以 $(n, a_{n})$ 为坐标的点在一条直线上, 即 $a_{n}$ 是关于 n 的一次函数或常数函数.

在复习概念时,教师通过恰当的提示,启发和引导学生从不同角度灵活表征,进而为理解概念,揭示概念实质奠定坚实基础.在教学过程中,教师诱发学生运用不同的数学语言表达同一个问题,发展了学生的数学表达能力,也使学生的表达更具条理性和逻辑性.

# 2.3 开展数学说题

在数学教学中发现,有部分学生口头表达能力较弱,每天只是埋头苦干,不重视交流和沟通,并未形成良好的合作意识.基于此,笔者在教学中开展数学说题活动,尝试通过“说”引导学生进行合作交流,实现优势互补,从而提升数学表达能力.

案例 3 已知两个等差数列 $\{a_{n}\},\{b_{n}\}$ 的前 n 项和分别为 $S_{n}, T_{n}$ ，若对于任意的正整数 n 都有 $\frac{S_{n}}{T_{n}} = \frac{7n + 45}{n + 3}$ ，则使 $\frac{a_{n}}{b_{n}}$ 为整数的正整数 n 的个数是 \_\_\_\_.

师:无需计算,请结合你的直观感受谈一谈你对本题的认识.

生 1:从题设信息可以看出,本题是一道以等差数列及其前 n 项和为背景的经典的等差数列问题,本题需要一定的推理能力和逻辑分析能力,有一定难度.

师:说得很好,接下来应该如何找到合适的切入点呢?

生 2: 已知给出了等差数列 $\{a_{n}\}, \{b_{n}\}$ 的前 n 项和的关系式为 $\frac{S_{n}}{T_{n}} = \frac{7n + 45}{n + 3}$ ，根据 $a_{n} = S_{n} - S_{n-1} (n < 1)$ ，为此可以根据关系式将 $a_{n}$ 与 $S_{n}$ 建立联系.

师:尝试该如何求解呢?

生3:根据已知,可以设 $S_{n}=(7n+45)k$ , $T_{n}=(n+3)k(k\neq0)$ , 则 $a_{n}=S_{n}-S_{n-1}=(7n+45)k-(7n+38)k=7k$ . 同理 $b_{n}=T_{n}-T_{n-1}=k$ , 所以 $\frac{a_{n}}{b_{n}}=\frac{7k}{k}=7$ , 故符合题意的正整数 n 为无穷多个.

生 4: 答案不对. 上述假设根本不成立, 假设中 $S_{n}$ 和 $T_{n}$ 为一次函数, 而等差数列的前 n 项和 $S_{n}=na_{1}+\frac{n(n-1)}{2}d$ , 若 $d\neq0$ 时, $S_{n}$ 是关于 n 的二次函数.

师:分析得非常有道理,由于对公式理解不够透彻,因此在假设时出现了错误.那么该如何假设呢?

生5: 设 $S_{n}=(7n+45)nk, T_{n}=(n+3)nk$ ，其中 $k\neq0$ ，则 $a_{n}=S_{n}-S_{n-1}=(7n+45)nk-(7n+38)\cdot(n-1)k=(14n+38)k.$

同理, 得 $b_{n}=T_{n}-T_{n-1}=(2n+2)k$ , 故 $\frac{a_{n}}{b_{n}}=\frac{(14n+38)k}{(2n+2)k}=7+\frac{12}{n+1}$ . 若使 $\frac{a_{n}}{b_{n}}$ 为整数, 则 $n+1$ 必为 12 的约数, 所以 n=1,2,3,5,11, 故符合题意的正整数应为 5 个.

生6:其实还可以根据等差数列的性质求解,即 $\frac{a_{n}}{b_{n}}=\frac{S_{2n-1}}{T_{2n-1}}=\frac{7(2n-1)+45}{(2n-1)+3}=7+\frac{12}{n+1}.$

在“说题”过程中学生的参与度较高，从对本题的初步认识，到错误的纠正，再到正解的给出，都充分发挥了学生的主体作用。“说题”教学为学生提供了一个较好的语言表达环境，学生可以自由表达自己的见解，进而有效提升表达能力和沟通能力。

总之,教师在组织教学活动时应积极为学生创设数学语言表达环境,鼓励学生运用精准的数学语言进行信息交流,进而在提升学生数学表达能力的同时,提高学生的数学思维能力和数学素养.
