# 解三角形中的最值或范围问题

# ● 哈尔滨师范大学教师教育学院 李鸿媛

摘要: 解三角形的最值或范围问题是高考考查的热点内容之一, 并且对解三角形的命题设计, 不只局限于解三角形, 而是通常利用正余弦定理、三角形面积公式等求解三角形的边、角、周长和面积的最值等问题. 这类问题的解法主要是将边角互化转化为三角函数的最值问题, 或利用基本不等式求最值. 本文中对这类问题加以归类解析, 以提升学生的解题能力.

关键词: 解三角形; 最值; 范围

# 1 与边有关的最值或范围问题

例 1 在 $\triangle ABC$ 中, 角 $A, B, C$ 的对边分别是 $a, b, c$ , 角 $B = \frac{\pi}{3}$ , 若 $a + c = 4$ , 则 $b$ 的取值范围为 \_\_\_\_.

解析:由 $a+c=4, B=\frac{\pi}{3}$ ，由余弦定理得 $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，则 $b^{2}=(a+c)^{2}-2ac-2ac\cos\frac{\pi}{3}$ ，即 $b^{2}=16-3ac$ .

由 $a + c \geqslant 2\sqrt{ac}$ ，得 $4 \geqslant 2\sqrt{ac}$ ，即 $0 < ac \leqslant 4$ ，于是 $4 \leqslant b^2 < 16$ ，所以 $2 \leqslant b < 4$ 。

评析:本题利用已知条件结合余弦定理,借助基本不等式求三角形边的取值范围 $^{[1]}$ ,渗透了逻辑推理、数学运算等数学核心素养.

例 2 在 $\triangle ABC$ 中, 角 $A, \frac{3}{2}B, C$ 成等差数列, 且 $\triangle ABC$ 的面积为 $1+\sqrt{2}$ , 则 $AC$ 边长的最小值是\_\_\_\_.

解析:由 $A, \frac{3}{2}B, C$ 成等差数列, 得 $A + C = 3B$ . 又 $A + B + C = \pi$ , 所以 $B = \frac{\pi}{4}$ . 设角 A, B, C 所对的边分别为 a, b, c, 则由 $S_{\triangle ABC} = \frac{1}{2}ac \sin B = 1 + \sqrt{2}$ , 可得 $ac = 2\sqrt{2} + 4$ . 由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac \cos B$ , 则 $b^{2} = a^{2} + c^{2} - \sqrt{2}ac$ . 又 $a^{2} + c^{2} \geqslant 2ac$ , 则 $b^{2} \geqslant (2 - \sqrt{2})ac$ , 即 $b^{2} \geqslant (2 - \sqrt{2})(2\sqrt{2} + 4)$ , 所以 $b \geqslant 2$ (当且仅当 a = c 时, 等号成立). 故 AC 边长的最小值为 2.

评析:本题考查了学生对等差数列的概念、三角形内角和定理、三角形面积公式、余弦定理等的掌握情况.解题的关键是将余弦定理与不等式相结合,进而求出三角形一边的最值.

# 2 与角有关的最值或范围问题

例 3 在 $\triangle ABC$ 中, 角 A, B, C 的对边分别是 a,b, c, 若 $A \neq \frac{\pi}{2}$ , $\sin C + \sin(B - A) = \sqrt{2} \sin 2A$ , 则角 A 的取值范围为 \_\_\_\_.

解法一: 在 $\triangle ABC$ 中, $C = \pi - (A + B)$ , 则 $\sin C = \sin(A + B)$ , 所以 $\sin(A + B) + \sin(B - A) = \sqrt{2} \sin 2A$ , 即 $2\sin B\cos A = 2\sqrt{2}\sin A\cos A$ . 又 $A \neq \frac{\pi}{2}$ , 则 $\cos A \neq 0$ , 所以 $\sin B = \sqrt{2}\sin A$ . 由正弦定理, 得 $b = \sqrt{2}a$ , 则 A 为锐角. 又 $\sin B = \sqrt{2}\sin A \in (0,1]$ , 于是可得 $\sin A \in \left(0, \frac{\sqrt{2}}{2}\right]$ , 故 $A \in \left(0, \frac{\pi}{4}\right]$ .

评析: 解法一利用三角形内角和定理、两角和与差的正弦公式、正弦定理与三角函数的性质等知识，对学生的推理能力、运算能力和直观想象能力进行了考查.

解法二: 在 $\triangle ABC$ 中, $C = \pi - (A + B)$ , 则 $\sin C = \sin(A + B)$ , 所以 $\sin(A + B) + \sin(B - A) = \sqrt{2} \sin 2A$ , 即 $2\sin B\cos A = 2\sqrt{2}\sin A\cos A$ . 又 $A \neq \frac{\pi}{2}$ , 则 $\cos A \neq 0$ , 所以 $\sin B = \sqrt{2}\sin A$ . 由正弦定理, 可得 $b = \sqrt{2}a$ . 结合余弦定理, 可以得到 $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = \frac{\frac{1}{2}b^{2} + c^{2}}{2bc} \geqslant \frac{2\sqrt{\frac{1}{2}b^{2} \cdot c^{2}}}{2bc} = \frac{\sqrt{2}}{2}$ , 当且仅当 $c = \frac{\sqrt{2}}{2}b$ 时, 等号成立, 故 $A \in \left(0, \frac{\pi}{4}\right]$ .

评析:解法二考查了三角形内角和定理、两角和与差的正弦公式、正弦定理、余弦定理、基本不等式等知识.这种解题方法需要学生灵活运用两个正数的和与积的关系,充分体现学生的数学运算能力和数据分析能力.

# 3 与周长有关的最值或范围问题

例 4 △ABC 为锐角三角形, 角 A, B, C 所对的边分别为a,b,c,已知 $\frac{\sqrt{3}}{3}b\sin C+c\cos B=a$ ,且c=2,
求 $\triangle ABC$ 周长的最大值.

解析:由 $\frac{\sqrt{3}}{3}b\sin C+c\cos B=a$ ，根据正弦定理，得 $\frac{\sqrt{3}}{3}\sin B\sin C+\sin C\cos B=\sin A$ 。由 $A=\pi-(B+C)$ ，得 $\sin A=\sin(B+C)$ 。所以 $\frac{\sqrt{3}}{3}\sin B\sin C+\sin C\cos B=\sin(B+C)$ ，即 $\frac{\sqrt{3}}{3}\sin B\sin C=\sin B\cos C$ 。

由 $\sin B \neq 0$ ，得 $\frac{\sqrt{3}}{3}\sin C = \cos C$ .

又 $\cos C \neq 0$ ，所以 $\tan C = \sqrt{3}$ .

而 $0 < C < \pi$ ，则 $C = \frac{\pi}{3}$

根据正弦定理，得 $a = \frac{4\sqrt{3}}{3}\sin A, b = \frac{4\sqrt{3}}{3}\sin B$ 则 $a + b + c = \frac{4\sqrt{3}}{3}\sin A + \frac{4\sqrt{3}}{3}\sin B + 2 = \frac{4\sqrt{3}}{3}\sin A + \frac{4\sqrt{3}}{3}\sin \left(\frac{2\pi}{3} - A\right) + 2 = \frac{4\sqrt{3}}{3}\left(\frac{3}{2}\sin A + \frac{\sqrt{3}}{2}\cos A\right) + 2 = 4\sin \left(A + \frac{\pi}{6}\right) + 2.$

由 $\triangle ABC$ 为锐角三角形，可知 $\left\{ \begin{array}{l}0 < A < \frac{\pi}{2},\\ 0 < \frac{2\pi}{3} -A <   \frac{\pi}{2}, \end{array} \right.$ 解得 $\frac{\pi}{6} <  A <   \frac{\pi}{2}$ 所以 $\frac{\pi}{3} <  A + \frac{\pi}{6} <  \frac{2\pi}{3}$

因此 $\frac{\sqrt{3}}{2} < \sin \left(A + \frac{\pi}{6}\right) \leqslant 1$ .

故 $2\sqrt{3} + 2 < 4\sin \left(A + \frac{\pi}{6}\right) + 2 \leqslant 6.$

因此 $\triangle ABC$ 周长的最大值为6.

评析:这道题解题的关键是利用正弦定理将边化为角,转化为求三角函数的最值问题 $^{[2]}$ ,考查了逻辑推理和数学运算等核心素养.

# 4 与面积有关的最值或范围问题

例 5 △ABC 的内角 A, B, C 所对的边分别是 a, b, c，已知 $2(c - a \cos B) = \sqrt{3} b$ .

(1)求角 A;

(2) 若 a=2，求 $\triangle ABC$ 面积的取值范围.

解法一:(1)略.

(2)由(1)知 $A=\frac{\pi}{6}$ ，又a=2，根据正弦定理，可得

$$
b = 4 \sin B, c = 4 \sin C.
$$

由 $C = \pi - A - B = \frac{5\pi}{6} - B$ ，得 $\sin C = \sin \left( \frac{5\pi}{6} - B \right)$ .

所以， $S_{\triangle ABC} = \frac{1}{2} bc \sin A = \frac{1}{4} bc = 4 \sin B \sin C = 4 \sin B \sin \left( \frac{5\pi}{6} - B \right) = 4 \sin B \left( \frac{1}{2} \cos B + \frac{\sqrt{3}}{2} \sin B \right) = 2 \sin B \cos B + 2\sqrt{3} \sin^2 B = \sin 2B - \sqrt{3} \cos 2B + \sqrt{3} = 2 \sin \left( 2B - \frac{\pi}{3} \right) + \sqrt{3}$ .

由 $0 < B < \frac{5\pi}{6}$ , 得 $-\frac{\pi}{3} < 2B - \frac{\pi}{3} < \frac{4\pi}{3}$ , 所以可知 $-\frac{\sqrt{3}}{2} < \sin \left(2B - \frac{\pi}{3}\right) \leqslant 1$ , 故 $0 < S_{\triangle ABC} \leqslant 2 + \sqrt{3}$ , 即 $\triangle ABC$ 面积的取值范围为 $(0, 2 + \sqrt{3}]$ .

解法二:(1)略.

(2)由(1)知 $A=\frac{\pi}{6}, a=2$ ，则 $S_{\triangle ABC}=\frac{1}{4}bc$ .

由 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{b^2 + c^2 - 4}{2bc} = \frac{\sqrt{3}}{2}$ ，可得 $b^2 + c^2 - 4 = \sqrt{3}bc$ 。又 $b^2 + c^2 \geqslant 2bc$ ，则 $0 < bc \leqslant \frac{4}{2 - \sqrt{3}} = 4(2 + \sqrt{3})$ ，所以 $0 < S_{\triangle ABC} \leqslant 2 + \sqrt{3}$ 。

故 $\triangle ABC$ 面积的取值范围为 $(0,2+\sqrt{3}]$ .

评析:本题求解三角形面积的取值范围,解法一通过正弦定理将边转化为角,再利用三角函数的性质,求解三角形面积的取值范围.解法二先利用余弦定理,结合不等式 $b^{2}+c^{2}\geqslant2bc$ ,求解bc的取值范围,接着利用三角形面积 $S_{\triangle ABC}=\frac{1}{2}bc\sin A$ 求出面积的取值范围 $^{[3]}$ .这两种解法都考查了数学运算、逻辑推理等数学核心素养.

数学这门学科需要学生具备较强的逻辑推理能力、运算能力、直观想象能力等.针对解三角形最值或范围问题,学生需要熟练掌握三角形的面积公式、同角三角函数的基本关系、正弦定理、余弦定理、基本不等式等知识,并能够进行综合运用.
