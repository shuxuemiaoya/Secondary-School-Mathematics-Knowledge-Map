孟凡群

多元函数的最值问题,常常以压轴题的身份“现身”于各种考试题中,尤其是一类条件等式下多元函数最值问题,“引无数考生竞折腰”.求解这类问题,不仅要求考生善于对目标函数进行适当变形,使其能够与基本不等式的应用相“匹配”,而且要求考生能根据实际问题,选择恰当的方法,从而达到优化解题过程的目的.基于此,本文介绍一种求多元函数最值问题的妙法——双换元法.

双换元,就是为了更好地解决问题,对题目中的两个部分用两个“新元”同时替换,使原问题凸显本质,便于构造基本不等式模型,从而让解答过程更流畅.本文先介绍双换元法在三类典型问题中的应用,同时将其引申为三换元法,以体现这种方法的灵活性.

# 1 双换元法的应用

双换元法,一般是针对多元函数的最值问题,那么这个方法主要能帮助我们解决哪些问题呢?

# 1.1 分式型最值问题

例 1 （1）已知 a, b, c 均为正实数， $ab + ac = 4$ ，则 $\frac{2}{a} + \frac{2}{b + c} + \frac{8}{a + b + c}$ 的最小值是 \_\_\_\_.

(2)已知 $a>1, b>\frac{1}{2}, \frac{1}{a-1}+\frac{2}{2b-1}=1$ ，则 $\frac{1}{a}+\frac{1}{b}$ 的最大值为 \_\_\_\_.

![](images/0b6179d492d02d654d2776a6d3b444719f27e234c24a361dae166692bfdd13ac.jpg)

(1)设 $a = x, b + c = y$ ，原题转化为已知 $x > 0, y > 0$ ，且 $xy = 4$ ，求 $\frac{2}{x} + \frac{2}{y} + \frac{8}{x + y}$ 的最小值.此时有

$$
\frac {2}{x} + \frac {2}{y} + \frac {8}{x + y} = \frac {1}{2} (\frac {4}{x} + \frac {4}{y}) + \frac {8}{x + y} =
$$

$$
\frac {1}{2} (y + x) + \frac {8}{x + y} \geqslant 2 \sqrt {4} = 4,
$$

当且仅当 $\frac{1}{2}(y+x)=\frac{8}{x+y},xy=4$ ，即x=y=2时，
等号成立，所以 $\frac{2}{x}+\frac{2}{y}+\frac{8}{x+y}$ 的最小值为4.

(2) 令 $\frac{1}{a - 1} = x, \frac{1}{2b - 1} = y$ ，则 $x > 0, y > 0, a = \frac{x + 1}{x}, b = \frac{y + 1}{2y}, x + 2y = 1$ ，所以 $x + 1 + 2y + 2 = 4$ ，故

$$
\frac {1}{a} + \frac {1}{b} = \frac {x}{x + 1} + \frac {2 y}{y + 1} =
$$

$$
\frac {x + 1 - 1}{x + 1} + \frac {2 (y + 1) - 2}{y + 1} = 3 - \frac {1}{x + 1} - \frac {2}{y + 1} =
$$

$$
3 - \frac {1}{4} \left(\frac {1}{x + 1} + \frac {2}{y + 1}\right) (x + 1 + 2 y + 2) =
$$

$$
3 - \frac {1}{4} [ 5 + \frac {2 (y + 1)}{x + 1} + \frac {2 (x + 1)}{y + 1} ] \leqslant
$$

$$
3 - \frac {1}{4} [ 5 + 2 \sqrt {\frac {2 (y + 1)}{x + 1} \cdot \frac {2 (x + 1)}{y + 1}} ] = \frac {3}{4},
$$

当且仅当 $x=\frac{1}{3}$ , $y=\frac{1}{3}$ ，即 a=4, b=2 时，等号成立，
故 $\frac{1}{a}+\frac{1}{b}$ 的最大值为 $\frac{3}{4}$ .

![](images/074228d058c45785babc6854abf765163b3d3f5c6222ca6338253f319d0decfd.jpg)

点评

一般地,处理多元最值问题的思考角度有以下几个.1)从元的个数角度,关键在于减元处理，可利用代入消元、整体换元、三角换元等方法减元；2)从元的次数角度，关键在于转化目标函数（代数式），如一次二次比分式型、齐次比型、双勾函数型等；3)从元的组合结构角度，关键在于结构分析，将问题转化为整体元的和、积、差、平方和、倒数和等并列结构的形式，再利用均值不等式等常用不等式求解最值，注意等号成立的条件.

# 1.2 条件等式可分解型最值问题

![](images/061c6b17c26abc3eef231f19582986427cf4b46683c08b97656bb0b0f93e873f.jpg)

例2 若实数 $x, y$ 满足 $x^{2} + 2xy - 3y^{2} = 1$ ，则$x^{2}+y^{2}$ 的最小值是 \_\_\_\_.

![](images/e876e4f6a070116afab1f54cb5a12f76a7a2830463633c8067077f32c40877eb.jpg)

因为 $x^{2} + 2xy - 3y^{2} = 1$ ，所以 $(x + 3y)(x -$

$y) = 1$ ，令 $x + 3y = t(t \neq 0)$ ，则 $x - y = \frac{1}{t}$

即 $x = \frac{1}{4} (t + \frac{3}{t}), y = \frac{1}{4} (t - \frac{1}{t})$ ，故

$$
x ^ {2} + y ^ {2} = \frac {1}{1 6} (t + \frac {3}{t}) ^ {2} + \frac {1}{1 6} (t - \frac {1}{t}) ^ {2} =
$$

$$
\frac {1}{8} \left(t ^ {2} + \frac {5}{t ^ {2}} + 2\right) \geqslant \frac {1}{8} \left(2 \sqrt {t ^ {2} \cdot \frac {5}{t ^ {2}}} + 2\right) = \frac {\sqrt {5} + 1}{4},
$$

当且仅当 $t^2 = \sqrt{5}$ 时，等号成立，故 $x^{2} + y^{2}\geqslant \frac{\sqrt{5} + 1}{4}$ 即 $x^{2} + y^{2}$ 的最小值为 $\frac{\sqrt{5} + 1}{4}$

![](images/99bfd81550d79d2ea518f081ab145a1a95ecf657a87efa56c55286e82f79908b.jpg)

# 点评

虽然换元时只用了一个变量,但变量与变量的倒数相当于是两个变量,双换元法在解决两个变量(二次式子)时可以起到简化解题过程的作用,这一方法在近几年的各地模拟题求解中屡见不鲜.

# 1.3 条件等式简单、目标函数复杂的最值问题

![](images/f9333a2c970e250f058bae942af1d7b2241f9b7e9b43c366315a950ea1799f09.jpg)

例3 已知正实数 $m, n$ 满足 $m + n = 1$ .

(1)求 $\frac{m^{2}}{m+1}+\frac{n^{2}}{n+2}$ 的最小值；  
(2)求 $\frac{1}{m+1}+\frac{2m-1}{n+2}$ 的最小值.

![](images/d5ace8aaafee2ebd71120eca5c2d415015c798d61c71fb4040e643abbc5215ca.jpg)

(1) 因为 $m > 0, n > 0, m + n = 1$ ，令 $a = m + 1$

$(a > 1), b = n + 2 (b > 2)$ , 则 $m = a - 1, n =$ $b - 2$ ，且 $a + b = m + n + 3 = 4$ ，所以

$$
\frac {m ^ {2}}{m + 1} + \frac {n ^ {2}}{n + 2} = \frac {(a - 1) ^ {2}}{a} + \frac {(b - 2) ^ {2}}{b} =
$$

$$
\frac {a ^ {2} - 2 a + 1}{a} + \frac {b ^ {2} - 4 b + 4}{b} =
$$

$$
\left(\frac {1}{a} + \frac {4}{b}\right) + (a + b) - 6 = \frac {1}{4} (a + b) \left(\frac {1}{a} + \frac {4}{b}\right) + 4 - 6 =
$$

$$
\frac {1}{4} \left(1 + \frac {b}{a} + \frac {4 a}{b} + 4\right) - 2 \geqslant
$$

$$
\frac {1}{4} (5 + 2 \sqrt {\frac {b}{a} \cdot \frac {4 a}{b}}) - 2 = \frac {1}{4},
$$

当且仅当 $\frac{b}{a}=\frac{4a}{b}$ 且 $a+b=4$ ，即 $a=\frac{4}{3}, b=\frac{8}{3}$ 时，等号成立，所以当且仅当 $m=a-1=\frac{1}{3}, n=b-2=\frac{2}{3}$ 时， $\frac{m^{2}}{m+1}+\frac{n^{2}}{n+2}\geqslant\frac{1}{4}$ ，故 $\frac{m^{2}}{m+1}+\frac{n^{2}}{n+2}$ 的最小值为 $\frac{1}{4}$ .

(2)由(1)得 $2m-1=2(1-n)-1=1-2n=1-2(b-2)=5-2b$ ，所以

$$
\frac {1}{m + 1} + \frac {2 m - 1}{n + 2} = \frac {1}{a} + \frac {5 - 2 b}{b} = \frac {1}{a} + \frac {5}{b} - 2 =
$$

$$
\frac {1}{4} (a + b) \left(\frac {1}{a} + \frac {5}{b}\right) - 2 = \frac {1}{4} \left(1 + \frac {b}{a} + \frac {5 a}{b} + 5\right) - 2 \geqslant
$$

$$
\frac {1}{4} (6 + 2 \sqrt {\frac {b}{a} \cdot \frac {5 a}{b}}) - 2 = \frac {\sqrt {5}}{2} - \frac {1}{2},
$$

当且仅当 $\frac{b}{a} = \frac{5a}{b}$ 且 $a + b = 4$ ，即 $a = \sqrt{5} -1,b = 5 - \sqrt{5}$

时，等号成立，所以当且仅当 $m = a - 1 = \sqrt{5} -2,n =$ $b - 2 = 3 - \sqrt{5}$ 时， $\frac{1}{m + 1} +\frac{2m - 1}{n + 2}\geqslant \frac{\sqrt{5}}{2} -\frac{1}{2}$ ，故 $\frac{1}{m + 1}+$ $\frac{2m - 1}{n + 2}$ 的最小值为 $\frac{\sqrt{5}}{2} -\frac{1}{2}$

![](images/714e5988b7711537797d301edc5e57e87cba96ec587123071eece3dd8b72ba9c.jpg)

# 点评

本题双换元的目的是使目标函数变得简单，并容易拆分，为“1”的代换法和基本不等式的应用创造条件.

# 2 双换元的延伸

通过以上分析,不难看出双换元是指解一个问题时同时换两个元,那么对于有些更复杂的多元最值问题,能否换三个元呢?

![](images/9d8b1dc0839616a1033f5b341c2ad3e0611e4fb6e80a25c8cfc05d3dbd9a9157.jpg)

例4 已知 $a > 0, b > 0, c > 0$ ，则 $\frac{a + 2b + 5c}{a + b} +$ $\frac{8a+2b+5c}{2b+3c}+\frac{a+3b+3c}{2c+a}$ 的最小值为 \_\_\_\_.

![](images/f6e5e3147fdd617194a0aa3a7ee606c1b923e9fedeb5a6ed1dd5f5ba2bc1307b.jpg)

设 $a + b = x, 2b + 3c = y, 2c + a = z$ ，则 $x >$

$0, y > 0, z > 0$ ，且 $a = \frac{4x - 2y + 3z}{7}, b =$

$\frac{3x+2y-3z}{7},c=\frac{-2x+y+2z}{7}$ ，所以 $b+5c=-x+$ $y+z,8a+2c=4x-2y+4z,3b+c=x+y-z$ ,故

$$
\frac {a + 2 b + 5 c}{a + b} + \frac {8 a + 2 b + 5 c}{2 b + 3 c} + \frac {a + 3 b + 3 c}{2 c + a} =
$$

$$
3 + \frac {b + 5 c}{a + b} + \frac {8 a + 2 c}{2 b + 3 c} + \frac {3 b + c}{2 c + a}.
$$

又 $\frac{b + 5c}{a + b} +\frac{8a + 2c}{2b + 3c} +\frac{3b + c}{2c + a} =$

$$
\frac {- x + y + z}{x} + \frac {4 x - 2 y + 4 z}{y} + \frac {x + y - z}{z} =
$$

$$
(\frac {y}{x} + \frac {z}{x} - 1) + (\frac {4 x}{y} + \frac {4 z}{y} - 2) + (\frac {x}{z} + \frac {y}{z} - 1) =
$$

$$
\left(\frac {y}{x} + \frac {4 x}{y}\right) + \left(\frac {z}{x} + \frac {x}{z}\right) + \left(\frac {4 z}{y} + \frac {y}{z}\right) - 4 \geqslant 6,
$$

所以 $\frac{a + 2b + 5c}{a + b} +\frac{8a + 2b + 5c}{2b + 3c} +\frac{a + 3b + 3c}{2c + a}\geqslant 9$ ，当且

仅当 $\frac{y}{x}=\frac{4x}{y},\frac{z}{x}=\frac{x}{z},\frac{4z}{y}=\frac{y}{z}$ ，即y=2x,z=x,y=2z，即 y=2x, z=x 时，等号成立，则所求最小值为 9.

![](images/0908a1898f6f7e9cbf2aac917d8a8f69f2269ccd0f868d2cd1e5d3e7b031f63c.jpg)

# 点评

本例同时换了三个“新元”，虽然没有达到“减元”的效果，却打破了原有式子的结构，使我们更容易应用基本不等式解题.
