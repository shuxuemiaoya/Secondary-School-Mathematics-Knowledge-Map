# 基于函数单调性定义引发的思考

范明辉 黄雨霜

(湖北省荆门市龙泉中学)

函数单调性是刻画函数性态的重要工具, 是高中数学中的一个重要知识, 也是高考的重要考点. 人教 A 版普通高中教科书数学必修第一册中给出的函数单调性的定义是这样的.

一般地，设函数 $f(x)$ 的定义域为 $D$ ，区间 $I \subseteq D$ 如果 $\forall x_1, x_2 \in I$ ，当 $x_1 < x_2$ 时，都有 $f(x_1) < f(x_2)$ ，那么就称函数 $f(x)$ 在区间 $I$ 上单调递增；当 $x_1 < x_2$ 时，都有 $f(x_1) > f(x_2)$ ，那么就称函数 $f(x)$ 在区间 $I$ 上单调递减.

介绍完函数单调性的定义之后,教材紧跟而来的是对函数单调性的研究与证明问题.本文基于函数单调性的定义,总结归纳与这一定义相关的一些重点问题及其处理方法,以期为读者学习函数单调性提供新的思考.

# 1 用定义证明函数单调性

在课堂教学中,教师一般会给学生总结用单调性的定义证明函数单调性的基本步骤,即取值、作差、变形、定号、下结论.这就导致学生碰到用定义证明函数单调性的问题,基本上就采取作差的方式去处理.那么,证明函数的单调性是否一定要作差?作差的目的是什么?

基于函数单调性的定义, 在区间 I 中取值 $x_{1} < x_{2}$ , 接下来就是判断函数值 $f(x_{1})$ 与 $f(x_{2})$ 的大小关系. 要知道, 作差的目的是比较函数值 $f(x_{1})$ 与 $f(x_{2})$ 的大小. 而作差法是处理比较大小问题的常用方法, 因此不论是教材上的例题解答还是教师的课堂教学中, 都喜欢采用作差的方法. 值得注意的是, 作差法是比较大小的常用方法, 但不是唯一方法. 机械地总结用定义证明函数单调性的基本步骤, 容易形成思维定式, 导致学生一遇到这样的问题就作差, 甚至因此走进“死胡同”.

# 1.1 利用不等式的基本性质

![](images/6b8cf5505717d3e3e949b1b947347cdf75a4f28b06ad0837ca0e25ae2602597d.jpg)

例 1 （人教 A 版普通高中教科书数学必修第一册 78 页例 1) 根据定义, 研究函数 $f(x)=kx+b(k\neq$

0) 的单调性.

![](images/13c8e9373e1a453589c36ca1fe3e006bff8a0599a7bf957f051df77af0ab7c9f.jpg)

解析

函数 $f(x) = kx + b (k \neq 0)$ 的定义域是 $\mathbf{R}$ .

$\forall x_{1},x_{2}\in\mathbf{R}$ 且 $x_{1}<x_{2}$ ，当k>0时， $kx_{1}<$ $kx_{2}, kx_{1}+b<kx_{2}+b$ ，即 $f(x_{1})<f(x_{2})$ ，则 $f(x)=kx+b$ 是增函数；当 k<0 时， $kx_{1}>kx_{2}, kx_{1}+b>kx_{2}+b$ ，即 $f(x_{1})>f(x_{2})$ ，则 $f(x)=kx+b$ 是减函数.

![](images/fa1633d90c8a1205117e626db3ccf81098f7a0409e580853a07d6110da263d26.jpg)

点评

本题借助不等式的基本性质,给出了教材中例题的不同解法,既能告诉学生,证明单调性不止作差一种方式,又顺应了新教材的内容编排顺序,用“旧知”(不等式的基本性质)证明“新知”(函数的单调性),体现了对已学知识的应用.同时,从学生的最近发展区出发,借助对初中学过的比较熟悉的一次函数单调性的研究,让学生进一步体会函数的单调性这一“新知”.

# 1.2 利用作商法

![](images/1a39b4d44df49a103a9c0c1a27db0761bc3bb941c17eb11337089fe009bd3b74.jpg)

例2 若非零函数 $f(x)$ 对任意实数 $x, y$ 均有$f(x+y)=f(x)\cdot f(y)$ ，且当x<0时， $f(x)>1$ ，求证： $f(x)$ 为R上的减函数.

![](images/222a4c08a40579d6beb3a1cb082ff5042174e7906883d948066b24110eaadff2.jpg)

解析

因为 $\forall x_{1},x_{2}\in \mathbf{R},x_{1} <   x_{2}$ ，所以 $x_{1} - x_{2} <   0$ 故 $f(x_{1} - x_{2}) > 1$ ，则

$$
\frac {f \left(x _ {1}\right)}{f \left(x _ {2}\right)} = \frac {f \left(x _ {2} + x _ {1} - x _ {2}\right)}{f \left(x _ {2}\right)} =
$$

$$
\frac {f (x _ {2}) \bullet f (x _ {1} - x _ {2})}{f (x _ {2})} = f (x _ {1} - x _ {2}) > 1,
$$

又 $f(x_{2})>0$ ，所以 $f(x_{1})>f(x_{2})$ ，即 $f(x)$ 为 R 上的减函数.

![](images/30e8635fd2af50200c0b3ccf4f46c74a495ccdbbd500883c67f7564dbb6c9e62.jpg)

点评

本例借助作商法比较函数值 $f(x_{1})$ 与 $f(x_{2})$ 的大小,给出了作差与借助不等式的基本性质之外的第三种处理方式.从多角度看待用定义证明函数单调性问题,能够帮助学生打开思路,将所学知识有机地糅合起来,融会贯通.

# 2 函数的单调区间不能简单合并

研究清楚函数单调性之后,自然要给出相应的结论,指明函数在具体区间上的单调性,由此而来的一个问题是单调区间的书写问题.许多高中数学教师都给学生强调过这么一句话:单调区间不能用并集符号连接.单调区间一定不能用并集符号连接吗?事实上,这句话是不严谨的.

在规范单调区间的书写时,教师通常会以反比例函数的单调性为例进行说明.函数 $f(x)=\frac{1}{x}$ 在 $(-∞,0)$ 和 $(0,+∞)$ 上都是单调递减的,但是不能说函数 $f(x)=\frac{1}{x}$ 在 $(-∞,0)∪(0,+∞)$ 上单调递减,或在整个定义域上单调递减,即不能说 $f(x)=\frac{1}{x}$ 是减函数.

究其根本,还是在函数单调性的定义上.定义中强调“ $\forall x_{1},x_{2}\in I$ ”,重点在任意性上.当选取的 $x_{1}\in (-\infty ,0),x_{2}\in (0, + \infty)$ 时,有 $x_{1} <   x_{2}$ ,且 $f(x_{1})<  0 <   f(x_{2})$ ，这与函数单调递减的定义相矛盾.矛盾的根源在于是在整个定义域上进行取值，而不是在单调区间内分别取值.

是不是所有的单调区间都不能并起来呢？若函数 $g(x) = \begin{cases} x + 1, & x > 0, \\ x - 1, & x < 0, \end{cases}$ 很显然函数 $g(x)$ 在 $(- \infty, 0)$ 和 $(0, +\infty)$ 上都是单调递增的，并且函数 $g(x)$ 在 $(- \infty, 0)$ 上的函数值都小于函数 $g(x)$ 在 $(0, +\infty)$ 上的函数值。此时， $\forall x_1, x_2 \in (-\infty, 0) \cup (0, +\infty)$ ， $x_1 < x_2$ ，都有 $f(x_1) < f(x_2)$ ，满足函数单调递增的定义，因此可以说函数 $g(x)$ 在定义域 $(- \infty, 0) \cup (0, +\infty)$ 上单调递增。也就是说，单调区间能否合并，关键在于自变量的选取是否满足任意性。

再看函数单调性的定义,会发现其中有三个关键表述:

① $x_{1}<x_{2}$ ;

② $f(x_{1})<f(x_{2})$ （或 $f(x_{1})>f(x_{2})$ ）；

③函数 $f(x)$ 单调递增(或单调递减).

在这三个表述中任意选取两个表述为条件,剩下的一个为问题.

若已知①②,求③,这是函数单调性的判定问题;

若已知①③,求②,这是比较大小问题;

若已知②③,求①,这是解不等式问题.

从函数的单调性定义出发,可以衍生出三种题型,而这些都是日常教学中的重点问题,由此可见,一

定要深入挖掘教材中的核心定义的内涵与外延,真正理解定义,才能让学生跳出题海.

前述例 1、例 2, 就是函数单调性的判定问题, 大致可分为具体函数和抽象函数的单调性判定问题, 这类问题下文不再赘述.

# 点评

比较大小问题是基于函数单调性的定义衍生而来的,借助函数的单调性以及自变量的范围来决定函数值的大小,从而产生大小比较.纵观近几年高考试题的考查情况,3.1和3.2的题型主要出现在单选题的前5题,属于容易题.而3.3和3.4的题型涉及构造函数或借助不等式进行放缩,往往出现在单选题的第7题或第8题,难度较大.学生需要在平时的学习中用好函数的单调性,了解函数的相关性质,不断积累常见的函数不等式,掌握构造函数解题的基本方法.

# 4 解不等式问题

这类问题往往涉及对函数单调性和奇偶性等基本性质的应用,笔者将此类题型大致分为以下“四层楼”类型,“楼层”越高,难度越大,借此激励学生在高中数学学习中勇于向上攀登,更上一层楼.

# 4.1 第一层楼：“ $f() < f()$ ”型问题

![](images/697f6c74414e813426d8fa68bf393e5d27b09a287ed37ddb36666cce8be1363a.jpg)

例7 已知函数 $f(x)$ 是定义在 $(-1, 1)$ 上的减，且 $f(1 - a) < f(a^2 - 1)$ ，求 $a$ 的取值范围.

![](images/da1bbcc7ea4d3cd5434189f64f9d04fd2d7c642f6dd03c48081e81871738c0d7.jpg)

# 解析

因为函数 $f(x)$ 是 $(-1, 1)$ 上的减函数，所以

$$
\left\{ \begin{array}{l} {- 1 <   1 - a <   1,} \\ {- 1 <   a ^ {2} - 1 <   1, \text {解得} 0 <   a <   1.} \\ {1 - a > a ^ {2} - 1,} \end{array} \right.
$$

# 4.3 第三层楼：“ $f() + f() < 0$ ”型问题

![](images/494b86fde88cf3f3c5ca88c0dceda53500ba81bb62e58a8417d22e24b25e3966.jpg)

例9 已知函数 $f(x) = x \mid x \mid$ ，对任意的 $x \in \mathbf{R}$ ，

$f(ax^{2})+4f(3-x)\geqslant0$ 恒成立，则实数 a 的最小值为 \_\_\_\_.

![](images/eee4cff7da10cbf89eb4c6ab8e5e3b89c6f8afba6476836755cdd67505996d05.jpg)

# 解析

容易证得函数 $f(x)=x|x|$ 为奇函数,且在 R 上单调递增.又因为

$$
4 f (3 - x) = 4 (3 - x) \mid 3 - x \mid =
$$

$$
(6 - 2 x) \mid 6 - 2 x \mid = f (6 - 2 x),
$$

所以 $f(ax^2) + f(6 - 2x)\geqslant 0$ ，则 $f(ax^{2})\geqslant -f(6-$ $2x) = f(2x - 6)$ ，故 $ax^{2}\geqslant 2x - 6$ ，即 $ax^2 -2x + 6\geqslant 0$ 恒成立，所以 $\left\{ \begin{array}{l}a > 0,\\ \Delta = 4 - 24a\leqslant 0, \end{array} \right.$ 解得 $a\geqslant \frac{1}{6}$ ，即实数 $a$ 的最小值为 $\frac{1}{6}$

# 4.4 第四层楼:“\(f(\ ) + f(\ ) < \text{数}"型问题

![](images/70d7895b9b450b83bd2aae9cc4ee185454b6f4b58e505b2679465b1a92780332.jpg)

例10 定义在 $(-1, 1)$ 上的函数 $f(x)$ 满足$f(x)=g(x)-g(-x)+2,\forall x_{1},x_{2}\in(-1,1),$ $x_{1}\neq x_{2}$ ，恒有 $\left[f\left(x_{1}\right)-f\left(x_{2}\right)\right]\left(x_{1}-x_{2}\right)>0$ ，则关于x的不等式 $f(3x+1)+f(x)>4$ 的解集为\_\_\_\_.

![](images/5731c3637827cd6dccff5c3e4e334cb27a466bba377d7d8c9b18c84348401ed2.jpg)

# 解析

因为 $\forall x_{1},x_{2}\in (-1,1),x_{1}\neq x_{2}$ ，恒有 $[f(x_1) - f(x_2)](x_1 - x_2) > 0$ ，所以函数$f(x)$ 在 $(-1,1)$ 上单调递增.记 $h(x) = f(x) - 2 = g(x) - g(-x)$ , 则 $h(x)$ 为奇函数, 且在 $(-1,1)$ 上单调递增. $f(3x + 1) + f(x) > 4 \Leftrightarrow f(3x + 1) - 2 > 2 - f(x) = -[f(x) - 2]$ , 即 $h(3x + 1) > -h(x) = h(-x)$ , 则 $\left\{ \begin{array}{l} -1 < 3x + 1 < 1, \\ -1 < x < 1, \\ 3x + 1 > -x, \end{array} \right.$ 解得 $-\frac{1}{4} < x < 0$ .

![](images/056c451fafd17751cd89f2d8cf311e3b147b1f21571a1d6100aa7d6ab273a0ce.jpg)

# 点评

以上四种解不等式问题,本质上还是考查函数的基本性质,以单调性为主.对于后三种问题的处理,需要进行适当变形,最终化归为第一层楼的题型.

# 5 小结

基于函数单调性的定义,能够衍生出多种题型,这些题型可以从不同角度考查学生对这一核心定义的掌握情况.但是“万变不离其宗”,只要深刻地认识到定义的内涵和外延,处理几道考题将不在话下.高中数学新教材中与函数的单调性定义类似的核心定义还有很多,在日常学习中,学生要多琢磨、多思考、多总结,才能真正地跳出数学题海,提升数学素养.
