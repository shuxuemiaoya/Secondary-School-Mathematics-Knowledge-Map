# 直接推理应用,特殊函数构建

# ● 江苏省宜兴市阳羡高级中学 孙玲

抽象函数是一类没有给出具体函数解析式,只给出函数的特殊条件或特征的函数模型.抽象函数问题,自身具有较强的抽象性,问题创设新颖,形式构思巧妙,考查条件隐蔽.而近年新高考涉及抽象函数的试题以多选题的形式出现,可以更加全面地考查相关函数的概念和性质,同时还可以巧妙融合原函数与导函数之间的关系,将函数的图象与基本性质(涉及定义域、值域、单调性、奇偶性、周期性、对称性等)集于一身,实现多个不同知识点之间的交汇与融合,是考查函数及其相关知识的良好载体,备受各类命题者青睐.

# 1 问题呈现

问题（多选题）定义在 $\mathbf{R}$ 上的函数 $f(x)$ 与 $g(x)$ 的导函数分别为 $f'(x)$ 和 $g'(x)$ ，若 $g(x) - f(3 - x) = 2, f'(x) = g'(x - 1)$ ，且 $g(-x + 2) = -g(x + 2)$ ，则下列说法中一定正确的是（ ）.

A. $g(x+2)$ 为偶函数

B. $f'(x+2)$ 为奇函数

C. 函数 $f(x)$ 是周期函数

$$
\mathrm{D.} \sum_ {k = 1} ^ {2 0 2 4} g (k) = 0
$$

此题以两个不同的抽象函数为问题背景,借助两抽象函数所满足的关系式以及相应导函数之间的关系来创设条件,进而判断对应函数的奇偶性与周期性、导函数的奇偶性以及函数值之和等,全面考查函数的基本性质等综合应用能力.

此类以多选题形式设置的抽象函数应用问题,整体难度不大,借助函数的基本模型,综合函数的奇偶性、对称性、函数求值等来切入与应用.常见的技巧方法往往包括两大类:一类是直接法推理思维,通过抽象函数的基本概念与基本性质的应用来分析与判断;二是特殊法思维,通过选取满足条件的特殊函数(如正弦型函数与余弦型函数)来具体化处理,利用特殊函数的构建,结合各选项的信息来分析与处理.

# 2 问题破解

# 2.1 直接推理思维

解法 1: 抽象函数性质法 1.

由 $g(-x + 2) = -g(x + 2)$ ，即 $g(-x + 2) + g(x + 2) = 0$ ，可知函数 $g(x)$ 的图象关于点 $(2,0)$ 对称，则 $g(x + 2)$ 为奇函数，故选项A错误.而由 $g(x) - f(3 - x) = 2$ ，得 $g(x) = f(3 - x) + 2$ ，两边同时求导可得 $g^{\prime}(x) = -f^{\prime}(3 - x)$ ，则 $g^{\prime}(x - 1) = -f^{\prime}(4 - x)$ .而结合 $f^{\prime}(x) = g^{\prime}(x - 1)$ ，可得 $f^{\prime}(x) = -f^{\prime}(4 - x)$ ，即 $f^{\prime}(x) + f^{\prime}(4 - x) = 0$ ，则知导函数 $f^{\prime}(x)$ 的图象关于点(2,0)对称，可知函数 $f^{\prime}(x + 2)$ 的图象关于点(0,0)对称，则 $f^{\prime}(x + 2)$ 为奇函数，故选项B正确.由 $f^{\prime}(x) + f^{\prime}(4 - x) = 0$ ，可得 $[f(x) - f(4 - x)]' = 0$ ，可设 $f(x) - f(4 - x) = c,c$ 为常数，令 $x = 2$ 时，可得 $f(2) - f(2) = c = 0$ ，所以 $f(x) - f(4 - x) = 0$ ，即 $f(x) = f(4 - x)$ ，可知函数 $f(x)$ 的图象关于直线 $x = 2$ 对称.而由 $g(x) - f(3 - x) = 2$ 可得 $f(3 - x) = g(x) - 2$ ，则有 $f(3 - (4 - x)) = g(4 - x) - 2$ ，整理为 $f(x - 1) = g(4 - x) - 2$ ，又函数 $g(x)$ 的图象关于点（2，0）对称，则有 $g(x) = -g(4 - x)$ ，得 $f(3 - x) + f(x - 1) = -4$ ，可知函数 $f(x)$ 的图象关于点(1，-2)对称.综合可知函数 $f(x)$ 是周期 $T = 4$ 的周期函数，故选项C正确.由 $f^{\prime}(x) = g^{\prime}(x - 1)$ ，可得 $g(x - 1) = f(x) + m,m$ 为常数.又结合 $g(x) - f(3 - x) = 2$ ，可得 $f(x) = g(3 - x) - 2$ 则有 $g(x - 1) = g(3 - x) - 2 + m.$ 令 $x = 2$ 时，可得 $g(1) = g(1) - 2 + m$ ，则 $m = 2$ ，即 $g(x - 1) = g(3 - x)$ 则知函数 $g(x)$ 的图象关于直线 $x = 1$ 对称，则函数 $g(x)$ 是周期 $T = 4$ 的周期函数，而 $g(1) + g(3) = 0,$ 又 $g(2) + g(4) = 0 + 0 = 0$ ，所以 $\sum_{k = 1}^{2024}g(k) = 506\times$ $[g(1) + g(2) + g(3) + g(4)] = 0$ ，故选项D正确.

综上分析,故选 BCD.

解法 2: 抽象函数性质法 2.

依题，由 $g(-x+2)=-g(x+2)$ ，可得 $g(x+2)$ 为奇函数，故选项 A 错误。而由 $g(x)-f(3-x)=2$ ，两边同时求导可得 $g'(x)+f'(3-x)=0$ ，从而可以得到 $g'(x-1)+f'(4-x)=0$ ，而结合 $f'(x)=g'(x-1)$ ，可得 $f'(x)+f'(4-x)=0$ 。用 $x+2$ 替换 x，得 $f'(x+2)+f'(2-x)=0$ ，则 $f'(x+2)$ 为奇函数，故选项 B 正确。由 $f'(x)=g'(x-1)$ ，可得 $f(x)=g(x-1)+m$ ，m 为常数，用 3-x 代入可得 $f(3-x)=g(2-x)+m$ 。又结合 $g(x)-f(3-x)=2$ ，即 $f(3-x)=g(x)-2$ ，可得 $g(x)-2=g(2-x)+m$ 。令 x=1 时，可得 $g(1)-2=g(1)+m$ ，解得 m=-2，则 $g(x)=g(2-x)$ 。因为 $g(-x+2)=-g(x+2)$ ，所以$g(x+2)=-g(x)$ ，则函数 $g(x)$ 是周期 T=4 的周期函数。结合 $g(x)-f(3-x)=2$ ，可知函数 $f(x)$ 也是周期函数，故选项 C 正确。由于函数 $g(x)$ 是周期为 4 的周期函数，而 $g(1)+g(2)+g(3)+g(4)=\left[g(1)+g(3)\right]+\left[g(2)+g(4)\right]=0$ ，所以 $\sum_{k=1}^{2024}g(k)=506\times\left[g(1)+g(2)+g(3)+g(4)\right]=0$ ，故选项 D 正确。余略。

点评:借助题中抽象函数以及对应的导函数之间的关系式,综合抽象函数的基本概念、奇偶性、对称性、周期性等相关基本性质与应用,合理推理与应用,进而确定对应抽象函数的基本特征,给问题的分析与判断奠定基础.特别要注意的是,在抽象函数的关系式的变形与推理过程中,要注意关系式的恒等变形以及变量的替换与应用等,利用条件与目标之间的联系来合理变形与转化.

# 2.2 特殊法思维

解法 3: 特殊函数法.

依题，取特殊函数 $f(x) = \cos \frac{\pi}{2} x - 2, g(x) = -\sin \frac{\pi}{2} x$ ，其满足条件 $g(x) - f(3 - x) = 2, f'(x) = g'(x - 1), g(-x + 2) = -g(x + 2)$ . 此时， $g(x + 2) = -\sin \left[\frac{\pi}{2}(x + 2)\right] = \sin \frac{\pi}{2} x$ 为奇函数，故选项 A 错误. 而 $f'(x) = -\frac{\pi}{2}\sin \frac{\pi}{2} x$ ，可得 $f'(x + 2) = -\frac{\pi}{2} \cdot \sin \left[\frac{\pi}{2}(x + 2)\right] = \frac{\pi}{2}\sin \frac{\pi}{2} x$ 为奇函数，故选项 B 正确. 函数 $f(x) = \cos \frac{\pi}{2} x - 2$ 是周期 $T = \frac{2\pi}{\frac{\pi}{2}} = 4$ 的周期函数，故选项 C 正确. 函数 $g(x) = -\sin \frac{\pi}{2} x$ 是周期 $T = \frac{2\pi}{\frac{\pi}{2}} = 4$ 的周期函数，而 $g(1) + g(2) + g(3) + g(4) = -1 + 0 + 1 + 0 = 0$ ，所以 $\sum_{k=1}^{2024} g(k) = 506 \times [g(1) + g(2) + g(3) + g(4)] = 0$ ，故选项 D 正确. 余略.

点评:依据两个原函数、两个导函数及其相互之间的关系,合理联想到正弦型函数与余弦型函数及其导数之间的关系,合理配凑相应的系数,以特殊思维切入来构建特殊函数,使之吻合题设中抽象函数所满足的条件,为进一步分析与判断各选项的真假创造条件.特殊函数法的关键在于联想到与题设相关的函数模型,合理配凑相应的系数使得特殊函数吻合题设中抽象函数满足的所有条件.

# 3 变式拓展

变式（多选题）设定义在 $\mathbf{R}$ 上的函数 $f(x)$ 与 $g(x)$ 的导函数分别为 $f'(x)$ 和 $g'(x)$ ，若 $g(x) - f(3 - x) = 2, f'(x) = g'(x - 1)$ ，且 $g(x + 2)$ 为奇函数，则下列说法中一定正确的是（ ）.

A. 函数 $g(x)$ 的图象关于 x=1 对称

B. $f(x)$ 的周期为4

$$
\mathrm{C.} \sum_ {k = 1} ^ {2 0 2 3} g (k) = 0
$$

$$
\mathrm{D}. f (2) + f (4) = 4
$$

解析:依题,由 $g(x+2)$ 为奇函数,则知函数 $g(x)$ 的图象关于点 $(2,0)$ 对称.而 $f'(x)=g'(x-1)$ ,可得 $f(x)=g(x-1)+m$ , m 为常数.而结合 $g(x)-f(3-x)=2$ , 即 $f(3-x)=g(x)-2$ , 所以可得 $f(x)=g(3-x)-2$ , 则 $g(3-x)-2=g(x-1)+m$ . 令 x=2 时, 可得 $g(1)-2=g(1)+m$ , 解得 m=-2, 则有 $g(3-x)=g(x-1)$ , 所以函数 $g(x)$ 的图象关于直线 x=1 对称, 故选项 A 正确.由 $f(x)=g(3-x)-2=g(x-1)-2$ , 而函数 $g(x)$ 的图象关于点 $(2,0)$ 对称和关于直线 x=1 对称, 则知函数 $g(x)$ 是周期为 4 的周期函数, 而结合 $f(x)=g(x-1)-2$ , 可知函数 $f(x)$ 的图象是由函数 $g(x)$ 的图象平移变换而来的, 所以函数 $f(x)$ 也是周期为 4 的周期函数, 故选项 B 正确.由于 $g(1)=-g(3)$ , $g(2)=g(4)=0$ , 则有 $g(1)+g(2)+g(3)+g(4)=0$ , 结合函数 $g(x)$ 是周期为 4 的周期函数, 所以 $\sum_{k=1}^{2023}g(k)=g(1)+g(2)+g(3)=0$ , 故选项 C 正确.又 $f(2)=g(1)-2$ , $f(4)=g(-1)-2=g(3)-2$ , 所以 $f(2)+f(4)=[g(1)-2]+[g(3)-2]=-4$ , 故选项 D 错误.

综上分析,故选 ABC.

# 4 教学启示

抽象函数是函数模块知识里的一个重点与难点，涉及抽象函数及其应用，以及原函数与导函数之间的交汇与融合问题，与之相关的问题在近三四年的新高考中都得以有效考查与应用。而涉及抽象函数及其综合应用问题，可以很好地考查并正确区分出不同层次学生的数学思维与数学知识差异。整体来说对学生的数学运算、数学抽象、逻辑推理等方面的素养要求比较高。

此类问题的解决策略之一就是正确掌握科学推理法，利用抽象函数的关系式加以巧妙转化与推理分析，这是解决问题的一种通法；而借助特殊法思维，通过特殊函数模型的构建，利用函数具体化这种方法是解决问题的一种“巧技妙法”，关键是要看关系式的结构结构和一些条件的加持，进而加以合理选取与特殊构建.Z
