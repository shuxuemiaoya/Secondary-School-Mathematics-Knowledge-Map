# 一道最值题的破解

# ● 江苏省徐州市树人中学 严慧

近年的高考数学试题中经常涉及“双变元”或“双参”的相关问题,此类问题主要涉及函数与导数、不等式等模块知识,能力要求高,综合性强,难度较大,往往以压轴题的形式呈现.

而涉及双变元代数式的最值(或取值范围)问题,是其中比较常见的一类考查方式,借助双变元代数式的结构特征,或消参处理,或齐次化处理,或换元处理等,都是解决此类问题中比较常用的技巧方法,成为破解问题的关键.

# 1 问题呈现

问题 若 $a > 0, b > 0$ ，且 $a + b = 1$ ，则 $\frac{2a}{a^2 + b} + \frac{b}{a + b^2}$ 的最大值为 \_\_\_\_.

此题题目简捷明了,以两个正数变量为背景,利用双变元之和为定值1,进而创设求解对应的分式代数式的最值问题.

解题时,关键是从双变量以及题设条件入手,合理通过消参处理、齐次化处理或换元思维,将双变元问题转化为单变量问题,进而利用相应的技巧方法来分析与解决,实现部分的突破与求解.

# 2 问题破解

# 2.1 消参思维

借助题设条件,通过合理的消参,化双变元代数式为单变量问题,进而利用单变量问题的基本解题方法来分析与处理.

解法 1: 换元法.

依题，结合 $a + b = 1$ ，可得 $\frac{2a}{a^2 + b} +\frac{b}{a + b^2} =$ $\frac{2a}{a^2 - a + 1} +\frac{1 - a}{a + (1 - a)^2} = \frac{a + 1}{a^2 - a + 1}.$ 设 $t = a + 1\in$ (1,2)，利用基本不等式，可得 $\frac{a + 1}{a^2 - a + 1} = \frac{t}{t^2 - 3t + 3} =$ $\frac{1}{t + \frac{3}{t} - 3}\leqslant \frac{1}{2\sqrt{t\times\frac{3}{t}} - 3} = \frac{2\sqrt{3} + 3}{3},$ 当且仅当 $t = \frac{3}{t},$

即 $t = \sqrt{3}$ ，亦即 $a = \sqrt{3} - 1, b = 2 - \sqrt{3}$ 时，等号成立. 所以 $\frac{2a}{a^2 + b} + \frac{b}{a + b^2}$ 的最大值为 $\frac{2\sqrt{3} + 3}{3}$ .

解法 2: 判别式法 1.

设 $t=a+1\in(1,2)$ ，则 $y=\frac{a+1}{a^{2}-a+1}=\frac{t}{t^{2}-3t+3}>0$ ，整理可得 $yt^{2}-(3y+1)t+3y=0$ 。

由于 $y > 0$ ，根据以上关于参数 $t$ 的一元二次方程有实数根，则 $\Delta \geqslant 0$ ，即 $3y^{2} - 6y - 1\leqslant 0$ ，解得 $\frac{3 - 2\sqrt{3}}{3}\leqslant y\leqslant \frac{3 + 2\sqrt{3}}{3}$ .而 $y > 0$ ，则有 $0 <   y\leqslant \frac{3 + 2\sqrt{3}}{3}$ 所以 $\frac{2a}{a^2 + b} +$ $\frac{b}{a + b^2}$ 的最大值为 $\frac{2\sqrt{3} + 3}{3}$

解法 3: 基本不等式法 1.

结合 $a + b = 1, a > 0, b > 0$ ，利用基本不等式，原式 $= \frac{a + 1}{(a + 1)^2 - 3(a + 1) + 3} = \frac{1}{(a + 1) + \frac{3}{a + 1} - 3} \leqslant$

$\frac{1}{2\sqrt{(a + 1)\times\frac{3}{a + 1}} - 3} = \frac{2\sqrt{3} + 3}{3}$ 当且仅当 $a + 1 =$

$\frac{3}{a+1}$ ，即 $a=\sqrt{3}-1, b=2-\sqrt{3}$ 时，等号成立。余略。

解法 4: 导数法 1.

依题，结合 $a + b = 1$ ，可得原式 $= \frac{a + 1}{a^2 - a + 1}$ .于是构建函数 $f(a) = \frac{a + 1}{a^2 - a + 1}, a \in (0,1)$ ，则 $f'(a) = -\frac{a^2 + 2a - 2}{(a^2 - a + 1)^2}$ .令 $f'(a) = 0$ ，解得 $a = \sqrt{3} - 1$

所以，当 $a \in (0, \sqrt{3} - 1)$ 时， $f'(a) > 0$ ，函数 $f(a)$ 单调递增；当 $a \in (\sqrt{3} - 1, +\infty)$ 时， $f'(a) < 0$ ，函数 $f(a)$ 单调递减。所以 $f(a) \leqslant f(a)_{\max} = f(\sqrt{3} - 1) = \frac{2\sqrt{3} + 3}{3}$ ，余略。

点评:对于双变元的代数式问题,合理的消元处理就是一个关键的步骤.而在消参变化后,其中利用基本不等式的放缩思维来解决代数式的最值问题,是解决此类问题中最为常见的一种基本技巧方法,其基本思路就是合理配凑关系式,使之吻合利用基本不等式的条件.另一种基本思路就是通过构建函数,借助函数与导数的综合法来处理与应用.

# 2.2 齐次化思维

根据题设条件,运用齐次化思维来恒等变形,借助比值换元,化双变元代数式为单变量问题,进而利用单变量问题的基本解题方法来分析与处理.

解法 5: 判别式法 2.

结合 $a + b = 1$ ，可得

$$
\frac {2 a}{a ^ {2} + b} + \frac {b}{a + b ^ {2}} = \frac {2 a (a + b)}{a ^ {2} + b (a + b)} + \frac {b (a + b)}{a (a + b) + b ^ {2}} =
$$

$$
\frac {2 + 3 \cdot \frac {b}{a} + \left(\frac {b}{a}\right) ^ {2}}{1 + \frac {b}{a} + \left(\frac {b}{a}\right) ^ {2}}.
$$

令 $t = \frac{b}{a} > 0$ ，则 $y = 1 + \frac{2t + 1}{t^2 + t + 1} > 1$ ，整理可得

$$
(y - 1) t ^ {2} + (y - 3) t + y - 2 = 0.
$$

由于 $y - 1 > 0$ ，根据以上关于参数 $t$ 的一元二次方程有实数根，则 $\Delta \geqslant 0$ ，即 $3y^{2} - 6y - 1 \leqslant 0$ ，解得 $\frac{3 - 2\sqrt{3}}{3} \leqslant y \leqslant \frac{3 + 2\sqrt{3}}{3}$ . 而 $y > 1$ ，则有 $1 < y \leqslant \frac{3 + 2\sqrt{3}}{3}$ ，余略.

解法 6: 基本不等式法 2.

依题, 结合 $a + b = 1$ , 原式 $= \frac{2 + 3 \cdot \frac{b}{a} + \left(\frac{b}{a}\right)^{2}}{1 + \frac{b}{a} + \left(\frac{b}{a}\right)^{2}}$ .

令 $t = \frac{b}{a}$ 则 $t > 0$ ，于是原式 $= \frac{2 + 3t + t^2}{1 + t + t^2} = 1+$ $4\times \frac{1}{(2t + 1) + \frac{3}{2t + 1}}\leqslant 1 + 4\times \frac{1}{2\sqrt{(2t + 1)\times\frac{3}{2t + 1}}} =$ $\frac{2\sqrt{3} + 3}{3}$ ，余略.

解法 7: 导数法 2.

结合 $a+b=1$ ，可得

$$
\frac {2 a}{a ^ {2} + b} + \frac {b}{a + b ^ {2}} = \frac {2 + 3 \cdot \frac {b}{a} + \left(\frac {b}{a}\right) ^ {2}}{1 + \frac {b}{a} + \left(\frac {b}{a}\right) ^ {2}}.
$$

令 $t=\frac{b}{a}>0$ ，构建函数 $f(t)=\frac{2+3t+t^{2}}{1+t+t^{2}}, t>0$ ，则 $f'(t)=-\frac{2t^{2}+2t-1}{(t^{2}+t+1)^{2}}$ 。令 $f'(t)=0$ ，解得 $t=\frac{\sqrt{3}-1}{2}$ 。而当 $t\in\left(0,\frac{\sqrt{3}-1}{2}\right)$ 时， $f'(t)>0$ ，函数 $f(t)$ 单调递增；当 $t\in\left(\frac{\sqrt{3}-1}{2},+\infty\right)$ 时， $f'(t)<0$ ，函数 $f(t)$ 单调递减。所以 $f(t)\leqslant f(t)_{\max}=f\left(\frac{\sqrt{3}-1}{2}\right)=\frac{2\sqrt{3}+3}{3}$ 。余略。

点评:根据题设中双变元之和为定值,利用分式代数式的齐次化处理,给代数式的最值问题求解提供更加宽广的空间.齐次化处理后,依托单变量代数式的结果,可以通过整体思维转化为方程问题,利用判别式法来转化,借助不等式的求解来确定;也可以通过合理的配凑与转化,利用基本不等式来放缩,实现代数式最值的求解;而导数法也为问题的解决提供另一种思路.

# 2.3 换元思维

借助题设条件,结合等差数列的等差中项性质,合理进行换元处理,化双变元代数式为单变量问题,进而利用单变量问题的基本解题方法来分析与处理.

解法 8: 判别式法 3.

依题, 结合 $a + b = 1$ , 可设 $a = \frac{1}{2} + t$ , $b = \frac{1}{2} - t$ , $t \in \left(-\frac{1}{2}, \frac{1}{2}\right)$ ，于是 $y = \frac{2a}{a^{2} + b} + \frac{b}{a + b^{2}} = \frac{t + \frac{3}{2}}{t^{2} + \frac{3}{4}} > 0$ ,
整理可得 $yt^{2}-t+\frac{3}{4}y-\frac{3}{2}=0.$ 由于 y>0，根据以上关于参数 t 的一元二次方程有实数根，则 $\Delta \geqslant 0$ ，即 $3y^{2}-6y-1 \leqslant 0.$ 余略.

点评:根据题设中双变元之和为定值,借助等差数列的等差中项引入参数进行换元处理,进而构建对应的单变量问题,为进一步解决问题奠定条件.而对于单变量问题的最值问题,除了以上的方程的判别式法外,还可以通过基本不等式法、导数法等来分析与处理,实现问题的分析与求解.
