# 一、巧展新问题

问题:(2021年普通高等学校招生全国统一考试模拟演练(八省联考)数学·7)已知抛物线 $y^{2}=2px$ 上三点 $A(2,2)$ ,B,C,直线AB,AC是圆 $(x-2)^{2}+y^{2}=1$ 的两条切线,则直线BC的方程为().

A. $x + 2y + 1 = 0$

B. $3x + 6y + 4 = 0$

C. $2x + 6y + 3 = 0$

D. $x + 3y + 2 = 0$

此题以抛物线为问题背景,巧妙融入点、直线、圆、抛物线这几类不同的平面解析几何中的元素类型,创新设置,合理融合,简捷明了.破解时可以从点、直线、曲线等不同思维角度切入,方法较多,思维多样.

# 二、夯实基本功

常规解法是我们破解问题中最常见和第一时间内最容易想到的方法之一，也最能体现学生的数学基本功。夯实学生基本功，这也是数学教学与学习中最基本的要求之一，强化基础训练，提升解题教学能力，全面提升学生的“四基”与能力。

解法1:(交点坐标法)由于A(2,2)在抛物线 $y^{2}=2px$ 上,故 $2^{2}=2p\times2$ ,即p=1,则抛物线方程为 $y^{2}=2x$ .设过点A(2,2)且与圆 $(x-2)^{2}+y^{2}=1$ 相切的直线方程为 $y-2=k(x-2)$ ,则圆心(2,0)到切线的距离 $d=\frac{|2k-0-2k+2|}{\sqrt{k^{2}+1}}=1$ ,解得 $k=\pm\sqrt{3}$ ,则有直线AB: $y-2=\sqrt{3}(x-2)$ ,直线AC: $y-2=-\sqrt{3}(x-2)$ ,联立 $\left\{\begin{aligned}y-2&=\sqrt{3}(x-2),\\ y^{2}&=2x,\end{aligned}\right.$ 整理可得 $\sqrt{3}y^{2}-2y+4$

$-4\sqrt{3}=0$ , 故 $y_{A}+y_{B}=\frac{2\sqrt{3}}{3}$ , 结合 $y_{A}=2$ 可得 $y_{B}=\frac{2\sqrt{3}-6}{3}$ ，则有 $x_{B}=\frac{8-4\sqrt{3}}{3}$ 。同理可得 $y_{C}=\frac{-2\sqrt{3}-6}{3}$ ，则有 $y_{B}+y_{C}=\frac{2\sqrt{3}-6}{3}+\frac{-2\sqrt{3}-6}{3}=-4$ ，由 B, C 在抛物线上，可得直线 BC 的斜率为 $k_{BC}=\frac{y_{B}-y_{C}}{\frac{y_{B}^{2}}{2}-\frac{y_{C}^{2}}{2}}=\frac{2(y_{B}-y_{C})}{(y_{B}+y_{C})(y_{B}-y_{C})}=\frac{2}{y_{B}+y_{C}}=-\frac{1}{2}$ ，所以直线 BC 的方程为 $y-\frac{2\sqrt{3}-6}{3}=-\frac{1}{2}\left(x-\frac{8-4\sqrt{3}}{3}\right)$ ，即 $3x+6y+4=0$ 。

故选 B.

点评: 此基本解法思维难度不大, 只要按照题目条件中给出的顺序, 依次求出 p 值, 设出直线 AB, AC 的方程, 利用相切(用圆心到直线的距离等于半径) 的条件分别求出直线 AB, AC 的斜率, 再联立抛物线方程, 分别算出交点 B, C 的坐标, 从而成功地求得直线 BC 的方程. 方法基本、常规, 解题过程中的运算量大, 只要肯算, 敢算, 就能得到结果.

# 三、培养探究欲

常规方法中往往数学运算量比较大,过程比较烦琐,而进一步剖析问题,合理诱导启发、深入探究,巧妙借助“设而不求”,合理探究,通过同构处理或构造处理来合理转化,简化运算,精炼过程,是一种不可多得的巧妙思维,也为该问题的进一步深化与拓展提供条件.

解法2:(同构法)由于A(2,2)在抛物线 $y^{2}=2px$ 上,故 $2^{2}=2p\times2$ ,即p=1,则抛物线方程为 $y^{2}=2x$ .设 $B\left(\frac{y_{1}^{2}}{2},y_{1}\right),C\left(\frac{y_{2}^{2}}{2},y_{2}\right)$ ,那么直线BC的斜率为 $k_{BC}=\frac{y_{1}-y_{2}}{\frac{y_{1}^{2}}{2}-\frac{y_{2}^{2}}{2}}=\frac{2(y_{1}-y_{2})}{(y_{1}+y_{2})(y_{1}-y_{2})}=\frac{2}{y_{1}+y_{2}}$ ,而直线

$BC$ 的方程为 $y - y_{1} = \frac{2}{y_{1} + y_{2}}\left(x - \frac{y_{1}^{2}}{2}\right)$ ，即 $2x - (y_{1} + y_{2})y + y_{1}y_{2} = 0.$ ①

而点 $A(2,2)$ 在抛物线 $y^{2} = 2x$ 上，同理可得直线 $AB$ 的方程为 $2x - (y_{1} + 2)y + 2y_{1} = 0$ ，由于直线 $AB$ 为圆 $(x - 2)^{2} + y^{2} = 1$ 的一条切线，则圆心(2,0)到切线 $AB$ 的距离为 $d = \frac{|4 - 0 + 2y_1|}{\sqrt{4 + (y_1 + 2)^2}} = 1$ ，整理可得 $3y_{1}^{2}$ $+12y_{1} + 8 = 0$ ，结合 $y_{1}^{2} = 2x_{1}$ ，可得 $6x_{1} + 12y_{1} + 8 =$ 0，即 $3x_{1} + 6y_{1} + 4 = 0.$ 同理可得 $3x_{2} + 6y_{2} + 4 = 0$ ，所以 $B(x_{1},y_{1}),C(x_{2},y_{2})$ 都在直线 $3x + 6y + 4 = 0$ 上.

故选 B.

点评:利用“设而不求”思维,通过设元技巧确定直线的斜率以及直线的方程,利用同构法转化相关的直线方程,结合直线与圆的位置关系以及点到直线的距离公式加以转化,通过参数代换,以及再次同构法处理来确定直线的方程.设而不求,巧妙同构,合理转化,完美破解.

# 四、拓展新结论

总结规律,拓展提升,有效发展学生的数学知识、数学思想方法和数学能力,合理引导学生自主归纳总结,深入钻研,认真探究,观察研究特点、转换视角、力求创新,进行合理的归纳总结,解题研究.

结论 1: 已知抛物线 $y^{2}=2px(p>0)$ 上定点 $A(x_{0},y_{0})(x_{0}>0)$ ，点 B, C 是抛物线上的动点，若 $k_{AB}+k_{AC}=0$ ，则直线 BC 的斜率为定值 $-\frac{p}{y_{0}}$ .

证明：设 $B\left(\frac{y_1^2}{2p}, y_1\right), C\left(\frac{y_2^2}{2p}, y_2\right)$ ，结合点 $A(x_0, y_0)(x_0 > 0)$ ，可得直线 $AB$ 的方程为 $y - y_0 = k_{AB}(x - x_0)$ ，与抛物线 $y^2 = 2px (p > 0)$ 联立，消去参数 $x$ 并整理可得 $\frac{k_{AB}}{2p} y^2 - y + y_0 - k_{AB}x_0 = 0$ ，结合韦达定理，可得 $y_0 + y_1 = \frac{2p}{k_{AB}}$ ，即 $y_1 = \frac{2p}{k_{AB}} - y_0$ 。同理可得 $y_2 = \frac{2p}{k_{AC}} - y_0 = -\frac{2p}{k_{AB}} - y_0$ ，所以 $k_{BC} = \frac{y_1 - y_2}{\frac{y_1^2}{2p} - \frac{y_2^2}{2p}} = \frac{2p(y_1 - y_2)}{(y_1 + y_2)(y_1 - y_2)} = \frac{2p}{y_1 + y_2} = \frac{2p}{\frac{2p}{k_{AB}} - y_0 - \frac{2p}{k_{AB}} - y_0} = -\frac{2p}{2y_0} = -\frac{p}{y_0}$ ，为定值。

推论1：已知抛物线 $y^{2} = 2px(p > 0)$ 上定点$A\left(\frac{p}{2},p\right)$ ，点B,C是抛物线上的动点，若 $k_{AB}+k_{AC}=0$ ，则直线BC的斜率为定值-1.

推论 2: 已知抛物线 $y^{2}=2px(p>0)$ 上定点 $A(x_{0},y_{0})(x_{0}>0)$ ，点 B, C 是抛物线上的动点，直线 AB, AC 是圆 $(x-a)^{2}+y^{2}=r^{2}$ 的两条切线（其中常数 $a\geqslant2p>r>0$ ），则直线 BC 的方程为 $2p(y_{0}^{2}-r^{2})x+(4pa-2r^{2})y_{0}y+4p^{2}(a^{2}-r^{2})-r^{2}y_{0}^{2}=0$ .

其实，将 $p = 1, y_0 = 2, a = 2, r = 1$ 代入以上推论2中的结论，可得 $6x + 12y + 8 = 0$ ，即 $3x + 6y + 4 = 0$ 就是所求的直线 $BC$ 的方程.该推论太复杂，作为一个了解即可.

结论2:已知椭圆 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1(a>b>0)$ 上定点 $A\left(c,\frac{b^{2}}{a}\right)$ ，离心率为e，点B,C是椭圆上的动点，若 $k_{AB}+k_{AC}=0$ ，则直线BC的斜率为定值e.

证明: 设 $B(x_{1}, y_{1})$ , $C(x_{2}, y_{2})$ ，设直线 AB 的方程为 $y = k(x - c) + \frac{b^{2}}{a}$ ，代入椭圆 $\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1$ ，整理可得 $(b^{2} + a^{2}k^{2})x^{2} + (2kab^{2} - 2k^{2}a^{2}c)x + a^{2}c^{2}k^{2} - b^{2}c^{2} - 2kab^{2}c = 0$ ，结合韦达定理，可得 $c + x_{1} = -\frac{2kab^{2} - 2k^{2}a^{2}c}{b^{2} + a^{2}k^{2}}$ ，解得 $x_{1} = -\frac{2kab^{2} - 2k^{2}a^{2}c}{b^{2} + a^{2}k^{2}} - c$ ，则有 $y_{1} = k(x_{1} - c) + \frac{b^{2}}{a} = kx_{1} - kc + \frac{b^{2}}{a}$ 。又 $k_{AB} + k_{AC} = 0$ ，即直线 AB 的斜率与 AC 的斜率互为相反数，在上式中以 -k 代 k，可得 $x_{2} = \frac{2kab^{2} + 2k^{2}a^{2}c}{b^{2} + a^{2}k^{2}} - c$ ， $y_{2} = -kx_{2} + kc + \frac{b^{2}}{a}$ ，所以直线 BC 的斜率 $k_{BC} = \frac{y_{1} - y_{2}}{x_{1} - x_{2}} = \frac{k(x_{1} + x_{2}) - 2kc}{x_{1} - x_{2}} = \frac{\frac{4k^{3}a^{2}c}{b^{2} + a^{2}k^{2}} - 4kc}{\frac{-4kab^{2}}{b^{2} + a^{2}k^{2}}} = \frac{c}{a} = e$ ，为一定值。
