# 一、链接教材

普通高中课程标准实验教科书《数学·必修4·苏教版》(江苏教育出版社,2012年6月第4版)第116页例4;

普通高中课程标准实验教科书《数学·必修4·人教版》(人民教育出版社,2007年4月第2版)第154页“巩固与提高”第7题.

【问题】在斜三角形 ABC 中, 求证: $\tan A + \tan B + \tan C = \tan A \tan B \tan C$ .

该结论阐述了斜三角形三个内角的正切函数之间满足的一个独特、奇妙的恒等式，实际上就是任意非直角三角形中和角正切公式的变形与拓展。根据公式特征，往往将这个公式称为三角形的三正切公式。

以三角形的三正切公式为问题背景或应用的试题活跃于近年各级各类考题中,尤其受到各级竞赛命题者的青睐.

# 二、证明结论

【结论】在斜三角形 ABC 中, 始终有 $\tan A + \tan B + \tan C = \tan A \tan B \tan C$ 成立.

证明: 在斜三角形 ABC 中, $\tan A$ , $\tan B$ , $\tan C$ 都有意义, 结合三角形的内角和公式 $A + B + C = \pi$ , 可得 $A + B = \pi - C$ , 所以 $\tan(A + B) = \tan(\pi - C) = -\tan C = \frac{\tan A + \tan B}{1 - \tan A \tan B}$ , 即 $\tan A + \tan B = -\tan C +$

$\tan A \tan B \tan C$ ，所以有 $\tan A + \tan B + \tan C = \tan A \tan B \tan C$ 成立.

【推论】当 $A + B + C = k\pi (k\in \mathbf{Z})$ ，且 $\tan A,\tan B$ $\tan C$ 都有意义时，始终有 $\tan A + \tan B + \tan C =$ $\tan A\tan B\tan C$ 成立.

# 三、应用结论

# (一) 模拟卷中的应用

例 1 （2019 届江苏省无锡市高三上学期期末检测·14）在锐角三角形 ABC 中，已知 $2\sin^{2}A + \sin^{2}B = 2\sin^{2}C$ ，则 $\frac{1}{\tan A} + \frac{1}{\tan B} + \frac{1}{\tan C}$ 的最小值为 \_\_\_\_.

分析:根据题目条件中的三角关系式进行恒等变换,得到 $3\tan A = \tan C$ , 进而根据三角形的三正切公式, 并结合参数之间的关系加以等价转化, 最后利用基本不等式来确定相应关系式的最值问题.

解析:由 $2\sin^{2}A + \sin^{2}B = 2\sin^{2}C$ ，变形 $2\sin^{2}C - 2\sin^{2}A = \sin^{2}B$ ，可得 $2\sin(A + C)\sin(C - A) = \sin^{2}B$ ，即有 $2\sin(C - A) = \sin B$ ，那么 $2\sin C\cos A - 2\cos C\sin A = \sin B = \sin(A + C) = \sin A\cos C + \cos A\sin C$ ，即 $3\sin A\cos C = \cos A\sin C$ ，亦即 $3\tan A = \tan C$ 。

设 $\tan A = x, \tan B = y, \tan C = z,$

根据三角形的三正切公式结论 $\tan A + \tan B + \tan C = \tan A \tan B \tan C$ ，可得 $x + y + z = xyz$ 。

又 z=3x，代入整理得 $4x+y=3x^{2}y$ ，即 $y=\frac{4x}{3x^{2}-1}$ ，那么 $\frac{1}{\tan A}+\frac{1}{\tan B}+\frac{1}{\tan C}=\frac{1}{x}+\frac{1}{y}+\frac{1}{z}=\frac{4}{3x}+\frac{3x^{2}-1}{4x}=\frac{3}{4}x+\frac{13}{12x}\geqslant2\sqrt{\frac{3}{4}x\times\frac{13}{12x}}=\frac{\sqrt{13}}{2}$ ，当且仅当 $\frac{3}{4}x=\frac{13}{12x}$ ，即 $x=\tan A=\frac{\sqrt{13}}{3}$ 时等号成立，所以 $\frac{1}{\tan A}+\frac{1}{\tan B}+\frac{1}{\tan C}$ 的最小值为 $\frac{\sqrt{13}}{2}$ .

故填答案: $\frac{\sqrt{13}}{2}$ .

点评:巧妙借助斜三角形中的三正切公式,把相关参数之间的关系加以有效链接,化隐含条件为已知条件,从而建立起相应的关系式,方便多变元问题的合理消元处理,从而为问题的进一步破解提供条件.

# (二) 高考卷中的应用

例 2 （2016 年江苏卷第 14 题）在锐角三角形 ABC 中，若 $\sin A = 2\sin B\sin C$ ，则 $\tan A\tan B\tan C$ 的最小值是 \_\_\_\_.

分析:根据题目条件中的三角关系式进行恒等变换,得到 $\tan B+\tan C=2\tan B\tan C$ ,从而利用三角形的三正切公式加以转化,利用基本不等式来处理,再通过不等式的性质来求解三角关系式的最值问题.

解析: 在锐角三角形 ABC 中, $\tan A$ , $\tan B$ , $\tan C$ 均为正数, 由已知条件 $\sin A = 2\sin B\sin C$ , 结合三角形的内角和公式 $A + B + C = \pi$ , 可得 $A = \pi - (B + C)$ , 则有 $\sin A = \sin[\pi - (B + C)] = \sin(B + C) = 2\sin B\sin C$ , 展开可得 $\sin B\cos C + \cos B\sin C = 2\sin B\sin C$ , 以上式子两边同除以 $\cos B\cos C$ , 可得 $\tan B + \tan C = 2\tan B\tan C$ .

根据三角形的三正切公式结论，可得 $\tan A\tan B\tan C = \tan A + \tan B + \tan C = \tan A + 2\tan B\tan C\geqslant 2\sqrt{2\tan A\tan B\tan C}$ ，整理可得 $\tan A\tan B\tan C\geqslant 8$ ，当且仅当 $\tan A = 2\tan B\tan C$ ，即 $\tan B + \tan C = 4,\tan B\tan C = 2$ ，亦即 $\tan A = 4,\tan B$ 与 $\tan C$ 的值为 $2 + \sqrt{2},2 - \sqrt{2}$ 时，等号成立，所以 $\tan A\tan B\tan C$ 的最小值是8.

故填答案:8.

点评:巧妙借助三角形的三正切公式,把斜三角形中三个内角的正切函数关系式加以有机转化,合理通过和式与积式之间的等价关系的过渡,从而方便利用基本不等式、函数或方程、导数等思维来处理,是破解问题的一个关键点.

# (三) 竞赛卷中的应用

例 3 （2018 年全国数学联赛(重庆)预赛第 6 题）在 $\triangle ABC$ 中， $\sin^{2}A + \sin^{2}C = 2018\sin^{2}B$ ，则 $\frac{(\tan A + \tan C)\tan^{2}B}{\tan A + \tan B + \tan C} =$ \_\_\_\_.

分析:根据题目条件中的三角关系式以及正弦定理,得到 $a^{2}+c^{2}=2018b^{2}$ ,结合所要求解的三角关系式,利用三角形的三正切公式加以转化与化简,并化正切函数为正、余弦函数，结合三角恒等变换、正弦定理与余弦定理的应用来转化，从而得以正确求值.

解析:根据条件 $\sin^{2}A + \sin^{2}C = 2018\sin^{2}B$ ，结合正弦定理，可得 $a^{2} + c^{2} = 2018b^{2}$ .

根据三角形的三正切公式结论,可得

所以 $\frac{(\tan A + \tan C)\tan^2B}{\tan A + \tan B + \tan C} = \frac{(\tan A + \tan C)\tan^2B}{\tan A\tan B\tan C}$

$$
\begin{array}{l} \tan A \tan B \tan C = \tan A + \tan B + \tan C, \\ = \frac {(\tan A + \tan C) \tan B}{\tan A \tan C} = \left(\frac {1}{\tan A} + \frac {1}{\tan C}\right) \tan B \\ = \left(\frac {\cos A}{\sin A} + \frac {\cos C}{\sin C}\right) \cdot \frac {\sin B}{\cos B} \\ = \frac {(\cos A \sin C + \cos C \sin A) \sin B}{\sin A \sin C \cos B} \\ = \frac {\sin (A + C) \sin B}{\sin A \sin C \cos B} = \frac {\sin^ {2} B}{\sin A \sin C \cos B} \\ = \frac {\sin^ {2} B}{\sin A \sin C} \cdot \frac {1}{\cos B} \\ = \frac {b ^ {2}}{a c} \cdot \frac {2 a c}{a ^ {2} + c ^ {2} - b ^ {2}} = \frac {2 b ^ {2}}{2 0 1 8 b ^ {2} - b ^ {2}} = \frac {2}{2 0 1 7}. \\ \end{array}
$$

故填答案: $\frac{2}{2017}$ .

点评:巧妙借助三角形的三正切公式,可以有效转化三角关系式并加以适当化简,为合理准确利用正弦定理、余弦定理来破解三角关系式建立起桥梁,从而明确三角形的边角关系,合理进行转化,从而得以正确求解.
