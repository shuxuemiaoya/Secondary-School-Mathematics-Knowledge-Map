# 例析三角函数最值（值域） 问题的五种求法

# ■传 知(特级教师) 一、归一法

![](images/10fef6dcfef7e6c885126d130f36a9ed09e7d230925422a9819bc9c18e6047f6.jpg)

例 1 （1）函数 $f(x)=4\cos x\sin\left(x+\frac{\pi}{3}\right)-\sqrt{3},x\in\left(-\frac{\pi}{6},\frac{\pi}{6}\right)$ 的最大值为 \_\_\_\_。

(2)已知 $\sin\alpha+\cos\beta=\frac{3}{2}$ ，则 $2\sin\alpha+\cos\beta$ 的取值范围是 \_\_\_\_。

解:(1) 函数 $f(x)=4\cos x\left(\frac{1}{2}\sin x+\frac{\sqrt{3}}{2}\cos x\right)-\sqrt{3}=2\sin x\cos x+2\sqrt{3}\cos^{2}x-\sqrt{3}=$ $\sin 2x+\sqrt{3}\cos 2x=2\sin\left(2x+\frac{\pi}{3}\right)$ 。由 $x\in\left(-\frac{\pi}{6},\frac{\pi}{6}\right)$ ，可得 $2x+\frac{\pi}{3}\in\left(0,\frac{2\pi}{3}\right)$ ，所以 $0<2\sin\left(2x+\frac{\pi}{3}\right)\leqslant2$ ，故 $f(x)$ 的最大值为 2。

(2)由 $\sin \alpha +\cos \beta = \frac{3}{2}$ ，可得 $\cos \beta = \frac{3}{2}$ $-\sin \alpha$ ，所以 $2\sin \alpha +\cos \beta = 2\sin \alpha +\frac{3}{2} -$ $\sin \alpha = \sin \alpha +\frac{3}{2}$ 。由 $\left\{ \begin{array}{l} - 1\leqslant \sin \alpha \leqslant 1,\\ -1\leqslant \frac{3}{2} -\sin \alpha \leqslant 1, \end{array} \right.$ 可得 $\frac{1}{2}\leqslant \sin \alpha \leqslant 1$ ，所以 $2\leqslant \sin \alpha +\frac{3}{2}\leqslant \frac{5}{2}$ ，即 $2\sin \alpha +\cos \beta$ 的取值范围是 $\left[2,\frac{5}{2}\right]$ 。

# 二、换元法

例 2 函数 $y = \sin x \cos x + \sin x + \cos x$ 的最大值为 \_\_\_\_。

解: 设 $\sin x + \cos x = t$ ，则 $\sin x \cos x = \frac{t^{2} - 1}{2}$ ，且 $t \in [-\sqrt{2}, \sqrt{2}]$ ，所以原函数等价于 $g(t) = \frac{t^{2} - 1}{2} + t = \frac{1}{2}(t + 1)^{2} - 1 \leqslant \frac{1}{2} (\sqrt{2} + 1)^{2} - 1 = \frac{1}{2} + \sqrt{2}$ 。故函数 $y_{\max} = \frac{1}{2} + \sqrt{2}$ 。

# 三、不等式法

例3 若 $x \in \left(0, \frac{\pi}{2}\right)$ , 则函数 $f(x) =$

$2\tan x + \tan\left(\frac{\pi}{2} - x\right)$ 的最小值为\_\_\_\_。

解： $f(x) = 2\tan x + \tan \left(\frac{\pi}{2} -x\right) =$ $\frac{2\sin x}{\cos x} +\frac{\cos x}{\sin x}\geqslant 2\sqrt{2}$ ，当且仅当 $\tan x = \frac{\sqrt{2}}{2}$ 时取等号，所以函数 $f(x)$ 的最小值为 $2\sqrt{2}$ 。

# 四、数形结合法

例4 求函数 $f(x) = \sin x + |\sin x|$ 的值域。

解: 易得 $f(x)=\left\{\begin{aligned}&2\sin x, \sin x \geqslant 0, \\ &0, \sin x < 0.\end{aligned}\right.$ 作出函数 $f(x)$ 的图像(图略)。由图可得 $f(x)$ 的值域为 $[0,2]$ 。

# 五、利用函数图像的凸凹性

例 5 求函数 $f(x)=\left(\sin x+\frac{1}{2}\right)\cdot\left(\cos x+\frac{\sqrt{3}}{2}\right)$ 在 $\left(0,\frac{\pi}{2}\right)$ 上取得最大值时的 x 值。

解: $f(x) = \left(\sin x + \frac{1}{2}\right)\left(\cos x + \frac{\sqrt{3}}{2}\right) =$ $\frac{1}{2}\sin 2x + \sin \left(x + \frac{\pi}{6}\right) + \frac{\sqrt{3}}{4} = \frac{1}{2}\sin (\pi - 2x)$ $+\sin \left(x + \frac{\pi}{6}\right) + \frac{\sqrt{3}}{4}$ 。由 $x \in \left(0, \frac{\pi}{2}\right)$ ，可得 $\pi - 2x \in (0, \pi), x + \frac{\pi}{6} \in \left(\frac{\pi}{6}, \frac{2\pi}{3}\right)$ 。因为函数 $y = \sin x$ 在 $(0, \pi)$ 上的图像上凸，所以 $f(x) = \frac{1}{2}\sin (\pi - 2x) + \sin \left(x + \frac{\pi}{6}\right) + \frac{\sqrt{3}}{4} =$ $\frac{1}{2}\left[\sin (\pi - 2x) + \sin \left(x + \frac{\pi}{6}\right) + \sin \left(x + \frac{\pi}{6}\right)\right] +$ $\frac{\sqrt{3}}{4} \leqslant \frac{3}{2}\sin \frac{(\pi - 2x) + \left(x + \frac{\pi}{6}\right) + \left(x + \frac{\pi}{6}\right)}{3} +$ $\frac{\sqrt{3}}{4} = \frac{3}{2}\sin \frac{4\pi}{9} + \frac{\sqrt{3}}{4}$ ，当且仅当 $\pi - 2x = x +$ $\frac{\pi}{6}$ ，即 $x = \frac{5\pi}{18}$ 时等号成立。故当函数 $f(x)$ 在 $\left(0, \frac{\pi}{2}\right)$ 上取得最大值时的 $x$ 值为 $\frac{5\pi}{18}$ 。
