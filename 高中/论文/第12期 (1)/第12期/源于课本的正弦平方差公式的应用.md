# 一、公式介绍

$\sin^{2}A-\sin^{2}B=\sin(A+B)\sin(A-B)$ (正弦平方差公式,证明过程略)。

# 二、公式的应用

# 1. 在求值中的应用

例1 $\cos^2\frac{\pi}{12} -\cos^2\frac{5\pi}{12} = ()$

A. $\frac{1}{2}$

B. $\frac{\sqrt{3}}{3}$

C. $\frac{\sqrt{2}}{2}$

D. $\frac{\sqrt{3}}{2}$

解:(方法 1) $\cos^{2}\frac{\pi}{12}-\cos^{2}\frac{5\pi}{12}=\cos^{2}\frac{\pi}{12}$ $-\cos^{2}\left(\frac{\pi}{2}-\frac{\pi}{12}\right)=\cos^{2}\frac{\pi}{12}-\sin^{2}\frac{\pi}{12}=\cos\frac{\pi}{6}$ $=\frac{\sqrt{3}}{2}$ 。应选 D。

(方法 2) $\cos^{2}\frac{\pi}{12}-\cos^{2}\frac{5\pi}{12}=\sin^{2}\frac{5\pi}{12}-$ $\sin^{2}\frac{\pi}{12}=\sin\left(\frac{5\pi}{12}+\frac{\pi}{12}\right)\sin\left(\frac{5\pi}{12}-\frac{\pi}{12}\right)=\sin\frac{\pi}{2}\cdot$ $\sin\frac{\pi}{3}=\frac{\sqrt{3}}{2}$ 。应选 D。

变式 1: 若 $\sin(\alpha+\beta)\sin(\alpha-\beta)=\frac{1}{4}$ ，则 $\cos2\alpha-\cos2\beta=$ \_\_\_\_。

提示: 因为 $\sin(\alpha+\beta)\sin(\alpha-\beta)=\sin^{2}\alpha-\sin^{2}\beta=\frac{1-\cos2\alpha}{2}-\frac{1-\cos2\beta}{2}=$ $\frac{\cos 2\beta - \cos 2\alpha}{2} = \frac{1}{4}$ ，所以 $\cos 2\alpha - \cos 2\beta = -\frac{1}{2}$ 。

# 2. 在取值范围(最值)中的应用

例 2 已知 $\triangle ABC$ 是锐角三角形, 若 $\sin^{2}A - \sin^{2}B = \sin B \sin C$ , 则 $\frac{a}{b}$ 的取值范围是 \_\_\_\_。

解: 已知 $\sin^{2}A - \sin^{2}B = \sin B \sin C$ ，由正弦平方差公式得 $\sin^{2}A - \sin^{2}B = \sin(A + B) \sin(A - B) = \sin B \sin C$ 。由 $C = \pi - (A + B)$ ，可得 $\sin C = \sin(A + B)$ ，所以 $\sin B =$

$\sin(A-B)$ 。

由 $\triangle ABC$ 为锐角三角形，即 $0 < A < \frac{\pi}{2}$ ， $0 < B < \frac{\pi}{2}$ ，可得 $-\frac{\pi}{2} < A - B < \frac{\pi}{2}$ ，结合 $y = \sin x$ 在 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ 上单调递增得 $B = A - B$ ，即 $A = 2B$ 。因为 $\triangle ABC$ 为锐角三角形，所

以 $\left\{\begin{aligned}0&<B<\frac{\pi}{2},\\ 0&<A=2B<\frac{\pi}{2},\quad 解得\frac{\pi}{6}<B<\frac{\pi}{4}.\\ 0&<C=\pi-3B<\frac{\pi}{2},\end{aligned}\right.$

故 $\frac{a}{b}=\frac{\sin A}{\sin B}=\frac{\sin 2B}{\sin B}=\frac{2\sin B\cos B}{\sin B}=$ $2\cos B\in(\sqrt{2},\sqrt{3})$ 。

变式 2: 记 $\triangle ABC$ 的内角 A, B, C 的对边分别为 a, b, c，已知 $c = 2\sqrt{2}$ , $b^{2} - a^{2} = 16$ ，则角 C 的最大值为 \_\_\_\_。

提示:由 $c=2\sqrt{2}$ , $b^{2}-a^{2}=16$ 得 $b^{2}-a^{2}=2c^{2}$ ，结合正弦定理得 $\sin^{2}B-\sin^{2}A=2\sin^{2}C$ ，所以 $\sin^{2}B-\sin^{2}A=\sin(A+B)\cdot\sin(B-A)=2\sin^{2}C$ ，所以 $\sin C=\frac{1}{2}\sin(B-A)\leqslant\frac{1}{2}$ ，所以角 C 的最大值为 $\frac{\pi}{6}$ 。

# 3. 在证明中的应用

例 3 记△ABC 的内角 A, B, C 的对边分别为 a, b, c，已知 $\sin C\sin(A-B)=\sin B\sin(C-A)$ ，证明： $2a^{2}=b^{2}+c^{2}$ 。

证明:(方法1)因为 $\sin C\sin(A-B)=\sin B\sin(C-A)$ ，所以 $\sin C\sin A\cos B-\sin C\sin B\cos A=\sin B\sin C\cos A-\sin B\cdot\sin A\cos C$ ，所以 $ac\cdot\frac{a^{2}+c^{2}-b^{2}}{2ac}-2bc\cdot\frac{b^{2}+c^{2}-a^{2}}{2bc}=-ab\cdot\frac{a^{2}+b^{2}-c^{2}}{2ab}$ ，整理得 $\frac{a^{2}+c^{2}-b^{2}}{2}-(b^{2}+c^{2}-a^{2})=-\frac{a^{2}+b^{2}-c^{2}}{2}$

所以 $2a^{2} = b^{2} + c^{2}$ 。

(方法 2)由 $\sin C = \sin(A + B)$ , $\sin B = \sin(C + A)$ , 结合 $\sin C \sin(A - B) = \sin B \cdot \sin(C - A)$ , 可得 $\sin(A + B) \sin(A - B) = \sin(A + C) \sin(C - A)$ 。由正弦平方差公式得 $\sin^{2}A - \sin^{2}B = \sin^{2}C - \sin^{2}A$ , 结合正弦定理得 $2a^{2} = b^{2} + c^{2}$ 。

变式 3: 在锐角 $\triangle ABC$ 中, 内角 A, B, C 所对的边分别为 a, b, c, 且满足 $a^{2}-b^{2}=bc$ 。

求证: $A = 2B$ 。

提示:(方法1)因为 $a^{2}=b^{2}+c^{2}-2bc\cos A=b^{2}+bc$ ，所以 $c-b=2b\cos A$ 。由正弦定理得 $\sin C-\sin B=2\sin B\cos A$ 。由 $\sin C=\sin(A+B)=\sin A\cos B+\cos A\cdot\sin B$ ，代入得 $\sin A\cos B-\cos A\sin B=\sin B$ ，即 $\sin(A-B)=\sin B$ 。因为在锐角 $\triangle ABC$ 中，0<A, $B<\frac{\pi}{2}$ ，所以 A-B=B，所以 A=2B。

(方法2)由正弦定理得 $\sin^{2}A - \sin^{2}B = \sin B\sin C$ ，所以 $(\sin A + \sin B)(\sin A - \sin B) = \sin B\sin C$ ，所以 $2\sin\frac{A+B}{2} \cdot \cos\frac{A-B}{2} \cdot 2\sin\frac{A-B}{2}\cos\frac{A+B}{2} = \sin(A + B) \cdot \sin(A - B) = \sin B\sin C$ 。因为 $\sin(A + B) = \sin C \neq 0$ ，所以 $\sin(A - B) = \sin B$ 。因为在锐角 $\triangle ABC$ 中，0 < A, $B < \frac{\pi}{2}$ ，所以 A - B = B，所以 A = 2B。

(方法 3)由正弦定理得 $\sin^{2}A - \sin^{2}B = \sin B\sin C$ ，结合正弦平方差公式得 $\sin(A + B)\sin(A - B) = \sin B\sin C$ ，所以 $\sin B = \sin(A - B)$ 。因为在锐角 $\triangle ABC$ 中，0 < A， $B < \frac{\pi}{2}$ ，所以 B = A - B，所以 A = 2B。

# 4. 在三角函数中的应用

例4 已知函数 $f(x) = \sin^2 x - \sin^2\left(x - \frac{\pi}{6}\right), x \in \mathbf{R}$ 。

(1) 求函数 $f(x)$ 的最小正周期。

(2) 求函数 $f(x)$ 在区间 $\left[-\frac{\pi}{3}, \frac{\pi}{4}\right]$ 上的取值范围。

解:(1)函数 $f(x)=\sin\left(x+x-\frac{\pi}{6}\right)\cdot$ $\sin\left(x-x+\frac{\pi}{6}\right)=\sin\left(2x-\frac{\pi}{6}\right)\sin\frac{\pi}{6}=$ $\frac{1}{2}\sin\left(2x-\frac{\pi}{6}\right)$ ，所以函数 $f(x)$ 的最小正周期 $T=\frac{2\pi}{2}=\pi$ 。

(2) 当 $x \in \left[-\frac{\pi}{3}, -\frac{\pi}{6}\right]$ 时, $2x - \frac{\pi}{6} \in$ $\left[-\frac{5\pi}{6}, -\frac{\pi}{2}\right]$ , 当 $x \in \left[-\frac{\pi}{6}, \frac{\pi}{4}\right]$ 时, $2x - \frac{\pi}{6} \in \left[-\frac{\pi}{2}, \frac{\pi}{3}\right]$ , 则函数 $f(x)$ 在区间 $\left[-\frac{\pi}{3}, -\frac{\pi}{6}\right]$ 上是减函数, 在区间 $\left[-\frac{\pi}{6}, \frac{\pi}{4}\right]$ 上是增函数, 所以 $f\left(-\frac{\pi}{3}\right) = -\frac{1}{4}, f\left(-\frac{\pi}{6}\right) = -\frac{1}{2}, f\left(\frac{\pi}{4}\right) = \frac{\sqrt{3}}{4}$ , 所以函数 $f(x)$ 在区间 $\left[-\frac{\pi}{3}, \frac{\pi}{4}\right]$ 上的最大值为 $\frac{\sqrt{3}}{4}$ , 最小值为 $-\frac{1}{2}$ 。故函数 $f(x)$ 在区间 $\left[-\frac{\pi}{3}, \frac{\pi}{4}\right]$ 上的取值范围是 $\left[-\frac{1}{2}, \frac{\sqrt{3}}{4}\right]$ 。

变式 4: 函数 $f(x)=\sin^{2}\left(x+\frac{\pi}{4}\right)-\sin^{2}\left(x-\frac{\pi}{4}\right)$ 是( )。

A. 最小正周期为 $\pi$ 的奇函数

B. 最小正周期为 $\pi$ 的偶函数

C. 最小正周期为 $2 \pi$ 的奇函数

D. 最小正周期为 $2 \pi$ 的偶函数

提示: 因为函数 $f(x)=\sin^{2}\left(x+\frac{\pi}{4}\right)-\sin^{2}\left(x-\frac{\pi}{4}\right)=\sin\left(x+\frac{\pi}{4}+x-\frac{\pi}{4}\right)\sin\left(x+\frac{\pi}{4}-x+\frac{\pi}{4}\right)=\sin2x\sin\frac{\pi}{2}=\sin2x$ ，所以函数 $f(x)$ 的最小正周期 $T=\pi$ 。又因为 $f(-x)=\sin(-2x)=-\sin2x=-f(x)$ ，所以函数 $f(x)$ 是最小正周期为 $\pi$ 的奇函数。应选 A。
