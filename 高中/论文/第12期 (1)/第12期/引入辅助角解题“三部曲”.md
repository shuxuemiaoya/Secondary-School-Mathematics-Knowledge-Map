# ■张振继(特级教师)

我们知道，将 $a\sin x + b\cos x$ 化为一个角的三角函数形式有利于问题的解决，而将 $a\sin x + b\cos x$ 化为一个角的三角函数形式通常需要三步：一提，即提系数 $\sqrt{a^2 + b^2}$ ， $a\sin x + b\cos x = \sqrt{a^2 + b^2}\left(\frac{a}{\sqrt{a^2 + b^2}}\sin x + \frac{b}{\sqrt{a^2 + b^2}}\cos x\right)$ ；二取，即取角 $\varphi$ ，令 $\sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}$ ， $\cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}$ ；三用，即用公式， $a\sin x + b\cos x = \sqrt{a^2 + b^2} (\sin x\cos \varphi + \cos x\sin \varphi) = \sqrt{a^2 + b^2}\sin (x + \varphi)$ 。

# 一、辅助角为特殊角

如果辅助角是特殊角,那么可以求出特殊角,从而将三角函数化为一个角的三角函数形式求解。

例 1 化简: $\sin 50^{\circ}(1+\sqrt{3}\tan 10^{\circ})$ 。

$$
\begin{array}{l} \text {解:原式} = \sin 5 0 ^ {\circ} \cdot \frac {2 \left(\frac {\sqrt {3}}{2} \sin 1 0 ^ {\circ} + \frac {1}{2} \cos 1 0 ^ {\circ}\right)}{\cos 1 0 ^ {\circ}} \\ = \sin 5 0 ^ {\circ} \cdot \frac {2 (\sin 1 0 ^ {\circ} \cos 3 0 ^ {\circ} + \cos 1 0 ^ {\circ} \sin 3 0 ^ {\circ})}{\cos 1 0 ^ {\circ}} \\ = 2 \cos 4 0 ^ {\circ} \cdot \frac {\sin 4 0 ^ {\circ}}{\cos 1 0 ^ {\circ}} = \frac {2 \cos 4 0 ^ {\circ} \sin 4 0 ^ {\circ}}{\cos 1 0 ^ {\circ}} = \\ \frac {\sin 8 0 ^ {\circ}}{\cos 1 0 ^ {\circ}} = 1 _ {\circ} \\ \end{array}
$$

# 二、辅助角为非特殊角

如果辅助角为非特殊角,那么可以用辅助角的正弦或余弦的三角函数表示出来,从而化为一个角的三角函数形式求解。

例 2 若 $\sin\alpha+2\cos\alpha=\frac{\sqrt{10}}{2}$ ，则 $\tan2\alpha=(\quad)$ 。

A. $\frac{4}{3}$

B. $\frac{3}{4}$

C. $-\frac{3}{4}$

D. $-\frac{4}{3}$

解:(方法1)由 $\sin\alpha+2\cos\alpha=\frac{\sqrt{10}}{2}$ ，可得 $\sqrt{5}\left(\frac{1}{\sqrt{5}}\sin\alpha+\frac{2}{\sqrt{5}}\cos\alpha\right)=\frac{\sqrt{10}}{2}$ ，即 $\frac{1}{\sqrt{5}}\sin\alpha$

$+\frac{2}{\sqrt{5}}\cos\alpha=\frac{\sqrt{2}}{2}$ 。令 $\cos\varphi=\frac{1}{\sqrt{5}},\sin\varphi=\frac{2}{\sqrt{5}}$ ，则 $\sin(\alpha+\varphi)=\frac{\sqrt{2}}{2}$ ，所以 $\alpha+\varphi=\frac{\pi}{4}+2k\pi$ 或 $\alpha+$ $\varphi=\frac{3\pi}{4}+2k\pi$ ，所以 $\alpha=\frac{\pi}{4}-\varphi+2k\pi$ 或 $\alpha=\frac{3\pi}{4}-\varphi+2k\pi$ ，其中 $k\in Z$ 。所以 $2\alpha=\frac{\pi}{2}-2\varphi+4k\pi$ 或 $\alpha=\frac{3\pi}{2}-2\varphi+4k\pi$ ，其中 $k\in Z$ 。

易得 $\tan 2\alpha = \tan \left(\frac{\pi}{2} - 2\varphi\right) = \frac{\sin \left(\frac{\pi}{2} - 2\varphi\right)}{\cos \left(\frac{\pi}{2} - 2\varphi\right)}$ $= \frac{\cos 2\varphi}{\sin 2\varphi} = \frac{1}{\tan 2\varphi} = \frac{1 - \tan^2\varphi}{2\tan\varphi}$ 。

由 $\cos\varphi=\frac{1}{\sqrt{5}},\sin\varphi=\frac{2}{\sqrt{5}}$ , 可得 $\tan\varphi=2$ 所以 $\tan 2\alpha=\frac{1-\tan^{2}\varphi}{2\tan\varphi}=-\frac{3}{4}$ 。应选 C。

(方法 2)由 $\sin\alpha+2\cos\alpha=\frac{\sqrt{10}}{2}$ ，两边平方得 $\sin^{2}\alpha+4\cos^{2}\alpha+4\sin\alpha\cos\alpha=\frac{5}{2}$ ，即 $3\cos^{2}\alpha+4\sin\alpha\cos\alpha=\frac{3}{2}$ ，所以 $3\times\frac{1+\cos2\alpha}{2}+2\sin2\alpha=\frac{3}{2}$ ，所以 $\tan2\alpha=\frac{\sin2\alpha}{\cos2\alpha}=-\frac{3}{4}$ 。应选 C。

例 3 在锐角 $\triangle ABC$ 中, 若 2(1 - cos A) = sin A, 求 $\frac{\sin B + 2\sin C}{\sin A}$ 的取值范围。

解:由 $2(1-\cos A)=\sin A$ ，可得 $4(1-\cos A)^{2}=\sin^{2}A=1-\cos^{2}A$ ，解得 $\cos A=\frac{3}{5}$ 或 $\cos A=1$ （舍去），所以 $\sin A=\frac{4}{5}$ 。

易得 $\frac{\sin B + 2\sin C}{\sin A} = \frac{\sin(A + C) + 2\sin C}{\sin A} =$ $\frac{\frac{4}{5}\cos C + \frac{3}{5}\sin C + 2\sin C}{\frac{4}{5}} = \frac{13\sin C + 4\cos C}{4}$ 。

令 $\cos \varphi = \frac{13}{\sqrt{185}}$ ， $\sin \varphi = \frac{4}{\sqrt{185}}$ （不妨取 $\varphi$ 为锐角），则 $\frac{13\sin C + 4\cos C}{4} = \frac{\sqrt{185}}{4}\sin (C + \varphi)$ 。

因为 $\triangle ABC$ 为锐角三角形，所以 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2},\\ \frac{\pi}{2} < A + C < \pi , \end{array} \right.$ 可得 $\frac{\pi}{2} -A <   C <   \frac{\pi}{2},\frac{\pi}{2} -A$ $+ \varphi <  C + \varphi < \frac{\pi}{2} +\varphi$ 。易得 $\sin (C + \varphi)\leqslant 1$

显然 $\sin \left(\frac{\pi}{2} +\varphi\right) = \cos \varphi = \frac{13}{\sqrt{185}},$ $\sin \left(\frac{\pi}{2} -A + \varphi\right) = \cos (A - \varphi) = \frac{3}{5}\times \frac{13}{\sqrt{185}} +$ $\frac{4}{5}\times \frac{4}{\sqrt{185}} = \frac{11}{\sqrt{185}} <  \frac{13}{\sqrt{185}} = \sin \left(\frac{\pi}{2} +\varphi\right).$

据上得 $\frac{11}{\sqrt{185}} < \sin (C + \varphi) \leqslant 1$ ，所以 $\frac{11}{4} < \frac{\sqrt{185}}{4} \sin (C + \varphi) \leqslant \frac{\sqrt{185}}{4}$ ，即 $\frac{\sin B + 2\sin C}{\sin A}$ 的取值范围为 $\left(\frac{11}{4}, \frac{\sqrt{185}}{4}\right)$ 。

# 三、化为一个角的余弦或正弦求解

令 $\cos \varphi = \frac{b}{\sqrt{a^2 + b^2}}$ ， $\sin \varphi = \frac{a}{\sqrt{a^2 + b^2}}$ ，则 $a\sin x + b\cos x = \sqrt{a^2 + b^2}\cos (x - \varphi)$ 。

例 4 已知非零实数 a, b 满足 $\frac{a\sin\frac{\pi}{5}+b\cos\frac{\pi}{5}}{a\cos\frac{\pi}{5}-b\sin\frac{\pi}{5}}=\tan\frac{8\pi}{15}$ ，求 $\frac{b}{a}$ 的值。

解：（方法1）由 $\frac{a\sin\frac{\pi}{5} + b\cos\frac{\pi}{5}}{a\cos\frac{\pi}{5} - b\sin\frac{\pi}{5}} =$ $\tan \frac{8\pi}{15}$ ，可得 $\frac{\frac{a}{\sqrt{a^2 + b^2}}\sin\frac{\pi}{5} + \frac{b}{\sqrt{a^2 + b^2}}\cos\frac{\pi}{5}}{\frac{a}{\sqrt{a^2 + b^2}}\cos\frac{\pi}{5} - \frac{b}{\sqrt{a^2 + b^2}}\sin\frac{\pi}{5}}$ $= \tan \frac{8\pi}{15}$ 。

引入辅助角 $\varphi$ ，满足 $\cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}$

$\sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}$ ，则 $\frac{\cos \varphi \sin \frac{\pi}{5} + \sin \varphi \cos \frac{\pi}{5}}{\cos \varphi \cos \frac{\pi}{5} - \sin \varphi \sin \frac{\pi}{5}} = \tan \frac{8\pi}{15}$ ，所以 $\frac{\sin\left(\varphi + \frac{\pi}{5}\right)}{\cos\left(\varphi + \frac{\pi}{5}\right)} = \tan \frac{8\pi}{15}$ ，即 $\tan \left(\varphi + \frac{\pi}{5}\right) = \tan \frac{8\pi}{15}$ ，所以 $\varphi + \frac{\pi}{5} = k\pi + \frac{8\pi}{15}$ （ $k \in \mathbf{Z}$ ），即 $\varphi = k\pi + \frac{\pi}{3} (k \in \mathbf{Z})$ 。故 $\frac{b}{a} = \tan \varphi = \tan \left(k\pi + \frac{\pi}{3}\right) = \tan \frac{\pi}{3} = \sqrt{3}$ 。

(方法2)由已知条件得 $\frac{\sin\frac{\pi}{5} + \frac{b}{a}\cos\frac{\pi}{5}}{\cos\frac{\pi}{5} - \frac{b}{a}\sin\frac{\pi}{5}}$ $= \frac{\sin\frac{8\pi}{15}}{\cos\frac{8\pi}{15}}$ ，解这个关于 $\frac{b}{a}$ 的方程可得， $\frac{b}{a} =$ $\frac{\sin\frac{8\pi}{15}\cos\frac{\pi}{5} - \cos\frac{8\pi}{15}\sin\frac{\pi}{5}}{\cos\frac{8\pi}{15}\cos\frac{\pi}{5} + \sin\frac{8\pi}{15}\sin\frac{\pi}{5}} = \frac{\sin\left(\frac{8\pi}{15} - \frac{\pi}{5}\right)}{\cos\left(\frac{8\pi}{15} - \frac{\pi}{5}\right)} =$ $\tan \frac{\pi}{3} = \sqrt{3}$ 。

# 感悟与教育

已知函数 $f(x)=\sqrt{3}\sin\omega x+\cos\omega x$ $(\omega>0)$ 在 $[0,\pi]$ 上有两个零点，则 $\omega$ 的取值范围是（）。

A. $\left(\frac{11}{6}, \frac{17}{6}\right)$

B. $\left[\frac{11}{6},\frac{17}{6}\right)$

C. $\left(\frac{5}{3},\frac{8}{3}\right)$

D. $\left[\frac{5}{3},\frac{8}{3}\right)$

提示: 函数 $f(x)=\sqrt{3}\sin\omega x+\cos\omega x=2\sin\left(\omega x+\frac{\pi}{6}\right)$ 。因为 $x\in[0,\pi]$ ，所以 $\omega x+\frac{\pi}{6}\in\left[\frac{\pi}{6},\omega\pi+\frac{\pi}{6}\right]$ ，结合函数 $y=\sin x$ 的图像与性质得 $2\pi\leqslant\omega\pi+\frac{\pi}{6}<3\pi$ ，解得 $\frac{11}{6}\leqslant\omega<\frac{17}{6}$ ，故 $\omega$ 的取值范围是 $\left[\frac{11}{6},\frac{17}{6}\right)$ 。应选 B。
