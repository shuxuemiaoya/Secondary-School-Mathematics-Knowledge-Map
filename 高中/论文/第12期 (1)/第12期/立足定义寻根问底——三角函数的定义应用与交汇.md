三角函数的定义是进行三角函数化简、求值和证明的重要依据,也是三角函数所有知识的根本。有了它才有了同角三角函数关系、诱导公式、图像与性质,才有了三角函数知识与其他数学知识的有机融合。因此解决三角函数问题,要抓住问题的本质,深刻理解三角函数的定义。正如数学大师波利亚所说“当我们遇到问题的时候,回到定义中去”。

# 一、已知角 $\alpha$ 的终边上一点 $P$ 的坐标，求角 $\alpha$ 的三角函数值

例 1 已知角 $\alpha$ 的终边经过点 $P(-4m, 3m) (m \neq 0)$ ，则 $2\sin \alpha + \cos \alpha$ 的值是（）。

A. 1 或 -1

B. $\frac{2}{5}$ 或 $-\frac{2}{5}$

C. 1 或 $-\frac{2}{5}$

D. -1 或 $\frac{2}{5}$

解:由题意得点 P 与原点间的距离 $r=\sqrt{(-4m)^{2}+(3m)^{2}}=5|m|$ 。

当 $m > 0$ 时， $r = 5m$ ，可得 $\sin \alpha = \frac{3m}{5m} = \frac{3}{5}, \cos \alpha = \frac{-4m}{5m} = -\frac{4}{5}$ ，所以 $2\sin \alpha + \cos \alpha = 2 \times \frac{3}{5} - \frac{4}{5} = \frac{2}{5}$ 。

当 $m < 0$ 时， $r = -5m$ ，可得 $\sin \alpha = \frac{3m}{-5m} = -\frac{3}{5}, \cos \alpha = \frac{-4m}{-5m} = \frac{4}{5}$ ，所以 $2\sin \alpha + \cos \alpha = 2 \times \left(-\frac{3}{5}\right) + \frac{4}{5} = -\frac{2}{5}$ 。

综上可得， $2\sin\alpha+\cos\alpha$ 的值是 $\frac{2}{5}$ 或 $-\frac{2}{5}$ 。应选B。

点评:若点 $P(x,y)$ 是角 $\alpha$ 终边上异于顶点的任一点, 点 P 到原点 O 的距离为 r, 则 $\sin \alpha = \frac{y}{r}, \cos \alpha = \frac{x}{r}, \tan \alpha = \frac{y}{x} (x \neq 0)$ 。

# 二、已知角 $\alpha$ 的一个三角函数值和终边上一点 $P$ 的横坐标或纵坐标，求与角 $\alpha$ 有关的三角函数值

例 2 设 $\alpha$ 是第二象限角, $P(x,1)$ 为其终边上一点, 且 $\cos\alpha=\frac{1}{2}x$ , 则 $\tan\alpha=$ \_\_\_\_。

解:由题意得 $\cos\alpha=\frac{x}{\sqrt{x^{2}+1}}=\frac{1}{2}x$ 。因为 $x\neq0$ ，所以 $\sqrt{x^{2}+1}=2$ ，解得 $x=\pm\sqrt{3}$ 。因为 $\alpha$ 是第二象限角，所以 $x=-\sqrt{3}$ ，所以 $\tan\alpha=\frac{1}{x}=\frac{1}{-\sqrt{3}}=-\frac{\sqrt{3}}{3}$ 。

点评:解答本题的关键是三角函数定义的灵活应用。

# 三、已知角 $\alpha$ 的终边所在的直线方程，求角 $\alpha$ 的三角函数值

例3 已知角 $\alpha$ 的终边在直线 $y = \frac{\sqrt{3}}{3} x$ 上，求 $\sin \alpha$ 和 $\tan \alpha$ 的值。

解: 若角 $\alpha$ 的终边为直线 $y=\frac{\sqrt{3}}{3}x(x>0)$ ，在角 $\alpha$ 的终边上任意取一点 $\left(t,\frac{\sqrt{3}}{3}t\right)(t>0)$ ，则它到原点的距离 $r=\sqrt{t^{2}+\frac{1}{3}t^{2}}=\frac{2\sqrt{3}}{3}t$ ，可得 $\sin\alpha=\frac{\frac{\sqrt{3}}{3}t}{\frac{2\sqrt{3}}{3}t}=\frac{1}{2},\tan\alpha=\frac{\frac{\sqrt{3}}{3}t}{t}=$

$\frac{\sqrt{3}}{3}$ ; 若角 $\alpha$ 的终边为直线 $y = \frac{\sqrt{3}}{3} x (x < 0)$ , 在角 $\alpha$ 的终边上任意取一点 $\left(t, \frac{\sqrt{3}}{3} t\right) (t < 0)$ , 则它到原点的距离 $r = \sqrt{t^2 + \frac{1}{3} t^2} = -\frac{2\sqrt{3}}{3} t$ , 可

得 $\sin \alpha = \frac{\frac{\sqrt{3}}{3}t}{-\frac{2\sqrt{3}}{3}t} = -\frac{1}{2},\tan \alpha = \frac{\frac{\sqrt{3}}{3}t}{t} = \frac{\sqrt{3}}{3}$ 。

综上可得， $\sin \alpha = \pm \frac{1}{2}, \tan \alpha = \frac{\sqrt{3}}{3}$ 。

点评:利用三角函数的定义,把三角函数的求值问题转化为关于 x,y,r 的代数运算问题,从而求出相应三角函数的值。

# 四、用三角函数定义证明三角恒等式

例4 求证： $1 + \tan^2\alpha = \frac{1}{\cos^2\alpha}$

证明:由三角函数的定义知 $\cos\alpha=\frac{x}{r}$ , $\tan\alpha=\frac{y}{x}$ ，所以左边 $=1+\frac{y^{2}}{x^{2}}=\frac{x^{2}+y^{2}}{x^{2}}=$ $\frac{1}{\left(\frac{x}{r}\right)^{2}}=\frac{1}{\cos^{2}\alpha}=$ 右边，所以 $1+\tan^{2}\alpha=\frac{1}{\cos^{2}\alpha}$ 。

点评:本题借助三角函数的定义证明三角恒等式,不仅思路清晰,操作简便,而且有助于培养同学们思维的灵活性和创造性。

# 五、三角函数的定义与同角三角函数的交汇

例5 已知 $-\frac{\pi}{2} < \alpha < 0, \sin \alpha + \cos \alpha = \frac{1}{5}$ , 求 $\sin \alpha - \cos \alpha$ 的值。

解: 在角 $\alpha$ 的终边上任取一点 $P(x, y)$ 。

根据三角函数的定义知 $\sin \alpha = \frac{y}{r}, \cos \alpha = \frac{x}{r}$ (其中 x > 0, y < 0)，所以 $\frac{y}{r} + \frac{x}{r} = \frac{1}{5}$ ，平方得 $12x^{2} + 25xy + 12y^{2} = 0$ ，解得 $y = -\frac{3}{4}x$ 或 $y = -\frac{4}{3}x$ ，所以 $r = \frac{5}{4}x, r = -\frac{5}{3}y$ 或 $r = \frac{5}{3}x, r = -\frac{5}{4}y$ ，所以 $\sin \alpha - \cos \alpha = \frac{y}{r} - \frac{x}{r} = -\frac{3}{5} - \frac{4}{5} = -\frac{7}{5}$ 或 $\sin \alpha - \cos \alpha = \frac{y}{r} - \frac{x}{r} = -\frac{4}{5} - \frac{3}{5} = -\frac{7}{5}$ 。故 $\sin \alpha - \cos \alpha = -\frac{7}{5}$ 。

点评:利用三角函数的定义,避开了同角三角函数公式的记忆与运用,这是解题的一种好方法。

# 六、三角函数的定义与诱导公式的交汇

例 6 已知角 $\alpha$ 的顶点与原点 O 重合, 始边与 x 轴的非负半轴重合, 它的终边与单位圆的交点为 $P\left(\frac{4}{5}, \frac{3}{5}\right)$ , 则 $\cos(\pi - \alpha) = (\quad)$ 。

A. $-\frac{4}{5}$

B. $-\frac{3}{5}$

C. $\frac{3}{5}$

D. $\frac{4}{5}$

解:由题意知 $\alpha$ 与 $\pi-\alpha$ 的终边关于 y 轴对称,所以 $\pi-\alpha$ 的终边与单位圆的交点为 $Q\left(-\frac{4}{5},\frac{3}{5}\right)$ 。由三角函数的定义可得, $\cos(\pi-\alpha)=-\frac{4}{5}$ 。应选 A。

点评:解答本题的关键是利用 $\alpha$ 与 $\pi-\alpha$ 的终边关于 y 轴对称,确定对称点的坐标,再利用三角函数的定义求解。

# 感悟与提高

1. 在平面直角坐标系 $xOy$ 中, 设角 $\alpha$ 的顶点与原点 $O$ 重合, 始边与 $x$ 轴的非负半轴重合, 终边经过点 $P(t,1)$ , 且 $\sin\left(\alpha+\frac{\pi}{2}\right)=-\frac{\sqrt{5}}{5}$ , 则 $t=(\quad)$ 。

A. -2

B. $-\frac{1}{2}$

C. $\frac{1}{2}$

D. 2

提示：由题意得 $\cos \alpha = \frac{t}{\sqrt{t^2 + 1}}$ ，则 $\sin \left(\alpha +\frac{\pi}{2}\right) = \cos \alpha = \frac{t}{\sqrt{t^2 + 1}} = -\frac{\sqrt{5}}{5}$ ，解得 $t = -\frac{1}{2}$ 或 $t = \frac{1}{2}$ （舍去）。应选B。

2. 已知角 $\alpha$ 的终边经过点 $P(-5, -12)$ , 则 $\sin \left(\frac{3\pi}{2} + \alpha\right)$ 的值等于 \_\_\_\_。

提示:由题意得角 $\alpha$ 的终边与 $\frac{3\pi}{2} + \alpha$ 的终边关于直线 y = -x 对称。因为角 $\alpha$ 的终边经过点 $P(-5, -12)$ ，所以 $\frac{3\pi}{2} + \alpha$ 的终边经过点 $Q(-12, 5)$ 。由三角函数的定义得 $\sin\left(\frac{3\pi}{2} + \alpha\right) = \frac{5}{\sqrt{(-12)^{2} + 5^{2}}} = \frac{5}{13}$ 。
