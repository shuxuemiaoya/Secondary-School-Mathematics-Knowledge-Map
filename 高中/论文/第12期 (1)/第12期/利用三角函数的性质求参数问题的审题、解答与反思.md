# 利用三角函数的性质求参数问题的审题、解答与反思

# ■石汉荣

含参数的三角函数问题,一般属于逆向思维问题,难度相对较大一些。下面利用三角函数的性质求参数问题,进行策略性的分类解析。

# 一、根据三角函数的单调性求参数

例1 已知函数 $f(x) = \sin \left( \omega x + \frac{\pi}{3} \right) (\omega > 0)$ 的单调递增区间为 $\left[ k\pi - \frac{5\pi}{12}, k\pi + \frac{\pi}{12} \right] (k \in \mathbf{Z})$ ，单调递减区间为 $\left[ k\pi + \frac{\pi}{12}, k\pi + \frac{7\pi}{12} \right] (k \in \mathbf{Z})$ ，则 $\omega$ 的值为 \_\_\_\_。

审题: 正弦函数和余弦函数的两个单调区间并集的长度就是函数的一个周期。

解答:由题意得 $\left(k\pi+\frac{7\pi}{12}\right)-\left(k\pi-\frac{5\pi}{12}\right)=\pi,$ 即 $f(x)$ 的周期为 $\pi$ ，则 $\omega=2$ 。

反思:解答此类问题要注意单调区间给出的方式,如“函数 $f(x)$ 在 $\left[k\pi-\frac{5\pi}{12},k\pi+\frac{\pi}{12}\right]$ $(k\in\mathbf{Z})$ 上单调递增”与“函数 $f(x)$ 的递增区间为 $\left[k\pi-\frac{5\pi}{12},k\pi+\frac{\pi}{12}\right](k\in\mathbf{Z})$ ”是不同的。

# 二、根据三角函数的奇偶性求参数

例 2 已知 $f(x)=\cos(\sqrt{3}x+\varphi)-\sqrt{3}\sin(\sqrt{3}x+\varphi)$ 为偶函数，则 $\varphi$ 可以取的一个值为（）。

A. $\frac{\pi}{6}$

B. $\frac{\pi}{3}$

C. $-\frac{\pi}{6}$

D. $-\frac{\pi}{3}$

审题: 把原函数化为一个角的一种三角函数形式是处理奇偶性的切入点。利用辅助角公式把原函数化为 $f(x)=A\cos(\omega x+\varphi)$ 的形式, 再利用偶函数的定义构建恒等式求值。

解答: 因为 $f(x)=\cos(\sqrt{3}x+\varphi)-\sqrt{3}\sin(\sqrt{3}x+\varphi)=2\cos\left[(\sqrt{3}x+\varphi)+\frac{\pi}{3}\right]=2\cos\left[\left(\frac{\pi}{3}+\varphi\right)+\sqrt{3}x\right]$ 是偶函数，所以 $2\cos\left[\left(\frac{\pi}{3}+\varphi\right)+\sqrt{3}x\right]=2\cos\left[\left(\frac{\pi}{3}+\varphi\right)-\sqrt{3}x\right]$ 对任意的 x 恒成立，化简整理得

$\sin \sqrt{3} x \sin \left( \frac{\pi}{3} + \varphi \right) = 0$ 对任意的 $x$ 恒成立。只有选项D符合。应选D。

反思: 函数 $f(x)=A\cos(\omega x+\varphi)+B$ 为奇函数 $\Leftrightarrow\varphi=k\pi+\frac{\pi}{2}(k\in\mathbf{Z})$ ，且 B=0；函数 $f(x)=A\cos(\omega x+\varphi)+B$ 为偶函数 $\Leftrightarrow\varphi=k\pi(k\in\mathbf{Z})$ 。

# 三、根据三角函数的周期性求参数

例3 若函数 $y = \sin \omega x \cdot \sin \left( \omega x + \frac{\pi}{2} \right)$ $(\omega>0)$ 的最小正周期为 $\frac{\pi}{7}$ ，则 $\omega=$ \_\_\_\_。

审题:根据诱导公式和二倍角公式,把原函数化为 $f(x)=A\sin(\omega x+\varphi)$ 的形式,再结合周期公式 $T=\frac{2\pi}{|\omega|}$ 求解。

解答: 因为函数 $y = \sin \omega x \cdot \sin (\omega x + \frac{\pi}{2}) = \sin \omega x \cos \omega x = \frac{1}{2} \sin 2\omega x$ ，所以周期 $T = \frac{2\pi}{2\omega} = \frac{\pi}{7}$ ，所以 $\omega = 7$ 。

反思: 求 $f(x)=A\sin(\omega x+\varphi)$ 的周期, 要注意 x 的系数 $\omega$ 是否规定了正负号, 若无符号规定, 则利用周期公式 $T=\frac{2\pi}{|\omega|}$ 求解。

# 感悟与教育

若函数 $f(x)=a\sin x-b\cos x$ 在 $x=\frac{\pi}{3}$ 处有最小值-2，则常数 a, b 的值为 \_\_\_\_。

提示:由辅助角公式得函数 $f(x)=\sqrt{a^{2}+b^{2}}\sin(x-\varphi)$ (其中 $\varphi$ 由 $\tan\varphi=\frac{b}{a}$ 确定)。
由题意可得， $\left\{\begin{aligned}-\sqrt{a^{2}+b^{2}}&=-2,\\f\left(\frac{\pi}{3}\right)&=\frac{\sqrt{3}}{2}a-\frac{b}{2}=-2,\end{aligned}\right.$ 解得 $\left\{\begin{aligned}a&=-\sqrt{3},\\ b&=1.\end{aligned}\right.$
