题目（2022年新高考Ⅰ卷7）设 $a = 0.1\mathrm{e}^{0.1}, b = \frac{1}{9}, c = -\ln 0.9$ ，则（ ）.

A. $a < b < c$

B. $c < b < a$

C. c < a < b

D. $a < c < b$

![](images/383cba57d465b3dcf63616ad7c73bb552fbb97d4493f0e6e44b1c5e7f6c0bb7e.jpg)

设 $f(x) = \ln (1 + x) - x(-1 <   x\leqslant 0)$ ，则

$$
f ^ {\prime} (x) = \frac {1}{1 + x} - 1 = - \frac {x}{1 + x} > 0,
$$

所以 $f(x)$ 在 $(-1,0)$ 上单调递增， $f(-\frac{1}{10})<f(0)=0$ ，即 $\ln\frac{9}{10}+\frac{1}{10}<0$ ，故 $\frac{9}{10}<e^{-\frac{1}{10}}$ ，则 $\frac{1}{10}e^{\frac{1}{10}}<\frac{1}{9}$ ，所以 a<b。设 $g(x)=xe^{x}+\ln(1-x)(0<x<\frac{1}{4})$ ，则

$$
g ^ {\prime} (x) = (x + 1) \mathrm{e} ^ {x} + \frac {1}{x - 1} = \frac {\mathrm{e} ^ {x} (x ^ {2} - 1) + 1}{x - 1}.
$$

令 $h(x) = \mathrm{e}^{x}(x^{2} - 1) + 1(0 < x < \frac{1}{4})$ ，则

$$
h ^ {\prime} (x) = \mathrm{e} ^ {x} \left(x ^ {2} + 2 x - 1\right) <   0.
$$

当 $0 < x < \frac{1}{4}$ 时， $h(x)$ 单调递减，又 $h(0) = 0$ ，所以当 $0 < x < \frac{1}{4}$ 时， $h(x) < 0, g'(x) > 0, g(x)$ 单调递增，所以 $g(0.1) > g(0) = 0$ ，即 $0.1e^{0.1} > -\ln 0.9$ ，所以 a > c。

综上，c<a<b，故选C.

比较数与式的大小一直是高考的热点,前些年通常考查利用幂函数、指数函数与对数函数的单调性比较大小,近几年考查趋势转移到构造复杂的函数,利用导数研究所构造函数的单调性,再通过赋值比较大小.求解此类问题的关键是观察所给式子的结构,通过式子结构的特点构造相应的函数.

解析

不妨设 $f_{1}(x) = \sqrt{1 + x}, f_{2}(x) = \frac{\mathrm{e}}{1 + x}$ ,

$f_{3}(x) = \ln (1 + x) + 1$ ，其中 $x\in [0,0.01]$ ，则 $a = f_{1}(0.01),b = f_{2}(0.01),c = f_{3}(0.01)$ .令 $f_{1}(x) = \sqrt{1 + x} = t = g_{1}(t)$ ，则 $f_{3}(x) = \ln (1 + x) + 1 = 2\ln t + 1 = g_3(t)$ ，其中 $t\in [1,\sqrt{1.01} ]$

设 $\varphi(t) = g_1(t) - g_3(t) = t - 2\ln t - 1$ ( $t \in [1, \sqrt{1.01}]$ ), 则 $\varphi'(t) = 1 - \frac{2}{t} = \frac{t - 2}{t} < 0$ , 所以 $\varphi(t)$ 在 $[1, \sqrt{1.01}]$ 上单调递减, 则

$$
a - c = \varphi (\sqrt {1 . 0 1}) <   \varphi (1) = 1 - 2 \ln 1 - 1 = 0,
$$

故 $a < c$ . 令 $h(x) = \frac{f_1(x)}{f_2(x)} = \frac{(1 + x)^{\frac{3}{2}}}{\mathrm{e}^x}$ ( $x \in [0$ ,

0.01]），则 $h^{\prime}(x) = \frac{\frac{3}{2} (1 + x)^{\frac{1}{2}} \mathrm{e}^{x} - \mathrm{e}^{x} (1 + x)^{\frac{3}{2}}}{\mathrm{e}^{2x}} =$ $\frac{\sqrt{1+x}\left(\frac{1}{2}-x\right)}{\mathrm{e}^{x}}>0$ , 所以 $h(x)$ 在 $[0,0.01]$ 上单调递增，则 $\frac{a}{b} = h(0.01) = \frac{f_1(0.01)}{f_2(0.01)} > h(0) = 1$ ，所以 $a > b$ .

综上，b<a<c，故选 B.

# 点评

这类问题可以考虑利用“分段法”来进行求解,即要比较 a,b,c 的大小关系,可以根据$a, b, c$ 的结构，找到两个数 $x_{1}, x_{2}$ ，使得（不妨设） $a < x_{1} < b < x_{2} < c$ ，从而判断出 $a, b, c$ 的大小关系.

变式 3 已知 $a = \frac{3(2 - \ln 3)}{\mathrm{e}^{2}}$ , $b = \ln \sqrt[3]{3}$ , $c = \frac{2 - \ln 4}{\mathrm{e}}$ , 则（）.

A. c<b<a

B. b<c<a

C. c < a < b

D. $a < b < c$

$$
a = \frac {3 (2 - \ln 3)}{\mathrm{e} ^ {2}} = \frac {\ln \frac {\mathrm{e} ^ {2}}{3}}{\frac {\mathrm{e} ^ {2}}{3}}, b = \ln \sqrt [ 3 ]{3} = \frac {\ln 3}{3}, c =

$\frac{2-\ln 4}{e}=\frac{\ln\frac{e}{2}}{\frac{e}{2}}$ ，构造 $F(x)=\frac{\ln x}{x}(x>0)$ ，则

$$
a = F \left(\frac {\mathrm{e} ^ {2}}{3}\right), b = F (3), c = F \left(\frac {\mathrm{e}}{2}\right).
$$

由 $F'(x)=\frac{1-\ln x}{x^{2}}(x>0)$ ，可知当 0<x<e 时， $F'(x)>0, F(x)$ 单调递增，当 x>e 时， $F'(x)<0, F(x)$ 单调递减，故当 x=e 时， $F(x)$ 取得最大值 $\frac{1}{e}$ . 因

为 $0 < \frac{\mathrm{e}}{2} < \frac{\mathrm{e}^2}{3} < \mathrm{e}, F(x)$ 在 $(0, \mathrm{e})$ 单调递增，所以 $c = F(\frac{\mathrm{e}}{2}) < a = F(\frac{\mathrm{e}^2}{3})$ ，即 $c < a$ 。

因为 $3 \in (\mathrm{e}, +\infty)$ , 令 $t = \frac{\ln x}{x}$ 有两个解 $x_{1}, x_{2}$ , 且 $x_{1} < x_{2}$ , 则 $1 < x_{1} < \mathrm{e} < x_{2}, t \in (0, \frac{1}{\mathrm{e}})$ , 可得 $\ln x_{1} = tx_{1}, \ln x_{2} = tx_{2}$ , 所以

$$
t = \frac {\ln x _ {2} - \ln x _ {1}}{x _ {2} - x _ {1}} = \frac {\ln x _ {2} + \ln x _ {1}}{x _ {2} + x _ {1}}, \tag {①}
$$

$$
\frac {1}{x _ {1} + x _ {2}} = \frac {t}{\ln (x _ {1} x _ {2})}. \tag {②}
$$

令 $g(x)=\ln x-\frac{2(x-1)}{x+1}(x>1)$ ，则 $g'(x)=\frac{(x-1)^{2}}{x(x+1)^{2}}>0$ ， $g(x)$ 单调递增，故当 x>1 时， $g(x)>g(1)=0$ ，即 $x\in(1,+\infty)$ 时， $\ln x>\frac{2(x-1)}{x+1}$ ，从而 $\ln\frac{x_{2}}{x_{1}}>\frac{2(\frac{x_{2}}{x_{1}}-1)}{\frac{x_{2}}{x_{1}}+1}$ ，即 $\frac{\ln x_{2}-\ln x_{1}}{x_{2}-x_{1}}>\frac{2}{x_{2}+x_{1}}$ ，结合①

和②可得 $t > \frac{2t}{\ln(x_{1}x_{2})}$ ，则 $x_{1}x_{2} > e^{2}$ 。又 $1 < \frac{e^{2}}{3} < e < 3$ ，所以当 $x_{1} = \frac{e^{2}}{3}$ 时， $x_{2} > 3$ ，由 $F(x)$ 在 $(e, +\infty)$ 上单调递减可知 $a = F(\frac{e^{2}}{3}) = F(x_{1}) = F(x_{2}) < F(3) = b$ ，即 a < b。

综上， $c < a < b$ ，故选C.

# 点评

本题有两个难点,一是对 a,b,c 同构后,构造函数 $F(x) = \frac{\ln x}{x} (x > 0)$ ; 二是构造函数$g(x)=\ln x-\frac{2(x-1)}{x+1}$ 寻找方程 $t=\frac{\ln x}{x}$ 的两个根的关系，再利用其关系比较a,b.

综上,比较某些数或式的大小问题,看似与函数的单调性无关,但是挖掘问题的内在联系,抓住其本质,构造函数并运用函数的单调性解题,有时能起到化难为易、化繁为简的作用.具体说来,对于复杂式子大小的比较问题通常要根据所给式子的结构特征构造函数,然后研究所构造的函数的单调性,再通过赋值比较大小.
