## 3.2 双曲线

双曲线也是具有广泛应用的一种圆锥曲线，如发电厂冷却塔的外形、通过声音时差测定位等都要用到双曲线的性质。本节我们将类比椭圆的研究方法研究双曲线的有关问题。

### 3.2.1 双曲线及其标准方程

我们知道，平面内与两个定点 $F_{1}$ ， $F_{2}$ 的距离的和等于常数（大于 $\left|F_{1}F_{2}\right|$ ）的点的轨迹是椭圆。一个自然的问题是：平面内与两个定点的距离的差等于常数的点的轨迹是什么？下面我们先用信息技术探究一下。

[[课本/【人教版】高中选择性必修 第一册数学电子课本/知识点/双曲线的定义|双曲线的定义]]


> [!explore] 探究
> 类比求椭圆标准方程的过程，我们如何建立适当的坐标系，得出双曲线的方程？
> 
> > [!abstract]- 分析
> > 观察我们画出的双曲线，发现它也具有对称性，而且直线 $F_1F_2$ 是它的一条对称轴，所以我们取经过两焦点 $F_1$ 和 $F_2$ 的直线为 $x$ 轴，线段 $F_1F_2$ 的垂直平分线为 $y$ 轴，建立如图 3.2-3 所示的平面直角坐标系 $Oxy$。设 $M(x, y)$ 是双曲线上任意一点，双曲线的焦距为 $2c\ (c > 0)$，那么，焦点 $F_1, F_2$ 的坐标分别是 $(-c, 0), (c, 0)$，又设 $|MF_1| - |MF_2| = \pm 2a$ （$a$ 为大于 $0$ 的常数，$a < c$）。
> > 
> > <div align="center">
> >   <img src="课本/【人教版】高中选择性必修%20第一册数学电子课本/知识点/images/e3f665ce3d43bed0f0e7adedf05f6e90995cd22e8b44225105dc90ee968ee9e3.jpg" width="55%" />
> >   <br />
> >   图 3.2-3
> > </div>
> > 
> > 由双曲线的定义，双曲线就是下列点的集合：
> > $$P = \{M \mid ||MF_1| - |MF_2|| = 2a, 0 < 2a < |F_1F_2|\}.$$
> > 
> > 因为
> > $$|MF_1| = \sqrt{(x + c)^2 + y^2}, \quad |MF_2| = \sqrt{(x - c)^2 + y^2},$$
> > 所以
> > $$\sqrt{(x + c)^2 + y^2} - \sqrt{(x - c)^2 + y^2} = \pm 2a. \tag{①}$$
> > 
> > 类比椭圆标准方程的化简过程，化简①，得
> > $$(c^2 - a^2)x^2 - a^2y^2 = a^2(c^2 - a^2),$$
> > 
> > 两边同除以 $a^2(c^2 - a^2)$，得
> > $$\frac{x^2}{a^2} - \frac{y^2}{c^2 - a^2} = 1.$$
> > 
> > 由双曲线的定义知，$2c > 2a$，即 $c > a$，所以 $c^2 - a^2 > 0$。
> > 
> > 类比椭圆标准方程的建立过程，令 $b^2 = c^2 - a^2$，其中 $b > 0$，代入上式，得
> > $$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \ (a > 0, b > 0). \tag{②}$$
