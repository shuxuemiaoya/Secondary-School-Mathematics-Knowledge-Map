1. 在下列各小题中，已知向量 a, b 的坐标，分别求 $a + b$ ，a - b 的坐标：
（1） $a = (-2, 4), b = (5, 2)$ ;
（2） $a = (4, 3), b = (-3, 8)$ ;
（3） $a = (2, 3), b = (-2, -3)$ ;
（4） $a = (3,0),b = (0,4).$

2. 在下列各小题中，已知 $A, B$ 两点的坐标，分别求 $\overrightarrow{AB}, \overrightarrow{BA}$ 的坐标：
（1） $A(3,5),B(6,9);$
（2） $A(-3, 4), B(6, 3)$ ;
（3） $A(0, 3), B(0, 5)$ ;
（4） $A(3,0),B(8,0)$ .

3. 若点 $A(0, 1)$ , $B(1, 0)$ , $C(1, 2)$ , $D(2, 1)$ , 则 $AB$ 与 $CD$ 有什么位置关系? 证明你的猜想.
