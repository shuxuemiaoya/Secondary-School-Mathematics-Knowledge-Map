### 复习巩固

1. 判断下列函数的单调性，并求出单调区间：
（1） $f(x) = -2x + 1$ ;
（2） $f(x) = x + \cos x, x \in \left(0, \frac{\pi}{2}\right)$ ;
（3） $f(x) = 2x - 4;$
（4） $f(x) = 2x^{3} + 4x$ .

2. 判断下列函数的单调性，并求出单调区间：
（1） $f(x) = x^{2} + 2x - 4$ ;
（2） $f(x) = 2x^{2} - 3x + 3$ ;
（3） $f(x) = 3x + x^3$ ;
（4） $f(x) = x^{3} + x^{2} - x.$

（1） $f(x)=6x^{2}+x+2;$   
（2） $f(x) = x^{3} - 12x$   
（3） $f(x)=6-12x+x^{3}$ ;   
（4） $f(x) = 48x - x^3.$
