##### 题型04求三角函数的单调区间
##### 【典例1】（24-25高一上·全国·课堂例题）求函数$y = \sin \left( \frac{\pi}{3} - x \right)$的单调递增区间．
<span class="fake-tag">答案</span>$\left\lbrack \frac{\text{5π}}{6} + 2 k \pi , \frac{1 1 \pi}{6} + 2 k \pi \right\rbrack$，$k \in Z$．
<span class="fake-tag">分析</span>函数$y = \sin \left( \frac{\pi}{3} - x \right)$可化为$y = - \sin \left( x - \frac{\pi}{3} \right)$，结合正弦函数性质可求其单调递增区间.
<span class="fake-tag">详解</span> $y = \sin \left( \frac{\pi}{3} - x \right) = - \sin \left( x - \frac{\pi}{3} \right)$，
令$z = x - \frac{\pi}{3}$，又$y = - \sin z$的单调递增区间是$\left\lbrack \frac{\pi}{2} + 2 k \pi , \frac{3 \pi}{2} + 2 k \pi \right\rbrack$，$k \in Z$，
∴令$\frac{\pi}{2} + 2 k \pi \leq x - \frac{\pi}{3} \leq \frac{3 \pi}{2} + 2 k \pi$，$k \in Z$，
得$\frac{\text{5π}}{6} + 2 k \pi \leq x \leq \frac{1 1 \pi}{6} + 2 k \pi$，$k \in Z$，
∴函数$y = \sin \left( \frac{\pi}{3} - x \right)$的单调递增区间为$\left\lbrack \frac{\text{5π}}{6} + 2 k \pi , \frac{1 1 \pi}{6} + 2 k \pi \right\rbrack$，$k \in Z$．
##### 【典例2】（23-24高一上·江苏无锡·期末）已知函数$f ( x ) = 2 \cos \left( 2 x - \frac{\pi}{6} \right) , x \in \mathbf{R}$．
(1)求函数$f ( x )$取得最大值、最小值的自变量$x$的集合，并求出最大值、最小值；
(2)求函数$f ( x )$在区间$[ 0 , \pi ]$上的单调递增区间．
<span class="fake-tag">答案</span>(1)答案见解析
(2)$\left\lbrack 0 , \frac{\pi}{12} \right\rbrack$和$\left\lbrack \frac{\text{7} \text{π}}{12} \text{,} \text{π} \right\rbrack$
<span class="fake-tag">分析</span>（1）直接利用余弦函数的性质求最值及取最值时$x$的集合；
（2）先通过$0 \leq x \leq \pi$求出$2 x - \frac{\pi}{6}$的范围，再根据余弦函数的性质求解单调增区间.
<span class="fake-tag">详解</span>（1）对于函数$f ( x ) = 2 \cos \left( 2 x - \frac{\pi}{6} \right) , x \in \mathbf{R}$，
当$2 x - \frac{\pi}{6} = 2 k \text{π,} k \in Z$，即$x \in \left\{ x | x = \frac{\pi}{12} + k \text{π,} k \in Z \right\}$时，函数$f ( x )$取得最大值$2$；
当$2 x - \frac{\pi}{6} = \pi + 2 k \text{π,} k \in Z$，即$x \in \left\{ x | x = \frac{7 \pi}{12} + k \text{π,} k \in Z \right\}$时，函数$f ( x )$取得最小值$- 2$．
（2）$\because 0 \leq x \leq \pi$，$\therefore - \frac{\pi}{6} \leq 2 x - \frac{\pi}{6} \leq \frac{\text{11} \text{π}}{6}$，
由$- \frac{\pi}{6} \leq 2 x - \frac{\pi}{6} \leq 0$和$\pi \leq 2 x - \frac{\pi}{6} \leq \frac{\text{11} \text{π}}{6}$可得
函数$f ( x )$的单调增区间为$\left\lbrack 0 , \frac{\pi}{12} \right\rbrack$和$\left\lbrack \frac{\text{7} \text{π}}{12} \text{,} \text{π} \right\rbrack$.
##### 【变式1】（23-24高一上·湖北孝感·期末）已知函数$f ( x ) = \sqrt{2} \sin \left( 2 x + \frac{\pi}{4} \right)$.
(1)求$f ( x )$在区间$\left\lbrack 0 , \frac{\pi}{2} \right\rbrack$上的最大值和最小值；
(2)求$f ( x )$在区间$[ 0 , 2 \pi ]$上的单调递减区间.
<span class="fake-tag">答案</span>(1)最大值为$\sqrt{2}$，最小值为$- 1$；
(2)$\lbrack \frac{\pi}{8} , \frac{5 \pi}{8} \rbrack$，$\lbrack \frac{9 \pi}{8} , \frac{1 3 \pi}{8} \rbrack$.
<span class="fake-tag">分析</span>（1）根据正弦函数的性质结合条件即得；
（2）利用正弦函数的单调性结合条件即得.
<span class="fake-tag">详解</span>（1）由$x \in \lbrack 0 , \frac{\pi}{2} \rbrack$可得$2 x + \frac{\pi}{4} \in \lbrack \frac{\pi}{4}$,，
当得$2 x + \frac{\pi}{4} = \frac{\pi}{2}$即时，函数取得最大值$\sqrt{2}$，
当得$2 x + \frac{\pi}{4} = \frac{5 \pi}{4}$即$x = \frac{\pi}{2}$时，函数取得最小值$- 1$，
即在区间$\left\lbrack 0 , \frac{\pi}{2} \right\rbrack$上的最大值为$\sqrt{2}$，最小值为$- 1$；
（2）∵$2 k \pi + \frac{\pi}{2} \leq 2 x + \frac{\pi}{4} \leq 2 k \pi + \frac{3 \pi}{2} ( k \in Z )$时单调递减，
∴$k \pi + \frac{\pi}{8} \leq x \leq k \pi + \frac{5 \pi}{8}$时单调递减，
当$k = 0$时，$x \in \lbrack \frac{\pi}{8} , \frac{5 \pi}{8} \rbrack \subset \lbrack 0 , 2 \pi \rbrack$；
当$k = 1$时，$x \in \lbrack \frac{9 \pi}{8} , \frac{1 3 \pi}{8} \rbrack \subset \lbrack 0 , 2 \pi \rbrack$；
∴的单调递减区间是$\lbrack \frac{\pi}{8} , \frac{5 \pi}{8} \rbrack$，$\lbrack \frac{9 \pi}{8} , \frac{1 3 \pi}{8} \rbrack$.
