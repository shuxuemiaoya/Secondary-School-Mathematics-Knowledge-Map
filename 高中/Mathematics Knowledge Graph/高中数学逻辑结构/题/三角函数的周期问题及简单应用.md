##### 题型01 三角函数的周期问题及简单应用
##### 【典例1】（24-25高一上·全国·课后作业）下列函数中，以$2 \pi$为最小正周期的是（ ）
$\quad$A．$y = \left| \text{sin} x \right|$ 
$\quad$B．$y = \text{sin} 2 x$ 
$\quad$C．$y = \text{cos} 4 x$ 
$\quad$D．$y = \left| \text{cos} \frac{x}{2} \right|$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>对于AD，根据图象变换和周期公式分析判断，对于BC，根据周期公式分析判断.
<span class="fake-tag">详解</span>对于A，$y = \left| \text{sin} x \right|$的图象是由$y = \text{sin} x$把$x$轴下方的图象翻折上去、$x$轴上方的图象保持不变得到的，
则最小正周期为$\pi$，故A错误；
对于B，$y = \text{sin} 2 x$的最小正周期为$\frac{2 \pi}{2} = \pi$，故B错误；
对于C，$y = \text{cos} 4 x$的最小正周期为$\frac{2 \pi}{4} = \frac{\pi}{2}$，故C错误；
对于D，$y = \left| \text{cos} \frac{x}{2} \right|$的图象是由$y = \text{cos} \frac{x}{2}$把$x$轴下方的图象翻折上去、$x$轴上方的图象保持不变得到的，
则最小正周期为$2 \pi$，故D正确．
故选：D．
##### 【典例2】（多选）（24-25高一上·全国·课后作业）（多选）下列函数中周期为π，且为偶函数的是（ ）
$\quad$A．$y = \left| \text{cos} x \right|$ 
$\quad$B．$y = \sin 2 x$
$\quad$C．$y = \sin \left( 2 x + \frac{\pi}{2} \right)$ 
$\quad$D．$y = \cos \frac{1}{2} x$
<span class="fake-tag">答案</span>AC
<span class="fake-tag">分析</span>根据周期的定义以及奇偶性的定义判断 A；根据 $y = \text{sin} 2 x$ 是奇函数， $y = \text{cos} \frac{1}{2} x$ 的周期为 $4 \pi$ ，分别判断 BD；化简 $y = \text{sin} \left( 2 x + \frac{\pi}{2} \right) = \text{cos} 2 x$, 再判断 C.
<span class="fake-tag">详解</span>对于A,因为 $\left| \text{cos} ( x + \pi ) \right| = \left| - \text{cos} x \right| = \left| \text{cos} x \right|$,
所以 $y = \left| \text{cos} x \right|$ 的周期为 $\pi$,
因为 $\left| \text{cos} ( - x ) \right| = \left| \text{cos} x \right|$,
所以 $y = \left| \text{cos} x \right|$ 是偶函数,A 符合题意；
对于B, $y = \text{sin} 2 x$ 是奇函数，B 不合题意；
对于D, $y = \text{cos} \frac{1}{2} x$ 的周期为 $\frac{2 \pi}{\frac{1}{2}} = 4 \pi$ ，所以 D 不合题意；
对于C,$y = \text{sin} \left( 2 x + \frac{\pi}{2} \right) = \text{cos} 2 x ,$
因为$\text{cos} ( - 2 x ) = \text{cos} 2 x ,$
$所 以 y = \text{sin} \left( 2 x + \frac{\pi}{2} \right)$ 是偶函数，
因为 $y = \text{sin} \left( 2 x + \frac{\pi}{2} \right) = \text{cos} 2 x$ 的周期是 $\frac{2 \pi}{2} = \pi , C$ 符合题意.
故选: AC.
##### 【变式1】（2024高二下·云南·学业考试）函数$y = \text{cos} \left( 2 x + \frac{\pi}{3} \right)$的最小正周期是（ ）
$\quad$A．$4 \pi$ 
$\quad$B．$2 \pi$ 
$\quad$C．$\pi$ 
$\quad$D．$\frac{\pi}{2}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>根据余弦型函数的最小正周期公式运算求解.
<span class="fake-tag">详解</span>由题意可得：函数$y = \text{cos} \left( 2 x + \frac{\pi}{3} \right)$的最小正周期是$T = \frac{2 \pi}{2} = \pi$.
故选：C.
##### 【变式2】（23-24高一下·上海·期末）下列四个函数中，以$\pi$为最小正周期的奇函数是（ ）
$\quad$A．$y = \text{sin} x$ 
$\quad$B．$y = \text{cos} 2 x$
$\quad$C．$y = \left| \text{sin} x \right|$ 
$\quad$D．$y = \text{sin} 2 x$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>由三角函数的奇偶性、周期性即可逐一判断各个选项.
<span class="fake-tag">详解</span>对于A，$y = \text{sin} x$是以为最小正周期的奇函数，故A不符合题意；
对于B，$y = \text{cos} 2 x$是以$\pi$为最小正周期的偶函数，故B不符合题意；
对于C，若$y = f ( x ) = \left| \text{sin} x \right|$，则$f \left( \frac{\pi}{2} \right) = \left| \text{sin} \frac{\pi}{2} \right| = 1 = \left| \text{sin} \left( - \frac{\pi}{2} \right) \right| = f \left( - \frac{\pi}{2} \right)$，为偶函数，故C不符合题意；
对于D，若$y = g ( x ) = \text{sin} 2 x$，显然其定义域为全体实数，且$g ( - x ) = - g ( x )$，所以$y = \text{sin} 2 x$是奇函数，且它的最小正周期为$\pi$，故D符合题意.
故选：D.
