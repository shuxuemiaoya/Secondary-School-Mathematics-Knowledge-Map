**2. 适用范围**

*   一元高次不等式（如 $(x-a)(x-b)(x-c) > 0$）
*   一元分式不等式（如 $\frac{(x-a)(x-b)}{(x-c)} \le 0$）

**3. 穿根引线法的步骤**

以求解 $(x-x_1)(x-x_2)...(x-x_n) > 0$ 为例（假设 $x_1 < x_2 < ... < x_n$ 且均为单根）：

1.  **化标准形式：** 将不等式右边化为0，左边化为若干个一次因式的乘积或商的形式，且每个因式中 $x$ 的系数为正。
    *   例如：$x^3 - 2x^2 - 5x + 6 > 0 \Rightarrow (x+2)(x-1)(x-3) > 0$
    *   例如：$\frac{1}{x-1} < \frac{2}{x+1} \Rightarrow \frac{1}{x-1} - \frac{2}{x+1} < 0 \Rightarrow \frac{(x+1)-2(x-1)}{(x-1)(x+1)} < 0 \Rightarrow \frac{-x+3}{(x-1)(x+1)} < 0 \Rightarrow \frac{x-3}{(x-1)(x+1)} > 0$ (注意 $x$ 系数要为正)
2.  **求根（零点）：** 令每个因式等于0，求出所有的根（包括分子和分母的根）。
    *   对于分式不等式，分母的根要特别标记，因为它们是无意义的点。
3.  **标根：** 在数轴上从小到大依次标出所有的根。这些根将数轴分成若干个区间。
4.  **穿线（画波浪线）：**
    *   从最右边的区间（大于最大根的区间）开始，从数轴上方画线。
    *   遇到**奇次根**（即该因式是1次、3次等奇数次幂），线穿过数轴。
    *   遇到**偶次根**（即该因式是2次、4次等偶数次幂），线不穿过数轴，而是从数轴上方（或下方）弹回。
    *   **解释原理：**
        *   当 $x$ 穿过一个单根 $x_i$ 时，因式 $(x-x_i)$ 的符号会改变，从而导致整个表达式的符号改变。
        *   当 $x$ 穿过一个偶次根 $x_j$ 时，因式 $(x-x_j)^k$ (k为偶数) 的符号在 $x_j$ 两侧保持不变（因为平方项总是非负的），所以整个表达式的符号不变。
5.  **定解：**
    *   根据不等号的方向确定解集：
        *   若 $> 0$，则取波浪线在数轴上方的区间。
        *   若 $< 0$，则取波浪线在数轴下方的区间。
        *   若 $\ge 0$ 或 $\le 0$，则在取区间的同时，还要考虑分子上的根（可以取等号的点）。分母上的根永远不能取等号。

#### **三、例题精讲**

**例1：** 求解不等式 $x^3 - 2x^2 - 5x + 6 > 0$

1.  **化标准形式：** $(x+2)(x-1)(x-3) > 0$
2.  **求根：** $x_1 = -2, x_2 = 1, x_3 = 3$ (均为单根)
3.  **标根：** 在数轴上标出 -2, 1, 3。
4.  **穿线：** 从右上方开始，依次穿过 3, 1, -2。
    *   数轴：`...(-2)...(1)...(3)...`
    *   波浪线：`+` (x>3) `_` (1<x<3) `+` (-2<x<1) `_` (x<-2)
5.  **定解：** 因为是 $> 0$，取波浪线在数轴上方的区间。
    *   解集：$(-2, 1) \cup (3, +\infty)$

**例2：** 求解不等式 $\frac{x-3}{(x-1)(x+1)} \ge 0$

1.  **化标准形式：** 已是标准形式。
2.  **求根：** 分子根 $x=3$；分母根 $x=1, x=-1$。
3.  **标根：** 在数轴上标出 -1, 1, 3。
4.  **穿线：** 所有根均为单根。从右上方开始，依次穿过 3, 1, -1。
    *   数轴：`...(-1)...(1)...(3)...`
    *   波浪线：`+` (x>3) `_` (1<x<3) `+` (-1<x<1) `_` (x<-1)
5.  **定解：** 因为是 $\ge 0$，取波浪线在数轴上方的区间，并考虑分子根。
    *   解集：$(-1, 1) \cup [3, +\infty)$ (注意 $x=3$ 可以取，但 $x=1, x=-1$ 不能取)

**例3：** 求解不等式 $(x-1)^2 (x+2) < 0$

1.  **化标准形式：** 已是标准形式。
2.  **求根：** $x=1$ (偶次重根), $x=-2$ (单根)。
3.  **标根：** 在数轴上标出 -2, 1。
4.  **穿线：** 从右上方开始。
    *   遇到 $x=1$ (偶次根)，线不穿过，从上方弹回。
    *   遇到 $x=-2$ (单根)，线穿过。
    *   数轴：`...(-2)...(1)...`
    *   波浪线：`+` (x>1) `+` (-2<x<1) `_` (x<-2)
5.  **定解：** 因为是 $< 0$，取波浪线在数轴下方的区间。
    *   解集：$(-\infty, -2)$

我们来一步步解释它的原理：

### 穿根引线法的原理

1.  **零点是符号变化的“临界点”：**
    *   对于一个连续函数 $f(x)$，它的函数值符号（正或负）只可能在两种情况下发生改变：
        *   $f(x) = 0$ (即 $x$ 是函数的零点)。
        *   $f(x)$ 不连续。
    *   在解一元高次不等式和分式不等式时，我们通常将不等式转化为 $f(x) > 0$ 或 $f(x) < 0$ 的形式。这些函数的零点（对于分式不等式，还包括使分母为零的点，这些点是函数不连续的点）将数轴分成了若干个区间。在每个区间内部，函数的符号是保持不变的。

2.  **因式分解与符号分析：**
    *   穿根引线法要求我们将不等式左边化为若干个一次因式（或其幂）的乘积或商的形式，例如 $(x-x_1)(x-x_2)...(x-x_n)$ 或 $\frac{(x-x_1)(x-x_2)}{(x-x_3)}$。
    *   **关键在于：** 表达式的整体符号是由每个因式的符号共同决定的。

3.  **“穿”与“不穿”的依据（单根与重根）：**
    *   **单根（奇次根）：** 如果一个因式 $(x-x_i)$ 出现奇数次（例如 $(x-x_i)^1$, $(x-x_i)^3$），那么当 $x$ 的值从 $x_i$ 的一侧变到另一侧时，因式 $(x-x_i)$ 的符号会发生改变（例如，从负变正，或从正变负）。由于它是奇数次幂，所以整个表达式的符号也会随之改变。
        *   **视觉表现：** 波浪线“穿过”数轴，表示函数值符号发生了变化。
    *   **偶次根（重根）：** 如果一个因式 $(x-x_j)$ 出现偶数次（例如 $(x-x_j)^2$, $(x-x_j)^4$），那么当 $x$ 的值从 $x_j$ 的一侧变到另一侧时，因式 $(x-x_j)^k$ (k为偶数) 的符号**不会改变**（因为一个数的偶数次幂总是非负的，除非这个数是0）。因此，整个表达式的符号在经过这个根时也不会改变。
        *   **视觉表现：** 波浪线“不穿过”数轴，而是从上方（或下方）“弹回”，表示函数值符号保持不变。

4.  **“从右上方开始”的依据：**
    *   在将不等式化为标准形式（即右边为0，左边因式中 $x$ 的系数都为正）后，考虑当 $x$ 取一个非常大的值（大于所有根）时，每个因式 $(x-x_i)$ 都是正数。
    *   因此，所有这些正数的乘积或商也必然是正数。
    *   **视觉表现：** 最右边的区间（大于最大根的区间）函数值一定为正，所以波浪线从数轴的上方开始画。

5.  **分式不等式的特殊处理：**
    *   分式不等式 $\frac{P(x)}{Q(x)} > 0$ 或 $\frac{P(x)}{Q(x)} < 0$ 的符号判断与乘积不等式类似。
    *   但需要注意的是，使分母 $Q(x)=0$ 的点，函数是没有定义的，因此这些点永远不能包含在解集中，即使不等号带有等号（如 $\ge 0$ 或 $\le 0$）。

### 总结

穿根引线法通过将复杂的不等式分解为简单的线性因式，并利用这些因式的零点作为数轴上的分界点。通过分析每个因式在零点两侧的符号变化规律（特别是奇次幂和偶次幂的区别），我们可以系统地确定整个表达式在不同区间内的符号，从而快速准确地找到不等式的解集。它巧妙地结合了**代数分析**（因式分解、符号判断）和**几何直观**（数轴、波浪线），是一种非常高效的解题工具。
