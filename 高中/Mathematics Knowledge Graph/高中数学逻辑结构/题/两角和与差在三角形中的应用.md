####### 题型3：两角和与差在三角形中的应用
在三角形中，因为  $A + B + C = \pi$  ，所以在三角形中有如下关系：
$\begin{array}{l} \sin A = \sin [ \pi - (B + C) ] = \sin (B + C) \\ = \sin B \cos C + \cos C \sin B \\ \cos A = \cos [ \pi - (B + C) ] = - \cos (B + C) \\ = - \cos B \cos C + \sin C \sin B \\ \tan A = \tan \left[ \pi - (B + C) \right] = - \tan (B + C) \\ = - \frac {\tan B + \tan C}{1 - \tan B \tan C} \\ \end{array}$
