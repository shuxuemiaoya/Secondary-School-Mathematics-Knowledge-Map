##### 【典例1】（24-25高一上·全国·课后作业）若$\text{tan} \alpha = 2$，则$2 \text{sin} \alpha \text{cos} \alpha$等于（ ）
$\quad$A．$\pm \frac{3}{5}$ 
$\quad$B．$- \frac{3}{5}$ 
$\quad$C．$\frac{3}{5}$ 
$\quad$D．$\frac{4}{5}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>先根据$1 = \text{si} \text{n}^{2} \alpha + \text{co} \text{s}^{2} \alpha$将所求式子分子化为齐次式，再利用同角三角函数关系化弦为切，最后代入切的值得结果.
<span class="fake-tag">详解</span>$2 \text{sin} \alpha \text{cos} \alpha = \frac{2 \text{sin} \alpha \text{cos} \alpha}{\text{si} \text{n}^{2} \alpha + \text{co} \text{s}^{2} \alpha} = \frac{2 \text{tan} \alpha}{\text{ta} \text{n}^{2} \alpha + 1} = \frac{2 \times 2}{2^{2} + 1} = \frac{4}{5}$.
故选：D

##### 【变式3】（24-25高一上·全国·课后作业）已知$\tan \alpha = \frac{2}{3}$，求下列各式的值．
(1)$\frac{\cos \alpha - \sin \alpha}{\cos \alpha + \sin \alpha} + \frac{\cos \alpha + \sin \alpha}{\cos \alpha - \sin \alpha}$；
(2)$\frac{1}{\text{sin} \alpha \text{cos} \alpha}$．
<span class="fake-tag">答案</span>(1)$\frac{26}{5}$
(2)$\frac{13}{6}$
<span class="fake-tag">分析</span>（1）将式子齐次化即可求解；
（2）将1看做，再进行齐次化即可求解.
<span class="fake-tag">详解</span>（1）因为$\tan \alpha = \frac{2}{3}$，所以$\cos \alpha \neq 0$，将式子$\frac{\cos \alpha - \sin \alpha}{\cos \alpha + \sin \alpha} + \frac{\cos \alpha + \sin \alpha}{\cos \alpha - \sin \alpha}$的分子分母同时除以$\cos \alpha$得：$\frac{1 - \tan \alpha}{1 + \tan \alpha} + \frac{1 + \tan \alpha}{1 - \tan \alpha}$
所以$\frac{\cos \alpha - \sin \alpha}{\cos \alpha + \sin \alpha} + \frac{\cos \alpha + \sin \alpha}{\cos \alpha - \sin \alpha} = \frac{1 - \tan \alpha}{1 + \tan \alpha} + \frac{1 + \tan \alpha}{1 - \tan \alpha} = \frac{1 - \frac{2}{3}}{1 + \frac{2}{3}} + \frac{1 + \frac{2}{3}}{1 - \frac{2}{3}} = \frac{26}{5}$．
（2）$\frac{1}{\sin \alpha \cos \alpha} = \frac{\sin^{2} \alpha + \cos^{2} \alpha}{\sin \alpha \cos \alpha} = \frac{\tan^{2} \alpha + 1}{\tan \alpha} = \frac{13}{6}$．
