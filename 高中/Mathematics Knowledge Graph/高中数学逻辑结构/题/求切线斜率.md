##### 题型04求切线斜率
##### 【典例1】（2023下·北京海淀·高二首都师范大学附属中学校考期中）若直线$l$过原点，且与函数$y = \frac{\ln x}{x}$的图像相切，则该直线的斜率为（ ）
$\quad$A．1 
$\quad$B．$\frac{1}{2 e}$ 
$\quad$C．$\frac{1}{e}$ 
$\quad$D．$\frac{1}{e^{2}}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>因为$y = \frac{\ln x}{x}$，所以$y^{'} = \frac{1 - \ln x}{x^{2}}$，设切点为$\left( x_{0} , \frac{{\ln x}_{0}}{x_{0}} \right)$，所以$\left. y^{'} \right|_{x = x_{0}} = \frac{1 - \text{ln} x_{0}}{x_{0}^{2}}$ ，
所以切线方程为$y - \frac{{\ln x}_{0}}{x_{0}} = \frac{1 - {\ln x}_{0}}{x_{0}^{2}} \left( x - x_{0} \right)$，
又切线过坐标原点，所以$- \frac{{\ln x}_{0}}{x_{0}} = \frac{1 - {\ln x}_{0}}{x_{0}^{2}} \left( - x_{0} \right)$，解得，
所以切线方程的斜率为$k = \frac{1 - {\ln x}_{0}}{x_{0}^{2}} = \frac{1 - \frac{1}{2}}{( \sqrt{e} )^{2}} = \frac{1}{2 e}$.
故选：B
##### 【典例2】（2023·海南省直辖县级单位·统考一模）函数$f ( x ) = x^{2} + 2 \ln x - b x + a$（*b*＞0，*a*∈R）在点$( b , f ( b ) )$处的切线斜率的最小值是（ ）
$\quad$A．2 
$\quad$B． 
$\quad$C．$2 \sqrt{2}$ 
$\quad$D．1
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>$f^{'} ( x ) = 2 x + \frac{2}{x} - b ( x > 0 )$，
所以在点$( b , f ( b ) )$处的切线斜率是$f^{'} ( b ) = 2 b + \frac{2}{b} - b = b + \frac{2}{b}$，
因为*b*＞0，所以$f^{'} ( b ) = b + \frac{2}{b} \geq 2 \sqrt{2}$，当且仅当即$b = \sqrt{2}$时等号成立，
故选：C．
##### 【变式1】（2022上·河南·高三河南省淮阳中学校联考阶段练习）已知$f ( x ) = x e^{x}$，过$P \left( \frac{1}{2} , 0 \right)$作曲线的切线，切点在第一象限，则切线的斜率为（ ）
$\quad$A．$\frac{3 \sqrt{e}}{2}$ 
$\quad$B．$3 e^{2}$ 
$\quad$C．$2 e$ 
$\quad$D．$\sqrt{e}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>解：由$f ( x ) = x e^{x}$，得$f^{'} ( x ) = ( x + 1 ) e^{x}$，
设切点坐标为$\left( x_{0} , x_{0} e^{x_{0}} \right)$，则切线方程为$y - x_{0} e^{x_{0}} = \left( x_{0} + 1 \right) e^{x_{0}} \left( x - x_{0} \right)$，
把点$P \left( \frac{1}{2} , 0 \right)$代入并整理，得$- x_{0} = \left( x_{0} + 1 \right) \left( \frac{1}{2} - x_{0} \right)$，
解得$x_{0} = 1$或$x_{0} = - \frac{1}{2}$（舍去），
故切线斜率为$f^{'} ( 1 ) = 2 e$．
故选：C．
