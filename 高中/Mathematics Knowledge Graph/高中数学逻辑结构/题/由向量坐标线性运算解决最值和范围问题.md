##### 【典例1】（2019·全国·高三校联考阶段练习）在直角梯形*ABCD*中$\overrightarrow{A B} \cdot \overrightarrow{A D} = 0 , \angle B = 3 0^{\circ}$，$A B = 2 \sqrt{3} , B C = 2$，点*E*为*BC*边上一点，且$\overrightarrow{A E} = x \overrightarrow{A B} + y \overrightarrow{A D}$，则$x y$的取值范围是（ ）
$\quad$A．$\left( - \infty ， \frac{1}{2} \right)$ 
$\quad$B．$\left\lbrack 0 , \frac{1}{2} \right\rbrack$

<span class="fake-tag">详解</span>建立如图所示的直角坐角坐标系，过$C$作$C F \bot A B$，垂足为$F$，
因为$\angle B = 3 0 {^\circ} , B C = 2$，
所以有$\sin B = \frac{C F}{B C} , \cos B = \frac{B F}{B C} \Rightarrow C F = 2 \sin 3 0 {^\circ} = 1 , B F = 2 \cos 3 0 {^\circ} = \sqrt{3}$，
