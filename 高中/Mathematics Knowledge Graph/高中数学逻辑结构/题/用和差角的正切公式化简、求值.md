##### 题型13用和差角的正切公式化简、求值
##### 【典例1】（2024高三·北京·专题练习）设$\tan ( \alpha + \beta ) = \frac{2}{5}$，$\tan \left( \beta - \frac{\pi}{4} \right) = \frac{1}{4}$，则$\tan \left( \alpha + \frac{\pi}{4} \right)$的值是（ ）
$\quad$A．$\frac{1}{6}$ 
$\quad$B．$\frac{3}{22}$ 
$\quad$C．$\frac{13}{22}$ 
$\quad$D．$\frac{13}{18}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>先由$\alpha + \frac{\pi}{4} = ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right)$，再利用两角差的正切公式进行求解即可.
<span class="fake-tag">详解</span>$\tan \left( \alpha + \frac{\pi}{4} \right) = \tan \left\lbrack ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right) \right\rbrack = \frac{\tan ( \alpha + \beta ) - \tan \left( \beta - \frac{\pi}{4} \right)}{1 + \tan ( \alpha + \beta ) \tan \left( \beta - \frac{\pi}{4} \right)}$，
将$\tan ( \alpha + \beta ) = \frac{2}{5}$，$\tan \left( \beta - \frac{\pi}{4} \right) = \frac{1}{4}$代入，得原式$= \frac{\frac{2}{5} - \frac{1}{4}}{1 + \frac{2}{5} \times \frac{1}{4}} = \frac{3}{22}$．
故选：B.

##### 【变式1】（23-24高一下·江苏·阶段练习）已知$\alpha , \beta \in \left( 0 , \frac{\pi}{2} \right)$，，$\tan \left( \beta - \frac{\pi}{4} \right) = \frac{1}{2}$，则$\tan ( 2 \alpha + \beta )$的值为（ ）
$\quad$A．$\frac{1}{3}$ 
$\quad$B．$- 3$ 
$\quad$C．$- \frac{1}{3}$ 
$\quad$D．$- 1$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>由，利用同角三角函数的关系求出$\tan \alpha$，倍角公式得$\tan 2 \alpha$，由$\tan \left( \beta - \frac{\pi}{4} \right) = \frac{1}{2}$，利用两角差的正切公式求出$\tan \beta$，再由两角和正切公式求出$\tan ( 2 \alpha + \beta )$.
<span class="fake-tag">详解</span>$\alpha \in \left( 0 , \frac{\pi}{2} \right)$，，则，
有$\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = 2$，$\tan 2 \alpha = \frac{2 \tan \alpha}{1 - \tan^{2} \alpha} = - \frac{4}{3}$，
$\tan \left( \beta - \frac{\pi}{4} \right) = \frac{\tan \beta - \tan \frac{\pi}{4}}{1 + \tan \beta \tan \frac{\pi}{4}} = \frac{\tan \beta - 1}{1 + \tan \beta} = \frac{1}{2}$，得$\tan \beta = 3$，
$\tan ( 2 \alpha + \beta ) = \frac{\tan 2 \alpha + \tan \beta}{1 - \tan 2 \alpha \tan \beta} = \frac{- \frac{4}{3} + 3}{1 - \left( - \frac{4}{3} \right) \times 3} = \frac{1}{3}$.
故选：A.
