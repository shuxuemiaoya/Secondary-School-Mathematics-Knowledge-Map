##### 题型04 二倍角中的拼凑角问题
##### 【典例1】（23-24高一·江苏·课后作业）已知α∈（0，$\frac{\pi}{2}$），β∈（﹣π，$- \frac{\pi}{2}$），sinα$= \frac{7 \sqrt{2}}{10}$，cosβ$= - \frac{2 \sqrt{5}}{5}$，则α+2β的值为（ ）
$\quad$A．$\frac{3}{4} \pi$ 
$\quad$B．$- \frac{3}{4} \pi$ 
$\quad$C．$\frac{5}{4} \pi$ 
$\quad$D．$- \frac{5}{4} \pi$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用同角三角函数关系式求出$\tan \alpha$、$\tan \beta$，利用二倍角的正切公式求出$\tan 2 \beta$，再根据的值可求得结果.
<span class="fake-tag">详解</span>由于α∈（0，$\frac{\pi}{2}$），sinα$= \frac{7 \sqrt{2}}{10}$，所以$\text{cos} \alpha = \sqrt{1 - \text{si} \text{n}^{2} \alpha} = \frac{\sqrt{2}}{10}$，
由于β∈（﹣π，$- \frac{\pi}{2}$），cosβ$= - \frac{2 \sqrt{5}}{5}$，所以$\text{sin} \beta = - \sqrt{1 - \text{co} \text{s}^{2} \beta} = - \frac{\sqrt{5}}{5}$.
所以$\text{tan} \alpha = \frac{\text{sin} \alpha}{\text{cos} \alpha} = 7$，$\text{tan} \beta = \frac{\text{sin} \beta}{\text{cos} \beta} = \frac{1}{2}$，所以$\tan 2 \beta = \frac{2 \tan \beta}{1 - \tan^{2} \beta} = \frac{2 \times \frac{1}{2}}{1 - \frac{1}{4}} = \frac{4}{3}$，
由于α∈（0，$\frac{\pi}{2}$），β∈（﹣π，$- \frac{\pi}{2}$），
所以$\alpha + 2 \beta \in \left( - 2 \pi ， - \frac{\pi}{2} \right)$，
由于tan（α+2β）$= \frac{\text{tan} \alpha + \text{tan} 2 \beta}{1 - \text{tan} \alpha \text{tan} 2 \beta} = \frac{7 + \frac{4}{3}}{1 - 7 \times \frac{4}{3}} = - 1$，
所以$\alpha + 2 \beta = - \frac{5 \pi}{4}$.
故选：D.
【点睛】关键点点睛：熟练掌握同角公式、二倍角的正切公式、两角和的正切公式是解题关键.
##### 【典例2】（23-24高二下·天津河北·期末）已知$\cos \alpha = \frac{2 \sqrt{2}}{3}$，$\alpha \in ( - \frac{\pi}{2} , 0 )$．
(1)求$\sin ( \alpha + \frac{\pi}{3} )$的值；
(2)若，$\beta \in ( 0 , \frac{\pi}{2} )$，求$\cos ( \alpha + 2 \beta )$的值．
<span class="fake-tag">答案</span>(1)$\frac{2 \sqrt{6} - 1}{6}$
(2)$\frac{14 \sqrt{2} + 2 4}{75}$
<span class="fake-tag">分析</span>（1）由同角三角函数关系以及两角和的正弦公式化简求值即可；（2）由二倍角公式求出，$\sin 2 \beta$，再由两角和的余弦公式即可求解.
<span class="fake-tag">详解</span>（1）因为$\cos \alpha = \frac{2 \sqrt{2}}{3}$，$\alpha \in ( - \frac{\pi}{2} , 0 )$，所以,
所以$\sin ( \alpha + \frac{\pi}{3} ) = \sin \alpha \cos \frac{\pi}{3} + \cos \alpha \sin \frac{\pi}{3} = - \frac{1}{3} \times \frac{1}{2} + \frac{2 \sqrt{2}}{3} \times \frac{\sqrt{3}}{2} = \frac{2 \sqrt{6} - 1}{6}$
（2）因为，$\beta \in ( 0 , \frac{\pi}{2} )$，所以$\cos \beta = \sqrt{1 - \sin^{2} \beta} = \frac{4}{5}$，
所以$\sin 2 \beta = 2 \sin \beta \cos \beta = \frac{24}{25}$，，
所以$\cos ( \alpha + 2 \beta ) = \cos \alpha \cos 2 \beta - \sin \alpha \sin 2 \beta = \frac{2 \sqrt{2}}{3} \times \frac{7}{25} + \frac{1}{3} \times \frac{24}{25} = \frac{14 \sqrt{2} + 2 4}{75}$
##### 【变式1】（23-24高一下·江苏南通·阶段练习）已知$\text{tan} \alpha = \frac{1}{7}$，$\text{tan} \beta = \frac{1}{3}$，且$\alpha$，都是锐角，
(1)求$\text{sin} 2 \alpha$的值；
(2)求$\alpha + 2 \beta$的值.
<span class="fake-tag">答案</span>(1)$\frac{7}{25}$；
(2)$\frac{\pi}{4}$.
<span class="fake-tag">分析</span>（1）利用二倍角公式和同角三角函数的关系，化简可得结论.
（2）利用二倍角公式得$\text{tan} 2 \beta = \frac{3}{4}$，再利用两角和的正切函数公式得$\text{tan} ( \alpha + 2 \beta ) = 1$，最后利用三角函数的求值计算得结论．
<span class="fake-tag">详解</span>（1）由$\text{tan} \alpha = \frac{1}{7}$，得$\text{sin} 2 \alpha = \frac{2 \sin \alpha \cos \alpha}{\sin^{2} \alpha + \cos^{2} \alpha} = \frac{2 \text{tan} \alpha}{1 + \text{ta} \text{n}^{2} \alpha} = \frac{2 \cdot \frac{1}{7}}{1 + ( \frac{1}{7} )^{2}} = \frac{7}{25}$.
（2）由$\text{tan} \beta = \frac{1}{3}$，得$\text{tan} 2 \beta = \frac{2 \text{tan} \beta}{1 - \text{ta} \text{n}^{2} \beta} = \frac{2 \times \frac{1}{3}}{1 - \frac{1}{9}} = \frac{6}{8} = \frac{3}{4}$，而$\text{tan} \alpha = \frac{1}{7}$，
因此$\text{tan} ( \alpha + 2 \beta ) = \frac{\text{tan} \alpha + \text{tan} 2 \beta}{1 - \text{tan} \alpha \text{tan} 2 \beta} = \frac{\frac{1}{7} + \frac{3}{4}}{1 - \frac{1}{7} \times \frac{3}{4}} = 1$，
又$\alpha$，为锐角，且$\text{tan} \alpha = \frac{1}{7} < 1 , \text{tan} \beta = \frac{1}{3} < 1$，则$0 < \alpha < \frac{\pi}{4} , 0 < \beta < \frac{\pi}{4}$，
因此$0 < \alpha + 2 \beta < \frac{3 \pi}{4}$，
所以$\alpha + 2 \beta$的值是$\frac{\pi}{4}$.
##### 【变式2】（23-24高三上·江苏宿迁·阶段练习）已知$\tan \alpha = \frac{1}{3}$，$\tan \beta = \frac{1}{7}$，且$- \pi < \alpha < - \frac{\pi}{2}$，$0 < \beta < \frac{\pi}{2}$，求$2 \alpha + \beta$的值.
<span class="fake-tag">答案</span>$- \frac{7 \pi}{4}$
<span class="fake-tag">分析</span>求出$\tan ( 2 \alpha + \beta )$的值以及$2 \alpha + \beta$的取值范围，即可求得$2 \alpha + \beta$的值.
<span class="fake-tag">详解</span>因为$\tan \alpha = \frac{1}{3}$，所以$\tan 2 \alpha = \frac{2 \tan \alpha}{1 - \tan^{2} \alpha} = \frac{\frac{2}{3}}{1 - \frac{1}{9}} = \frac{3}{4}$，
所以$\tan ( 2 \alpha + \beta ) = \frac{\tan 2 \alpha + \tan \beta}{1 - \tan 2 \alpha \tan \beta} = \frac{\frac{3}{4} + \frac{1}{7}}{1 - \frac{3}{4} \times \frac{1}{7}} = 1$，
因为$- \pi < \alpha < - \frac{\pi}{2}$，所以$- 2 \pi < 2 \alpha < - \pi$，
又因为$\tan 2 \alpha = \frac{3}{4} > 0$，所以$- 2 \pi < 2 \alpha < - \frac{3}{2} \pi$，
因为$0 < \beta < \frac{\pi}{2}$，所以$- 2 \pi < 2 \alpha + \beta < - \pi$，所以$2 \alpha + \beta = - \frac{7 \pi}{4}$.
