##### 题型03全概率公式和贝叶斯公式的综合应用
##### 【典例1】（2024上·云南·高三校联考阶段练习）某次考试共有8道单选题，某学生掌握了其中5道题，2道题有思路，1道题完全没有思路．掌握了的题目他可以选择唯一正确的答案，有思路的题目每道做对的概率为$\frac{3}{5}$，没有思路的题目，只好任意猜一个答案，猜对的概率为$\frac{1}{4}$．已知这个学生随机选一道题作答且做对了，则该题为有思路的题目的概率为（ ）
$\quad$A．$\frac{3}{20}$ 
$\quad$B．$\frac{8}{43}$ 
$\quad$C．$\frac{1}{4}$ 
$\quad$D．$\frac{3}{5}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>设事件$A_{1}$表示选到会做的题，事件表示选到有思路的题，事件$A_{3}$表示选到完全没有思路的题；
设事件$B$表示答对该题，则$P ( B | A_{1} ) = 1 ， \mspace{6mu} \mspace{6mu} P ( B | A_{2} ) = \frac{3}{5} ， \mspace{6mu} \mspace{6mu} P ( B | A_{3} ) = \frac{1}{4}$，
设事件$U$表示答对某个题，
则$P ( U ) = P ( A_{1} ) P ( B | A_{1} ) + P ( A_{2} ) P ( B | A_{2} ) + P ( A_{3} ) P ( B | A_{3} ) = \frac{5}{8} \times 1 + \frac{2}{8} \times \frac{3}{5} + \frac{1}{8} \times \frac{1}{4} = \frac{129}{160}$，
设事件$C$表示将有思路的题目做对，则$P ( C ) = \frac{P ( A_{2} ) P ( B | A_{2} )}{P ( U )} = \frac{8}{43}$，
故选：B
##### 【典例2】（多选）（2024·全国·高三专题练习）有3台车床加工同一型号的零件，第1，2，3台加工的次品率分别为$6 \% , 5 \% , 4 \%$，加工出来的零件混放在一起．已知第1，2，3台车床加工的零件数的比为$5 : 6 : 9$，现任取一个零件，记事件$A_{i} =$ “零件为第*i*台车床加工”（$i = 1 , 2 , 3$），事件$B =$ “零件为次品”，则（ ）
$\quad$A． 
$\quad$B．$P \left( B | A_{2}  \right) = \frac{1}{6}$
$\quad$C． 
$\quad$D．$P \left( A_{1} | B  \right) = \frac{5}{16}$
<span class="fake-tag">答案</span>ACD
<span class="fake-tag">详解</span>AB选项，事件$A_{i} =$ “零件为第*i*台车床加工”（ $i = 1 , 2 , 3$），事件$B =$ “零件为次品”，
则$P \left( A_{1} \right) = \frac{5}{5 + 6 + 9} = \frac{1}{4}$，$P \left( A_{2} \right) = \frac{6}{5 + 6 + 9} = \frac{3}{10}$，$P \left( A_{3} \right) = \frac{9}{5 + 6 + 9} = \frac{9}{20}$，
$P \left( B | A_{1}  \right) = 6 \%$，$P \left( B | A_{2}  \right) = 5 \%$，$P \left( B | A_{3}  \right) = 4 \%$，故A正确，B错误；
C选项，$P ( B ) = P \left( A_{1} B \right) + P \left( A_{2} B \right) + P \left( A_{3} B \right)$
$= P \left( A_{1} \right) P \left( B | A_{1}  \right) + P \left( A_{2} \right) P \left( B | A_{2}  \right) + P \left( A_{3} \right) P \left( B | A_{3}  \right)
$= \frac{1}{4} \times 6 \% + \frac{3}{10} \times 5 \% + \frac{9}{20} \times 4 \% = 0 . 0 4 8$，故C正确；
D选项，$P \left( A_{1} | B  \right) = \frac{P \left( A_{1} B \right)}{P ( B )} = \frac{P \left( B | A_{1}  \right) P \left( A_{1} \right)}{P ( B )} = \frac{0 . 2 5 \times 6 \%}{0 . 0 4 8} = \frac{5}{16}$，故D正确．
故选：ACD．
##### 【典例3】（2023下·福建龙岩·高二福建省连城县第一中学校考阶段练习）设某芯片制造厂有甲、乙、丙三条生产线，生产规格的芯片，现有20块该规格的芯片，其中甲、乙、丙生产的芯片分别为6块、6块、8块，且甲、乙、丙生产该芯片的次品率依次为$\frac{1}{10} ， \frac{1}{15} ， \frac{1}{20}$.现从这20块芯片中任取1块芯片，若取到的芯片是次品，则该芯片是甲厂生产的概率为 .
<span class="fake-tag">答案</span>$\frac{3}{7}$
<span class="fake-tag">详解</span>记芯片分别由甲、乙、丙三条生产线生产为事件$A_{1} , A_{2} , A_{3}$，
记取到的芯片是次品为事件$B$，
则$P ( A_{1} ) = \frac{6}{20} , P ( A_{2} ) = \frac{6}{20} , P ( A_{3} ) = \frac{8}{20}$，
$P ( B | A_{1}  ) = \frac{1}{10} , P ( B | A_{2}  ) = \frac{1}{15} , P ( B | A_{3}  ) = \frac{1}{20}$，
$P ( B ) = P ( A_{1} ) \cdot P ( B | A_{1}  ) + P ( A_{2} ) P ( B | A_{2}  ) + P ( A_{3} ) P ( B | A_{3}  )$
$= \frac{6}{20} \times \frac{1}{10} + \frac{6}{20} \times \frac{1}{15} + \frac{8}{20} \times \frac{1}{20} = \frac{3 + 2 + 2}{20 \times 5} = 0 . 0 7$，
故$P (  A_{1} | B ) = \frac{P ( A_{1} ) P (  B | A_{1} )}{P ( B )} = \frac{\frac{6}{20} \times \frac{1}{10}}{0 . 0 7} = \frac{3}{7}$，
则若取到的芯片是次品，则该芯片是甲厂生产的概率为$\frac{3}{7}$.
故答案为：$\frac{3}{7}$
##### 【变式1】（2024·全国·高二假期作业）某批产品来自$A$，$B$两条生产线，$A$生产线占$6 0 \%$，次品率为4%；$B$生产线占，次品率为$5 \%$，现随机抽取一件进行检测，若抽到的是次品，则它来自$A$生产线的概率是（ ）
$\quad$A．$\frac{1}{2}$ 
$\quad$B．$\frac{6}{11}$ 
$\quad$C．$\frac{3}{5}$ 
$\quad$D．$\frac{5}{9}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>因为抽到的次品可能来自于$A$，$B$两条生产线，设$A =$ “抽到的产品来自$A$生产线”，
$B =$ “抽到的产品来自$B$生产线”，$C =$ “抽到的一件产品是次品”，
则$P ( A ) = 0 . 6 , P ( B ) = 0 . 4 , P ( C | A ) = 0 . 0 4 , P ( C | B ) = 0 . 0 5$，
由全概率公式得$P ( C ) = P ( A ) P \left( C | A  \right) + P ( B ) P \left( C | B  \right) = 0 . 6 \times 0 . 0 4 + 0 . 4 \times 0 . 0 5 = 0 . 0 4 4$，
所以它来自$A$生产线的概率是$P \left( A | C  \right) = \frac{P ( A C )}{P ( C )} = \frac{P ( A ) P \left( C | A  \right)}{P ( C )} = \frac{0 . 6 \times 0 . 0 4}{0 . 0 4 4} = \frac{6}{11}$.
故选：B
##### 【变式2】（2024上·江苏扬州·高三统考期末）有一个邮件过滤系统，它可以根据邮件的内容和发件人等信息，判断邮件是不是垃圾邮件，并将其标记为垃圾邮件或正常邮件.对这个系统的测试具有以下结果：每封邮件被标记为垃圾邮件的概率为$\frac{2}{5}$，被标记为垃圾邮件的有$\frac{1}{10}$的概率是正常邮件，被标记为正常邮件的有$\frac{1}{10}$的概率是垃圾邮件，则垃圾邮件被该系统成功过滤（即垃圾邮件被标记为垃圾邮件）的概率为 .
<span class="fake-tag">答案</span>$\frac{6}{7}$
<span class="fake-tag">详解</span>记$A =$ “正常邮件”，$B =$ “标记为正常邮件”，则$P ( \overline{B} ) = \frac{2}{5}$，$P ( A | \overline{B} ) = \frac{1}{10}$，$P ( \overline{A} | B ) = \frac{1}{10}$，
所以$P ( B ) = 1 - P ( \overline{B} ) = \frac{3}{5}$，$P ( \overline{A} | \overline{B} ) = 1 - P ( A | \overline{B} ) = \frac{9}{10}$，
故$P ( \overline{A} ) = P ( \overline{A} | B ) P ( B ) + P ( \overline{A} | \overline{B} ) P ( \overline{B} ) = \frac{3}{50} + \frac{18}{50} = \frac{21}{50}$，
所以$P ( \overline{B} | \overline{A} ) = \frac{P ( \overline{B} ) P ( \overline{A} | \overline{B} )}{P ( \overline{A} )} = \frac{\frac{18}{50}}{\frac{21}{50}} = \frac{6}{7}$.
故答案为：$\frac{6}{7}$
