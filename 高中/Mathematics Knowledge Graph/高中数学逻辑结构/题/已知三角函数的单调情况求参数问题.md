##### 题型06已知三角函数的单调情况求参数问题

三种解法
第一种写出x的单调区间，然后让给定区间成为子集
第二种给定区间写出整体的区间，让这个区间在单调区间内
第三种用周期性
##### 【典例1】（多选）（23-24高一下·辽宁抚顺·期中）若函数$f ( x ) = \cos \left( \omega x - \frac{\pi}{12} \right) ( \omega > 0 )$在$\left\lbrack \frac{\pi}{6} , \frac{2 \pi}{3} \right\rbrack$上单调，则$\omega$的取值可能为（ ）
$\quad$A．$\frac{1}{16}$ 
$\quad$B．$\frac{1}{8}$ 
$\quad$C．$\frac{3}{8}$ 
$\quad$D．$\frac{7}{4}$
<span class="fake-tag">答案</span>AB
<span class="fake-tag">分析</span>根据余弦函数只能在半个周期内单调可得$0 < \omega \leq 2$，再通过整体法确定$\omega x - \frac{\pi}{12}$的取值范围，最后求解$\omega$取值范围即可.
<span class="fake-tag">详解</span>由题意函数的最小正周期为$T = \frac{2 \pi}{\omega}$，
因为函数在区间$\lbrack \frac{\pi}{6} , \frac{2 \pi}{3} \rbrack$上单调，
可得$\frac{2 \pi}{3} - \frac{\pi}{6} \leq \frac{\pi}{\omega}$，
则$0 < \omega \leq 2$．
因为$x \in \left\lbrack \frac{\pi}{6} , \frac{2 \pi}{3} \right\rbrack$，
所以$\omega x - \frac{\pi}{12} \in \left\lbrack \frac{\omega \pi}{6} - \frac{\pi}{12} , \frac{2 \omega \pi}{3} \right. \left. - \frac{\pi}{12} \right\rbrack$．
因为$0 < \omega \leq 2$，
所以$- \frac{\pi}{12} < \frac{\omega \pi}{6} - \frac{\pi}{12} \leq \frac{\pi}{4}$．
因为在$\left\lbrack \frac{\pi}{6} , \frac{2 \pi}{3} \right\rbrack$上单调，
所以$\begin{cases}\frac{\omega \pi}{6} - \frac{\pi}{12} \leq 0 \\ \frac{2 \omega \pi}{3} - \frac{\pi}{12} \leq 0\end{cases}$或$\begin{cases}\frac{\omega \pi}{6} - \frac{\pi}{12} \geq 0 , \\ \frac{2 \omega \pi}{3} - \frac{\pi}{12} \leq \pi ,\end{cases}$
解得$0 < \omega \leq \frac{1}{8}$或$\frac{1}{2} \leq \omega \leq \frac{13}{8}$．
故选：AB.
##### 【典例2】（2024·广东佛山·模拟预测）已知函数在区间$\left( \frac{\pi}{6} , \frac{\pi}{2} \right)$上单调，$f \left( \frac{\pi}{4} \right) = \frac{1}{2}$，且对任意的$x \in R$，都有$f ( x ) \geq f \left( \frac{7 \pi}{12} \right)$，则初相的值为（ ）
$\quad$A．$- \frac{\pi}{3}$ 
$\quad$B．$- \frac{\pi}{6}$ 
$\quad$C．$\frac{\pi}{6}$ 
$\quad$D．$\frac{\pi}{3}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>由函数在区间$\left( \frac{\pi}{6} , \frac{\pi}{2} \right)$上单调，得$\frac{\pi}{\omega} \geq \frac{\pi}{2} - \frac{\pi}{6}$，又$\omega \in N^{*}$，则$\omega = 1 , 2 , 3$，又对任意的$x \in R$，都有$f ( x ) \geq f \left( \frac{7 \pi}{12} \right)$，则$f \left( \frac{7 \pi}{12} \right)$为函数的最小值，然后分$\omega = 1$，，$\omega = 3$时讨论，即可得到初相的值.
<span class="fake-tag">详解</span>因为函数在区间$\left( \frac{\pi}{6} , \frac{\pi}{2} \right)$上单调，
所以$\frac{\pi}{\omega} \geq \frac{\pi}{2} - \frac{\pi}{6}$，所以$0 < \omega \leq 3$，又$\omega \in N^{*}$，则$\omega = 1 , 2 , 3$，
对任意的$x \in R$，都有$f ( x ) \geq f \left( \frac{7 \pi}{12} \right)$，
即$f \left( \frac{7 \pi}{12} \right)$为函数的最小值，
当$\omega = 1$时，$f ( x ) = \sin ( x + \varphi )$，
所以$\frac{7 \pi}{12} + \varphi = \frac{3 \pi}{2} + 2 k \pi , k \in Z$，
因为，则此时不存在；
当时，$f ( x ) = \sin ( 2 x + \varphi )$，
所以$2 \times \frac{7 \pi}{12} + \varphi = \frac{3 \pi}{2} + 2 k \pi , k \in Z$，
因为，则此时$\varphi = \frac{\pi}{3}$， $f ( x ) = \sin ( 2 x + \frac{\pi}{3} )$，
则$f ( \frac{\pi}{4} ) = \sin ( \frac{\pi}{2} + \frac{\pi}{3} ) = \frac{1}{2}$，符合题意；
当$\omega = 3$时，$f ( x ) = \sin ( 3 x + \varphi )$，
所以$3 \times \frac{7 \pi}{12} + \varphi = \frac{3 \pi}{2} + 2 k \pi , k \in Z$，
因为，则此时$\varphi = - \frac{\pi}{4}$， $f ( x ) = \sin ( 3 x - \frac{\pi}{4} )$，
则$f ( \frac{\pi}{4} ) = \sin ( \frac{\text{3} \text{π}}{4} - \frac{\pi}{4} ) = 1$，不符合题意.

##### 【变式1】（23-24高二下·河南新乡·期末）若函数$f ( x ) = \cos \left( n x - \frac{\pi}{4} \right) \left( n \in \mathbf{N}^{*} \right)$在$\left\lbrack \frac{\pi}{8} , \frac{\text{3π}}{8} \right\rbrack$上单调递减，则满足条件的$n$的个数为（ ）
$\quad$A．$4$ 
$\quad$B．$3$ 
$\quad$C．$2$ 
$\quad$D．$1$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>先对$n$分不同情况进行讨论，得出当$n = 1$时不满足条件，当$n = 2$或$n = 3$时满足条件，当$n \geq 4$时不满足条件，即得到所求的全部$n$为$n = 2$和$n = 3$，从而得到答案.
<span class="fake-tag">详解</span>若$n = 1$，则$f \left( \frac{\pi}{8} \right) = \cos \frac{\pi}{8} < 1 = f \left( \frac{\pi}{4} \right)$，故$f ( x )$不满足条件；
若$n = 2$或$n = 3$，则对$\frac{\pi}{8} \leq x \leq \frac{\text{3π}}{8}$有$0 \leq 2 x - \frac{\pi}{4} \leq \frac{\pi}{2}$，或$\frac{\pi}{8} \leq 3 x - \frac{\pi}{4} \leq \frac{\text{7} \text{π}}{8} < \pi$.
所以$n x - \frac{\pi}{4} \in [ 0 , \pi ]$，根据复合函数单调性知$f ( x )$在$\left\lbrack \frac{\pi}{8} , \frac{\text{3} \text{π}}{8} \right\rbrack$上单调递减，满足条件；
若$n = 4$，则$f \left( \frac{\text{5π}}{16} \right) = - 1 < - \frac{\sqrt{2}}{2} = f \left( \frac{\text{3π}}{8} \right)$，故$f ( x )$不满足条件；
若$n \geq 5$，则由$\frac{3 n - 2}{8} - \frac{n - 2}{8} = \frac{n}{4} > 1$可知，存在正整数$k$满足$\frac{n - 2}{8} < k < \frac{3 n - 2}{8}$.
此时$\frac{\pi}{8} < \frac{4 k + 1}{4 n} \pi < \frac{\text{3π}}{8}$，$f \left( \frac{4 k + 1}{4 n} \pi \right) = \cos \left( \frac{4 k + 1}{4} \pi - \frac{\pi}{4} \right) = \cos k \pi = ( - 1 )^{k}$，从而$f ( x )$在$\left( \frac{\pi}{8} , \frac{\text{3} \text{π}}{8} \right)$上存在极值点，不可能单调递减，不满足条件.
综上，满足条件的有$n = 2$和$n = 3$.
故选：C.

##### 【变式2】（24-25高三上·广东·阶段练习）若函数$f ( x ) = \text{sin} \left( \omega x - \frac{\pi}{4} \right)$与$g ( x ) = \text{sin} \left( \omega x + \frac{\pi}{4} \right)$在区间$\left( 0 , \frac{\pi}{2} \right)$上均单调递增，则实数$\omega$的取值范围为 .
<span class="fake-tag">答案</span>
<span class="fake-tag">分析</span>确定$\omega > 0$，根据正弦函数的递增区间求出$\omega$的范围，结合正弦函数的周期性求出$\omega$的范围可得答案.
<span class="fake-tag">详解</span>当$\omega = 0$时，$f ( x ) = \text{sin} \left( - \frac{\pi}{4} \right)$不具备单调性，
当$\omega < 0$时，$f ( x ) = \text{sin} \left( \omega x - \frac{\pi}{4} \right) = - \text{sin} \left( - \omega x + \frac{\pi}{4} \right)$，
若在区间$\left( 0 , \frac{\pi}{2} \right)$上单调递增，则在$y = \text{sin} \left( - \omega x + \frac{\pi}{4} \right)$在区间$\left( 0 , \frac{\pi}{2} \right)$上单调递减，
可得$\frac{\pi}{4} < - \omega x + \frac{\pi}{4} < - \frac{\omega \pi}{2} + \frac{\pi}{4}$，因为$y = \text{sin} t$在$\left( \frac{\pi}{4} , \frac{\pi}{2} \right)$上是单调递增的，
所以$y = \text{sin} \left( - \omega x + \frac{\pi}{4} \right)$在$\left( 0 , \frac{\pi}{2} \right)$上不可能单调递减，所以$\omega < 0$不成立，
于是$\omega > 0$.
若函数$f ( x ) = \text{sin} \left( \omega x - \frac{\pi}{4} \right)$在区间$\left( 0 , \frac{\pi}{2} \right)$上单调递增，则
$\begin{cases}2 k \pi - \frac{\pi}{2} \leq - \frac{\pi}{4} \\ \frac{\pi \omega}{2} - \frac{\pi}{4} \leq 2 k \pi + \frac{\pi}{2}\end{cases} \left( k \in \mathbf{Z} \right)$，$\begin{cases}k \leq \frac{1}{8} \\ \omega \leq 4 k + \frac{3}{2}\end{cases}$，
若函数$g ( x ) = \text{sin} \left( \omega x + \frac{\pi}{4} \right)$在区间$\left( 0 , \frac{\pi}{2} \right)$上单调递增，则
$\begin{cases}2 k \pi - \frac{\pi}{2} \leq \frac{\pi}{4} \\ \frac{\pi \omega}{2} + \frac{\pi}{4} \leq 2 k \pi + \frac{\pi}{2}\end{cases} \left( k \in \mathbf{Z} \right)$，$\begin{cases}k \leq \frac{3}{8} \\ \omega \leq 4 k + \frac{1}{2}\end{cases}$，
因为$\omega > 0$，所以$k = 0$时，$0 < \omega \leq \frac{1}{2}$，
综上所述，$0 < \omega \leq \frac{1}{2}$.
故答案为：$\left. 0 , \frac{1}{2} \right.$.
