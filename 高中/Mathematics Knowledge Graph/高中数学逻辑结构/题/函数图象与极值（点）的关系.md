##### 题型01函数图象与极值（点）的关系
##### 【典例1】（多选）（2023上·黑龙江哈尔滨·高三哈师大附中校考阶段练习）如图所示是的导数$y = f^{'} ( x )$的图象，下列结论中正确的有（ ）．
![@@@dcca38db-3195-4ab4-a8f6-45a5e0ab0af0](高中习题/课堂同步/随堂练习习题/media/1d6955dde73d26014de13d4165ef2b84.png)
$\quad$A．$f ( x )$的单调递增区间是$( - 1 , 2 ) \cup ( 4 , + \infty )$
$\quad$B．$x = - 1$是$f ( x )$的极小值点
$\quad$C．$f ( x )$在区间$( 2 , 4 )$上单调递减，在区间$( - 1 , 2 )$上单调递增
$\quad$D．是$f ( x )$的极小值点
<span class="fake-tag">答案</span>BC
<span class="fake-tag">详解</span>由导函数的图象可知，当$- 3 < x < - 1$或$2 < x < 4$时，$f^{'} ( x ) < 0$；当$- 1 < x < 2$或$x \text{>4}$时，$f^{'} ( x ) > 0$；
所以$f ( x )$的单调递增区间为$( - 1 , 2 )$和$( 4 , + \infty )$，单调递减区间为$( - 3 , - 1 )$和$( 2 , 4 )$.故A错误，C正确；
所以$x = - 1$或$x = 4$是$f ( x )$的极小值点；故B正确；
所以是$f ( x )$取得极大值点；故D错误.
故选：BC.
##### 【典例2】（2023·上海·高二专题练习）已知函数$f ( x ) = a x^{3} + b x^{2} + c x$，其导函数$y = f^{'} ( x )$的图象经过点$( 1 , 0 )$，$( 2 , 0 )$，如图所示，则下列说法中正确结论的序号为 ．
![@@@af889634-2719-4ceb-ab45-2c483f3d0d62](高中习题/课堂同步/随堂练习习题/media/20f714a93655a63b4a35c17073fa9f15.png)
①当$x = \frac{3}{2}$时函数取得极小值；
②$f ( x )$有两个极值点；
③当时函数取得极小值；
④当$x = 1$时函数取得极大值．
<span class="fake-tag">答案</span>②③④
<span class="fake-tag">详解</span>由图象可知，当$x \in ( - \infty , 1 )$时，$f^{'} ( x ) > 0$；当$x \in ( 1 , 2 )$时，$f^{'} ( x ) < 0$；当$x \in ( 2 , + \infty )$时，$f^{'} ( x ) > 0$.
所以函数$f ( x )$在上单调递增，在$( 1 , 2 )$上单调递减，在$( 2 , + \infty )$上单调递增，
所以函数$f ( x )$有两个极值点，当$x = 1$时函数取得极大值，当时函数取得极小值，
故①错误，②③④正确.
故答案为：②③④
##### 【变式1】（多选）（2023上·江西宜春·高三江西省丰城中学校考开学考试）如图所示是的导数$y = f^{'} ( x )$的图象，下列结论中正确的有（ ）
![@@@bd74f1eb-d672-430e-a7f8-3ad3eca8d27c](高中习题/课堂同步/随堂练习习题/media/dff49c84e4862f6408faba3c9d8a6183.png)
$\quad$A．$f ( x )$的单调递增区间是$( - 1 , 2 ) , ( 4 , + \infty )$
$\quad$B．$x = - 1$是$f ( x )$的极小值点
$\quad$C．$f ( x )$在区间$( 2 , 4 )$上是减函数，在区间上是增函数
$\quad$D．是$f ( x )$的极小值点
<span class="fake-tag">答案</span>ABC
<span class="fake-tag">详解</span>解：根据图象知当$x \in ( - 1 , 2 ) \cup ( 4 + \infty )$时，$f^{'} ( x ) > 0$，函数在$( - 1 , 2 ) , ( 4 , + \infty )$上单调递增；
当$x \in ( - 3 , - 1 ) \cup ( 2 , 4 )$时，$f^{'} ( x ) < 0$，函数在$( - 3 , - 1 ) , ( 2 , 4 )$上单调递减．故A、C正确；

当时，$f ( x )$取得是极大值，不是$f ( x )$的极小值点，故D错误．
故选：ABC*．*
