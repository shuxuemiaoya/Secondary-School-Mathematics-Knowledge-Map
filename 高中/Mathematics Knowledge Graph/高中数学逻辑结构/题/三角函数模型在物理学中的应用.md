##### 【典例1】（24-25高一上·全国·课后作业）阻尼器是一种以提供阻力达到减震效果的专业工程装置，我国第一高楼上海中心大厦的阻尼器减震装置，被称为“镇楼神器”，如图（1）．由物理学知识可知，某阻尼器的运动过程可近似为单摆运动，其离开平衡位置的位移*y*（单位：m）和时间*t*（单位：s）的函数关系为$y = \sin ( \omega t + \varphi ) \left( \omega > 0 , | \varphi | < \pi \right)$，如图（2）．若该阻尼器在摆动过程中连续三次到达位置$y_{0}$（$- 1 < y_{0} < 1$）的时间分别为，，（），且$t_{1} + t_{2} = 2$，$t_{2} + t_{3} = 6$，则在一个周期内阻尼器离开平衡位置的位移大于0.5 m的总时间为（ ）

$\quad$A．$\frac{1}{3} \mspace{6mu} s$

<span class="fake-tag">分析</span>先确定函数的一个周期，再解不等式求另一个周期，最后计算总时间即可.
<span class="fake-tag">详解</span>由题意得$\frac{1}{2} ( t_{1} + t_{2} ) = 1$，$\frac{1}{2} ( t_{2} + t_{3} ) = 3$，
故函数$y = \sin ( \omega t + \varphi ) \left( \omega > 0 , | \varphi | < \pi \right)$的周期为$T = 2 \times ( 3 - 1 ) = 4$，$\omega = \frac{2 \pi}{4} = \frac{\pi}{2}$，可得$y = \sin \left( \frac{\pi}{2} t + \varphi \right)$，
令$\sin \left( \frac{\pi}{2} t + \varphi \right) > 0 . 5$，解得$4 k + \frac{1}{3} - \frac{2}{\pi} \varphi < t < 4 k + \frac{5}{3} - \frac{2}{\pi} \varphi , k \in Z$，
故总时间为$4 k + \frac{5}{3} - \frac{2}{\pi} \varphi - ( 4 k + \frac{1}{3} - \frac{2}{\pi} \varphi ) = \frac{4}{3}$，
综上在一个周期内阻尼器离开平衡位置的位移大于0.5m的总时间为$\frac{4}{3} s$.

##### 【变式2】（多选）（22-23高一上·福建宁德·期末）从物理学知识可知，图中弹簧振子中的小球相对平衡位置的位移$y$与时间$t$（单位：$s$）的关系符合函数$y = A \text{sin} ( \omega t + \varphi ) ( | \omega | < 1 0 0 )$．从某一时刻开始，用相机的连拍功能给弹簧振子连拍了20张照片．已知连拍的间隔为$0 . 0 1 s$，将照片按拍照的时间先后顺序编号，发现仅有第5张、第13张、第17张照片与第1张照片是完全一样的，则小球正好处于平衡位置的所有照片的编号有（ ）
![@@@a85022b8-8ed2-4d69-9e7a-c4a408e26126](高中习题/课堂同步/随堂练习习题/必修一/Attachments/5066f28ffc4e4aeb09b6c4f9cb5ab7af.png)
$\quad$A．4 
$\quad$B．6 
$\quad$C．12 
$\quad$D．18
<span class="fake-tag">答案</span>BCD
<span class="fake-tag">分析</span>首先分析出弹簧振子运动时的最小正周期$T = \frac{3}{25} s$，并求出$\omega$的值，然后结合已知条件求出的值，令$y = 0$，可求出结果.
<span class="fake-tag">详解</span>因为仅有第5张，第13张，第17张照片与第1张照片完全一样，
则弹簧振子运动时的最小正周期为$T = 1 2 \times 0 . 0 1 = 0 . 1 2 = \frac{3}{25} s$，
则$\omega = \frac{2 \pi}{\frac{3}{25}} = \frac{5 0 \pi}{3}$，所以$y = A \sin \left( \frac{5 0 \pi t}{3} + \varphi \right)$，
由题意可知，$A \sin \left( \frac{5 0 \pi}{3} \times \frac{1}{100} + \varphi \right) = A \sin \left( \frac{5 0 \pi}{3} \times \frac{5}{100} + \varphi \right)$，
所以$\sin \left( \frac{\pi}{6} + \varphi \right) = \sin \left( \frac{5 \pi}{6} + \varphi \right)$，则$\frac{1}{2} \cos \varphi + \frac{\sqrt{3}}{2} \sin \varphi = \frac{1}{2} \cos \varphi - \frac{\sqrt{3}}{2} \sin \varphi$，
所以$\sin \varphi = 0$，则$\varphi = m \pi$，$( m \in Z )$，则$y = A \sin \left( \frac{5 0 \pi t}{3} + m \pi \right)$，
令$y = 0$，可得$\frac{5 0 \pi t}{3} + m \pi = n \pi ( m , n \in Z )$，所以$t = \frac{3}{50} ( n - m )$，
令$k = n - m \in Z$，则$t = \frac{3}{50} k ( k \in Z )$，由$0 < \frac{3 k}{50} \leq \frac{1}{5}$，可得，
因为，则$k \in \left\{ 1 , 2 , 3 \right\}$，
当$k = 1$时，$t = \frac{3}{50} = 0 . 0 6 s$，对应第6张照片，
当$k = 2$时，$t = \frac{6}{50} = 0 . 1 2 s$，对应第12张照片，
当$k = 3$时，$t = \frac{9}{50} = 0 . 1 8 s$，对应第18张照片.
故选：BCD
