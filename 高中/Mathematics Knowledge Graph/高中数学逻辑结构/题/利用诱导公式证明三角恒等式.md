$\quad$C．$\text{sin} \left( 5 3^{\circ} - x \right) = \text{cos} \left( 3 7^{\circ} + x \right)$

对于C，$\text{sin} \left( 5 3^{\circ} - x \right) = \text{sin} \left\lbrack 9 0^{\circ} - \left( 3 7^{\circ} + x \right) \right\rbrack \text{=cos} \left( 3 7^{\circ} + x \right)$，故C正确；
