##### 题型02 乘法公式的应用
##### 【典例1】![](MathLogic-Weave/高中数学逻辑结构/题/Attachments/e74b54e533e499bf15f213c9a50a3da4.png)（2024·全国·高三专题练习）已知1号箱中有2个白球和4个红球，2号箱中有5个白球和3个红球（白球与红球大小、形状、质地相同），现随机从1号箱中取出一球放入2号箱，再从2号箱中随机取出一球，则两次都取到红球的概率是（ ）
$\quad$A．$\frac{11}{27}$ 
$\quad$B． 
$\quad$C．$\frac{8}{27}$ 
$\quad$D．$\frac{3}{8}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>设“从1号箱中取到红球放入2号箱”为事件*A*，“从2号箱中取到红球”为事件*B*.
由题意，知$P ( A ) = \frac{4}{2 + 4} = \frac{2}{3}$，$P \left(  B | A \right) = \frac{3 + 1}{8 + 1} = \frac{4}{9}$，所以$P ( B A ) = P \left(  B | A \right) P ( A ) = \frac{4}{9} \times \frac{2}{3} = \frac{8}{27}$，
所以两次都取到红球的概率为$\frac{8}{27}$.
故选：C.
##### 【典例2】（2023上·上海·高二上海市行知中学校考阶段练习）一个盒子中装有2个红球，8个黑球，从中不放回地任取1个小球，则第二次才取出红球的概率是 .
<span class="fake-tag">答案</span>$\frac{8}{45}$
<span class="fake-tag">详解</span>由题意知第一次取出的是黑球，设为事件$A$，
第二次取出红球设为事件$B$，
则$P ( A ) = \frac{8}{10} = \frac{4}{5}$，则$P \left(  B | A \right) = \frac{2}{9}$，
所以第二次才取出红球的概率是$P ( A B ) = P ( A ) P \left(  B | A \right) = \frac{4}{5} \times \frac{2}{9} = \frac{8}{45}$.
故答案为：$\frac{8}{45}$
##### 【典例3】（2024·全国·高三专题练习）某厂产品的废品率为4%，而合格品中有75%是一等品，求一等品率．
<span class="fake-tag">答案</span>72%.
<span class="fake-tag">详解</span>记*A*：合格品,记*B*：一等品，由于$B \subseteq A$,则$P ( B ) = P ( A B )$，
由题意，$P ( A ) = 1 - 4 \% = 9 6 \% , P ( B | A ) = 7 5 \%$，
故$P ( B ) = P ( A B ) = P ( A ) P ( B | A ) = 9 6 \% \times 7 5 \% = 0 . 7 2$，
即一等品率为72%.
##### 【变式1】（2024·全国·高二假期作业）设*A*，*B*是两个事件，$P ( A ) > 0$，$P ( B ) > 0$，则下列结论一定成立的是（ ）
$\quad$A．$P \left( B | A  \right) P \left( A | B  \right) = 1$ 
$\quad$B．$P ( A B ) = P ( A ) P ( B )$
$\quad$C．$P ( B ) \leq P \left( B | A  \right)$ 
$\quad$D．$P ( A B ) \leq P \left( B | A  \right)$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>A：由$P \left( B | A  \right) P \left( A | B  \right) = 1$，而$0 \leq P \left( B | A  \right) , P \left( A | B  \right) \leq 1$，则$P \left( B | A  \right) = \frac{P ( A B )}{P ( A )} = P \left( A | B  \right) = \frac{P ( A B )}{P ( B )} = 1$，即$P ( A B ) = P ( A ) = P ( B )$时成立，否则不成立，排除；
B：当*A*，*B*是两个相互独立的事件，有$P ( A B ) = P ( A ) P ( B )$，否则不成立，排除；
C：由$P ( B ) \leq P \left( B | A  \right) = \frac{P ( A B )}{P ( A )}$且$0 < P ( A ) \leq 1$，故$P ( A B ) \geq P ( A ) P ( B )$时成立，否则不成立，排除；
D：由$P ( A B ) = P \left( B | A  \right) P ( A )$，而$0 < P ( A ) \leq 1$，则$P ( A B ) \leq P \left( B | A  \right)$，符合；
故选：D
##### 【变式2】（2024上·河南南阳·高二南阳市第五中学校校联考期末）已知$P ( A ) = \frac{5}{6}$，$P \left( B | \bar{A}  \right) = \frac{1}{2}$，则$P \left( \overline{A} B \right) =$ .
<span class="fake-tag">答案</span>
<span class="fake-tag">详解</span>因为$P ( A ) = \frac{5}{6}$，则$P \left( \bar{A} \right) = 1 - P ( A ) = 1 - \frac{5}{6} = \frac{1}{6}$，
所以，$P \left( \bar{A} B \right) = P \left( \bar{A} \right) P \left( B | \bar{A}  \right) = \frac{1}{6} \times \frac{1}{2} = \frac{1}{12}$.
故答案为：.
##### 【变式3】（2024·全国·高三专题练习）玛丽想在网上购买一款品牌手机，客服承诺该品牌手机从1m高的地方掉落时，屏幕第一次未碎掉的概率为0.5，当第一次未碎掉时第二次也未碎掉的概率为0.3，玛丽想如果手机从1m高的地方掉落两次后屏幕仍未碎掉的概率大于0.2就可以购买，否则放弃．请你用所学的概率知识帮玛丽做一下决策．
<span class="fake-tag">答案</span>玛丽应该放弃购买
<span class="fake-tag">详解</span>设$A_{i} =$ “第*i*次掉落后，手机屏幕没有碎掉”，$i = 1$，2，
则由已知可得$P \left( A_{1} \right) = 0 . 5$，$P \left( A_{2} | A_{1}  \right) = 0 . 3$，
故$P \left( A_{2} A_{1} \right) = P \left( A_{1} \right) P \left( A_{2} | A_{1}  \right) = 0 . 5 \times 0 . 3 = 0 . 1 5$．
即这款手机从1m高的地方掉落两次后，屏幕仍未碎掉的概率为0.15，
因为$0 . 1 5 < 0 . 2$，故玛丽应该放弃购买．
