### 题型2：判断三角形形状
![](高中习题/高考/一本通/Attachments/d1b78d32176d26fb3e100537f7ced15da84e874911b2501c524ea4f5902ddfbe.jpg)
判断三角形的形状，主要有如下两条途径：
(1) 利用正、余弦定理把已知条件转化为边边关系, 通过因式分解、配方等方法得出边的相应关系,从而判断出三角形的形状.
$\triangle ABC$  为直角三角形  $\Leftrightarrow a^{2} = b^{2} + c^{2}$  或  $b^{2} = a^{2} + c^{2}$  或  $c^2 = a^2 +b^2$
$\triangle ABC$  为锐角三角形  $\Leftrightarrow a^{2} + b^{2} > c^{2}$  且  $b^{2} + c^{2} > a^{2}$  且  $c^2 +a^2 >b^2$
$\triangle \triangle ABC$  为钝角三角形  $\Leftrightarrow a^2 + b^2 < c^2$  或  $b^2 + c^2 < a^2$  或  $c^2 + a^2 < b^2$ .
(2) 利用正、余弦定理把已知条件转化为内角的三角函数间的关系, 通过三角恒等变换, 得出内角的关系, 从而判断出三角形的形状, 此时要注意在  $\triangle ABC$  中,  $\angle A + \angle B + \angle C = 180^{\circ}$
在使用以上两种解法的等式变形中，一般两边不要约去公因式，应移项提取公因式，以免漏解.
若  $\cos A = 0$  ，则  $A = 90^{\circ},\triangle ABC$  为直角三角形；
若  $\cos A < 0$  ，则  $\triangle ABC$  为钝角三角形；
若  $\cos A > 0$  且  $\cos B > 0$  且  $\cos C > 0$  ，则  $\triangle ABC$  为锐角三角形.
##### 题型03 判断三角形的形状
##### 【典例1】（2023下·河北保定·高一保定一中校考阶段练习）在$\bigtriangleup A B C$中，其内角的对边分别为$a , b , c$，若$a \text{cos} B + b \text{cos} A = a$，则$\bigtriangleup A B C$的形状是（ ）
$\quad$A．等腰三角形 
$\quad$B．直角三角形
$\quad$C．等腰直角三角形 
$\quad$D．等腰或直角三角形
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>因为$a \text{cos} B + b \text{cos} A = a$，所以由余弦定理得$a \times \frac{a^{2} + c^{2} - b^{2}}{2 a c} + b \times \frac{b^{2} + c^{2} - a^{2}}{2 b c} = a$，
所以$2 c^{2} = 2 a c$，所以$c = a$，所以$\bigtriangleup A B C$为等腰三角形.
故选：A.
##### 【典例2】（2023下·海南海口·高一海南中学校考期中）在$\bigtriangleup A B C$中，$A$，$B$，$C$所对的边分别为$a$，$b$，$c$，若$a = 7$，$b = 1 0$，$c = 6$，则$\bigtriangleup A B C$是（ ）
$\quad$A．锐角三角形 
$\quad$B．钝角三角形
$\quad$C．直角三角形 
$\quad$D．以上答案都不对
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由$\cos B = \frac{a^{2} + c^{2} - b^{2}}{2 a c} = \frac{4 9 + 3 6 - 1 0 0}{2 \times 7 \times 6} = - \frac{5}{28} < 0$，而$0 < B < \pi$，
所以$\frac{\pi}{2} < B < \pi$，即为钝角，故$\bigtriangleup A B C$为钝角三角形.
故选：B
##### 【典例3】（2023上·全国·高三专题练习）在$\bigtriangleup A B C$中，角$A$，$B$，$C$所对的边分别为$a$，$b$，$c$，$b = a + 1$，$c = a + 2$．是否存在正整数$a$，使得$\bigtriangleup A B C$为钝角三角形？若存在，求$a$；若不存在，说明理由．
<span class="fake-tag">答案</span>存在正整数$a = 2$，使得$\bigtriangleup A B C$为钝角三角形
<span class="fake-tag">详解</span>由题意，知$c > b > a$，要使$\bigtriangleup A B C$为钝角三角形，
需$\cos C = \frac{a^{2} + b^{2} - c^{2}}{2 a b} = \frac{a^{2} + ( a + 1 )^{2} - ( a + 2 )^{2}}{2 \times a \times ( a + 1 )} = \frac{a - 3}{2 a} < 0$，得$0 < a < 3$．
因为$a$为正整数，所以$a = 1$或$a = 2$．
当$a = 1$时，$b = 2$，$c = 3$，此时不能构成三角形；
当$a = 2$时，$b = 3$，$c = 4$，满足题意．
综上，存在正整数$a = 2$，使得$\bigtriangleup A B C$为钝角三角形．
##### 【变式1】（2023下·江苏宿迁·高一统考期末）在$\bigtriangleup A B C$中，角$A   ， B   ， C$所对的边分别为$a   ， b   ， c$．若$a + c \cos A = b + c \cos B$，则$\bigtriangleup A B C$为（ ）
$\quad$A．等腰三角形 
$\quad$B．直角三角形
$\quad$C．等腰直角三角形 
$\quad$D．等腰或直角三角形
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>由余弦定理可得：$a + c \times \frac{b^{2} + c^{2} - a^{2}}{2 b c} = b + c \times \frac{a^{2} + c^{2} - b^{2}}{2 a c}$，
即$2 a^{2} b + a b^{2} + a c^{2} - a^{3} = 2 a b^{2} + a^{2} b + c^{2} b - b^{3}$，
整理得：$( a - b ) ( a^{2} + b^{2} - c^{2} ) = 0$，
得$a = b$或$a^{2} + b^{2} = c^{2}$，所以$\bigtriangleup A B C$为等腰或直角三角形.
故选：D
##### 【变式2】（2023下·黑龙江哈尔滨·高一哈尔滨市第三十二中学校校考期中）在$\bigtriangleup A B C$中，若$C = 6 0^{^\circ}$，$c^{2} = a b$，则$\bigtriangleup A B C$的形状是（ ）
$\quad$A．等腰直角三角形 
$\quad$B．直角三角形
$\quad$C．等腰三角形 
$\quad$D．等边三角形
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>由余弦定理知$\cos C = \frac{b^{2} + a^{2} - c^{2}}{2 a b}$，
因为$c^{2} = a b$，$C = 6 0^{^\circ}$，
所以$\cos 6 0^{^\circ} = \frac{b^{2} + a^{2} - a b}{2 a b} = \frac{1}{2}$，
所以$( a - b )^{2} = 0$，所以$b = a$，
因此，所以$B = A = C = 6 0^{^\circ}$，
即$\bigtriangleup A B C$是等边三角形，
故选：D.
##### 【变式3】（2023下·上海青浦·高一上海市青浦高级中学校考期中）在△*ABC*中，角*A*，*B*，*C*所对的边为*a*，*b*，*c*
(1)若$\sin 2 B = \sqrt{3} \sin B$，求∠*B*；
(2)若$a = 2 b \cos C$，试判断△*ABC*的形状．
<span class="fake-tag">答案</span>(1)$B = \frac{\pi}{6}$
(2)△*ABC*是等腰三角形
<span class="fake-tag">详解</span>（1）由$\sin 2 B = 2 \sin B \cos B = \sqrt{3} \sin B$，而$\sin B > 0$，故$\cos B = \frac{\sqrt{3}}{2}$，
又$B \in ( 0 , \pi )$，故$B = \frac{\pi}{6}$.
（2）$a = 2 b \cos C = 2 b \times \frac{a^{2} + b^{2} - c^{2}}{2 a b} = \frac{a^{2} + b^{2} - c^{2}}{a}$，故$b^{2} - c^{2} = 0$，即$b = c$，
所以△*ABC*是等腰三角形.
