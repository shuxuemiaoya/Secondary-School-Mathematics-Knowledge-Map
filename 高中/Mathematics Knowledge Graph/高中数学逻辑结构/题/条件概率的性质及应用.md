##### 题型03条件概率的性质及应用
##### 【典例1】（2024·湖北武汉·武汉市第六中学校联考二模）设$A$，$B$为任意两个事件，且$A \subseteq B$，$P ( B ) > 0$，则下列选项必成立的是（ ）
$\quad$A．$P ( A ) > P ( A | B )$ 
$\quad$B．$P ( A ) \geq P ( A | B )$
$\quad$C．$P ( A ) < P ( A | B )$ 
$\quad$D．$P ( A ) \leq P ( A | B )$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>由$A \subseteq B$，则$A \cap B = A$，故$P ( A ) = P ( A B ) \leq P ( B )$，
而$P ( A | B ) = \frac{P ( A B )}{P ( B )} = \frac{P ( A )}{P ( B )}$，则$P ( A | B ) P ( B ) = P ( A )$，又$1 \geq P ( B ) > 0$，
所以$P ( A ) \leq P ( A | B )$.
故选：D
##### 【典例2】（多选）（2024·全国·高三专题练习）设$A$，$B$是一个随机试验中的两个事件，且$P ( A ) = \frac{1}{2}$，$P ( B ) = \frac{11}{24}$，$P ( \overline{A} B + A \overline{B} ) = \frac{7}{24}$，则下列结论中正确的是（ ）
$\quad$A．$P ( \overline{A} B ) = \frac{1}{8}$ 
$\quad$B．$P ( \overline{A} + B ) = \frac{5}{6}$
$\quad$C．$P ( A | B ) = \frac{9}{11}$ 
$\quad$D．$P ( \overline{A} | B ) = P ( \overline{B} | A )$
<span class="fake-tag">答案</span>AB
<span class="fake-tag">详解</span>因为$P ( A ) = \frac{1}{2}$，$P ( B ) = \frac{11}{24}$，所以$P ( \overline{A} ) = \frac{1}{2}$，$P ( \overline{B} ) = \frac{13}{24}$.
因为$\overline{A} B$与$A \overline{B}$为互斥事件，所以$P ( \overline{A} B \cdot A \overline{B} ) = 0$，
所以$P ( \overline{A} B + A \overline{B} ) = P ( \overline{A} B ) + P ( A \overline{B} ) - P ( \overline{A} B \cdot A \overline{B} ) = P ( \overline{A} B ) + P ( A \overline{B} )$
$= P ( B ) - P ( A B ) + P ( A ) - P ( A B ) = \frac{1}{2} + \frac{11}{24} - 2 P ( A B ) = \frac{7}{24}$，
所以$P ( A B ) = \frac{1}{3}$，
故$P ( \overline{A} B ) = P ( B ) - P ( A B ) = \frac{11}{24} - \frac{1}{3} = \frac{1}{8}$，故A正确；
$P ( \overline{A} + B ) = P ( \overline{A} ) + P ( B ) - P ( \overline{A} B ) = P ( \overline{A} ) + P ( B ) - \lbrack P ( B ) - P ( A B ) \rbrack = P ( \overline{A} ) + P ( A B ) = \frac{1}{2} + \frac{1}{3} = \frac{5}{6}$，故B正确；
$P ( A | B ) = \frac{P ( A B )}{P ( B )} = \frac{\frac{1}{3}}{\frac{11}{24}} = \frac{8}{11}$，故C错误；
$P ( \overline{A} | B ) = \frac{P ( \overline{A} B )}{P ( B )} = \frac{\frac{1}{8}}{\frac{11}{24}} = \frac{3}{11}$，$P ( \overline{B} | A ) = \frac{P ( A \overline{B} )}{P ( A )} = \frac{P ( A ) - P ( A B )}{P ( A )} = \frac{\frac{1}{2} - \frac{1}{3}}{\frac{1}{2}} = \frac{1}{3}$，
所以$P ( \overline{A} | B ) \neq P ( \overline{B} | A )$，故D错误.
故选:AB.
##### 【典例3】（多选）（2024上·辽宁沈阳·高二沈阳市第八十三中学校联考期末）为庆祝建党100周年，讴歌中华民族实现伟大复兴的奋斗历程，增进全体党员干部职工对党史知识的了解，某单位组织开展党史知识竞赛活动，以支部为单位参加比赛，某支部在5道党史题中(有3道选择题和$2$道填空题)，不放回地依次随机抽取$2$道题作答，设事件*A*为“第1次抽到选择题”，事件*B*为“第$2$次抽到选择题”，则下列结论中正确的是（ ）
$\quad$A．$P ( A ) = \frac{3}{5}$ 
$\quad$B．$P ( A B ) = \frac{3}{10}$
$\quad$C．$P \left( B | A  \right) = \frac{1}{2}$ 
$\quad$D．$P \left( B | \bar{A}  \right) = \frac{1}{2}$
<span class="fake-tag">答案</span>ABC
<span class="fake-tag">详解</span>$P ( A ) = \frac{C_{3}^{1}}{C_{5}^{1}} = \frac{3}{5}$,故A正确；
$P ( A B ) = \frac{C_{3}^{1} C_{2}^{1}}{C_{5}^{1} C_{4}^{1}} = \frac{3}{10}$，故B正确；
$P \left( B | A  \right) = \frac{P ( A B )}{P ( A )} = \frac{\frac{3}{10}}{\frac{3}{5}} = \frac{1}{2}$，故C正确；
$P \left( \bar{A} \right) = \frac{C_{2}^{1}}{C_{5}^{1}} = \frac{2}{5}$，$P \left( \bar{A} B \right) = \frac{C_{2}^{1} C_{3}^{1}}{C_{5}^{1} C_{4}^{1}} = \frac{3}{10}$，$P \left( B | \bar{A}  \right) = \frac{P \left( \bar{A} B \right)}{P \left( \bar{A} \right)} = \frac{\frac{3}{10}}{\frac{2}{5}} = \frac{3}{4}$，故D错误.
故选: ABC
##### 【变式1】（2024·全国·高二假期作业）下列说法正确的是（ ）
$\quad$A．$P \left( B | A  \right) < P ( A B )$ 
$\quad$B．$P \left( B | A  \right) = \frac{P ( B )}{P ( A )}$是可能的
$\quad$C．$0 < P \left( B | A  \right) < 1$ 
$\quad$D．$P \left( A | A  \right) = 0$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由$P ( B | A ) = \frac{P ( A B )}{P ( A )}$，当$0 < P ( A ) < 1$，则$P(B∣A)>P(AB)$，A错误；
当*A*或*B*为不可能事件时，，C错误；
B：要使$P \left( B | A  \right) = \frac{P ( B )}{P ( A )}$，即$P ( A B ) = P ( B )$，当$B$恰好为*A*的子事件成立，正确；
D：由$P ( A | A ) = \frac{P ( A )}{P ( A )} = 1$，故错误.
故选：B
##### 【变式2】（多选）（2024·全国·高三专题练习）若$\overline{A}$、$\overline{B}$分别为随机事件$A$、$B$的对立事件，$P ( A ) > 0$，$P ( B ) > 0$，则下列结论正确的是（ ）
$\quad$A．$P \left( B | A  \right) + P \left( B | \bar{A}  \right) = 1$ 
$\quad$B．$P \left( \bar{A} | B  \right) P ( B ) = P \left( B | \bar{A}  \right) P \left( \bar{A} \right)$
$\quad$C．$P \left( A | B  \right) + P \left( \bar{A} | B  \right) = P ( B )$ 
$\quad$D．若$P \left( A | B  \right) = P ( A )$，则$P \left( B | A  \right) = P ( B )$
<span class="fake-tag">答案</span>BD
<span class="fake-tag">详解</span>对于A选项，因为$P \left( B | A  \right) + P \left( \bar{B} | A  \right) = \frac{P ( A B )}{P ( A )} + \frac{P \left( A \bar{B} \right)}{P ( A )} = \frac{P ( A B ) + P \left( A \bar{B} \right)}{P ( A )} = \frac{P ( A )}{P ( A )} = 1$，
但$P \left( B | \bar{A}  \right)$与$P \left( \bar{B} | A  \right)$不一定相等，故$P \left( B | A  \right) + P \left( B | \bar{A}  \right)$不一定等于$1$，A错；
对于B选项，因为$P \left( \bar{A} | B  \right) P ( B ) = P \left( \bar{A} B \right)$，$P \left( B | \bar{A}  \right) P \left( \bar{A} \right) = P \left( \bar{A} B \right)$，
所以，$P \left( \bar{A} | B  \right) P ( B ) = P \left( B | \bar{A}  \right) P \left( \bar{A} \right)$，B对；
对于C选项，$P \left( A | B  \right) + P \left( \bar{A} | B  \right) = \frac{P ( A B )}{P ( B )} + \frac{P \left( \bar{A} B \right)}{P ( B )} = \frac{P ( B )}{P ( B )} = 1$，C错；
对于D选项，因为$P \left( A | B  \right) = \frac{P ( A B )}{P ( B )} = P ( A )$，所以，$P ( A B ) = P ( A ) P ( B )$，
所以，事件$A$、$B$独立，故$P \left( B | A  \right) = \frac{P ( A B )}{P ( A )} = P ( B )$，D对.
故选：BD.
##### 【变式3】（2024·全国·高三专题练习）设某种灯管使用了500h还能继续使用的概率是0.94，使用到700h后还能继续使用的概率是0.87，问已经使用了500h的灯管还能继续使用到700h的概率是多少？
<span class="fake-tag">答案</span>$\frac{87}{94}$
<span class="fake-tag">详解</span>解：设*A*＝“能使用到500h”，*B*＝“能使用到700h”，则$P ( A ) = 0 . 9 4$，$P ( B ) = 0 . 8 7$．而所求的概率为$P ( B | A )$，由于$B \subseteq A$，故$P ( B | A ) = \frac{P ( A \cap B )}{P ( A )} = \frac{P ( B )}{P ( A )} = \frac{0 . 8 7}{0 . 9 4} = \frac{87}{94}$．
故答案为：$\frac{87}{94}$.
