因为$\overrightarrow{C B} = \lambda \overrightarrow{C A} + \mu \overrightarrow{C O}$，
所以$\lambda + \mu = \frac{7 t}{3} + \frac{7 ( 1 - t )}{3} = \frac{7}{3}$，
故选：D

##### 【变式1】（2023下·浙江宁波·高二校联考期末）在$\bigtriangleup A B C$中，点*O*满足$\overrightarrow{C O} = 2 \overrightarrow{O B}$，过点*O*的直线分别交射线*AB*，*AC*于点*M*，*N*，且$\overrightarrow{A M} = m \overrightarrow{A B}$，$\overrightarrow{A N} = n \overrightarrow{A C}$，则$m + 2 n$的最小值为（ ）
$\quad$A．$\frac{8}{3}$ 
$\quad$B．$\frac{10}{3}$ 
$\quad$C．3 
$\quad$D．4
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题可知，$m > 0 , n > 0$，
因为$\overrightarrow{A M} = m \overrightarrow{A B}$，$\overrightarrow{A N} = n \overrightarrow{A C}$，所以$\overrightarrow{A B} = \frac{1}{m} \overrightarrow{A M}$，$\overrightarrow{A C} = \frac{1}{n} \overrightarrow{A N}$，
又$\overrightarrow{C O} = 2 \overrightarrow{O B}$，所以$\overrightarrow{A O} - \overrightarrow{A C} = 2 \overrightarrow{A B} - 2 \overrightarrow{A O}$，
所以$\overrightarrow{A O} = \frac{2}{3} \overrightarrow{A B} + \frac{1}{3} \overrightarrow{A C} = \frac{2}{3 m} \overrightarrow{A M} + \frac{1}{3 n} \overrightarrow{A N}$，
因为$M , O , N$三点共线，所以$\frac{2}{3 m} + \frac{1}{3 n} = 1$，
所以$m + 2 n = ( m + 2 n ) ( \frac{2}{3 m} + \frac{1}{3 n} ) = \frac{4}{3} + \frac{m}{3 n} + \frac{4 n}{3 m} \geq \frac{4}{3} + 2 \sqrt{\frac{4}{9}} = \frac{8}{3}$，
当且仅当$\begin{cases}\frac{m}{3 n} = \frac{4 n}{3 m} \\ \frac{2}{3 m} + \frac{1}{3 n} = 1\end{cases}$，即$m = \frac{4}{3} , n = \frac{2}{3}$时，等号成立.
所以$m + 2 n$的最小值为$\frac{8}{3}$.
故选：A
