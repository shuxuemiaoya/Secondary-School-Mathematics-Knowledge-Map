##### 题型02 函数与导函数图象间的关系
##### 【典例1】（2023·高二课时练习）已知函数$f ( x )$的导函数$f^{'} ( x )$的图象如图，则下列结论正确的是（ ）
![@@@f36138d9-fc1d-4d97-948a-857badcebbb2](MathLogic-Weave/高中数学逻辑结构/题/Attachments/eeb3b95f441c23f8c23d209d0b48cbfb.png)
$\quad$A．函数$f ( x )$在区间$( - 2 , 1 )$上单调递增
$\quad$B．函数$f ( x )$在区间$( 1 , 3 )$上单调递减
$\quad$C．函数$f ( x )$在区间$( 4 , 5 )$上单调递增
$\quad$D．函数$f ( x )$在区间$( - 3 , - 2 )$上单调递增
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>由导数的图象可知，当$x \in ( - 1 , 2 ) \cup ( 4 , 5 )$时，$f^{'} ( x ) > 0$，所以$f ( x )$在区间$( - 1 , 2 )$，$( 4 , 5 )$上单调递增，故C正确；
当$2 < x < 4$时，$f^{'} ( x ) < 0$，所以$f ( x )$在区间$( 2 , 4 )$上单调递减，
当$- 3 < x < - 1$时，$f^{'} ( x ) < 0$，则$f ( x )$在区间$( - 3 , - 1 )$上单调递减，故A、B、D错误；
故选：C．

##### 【变式1】（2023下·四川成都·高二四川省成都市新都一中校联考期中）已知函数$y = f ( x ) ( x \in R )$的导函数$f^{'} ( x )$ 的图像如图所示，则函数（ ）
![@@@24341ab2-dd26-437a-a365-3a80ea96fb36](MathLogic-Weave/高中数学逻辑结构/题/Attachments/dd57e8ecbdf5e86806c7c0e015be4e2f.png)
$\quad$A．在$( - \infty , - 2 )$上单调递增 
$\quad$B．在$( 1 , + \infty )$上单调递减
$\quad$C．在上单调递增 
$\quad$D．在$( 3 , + \infty )$上单调递减
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>由图可知：当$x < - 2$ 时，$f^{'} ( x ) < 0 , f ( x )$ 单调递减，当$- 2 < x < 3$ 时，$f^{'} ( x ) \geq 0 , f ( x )$ 单调递增，当$x > 3$ 时，$f^{'} ( x ) < 0 , f ( x )$ 单调递增；
故选：D.
