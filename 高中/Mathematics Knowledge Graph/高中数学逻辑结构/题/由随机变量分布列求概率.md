##### 题型04由随机变量分布列求概率
##### 【典例1】（2024·全国·高二假期作业）设离散型随机变量*X*的概率分布为
| *X* | 0    | 1    | 2    | 3    | 4   |
|-----|------|------|------|------|-----|
| *P* | 0.15 | 0.15 | 0.15 | 0.25 | *m* |
若随机变量$Y = X - 2$，则$P ( Y = 2 )$等于（ ）
$\quad$A．0.3 
$\quad$B．0.4
$\quad$C．0.6 
$\quad$D．0.7
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由0.15＋0.15＋0.15＋0.25＋*m*＝1，得*m*＝0.3，
所以$P ( Y = 2 ) = P ( X = 4 ) = 0 . 3$.
故选：A.
##### 【典例2】（2024·全国·高二假期作业）一袋中装有4个白球和2个红球，现从袋中往外取球，每次任取一个不放回，取出后记下颜色，若为红色停止，若为白色则继续抽取，停止时从袋中抽取的白球的个数为随机变量$X$，则$P ( X \leq 2 ) =$（ ）
$\quad$A．$\frac{4}{5}$
$\quad$B．$\frac{2}{5}$
$\quad$C．$\frac{1}{5}$
$\quad$D．$\frac{3}{5}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>令$X = k$表示前*k*个球为白球，第$k + 1$个球为红球，
此时$P ( X = 0 ) = \frac{2}{6} = \frac{1}{3} , P ( X = 1 ) = \frac{4}{6} \times \frac{2}{5} = \frac{4}{15} , P ( X = 2 ) = \frac{4}{6} \times \frac{3}{5} \times \frac{2}{4} = \frac{1}{5}$，
则$P ( X \leq 2 ) = P ( X = 0 ) + P ( X = 1 ) + P ( X = 2 ) = \frac{1}{3} + \frac{4}{15} + \frac{1}{5} = \frac{4}{5}$．
故选：A．

##### 【变式1】（2024·全国·高二假期作业）设随机变量*X*的分布列$P ( X = i ) = \frac{k}{2^{i}} ( i = 1 , 2 , 3 )$，则$P ( X \geq 2 )$的值为（ ）
$\quad$A．1 
$\quad$B．$\frac{3}{7}$
$\quad$C． 
$\quad$D．$\frac{5}{7}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>因为随机变量*X*的分布列$P ( X = i ) = \frac{k}{2^{i}} ( i = 1 , 2 , 3 )$，
所以$\frac{k}{2^{1}} + \frac{k}{2^{2}} + \frac{k}{2^{3}} = 1$，解得：$k = \frac{8}{7}$，
$P ( X \geq 2 ) = P ( X = 2 ) + P ( X = 3 ) = \frac{\frac{8}{7}}{4} + \frac{\frac{8}{7}}{8} = \frac{2}{7} + \frac{1}{7} = \frac{3}{7}$.
故选：B.
##### 【变式2】（2024·全国·高二假期作业）已知离散型随机变量*X*的分布列如下表：

$\quad$C．$\frac{5}{6}$
$\quad$D．$\frac{3}{4}$
