$\quad$C．$\left\lbrack \sqrt{3} , 3 \sqrt{3} \right\rbrack$ 
$\quad$D．
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>先求出$2 x + \frac{\pi}{6}$的范围，再由正切函数的性质求出$\tan ( 2 x + \frac{\pi}{6} )$范围，再乘以3即可.
<span class="fake-tag">详解</span>$\because x \in \left\lbrack 0 , \frac{\pi}{12} \right\rbrack , \therefore 2 x + \frac{\pi}{6} \in \left\lbrack \frac{\pi}{6} , \frac{\pi}{3} \right\rbrack , \therefore \tan \left( 2 x + \frac{\pi}{6} \right) \in \left\lbrack \frac{\sqrt{3}}{3} , \sqrt{3} \right\rbrack , \therefore 3 \tan \left( 2 x + \frac{\pi}{6} \right) \in \left\lbrack \sqrt{3} , 3 \sqrt{3} \right\rbrack$

##### 【典例2】（24-25高一上·上海·随堂练习）已知函数$y = m \tan x + n$在$\left\lbrack k \pi - \frac{\pi}{4} , k \pi + \frac{\pi}{4} \right\rbrack$，上的最小值、最大值分别为1和7，求*m*和*n*的值.
<span class="fake-tag">答案</span>$\begin{cases}m = 3 \\ n = 4\end{cases}$或$\begin{cases}m = - 3 \\ n = 4\end{cases}$.
<span class="fake-tag">分析</span>根据$m$的正负分类讨论，利用函数的单调性分别表达出最值关系式，解方程组可得.
<span class="fake-tag">详解</span>正切函数$y = \tan x$在$\left\lbrack k \pi - \frac{\pi}{4} , k \pi + \frac{\pi}{4} \right\rbrack$，单调递增，
且$\tan {} \left( k \pi - \frac{\pi}{4} \right) = \tan \left( - \frac{\pi}{4} \right) = - 1$， $\tan {} \left( k \pi + \frac{\pi}{4} \right) = \tan \frac{\pi}{4} = 1$，
由题意函数最小值、最大值分别为1和7，可知$m \neq 0$，
①当$m > 0$时，函数$y = m \tan x + n$在$\left\lbrack k \pi - \frac{\pi}{4} , k \pi + \frac{\pi}{4} \right\rbrack$，单调递增，
$\therefore \begin{cases}m + n = 7 \\ - m + n = 1\end{cases}$，解得$\begin{cases}m = 3 \\ n = 4\end{cases}$；
②当$m < 0$时，函数$y = m \tan x + n$在$\left\lbrack k \pi - \frac{\pi}{4} , k \pi + \frac{\pi}{4} \right\rbrack$，单调递减，
$\therefore \begin{cases}- m + n = 7 \\ m + n = 1\end{cases}$即$\begin{cases}m = - 3 \\ n = 4\end{cases}$.
综上所述，$\begin{cases}m = 3 \\ n = 4\end{cases}$或$\begin{cases}m = - 3 \\ n = 4\end{cases}$.
