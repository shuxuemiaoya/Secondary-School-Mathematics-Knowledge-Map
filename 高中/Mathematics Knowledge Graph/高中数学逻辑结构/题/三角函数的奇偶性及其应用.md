##### 题型02三角函数的奇偶性及其应用
##### 【典例1】（23-24高一·上海·课堂例题）判断下列函数的奇偶性，并说明理由：
(1)$y = \sin 3 x$；
(2)$y = \left| \sin x \right|$；
(3)$y = x \sin x$；
(4)$y = 2 \sin \left( x + \frac{\pi}{6} \right)$.
<span class="fake-tag">答案</span>(1)奇函数；理由见解析
(2)偶函数；理由见解析
(3)偶函数；理由见解析
(4)非奇非偶函数；理由见解析
<span class="fake-tag">分析</span>先求出函数的定义域，求出$f ( - x )$，然后利用函数奇偶性的定义进行判断即可.
<span class="fake-tag">详解</span>（1）函数的定义域为$R$，
$f ( - x ) = \sin 3 ( - x ) = - \sin 3 x = - f ( x )$，
则$y = f ( x ) = \sin 3 x$为奇函数.
（2）函数的定义域为$R$，
$f ( - x ) = \left| \sin ( - x ) \right| = \left| - \sin x \right| = \left| \sin x \right| = f ( x )$，
则$y = f ( x ) = \left| \sin x \right|$为偶函数.

（4）函数的定义域为$R$，
$f ( 0 ) = 2 \sin \frac{\pi}{6} = 1 \neq 0$，所以$y = 2 \sin \left( x + \frac{\pi}{6} \right)$不是奇函数
$f ( - \frac{\pi}{6} ) = 2 \sin 0 = 0$，$f ( \frac{\pi}{6} ) = 2 \sin \frac{\pi}{3} = \sqrt{3}$，则$f ( - \frac{\pi}{6} ) \neq f ( \frac{\pi}{6} )$，则$y = 2 \sin \left( x + \frac{\pi}{6} \right)$不是偶函数，
所以$y = f ( x ) = 2 \sin \left( x + \frac{\pi}{6} \right)$非奇非偶函数.

##### 【变式1】（2024·贵州黔南·二模）若函数$f ( x ) = \text{cos} \left( x - \frac{\pi}{3} + \varphi \right)$为偶函数，则的值可以是（ ）
$\quad$A． 
$\quad$B．$\frac{4 \pi}{3}$ 
$\quad$C．$\pi$ 
$\quad$D．$\frac{\pi}{2}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>由题意可知：$x = 0$为函数$f ( x )$的对称轴，结合余弦函数对称性分析求解.
<span class="fake-tag">详解</span>由题意可知：$x = 0$为函数$f ( x )$的对称轴，
则$- \frac{\pi}{3} + \varphi = k \text{π,} k \in \mathbf{Z}$，则$\varphi = k \pi + \frac{\pi}{3} , k \in \mathbf{Z}$，
对于选项A：令$\varphi = k \pi + \frac{\pi}{3} = \frac{5 \pi}{6}$，解得$k = \frac{1}{2} \notin \mathbf{Z}$，不合题意；
对于选项B：令$\varphi = k \pi + \frac{\pi}{3} = \frac{4 \pi}{3}$，解得$k = 1 \in \mathbf{Z}$，符合题意；
对于选项C：令$\varphi = k \pi + \frac{\pi}{3} = \pi$，解得$k = \frac{2}{3} \notin \mathbf{Z}$，不合题意；
对于选项D：令$\varphi = k \pi + \frac{\pi}{3} = \frac{\pi}{2}$，解得$k = \frac{1}{6} \notin \mathbf{Z}$，不合题意；
故选：B.
##### 【变式2】（多选）（24-25高三上·江苏南通·阶段练习）下列$x \in \mathbf{R}$的函数是偶函数的是（ ）
$\quad$A．$y = \sin \left( \sin x \right)$ 
$\quad$B．$y = \cos \left( \sin x \right)$ 
$\quad$C．$y = \cos \left( \cos x \right)$ 
$\quad$D．$y = \sin \left( \cos x \right)$
<span class="fake-tag">答案</span>BCD
<span class="fake-tag">分析</span>根据题意结合正、余弦函数的奇偶性逐项分析判断.
<span class="fake-tag">详解</span>因为函数的定义域为，
对于选项A：因为$\sin \left\lbrack \sin \left( - \frac{\pi}{2} \right) \right\rbrack = \sin ( - 1 ) = - \sin 1 , \sin \left( \sin \frac{\pi}{2} \right) = \sin 1$，
可知$y = \sin \left( \sin x \right)$不是偶函数，故A错误；
对于选项B：因为$\cos \left\lbrack \sin ( - x ) \right\rbrack = \cos \left( - \sin x \right) = \cos \left( \sin x \right)$，
所以$y = \cos \left( \sin x \right)$是偶函数，故B正确；
对于选项C：因为$\cos \left\lbrack \cos ( - x ) \right\rbrack = \cos \left( \cos x \right)$，
所以$y = \cos \left( \cos x \right)$是偶函数，故C正确；
对于选项D：因为$\sin \left\lbrack \cos ( - x ) \right\rbrack = \sin \left( \cos x \right)$，
所以$y = \sin \left( \cos x \right)$是偶函数，故D正确；
故选：BCD.
