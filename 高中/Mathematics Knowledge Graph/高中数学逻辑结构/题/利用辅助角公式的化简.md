### 基础点2：利用辅助角公式的化简
##### 【5】将下列函数化简成  $y = A \sin (\omega x + \varphi)$  的形式，其中  $\omega > 0$ ，并写出  $\tan \varphi$  的值.
(1)  $y = \frac{\sqrt{3}}{2} \sin x + \frac{1}{2} \cos x$ ;  
(2)  $y = \sqrt{3} \sin x + \cos x$ ;  
(3)  $y = \sin x + \cos x$ ;  
(4)  $y = \sqrt{2} \cos x - \sqrt{6} \sin x$ ;
(5)  $y = \frac{\sqrt{2}}{6} \sin \frac{x}{2} + \frac{\sqrt{6}}{6} \cos \frac{x}{2}$ ;  
(6)  $y = 12\sin x + 5\cos x$ ;  
(7)  $y = \sin \left(x + \frac{\pi}{3}\right) - \sin x$ ;  
(8)  $y = \sin x + \cos \left(x - \frac{\pi}{6}\right).$
