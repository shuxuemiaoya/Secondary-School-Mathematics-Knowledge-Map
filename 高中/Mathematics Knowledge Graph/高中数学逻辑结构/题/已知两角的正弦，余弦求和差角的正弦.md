##### 【典例1】（24-25高一上·全国·课后作业）已知$\text{cos} \alpha = \frac{3}{5}$，$\text{cos} ( \alpha - \beta ) = \frac{12}{13}$且，则$\text{sin} \beta =$ .

<span class="fake-tag">分析</span>根据题干条件，结合同角三角函数的关系可得$\text{sin} \alpha = \frac{4}{5}$，$\text{sin} ( \alpha - \beta ) = - \frac{5}{13}$的值，根据两角和的正弦公式$\text{sin} \beta = \text{sin} \left\lbrack \alpha - ( \alpha - \beta ) \right\rbrack = \text{sin} \alpha \text{cos} ( \alpha - \beta ) - \text{cos} \alpha \text{sin} ( \alpha - \beta )$，化简整理即可得答案.
<span class="fake-tag">详解</span>∵$\text{cos} \alpha = \frac{3}{5}$，$0 < \alpha < \frac{\pi}{2}$，∴$\text{sin} \alpha = \frac{4}{5}$.
又∵，∴$- \frac{\pi}{2} < \alpha - \beta < 0$，
∴$\text{sin} ( \alpha - \beta ) = - \frac{5}{13}$，
∴$\text{sin} \beta = \text{sin} \left\lbrack \alpha - ( \alpha - \beta ) \right\rbrack = \text{sin} \alpha \text{cos} ( \alpha - \beta ) - \text{cos} \alpha \text{sin} ( \alpha - \beta )$
$= \frac{4}{5} \times \frac{12}{13} - \frac{3}{5} \times \left( - \frac{5}{13} \right) = \frac{63}{65}$.
故答案为：$\frac{63}{65}$.

又因为$\text{cos} \beta = - \frac{2}{3}$，$\beta \in \left( \frac{\pi}{2} , \pi \right)$，
所以$\text{sin} \beta = \sqrt{1 - \text{co} \text{s}^{2} \beta} = \sqrt{1 - \left( - \frac{2}{3} \right)^{2}} = \frac{\sqrt{5}}{3}$，
所以$\text{sin} ( \alpha + \beta ) = \text{sin} \alpha \text{cos} \beta + \text{cos} \alpha \text{sin} \beta$

= - \frac{2}{9} - \frac{2 \sqrt{10}}{9}
$= - \frac{2 + 2 \sqrt{10}}{9}$，
$\text{sin} ( \alpha - \beta ) = \text{sin} \alpha \text{cos} \beta - \text{cos} \alpha \text{sin} \beta$
$= \frac{1}{3} \times \left( - \frac{2}{3} \right) - \left( - \frac{2 \sqrt{2}}{3} \right) \times \frac{\sqrt{5}}{3}$
$= \frac{2 \sqrt{10} - 2}{9}$.
