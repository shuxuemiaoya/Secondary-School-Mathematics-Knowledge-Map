### 3. 正弦定理的变形
(1)  $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R.$  （ $R$  为  $\triangle ABC$  外接圆半径）；  
（2）  $a:b:c = \sin A:\sin B:\sin C$  
（3）  $a = 2R\sin A,b = 2R\sin B,c = 2R\sin C(R$  为  $\triangle ABC$  的外接圆半径）；  
（4）  $\sin A = \frac{a}{2R},\sin B = \frac{b}{2R},\sin C = \frac{c}{2R}$  （  $R$  为△ABC的外接圆半径）；  
(5)  $\frac{a + b + c}{\sin A + \sin B + \sin C} = \frac{a + b}{\sin A + \sin B} = \frac{a + c}{\sin A + \sin C} = \frac{b + c}{\sin B + \sin C} = 2R$  （ $R$  为  $\triangle ABC$  的外接圆半径）.
