##### 【典例2】（2023下·四川自贡·高一统考期末）已知非零向量$\overrightarrow{a} , \overrightarrow{b}$满足$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = \left| \overrightarrow{a} - \overrightarrow{b} \right|$，则$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为 ．
<span class="fake-tag">答案</span>$\frac{\pi}{3}$/$60 {^\circ}$
<span class="fake-tag">详解</span>如图，设$\overrightarrow{a} = \overrightarrow{O A} , \overrightarrow{b} = \overrightarrow{O B} , \overrightarrow{a} - \overrightarrow{b} = \overrightarrow{B A}$，
因为$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = \left| \overrightarrow{a} - \overrightarrow{b} \right|$，即$\left| \overrightarrow{O A} \right| = \left| \overrightarrow{O B} \right| = \left| \overrightarrow{B A} \right|$，可知$\bigtriangleup O A B$为等边三角形，
所以$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$\angle A O B = \frac{\pi}{3}$.
故答案为：$\frac{\pi}{3}$.

##### 【变式2】（2023下·河南驻马店·高一校联考期中）在$\bigtriangleup A B C$中，$\left| \overrightarrow{A C} + \overrightarrow{C B} \right| = \left| \overrightarrow{A C} - \overrightarrow{A B} \right| = \left| \overrightarrow{A B} + \overrightarrow{B C} \right|$，则$\bigtriangleup A B C$是（ ）
$\quad$A．等边三角形 
$\quad$B．直角三角形 
$\quad$C．钝角三角形 
$\quad$D．等腰直角三角形
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>因为$\overrightarrow{A C} + \overrightarrow{C B} = \overrightarrow{A B}$，$\overrightarrow{A C} - \overrightarrow{A B} = \overrightarrow{B C}$，$\overrightarrow{A B} + \overrightarrow{B C} = \overrightarrow{A C}$，$\left| \overrightarrow{A C} + \overrightarrow{C B} \right| = \left| \overrightarrow{A C} - \overrightarrow{A B} \right| = \left| \overrightarrow{A B} + \overrightarrow{B C} \right|$，
所以$\left| \overrightarrow{A B} \right| = \left| \overrightarrow{B C} \right| = \left| \overrightarrow{A C} \right|$，
所以$\bigtriangleup A B C$是等边三角形．
