##### 题型07 利用相切关系求最小距离
##### 【典例1】（2024上·贵州黔东南·高三天柱民族中学校考阶段练习）已知点*P*在函数$f ( x ) = x e^{x} + 1$的图象上，点*Q*在函数$g ( x ) = \frac{\ln x}{x}$的图象上，则的最小值为 .
<span class="fake-tag">答案</span>$\sqrt{2}$
<span class="fake-tag">详解</span>![@@@8b69450e-79e8-4a04-8f87-0eb8bfa698cc](高中习题/课堂同步/随堂练习习题/media/9db3efd7181d996458b208f29692380c.png)
由函数$f ( x ) = x e^{x} + 1$，求导可得：$f^{'} ( x ) = ( 1 + x ) e^{x}$，则$f^{'} ( 0 ) = 1$，
在$A ( 0 , 1 )$处的切线方程为$y - 1 = 1 \times ( x - 0 )$，整理可得：$y = x + 1$；
由函数$g ( x ) = \frac{\ln x}{x}$，求导可得：$g^{'} ( x ) = \frac{1 - \ln x}{x^{2}}$，则$g^{'} ( 1 ) = 1$，
在$B ( 1 , 0 )$处的切线方程为$y - 0 = 1 \times ( x - 1 )$，整理可得$y = x - 1$；
由直线$A B$的斜率$k_{A B} = \frac{1 - 0}{0 - 1} = - 1$，易知：直线$A B$分别与两条切线垂直..
故答案为：$\sqrt{2}$.
##### 【典例2】（2023下·湖北·高二校联考阶段练习）若点$P$是曲线$y = x^{2} - \text{ln} x$上任意一点，点$Q$是直线$x - y - 3 = 0$上任意一点，则的最小距离为 .
<span class="fake-tag">答案</span>$\frac{3 \sqrt{2}}{2}$/$\frac{3}{2} \sqrt{2}$
<span class="fake-tag">详解</span>$\because y = x^{2} - \text{ln} x ( x > 0 ) , \therefore y^{'} = 2 x - \frac{1}{x}$
令$y^{'} = 1$，则$x = 1$，即曲线$y = x^{2} - \text{ln} x$在$( 1 , 1 )$处的切线方程为：$y - 1 = 1 \times ( x - 1 )$，
即$y = x$,
如下图所示，当$P ( 1 , 1 )$时的最小值为点$P$到直线$x - y - 3 = 0$的距离（$Q$为垂足）.
故${| P Q | \frac{| 1 - 1 - 3 |}{\sqrt{1^{2} + 1^{2}}} \frac{3 \sqrt{2}}{2}}_{\min}$.
故答案为：$\frac{3 \sqrt{2}}{2}$

##### 【变式1】（2023下·江西赣州·高二统考期中）设点*A*在直线$\sqrt{3} x - y + 1 = 0$上，点*B*在函数$f ( x ) = \ln x$的图象上，则$| A B |$的最小值为 .
<span class="fake-tag">答案</span>$1 + \frac{1}{4} \text{ln} 3$
<span class="fake-tag">详解</span>设函数$f ( x ) = \text{ln} x$与直线$\sqrt{3} x - y + 1 = 0$平行的切线为$l$，则$l$的斜率为，
由$f^{'} ( x ) = \frac{1}{x} = \sqrt{3}$，得$x = \frac{\sqrt{3}}{3}$，所以切点为$P \left( \frac{\sqrt{3}}{3} , - \frac{1}{2} \text{ln} 3 \right)$，
则点$P$到直线$l$的距离就是$| A B |$的最小值，即$\frac{\left| 1 + \frac{1}{2} \text{ln} 3 + 1 \right|}{2} = 1 + \frac{1}{4} \text{ln} 3$.
故答案为：$1 + \frac{1}{4} \text{ln} 3$.
