##### 题型04 正切函数单调性的应用
##### 【典例1】（24-25高一上·上海·课堂例题）比较$\tan \frac{6}{5} \pi$与$\tan \left( - \frac{1 3 \pi}{7} \right)$的大小.
<span class="fake-tag">答案</span>$\text{tan} \frac{6}{5} \pi > \text{tan} \left( - \frac{1 3 \pi}{7} \right)$.
<span class="fake-tag">分析</span>根据诱导公式结合正切函数的单调性即可得解.
<span class="fake-tag">详解</span>$\text{tan} \frac{6}{5} \pi = \text{tan} \left( \pi + \frac{\pi}{5} \right) = \text{tan} \frac{\pi}{5}$，
$\text{tan} \left( - \frac{13}{7} \pi \right) = - \text{tan} \frac{13}{7} \pi = - \text{tan} \left( 2 \pi - \frac{\pi}{7} \right) = - \text{tan} \left( - \frac{\pi}{7} \right) = \text{tan} \frac{\pi}{7}$，
∵$- \frac{\pi}{2} < \frac{\pi}{7} < \frac{\pi}{5} < \frac{\pi}{2}$，$y = \text{tan} x$在$\left( - \frac{\pi}{2} , \frac{\pi}{2} \right)$上为严格增函数，
∴$\text{tan} \frac{\pi}{7} < \text{tan} \frac{\pi}{5}$，即$\text{tan} \frac{6}{5} \pi > \text{tan} \left( - \frac{1 3 \pi}{7} \right)$.
##### 【典例2】（24-25高一上·上海·课堂例题）求函数$y = \sqrt{3 \tan x - \sqrt{3}}$的定义域；
<span class="fake-tag">答案</span>$\left\{ x \left| k \pi + \frac{\pi}{6} \leq x < k \pi + \frac{\pi}{2} , k \in Z \right. \right\}$.
<span class="fake-tag">分析</span>由题意得$\text{tan} x \geq \frac{\sqrt{3}}{3}$，然后根据正切函数的性质求解即可.
<span class="fake-tag">详解</span>由$3 \text{tan} x - \sqrt{3} \geq 0$，得$\text{tan} x \geq \frac{\sqrt{3}}{3}$.
在$\left( - \frac{\pi}{2} , \frac{\pi}{2} \right)$内满足上述不等式的*x*的取值范围为$\left. \frac{\pi}{6} , \frac{\pi}{2} \right)$.
又$y = \text{tan} x$的周期为$\pi$，
所以所求*x*的范围是$\left\{ x \left| k \pi + \frac{\pi}{6} \leq x < k \pi + \frac{\pi}{2} , k \in Z \right. \right\}$.
##### 【变式1】（23-24高一上·安徽黄山·期末）已知函数$f ( x ) = \tan \omega x$在$( - \frac{\pi}{2} , \frac{\pi}{2} )$内是减函数，则$\omega$的取值范围是
$\quad$A．$0 < \omega \leq 1$ 
$\quad$B．$- 1 \leq \omega < 0$ 
$\quad$C．$- 2 \leq \omega < 0$ 
$\quad$D．$0 < \omega \leq \frac{1}{2}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由题设有$y = \omega x , x \in \left( - \frac{\pi}{2} , \frac{\pi}{2} \right)$为减函数，且$\forall x \in \left( - \frac{\pi}{2} , \frac{\pi}{2} \right)$，$- \frac{\pi}{2} < \omega x < \frac{\pi}{2}$恒成立，所以$\begin{cases}\omega < 0 \\ \omega \times \frac{\pi}{2} \geq - \frac{\pi}{2} \\ \omega \times \left( - \frac{\pi}{2} \right) \leq \frac{\pi}{2}\end{cases}$，解得$- 1 \leq \omega < 0$，选B.
##### 【变式2】（23-24高一下·广西钦州·期中）不等式$\text{tan} ( x + \frac{\pi}{3} ) < 1$的解集为（ ）
$\quad$A．$( - \frac{5 \pi}{6} + k \pi , - \frac{\pi}{12} + k \pi ) ( k \in \mathbf{Z} )$ 
$\quad$B．$( - \frac{5 \pi}{6} + 2 k \pi , - \frac{\pi}{12} + 2 k \pi ) ( k \in \mathbf{Z} )$
$\quad$C．$( - \frac{\pi}{2} + k \pi , - \frac{\pi}{4} + k \pi ) ( k \in \mathbf{Z} )$ 
$\quad$D．$( - \frac{\pi}{2} + 2 k \pi , - \frac{\pi}{4} + 2 k \pi ) ( k \in \mathbf{Z} )$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>利用正切函数的单调性解不等式即得.
<span class="fake-tag">详解</span>依题意，得$- \frac{\pi}{2} + k \pi < x + \frac{\pi}{3} < \frac{\pi}{4} + k \text{π,} k \in \mathbf{Z}$，解得$- \frac{5 \pi}{6} + k \pi < x < - \frac{\pi}{12} + k \pi , k \in \mathbf{Z}$，
所以不等式$\text{tan} ( x + \frac{\pi}{3} ) < 1$的解集为$( - \frac{5 \pi}{6} + k \pi , - \frac{\pi}{12} + k \pi ) ( k \in \mathbf{Z} )$.
故选：A
##### 【变式3】（多选）（23-24高一下·浙江杭州·开学考试）下列不等式中，正确的是（ ）．
$\quad$A．$\tan \frac{1 3 \pi}{4} < \tan \frac{1 3 \pi}{5}$ 
$\quad$B．$\sin \frac{\pi}{5} < \cos \left( - \frac{\pi}{7} \right)$
$\quad$C．$\frac{\pi}{5} > \sin \frac{\pi}{5}$ 
$\quad$D．$\frac{\pi}{5} > \tan \frac{\pi}{5}$
<span class="fake-tag">答案</span>BC
<span class="fake-tag">分析</span>利用诱导公式及三角函数的单调性判断A、B，利用三角函数线证明当$0 < x < \frac{\pi}{2}$时$\sin x < x < \tan x$，即可判断C、D.
<span class="fake-tag">详解</span>对于A：$\tan \frac{1 3 \pi}{4} = \tan \left( 3 \pi + \frac{\pi}{4} \right) = \tan \frac{\pi}{4} = 1$，
$\tan \frac{1 3 \pi}{5} = \tan \left( 3 \pi - \frac{\text{2π}}{5} \right) = - \tan \frac{\text{2π}}{5} < 0$，所以$\tan \frac{1 3 \pi}{4} > \tan \frac{1 3 \pi}{5}$，故A错误；
对于B：因为$\frac{\pi}{7} < \frac{\pi}{6} < \frac{\pi}{5} < \frac{\pi}{4}$，且$y = \sin x$在$\left( 0 , \frac{\pi}{2} \right)$上单调递增，$y = \cos x$在$\left( 0 , \frac{\pi}{2} \right)$上单调递减，
所以$\frac{1}{2} = \sin \frac{\pi}{6} < \sin \frac{\pi}{5} < \sin \frac{\pi}{4} = \frac{\sqrt{2}}{2}$，又$\cos \left( - \frac{\pi}{7} \right) = \cos \frac{\pi}{7} > \cos \frac{\pi}{6} = \frac{\sqrt{3}}{2}$，
所以$\sin \frac{\pi}{5} < \cos \left( - \frac{\pi}{7} \right)$，故B正确；
