##### 题型11已知两角的正弦，余弦求和差角的正切
##### 【典例1】（23-24高一下·江苏连云港·期中）已知$\text{tan} \left( \alpha + \frac{\pi}{4} \right) = - 3$，则$\text{tan} \alpha =$（ ）
$\quad$A．－3 
$\quad$B．2 
$\quad$C．3 
$\quad$D．不存在
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>利用两角差的正切公式即可求解.
<span class="fake-tag">详解</span>因为$\text{tan} \left( \alpha + \frac{\pi}{4} \right) = - 3$，
所以$\text{tan} \alpha = \tan \left\lbrack \left( \alpha + \frac{\pi}{4} \right) - \frac{\pi}{4} \right\rbrack = \frac{- 3 - 1}{1 + ( - 3 ) \times 1} = 2$.
故选：B.
##### 【典例2】（23-24高三上·全国·阶段练习）已知$\tan ( \alpha + \beta ) , \tan ( \alpha - \beta )$是方程$x^{2} + 5 x + 6 = 0$的两个根，则$\tan 2 \alpha =$（ ）
$\quad$A．$- 1$ 
$\quad$B．1 
$\quad$C．$- 2$ 
$\quad$D．2
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>利用两角和的正切公式计算．
<span class="fake-tag">详解</span>由于$\tan ( \alpha + \beta ) , \tan ( \alpha - \beta )$是方程$x^{2} + 5 x + 6 = 0$的两个根，所以$\tan ( \alpha + \beta ) + \tan ( \alpha - \beta ) = - 5$，$\tan ( \alpha + \beta ) \cdot \tan ( \alpha - \beta ) = 6$，所以$\tan 2 \alpha = \frac{\tan ( \alpha + \beta ) + \tan ( \alpha - \beta )}{1 - \tan ( \alpha + \beta ) \cdot \tan ( \alpha - \beta )} = \frac{- 5}{1 - 6} = 1$．
故选：B．
##### 【典例3】（23-24高一下·四川绵阳·阶段练习）在$\bigtriangleup A B C$中，已知$\tan A , \tan B$是方程$x^{2} - \sqrt{2} m x + m + 1 = 0$的两个实根，则$\tan 2 C =$ .
<span class="fake-tag">答案</span>$- 2 \sqrt{2}$
<span class="fake-tag">分析</span>利用韦达定理及两角和的正切公式求得$\tan ( A + B )$，由诱导公式求得$\tan C$，然后由正切的二倍角公式计算．
<span class="fake-tag">详解</span>由题意$2 m^{2} - 4 ( m + 1 ) \geq 0$，$m \leq 1 - \sqrt{3}$或$m \geq 1 + \sqrt{3}$，
$\tan A + \tan B = \sqrt{2} m$，$\tan A \tan B = m + 1$，
$\tan ( A + B ) = \frac{\tan A + \tan B}{1 - \tan A \tan B} = \frac{\sqrt{2} m}{1 - ( m + 1 )} = - \sqrt{2}$，
又$A + B + C = \pi$，所以$\tan C = - \tan ( A + C ) = \sqrt{2}$，
所以$\tan 2 C = \frac{2 \tan C}{1 - \tan^{2} C} = \frac{2 \sqrt{2}}{1 - 2} = - 2 \sqrt{2}$，
故答案为：$- 2 \sqrt{2}$．
##### 【变式1】（2024·广东潮州·二模）若$\frac{3 \sin \alpha + 2 \cos \alpha}{2 \sin \alpha - \cos \alpha} = \frac{8}{3}$，则$\tan \left( \alpha + \frac{\pi}{4} \right) =$（ ）
$\quad$A．$- 3$ 
$\quad$B．$3$ 
$\quad$C．$- 2$ 
$\quad$D．$2$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>利用弦化切可求得$\tan \alpha$的值，再利用两角和的正切公式可求得$\tan \left( \alpha + \frac{\pi}{4} \right)$的值.
<span class="fake-tag">详解</span>因为$\frac{3 \sin \alpha + 2 \cos \alpha}{2 \sin \alpha - \cos \alpha} = \frac{3 \tan \alpha + 2}{2 \tan \alpha - 1} = \frac{8}{3}$，解得，
所以，$\tan \left( \alpha + \frac{\pi}{4} \right) = \frac{\tan \alpha + \tan \frac{\pi}{4}}{1 - \tan \alpha \tan \frac{\pi}{4}} = \frac{2 + 1}{1 - 2} = - 3$.
故选：A.
##### 【变式2】（23-24高一·全国·单元测试）若$\tan \left( 18 0^{\circ} - \alpha \right) = - \frac{4}{3}$，则$\tan \left( \alpha + 4 0 5^{\circ} \right)$等于（ ）
$\quad$A．$\frac{1}{7}$ 
$\quad$B．$7$ 
$\quad$C．$- \frac{1}{7}$ 
$\quad$D．
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用诱导公式求出$\tan \alpha$的值，再利用诱导公式以及两角和的正切公式可求得结果.
<span class="fake-tag">详解</span>因为$\tan \left( 18 0^{\circ} - \alpha \right) = - \tan \alpha = - \frac{4}{3}$，所以，$\tan \alpha = \frac{4}{3}$，
因此，$\tan \left( \alpha + 4 0 5^{\circ} \right) = \tan \left( \alpha + 4 5^{\circ} \right) = \frac{\tan \alpha + \tan 4 5^{\circ}}{1 - \tan \alpha \tan 4 5^{\circ}} = \frac{\frac{4}{3} + 1}{1 - \frac{4}{3}} = - 7$.
故选：D.
##### 【变式3】（23-24高一下·云南大理·期末）如图，角的顶点与平面直角坐标系$x O y$的原点重合，始边与$x$轴的非负半轴重合，终边与单位圆交于点$P$，若点$P$的坐标为$( - \frac{4}{5} , y_{0} )$（其中$y_{0} > 0$）．

(2)若将$O P$绕原点$O$按逆时针方向旋转45°，得到角$\alpha$，求$\text{tan} \alpha$的值．
<span class="fake-tag">答案</span>(1)$\frac{3}{5}$；
(2)$\frac{1}{7}$.
<span class="fake-tag">分析</span>（1）由三角函数定义求得，再由平方关系求得$\sin \theta$作答.
（2）根据给定条件得$\alpha = \theta + 4 5 {^\circ}$，利用两角和的正切公式求解作答．
