$\quad$A．11 
$\quad$B．10 
$\quad$C．9 
$\quad$D．8
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>将题意转化为函数$y = \lg x$与$y = \left| \text{sin} 2 x \right|$图象公共点的个数即可.
<span class="fake-tag">详解</span>由$x \in ( 0 , 3 \pi )$，得$2 x \in ( 0 , 6 \pi )$，

当$x \in ( 0 , 3 \pi )$时，由两函数图象可知两图象共有11个公共点，从而方程有11个实数根．
