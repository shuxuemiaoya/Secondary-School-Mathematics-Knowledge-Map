$\quad$A．$- \frac{1}{3}$ 
$\quad$B． 
$\quad$C．$- \frac{2}{3}$ 
$\quad$D．
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>因为$\overrightarrow{A D} = \frac{3}{2} \overrightarrow{D C}$，所以$\overrightarrow{A C} = \frac{5}{3} \overrightarrow{A D}$，
又$P$是直线$B D$上的一点，所以$\overrightarrow{A P} = x \overrightarrow{A B} + ( 1 - x ) \overrightarrow{A D}$，
又$\overrightarrow{A P} = t \overrightarrow{A B} + \frac{2}{5} \overrightarrow{A C} = t \overrightarrow{A B} + \frac{2}{3} \overrightarrow{A D}$，
所以$\begin{cases}x = t \\ 1 - x = \frac{2}{3}\end{cases}$，所以$x = t = \frac{1}{3}$.
故选：B

##### 【典例3】（2023下·四川绵阳·高一三台中学校考阶段练习）已知向量$\overrightarrow{a}$，$\overrightarrow{b}$不共线，且$\overrightarrow{O A} = 2 \overrightarrow{a} - \overrightarrow{b}$，$\overrightarrow{O B} = 3 \overrightarrow{a} + \overrightarrow{b}$，$\overrightarrow{O C} = \overrightarrow{a} + \lambda \overrightarrow{b}$.
(1)将$\overrightarrow{A B}$用$\overrightarrow{a}$，$\overrightarrow{b}$表示；
(2)若$\overrightarrow{O A} \text{//} \overrightarrow{O C}$，求$\lambda$的值；
<span class="fake-tag">答案</span>(1)$\overrightarrow{A B} = \overrightarrow{a} + 2 \overrightarrow{b}$
(2)$- \frac{1}{2}$
<span class="fake-tag">详解</span>（1）因为$\overrightarrow{O A} = 2 \overrightarrow{a} - \overrightarrow{b}$，$\overrightarrow{O B} = 3 \overrightarrow{a} + \overrightarrow{b}$，所以$\overrightarrow{A B} = \overrightarrow{O B} - \overrightarrow{O A} = 3 \overrightarrow{a} + \overrightarrow{b} - \left( 2 \overrightarrow{a} - \overrightarrow{b} \right) = \overrightarrow{a} + 2 \overrightarrow{b}$；
（2）因为$\overrightarrow{O A} \text{//} \overrightarrow{O C}$，$\overrightarrow{O A} = 2 \overrightarrow{a} - \overrightarrow{b}$，$\overrightarrow{O C} = \overrightarrow{a} + \lambda \overrightarrow{b}$，
所以$\overrightarrow{O A} = t \overrightarrow{O C}$，即$2 \overrightarrow{a} - \overrightarrow{b} = t \left( \overrightarrow{a} + \lambda \overrightarrow{b} \right)$，
又向量$\overrightarrow{a}$，$\overrightarrow{b}$不共线，所以$\begin{cases}2 = t \\ - 1 = t \lambda\end{cases}$，
解得$t = 2 , \lambda = - \frac{1}{2}$，即$\lambda$的值为$- \frac{1}{2}$.
##### 【变式1】（2023下·江苏南通·高一校考期中）已知$\overrightarrow{e_{1}} , \overrightarrow{e_{2}}$是两个不共线的向量，向量$\overrightarrow{a} = 2 \overrightarrow{e_{1}} - \overrightarrow{e_{2}} , \overrightarrow{b} = k \overrightarrow{e_{1}} + \overrightarrow{e_{2}}$．若$\overrightarrow{a} / / \overrightarrow{b}$，则$k =$（ ）
$\quad$A．$- 2$ 
$\quad$B．$- \frac{1}{2}$ 
$\quad$C．2 
$\quad$D．$\frac{1}{2}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题设$\overrightarrow{a} = \lambda \overrightarrow{b}$且$\lambda \in R$，故$2 \overrightarrow{e_{1}} - \overrightarrow{e_{2}} = \lambda k \overrightarrow{e_{1}} + \lambda \overrightarrow{e_{2}}$，则$\begin{cases}\lambda k = 2 \\ \lambda = - 1\end{cases}$，可得$k = - 2$.
故选：A

<span class="fake-tag">答案</span>$- 8$
<span class="fake-tag">详解</span>由$\overrightarrow{a} \text{//} \overrightarrow{b}$可设：$\overrightarrow{b} = \lambda \overrightarrow{a} \left( \lambda \in \mathbf{R} \right)$，则$6 \overrightarrow{e_{1}} + k \overrightarrow{e_{2}} = 3 \lambda \overrightarrow{e_{1}} - 4 \lambda \overrightarrow{e_{2}}$，
$\therefore \begin{cases}3 \lambda = 6 \\ - 4 \lambda = k\end{cases}$，解得：$k = - 8$.
故答案为：$- 8$.
