##### 题型04求函数的最值（不含参）
##### 【典例1】（2023上·北京海淀·高三校考阶段练习）函数在区间$[ 1 , 2 ]$上的最大值是（ ）
$\quad$A．0 
$\quad$B．$\frac{1}{2}$ 
$\quad$C．1 
$\quad$D．$\frac{3}{2}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>$f^{'} ( x ) = 3 x - \frac{27}{x} = \frac{3 ( x + 3 ) ( x - 3 )}{x}$，定义域为$( 0 , + \infty )$，
令$f^{'} ( x ) > 0$，解得$x > 3$，令$f^{'} ( x ) < 0$，解得$0 < x < 3$，
所以$f ( x )$在$( 3 , + \infty )$上单调递增，$( 0 , 3 )$单调递减，
所以$f ( x )$在区间$[ 1 , 2 ]$上的最大值为$f ( 1 ) = \frac{3}{2}$.
故选：D.
##### 【典例2】（2023上·北京顺义·高三牛栏山一中校考阶段练习）已知函数$f ( x ) = \left( x^{2} - 3 x + 1 \right) e^{x}$．
(1)求曲线在$\left( 0 , f ( 0 ) \right)$处的切线方程；
(2)求$f ( x )$在区间$[ - 2 , 0 ]$上的最大值和最小值．
<span class="fake-tag">答案</span>(1)$2 x + y - 1 = 0$
(2)最大值为$\frac{5}{e}$，最小值为1
<span class="fake-tag">详解</span>（1）对函数$f ( x ) = \left( x^{2} - 3 x + 1 \right) e^{x}$求导得，$f^{'} ( x ) = \left( x^{2} - 3 x + 1 + 2 x - 3 \right) e^{x} = \left( x^{2} - x - 2 \right) e^{x}$，
所以$f ( 0 ) = 1 , f^{'} ( 0 ) = - 2$，
所以曲线在$\left( 0 , f ( 0 ) \right)$处的切线方程为$y - 1 = - 2 ( x - 0 )$，
化简并整理得该切线方程为$2 x + y - 1 = 0$.
（2）由（1）可知$f^{'} ( x ) = \left( x^{2} - x - 2 \right) e^{x} = ( x + 1 ) ( x - 2 ) e^{x}$，
当$x \in [ - 2 , 0 ]$时，$f^{'} ( x ) , f ( x )$随$x$的变化情况如下表：
| $ x $       | $ \left. - 2 , - 1 ) $ |         | $ \left. - 1 , 0 \right. $ |
|---------------|--------------------------|---------|------------------------------|
|               | $ + $                  | $ 0 $ | $ - $                      |
| $ f ( x ) $ | $ \nearrow $           | 极大值  | $ \searrow $               |
由上表可知函数$f ( x ) = \left( x^{2} - 3 x + 1 \right) e^{x}$在$\left. - 2 , - 1 )$上单调递增，在$\left. - 1 , 0 \right.$上单调递减，且在$x = - 1$时$f ( x )$取得极大值，
所以$f ( x )$在区间$[ - 2 , 0 ]$上的最大值$f ( - 1 ) = \frac{5}{e}$，
而$f ( x )$在区间$[ - 2 , 0 ]$上的最小值为$f ( 0 ) , f ( - 2 )$中的较小者，
又$0 < e < 3$，所以$f ( 0 ) = 1 < \frac{11}{9} < \frac{11}{e^{2}} = f ( - 2 )$，
所以$f ( x )$在区间$[ - 2 , 0 ]$上的最小值为$f ( 0 ) = 1$.
