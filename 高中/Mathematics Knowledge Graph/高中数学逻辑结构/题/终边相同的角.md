##### 题型02终边相同的角
##### 【典例1】（23-24高一下·辽宁沈阳·期中）与角$\mathbf{-} \mathbf{2024} \mathbf{^\circ} \mathbf{4}^{\mathbf{'}}$终边相同的角是（ ）
$\quad$A．$\mathbf{- 4 0 4 {^\circ}} \mathbf{4}^{\mathbf{'}}$ B．$\mathbf{- 2 2 4 {^\circ}} \mathbf{4}^{\mathbf{'}}$ C．$\mathbf{3 1 5 {^\circ} 5} \mathbf{6}^{\mathbf{'}}$ D．$\mathbf{675} \mathbf{^\circ} \mathbf{5} \mathbf{6}^{\mathbf{'}}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>利用终边相同角的概念公式求解即可.
<span class="fake-tag">详解</span>解：$\because - 2024 {^\circ} 4^{'} = - 5 \times 360 {^\circ} - 224 {^\circ} 4^{'}$，
$\therefore$与角$- 2 0 2 4 {^\circ} 4^{'}$终边相同的角是$- 224 {^\circ} 4^{'}$．
故选：B.
##### 【典例2】（24-25高一上·上海·课后作业）在与530°终边重合的角中，求满足下列条件的角．
(1)最大的负角；
(2)最小的正角；
(3)–720°到–360°的角．
<span class="fake-tag">答案</span>(1)$- 190 {^\circ}$
(2)$170 {^\circ}$
(3)$- 550 {^\circ}$
<span class="fake-tag">分析</span>先求出与530°终边相同角的集合，然后再分别取满足题意的*k*值，即可得解
<span class="fake-tag">详解</span>（1）因为与530°终边相同角的集合为$\left\{ \alpha | \alpha = 1 7 0 {^\circ} + k \cdot 360 {^\circ} ， k \in Z \right\}$，
当$k = - 1$时，得到最大的负角为：$170 {^\circ} - 360 {^\circ} = - 190 {^\circ}$；
（2）由（1）知，当$k = 0$时，得到最小的正角为：$170 {^\circ} + 0 \times 360 {^\circ} = 1 7 0 {^\circ}$；
（3）由（1）知，当$k = - 2$时，得到–720°到–360°的角为：$170 {^\circ} - 2 \times 360 {^\circ} = - 550 {^\circ}$；
##### 【变式1】（23-24高一下·山东日照·期中）在$\mathbf{0 {^\circ} \sim 3 6 0 {^\circ}}$内，与$\mathbf{-} \mathbf{520} \mathbf{^\circ}$角终边相同的角是（ ）
$\quad$A．$\mathbf{3 1 0 {^\circ}}$ B．$\mathbf{2 0 0 {^\circ}}$ C．$\mathbf{1 4 0 {^\circ}}$ D．$\mathbf{20} \mathbf{^\circ}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>由终边相同的角的定义计算即可得.
<span class="fake-tag">详解</span>$- 5 2 0 {^\circ} + 2 \times 3 6 0 {^\circ} = 2 0 0 {^\circ}$，而其它项对应角都不满足$- 520 {^\circ} + 3 6 0 {^\circ} n , n \in Z$.
故选：B.
##### 【变式2】（23-24高一·上海·课堂例题）找出与下列各角的终边重合的角$\mathbf{\alpha} \left( \mathbf{0} \mathbf{{^\circ} \leq} \mathbf{\alpha < 3 6 0} \mathbf{^\circ} \right)$，并判别下列各角是第几象限的角：
(1)$\mathbf{-} \mathbf{1441} \mathbf{^\circ}$；
(2)$\mathbf{890} \mathbf{^\circ}$．
<span class="fake-tag">答案</span>(1)与角$359 {^\circ}$的终边重合，第四象限角；
(2)与角$170 {^\circ}$的终边重合，第二象限角.
<span class="fake-tag">分析</span>（1）（2）将给定角写成$k \cdot 360 {^\circ} + \alpha ( k \in Z )$，即可求解得答案.
<span class="fake-tag">详解</span>（1）$- 1 4 4 1 {^\circ} = - 5 \times 3 6 0 {^\circ} + 3 5 9 {^\circ}$，且$270 {^\circ} < 3 5 9 {^\circ} < 3 6 0 {^\circ}$，
所以角$- 1 4 4 1 {^\circ}$与角$359 {^\circ}$的终边重合，它是第四象限角.
（2）$8 9 0 {^\circ} = 2 \times 3 6 0 {^\circ} + 1 7 0 {^\circ}$，且$90 {^\circ} < 1 7 0 {^\circ} < 1 8 0 {^\circ}$，
所以角$8 9 0 {^\circ}$与角$170 {^\circ}$的终边重合，它是第二象限角.
