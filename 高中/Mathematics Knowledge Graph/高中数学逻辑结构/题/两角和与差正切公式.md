##### 题型10两角和与差正切公式
##### 【典例1】（24-25高一下·全国·随堂练习）已知，$\tan \beta = 3$，则$\tan ( \alpha + \beta )$等于（ ）
$\quad$A．1 
$\quad$B．5 
$\quad$C．$- 1$ 
$\quad$D．$- 5$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>利用两角和的正切公式可求得$\tan ( \alpha + \beta )$的值.
<span class="fake-tag">详解</span>因为，$\tan \beta = 3$，
所以$\tan ( \alpha + \beta ) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta} = \frac{2 + 3}{1 - 2 \times 3} = - 1$.
故选：C.
##### 【典例2】（24-25高一下·全国·课堂例题）化简$\frac{1 - \tan 1 5^{\circ}}{1 + \tan 1 5^{\circ}}$等于（ ）
$\quad$A． 
$\quad$B．$\frac{\sqrt{3}}{3}$ 
$\quad$C．3 
$\quad$D．1
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>转化为两角差的正切公式，即可求解.
<span class="fake-tag">详解</span>原式$= \frac{\tan 4 5^{\circ} - \tan 1 5^{\circ}}{1 + \tan 4 5^{\circ} \tan 1 5^{\circ}} = \tan \left( 4 5^{\circ} - 1 5^{\circ} \right) = \tan 3 0^{\circ} = \frac{\sqrt{3}}{3}$．
故选：B
##### 【典例3】（24-25高一下·全国·课后作业）已知，则$\tan \left( \alpha - \frac{\pi}{3} \right)$的值为 ．
<span class="fake-tag">答案</span>

##### 【变式1】（24-25高一下·全国·随堂练习）已知$\tan \alpha = - \frac{3}{4}$，则$\tan \left( \frac{\pi}{4} - \alpha \right)$等于（ ）
$\quad$A．$- \frac{1}{7}$ 
$\quad$B． 
$\quad$C．$\frac{1}{7}$ 
$\quad$D．7
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用两角差的正切展开式计算可得答案.
<span class="fake-tag">详解</span>因为$\tan \alpha = - \frac{3}{4}$，
所以$\tan \left( \frac{\pi}{4} - \alpha \right) = \frac{\tan \frac{\pi}{4} - \tan \alpha}{1 + \tan \frac{\pi}{4} \times \tan \alpha} = \frac{1 + \frac{3}{4}}{1 - \frac{3}{4}} = 7$.

##### 【变式2】（24-25高一下·全国·课后作业）与相等的是（ ）

##### 【变式3】（23-24高一下·湖北黄冈·期中）$\frac{\tan \frac{3 \pi}{4} + \tan \frac{7 \pi}{12}}{1 - \tan \frac{5 \pi}{12}} =$（ ）
$\quad$A． 
$\quad$B．$- \sqrt{3}$ 
$\quad$C．$- \frac{\sqrt{3}}{3}$ 
$\quad$D．$\frac{\sqrt{3}}{3}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据题意利用诱导公式结合两角和差公式运算求解.
<span class="fake-tag">详解</span>由题意可得$\frac{\tan \frac{3 \pi}{4} + \tan \frac{7 \pi}{12}}{1 - \tan \frac{5 \pi}{12}} = \frac{\tan \frac{3 \pi}{4} + \tan \left( \pi - \frac{5 \pi}{12} \right)}{1 - \tan \frac{5 \pi}{12}}$
$= \frac{\tan \frac{3 \pi}{4} - \tan \frac{5 \pi}{12}}{1 + \tan \frac{3 \pi}{4} \tan \frac{5 \pi}{12}} = \tan \left( \frac{3 \pi}{4} - \frac{5 \pi}{12} \right) = \tan \frac{\pi}{3} = \sqrt{3}$，
所以$\frac{\tan \frac{3 \pi}{4} + \tan \frac{7 \pi}{12}}{1 - \tan \frac{5 \pi}{12}} = \sqrt{3}$.
故选：A.
