##### 题型04 平面向量基本定理的综合应用
##### 【典例1】（2023上·北京·高三101中学校考阶段练习）如图，在$\bigtriangleup A B C$中，*M*，*N*分别为*AB*，*AC*边上的中点，*P*是线段*MN*上的一个动点（不含端点），*CP*与*AB*交于点*D*，*BP*与*AC*交于点*E*，$\overrightarrow{A D} = \lambda \overrightarrow{A B}$，$\overrightarrow{A E} = \mu \overrightarrow{A C}$，则$\frac{1}{\lambda} + \frac{1}{\mu}$的最小值为（ ）
![@@@d79ced75-5ca2-4419-b4d0-0c0d6f77519b](高中习题/课堂同步/随堂练习习题/必修二/Attachments/724c9df920eb7665955c97f1258a5171.png)
$\quad$A．2 
$\quad$B．4 
$\quad$C．6 
$\quad$D．8
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>设$M P = t M N$，则$t \in ( 0 , 1 )$，
因为*M*，*N*分别为*AB*，*AC*边上的中点，所以$M N = \frac{1}{2} B C$，$A M = M B , A N = N C$，
故$M P = \frac{1}{2} t B C$，
因为$\bigtriangleup D M P$∽$\bigtriangleup D B C$，所以$D M = \frac{1}{2} t B D$，
设$B D = x$，则$D M = \frac{1}{2} t x , M B = x - \frac{1}{2} t x$，$A D = A M - D M = x - t x$，
故$\frac{A D}{A B} = \frac{x - t x}{2 x - t x} = \frac{1 - t}{2 - t}$，故$\lambda = \frac{1 - t}{2 - t}$，
同理可得$N P = ( 1 - t ) M N$，$N P = \frac{1}{2} ( 1 - t ) B C$，
因为$\bigtriangleup E N P$∽$\bigtriangleup E C B$，所以$E N = \frac{1}{2} ( 1 - t ) E C$，
设$E C = y$，则$E N = \frac{1}{2} ( 1 - t ) y , C N = y - \frac{1}{2} ( 1 - t ) y = \frac{1}{2} ( 1 + t ) y$，
$A C = ( 1 + t ) y$，$A E = ( 1 + t ) y - y = t y$，
故$\frac{A E}{A C} = \frac{t}{1 + t}$，$\mu = \frac{t}{1 + t}$，
则$\frac{1}{\lambda} + \frac{1}{\mu} = \frac{2 - t}{1 - t} + \frac{1 + t}{t} = 1 + \frac{1}{1 - t} + 1 + \frac{1}{t} = 2 + \frac{1}{1 - t} + \frac{1}{t} = 2 + \frac{1}{t ( 1 - t )}$
因为$t \in ( 0 , 1 )$，由基本不等式得$t ( 1 - t ) \leq \left( \frac{t + 1 - t}{2} \right)^{2} = \frac{1}{4}$，
当且仅当$t = 1 - t$，即$t = \frac{1}{2}$时，等号成立，
故$\frac{1}{\lambda} + \frac{1}{\mu} = 2 + \frac{1}{t ( 1 - t )} \geq 2 + 4 = 6$.
故选：C

(1)若$M$为弧$A C$中点，求$x + y$；
(2)求$\overrightarrow{A M} \cdot \overrightarrow{A B}$最大值．

##### 【变式1】（2023上·江西吉安·高三吉安一中校考期中）$\bigtriangleup A B C$中，$D$为$A C$上一点且满足$\overrightarrow{C D} = \frac{3}{4} \overrightarrow{C A}$，若$P$为$B D$上一点，且满足$\overrightarrow{A P} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C}$，$\lambda , \mu$为正实数，则下列结论正确的是（ ）
$\quad$A．$\lambda \mu$的最小值为$\frac{1}{16}$ 
$\quad$B．$\lambda \mu$的最大值为1
$\quad$C．的最大值为16 
$\quad$D．的最小值为4
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>AB选项，因为$\overrightarrow{C D} = \frac{3}{4} \overrightarrow{C A}$，所以$\overrightarrow{A C} = 4 \overrightarrow{A D}$，
故$\overrightarrow{A P} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C} = \lambda \overrightarrow{A B} + 4 \mu \overrightarrow{A D}$，
因为$B , P , D$三点共线，设$\overrightarrow{P B} = m \overrightarrow{B D}$，即$\overrightarrow{A B} - \overrightarrow{A P} = m \overrightarrow{A D} - m \overrightarrow{A B}$，
故$\overrightarrow{A P} = ( 1 + m ) \overrightarrow{A B} - m \overrightarrow{A D}$，
令$\lambda = 1 + m , 4 \mu = - m$，故$\lambda + 4 \mu = 1$，
![@@@662629288791458f9c6c9c5da9531d3f](高中习题/课堂同步/随堂练习习题/必修二/Attachments/3280e03ff4c518f0df2f76e8ffeb75e3.png)
$\lambda , \mu$为正实数，由基本不等式得$\lambda + 4 \mu = 1 \geq 2 \sqrt{4 \lambda \mu} = 4 \sqrt{\lambda \mu}$，解得$\lambda \mu \leq \frac{1}{16}$，
当且仅当$\lambda = \frac{1}{2} , \mu = \frac{1}{8}$时，等号成立，所以$\lambda \mu$的最大值为$\frac{1}{16}$，AB错误；
CD选项，$\frac{1}{\lambda} + \frac{1}{4 \mu} = \left( \frac{1}{\lambda} + \frac{1}{4 \mu} \right) \cdot ( \lambda + 4 \mu ) = 1 + 1 + \frac{4 \mu}{\lambda} + \frac{\lambda}{4 \mu} \geq 2 + 2 \sqrt{\frac{4 \mu}{\lambda} \cdot \frac{\lambda}{4 \mu}} = 4$，
当且仅当$\frac{4 \mu}{\lambda} = \frac{\lambda}{4 \mu}$，即$\lambda = \frac{1}{2} , \mu = \frac{1}{8}$时，等号成立，C错误，D正确.
故选：D
##### 【变式2】（2023上·山东济宁·高三统考期中）在$\bigtriangleup A B C$中，点$D , E$是线段$B C$上的两个动点，且$\overrightarrow{A D} + \overrightarrow{A E} = x \overrightarrow{A B} + \frac{y}{2} \overrightarrow{A C}$，则$\frac{1}{x} + \frac{2}{y}$的最小值为（ ）．
$\quad$A． 
$\quad$B．$\frac{4}{3}$ 
$\quad$C．2 
$\quad$D．8
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>如图所示：
![@@@3c5851a6-e823-40dc-8b7f-195242a0222d](高中习题/课堂同步/随堂练习习题/必修二/Attachments/faa8d80afed20b1fcc674a77e0d768cf.png)
不妨设$\overrightarrow{C D} = \lambda \overrightarrow{C B} , ( 0 \leq \lambda \leq 1 )$，则$\overrightarrow{A D} = \overrightarrow{A C} + \overrightarrow{C D} = \overrightarrow{A C} + \lambda \overrightarrow{C B} = \overrightarrow{A C} + \lambda \left( \overrightarrow{C A} + \overrightarrow{A B} \right) = \lambda \overrightarrow{A B} + ( 1 - \lambda ) \overrightarrow{A C}$，
同理设$\overrightarrow{C E} = \mu \overrightarrow{C B} , ( 0 \leq \mu \leq 1 )$，则$\overrightarrow{A E} = \overrightarrow{A C} + \overrightarrow{C E} = \overrightarrow{A C} + \mu \overrightarrow{C B} = \overrightarrow{A C} + \mu \left( \overrightarrow{C A} + \overrightarrow{A B} \right) = \mu \overrightarrow{A B} + ( 1 - \mu ) \overrightarrow{A C}$，
所以$\overrightarrow{A D} + \overrightarrow{A E} = \left\lbrack \lambda \overrightarrow{A B} + ( 1 - \lambda ) \overrightarrow{A C} \right\rbrack + \left\lbrack \mu \overrightarrow{A B} + ( 1 - \mu ) \overrightarrow{A C} \right\rbrack = ( \lambda + \mu ) \overrightarrow{A B} + ( 2 - \lambda - \mu ) \overrightarrow{A C}$
又由题意$\overrightarrow{A D} + \overrightarrow{A E} = x \overrightarrow{A B} + \frac{y}{2} \overrightarrow{A C}$，
所以$x = \lambda + \mu , \frac{y}{2} = 2 - \lambda - \mu , x + \frac{y}{2} = ( \lambda + \mu ) + ( 2 - \lambda - \mu ) = 2 , 0 \leq x \leq 2 , 0 \leq y \leq 4$，
从而$\frac{x}{2} + \frac{y}{4} = 1 , 0 \leq x \leq 2 , 0 \leq y \leq 4$，
当$x \neq 0 , y \neq 0$时，由基本不等式可得$\frac{1}{x} + \frac{2}{y} = \left( \frac{x}{2} + \frac{y}{4} \right) \left( \frac{1}{x} + \frac{2}{y} \right) = 1 + \frac{y}{4 x} + \frac{x}{y} \geq 1 + 2 \sqrt{\frac{y}{4 x} \cdot \frac{x}{y}} = 2$，
等号成立当且仅当$x = 1 , y = 2$.
综上所述：$\frac{1}{x} + \frac{2}{y}$的最小值为2.
故选：C.
