##### 题型03 利用二倍角公式解决条件求值问题
##### 【典例1】（24-25高三上·贵州黔东南·开学考试）已知$\alpha \in ( 0 , \pi )$，且$\text{cos} \left( \alpha + \frac{\pi}{4} \right) = \frac{1}{3}$，则$\text{cos} 2 \alpha =$（ ）
$\quad$A．$\frac{4 \sqrt{2}}{9}$ 
$\quad$B．$\pm \frac{4 \sqrt{2}}{9}$ 
$\quad$C．$\frac{7}{9}$ 
$\quad$D．$\pm \frac{7}{9}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>利用二倍角公式结合角的余弦值确定角的范围计算即可.
<span class="fake-tag">详解</span>因为$\alpha \in ( 0 , \pi )$，$\text{cos} \left( \alpha + \frac{\pi}{4} \right) = \frac{1}{3} > 0$，所以$\alpha + \frac{\pi}{4} \in \left( \frac{\pi}{4} , \frac{\pi}{2} \right)$，
则$\text{sin} \left( \alpha + \frac{\pi}{4} \right) = \sqrt{1 - \text{co} \text{s}^{2} \left( \alpha + \frac{\pi}{4} \right)} = \frac{2 \sqrt{2}}{3}$，
则$\text{cos} 2 \alpha = \text{cos} \left\lbrack 2 \left( \alpha + \frac{\pi}{4} \right) - \frac{\pi}{2} \right\rbrack = \text{sin} 2 \left( \alpha + \frac{\pi}{4} \right) = 2 \text{sin} \left( \alpha + \frac{\pi}{4} \right) \cdot \text{cos} \left( \alpha + \frac{\pi}{4} \right) = \frac{4 \sqrt{2}}{9}$.
故选：A

<span class="fake-tag">详解</span>令$x = \frac{\pi}{3} - \alpha$，$\cos \left( \frac{\pi}{3} - \alpha \right) = \frac{2}{3}$，则$\cos x = \frac{2}{3}$，
