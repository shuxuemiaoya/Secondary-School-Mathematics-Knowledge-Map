$\quad$B．$- \frac{3}{2}$ 
$\quad$C．0

##### 【典例2】（2024高三上·全国·专题练习）函数$y = 3 - 2 \cos \left( 2 x - \frac{\pi}{3} \right)$，$x \in \left\lbrack \frac{\pi}{6} , \frac{\pi}{2} \right\rbrack$的值域为 ．
<span class="fake-tag">答案</span>$[ 1 , 4 ]$
<span class="fake-tag">分析</span>先求出整体角的范围，再利用余弦函数的值域求解即可.
<span class="fake-tag">详解</span>因为，所以$0 \leq 2 x - \frac{\pi}{3} \leq \frac{2 \pi}{3}$，
所以$- \frac{1}{2} \leq \cos \left( 2 x - \frac{\pi}{3} \right) \leq 1$，
所以$1 \leq 3 - 2 \cos \left( 2 x - \frac{\pi}{3} \right) \leq 4$．
所以函数的值域为$[ 1 , 4 ]$．
故答案为：$[ 1 , 4 ]$
##### 【变式1】（23-24高一下·辽宁辽阳·期末）已知函数$f ( x ) = \text{sin} \left( \omega x + \frac{\pi}{6} \right) + \frac{1}{2} ( 0 < \omega < 7 )$，且$\forall x_{0} \in \mathbf{R} , f \left( x_{0} \right) \leqslant f \left( \frac{\pi}{3} \right)$.
(1)求$\omega$的值；
(2)求$f ( x )$的单调递增区间；
(3)若$x \in [ 0 , m ] , f ( x )$的值域是$\left\lbrack 1 , \frac{3}{2} \right\rbrack$，求$m$的取值范围.
<span class="fake-tag">答案</span>(1)$\omega = 1$
(2)$\left\lbrack - \frac{2 \pi}{3} + 2 k \text{π} \text{,} \frac{\pi}{3} + 2 k \pi \right\rbrack ( k \in Z )$
(3)$\frac{\pi}{3} \leq m \leq \frac{\text{2} \text{π}}{3}$
<span class="fake-tag">分析</span>（1）代入最大值点化简函数即可求参；
（2）应用正弦函数的单调增区间求解即可；
（3）化简得出正弦函数的值域进而确定自变量的取值范围.
<span class="fake-tag">详解</span>（1）因为$f ( x ) = \text{sin} \left( \omega x + \frac{\pi}{6} \right) + \frac{1}{2} , \forall x_{0} \in \text{R,} f \left( x_{0} \right) \leq f \left( \frac{\pi}{3} \right)$，所以$f ( x )_{\text{max}} = f \left( \frac{\pi}{3} \right) = 1 + \frac{1}{2}$,
可得$f \left( \frac{\pi}{3} \right) = \text{sin} \left( \omega \frac{\pi}{3} + \frac{\pi}{6} \right) + \frac{1}{2} \text{=1+} \frac{1}{2} ， \text{sin} \left( \omega \frac{\pi}{3} + \frac{\pi}{6} \right) \text{=1} ， \omega \frac{\pi}{3} + \frac{\pi}{6} = \frac{\pi}{2} + 2 k \pi$，
所以$\omega = 1 + 6 k , k \in Z , 0 < \omega < 7$,
所以$\omega = 1$.
（2）$x + \frac{\pi}{6} \in \left\lbrack - \frac{\pi}{2} + 2 k \text{π} \text{,} \frac{\pi}{2} + 2 \text{k} \text{π} \right\rbrack ( k \in Z ) , x \in \left\lbrack - \frac{\text{2} \text{π}}{3} + 2 k \text{π} \text{,} \frac{\pi}{3} + 2 \text{k} \text{π} \right\rbrack ( k \in Z ) ,$
$f ( x ) = \text{sin} \left( x + \frac{\pi}{6} \right) + \frac{1}{2}$的单调增区间为$\left\lbrack - \frac{\text{2} \text{π}}{3} + 2 k \text{π} \text{,} \frac{\pi}{3} + 2 \text{k} \text{π} \right\rbrack ( k \in Z )$.
（3）因为$x \in [ 0 , m ] , x + \frac{\pi}{6} \in \left\lbrack \frac{\pi}{6} , \frac{\pi}{6} + m \right\rbrack$,
又因为$f ( x ) = \text{sin} \left( x + \frac{\pi}{6} \right) + \frac{1}{2} \in \left\lbrack 1 , \frac{3}{2} \right\rbrack \text{,sin} \left( x + \frac{\pi}{6} \right) \in \left\lbrack \frac{1}{2} \text{,1} \right\rbrack ,$ ,
所以$\frac{\pi}{2} \leq \frac{\pi}{6} + m \leq \frac{\text{5π}}{6} ,$即$\frac{\pi}{3} \leq m \leq \frac{\text{2} \text{π}}{3}$.
##### 【变式2】（23-24高一下·河南南阳·期末）已知函数$f ( x ) = 2 \text{cos} \left( 2 x + \frac{\pi}{3} \right) + 1$.
(1)求$f ( x )$的单调递增区间；
(2)求$f ( x )$在$\left\lbrack 0 , \frac{\pi}{2} \right\rbrack$上的值域.
<span class="fake-tag">答案</span>(1)$\left\lbrack - \frac{2}{3} \pi + k \text{π} \text{,} - \frac{\pi}{6} + k \pi \right\rbrack , k \in Z$
(2)$[ - 1 , 2 ]$
<span class="fake-tag">分析</span>（1）根据余弦函数的性质计算可得.
（2）由$x$的取值范围求出$2 x + \frac{\pi}{3} \in \left\lbrack \frac{\pi}{3} , \frac{\text{4} \text{π}}{3} \right\rbrack$，再根据余弦函数的性质计算可得.
<span class="fake-tag">详解</span>（1）$f ( x ) = 2 \text{cos} \left( 2 x + \frac{\pi}{3} \right) + 1$，令$- \pi + 2 k \pi \leq 2 x + \frac{\pi}{3} \leq 2 k \pi , k \in Z$，
解得$- \frac{2}{3} \pi + k \pi \leq x \leq - \frac{\pi}{6} + k \pi , k \in Z$，
所以函数的单调递增区间为$\left\lbrack - \frac{2}{3} \pi + k \text{π} \text{,} - \frac{\pi}{6} + k \pi \right\rbrack , k \in Z$.
（2）$f ( x ) = 2 \text{cos} \left( 2 x + \frac{\pi}{3} \right) + 1$，因为$x \in \left\lbrack 0 , \frac{\pi}{2} \right\rbrack$，所以$2 x + \frac{\pi}{3} \in \left\lbrack \frac{\pi}{3} , \frac{\text{4} \text{π}}{3} \right\rbrack$，
可得$\text{cos} \left( 2 x + \frac{\pi}{3} \right) \in \left\lbrack - 1 , \frac{1}{2} \right\rbrack$，则$2 \text{cos} \left( 2 x + \frac{\pi}{3} \right) + 1 \in [ - 1 , 2 ]$，
即函数$f ( x )$在$\left\lbrack 0 , \frac{\pi}{2} \right\rbrack$上的值域为$[ - 1 , 2 ]$．
