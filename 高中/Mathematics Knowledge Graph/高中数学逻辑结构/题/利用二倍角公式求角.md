##### 题型02 利用二倍角公式求角
##### 【典例1】（23-24高一下·江苏苏州）设$\alpha \in \left( 0 , \frac{\pi}{2} \right) , \beta \in \left( 0 , \frac{\pi}{2} \right)$，且$\text{tan} \alpha = \frac{1}{7} , \text{tan} \beta = \frac{1}{3}$，则（ ）
$\quad$A．$\frac{\pi}{4}$ 
$\quad$B．$\frac{\pi}{3}$ 
$\quad$C．$\frac{3 \pi}{4}$ 
$\quad$D．$\frac{5 \pi}{4}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据二倍角的正切公式与两角和的正切公式求解，再分析角度范围得到$\alpha + 2 \beta$即可
<span class="fake-tag">详解</span>因为$\tan \alpha = \frac{1}{7} , \tan \beta = \frac{1}{3} \Rightarrow \tan 2 \beta = \frac{\frac{2}{3}}{1 - \frac{1}{9}} = \frac{3}{4}$，所以$\tan ( \alpha + 2 \beta ) = \frac{\frac{1}{7} + \frac{3}{4}}{1 - \frac{1}{7} \times \frac{3}{4}} = \frac{4 + 2 1}{2 8 - 5} = 1$，且$0 < \tan 2 \beta = \frac{3}{4} < 1 \Rightarrow 2 \beta \in ( 0 , \frac{\pi}{4} )$，所以$\alpha + 2 \beta \in ( 0 , \frac{3 \pi}{4} )$，则$\alpha + 2 \beta = \frac{\pi}{4}$
故选：A．
##### 【典例2】（23-24高一上·浙江杭州）在平面直角坐标系$x O y$中，锐角$\alpha$、的顶点为坐标原点$O$，始边为$x$轴的正半轴，终边与单位圆$O$的交点分别为$P$、$Q$．已知点$P$的横坐标为$\frac{\sqrt{2}}{10}$，点$Q$的纵坐标为．

(1)求的值；

<span class="fake-tag">分析</span>（1）利用三角函数的定义以及同角三角函数的基本关系可求得$\alpha$、的正弦值、余弦值，利用两角和的正弦公式可求得的值；
（2）求出$2 \beta$的正弦值、余弦值，利用两角和的余弦公式可求得$\alpha + 2 \beta$的余弦值，求出$\alpha + 2 \beta$的取值范围，即可求得结果.
<span class="fake-tag">详解</span>（1）解：利用三角函数的定义可得$\cos \alpha = \frac{\sqrt{2}}{10}$，$\sin \beta = \frac{\sqrt{5}}{5}$，
又$\alpha$、是锐角，所以，$\cos \beta = \sqrt{1 - \sin^{2} \beta} = \frac{2 \sqrt{5}}{5}$，
所以，$\sin ( \alpha + \beta ) = \sin \alpha \cos \beta + \cos \alpha \sin \beta = \frac{3 \sqrt{10}}{10}$.
（2）解：因为$\sin 2 \beta = 2 \sin \beta \cos \beta = \frac{4}{5}$，${\cos 2 \beta = 2} {\cos {}^{2}} \beta - 1 = \frac{3}{5} > 0$，
又是锐角，则$0 < 2 \beta < \pi$，所以$0 < 2 \beta < \frac{\pi}{2}$，
又因为$0 < \alpha < \frac{\pi}{2}$，则$0 < \alpha + 2 \beta < \pi$，
而$\cos ( \alpha + 2 \beta ) = \cos \alpha \cos 2 \beta - \sin \alpha \sin 2 \beta = - \frac{\sqrt{2}}{2}$，所以$\alpha + 2 \beta = \frac{3 \pi}{4}$．
##### 【变式1】（23-24高一下·广东湛江·阶段练习）已知$0 < \alpha < \frac{\pi}{2}$，$- \frac{\pi}{2} < \beta < 0$，$\text{cos} \alpha = \frac{\sqrt{2}}{10}$，$\text{sin} \beta = - \frac{\sqrt{5}}{5}$．
(1)求$\text{cos} ( \alpha - \beta )$的值；
(2)求$\text{tan} ( \alpha - 2 \beta )$的值，并确定$\alpha - 2 \beta$的大小．
<span class="fake-tag">答案</span>(1)$- \frac{\sqrt{10}}{10}$
(2)
<span class="fake-tag">分析</span>（1）先通过条件求出$\sin \alpha$，$\cos \beta$，再利用两角差的余弦公式计算$\text{cos} ( \alpha - \beta )$即可；
（2）通过（1）求出$\tan \alpha$，$\tan 2 \beta$，再利用两角差的正切公式计算$\text{tan} ( \alpha - 2 \beta )$即可.
<span class="fake-tag">详解</span>（1）$\because 0 < \alpha < \frac{\pi}{2}$，$- \frac{\pi}{2} < \beta < 0$，$\text{cos} \alpha = \frac{\sqrt{2}}{10}$，$\text{sin} \beta = - \frac{\sqrt{5}}{5}$，
$\therefore \sin \alpha = \sqrt{1 - \text{co} \text{s}^{2} \alpha} = \frac{7 \sqrt{2}}{10}$，$\text{cos} \beta = \sqrt{1 - \text{si} \text{n}^{2} \beta} = \frac{2 \sqrt{5}}{5}$，
$\therefore \text{cos} ( \alpha - \beta ) = \cos \alpha \cos \beta + \sin \alpha \sin \beta = \frac{\sqrt{2}}{10} \times \frac{2 \sqrt{5}}{5} + \frac{7 \sqrt{2}}{10} \times \left( - \frac{\sqrt{5}}{5} \right) = - \frac{\sqrt{10}}{10}$；
（2）由（1）得$\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = 7$，$\tan \beta = \frac{\sin \beta}{\cos \beta} = - \frac{1}{2}$，$\tan 2 \beta = \frac{2 \tan \beta}{1 - \tan^{2} \beta} = \frac{2 \times \left( - \frac{1}{2} \right)}{1 - \left( - \frac{1}{2} \right)^{2}} = - \frac{4}{3}$，
$\therefore \text{tan} ( \alpha - 2 \beta ) = \frac{\tan \alpha - \tan 2 \beta}{1 + \tan \alpha \tan 2 \beta} = \frac{7 - \left( - \frac{4}{3} \right)}{1 + 7 \times \left( - \frac{4}{3} \right)} = - 1$，
由$0 < \alpha < \frac{\pi}{2}$，$- \frac{\pi}{2} < \beta < 0$得$0 < \alpha - 2 \beta < \frac{\text{3} \text{π}}{2}$，
$\therefore \alpha - 2 \beta = \frac{3 \pi}{4}$.
