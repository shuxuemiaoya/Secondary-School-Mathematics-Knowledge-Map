##### 题型02求已知函数的极值（点）
##### 【典例1】（2023上·陕西渭南·高三校考阶段练习）已知函数$f ( x ) = x \ln x$．
(1)求曲线在点$\left( 1 , f ( 1 ) \right)$处的切线方程；
(2)求$f ( x )$的单调区间和极值．
<span class="fake-tag">答案</span>(1)$x - y - 1 = 0$
(2)单调递减区间为$\left( 0 , \frac{1}{e} \right)$，单调递增区间为$\left( \frac{1}{e} , + \infty \right)$；极小值为$- \frac{1}{e}$，无极大值.
<span class="fake-tag">详解</span>（1）$f ( 1 ) = 0$，
$f^{'} ( x ) = 1 + \ln x$，$f^{'} ( 1 ) = 1 + \ln 1 = 1$，
故曲线在点$\left( 1 , f ( 1 ) \right)$处的切线方程为$y = x - 1$，即$x - y - 1 = 0$；
（2）$f ( x ) = x \ln x$的定义域为$( 0 , + \infty )$，
故$f^{'} ( x ) = 1 + \ln x$，
当$x = \frac{1}{e}$时，$f^{'} ( x ) = 0$，
当$0 < x < \frac{1}{e}$时，$f^{'} ( x ) < 0$，当$x > \frac{1}{e}$时，$f^{'} ( x ) > 0$，
故$f ( x ) = x \ln x$的单调递减区间为$\left( 0 , \frac{1}{e} \right)$，单调递增区间为$\left( \frac{1}{e} , + \infty \right)$，
$f ( x )$的极小值为$f \left( \frac{1}{e} \right) = \frac{1}{e} \ln \frac{1}{e} = - \frac{1}{e}$，无极大值.
##### 【典例2】（2023上·四川眉山·高三四川省眉山第一中学校考开学考试）若函数$f ( x ) = \frac{1}{3} x^{3} - b x + 4$，为函数$f ( x )$的极值点.
(1)求$b$的值；
(2)求函数的极值.
<span class="fake-tag">答案</span>(1)$4$
(2)$f ( x )$的极小值为$- \frac{4}{3}$，$f ( x )$的极大值为$\frac{28}{3}$
<span class="fake-tag">详解</span>（1）因为$f ( x ) = \frac{1}{3} x^{3} - b x + 4$，所以$f^{'} ( x ) = x^{2} - b$.
因为是$f ( x )$的一个极值点，所以$f^{'} ( 2 ) = 0$，即$2^{2} - b = 0$，则，
当时，$f^{'} ( x ) = x^{2} - 4 = ( x + 2 ) ( x - 2 )$，
令$f^{'} ( x ) > 0$，得$x < - 2$或$x > 2$；令$f^{'} ( x ) < 0$，得$- 2 < x < 2$；
所以$f ( x )$在$( - \infty , - 2 ) , ( 2 , + \infty )$上单调递增，在$( - 2 , 2 )$上单调递减，
所以是$f ( x )$的极小值点，满足题意，故.
（2）由（1）知$f ( x ) = \frac{1}{3} x^{3} - 4 x + 4$，且是$f ( x )$的极小值点，$x = - 2$是$f ( x )$的极大值点，
所以$f ( x )$的极小值为$f ( 2 ) = \frac{1}{3} \times 2^{3} - 4 \times 2 + 4 = - \frac{4}{3}$，$f ( x )$的极大值为$f ( - 2 ) = \frac{1}{3} \times ( - 2 )^{3} - 4 \times ( - 2 ) + 4 = \frac{28}{3}$.
##### 【变式1】（2023·海南省直辖县级单位·校考模拟预测）已知函数$f ( x ) = x^{2} - 4 \ln x + 1$．
(1)求曲线在$\left( 1 , f ( 1 ) \right)$处的切线方程；
(2)求$f ( x )$的单调区间与极值．
<span class="fake-tag">答案</span>(1)$2 x + y - 4 = 0$

<span class="fake-tag">详解</span>（1）依题意，$f^{'} ( x ) = 2 x - \frac{4}{x}$，$x > 0$．
$f^{'} ( 1 ) = 2 \times 1 - \frac{4}{1} = - 2$，$f ( 1 ) = 1 - 4 \text{ln} 1 + 1 = 2$，
故所求切线方程为$y - 2 = - 2 ( x - 1 )$，即$2 x + y - 4 = 0$．
（2）令$f^{'} ( x ) = 0$，解得，
故当$x \in \left( 0 , \sqrt{2} \right)$时，$f^{'} ( x ) < 0$，当$x \in \left( \sqrt{2} , + \infty \right)$时，$f^{'} ( x ) > 0$，
故$f ( x )$的单调递减区间为$\left( 0 , \sqrt{2} \right)$，单调递增区间为$\left( \sqrt{2} , + \infty \right)$，
则$f ( x )$的极小值为$f \left( \sqrt{2} \right) = 3 - 2 \text{ln} 2$，无极大值．
##### 【变式2】（2023下·重庆江北·高二重庆十八中校考期中）已知$x = 0$是函数$f ( x ) = x^{2} ( x - k )$的极小值点．
(1)求实数$k$的取值范围；
(2)求$f ( x )$的极大值．
<span class="fake-tag">答案</span>(1)$( - \infty , 0 )$
(2)$- \frac{4 k^{3}}{27}$
<span class="fake-tag">详解</span>（1）因为$f^{'} ( x ) = 2 x ( x - k ) + x^{2} = x ( 3 x - 2 k )$，
令$f^{'} ( x ) = 0$，解得$x = 0$或$x = \frac{2 k}{3}$，
当$\frac{2 k}{3} = 0$，即$k = 0$时，$f ( x ) = x^{3}$在$R$上单调递增，无极值点，不合题意；
当$\frac{2 k}{3} > 0$，即$k > 0$时，令$f^{'} ( x ) > 0$，解得$x < 0$或$x > \frac{2 k}{3}$；令$f^{'} ( x ) < 0$，解得$0 < x < \frac{2 k}{3}$；
则$f ( x )$在$( - \infty , 0 )$，$\left( \frac{2 k}{3} , + \infty \right)$上单调递增，在$\left( 0 , \frac{2 k}{3} \right)$上单调递减，
所以$x = 0$是函数$f ( x )$的极大值点，不合题意；
当$\frac{2 k}{3} < 0$，即$k < 0$时，令$f^{'} ( x ) > 0$，解得$x > 0$或$x < \frac{2 k}{3}$；令$f^{'} ( x ) < 0$，解得$\frac{2 k}{3} < x < 0$；
则$f ( x )$在$\left( - \infty , \frac{2 k}{3} \right)$，$( 0 , + \infty )$上单调递增，在$\left( \frac{2 k}{3} , 0 \right)$上单调递减，
所以$x = 0$是函数$f ( x )$的极小值点，符合题意；
综上所述：实数$k$的取值范围$( - \infty , 0 )$.
（2）由（1）可知：$f ( x )$在$\left( - \infty , \frac{2 k}{3} \right)$，$( 0 , + \infty )$上单调递增，在$\left( \frac{2 k}{3} , 0 \right)$上单调递减，
所以$f ( x )$的极大值为$f \left( \frac{2 k}{3} \right) = - \frac{4 k^{3}}{27}$.
