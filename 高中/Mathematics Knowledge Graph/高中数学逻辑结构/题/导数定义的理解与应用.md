<span class="fake-tag">详解</span>$\lim_{x \rightarrow 0} \frac{f ( 1 - 2 x ) - f ( 1 )}{4 x} = - 1$，故$k = f^{'} ( 1 ) = \lim_{x \rightarrow 0} \frac{f ( 1 - 2 x ) - f ( 1 )}{- 2 x} = 2$.
