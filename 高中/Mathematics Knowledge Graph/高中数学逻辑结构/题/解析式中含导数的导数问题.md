##### 题型03解析式中含$\mathbf{f}^{\mathbf{'}} \mathbf{(} \mathbf{x}_{\mathbf{0}} \mathbf{)}$的导数问题
##### 【典例1】（2022下·吉林长春·高二统考期中）若$f ( x ) = 2 x f^{'} ( 1 ) + x^{2}$，则$f^{'} ( 0 )$等于（ ）
$\quad$A．2 
$\quad$B．0 
$\quad$C．-2 
$\quad$D．-4
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>因为$f ( x ) = 2 x f^{'} ( 1 ) + x^{2}$，所以$f^{'} ( x ) = 2 f^{'} ( 1 ) + 2 x$
所以$f^{'} ( 1 ) = 2 f^{'} ( 1 ) + 2$，得$f^{'} ( 1 ) = - 2$
所以$f^{'} ( x ) = - 4 + 2 x$，所以$f^{'} ( 0 ) = - 4$
故选：D
##### 【典例2】（2022下·山东·高二校联考阶段练习）已知函数$f ( x ) = x^{3} + \frac{f^{'} ( 1 )}{4} x^{2} + x - 1$，$f^{'} ( x )$是$f ( x )$的导函数，则$f ( 1 ) + f^{'} ( 2 ) =$ ．
<span class="fake-tag">答案</span>24
<span class="fake-tag">详解</span>因为$f ( x ) = x^{3} + \frac{f^{'} ( 1 )}{4} x^{2} + x - 1$，所以$f^{'} ( x ) = 3 x^{2} + \frac{f^{'} ( 1 )}{2} x + 1$，所以$f^{'} ( 1 ) = 4 + \frac{f^{'} ( 1 )}{2}$，即$f^{'} ( 1 ) = 8$，
$f ( 1 ) = 1 + \frac{f^{'} ( 1 )}{4} + 1 - 1 = 3$，$f^{'} ( 2 ) = 1 2 + \frac{f^{'} ( 1 )}{2} \times 2 + 1 = 2 1$，
故$f ( 1 ) + f^{'} ( 2 ) = 3 + 2 1 = 2 4$．
故答案为：$24$
