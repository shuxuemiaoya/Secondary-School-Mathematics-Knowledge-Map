##### 【典例1】（2022下·湖北·高二统考期末）函数$f ( x ) = \frac{1}{2} x^{2} - \ln x$的单调递减区间为（ ）
$\quad$A．$( - 1 , 1 )$ 
$\quad$B． 
$\quad$C．$( 1 , + \infty )$ 
$\quad$D．$( 0 , + \infty )$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>解：因为$f ( x ) = \frac{1}{2} x^{2} - \ln x$，
所以$f^{'} ( x ) = x - \frac{1}{x} = \frac{( x - 1 ) ( x + 1 )}{x}$，
令$f^{'} ( x ) < 0$，得$0 < x < 1$，
所以$f ( x )$的单调递减区间为，
故选：B
##### 【典例2】（2023下·河北沧州·高二校考阶段练习）函数$f ( x ) = 2 x - 5 \ln x - 4$的单调递减区间是（ ）
$\quad$A．$( 0 , 3 )$ 
$\quad$B．$( 3 , + \infty )$ 
$\quad$C．$\left( - \infty , \frac{5}{2} \right)$ 
$\quad$D．$\left( 0 , \frac{5}{2} \right)$
<span class="fake-tag">答案</span>D
