### 方法2：转化为三角函数法
##### 【26】在  $\triangle ABC$  中， $A, B, C$  的对边分别为  $a, b, c$ ，且满足  $2c\sin B = (2a + c)\tan C$ 。
（1）求  $B$  
（2）若  $b = \sqrt{3}$ ，求  $a + 2c$  的取值范围
##### 【27】在  $\triangle ABC$  中，角  $A, B, C$  的对边分别为  $a, b, c$  且  $a \sin A - c \sin C = (b - c) \sin B$ .
（1）求  $A$  的大小；  
（2）若  $\triangle ABC$  为锐角三角形，求  $\frac{b}{c}$  的取值范围
##### 【28】在  $\triangle ABC$  中，内角  $A, B, C$  的对边分别为  $a, b, c$ ，已知角  $A$  为锐角， $\triangle ABC$  的面积为  $S$ ，且  $a^2 = 4\sqrt{3} S$ 。
（1）若  $a\cos B + b\sin A = c$  ，求  $A$  
（2）求  $\frac{b}{c} +\frac{c}{b}$  的最大值.
##### 【29】锐角  $\triangle ABC$  中, 角  $A, B, C$  所对边的长分别为  $a, b, c$ ,  $a \sin \frac{A + C}{5} = b \sin A$ .
（1）求  $B$  的大小；  
（2）若  $2c\cos A + 2a\cos C = ab$ ，求  $b$  的取值范围
##### 【32】 $\triangle ABC$  的内角  $A, B, C$  的对边分别为  $a, b, c$ ，已知  $2 \cos C (a \cos B + b \cos A) = c$ 。
（1）求  $C$  
（2）求  $\sin A + \sin B$  的取值范围
##### 【30】在  $\triangle ABC$  中，角  $A, B, C$  所对的边分别是  $a, b, c$ . 已知  $\frac{2\cos A}{bc} = \frac{\cos B}{ab} + \frac{\cos C}{ac}$ .
（1）求  $A$  
（2）若  $a = \sqrt{3}$  ，且  $c > a$  ，求  $b + c$  的取值范围
##### 【33】锐角  $\triangle ABC$  的内角  $A, B, C$  的对边分别为  $a, b, c$ ，且  $\frac{2c - b}{a} = \frac{\cos B}{\cos A}$ 。
（1）求  $A$  
（2）求  $\cos B + \cos C$  的取值范围
