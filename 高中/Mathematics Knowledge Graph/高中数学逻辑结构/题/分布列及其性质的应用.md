##### 题型02 分布列及其性质的应用
##### 【典例1】（2024·全国·高三专题练习）设某种疫苗试验的失败率是成功率的5倍，用随机变量*X*去描述1次试验的成功次数，则$P ( X = 0 )$等于（ ）
$\quad$A．0 
$\quad$B．$\frac{1}{6}$
$\quad$C．$\frac{5}{6}$
$\quad$D．1
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>解：根据题意得，“$X = 0$”表示试验失败，
“$X = 1$”表示试验成功，成功率为*p*，失败率为5*p*，
故*X*的分布列为：

|X|0|1|
|---|---|---|
|P|5p|p|
所以$5 p + p = 1$，得$p = \frac{1}{6}$，
所以失败率为$\frac{5}{6}$，即$P ( X = 0 ) = \frac{5}{6}$．
故选：C.
##### 【典例2】（2024下·全国·高二随堂练习）随机变量*ξ*的分布列如下：
| ξ   | x₁  | 0   | 1   |
| --- | --- | --- | --- |
| P   | a   | b   | c   |
其中$2 b = a + c$，则$P ( | \xi | = 1 )$等于（ ）
$\quad$A． 
$\quad$B．$\frac{1}{4}$
$\quad$C．$\frac{1}{2}$
$\quad$D．
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>$\because 2 b = a + c$，且$a + b + c = 1$，
解得$b = \frac{1}{3}$，
$\therefore P ( | \xi | = 1 ) = P ( \xi = - 1 ) + P ( \xi = 1 ) = a + c = 2 b = \frac{2}{3}$.
故选：D.

|$X$| 1   | 2     | 3   | 4       |
| ----- | --- | ----- | --- | ------- |
|$P$| 0.1 |$m$| 0.3 |$2 m$|

##### 【典例4】（2024·全国·高二假期作业）已知离散型随机变量*X*的分布列如表所示，则*m*的值为 .
|$X$| 0   | 1   | 2                   | 3           |

##### 【变式2】（多选）（2024·全国·高二假期作业）已知随机变量*X*的分布列为$P ( X = n ) = \frac{a}{( n + 1 ) ( n + 2 )}$（$n = 0 , 1 , 2$），其中$a$是常数，则（ ）
$\quad$A．$P ( X = 0 ) + P ( X = 1 ) + P ( X = 2 ) = 1$
$\quad$B．$a = \frac{4}{3}$
$\quad$C．$P ( 0 \leq X < 2 ) = \frac{8}{9}$
$\quad$D．以上均不正确
<span class="fake-tag">答案</span>ABC
<span class="fake-tag">详解</span>根据题意，随机变量$X$的分布列为$P ( X = n ) = \frac{a}{( n + 1 ) ( n + 2 )}$，
则$P ( X = 0 ) + P ( X = 1 ) + P ( X = 2 ) = \frac{a}{2} + \frac{a}{6} + \frac{a}{12} = 1$，解得$a = \frac{4}{3}$，
则$P ( 0 \leq X < 2 ) = P ( X = 0 ) + P ( X = 1 ) = \frac{2}{3} + \frac{2}{9} = \frac{8}{9}$.
故选：ABC.

<span class="fake-tag">详解</span>$\because P ( X = n ) = \frac{a}{n ( n + 1 )} ( n = 1 , 2 , 3 , 4 )$，$\therefore \frac{a}{2} + \frac{a}{6} + \frac{a}{12} + \frac{a}{20} = 1$，解得：$a = \frac{5}{4}$，
