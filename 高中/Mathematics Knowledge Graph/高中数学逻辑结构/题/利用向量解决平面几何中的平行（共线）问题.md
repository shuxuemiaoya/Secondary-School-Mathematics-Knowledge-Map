##### 题型01 利用向量解决平面几何中的平行（共线）问题
##### 【典例1】（2023·全国·高三专题练习）在四边形$A B C D$中，若$\overrightarrow{A C} = \overrightarrow{A B} + \overrightarrow{A D}$，且，则四边形$A B C D$是（ ）
$\quad$A．矩形 
$\quad$B．等腰梯形
$\quad$C．正方形 
$\quad$D．菱形
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>因为$\overrightarrow{A C} = \overrightarrow{A B} + \overrightarrow{A D}$，可得$\overrightarrow{A B} + \overrightarrow{B C} = \overrightarrow{A B} + \overrightarrow{A D}$，所以$\overrightarrow{B C} = \overrightarrow{A D}$，
即$B C / / A D$且，所以四边形$A B C D$为平行四边形，
又由，可得四边形$A B C D$的对角线互相垂直，
所以四边形$A B C D$为菱形.
故选：D.
##### 【典例2】（2023·全国·高一随堂练习）如图，在四边形*ABCD*中，点*E*，*F*，*G*，*H*分别为*BD*，*AB*，*AC*和*CD*的中点.求证：四边形*EFGH*为平行四边形.

<span class="fake-tag">答案</span>证明见解析
<span class="fake-tag">详解</span>因为点*E*，*F*，*G*，*H*分别为*BD*，*AB*，*AC*和*CD*的中点，
所以$\overrightarrow{F E} = \frac{1}{2} \overrightarrow{A D} , \overrightarrow{G H} = \frac{1}{2} \overrightarrow{A D} ,$
所以$\overrightarrow{F E} = \overrightarrow{G H}$，
又因为$F E$与$G H$不共线，所以$F E \text{//} G H$，且$F E = G H$，
所以四边形*EFGH*为平行四边形.
##### 【变式1】（2023上·山东泰安·高二校考开学考试）在四边形$A B C D$中，，则四边形$A B C D$的形状是 .
<span class="fake-tag">答案</span>矩形
<span class="fake-tag">详解</span>由$\overrightarrow{A B} \cdot \overrightarrow{B C} = 0 ,$可知$\overrightarrow{A B} \bot \overrightarrow{B C}$,进而$A B \bot B C$，
由$\overrightarrow{B C} = \overrightarrow{A D}$可得且$B C / / A D$，所以四边形为矩形，
故答案为：矩形
