##### 【典例2】（25-26高一上·全国·课后作业）已知$\text{sin} \alpha = \frac{2 m - 5}{m + 1} , \text{cos} \alpha = - \frac{m}{m + 1}$，且$\alpha$为第三象限角，则$\text{tan} \alpha =$ ．
<span class="fake-tag">答案</span>$\frac{4}{3}$/$1 \frac{1}{3}$
<span class="fake-tag">分析</span>由同角三角函数关系求出$m$并检验，结合商数关系即可求解.
<span class="fake-tag">详解</span>$\because \text{sin} \alpha = \frac{2 m - 5}{m + 1} , \text{cos} \alpha = - \frac{m}{m + 1}$，
$\therefore$由$\text{si} \text{n}^{2} \alpha + \text{co} \text{s}^{2} \alpha = 1$，可得$\left( \frac{2 m - 5}{m + 1} \right)^{2} + \left( - \frac{m}{m + 1} \right)^{2} = 1$，解得$m = 4$或$m = \frac{3}{2}$．
又$\because \alpha$为第三象限角，$\therefore \text{sin} \alpha < 0 , \text{cos} \alpha < 0$，把$m$的值代入检验得$m = \frac{3}{2}$，

故答案为：$\frac{4}{3}$.
