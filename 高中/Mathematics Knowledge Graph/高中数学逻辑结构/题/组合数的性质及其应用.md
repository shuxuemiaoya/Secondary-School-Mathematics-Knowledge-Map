##### 题型04 组合数的性质及其应用
##### 【典例1】（2023下·甘肃白银·高二统考开学考试）$C_{6}^{2} + C_{6}^{3} + C_{7}^{4} + C_{8}^{5} + C_{9}^{6} =$（ ）
$\quad$A．84 
$\quad$B．120 
$\quad$C．126 
$\quad$D．210
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>因为$C_{n}^{m - 1} + C_{n}^{m} = C_{n + 1}^{m}$，
所以$C_{6}^{2} + C_{6}^{3} + C_{7}^{4} + C_{8}^{5} + C_{9}^{6} = C_{7}^{3} + C_{7}^{4} + C_{8}^{5} + C_{9}^{6} = C_{8}^{4} + C_{8}^{5} + C_{9}^{6} = C_{9}^{5} + C_{9}^{6} = C_{10}^{6} = 2 1 0$．
故选：D

##### 【典例3】（多选）（2023下·江苏南京·高二南京师大附中校考期中）若$C_{8}^{2 x - 1} = C_{7}^{x - 1} + C_{7}^{x}$，则正整数$x$的值是（ ）
$\quad$A．$1$ 
$\quad$B．$2$ 
$\quad$C．$3$ 
$\quad$D．$4$
<span class="fake-tag">答案</span>AC
<span class="fake-tag">详解</span>因为$C_{7}^{x - 1} + C_{7}^{x} = C_{8}^{x}$，所以$C_{8}^{2 x - 1} = C_{8}^{x}$，即$2 x - 1 = x$或$2 x - 1 + x = 8$，
解得$x = 1$或3，经检验均满足要求.
故选：AC
##### 【典例4】（2023下·河北邢台·高二邢台一中校考阶段练习）若$C_{20}^{2 n + 6} = C_{20}^{n + 2}$（$n \in N^{*}$），则$n =$ .
<span class="fake-tag">答案</span>4
<span class="fake-tag">详解</span>由题意可知$2 n + 6 = 2 0 - ( n + 2 )$，解得$n = 4$，
或$2 n + 6 = n + 2$，解得$n = - 4$，舍去，
综上：$n = 4$.
故答案为：4
##### 【变式1】（2023下·江苏徐州·高二徐州高级中学校考期中）若$C_{n + 1}^{6} - C_{n}^{6} = C_{n}^{7}$，则$n$的值为（ ）
$\quad$A．10 
$\quad$B．11 
$\quad$C．12 
$\quad$D．13
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>若$C_{n + 1}^{6} - C_{n}^{6} = C_{n}^{7}$，则$C_{n + 1}^{6} = C_{n}^{6} + C_{n}^{7} = C_{n + 1}^{7}$，
所以$n + 1 = 6 + 7 = 1 3$,解得$n = 1 2$.
故选:C.
##### 【变式2】（多选）（2023下·山西运城·高二统考期中）若$C_{21}^{m + 2} = C_{21}^{2 m - 5}$，则$m$的值可以是（ ）
$\quad$A．6 
$\quad$B．7 
$\quad$C．8 
$\quad$D．9
<span class="fake-tag">答案</span>BC
