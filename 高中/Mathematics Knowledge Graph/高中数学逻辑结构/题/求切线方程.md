##### 题型05 求切线方程
##### 【典例1】（2023下·湖南长沙·高二长沙市长郡梅溪湖中学校考期中）设$f ( x )$为R上的可导函数，且$\lim_{\Delta x \rightarrow 0} \frac{f ( 1 ) - f ( 1 + 2 \Delta x )}{\Delta x} = \frac{1}{2}$，则曲线在点$\left( 1 , f ( 1 ) \right)$处的切线斜率为 .
<span class="fake-tag">答案</span>$- \frac{1}{4}$/$- 0 . 2 5$
<span class="fake-tag">详解</span>由已知可得$f^{'} ( 1 ) = \lim_{\Delta x \rightarrow 0} \frac{f ( 1 ) - f ( 1 + 2 \Delta x )}{- 2 \Delta x} = - \frac{1}{2} \lim_{\Delta x \rightarrow 0} \frac{f ( 1 ) - f ( 1 + 2 \Delta x )}{\Delta x} = - \frac{1}{4}$.
根据导数的几何意义可知，曲线在点$\left( 1 , f ( 1 ) \right)$处的切线斜率为$- \frac{1}{4}$.
故答案为：$- \frac{1}{4}$.

##### 题型06求切线方程（过型）
##### 【典例1】（2023下·山东威海·高二统考期末）写出曲线$y = ( 2 x + 1 ) e^{x}$过坐标原点的一条切线方程 .

故切线方程为$y - ( 2 t + 1 ) e^{t} = ( 2 t + 3 ) \cdot e^{t} ( x - t )$，
由于切线过原点，故$0 - ( 2 t + 1 ) e^{t} = ( 2 t + 3 ) \cdot e^{t} ( 0 - t )$，

故答案为：$y = 4 \sqrt{e} x$或$y = \frac{1}{e} x$（任写一个即可）
