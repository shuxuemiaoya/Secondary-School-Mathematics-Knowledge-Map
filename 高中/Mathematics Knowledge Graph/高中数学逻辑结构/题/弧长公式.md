##### 【典例1】（23-24高一下·辽宁沈阳·阶段练习）在单位圆中，长度为的弦所对的劣弧长是（ ）
$\quad$A．$\frac{\mathbf{2} \mathbf{\pi}}{\mathbf{3}}$ B．$\frac{\mathbf{\pi}}{\mathbf{3}}$ C．$\frac{\mathbf{\pi}}{\mathbf{6}}$ D．
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>由单位圆中的弦长，求出弦所对的劣弧的圆心角，可求弧长.
<span class="fake-tag">详解</span>单位圆$O$中，弦$A B$长度为为$A B$中点，

则有$O C \bot A B , B C = \frac{\sqrt{3}}{2} , \text{sin} \angle B O C = \frac{B C}{B O} = \frac{\sqrt{3}}{2}$，
由$0 < \angle B O C < \frac{\pi}{2}$，得$\angle B O C = \frac{\pi}{3}$，

##### 【典例2】（24-25高一·上海·随堂练习）已知一扇形的圆心角为$\mathbf{\alpha}$，半径为，弧长为$\mathbf{l}$．

(2)已知扇形的周长为$\mathbf{10} \text{cm}$，面积是，求扇形的圆心角．
