##### 【变式4】（2023·贵州六盘水·统考模拟预测）在$\bigtriangleup A B C$中，角*A*，*B*，*C*的对边分别是*a*，*b*，*c*，且$b \cos A + \sqrt{3} b \sin A = a + c$.

(2)若$\bigtriangleup A B C$的中线*BD*长为$2 \sqrt{3}$，求$a + c$的最大值.
<span class="fake-tag">答案</span>(1)$B = \frac{\pi}{3}$
(2)8
<span class="fake-tag">详解</span>（1）因为$b \cos A + \sqrt{3} b \sin A = a + c$，
所以$\sin B \cos A + \sqrt{3} \sin B \sin A = \sin A + \sin C$，
又$C = \pi - ( A + B )$，
所以$\sin C = \sin \left\lbrack \pi - ( A + B ) \right\rbrack = \sin ( A + B ) = \sin A \cos B + \cos A \sin B$，
所以$\sin B \cos A + \sqrt{3} \sin B \sin A = \sin A + \sin A \cos B + \cos A \sin B$，
整理得$\sin A \left( \sqrt{3} \sin B - \cos B \right) = \sin A$，
因为$A \in ( 0 , \pi ) , \sin A > 0$，所以$\sqrt{3} \sin B - \cos B = 1$，即$2 \sin \left( B - \frac{\pi}{6} \right) = 1$，

（2）因为*D*为*AC*中点，
