##### 题型07三角函数的对称性
##### 【典例1】（23-24高一下·江苏常州·期中）已知函数$f ( x ) = \sin ( \omega x + \varphi ) ( \omega > 0 , 0 < \varphi < \pi )$的图象关于点$\left( \frac{2 \pi}{3} , 0 \right)$对称，且$f ( 0 ) = \frac{\sqrt{3}}{2}$，则$\omega$的最小值为 ．
<span class="fake-tag">答案</span>$\frac{1}{2}$/$0 . 5$
<span class="fake-tag">分析</span>由$f ( 0 ) = \frac{\sqrt{3}}{2}$及$0 < \varphi < \pi$得，$\varphi = \frac{\pi}{3}$或$\frac{\text{2π}}{3}$，结合的图象关于点$( \frac{2 \pi}{3} , 0 )$对称，即可求出$\omega$的最小值．
<span class="fake-tag">详解</span>由的图象关于点$( \frac{2 \pi}{3} , 0 )$对称，得$\frac{\text{2} \text{π}}{3} \omega + \varphi = k \pi , k \in Z$，
由$f ( 0 ) = \frac{\sqrt{3}}{2}$及$0 < \varphi < \pi$得，$\varphi = \frac{\pi}{3}$或$\frac{\text{2} \text{π}}{3}$，
当$\varphi = \frac{\pi}{3}$时，$\omega = \frac{3 k - 1}{2} , k \in Z$，由$\omega > 0$得$\omega$的最小值为$1$；
当$\varphi = \frac{\text{2π}}{3}$时，$\omega = \frac{3 k - 2}{2} , k \in Z$，由$\omega > 0$得$\omega$的最小值为$\frac{1}{2}$；
综上所述，$\omega$的最小值为$\frac{1}{2}$；
故答案为：$\frac{1}{2}$．
##### 【典例2】（2024高三·全国·专题练习）已知函数$f ( x ) = 2 \cos ( 3 x + \varphi )$的图象关于点$\left( \frac{4 \pi}{3} , 0 \right)$对称，那么$| \varphi |$的最小值为 ．

<span class="fake-tag">分析</span>根据余弦函数图像的性质，代入对称中心，$3 \times \frac{4 \pi}{3} + \varphi = k \pi + \frac{\pi}{2} , k \in \mathbf{Z}$求得$\varphi = k \pi - \frac{7 \pi}{2} , k \in \mathbf{Z}$，由此$| \varphi |$最小值即可求解.
<span class="fake-tag">详解</span>$\because f ( x ) = 2 \text{cos} ( 3 x + \varphi )$的图象关于点$\left( \frac{4 \pi}{3} , 0 \right)$对称，

令$k = 4$，可得$| \varphi |$的最小值为$\frac{\pi}{2}$．
故答案为：$\frac{\pi}{2}$
