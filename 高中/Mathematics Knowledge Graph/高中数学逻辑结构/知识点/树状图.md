### 一、定义
用“分叉”的方式，分步骤列举所有等可能结果，解决概率与计数问题。

### 二、画法口诀
> 分层画叉，每枝分叉，路径读完，结果不差。

1. 第一层：写出第一步所有可能结果。
2. 第二层：第一层每枝分别画出第二步的所有可能结果。
3. 重复直到步骤结束。
4. 从根到叶每一条路径 = 一个等可能结果。

### 三、经典例题

> [!example]- 例1：放回（两步）
> 盒中有2红1白，有放回摸两次，求两次颜色相同概率。

```
       ┌─ 红 ─┬─ 红 = (红,红)
       │      └─ 白 = (红,白)
开始 ─┤
       │      ┌─ 红 = (白,红)
       └─ 白 ─┴─ 白 = (白,白)
```
总结果：3×3=9种；颜色相同： (红,红)+(白,白)
- (红,红)含4种（按球编号），(白,白)含1种
- 法一：P = (4+1)/9 = 5/9
- 法二（按颜色概率）：(2/3)×(2/3)+(1/3)×(1/3)=5/9

> [!example]- 例2：不放回（两步）
> 同上球，不放回摸两次，求颜色相同概率。

```
       ┌─ 红 ─┬─ 红 (另一红) = (红,红)
       │      └─ 白         = (红,白)
开始 ─┤
       └─ 白 ── 红 (两红之一) = (白,红)
```
总结果：3×2=6种；颜色相同： (红,红) 含2种
- P = 2/6 = 1/3

> [!example]- 例3：三步
> 抛三枚硬币，求恰好两枚正面朝上的概率。

```
                    ┌─ 正 → 正正正
           ┌─ 正 ──┤
           │       └─ 反 → 正正反
  ┌─ 正 ──┤
  │       │       ┌─ 正 → 正反正
  │       └─ 反 ──┤
  │               └─ 反 → 正反反
开始
  │               ┌─ 正 → 反正正
  │       ┌─ 正 ──┤
  │       │       └─ 反 → 反正反
  └─ 反 ──┤
          │       ┌─ 正 → 反反正
          └─ 反 ──┤
                  └─ 反 → 反反反
```
总结果：2³=8种；两正： (正正反)(正反正)(反正正) → 3种
- P = 3/8

### 四、列表法与树状图对比（速查）

|          | 列表法     | 树状图       |
|----------|------------|--------------|
| 两步     | 方便       | 也方便       |
| 三步以上 | 不方便     | 优势明显     |
| 不放回   | 需调整表格 | 分支递减自然 |

### 五、易错点（学生常错）

1. 分支数：不放回时每步分支数递减，别忘减。
2. 路径：一条路径读完才算一个结果，不能跨枝组合。
3. 等可能：画图前确保每步各分支机会相同。
4. 有序性：树状图默认按步骤顺序，(红,白) ≠ (白,红)。

### 六、课堂一句话总结

> 画树状图分步列结果，数出路径总数，符合条件数除以总数得概率。
