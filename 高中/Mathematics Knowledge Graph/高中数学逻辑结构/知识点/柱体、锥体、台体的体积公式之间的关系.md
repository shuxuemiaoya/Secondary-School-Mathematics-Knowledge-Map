# 圆柱、圆锥、圆台的体积公式及其统一

## 公式
设下底面半径 $r$，上底面半径 $r'$，高 $h$。

圆柱：
$V_{\text{柱}} = \pi r^2 h$

圆锥：
$V_{\text{锥}} = \frac{1}{3} \pi r^2 h$

圆台：
$V_{\text{台}} = \frac{1}{3} \pi h (r'^2 + r'r + r^2)$

## 统一关系

圆台公式是通用形式，圆柱和圆锥是其特例。

### 圆台 → 圆柱
当 $r' = r$ 时：
$V_{\text{台}} = \frac{1}{3} \pi h (r^2 + r \cdot r + r^2) = \frac{1}{3} \pi h (3r^2) = \pi r^2 h = V_{\text{柱}}$

### 圆台 → 圆锥
当 $r' = 0$ 时：
$V_{\text{台}} = \frac{1}{3} \pi h (0 + 0 + r^2) = \frac{1}{3} \pi r^2 h = V_{\text{锥}}$

## 与棱体体积公式的类比

| 几何体 |                    棱体公式                    |                    旋转体公式                    |
| :-: | :----------------------------------------: | :-----------------------------------------: |
| 柱体  |                 $V = Sh$                  |              $V = \pi r^2 h$               |
| 锥体  |           $V = \frac{1}{3} Sh$            |        $V = \frac{1}{3} \pi r^2 h$         |
| 台体  | $V = \frac{1}{3} h (S' + \sqrt{S'S} + S)$ | $V = \frac{1}{3} \pi h (r'^2 + r'r + r^2)$ |

其中 $S = \pi r^2$，$S' = \pi r'^2$，则 $\sqrt{S'S} = \pi r' r$，完全对应。

# 柱体、锥体、台体的统一体积公式

## 统一公式

对于任意台体（棱台或圆台），设上底面积 $S'$，下底面积 $S$，高 $h$，体积公式为：
$V_{\text{台}} = \frac{1}{3} h \left( S' + \sqrt{S'S} + S \right)$

柱体和锥体的体积均可作为台体公式的特例：

- 柱体：$S' = S$ 时  
$  V = \frac{1}{3}h (S + S + S) = Sh
$

- 锥体：$S' = 0$ 时  
$
  V = \frac{1}{3}h (0 + 0 + S) = \frac{1}{3}Sh
$
因此，台体体积公式是柱体和锥体体积公式的统一表达。

## 柱体、锥体、台体体积公式之间的关系

从几何结构上看，三者通过上底面的变化连续过渡：

- 锥体：上底面缩为一个点（$S' = 0$）
- 台体：上底面介于 0 和下底面之间（$0 < S' < S$）
- 柱体：上底面扩大到与下底面全等（$S' = S$）

演变过程：
锥体 →（用平行于底面的平面截去顶部）→ 台体 →（上底面继续扩大）→ 柱体

数学上，固定下底面 $S$ 和高 $h$，体积 $V$ 是关于上底面积 $S'$ 的连续函数：$
V(S') = \frac{1}{3}h \left( S' + \sqrt{S'S} + S \right)
$
当 $S'$ 从 $0$ 增大到 $S$ 时，$V$ 从 $\frac{1}{3}Sh$ 连续增大到 $Sh$，完美衔接锥体和柱体。

## 总结

- 一个通用公式：$V = \frac{1}{3}h(S' + \sqrt{S'S} + S)$ 统一了柱体、锥体、台体的体积计算。
- 两个特例：$S' = S$ 得柱体；$S' = 0$ 得锥体。
- 几何本质：三个公式的差异仅源于上底面的大小，反映了从“尖顶”到“平顶”的连续变化。
