北宋的数学家沈括博学多才、善于观察，据说有一天，他走进一家酒馆，看见一层层垒起的酒坛，不禁想到：“怎么求这些酒坛的总数呢？”沈括“用鸟童（长方台）法求之，常失于数少”，他想堆积的酒坛、棋子等虽然看

起来像实体,但中间是有空隙的,应该把它们看成离散的量。经过反复尝试,沈括提出对于上底有  $ab$  个,下底有  $cd$  个,共  $n$  层的堆积物(图1),可以用公式  $S = \frac{n}{6} [(2b + d)a + (b + 2d)c] + \frac{n}{6} (c - a)$  求出物体的总数。这就是所谓的"隙积术",相当于求数列  $ab$ ,  $(a + 1)(b + 1)$ ,  $(a + 2)(b + 2)$ ,  $\dots$ ,  $(a + n - 1)(b + n - 1) = cd$  的和。然而,"隙积术"的意义并不在于提出了二阶等差数列的一个求和公式,而在于发展了自《九章算术》以来对等差数列问题的研究,开创了我国"垛积术"的研究。<center><img src="MathLogic%20Weave/高中数学逻辑结构/知识点/Attachments/494f6afa33bba9b2e9cd364b103691305ee988c7cb7749dbfdb0da428f7ca9a7.jpg" style="max-width:100%;"></center><center>图1</center><center><img src="MathLogic%20Weave/高中数学逻辑结构/知识点/Attachments/a331f973e0b52470454299660d601a6183a6ee30b43bf8ae48bbe277841af76a.jpg" style="max-width:100%;"></center><center>图2</center>

南宋的数学家杨辉"善于把已知形状、大小的几何图形的求面积、体积的连续量问题转化为求离散量的垛积问题"。例如,求图2"圭垛"中的格点个数总和,杨辉认为虽然圭垛的形状与三角形相似,但要用梯形的面积公式计算,即  $S_{7} = \frac{(1 + 7)\times 7}{2} = 28$ 。在他的专著《详解九章算法·商功》中,

杨辉将堆垛与相应立体图形作类比,推导出了三角垛、方垛、当楼垛、当童垛等的公式,例如三角垛指的是顶层放1个,第二层放3个,第三层放6个……第  $n$  层放  $\frac{1}{2} n(n + 1)$  个物体堆成的堆垛,类比图3中的立体图形,杨辉推出了它的求和公式  $S = 1 + 3 + 6 + \dots +\frac{1}{2} n(n + 1) = \frac{1}{6} n(n + 1)(n + 2)$ 。<center><img src="MathLogic%20Weave/高中数学逻辑结构/知识点/Attachments/b429f51998d271b8ea7a40b86dbf67fc30e2410e997989db2ae9a5d4943c8c0c.jpg" style="max-width:100%;"></center><center>图3</center>
