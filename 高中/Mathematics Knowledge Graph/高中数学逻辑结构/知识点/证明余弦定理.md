## 余弦定理

在 $\triangle ABC$ 中，设 $a = BC$，$b = CA$，$c = AB$，则：
$a^2 = b^2 + c^2 - 2bc\cos A$
$b^2 = a^2 + c^2 - 2ac\cos B$
$c^2 = a^2 + b^2 - 2ab\cos C$

下面以证明 $a^2 = b^2 + c^2 - 2bc\cos A$ 为例。

---

### 方法一：向量法（最简洁）

取 $\overrightarrow{AB}$ 和 $\overrightarrow{AC}$ 为基底，则：
$\overrightarrow{BC} = \overrightarrow{AC} - \overrightarrow{AB}$

两边平方：
$|\overrightarrow{BC}|^2 = |\overrightarrow{AC} - \overrightarrow{AB}|^2 = |\overrightarrow{AC}|^2 + |\overrightarrow{AB}|^2 - 2\overrightarrow{AC} \cdot \overrightarrow{AB}$
即：
$a^2 = b^2 + c^2 - 2bc\cos A$

---

### 方法二：坐标法

如图，以 $A$ 为原点，$AB$ 所在直线为 $x$ 轴建立平面直角坐标系，则：

- $A(0, 0)$
- $B(c, 0)$
- $C(b\cos A, b\sin A)$

则：
$a^2 = |BC|^2 = (b\cos A - c)^2 + (b\sin A - 0)^2$

展开：
$a^2 = b^2\cos^2 A - 2bc\cos A + c^2 + b^2\sin^2 A$

合并 $\cos^2 A + \sin^2 A = 1$：
$a^2 = b^2 + c^2 - 2bc\cos A$

---

### 方法三：几何法（作高线）

过 $B$ 作 $BD \perp AC$ 于 $D$，则：

- $AD = c\cos A$
- $CD = b - c\cos A$
- $BD = c\sin A$

在 $\triangle BCD$ 中，由勾股定理：
$a^2 = BD^2 + CD^2 = (c\sin A)^2 + (b - c\cos A)^2$

展开：
$a^2 = c^2\sin^2 A + b^2 - 2bc\cos A + c^2\cos^2 A$

合并：
$a^2 = b^2 + c^2 - 2bc\cos A$

---

### 方法四：利用勾股定理（分锐角、钝角讨论）

情况1：$\angle A$ 为锐角

过 $C$ 作 $CD \perp AB$ 于 $D$，则：

- $AD = b\cos A$
- $CD = b\sin A$
- $BD = c - b\cos A$

在 $\triangle BCD$ 中：
$a^2 = CD^2 + BD^2 = (b\sin A)^2 + (c - b\cos A)^2 = b^2 + c^2 - 2bc\cos A$

情况2：$\angle A$ 为钝角

过 $C$ 作 $CD \perp AB$ 的延长线于 $D$，则：

- $AD = b\cos(\pi - A) = -b\cos A$
- $CD = b\sin(\pi - A) = b\sin A$
- $BD = c + AD = c - b\cos A$
同样得到：
$a^2 = b^2 + c^2 - 2bc\cos A$

---

### 方法五：利用圆幂定理（托勒密定理）

作 $\triangle ABC$ 的外接圆，设外接圆半径为 $R$，由正弦定理：
$a = 2R\sin A,\quad b = 2R\sin B,\quad c = 2R\sin C$

则：
$a^2 = 4R^2\sin^2 A = 4R^2(1 - \cos^2 A)$

而由三角恒等式 $\cos A = -\cos(B + C)$ 及和角公式展开，结合正弦定理代入，也可推导出余弦定理（过程略繁）。

---

### 总结

余弦定理的证明方法主要有：

| 方法 | 核心思路 |
|------|----------|
| 向量法 | 利用向量减法与数量积 |
| 坐标法 | 建立坐标系，用两点间距离公式 |
| 几何法（作高） | 构造直角三角形，用勾股定理 |
| 分类讨论法 | 分锐角、钝角、直角三种情况 |
| 圆幂定理法 | 结合正弦定理与三角恒等式 |

其中向量法和坐标法最为简洁通用，几何法最直观易懂。
