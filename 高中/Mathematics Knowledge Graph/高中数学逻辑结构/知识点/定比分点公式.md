如图6.3-18，线段 $P_{1}P_{2}$ 的端点 $P_{1}$ ， $P_{2}$ 的坐标分别是 $(x_{1},y_{1})$ ， $(x_{2},y_{2})$ ，点 $P$ 是直线 $P_{1}P_{2}$ 上的一点。当 $\overrightarrow{P_1P} = \lambda \overrightarrow{PP_2}$ 时，点 $P$ 的坐标是什么？<center><img src="MathLogic%20Weave/高中数学逻辑结构/知识点/Attachments/20fcff28ec44948bf2cf7dae23c28def6d8cd720349302e7b64e30e219140843.jpg" style="max-width:100%;"></center><center>图6.3-18</center>

### 方法一：坐标法
设 $P(x, y)$，则：
- $\overrightarrow{P_1P} = (x - x_1, y - y_1)$
- $\overrightarrow{PP_2} = (x_2 - x, y_2 - y)$
由条件 $\overrightarrow{P_1P} = \lambda \overrightarrow{PP_2}$ 得：
$(x - x_1, y - y_1) = \lambda (x_2 - x, y_2 - y)$

分别写出横纵坐标方程：
$\begin{cases}
x - x_1 = \lambda (x_2 - x) \\
y - y_1 = \lambda (y_2 - y)
\end{cases}$
解第一个方程：
$x - x_1 = \lambda x_2 - \lambda x \implies x + \lambda x = x_1 + \lambda x_2 \implies x(1 + \lambda) = x_1 + \lambda x_2$
$\implies x = \frac{x_1 + \lambda x_2}{1 + \lambda}$
同理可得：
$y = \frac{y_1 + \lambda y_2}{1 + \lambda}$
所以点 $P$ 的坐标为：
$P\left( \frac{x_1 + \lambda x_2}{1 + \lambda}, \frac{y_1 + \lambda y_2}{1 + \lambda} \right)$

---

### 方法二：向量线性表示法
由 $\overrightarrow{P_1P} = \lambda \overrightarrow{PP_2}$，我们可以将 $\overrightarrow{OP}$ 用 $\overrightarrow{OP_1}$ 和 $\overrightarrow{OP_2}$ 线性表示。
因为 $\overrightarrow{P_1P} = \overrightarrow{OP} - \overrightarrow{OP_1}$，$\overrightarrow{PP_2} = \overrightarrow{OP_2} - \overrightarrow{OP}$，代入条件：
$\overrightarrow{OP} - \overrightarrow{OP_1} = \lambda (\overrightarrow{OP_2} - \overrightarrow{OP})$

移项：
$\overrightarrow{OP} + \lambda \overrightarrow{OP} = \overrightarrow{OP_1} + \lambda \overrightarrow{OP_2}$
$(1 + \lambda) \overrightarrow{OP} = \overrightarrow{OP_1} + \lambda \overrightarrow{OP_2}$
因为 $\lambda \neq -1$，两边除以 $1 + \lambda$：
$\overrightarrow{OP} = \frac{\overrightarrow{OP_1} + \lambda \overrightarrow{OP_2}}{1 + \lambda}$

代入坐标即得：
$P\left( \frac{x_1 + \lambda x_2}{1 + \lambda}, \frac{y_1 + \lambda y_2}{1 + \lambda} \right)$
