# 圆柱、圆锥、圆台的表面积公式关系

## 公式
设底面半径分别为 \(r\)（下底）、\(r'\)（上底），母线长为 \(l\)，高为 \(h\)。

### 圆柱
$S_{\text{柱}} = 2\pi r^2 + 2\pi r l$
（两个底面 + 侧面）

### 圆锥
$S_{\text{锥}} = \pi r^2 + \pi r l$
（一个底面 + 侧面）

### 圆台
$S_{\text{台}} = \pi r'^2 + \pi r^2 + \pi (r + r') l$
（上底 + 下底 + 侧面）

## 统一关系

圆台公式是通用公式，圆柱和圆锥是其特殊情况。

### 1. 圆台 → 圆柱
当上底面半径等于下底面半径时，\(r' = r\)：
$\begin{aligned}
S_{\text{台}} &= \pi r^2 + \pi r^2 + \pi (r + r) l \\
&= 2\pi r^2 + 2\pi r l = S_{\text{柱}}
\end{aligned}$

### 2. 圆台 → 圆锥
当上底面半径缩小为 0 时，\(r' = 0\)：
$\begin{aligned}
S_{\text{台}} &= \pi \cdot 0^2 + \pi r^2 + \pi (r + 0) l \\
&= \pi r^2 + \pi r l = S_{\text{锥}}
\end{aligned}$

## 几何解释

三种旋转体通过上底面半径的变化相互联系：

- 圆柱：上、下底面半径相等（\(r' = r\)），母线垂直于底面
- 圆台：上、下底面半径不等（\(0 < r' < r\)），母线倾斜
- 圆锥：上底面半径缩为 0（\(r' = 0\)），母线汇聚于一点

演变过程：
圆锥 →（用平行于底面的平面截去顶部）→ 圆台 →（上底面半径扩大到与下底面相等）→ 圆柱

## 侧面公式的统一

圆台侧面积：\(S_{\text{侧}} = \pi (r + r') l\)

- 当 \(r' = r\) 时：\(S_{\text{侧}} = 2\pi r l\)（圆柱侧面积）
- 当 \(r' = 0\) 时：\(S_{\text{侧}} = \pi r l\)（圆锥侧面积）

## 与棱体公式的类比

| 棱体 | 旋转体 | 统一公式类型 |
|:---:|:---:|:---:|
| 棱柱 | 圆柱 | 上底面 = 下底面 |
| 棱台 | 圆台 | 上、下底面相似（半径比） |
| 棱锥 | 圆锥 | 上底面缩为点（半径 = 0） |

两套公式在结构上完全对应，体现了从柱体到锥体的连续演变过程。
