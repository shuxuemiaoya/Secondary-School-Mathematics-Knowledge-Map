### 由图象确定三角函数解析式
结合图像求三角函数解析式，即求  $A,\omega ,\varphi$  的值，最主要的是看图像上的关键点和特殊点.
$A$  值的确定方法：图像中最高点的纵坐标减去最低点的纵坐标所得差的一半.
$\omega$  值的确定方法：①代数法：求出  $A, \varphi$  的值之后，可由特殊点的坐标确定  $\omega$  的值；②几何法：利用  $\omega$  的几何意义，特殊点伸缩变换前后对应点横坐标的比值即为  $\omega$ 。

### 求ω的取值范围问题
### 周期法 常用结论：
（1）任意两条对称轴之间的距离为半周期的整数倍，即： $\frac{T}{2} k$  
(2) 任意两个对称中心之间的距离为半周期的整数倍, 即:  $\frac{T}{2} k$  
（3）任意对称轴与对称中心之间的距离为  $\frac{1}{4}$  个周期的奇数倍，即： $\frac{T}{4} (2k + 1)$  
（4）函数  $f(x) = A\sin (\omega x + \varphi) + B$  在  $(a,b)$  内单调，可知；  $\left\{ \begin{array}{l}b - a\leq \frac{T}{2}\\ k\pi -\frac{\pi}{2}\leq a\omega +\varphi \leq b\omega +\varphi \leq k\pi +\frac{\pi}{2} \end{array} \right.$  
（5）函数  $f(x) = A\sin (\omega x + \varphi) + B$  在  $(a,b)$  内不单调，可知：  $\left\{ \begin{array}{l}b - a\geq \frac{T}{2}\\ a\omega +\varphi \leq k\pi +\frac{\pi}{2}\leq b\omega +\varphi \end{array} \right.$  
（6）函数  $f(x) = A\sin (\omega x + \varphi) + B$  在  $(a,b)$  内无零点，可知：  $\left\{ \begin{array}{l}b - a\leq \frac{T}{2}\\ k\pi \leq a\omega +\varphi \leq b\omega +\varphi \leq (k + 1)\pi \end{array} \right.$  
（7）函数  $f(x) = A\sin (\omega x + \varphi) + B$  在  $(a,b)$  内有  $n$  个零点，可知：  $\left\{ \begin{array}{l}(k - 1)\pi \leq a\omega +\varphi < k\pi \\ (k + n - 1)\pi < b\omega +\varphi \leq (k + n)\pi \end{array} \right.$
### 1. 单调性
对于  $f(x) = A\sin (\omega x + \varphi)$  ，根据单调性求  $\omega$  ，主要是关注单调区间的端点.
方法一（代数法）：根据单调区间的长度初步确定  $\omega$  的取值范围：
如果函数在单调区间内递增，则  $-\frac{\pi}{2} + 2k\pi \leqslant \omega x + \varphi \leqslant \frac{\pi}{2} + 2k\pi (k \in \mathbf{Z})$
如果函数在单调区间内递减，则  $\frac{\pi}{2} + 2k\pi \leqslant \omega x + \varphi \leqslant \frac{3\pi}{2} + 2k\pi (k \in \mathbf{Z})$
如果函数只是在区间内单调，则  $k\pi - \frac{\pi}{2} \leqslant \omega x + \varphi \leqslant k\pi + \frac{\pi}{2} (k \in \mathbf{Z})$ ，取交集可得  $\omega$  的取值范围.
方法二（几何法）：在  $\omega$  的作用下，单调区间内的函数图像在伸缩前后单调性不变，由区间端点伸缩前后的比值可得  $\omega$  的取值范围：压缩时取到最大值，伸长时取到最小值.

### 2. 对称中心和对称轴
$f(x) = A\sin (\omega x + \varphi)\left(\omega >0,0 <   \varphi <  \frac{\pi}{2}\right)$  在区间内有几个对称轴、对称中心（零点），关注区间的端点.
方法一（代数法）：根据区间长度可以初步确定  $\omega$  的范围：
如果函数在区间  $(x_{1}, x_{2})$  内没有最大值点，则  $\frac{\pi}{2} + 2n\pi < \omega x_{i} + \varphi < \frac{5\pi}{2} + 2n\pi (n \in \mathbf{Z}, i = 1, 2)$
如果函数在区间  $(0, \pi]$  内至少有  $n$  个最大值点，则  $\omega \pi + \varphi \geqslant \frac{\pi}{2} + 2(n - 1)\pi (n \in \mathbf{N}^{*})$ .
如果函数在区间  $(0, \pi]$  内恰好有  $n$  个最大值点，则  $\frac{\pi}{2} + 2n\pi > \omega\pi + \varphi \geqslant \frac{\pi}{2} + 2(n - 1)\pi (n \in \mathbb{N}^*)$
如果函数在区间  $(0, \pi]$  内至多有  $n$  个最大值点，则  $\omega \pi + \varphi \leqslant \frac{\pi}{2} + 2(n - 1)\pi (n \in \mathbf{N}^*)$ .
方法二（几何法）：将  $f(x) = A\sin (x + \varphi)$  的对称轴或对称中心（零点）伸缩变换至区间端点处，若包含这个点则变换至区间内，若不包含则变换至区间外，根据变换前后横坐标的比值确定  $\omega$ 。

##### 例1
###### 思路一（代数法）：从函数图像与  $x$  轴的交点可以看出  $f(x)$  的周期大于  $\pi$  小于  $2\pi$ ，所以  $1 < |\omega| < 2$ ；再根据特殊点  $\left(-\frac{4\pi}{9}, 0\right)$  可得  $-\frac{4\pi}{9}\omega + \frac{\pi}{6} = -\frac{\pi}{2} + 2k\pi (k \in \mathbf{Z})$ ，表示出  $\omega$ ；最后结合范围可求出  $\omega$  的值，最小正周期  $T = \frac{2\pi}{\omega}$ .
解法一（代数法）：由图像可得  $f(x)$  的周期大于  $\pi$  小于  $2\pi$ ，所以  $\pi < \left|\frac{2\pi}{\omega}\right| < 2\pi$ ， $1 < |\omega| < 2$ 。函数图像过点  $\left(-\frac{4\pi}{9}, 0\right)$ ，所以  $-\frac{4\pi}{9}\omega + \frac{\pi}{6} = -\frac{\pi}{2} + 2k\pi (k \in \mathbf{Z})$ ， $\omega = \frac{3}{2} - \frac{9}{2}k$ ， $1 < \frac{3}{2} - \frac{9}{2}k < 2$ ，可得  $-\frac{1}{9} < k < \frac{1}{9} (k \in \mathbf{Z})$ ，则  $k = 0$ ，此时  $\omega = \frac{3}{2}$ ，所以最小正周期  $T = \frac{2\pi}{\frac{3}{2}} = \frac{4\pi}{3}$ ，故选 C.
###### 思路二（几何法）：若  $\omega = 1$  ，则图中的点  $\left(-\frac{4\pi}{9},0\right)$  伸缩前对应点为  $\left(-\frac{2\pi}{3},0\right)$  ，根据  $\omega$  的几何
意义可得  $\omega = \frac{-\frac{2\pi}{3}}{-\frac{4\pi}{9}}$  代入  $T = \frac{2\pi}{\omega}$
解法二（几何法）：令  $\omega = 1$  ，则  $f(x) = \cos \left(x + \frac{\pi}{6}\right)$  ，如图所示.
因为  $\omega = 1$  ，所以  $\left(-\frac{2\pi}{3},0\right)$  经过伸缩变换以后对应点  $\left(-\frac{4\pi}{9},0\right)$  ，根据  $\omega$  的几何意义知  $\omega = -\frac{2\pi}{3} -\frac{4\pi}{9} = \frac{3}{2}$  则  $T = \frac{2\pi}{3} = \frac{4\pi}{3}$  故选C.

##### 例3
###### 思路一（代数法）：整体代换+单调性+集合
1. 整体换元  令 $t=\omega x+\varphi$，把复合函数的单调性，转化为研究 $t$ 在正弦函数图像上的位置。
2. 卡单调区间  因为 $\sin t$ 只在某些区间内单调，所以必须让 $t$ 的整个取值范围，完整落在某一个单调区间内。即：- 左端点卡左边界；- 右端点卡右边界。由此列不等式。
3. 利用半周期限制  正弦函数一次单调的最长长度是半个周期，因此：$t$ 的跨度 $\le \pi$等价于：$\omega \times (\text{原区间长度})\le \pi$
4. 枚举整数 $k$ 单调区间会随周期平移，因此最后枚举整数 $k$，取所有满足条件的区间即可。
解：方法一：原函数卡根
由 $x\in\left[\frac{\pi}{2},\pi\right]$ 可得 $\frac{\pi}{2}\omega+\frac{\pi}{4}\leq\omega x+\frac{\pi}{4}\leq\pi\omega+\frac{\pi}{4}$，结合原函数单调区间，得 $\begin{cases} \frac{\pi}{2}\omega + \frac{\pi}{4} \geq \frac{\pi}{2} + 2k\pi \\ \pi\omega + \frac{\pi}{4} \leq \frac{3\pi}{2} + 2k\pi \end{cases}$，解得 $\frac{1}{2}+4k\leq\omega\leq\frac{5}{4}+2k$ ①，因为 $f(x)$ 在区间 $\left[\frac{\pi}{2},\pi\right]$ 上单调递减，所以 $T=\frac{2\pi}{\omega}\geq2\left(\pi-\frac{\pi}{2}\right)=\pi$，所以 $0<\omega\leq2$ ②。当 $k=0$ 时，结合①②得 $\frac{1}{2}\leq\omega\leq\frac{5}{4}$；当 $k=1$ 时，得 $\frac{9}{2}\leq\omega\leq\frac{13}{4}$，与 $0<\omega\leq2$ 矛盾；易知，当 $k\leq-1$ 或 $k\geq1$ 时均不满足题意。综上，$\omega$ 的取值范围为 $\left[\frac{1}{2},\frac{5}{4}\right]$。
方法二：现函数卡根
由 $\frac{\pi}{2}+2k\pi\leq\omega x+\frac{\pi}{4}\leq\frac{3\pi}{2}+2k\pi,\ k\in\mathbf Z$，解得 $\frac{\pi}{4\omega}+\frac{2k\pi}{\omega}\leq x\leq\frac{5\pi}{4\omega}+\frac{2k\pi}{\omega}$，所以函数 $f(x)$ 的单调递减区间为 $\left[\frac{\pi}{4\omega}+\frac{2k\pi}{\omega},\frac{5\pi}{4\omega}+\frac{2k\pi}{\omega}\right],k\in\mathbf Z$。因为 $f(x)$ 在区间 $\left[\frac{\pi}{2},\pi\right]$ 上单调递减，所以 $T=\frac{2\pi}{\omega}\geq2\left(\pi-\frac{\pi}{2}\right)=\pi$，所以 $0<\omega\leq2$。当 $k=0$ 时，由 $\begin{cases} \frac{\pi}{4\omega} \leq \frac{\pi}{2} \\ \frac{5\pi}{4\omega} \geq \pi \end{cases}$，得 $\frac{1}{2}\leq\omega\leq\frac{5}{4}$；当 $k=1$ 时，由 $\begin{cases} \frac{9\pi}{4\omega} \leq \frac{\pi}{2} \\ \frac{13\pi}{4\omega} \geq \pi \end{cases}$，得 $\frac{9}{2}\leq\omega\leq\frac{13}{4}$，与 $0<\omega\leq2$ 矛盾；易知，当 $k\leq-1$ 或 $k\geq1$ 时均不满足题意。综上，$\omega$ 的取值范围为 $\left[\frac{1}{2},\frac{5}{4}\right]$。
###### 思路二（几何法）：  $f(x) = \sin \left(x + \frac{\pi}{4}\right)$  的单调递减区间  $\frac{\pi}{4} \leqslant x \leqslant \frac{5\pi}{4}$  经过伸缩以后落到区间  $\left[\frac{\pi}{2}, \pi\right]$  内，根据  $\omega$  的几何意义可得  $\omega_{\min} = \frac{\frac{\pi}{4}}{\frac{\pi}{2}} = \frac{1}{2}, \omega_{\max} = \frac{\frac{5\pi}{4}}{\pi} = \frac{5}{4}$ .
解（几何法）：令  $\omega = 1$  ，则  $f(x) = \sin \left(x + \frac{\pi}{4}\right)$  ，其图像如右图所示.

###### 思路一（代数法）
由 $T=\pi$ 得 $\omega=2$，故 $f(x)=\sin(2x+\varphi)$。  
方法一：原函数卡根  
由 $x\in\left(\frac{\pi}{3},\frac{4\pi}{5}\right)$ 得 $2x+\varphi\in\left(\frac{2\pi}{3}+\varphi,\frac{8\pi}{5}+\varphi\right)$。  
若 $f(x)$ 在 $\left(\frac{\pi}{3},\frac{4\pi}{5}\right)$ 上单调递增，则 $\left(\frac{2\pi}{3}+\varphi,\frac{8\pi}{5}+\varphi\right)\subseteq\left[-\frac{\pi}{2}+2k\pi,\frac{\pi}{2}+2k\pi\right],\ k\in\mathbf Z$，  
得 $\begin{cases} \frac{2\pi}{3}+\varphi\geq -\frac{\pi}{2}+2k\pi \\[2pt] \frac{8\pi}{5}+\varphi\leq \frac{\pi}{2}+2k\pi \end{cases}$，解得 $\varphi\in\left[-\frac{7\pi}{6}+2k\pi,-\frac{11\pi}{10}+2k\pi\right]$，  
结合 $|\varphi|<\frac{\pi}{2}$，该区间与 $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$ 无交集，故不可能单调递增。  
若 $f(x)$ 在 $\left(\frac{\pi}{3},\frac{4\pi}{5}\right)$ 上单调递减，则 $\left(\frac{2\pi}{3}+\varphi,\frac{8\pi}{5}+\varphi\right)\subseteq\left[\frac{\pi}{2}+2k\pi,\frac{3\pi}{2}+2k\pi\right]$，  
得 $\begin{cases} \frac{2\pi}{3}+\varphi\geq \frac{\pi}{2}+2k\pi \\[2pt] \frac{8\pi}{5}+\varphi\leq \frac{3\pi}{2}+2k\pi \end{cases}$，解得 $\varphi\in\left[-\frac{\pi}{6}+2k\pi,-\frac{\pi}{10}+2k\pi\right]$。
