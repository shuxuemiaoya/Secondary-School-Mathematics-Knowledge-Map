# 中线
如图,  $\triangle ABC$  中,  $AD$  为  $BC$  的中线, 已知  $AB$ ,  $AC$ , 及  $\angle A$ , 求中线  $AD$  长.

### ① [[初中数学知识点/中线定理]]：  $AB^{2} + AC^{2} = 2(BD^{2} + AD^{2})$ 
#### 推导过程
在△ABD中，cos  $B = \frac{AB^{2} + BD^{2} - AD^{2}}{2AB\cdot BD}$  在△ABC中，cos  $B =$ $\frac{AB^{2} + BC^{2} - AC^{2}}{2AB\cdot BC}$  联立得  $AB^{2} + AC^{2} = 2(BD^{2} + AD^{2})$

### ② $\overrightarrow{AD}^2 = \frac{1}{4} (b^2 +c^2 +2bc\cos A).$
#### 推导过程： 法1：向量法（推荐首选）
设 $\overrightarrow{AB} = \vec{c}$，$\overrightarrow{AC} = \vec{b}$。  
由 $D$ 是 $BC$ 中点得：
$\overrightarrow{AD} = \frac{1}{2}(\overrightarrow{AB} + \overrightarrow{AC}) = \frac{1}{2}(\vec{c} + \vec{b})$
两边平方：
$\begin{aligned}|\overrightarrow{AD}|^2 &= \frac{1}{4}(\vec{b}+\vec{c})\cdot (\vec{b}+\vec{c}) \\&= \frac{1}{4}(|\vec{b}|^2 + |\vec{c}|^2 + 2\vec{b}\cdot\vec{c}) \\&= \frac{1}{4}(b^2 + c^2 + 2bc\cos\alpha)\end{aligned}$
所以中线长：$AD = \frac{1}{2}\sqrt{b^2 + c^2 + 2bc\cos\alpha}$

#### 法2：余弦定理：邻补角余弦值为相反数，即  $\cos \angle ADB + \cos \angle ADC = 0$
设 $BC = a$，$BD = DC = \frac{a}{2}$。  
在 $\triangle ABD$ 和 $\triangle ACD$ 中，分别对 $\angle ADB$ 和 $\angle ADC$ 用余弦定理：
$\cos\angle ADB = \frac{AD^2 + \left(\frac{a}{2}\right)^2 - c^2}{2\cdot AD \cdot \frac{a}{2}}$
$\cos\angle ADC = \frac{AD^2 + \left(\frac{a}{2}\right)^2 - b^2}{2\cdot AD \cdot \frac{a}{2}}$
因为 $\angle ADB$ 与 $\angle ADC$ 互补（邻补角），故 $\cos\angle ADB + \cos\angle ADC = 0$，即：
$\frac{AD^2 + \frac{a^2}{4} - c^2}{AD\cdot a} + \frac{AD^2 + \frac{a^2}{4} - b^2}{AD\cdot a} = 0$

分子相加为零：
$2AD^2 + \frac{a^2}{2} - (b^2 + c^2) = 0$
所以：
$AD^2 = \frac{b^2 + c^2}{2} - \frac{a^2}{4}$

其中 $a^2 = b^2 + c^2 - 2bc\cos\alpha$（第一步先求出 $a$），代入化简即得与向量法相同的结果：
$AD = \frac{1}{2}\sqrt{b^2 + c^2 + 2bc\cos\alpha}$

### 变式拓展：$BD:CD = \lambda$（有内分点比）
若条件改为“$AD$ 为 $BC$ 上的分点，且 $\dfrac{BD}{CD} = \lambda$”，求 $AD$ 长度。
- 向量法：设 $D$ 分 $BC$ 比为 $\lambda$，则 $\overrightarrow{AD} = \dfrac{\overrightarrow{AB} + \lambda \overrightarrow{AC}}{1+\lambda}$，平方即可。
- 余弦定理：分别在 $\triangle ABD$ 和 $\triangle ACD$ 中用余弦定理，利用 $\angle ADB+\angle ADC=\pi$ 列出方程求解。
