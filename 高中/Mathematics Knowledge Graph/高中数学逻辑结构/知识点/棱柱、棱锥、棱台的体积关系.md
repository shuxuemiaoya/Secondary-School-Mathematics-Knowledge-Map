## 公式
$V_{\text{棱柱}} = Sh, \quad V_{\text{棱锥}} = \frac{1}{3}Sh, \quad V_{\text{棱台}} = \frac{1}{3}h\left(S' + \sqrt{S'S} + S\right)$

## 统一关系

棱台公式是通用公式，棱柱和棱锥是其特殊情况：

### 1. 棱台 → 棱柱
当上底面与下底面全等时，$S' = S$：
$V_{\text{台}} = \frac{1}{3}h(S + \sqrt{S^2} + S) = \frac{1}{3}h(3S) = Sh$

### 2. 棱台 → 棱锥
当上底面缩小为一个点时，$S' = 0$：
$V_{\text{台}} = \frac{1}{3}h(0 + \sqrt{0 \cdot S} + S) = \frac{1}{3}Sh$

## 几何解释

三种几何体通过上底面的变化相互联系：

- 棱柱：上、下底面全等（相似比 $k=1$）
- 棱台：上、下底面相似（$0 < k < 1$）
- 棱锥：上底面缩为一个点（$k=0$）

演变过程：
棱锥 →（用平行于底面的平面截去顶部）→ 棱台 →（上底面扩大到与下底面全等）→ 棱柱

## 公式的结构意义

- $S$、$S'$：上、下底面的面积贡献
- $\sqrt{S'S}$：上、下底面积的几何平均，反映两底面的相似比
- $\frac{1}{3}h$：体现从棱锥到棱柱的体积计算一致性
