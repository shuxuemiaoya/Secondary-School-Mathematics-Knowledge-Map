##### 题型04 向量在物理中的应用
##### 【典例1】（2023·全国·高一随堂练习）已知两个力$F_{1}$，$F_{2}$的夹角为90°，它们的合力大小为10N，合力与$F_{1}$的夹角为60°，那么$F_{1}$的大小为（ ）．
$\quad$A．$5 \sqrt{3}$N 
$\quad$B．5N 
$\quad$C．10N 
$\quad$D．$5 \sqrt{2}$N
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>![@@@87e034e7-0b34-46b7-9346-ccae603d3a23](MathLogic-Weave/高中数学逻辑结构/题/Attachments/eb66cfc749dee867725d26378a498702.png)
如图，$\overrightarrow{O A} = \overrightarrow{F_{1}}$，$\overrightarrow{O B} = \overrightarrow{F_{2}}$，$\angle A O C = 6 0 {^\circ}$，$\angle O A C = 9 0 {^\circ}$，$\left| \overrightarrow{O C} \right| = 1 0$.
在$\text{Rt} \bigtriangleup O A C$中，有$\left| \overrightarrow{O A} \right| = \left| \overrightarrow{O C} \right| \cos \angle A O C = 5$，
所以，$F_{1}$的大小为5N.
故选：B.
##### 【典例2】（2022上·江西·高二南昌县莲塘第一中学校考期中）在如图的天平中，左、右两个秤盘均被3根细绳均匀地固定在横梁上．在其中一个秤盘中放入重量为$6 0 N$的物品，在另一个秤盘中放入重量$6 0 N$的砝码，天平平衡．$3$根细绳通过秤盘分担对物品的拉力（拉力分别为，$\overrightarrow{F_{2}}$，$\overrightarrow{F_{3}} )$，若3根细绳两两之间的夹角均为$\frac{\pi}{3}$，不考虑秤盘和细绳本身的质量，则的大小为 $N$．
![@@@7dc41e01-2ac6-40e7-bfc7-1bf697908b2c](MathLogic-Weave/高中数学逻辑结构/题/Attachments/77560818d7206d55b2d31225ea0130bb.png)
<span class="fake-tag">答案</span>$10 \sqrt{6}$
<span class="fake-tag">详解</span>依题意，$\left| \overrightarrow{F_{1}} | = | \overrightarrow{F_{2}} | = | \overrightarrow{F_{3}} \right|$且$\left| \overrightarrow{F_{1}} + \overrightarrow{F_{2}} + \overrightarrow{F_{3}} \right| = 6 0$，
所以$\left| \overrightarrow{F_{1}} |^{2} + \right| \overrightarrow{F_{2}} |^{2} + | \overrightarrow{F_{3}} |^{2} + 2 \overrightarrow{F_{1}} \cdot \overrightarrow{F_{2}} + 2 \overrightarrow{F_{2}} \cdot \overrightarrow{F_{3}} + 2 \overrightarrow{F_{3}} \cdot \overrightarrow{F_{1}} = 3 6 0 0$，
即$3 \left| \overrightarrow{F_{1}} |^{2} + 3 \times 2 \right| \overrightarrow{F_{1}} |^{2} \times \frac{1}{2} = 3 6 0 0$，解得$\left| \overrightarrow{F_{1}} \right| = 1 0 \sqrt{6}$．
故答案为：$10 \sqrt{6}$．

##### 【变式1】（2023·全国·高一随堂练习）飞机从*A*地向西北飞行200km到达*B*地后，又从*B*地向东飞行$100 \sqrt{2}$km到达*C*地，再从*C*地向南偏东60°飞行$50 \sqrt{2}$km到达*D*地，求飞机从*D*地飞回*A*地的位移．
<span class="fake-tag">答案</span>大小为$50 \sqrt{6} \text{km}$，方向为南偏西$60 {^\circ}$
<span class="fake-tag">详解</span>![@@@68f7c894-2930-445c-9cd7-516f44444420](MathLogic-Weave/高中数学逻辑结构/题/Attachments/193749f960ecc556050a51b06b1edcab.png)
如图，飞机从$A$运动到$D$的过程，
由已知可得，$A B = 2 0 0$，$B C = 1 0 0 \sqrt{2}$，且$\angle B A C = 4 5 {^\circ}$，
所以，，$\angle A C B = 9 0 {^\circ}$.
过点$D$作$D E \bot A C$，
因为$\angle E C D = 6 0 {^\circ}$，
所以$C E = C D \cos 6 0 {^\circ} = 2 5 \sqrt{2}$，$D E = C D \sin 6 0 {^\circ} = 2 5 \sqrt{6}$，
所以，$A E = A C - C E = 7 5 \sqrt{2}$.
由勾股定理可得，$A D = \sqrt{D E^{2} + A E^{2}} = 5 0 \sqrt{6}$，
$\cos \angle A D E = \frac{D E}{A D} = \frac{25 \sqrt{6}}{50 \sqrt{6}} = \frac{1}{2}$，所以$\angle A D E = 6 0 {^\circ}$.
所以，飞机从*D*地飞回*A*地的位移大小为$50 \sqrt{6} \text{km}$，方向为南偏西$60 {^\circ}$.
