### 证明三角恒等式常用的方法：
（1）从左向右推导或从右向左推导，一般由繁到简  
（2）左右归一法，即证明左右两边都等于同一个式子  
（3）化异为同法，即针对题设与结论间的差异，有针对性地进行变形，以消除差异.  
（4）变更命题法，如要证明  $\frac{a}{b} = \frac{c}{d}$  可证  $ad = bc$  或证  $\frac{d}{b} = \frac{c}{a}$  等.  
（5）比较法，即设法证明“左边一右边  $= 0$  ”或“  $\frac{\text{左边}}{\text{右边}} = 1$  ”.
##### 【9】（2023·全国高一专项练习）求证：
(1)  $1 + \tan^2 \alpha = \frac{1}{\cos^2 \alpha}$ ;  
(2)  $\sin^4\alpha -\cos^4\alpha = \sin^2\alpha -\cos^2\alpha$  
(3)  $\frac{\sin \alpha}{1 - \cos \alpha} \cdot \frac{\cos \alpha \cdot \tan \alpha}{1 + \cos \alpha} = 1$ ;  
（4）  $\tan^2\theta -\sin^2\theta = \tan^2\theta \sin^2\theta$  
(5)  $\frac{1 - \tan^2\theta}{1 + \tan^2\theta} = \cos^2\theta -\sin^2\theta$
(6)  $\frac{\tan\theta\cdot\sin\theta}{\tan\theta - \sin\theta} = \frac{1 + \cos\theta}{\sin\theta}$ ;  
(7)  $\frac{1 - 2\sin\alpha\cos\alpha}{\cos^2\alpha - \sin^2\alpha} = \frac{1 - \tan\alpha}{1 + \tan\alpha}$ ;  
(8)  $\frac{\cos x}{1 - \sin x} = \frac{1 + \sin x}{\cos x}$ ;  
(9)  $\frac{\tan\alpha\cdot\sin\alpha}{\tan\alpha - \sin\alpha} = \frac{\tan\alpha + \sin\alpha}{\tan\alpha\cdot\sin\alpha}$  
(10)  $\frac{\sin^2\alpha + 2\cos^2\alpha + 1}{\cos^2\alpha - \sin^2\alpha} = \frac{3 + 2\tan^2\alpha}{1 - \tan^2\alpha}$ .
