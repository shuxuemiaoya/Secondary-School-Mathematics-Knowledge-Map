$\frac{\alpha}{n}$  所在象限的判断方法：
已知角  $\alpha$  所在象限，要确定角  $\frac{\alpha}{n}$  所在象限，有两种方法：
【解法1】用不等式表示出角  $\frac{\alpha}{n}$  的范围，然后对  $k$  的取值分情况讨论：被  $n$  整除；被  $n$  除余1；被  $n$  除余2；...；被  $n$  除余  $n - 1$  。从而得出结论；
【解法2】:作出各个象限的从原点出发的  $n$  等分射线，它们与坐标轴把周角分成  $4n$  个区域.从  $x$  轴非负半轴起，按逆时针方向把这  $4n$  个区域依次循环标上1,2,3,4.  $\alpha$  的终边在第几象限，则标号为几的区域，就是  $\frac{\alpha}{n}$  的终边所落在的区域.如此，  $\frac{\alpha}{n}$  所在的象限就可以由标号区域所在的象限直观地看出
##### 题型05 确定$\mathbf{n}$分角的终边所在的象限
##### 【典例1】（23-24高一下·辽宁辽阳·期中）已知角$\mathbf{\alpha}$的终边经过点，则$\frac{\mathbf{\alpha}}{\mathbf{2}}$是（ ）
$\quad$A．第一或第三象限角 B．第二或第四象限角
$\quad$C．第一或第二象限角 D．第三或第四象限角
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据角$\alpha$所在的象限，表示$\frac{\alpha}{2}$所在的象限.
<span class="fake-tag">详解</span>由题意可知$\alpha$是第二象限角，$\frac{\pi}{2} + 2 k \pi < \alpha < \pi + 2 k \pi , k \in Z$，
则$\frac{\pi}{4} + k \pi < \frac{\alpha}{2} < \frac{\pi}{2} + k \pi , k \in Z$,则$\frac{\alpha}{2}$是第一或第三象限角．
故选：A
##### 【典例2】（23-24高一上·河北石家庄·期中）如果角$\mathbf{\alpha}$的终边在第三象限，则$\frac{\mathbf{\alpha}}{\mathbf{3}}$的终边一定不在（ ）
$\quad$A．第一象限 B．第二象限
$\quad$C．第三象限 D．第四象限
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>根据角$\alpha$的终边在第三象限，得$k \cdot 3 6 0 {^\circ} + 1 8 0 {^\circ} < \alpha < k \cdot 3 6 0 {^\circ} + 2 7 0 {^\circ} , k \in Z$，即$k \cdot 120 {^\circ} + 6 0 {^\circ} < \frac{\alpha}{3} < k \cdot 120 {^\circ} + 9 0 {^\circ} , k \in Z$，然后分类讨论，再结合象限角定义可判断.
<span class="fake-tag">详解</span>∵*α*为第三象限角，∴$k \cdot 360 {^\circ} + 1 8 0 {^\circ} < \alpha < k \cdot 360 {^\circ} + 2 7 0 {^\circ} , k \in Z$，
∴$k \cdot 120 {^\circ} + 6 0 {^\circ} < \frac{\alpha}{3} < k \cdot 120 {^\circ} + 9 0 {^\circ} , k \in Z$，
令$k = 3 n$，$n \in Z$，时，$3 n \cdot 1 2 0 {^\circ} + 6 0 {^\circ} < \frac{\alpha}{3} < 3 n \cdot 1 2 0 {^\circ} + 9 0 {^\circ}$，$n \in Z$，

令$k = 3 n + 2$，$n \in Z$时，$( 3 n + 2 ) \cdot 1 2 0 {^\circ} + 6 0 {^\circ} < \frac{\alpha}{3} < ( 3 n + 2 ) \cdot 1 2 0 {^\circ} + 9 0 {^\circ}$，$n \in Z$，
∴可得$\frac{\alpha}{3}$的终边在第四象限，

##### 【典例3】（24-25高一上·上海·课堂例题）已知$\mathbf{\alpha}$为第三象限的角，讨论角$\mathbf{\pi - \alpha}$，$\mathbf{2} \mathbf{\alpha}$，$\frac{\mathbf{\alpha}}{\mathbf{3}}$的终边的位置.
<span class="fake-tag">答案</span>答案见解析.
<span class="fake-tag">分析</span>根据$\alpha$所在象限得出$\alpha$的取值范围，再分别计算出$\pi - \alpha$，$2 \alpha$，$\frac{\alpha}{3}$的范围，即可判断出所在象限.
<span class="fake-tag">详解</span>∵$\alpha$是第三象限的角，
∴$2 k \pi + \pi < \alpha < 2 k \pi + \frac{3 \pi}{2}$（），
∴$- 2 k \pi - \frac{3 \pi}{2} < - \alpha < - 2 k \pi - \pi$（），
∴$- 2 k \pi - \frac{\pi}{2} < \pi - \alpha < - 2 k \pi$（），
∴$\pi - \alpha$是第四象限的角.
∵$2 k \pi + \pi < \alpha < 2 k \pi + \frac{3 \pi}{2}$（），
∴$4 k \pi + 2 \pi < 2 \alpha < 4 k \pi + 3 \pi$（），
∴$2 \alpha$是第一象限的角或第二象限的角或*y*轴正半轴上的角.
∵$2 k \pi + \pi < \alpha < 2 k \pi + \frac{3 \pi}{2}$（），
∴$\frac{2 k \pi}{3} + \frac{\pi}{3} < \frac{\alpha}{3} < \frac{2 k \pi}{3} + \frac{\pi}{2}$（）.
若$k = 3 n$（$n \in \mathbf{Z}$），
则$2 n \pi + \frac{\pi}{3} < \frac{\alpha}{3} < 2 n \pi + \frac{\pi}{2}$（$n \in \mathbf{Z}$），
∴$\frac{\alpha}{3}$是第一象限的角；
若$k = 3 n + 1$（$n \in \mathbf{Z}$），
则$2 n \pi + \pi < \frac{\alpha}{3} < 2 n \pi + \frac{\text{7π}}{6}$（$n \in \mathbf{Z}$），
∴$\frac{\alpha}{3}$是第三象限的角；
若$k = 3 n + 2$（$n \in \mathbf{Z}$），

∴$\frac{\alpha}{3}$是第一象限的角、第三象限的角或第四象限的角.
综上所述，结论是：$\pi - \alpha$是第四象限的角，$2 \alpha$是第一象限的角或第二象限的角或*y*轴正半轴上的角，$\frac{\alpha}{3}$是第一象限的角、第三象限的角或第四象限的角.
##### 【变式1】（23-24高三上·上海静安·期末）设$\mathbf{\alpha}$是第一象限的角，则$\frac{\mathbf{\alpha}}{\mathbf{2}}$所在的象限为（ ）
$\quad$A．第一象限 B．第三象限
$\quad$C．第一象限或第三象限 D．第二象限或第四象限
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>根据$\alpha$是第一象限的角，求出$\frac{\alpha}{2}$的范围判断即可得解.
<span class="fake-tag">详解</span>因为$\alpha$是第一象限的角，
所以$2 k \pi < \alpha < 2 k \pi + \frac{\pi}{2}$，，
所以$k \pi < \frac{\alpha}{2} < k \pi + \frac{\pi}{4} , k \in Z$，
当$k = 2 n , n \in Z$时，$2 n \pi < \frac{\alpha}{2} < 2 n \pi + \frac{\pi}{4} , n \in Z$，$\frac{\alpha}{2}$为第一象限角；
当$k = 2 n + 1 , n \in Z$时，$2 n \pi + \pi < \frac{\alpha}{2} < 2 n \pi + \pi + \frac{\pi}{4} , n \in Z$，$\frac{\alpha}{2}$为第三象限角.
故选：C
##### 【变式2】（23-24高一下·全国·课后作业）已知角$\mathbf{\alpha}$是第三象限角，求$\frac{\mathbf{\alpha}}{\mathbf{2}} \mathbf{，} \frac{\mathbf{\alpha}}{\mathbf{3}}$所在的象限.
<span class="fake-tag">答案</span>$\frac{\alpha}{2}$在第二或第四象限；$\frac{\alpha}{3}$在第一，第三或第四象限
<span class="fake-tag">分析</span>先写出角$\alpha$满足的不等式，再分别写出$\frac{\alpha}{2} ， \frac{\alpha}{3}$满足的不等式，根据不等式确定象限即可.
<span class="fake-tag">详解</span>角$\alpha$是第三象限角,即$\pi + 2 k \pi < \alpha < \frac{3 \pi}{2} + 2 k \text{π} \text{,} k \in Z$,
对于$\frac{\alpha}{2}$：
$\frac{\pi}{2} + k \pi < \frac{\alpha}{2} < \frac{3 \pi}{4} + k \text{π} \text{,} k \in Z$，
当$k$为偶数时，$\frac{\alpha}{2}$在第一象限；当$k$为奇数时，$\frac{\alpha}{2}$在第四象限；
故$\frac{\alpha}{2}$在第二或第四象限；
对于$\frac{\alpha}{3}$：
$\frac{\pi}{3} + \frac{2}{3} k \pi < \frac{\alpha}{3} < \frac{\pi}{2} + \frac{2}{3} k \text{π} \text{,} k \in Z$，
当$k = 3 m , m \in Z$时，$\frac{\alpha}{3}$在第一象限；当$k = 3 m + 1 , m \in Z$时，$\frac{\alpha}{3}$在第三象限；当$k = 3 m + 2 , m \in Z$时，$\frac{\alpha}{3}$在第四象限；
故$\frac{\alpha}{3}$在第一，第三或第四象限.
