##### 题型02 已知两角的正弦，余弦求和差角的余弦
##### 【典例1】（23-24高一下·江苏苏州·期中）已知$\alpha$，都是锐角，$\text{cos} \alpha = \frac{3}{5}$，$\text{sin} ( \alpha - \beta ) = \frac{5}{13}$，则$\text{cos} \beta =$（ ）
$\quad$A．$\frac{16}{65}$ 
$\quad$B．$\frac{33}{65}$ 
$\quad$C． 
$\quad$D．$\frac{63}{65}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>利用同角三角函数关系得到$\text{sin} \alpha = \frac{4}{5}$，$\text{cos} ( \alpha - \beta ) = \frac{12}{13}$，凑角法得到答案.
<span class="fake-tag">详解</span>因为$\alpha$，$\beta \in \left( 0 , \frac{\pi}{2} \right)$，所以$\alpha - \beta \in \left( - \frac{\pi}{2} , \frac{\pi}{2} \right)$，所以$\text{sin} \alpha = \frac{4}{5}$，$\text{cos} ( \alpha - \beta ) = \frac{12}{13}$，
所以$\text{cos} \beta = \text{cos} \left\lbrack \alpha - ( \alpha - \beta ) \right\rbrack = \text{cos} \alpha \cdot \text{cos} ( \alpha - \beta ) + \text{sin} \alpha \cdot \text{sin} ( \alpha - \beta )$
$= \frac{3}{5} \times \frac{12}{13} + \frac{4}{5} \times \frac{5}{13} = \frac{56}{65}$.
故选：C
##### 【典例2】（24-25高一上·上海·课后作业）已知$\sin ( \alpha - \gamma ) = \frac{3}{5}$，$\cos ( \beta - \gamma ) = \frac{5}{13}$，则$\cos ( \alpha - \beta ) =$ .
<span class="fake-tag">答案</span>$\pm \frac{56}{65}$或$\pm \frac{16}{65}$
<span class="fake-tag">分析</span>已知$( \alpha - \gamma )$，$( \beta - \gamma )$两个角，要求，发现$( \alpha - \beta ) = [ ( \alpha - \gamma ) - ( \beta - \gamma ) ]$，套用余弦和差角公式得解.
<span class="fake-tag">详解</span>由题意知：$\sin ( \alpha - \gamma ) = \frac{3}{5}$，$\cos ( \beta - \gamma ) = \frac{5}{13}$，
可得：$\cos ( \alpha - \gamma ) = \pm \frac{4}{5}$，$\sin ( \beta - \gamma ) = \pm \frac{12}{13}$
$\because \cos ( \alpha - \beta ) = \cos [ ( \alpha - \gamma ) - ( \beta - \gamma ) ] = \cos ( \alpha - \gamma ) \cos ( \beta - \gamma ) + \sin ( \alpha - \gamma ) \sin ( \beta - \gamma )$
当$\cos ( \alpha - \gamma ) = \frac{4}{5}$，$\sin ( \beta - \gamma ) = \frac{12}{13}$时，原式$= \frac{4}{5} \times \frac{5}{13} + \frac{3}{5} \times \frac{12}{13} = \frac{56}{65}$；
当$\cos ( \alpha - \gamma ) = - \frac{4}{5}$，$\sin ( \beta - \gamma ) = \frac{12}{13}$时，原式$= - \frac{4}{5} \times \frac{5}{13} + \frac{3}{5} \times \frac{12}{13} = \frac{16}{65}$；
当$\cos ( \alpha - \gamma ) = \frac{4}{5}$，$\sin ( \beta - \gamma ) = - \frac{12}{13}$时，原式$= \frac{4}{5} \times \frac{5}{13} + \frac{3}{5} \times ( - \frac{12}{13} ) = - \frac{16}{65}$；
当$\cos ( \alpha - \gamma ) = - \frac{4}{5}$，$\sin ( \beta - \gamma ) = - \frac{12}{13}$时，原式$= - \frac{4}{5} \times \frac{5}{13} + \frac{3}{5} \times ( - \frac{12}{13} ) = - \frac{56}{65}$；
$\therefore \cos ( \alpha - \beta ) = \pm \frac{56}{65} 或 \pm \frac{16}{65}$.
故答案为：$\pm \frac{56}{65}$或$\pm \frac{16}{65}$
##### 【典例3】（2024·陕西铜川·二模）已知锐角满足$\sin \alpha = \frac{\sqrt{5}}{5}$，$\cos \beta = \frac{3}{5}$，则$\cos ( \alpha - \beta ) =$ .
<span class="fake-tag">答案</span>$\frac{2 \sqrt{5}}{5}$/$\frac{2}{5} \sqrt{5}$
<span class="fake-tag">分析</span>利用同角三角函数关系可求得$\cos \alpha , \sin \beta$，代入两角和差余弦公式即可.
<span class="fake-tag">详解</span>$\because \alpha , \beta$均为锐角，$\therefore \cos \alpha = \sqrt{1 - \sin^{2} \alpha} = \frac{2 \sqrt{5}}{5}$，$\sin \beta = \sqrt{1 - \cos^{2} \beta} = \frac{4}{5}$，
$\therefore \cos ( \alpha - \beta ) = \cos \alpha \cos \beta + \sin \alpha \sin \beta = \frac{2 \sqrt{5}}{5} \times \frac{3}{5} + \frac{\sqrt{5}}{5} \times \frac{4}{5} = \frac{2 \sqrt{5}}{5}$.
故答案为：$\frac{2 \sqrt{5}}{5}$.
##### 【变式1】（23-24高一下·河北·期末）已知$\text{cos} \left( \frac{\pi}{4} - \alpha \right) = \frac{3}{5} , \text{sin} \left( \frac{5 \pi}{4} + \beta \right) = - \frac{12}{13} , \alpha \in \left( \frac{\pi}{4} , \frac{3 \pi}{4} \right) , \beta \in \left( 0 , \frac{\pi}{4} \right)$，则$\text{cos} ( \alpha + \beta ) =$（ ）
$\quad$A．$- \frac{33}{65}$ 
$\quad$B．$\frac{33}{65}$ 
$\quad$C．$- \frac{63}{65}$ 
$\quad$D．$\frac{63}{65}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>先求出$\text{sin} \left( \frac{\pi}{4} - \alpha \right)$和$\text{cos} \left( \frac{5 \pi}{4} + \beta \right)$的值，利用$\text{cos} ( \alpha + \beta ) = - \text{cos} ( \pi + \alpha + \beta ) = - \text{cos} \left\lbrack \left( \frac{5 \pi}{4} + \beta \right) - \left( \frac{\pi}{4} - \alpha \right) \right\rbrack$，即可求出$\text{cos} ( \alpha + \beta )$的值．
<span class="fake-tag">详解</span>$\because \text{cos} \left( \frac{\pi}{4} - \alpha \right) = \frac{3}{5} , \text{sin} \left( \frac{5 \pi}{4} + \beta \right) = - \frac{12}{13} , \alpha \in \left( \frac{\pi}{4} , \frac{3 \pi}{4} \right) , \beta \in \left( 0 , \frac{\pi}{4} \right) \therefore - \frac{\pi}{2} < \frac{\pi}{4} - \alpha < 0 , \quad \frac{5 \pi}{4} < \frac{\text{5} \text{π}}{4} + \beta < \frac{3 \pi}{2}$，
$\therefore \text{sin} \left( \frac{\pi}{4} - \alpha \right) = - \frac{4}{5} , \text{cos} \left( \frac{5 \pi}{4} + \beta \right) = - \frac{5}{13}$，
$\therefore \text{cos} ( \alpha + \beta ) = - \text{cos} ( \pi + \alpha + \beta ) = - \text{cos} \left\lbrack \left( \frac{5 \pi}{4} + \beta \right) - \left( \frac{\pi}{4} - \alpha \right) \right\rbrack$
$= - \text{cos} \left( \frac{5 \pi}{4} + \beta \right) \text{cos} \left( \frac{\pi}{4} - \alpha \right) - \text{sin} \left( \frac{\text{5} \text{π}}{4} + \beta \right) \text{sin} \left( \frac{\pi}{4} - \alpha \right)$
故选：A.
