##### 题型02 求物体运动的瞬时速度（含瞬时变化率）
##### 【典例1】（2023下·宁夏银川·高二宁夏育才中学校考阶段练习）在高台跳水运动中，$t s$时运动员相对于水面的高度$($单位：）是$h ( t ) = - 4 . 9 t^{2} + 6 . 5 t + 1 0$，则运动员在$t = 1 s$时的瞬时速度为![@@@8c8a56e97fb64223b4df30a4cc9fbc57](高中习题/课堂同步/随堂练习习题/media/69c1ed6f58ec6fc8c87845f280aebd7d.png)（ ）
$\quad$A．$- 3 . 3 m / s$ 
$\quad$B．$- 8 . 2 m / s$ 
$\quad$C．$3 . 3 m / s$ 
$\quad$D．$1 . 6 m / s$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>运动员在$t = 1 s$时的瞬时速度即为$h^{'} ( 1 )$，令$y = h ( t )$，
根据导数的定义，$\frac{\Delta y}{\Delta t} = \frac{h ( 1 + \Delta t ) - h ( 1 )}{\Delta t}$
$= \frac{- 4 . 9 ( 1 + \Delta t )^{2} + 6 . 5 ( 1 + \Delta t ) + 1 0 - ( - 4 . 9 + 6 . 5 + 1 0 )}{\Delta t}$= - 4 . 9 \Delta t - 3 . 3$，
所以$h^{'} ( 1 ) = \underset{\Delta t \rightarrow 0}{\text{lim}} \frac{\Delta y}{\Delta t} = \underset{\Delta t \rightarrow 0}{\text{lim}} ( - 4 . 9 \Delta t - 3 . 3 ) = - 3 . 3$，
故运动员在$t = 1 s$时的瞬时速度为$- 3 . 3 m / s$.
故选：A．
##### 【典例2】（2023·河南·高二校联考阶段练习）函数$f ( x ) = x^{2}$在区间$[ 0 , 2 ]$上的平均变化率等于时的瞬时变化率，则$m =$（ ）
$\quad$A．$\frac{1}{2}$ 
$\quad$B．1 
$\quad$C．2 
$\quad$D．$\frac{3}{2}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>函数$f ( x ) = x^{2}$在区间$[ 0 , 2 ]$上的平均变化率等于$\frac{f ( 2 ) - f ( 0 )}{2 - 0} = \frac{4 - 0}{2 - 0} = 2$，
$f ( x ) = x^{2}$在时的瞬时变化率为$\lim_{\bigtriangleup x \rightarrow 0} \frac{f ( m + \bigtriangleup x ) - f ( m )}{\bigtriangleup x} = \lim_{\bigtriangleup x \rightarrow 0} ( \bigtriangleup x + 2 m ) = 2 m$，
所以$2 = 2 m$，解得$m = 1$.
故选：B
##### 【变式1】（2023下·浙江嘉兴·高二校联考期中）函数$f ( x ) = x^{2}$在处的瞬时变化率为（ ）
$\quad$A．$- 2$ 
$\quad$B．$2$ 
$\quad$C．$4$ 
$\quad$D．$- 4$
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>因为$\frac{f ( 2 + \Delta x ) - f ( 2 )}{\Delta x} = \frac{( 2 + \Delta x )^{2} - 4}{\Delta x} = \frac{4 + 4 \Delta x + ( \Delta x )^{2} - 4}{\Delta x} = \Delta x + 2$，
所以，函数$f ( x ) = x^{2}$在处的瞬时变化率为$f^{'} ( 2 ) = \lim_{\Delta x \rightarrow 0} \frac{f ( 2 + \Delta x ) - f ( 2 )}{\Delta x}$
$= \lim_{\Delta x \rightarrow 0} ( \Delta x + 4 ) = 4$.
故选：C.
