##### 【典例1】（23-24高一下·江苏南京·期中）$\sin 3 5 {^\circ} \cos 2 5 {^\circ} - \cos 1 45 {^\circ} \sin 2 5 {^\circ} =$（ ）
$\quad$A． 
$\quad$B．$\frac{1}{2}$ 
$\quad$C．$- \frac{1}{2}$ 
$\quad$D．
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据诱导公式把题目中的角转化为锐角，最后逆用两角和的正弦公式进行求解即可.
<span class="fake-tag">详解</span>$\sin 3 5 {^\circ} \cos 2 5 {^\circ} - \cos 1 45 {^\circ} \sin 2 5 {^\circ} = \sin 3 5 {^\circ} \cos 2 5 {^\circ} - \cos ( 180 {^\circ} - 35 {^\circ} ) \sin 2 5 {^\circ}$
$= \sin 3 5 {^\circ} \cos 2 5 {^\circ} - \left( - \cos 3 5 {^\circ} \right) \sin 2 5 {^\circ} = \sin 3 5 {^\circ} \cos 2 5 {^\circ} + \cos 3 5 {^\circ} \sin 2 5 {^\circ} = \sin ( 35 {^\circ} + 2 5 {^\circ} ) = \sin 6 0 {^\circ} = \frac{\sqrt{3}}{2}$

##### 【典例2】（24-25高一上·上海·课前预习）化简$\text{cos} ( x + y ) \text{sin} y - \text{sin} ( x + y ) \text{cos} y =$ .
<span class="fake-tag">答案</span>$- \text{sin} x$
<span class="fake-tag">分析</span>先根据两角和差正弦公式逆用,再应用诱导公式化简即可.
<span class="fake-tag">详解</span>由两角和差公式可得$\text{cos} ( x + y ) \text{sin} y - \text{sin} ( x + y ) \text{cos} y = \text{sin} \left\lbrack y - ( x + y ) \right\rbrack \text{=sin} ( - x )$，
由诱导公式可得$\text{cos} ( x + y ) \text{sin} y - \text{sin} ( x + y ) \text{cos} y \text{=sin} ( - x ) = - \text{sin} x$.
故答案为：$- \text{sin} x$.

##### 【变式1】（23-24高一下·江苏淮安·阶段练习）化简$\sin 1 6 7^{\circ} \cos 1 7^{\circ} + \sin 1 0 3^{\circ} \sin 1 6 3^{\circ} =$（ ）
$\quad$A． 
$\quad$B．$\frac{1}{2}$ 
$\quad$C．$\sin 4^{\circ}$ 
$\quad$D．$\cos 4^{\circ}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>根据诱导公式结合两角和差公式公式运算求解.
<span class="fake-tag">详解</span>因为$\sin 1 6 7^{\circ} = \sin \left( 18 0^{\circ} - 1 3^{\circ} \right) = \sin 1 3^{\circ}$，$\sin 1 0 3^{\circ} = \sin \left( 9 0^{\circ} + 1 3^{\circ} \right) = \cos 1 3^{\circ}$，
$\sin 1 6 3^{\circ} = \sin \left( 18 0^{\circ} - 1 7^{\circ} \right) = \sin 1 7^{\circ}$，
所以$\sin 1 6 7^{\circ} \cos 1 7^{\circ} + \sin 1 0 3^{\circ} \sin 1 6 3^{\circ} = \sin 1 3^{\circ} \cos 1 7^{\circ} + \cos 1 3^{\circ} \sin 1 7^{\circ}$= \sin \left( 1 3^{\circ} + 1 7^{\circ} \right) = \sin 3 0^{\circ} = \frac{1}{2}$.
