##### 题型03 向量的模
##### 【典例1】（2023下·山东菏泽·高一山东省东明县第一中学校考阶段练习）如果一架飞机向西飞行$150 \text{km}$，再向南飞行$350 \text{km}$，记飞机飞行的路程为，位移为$\overrightarrow{a}$，则（ ）．
$\quad$A．$s > \left| \overrightarrow{a} \right|$ 
$\quad$B．$s = \left| \overrightarrow{a} \right|$ 
$\quad$C．$s < \left| \overrightarrow{a} \right|$ 
$\quad$D．与$\left| \overrightarrow{a} \right|$不能比较大小
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题意，作图如下：
![@@@c030c408e85c436a80b9cb80b056a158](高中习题/课堂同步/随堂练习习题/必修二/Attachments/087d574f0f5baac09e37c62241b7f806.png)
则该飞机由$A$先飞到$B$，再飞到$C$，则$A B = 1 5 0 \text{km}$，$B C = 3 5 0 \text{km}$，$\overrightarrow{a} = \overrightarrow{A C}$，
则飞机飞行的路程为$s = 5 0 0 \text{km}$，$\left| \overrightarrow{a} \right| = \sqrt{15 0^{2} + 3 5 0^{2}} = 5 0 \sqrt{58} \text{km}$，
所以$s > \left| \overrightarrow{a} \right|$.
故选：A.
##### 【典例2】（2022·高一课时练习）如图，已知$\overrightarrow{a}$是单位向量，求出图中向量$\overrightarrow{b}$，$\overrightarrow{c}$，$\overrightarrow{d}$，$\overrightarrow{e}$的模.
![@@@779e2381-ff1e-4974-b0f3-3c2b6d1b2307](高中习题/课堂同步/随堂练习习题/必修二/Attachments/e9899f559dff19831b815b00ba99f219.png)
<span class="fake-tag">答案</span>$\left| \overrightarrow{b} \right| = 2 , \left| \overrightarrow{c} \right| = 3 , \left| \overrightarrow{d} \right| = \sqrt{10} , \left| \overrightarrow{e} \right| = \sqrt{13}$
<span class="fake-tag">详解</span>因为$\overrightarrow{a}$是单位向量，所以图中小正方形的边长为$1$；
所以$\left| \overrightarrow{b} \right| = 2 , \left| \overrightarrow{c} \right| = 3$，
由勾股定理可知，$\left| \overrightarrow{d} \right| = \sqrt{1^{2} + 3^{2}} = \sqrt{10}$，$\left| \overrightarrow{e} \right| = \sqrt{2^{2} + 3^{2}} = \sqrt{13}$.

##### 【变式2】（2023·全国·高一随堂练习）如图，某船从点*O*出发沿北偏东30°的方向行驶至点*A*处，求该船航行向量的长度（单位：n mile）．
![@@@0ccddee3-f6b7-4912-b4d6-7933a249fed3](高中习题/课堂同步/随堂练习习题/必修二/Attachments/26b102de2eb5808f5d892f0c1bc79cfb.png)
<span class="fake-tag">答案</span>2 n mile．
<span class="fake-tag">详解</span>由题意$\left| \overrightarrow{O A} \right| = \frac{1}{\cos ( 90 {^\circ} - 30 {^\circ} )} = 2$，
所以向量的长度为2 n mile．
