(5)$u = 2 x - 1$，$y_{x}^{'} = \frac{2}{3} ( 2 x - 1 )^{- \frac{2}{3}}$ (6)$u = - x + 1$，$y_{x}^{'} = - \frac{1}{\cos^{2} ( - x + 1 )}$

（2）令，因为$y_{x}^{'} = y_{u}^{'} \cdot u_{x}^{'}$，

= - \left( \frac{\sin u}{\cos u} \right)^{'}
$= - \frac{\left( \sin u \right)^{'} \cos u - \sin u \left( \cos u \right)^{'}}{\cos^{2} u}$
= - \frac{\cos^{2} u + \sin^{2} u}{\cos^{2} u}
$= - \frac{1}{\cos^{2} u}$

##### 【变式1】（2023·全国·高二随堂练习）写出下列函数的中间变量，并利用复合函数的求导法则分别求出函数的导数：
(1)$y = \frac{1}{( 2 x - 1 )^{2}}$； (2)$y = \sin ( - x + 1 )$；
(3)$y = e^{- 2 x + 1}$； (4)$y = \cos ( x + 3 )$．
<span class="fake-tag">答案</span>(1)中间变量为$t = 2 x - 1$，$- \frac{4}{( 2 x - 1 )^{3}}$
(2)中间变量为$t = - x + 1$，$- \cos ( x - 1 )$
(3)中间变量为$t = - 2 x + 1$，$- 2 e^{- 2 x + 1}$
(4)中间变量为$t = x + 3$，$- \sin ( x + 3 )$
<span class="fake-tag">详解</span>（1）对于$y = \frac{1}{( 2 x - 1 )^{2}}$，中间变量为$t = 2 x - 1$，则$y = \frac{1}{t^{2}} = t^{- 2}$，
所以$y^{'} = \left( t^{- 2} \right)^{'} ( 2 x - 1 )^{'} = - 2 t^{- 3} \times 2 = - \frac{4}{t^{3}} = - \frac{4}{( 2 x - 1 )^{3}}$.
（2）对于$y = \sin ( - x + 1 )$，中间变量为$t = - x + 1$，则$y = \sin t$，
所以$y^{'} = \left( \sin t \right)^{'} ( - x + 1 )^{'} = - \cos t = - \cos ( - x + 1 ) = - \cos ( x - 1 )$.
（3）对于$y = e^{- 2 x + 1}$，中间变量为$t = - 2 x + 1$，则$y = e^{t}$，
所以$y^{'} = \left( e^{t} \right)^{'} ( - 2 x + 1 )^{'} = - 2 e^{t} = - 2 e^{- 2 x + 1}$.
（4）对于$y = \cos ( x + 3 )$，中间变量为$t = x + 3$，则$y = \cos t$，
$y^{'} = \left( \cos t \right)^{'} ( x + 3 )^{'} = - \sin t = - \sin ( x + 3 )$.
