##### 【典例2】（25-26高一上·全国·课后作业）已知角的终边经过点$( 2 a + 1 , a - 2 )$，且$\text{cos} \theta = \frac{3}{5}$，则实数$a =$ ．
<span class="fake-tag">答案</span>$\frac{2}{11}$
<span class="fake-tag">分析</span>根据任意角的三角函数定义计算求参即可.
<span class="fake-tag">详解</span>由题设，可知$\frac{2 a + 1}{\sqrt{( 2 a + 1 )^{2} + ( a - 2 )^{2}}} = \frac{3}{5}$，且$2 a + 1 > 0$，即$a > - \frac{1}{2}$，
$\therefore \frac{4 a^{2} + 4 a + 1}{5 a^{2} + 5} = \frac{9}{25}$，则$11 a^{2} + 2 0 a - 4 = 0$，
解得$a = - 2$（舍）或$a = \frac{2}{11}$，综上，$a = \frac{2}{11}$．
故答案为：$\frac{2}{11}$
##### 【典例3】（23-24高一下·河南·阶段练习）已知角的终边经过点$P ( 4 , m )$，若$\sin \theta = - \frac{\sqrt{5}}{5}$，则实数$m =$ ．
<span class="fake-tag">答案</span>$- 2$
<span class="fake-tag">分析</span>由三角函数的定义求出角的正弦值，且$\sin \theta = - \frac{\sqrt{5}}{5}$，建立等式，求参数$m$的值即可；
<span class="fake-tag">详解</span>由于角的终边经过点$P ( 4 , m )$，
由角正弦的定义得：$\sin \theta = \frac{m}{\sqrt{4^{2} + m^{2}}}$，且$\sin \theta = - \frac{\sqrt{5}}{5}$，
得：$\frac{m}{\sqrt{4^{2} + m^{2}}} = - \frac{\sqrt{5}}{5}$，解方程得：$5 m^{2} = m^{2} + 4$，
即$m^{2} = 4$，得$m = \pm 2$，
由于$\frac{m}{\sqrt{4^{2} + m^{2}}} = - \frac{\sqrt{5}}{5} < 0$，则$m < 0$，
所以$m = - 2$．
故答案是：$- 2$.

##### 【变式2】（23-24高一下·江西抚州·期中）已知角$\alpha$的终边经过点$( - 3 , m )$，若$\tan \alpha = \frac{2}{3}$，则（ ）
$\quad$A．$- \frac{2 \sqrt{13}}{13}$ 
$\quad$B．$\frac{2 \sqrt{13}}{13}$ 
$\quad$C．$- \frac{3 \sqrt{13}}{13}$ 
$\quad$D．$\frac{3 \sqrt{13}}{13}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>根据三角函数的定义求出$m$，再由三角函数的定义计算可得.
<span class="fake-tag">详解</span>因为角$\alpha$的终边经过点$( - 3 , m )$，且$\tan \alpha = \frac{2}{3}$，
所以$\text{tan} \alpha = - \frac{m}{3} = \frac{2}{3}$，解得$m = - 2$，
所以$\text{sin} \alpha = \frac{- 2}{\sqrt{( - 3 )^{2} + ( - 2 )^{2}}} = - \frac{2 \sqrt{13}}{13}$.
故选：A.
