##### 题型05 向量夹角问题
##### 【典例1】（2023上·北京海淀·高三北大附中校考阶段练习）已知向量$\overrightarrow{a}$，$\overrightarrow{b}$，$\overrightarrow{c}$满足$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = \left| \overrightarrow{c} \right| = 1$，且$\overrightarrow{a} + \overrightarrow{b} + \overrightarrow{c} = \overrightarrow{0}$，则$\cos \left\langle \overrightarrow{a} - \overrightarrow{c} , \overrightarrow{b} - \overrightarrow{c} \right\rangle =$（ ）
$\quad$A．$- \frac{\sqrt{3}}{2}$ 
$\quad$B．$- \frac{1}{2}$ 
$\quad$C．$\frac{1}{2}$ 
$\quad$D．$\frac{\sqrt{3}}{2}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>设$\overrightarrow{a} = \overrightarrow{O A} , \overrightarrow{b} = \overrightarrow{O B} , \overrightarrow{c} = \overrightarrow{O C}$，
因为$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = \left| \overrightarrow{c} \right| = 1$，$\overrightarrow{a} + \overrightarrow{b} + \overrightarrow{c} = \overrightarrow{0}$，
可知三点不共线，且$O$既是$\bigtriangleup A B C$的重心也是$\bigtriangleup A B C$的外心，
所以$\bigtriangleup A B C$为等边三角形，
![@@@10a97b4ae7494ce9960063e69f63c134](MathLogic-Weave/高中数学逻辑结构/题/Attachments/01bb48830165cb282638bbe75f899391.png)
则$\overrightarrow{a} - \overrightarrow{c} = \overrightarrow{O A} - \overrightarrow{O C} = \overrightarrow{C A} , \overrightarrow{b} - \overrightarrow{c} = \overrightarrow{O B} - \overrightarrow{O C} = \overrightarrow{C B}$，
所以$\cos \left\langle \overrightarrow{a} - \overrightarrow{c} , \overrightarrow{b} - \overrightarrow{c} \right\rangle = \cos \left\langle \overrightarrow{C A} , \overrightarrow{C B} \right\rangle = \cos \angle A C B = \frac{1}{2}$.
故选：C.
##### 【典例2】（2024上·贵州黔东南·高三天柱民族中学校考阶段练习）已知向量$\left| \overrightarrow{a} \right| = 2$，$\left| \overrightarrow{b} \right| = 1$，$\left| \overrightarrow{a} + 2 \overrightarrow{b} \right| = 2$，则$\left\langle \overrightarrow{a} , \overrightarrow{b} \right\rangle =$ .
<span class="fake-tag">答案</span>$\frac{2 \pi}{3}$
<span class="fake-tag">详解</span>由$| \overrightarrow{a} + 2 \overrightarrow{b} | = 2$可得$\left( \overrightarrow{a} + 2 \overrightarrow{b} \right)^{2} = 4$，
即$\left( \overrightarrow{a} \right)^{2} + 4 \overrightarrow{a} \mspace{6mu} \cdot \mspace{6mu} \overrightarrow{b} + 4 \left( \overrightarrow{b} \right)^{2} = 4$，即$\overrightarrow{a} \cdot \mspace{6mu} \overrightarrow{b} = - 1$，
所以$\text{cos} \left\langle \overrightarrow{a} , \mspace{6mu} \overrightarrow{b} \right\rangle = \frac{\overrightarrow{a} \cdot \overrightarrow{b}}{\left| \overrightarrow{a} \right| \left| \overrightarrow{b} \right|} = - \frac{1}{2}$，又$\left\langle \overrightarrow{a} , \overrightarrow{b} \right\rangle \in [ 0 , \pi ]$，
所以$\left\langle \overrightarrow{a} , \overrightarrow{b} \right\rangle = \frac{2 \pi}{3}$.
故答案为：$\frac{2 \pi}{3}$
##### 【典例3】（2023上·北京·高三101中学校考阶段练习）已知$\left| \overrightarrow{a} \right| = 1$，$\left| \overrightarrow{b} \right| = \sqrt{2}$，，若$\overrightarrow{a} + t \overrightarrow{b}$与$t \overrightarrow{a} + \overrightarrow{b}$的夹角为锐角，则实数*t*的取值范围是 ．
<span class="fake-tag">答案</span>$\left( \frac{3 - \sqrt{5}}{2} , 1 \right) \cup \left( 1 , \frac{3 + \sqrt{5}}{2} \right)$
<span class="fake-tag">详解</span>因为$\overrightarrow{a} + t \overrightarrow{b}$与$t \overrightarrow{a} + \overrightarrow{b}$的夹角为锐角，又$\text{cos} \overrightarrow{a} + t \overrightarrow{b} , t \overrightarrow{a} + \overrightarrow{b} = \frac{( \overrightarrow{a} + t \overrightarrow{b} ) \cdot ( t \overrightarrow{a} + \overrightarrow{b} )}{\left| \overrightarrow{a} + t \overrightarrow{b} \right| \cdot \left| t \overrightarrow{a} + \overrightarrow{b} \right|}$，
所以$( \overrightarrow{a} + t \overrightarrow{b} ) \cdot ( t \overrightarrow{a} + \overrightarrow{b} ) = t \overrightarrow{a}^{2} + ( 1 + t^{2} ) \overrightarrow{a} \cdot \overrightarrow{b} + t \overrightarrow{b}^{2} > 0$，
又$\left| \overrightarrow{a} \right| = 1$，$\left| \overrightarrow{b} \right| = \sqrt{2}$，，所以$t - ( 1 + t^{2} ) + 2 t = - t^{2} + 3 t - 1 > 0$，
解得$\frac{3 - \sqrt{5}}{2} < t < \frac{3 + \sqrt{5}}{2}$，又因$\overrightarrow{a} + t \overrightarrow{b} , t \overrightarrow{a} + \overrightarrow{b} \in [ 0 , \pi ]$，
当$\overrightarrow{a} + t \overrightarrow{b} , t \overrightarrow{a} + \overrightarrow{b} = 0$时，也满足$( \overrightarrow{a} + t \overrightarrow{b} ) \cdot ( t \overrightarrow{a} + \overrightarrow{b} ) > 0$，此时不合题意，
当$\overrightarrow{a} + t \overrightarrow{b}$与$t \overrightarrow{a} + \overrightarrow{b}$共线同向时，有$\overrightarrow{a} + t \overrightarrow{b} = \mu ( t \overrightarrow{a} + \overrightarrow{b} )$，从而得到$\begin{cases}1 = \mu t \\ \mu = t\end{cases}$，解得$t = \pm 1$，
又$- 1 < \frac{3 - \sqrt{5}}{2}$，所以实数*t*的取值范围是$\left( \frac{3 - \sqrt{5}}{2} , 1 \right) \cup \left( 1 , \frac{3 + \sqrt{5}}{2} \right)$，
故答案为：$\left( \frac{3 - \sqrt{5}}{2} , 1 \right) \cup \left( 1 , \frac{3 + \sqrt{5}}{2} \right)$.
##### 【变式1】（2024上·江西·高三校联考阶段练习）已知平面向量$\overrightarrow{a}$、$\overrightarrow{b}$满足$\left| \overrightarrow{b} \right| = 2 \left| \overrightarrow{a} \right| = 2$，若$\overrightarrow{a} \bot \left( \overrightarrow{a} + \overrightarrow{b} \right)$，则$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为（ ）
$\quad$A．$\frac{\pi}{6}$ 
$\quad$B．$\frac{5 \pi}{6}$ 
$\quad$C．$\frac{\pi}{3}$ 
$\quad$D．$\frac{2 \pi}{3}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>因为$\left| \overrightarrow{b} \right| = 2 \left| \overrightarrow{a} \right| = 2$，且$\overrightarrow{a} \bot \left( \overrightarrow{a} + \overrightarrow{b} \right)$，所以$\overrightarrow{a} \cdot \left( \overrightarrow{a} + \overrightarrow{b} \right) = 0$，即$\overrightarrow{a}^{2} + \overrightarrow{a} \cdot \overrightarrow{b} = 0$，
所以$\overrightarrow{a} \cdot \overrightarrow{b} = - \overrightarrow{a}^{2} = - 1$，
设$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$\theta$，则$\cos \theta = \frac{\overrightarrow{a} \cdot \overrightarrow{b}}{\left| \overrightarrow{a} \right| \cdot \left| \overrightarrow{b} \right|} = \frac{- 1}{2 \times 1} = - \frac{1}{2}$，因为$\theta \in [ 0 , \pi ]$，
所以$\theta = \frac{2 \pi}{3}$，即$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$\frac{2 \pi}{3}$.
故选：D

##### 【变式3】（2023上·北京怀柔·高三北京市怀柔区第一中学校考阶段练习）已知平面向量$\overrightarrow{a}$，$\overrightarrow{b}$满足$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = 1$，$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$6 0 {^\circ}$，若$\overrightarrow{a} + \overrightarrow{b}$与$t \overrightarrow{a} - \overrightarrow{b}$的夹角为钝角，则一个满足条件的$t$的值可以为 ．
<span class="fake-tag">答案</span>$0$（答案不唯一，只要满足$t \in ( - \infty , - 1 ) \cup ( - 1 , 1 )$即可）
<span class="fake-tag">详解</span>因为$\left| \overrightarrow{a} \right| = \left| \overrightarrow{b} \right| = 1$，$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$60 {^\circ}$，
所以$\overrightarrow{a} \cdot \overrightarrow{b} = \frac{1}{2}$，
因为$\overrightarrow{a} + \overrightarrow{b}$与$t \overrightarrow{a} - \overrightarrow{b}$的夹角为钝角，
所以$\left( \overrightarrow{a} + \overrightarrow{b} \right) \cdot \left( t \overrightarrow{a} - \overrightarrow{b} \right) < 0$且这两个向量不共线，
$\left( \overrightarrow{a} + \overrightarrow{b} \right) \cdot \left( t \overrightarrow{a} - \overrightarrow{b} \right) = t \overrightarrow{a}^{2} + ( t - 1 ) \overrightarrow{a} \cdot \overrightarrow{b} - \overrightarrow{b}^{2} = \frac{3}{2} t - \frac{3}{2} < 0$，解得$t < 1$，
当$\left( \overrightarrow{a} + \overrightarrow{b} \right) \text{//} \left( t \overrightarrow{a} - \overrightarrow{b} \right)$时，
存在唯一实数$\lambda$，使得$t \overrightarrow{a} - \overrightarrow{b} = \lambda \left( \overrightarrow{a} + \overrightarrow{b} \right) = \lambda \overrightarrow{a} + \lambda \overrightarrow{b}$，
所以$\begin{cases}t = \lambda \\ - 1 = \lambda\end{cases}$，所以$t = \lambda = - 1$，
又$\left( \overrightarrow{a} + \overrightarrow{b} \right) , \left( t \overrightarrow{a} - \overrightarrow{b} \right)$不共线，所以$t \neq - 1$，
综上所述，$t \in ( - \infty , - 1 ) \cup ( - 1 , 1 )$，
所以满足条件的$t$的值可以为$0$.
