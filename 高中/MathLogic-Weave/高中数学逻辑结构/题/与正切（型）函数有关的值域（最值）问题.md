故函数$f ( x ) = \sqrt{3 - \tan^{2} x}$的定义域是$\left\lbrack k \pi - \frac{\pi}{3} , k \pi + \frac{\pi}{3} \right\rbrack \left( k \in \mathbf{Z} \right)$；

##### 【变式2】（24-25高一上·上海·课堂例题）求函数的最大值和最小值.
<span class="fake-tag">答案</span>最大值为$2 \sqrt{2}$，最小值为$- 2 \sqrt{2}$.
<span class="fake-tag">分析</span>结合分离常数法和基本不等式，然后分类讨论即可求解.
<span class="fake-tag">详解</span>解：①当时，$y = 0$；
②$\text{tan} x > 0$时，$y = \frac{8}{2 \text{tan} x + \frac{1}{\text{tan} x}}$，
由$2 \text{tan} x + \frac{1}{\text{tan} x} \geq 2 \sqrt{2}$可知$y \leq \frac{8}{2 \sqrt{2}} = 2 \sqrt{2}$，
当且仅当$2 \text{tan} x = \frac{1}{\text{tan} x}$，即$\text{tan} x = \frac{\sqrt{2}}{2}$时等号成立，∴$0 < y \leq 2 \sqrt{2}$.
③当$\text{tan} x < 0$时，$y = \frac{8}{2 \text{tan} x + \frac{1}{\text{tan} x}}$，
由$- 2 \tan x + \frac{1}{- \tan x} \geq 2 \sqrt{2}$知$2 \tan x + \frac{1}{\tan x} \leq - 2 \sqrt{2}$，当且仅当$\tan x = - \frac{\sqrt{2}}{2}$,故$\frac{8}{- 2 \sqrt{2}} \leq y < 0$，即$- 2 \sqrt{2} \leq y < 0$.
综上，$y$的最大值为$2 \sqrt{2}$，最小值为$- 2 \sqrt{2}$.
##### 【变式3】（24-25高一上·上海·课堂例题）求函数$y = \text{ta} \text{n}^{2} x - 2 \text{tan} x$，$x \in \left\lbrack - \frac{\pi}{3} , \frac{\pi}{3} \right\rbrack$的值域.
<span class="fake-tag">答案</span>$\left\lbrack - 1 , 3 + 2 \sqrt{3} \right\rbrack$.
<span class="fake-tag">分析</span>应用复合函数的单调性，结合正切函数及二次函数求值域即可.
<span class="fake-tag">详解</span>$y = \text{ta} \text{n}^{2} x - 2 \text{tan} x = \left( \text{tan} x - 1 \right)^{2} - 1$.
∵$x \in \left\lbrack - \frac{\pi}{3} , \frac{\pi}{3} \right\rbrack$，∴$\text{tan} x \in \left\lbrack - \sqrt{3} , \sqrt{3} \right\rbrack$.
当$\text{tan} x = 1$，即$x = \frac{\pi}{4}$时，*y*取最小值-1；
当$\text{tan} x = - \sqrt{3}$，即$x = - \frac{\pi}{3}$时，*y*取最大值$3 + 2 \sqrt{3}$.
∴函数的值域为$\left\lbrack - 1 , 3 + 2 \sqrt{3} \right\rbrack$.
