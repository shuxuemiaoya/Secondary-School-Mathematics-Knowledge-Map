##### 题型12$\mathbf{1} \mathbf{5}^{\mathbf{\circ}}$（$\mathbf{7} \mathbf{5}^{\mathbf{\circ}}$）的正切值
##### 【典例1】（23-24高一下·四川内江·阶段练习）$\tan 1 5^{^\circ} =$（ ）．
$\quad$A．$\frac{\sqrt{6} + \sqrt{2}}{4}$ 
$\quad$B．$\frac{\sqrt{6} - \sqrt{2}}{4}$ 
$\quad$C．$2 + \sqrt{3}$ 
$\quad$D．
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>由$\tan 1 5^{^\circ} = \tan \left( 4 5^{^\circ} - 3 0^{^\circ} \right)$，利用两角差的正切公式计算可得.
<span class="fake-tag">详解</span>$\tan 1 5^{^\circ} = \tan \left( 4 5^{^\circ} - 3 0^{^\circ} \right)$
$= \frac{\tan 4 5^{^\circ} - \tan 3 0^{^\circ}}{1 + \tan 4 5^{^\circ} \tan 3 0^{^\circ}} = \frac{1 - \frac{\sqrt{3}}{3}}{1 + 1 \times \frac{\sqrt{3}}{3}} = 2 - \sqrt{3}$.
故选：D
##### 【典例2】（23-24高一上·广东广州·期末）$\tan 1 5 {^\circ} + \tan 7 5 {^\circ} =$ ．
<span class="fake-tag">答案</span>4
<span class="fake-tag">分析</span>，然后化简求值即可．
<span class="fake-tag">详解</span>解：
$= \frac{\tan 4 5 {^\circ} - \tan 3 0 {^\circ}}{1 + \tan 4 5 {^\circ} \tan 3 0 {^\circ}} + \frac{\tan 4 5 {^\circ} + \tan 3 0 {^\circ}}{1 - \tan 4 5 {^\circ} \tan 3 0 {^\circ}}$
$= 4$．
故答案为：$4$．
##### 【典例3】（23-24高三上·河北·阶段练习） ．
<span class="fake-tag">答案</span>$2 + \sqrt{3}$
<span class="fake-tag">分析</span>由，由诱导公式结合正切的和角公式可得出答案.
<span class="fake-tag">详解</span>$\tan \frac{1 7 \pi}{12} = \tan \left( \pi + \frac{5 \pi}{12} \right) = \tan \frac{5 \pi}{12} = \tan \left( \frac{\pi}{6} + \frac{\pi}{4} \right) = \frac{\frac{\sqrt{3}}{3} + 1}{1 - \frac{\sqrt{3}}{3}} = 2 + \sqrt{3}$．
故答案为：$2 + \sqrt{3}$
【点睛】本题考查诱导公式可正切的和角公式的应用，属于基础题
##### 【变式1】（23-24高一下·陕西榆林·期末）$\tan 7 5 {^\circ} =$（ ）
$\quad$A． 
$\quad$B．$2 + \sqrt{3}$ 
$\quad$C．$\sqrt{3} - 2$ 
$\quad$D．$3 - \sqrt{3}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>根据两角和的正切公式计算可得；
<span class="fake-tag">详解</span>解：$\tan 7 5 {^\circ} = \tan ( 45 {^\circ} + 3 0 {^\circ} ) = \frac{\tan 4 5 {^\circ} + \tan 3 0 {^\circ}}{1 - \tan 4 5 {^\circ} \tan 3 0 {^\circ}} = \frac{1 + \frac{\sqrt{3}}{3}}{1 - 1 \times \frac{\sqrt{3}}{3}} = 2 + \sqrt{3}$
故选：B
##### 【变式2】（23-24高一下·江苏徐州·期中）$\tan 1 0 5^{o}$的值为（ ）
$\quad$A． 
$\quad$B．$- 2 - \sqrt{3}$ 
$\quad$C．$- 2 + \sqrt{3}$ 
$\quad$D．
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>根据$\tan 1 05 {^\circ} = \tan ( 45 {^\circ} + 6 0 {^\circ} )$，利用两角和的正切公式即可得出答案.
<span class="fake-tag">详解</span>解：$\tan 1 05 {^\circ} = \tan ( 45 {^\circ} + 6 0 {^\circ} ) = \frac{\tan 4 5 {^\circ} + \tan 6 0 {^\circ}}{1 - \tan 4 5 {^\circ} \cdot \tan 6 0 {^\circ}} = \frac{1 + \sqrt{3}}{1 - \sqrt{3}} = - 2 - \sqrt{3}$.
故选：B.
##### 【变式3】（23-24高一·江苏·课后作业）求值：$\tan \frac{1 1 \pi}{12} =$ .
<span class="fake-tag">答案</span>$- 2 + \sqrt{3}$

故答案为：$- 2 + \sqrt{3}$.
