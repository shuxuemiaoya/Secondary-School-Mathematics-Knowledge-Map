##### 题型01三角形中中线长（定值）
##### 【典例1】（2023下·辽宁·高一校联考期末）在$\bigtriangleup A B C$中，角*A*，*B*，*C*的对边分别为*a*，*b*，*c*，向量$\overrightarrow{m} = ( a , b )$与$\overrightarrow{n} = \left( \cos A , \sin B \right)$平行．若$c = 2$，$b = \sqrt{2}$，则*BC*边上的中线*AD*为（ ）
$\quad$A．1 
$\quad$B．2 
$\quad$C．$\sqrt{10}$ 
$\quad$D．$\frac{\sqrt{10}}{2}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>由于向量$\overrightarrow{m} = ( a , b )$与$\overrightarrow{n} = \left( \cos A , \sin B \right)$平行，
所以$a \sin B = b \cos A$，由正弦定理得$\sin A \sin B = \sin B \cos A$，
由于$\sin B > 0$所以$\sin A = \cos A$，
由于$0 < A < \pi$，所以$A = \frac{\pi}{4}$.
$\overrightarrow{A D} = \frac{1}{2} \left( \overrightarrow{A B} + \overrightarrow{A C} \right)$，两边平方得$\overrightarrow{A D}^{2} = \frac{1}{4} \left( \overrightarrow{A B}^{2} + 2 \overrightarrow{A B} \cdot \overrightarrow{A C} + \overrightarrow{A C}^{2} \right)$= \frac{1}{4} \left( 4 + 2 \times 2 \times \sqrt{2} \times \cos \frac{\pi}{4} + 2 \right) = \frac{10}{4} = \frac{5}{2}$，
所以$\left| \overrightarrow{A D} \right| = \frac{\sqrt{10}}{2}$.
故选：D

##### 【典例3】（2023下·浙江杭州·高二校联考期中）已知$\bigtriangleup A B C$的内角*A*，*B*，*C*的对边分别为*a*，*b*，*c*，$2 a \cos B = 2 c + b$．
(1)求*A*；
(2)若$a = 4 , b + c = 2 \sqrt{5}$，求$\bigtriangleup A B C$中*BC*边中线*AD*长．
<span class="fake-tag">答案</span>(1)$A = \frac{2 \pi}{3}$
(2)$A D = \sqrt{2}$
<span class="fake-tag">详解</span>（1）因为$2 a \cos B = 2 c + b$，
由正弦定理得$2 \sin A \cos B = 2 \sin C + \sin B$，
即$2 \sin A \cos B = 2 \sin ( A + B ) + \sin B$，
即$2 \sin A \cos B = 2 \sin A \cos B + 2 \cos A \sin B + \sin B$，
所以$2 \cos A \sin B + \sin B = 0$，
又$\sin B > 0$，所以$\cos A = - \frac{1}{2}$，
又$A \in ( 0 , \pi )$，所以$A = \frac{2 \pi}{3}$；
（2）由余弦定理得$a^{2} = b^{2} + c^{2} - 2 b c \cos \angle B A C = ( b + c )^{2} - b c$，
即，所以$b c = 4$，
因为$A D$为$\bigtriangleup A B C$中*BC*边的中线，
所以$\overrightarrow{A D} = \frac{1}{2} \left( \overrightarrow{A B} + \overrightarrow{A C} \right)$，
则$\left| \overrightarrow{A D} \right| = \frac{1}{2} \sqrt{\left( \overrightarrow{A B} + \overrightarrow{A C} \right)^{2}} = \frac{1}{2} \sqrt{\overrightarrow{A B}^{2} + \overrightarrow{A C}^{2} + 2 \overrightarrow{A B} \cdot \overrightarrow{A C}}$
$= \frac{1}{2} \sqrt{c^{2} + b^{2} + 2 b c \cos \frac{2 \pi}{3}} = \frac{1}{2} \sqrt{( c + b )^{2} - 3 b c} = \frac{1}{2} \sqrt{20 - 12} = \sqrt{2}$，
所以$A D = \sqrt{2}$.

##### 【变式1】（2022·江苏南通·统考模拟预测）已知$\bigtriangleup A B C$的面积为$2 \sqrt{3} , A B = 2 , A C = 4$，则$\bigtriangleup A B C$的中线$A D$长的一个值为 .
<span class="fake-tag">答案</span>$\sqrt{7}$或$\sqrt{3}$
<span class="fake-tag">详解</span>因为$\bigtriangleup A B C$的面积为$2 \sqrt{3} , A B = 2 , A C = 4$，
所以$S_{\bigtriangleup A B C} = \frac{1}{2} A B \cdot A C \sin A = 4 \sin A = 2 \sqrt{3} \Rightarrow \sin A = \frac{\sqrt{3}}{2}$，
故$A = \frac{\pi}{3}$或$\frac{2 \pi}{3}$；
①当$A = \frac{\pi}{3}$时，$B C^{2} = A B^{2} + A C^{2} - 2 A B \cdot A C \cos A = 1 2 \Rightarrow B C = 2 \sqrt{3}$，
故$B D = \frac{1}{2} B C = \sqrt{3}$，
因为$A B^{2} + B C^{2} = A C^{2}$，所以$A B \bot B C$，
故$A D^{2} = A B^{2} + B D^{2} = 7 \Rightarrow A D = \sqrt{7}$；
②当$A = \frac{2 \pi}{3}$时，$B C^{2} = A B^{2} + A C^{2} - 2 A B \cdot A C \cos A = 2 8 \Rightarrow B C = 2 \sqrt{7}$，
故$B D = \frac{1}{2} B C = \sqrt{7}$，
在$\bigtriangleup A B C$中，由余弦定理可知$\cos B = \frac{A B^{2} + B C^{2} - A C^{2}}{2 A B \cdot B C} = \frac{2 \sqrt{7}}{7}$，
在$\bigtriangleup A B D$中，由余弦定理可知，$A D^{2} = A B^{2} + B D^{2} - 2 A B \cdot B D \cos B = 3$，
故$A D = \sqrt{3}$.
综上所述，$\bigtriangleup A B C$的中线$A D$长为$\sqrt{7}$或.
故答案为：$\sqrt{7}$或.

##### 【变式3】20．（2023上·安徽·高三宿城一中校联考阶段练习）在$\bigtriangleup A B C$中，内角*A*，*B*，*C*所对边的长分别为*a*，*b*，*c*，且满足$a + c = b \left( \sqrt{3} \text{sin} A + \text{cos} A \right)$.
(1)求*B*；
(2)若$b = 3$，且$\bigtriangleup A B C$的面积为，$B D$是$\bigtriangleup A B C$的中线，求$B D$的长.
<span class="fake-tag">答案</span>(1)$B = \frac{\pi}{3}$
(2)$\frac{\sqrt{17}}{2}$
<span class="fake-tag">详解</span>（1）因为$a + c = b \left( \sqrt{3} \text{sin} A + \text{cos} A \right)$，
由正弦定理可得$\text{sin} A + \text{sin} C = \text{sin} B \left( \sqrt{3} \text{sin} A + \text{cos} A \right)$，
即$\text{sin} A + \text{sin} ( A + B ) = \text{sin} B \left( \sqrt{3} \text{sin} A + \text{cos} A \right)$，
即$\text{sin} A + \text{sin} A \text{cos} B = \sqrt{3} \text{sin} A \text{sin} B$，
又因为$\text{sin} A > 0$，所以$\sqrt{3} \text{sin} B - \text{cos} B = 1$，所以$\text{sin} \left( B - \frac{\pi}{6} \right) = \frac{1}{2}$.
又因为$B \in ( 0 , \pi )$，所以$B - \frac{\pi}{6} \in \left( - \frac{\pi}{6} , \frac{5 \pi}{6} \right)$，
所以$B - \frac{\pi}{6} = \frac{\pi}{6}$，所以$B = \frac{\pi}{3}$.
（2）因为$S_{\bigtriangleup A B C} = \sqrt{3}$，所以$\frac{1}{2} a c \text{sin} B = \sqrt{3}$得$a c = 4$，
由余弦定理得：$a^{2} + c^{2} = b^{2} + 2 a c \text{cos} B = 1 3$.
又$\overrightarrow{B D} = \frac{1}{2} \left( \overrightarrow{B A} + \overrightarrow{B C} \right)$，
所以$| \overrightarrow{B D} |^{2} = \frac{1}{4} ( \overrightarrow{B A} + \overrightarrow{B C} )^{2} = \frac{1}{4} \left( c^{2} + a^{2} + 2 a c \text{cos} B \right) = \frac{17}{4}$，
得$\left| \overrightarrow{B D} \right| = \frac{\sqrt{17}}{2}$，故$B D$的长为$\frac{\sqrt{17}}{2}$.
