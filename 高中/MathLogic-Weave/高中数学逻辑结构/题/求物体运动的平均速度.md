##### 题型01 求物体运动的平均速度(含平均变化率）
##### 【典例1】（2023下·河南新乡·高二统考期中）某物体沿直线运动，其位移（单位：$m$）与时间$t$（单位：$s$）之间的关系为$s ( t ) = \frac{1}{4} t^{2} + t$，则在$1 \leq t \leq 4$这段时间内，该物体的平均速度为（ ）
$\quad$A．$2 \text{m/s}$ 
$\quad$B．$\frac{9}{4} \text{m/s}$ 
$\quad$C．$\frac{11}{4} \text{m/s}$ 
$\quad$D．$3 \text{m/s}$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由位移与时间$t$之间的关系为$s ( t ) = \frac{1}{4} t^{2} + t$，
根据平均变化率的计算公式，可得在$1 \leq t \leq 4$这段时间内，该物体的平均速度为：
$\overline{v} = \frac{s ( 4 ) - s ( 1 )}{4 - 1} = \frac{9}{4} \text{m/s}$
故选：B.
