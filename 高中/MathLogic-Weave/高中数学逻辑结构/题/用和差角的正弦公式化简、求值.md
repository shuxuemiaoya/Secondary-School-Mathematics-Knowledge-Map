##### 题型09用和差角的正弦公式化简、求值
##### 【典例1】（2024高三·北京·专题练习）已知$\alpha , \beta \in \left( \frac{3 \pi}{4} , \pi \right)$，$\sin ( \alpha + \beta ) = - \frac{3}{5}$，$\sin \left( \beta - \frac{\pi}{4} \right) = \frac{24}{25}$，则$\sin \left( \alpha + \frac{\pi}{4} \right) =$ .
<span class="fake-tag">答案</span>$- \frac{3}{5}$/$- 0 . 6$
<span class="fake-tag">分析</span>结合角的范围利用同角三角函数基本关系求得$\cos ( \alpha + \beta ) = \frac{4}{5}$和$\cos \left( \beta - \frac{\pi}{4} \right) = - \frac{7}{25}$，然后利用拼凑角思想和两角差的正弦公式化简求值即可.
<span class="fake-tag">详解</span>由题意知，$\alpha + \beta \in \left( \frac{3 \pi}{2} , 2 \pi \right)$，又$\sin ( \alpha + \beta ) = - \frac{3}{5}$，
所以$\cos ( \alpha + \beta ) = \frac{4}{5}$，因为$\sin \left( \beta - \frac{\pi}{4} \right) = \frac{24}{25}$，$\beta - \frac{\pi}{4} \in \left( \frac{\pi}{2} , \frac{3 \pi}{4} \right)$，所以$\cos \left( \beta - \frac{\pi}{4} \right) = - \frac{7}{25}$，
所以$\sin \left( \alpha + \frac{\pi}{4} \right) = \sin \left\lbrack ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right) \right\rbrack = \sin ( \alpha + \beta ) \cos \left( \beta - \frac{\pi}{4} \right) - \cos ( \alpha + \beta ) \sin \left( \beta - \frac{\pi}{4} \right) = - \frac{3}{5}$．
故答案为：$- \frac{3}{5}$
##### 【典例2】（23-24高一下·广东湛江·期末）已知$\alpha , \beta \in \left( \frac{3 \pi}{4} , \pi \right)$，$\text{sin} ( \alpha + \beta ) = - \frac{3}{5}$，$\text{sin} \left( \beta - \frac{\pi}{4} \right) = \frac{\sqrt{2}}{2}$，则$\text{cos} \left( \alpha + \frac{\pi}{4} \right) =$ ．
<span class="fake-tag">答案</span>$- \frac{7 \sqrt{2}}{10}$
<span class="fake-tag">分析</span>根据同角三角关系求$\cos ( \alpha + \beta )$，$\cos \left( \beta - \frac{\pi}{4} \right)$，根据角的关系$\alpha + \frac{\pi}{4} = ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right)$，结合两角和差公式运算求解.
<span class="fake-tag">详解</span>因为$\alpha , \beta \in \left( \frac{3 \pi}{4} , \pi \right)$，则$\alpha + \beta \in \left( \frac{3 \pi}{2} , 2 \pi \right)$，$\beta - \frac{\pi}{4} \in \left( \frac{\pi}{2} , \frac{\text{3} \text{π}}{4} \right)$，
且$\text{sin} ( \alpha + \beta ) = - \frac{3}{5}$，$\text{sin} \left( \beta - \frac{\pi}{4} \right) = \frac{\sqrt{2}}{2}$，
可得$\cos ( \alpha + \beta ) = \sqrt{1 - \text{si} \text{n}^{2} ( \alpha + \beta )} = \frac{4}{5}$，$\cos \left( \beta - \frac{\pi}{4} \right) = - \sqrt{1 - \text{si} \text{n}^{2} \left( \beta - \frac{\pi}{4} \right)} = - \frac{\sqrt{2}}{2}$，
又因为$\alpha + \frac{\pi}{4} = ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right)$，
则$\cos \left( \alpha + \frac{\pi}{4} \right) = \cos \left\lbrack ( \alpha + \beta ) - \left( \beta - \frac{\pi}{4} \right) \right\rbrack$
$= \cos ( \alpha + \beta ) \cos \left( \beta - \frac{\pi}{4} \right) + \sin ( \alpha + \beta ) \sin \left( \beta - \frac{\pi}{4} \right)$= \frac{4}{5} \times \left( - \frac{\sqrt{2}}{2} \right) + \left( - \frac{3}{5} \right) \times \frac{\sqrt{2}}{2} = - \frac{7 \sqrt{2}}{10}$，
所以$\text{cos} \left( \alpha + \frac{\pi}{4} \right) = - \frac{7 \sqrt{2}}{10}$.
故答案为：$- \frac{7 \sqrt{2}}{10}$.
