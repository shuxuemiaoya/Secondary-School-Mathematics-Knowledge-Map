\subsection{一、选择题:本题共8小题,每小题5分,共40分.在每小题给出的四个选项中,只有一项是符合题目要求的.}\label{ux4e00ux9009ux62e9ux9898ux672cux9898ux51718ux5c0fux9898ux6bcfux5c0fux98985ux5206ux517140ux5206.ux5728ux6bcfux5c0fux9898ux7ed9ux51faux7684ux56dbux4e2aux9009ux9879ux4e2dux53eaux6709ux4e00ux9879ux662fux7b26ux5408ux9898ux76eeux8981ux6c42ux7684.}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  在复平面内, 复数 \(z\) 对应的点的坐标是 \((-1, -\sqrt{3})\) , 则 \(z\) 的共轭复数 \(z =\)

  \begin{itemize}
  \tightlist
  \item
    A. \(1 + \sqrt{3}\mathrm{i}\)
  \item
    B. \(1 - \sqrt{3}\mathrm{i}\)
  \item
    C. \(-1 + \sqrt{3}\mathrm{i}\)
  \item
    D. \(-1 - \sqrt{3}\mathrm{i}\)
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} C．\(-1+\sqrt{3}\mathrm{i}\)

  \textbf{分析：} 根据复数的几何表示确定实部和虚部，再利用共轭复数只改变虚部符号。

  \textbf{详细解析：}

  复数 \(z\) 对应点 \((-1,-\sqrt3)\)，所以 \(z=-1-\sqrt3\mathrm{i}\)。共轭复数只改变虚部的符号，故 \(\overline z=-1+\sqrt3\mathrm{i}\)。

  \end{examSolutionBox}
\item
  已知集合 \(A = \{-1, 0, 1, 2, 8\}\) , \(B = \{x \mid \sqrt[3]{x} = x\}\) , 则 \(A \cap B =\)

  \begin{itemize}
  \tightlist
  \item
    A. \(\{0, 1\}\)
  \item
    B. \(\{-1, 0, 1\}\)
  \item
    C. \(\{0, 2, 8\}\)
  \item
    D. \(\{0, 1, 2, 8\}\)
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} B．\(\{-1,0,1\}\)

  \textbf{分析：} 先解方程 \(\sqrt[3]{x}=x\) 求出集合 \(B\)，再与集合 \(A\) 取交集。

  \textbf{详细解析：}

  由 \(\sqrt[3]{x}=x\) 两边立方，得 \(x=x^3\)，即 \(x(x-1)(x+1)=0\)，所以 \(B=\{-1,0,1\}\)。这三个数都属于 \(A\)，故 \(A\cap B=\{-1,0,1\}\)。

  \end{examSolutionBox}
\item
  设 \(\vec{a}, \vec{b}\) 为单位向量，且 \(|\vec{a} - \vec{b}| = \sqrt{2}\) ，则 \(|\vec{a} + \vec{b}| =\)

  \begin{itemize}
  \tightlist
  \item
    A. 1
  \item
    B. \(\sqrt{2}\)
  \item
    C. \(\sqrt{3}\)
  \item
    D. 2
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} B．\(\sqrt2\)

  \textbf{分析：} 利用向量和、差的模平方公式先求 \(\vec a\cdot\vec b\)，再计算 \(|\vec a+\vec b|\)。

  \textbf{详细解析：}

  因为 \(\vec a,\vec b\) 都是单位向量，
  \[
  |\vec a-\vec b|^2=|\vec a|^2+|\vec b|^2-2\vec a\cdot\vec b
  =2-2\vec a\cdot\vec b=2,
  \]
  所以 \(\vec a\cdot\vec b=0\)。于是
  \[
  |\vec a+\vec b|^2=|\vec a|^2+|\vec b|^2+2\vec a\cdot\vec b=2,
  \]
  故 \(|\vec a+\vec b|=\sqrt2\)。

  \end{examSolutionBox}
\item
  已知 \(\dfrac{\sin(\alpha+\beta)}{\sin(\alpha-\beta)}=3\) ，则 \(\dfrac{\tan\alpha}{\tan\beta}=\)

  \begin{itemize}
  \tightlist
  \item
    A. \(\dfrac{1}{3}\)
  \item
    B. \(\dfrac{1}{2}\)
  \item
    C. 2
  \item
    D. 3
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} C．\(2\)

  \textbf{分析：} 展开正弦和差公式并整理，得到 \(\sin\alpha\cos\beta\) 与 \(\cos\alpha\sin\beta\) 的比例关系。

  \textbf{详细解析：}

  将条件展开：
  \[
  \sin\alpha\cos\beta+\cos\alpha\sin\beta
  =3(\sin\alpha\cos\beta-\cos\alpha\sin\beta).
  \]
  整理得 \(\sin\alpha\cos\beta=2\cos\alpha\sin\beta\)。原式有意义且满足给定比值时，相关分母不为零，因此
  \[
  \frac{\tan\alpha}{\tan\beta}=2.
  \]

  \end{examSolutionBox}
\end{enumerate}

\item
  某中学举办田径运动会, 某班从甲、乙等6名学生中选4名学生代表班级参加学校 \(4 \times 1\) 米接力赛, 其中甲只能跑第1棒或第2棒, 乙只能跑第2棒或第4棒, 那么甲、乙都参加不同棒次安排方案总数为

  \begin{itemize}
  \tightlist
  \item
    A. 12
  \item
    B. 24
  \item
    C. 30
  \item
    D. 36
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} D．\(36\)

  \textbf{分析：} 先枚举甲、乙可占据的不同棒次组合，再选择并排列其余两名学生。

  \textbf{详细解析：}

  甲、乙所在棒次的有序组合只能是 \((1,2)\)、\((1,4)\)、\((2,4)\)，共 \(3\) 种。从其余 \(4\) 人中选出 \(2\) 人有 \(\binom42=6\) 种，再将这两人安排到剩余两个棒次有 \(2!\) 种。因此方案总数为
  \[
  3\binom42\cdot2!=3\times6\times2=36.
  \]

  \end{examSolutionBox}
\item
  长方体的一条体对角线与它在一个顶点处的三个面所成的角分别为 \(\alpha, \beta, \gamma\) ，则

  \begin{itemize}
  \tightlist
  \item
    A. \(\sin^2\alpha + \sin^2\beta + \sin^2\gamma = 1\)
  \item
    B. \(\sin^2\alpha + \sin^2\beta + \sin^2\gamma = 2\)
  \item
    C. \(\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 3\)
  \item
    D. \(\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1\)
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} A．\(\sin^2\alpha+\sin^2\beta+\sin^2\gamma=1\)

  \textbf{分析：} 把体对角线在三条互相垂直棱方向上的分量与线面角的正弦对应起来。

  \textbf{详细解析：}

  设长方体从同一顶点出发的三条棱长分别为 \(a,b,c\)，体对角线长为 \(d=\sqrt{a^2+b^2+c^2}\)。直线与三个相邻面的夹角的正弦分别等于体对角线在三个对应法向方向上的分量与 \(d\) 的比，因此可记为 \(\frac a d,\frac b d,\frac c d\)（次序不影响结论）。于是
  \[
  \sin^2\alpha+\sin^2\beta+\sin^2\gamma
  =\frac{a^2+b^2+c^2}{d^2}=1.
  \]

  \end{examSolutionBox}
\item
  设 P, Q 分别为 \(x^{2} + (y - 6)^{2} = 2\) 和椭圆 \(\dfrac{x^{2}}{10} + y^{2} = 1\) 上的点，则 P, Q 两点间的最大距离是

  \begin{itemize}
  \tightlist
  \item
    A. \(5\sqrt{2}\)
  \item
    B. \(\sqrt{46} + \sqrt{2}\)
  \item
    C. \(7 + \sqrt{2}\)
  \item
    D. \(\triangle\sqrt{2}\)
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} \(6\sqrt2\)（按选项位置应为 D，但 D 的 OCR 文本``\(\triangle\sqrt2\)''存在歧义）

  \textbf{分析：} 先求椭圆上的点到圆心的最大距离，再加上圆的半径；选项 D 的 OCR 字符保持为歧义说明。

  \textbf{详细解析：}

  圆的圆心为 \(O(0,6)\)，半径为 \(\sqrt2\)。固定椭圆上的点 \(Q\) 后，圆上点 \(P\) 到 \(Q\) 的最大距离为 \(OQ+\sqrt2\)，所以只需求椭圆上 \(OQ\) 的最大值。设 \(Q(x,y)\)，由 \(\frac{x^2}{10}+y^2=1\) 得 \(x^2=10(1-y^2)\)，从而
  \[
  OQ^2=x^2+(y-6)^2
  =10(1-y^2)+(y-6)^2
  =50-9\left(y+\frac23\right)^2.
  \]
  当 \(y=-\frac23\) 时取得最大值 \(50\)，且该纵坐标满足椭圆条件，所以 \(\max OQ=5\sqrt2\)。因此
  \[
  \max PQ=5\sqrt2+\sqrt2=6\sqrt2.
  \]
  题目中 D 项的字符无法由 OCR 文本可靠辨认；这里只依据题目条件确定数值，不推断原图中的缺失字符。

  \end{examSolutionBox}
\item
  若存在 \(a \in R\) 且 \(a \neq 0\) , 对任意的 \(x \in R\) , 均有 \(f(x + a) < f(x) + f(a)\) 恒成立, 则称函数 \(f(x)\) 具有性质 \(P\) . 已知: \(q_{1}: f(x)\) 单调递减, 且 \(f(x) > 0\) 恒成立; \(q_{2}: f(x)\) 单调递增, 存在 \(x_{0} < 0\) 使得 \(f(x_{0}) = 0\) , 则是 \(f(x)\) 具有性质 \(P\) 的充分条件是

  \begin{itemize}
  \tightlist
  \item
    A. \(q_{1}\) 和 \(q_{2}\)
  \item
    B. 只有 \(q_{1}\)
  \item
    C. 只有 \(q_{2}\)
  \item
    D. \(q_{1}\) 和 \(q_{2}\) 都不是
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} A

  \textbf{分析：} 分别验证条件 \(q_1\) 与 \(q_2\) 是否都能给出满足性质 \(P\) 的非零平移量。

  \textbf{详细解析：}

  对于 \(q_1\)，取任意 \(a>0\)。由 \(f(x)\) 单调递减，\(f(x+a)\leqslant f(x)\)，又 \(f(a)>0\)，故
  \[
  f(x+a)<f(x)+f(a),
  \]
  所以 \(q_1\) 是充分条件。对于 \(q_2\)，取题设中的 \(a=x_0<0\)，则 \(a\neq 0\) 且 \(f(a)=0\)。因为 \(x+a<x\)，由 \(f(x)\) 单调递增可得
  \[
  f(x+a)<f(x)=f(x)+f(a),
  \]
  所以 \(q_2\) 也是充分条件。因此应选 A。

  \end{examSolutionBox}
\end{enumerate}

\subsection{二、选择题: 大题共 3 小题, 每小题 6 分, 共 18 分. 在每小题给出的四个选项中, 有多项是符合题目要求的, 全部选对的得 6 分, 部分选对的得部分分, 有选错的得 0 分.}\label{ux4e8cux9009ux62e9ux9898-ux5927ux9898ux5171-3-ux5c0fux9898-ux6bcfux5c0fux9898-6-ux5206-ux5171-18-ux5206.-ux5728ux6bcfux5c0fux9898ux7ed9ux51faux7684ux56dbux4e2aux9009ux9879ux4e2d-ux6709ux591aux9879ux662fux7b26ux5408ux9898ux76eeux8981ux6c42ux7684-ux5168ux90e8ux9009ux5bf9ux7684ux5f97-6-ux5206-ux90e8ux5206ux9009ux5bf9ux7684ux5f97ux90e8ux5206ux5206-ux6709ux9009ux9519ux7684ux5f97-0-ux5206.}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\setcounter{enumi}{8}
\item
  已知曲线 \(C: mx^2 + ny^2 = 1\) ，下列说法正确的是

  \begin{itemize}
  \tightlist
  \item
    A. 若 \(m > n > 0\) ，则 \(C\) 是椭圆，其焦点在 \(y\) 轴上
  \item
    B. 若 \(m = n > 0\) ，则 \(C\) 是圆，其半径为 \(\sqrt{n}\)
  \item
    C. 若 \(mn < 0\) ，则 \(C\) 是双曲线，其渐近线方程为 \(y = \pm \sqrt{-\dfrac{m}{n}} x\)
  \item
    D. 若 \(m = 0, n > 0\) ，则 \(C\) 是两条直线
  \end{itemize}

  \begin{examSolutionBox}

  \textbf{答案：} ACD

  \textbf{分析：} 按参数符号和大小分别判断曲线类型、长轴方向、半径、渐近线及退化情形。

  \textbf{详细解析：}

  当 \(m>n>0\) 时，
  \[
  \frac{x^2}{1/m}+\frac{y^2}{1/n}=1,
  \]
  且 \(1/n>1/m\)，长轴在 \(y\) 轴上，A 正确。当 \(m=n>0\) 时，曲线为 \(x^2+y^2=1/n\)，半径是 \(1/\sqrt n\)，B 错误。当 \(mn<0\) 时，曲线为双曲线，令二次齐次部分 \(mx^2+ny^2=0\)，得渐近线
  \[
  y=\pm\sqrt{-\frac mn}\,x,
  \]
  故 C 正确。当 \(m=0,n>0\) 时，\(ny^2=1\)，即 \(y=\pm1/\sqrt n\)，为两条平行直线，D 正确。

  \end{examSolutionBox}
\end{enumerate}

\textbf{答案：} ABD

\textbf{分析：} 利用回归直线经过样本中心求截距，并结合回归系数及残差图比较相关性、方差和决定系数。

\textbf{详细解析：}

\[

   \bar y=\frac{970}{100}=9.7

\[
   9.7=-0.02\times2000+\hat a_1,

\end{itemize}

\begin{examSolutionBox}

\textbf{答案：} ACD

\textbf{分析：} 研究极值点方程 \(f\prime(x)=0\) 在各周期区间内的根，并比较根与整数倍 \(\pi\) 的偏差。

\textbf{详细解析：}

函数定义域为 \((0,+\infty)\)，且
\[
   f'(x)=\frac1x+\sin x.
   \]
在每个区间 \(((2k-1)\pi,2k\pi)\) 内，方程 \(f'(x)=0\)，即 \(\sin x=-1/x\)，恰有两个根，并且
\[
   (2k-1)\pi<x_{2k-1}<\frac{(4k-1)\pi}{2}
   <x_{2k}<2k\pi.
   \]
因此 \((n-\tfrac12)\pi<x_n<(n+\tfrac12)\pi\)，A 正确。另一方面，
\[
   x_{2k+1}>(2k+1)\pi,\qquad x_{2k}<2k\pi,
   \]
所以 \(x_{2k+1}-x_{2k}>\pi\)，B 错误。

令 \(d_n=|x_n-n\pi|\)。由 \(0<d_n<\pi/2\) 及极值点方程可得
\[
   \sin d_n=\frac1{x_n}.
   \]
随着 \(n\) 增大，\(x_n\) 严格增大，故 \(1/x_n\) 严格减小；又 \(\sin x\) 在 \((0,\pi/2)\) 上严格递增，所以 \(d_n\) 严格递减，C 正确。

对于奇数项，设 \(x_{2n-1}=(2n-1)\pi+d\)，其中 \(0<d<\pi/2\)，并令 \(t=\pi/2-d\)。由 \(\sin d=1/x_{2n-1}\) 以及 \(\tan t>t\)，得
\[
   \cos d=\sin t>t\cos t
   =\frac{\pi/2-d}{x_{2n-1}}.
   \]
再利用 \(\ln(1+u)<u\)，可得
\[
   \ln\frac{(4n-1)\pi/2}{x_{2n-1}}
   <\frac{(4n-1)\pi/2-x_{2n-1}}{x_{2n-1}}
   =\frac{\pi/2-d}{x_{2n-1}}
   <\cos d.
   \]
而 \(\cos x_{2n-1}=-\cos d\)，所以
\[
   f(x_{2n-1})=\ln x_{2n-1}+\cos d
   >\ln\frac{(4n-1)\pi}{2}.
   \]
故 D 正确。

\end{examSolutionBox}

\par\smallskip\noindent（2）在定义域 \(x>0\) 内，将零点问题转化为研究 \(g(x)=ax-3\ln x\) 的最小值；
\par\smallskip\noindent（3）把 \(f(x)-2x\) 写成 \(x\) 与另一个函数的乘积，证明后一个因子在其最小点处仍为正。

\textbf{详细解析：}

函数的定义域为 \((0,+\infty)\)。


\par\smallskip\noindent（1）当 \(a=1\) 时，
\[
   f(x)=x^2-3x\ln x,
   \]
所以
\[
   f'(x)=2x-3(\ln x+1).
   \]
又 \(f(1)=1\)，\(f'(1)=2-3=-1\)，故曲线在 \((1,f(1))=(1,1)\) 处的切线方程为
\[
   y-1=-(x-1),
   \]
即
\[
   \boxed{y=-x+2}.
   \]


\par\smallskip\noindent（2）因为 \(a>0,\ x>0\)，所以
\[
   f(x)=ax(ax-3\ln x).
   \]
故 \(f(x)=0\) 等价于
\[
   g(x)=ax-3\ln x=0.
   \]
求导得
\[
   g'(x)=a-\frac3x.
   \]
当 \(0<x<\frac3a\) 时，\(g'(x)<0\)；当 \(x>\frac3a\) 时，\(g'(x)>0\)。因此 \(g(x)\) 在 \(x=\frac3a\) 处取得最小值
\[
   g\left(\frac3a\right)
   =3-3\ln\frac3a
   =3\ln\frac{ae}{3}.
   \]
同时，
\[
   \lim_{x\to0^+}g(x)=+\infty,\qquad
   \lim_{x\to+\infty}g(x)=+\infty.
   \]
因此：

\begin{itemize}
\tightlist
\item
  当 \(0<a<\frac3e\) 时，最小值小于 \(0\)，方程 \(g(x)=0\) 有两个正根，故 \(f(x)\) 有两个零点；
\item
  当 \(a=\frac3e\) 时，最小值等于 \(0\)，方程有唯一正根 \(x=e\)，故 \(f(x)\) 有一个零点；
\item
  当 \(a>\frac3e\) 时，最小值大于 \(0\)，方程无正根，故 \(f(x)\) 没有零点。
\end{itemize}


\par\smallskip\noindent（3）当 \(a>2\) 时，
\[
   f(x)-2x
   =x\bigl(a^2x-3a\ln x-2\bigr).
   \]
令
\[
   h(x)=a^2x-3a\ln x-2,\qquad x>0.
   \]
则
\[
   h'(x)=a^2-\frac{3a}{x}.
   \]
因此 \(h(x)\) 在 \(x=\frac3a\) 处取得最小值，且
\[
   h\left(\frac3a\right)
   =3a-3a\ln\frac3a-2
   =3a\left(1-\ln\frac3a\right)-2.
   \]
由于 \(a>2\)，所以 \(0<\frac3a<\frac32\)。利用 \(\ln t<t-1\ (t>0,\ t\ne1)\)（在 \(t=1\) 时也有 \(\ln t\le t-1\)），可得
\[
   \ln\frac3a\leqslant\frac3a-1<\frac12.
   \]
从而
\[
   h\left(\frac3a\right)
   >3a\cdot\frac12-2
   >1>0.
   \]
故对任意 \(x>0\)，均有 \(h(x)>0\)。又 \(x>0\)，所以
\[
   f(x)-2x=xh(x)>0,
   \]
即
\[
   \boxed{f(x)>2x}.
   \]

   0,&k\ge11;
   \end{cases}
   \]

\par\smallskip\noindent（3）从游戏策划收益角度应选择方案一。

\textbf{分析：}方案一中各次抽卡相互独立，首次抽中次数服从几何分布；方案二中前 \(9\) 次按成功概率 \(p_2\) 独立抽取，第 \(10\) 次在前 \(9\) 次均未抽中时必定抽中。比较两种方案首次抽中时抽卡次数的数学期望即可比较平均累计花费。

\textbf{详细解析：}


\par\smallskip\noindent（1）方案一没有保底机制，每次抽中新皮肤的概率始终为 \(p_1\)，且不受前三次结果影响。

因此，在已知前三次均未抽中的条件下，第四次抽中的概率仍为
\[
   \boxed{p_1}.
   \]


\par\smallskip\noindent（2）对于方案一，第 \(k\) 次首次抽中意味着前 \(k-1\) 次均未抽中且第 \(k\) 次抽中，

所以对 \(k=1,2,\ldots\)，
\[
   \boxed{P(X=10k)=(1-p_1)^{k-1}p_1}.
   \]

对于方案二，

当 \(1\le k\le9\) 时，同理有
\[
   P(Y=10k)=(1-p_2)^{k-1}p_2.
   \]
当 \(k=10\) 时，前 \(9\) 次均未抽中后第 \(10\) 次必定抽中，

故
\[
   P(Y=100)=(1-p_2)^9.
   \]
由于首次抽中最迟发生在第 \(10\) 次，

所以当 \(k\ge11\) 时 \(P(Y=10k)=0\)。综上，
\[
   \boxed{
   P(Y=10k)=
   \begin{cases}
   (1-p_2)^{k-1}p_2,&1\le k\le9,\\
   (1-p_2)^9,&k=10,\\
   0,&k\ge11.
   \end{cases}}
   \]


\par\smallskip\noindent（3）题目末尾写作``\(P_1=2P_2=0.1\)''，而前文定义的是小写 \(p_1,p_2\)。这里按同一概率参数理解，

即
\[
   p_1=0.1,\qquad p_2=0.05.
   \]
设方案一、二中首次抽中的抽卡次数分别为 \(N_1,N_2\)，

则
\[
   E(N_1)=\frac1{p_1}=10,
   \qquad
   E(X)=10E(N_1)=100\text{（元）}.
   \]
对于方案二，令 \(q=1-p_2=0.95\)。

由尾和公式，
\[
   E(N_2)
   =\sum_{k=1}^{10}P(N_2\ge k)
   =\sum_{j=0}^{9}q^j
   =\dfrac{1-q^{10}}{1-q}
   =\dfrac{1-0.95^{10}}{0.05}.
   \]
利用参考数据 \(0.95^{10}\approx0.60\)，

得
\[
   E(N_2)\approx\dfrac{1-0.60}{0.05}=8,
   \qquad
   E(Y)=10E(N_2)\approx80\text{（元）}.
   \]
因为 \(E(X)=100>E(Y)\approx80\)，玩家采用方案一时首次抽中新皮肤前的平均累计花费更高。

因此，从游戏策划收益角度应选择
\[
   \boxed{\text{方案一}}.
   \]
