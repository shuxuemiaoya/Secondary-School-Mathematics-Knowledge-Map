##### 题型05利用单调性比较三角函数值的大小
##### 【典例1】（24-25高一上·全国·课堂例题）比较大小：
(1)$\sin 2 2 0^{\circ}$与$\sin 2 3 0^{\circ}$；
(2)$\sin \left( - \frac{2 0 \pi}{7} \right)$与$\cos \left( - \frac{1 0 \pi}{3} \right)$．
<span class="fake-tag">答案</span>(1)$\sin 2 2 0^{\circ} > \sin 2 3 0^{\circ}$
(2)$\sin \left( - \frac{\text{20} \text{π}}{7} \right) > \cos \left( - \frac{1 0 \pi}{3} \right)$
<span class="fake-tag">分析</span>（1）根据正弦函数$y = \sin x$单调性比较大小即可；
（2）由诱导公式可得$\sin \left( - \frac{2 0 \pi}{7} \right) = - \sin \frac{\pi}{7}$，$\cos \left( - \frac{1 0 \pi}{3} \right) = - \sin \frac{\pi}{6}$，再结合正弦函数单调性比较大小.
<span class="fake-tag">详解</span>（1）因为函数$y = \sin x$在$9 0^{\circ} \leq x \leq 27 0^{\circ}$上是减函数，
且$9 0^{\circ} < 2 2 0^{\circ} < 2 3 0^{\circ} < 2 7 0^{\circ}$，
所以$\sin 2 2 0^{\circ} > \sin 2 3 0^{\circ}$．
（2）$\sin \left( - \frac{2 0 \pi}{7} \right) = \sin \frac{8 \pi}{7} = - \sin \frac{\pi}{7}$，
$\cos \left( - \frac{1 0 \pi}{3} \right) = \cos \frac{2 \pi}{3} = - \cos \frac{\pi}{3} = - \sin \frac{\pi}{6}$．
因为函数$y = \sin x$在$\left\lbrack - \frac{\pi}{2} , \frac{\pi}{2} \right\rbrack$上是增函数，而$- \frac{\pi}{2} < \frac{\pi}{7} < \frac{\pi}{6} < \frac{\pi}{2}$，
所以$\sin \frac{\pi}{7} < \sin \frac{\pi}{6}$，
所以$- \sin \frac{\pi}{7} > - \sin \frac{\pi}{6}$．
故$\sin \left( - \frac{\text{20} \text{π}}{7} \right) > \cos \left( - \frac{1 0 \pi}{3} \right)$．
##### 【典例2】（2024高一上·全国·专题练习）利用三角函数的单调性，比较下列各组数的大小．
(1)$\sin \left( - \frac{\pi}{18} \right)$与$\sin \left( - \frac{\pi}{10} \right)$；
(2)$\sin 1 9 6^{\circ}$与$\cos 1 5 6^{\circ}$；
(3)$\cos \left( - \frac{23}{5} \pi \right)$与$\cos \left( - \frac{17}{4} \pi \right)$.
<span class="fake-tag">答案</span>(1)$\sin \left( - \frac{\pi}{18} \right) > \sin \left( - \frac{\pi}{10} \right)$.
(2)$\sin 1 9 6^{\circ} > \cos 1 5 6^{\circ}$.
(3)$\cos \left( - \frac{23}{5} \pi \right) < \cos \left( - \frac{17}{4} \pi \right)$.
<span class="fake-tag">分析</span>（1）利用正弦函数的单调性，比较正弦值的大小；
（2）由诱导公式有$\sin 1 9 6^{\circ} = - \sin 1 6^{\circ}$，$\cos 1 5 6^{\circ} = - \sin 6 6^{\circ}$，利用正弦函数的单调性比较大小；
（3）利用诱导公式和余弦函数的单调性比较大小
<span class="fake-tag">详解</span>（1）由$- \frac{\pi}{2} < - \frac{\pi}{10} < - \frac{\pi}{18} < \frac{\pi}{2}$，函数$y = \sin x$在$\left\lbrack - \frac{\pi}{2} , \frac{\pi}{2} \right\rbrack$上单调递增，
所以$\sin \left( - \frac{\pi}{18} \right) > \sin \left( - \frac{\pi}{10} \right)$.
（2）$\sin 1 9 6^{\circ} = \sin \left( 18 0^{\circ} + 1 6^{\circ} \right) = - \sin 1 6^{\circ}$，$\cos 1 5 6^{\circ} = \cos \left( 9 0^{\circ} + 6 6^{\circ} \right) = - \sin 6 6^{\circ}$，
由$0^{\circ} < 1 6^{\circ} < 6 6^{\circ} < 9 0^{\circ}$，有$\sin 1 6^{\circ} < \sin 6 6^{\circ}$，
从而$- \sin 1 6^{\circ} > - \sin 6 6^{\circ}$，即$\sin 1 9 6^{\circ} > \cos 1 5 6^{\circ}$.
（3）$\cos \left( - \frac{23}{5} \pi \right) = \cos \frac{23}{5} \pi = \cos \left( 4 \pi + \frac{3}{5} \pi \right) = \cos \frac{3}{5} \pi$，
$\cos \left( - \frac{17}{4} \pi \right) = \cos \frac{17}{4} \pi = \cos \left( 4 \pi + \frac{1}{4} \pi \right) = \cos \frac{1}{4} \pi$
$0 < \frac{\pi}{4} < \frac{\text{3π}}{5} < \pi$，且$y = \cos x$在$[ 0 , \pi ]$上是减函数，
则$\cos \frac{\text{3π}}{5} < \cos \frac{\pi}{4}$，即$\cos \left( - \frac{23}{5} \pi \right) < \cos \left( - \frac{17}{4} \pi \right)$.
##### 【变式1】（23-24高一·上海·课堂例题）利用函数的单调性，比较下列各组数的大小：
(1)$\sin \frac{3 \pi}{11}$与$\sin \frac{5 \pi}{12}$；
(2)$\sin \left( - \frac{7 6 \pi}{11} \right)$与$\sin \frac{8 5 \pi}{12}$*.*
<span class="fake-tag">答案</span>(1)$\sin \frac{\text{3} \text{π}}{11} < \sin \frac{5 \pi}{12}$
(2)$\sin \frac{8 5 \pi}{12} > \sin \left( - \frac{7 6 \pi}{11} \right)$
<span class="fake-tag">分析</span>（1）利用正弦函数的单调性，比较正弦值的大小；
（2）由诱导公式有$\sin \left( - \frac{7 6 \pi}{11} \right) = - \sin \frac{\pi}{11}$，$\sin \frac{8 5 \pi}{12} = - \sin \frac{\pi}{12}$，利用正弦函数的单调性比较大小.
<span class="fake-tag">详解</span>（1）由$0 < \frac{\text{3π}}{11} < \frac{\text{5π}}{12} < \frac{\pi}{2}$，函数$y = \sin x$在上单调递增，
所以$\sin \frac{\text{3} \text{π}}{11} < \sin \frac{5 \pi}{12}$.
（2）由于$\sin \left( - \frac{7 6 \pi}{11} \right) = \sin \left( - \frac{7 6 \pi}{11} + 8 \pi \right) = \sin \frac{1 2 \pi}{11} = - \sin \frac{\pi}{11}$，
$\sin \frac{8 5 \pi}{12} = \sin \left( \frac{8 5 \pi}{12} - 6 \pi \right) = \sin \frac{1 3 \pi}{12} = \sin \left( \pi + \frac{\pi}{12} \right) = - \sin \frac{\pi}{12}$，
因为函数$y = \sin x$在上单调递增，
由$\frac{\pi}{\text{12}} < \frac{\pi}{\text{11}}$可得$\sin \frac{\pi}{\text{12}} < \sin \frac{\pi}{\text{11}}$，所以$- \sin \frac{\pi}{\text{12}} > - \sin \frac{\pi}{\text{11}}$，
所以$\sin \frac{8 5 \pi}{12} > \sin \left( - \frac{7 6 \pi}{11} \right)$.
##### 【变式2】（24-25高一上·全国·课后作业）比较下列各组数的大小．
(1)$\text{sin} \frac{2 1 \pi}{5}$与$\text{sin} \frac{4 2 \pi}{5}$；
(2)$\text{cos} \frac{1 7 \pi}{8}$与$\text{cos} \frac{3 7 \pi}{9}$．
<span class="fake-tag">答案</span>(1)$\text{sin} \frac{2 1 \pi}{5} < \text{sin} \frac{4 2 \pi}{5}$
(2)$\text{cos} \frac{\text{37} \text{π}}{9} > \text{cos} \frac{\text{17} \text{π}}{8}$
<span class="fake-tag">分析</span>（1）（2）先应用诱导公式化简到同一单调区间，再应用正余弦函数单调性判断大小；
<span class="fake-tag">详解</span>（1）∵$\text{sin} \frac{2 1 \pi}{5} = \text{sin} \left( 4 \pi + \frac{\pi}{5} \right) = \text{sin} \frac{\pi}{5}$，$\text{sin} \frac{4 2 \pi}{5} = \text{sin} \left( 8 \pi + \frac{\text{2} \text{π}}{5} \right) = \text{sin} \frac{\text{2} \text{π}}{5}$，
又$y = \text{sin} x$在上单调递增，且$0 < \frac{\pi}{5} < \frac{2 \pi}{5} < \frac{\pi}{2}$，
∴$\text{sin} \frac{\pi}{5} < \text{sin} \frac{2 \pi}{5}$，
∴$\text{sin} \frac{2 1 \pi}{5} < \text{sin} \frac{4 2 \pi}{5}$．
（2）∵$\text{cos} \frac{1 7 \pi}{8} = \text{cos} \left( 2 \pi + \frac{\pi}{8} \right) = \text{cos} \frac{\pi}{8}$，
$\text{cos} \frac{3 7 \pi}{9} = \text{cos} \left( 4 \pi + \frac{\pi}{9} \right) = \text{cos} \frac{\pi}{9}$．
又$y = \text{cos} x$在[0,π]上单调递减，且$0 < \frac{\pi}{9} < \frac{\pi}{8} < \pi$，
∴$\text{cos} \frac{\pi}{9} > \text{cos} \frac{\pi}{8}$，∴$\text{cos} \frac{\text{37} \text{π}}{9} > \text{cos} \frac{\text{17} \text{π}}{8}$．
