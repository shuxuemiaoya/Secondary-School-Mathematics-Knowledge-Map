##### 题型02平面向量数量积（最值，范围）问题
##### 【典例1】（2023下·天津·高一统考期末）在$\bigtriangleup A B C$中，$A B = 2$，$A C = 3$，$\angle A = 6 0 {^\circ}$.若$P$，$Q$分别为边$A B$，$A C$上的点，且满足$\overrightarrow{A P} = \lambda \overrightarrow{A B}$，$\overrightarrow{A Q} = \left( 1 - \frac{\lambda}{5} \right) \overrightarrow{A C}$，则$\overrightarrow{B Q} \cdot \overrightarrow{C P}$的最大值为（ ）
$\quad$A．$- \frac{86}{15}$ 
$\quad$B．$- \frac{29}{5}$ 
$\quad$C．$- \frac{23}{4}$ 
$\quad$D．$- 6$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题意得，$\overrightarrow{B Q} = \overrightarrow{A Q} - \overrightarrow{A B}$，$\overrightarrow{C P} = \overrightarrow{A P} - \overrightarrow{A C}$，
因为$\overrightarrow{A P} = \lambda \overrightarrow{A B}$，$\overrightarrow{A Q} = \left( 1 - \frac{\lambda}{5} \right) \overrightarrow{A C}$，
所以$\overrightarrow{B Q} = \left( 1 - \frac{\lambda}{5} \right) \overrightarrow{A C} - \overrightarrow{A B}$，$\overrightarrow{C P} = \lambda \overrightarrow{A B} - \overrightarrow{A C}$，
所以$\overrightarrow{B Q} \cdot \overrightarrow{C P} = \left\lbrack \left( 1 - \frac{\lambda}{5} \right) \overrightarrow{A C} - \overrightarrow{A B} \right\rbrack \cdot \left( \lambda \overrightarrow{A B} - \overrightarrow{A C} \right) = \left( \frac{\lambda}{5} - 1 \right) \overrightarrow{A C}^{2} - \lambda \overrightarrow{A B}^{2} + \left( 1 + \lambda - \frac{\lambda^{2}}{5} \right) \overrightarrow{A B} \cdot \overrightarrow{A C}$，
因为$\overrightarrow{A C}^{2} = \left| \overrightarrow{A C} \right|^{2} = 9 ， \overrightarrow{A B}^{2} = \left| \overrightarrow{A B} \right|^{2} = 4 ， \overrightarrow{A B} \cdot \overrightarrow{A C} = \left| \overrightarrow{A B} \right| \cdot \left| \overrightarrow{A C} \right| \cos 6 0 {^\circ} = 2 \times 3 \times \frac{1}{2} = 3$，
所以$\overrightarrow{B Q} \cdot \overrightarrow{C P} = \left( \frac{\lambda}{5} - 1 \right) \times 9 - 4 \lambda + 3 \left( 1 + \lambda - \frac{\lambda^{2}}{5} \right) = - \frac{3}{5} \lambda^{2} + \frac{4}{5} \lambda - 6$，
函数$y = - \frac{3}{5} \lambda^{2} + \frac{4}{5} \lambda - 6 ( 0 \leq \lambda \leq 1 )$开口向下，对称轴为$\lambda = - \frac{\frac{4}{5}}{2 \times \left( - \frac{3}{5} \right)} = \frac{2}{3}$，
当$\lambda = \frac{2}{3}$时，取最大值$y = - \frac{3}{5} \times \left( \frac{2}{3} \right)^{2} + \frac{4}{5} \times \frac{2}{3} - 6 = \frac{4}{15} - 6 = - \frac{86}{15}$.
故选：A
##### 【典例2】（2023下·江苏泰州·高一统考期末）已知$\bigtriangleup A B C$的外接圆的圆心为$O$，且$A = \frac{\pi}{3}$，$B C = 2 \sqrt{3}$，则$\overrightarrow{O B} \cdot \overrightarrow{A C}$的最大值为（ ）
$\quad$A．$\frac{3}{2}$ 
$\quad$B． 
$\quad$C．2 
$\quad$D．3
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>由正弦定理得$2 R = \frac{B C}{\sin A} = \frac{2 \sqrt{3}}{\sin \frac{\pi}{3}} = 4$，故$O A = O B = O C = 2$，
因为$A = \frac{\pi}{3}$，所以$\angle B O C = \frac{\text{2} \text{π}}{3}$，
则$\overrightarrow{O B} \cdot \overrightarrow{A C} = \overrightarrow{O B} \cdot \left( \overrightarrow{O C} - \overrightarrow{O A} \right) = \overrightarrow{O B} \cdot \overrightarrow{O C} - \overrightarrow{O B} \cdot \overrightarrow{O A} = 4 \cos \frac{\text{2} \text{π}}{3} - 4 \cos \angle A O C$
$= - 2 - 4 \cos \angle A O C$，
因为$\angle A O B \in \left( 0 , \frac{2 \pi}{3} \right)$，所以$\angle A O C \in \left( 0 , \frac{4 \pi}{3} \right)$，则$\cos \angle A O C \in \left. - 1 , 1 )$，
故$\overrightarrow{O B} \cdot \overrightarrow{A C} = - 2 - 4 \cos \angle A O C \in \left. - 6 , 2 \right.$.

##### 【典例3】（2023下·内蒙古包头·高一统考期末）边长为2的等边三角形*ABC*的重心为*G*，设平面内任意一点*P*，则$\overrightarrow{A P} \cdot \overrightarrow{G P}$的最小值为 ．
<span class="fake-tag">答案</span>$- \frac{1}{3}$
<span class="fake-tag">详解</span>由题意，设等边$\bigtriangleup A B C$的边长为$2$，以$B C$的中点$O$为原点，以$O C , O A$分别为$x , y$轴建立直角坐标系，可作图如下：
![@@@cc525ce8-d9d4-4f97-8e40-548a1b48f0c9](MathLogic-Weave/高中数学逻辑结构/题/Attachments/e1332e57175f7a6da08aea85ffbfa5ff.png)
由$G$为等边$\bigtriangleup A B C$的重心，则$O A = \sqrt{3}$，，即$A \left( 0 , \sqrt{3} \right)$，$G \left( 0 , \frac{\sqrt{3}}{3} \right)$，
设$P ( x , y )$，则$\overrightarrow{A P} = \left( x , y - \sqrt{3} \right)$，$\overrightarrow{G P} = \left( x , y - \frac{\sqrt{3}}{3} \right)$，
$\overrightarrow{A P} \cdot \overrightarrow{G P} = x^{2} + \left( y - \sqrt{3} \right) \left( y - \frac{\sqrt{3}}{3} \right) = x^{2} + y^{2} - \frac{4 \sqrt{3}}{3} y + 1 = x^{2} + \left( y - \frac{2 \sqrt{3}}{3} \right)^{2} - \frac{1}{3}$，
对于$\forall x , y \in R$，$x^{2} + \left( y - \frac{2 \sqrt{3}}{3} \right)^{2} \geq 0$，故$\overrightarrow{A P} \cdot \overrightarrow{G P} \geq - \frac{1}{3}$.
故答案为：$- \frac{1}{3}$.
##### 【典例4】（2023下·四川成都·高一统考期末）已知边长为2的菱形$A B C D$中，是边$A D$所在直线上的一点，则$\overrightarrow{E B} \cdot \overrightarrow{E C}$的取值范围为 ．
<span class="fake-tag">答案</span>$\left. 0 , + \infty )$
<span class="fake-tag">详解</span>![@@@b54ad20d-e697-4bc7-9759-2e15ce16a4fe](MathLogic-Weave/高中数学逻辑结构/题/Attachments/90a4761a91f5e0aa43807f4a55b119a9.png)
取$B C$的中点$Q$，连接$E Q$，则$\overrightarrow{E B} + \overrightarrow{E C} = 2 \overrightarrow{E Q}$，
所以$\overrightarrow{E B} \cdot \overrightarrow{E C} = \frac{1}{4} \lbrack ( \overrightarrow{E B} + \overrightarrow{E C} )^{2} - ( \overrightarrow{E B} - \overrightarrow{E C} )^{2} \rbrack = \frac{1}{4} ( 4 \left| \overrightarrow{E Q} \right|^{2} - \left| \overrightarrow{C B} \right|^{2} ) = \left| \overrightarrow{E Q} \right|^{2} - 1$，
当且仅当$E Q \bot B C$时，$E Q$有最小值，则$\left| \overrightarrow{E Q} \right|^{2} - 1$有最小值，
此时菱形的面积$E Q \times B C = 2 \times \frac{1}{2} \times A B \times A D \times \sin 3 0^{\circ} \Rightarrow E Q \times 2 = 2 \times \frac{1}{2} \times 2 \times 2 \times \frac{1}{2} \Rightarrow E Q = 1$，
$\left| \overrightarrow{E Q} \right|^{2} - 1$最小值为$1 - 1 = 0$，
因为$E$是边$A D$所在直线上的一点，所以$E Q$无最大值，$\left| \overrightarrow{E Q} \right|^{2} - 1$无最大值，
$\overrightarrow{E B} \cdot \overrightarrow{E C}$的取值范围为$\left. 0 , + \infty )$，
故答案为：$\left. 0 , + \infty )$
##### 【变式1】（多选）（2023下·辽宁大连·高一大连八中校考期中）在$\bigtriangleup A B C$中，$A C = 3$，，$\angle C = 9 0^{\circ}$，$P$为$\bigtriangleup A B C$内任意一点（含边界），且$P C = 1$，则$\overrightarrow{P A} \cdot \overrightarrow{P B}$的值可能是（ ）
$\quad$A． 
$\quad$B．$- 4$ 
$\quad$C．$- 3$ 
$\quad$D．$- 2$
<span class="fake-tag">答案</span>BCD
<span class="fake-tag">详解</span>在$\text{Rt} \bigtriangleup A B C$中，$A C = 3$，，$\angle C = 9 0^{\circ}$，
以点$C$为坐标原点，$C B$、$C A$所在直线分别为$x$、$y$轴建立如下图所示的平面直角坐标系，
![@@@3bf99cbf-a03e-4866-b899-e02cd8c360c0](MathLogic-Weave/高中数学逻辑结构/题/Attachments/1c88a362275793b1c3807453d5ff258a.png)
则$A ( 0 , 3 )$、$B ( 4 , 0 )$、$C ( 0 , 0 )$，
因为$P$为$\bigtriangleup A B C$内任意一点（含边界），且$P C = 1$，设点$P \left( \cos \theta , \sin \theta \right) \left( 0 \leq \theta \leq \frac{\pi}{2} \right)$，
$\overrightarrow{P A} = \left( - \cos \theta , 3 - \sin \theta \right)$，$\overrightarrow{P B} = \left( 4 - \cos \theta , - \sin \theta \right)$，
所以，$\overrightarrow{P A} \cdot \overrightarrow{P B} = - \cos \theta \left( 4 - \cos \theta \right) - \sin \theta \left( 3 - \sin \theta \right) = 1 - \left( 3 \sin \theta + 4 \cos \theta \right) = 1 - 5 \sin ( \theta + \varphi )$，
为锐角，且$\tan \varphi = \frac{4}{3}$，
因为$0 \leq \theta \leq \frac{\pi}{2}$，则$\varphi \leq \theta + \varphi \leq \frac{\pi}{2} + \varphi$，
由$\varphi \leq \theta + \varphi \leq \frac{\pi}{2}$可得$0 \leq \theta \leq \frac{\pi}{2} - \varphi$，由$\frac{\pi}{2} \leq \theta + \varphi \leq \frac{\pi}{2} + \varphi$得$\frac{\pi}{2} - \varphi \leq \theta \leq \frac{\pi}{2}$，
所以，函数$f ( \theta ) = 1 - 5 \sin ( \theta + \varphi )$在$\left\lbrack 0 , \frac{\pi}{2} - \varphi \right\rbrack$上单调递减，在$\left\lbrack \frac{\pi}{2} - \varphi , \frac{\pi}{2} \right\rbrack$上单调递增，
所以，$f ( \theta )_{\min}$，
又因为$f ( 0 ) = 1 - 4 = - 3$，$f \left( \frac{\pi}{2} \right) = 1 - 3 \sin \frac{\pi}{2} = - 2$，则$- 4 \leq \overrightarrow{P A} \cdot \overrightarrow{P B} \leq - 2$，
故选：BCD.
