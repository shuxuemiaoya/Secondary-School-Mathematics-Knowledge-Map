##### 题型06 弧度制的概念
##### 【典例1】（23-24高一上·全国·课后作业）判断正误（正确的写正确，错误的写错误）
（1）1rad的角比1°的角要大．( )
（2）用角度制和弧度制度量角，都与圆的半径有关．( )
（3）每个弧度制的角，都有唯一的角度制的角与之对应．( )
（4）1°的角是周角的$\frac{\mathbf{1}}{\mathbf{360}}$，1rad的角是周角的$\frac{\mathbf{1}}{\mathbf{2} \mathbf{\pi}}$.( )
<span class="fake-tag">答案</span> 正确 错误 正确 正确
<span class="fake-tag">分析</span>根据角度值与弧度制之间的关系，以及两者之间的互化即可逐一判断结果.
<span class="fake-tag">详解</span>1rad代表$\left( \frac{180}{\pi} \right)^{\circ}$，约等于$5 7 . 3^{\circ}$，比1°的角要大，所以（1）正确；
用角度制和弧度制度量角，角的大小不随圆的半径而改变，都与圆的半径无关，即（2）错误；
每个弧度制的角，都有唯一的角度制的角与之对应，即角度值和弧度制可以互化，所以（3）正确；
周角是$36 0^{\circ}$的角，所以1°的角是周角的$\frac{1}{360}$；同时周角是$2 \pi$rad的角，因此1rad的角是周角的$\frac{1}{2 \pi}$，即（4）正确.
故答案为：正确，错误，正确，正确
##### 【典例2】（多选）（23-24高一下·江西新余·阶段练习）下列命题中，正确的是（ ）
$\quad$A．1弧度的角就是长为半径的弦所对的圆心角
$\quad$B．若$\mathbf{\alpha}$是第一象限的角，则$\frac{\mathbf{\pi}}{\mathbf{2}} \mathbf{-} \mathbf{\alpha}$也是第一象限的角
$\quad$C．若两个角的终边重合，则这两个角相等
$\quad$D．用角度制和弧度制度量角，都与圆的半径无关
<span class="fake-tag">答案</span>BD
<span class="fake-tag">分析</span>根据角度制和弧度制的定义，利用象限角的概念即可判断.
<span class="fake-tag">详解</span>对于A选项，1弧度的角就是长为半径的弧所对的圆心角，故A错误；
对于B选项，若$\alpha$是第一象限的角，则$- \alpha$是第四象限的角，所以$- \alpha + \frac{\pi}{2}$是第一象限的角，故B正确；
对于C选项，当$\alpha = 3 0 {^\circ} , \beta = 3 9 0 {^\circ}$时，$\alpha$与终边重合，但两个角不相等，故C错误；
对于D选项，不论是用角度制还是弧度制度量角，由角度值和弧度值的定义可知度量角与所取圆的半径无关，故D正确.
故选：BD.
##### 【变式1】（24-25高一上·全国·课后作业）下列说法正确的是（ ）
$\quad$A．1弧度的角与1°的角一样大
$\quad$B．若圆的一条弦长等于半径，则这条弦所对的圆心角是$\frac{\mathbf{\pi}}{\mathbf{3}}$
$\quad$C．经过5分钟分针转了30°
$\quad$D．长度等于半径的弦所对的圆心角的大小是1弧度
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>利用弧度制的定义对选项逐一分析即可.
<span class="fake-tag">详解</span>对于A，根据弧度制定义可知A错误；
对于B，若圆的一条弦长等于半径，则这条弦所对的圆心角为$6 0 {^\circ}$，即$\frac{\pi}{3}$，故B正确；
对于C，经过5分钟分针转了$- 30 {^\circ}$，故C错误；
对于D，由弧度制的定义可知，长度等于半径长的弧所对的圆心角的大小是1弧度，则长度等于半径的弦所对的圆心角的大小不是1弧度，故D错误.
故选：B．
