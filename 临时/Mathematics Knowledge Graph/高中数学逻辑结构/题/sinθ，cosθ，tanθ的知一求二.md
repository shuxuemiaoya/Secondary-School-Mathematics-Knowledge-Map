##### 【典例1】（23-24高一下·北京·期中）已知$x \in ( 0 , \pi )$，$\text{tan} x = - 2 \sqrt{2}$，则$\text{cos} x =$（ ）
$\quad$A．$\frac{2 \sqrt{2}}{3}$ 
$\quad$B．$\frac{1}{3}$ 
$\quad$C．$- \frac{2 \sqrt{2}}{3}$ 
$\quad$D．$- \frac{1}{3}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>根据同角三角函数基本关系式结合三角函数符合可得结果.
<span class="fake-tag">详解</span>因为$\text{tan} x = \frac{\text{sin} x}{\text{cos} x} = - 2 \sqrt{2} \Rightarrow \text{sin} x = - 2 \sqrt{2} \text{cos} x$，
又$\text{si} \text{n}^{2} x + \text{co} \text{s}^{2} x = \left( - 2 \sqrt{2} \text{cos} x \right)^{2} + \text{co} \text{s}^{2} x = 9 \text{co} \text{s}^{2} x = 1$，
又$x \in ( 0 , \pi )$，$\text{tan} x = - 2 \sqrt{2} < 0$，所以$x \in \left( \frac{\pi}{2} , \pi \right)$，
所以$\text{cos} x = - \frac{1}{3}$，
故选：D.
##### 【典例2】（23-24高一下·山东潍坊·阶段练习）（1）已知，且$\alpha$是第二象限角，求$\cos \alpha$和$\tan \alpha$.
（2）若$\tan \alpha = - \frac{15}{8}$，求$\sin \alpha$的值.
<span class="fake-tag">答案</span>（1）$- \frac{5}{13}$，$- \frac{12}{5}$；（2）$\frac{15}{17}$或$- \frac{15}{17}$
<span class="fake-tag">分析</span>（1）根据同角三角函数的基本关系计算可得.
（2）首先判断$\alpha$是第二、四象限角，再根据同角三角函数的基本关系计算可得.
<span class="fake-tag">详解</span>（1）因为，且$\alpha$是第二象限角，
所以$\cos \alpha = - \sqrt{1 - \sin^{2} \alpha} = - \sqrt{1 - \left( \frac{12}{13} \right)^{2}} = - \frac{5}{13}$，
所以$\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = \frac{\frac{12}{13}}{- \frac{5}{13}} = - \frac{12}{5}$.
（2）因为$\tan \alpha = - \frac{15}{8} < 0$，所以$\alpha$是第二、四象限角.
由，可得${} {\sin {}^{2}} \alpha = \left( \frac{15}{17} \right)^{2}$.
当$\alpha$是第二象限角时，$\sin \alpha = \frac{15}{17}$；
当$\alpha$是第四象限角时，$\sin \alpha = - \frac{15}{17}$.
##### 【变式1】（23-24高一下·北京延庆·期末）若$\tan \alpha = - \frac{3}{4}$，$\cos \alpha < 0$，则（ ）
$\quad$A．$\frac{4}{5}$ 
$\quad$B．$- \frac{4}{5}$ 
$\quad$C．$\frac{3}{5}$ 
$\quad$D．$- \frac{3}{5}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>应用同角三角函数关系结合三角函数的正负计算即可.
<span class="fake-tag">详解</span>因为$\text{tan} \alpha = \frac{\text{sin} \alpha}{\text{cos} \alpha} = - \frac{3}{4} ,$所以$\text{sin} \alpha = - \frac{3}{4} \text{cos} \alpha$
又因为$\text{si} \text{n}^{2} \alpha + \text{co} \text{s}^{2} \alpha = 1$，所以$\frac{9}{16} \text{co} \text{s}^{2} \alpha + \text{co} \text{s}^{2} \alpha = \frac{25}{16} \text{co} \text{s}^{2} \alpha = 1 , \text{co} \text{s}^{2} \alpha = \frac{16}{25}$,
因为$\text{cos} \alpha < 0$，所以$\text{cos} \alpha = - \frac{4}{5}$，所以$\text{sin} \alpha = - \frac{3}{4} \text{cos} \alpha = \frac{3}{5}$.
故选：C.

##### 【典例1】（23-24高一下·广西桂林·期末）已知$\text{cos} \alpha = - \frac{3}{5}$，且$\alpha$为第二象限角，则$\text{tan} \alpha =$（ ）
$\quad$A．$- \frac{3}{4}$ 
$\quad$B．$\frac{3}{4}$ 
$\quad$C．$- \frac{4}{3}$ 
$\quad$D．$\frac{4}{3}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>应用同角三角函数关系计算求解即可.
<span class="fake-tag">详解</span>因为$\alpha$为第二象限角,又因为$\text{cos} \alpha = - \frac{3}{5} , \text{sin} \alpha = \sqrt{\text{1-co} \text{s}^{2} \alpha} = \frac{4}{5}$,

##### 【典例1】（23-24高一下·上海·期中）已知$\alpha$是第三象限角，$\text{tan} \alpha = \frac{5}{12}$，则$\cos \alpha$的值是（ ）
$\quad$A．$\frac{5}{13}$ 
$\quad$B．$- \frac{5}{13}$
$\quad$C．$\frac{12}{13}$ 
$\quad$D．$- \frac{12}{13}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>由$\alpha$是第三象限角和商数关系$\tan \alpha = \frac{\text{sin} \alpha}{\cos \alpha}$结合$\text{si} \text{n}^{2} \alpha + \cos^{2} \alpha = 1$即可求解.
<span class="fake-tag">详解</span>因为$\text{tan} \alpha = \frac{5}{12}$，所以$\frac{\text{sin} \alpha}{\cos \alpha} = \frac{5}{12}$即$\text{sin} \alpha = \frac{5}{12} \cos \alpha$，
又因为$\text{si} \text{n}^{2} \alpha + \cos^{2} \alpha = 1$，所以$\left( \frac{5}{12} \cos \alpha \right)^{2} + \cos^{2} \alpha = 1$，解得$\cos \alpha = \pm \frac{12}{13}$，
因为$\alpha$是第三象限角，所以$\cos \alpha = - \frac{12}{13}$.
故选：D.

##### 【变式1】（23-24高一上·湖南长沙·期末）已知$\text{tan} \alpha = \sqrt{2}$，$\alpha$为第三象限角，则（ ）
$\quad$A．$- \sqrt{2}$ 
$\quad$B．$- 2 \sqrt{2}$ 
$\quad$C．$- \sqrt{3}$ 
$\quad$D．$- 2 \sqrt{3}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">分析</span>利用同角三角函数的商数与平方关系求解${} {\cos {}^{2}} \alpha$，再根据$\alpha$所在象限求解即$\sin \alpha , \cos \alpha$,代入可得.
<span class="fake-tag">详解</span>由$\tan \alpha = \sqrt{2}$，得$\sin \alpha = \sqrt{2} \cos \alpha$，所以$\sin^{2} \alpha = 2 \cos^{2} \alpha$，
联立，解得${} {\cos {}^{2}} \alpha = \frac{1}{3}$，
因为$\alpha$为第三象限角，
所以$\cos \alpha = - \frac{\sqrt{3}}{3}$，
故$\sqrt{2} \text{sin} \alpha + \text{cos} \alpha = 2 \cos \alpha + \cos \alpha = 3 \cos \alpha = 3 \times \left( - \frac{\sqrt{3}}{3} \right) = - \sqrt{3}$
故选：C.
