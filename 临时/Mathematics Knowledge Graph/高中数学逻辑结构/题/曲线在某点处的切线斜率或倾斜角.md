##### 题型03 曲线在某点处的切线斜率或倾斜角
##### 【典例1】（2023·高二课时练习）已知函数$f ( x ) = x - \frac{1}{x}$，则该函数在$x = 1$处的切线斜率为（ ）
$\quad$A．0 
$\quad$B．1 
$\quad$C．2 
$\quad$D．3
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>因为$f ( 1 + \Delta x ) - f ( 1 ) = ( 1 + \Delta x ) - \frac{1}{1 + \Delta x} - \left( 1 - \frac{1}{1} \right)$，
$= \Delta x + 1 - \frac{1}{1 + \Delta x} = \Delta x + \frac{\Delta x}{1 + \Delta x}$，
所以斜率$k = \lim_{\Delta x \rightarrow 0} \frac{f ( 1 + \Delta x ) - f ( 1 )}{\Delta x}$，
$= \lim_{\Delta x \rightarrow 0} \left( 1 + \frac{1}{1 + \Delta x} \right) = 1 + 1 = 2$．
故选：C
##### 【典例2】（2023下·湖北·高二校联考期中）点$P$在曲线$y = 2 x^{3} - \sqrt{3} x + \frac{1}{4}$上移动，设点$P$处切线的倾斜角为$\alpha$，则角$\alpha$的范围是（ ）
$\quad$A．$\left. \frac{2 \pi}{3} , \pi \right)$ 
$\quad$B．$\left. 0 , \frac{\pi}{2} \right) \cup \left. \frac{\text{2} \text{π}}{3} \text{,} \text{π} \right)$ 
$\quad$C．$\lbrack 0 , \pi )$ 
$\quad$D．$\left. - \frac{\pi}{2} , 0 \right) \cup \left. \frac{\pi}{2} \text{,} \text{π} \right)$
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>解：由$y = 2 x^{3} - \sqrt{3} x + \frac{1}{4}$，可得$y^{'} = 6 x^{2} - \sqrt{3}$，
所以$y \in \left. - \sqrt{3} , + \infty \right)$，即$k = \text{tan} \alpha \in \left. - \sqrt{3} , + \infty \right)$，
当$\text{tan} \alpha \in \left. - \sqrt{3} , 0 \right)$时，$\alpha \in \left. \frac{\text{2} \text{π}}{3} , \pi \right)$，当$\text{tan} \alpha \in \left. 0 , + \infty )$时，$\alpha \in \left. 0 , \frac{\pi}{2} \right)$，
所以角$\alpha$的范围是$\left. 0 , \frac{\pi}{2} \right) \cup \left. \frac{\text{2} \text{π}}{3} \text{,} \text{π} \right)$.
故选：B.
##### 【变式1】（2022下·安徽黄山·高二屯溪一中校考期中）设$f ( x )$为可导函数，且满足$\lim_{h \rightarrow 0} \frac{f ( 2 ) - f ( 2 - h )}{2 h} = - 1$，则曲线在点$\left( 2 , f ( 2 ) \right)$处的切线的斜率是（ ）
$\quad$A．.2 
$\quad$B．$- 2$ 
$\quad$C．$- \frac{1}{2}$ 
$\quad$D．
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>分析：化简$\underset{h \rightarrow 0}{\text{lim}} \frac{f ( 2 ) - f ( 2 - h )}{2 h} = - 1$得到$f^{'} ( 2 )$，即得切线的斜率.
详解：∵$\underset{h \rightarrow 0}{\text{lim}} \frac{f ( 2 ) - f ( 2 - h )}{2 h} = - 1$，
∴$\underset{h \rightarrow 0}{\text{lim}} \frac{f ( 2 ) - f ( 2 - h )}{h} = - 1$，
∴$\frac{1}{2} f^{'} ( 2 ) = - 1$，
∴$f^{'} ( 2 ) = - 2 = k$，
故曲线$y = f ( x )$在点$\left( 2 , f ( 2 ) \right)$处的切线的斜率是-2，
故选B.
##### 【变式2】（2022·河北邯郸·统考一模）已知函数$f ( x ) = a x^{2} + \ln x$满足$\lim_{\Delta x \rightarrow 0} \frac{f ( 1 ) - f ( 1 - 2 \Delta x )}{3 \Delta x} = 2$，则曲线在点$\left( \frac{1}{2} , f \left( \frac{1}{2} \right) \right)$处的切线斜率为 ．
<span class="fake-tag">答案</span>3
<span class="fake-tag">详解</span>由$\lim_{\Delta x \rightarrow 0} \frac{f ( 1 ) - f ( 1 - 2 \Delta x )}{3 \Delta x} = 2$，可得$\lim_{\Delta x \rightarrow 0} \frac{f ( 1 - 2 \Delta x ) - f ( 1 )}{- 2 \Delta x} = 3$．
因为$f^{'} ( x ) = 2 a x + \frac{1}{x}$，所以$f^{'} ( 1 ) = 2 a + 1 = 3$，即$a = 1$，则$f ( x ) = x^{2} + \ln x$，
所以$f^{'} ( x ) = 2 x + \frac{1}{x}$，$f^{'} \left( \frac{1}{2} \right) = 3$．
故答案为：3.
