##### 【典例1】（2023·全国·高三专题练习）设函数$f ( x ) = a \ln x + \frac{x - 1}{x + 1}$，其中$a$为常数，讨论函数$f ( x )$的单调性．
<span class="fake-tag">答案</span>答案见解析
<span class="fake-tag">详解</span>根据题意，$f ( x ) = a \ln x + \frac{x - 1}{x + 1}$，则$x > 0$，
导数$f^{'} ( x ) = \frac{a}{x} + \frac{2}{( x + 1 )^{2}}$，
分2种情况讨论：
①当$a \geq 0$时，$f^{'} ( x ) > 0$，函数$f ( x )$在$( 0 , + \infty )$上为增函数；
②当$a < 0$时，$f^{'} ( x ) = \frac{a}{x} + \frac{2}{( x + 1 )^{2}} = \frac{a x^{2} + ( 2 a + 2 ) x + a}{x ( x + 1 )^{2}}$，
令$g ( x ) = a x^{2} + ( 2 a + 2 ) x + a$，
则有$\Delta = ( 2 a + 2 )^{2} - 4 a^{2} = 8 a + 4$，
当$a \leq - \frac{1}{2}$时，$\Delta \leq 0$，有$g ( x ) \leq 0$恒成立，
则有，函数$f ( x )$为减函数，
当$- \frac{1}{2} < a < 0$时，$\Delta > 0$，$a x^{2} + ( 2 a + 2 ) x + a = 0$有两个根，
$x_{1} = \frac{- ( a + 1 ) + \sqrt{2 a + 1}}{a}$或，
且$0 < x_{1} < x_{2}$，
则在区间$( 0$,$\frac{- ( a + 1 ) + \sqrt{2 a + 1}}{a} )$和$( \frac{- ( a + 1 ) - \sqrt{2 a + 1}}{a}$,$+ \infty )$上，$g ( x ) < 0$，
则有$f^{'} ( x ) < 0$，函数$f ( x )$为减函数，
在区间$( \frac{- ( a + 1 ) + \sqrt{2 a + 1}}{a}$,$\frac{- ( a + 1 ) - \sqrt{2 a + 1}}{a} )$上，
$f^{'} ( x ) > 0$，函数$f ( x )$为增函数；
综合可得：当$a \geq 0$时，$f ( x )$在$( 0 , + \infty )$上为增函数，
当$a \leq - \frac{1}{2}$时，函数$f ( x )$在$( 0 , + \infty )$上为减函数，
当$- \frac{1}{2} < a < 0$时，在区间$( 0$,$\frac{- ( a + 1 ) + \sqrt{2 a + 1}}{a} )$
和$( \frac{- ( a + 1 ) - \sqrt{2 a + 1}}{a}$,$+ \infty )$上，函数$f ( x )$为减函数，
在区间$( \frac{- ( a + 1 ) + \sqrt{2 a + 1}}{a}$,$\frac{- ( a + 1 ) - \sqrt{2 a + 1}}{a} )$上，函数$f ( x )$为增函数．
##### 【典例2】（2023·全国·高二专题练习）已知函数$f ( x ) = \frac{1}{x} - x + a \ln x ( a > 0 )$.讨论$f ( x )$的单调性．

<span class="fake-tag">详解</span>由题意知，$f ( x )$定义域为$( 0 , + \infty )$，$f^{'} ( x ) = - \frac{1}{x^{2}} - 1 + \frac{a}{x} = - \frac{x^{2} - a x + 1}{x^{2}} ( a > 0 )$；
令$g ( x ) = x^{2} - a x + 1 ( a > 0 )$，则$\Delta = a^{2} - 4$.
①当$\Delta \leq 0$，即$0 < a \leq 2$时，$f^{'} ( x ) \leq 0$（当且仅当$a = 2$，$x = 1$时取等号），
$\therefore f ( x )$在$( 0 , + \infty )$上单调递减；
②当$\Delta > 0$，即$a > 2$时，令$g ( x ) = 0$，解得$x_{1} = \frac{a - \sqrt{a^{2} - 4}}{2}$，$x_{2} = \frac{a + \sqrt{a^{2} - 4}}{2}$，
$\therefore$当$x \in \left( 0 , x_{1} \right) \cup \left( x_{2} , + \infty \right)$时，$f^{'} ( x ) < 0$；当时，$f^{'} ( x ) > 0$；
$\therefore f ( x )$在$\left( 0 , \frac{a - \sqrt{a^{2} - 4}}{2} \right) , \left( \frac{a + \sqrt{a^{2} - 4}}{2} , + \infty \right)$上单调递减，在$\left( \frac{a - \sqrt{a^{2} - 4}}{2} , \frac{a + \sqrt{a^{2} - 4}}{2} \right)$上单调递增；
综上所述：当$0 < a \leq 2$时，$f ( x )$在$( 0 , + \infty )$上单调递减；
当$a > 2$时，$f ( x )$在$\left( 0 , \frac{a - \sqrt{a^{2} - 4}}{2} \right) , \left( \frac{a + \sqrt{a^{2} - 4}}{2} , + \infty \right)$上单调递减，在$\left( \frac{a - \sqrt{a^{2} - 4}}{2} , \frac{a + \sqrt{a^{2} - 4}}{2} \right)$上单调递增.
