$\quad$A． 
$\quad$B．

##### 【典例3】（2023·全国·高三专题练习）经过$\bigtriangleup O A B$的重心*G*的直线与*OA*，*OB*分别交于点*P*，*Q*，设$\overrightarrow{O P} = m \overrightarrow{O A}$，$\overrightarrow{O Q} = n \overrightarrow{O B} ( m > 0 , n > 0 )$.
(1)证明：$\frac{1}{m} + \frac{1}{n}$为定值；
(2)求*m*＋*n*的最小值.
<span class="fake-tag">答案</span>(1)证明见解析
(2)$\frac{4}{3}$
<span class="fake-tag">详解</span>（1）设$\overrightarrow{O A} = \overrightarrow{a} , \overrightarrow{O B} = \overrightarrow{b}$，
因为$\bigtriangleup O A B$的重心是*G*点，
所以$\overrightarrow{O G} = \frac{2}{3} \times \frac{1}{2} \left( \overrightarrow{a} + \overrightarrow{b} \right) = \frac{1}{3} \left( \overrightarrow{a} + \overrightarrow{b} \right)$，
$\overrightarrow{P Q} = \overrightarrow{O Q} - \overrightarrow{O P} = n \overrightarrow{b} - m \overrightarrow{a}$，
$\overrightarrow{P G} = \overrightarrow{O G} - \overrightarrow{O P} = \frac{1}{3} \left( \overrightarrow{a} + \overrightarrow{b} \right) - m \overrightarrow{a} = \left( \frac{1}{3} - m \right) \overrightarrow{a} + \frac{1}{3} \overrightarrow{b}$，
因为*G*， *P*，*Q*三点共线，
所以存在$\lambda$，使得$\overrightarrow{P Q} = \lambda \overrightarrow{P G}$，即$n \overrightarrow{b} - m \overrightarrow{a} = \lambda \left\lbrack \left( \frac{1}{3} - m \right) \overrightarrow{a} + \frac{1}{3} \overrightarrow{b} \right\rbrack$，
所以有$\begin{cases}- m = \lambda \left( \frac{1}{3} - m \right) \\ n = \frac{1}{3} \lambda\end{cases} \Rightarrow \frac{1}{m} + \frac{1}{n} = 3$；
（2）因为$m > 0 , n > 0$，
所以$m + n = \frac{1}{3} ( m + n ) \left( \frac{1}{m} + \frac{1}{n} \right) = \frac{1}{3} \left( 2 + \frac{n}{m} + \frac{m}{n} \right) \geq \frac{1}{3} \left( 2 + 2 \sqrt{\frac{n}{m} \cdot \frac{m}{n}} \right) = \frac{4}{3}$，
当且仅当时取等号，即当$m = n = \frac{3}{2}$时取等号，
所以*m*＋*n*的最小值为$\frac{4}{3}$.
##### 【变式1】（2023上·江西吉安·高三吉安一中校考期中）$\bigtriangleup A B C$中，$D$为$A C$上一点且满足$\overrightarrow{C D} = \frac{3}{4} \overrightarrow{C A}$，若$P$为$B D$上一点，且满足$\overrightarrow{A P} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C}$，$\lambda , \mu$为正实数，则下列结论正确的是（ ）
$\quad$A．$\lambda \mu$的最小值为$\frac{1}{16}$ 
$\quad$B．$\lambda \mu$的最大值为1
$\quad$C．的最大值为16 
$\quad$D．的最小值为4
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>AB选项，因为$\overrightarrow{C D} = \frac{3}{4} \overrightarrow{C A}$，所以$\overrightarrow{A C} = 4 \overrightarrow{A D}$，
故$\overrightarrow{A P} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C} = \lambda \overrightarrow{A B} + 4 \mu \overrightarrow{A D}$，
因为$B , P , D$三点共线，设$\overrightarrow{P B} = m \overrightarrow{B D}$，即$\overrightarrow{A B} - \overrightarrow{A P} = m \overrightarrow{A D} - m \overrightarrow{A B}$，
故$\overrightarrow{A P} = ( 1 + m ) \overrightarrow{A B} - m \overrightarrow{A D}$，
令$\lambda = 1 + m , 4 \mu = - m$，故$\lambda + 4 \mu = 1$，
![@@@662629288791458f9c6c9c5da9531d3f](高中习题/课堂同步/随堂练习习题/media/59639d73bc2e369a55b9b18f106382d3.png)
$\lambda , \mu$为正实数，由基本不等式得$\lambda + 4 \mu = 1 \geq 2 \sqrt{4 \lambda \mu} = 4 \sqrt{\lambda \mu}$，解得$\lambda \mu \leq \frac{1}{16}$，
当且仅当$\lambda = \frac{1}{2} , \mu = \frac{1}{8}$时，等号成立，所以$\lambda \mu$的最大值为$\frac{1}{16}$，AB错误；
CD选项，$\frac{1}{\lambda} + \frac{1}{4 \mu} = \left( \frac{1}{\lambda} + \frac{1}{4 \mu} \right) \cdot ( \lambda + 4 \mu ) = 1 + 1 + \frac{4 \mu}{\lambda} + \frac{\lambda}{4 \mu} \geq 2 + 2 \sqrt{\frac{4 \mu}{\lambda} \cdot \frac{\lambda}{4 \mu}} = 4$，
当且仅当$\frac{4 \mu}{\lambda} = \frac{\lambda}{4 \mu}$，即$\lambda = \frac{1}{2} , \mu = \frac{1}{8}$时，等号成立，C错误，D正确.
故选：D

##### 【变式3】（2023下·陕西西安·高一西安市铁一中学校考期中）如图，已知点$G$是$\bigtriangleup A B C$的重心，若过$\bigtriangleup A B C$的重心$G$，且$\overrightarrow{A B} = \overrightarrow{a}$，$\overrightarrow{A C} = \overrightarrow{b}$，$\overrightarrow{A P} = m \overrightarrow{a}$，$\overrightarrow{A Q} = n \overrightarrow{b}$（$m > 0$，$n > 0$），试求$m + 2 n$的最小值．
![@@@a1277697-9abb-4586-8659-e6239a60ba13](高中习题/课堂同步/随堂练习习题/media/2ef7559f6d92200dcaa025f2adb539d7.png)
<span class="fake-tag">答案</span>$1 + \frac{2 \sqrt{2}}{3}$
<span class="fake-tag">详解</span>∵$G$是$\bigtriangleup A B C$的重心，∴$A D$是$B C$边上的中线，，
∴$\overrightarrow{A D} = \frac{1}{2} \left( \overrightarrow{A B} + \overrightarrow{A C} \right) = \frac{1}{2} \left( \overrightarrow{a} + \overrightarrow{b} \right)$，
∴$\overrightarrow{A G} = \frac{2}{3} \overrightarrow{A D} = \frac{2}{3} \times \frac{1}{2} \left( \overrightarrow{a} + \overrightarrow{b} \right) = \frac{1}{3} \left( \overrightarrow{a} + \overrightarrow{b} \right)$，
又∵$\overrightarrow{A P} = m \overrightarrow{a}$，$\overrightarrow{A Q} = n \overrightarrow{b}$（$m > 0$，$n > 0$），∴$\overrightarrow{a} = \frac{1}{m} \overrightarrow{A P}$，$\overrightarrow{b} = \frac{1}{n} \overrightarrow{A Q}$，
∴$\overrightarrow{A G} = \frac{1}{3} \left( \overrightarrow{a} + \overrightarrow{b} \right) = \frac{1}{3} \left( \frac{1}{m} \overrightarrow{A P} + \frac{1}{n} \overrightarrow{A Q} \right) = \frac{1}{3 m} \overrightarrow{A P} + \frac{1}{3 n} \overrightarrow{A Q}$，
又∵$P$，$Q$，$G$三点共线，
∴$\frac{1}{3 m} + \frac{1}{3 n} = 1$.
又∵$m > 0$，$n > 0$，∴由基本不等式，有
$m + 2 n = ( m + 2 n ) \left( \frac{1}{3 m} + \frac{1}{3 n} \right) = 1 + \frac{2 n}{3 m} + \frac{m}{3 n} \geq 1 + 2 \sqrt{\frac{2 n}{3 m} \times \frac{m}{3 n}} = 1 + \frac{2 \sqrt{2}}{3}$，
当且仅当$\frac{2 n}{3 m} = \frac{m}{3 n}$，即$m = \frac{1 + \sqrt{2}}{3}$，$n = \frac{2 + \sqrt{2}}{6}$时，等号成立，
∴$m + 2 n$的最小值为$1 + \frac{2 \sqrt{2}}{3}$.
