##### 题型01 测量距离问题
##### 【典例1】（2023上·全国·高三专题练习）某地为响应习近平总书记关于生态文明建设的号召，大力开展“青山绿水”工程，造福于民，拟对该地某湖泊进行治理，在治理前，需测量该湖泊的相关数据.如图所示，测得∠*C*＝120°，$B C = 4 0$米，$A C = 6 0 \sqrt{3}$米，则*A*，*B*间的直线距离约为（ ）
![@@@5de3c59d14e84c01837e9b0ce51a6ccb](MathLogic-Weave/高中数学逻辑结构/题/Attachments/bf44dd09c11011e7dc08686949e66641.png)
$\quad$A．60米 
$\quad$B．130米 
$\quad$C．150米 
$\quad$D．300米
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由题设，在$\bigtriangleup A B C$中，
由余弦定理$A B^{2} = A C^{2} + B C^{2} - 2 A C \cdot B C \cos C = 1 2 4 0 0 + 2 4 0 0 \sqrt{3} \approx 16557$，
所以$A B \approx 130$米.
故选：B.
##### 【典例2】（2023上·江苏无锡·高一江苏省南菁高级中学校考阶段练习）如图，位于我国南海海域的某直径为$5 \sqrt{5}$海里的圆形海域上有四个小岛，已知小岛*B*与小岛*C*相距为5海里（小岛的大小忽略不计，测量误差忽略不计），经过测量得到数据：$\text{cos} \angle B A D = - \frac{2}{3}$．小岛*C*与小岛*D*之间的距离为 海里．
![@@@fdbe51e4-4cd2-44b5-afe9-bda5e52fcf9e](MathLogic-Weave/高中数学逻辑结构/题/Attachments/4ee804c8548423866860a83acf2d51ae.png)
<span class="fake-tag">答案</span>$\frac{1 0 + 1 0 \sqrt{5}}{3}$
<span class="fake-tag">详解</span>由于四点共圆，
所以，
由正弦定理可知$\frac{B D}{\sin C} = 5 \sqrt{5} \Rightarrow B D = \frac{25}{3}$，
在$\bigtriangleup B C D$中，$B D^{2} = C D^{2} + B C^{2} - 2 \cos C \cdot C D \cdot C B \Rightarrow C D^{2} - \frac{20}{3} C D - \frac{400}{9} = 0$，
解之得$C D = \frac{\frac{20}{3} \pm \frac{20 \sqrt{5}}{3}}{2} = \frac{10}{3} \pm \frac{10 \sqrt{5}}{3}$，
显然$\frac{10 - 10 \sqrt{5}}{3} < 0$不合题意.
故答案为：$\frac{1 0 + 1 0 \sqrt{5}}{3}$.
##### 【典例3】（2023·辽宁抚顺·校考模拟预测）如图，某乡镇绿化某一座山体，以地面为基面，在基面上选取*A*，*B*，*C*，*D*四个点，使得$A D = 2 \sqrt{2} B C$，测得$\angle B A D = 3 0^{\circ}$，$\angle B C D = 4 5^{\circ}$，$\angle A D C = 1 2 0^{\circ}$．
![@@@036f3f0b-1407-416a-8ecb-8ee57f817990](MathLogic-Weave/高中数学逻辑结构/题/Attachments/628ee2a5fec947b49e21ee2ae4df5e46.png)
(1)若*B*，*D*选在两个村庄，两村庄之间有一直线型隧道，且$B D = 1 0 \sqrt{2} \text{km}$，$C D = 2 0 \text{km}$，求*A*，*C*两点间距离；
(2)求的值．
<span class="fake-tag">答案</span>(1)$20 \sqrt{7} \text{km}$
(2)$\frac{4 + \sqrt{3}}{13}$
<span class="fake-tag">详解</span>（1）在$\bigtriangleup B C D$中，由正弦定理得，
即$\frac{20}{\sin \angle C B D} = \frac{10 \sqrt{2}}{\sin 4 5^{\circ}}$，
解得$\sin \angle C B D = 1$，所以$\angle C B D = 9 0^{\circ}$，
则$\bigtriangleup B C D$为等腰直角三角形，所以，
则$A D = 2 \sqrt{2} B C = 4 0$．
![@@@f00f2453-622f-423d-b03c-21e4aa56b096](MathLogic-Weave/高中数学逻辑结构/题/Attachments/9a97101308e8eb39348ec6759e79460d.png)
在$\bigtriangleup A C D$中，由余弦定理得
$A C^{2} = A D^{2} + C D^{2} - 2 A D \times C D \cos \angle A D C = 1 6 0 0 + 4 0 0 - 2 \times 40 \times 20 \times \left( - \frac{1}{2} \right) = 2 8 0 0$，
故$A C = 2 0 \sqrt{7}$．
故*A*，*C*两点间距离为$20 \sqrt{7} \text{km}$．
（2）设$\angle B D C = \theta$，则由题意可知，$\angle A D B = 1 2 0^{\circ} - \theta$，$\angle A B D = 3 0^{\circ} + \theta$．
在$\bigtriangleup A B D$中，由正弦定理得$\frac{B D}{\sin \angle B A D} = \frac{A D}{\sin \angle A B D}$，即$\frac{A D}{B D} = 2 \sin \left( 3 0^{\circ} + \theta \right)$，
在$\bigtriangleup B C D$中，由正弦定理得$\frac{B C}{\sin \angle B D C} = \frac{B D}{\sin \angle B C D}$，即$\frac{B C}{B D} = \sqrt{2} \sin \theta$，
又$A D = 2 \sqrt{2} B C$，所以$2 \sin \left( 3 0^{\circ} + \theta \right) = 2 \sqrt{2} \times \sqrt{2} \sin \theta \Rightarrow \frac{1}{2} \cos \theta + \frac{\sqrt{3}}{2} \sin \theta = 2 \sin \theta$，
解得$\tan \theta = \frac{4 + \sqrt{3}}{13}$，所以$\tan \angle B D C = \frac{4 + \sqrt{3}}{13}$．
##### 【变式1】（2023上·北京·高三北京四中校考期中）如图，为了测量湖两侧的$A$，$B$两点之间的距离，某观测小组的三位同学分别在$B$点，距离$A$点30km处的$C$点，以及距离$C$点10km处的$D$点进行观测.甲同学在$B$点测得$\angle D B C = 3 0 {^\circ}$，乙同学在$C$点测得$\angle A C B = 4 5 {^\circ}$，丙同学在$D$点测得$\angle B D C = 4 5 {^\circ}$，则$A$，$B$两点间的距离为 km.
![@@@09c4faf4-97df-4db3-a7ee-188337c4f4f9](MathLogic-Weave/高中数学逻辑结构/题/Attachments/ba330dd79da5a9b6a0f5c1d0359d5e48.png)
<span class="fake-tag">答案</span>$10 \sqrt{5}$
<span class="fake-tag">详解</span>$\angle D B C = 3 0 {^\circ}$， $\angle A C B = 4 5 {^\circ}$， $\angle B D C = 4 5 {^\circ}$，$A C = 3 0$，$C D = 1 0$，
$\bigtriangleup B C D$中，由正弦定理，有$\frac{C D}{\sin \angle D B C} = \frac{B C}{\sin \angle B D C}$，则$B C = \frac{C D \sin \angle B D C}{\sin \angle D B C} = \frac{10 \sin 4 5 {^\circ}}{\sin 3 0 {^\circ}} = 1 0 \sqrt{2}$，
$\bigtriangleup A B C$中，由余弦定理，
有$A B^{2} = B C^{2} + A C^{2} - 2 B C \cdot A C \cdot \cos \angle A C B = \left( 10 \sqrt{2} \right)^{2} + 3 0^{2} - 2 \times 10 \sqrt{2} \times 30 \times \frac{\sqrt{2}}{2} = 5 0 0$，
得$A B = 1 0 \sqrt{5}$，即$A$，$B$两点间的距离为$10 \sqrt{5}$.
故答案为：$10 \sqrt{5}$.
##### 【变式2】（2023上·全国·高三专题练习）如图，*A*、*B*两点都在河的对岸(不可到达)，若在河岸选取相距20米的*C*、*D*两点，测得∠*BCA*＝60°，∠*ACD*＝30°，∠*CDB*＝45°，∠*BDA*＝60°，那么此时*A*，*B*两点间的距离是多少？
![@@@f05ad362-f30f-4e19-b297-92e09c393f88](MathLogic-Weave/高中数学逻辑结构/题/Attachments/69298eafdf2f3562f2d84f1ce0d70181.png)
<span class="fake-tag">答案</span>$10 \sqrt{6}$米
<span class="fake-tag">详解</span>根据正弦定理，
在$\bigtriangleup A C D$中，有$\frac{2 0 ( \sin 4 5^{^\circ} \cos 6 0 {^\circ} + \cos 4 5 {^\circ} \sin 6 0 {^\circ} )}{\sin 4 5 {^\circ}} = 1 0 ( 1 + \sqrt{3} )$ (米)，
在$\bigtriangleup B C D$中，有$B C = \frac{C D \sin 4 5 {^\circ}}{\sin \left\lbrack 18 0^{^\circ} - \left( 3 0^{^\circ} + 4 5 {^\circ} + 6 0^{^\circ} \right) \right\rbrack} = 2 0$ (米)．
在$\bigtriangleup A B C$中，由余弦定理得*AB*＝$\sqrt{A C^{2} + B C^{2} - 2 A C \cdot B C \cos \angle B C A}$＝$10 \sqrt{6}$ (米)．
所以*A*，*B*两点间的距离为$10 \sqrt{6}$米．
##### 【变式3】（2023下·辽宁·高二凤城市第一中学校联考阶段练习）如图，某湿地为拓展旅游业务，现准备在湿地内建造一个观景台$D$，已知射线$A B$，$A C$为湿地两边夹角为$\frac{\pi}{3}$的两条公路（长度均超过4千米），在两条公路$A B$，$A C$上分别设立游客接送点$E$，$F$，且千米．若要求观景台$D$与两接送点所成角$\angle E D F$与$\angle B A C$互补，且观景台$D$在$E F$的右侧，并在观景台$D$与接送点$E$，$F$之间建造两条观光线路$D E$和$D F$，求观光线路之和最长是多少千米，此时$D A$为多少千米？
![@@@279a7099-936a-45a1-82c0-3ac0e62f69dc](MathLogic-Weave/高中数学逻辑结构/题/Attachments/0924387fab957e57fabb81a6c2fe815e.png)
<span class="fake-tag">答案</span>观光线路之和最长是4千米，此时$D A$为4千米
<span class="fake-tag">详解</span>在$\bigtriangleup A E F$中，因为，$\angle E A F = \frac{\pi}{3}$，所以$E F = 2 \sqrt{3}$，
又$\angle E D F$与$\angle E A F$互补，所以$\angle E D F = \frac{\text{2} \text{π}}{3}$，
在$\bigtriangleup D E F$中，由余弦定理得，
即$D E^{2} + D F^{2} + D E \cdot D F = 1 2$，即$( D E + D F )^{2} - D E \cdot D F = 1 2$，
又因为，所以$D E + D F \leq 4$，
当且仅当$D E = D F = 2$时取等号，
![@@@9ed106dd-e604-4451-a393-610b1eeb413c](MathLogic-Weave/高中数学逻辑结构/题/Attachments/a2124cb2b017fc8b4f39742e7dca704e.png)
此时由于$D E = D F$，，$A D = A D$，所以$\bigtriangleup A D E$≌$\bigtriangleup A D F$，
又$\angle E D F$与$\angle E A F$互补，所以$\angle A E D = \frac{\pi}{2}$，所以$A D = 4$.
所以观光线路之和最长是4千米，此时$D A$为4千米.
