##### 题型03 向量共线的判定
##### 【典例1】（2022·河南·校联考三模）已知$\overrightarrow{a}$、$\overrightarrow{b}$、$\overrightarrow{c}$均为非零向量，且$\overrightarrow{a} = 2 \overrightarrow{b}$，$\overrightarrow{b} = - 3 \overrightarrow{c}$，则（ ）
$\quad$A．$\overrightarrow{a}$与$\overrightarrow{c}$垂直 
$\quad$B．$\overrightarrow{b}$与$\overrightarrow{c}$同向 
$\quad$C．$\overrightarrow{a}$与$\overrightarrow{c}$反向 
$\quad$D．$\overrightarrow{a}$与$\overrightarrow{b}$反向
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>因为$\overrightarrow{a} = 2 \overrightarrow{b}$，$\overrightarrow{b} = - 3 \overrightarrow{c}$，所以$\overrightarrow{a}$与$\overrightarrow{b}$同向，$\overrightarrow{b}$与$\overrightarrow{c}$反向，所以$\overrightarrow{a}$与$\overrightarrow{c}$反向．
故选：C.
##### 【典例2】（2023·高一课时练习）设$\overrightarrow{e_{1}}$，$\overrightarrow{e_{2}}$是两个不共线的向量，关于向量$\overrightarrow{a}$，$\overrightarrow{b}$有①$\overrightarrow{a} = 2 \overrightarrow{e_{1}}$，$\overrightarrow{b} = - 2 \overrightarrow{e_{1}}$；②$\overrightarrow{a} = \overrightarrow{e_{1}} - \overrightarrow{e_{2}}$，$\overrightarrow{b} = - 2 \overrightarrow{e_{1}} + 2 \overrightarrow{e_{2}}$；③$\  \overrightarrow{a} = 4 \overrightarrow{e_{1}} - \frac{2}{5} \overrightarrow{e_{2}}$；$\overrightarrow{b} = \overrightarrow{e_{1}} - \frac{1}{10} \overrightarrow{e_{2}}$，④$\overrightarrow{a} = \overrightarrow{e_{1}} + \overrightarrow{e_{2}}$；$\overrightarrow{b} = 2 \overrightarrow{e_{1}} - 2 \overrightarrow{e_{2}}$．其中$\overrightarrow{a}$，$\overrightarrow{b}$共线的有 ．（填序号）
<span class="fake-tag">答案</span>①②③
<span class="fake-tag">详解</span>①，共线；
②$\overrightarrow{a} = - \frac{1}{2} \overrightarrow{b}$，共线；
③$\overrightarrow{a} = 4 \overrightarrow{b}$，共线；
④$\overrightarrow{a}$和$\overrightarrow{b}$无法表示成$\overrightarrow{a} = \lambda \overrightarrow{b}$，所以不共线.
故答案为：①②③
##### 【典例3】（2023·全国·高一随堂练习）设$\overrightarrow{e_{1}}$，$\overrightarrow{e_{2}}$为不共线的非零向量，判断下列各题中的$\overrightarrow{a}$，$\overrightarrow{b}$向量是否共线．
(1)$\overrightarrow{a} = - 2 \overrightarrow{e_{1}}$，$\overrightarrow{b} = 2 \overrightarrow{e_{1}}$；
(2)$\overrightarrow{a} = \overrightarrow{e_{1}} - \overrightarrow{e_{2}}$，$\overrightarrow{b} = - 2 \overrightarrow{e_{1}} + 2 \overrightarrow{e_{2}}$；
(3)$\overrightarrow{a} = - 2 \overrightarrow{e_{1}} + 3 \overrightarrow{e_{2}}$，$\overrightarrow{b} = 2 \overrightarrow{e_{1}}$．
<span class="fake-tag">答案</span>(1)共线(2)共线 3)不共线
<span class="fake-tag">详解</span>（1），则有$\overrightarrow{a} = - \overrightarrow{b}$，即$\overrightarrow{a} , \overrightarrow{b}$共线；
（2）$\overrightarrow{a} = \overrightarrow{e_{1}} - \overrightarrow{e_{2}} , \overrightarrow{b} = - 2 \overrightarrow{e_{1}} + 2 \overrightarrow{e_{2}} = - 2 \left( \overrightarrow{e_{1}} - \overrightarrow{e_{2}} \right)$，则有$\overrightarrow{b} = - 2 \overrightarrow{a}$，即$\overrightarrow{a} , \overrightarrow{b}$共线；
（3）设$\overrightarrow{a}$，$\overrightarrow{b}$共线，则由共线向量基本定理，得存在$\lambda \in R$，使$\overrightarrow{a} = \lambda \overrightarrow{b}$，
即$- 2 \overrightarrow{e_{1}} + 3 \overrightarrow{e_{2}} = 2 \lambda \overrightarrow{e_{1}}$，所以$\overrightarrow{e_{2}} = \frac{( 2 \lambda + 2 )}{3} \overrightarrow{e_{1}}$，所以$\overrightarrow{e_{1}} , \overrightarrow{e_{2}}$共线，
这与已知条件$\overrightarrow{e_{1}} , \overrightarrow{e_{2}}$不共线矛盾，不共线.
##### 【变式1】（2023·全国·高一专题练习）对于非零向量$\overrightarrow{a} , \overrightarrow{b}$， “$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{0}$”是“$\overrightarrow{a} / / \overrightarrow{b}$”的（ ）
$\quad$A．充分不必要条件 
$\quad$B．必要不充分条件
$\quad$C．充分必要条件 
$\quad$D．既不充分也不必要条件
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>对于非零向量$\overrightarrow{a} , \overrightarrow{b}$，当$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{0}$时，，$\overrightarrow{a} / / \overrightarrow{b}$一定成立，即充分性成立；
当$\overrightarrow{a} / / \overrightarrow{b}$时，$\overrightarrow{a} = \lambda \overrightarrow{b} ( \lambda \neq 0 )$，不一定满足$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{0}$，即必要性不成立.
所以对于非零向量$\overrightarrow{a} , \overrightarrow{b}$， “$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{0}$”是“$\overrightarrow{a} / / \overrightarrow{b}$”的充分不必要条件.
故选：A
##### 【变式2】（2023·高一课时练习）已知$\overrightarrow{a}$、$\overrightarrow{b}$是两非零向量，且$\overrightarrow{a}$与$\overrightarrow{b}$共线，若非零向量$\overrightarrow{c}$与$\overrightarrow{a}$共线，则$\overrightarrow{c}$与$\overrightarrow{b}$必定 ．
<span class="fake-tag">答案</span>共线
<span class="fake-tag">详解</span>因为$\overrightarrow{a}$、$\overrightarrow{b}$是两非零向量，且$\overrightarrow{a}$与$\overrightarrow{b}$共线，所以$\exists \lambda_{1}$，使得$\overrightarrow{a} = \lambda_{1} \overrightarrow{b}$.
又因为非零向量$\overrightarrow{c}$与$\overrightarrow{a}$共线，所以$\exists \lambda_{2}$，使得$\overrightarrow{c} = \lambda_{2} \overrightarrow{a}$.
所以，$\overrightarrow{c} = \lambda_{2} \overrightarrow{a} = \lambda_{1} \lambda_{2} \overrightarrow{b}$.
所以，$\overrightarrow{c}$与$\overrightarrow{b}$必定共线.
故答案为：共线.
##### 【变式3】（2023·全国·高一随堂练习）判断下列各小题中的向量$\overrightarrow{a}$，$\overrightarrow{b}$是否共线：
(1)$\overrightarrow{a} = 3 \overrightarrow{e}$，$\overrightarrow{b} = - \frac{3}{2} \overrightarrow{e}$；
(2)$\overrightarrow{a} = - 2 \overrightarrow{e_{1}} - 2 \overrightarrow{e_{2}}$，$\overrightarrow{b} = \overrightarrow{e_{1}} + \overrightarrow{e_{2}}$（其中两个非零向量$\overrightarrow{e_{1}}$和$\overrightarrow{e_{2}}$不共线）；
(3)$\overrightarrow{a} = \frac{2}{3} \overrightarrow{e}$，$\overrightarrow{b} = 3 \overrightarrow{a} - \frac{5}{2} \overrightarrow{e}$.
<span class="fake-tag">答案</span>(1)共线；(2)共线；(3)共线.
<span class="fake-tag">详解</span>（1）$\overrightarrow{a} = 3 \overrightarrow{e}$，$\overrightarrow{b} = - \frac{3}{2} \overrightarrow{e}$，所以$\overrightarrow{a} = - 2 \overrightarrow{b}$，
所以$\overrightarrow{a}$，$\overrightarrow{b}$共线.
（2）$\overrightarrow{a} = - 2 \overrightarrow{e_{1}} - 2 \overrightarrow{e_{2}}$，$\overrightarrow{b} = \overrightarrow{e_{1}} + \overrightarrow{e_{2}}$,
所以$\overrightarrow{b} = - 2 \overrightarrow{a}$，所以$\overrightarrow{a}$，$\overrightarrow{b}$共线.
（3）因为$\overrightarrow{a} = \frac{2}{3} \overrightarrow{e}$，$\overrightarrow{b} = 3 \overrightarrow{a} - \frac{5}{2} \overrightarrow{e}$，
所以$\overrightarrow{b} = 2 \overrightarrow{e} - \frac{5}{2} \overrightarrow{e} = - \frac{1}{2} \overrightarrow{e}$，
所以$\overrightarrow{a} = - \frac{4}{3} \overrightarrow{b}$.
所以$\overrightarrow{a}$，$\overrightarrow{b}$共线.
