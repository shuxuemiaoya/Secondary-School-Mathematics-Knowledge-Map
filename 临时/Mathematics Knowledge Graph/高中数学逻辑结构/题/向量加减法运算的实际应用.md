##### 题型05 向量加减法运算的实际应用
##### 【典例1】（2021下·高一课时练习）某人顺风匀速行走速度大小为$\overrightarrow{a}$，方向与风向相同，此时风速大小为$\overrightarrow{v}$，则此人实际感到的风速为（ ）
$\quad$A．$\overrightarrow{a} - \overrightarrow{v}$ 
$\quad$B．$\overrightarrow{v} - \overrightarrow{a}$
$\quad$C．$\overrightarrow{a} + \overrightarrow{v}$ 
$\quad$D．$\overrightarrow{v}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题意，某人顺风匀速行走速度大小为$\overrightarrow{a}$，方向与风向相同，此时风速大小为$\overrightarrow{v}$，
根据向量的运算法则，可得此人实际感到的风速为$\overrightarrow{a} - \overrightarrow{v}$.
故选：A.
##### 【典例2】（2023·高一课时练习）在$\overrightarrow{a} =$ “向北走$20 \text{km}$”，$\overrightarrow{b} =$ “向西走$15 \text{km}$”，则$| \overrightarrow{a} - \overrightarrow{b} | =$ ，$\overrightarrow{a} + \overrightarrow{b}$与$\overrightarrow{a}$的夹角的余弦值为 ．
<span class="fake-tag">答案</span> 25 $\frac{4}{5}$/$0 . 8$
<span class="fake-tag">详解</span>如图，在矩形$O A C B$中，设$\overrightarrow{a} = \overrightarrow{O A} , \overrightarrow{b} = \overrightarrow{O B}$，则$\left| \overrightarrow{a} \right| = \left| \overrightarrow{O A} \right| = 2 0 , \left| \overrightarrow{b} \right| = \left| \overrightarrow{O B} \right| = 1 5$，
空1：$| \overrightarrow{a} - \overrightarrow{b} | = \left| \overrightarrow{O A} - \overrightarrow{O B} \right| = \left| \overrightarrow{B A} \right| = \sqrt{2 0^{2} + 1 5^{2}} = 2 5$；
空2：因为$\overrightarrow{a} + \overrightarrow{b} = \overrightarrow{O A} + \overrightarrow{O B} = \overrightarrow{O C}$，则$\overrightarrow{a} + \overrightarrow{b}$与$\overrightarrow{a}$的夹角即为$\angle A O C$，
所以$\cos \angle A O C = \frac{O A}{O C} = \frac{O A}{A B} = \frac{20}{25} = \frac{4}{5}$.
故答案为：25；$\frac{4}{5}$.

##### 【变式1】（2023·全国·高一专题练习）在$\bigtriangleup A B C$中，若$\left| \overrightarrow{A B} \right| = | \overrightarrow{A C} | = \left| \overrightarrow{A B} - \overrightarrow{A C} \right|$，则$\bigtriangleup A B C$的形状为（ ）
$\quad$A．等边三角形 
$\quad$B．等腰三角形
$\quad$C．直角三角形 
$\quad$D．等腰直角三角形
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>因为$\left| \overrightarrow{A B} - \overrightarrow{A C} \right| = \left| \overrightarrow{C B} \right|$，$\left| \overrightarrow{A B} \right| = | \overrightarrow{A C} | = \left| \overrightarrow{A B} - \overrightarrow{A C} \right|$，
所以$\left| \overrightarrow{A B} \right| = \left| \overrightarrow{A C} \right| = \left| \overrightarrow{C B} \right|$，
所以$\bigtriangleup A B C$为等边三角形．
故选：A
