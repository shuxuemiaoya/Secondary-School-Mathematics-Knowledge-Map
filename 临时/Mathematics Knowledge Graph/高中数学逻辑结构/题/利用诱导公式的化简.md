<span class="fake-tag">详解</span>原式$= \frac{\cos \left( \frac{\pi}{2} - \alpha \right)}{\sin \left( 2 \pi + \frac{\pi}{2} + \alpha \right)} \cdot \left( - \sin \alpha \right) \cdot \frac{\sin \left( \frac{3 \pi}{2} - \alpha \right)}{\cos \left( \frac{3 \pi}{2} - \alpha \right)}$

##### 【典例3】（23-24高一下·江西萍乡·期中）在①$\text{sin} \alpha \text{cos} \alpha = - \frac{2}{5}$，②$\text{sin} \alpha = - \frac{2 \sqrt{5}}{5}$两个条件中任选一个补充到下面的问题中，并解答.
已知角$\alpha \in \left( \frac{3 \pi}{2} , \frac{7 \pi}{4} \right)$，且________.
(1)求$\text{tan} \alpha$的值；
(2)求$\frac{\text{sin} \left( \frac{3 \pi}{2} - \alpha \right) \text{cos} ( \pi + \alpha ) \text{tan} ( - \alpha - \pi )}{\text{cos} ( 2 \pi - \alpha ) \text{sin} ( \pi - \alpha ) \text{tan} ( - \alpha )}$的值.

(2)$- \frac{1}{2}$
<span class="fake-tag">分析</span>（1）若选①，根据同角三角函数关系结合齐次化方法，可得$\frac{\text{tan} \alpha}{\text{ta} \text{n}^{2} \alpha + 1} = - \frac{2}{5}$，解方程求$\tan \alpha$，
若选②，根据同角关系由$\sin \alpha$求$\cos \alpha$，再求$\tan \alpha$；
（2）根据诱导公式化简求值.
<span class="fake-tag">详解</span>（1）若选①，因为$\text{sin} \alpha \text{cos} \alpha = - \frac{2}{5}$，所以$\frac{\text{sin} \alpha \text{cos} \alpha}{\text{si} \text{n}^{2} \alpha + \text{co} \text{s}^{2} \alpha} = - \frac{2}{5}$，
则$\frac{\text{tan} \alpha}{\text{ta} \text{n}^{2} \alpha + 1} = - \frac{2}{5}$，解得：$\text{tan} \alpha = - 2$或，
因为角$\alpha \in \left( \frac{3 \pi}{2} , \frac{7 \pi}{4} \right)$，所以$\text{tan} \alpha = - 2$；
若选②，因为$\text{sin} \alpha = - \frac{2 \sqrt{5}}{5}$，角$\alpha \in \left( \frac{3 \pi}{2} , \frac{7 \pi}{4} \right)$，
所以$\text{cos} \alpha = \sqrt{1 - \text{si} \text{n}^{2} \alpha} = \frac{\sqrt{5}}{5}$，
所以$\text{tan} \alpha = \frac{\text{sin} \alpha}{\text{cos} \alpha} = \frac{- \frac{2 \sqrt{5}}{5}}{\frac{\sqrt{5}}{5}} = - 2$；
（2）由（1）可知，$\text{tan} \alpha = - 2$，
所以$\frac{\text{sin} \left( \frac{3 \pi}{2} - \alpha \right) \text{cos} ( \pi + \alpha ) \text{tan} ( - \alpha - \pi )}{\text{cos} ( 2 \pi - \alpha ) \text{sin} ( \pi - \alpha ) \text{tan} ( - \alpha )} = \frac{\left( - \text{cos} \alpha \right) \left( - \text{cos} \alpha \right) \left( - \text{tan} \alpha \right)}{\text{cos} \alpha \text{sin} \alpha \left( - \text{tan} \alpha \right)} = \frac{\text{cos} \alpha}{\text{sin} \alpha} = \frac{1}{\text{tan} \alpha} = - \frac{1}{2} .$
