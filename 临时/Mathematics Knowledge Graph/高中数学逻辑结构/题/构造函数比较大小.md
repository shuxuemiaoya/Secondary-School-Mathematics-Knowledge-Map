
####### 题型6：构造函数比较大小
![](3d6e9aabbc6bf69399470e132f3bcf0a03af3ae2f254c88e2e6d08e1fe57bcb5.jpg)
在比较两数（式）的大小关系时，首先要判断所给函数的单调性，再根据函数的单调性比较大小，有时还需要根据待比较式的结构特征构造新的函数，由新函数的单调性来比较大小。对于大部分同学还是有难度的，专题中有专项练习，本节只做简单了解性练习。
##### 【47】已知  $a = \frac{\ln 7}{7}, b = \frac{1}{\mathrm{e}}, c = \frac{\ln 5}{5}$ ，则  $a, b, c$  的大小关系为（）
$\quad$A.  $c < b < a$  
$\quad$B.  $c < a < b$  
$\quad$C.  $a < c < b$  
$\quad$D.  $a < b < c$
##### 【48】（2024高三下·全国·专题练习）已知  $a = \frac{4}{\ln 4}$ $b = \frac{3}{\ln 3},c = e$  ，则下列大小关系正确的是（
$\quad$A.  $a < b < c$  
$\quad$B.  $a < c < b$  
$\quad$C.  $c < b < a$  
$\quad$D.  $c < a < b$
##### 【49】已知  $a = \left(\frac{3}{2}\right)^{\frac{2}{3}}$  ，  $b = \left(\frac{7}{5}\right)^{\frac{5}{7}}$  ，  $c = \left(\frac{5}{3}\right)^{\frac{3}{5}}$  则  $a,b$ $c$  的大小关系为（ ）
$\quad$A.  $a < b < c$  
$\quad$B.  $b < a < c$  
$\quad$C.  $c < b < a$  
$\quad$D.  $a < c < b$
##### 【50】（23-24高二下·吉林长春·期末）若  $a = \mathrm{e}^{\frac{1}{\mathrm{e}}}$ $b = \sqrt{2},c = \sqrt{6}$  ，则（）

$\quad$B.  $a < b < c$  
$\quad$C.  $c < a < b$  
$\quad$D.  $b < a < c$
