### 题型04 向量坐标运算解决几何问题
##### 【典例1】（2022下·天津南开·高一南开中学校考期末）如图，在矩形$A B C D$中，$A B = 3 , B C = 4 , E$为$A D$上一点，$B E \bot A C$，若$\overrightarrow{B A} = \lambda \overrightarrow{B E} + \mu \overrightarrow{A C}$，则$\lambda - \mu$的值为（ ）
![@@@a667231e-4bc0-4ab1-ac8e-5604a2da4fd6](高中习题/课堂同步/随堂练习习题/必修二/Attachments/316983e79aa1ecc9eebdc9567581ece6.png)
$\quad$A．$\frac{1}{5}$ 
$\quad$B．$\frac{7}{25}$ 
$\quad$C．$\frac{16}{25}$ 
$\quad$D．1
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>![@@@405324d1-4f92-4408-a36c-bcfd569276e0](高中习题/课堂同步/随堂练习习题/必修二/Attachments/59f2c6cad5a2443cb2c2e17cfec93883.png)
建立如图示坐标系，由$A B = 3 , B C = 4 ,$则有：$B ( 0 , 0 ) , C ( 4 , 0 ) , A ( 0 , 3 ) , D ( 4 , 3 ) ,$
因为*E*为$A D$上一点，可设$E ( x , 3 ) ,$
所以$\overrightarrow{B A} = ( 0 , 3 ) , \overrightarrow{B E} = ( x , 3 ) , \overrightarrow{A C} = ( 4 , - 3 )$.
因为$B E \bot A C$，所以$\overrightarrow{B E} \overrightarrow{A C} = 0$，即$4 x - 9 = 0$，解得：$x = \frac{9}{4}$，所以$E \left( \frac{9}{4} , 3 \right)$.
由$\overrightarrow{B A} = \lambda \overrightarrow{B E} + \mu \overrightarrow{A C}$得：
$\begin{cases}\frac{9}{4} \lambda + 4 \mu = 0 \\ 3 \lambda - 3 \mu = 3\end{cases}$，解得：$\begin{cases}\lambda = \frac{16}{25} \\ \mu = - \frac{9}{25}\end{cases}$，所以$\lambda - \mu = 1$.
故选：D
##### 【典例2】（多选）（2023下·河北唐山·高一统考期末）如图，在菱形$A B C D$中，$\angle B A D = 6 0 {^\circ}$，延长边$C D$至点$E$，使得$D E = C D$.动点$P$从点$A$出发，沿菱形的边按逆时针方向运动一周回到$A$点，若，则（ ）
![@@@964c9dc8-7e1f-43a7-a765-90401f648841](高中习题/课堂同步/随堂练习习题/必修二/Attachments/f3d39b733f16368f33f260fd50093267.png)
$\quad$A．满足$\lambda + \mu = 1$的点$P$有且只有一个
$\quad$B．满足$\lambda + \mu = 2$的点$P$有两个
$\quad$C．$\lambda + \mu$存在最小值
$\quad$D．$\lambda + \mu$不存在最大值
<span class="fake-tag">答案</span>BC
<span class="fake-tag">详解</span>建立如图所示的平面直角坐标系，设菱形$A B C D$的边长为1，$P ( x , y )$，则
$A ( 0 , 0 ) , B ( 1 , 0 ) , C \left( \frac{3}{2} , \frac{\sqrt{3}}{2} \right) , D \left( \frac{1}{2} , \frac{\sqrt{3}}{2} \right) , E \left( - \frac{1}{2} , \frac{\sqrt{3}}{2} \right)$，
所以$\overrightarrow{A B} = ( 1 , 0 ) , \overrightarrow{A E} = \left( - \frac{1}{2} , \frac{\sqrt{3}}{2} \right)$，$\overrightarrow{A P} = ( x , y )$，
由，得$( x , y ) = \lambda ( 1 , 0 ) + \mu \left( - \frac{1}{2} , \frac{\sqrt{3}}{2} \right) = \left( \lambda - \frac{1}{2} \mu , \frac{\sqrt{3}}{2} \mu \right)$，
所以$\begin{cases}x = \lambda - \frac{1}{2} \mu \\ y = \frac{\sqrt{3}}{2} \mu\end{cases}$，所以$\lambda + \mu = x + \sqrt{3} y$，
①当点$P$在$A B$上时，$0 \leq x \leq 1$，且$y = 0$，
所以$\lambda + \mu = x + \sqrt{3} y = x \in [ 0 , 1 ]$；
②当点$P$在$B C$（不含点*B*）上时，则$\overrightarrow{B P} = m \overrightarrow{B C}$，所以$( x - 1 , y ) = m \left( \frac{1}{2} , \frac{\sqrt{3}}{2} \right)$，化简$y = \sqrt{3} ( x - 1 )$，
所以$\lambda + \mu = x + \sqrt{3} y = x + 3 ( x - 1 ) = 4 x - 3$，
因为$1 < x \leq \frac{3}{2}$，所以$1 < 4 x - 3 \leq 3$，即$\lambda + \mu \in \left. 1 , 3 \right.$；
③当点$P$在$C D$（不含点*C*）上时，$\frac{1}{2} \leq x < \frac{3}{2}$，且$y = \frac{\sqrt{3}}{2}$，
所以$\frac{1}{2} + \frac{3}{2} \leq x + \sqrt{3} y < \frac{3}{2} + \frac{3}{2}$，即$2 \leq x + \sqrt{3} y < 3$，所以$\lambda + \mu \in \left. 2 , 3 )$；
④当点$P$在$A D$（不含点*A*、*D*）上时，则$\overrightarrow{A P} = n \overrightarrow{A D}$，所以$( x , y ) = n \left( \frac{1}{2} , \frac{\sqrt{3}}{2} \right)$，化简$y = \sqrt{3} x$，
所以$\lambda + \mu = x + \sqrt{3} y = x + 3 x = 4 x$，
因为，所以$0 < 4 x < 2$，所以$\lambda + \mu \in ( 0 , 2 )$；
对于A，由①知，当$\lambda + \mu = 1$时，$x = 1$，此时点$P$与点$B$重合；
由④可知当$\lambda + \mu = 1$时，$x = \frac{1}{4}$，$y = \frac{\sqrt{3}}{4}$，此时点$P$在$A D$的中点处；
其它均不可能，所以这样的点$P$有两个，所以A错误，
对于B，由②知，当$\lambda + \mu = 2$时，$x = \frac{5}{4}$，$y = \frac{\sqrt{3}}{4}$，此时点$P$在$B C$的中点；
由③知，当$\lambda + \mu = 2$时，$x = \frac{1}{2}$，$y = \frac{\sqrt{3}}{2}$，此时点$P$在点$D$处；
其它均不可能，所以这样的点$P$有两个，所以B正确，
对于CD，由①②③④可得：
当$x = y = 0$，即点$P$为点$A$时，$\lambda + \mu$取到最小值0；
当$x = \frac{3}{2} , y = \frac{\sqrt{3}}{2}$，即点$P$为点$C$时，$\lambda + \mu$取到最大值3，所以C正确，D错误，
故选：BC.

##### 【变式1】（多选）（2022·江苏·高三专题练习）如图，延长正方形*ABCD*的边*CD*至点*E*，使得*DE= CD*，动点*P*从点*A*出发，沿正方形的边按逆时针方向运动一周后回到点*A*，若，则下列判断不正确的是（ ）
![@@@b3c2ef7e-059a-4262-940f-1c6a1d17932d](高中习题/课堂同步/随堂练习习题/必修二/Attachments/48fc263cf79dc96f5b3d24e4a6b1ccba.png)
$\quad$A．满足*λ+μ*=2的点*P*必为*BC*的中点
$\quad$B．满足*λ+μ*=1的点*P*有且只有一个
$\quad$C．满足*λ+μ*=3的点*P*有且只有一个
$\quad$D．*λ+μ*=$\frac{3}{2}$的的点*P*有且只有一个
<span class="fake-tag">答案</span>ABD
<span class="fake-tag">详解</span>如图建系，取$A B = 1$，∵$\overrightarrow{A E} = \overrightarrow{A D} + \overrightarrow{D E} = \overrightarrow{A D} - \overrightarrow{A B}$，
![@@@b5e102fd-8b65-454d-94b3-8efebbe63faa](高中习题/课堂同步/随堂练习习题/必修二/Attachments/78ad87a92b78ea28d1a86525cdf3cc3e.png)
∴，
动点$P$从点$A$出发，沿正方形的边按逆时针方向运动一周回到$A$点，
当$P \in A B$时，有$0 \leq \lambda - \mu \leq 1$且$\mu = 0$，∴$0 \leq \lambda \leq 1$，∴$0 \leq \lambda + \mu \leq 1$，
当$P \in B C$时，有$\lambda - \mu = 1$且$0 \leq \mu \leq 1$，则$\lambda = \mu + 1$，∴$1 \leq \lambda \leq 2$，∴$1 \leq \lambda + \mu \leq 3$，
当$P \in C D$时，有$0 \leq \lambda - \mu \leq 1$且，则$\mu \leq \lambda \leq \mu + 1$，∴$1 \leq \lambda \leq 2$，∴$2 \leq \lambda + \mu \leq 3$，
当$P \in A D$时，有$\lambda - \mu = 0$且$0 \leq \mu \leq 1$，则$\lambda = \mu$，∴$0 \leq \lambda \leq 1$，∴$0 \leq \lambda + \mu \leq 2$，
综上，$0 \leq \lambda + \mu \leq 3$，
选项A：取$\lambda = \mu = 1$，满足$\lambda + \mu = 2$，此时$\overrightarrow{A P} = \overrightarrow{A B} + \overrightarrow{A E} = \overrightarrow{A D}$，因此点$P$不一定是$B C$的中点，故A错误；
选项B：当点$P$取$B$点或$A D$的中点时，均满足$\lambda + \mu = 1$，此时点$P$不唯一，故B错误；
选项C：当点$P$取$C$点时，$\lambda - \mu = 1$且，解得$\lambda = 2$，$\lambda + \mu$为$3$，故C正确；
选项D：当点$P$取$B C$的中点或$D E$的中点时，均满足$\lambda + \mu = \frac{3}{2}$，此时点$P$不唯一，故D错误；
故选：ABD.
##### 【变式2】（2022下·湖北十堰·高一郧阳中学校考阶段练习）某公园有三个警卫室*A*､*B*､*C*，互相之间均有直道相连，$A B = 2$千米，$A C = 2 \sqrt{3}$千米，千米，保安甲沿*CB*从警卫室*C*出发前往警卫室*B*，同时保安乙沿*BA*从警卫室*B*出发前往警卫室*A*，甲的速度为2千米/小时，乙的速度为1千米/小时.
![@@@f3aae25a-1fa8-4a8a-8274-076420d8b664](高中习题/课堂同步/随堂练习习题/必修二/Attachments/72eb1e91e50854fa210df8696b038f1c.png)
(1)保安甲从*C*出发1.5小时后达点*D*，若$\overrightarrow{A D} = x \overrightarrow{A B} + y \overrightarrow{A C}$，求实数*x*､*y*的值；
(2)若甲乙两人通过对讲机联系，对讲机在公园内的最大通话距离不超过2千米，试问有多长时间两人不能通话？
<span class="fake-tag">答案</span>(1)$x = \frac{3}{4} , y = \frac{1}{4}$
(2)两人约有$\frac{6}{7}$小时不能通话
<span class="fake-tag">详解</span>（1）因为$A B^{2} + A C^{2} = B C^{2}$，所以$A B \bot A C$，
因此建立如图所示的平面直角坐标系，
$A ( 0 , 0 ) , B ( 2 , 0 ) , C ( 0 , 2 \sqrt{3} )$，
设保安甲从*C*出发$t$小时后达点*D*，所以有$\overrightarrow{C D} = \frac{2 t}{4} \overrightarrow{C B} \Rightarrow \overrightarrow{C D} = \frac{t}{2} \overrightarrow{C B}$，
设$D ( x_{1} , y_{1} )$，由$\overrightarrow{C D} = \frac{t}{2} \overrightarrow{C B} \Rightarrow ( x_{1} , y_{1} - 2 \sqrt{3} ) = \frac{t}{2} ( 2 , - 2 \sqrt{3} ) \Rightarrow x_{1} = t , y_{1} = 2 \sqrt{3} - \sqrt{3} t$，
即$D ( t , 2 \sqrt{3} - \sqrt{3} t )$，当$t = 1 . 5$时，，
由$\overrightarrow{A D} = x \overrightarrow{A B} + y \overrightarrow{A C} \Rightarrow ( \frac{3}{2} , \frac{\sqrt{3}}{2} ) = x ( 2 , 0 ) + y ( 0 , 2 \sqrt{3} ) = ( 2 x , 2 \sqrt{3} y )$
$\Rightarrow \begin{cases}\frac{3}{2} = 2 x \\ \frac{\sqrt{3}}{2} = 2 \sqrt{3} y\end{cases} \Rightarrow x = \frac{3}{4} , y = \frac{1}{4}$；
![@@@fb443c74-955f-46ca-87f5-58d59a20409f](高中习题/课堂同步/随堂练习习题/必修二/Attachments/08720dfb33ccbf783484d2ef32e818fa.png)
（2）设保安乙从*B*出发$t$小时后达点*E*，所以点*E*的坐标为$( 2 - t , 0 )$，
于是有$\overrightarrow{D E} = ( 2 - 2 t , \sqrt{3} t - 2 \sqrt{3} )$，
因为对讲机在公园内的最大通话距离超过2千米，两人不能通话，
所以有$\left| \overrightarrow{D E} \right| > 2$，所以$\sqrt{( 2 - 2 t )^{2} + ( \sqrt{3} t - 2 \sqrt{3} )^{2}} > 2$
解之：$t > 2$或$t < \frac{6}{7}$，又$0 \leq t \leq 2$
所以两人约有$\frac{6}{7}$小时不能通话.
