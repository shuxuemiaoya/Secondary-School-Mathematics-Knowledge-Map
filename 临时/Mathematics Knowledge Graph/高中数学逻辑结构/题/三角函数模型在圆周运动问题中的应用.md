##### 题型03三角函数模型在圆周运动问题中的应用
##### 【典例1】（24-25高一上·全国·单元测试）如图，一个大风车的半径为$6 m , 1 2 \text{min}$旋转一周，它的最低点$P_{0}$离地面2m，风车翼片的一个端点$P$从$P_{0}$开始按逆时针方向旋转，则点$P$离地面距离$h ( m )$与时间$t \left( \text{min} \right)$之间的函数关系式是（ ）
![@@@a2cd0189-0741-4247-b0bc-a0662120a6fa](高中习题/课堂同步/随堂练习习题/必修一/Attachments/92f32eefda092dd777b344353df6a962.png)
$\quad$A．$h ( t ) = - 6 \text{sin} \frac{\pi}{6} t + 6$ 
$\quad$B．$h ( t ) = - 6 \text{cos} \frac{\pi}{6} t + 6$
$\quad$C．$h ( t ) = - 6 \text{sin} \frac{\pi}{6} t + 8$ 
$\quad$D．$h ( t ) = - 6 \text{cos} \frac{\pi}{6} t + 8$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用待定系数法设出函数解析式后，由题意可得函数周期、最大最小值等，即可计算出函数中相应系数，即可得解.
<span class="fake-tag">详解</span>根据题意可设$h ( t ) = A \text{cos} \omega t + B$，则$A < 0 , B > 0$．旋转一周，
$\therefore \frac{2 \pi}{\omega} = 1 2 , \therefore \omega = \frac{\pi}{6}$．
$\because$最大值与最小值分别为14，2，
$\therefore \begin{cases}- A + B = 1 4 \\ A + B = 2\end{cases}$，解得$A = - 6 , B = 8$．
$\therefore h ( t ) = - 6 \text{cos} \frac{\pi}{6} t + 8$．
故选：D．
##### 【典例2】（23-24高一下·广东佛山·期中）“广佛之眼”摩天轮半径为$5 0 m$，成为佛山地标建筑之一，被称作天空之眼摩天轮．如图，圆心$O$距地面的高度为$6 0 m$，已知摩天轮按逆时针方向匀速转动，每$15 \text{min}$转动一圈，游客在摩天轮的舱位转到距离地面最近的位置进舱则游客进舱$10 \text{min}$时他距离地面的高度为 $m$．
![@@@fab5edcf-8879-4520-8467-92dc7ef1ba55](高中习题/课堂同步/随堂练习习题/必修一/Attachments/7e37438b1cea65a17d693c95b742ba4a.png)
<span class="fake-tag">答案</span>85
<span class="fake-tag">分析</span>设在$t \text{ min}$时，距离地面的高度为$h = A \sin ( \omega t + \varphi ) + b ( A > 0 )$，其中$- \pi < \varphi < \pi$，根据题中条件求出$\omega , \varphi$的值，可得出$h$关于$t$的函数关系式，然后将代入函数解析式，即可得解.
<span class="fake-tag">详解</span>因为摩天轮的半径为$5 0 m$，圆心$O$距地面的高度为$6 0 m$，
设在$t \text{ min}$时，距离地面的高度为$h = A \sin ( \omega t + \varphi ) + b ( A > 0 )$，其中$- \pi < \varphi < \pi$，
则$\begin{cases}A + b = 1 1 0 \\ b = 6 0\end{cases}$，可得$\begin{cases}A = 5 0 \\ b = 6 0\end{cases}$，则$h = 6 0 + 5 0 \sin ( \omega t + \varphi )$，
由摩天轮按逆时针方向匀速转动，每$15 \text{min}$转动一圈，可得$\frac{2 \pi}{\omega} = 1 5$，所以$\omega = \frac{2 \pi}{15}$，
即$h = 6 0 + 5 0 \sin \left( \frac{2 \pi}{15} t + \varphi \right)$，
当时，可得$6 0 + 5 0 \sin \varphi = 1 0$，即$\sin \varphi = - 1$，因为$- \pi < \varphi < \pi$，解得$\varphi = - \frac{\pi}{2}$，所以$h = 6 0 + 5 0 \sin \left( \frac{2 \pi}{15} t - \frac{\pi}{2} \right) = 6 0 - 50 \cos \left( \frac{2 \pi}{15} t \right)$，
令，可得$h = 6 0 - 50 \cos \left( \frac{2 \pi}{15} \times 10 \right) = 6 0 + 2 5 = 8 5$，
所以，游客进䑪$10 \text{min}$时他距离地面的高度为$8 5 m$，
故答案为：85．
##### 【典例3】（23-24高一下·江西萍乡·期中）筒车发明于隋而盛于唐，是山地灌溉中一种古老的提水设备，距今已有1000多年的历史，它以水流作动力，取水灌田.如图，为了打造传统农耕文化，某景区的景观筒车直径12米，有24个盛水筒均匀分布，分别寓意一年12个月和24节气，筒车转一周需48秒，其最高点到水面的距离为10米，每一个盛水筒都做逆时针匀速圆周运动，盛水筒$A$（视为质点）的初始位置$P_{0}$到水面的距离为7米.
![@@@21dc2827-c7cf-4891-8e14-ca0ce01b072d](高中习题/课堂同步/随堂练习习题/必修一/Attachments/b0547832f5fa825b7278c612f9bba604.png)
(1)盛水筒$A$经过$t$秒后到水面的距离为$h$米，求筒车转动一周的过程中，$h$关于$t$的函数解析式；
(2)为了把水引到高处，在筒车中心$O$正上方距离水面8米处正中间设置一个宽4米的水平盛水槽，筒车受水流冲击转到盛水槽正上方后，把水倒入盛水槽，求盛水筒$A$转一圈的过程中，有多长时间能把水倒入盛水槽.（参考数据：$\text{sin} \frac{2 \pi}{5} \approx \frac{2 \sqrt{2}}{3}$）
<span class="fake-tag">答案</span>(1)$h = 6 \text{sin} \left( \frac{\pi}{24} t + \frac{\pi}{6} \right) + 4$，$t \in [ 0 , 4 8 ]$
(2)$\frac{24}{5}$秒
<span class="fake-tag">分析</span>（1）首先以点$O$为原点，建立平面直角坐标系，利用三角函数表示$h$；
（2）由题意转化为$h = 6 \text{sin} \left( \frac{\pi}{24} t + \frac{\pi}{6} \right) + 4 \geq 4 \sqrt{2} + 4$，转化为三角不等式问题，即可求解.
<span class="fake-tag">详解</span>（1）以简车中心$O$为原点，与水面平行的直线为$x$轴建立平面直角坐标系，
由题知，$h = 6 \text{sin} \angle A O x + 4 = 6 \text{sin} \left( \angle A O P_{0} + \angle P_{0} O x \right) + 4$，
又筒车半径为6，点$P_{0}$的纵坐标为3，则$\angle P_{0} O x = \frac{\pi}{6}$，
由题知，$\frac{\angle A O P_{0}}{t} = \frac{2 \pi}{48}$，解得$\angle A O P_{0} = \frac{\pi}{24} t$，$t \in [ 0 , 4 8 ]$，
故$h = 6 \text{sin} \left( \frac{\pi}{24} t + \frac{\pi}{6} \right) + 4$，$t \in [ 0 , 4 8 ]$；
（2）如图，作弦$C D$平行且等于盛水槽$M N$，则在$\bigtriangleup O C D$中，
![@@@65a544f5-ee09-460d-8c54-39b8f5ab596a](高中习题/课堂同步/随堂练习习题/必修一/Attachments/d9bb1391377194e8ba1cd2225634ac3e.png)$O C = 6$，$O D = 6$，$C D = 4$，则$O H = 4 \sqrt{2}$，
则$C D$距离水面的高度$4 \sqrt{2} + 4$，
盛水筒转到盛水槽$M N$的正上方（即$\overset{C D}{⏜}$之间），能把水倒入盛水槽，
即当$h = 6 \text{sin} \left( \frac{\pi}{24} t + \frac{\pi}{6} \right) + 4 \geq 4 \sqrt{2} + 4$时符合题意，
则$\text{sin} \left( \frac{\pi}{24} t + \frac{\pi}{6} \right) \geq \frac{2 \sqrt{2}}{3}$，即$\frac{2 \pi}{5} \leq \frac{\pi}{24} t + \frac{\pi}{6} \leq \frac{3 \pi}{5}$，解得$\frac{28}{5} \leq t \leq \frac{52}{5}$，
因为$\frac{52}{5} - \frac{28}{5} = \frac{24}{5}$，所以盛水筒$A$转一圈的过程中，能把水倒入盛水槽的时间为$\frac{24}{5}$秒.
##### 【变式1】（多选）（23-24高一下·湖北·期中）如图，摩天轮的半径为50米，摩天轮的中心$O$点距离地面的高度为55米，摩天轮匀速逆时针旋转，每24分钟转一圈，摩天轮上点$P$的起始位置在最高点处，下列结论正确的是（ ）
![@@@7f5193dc-f9ac-4d8b-b0d4-19ae77e7397f](高中习题/课堂同步/随堂练习习题/必修一/Attachments/ce28fc5b284563f6cde913c449527b97.png)
$\quad$A．经过12分钟，点$P$首次到达最低点
$\quad$B．第16分钟和第32分钟点$P$距离地面一样高
$\quad$C．从第28分钟至第40分钟点$P$距离地面的高度一直在降低
$\quad$D．摩天轮在旋转一周的过程中，点$P$有8分钟距离地面的高度不低于80米
<span class="fake-tag">答案</span>ABD
<span class="fake-tag">分析</span>由题意结合诱导公式可得$h ( t ) = 5 0 \cos \frac{\pi}{12} t + 5 5 , t \geq 0$，根据题意结合余弦函数性质逐项分析判断即可.
<span class="fake-tag">详解</span>设$t$为摩天轮匀速逆时针旋转的时间，单位为分钟，
则$h ( t ) = 5 0 \sin \left( \frac{\pi}{12} t + \frac{\pi}{2} \right) + 5 5 = 5 0 \cos \frac{\pi}{12} t + 5 5 , t \geq 0$.
对于A选项，由于摩天轮匀速逆时针旋转，每24分钟转一圈，
因为$t \geq 0$，则$\frac{\pi}{12} t \geq 0$，令$\frac{\pi}{12} t = \pi$，解得$t = \text{12}$，
所以经过12分钟，点*P*首次到达最低点，故A选项正确；
对于B选项，因为$h ( 1 6 ) = 5 0 \cos \frac{4}{3} \pi + 5 5 = 3 0 , h ( 3 2 ) = h ( 8 ) = 5 0 \cos \frac{2}{3} \pi + 5 5 = 3 0$，
即$h ( 1 6 ) = h ( 3 2 )$，所以第16分钟和第32分钟点*P*距离地面一样高，B选项正确；
对于C选项，由于摩天轮匀速逆时针旋转，每24分钟转一圈，
所以第28分钟至第40分钟，相当于第4分钟至第16分钟，
根据A选项可知，经过12分钟，点*P*首次到达最低点，
所以第4分钟至第12分钟，摩天轮高度降低，第12分钟至第16分钟，摩天轮高度上升，所以C选项错误；
对于D选项，由$h ( t ) = 5 0 \cos \frac{\pi}{12} t + 5 5 \geq 8 0$，则$\cos \frac{\pi}{12} t \geq \frac{1}{2}$，
其中$0 \leq t \leq 2 4$，即$0 \leq \frac{\pi}{12} t \leq 2 \pi$，
则$0 \leq \frac{\pi}{12} t \leq \frac{\pi}{3}$或$\frac{5 \pi}{3} \leq \frac{\pi}{12} t \leq 2 \pi$，解得$0 \leq t \leq 4$或$20 \leq t \leq 24$，
故摩天轮在旋转一周的过程中点*P*有$4 + 4 = 8$分钟距离地面不低于80米， D选项正确.
故选：ABD
##### 【变式2】（多选）（23-24高一下·广东肇庆·期中）如图，一个半径为4m的筒车按逆时针方向每分钟转2圈，筒车的轴心$O$距离水面的高度为2.5m.设筒车上的某个盛水筒$P$到水面的距离为$d$（单位：m）（在水面下时，$d$为负数）.若以盛水筒$P$刚浮出水面时开始计算时间，$d$与时间$t$（单位：s）之间的关系为$d = A \sin ( \omega t + \varphi ) + b$（，$\omega > 0$，$- \frac{\pi}{2} < \varphi < \frac{\pi}{2}$），则（ ）
![@@@e1fa3d23-5865-4c96-93b0-61373a939a96](高中习题/课堂同步/随堂练习习题/必修一/Attachments/7f25de0dd013c95b44ea69d7c56eeed8.png)
$\quad$A．$A = 4$ 
$\quad$B．$\omega = \frac{\pi}{30}$ 
$\quad$C．$b = 2 . 5$ 
$\quad$D．$\sin \varphi = \frac{5}{8}$
<span class="fake-tag">答案</span>AC
<span class="fake-tag">分析</span>根据实际含义分别求的值即可，再根据$t = 0 , d = 0$可求得$\sin \varphi$，进而判断各个选项即可.
<span class="fake-tag">详解</span>对于A，振幅*A*即为半径，$A = 4$，A正确；
