##### 【典例1】（2019下·湖北武汉·高一校联考期中）已知△*ABC*的面积为$S$, ∠*BAC=*$2 \alpha$, *AD*是△*ABC*的角平分线, 则*AD*长度的最大值为（ ）

$\quad$B．$\sqrt{\frac{S}{\sin \alpha}}$ 
$\quad$C．$\sqrt{S \cdot \tan \alpha}$ 
$\quad$D．$\sqrt{\frac{S}{\tan \alpha}}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">详解</span>$\bigtriangleup A B C$中，∠*BAC=*$2 \alpha$, *AD*是角平分线得
$S_{\bigtriangleup A B D} = \frac{1}{2} A B \cdot A D \sin \alpha$，$S_{\bigtriangleup A C D} = \frac{1}{2} A C \cdot A D \sin \alpha$，$S_{\bigtriangleup A B C} = \frac{1}{2} A B \cdot A C \sin 2 \alpha$
而$S_{\bigtriangleup A B C} = S_{\bigtriangleup A B D} + S_{\bigtriangleup A C D}$
因此$\frac{1}{2} A B \cdot A C \sin 2 \alpha = \frac{1}{2} A B \cdot A D \sin \alpha + \frac{1}{2} A C \cdot A D \sin \alpha$
得$A D = \frac{2 A B \cdot A C \cdot \sin \alpha \cdot \cos \alpha}{( A B + A C ) \sin \alpha} \leq \frac{2 A B \cdot A C \cdot \sin \alpha \cdot \cos \alpha}{2 \sqrt{A B \cdot A C} \sin \alpha} = \sqrt{A B \cdot A C} \cos \alpha$
而$A B \cdot A C = \frac{2 S}{\sin 2 \alpha}$，
所以$A {D \sqrt{\frac{2 S}{\sin 2 \alpha}} \cos \alpha \sqrt{\frac{2 S}{2 \sin \alpha \cdot \cos \alpha} \cdot \cos^{2} \alpha} = \sqrt{\frac{S}{\tan \alpha}}}_{\max}$
故选D项.

##### 【典例3】（2023下·江苏盐城·高一盐城市第一中学校联考期中）已知△$A B C$的内角所对的边分别为$a , b , c$，且$\frac{2 ( a - b )}{c} = \frac{2 \sin C - \sin B}{\sin A + \sin B}$．

##### 【典例4】（2022下·河北保定·高一校联考阶段练习）记$\bigtriangleup A B C$的内角$A$，$B$，$C$的对边分别为$a$，$b$，$c$，且$b \cos C + c \cos B = 2 a \cos A$.
(1)求$A$的大小；
(2)若$B C$边上的高为$\frac{\sqrt{3}}{2}$，且$A$的角平分线交$B C$于点$D$，求$A D$的最小值.
<span class="fake-tag">答案</span>(1)$A = \frac{\pi}{3}$
(2)$\frac{\sqrt{3}}{2}$
<span class="fake-tag">详解</span>（1）由正弦定理得$\sin B \cos C + \sin C \cos B = 2 \sin A \cos A$，得$\sin ( B + C ) = \sin A = 2 \sin A \cos A$，
因为$A \in ( 0 , \pi )$，所以$\cos A = \frac{1}{2}$，即$A = \frac{\pi}{3}$.
（2）因为$S_{\bigtriangleup A B C} = \frac{1}{2} b c \sin A = \frac{1}{2} \times \frac{\sqrt{3}}{2} a$，所以$b c = a$.
由余弦定理得$a^{2} = b^{2} + c^{2} - b c$，得$b^{2} c^{2} = b^{2} + c^{2} - b c \geq b c$（当且仅当$b = c = 1$时，等号成立），即$b c \geq 1$.
因为$S_{\bigtriangleup A B C} = \frac{1}{2} b c \sin A = \frac{1}{2} b \cdot A D \cdot \sin \frac{\pi}{6} + \frac{1}{2} c \cdot A D \cdot \sin \frac{\pi}{6}$，所以$A D = \frac{\sqrt{3} b c}{b + c}$.
因为$b^{2} c^{2} + 3 b c = ( b + c )^{2}$，所以$A D^{2} = \frac{3 b^{2} c^{2}}{b^{2} c^{2} + 3 b c} = \frac{3}{1 + \frac{3}{b c}}$.
因为函数$f ( x ) = \frac{3}{1 + \frac{3}{x}}$在$\left. 1 , + \infty )$上单调递增，所以$f ( x ) \geq f ( 1 ) = \frac{3}{4}$，
所以$A D^{2} \geq \frac{3}{4}$，即$A D \geq \frac{\sqrt{3}}{2}$.故$A D$的最小值为$\frac{\sqrt{3}}{2}$.
