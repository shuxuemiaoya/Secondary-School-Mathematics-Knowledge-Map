##### 题型02 给值(式)求值问题
##### 【典例1】（23-24高一下·江西南昌·阶段练习）若$\text{sin} \left( \alpha - \frac{\pi}{6} \right) = \frac{1}{3}$，则$\text{sin} \left( \alpha + \frac{5 \pi}{6} \right) =$（ ）
$\quad$A．$\frac{\sqrt{2}}{3}$ 
$\quad$B．$\frac{1}{3}$ 
$\quad$C．$- \frac{\sqrt{2}}{3}$ 
$\quad$D．$- \frac{1}{3}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用诱导公式直接求解即可.
<span class="fake-tag">详解</span>因为$\text{sin} \left( \alpha - \frac{\pi}{6} \right) = \frac{1}{3}$，
所以$\text{sin} \left( \alpha + \frac{5 \pi}{6} \right) = \text{sin} \left\lbrack \pi + \left( \alpha - \frac{\pi}{6} \right) \right\rbrack = - \text{sin} \left( \alpha - \frac{\pi}{6} \right) = - \frac{1}{3}$.
故选：D.
##### 【典例2】（24-25高一上·全国·课前预习）已知$\sin \left( \theta - \frac{\pi}{3} \right) = - \frac{1}{3}$，且$\theta \in \left( 0 , \frac{\pi}{2} \right)$，则$\cos \left( \frac{2 \pi}{3} + \theta \right) =$ ．
<span class="fake-tag">答案</span>$- \frac{2 \sqrt{2}}{3}$/$- \frac{2}{3} \sqrt{2}$
<span class="fake-tag">分析</span>根据已知角与所求角之间的关系，利用诱导公式与同角三角函数关系求值即可.
<span class="fake-tag">详解</span>$\cos \left( \frac{2 \pi}{3} + \theta \right) = \cos \left\lbrack \left( \theta - \frac{\pi}{3} \right) + \pi \right\rbrack = - \cos \left( \theta - \frac{\pi}{3} \right)$.
$\because \theta \in \left( 0 , \frac{\pi}{2} \right)$，$\therefore \theta - \frac{\pi}{3} \in \left( - \frac{\pi}{3} , \frac{\pi}{6} \right)$，
$\therefore \cos \left( \theta - \frac{\pi}{3} \right) > 0$，则，
$\therefore \cos \left( \frac{2 \pi}{3} + \theta \right) = - \frac{2 \sqrt{2}}{3}$．
故答案为：$- \frac{2 \sqrt{2}}{3}$.
##### 【典例3】（24-25高一上·全国·课堂例题）已知，且$\alpha$是第三象限角，求$\sin \left( \frac{7 \pi}{6} + \alpha \right)$的值．
<span class="fake-tag">答案</span>$\frac{2 \sqrt{2}}{3}$
<span class="fake-tag">分析</span>根据$\alpha$是第三象限角可求得$\frac{\pi}{3} - \alpha$所在象限，再由诱导公式计算可得结果.
<span class="fake-tag">详解</span>因为$\alpha$是第三象限角，所以$- \alpha$是第二象限角，则$2 k \pi + \frac{\pi}{2} + \frac{\pi}{3} < \frac{\pi}{3} - \alpha < 2 k \pi + \pi + \frac{\pi}{3} , k \in Z$，
又$\sin \left( \frac{\pi}{3} - \alpha \right) = \frac{1}{3}$，所以$\frac{\pi}{3} - \alpha$是第二象限角，
可得$\cos \left( \frac{\pi}{3} - \alpha \right) = - \frac{2 \sqrt{2}}{3}$，
所以$\sin \left( \frac{7 \pi}{6} + \alpha \right) = \sin \left( \pi + \frac{\pi}{6} + \alpha \right)$
$= - \sin \left( \frac{\pi}{6} + \alpha \right) = - \cos \left( \frac{\pi}{2} - \left( \frac{\pi}{6} + \alpha \right) \right)$= - \cos \left( \frac{\pi}{3} - \alpha \right) = \frac{2 \sqrt{2}}{3}$．
