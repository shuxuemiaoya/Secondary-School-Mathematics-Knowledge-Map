### 2.等面积法：$AD = \frac{2bc\cos\frac{A}{2}}{b+c}$
#### 推导过程
由 $S_{\triangle ABD} + S_{\triangle ACD} = S_{\triangle ABC}$，利用三角形面积公式 $S = \frac12 ab\sin C$：
$\frac12 c \cdot AD \cdot \sin\frac{A}{2} + \frac12 b \cdot AD \cdot \sin\frac{A}{2} = \frac12 b c \sin A$
提取公因式，两边乘以 2：
$AD \sin\frac{A}{2} (b + c) = b c \sin A$
所以
$AD = \frac{bc \sin A}{(b+c)\sin\frac{A}{2}}$
利用倍角公式 $\sin A = 2\sin\frac{A}{2}\cos\frac{A}{2}$，约去 $\sin\frac{A}{2}$（$\frac{A}{2}\neq 0$），得：
$\boxed{AD = \frac{2bc\cos\frac{A}{2}}{b+c}}$

##### 典例3 在△ABC中，内角A，B，C所对的边分别为a，b，c，且asinB=bsin  $\left(A\neq \frac{\pi}{3}\right)$
(1)求角  $A$  的大小；
(2)(一题多解)若  $AB = 3$  ，  $AC = 1$  ，  $\angle BAC$  的平分线交  $BC$  于点  $D$  ，求  $AD$  的长.
解：(1)因为asin  $B = b\sin \left(A + \frac{\pi}{3}\right)$  由正弦定理得sinAsin  $B = \sin B\sin \left(A + \frac{\pi}{3}\right)$  因为sin  $B = 0$  ，所以  $\sin A = \sin \left(A + \frac{\pi}{3}\right)$  所以  $\sin A = \frac{1}{2}\sin A + \frac{\sqrt{3}}{2}\cos A,$  即  $\frac{1}{2}\sin A = \frac{\sqrt{3}}{2}\cos A$  ，所以tan  $A = \sqrt{3}$  因为  $A\in (0,\pi)$  ，所以  $A = \frac{\pi}{3}$
(2)法一：因为  $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ADC},$  所以  $\frac{1}{2} AB\cdot AC\cdot \sin \angle BAC = \frac{1}{2} AB\cdot AD\cdot \sin \angle BAD + \frac{1}{2} AD\cdot AC\cdot \sin \angle DAC,$  所以  $\frac{1}{2}\times 3\times 1\times \sin \frac{\pi}{3} = \frac{1}{2}\times 3\times AD\times \sin \frac{\pi}{6} +\frac{1}{2}\times AD\times 1\times \sin \frac{\pi}{6}$  所以  $AD = \frac{3\sqrt{3}}{4}$  

法二：在△ABC中，由余弦定理得  $BC^{2} = AB^{2} + AC^{2} - 2AB\cdot AC\cdot \cos \angle BAC = 3^{2} + 1^{2}-$ $2\times 3\times 1\times \cos \frac{\pi}{3} = 7$  ，所以  $BC = \sqrt{7}$  在△ABD中，由正弦定理得  $\frac{BD}{\sin\angle BAD} = \frac{AB}{\sin\angle ADB},$  在△ADC中，由正弦定理得  $\frac{DC}{\sin\angle DAC} = \frac{AC}{\sin\angle ADC}$  因为  $\sin \angle BAD = \sin \angle DAC$  ，  $\sin \angle ADB = \sin \angle ADC$
所以  $\frac{B D}{D C} = \frac{A B}{A C} = \frac{3}{1}$  所以  $D C = \frac{\sqrt{7}}{4}$ 在△ADC中，由余弦定理得  $D C^{2} = A D^{2} + A C^{2} - 2A D\cdot A C\cdot \cos \angle D A C$  ，设  $A D = x$  ，则  $\frac{7}{16} = x^{2}+$ $1 - 2x\cdot \frac{\sqrt{3}}{2}$  即  $x^{2} - \sqrt{3} x + \frac{9}{16} = 0$  ，解得  $x = \frac{3\sqrt{3}}{4}$  或  $\frac{\sqrt{3}}{4}$ 在△ABC中，由余弦定理得  $\cos C = \frac{1 + 7 - 9}{2\sqrt{7}} = - \frac{1}{2\sqrt{7}} < 0$  ，所以  $C$  是钝角，则在△ADC中，  $A D > A C$  ，所以  $A D = \frac{3\sqrt{3}}{4}$ 

法三：在△ABD中，由正弦定理得  $\frac{B D}{\sin\angle B A D} = \frac{A B}{\sin\angle A D B}$  ，在△ADC中，由正弦定理得  $\frac{D C}{\sin\angle D A C} = \frac{A C}{\sin\angle A D C}$ 因为  $\sin \angle B A D = \sin \angle D A C$  ，  $\sin \angle A D B = \sin \angle A D C$  ，所以  $\frac{B D}{D C} = \frac{A B}{A C} = \frac{3}{1}$  所以  $\frac{A D}{D C} = \frac{A B}{A C} = \frac{3}{1}$  所以  $\overrightarrow{A D} = \overrightarrow{A B} +\overrightarrow{B D} = \overrightarrow{A B} +\frac{3}{4}\overrightarrow{B C} = \overrightarrow{A B} +\frac{3}{4} (\overrightarrow{A C} - \overrightarrow{A B}) = \frac{1}{4}\overrightarrow{A B} +\frac{3}{4}\overrightarrow{A C}$  ，所以  $|\overrightarrow{A D} |^{2} = \left(\frac{1}{4}\overrightarrow{A B} +\frac{3}{4}\overrightarrow{A C}\right)^{2} = \frac{1}{16} |\overrightarrow{A B} |^{2} + \frac{9}{16} |\overrightarrow{A C} |^{2} + \frac{3}{8}\overrightarrow{A B}\cdot \overrightarrow{A C} = \frac{1}{16}\times 9 + \frac{9}{16}$ $\times 1 + \frac{3}{8}\times 3\times 1\times \frac{1}{2} = \frac{27}{16}$  所以  $A D = \frac{3\sqrt{3}}{4}$
