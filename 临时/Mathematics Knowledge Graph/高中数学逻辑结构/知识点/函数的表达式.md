# 类型I：求函数的定义域
##### 【例1】函数  $f(x) = \sqrt{2^x - 1} +\frac{1}{x - 2} +\ln (3 - x)$  的定义域为

【解析】由  $\left\{ \begin{array}{l}2^{x} - 1\geq 0\\ x - 2\neq 0\\ 3 - x > 0 \end{array} \right.$  解得：  $0\leq x< 3$  且  $x\neq 2$  ，所以  $f(x)$  的定义域为  $[0,2)\cup (2,3)$ 答案：  $[0,2)\cup (2,3)$
【反思】函数的定义域一定要写成区间或集合的形式
##### 【变式】若  $f(2x + 1)$  的定义域为  $[0,3]$  ，则函数  $y = f(x - 1)$  的定义域为

【解析】定义域指的是自变量  $x$  的取值集合，  $f(2x + 1)$  的定义域为  $[0,3]\Rightarrow$  在  $f(2x + 1)$  中，  $0\leq x\leq 3$  所以  $1\leq 2x + 1\leq 7$  ，即  $f(2x + 1)$  的括号整体的范围是  $[1,7]$  ，抽象函数定义域遵循括号范围恒不变原则，所以在  $y = f(x - 1)$  中，  $1\leq x - 1\leq 7$  ，解得：  $2\leq x\leq 8$  ，故  $y = f(x - 1)$  的定义域为  $[2,8]$ 答案：  $[2,8]$

【答案】[2,8]
【总结】给出解析式求定义域，根据解析式有意义建立不等式求  $x$  的范围即可；抽象函数求定义域，抓住两点： $①$  定义域永远指自变量  $x$  的取值集合，  $②$  “  $f(\dots)$  ”的括号范围恒不变.

##### 【例2】已知  $f(\sqrt{x} +1) = x - 3\sqrt{x}$  ，则  $f(x) =$

【解析】欲求  $f(x)$  ，可先将  $f(\sqrt{x} +1)$  指导里的整体换元成  $t$  ，求出  $f(t)$  令  $t = \sqrt{x} +1(t\geq 1)$  ，则  $x = (t - 1)^2$  ，所以  $f(t) = (t - 1)^2 - 3(t - 1) = t^2 - 5t + 4(t\geq 1)$  ，故  $f(x) = x^{2} - 5x + 4(x\geq 1)$  答案：  $x^{2} - 5x + 4(x\geq 1)$
【反思】已知函数  $y = f(g(x))$  的解析式求  $f(x)$  的解析式的流程：  $①$  令  $t = g(x)$  ，则  $f(g(x))$  可化为  $f(t)$  ，  $②$  由 $t = g(x)$  反解出  $x$  ，用  $t$  表示，代入所给函数  $y = f(g(x))$  的右侧，从而求得  $f(t)$  ；  $(3)$  由  $t = g(x)$  研究  $t$  的取值范围，得到  $f(t)$  的定义域；  $(\widehat{\Delta})$  将  $f(t)$  的自变量  $t$  换回成  $x$  ，得到  $f(x)$
##### 【例3】已知  $f(x)$  是一次函数，且  $f(f(x)) = 4x + 3$  ，则  $f(x) =$

【解析】已知了函数类型，可用待定系数法求解析式，由题意，可设  $f(x) = ax + b(a\neq 0)$  则  $f(f(x)) = af(x) + b = a(ax + b) + b = 4x + 3$  ，所以  $a^2 x + ab + b = 4x + 3$  对比左右系数可得  $\left\{ \begin{array}{l}a^{2} = 4\\ ab + b = 3 \end{array} \right.$  解得：  $\left\{ \begin{array}{l}a = 2\\ b = 1 \end{array} \right.$  或  $\left\{ \begin{array}{l}a = - 2\\ b = - 3 \end{array} \right.$  ，所以  $f(x) = 2x + 1$  或  $f(x) = - 2x - 3$

【答案】  $2x + 1$  或  $- 2x - 3$
【反思】已知  $f(x)$  的函数类型（如一次、二次函数，指数函数等）求  $f(x)$  的解析式，可用待定系数法.
##### 【例4】已知定义在  $\mathbf{R}$  上的函数  $f(x)$  满足  $f(x) = 2f(- x) + x$  ，则  $f(x) =$

【解析】看到  $f(x)$  和  $f(- x)$  在同一式子中，想到将  $x$  换成  $- x$  ，再构造一个含  $f(x)$  和  $f(- x)$  的方程，在  $f(x) = 2f(- x) + x$  中将  $x$  换成  $- x$  可得  $f(- x) = 2f(x) - x$  ，所以  $\left\{ \begin{array}{l}f(x) = 2f(- x) + x\\ f(- x) = 2f(x) - x \end{array} \right.$ $①$  将  $②$  代入  $①$  得：  $f(x) = 2[2f(x) - x] + x$  ，整理得：  $f(x) = \frac{x}{3}$

【答案】  $\frac{x}{3}$
【反思】类似地，若给出的是  $f(x)$  与  $f\left(\frac{1}{x}\right)$  的方程，则可将  $x$  换成  $\frac{1}{x}$  得到一个新的方程.
##### 【变式】已知函数  $f(x)$  的定义域为  $\mathbf{R}$  ，  $y = f(x) + \mathbf{e}^{x}$  是偶函数，  $y = f(x) - 3\mathbf{e}^{x}$  是奇函数，则 $f(x) =$

【解析】给了两个与  $f(x)$  有关的奇偶性条件，先用奇偶性的代数定义来翻译它们，建立关于  $f(x)$  的方程，设  $g(x) = f(x) + \mathbf{e}^{x}$  ，  $h(x) = f(x) - 3\mathbf{e}^{x}$  ，则由题意，  $g(x)$  为偶函数，  $h(x)$  为奇函数，所以  $\left\{ \begin{array}{l}g(- x) = g(x)\\ h(- x) = - h(x) \end{array} \right.$  ，故  $\left\{ \begin{array}{l}f(- x) + \mathbf{e}^{- x} = f(x) + \mathbf{e}^{x}①\\ f(- x) - 3\mathbf{e}^{- x} = - f(x) + 3\mathbf{e}^{x}② \end{array} \right.$  ，要求的是  $f(x)$  ，故考虑用两式作差，消去  $f(- x)$  由  $① - ②$  可得  $4\mathbf{e}^{- x} = 2f(x) - 2\mathbf{e}^{x}$  ，所以  $f(x) = \mathbf{e}^{x} + 2\mathbf{e}^{- x}$

【答案】  $\mathrm{e}^{x} + 2\mathrm{e}^{- x}$
类型Ⅲ：一类分式函数的最值问题
##### 【例5】函数  $y = \frac{x - 1}{x^2 - x + 1} (x > 1)$  的最大值为

【解法1】像这种“一次函数”型的分式函数，通用做法是令一次函数部分为  $t$  ，再分子分母同除以  $t$  二次函数令  $t = x - 1$  ，则  $t > 0$  ，  $x = t + 1$  ，所以  $y = \frac{t}{(t + 1)^2 - (t + 1) + 1} = \frac{t}{t^2 + t + 1} = \frac{1}{t + \frac{1}{t} + 1}\leq \frac{1}{2\sqrt{t\cdot\frac{1}{t} + 1}} = \frac{1}{3},$  当且仅当  $t = \frac{1}{t}$  即  $t = 1$  时取等号，此时  $x = 2$  ，故函数  $y = \frac{x - 1}{x^2 - x + 1} (x > 1)$  的最大值为  $\frac{1}{3}$  解法2：若将解析式看成关于  $x$  的方程，则该方程能化为一元二次方程，用判别式研究  $y$  的最值，将  $y = \frac{x - 1}{x^2 - x + 1}$  变形成  $y(x^{2} - x + 1) = x - 1$  ，整理得：  $yx^{2} - (y + 1)x + y + 1 = 0$ $①$  当  $y\neq 0$  时，把  $①$  看成关于  $x$  的一元二次方程，则  $\Delta = (y + 1)^2 - 4y(y + 1)\geq 0$  ，解得：  $- 1\leq y\leq \frac{1}{3}$ $y_{\mathrm{max}}$  一定是  $\frac{1}{3}$  ？不一定，还得看  $y$  能否等于  $\frac{1}{3}$  ，可将  $y = \frac{1}{3}$  代回解析式，看能否求出满足题意的  $x$  由  $\frac{1}{3} = \frac{x - 1}{x^2 - x + 1}$  可解得：  $x = 2$  ，满足  $x > 1$  ，所以函数  $y = \frac{x - 1}{x^2 - x + 1} (x > 1)$  的最大值为  $\frac{1}{3}$  答案：  $\frac{1}{3}$
##### 【变式1】函数  $y = \frac{x^2 - 2x + 2}{x^2 - x + 1} (x > 1)$  的最小值为

【解法1】与例5相比，这里分子变成子二次函数，怎么办呢？可将分子的  $\frac{2}{3}$  凑成分母的形式，通过拆项把分子化为一次函数，从而将问题化归成例5的类型来处理，由题意，  $y = \frac{x^2 - 2x + 2}{x^2 - x + 1} = \frac{(x^2 - x + 1) - (x - 1)}{x^2 - x + 1} = 1 - \frac{x - 1}{x^2 - x + 1}$  由上一题结论可得  $y_{\min} = 1 - \frac{1}{3} = \frac{2}{3}$  解法2：将  $y = \frac{x^2 - 2x + 2}{x^2 - x + 1}$  变形成  $y(x^{2} - x + 1) = x^{2} - 2x + 2$  ，整理得：  $(y - 1)x^{2} + (2 - y)x + y - 2 = 0$  当  $y\neq 1$  时，将该方程看成关于  $x$  的一元二次方程，则  $\Delta = (2 - y)^2 - 4(y - 1)(y - 2)\geq 0$  ，所以  $\frac{2}{3}\leq y\leq 2(y\neq 1)$ $y_{\min}$  一定是  $\frac{2}{3}$  ？不一定，还得看  $y = \frac{2}{3}$  能否成立，可将  $y = \frac{2}{3}$  代回解析式，看能否求出满足题意的  $x$  由  $\frac{2}{3} = \frac{x^2 - 2x + 2}{x^2 - x + 1}$  解得：  $x = 2$  ，满足  $x > 1$  ，所以函数  $y = \frac{x^2 - 2x + 2}{x^2 - x + 1} (x > 1)$  的最小值为  $\frac{2}{3}$  答案：  $\frac{2}{3}$
##### 【变式2】函数  $y = \frac{\sqrt{x^2 + 1}}{x^2 + 5}$  的最大值为

【解析】此处虽不是直接的“一次函数”，但分子的  $\sqrt{x^2 + 1}$  相比于分母可看成一次，故将其换元成  $t$  二次函数设  $t = \sqrt{x^2 + 1}$  ，则  $t\geq 1$  ，  $x^{2} = t^{2} - 1$  ，所以  $y = \frac{\sqrt{x^2 + 1}}{x^2 + 5} = \frac{t}{t^2 + 4} = \frac{1}{t + \frac{4}{t}}\leq \frac{1}{2\sqrt{t\cdot\frac{4}{t}}} = \frac{1}{4},$  当且仅当  $t = \frac{4}{t}$  即  $t = 2$  时取等号，此时  $x = \pm \sqrt{3}$  ，所以函数  $y = \frac{\sqrt{x^2 + 1}}{x^2 + 5}$  的最大值为  $\frac{1}{4}$

【答案】  $\frac{1}{4}$
