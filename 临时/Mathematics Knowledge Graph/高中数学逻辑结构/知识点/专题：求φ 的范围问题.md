## 23.3  $\varphi$  的范围
### 研究密钥
对于函数  $f(x) = \sin \omega x(\omega >0)$  经平移变换后得到 $g(x) = \sin (\omega x + \varphi) = \sin \left[\omega \left(x + \frac{\varphi}{\omega}\right)\right](\omega >0).$
$\frac{\varphi}{\omega}$  的几何意义：如右图所示，在平移变换前后，对应点横坐标的差值，  $\frac{\varphi}{\omega} = x_A - x_{A'}$  ，即  $\varphi = \omega (x_A - x_{A'})$
![](99cfea17db0cb23c25f360f5bb01eab43917da7f0766a211015946aa7ae581c6.jpg)
##### 例23.5 若函数  $f(x) = \cos (2x + \varphi) (0 < \varphi < \pi)$  在区间  $\left[-\frac{\pi}{6}, \frac{\pi}{6}\right]$  上单调递减，且在区间  $\left(0, \frac{\pi}{6}\right)$  上存在零点，则  $\varphi$  的取值范围是（ ）.
$\quad$A.  $\left(\frac{\pi}{6}, \frac{\pi}{2}\right]$
$\quad$B.  $\left[\frac{2\pi}{3}, \frac{5\pi}{6}\right)$
$\quad$C.  $\left(\frac{\pi}{2}, \frac{2\pi}{3}\right]$
$\quad$D.  $\left[\frac{\pi}{3}, \frac{\pi}{2}\right)$
分析 运用图像平移变换求解  $\varphi$  的取值范围.

<span class="fake-tag">解析</span>  $\gg$  令  $\varphi = 0$  ，其图像如图所示
若  $f(x) = \cos (2x + \varphi)(0 < \varphi < \pi)$  在区间  $\left[-\frac{\pi}{6}, \frac{\pi}{6}\right]$  上单调递减，则  $\frac{\varphi}{2} \geqslant \frac{\pi}{6}$ ，可得  $\varphi \geqslant \frac{\pi}{3}$ .
又  $f(x)$  在区间  $\left(0, \frac{\pi}{6}\right)$  上存在零点， $\frac{\pi}{4} - \frac{\pi}{6} < \frac{\varphi}{2} < \frac{\pi}{4}$ ，可得  $\frac{\pi}{6} < \varphi < \frac{\pi}{2}$ .
综上所述， $\varphi$  的取值范围为  $\left[\frac{\pi}{3}, \frac{\pi}{2}\right)$ ，故选D.

##### 变式 1 已知函数  $f(x) = \sin (\omega x + \varphi) \left(\omega > 0, |\varphi| < \frac{\pi}{2}\right)$  的最小正周期为  $\pi$ ，且  $f(x)$  是  $\left(\frac{\pi}{3}, \frac{4\pi}{5}\right)$  上的单调函数，则  $\varphi$  的取值范围是（ ）.
$\quad$A.  $\left(-\frac{\pi}{2}, - \frac{\pi}{6}\right]$
$\quad$B.  $\left(-\frac{\pi}{2}, \frac{\pi}{6}\right]$
$\quad$C.  $\left[-\frac{\pi}{6}, - \frac{\pi}{10}\right]$
$\quad$D.  $\left[-\frac{\pi}{6}, \frac{\pi}{2}\right)$

<span class="fake-tag">解析</span> 依题意得  $T = \frac{2\pi}{\omega} = \pi$  ，则  $\omega = 2, f(x) = \sin (2x + \varphi)$ ，令  $f_0(x) = \sin 2x$ ，将  $y = f_0(x)$  向右平移  $\frac{|\varphi|}{2}$  个单位，则  $\left\{ \begin{array}{l} \frac{|\varphi|}{2} \geqslant \frac{4\pi}{5} - \frac{3\pi}{4} = \frac{\pi}{20} \\ \frac{|\varphi|}{2} \leqslant \frac{\pi}{3} - \frac{\pi}{4} = \frac{\pi}{12} \end{array} \right.$ ，可得  $-\frac{\pi}{6} \leqslant \varphi \leqslant -\frac{\pi}{10}\left(\frac{\pi}{2} < \varphi < 0\right)$ . 如右图所示.
