# 双曲线的标准方程

双曲线的标准方程分为焦点在 $x$ 轴上与焦点在 $y$ 轴上两种形式，其中参数满足关系式 $c^2 = a^2 + b^2$ ($a > 0, b > 0, c > 0$)：

| 焦点位置 | 标准方程 | 焦点坐标 | 参数关系 |
| :--- | :--- | :--- | :--- |
| **焦点在 $x$ 轴** | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1 \ (a > 0, b > 0)$ | $F_1(-c, 0), F_2(c, 0)$ | $b = \sqrt{c^2 - a^2}$ |
| **焦点在 $y$ 轴** | $\dfrac{y^2}{a^2} - \dfrac{x^2}{b^2} = 1 \ (a > 0, b > 0)$ | $F_1(0, -c), F_2(0, c)$ | $b = \sqrt{c^2 - a^2}$ |
