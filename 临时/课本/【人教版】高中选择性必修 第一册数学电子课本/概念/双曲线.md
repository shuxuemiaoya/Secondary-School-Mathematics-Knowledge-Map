# 双曲线

平面内与两个定点 $F_1, F_2$ 的距离的差的绝对值等于非零常数（小于 $|F_1F_2|$）的点的轨迹叫做**双曲线**（Hyperbola）。

* **焦点**：这两个定点 $F_1, F_2$ 叫做双曲线的**焦点**（Focus）。
* **焦距**：两焦点间的距离叫做双曲线的**焦距**，通常记作 $2c$ ($c > 0$)。
* **常数定义**：设动点为 $M$，则双曲线是点集 $P = \{M \mid ||MF_1| - |MF_2|| = 2a\}$，其中 $0 < 2a < |F_1F_2| = 2c$ ($0 < a < c$)。
