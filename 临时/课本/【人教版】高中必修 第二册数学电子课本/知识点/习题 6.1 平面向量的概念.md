2. 如图，点 $O$ 是 $\square ABCD$ 的对角线的交点，且 $\overrightarrow{OA} = \boldsymbol{a}, \overrightarrow{OB} = \boldsymbol{b}, \overrightarrow{AB} = \boldsymbol{c}$ ，分别写出 $\square ABCD$ 和折线 MPQRST 中与 $\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{c}$ 相等的向量.

###### 综合运用

3. 判断下列结论是否正确（正确的在括号内打“√”，错误的打“×”），并说明理由.  
（1）若 $\boldsymbol{a}$ 与 $\boldsymbol{b}$ 都是单位向量，则 $\boldsymbol{a} = \boldsymbol{b}$ （ ）  
（2） 方向为南偏西 $60^{\circ}$ 的向量与北偏东 $60^{\circ}$ 的向量是共线向量. （ ）  
（3）直角坐标平面上的 $x$ 轴、 $y$ 轴都是向量. （ ）  
（4）若 $\boldsymbol{a}$ 与 $\boldsymbol{b}$ 是平行向量，则 $\boldsymbol{a}=\boldsymbol{b}$. （ ）  
（5） 若用有向线段表示的向量 $\overrightarrow{AM}$ 与 $\overrightarrow{AN}$ 不相等，则点 M 与 N 不重合. ( )  
（6） 海拔、温度、角度都不是向量. ( )
