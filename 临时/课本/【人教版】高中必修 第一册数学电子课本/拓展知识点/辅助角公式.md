> [!example] 例 9 求下列函数的周期，最大值和最小值：
> （1） $y = \sin x + \sqrt{3} \cos x;$
> （2） $y = 3\sin x + 4\cos x.$
>
> > [!tip]- 分析：
> > 便于求周期和最大值、最小值的三角函数式是 $y = A\sin (x + \varphi)$ ，利用和角公式将其展开，可化为 $y = a\sin x + b\cos x$ 的形式。反之，利用和（差）角公式，可将 $y = a\sin x + b\cos x$ 转化为 $y = A\sin (x + \varphi)$ 的形式，进而就可以求得其周期和最值了。
>
> > [!success]- 解：
> > （1） $y=\sin x+\sqrt{3}\cos x$
> > $= 2 \left(\frac {1}{2} \sin x + \frac {\sqrt {3}}{2} \cos x\right) ^ {\bullet}$
> > $= 2 \left(\sin x \cos \frac {\pi}{3} + \cos x \sin \frac {\pi}{3}\right) = 2 \sin \left(x + \frac {\pi}{3}\right).$
> > 因此，所求周期为 $2\pi$ ，最大值为 2，最小值为 -2.
> >
> > （2） 设 $3\sin x + 4\cos x = A\sin(x + \varphi)$ ，则
> > $3 \sin x + 4 \cos x = A \sin x \cos \varphi + A \cos x \sin \varphi .$
> > 于是 $A\cos \varphi = 3, A\sin \varphi = 4,$
> > 于是 $A^2\cos^2\varphi + A^2\sin^2\varphi = 25,$
> > 所以 $A^2 = 25.$
> >
> > 取 $A = 5$ ，则 $\cos \varphi = \frac{3}{5}$ ， $\sin \varphi = \frac{4}{5}$
> > 由 $y=5\sin(x+\varphi)$ 可知，所求周期为 $2\pi$ ，最大值为 5，最小值为 -5.


对于形如 $a\sin x + b\cos x$ （其中 $a, b$ 为常数，且不同时为0）的表达式，可以化为：

$$a\sin x + b\cos x = \sqrt{a^2 + b^2} \cdot \sin(x + \varphi)$$

其中，$\sqrt{a^2 + b^2}$ 称为**振幅**（或模长）， $\quad \sin\varphi = \frac{b}{\sqrt{a^2 + b^2}}$,$\varphi$就是我们重点要分析的**辅助角**。

---

### 2. 辅助角 $\varphi$ 的定义（坐标定义）

很多同学误以为辅助角就是“$\tan\varphi = \frac{b}{a}$”，**这是一个巨大的误区**，因为正切函数在 $(0, 2\pi)$ 内无法唯一确定角度。正确的定义必须依赖**象限**，即利用**点的坐标**来确定：

如果令点 $P(a, b)$，那么辅助角 $\varphi$ 就是**以 $x$ 轴正半轴为始边，射线 $OP$ 为终边所旋转的角度**。

由此，我们可以严格定义：
$$ \quad \sin\varphi = \frac{b}{\sqrt{a^2 + b^2}} $$

---

### 3. 深度分析：如何确定 $\varphi$ 的具体象限和数值？

这是你要求讲解的重点。确定 $\varphi$ 必须严格按照 **$a$ 和 $b$ 的符号（正负）** 来分类讨论。我们可以将 $\varphi$ 看作复数 $a + bi$ 的辐角主值。

#### 情况一：$a > 0$（最安全、最常见的情况）
当 $a > 0$ 时，$\cos\varphi > 0$，意味着 $\varphi$ 落在**第一象限**或**第四象限**（即 $(-\frac{\pi}{2}, \frac{\pi}{2})$）。
此时，可以直接使用反正切函数：
$$ \varphi = \arctan\left(\frac{b}{a}\right) $$

- 若 $b > 0$，$\varphi$ 为正值（第一象限）。
- 若 $b = 0$，$\varphi = 0$。
- 若 $b < 0$，$\varphi$ 为负值（第四象限）。

> **示例**：$y = 3\sin x - 4\cos x$。这里 $a=3>0, b=-4$，所以 $\varphi = \arctan(-\frac{4}{3})$，结果为 $y = 5\sin(x - 53.13^\circ)$。

#### 情况二：$a < 0$（最容易出错的盲区）
当 $a < 0$ 时，$\cos\varphi < 0$，意味着 $\varphi$ 落在**第二象限**或**第三象限**。此时 **$\varphi = \arctan(\frac{b}{a})$ 是错的**（因为反正切的值域只在第一/四象限）。

正确的做法是：
$$ \varphi = \arctan\left(\frac{b}{a}\right) + \pi \quad (\text{或 } \varphi = \arctan\left(\frac{b}{a}\right) - \pi) $$

通常为了保持 $\varphi$ 在 $(0, 2\pi)$ 或 $(-\pi, \pi)$ 区间内，我们取：
- 若 $b > 0$（第二象限）：$\varphi = \arctan(\frac{b}{a}) + \pi$。
- 若 $b < 0$（第三象限）：$\varphi = \arctan(\frac{b}{a}) - \pi$（这样得到一个负角，落在 $-\pi$ 到 $-\frac{\pi}{2}$ 之间）。

> **示例**：$y = -3\sin x + 4\cos x$。这里 $a=-3, b=4$，$\arctan(\frac{4}{-3}) \approx -53.13^\circ$。因为 $a<0, b>0$，所以 $\varphi = -53.13^\circ + 180^\circ = 126.87^\circ$（第二象限）。原式 $= 5\sin(x + 126.87^\circ)$。

#### 情况三：特殊情况（$a=0$ 或 $b=0$）
- 若 $a=0, b>0$：原式 $= b\sin x$，此时 $\varphi = \frac{\pi}{2}$（即 $90^\circ$）。
- 若 $a=0, b<0$：$\varphi = -\frac{\pi}{2}$。
- 若 $b=0, a>0$：$\varphi = 0$。
- 若 $b=0, a<0$：原式 $= a\sin x$，需提取负号，等价于 $\varphi = \pi$。

---

### 4. 辅助角取值的“角度大小”分析

除了象限，我们还需要分析辅助角相对于已知特殊角（如 $30^\circ, 45^\circ, 60^\circ$）的大小。

- **若 $\left|\frac{b}{a}\right| = 1$**，则 $|\varphi| = 45^\circ$（或 $\frac{\pi}{4}$）。
- **若 $\left|\frac{b}{a}\right| = \sqrt{3}$**，则 $|\varphi| = 60^\circ$（或 $\frac{\pi}{3}$）。
- **若 $\left|\frac{b}{a}\right| = \frac{\sqrt{3}}{3}$**，则 $|\varphi| = 30^\circ$（或 $\frac{\pi}{6}$）。

**深度洞察**：辅助角 $\varphi$ 的几何意义，其实是**将单位圆上的点 $(a/R, b/R)$ 旋转至 $(1, 0)$ 的逆过程**。它不改变波的形状，只改变波的“起始位置”（相位）。从图像上看，$\varphi$ 决定了正弦曲线在 $x$ 轴上的**水平平移量**（左移还是右移）。

### 5. 一个非常实用的规避陷阱的技巧（推荐）

如果你不想每次都纠结 $a$ 的正负导致角度出错，可以采用**余弦化公式**，它天然规避了 $a$ 的正负问题：

$$ a\sin x + b\cos x = \sqrt{a^2 + b^2} \cos(x - \theta) $$

其中，$\theta$ 的坐标定义为：
$$ \cos\theta = \frac{b}{\sqrt{a^2+b^2}}, \quad \sin\theta = \frac{a}{\sqrt{a^2+b^2}} $$

此时，$\theta$ 只取决于点 $(b, a)$。但在解题中，更常用的还是 $\sin(x+\varphi)$ 形式，所以掌握**象限判定**仍是根本。

### 6. 总结口诀与实战检验

**口诀**：“提斜边，定象限；$a$ 正直接 $arc tan$，$a$ 负加减 $180$ 度（或 $\pi$）。”

**实战检验**：
求 $y = -\sin x + \cos x$ 的辅助角。
- 计算 $R = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$。
- 判断 $a=-1 < 0, b=1 > 0$，点在第二象限。
- 基础锐角为 $\arctan(1/-1)$ 的绝对值，即 $45^\circ$。
- 第二象限的角为 $180^\circ - 45^\circ = 135^\circ$（即 $\frac{3\pi}{4}$）。
- 所以 $y = \sqrt{2}\sin(x + \frac{3\pi}{4})$。
- **验证**：展开 $\sin(x + 135^\circ) = \sin x \cos 135^\circ + \cos x \sin 135^\circ = -\frac{\sqrt{2}}{2}\sin x + \frac{\sqrt{2}}{2}\cos x$，乘以 $\sqrt{2}$ 正好等于 $-\sin x + \cos x$。正确！
