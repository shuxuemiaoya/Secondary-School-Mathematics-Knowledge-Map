# Question 11

<!-- question-source:start -->
11.[天津部分区2025高一期中联考]已知 $a = \left(\frac{2}{5}\right)^{0.3}, b = \left(\frac{1}{4}\right)^{0.3}, c = \left(\frac{1}{4}\right)^{-0.3}$ , 则 $a, b, c$ 的大小关系为 ( )
A. $a < c < b$ B. $a < b < c$ C. $b < c < a$ D. $b < a < c$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
11. D 【解析】 $c=\left(\frac{1}{4}\right)^{-0.3}=4^{0.3}$ ，

敲黑板：当幂指数不同时，可以先转化为相同的幂指数，再运用幂函数的单调性比较大小

幂函数 $f(x)=x^{0.3}$ 在 $(0,+\infty)$ 上单调递增，因为 $\frac{1}{4}<\frac{2}{5}<4$ ，所以 $f\left(\frac{1}{4}\right)<f\left(\frac{2}{5}\right)<$ $f(4)$ ，即 $\left(\frac{1}{4}\right)^{0.3} <   \left(\frac{2}{5}\right)^{0.3} <   4^{0.3}$ ，所以 $b< a < c$ ，故选D.

规律方法 比较幂大小的三种常用方法：
(1) 直接法: 当幂指数相同时, 可直接利用幂函数的单调性来比较.
(2) 转化法: 当幂指数不同时, 可以先转化为相同的幂指数, 再运用单调性比较大小.
(3) 中间量法: 当底数不同且幂指数也不同时, 不能运用幂函数的单调性比较大小, 可选取适当的中间值与两数分别比较, 从而达到比较大小的目的.
