# Question 6

<!-- question-source:start -->
6. (多选) 已知幂函数 $f(x)$ 的图象经过点 $\left(\frac{1}{8}, \frac{\sqrt{2}}{4}\right), P(x_1, y_1), Q(x_2, y_2) (0 < x_1 < x_2)$ 是函数图象上任意不同的两点, 则下列结论正确的有 ( ) A. $x_1 f(x_1) > x_2 f(x_2)$ B. $x_1 f(x_2) < x_2 f(x_1)$

知识的掌握,生活的积累,都是沿着螺旋线上升的。

C. $\frac{f(x_1)}{x_1} >\frac{f(x_2)}{x_2}$ D. $\frac{f(x_1)}{x_1} <  \frac{f(x_2)}{x_2}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
6. BC 【解析】设幂函数 $f(x)=x^{\alpha}$ ，则有 $\left(\frac{1}{8}\right)^{\alpha}=2^{-3\alpha}=\frac{\sqrt{2}}{4}=2^{-\frac{3}{2}}$ ，解得 $\alpha=\frac{1}{2}$ ，所以 $f(x)=\sqrt{x}(x\geqslant0)$ .
作出函数 $f(x)$ 的大致图象如图所示，由其图象知图象上的点与原点连线所在直线的倾斜程度随x的增大而减小，即 $\frac{f(x_{2})}{x_{2}}<\frac{f(x_{1})}{x_{1}}$ ，即 $x_{1}f(x_{2})<x_{2}f(x_{1})$ ，所以B,C正确.
