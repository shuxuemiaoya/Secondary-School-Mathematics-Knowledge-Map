# Question 2

<!-- question-source:start -->
2.[广东梅州2025高一月考]已知集合 $A = \{x\mid y = \sqrt{x - 2}\} ,B = \{y\mid y = x^2 +1\}$ ，则 （）A. $A\cap B = \emptyset$ B. $A\cap B = A$ C. $A\cup B = A$ D. $\complement_{\mathbb{R}}B\subseteq A$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
2.B【解析】由 $y = \sqrt{x - 2}$ 有意义，可得 $x\geqslant$ 2，即 $A = [2, + \infty)$ 由 $y = x^{2} + 1\geqslant 1$ ，可得 $B = [1, + \infty)$ 故 $A\cap B = [2, + \infty) = A$ ，故A错误，B正确； $A\cup B = [1, + \infty) = B$ ，故C错误； $\mathbb{C}_{\mathbb{R}}B = (-\infty ,1)$ 显然不是集合 $A$ 的子集，故D错误.故选B.
