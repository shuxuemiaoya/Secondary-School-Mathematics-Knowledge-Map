# Question 1

<!-- question-source:start -->
1. 已知集合 $A = \{1,2\}, B = \{4,5,6\}$ , 则从 $A$ 到 $B$ 的函数 $f(x)$ 有 ( )
A. 8个 B. 6个
C. 7个 D. 9个
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
1. D 【解析】集合 $A = \{1,2\}$ 中有两个元素，若在集合 $B$ 中都对应相同的元素，则有3种情况： $f(1) = 4, f(2) = 4; f(1) = 5, f(2) = 5; f(1) = 6, f(2) = 6.$ 若在集合 $B$ 中都对应不同的元素，则有6种情况： $f(1) = 4, f(2) = 5; f(1) = 5, f(2) = 4; f(1) = 4, f(2) = 6; f(1) = 6, f(2) = 4; f(1) = 5, f(2) = 6; f(1) = 6, f(2) = 5.$ 所以从 $A$ 到 $B$ 的函数 $f(x)$ 有9个.故选D.
