# Question 3

<!-- question-source:start -->
3.[江苏2020·12,5分]已知 $5x^{2}y^{2}+y^{4}=1(x,y\in R)$ ，则 $x^{2}+y^{2}$ 的最小值是\_\_\_\_.
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
3.【解】(1)由 a=16，得 $16x|x|\leqslant|x^{3}+1|+|x^{3}-1|+8|x|$ .
当 $x \leqslant 0$ 时， $16x|x| \leqslant 0, |x^{3}+1| + |x^{3}-1| + 8|x| \geqslant |x^{3}+1| + |x^{3}-1| \geqslant |x^{3}+1-x^{3}+1|=2$ （当且仅当 x = 0 时等号成立），不等式成立.
当 0 < x < 1 时， $0 < x^{3} < 1$ ，则 $16x^{2} \leqslant 2 + 8x$ ，即 $8x^{2}-4x-1 \leqslant 0$ ，则 $0 < x \leqslant \frac{1+\sqrt{3}}{4}$ .
