# Question 5

<!-- question-source:start -->
5.[全国新课标Ⅰ2023·1,5分]已知集合 $M=\{-2,-1,0,1,2\}$ ， $N=\{x\mid x^{2}-x-6\geqslant0\}$ ，则 $M\cap N=$ ( )
A. $\{-2,-1,0,1\}$ B. $\{0,1,2\}$ C. $\{-2\}$ D. $\{2\}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
5. C 【解析】由 $x^{2}-x-6 \geqslant 0$ ，得 $x \leqslant -2$ 或 $x \geqslant 3$ ，则 $N = \{x \mid x \leqslant -2 \text{ 或 } x \geqslant 3\}$ . ∵ $M = \{-2, -1, 0, 1, 2\}$ , ∴ $M \cap N = \{-2\}$ ，故选 C.
