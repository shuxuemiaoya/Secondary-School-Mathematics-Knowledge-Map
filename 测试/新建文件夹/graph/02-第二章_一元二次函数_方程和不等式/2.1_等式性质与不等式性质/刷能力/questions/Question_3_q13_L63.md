# Question 3

<!-- question-source:start -->
3.[山西大同部分学校2025高一联考]若-3≤2a+b≤4,-1≤a-b≤2,则a+5b的取值范围是( )
A. $\left\{a+5b\mid-\frac{25}{3}\leqslant a+5b\leqslant8\right\}$ B. $\{a+5b\mid-13\leqslant a+5b\leqslant12\}$ C. $\{a+5b\mid-12\leqslant a+5b\leqslant11\}$ D. $\{a+5b\mid-9\leqslant a+5b\leqslant5\}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
3.C 【解析】设 $a + 5b = m(2a + b) + n(a - b)$ 其中 $m, n \in \mathbb{R}$ , 则 $a + 5b = (2m + n)a + (m - n)b$ , 所以 $\left\{ \begin{array}{l} 2m + n = 1, \\ m - n = 5, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} m = 2, \\ n = -3, \end{array} \right.$ 所以 $a + 5b = 2(2a + b) - 3(a - b)$ . 故选C.
