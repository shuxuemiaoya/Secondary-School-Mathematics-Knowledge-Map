# Question 4

<!-- question-source:start -->
4. 希腊数学家泰特托斯（Theaetetus，公元前417—公元前369年）详细地讨论了无理数的理论，他通过如图来构造无理数 $\sqrt{2}, \sqrt{3}, \sqrt{5}, \cdots$ ，则 $\sin \angle BAD =$ （ ）A. $\frac{2\sqrt{6} + 3\sqrt{3}}{6}$ B. $\frac{2\sqrt{6} - 3\sqrt{3}}{6}$ C. $\frac{2\sqrt{3} + \sqrt{6}}{6}$ D. $\frac{2\sqrt{3} - \sqrt{6}}{6}$

![](../../../../images/questions/part-002/707008e76456dd25e75df6d36843f26eda10e52c62157c0e169b5040844b51c1.jpg)
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
4. D 【解析】 $y = \sin^{2}\left(x + \frac{\pi}{6}\right) = \frac{1 - \cos\left(2x + \frac{\pi}{3}\right)}{2} = -\frac{1}{2}\cos\left(2x + \frac{\pi}{3}\right) + \frac{1}{2},$ 令 $2x + \frac{\pi}{3} = k\pi (k \in \mathbb{Z})$ ，得 $x = \frac{k\pi}{2} - \frac{\pi}{6} (k \in \mathbb{Z})$ ，
所以函数 $y=\sin^{2}\left(x+\frac{\pi}{6}\right)$ 图象的对称轴为直线 $x = \frac{k\pi}{2} -\frac{\pi}{6} (k\in \mathbf{Z})$ 函数 $y = \sin 2x + a\cos 2x = \sqrt{1 + a^2}\sin (2x+$ $\theta)$ ，其中 $\sin \theta = \frac{a}{\sqrt{1 + a^2}},\cos \theta = \frac{1}{\sqrt{1 + a^2}}$ 则 $\tan \theta = a$ 令 $2x + \theta = n\pi +\frac{\pi}{2} (n\in \mathbf{Z})$ ，得 $x = \frac{n}{2}\pi +$ $\frac{\pi}{4} -\frac{\theta}{2} (n\in \mathbf{Z})$ 所以函数 $y = \sin 2x + a\cos 2x$ 图象的对称轴为直线 $x = \frac{n}{2}\pi +\frac{\pi}{4} -\frac{\theta}{2} (n\in \mathbf{Z})$ 因为两函数图象的对称轴相同，所以 $\frac{\pi}{4} -\frac{\theta}{2} = -\frac{\pi}{6} +\frac{s\pi}{2},s\in \mathbf{Z},$ 解得 $\theta = \frac{5\pi}{6}-$ $s\pi ,s\in \mathbf{Z},$ 所以 $a = \tan \theta = -\frac{\sqrt{3}}{3} .$ 故选D.
