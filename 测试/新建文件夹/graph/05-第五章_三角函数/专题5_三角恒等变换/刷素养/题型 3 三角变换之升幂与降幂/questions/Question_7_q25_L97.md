# Question 7

<!-- question-source:start -->
7.[江苏天一中学等四校2025联考]若 $\cos 2\alpha = \frac{3}{5}$ , 则 $\sin^4\alpha + \cos^4\alpha =$ ( )
A. $-\frac{17}{25}$ B. $\frac{17}{25}$ C. $-\frac{8}{25}$ D. $\frac{8}{25}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
7.B【解析】因为 $\cos 2\alpha = \frac{3}{5}$ 所以 $\cos^2\alpha = \frac{1 + \cos 2\alpha}{2} = \frac{1}{2}\left(1 + \frac{3}{5}\right) = \frac{4}{5},$ $\sin^2\alpha = \frac{1 - \cos 2\alpha}{2} = \frac{1}{2}\left(1 - \frac{3}{5}\right) = \frac{1}{5},$ 所以 $\sin^4\alpha +\cos^4\alpha = \left(\frac{1}{5}\right)^2 +\left(\frac{4}{5}\right)^2 = \frac{17}{25}.$ 故选B.
