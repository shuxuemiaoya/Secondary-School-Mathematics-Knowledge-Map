# Question 8

<!-- question-source:start -->
8.[天津2024·4,5分]下列函数是偶函数的为
( )
A. $y=\frac{e^{x}-x^{2}}{e^{x}+x^{2}}$ B. $y=\frac{\cos x-x^{2}}{x^{2}+1}$ C. $y=\frac{e^{x}-x}{e^{x}+x}$ D. $y=\frac{\sin x-x}{x^{2}+1}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
8.B【解析】对于A,记 $f(x)=\frac{\mathrm{e}^{x}-x^{2}}{\mathrm{e}^{x}+x^{2}}$ ，定义域为R，
则 $f(-x)=\frac{\mathrm{e}^{-x}-(-x)^{2}}{\mathrm{e}^{-x}+(-x)^{2}}=\frac{1-x^{2}\mathrm{e}^{x}}{1+x^{2}\mathrm{e}^{x}}\neq f(x)$ ，则 $f(x)$ 不是偶函数，故 A 错误；
对于 B, 记 $g(x)=\frac{\cos x-x^{2}}{x^{2}+1}$ ，定义域为 R，
则 $g(-x)=\frac{\cos(-x)-(-x)^{2}}{(-x)^{2}+1}=\frac{\cos x-x^{2}}{x^{2}+1}=g(x)$ ，则 $g(x)$ 是偶函数，故 B 正确；

对于 C, 记 $h(x)=\frac{\mathrm{e}^{x}-x}{\mathrm{e}^{x}+x}$ ，定义域为 R，则 $h(-x)=\frac{\mathrm{e}^{-x}-(-x)}{\mathrm{e}^{-x}+(-x)}=\frac{1+xe^{x}}{1-xe^{x}}\neq h(x)$ ，则 $h(x)$ 不是偶函数，故 C 错误；
对于 D，记 $p(x)=\frac{\sin x-x}{x^{2}+1}$ ，定义域为 R，
则 $p(-x)=\frac{\sin(-x)-(-x)}{(-x)^{2}+1}=\frac{-\sin x+x}{x^{2}+1}=-p(x)$ 则 $p(x)$ 是奇函数，故 D 错误，故选 B.
