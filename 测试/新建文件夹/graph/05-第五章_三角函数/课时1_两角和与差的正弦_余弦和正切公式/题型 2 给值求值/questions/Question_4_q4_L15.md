# Question 4

<!-- question-source:start -->
4. 若 $\alpha, \beta$ 都是锐角，且 $\cos \alpha = \frac{\sqrt{5}}{5}, \sin (\alpha - \beta) = \frac{\sqrt{10}}{10}$ ，则 $\cos \beta =$ （ ）A. $\frac{\sqrt{2}}{2}$ B. $\frac{\sqrt{2}}{10}$ C. $-\frac{\sqrt{2}}{2}$ 或 $-\frac{\sqrt{2}}{10}$ D. $\frac{\sqrt{2}}{2}$ 或 $\frac{\sqrt{2}}{10}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
4. A 【解析】因为 $\alpha, \beta$ 都是锐角，所以 $-\frac{\pi}{2} < \alpha - \beta < \frac{\pi}{2}$ .
由题意得 $\cos(\alpha-\beta)=\sqrt{1-\left(\frac{\sqrt{10}}{10}\right)^{2}}=$ $\frac{3\sqrt{10}}{10}, \sin \alpha = \sqrt{1 - \left(\frac{\sqrt{5}}{5}\right)^{2}} = \frac{2\sqrt{5}}{5},$ →避坑：先判断角的范围再求三角函数值不易产生增根
∴ $\cos \beta = \cos [\alpha - (\alpha - \beta)] = \cos \alpha \cos (\alpha -$ 得 $\frac{k\pi}{2}-\frac{\pi}{12}<x\leqslant\frac{k\pi}{2}+\frac{\pi}{24},k\in\mathbf{Z},$ 故满足 $y=f\left(2x-\frac{\pi}{3}\right)\geqslant1$ 的实数 x 的集合为 $\left\{x\left|\frac{k\pi}{2}-\frac{\pi}{12}<x\leqslant\frac{k\pi}{2}+\frac{\pi}{24},k\in\mathbf{Z}\right.\right\}.$
