# Question 5

<!-- question-source:start -->
5.[山东聊城部分学校2025联考]已知 $0<\beta<\alpha<\frac{\pi}{2},\cos(\alpha-\beta)=\frac{3}{5},\cos\alpha\cos\beta=\frac{1}{2}$ ，则 $\frac{1}{\tan\alpha}-\frac{1}{\tan\beta}=$ ( )

A. $-\frac{1}{10}$ B. $\frac{8}{11}$ C.-4 D.-8

√ 答案 P242
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
5. D 【解析】因为 $0 < \alpha < \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} < -\alpha < 0$ 。又 $0 < \beta < \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} < \beta - \alpha < \frac{\pi}{2}$ 。
又 $\beta < \alpha$ ，所以 $-\frac{\pi}{2} < \beta - \alpha < 0$ ，所以 $\sin(\beta - \alpha) < 0$ 。
又因为 $\cos(\alpha - \beta) = \frac{3}{5}$ 所以 $\sin(\beta-\alpha)=-\sqrt{1-\cos^{2}(\beta-\alpha)}=-\frac{4}{5}$ 且 $\cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta=\frac{3}{5}$ 又 $\cos\alpha\cos\beta=\frac{1}{2}$ ，所以 $\sin\alpha\sin\beta=\frac{3}{5}-\frac{1}{2}=\frac{1}{10}$ 所以 $\frac{1}{\tan\alpha}-\frac{1}{\tan\beta}=\frac{\cos\alpha}{\sin\alpha}-\frac{\cos\beta}{\sin\beta}=$ $\frac{\cos\alpha\sin\beta-\cos\beta\sin\alpha}{\sin\alpha\sin\beta}=\frac{\sin(\beta-\alpha)}{\sin\alpha\sin\beta}=$ $\frac{-\frac{4}{5}}{\frac{1}{10}}=-8.$ 故选 D.
