# Question 12

<!-- question-source:start -->
12. 若 $\sin x + \cos x = \frac{1}{3}, x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ ，则 $\sin x - \cos x$ 的值为
A. $\pm\frac{\sqrt{17}}{3}$ B. $\frac{\sqrt{17}}{3}$ C. $-\frac{\sqrt{17}}{3}$ D. $\frac{1}{3}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
12. C 【解析】已知 $\sin x + \cos x = \frac{1}{3}, x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ ，所以 $1 + 2\sin x \cos x = \frac{1}{9}$ ，即 $\sin x \cos x = -\frac{4}{9}$ ，所以 $x \in \left(-\frac{\pi}{2}, 0\right)$ ，所以 $\sin x - \cos x < 0$ ，所以 $\sin x - \cos x = -\sqrt{(\sin x + \cos x)^2 - 4\sin x \cos x} = -\frac{\sqrt{17}}{3}$ 。故选 C.

规律方法 应用 $\sin\theta\pm\cos\theta,\sin\theta\cdot\cos\theta$ 三者的关系求解问题时主要是方程思想的运用, 对于三角函数式 $\sin\theta\pm\cos\theta,\sin\theta\cdot\cos\theta$ 之间的关系, 可以通过 $(\sin\theta\pm\cos\theta)^{2}=1\pm2\sin\theta\cdot\cos\theta$ 进行转化; 若已知 $\sin\theta\pm\cos\theta,\sin\theta\cdot\cos\theta$ 中三者之一, 利用方程思想进一步可以求得 $\sin\theta,\cos\theta$ 的值, 从而求出其余的三角函数值.
