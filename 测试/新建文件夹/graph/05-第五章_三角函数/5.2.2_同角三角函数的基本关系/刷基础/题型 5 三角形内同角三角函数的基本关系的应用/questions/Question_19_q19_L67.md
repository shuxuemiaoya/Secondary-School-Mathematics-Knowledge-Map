# Question 19

<!-- question-source:start -->
19. 已知角 $A$ 是 $\triangle ABC$ 的内角, 若 $\sin A - 2\cos A = -1$ , 则下列式子正确的是 ( )
A. $2\sin A - \cos A = 2$ B. $2\sin A + \cos A = -2$

C. $\tan A = \frac{3}{4}$ D. $\sin A\cos A = -\frac{12}{25}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
19.C 【解析】由 $\sin A - 2\cos A = -1$ ，得 $\sin A = 2\cos A - 1 > 0$ ，所以 $\cos A > \frac{1}{2}$ ，所以 $A$ 为锐角。由 $\left\{ \begin{array}{l} \sin A - 2\cos A = -1, \\ \sin^2 A + \cos^2 A = 1, \end{array} \right.$ 解得 $\sin A = \frac{3}{5}, \cos A = \frac{4}{5}$ ，所以 $2\sin A - \cos A = \frac{2}{5}, 2\sin A + \cos A = 2, \tan A = \frac{\sin A}{\cos A} = \frac{3}{4}, \sin A\cos A = \frac{12}{25}$ 。故选 C.
