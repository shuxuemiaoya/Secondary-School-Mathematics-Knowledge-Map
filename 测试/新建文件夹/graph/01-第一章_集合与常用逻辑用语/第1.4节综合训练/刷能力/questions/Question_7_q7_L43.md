# Question 7

<!-- question-source:start -->
7.[四川成都2025高一段考]有限集合S中元素的个数记作card(S)，设A,B都为有限集合，给出下列命题：
① $A \cap B = \varnothing$ 的充要条件是 card $(A \cup B) = \text{card}(A) + \text{card}(B)$ ;
② $A \subseteq B$ 的必要不充分条件可以是 card $(A) < \text{card}(B) + 1$ ;
③ $A \subsetneqq B$ 的充分不必要条件可以是 card $(A) \leqslant \text{card}(B) - 1$ ;
④A=B 的充要条件是 card $(A)=\text{card}(B)$ .
其中,是真命题的有\_\_\_\_.(填序号)
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
7. ①② 【解析】①若 $A \cap B = \emptyset$ ，则集合 $A$ 与 $B$ 无重复元素，则 $\operatorname{card}(A \cup B) = \operatorname{card}(A) + \operatorname{card}(B)$ ，即 $A \cap B = \emptyset$ 是 $\operatorname{card}(A \cup B) = \operatorname{card}(A) + \operatorname{card}(B)$ 的充分条件；若 $\operatorname{card}(A \cup B) = \operatorname{card}(A) + \operatorname{card}(B)$ ，则集合 $A$ 与 $B$ 无重复元素，则 $A \cap B = \emptyset$ ，即 $A \cap B = \emptyset$ 是 $\operatorname{card}(A \cup B) = \operatorname{card}(A) + \operatorname{card}(B)$ 的必要条件。综上所述， $A \cap B = \emptyset$ 的充要条件是 $\operatorname{card}(A \cup B) = \operatorname{card}(A) + \operatorname{card}(B)$ ，①正确。②若 $A \subseteq B$ ，即集合 $A$ 中所有元素均属于集合 $B$ ，此时 $\operatorname{card}(A) \leqslant \operatorname{card}(B)$ ，即 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ ，所以 $A \subseteq B$ 是 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ 的充分条件，即 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ 是 $A \subseteq B$ 的必要条件；若 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ ，无法判断集合 $A$ 与集合 $B$ 的关系，即 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ 不是 $A \subseteq B$ 的充分条件。综上所述， $A \subseteq B$ 的必要不充分条件可以是 $\operatorname{card}(A) < \operatorname{card}(B) + 1$ ，②正确。③若 $\operatorname{card}(A) \leqslant \operatorname{card}(B) - 1$ ，无法判断集合 $A$ 与集合 $B$ 的关系，即 $\operatorname{card}(A) \leqslant \operatorname{card}(B) - 1$ 不是 $A \subsetneq B$ 的充分条件，③错误。④若 $\operatorname{card}(A) = \operatorname{card}(B)$ ，无法判断集合 $A$ 中元素与集合 $B$ 的关系，不能说明 $A = B$ ，④错误。故选①②。
