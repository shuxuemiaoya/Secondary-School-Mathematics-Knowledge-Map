# Question 4

<!-- question-source:start -->
4.[黑龙江哈师大附中2024高一月考]已知全集为U,集合M,N满足 $M\subseteq N\subseteq U$ ,则下列运算结果一定为U的是()A. $M\cup N$ B. $(\complement_{U}N)\cup(\complement_{U}M)$ C. $M\cup(\complement_{U}N)$ D. $N\cup(\complement_{U}M)$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
4. D 【解析】由 $M \subseteq N \subseteq U$ 得当 $N \subsetneq U$ 时， $M \cup N = N \subsetneq U$ ，故选项 A 不正确； $(\complement_{U}N) \cup (\complement_{U}M) = \complement_{U}(M \cap N) = \complement_{U}M$ ，当 $M \neq \varnothing$ 巧思：运用了德·摩根定律
时， $C_{U}M \subsetneq U$ ，故选项 B 不正确；
当 $M \subsetneq N$ 时， $M \cup (\complement_{U}N) \subsetneq U$ ，故选项 C 不正确；
因为 $M \subseteq N \subseteq U$ ，所以 $N \cup (\complement_{U}M) = U$ ，故选项 D 正确.
故选 D.
