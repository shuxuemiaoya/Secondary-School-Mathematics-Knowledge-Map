# Question 9

<!-- question-source:start -->
9. 教材变式已知集合 $A = \{x \mid (x - 3)(x - a) = 0, a \in \mathbb{R}\}, B = \{x \mid (x - 4)(x - 1) = 0\}$ , 若 $A \cap B = \varnothing$ , $A \cup B = \{1, 3, 4\}$ , 则实数 $a$ 的值为 ( )
A. 1 B. -3 C. 4 D. 3
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
9. D 【解析】集合 $B=\{x \mid (x-4)(x-1)=0\}=\{1,4\}$ ，易知 $3 \in A, a \in A$ ，
∵ $A \cap B = \varnothing, \therefore a \notin B.$ ∵ $A \cup B = \{1, 3, 4\}, \therefore a = 3.$ 故选 D.
链接教材 这道题目是由教材 P14 第 5 题改编得到, 基本的解题思路是根据 $B=\{1,4\}$ ，由 $A \cap B = \varnothing$ 得出 $a \notin B$ ，再由 $A \cup B = \{1, 3, 4\}$ 即可得出 a = 3.
