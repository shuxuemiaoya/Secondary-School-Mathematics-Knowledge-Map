# Question 13

<!-- question-source:start -->
13.[全国新高考Ⅰ2022·1,5分]若集合 $M =$ $\{x|\sqrt{x} < 4\},N = \{x|3x\geqslant 1\}$ ，则 $M\cap N = (\quad)$ A. $\{x|0\leqslant x <   2\}$ B. $\left\{x\mid \frac{1}{3}\leqslant x <   2\right\}$ C. $\{x|3\leqslant x <   16\}$ D. $\left\{x\mid \frac{1}{3}\leqslant x <   16\right\}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
13. D 【解析】 $M = \{x \mid \sqrt{x} < 4\} = \{x \mid 0 \leqslant x < 16\}$ ， $N = \{x \mid 3x \geqslant 1\} = \left\{x \mid x \geqslant \frac{1}{3}\right\}$ ，所以 $M \cap N = \left\{ x \mid \frac{1}{3} \leqslant x < 16 \right\}$ . 故选 D.
