# Question 9

<!-- question-source:start -->
9.[全国乙理2023·2,5分]设全集 $U = \mathbf{R}$ ，集合 $M = \{x\mid x <   1\} ,N = \{x\mid -1 <   x <   2\}$ ，则 $\{x\mid x\geqslant 2\} =$ （）A. $\complement_U(M\cup N)$ B. $N\cup \complement_UM$ C. $\complement_U(M\cap N)$ D. $M\cup \complement_UN$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
9. A 【解析】因为 $M=\{x \mid x < 1\}$ , $N=\{x \mid -1 < x < 2\}$ ，所以 $M \cup N = \{x \mid x < 2\}$ , $\complement_{U} M = \{x \mid x \geqslant 1\}$ , $M \cap N = \{x \mid -1 < x < 1\}$ , $\complement_{U} N = \{x \mid x \leqslant -1 \text{ 或 } x \geqslant 2\}$ ，所以 $\complement_{U}(M \cup N) = \{x \mid x \geqslant 2\}$ , $N \cup \complement_{U} M = \{x \mid x > -1\}$ , $\complement_{U}(M \cap N) = \{x \mid x \leqslant -1 \text{ 或 } x \geqslant 1\}$ , $M \cup \complement_{U} N = \{x \mid x < 1 \text{ 或 } x \geqslant 2\}$ ，故选 A.
