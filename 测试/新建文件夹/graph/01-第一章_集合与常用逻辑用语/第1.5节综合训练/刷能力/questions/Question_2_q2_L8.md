2.[重庆一中2024高一期末]已知命题 $p:\forall x\in \{x\mid1<x<2\},x^{2}-3x+2>0$ ，则 $\neg p$ 是（）
A. $\exists x \in \{x \mid 1 < x < 2\}, x^{2} - 3x + 2 > 0$ B. $\exists x \in \{x \mid 1 < x < 2\}, x^{2} - 3x + 2 \leqslant 0$ C. $\exists x \in \{x \mid x \leqslant 1 \text{ 或 } x \geqslant 2\}, x^{2} - 3x + 2 > 0$ D. $\exists x \in \{x \mid x \leqslant 1 \text{ 或 } x \geqslant 2\}, x^{2} - 3x + 2 \leqslant 0$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
2. B 【解析】命题 $p: \forall x \in \{x \mid 1 < x < 2\}, x^{2} - 3x + 2 > 0$ 是全称量词命题, 其否定是存在量词命题,
所以 $\neg p:\exists x\in\{x\mid1<x<2\},x^{2}-3x+2\leqslant0.$ 故选 B.
