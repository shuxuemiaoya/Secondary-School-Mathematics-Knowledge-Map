# Question 3

<!-- question-source:start -->
3.[江西赣州2025高一月考]已知 $a, b, c \in \mathbb{R}$ , 则下列语句能成为“ $a, b, c$ 都不小于1”的否定形式的是 ( )
A. $a, b, c$ 中至少有1个大于1
B. $a, b, c$ 都小于1
C. $a, b, c$ 都不大于1
D. $a < 1$ 或 $b < 1$ 或 $c < 1$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
3. D 【解析】由 a, b, c 都不小于 1，得 $a \geqslant 1$ ， $b \geqslant 1, c \geqslant 1$ ，即 a, b, c 都大于或等于 1，所以其否定是 a, b, c 不都大于或等于 1，即 a, b, c 中至少有一个小于 1，故 a < 1 或 b < 1 或 c < 1。故选 D.
<!-- answer-source:end -->
