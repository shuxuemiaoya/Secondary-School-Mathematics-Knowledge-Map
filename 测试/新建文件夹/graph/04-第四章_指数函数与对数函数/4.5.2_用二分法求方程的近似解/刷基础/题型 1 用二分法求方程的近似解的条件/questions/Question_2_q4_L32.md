# Question 2

<!-- question-source:start -->
2.[天津一中2025高一期末]下列函数中,不能用二分法求零点的是 ( )
A. $f(x)=\ln x-3$ B. $f(x)=x^{2}+2\sqrt{2}x+2$ C. $f(x)=x+\frac{1}{x}-3$ D. $f(x)=2^{x}-3$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
2. B 【解析】对于 A, $f(x) = \ln x - 3$ 有唯一零点 $e^{3}$ ，且函数值在零点两侧异号，故可用二分法求零点；对于 B，函数 $f(x) = x^{2} + 2\sqrt{2}x + 2 = (x + \sqrt{2})^{2} \geqslant 0$ ，故函数有唯一零点 $-\sqrt{2}$ ，但函数值在零点两侧同号，故不能用二分法求零点；对于 C, $f(x) = x + \frac{1}{x} - 3$ 有两个不同零点 $\frac{3 \pm \sqrt{5}}{2}$ ，且在每个零点左右两侧函数值异号，故可用二分法求零点；对于 D, $f(x) = 2^{x} - 3$ 有唯一零点 $\log_{2}3$ ，且函数值在零点两侧异号，故可用二分法求零点。故选 B.
