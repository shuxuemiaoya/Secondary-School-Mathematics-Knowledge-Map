# Question 17

<!-- question-source:start -->
17.[全国新课标Ⅱ2024·8,5分]设函数 $f(x)=(x+a)\ln(x+b)$ .若 $f(x)\geqslant0$ ,则 $a^{2}+b^{2}$ 的最小值为
A. $\frac{1}{8}$ B. $\frac{1}{4}$ C. $\frac{1}{2}$ D.1
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
17. C 【解析】 $f(x)=(x+a)\ln(x+b)\geqslant0$ 可看作 $f_{1}(x)=x+a$ 与 $f_{2}(x)=\ln(x+b)$ 在定义域 $(-b,+\infty)$ 内同正同负，因此两函数图象与 x 轴的交点重合，如图所示.
→ 点悟：将 $f(x)=(x+a)\ln(x+b)\geqslant0$ 看成直线与曲线的相交问题，判断出在 x 轴上的交点重合

![](../../../../../images/answers/part-002/76f2db5c98c646ec5db5edf54e8772f7182778bb4484cc27ca4065009d967893.jpg)

令 $f_{1}(x) = x + a = 0, f_{2}(x) = \ln (x + b) = 0$ ，得 $-a = 1 - b$ ，即 $a - b + 1 = 0, a^{2} + b^{2} = (b - 1)^{2} + b^{2} = 2b^{2} - 2b + 1 = 2\left(b - \frac{1}{2}\right)^{2} + \frac{1}{2} \geqslant \frac{1}{2}$ ，所以 $a^{2} + b^{2}$ 的最小值为 $\frac{1}{2}$ ，故选C.
