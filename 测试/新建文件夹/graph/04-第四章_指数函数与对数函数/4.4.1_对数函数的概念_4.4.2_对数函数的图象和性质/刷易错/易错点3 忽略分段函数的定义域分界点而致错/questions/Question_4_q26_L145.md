# Question 4

<!-- question-source:start -->
4.[江苏西交大附中2025高一期中]已知 $a = \log_32, b = \left(\frac{1}{5}\right)^{\frac{1}{2}}, c = \left(\frac{1}{25}\right)^{\frac{1}{3}}$ ，则实数 $a, b, c$ 的大小关系正确的是 （）A. $a < b < c$ B. $b < c < a$ C. $c < b < a$ D. $c < a < b$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
4. C 【解析】因为 $a=\log_{3}2>\log_{3}\sqrt{3}=\frac{1}{2}$ , $b=\left(\frac{1}{5}\right)^{\frac{1}{2}}=\frac{1}{\sqrt{5}}<\frac{1}{2}$ ，所以 a>b。而 $b=\left(\frac{1}{5}\right)^{\frac{1}{2}}=\left(\frac{1}{25}\right)^{\frac{1}{4}}$ , $c=\left(\frac{1}{25}\right)^{\frac{1}{3}}$ ,
易知函数 $f(x)=\left(\frac{1}{25}\right)^x$ 在 R 上单调递减，
因为 $\frac{1}{4}<\frac{1}{3}$ ，所以 $\left(\frac{1}{25}\right)^{\frac{1}{3}}<\left(\frac{1}{25}\right)^{\frac{1}{4}}$ ，即 c<b。综上可得，c<b<a。故选 C.
