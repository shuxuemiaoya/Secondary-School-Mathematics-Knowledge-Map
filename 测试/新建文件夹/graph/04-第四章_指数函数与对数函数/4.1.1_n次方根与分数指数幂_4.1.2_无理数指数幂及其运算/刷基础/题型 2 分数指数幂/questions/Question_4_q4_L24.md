# Question 4

<!-- question-source:start -->
4.[江苏宿迁中学2025高一月考]下列等式成立的是
( )
A. $x^{\frac{1}{3}}=-\sqrt[3]{x}(x\neq0)$ B. $\sqrt[2]{(-3)^{4}}=\sqrt[3]{-3}$ C. $\sqrt{x^{3}+y^{3}}=(x+y)^{\frac{3}{2}}$ D. $\sqrt[3]{9}=\sqrt[3]{3}$
<!-- question-source:end -->

## 答案与解析

<!-- answer-source:start -->
4. D 【解析】对于 A, $x^{\frac{1}{3}} = \sqrt[3]{x} (x \neq 0)$ ，故 A 错误；
对于 B, $\sqrt[2]{(-3)^{4}} = \sqrt[2]{3^{4}} = 9 > 0, \sqrt[3]{-3} < 0,$ 故 B 错误；
对于 C, 当 x = 1, y = 1 时， $\sqrt{x^{3}+y^{3}}=\sqrt{2}$ $(x+y)^{\frac{3}{2}}=2^{\frac{3}{2}}=2\sqrt{2}$ ，故 C 错误；

$f(2 + 2x - x^2) \leqslant f(2 - x - 2x^2)$ 的解集互为补集，因此解集为 $\{x \mid x < -3$ 或 $x > 0\}$ ，不符合题意.综上所述，当 $f(2 + 2x - x^2) < f(2 - x - 2x^2)$ 时，满足解集为 $\{x \mid -3 < x < 0\}$ .
