##### 题型03根据函数的极值（点）求参数
##### 【典例1】（2023上·四川遂宁·高三四川省蓬溪中学校校考阶段练习）已知函数$f ( x ) = x ( x - m )^{2}$在$x = 1$处有极大值，则$m$的值为（ ）
$\quad$A．1 
$\quad$B．2 
$\quad$C．3 
$\quad$D．1或3
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>$\because f^{'} ( x ) = ( x - m ) ( 3 x - m )$，$\therefore f^{'} ( 1 ) = ( 1 - m ) ( 3 - m ) = 0$，
∴$m = 1$或$m = 3$，
当$m = 1$时，$f^{'} ( x ) = ( x - 1 ) ( 3 x - 1 )$，
令$f^{'} ( x ) > 0$，得$x < \frac{1}{3}$或$x > 1$；令$f^{'} ( x ) < 0$，得；
从而$f ( x )$在$\left( - \infty , \frac{1}{3} \right)$单调递增，在$\left( \frac{1}{3} , 1 \right)$单调递减，在$( 1 , + \infty )$单调递增，
所以$f ( x )$在$x = 1$处有极小值，不合题意，
当$m = 3$时，经检验，满足题意；
综上，$m = 3$.
故选：C
##### 【典例2】（2023上·陕西咸阳·高三统考期中）若函数既有极大值也有极小值，则$a$的取值范围是（ ）
$\quad$A．$\left( - \frac{1}{8} , 0 \right)$ 
$\quad$B．$\left( - \frac{1}{2} , 0 \right)$ 
$\quad$C．$\left( 0 , \frac{1}{4} \right)$ 
$\quad$D．
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>因为，定义域为$( 0 , + \infty )$，
所以$f^{'} ( x ) = \frac{a}{x} + \frac{1}{x^{2}} - \frac{2}{x^{3}} = \frac{a x^{2} + x - 2}{x^{3}} ( a \neq 0 )$，
因为函数$f ( x )$既有极大值也有极小值，
所以方程$a x^{2} + x - 2 = 0$有两个不相等的正根，设两根为$x_{1} , x_{2}$，
则有$\begin{cases}\Delta = 1 + 8 a > 0 \\ x_{1} + x_{2} = - \frac{1}{a} > 0 \\ x_{1} x_{2} = \frac{- 2}{a} > 0\end{cases}$，解得$- \frac{1}{8} < a < 0$，
所以$a$的取值范围为$\left( - \frac{1}{8} , 0 \right)$，
故选：A.
##### 【典例3】（2023上·北京·高三北京四中校考阶段练习）已知函数$f ( x ) = x^{3} + a x^{2} + b x + c$在$x_{0}$处取得极小值$- \frac{3}{2}$，其导函数为$f^{'} ( x )$．当$x$变化时，$f^{'} ( x )$变化情况如下表：
| $ x $           | $ \left( - \infty , - \frac{2}{3} \right) $ | $ - \frac{2}{3} $ | $ \left( - \frac{2}{3} , 1 \right) $ | 1 | $ ( 1 , + \infty ) $ |
|-------------------|-----------------------------------------------|---------------------|----------------------------------------|---|------------------------|
| $ f^{'} ( x ) $ | +                                             | 0                   | -                                      | 0 | +                      |
(1)写出$x_{0}$的值，并说明理由；
(2)求$a , b , c$的值．
<span class="fake-tag">答案</span>(1)$x_{0} = 1$，理由见解析；
(2)$a = - \frac{1}{2} , b = - 2 , c = 0$
<span class="fake-tag">详解</span>（1）解：$x_{0} = 1$，理由如下：
由表格中的数据可知，
当$x \in \left( - \infty , - \frac{2}{3} \right)$时，$f^{'} ( x ) > 0$，$f ( x )$单调递增；
当$x \in \left( - \frac{2}{3} , 1 \right)$时，$f^{'} ( x ) < 0$，$f ( x )$单调递减；
当$x \in ( 1 , + \infty )$时，$f^{'} ( x ) > 0$，$f ( x )$单调递增；
所以，当$x = - \frac{2}{3}$时，函数$f ( x )$取得极大值$f \left( - \frac{2}{3} \right)$，
当$x = 1$时，函数$f ( x )$取得极小值$f ( 1 ) = - \frac{3}{2}$.
所以，$x_{0} = 1$为函数$f ( x )$的极小值点.
（2）解：由题知$f^{'} ( x ) = 3 x^{2} + 2 a x + b$，
所以，结合（1）有：$\begin{cases}f^{'} ( 1 ) = 0 \\ f^{'} \left( - \frac{2}{3} \right) = 0 \\ f ( 1 ) = - \frac{3}{2}\end{cases}$，即$\begin{cases}3 + 2 a + b = 0 \\ \frac{4}{3} - \frac{4}{3} a + b = 0 \\ 1 + a + b + c = - \frac{3}{2}\end{cases}$，解得$a = - \frac{1}{2} , b = - 2 , c = 0$.
所以，$a = - \frac{1}{2} , b = - 2 , c = 0$
##### 【变式1】（2023上·陕西·高三校联考阶段练习）若函数$f ( x ) = x^{3} - a x^{2} + 4 x - 8$在处取得极小值，则$a =$（ ）
$\quad$A．4 
$\quad$B．2 
$\quad$C．-2 
$\quad$D．-4
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题意可得$f^{'} ( x ) = 3 x^{2} - 2 a x + 4$，则$f^{'} ( 2 ) = 3 \times 2^{2} - 4 a + 4 = 0$，解得$a = 4$.
当$a = 4$时，$f^{'} ( x ) = 3 x^{2} - 8 x + 4 = ( x - 2 ) ( 3 x - 2 )$，
当$x < \frac{2}{3}$或$x > 2$时，$f^{'} ( x ) > 0$，则$f ( x )$在$（ - \infty , \frac{2}{3} ）$，$（ 2 , + \infty ）$单调递增，
当时，$f^{'} ( x ) < 0$，则$f ( x )$在$( \frac{2}{3} , 2 )$单调递减，
所以，函数$f ( x ) = x^{3} - a x^{2} + 4 x - 8$在处取得极小值，此时$a = 4$.
故选：A
##### 【变式2】（2023·贵州遵义·统考三模）函数$f ( x ) = a x + \frac{\ln x}{b} + 1$在$x = 1$处取得极值0，则$a + b =$（ ）

$\quad$B．$\frac{1}{2}$ 
$\quad$C．1

##### 【变式3】（2022下·甘肃·高二校考期中）已知函数$f ( x ) = x^{3} + 3 a x^{2} + b x + a^{2}$在$x = - 1$时有极值0，求常数$a$，$b$的值.
<span class="fake-tag">答案</span>$a = 2 , b = 9$
<span class="fake-tag">详解</span>因为$f ( x ) = x^{3} + 3 a x^{2} + b x + a^{2}$，所以$f^{'} ( x ) = 3 x^{2} + 6 a x + b$，
由题意可知，$\begin{cases}f^{'} ( - 1 ) = 0 \\ f ( - 1 ) = 0\end{cases}$，即$\begin{cases}3 - 6 a + b = 0 \\ - 1 + 3 a - b + a^{2} = 0\end{cases}$，解得$\begin{cases}a = 1 \\ b = 3\end{cases}$或$\begin{cases}a = 2 \\ b = 9\end{cases}$，
当$a = 1 , b = 3$时，$f^{'} ( x ) = 3 x^{2} + 6 x + 3 = 3 ( x + 1 )^{2} \geq 0$，函数$f ( x )$为$( - \infty , + \infty )$上的递增函数，此时函数$f ( x )$无极值，不合题意；
当$a = 2 , b = 9$时，$f^{'} ( x ) = 3 x^{2} + 1 2 x + 9 = 3 ( x + 1 ) ( x + 3 )$，
令$f^{'} ( x ) > 0$，得$x < - 3$或$x > - 1$，令$f^{'} ( x ) < 0$，得$- 3 < x < - 1$，
所以函数$f ( x )$在$( - \infty , - 3 )$和$( - 1 , + \infty )$上递增，在上递减，
所以$f ( x )$在$x = - 1$时取得极大值，符合题意.
所以$a = 2 , b = 9$.
