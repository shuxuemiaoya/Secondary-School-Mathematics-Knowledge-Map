##### 【典例1】（2023上·天津南开·高三南开中学校考阶段练习）$\bigtriangleup A B C$是由3个全等的三角形与中间一个小等边三角形拼成的一个较大的等边三角形，若$\overrightarrow{A F} = 3 \overrightarrow{E F}$，$\left| \overrightarrow{A F} \right| = 3$，且$\overrightarrow{A F} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C}$，则$\lambda + \mu =$（ ）.
![@@@d8ea23d9-fde1-4262-8e76-05dc4737880d](高中习题/课堂同步/随堂练习习题/media/0467d9f51c9a0c365b1a9de72cb670cb.jpeg)
$\quad$A．$\frac{15}{19}$ 
$\quad$B．$\frac{6}{19}$ 
$\quad$C．$\frac{9}{19}$ 
$\quad$D．$\frac{4 \sqrt{19}}{19}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由题设$\overrightarrow{A F} = \overrightarrow{A B} + \overrightarrow{B F} = \overrightarrow{A B} + \frac{2}{3} \overrightarrow{B D} = \overrightarrow{A B} + \frac{2}{3} ( \overrightarrow{B C} + \overrightarrow{C D} ) = \overrightarrow{A B} + \frac{2}{3} ( \overrightarrow{B C} + \frac{2}{3} \overrightarrow{C E} )$
$= \overrightarrow{A B} + \frac{2}{3} \overrightarrow{B C} + \frac{4}{9} ( \overrightarrow{C A} + \overrightarrow{A E} ) = \overrightarrow{A B} + \frac{2}{3} \overrightarrow{B C} + \frac{4}{9} \overrightarrow{C A} + \frac{8}{27} \overrightarrow{A F}$
$= \overrightarrow{A B} + \frac{2}{3} ( \overrightarrow{A C} - \overrightarrow{A B} ) - \frac{4}{9} \overrightarrow{A C} + \frac{8}{27} \overrightarrow{A F} = \frac{1}{3} \overrightarrow{A B} + \frac{2}{9} \overrightarrow{A C} + \frac{8}{27} \overrightarrow{A F}$，
所以$\frac{19}{27} \overrightarrow{A F} = \frac{1}{3} \overrightarrow{A B} + \frac{2}{9} \overrightarrow{A C}$，即$\overrightarrow{A F} = \frac{9}{19} \overrightarrow{A B} + \frac{6}{19} \overrightarrow{A C}$，
又$\overrightarrow{A F} = \lambda \overrightarrow{A B} + \mu \overrightarrow{A C}$，故$\frac{15}{19}$.
故选：A
