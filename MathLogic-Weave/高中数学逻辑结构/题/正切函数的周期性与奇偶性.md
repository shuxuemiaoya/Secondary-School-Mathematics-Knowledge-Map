##### 【典例3】（23-24高一·上海·课堂例题）判断下列函数的奇偶性，并说明理由：
(1)$y = \tan 2 x$；
(2)$y = \left| \tan x \right|$；
(3)$y = \frac{1}{\tan x}$；
(4)$y = \frac{\tan x}{x}$．
<span class="fake-tag">答案</span>(1)奇函数，理由见解析
(2)偶函数，理由见解析
(3)奇函数，理由见解析

<span class="fake-tag">分析</span>根据函数奇偶性以及正切函数的知识求得正确答案.
<span class="fake-tag">详解</span>（1）$y = \tan 2 x$是奇函数，理由如下：
设$f ( x ) = \tan 2 x$，由$2 x \neq k \pi + \frac{\pi}{2}$解得$x \neq \frac{k \pi}{2} + \frac{\pi}{4}$，
所以$f ( x )$的定义域为$\left\{ x | x \neq \frac{k \pi}{2} + \frac{\pi}{4} , k \in Z \right\}$，
$f ( - x ) = \tan ( - 2 x ) = - \tan 2 x = - f ( x )$，
所以$f ( x )$是奇函数.
（2）$y = \left| \tan x \right|$是偶函数，理由如下：
设$h ( x ) = \left| \tan x \right|$，则$h ( x )$的定义域是$\left\{ x | x \neq k \pi + \frac{\pi}{2} , k \in Z \right\}$，
$h ( - x ) = \left| \tan ( - x ) \right| = \left| - \tan x \right| = \left| \tan x \right| = h ( x )$，
所以$h ( x )$是偶函数.
（3）$y = \frac{1}{\tan x}$是奇函数，理由如下：
设$g ( x ) = \frac{1}{\tan x}$，则定义域是$\left\{ x | x \neq \frac{k \pi}{2} , k \in Z \right\}$，
$g ( - x ) = \frac{1}{\tan ( - x )} = - \frac{1}{\tan x} = - g ( x )$，
所以是奇函数.
（4）$y = \frac{\tan x}{x}$是偶函数，理由如下：
设$m ( x ) = \frac{\tan x}{x}$，则$m ( x )$的定义域是$\left\{ x | x \neq k \pi + \frac{\pi}{2} , k \in Z \right\} \cup \left\{ x | x \neq 0 \right\}$，
$m ( - x ) = \frac{\tan ( - x )}{- x} = \frac{- \tan x}{- x} = \frac{\tan x}{x} = m ( x )$，
所以$m ( x )$是偶函数.
