##### 题型06 根据函数的最值求参数
##### 【典例1】（2023下·北京丰台·高二统考期中）已知函数$f ( x ) = x^{3} - 6 x^{2} + 9 x$．
(1)求函数$f ( x )$的单调区间；
(2)若$f ( x )$在区间$\lbrack 1 , m \rbrack$上的最小值为$0$，求$m$的取值范围.
<span class="fake-tag">答案</span>(1)单调递增区间为$( - \infty , 1 )$，$( 3 , + \infty )$，单调递减区间为$( 1 , 3 )$
(2)$m \geq 3$
<span class="fake-tag">详解</span>（1）由题可知$f^{'} ( x ) = 3 x^{2} - 1 2 x + 9$，
令$f^{'} ( x ) = 0$，即$3 x^{2} - 1 2 x + 9 = 0$，解得$x = 1$或$x = 3$，
当$x$变化时，$f^{'} ( x )$，$f ( x )$的变化情况如下表：
| $ x $       | $ ( - \infty , 1 ) $ | $ 1 $ | $ ( 1 , 3 ) $ | $ 3 $ | $ ( 3 , + \infty ) $ |
|---------------|------------------------|---------|-----------------|---------|------------------------|
|               | $ + $                | 0       | $ - $         | 0       | $ + $                |
| $ f ( x ) $ | 单调递增               | 极大值  | 单调递减        | 极小值  | 单调递增               |
所以$f ( x )$的单调递增区间为$( - \infty , 1 )$，$( 3 , + \infty )$，单调递减区间为$( 1 , 3 )$.
（2）因为$f ( x )$在区间$( 1 , 3 )$上单调递减，在区间$( 3 , + \infty )$上单调递增，
又有$f ( 1 ) = 4$，$f ( 3 ) = 0$，要使$f ( x )$在区间$\lbrack 0 , m \rbrack$上的最小值为$0$，则$m \geq 3$.
##### 【典例2】（2023下·福建泉州·高二福建省德化第一中学校考阶段练习）已知函数$f ( x ) = x^{3} + a x + b$，且满足$f ( x )$的导数$y = f^{'} ( x )$的最小值为$- \frac{3}{4}$.
(1)求$a$值；
(2)若函数在区间$[ - 1 , 2 ]$上的最大值与最小值的和为7，求$b$值.
<span class="fake-tag">答案</span>(1)$a = - \frac{3}{4}$
(2)$b = \frac{3}{8}$
<span class="fake-tag">详解</span>（1）∵$f^{'} ( x ) = 3 x^{2} + a$，则$f^{'} ( x )$的最小值为$f^{'} ( 0 ) = a$，
由题意可得：$a = - \frac{3}{4}$.
（2）由（1）可得：$f ( x ) = x^{3} - \frac{3}{4} x + b , x \in [ - 1 , 2 ]$，则，
令$f^{'} ( x ) > 0$，解得$\frac{1}{2} < x \leq 2$或$- 1 \leq x < - \frac{1}{2}$；令$f^{'} ( x ) < 0$，解得$- \frac{1}{2} < x < \frac{1}{2}$；
则$f ( x )$在$\left. - 1 , - \frac{1}{2} \right) , \left. \frac{1}{2} , 2 \right.$单调递增，在$\left( - \frac{1}{2} , \frac{1}{2} \right)$上单调递增，
且$f \left( \frac{1}{2} \right) = \left( \frac{1}{2} \right)^{3} - \frac{3}{4} \times \frac{1}{2} + b = - \frac{1}{4} + b$，$f \left( - \frac{1}{2} \right) = \left( - \frac{1}{2} \right)^{3} + \frac{3}{4} \times \frac{1}{2} + b = \frac{1}{4} + b$，
$f ( - 1 ) = - 1 - \frac{3}{4} ( - 1 ) + b = - \frac{1}{4} + b$，$f ( 2 ) = 2^{3} - \frac{3}{4} \times 2 + b = \frac{13}{2} + b$，
且$- \frac{1}{4} + b < \frac{1}{4} + b < \frac{13}{2} + b$，
所以函数在区间$[ - 1 , 2 ]$上的最大值${\left\lbrack f ( x ) \right\rbrack \frac{13}{2}}_{\max}$，最小值${\left\lbrack f ( x ) \right\rbrack \frac{1}{4}}_{\min}$，
又∵函数在区间$[ - 1 , 2 ]$上的最大值与最小值的和为7，
则$\frac{13}{2} + b + \left( - \frac{1}{4} + b \right) = \frac{25}{4} + 2 b = 7$，解得$b = \frac{3}{8}$.
##### 【变式1】（2023上·安徽芜湖·高二芜湖一中校考期末）已知函数$f ( x ) = \ln x + \frac{a}{x}$，$a \in \mathbf{R}$．
(1)当$a = 2$时，求曲线在点$\left( 1 , f ( 1 ) \right)$处的切线方程；
(2)若函数$f ( x )$在$[ 1 , e ]$上的最小值是$\frac{3}{2}$，求*a*的值．
<span class="fake-tag">答案</span>(1)$x + y - 3 = 0$
(2)$a = \sqrt{e}$
<span class="fake-tag">详解</span>（1）当$a = 2$时，$f ( x ) = \ln x + \frac{2}{x}$，$f ( 1 ) = 2$，
所以切点为$( 1 , 2 )$，
$f^{'} ( x ) = \frac{1}{x} - \frac{2}{x^{2}}$，则$f^{'} ( 1 ) = 1 - 2 = - 1$，
所以切线方程为$y - 2 = - ( x - 1 )$，即$x + y - 3 = 0$.
（2）$f^{'} ( x ) = \frac{1}{x} - \frac{a}{x^{2}} = \frac{x - a}{x^{2}}$，$x > 0$，
若，则$f^{'} ( x ) \geq 0$在$[ 1 , e ]$上恒成立，
所以$f ( x )$在$[ 1 , e ]$上单调递增，
所以$f {( x ) \frac{3}{2}}_{\min}$，不满足题意；
若$1 < a < e$，令$f^{'} ( x ) < 0$，解得$1 \leq x < a$，令$f^{'} ( x ) > 0$，解得$a < x \leq e$，
所以函数$f ( x )$在$\left. 1 , a )$单调递减，单调递增，
所以$f {( x ) \ln a \frac{3}{2}}_{\min}$，解得$a = \sqrt{e}$，满足题意；
若$a \geq e$， 则$f^{'} ( x ) \leq 0$在$[ 1 , e ]$上恒成立，
所以$f ( x )$在$[ 1 , e ]$上单调递减，
所以$f {( x ) e \frac{a}{e} \frac{3}{2}}_{\min}$，解得$a = \frac{e}{2}$，不满足题意，
综上，$a = \sqrt{e}$.
##### 【变式2】（2023上·河南·高三校联考阶段练习）已知函数$f ( x ) = \frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x + 1$，$a \in \mathbf{R}$．
(1)若曲线关于点对称，求*a*的值；
(2)若$f ( x )$在区间$[ 0 , 1 ]$上的最小值为1，求*a*的取值范围．
<span class="fake-tag">答案</span>(1)$a = 1$
(2)$\left. - \infty , - \frac{2}{9} \right.$
<span class="fake-tag">详解</span>（1）设$g ( x ) = f ( x ) - 1 = \frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x$．
由题意知，$g ( x )$是奇函数，所以，
即对任意$x \in \mathbf{R}$，有$- \left\lbrack \frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x \right\rbrack = - \frac{1}{3} x^{3} + ( a - 1 ) x^{2} + 4 a x$，化简得$( 1 - a ) x^{2} = ( a - 1 ) x^{2}$，
所以$a - 1 = 0$，即$a = 1$．
（2）方法1：因为$f ( x )$在$[ 0 , 1 ]$上的最小值为1，
故$f ( 1 ) = \frac{1}{3} + ( a - 1 ) - 4 a + 1 \geq 1$，解得$a \leq - \frac{2}{9}$．
$f^{'} ( x ) = x^{2} + 2 ( a - 1 ) x - 4 a = ( x - 2 ) ( x + 2 a )$
当$x \in [ 0 , 1 ]$时，$x - 2 < 0$．
若$- \frac{1}{2} < a \leq - \frac{2}{9}$，则$- 2 a \in \left. \frac{4}{9} , 1 \right)$．
当$x \in ( 0 , - 2 a )$时，$f^{'} ( x ) > 0$；当$x \in ( - 2 a , 1 )$时，$f^{'} ( x ) < 0$，
所以$f ( x )$在$( 0 , - 2 a )$上单调递增，在$( - 2 a , 1 )$上单调递减．
而$f ( 0 ) = 1$，$f ( 1 ) \geq 1$，因此$f ( x )$在$[ 0 , 1 ]$上的最小值为1，满足题意．
若$a \leq - \frac{1}{2}$，则$- 2 a \geq 1$，当$x \in [ 0 , 1 ]$时，$f^{'} ( x ) \geq 0$，所以$f ( x )$在上单调递增，
故$f ( x )$在$[ 0 , 1 ]$上的最小值为$f ( 0 ) = 1$，满足题意．
综上所述，*a*的取值范围为$\left. - \infty , - \frac{2}{9} \right.$．
方法2：由题意知$f ( x ) = \frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x + 1 \geq 1$，即$\frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x \geq 0$，
又$x \in [ 0 , 1 ]$，$x = 0$时，$\frac{1}{3} x^{3} + ( a - 1 ) x^{2} - 4 a x = 0$，
所以$f ( x ) \geq 1$等价于$\frac{1}{3} x^{2} + ( a - 1 ) x - 4 a \geq 0$，
令$m ( x ) = \frac{1}{3} x^{2} + ( a - 1 ) x - 4 a$，分情况讨论，
①$\begin{cases}\frac{3 ( 1 - a )}{2} > 1 \\ m ( 1 ) = \frac{1}{3} + a - 1 - 4 a \geq 0\end{cases}$，即$\begin{cases}a < \frac{1}{3} \\ a \leq - \frac{2}{9}\end{cases}$，故$a \leq - \frac{2}{9}$；
②$\begin{cases}0 \leq \frac{3 ( 1 - a )}{2} \leq 1 \\ m \left\lbrack \frac{3 ( 1 - a )}{2} \right\rbrack = \frac{3 ( 1 - a )^{2}}{4} - \frac{3 ( 1 - a )^{2}}{2} - 4 a \geq 0\end{cases}$，即$\begin{cases}\frac{1}{3} \leq a \leq 1 \\ - 3 \leq a \leq - \frac{1}{3}\end{cases}$，无解；
③$\begin{cases}\frac{3 ( 1 - a )}{2} < 0 \\ m ( 0 ) = - 4 a \geq 0\end{cases}$，即$\begin{cases}a > 1 \\ a \leq 0\end{cases}$，无解．
综上所述，*a*的取值范围是$\left. - \infty , - \frac{2}{9} \right.$．
