##### 题型06 共线向量
##### 【典例1】（多选）（2023上·高二课时练习）(多选)下列命题的判断正确的是（ ）
$\quad$A．若向量$\overrightarrow{A B}$与向量$\overrightarrow{C D}$共线，则*A*，*B*，*C*，*D*四点在一条直线上
$\quad$B．若*A*，*B*，*C*，*D*四点在一条直线上，则向量$\overrightarrow{A B}$与向量$\overrightarrow{C D}$共线
$\quad$C．若*A*，*B*，*C*，*D*四点不在一条直线上，则向量$\overrightarrow{A B}$与向量$\overrightarrow{C D}$不共线
$\quad$D．若向量$\overrightarrow{A B}$与向量$\overrightarrow{B C}$共线，则*A*，*B*，*C*三点在一条直线上
<span class="fake-tag">答案</span>BD
<span class="fake-tag">详解</span>对于A，平行四边形$A B C D$中，$\overrightarrow{A B} = \overrightarrow{D C}$，满足向量$\overrightarrow{A B}$与$\overrightarrow{C D}$共线，而四点不共线，A错误；
对于B，四点在一条直线上，则向量$\overrightarrow{A B}$与$\overrightarrow{C D}$方向相同或相反，即向量$\overrightarrow{A B}$与$\overrightarrow{C D}$共线，B正确；
对于C，平行四边形$A B C D$中，满足四点不共线，有$\overrightarrow{A B} = \overrightarrow{D C}$，即向量$\overrightarrow{A B}$与$\overrightarrow{C D}$共线，C错误；
对于D，向量$\overrightarrow{A B}$与$\overrightarrow{B C}$共线，而向量$\overrightarrow{A B}$与$\overrightarrow{B C}$有公共点$B$，因此三点在一条直线上，D正确.
故选：BD

##### 【变式1】（多选）（2023下·贵州遵义·高一校考阶段练习）下列说法错误的是（ ）
$\quad$A．有向线段$\overrightarrow{A B}$与$\overrightarrow{B A}$表示同一向量
$\quad$B．两个有公共终点的向量是平行向量
$\quad$C．零向量与单位向量是平行向量
$\quad$D．单位向量都相等
<span class="fake-tag">答案</span>ABD
<span class="fake-tag">详解</span>对A, 有向线段$\overrightarrow{A B}$与$\overrightarrow{B A}$表示相反向量，不是同一向量，A错误；
对B，两个有公共终点的向量不一定是平行向量，B错误；
对C，我们规定：零向量与任意向量是平行向量，C正确；
对D，单位向量仅是模长相等，方向不确定，D错误；
故选:ABD.
##### 【变式2】（多选）（2023下·四川遂宁·高一射洪中学校考阶段练习）下列命题中错误的有（ ）
$\quad$A．起点相同的单位向量，终点必相同；
$\quad$B．已知向量$\overrightarrow{A B} \parallel \overrightarrow{C D}$，则四边形*ABCD*为平行四边形；
$\quad$C．若$\overrightarrow{a} \text{//} \overrightarrow{b} , \overrightarrow{b} \text{//} \overrightarrow{c}$，则$\overrightarrow{a} \text{//} \overrightarrow{c}$；
$\quad$D．若$\overrightarrow{a} = \overrightarrow{b} , \overrightarrow{b} = \overrightarrow{c}$，则$\overrightarrow{a} = \overrightarrow{c}$
<span class="fake-tag">答案</span>AC
<span class="fake-tag">详解</span>单位向量的方向不确定，所以起点相同的，终点不一定相同，A选项错误；
四边形*ABCD*中，$\overrightarrow{A B} \parallel \overrightarrow{C D}$，则$A B \text{//} C D$且$A B = C D$，四边形*ABCD*为平行四边形，B选项正确；
当$\overrightarrow{b} = \overrightarrow{0}$时，满足$\overrightarrow{a} \text{//} \overrightarrow{b} , \overrightarrow{b} \text{//} \overrightarrow{c}$，但不能得到$\overrightarrow{a} \text{//} \overrightarrow{c}$，C选项错误；
由向量相等的条件可知，若$\overrightarrow{a} = \overrightarrow{b} , \overrightarrow{b} = \overrightarrow{c}$，则$\overrightarrow{a} = \overrightarrow{c}$，D选项正确.
故选：AC
