##### 题型02 已知两边及一角解三角形
##### 【典例1】（2023上·新疆·高二学业考试）在$\bigtriangleup A B C$中，角的对边分别是$a , b , c$，已知$A = \frac{\pi}{3}$，$a = \sqrt{3}$，$b = 1$，则$c$等于（ ）
$\quad$A．1 
$\quad$B．2 
$\quad$C．$\sqrt{3} - 1$ 
$\quad$D．
<span class="fake-tag">答案</span>B
<span class="fake-tag">详解</span>由余弦定理$a^{2} = b^{2} + c^{2} - 2 b c \cos A$，
将$A = \frac{\pi}{3}$，$a = \sqrt{3}$，$b = 1$，代入得$3 = 1^{2} + c^{2} - 2 c \cos \frac{\pi}{3}$，
则有$c^{2} - c - 2 = 0$，且$c > 0$，解得$c = 2$.
故选：B.

##### 【变式1】（2023上·湖南常德·高二校联考期中）在△*ABC*中，$A B = 1$，$B C = \sqrt{5}$，，则$A C =$（ ）

##### 【变式2】（2023上·全国·高三专题练习）在锐角$\bigtriangleup A B C$中，$a = 7 , \mspace{6mu} c = 8$，$\bigtriangleup A B C$的面积为$16 \sqrt{3}$，则$b$ = ．
<span class="fake-tag">答案</span>$\sqrt{97}$
<span class="fake-tag">详解</span>因为$a = 7 , \mspace{6mu} c = 8$，所以$\bigtriangleup A B C$的面积为$\frac{1}{2} a c \sin B = \frac{1}{2} \times 7 \times 8 \sin B = 1 6 \sqrt{3}$，解得$\sin B = \frac{4 \sqrt{3}}{7}$，
又因为$\bigtriangleup A B C$为锐角三角形，所以$\cos B = \sqrt{1 - \sin^{2} B} = \sqrt{1 - ( \frac{4 \sqrt{3}}{7} )^{2}} = \frac{1}{7}$，
由余弦定理得$b = \sqrt{a^{2} + c^{2} - 2 a c \cos B} = \sqrt{4 9 + 6 4 - 2 \times 7 \times 8 \times \frac{1}{7}} = \sqrt{97}$．
故答案为：$\sqrt{97}$.
