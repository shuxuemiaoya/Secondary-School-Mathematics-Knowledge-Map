##### 题型02 贝叶斯公式的应用
##### 【典例1】（2024·全国·高二假期作业）居民的某疾病发病率为$1 \%$，现进行普查化验，医学研究表明，化验结果是可能存有误差的．已知患有该疾病的人其化验结果$9 9 \%$呈阳性，而没有患该疾病的人其化验结果$1 \%$呈阳性．现有某人的化验结果呈阳性，则他真的患该疾病的概率是（ ）
$\quad$A．0.99 
$\quad$B．0.9 
$\quad$C．0.5 
$\quad$D．0.1
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>记事件$A :$某人患病，事件$B :$化验结果呈阳性，
由题意可知$P ( A ) = \frac{1}{100}$，$P \left( B | A  \right) = \frac{\text{99}}{\text{100}}$，$P \left( B | \bar{A}  \right) = \frac{1}{\text{100}}$，
所以，$P ( B ) = P ( A ) \cdot P \left( B | A  \right) + P \left( \bar{A} \right) \cdot P \left( B | \bar{A}  \right)$$= \frac{1}{\text{100}} \times \frac{99}{100} + \left( 1 - \frac{1}{100} \right) \times \frac{1}{100} = \frac{\text{99}}{5 \times \text{1} \text{0}^{3}}$，
现在某人的化验结果呈阳性，则他真的患该疾病的概率是：
$P \left( A | B  \right) = \frac{P ( A B )}{P ( B )} = \frac{P ( A ) \cdot P \left( B | A  \right)}{P ( B )} = \frac{\frac{1}{\text{100}} \times \frac{99}{100}}{\frac{\text{99}}{5 \times \text{1} \text{0}^{3}}} = \frac{1}{2}$.
故选：C.
##### 【典例2】（2024·天津·校考模拟预测）第三次人工智能浪潮滚滚而来，以ChatGPT发布为里程碑，开辟了人机自然交流的新纪元．ChatGPT所用到的数学知识并非都是遥不可及的高深理论，概率就被广泛应用于ChatGPT中，某学习小组设计了如下问题进行研究：甲和乙两个箱子中各装有5个大小相同的小球，其中甲箱中有3个红球、2个白球，乙箱中有4个红球、1个白球，从甲箱中随机抽出2个球，在已知抽到红球的条件下，则2个球都是红球的概率为 ；掷一枚质地均匀的骰子，如果点数小于等于4，从甲箱子中随机抽出1个球；如果点数大于等于5，从乙箱子中随机抽出1个球，若抽到的是红球，则它是来自乙箱的概率是 ．
<span class="fake-tag">答案</span> $\frac{2}{5}$/0.4
<span class="fake-tag">详解</span>记事件$A$表示“抽出的2个球中有红球”，事件$B$表示“两个球都是红球”，
则$P ( A ) = 1 - \frac{C_{2}^{2}}{C_{5}^{2}} = \frac{9}{10}$，$P ( A B ) = \frac{C_{3}^{2}}{C_{5}^{2}} = \frac{3}{10}$，
故$P \left( B | A  \right) = \frac{P ( A B )}{P ( A )} = \frac{\frac{3}{10}}{\frac{9}{10}} = \frac{1}{3}$，
即从甲箱中随机抽出2个球，在已知抽到红球的条件下，则2个球都是红球的概率为；
设事件$C$表示“从乙箱中抽球”，则事件$\overline{C}$表示“从甲箱中抽球”，事件$D$表示“抽到红球”，
则$P ( C ) = \frac{2}{6} = \frac{1}{3}$，$P \left( \overline{C} \right) = \frac{4}{6} = \frac{2}{3}$，
$P \left( D | C  \right) = \frac{4}{5}$，$P \left( D | \bar{C}  \right) = \frac{3}{5}$，
所以$P ( D ) = P ( C D ) + P \left( \bar{C} D \right)$
$= P ( C ) P \left( D | C  \right) + P \left( \bar{C} \right) P \left( D | \bar{C}  \right)
$= \frac{1}{3} \times \frac{4}{5} + \frac{2}{3} \times \frac{3}{5} = \frac{2}{3}$，
所以$P \left( C | D  \right) = \frac{P ( C ) P \left( D | C  \right)}{P ( D )} = \frac{\frac{1}{3} \times \frac{4}{5}}{\frac{2}{3}} = \frac{2}{5}$，
即若抽到的是红球，则它是来自乙箱的概率是$\frac{2}{5}$.
故答案为：；$\frac{2}{5}$
##### 【典例3】（2024·全国·高三专题练习）三批同种规格的产品，第一批占25%，次品率为6%；第二批占30%，次品率为5%；第三批占45%，次品率为5%．将三批产品混合，从混合产品中任取一件．
(1)求这件产品是次品的概率；
(2)已知取到的是次品，求它取自第一批产品的概率．
<span class="fake-tag">答案</span>(1)$0 . 0 5 2 5$
(2)$\frac{2}{7}$
<span class="fake-tag">详解</span>（1）设取到第批产品为事件$A_{i}$，$i = 1 , 2 , 3$，取到次品为事件$B$.
$P ( B ) = P \left( A_{1} \right) P \left( B | A_{1}  \right) + P \left( A_{2} \right) P \left( B | A_{2}  \right) + P \left( A_{3} \right) P \left( B | A_{3}  \right)$$= 0 . 2 5 \times 0 . 0 6 + 0 . 3 \times 0 . 0 5 + 0 . 4 5 \times 0 . 0 5 = 0 . 0 5 2 5$.
（2）$P \left( A_{1} | B  \right) = \frac{P \left( A_{1} B \right)}{P ( B )} = \frac{P \left( A_{1} \right) P \left( B | A_{1}  \right)}{P ( B )} = \frac{0 . 2 5 \times 0 . 0 6}{0 . 0 5 2 5} = \frac{2}{7}$.
##### 【变式1】（2024·全国·高三专题练习）根据以往的临床记录，某种诊断癌症的试验有如下的效果：若以$A$表示事件“试验反应为阳性”，以$C$表示事件“被诊断者患有癌症”，则有$P ( A | C ) = 0 . 9 5$，$P ( \bar{A} | \bar{C} ) = 0 . 9 5 .$现在对自然人群进行普查，设被试验的人患有癌症的概率为$0 . 0 0 5$，即$P ( C ) = 0 . 0 0 5$，则$P ( C | A ) \approx$（ ）
$\quad$A．$0 . 0 8 7$ 
$\quad$B．$0 . 9 5 0$ 
$\quad$C．$0 . 0 5 0$ 
$\quad$D．$0 . 4 7 5$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>解：因为$P ( \bar{A} | \bar{C} ) = 0 . 9 5$，所以$P ( A | \bar{C} ) = 1 - P ( \bar{A} | \bar{C} ) = 0 . 0 5$，
因为$P ( C ) = 0 . 0 0 5$，所以$P \left( \bar{C} \right) = 0 . 9 9 5$，
所以由全概率公式可得$P ( A ) = P ( A | C ) \cdot P ( C ) + P ( A | \bar{C} ) \cdot P \left( \bar{C} \right)$，
因为$P ( A C ) = P ( C | A ) P ( A ) = P ( A | C ) P ( C )$，
所以$P ( C | A ) = \frac{P ( A | C ) P ( C )}{P ( A | C ) P ( C ) + P ( A | \bar{C} ) P \left( \bar{C} \right)} = \frac{0 . 9 5 \times 0 . 0 0 5}{0 . 9 5 \times 0 . 0 0 5 + 0 . 0 5 \times 0 . 9 9 5} = \frac{19}{218}$．
所以$P ( C | A ) = \frac{19}{218} \approx 0 . 0 8 7$．
故选：A
##### 【变式2】（2024·全国·高三专题练习）有3台车床加工同一型号的零件，第1台加工的次品率为8%，第2台加工的次品率为3%，第3台加工的次品率为2%，加工出来的零件混放在一起．已知第1，2，3台车床加工的零件数分别占总数的10%，40%，50%，从混放的零件中任取一个零件，如果该零件是次品，那么它是第3台车床加工出来的概率为 ．
<span class="fake-tag">答案</span>
<span class="fake-tag">详解</span>记事件$A$：车床加工的零件为次品，记事件$B_{i}$：第台车床加工的零件，
则$P ( A | B_{1} ) = 8 \%$，$P ( A | B_{2} ) = 3 \%$，$P ( A | B_{3} ) = 2 \%$，$P ( B_{1} ) = 1 0 \%$，$P ( B_{2} ) = 4 0 \%$，$P ( B_{3} ) = 5 0 \%$，
任取一个零件是次品的概率为$P ( A ) = P ( A B_{1} ) + P ( A B_{2} ) + P ( A B_{3} ) = 8 \% \times 1 0 \% + 3 \% \times 4 0 \% + 2 \% \times 5 0 \% = 0 . 0 3$
如果该零件是次品，那么它是第3台车床加工出来的概率为

##### 【变式3】（2024·全国·高二假期作业）现在一些大的建筑工程都实行招投标制．在发包过程中，对参加招标的施工企业的资质（含施工质量、信誉等）进行调查和评定是非常重要的．设*B*=“被调查的施工企业资质不好”，*A*=“被调查的施工企业资质评定为不好”．由过去的资料知$P \left(  A | B \right) = 0 . 9 7$，$P \left(  \bar{A} | \bar{B} \right) = 0 . 9 5$．现已知在被调查的施工企业当中有$6 \%$确实资质不好，求评定为资质不好的施工企业确实资质不好的概率（精确到0.01）．
<span class="fake-tag">答案</span>0.55
<span class="fake-tag">详解</span>由题意可得$P ( B ) = 0 . 0 6$，$P \left(  A | B \right) = 0 . 9 7$，$P \left(  \bar{A} | \bar{B} \right) = 0 . 9 5$，
所以$P \left(  A | \bar{B} \right) = 1 - P \left(  \bar{A} | \bar{B} \right) = 1 - 0 . 9 5 = 0 . 0 5 , P \left( \bar{B} \right) = 1 - P ( B ) = 1 - 0 . 0 6 = 0 . 9 4$，
$P \left(  B | A \right) = \frac{P ( A B )}{P ( A )} = \frac{P ( B ) \cdot P \left(  A | B \right)}{P ( A B ) + P \left( A \bar{B} \right)} = \frac{P ( B ) \cdot P \left(  A | B \right)}{P ( B ) \cdot P \left(  A | B \right) + P \left( \bar{B} \right) \cdot P \left(  A | \bar{B} \right)}$
$= \frac{0 . 0 6 \times 0 . 9 7}{0 . 0 6 \times 0 . 9 7 + 0 . 9 4 \times 0 . 0 5} \approx 0 . 5 5$.
即评定为资质不好的施工企业确实资质不好的概率约为0.55.
