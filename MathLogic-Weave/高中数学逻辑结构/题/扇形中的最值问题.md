##### 题型11扇形中的最值问题
##### 【典例1】（23-24高一下·陕西渭南·阶段练习）已知扇形的圆心角是$\mathbf{\alpha}$，半径为，弧长为$\mathbf{l}$；
(1)若$\mathbf{\alpha = 1 0} \mathbf{5}^{\mathbf{\circ}} \mathbf{, r = 8} \text{cm}$，求扇形的弧长$\mathbf{l}$；
(2)若扇形的周长为$\mathbf{10} \text{cm}$，当扇形的圆心角$\mathbf{\alpha}$为多少弧度时，这个扇形的面积最大，最大值是多少？并求出此时的半径.
<span class="fake-tag">答案</span>(1)$\frac{1 4 \pi}{3} \left( \text{cm} \right)$
(2)，$\frac{25}{4} \text{c} \text{m}^{2}$，$r = \frac{5}{2} \text{cm}$
<span class="fake-tag">分析</span>（1）利用弧长公式可得答案；
（2）利用周长和面积公式，结合二次函数可得答案.
<span class="fake-tag">详解</span>（1）$\alpha = 1 0 5^{\circ} = \frac{7 \pi}{12}$，
$l = \alpha r = \frac{7 \pi}{12} \times 8 = \frac{1 4 \pi}{3} \left( \text{cm} \right)$.
（2）由已知得，$l + 2 r = 1 0$，
所以$S = \frac{1}{2} l r = \frac{1}{2} ( 1 0 - 2 r ) r = - r^{2} + 5 r = - \left( r - \frac{5}{2} \right)^{2} + \frac{25}{4}$，$r \in ( 0 , 5 )$，
所以当$r = \frac{5}{2} \text{cm}$时，面积$S$取得最大值$\frac{25}{4} \text{c} \text{m}^{2}$，
此时$l = 5 \text{cm} , r = \frac{5}{2} \text{cm}$，所以$\alpha = \frac{l}{r} = 2$.
##### 【典例2】（23-24高一上·全国·期末）已知一个扇形的中心角是$\mathbf{\alpha}$，所在圆的半径是R.
(1)若$\mathbf{\alpha = 6 0 {^\circ}}$，$\mathbf{R = 1 0} \mathbf{\mspace{6mu}} \text{cm}$，求扇形的面积；
(2)若扇形的周长为$\mathbf{2 0 \mspace{6mu}} \text{cm}$，面积为$\mathbf{9} \mathbf{\mspace{6mu}} \text{c} \text{m}^{\mathbf{2}}$，求扇形圆心角的弧度数；
(3)若扇形的周长为定值C，当$\mathbf{\alpha}$为多少弧度时，该扇形面积最大？并求出最大值.
<span class="fake-tag">答案</span>(1)$\frac{5 0 \pi}{3}$
(2)$\alpha = \frac{2}{9}$
(3)当时，扇形面积有最大值，为$\frac{C^{2}}{16}$
<span class="fake-tag">分析</span>（1）利用弧度制转化角度，根据扇形面积公式，可得答案；
（2）根据扇形周长以及面积计算公式，建立方程组，可得答案；
（3）根据扇形周长的计算公式表示出半径与角度之间的关系，写出扇形面积的表达式，利用基本不等式，可得答案.
<span class="fake-tag">详解</span>（1）由$\alpha = 6 0^{\circ} = \frac{\pi}{3}$，则$S = \frac{1}{2} \alpha R^{2} = \frac{1}{2} \times \frac{\pi}{3} \times 1 0^{2} = \frac{5 0 \pi}{3} \left( \text{c} \text{m}^{2} \right)$.
（2）由$\begin{cases}R \alpha + 2 R = 2 0 \\ \frac{1}{2} \alpha R^{2} = 9\end{cases}$，解得$\alpha = \frac{2}{9}$或18，因为$0 < \alpha < 2 \pi$，所以$\alpha = \frac{2}{9}$.
（3）由$2 R + \alpha R = C$，得$R = \frac{C}{2 + \alpha}$，
则$S = \frac{1}{2} \alpha R^{2} = \frac{1}{2} \alpha \cdot \frac{C^{2}}{\alpha^{2} + 4 \alpha + 4} = \frac{C^{2}}{2} \cdot \frac{1}{\alpha + \frac{4}{\alpha} + 4}$，
由$0 < \alpha < 2 \pi$，则$S \leq \frac{C^{2}}{2} \cdot \frac{1}{2 \sqrt{\alpha \cdot \frac{4}{\alpha}} + 4} = \frac{C^{2}}{16}$，当且仅当时，等号成立，
当时，扇形面积有最大值$\frac{C^{2}}{16}$.
##### 【变式1】（23-24高一下·北京·阶段练习）（1）一条弦$\mathbf{A B}$的长等于它所在圆的半径，求弦$\mathbf{A B}$和劣弧$\mathbf{A B}$所组成的弓形的面积;
（2）一扇形的周长为$\mathbf{10} \text{cm}$，那么扇形的半径和圆心角各取什么值时，才能使扇形的面积最大?并求出最大值?
<span class="fake-tag">答案</span>（1）$\frac{2 \pi - 3 \sqrt{3}}{12} R^{2}$；（2）扇形半径$\frac{5}{2} \text{cm}$，扇形圆心角为$2$，扇形面积最大值$\frac{25}{4} \text{c} \text{m}^{2}$.
<span class="fake-tag">分析</span>（1）要怕给定条件，求出劣弧$A B$所对的圆心角，再求出扇形面积及三角形面积即得.
（2）设出扇形的半径，结合已知建立函数关系，借助二次函数求解即得.
<span class="fake-tag">详解</span>（1）如图，在圆$O$中，弦$A B = R$，则$\bigtriangleup A O B$是正三角形，$\angle A O B = \frac{\pi}{3}$，$A B$边上的高为$\frac{\sqrt{3}}{2} R$，
因此$S_{\bigtriangleup A B C} = \frac{1}{2} \cdot R \cdot \frac{\sqrt{3}}{2} R = \frac{\sqrt{3}}{4} R^{2}$，而扇形$A O B$面积为$\frac{1}{2} \cdot \frac{\pi}{3} R^{2} = \frac{\pi}{6} R^{2}$，
所以弦$A B$和劣弧$A B$所组成的弓形的面积是$\frac{\pi}{6} R^{2} - \frac{\sqrt{3}}{4} R^{2} = \frac{2 \pi - 3 \sqrt{3}}{12} R^{2}$.

（2）设扇形的半径为，则扇形弧长$l = 1 0 - 2 r$，
扇形面积$S = \frac{1}{2} l r = - r^{2} + 5 r = - ( r - \frac{5}{2} )^{2} + \frac{25}{4} \leq \frac{25}{4}$，当且仅当$r = \frac{5}{2}$时取等号，

##### 【变式2】（23-24高一上·海南省直辖县级单位·阶段练习）已知一扇形的圆心角为$\mathbf{\alpha}$，半径为，弧长为$\mathbf{l}$.
(1)若$\mathbf{\alpha = 6 0} \mathbf{^\circ}$，，求扇形的周长；
(2)若扇形的周长为20，求扇形面积的最大值，此时扇形的圆心角$\mathbf{\alpha}$为多少弧度.
<span class="fake-tag">答案</span>(1)$2 \pi + 1 2$
(2)最大值为$25$，此时扇形的圆心角$\alpha$为弧度
<span class="fake-tag">分析</span>（1）根据弧长公式计算即可；
（1）根据扇形的周长将用$\alpha$表示，再根据扇形的面积公式结合基本不等式即可得解.
<span class="fake-tag">详解</span>（1）$\alpha = 6 0 {^\circ} = \frac{\pi}{3}$，
故扇形的周长为$l + 2 R = \frac{\pi}{3} \times 6 + 2 \times 6 = 2 \pi + 1 2$；
（2）扇形的周长为20，
则$\alpha R + 2 R = 2 0$，所以$R = \frac{20}{\alpha + 2}$，
则扇形的面积$S = \frac{1}{2} \alpha R^{2} = \frac{1}{2} \alpha \cdot \frac{400}{( \alpha + 2 )^{2}} = \frac{200}{\alpha + \frac{4}{\alpha} + 4} \leq \frac{200}{2 \sqrt{\alpha \cdot \frac{4}{\alpha}} + 4} = 2 5$，
当且仅当$\alpha = \frac{4}{\alpha}$，即时取等号，
所以扇形面积的最大值为$25$，此时扇形的圆心角$\alpha$为$2$弧度.
