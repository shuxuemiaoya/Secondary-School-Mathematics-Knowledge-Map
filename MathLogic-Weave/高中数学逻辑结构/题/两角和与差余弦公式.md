##### 题型01 两角和与差余弦公式
##### 【典例1】（24-25高一下·全国·随堂练习）已知$\cos \alpha = \frac{12}{13}$，$\alpha \in \left( - \frac{\pi}{2} , 0 \right)$，则的值为（ ）
$\quad$A． 
$\quad$B．$\frac{7 \sqrt{2}}{13}$ 
$\quad$C．$\frac{17 \sqrt{2}}{26}$ 
$\quad$D．$\frac{7 \sqrt{2}}{26}$
<span class="fake-tag">答案</span>D
<span class="fake-tag">分析</span>利用同角三角函数基本关系式和两角差的余弦公式，即可求解.
<span class="fake-tag">详解</span>因为$\cos \alpha = \frac{12}{13}$，$\alpha \in \left( - \frac{\pi}{2} , 0 \right)$，则$\sin \alpha = - \sqrt{1 - \cos^{2} \alpha} = - \frac{5}{13}$，
所以$\cos \left( \alpha - \frac{\pi}{4} \right) = \cos \alpha \cos \frac{\pi}{4} + \sin \alpha \sin \frac{\pi}{4} = \frac{12}{13} \times \frac{\sqrt{2}}{2} + \left( - \frac{5}{13} \right) \times \frac{\sqrt{2}}{2} = \frac{7 \sqrt{2}}{26}$.
故选：D
##### 【典例2】（24-25高一下·全国·课前预习）已知$\alpha$，$\beta \in \left( 0 , \frac{\pi}{2} \right)$，且，$\cos \beta = \frac{\sqrt{10}}{10}$，求的值.
<span class="fake-tag">答案</span>$\frac{3 \pi}{4}$
<span class="fake-tag">分析</span>根据角所在的象限，利用同角三角函数的基本关系求出$\cos \alpha = \frac{\sqrt{5}}{5}$，$\sin \beta = \frac{3 \sqrt{10}}{10}$，再用两角和的余弦公式求解即可.
<span class="fake-tag">详解</span>$\because \alpha$，$\beta \in \left( 0 , \frac{\pi}{2} \right)$，，$\cos \beta = \frac{\sqrt{10}}{10}$，
，$\sin \beta = \frac{3 \sqrt{10}}{10}$，
$\therefore \cos ( \alpha + \beta ) = \cos \alpha \cos \beta - \sin \alpha \sin \beta = \frac{\sqrt{5}}{5} \times \frac{\sqrt{10}}{10} - \frac{2 \sqrt{5}}{5} \times \frac{3 \sqrt{10}}{10} = - \frac{\sqrt{2}}{2}$.

$\quad$C．$- \frac{5}{8}$ 
$\quad$D．$- \frac{29}{32}$
