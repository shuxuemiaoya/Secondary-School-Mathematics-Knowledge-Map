##### 【典例2】（2023下·江西萍乡·高一统考期中）在$\bigtriangleup A B C$中，角*A*，$B$，$C$的对边分别为$a$，$b$，$c$，若，，则边$A C$上的中线$B D$长度的最大值为 ．
<span class="fake-tag">答案</span>$2 \sqrt{3}$
<span class="fake-tag">详解</span>![@@@2bbf10a3-7c59-4414-b977-6aa35eb70518](MathLogic-Weave/高中数学逻辑结构/题/Attachments/c65925811aee1b50560f3c07d23727d0.png)
在$\bigtriangleup A B C$中有$A 、 B 、 C \in ( 0 , \pi ) , \sin ( A + B ) = \sin ( \pi - C ) = \sin C$，
故由正弦定理可得$( a - c ) \sin A + c \sin ( A + B ) = b \sin B \Rightarrow a ( a - c ) + c^{2} = b^{2}$，
由余弦定理得$\cos B = \frac{a^{2} + c^{2} - b^{2}}{2 a c} = \frac{a c}{2 a c} = \frac{1}{2} \Rightarrow B = \frac{\pi}{3}$，
由三角形中线的性质可得：$\overrightarrow{B D} = \frac{1}{2} \left( \overrightarrow{B A} + \overrightarrow{B C} \right) \Rightarrow \overrightarrow{B D}^{2} = \frac{1}{4} \left( \overrightarrow{B A}^{2} + \overrightarrow{B C}^{2} + 2 \overrightarrow{B A} \cdot \overrightarrow{B C} \right)$，
即$B D^{2} = \frac{1}{4} \left( c^{2} + a^{2} + 2 c a \cos B \right) = \frac{1}{4} \left( a^{2} + c^{2} + a c \right)$，
又$a^{2} + c^{2} - a c = b^{2} = 1 6 \Rightarrow a^{2} + c^{2} = 1 6 + a c \geq 2 a c \Rightarrow a c \leq 16$，
故$a^{2} + c^{2} + a c = 2 a c + 1 6 \leq 48$，当且仅当$a = c = 4$时取得等号，
所以$B D^{2} = \frac{1}{4} \left( a^{2} + c^{2} + a c \right) \leq 12 \Rightarrow B D \leq 2 \sqrt{3}$.
故答案为：$2 \sqrt{3}$.
##### 【典例3】（2023上·辽宁大连·高三大连市第一中学校考阶段练习）在锐角△*ABC*中，角*A*，*B*，*C*所对的边分别为 *a*，*b*，*c*.①2*a*cos*B*+*b*-2*c*=0；②$\frac{\text{cos} C}{\text{cos} B} + \frac{c}{b} = \frac{\sqrt{3}}{\text{sin} 2 B}$；③$\text{tan} B = \frac{\text{tan} C + \sqrt{3}}{\sqrt{3} \text{tan} C - 1}$.在以上三个条件中选择一个，并作答.
(1)求角*A*；
(2)已知△*ABC*的面积为$4 \sqrt{3}$，*AD*是*BC*边上的中线，求*AD*的最小值.
<span class="fake-tag">答案</span>(1)条件选择见解析，$A = \frac{\pi}{3}$
(2)$2 \sqrt{3}$
<span class="fake-tag">详解</span>（1）若选①，因为：$2 a \cos B + b - 2 c = 0$，即：$2 a \frac{a^{2} + c^{2} - b^{2}}{2 a c} + b - 2 c = 0$，
则：$a^{2} + c^{2} - b^{2} + b c - 2 c^{2} = 0$，即：$c^{2} + b^{2} - a^{2} = b c$，所以：$\cos A = \frac{c^{2} + b^{2} - a^{2}}{2 b c} = \frac{1}{2}$，
因为：$A \in \left( 0 , \frac{\pi}{2} \right)$，故$A = \frac{\pi}{3}$；
若选②，原式等价于$\frac{\cos C}{\cos B} + \frac{\sin C}{\sin B} = \frac{\sqrt{3}}{\sin 2 B}$，即$\frac{\sin B \cos C + \cos B \sin C}{\sin B \cos B} = \frac{\sqrt{3}}{\sin 2 B}$，
即：$\frac{\sqrt{3}}{\sin 2 B} = \frac{\sin ( B + C )}{\frac{1}{2} \sin 2 B} = \frac{2 \sin A}{\sin 2 B}$，因为：$A , B \in \left( 0 , \frac{\pi}{2} \right)$，则$0 < 2 B < \pi$，所以：$\sin 2 B > 0$，
则：$\sin A = \frac{\sqrt{3}}{2}$，故$A = \frac{\pi}{3}$；
若选③，原式等价于$\sqrt{3} \tan B \tan C - \tan B = \tan C + \sqrt{3}$，即：$- \tan B - \tan C = \sqrt{3} \left( 1 - \tan B \tan C \right)$，
所以：$- \frac{\tan B + \tan C}{\left( 1 - \tan B \tan C \right)} = \sqrt{3}$，即：$- \tan ( B + C ) = \sqrt{3}$，即：$\sqrt{3} = - \tan ( \pi - A ) = \tan A$，
因为：$A \in \left( 0 , \frac{\pi}{2} \right)$，故$A = \frac{\pi}{3}$.
（2）因为$S_{\bigtriangleup A B C} = \frac{1}{2} b c \sin A = \frac{\sqrt{3}}{4} b c = 4 \sqrt{3}$，所以：$b c = 1 6$，
因为$D$为$B C$的中点，则：$\overrightarrow{A D} = \overrightarrow{A B} + \overrightarrow{B D} = \overrightarrow{A B} + \frac{1}{2} \overrightarrow{B C}  = \overrightarrow{A B} + \frac{1}{2} \left( \overrightarrow{A C} - \overrightarrow{A B} \right) = \frac{1}{2} \left( \overrightarrow{A B} + \overrightarrow{A C} \right)$
所以：$2 \overrightarrow{A D} = \overrightarrow{A B} + \overrightarrow{A C}$，
则：$4 \overrightarrow{A D}^{2} = \left( \overrightarrow{A B} + \overrightarrow{A C} \right)^{2} = \overrightarrow{A B}^{2} + \overrightarrow{A C}^{2} + 2 \overrightarrow{A B} \cdot \overrightarrow{A C}  = b^{2} + c^{2} + 2 b c \cos \frac{\pi}{3} = b^{2} + c^{2} + b c \geq 2 \sqrt{b^{2} \times c^{2}} + b c = 3 b c = 4 8$当且仅当$b = c = 4$时，等号成立，
因此：$A D$的最小值为$2 \sqrt{3}$.
