##### 题型01 几何图形中用已知向量表示未知向量
##### 【典例1】（2023上·湖北黄石·高二阳新县第一中学校联考期中）如图，在四边形*ABCD*中，$\overrightarrow{D C} = 2 \overrightarrow{A B} , \overrightarrow{B E} = 2 \overrightarrow{E C}$，设$\overrightarrow{D C} = \overrightarrow{a}$，$\overrightarrow{D A} = \overrightarrow{b}$，则$\overrightarrow{D E}$等于（ ）
![@@@560ff285-e256-4a90-a623-aa72ad810da1](高中习题/课堂同步/随堂练习习题/media/ff6621bf051e93305d9a6fc595d116dc.png)
$\quad$A．$\frac{5}{6} \overrightarrow{a} + \frac{1}{2} \overrightarrow{b}$ 
$\quad$B．$\frac{2}{3} \overrightarrow{a} + \frac{1}{2} \overrightarrow{b}$
$\quad$C．$\frac{5}{6} \overrightarrow{a} + \frac{1}{3} \overrightarrow{b}$ 
$\quad$D．$\frac{2}{3} \overrightarrow{a} + \frac{1}{3} \overrightarrow{b}$
<span class="fake-tag">答案</span>C
<span class="fake-tag">详解</span>因为$\overrightarrow{D C} = 2 \overrightarrow{A B} , \overrightarrow{B E} = 2 \overrightarrow{E C}$，
所以$\overrightarrow{D E} = \overrightarrow{D C} + \overrightarrow{C E} = \overrightarrow{D C} + \frac{1}{3} \overrightarrow{C B} = \overrightarrow{D C} + \frac{1}{3} \left( \overrightarrow{D B} - \overrightarrow{D C} \right) = \overrightarrow{D C} + \frac{1}{3} \left( \overrightarrow{D A} + \overrightarrow{A B} - \overrightarrow{D C} \right)$
$= \frac{2}{3} \overrightarrow{D C} + \frac{1}{3} \overrightarrow{D A} + \frac{1}{3} \overrightarrow{A B} = \frac{2}{3} \overrightarrow{D C} + \frac{1}{3} \overrightarrow{D A} + \frac{1}{6} \overrightarrow{D C} = \frac{5}{6} \overrightarrow{a} + \frac{1}{3} \overrightarrow{b}$.
故选：C
