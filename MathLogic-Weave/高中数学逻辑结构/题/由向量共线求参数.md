### 题型09 由向量共线求参数
##### 【典例1】（2023·新疆·高三学业考试）已知向量$\overrightarrow{a} = ( 2 , 3 )$，$\overrightarrow{b} = ( - 1 , 2 )$，若$m \overrightarrow{a} + n \overrightarrow{b}$与$\overrightarrow{a} - 2 \overrightarrow{b}$共线，则$\frac{m}{n} =$（ ）
$\quad$A．$- \frac{1}{2}$ 
$\quad$B．$2$ 
$\quad$C．$\frac{1}{2}$ 
$\quad$D．$- 2$
<span class="fake-tag">答案</span>A
<span class="fake-tag">详解</span>由$\overrightarrow{a} = ( 2 , 3 )$，$\overrightarrow{b} = ( - 1 , 2 )$，则$m \overrightarrow{a} + n \overrightarrow{b} = ( 2 m - n , 3 m + 2 n )$，$\overrightarrow{a} - 2 \overrightarrow{b} = ( 4 , - 1 )$，
由$m \overrightarrow{a} + n \overrightarrow{b}$与$\overrightarrow{a} - 2 \overrightarrow{b}$共线，则有$- ( 2 m - n ) - 4 ( 3 m + 2 n ) = 0$，
化简得$2 m + n = 0$，即$\frac{m}{n} = - \frac{1}{2}$.
故选：A.
##### 【典例2】（2023·四川成都·校联考一模）已知$\overrightarrow{a} = ( 1 - m , 2 )$，$\overrightarrow{b} = ( n , 1 )$，$m > 0$，$n > 0$，若存在非零实数$\lambda$使得$\overrightarrow{a} = \lambda \overrightarrow{b}$，则$\frac{1}{m} + \frac{2}{n}$的最小值为（ ）
$\quad$A．8 
$\quad$B．9 
$\quad$C．10

所以$1 - m = 2 n$，即$m + 2 n = 1$，
所以$\frac{1}{m} + \frac{2}{n} = \left( \frac{1}{m} + \frac{2}{n} \right) ( m + 2 n ) = 5 + \frac{2 n}{m} + \frac{2 m}{n} \geq 5 + 2 \sqrt{\frac{2 n}{m} \cdot \frac{2 m}{n}} = 9$，

所以$\frac{1}{m} + \frac{2}{n}$的最小值为$9$.
