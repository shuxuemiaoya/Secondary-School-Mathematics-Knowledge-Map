##### 题型05 诱导公式在三角形中的应用
##### 【典例1】（2024高一上·全国·专题练习）在$\bigtriangleup A B C$中，给出下列四个式子：①$\sin ( A + B ) + \sin C$；②$\cos ( A + B ) + \cos C$；③$\sin ( 2 A + 2 B ) + \sin 2 C$；④$\cos ( 2 A + 2 B ) + \cos 2 C$.其中为常数的是（ ）
$\quad$A．①③ 
$\quad$B．②③
$\quad$C．①④ 
$\quad$D．②④
<span class="fake-tag">答案</span>B
<span class="fake-tag">分析</span>由诱导公式结合$A + B + C = \pi$对选项一一化简即可得出答案.
<span class="fake-tag">详解</span>①因为在$\bigtriangleup A B C$中，$A + B + C = \pi$，
所以$\sin ( A + B ) + \sin C = \sin ( \pi - C ) + \sin C = \sin C + \sin C = 2 \sin C$；
②因为在$\bigtriangleup A B C$中，$A + B + C = \pi$，$\cos ( A + B ) + \cos C = \cos ( \pi - C ) + \cos C = - \cos C + \cos C = 0$；
③$\sin ( 2 A + 2 B ) + \sin 2 C = \sin \left\lbrack 2 ( A + B ) \right\rbrack + \sin 2 C = \sin \left\lbrack 2 ( \pi - C ) \right\rbrack + \sin 2 C$= \sin ( 2 \pi - 2 C ) + \sin 2 C = - \sin 2 C + \sin 2 C = 0$；
④$\cos ( 2 A + 2 B ) + \cos 2 C = \cos \left\lbrack 2 ( A + B ) \right\rbrack + \cos 2 C = \cos \left\lbrack 2 ( \pi - C ) \right\rbrack + \cos 2 C$= \cos ( 2 \pi - 2 C ) + \cos 2 C = \cos 2 C + \cos 2 C = 2 \cos 2 C$.
故选：B.
##### 【典例2】（多选）（23-24高一下·广东佛山·阶段练习）在$\bigtriangleup A B C$中，下列等式恒成立的是（ ）
$\quad$A．$\sin ( A + B ) - \sin C = 0$ 
$\quad$B．$\cos ( B + C ) - \cos A = 0$
$\quad$C．$\frac{\sin \frac{A + B}{2}}{\cos \frac{C}{2}} = 1$ 
$\quad$D．$\frac{\cos \frac{B + C}{2}}{\cos \frac{A}{2}} = 1$
<span class="fake-tag">答案</span>AC
<span class="fake-tag">分析</span>利用诱导公式及同角三角函数基本关系分别对各选项进行化简计算即可验证.
<span class="fake-tag">详解</span>对于A, $\sin ( A + B ) - \sin C = \sin C - \sin C = 0$,A正确;
对于B, $\cos ( B + C ) - \cos A = - \cos A - \cos A = - 2 \cos A$,B错误;
对于C, $\frac{\sin \frac{A + B}{2}}{\cos \frac{C}{2}} = \frac{\sin \left( \frac{\pi}{2} - \frac{C}{2} \right)}{\cos \frac{C}{2}} = \frac{\cos \frac{C}{2}}{\cos \frac{C}{2}} = 1$, C正确;
对于D, $\frac{\cos \frac{B + C}{2}}{\cos \frac{A}{2}} = \frac{\cos \left( \frac{\pi}{2} - \frac{A}{2} \right)}{\cos \frac{A}{2}} = \frac{\sin \frac{A}{2}}{\cos \frac{A}{2}} = \tan \frac{A}{2}$, D错误.
故选:AC.
##### 【典例3】（23-24高一下·四川广安·阶段练习）已知角*A*为锐角，$\sin A \cos A \tan A = \frac{1}{2}$，
(1)求角*A*的大小；
(2)求$\sin ( \pi + A ) \cos \left( \frac{2 0 2 3 \pi}{2} - A \right)$的值．
<span class="fake-tag">答案</span>(1)$A = \frac{\pi}{4}$
(2)$\frac{1}{2}$
<span class="fake-tag">分析</span>（1）根据同角三角函数之间的基本关系分析运算；
（2）根据诱导公式化简整理，并代入$\sin^{2} A = \frac{1}{2}$，计算即可得出结果.
<span class="fake-tag">详解</span>（1）由$\sin A \cos A \tan A = \sin A \cos A \frac{\sin A}{\cos A} = \sin^{2} A = \frac{1}{2}$，可得$\sin^{2} A = \frac{1}{2}$，
由角*A*为锐角，则$\sin A > 0$，
所以$\sin A = \frac{\sqrt{2}}{2}$，故$A = \frac{\pi}{4}$．
（2）∵$\sin ( \pi + A ) \cos \left( \frac{2 0 2 3 \pi}{2} - A \right) = - \sin A \cos \left( 1 0 1 0 \pi + \frac{3 \pi}{2} - A \right) = - \sin A \cos \left( \frac{3 \pi}{2} - A \right) = \sin^{2} A$，
由（1）可得$\sin^{2} A = \frac{1}{2}$，
即$\sin ( \pi + A ) \cos \left( \frac{2 0 2 3 \pi}{2} - A \right) = \frac{1}{2}$．
##### 【变式1】（23-24高三上·江苏·开学考试）若$\bigtriangleup A B C$的内角*A*，*B*，*C*满足$\text{sin} A = \text{cos} B = \text{tan} C$， 则*A*与*B*的关系为（ ）
$\quad$A．$A - B = \frac{\pi}{2}$ 
$\quad$B．$A + B = \frac{\pi}{2}$ 
$\quad$C．$B - A = \frac{\pi}{2}$ 
$\quad$D．$A + B = \frac{\pi}{3}$
<span class="fake-tag">答案</span>A
<span class="fake-tag">分析</span>依题意由$\sin A = \cos B$可得$A = B + \frac{\pi}{2}$或$A + B = \frac{\pi}{2}$，再分类讨论，即可判断.
<span class="fake-tag">详解</span>因为$\text{sin} A = \text{cos} B$，且 *A*，*B*，*C*为$\bigtriangleup A B C$的内角，因为$\text{sin} A = \text{cos} B > 0 ,$所以$0 < B < \frac{\pi}{2} ,$
所以$A = B + \frac{\pi}{2}$或$A + B = \frac{\pi}{2}$，
若$A + B = \frac{\pi}{2}$，则$C = \frac{\pi}{2}$，此时$\text{tan} C$不存在，故舍去；
∴ $A = \frac{\pi}{2} + B$.
故选：A.
##### 【变式2】（多选）（23-24高一下·安徽·开学考试）已知锐角三角形$A B C$中，设$a = \tan A \tan B$，$f ( x ) = \log_{a} x$则下列判断正确的是（ ）
$\quad$A．$\sin A > \cos B$ 
$\quad$B．$a > 1$
$\quad$C． 
$\quad$D．$f ( \cos A ) > f ( \sin B )$
<span class="fake-tag">答案</span>ABC
<span class="fake-tag">分析</span>根据锐角三角形分析角的范围与关系，并利用诱导公式，以及对数函数的单调性，即可判断正误.
<span class="fake-tag">详解</span>解：因为三角形$A B C$为锐角三角形，所以$A + B > \frac{\pi}{2}$，则$\frac{\pi}{2} > A > \frac{\pi}{2} - B > 0$，
所以$\sin A > \sin \left( \frac{\pi}{2} - B \right) = \cos B > 0$，A选项正确；
同理$\sin B > \cos A > 0$，则$\frac{\sin A}{\cos B} > 1$，$\frac{\sin B}{\cos A} > 1$，
因此$\tan A \tan B = \frac{\sin A}{\cos B} \cdot \frac{\sin B}{\cos A} > 1$，，B，C选项正确；
由于$a > 1$，所以$f ( x ) = \log_{a} x$在是增函数，
又$\sin B > \cos A > 0$，所以，D选项错误．
故选：ABC．
##### 【变式3】（23-24高一·全国·课后作业）$\bigtriangleup A B C$中，若，则$\bigtriangleup A B C$形状为 ．
<span class="fake-tag">答案</span>直角三角形
<span class="fake-tag">分析</span>根据三角形内角和定理得到$A + B + C = \pi$，利用诱导公式化简，得到$\tan \frac{B + C}{2} = 1$，求出$A = B + C = \frac{\pi}{2}$，即可确定出三角形形状．
<span class="fake-tag">详解</span>解：$\because A + B + C = \pi$，$\frac{A}{2} = \frac{\pi}{2} - \frac{B + C}{2}$，
$\therefore \sin \frac{A}{2} = \sin \left( \frac{\pi}{2} - \frac{B + C}{2} \right) = \cos \frac{B + C}{2} = \sin \frac{B + C}{2}$，即$\tan \frac{B + C}{2} = 1$，又$\frac{B + C}{2} \in ( 0 , \pi )\frac{B + C}{2} = \frac{\pi}{4}$，即$A = B + C = \frac{\pi}{2}$，
则$\bigtriangleup A B C$为直角三角形．
故答案为：直角三角形.
