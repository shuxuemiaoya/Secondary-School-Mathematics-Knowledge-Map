##### 题型03平面向量的模（最值，范围）问题
##### 【典例1】（2023·上海崇明·统考一模）已知不平行的两个向量$\overrightarrow{a} , \mspace{6mu} \overrightarrow{b}$满足$\left|  \overrightarrow{a} \right| = 1$，$\overrightarrow{a} \cdot \overrightarrow{b} = \sqrt{3}$．若对任意的$t \in R$，都有$\left| \overrightarrow{b} - t \overrightarrow{a} \right| \geq 2$成立，则$\left| \overrightarrow{b} \right|$的最小值等于 ．
<span class="fake-tag">答案</span>$\sqrt{7}$
<span class="fake-tag">详解</span>依题意，设$\overrightarrow{a}$与$\overrightarrow{b}$的夹角为$\theta ( 0 \leq \theta \leq \pi )$，$\left| \overrightarrow{b} \right| = m ( m > 0 )$，
因为$\left|  \overrightarrow{a} \right| = 1$，$\overrightarrow{a} \cdot \overrightarrow{b} = \sqrt{3}$，所以$\left| \overrightarrow{a} \right| \left| \overrightarrow{b} \right| \cos \theta = \sqrt{3}$，即$m \cdot \cos \theta = \sqrt{3}$，
则$\cos \theta = \frac{\sqrt{3}}{m} = [ - 1 , 1 ]$，所以$m \geq \sqrt{3}$，
因为对任意的$t \in R$，都有$\left| \overrightarrow{b} - t \overrightarrow{a} \right| \geq 2$成立，
所以$\left( \overrightarrow{b} - t \overrightarrow{a} \right)^{2} \geq 4$，即$\overrightarrow{b}^{2} - 2 t \overrightarrow{a} \cdot \overrightarrow{b} + t^{2} \overrightarrow{a}^{2} \geq 4$，即$t^{2} - 2 \sqrt{3} t + m^{2} - 4 \geq 0$对于$t \in R$恒成立，
故$\Delta = \left( 2 \sqrt{3} \right)^{2} - 4 \left( m^{2} - 4 \right) \leq 0$，又$m > 0$，解得$m \geq \sqrt{7}$，
综上，$m \geq \sqrt{7}$，则$\left| \overrightarrow{b} \right|$的最小值为$\sqrt{7}$.
故答案为：$\sqrt{7}$.

##### 【典例3】（2023下·上海闵行·高一校考阶段练习）已知$\left| \overrightarrow{O A} \right| = 2$，$\left| \overrightarrow{O B} \right| = 1$，$\overrightarrow{O C} = x \overrightarrow{O A} + y \overrightarrow{O B}$，且$x + y = 1$，$\angle A O B$为钝角，若$f ( t ) = \left| \overrightarrow{O A} - t \overrightarrow{O B} \right|$的最小值为，则$\left| \overrightarrow{O C} \right|$的最小值是
<span class="fake-tag">答案</span>$\frac{\sqrt{21}}{7}$
<span class="fake-tag">详解</span>$f ( t ) = \left| \overrightarrow{O A} - t \overrightarrow{O B} \right| = \sqrt{\left( \overrightarrow{O A} - t \overrightarrow{O B} \right)^{2}}$
$= \sqrt{\left| \overrightarrow{O A} \right|^{2} - 2 t \overrightarrow{O A} \cdot \overrightarrow{O B} + t^{2} \left| \overrightarrow{O B} \right|^{2}}$= \sqrt{4 - 2 t \overrightarrow{O A} \cdot \overrightarrow{O B} + t^{2}}$，
因为$f ( t ) = \left| \overrightarrow{O A} - t \overrightarrow{O B} \right|$的最小值为，所以$g ( t ) = 4 - 2 t \overrightarrow{O A} \cdot \overrightarrow{O B} + t^{2}$的最小值为$3$，
又$g {( t ) \left( \overrightarrow{O A} \cdot \overrightarrow{O B} \right) \left( \overrightarrow{O A} \cdot \overrightarrow{O B} \right)^{2}}_{\min}$，所以$4 - \left( \overrightarrow{O A} \cdot \overrightarrow{O B} \right)^{2} = 3$，
所以$\overrightarrow{O A} \cdot \overrightarrow{O B} = \pm 1$，
又$\angle A O B$为钝角，所以$\overrightarrow{O A} \cdot \overrightarrow{O B} = - 1$，即$\overrightarrow{O A} \cdot \overrightarrow{O B} = \left| \overrightarrow{O A} \right| \cdot \left| \overrightarrow{O B} \right| \cos \angle A O B = - 1$，则$\cos \angle A O B = - \frac{1}{2}$，

所以$\left| \overrightarrow{O C} \right| = \sqrt{\left( x \overrightarrow{O A} + y \overrightarrow{O B} \right)^{2}} = \sqrt{x^{2} \overrightarrow{O A}^{2} + 2 x y \overrightarrow{O A} \cdot \overrightarrow{O B} + y^{2} \overrightarrow{O B}^{2}}$
= \sqrt{x^{2} \left| \overrightarrow{O A} \right|^{2} - 2 x y + y^{2} \left| \overrightarrow{O B} \right|^{2}}
$= \sqrt{4 x^{2} - 2 x y + y^{2}}$，

所以当$x = \frac{2}{7}$时${\left| \overrightarrow{O C} \right| \frac{\sqrt{21}}{7}}_{\min}$.
故答案为：$\frac{\sqrt{21}}{7}$
##### 【典例4】（2023下·四川眉山·高三校考开学考试）在△*ABC*内，角*A*，*B*，*C*所对的边分别为*a*，*b*，*c*，且$b \cos A - c \cos B = ( c - a ) \cos B$．
(1)求角*B*的值；
(2)若$2 a + c = 4$，点*D*是*AC*边上靠近点*C*的三等分点，求*BD*的取值范围.
<span class="fake-tag">答案</span>(1)$B = \frac{\pi}{3}$
(2)$\left. \frac{2 \sqrt{3}}{3} , \frac{4}{3} \right)$
<span class="fake-tag">详解</span>（1）∵$b \cos A - c \cos B = ( c - a ) \cos B$．
∴由正弦定理，得$\sin B \cos A - \sin C \cos B = \left( \sin C - \sin A \right) \cos B$．
∴$\sin A \cos B + \cos A \sin B = 2 \sin C \cos B$．
∴$\sin ( A + B ) = 2 \sin C \cos B$．
又$A + B + C = \pi$，∴$\sin ( A + B ) = \sin C$．
又∵$0 < C < \pi$，∴$\cos B = \frac{1}{2}$．又$B \in ( 0 , \pi )$，∴$B = \frac{\pi}{3}$．
（2）由题意可知，$\overrightarrow{B D} = \overrightarrow{B C} + \overrightarrow{C D} = \overrightarrow{B C} + \frac{1}{3} \overrightarrow{C A} = \overrightarrow{B C} + \frac{1}{3} \left( \overrightarrow{B A} - \overrightarrow{B C} \right)$,
即$\overrightarrow{B D} = \frac{2}{3} \overrightarrow{B C} + \frac{1}{3} \overrightarrow{B A}$，
所以$\overrightarrow{B D}^{2} = \left( \frac{2}{3} \overrightarrow{B C} + \frac{1}{3} \overrightarrow{B A} \right)^{2} = \frac{4}{9} \overrightarrow{B C}^{2} + \frac{1}{9} \overrightarrow{B A}^{2} + \frac{4}{9} \overrightarrow{B C} \cdot \overrightarrow{B A}$，
$\overrightarrow{B D}^{2} = \frac{4}{9} a^{2} + \frac{1}{9} c^{2} + \frac{4}{9} a c \cdot \frac{1}{2} = \frac{4}{9} a^{2} + \frac{1}{9} c^{2} + \frac{2}{9} a c$，
$= \frac{4}{9} \left( a^{2} + \frac{1}{4} c^{2} + \frac{1}{2} a c \right) = \frac{4}{9} \left\lbrack \left( a + \frac{1}{2} c \right)^{2} - \frac{1}{2} a c \right\rbrack$，且$a + \frac{1}{2} c = 2$，
所以$\overrightarrow{B D}^{2} = \frac{4}{9} \left( 4 - \frac{1}{2} a c \right) = \frac{16}{9} - \frac{2}{9} a ( 4 - 2 a )$，
$= \frac{4}{9} a^{2} - \frac{8}{9} a + \frac{16}{9} = \frac{4}{9} ( a - 1 )^{2} + \frac{12}{9}$，由$2 a + c = 4$可知，$0 < a < 2$，
所以$\overrightarrow{B D}^{2} \in \left. \frac{4}{3} , \frac{16}{9} \right)$，则$B D$的取值范围是$\left. \frac{2 \sqrt{3}}{3} , \frac{4}{3} \right)$.
##### 【变式1】（2023上·天津武清·高三天津市武清区杨村第一中学校考阶段练习）在$\bigtriangleup A B C$中，$\angle B A C = \frac{\pi}{3} , D$为$A B$中点，$P$为线段$C D$上一点，且满足，若$\left| \overrightarrow{B C} \right| = \sqrt{6}$，则$\left| \overrightarrow{A P} \right|$的最大值为 ．
<span class="fake-tag">答案</span>$\sqrt{2}$
<span class="fake-tag">详解</span>由题可得， $\overrightarrow{A B} = 2 \overrightarrow{A D}$，则$\overrightarrow{A P} = t \overrightarrow{A C} + \frac{2}{3} \overrightarrow{A D}$，因*D*,*P*,*C* 三点共线，
则$t + \frac{2}{3} = 1 \Rightarrow \overrightarrow{A P} = \frac{1}{3} \overrightarrow{A C} + \frac{2}{3} \overrightarrow{A D} \Rightarrow \left| \overrightarrow{A P} \right|^{2} = \frac{1}{9} \left( \left| \overrightarrow{A C} \right|^{2} + 4 \left| \overrightarrow{A D} \right|^{2} + 2 \left| \overrightarrow{A C} \right| \cdot \left| \overrightarrow{A D} \right| \right)$.
又注意到$\overrightarrow{B C} = \overrightarrow{A C} - \overrightarrow{A B} = \overrightarrow{A C} - 2 \overrightarrow{A D}$，结合$\left| \overrightarrow{B C} \right| = \sqrt{6}$，余弦定理可得：
$\left| \overrightarrow{B C} \right|^{2} = 6 = | A C |^{2} + 4 | A D |^{2} - 2 | A C | \cdot | A D | \Rightarrow | A C |^{2} + 4 | A D |^{2} = 6 + 2 | A C | \cdot | A D |$.
则$\left| \overrightarrow{A P} \right|^{2} = \frac{1}{9} \left( 6 + 4 \left| \overrightarrow{A C} \right| \cdot \left| \overrightarrow{A D} \right| \right)$.又由基本不等式，$6 = | A C |^{2} + 4 | A D |^{2} - 2 | A C | \cdot | A D | \geq$2 \sqrt{| A C |^{2} \cdot 4 | A D |^{2}} - 2 | A C | \cdot | A D | = 2 | A C | \cdot | A D | \Rightarrow | A C | \cdot | A D | \leq 3$.
当且仅当$| A C |^{2} = 4 | A D |^{2}$，即$| A C | = 2 | A D |$时取等号.
则$\left| \overrightarrow{A P} \right|^{2} = \frac{1}{9} \left( 6 + 4 \left| \overrightarrow{A C} \right| \cdot \left| \overrightarrow{A D} \right| \right) \leq 2 \Rightarrow \left| \overrightarrow{A P} \right| \leq \sqrt{2}$.
故答案为：$\sqrt{2}$.

##### 【变式2】（2023·全国·高三专题练习）已知向量$\overrightarrow{a} , \overrightarrow{b}$满足$\left| \overrightarrow{a} \right| = 2 , \left| \overrightarrow{b} \right| = 1$，若$\overrightarrow{a} \cdot \left( \overrightarrow{a} + \overrightarrow{b} \right) + \overrightarrow{b} \cdot \left( \overrightarrow{a} - \overrightarrow{b} \right)$的最大值为1，$\left| \overrightarrow{a} + 2 \overrightarrow{b} \right|$的取值范围为 ．
<span class="fake-tag">答案</span>$[ 0 , 2 ]$
<span class="fake-tag">详解</span>设向量$\overrightarrow{a} , \overrightarrow{b}$的夹角为*θ*，则$\theta \in [ 0 , \pi ]$；又$\left| \overrightarrow{a} \right| = 2 , \left| \overrightarrow{b} \right| = 1$,
所以$\overrightarrow{a} \cdot \left( \overrightarrow{a} + \overrightarrow{b} \right) + \overrightarrow{b} \cdot \left( \overrightarrow{a} - \overrightarrow{b} \right) = \overrightarrow{a}^{2} + 2 \overrightarrow{a} \cdot \overrightarrow{b} - \overrightarrow{b}^{2} = 3 + 4 \text{cos} \theta \leq 1$，
所以$- 1 \leq \text{cos} \theta \leq - \frac{1}{2}$,
所以$| \overrightarrow{a} + 2 \overrightarrow{b} |^{2} = \overrightarrow{a}^{2} + 4 \overrightarrow{a} \cdot \overrightarrow{b} + 4 \overrightarrow{b}^{2} = 8 + 8 \text{cos} \theta$，
又$\text{cos} \theta \in \left\lbrack - 1 , - \frac{1}{2} \right\rbrack$，所以$8 + 8 \text{cos} \theta \in [ 0 , 4 ]$，所以$\left| \overrightarrow{a} + 2 \overrightarrow{b} \right|$的取值范围是$[ 0 , 2 ]$．
故答案为：$[ 0 , 2 ]$．
##### 【变式3】（2023上·江苏南京·高二统考期中）在$\bigtriangleup A B C$中，$a , b , c$分别为角所对的边，$\overrightarrow{A B} \cdot \overrightarrow{A C} = b^{2} - \frac{1}{2} a b$．
(1)求角$C$的大小；
(2)若$\bigtriangleup A B C$的面积为$\frac{\sqrt{3}}{2}$，且$\overrightarrow{C M} = 2 \overrightarrow{M B}$，$\overrightarrow{A N} = 3 \overrightarrow{N M}$，求$\left| \overrightarrow{C N} \right|$的最小值．
<span class="fake-tag">答案</span>(1)$\frac{\pi}{3}$
(2)$\frac{\sqrt{3}}{2}$
<span class="fake-tag">详解</span>（1）解法一：因为$\overrightarrow{A B} \cdot \overrightarrow{A C} = b^{2} - \frac{1}{2} a b$，所以$b c \cos A = b^{2} - \frac{1}{2} a b$，
由余弦定理得$b c \times \frac{b^{2} + c^{2} - a^{2}}{2 b c} = b^{2} - \frac{1}{2} a b$，化简得$\frac{b^{2} + a^{2} - c^{2}}{2 a b} = \frac{1}{2}$，
所以$\cos C = \frac{1}{2}$，因为$C \in ( 0 , \pi )$，所以.
【解法2】因为$\overrightarrow{A B} \cdot \overrightarrow{A C} = b^{2} - \frac{1}{2} a b$，所以$b c \cos A = b^{2} - \frac{1}{2} a b$，
由正弦定理得$\sin B \sin C \cos A = \sin^{2} B - \frac{1}{2} \sin A \sin B$，
因为$B \in ( 0 , \pi )$，可得$\sin B > 0$，所以$\sin C \cos A = \sin B - \frac{1}{2} \sin A$，
因为$A + B + C = \pi$，所以$\sin C \cos A = \sin ( A + C ) - \frac{1}{2} \sin A$，
即$\sin C \cos A = \sin A \cos C + \cos A \sin C - \frac{1}{2} \sin A$，
化简得$\sin A \cos C = \frac{1}{2} \sin A$，因为$A \in ( 0 , \pi )$，可得$\sin A > 0$，
所以$\cos C = \frac{1}{2}$，因为$C \in ( 0 , \pi )$，所以.
（2）解：因为$S_{\bigtriangleup A B C} = \frac{1}{2} a b \sin C = \frac{1}{2} a b \sin \frac{\pi}{3} = \frac{\sqrt{3}}{2}$，所以$a b = 2$，
又因为$\overrightarrow{C M} = 2 \overrightarrow{M B}$，$\overrightarrow{A N} = 3 \overrightarrow{N M}$，
所以$\overrightarrow{C N} = \overrightarrow{C A} + \overrightarrow{A N} = \overrightarrow{C A} + \frac{3}{4} \overrightarrow{A M} = \overrightarrow{C A} + \frac{3}{4} ( \overrightarrow{C M} - \overrightarrow{C A} ) = \frac{1}{4} \overrightarrow{C A} + \frac{3}{4} \overrightarrow{C M} = \frac{1}{4} \overrightarrow{C A} + \frac{1}{2} \overrightarrow{C B}$，
所以$\left| \overrightarrow{C N} \right|^{2} = ( \frac{1}{4} \overrightarrow{C A} + \frac{1}{2} \overrightarrow{C B} )^{2} = \frac{1}{16} b^{2} + \frac{1}{4} a^{2} + \frac{1}{4} \overrightarrow{C A} \cdot \overrightarrow{C B}$
$= \frac{1}{16} b^{2} + \frac{1}{4} a^{2} + \frac{1}{4} \geq 2 \sqrt{\frac{1}{16} b^{2} \cdot \frac{1}{4} a^{2}} + \frac{1}{4} = \frac{3}{4}$，
当且仅当$\frac{1}{16} b^{2} = \frac{1}{4} a^{2}$时，即$a = 1 , b = 2$等号成立，
所以$\left| \overrightarrow{C N} \right|$的最小值为$\frac{\sqrt{3}}{2}$．
