##### 题型06已知角平分线，求其它元素
##### 【典例1】（2022上·贵州·高三统考开学考试）已知$\bigtriangleup A B C$的内角对应的边分别是$a , b , c$，内角$A$的角平分线交边$B C$于$D$点，且$A D = 4$.若$( 2 b + c ) \cos A + a \cos C = 0$，则$\bigtriangleup A B C$面积的最小值是 .
<span class="fake-tag">答案</span>$16 \sqrt{3}$
<span class="fake-tag">详解</span>∵$( 2 b + c ) \cos A + a \cos C = 0$，
∴$2 \sin B \cos A + \sin C \cos A + \sin A \cos C = 0$，
即$2 \sin B \cos A + \sin ( C + A ) = 2 \sin B \cos A + \sin B = 0$，
又$B \in ( 0 , \pi )$，$\sin B > 0$，
∴$2 \cos A + 1 = 0$，即$\cos A = - \frac{1}{2}$，又$A \in ( 0 , \pi )$，
∴$A = \frac{2 \pi}{3}$，
由题可知$S_{\bigtriangleup A B C} = S_{\bigtriangleup A B D} + S_{\bigtriangleup A C D}$，$A D = 4$，
所以$\frac{1}{2} b c \sin \frac{2 \pi}{3} = \frac{1}{2} \times 4 c \sin \frac{\pi}{3} + \frac{1}{2} \times 4 b \sin \frac{\pi}{3}$，即$b c = 4 ( b + c )$，
又$b c = 4 ( b + c ) \geq 8 \sqrt{b c}$，即$b c \geq 64$，当且仅当$b = c$取等号，
所以$S_{\bigtriangleup A B C} = \frac{1}{2} b c \sin \frac{2 \pi}{3} \geq \frac{1}{2} \times 64 \times \frac{\sqrt{3}}{2} = 1 6 \sqrt{3}$，
即$\bigtriangleup A B C$面积的最小值是$16 \sqrt{3}$.
故答案为：$16 \sqrt{3}$

##### 【典例3】（2023上·贵州贵阳·高三贵阳一中校考阶段练习）在$\bigtriangleup A B C$中，内角的对边分别为$a , b , c$，且$\text{sin} B + \text{sin} C = \frac{a \text{sin} A - b \text{sin} B}{c} , a = 6 \sqrt{2}$.

所以由正弦定理得，
即$b^{2} + c^{2} - a^{2} = - b c$，由余弦定理得$\text{cos} A = \frac{b^{2} + c^{2} - a^{2}}{2 b c} = - \frac{1}{2}$，
