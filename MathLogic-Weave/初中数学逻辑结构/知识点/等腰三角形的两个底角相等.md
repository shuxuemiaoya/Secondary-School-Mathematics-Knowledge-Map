# 定理 等腰三角形的两个底角相等。

这一定理可以简述为：等边对等角。

已知：如图1-15，在 $\triangle ABC$ 中， $AB = AC_{\circ}$

求证： $\angle B = \angle C$

证明：如图1-17，取 $BC$ 的中点 $D$ ，连接 $AD_{\circ}$

$AB = AC$ $BD = CD$ $AD = AD$

$\triangle ABD \cong \triangle ACD$ (SSS)。

$\angle B = \angle C$ （全等三角形的对应角相等）。
