
在上一节用小棒拼摆正方形时，我们得到了几个不同的代数式：
$$
x + x + (x + 1), 4 + 3 (x - 1), 4 x - (x - 1), 3 x + 1 。
$$
它们都表示拼摆 $x$ 个正方形所需小棒的根数，因此应该相等。对此，你能用运算律加以解释吗？与同伴进行交流。

利用乘法对加法的分配律去括号，可得
$$  
\begin{aligned}  
x+x+(x+1) &= x+x+x+1 = 3x+1; \\  
4+3(x-1) &= 4+3x-3 = 3x+1; \\  
4x-(x-1) &= 4x+(-1)(x-1) \\  
&= 4x+(-1)x+(-1)\times(-1) = 4x-x+1 = 3x+1.  
\end{aligned}  
$$

三个代数式都可化为 $3x + 1$ 的形式，因此，这四个代数式是相等的。

> (3) $a + (b - c)$ ; (4) $a - (b - c)$ 。
> > [!success]- 解析
> > 我们可以把括号前面的符号分别看作 $+1$ 或 $-1$ ，利用乘法分配律将其展开：
> > 
> > 1. $a + (b + c) = a + 1 \times (b + c) = a + b + c$
> > 2. $a - (b + c) = a + (-1) \times (b + c) = a - b - c$
> > 3. $a + (b - c) = a + 1 \times (b - c) = a + b - c$
> > 4. $a - (b - c) = a + (-1) \times (b - c) = a - b + c$
> 
> > [!summary] [去括号法则](课本/【2024版】【北师大版】/【2024版】【北师大版】七年级上册数学/概念/去括号法则.md)
> > 括号前是“+”，把括号和它前面的“+”去掉后，原括号里各项的符号都不改变。
> > 括号前是“-”，把括号和它前面的“-”去掉后，原括号里各项的符号都要改变。

> 1. $4a-(a-3b)$；
> 2. $a+(5a-3b)-(a-2b)$；
> 3. $3(2xy-y)-2xy$；
> 4. $5x-y-2(x-y)$。

> > 1. $4a-(a-3b)=4a-a+3b=3a+3b;$

> > 3. $3(2xy-y)-2xy=(6xy-3y)-2xy=6xy-3y-2xy=4xy-3y;$

> > $$
> > 5x-y-2(x-y)=5x-y-(2x-2y)=5x-y-2x+2y=3x+y.
> > $$


> [!question] 思考·交流
> 你认为去括号时要注意什么？与同伴进行交流。
>
> > [!warning]- 核心注意点（避坑指南）
> > 去括号时极易出现以下三种典型错误，在实际运算中需要格外注意：
> > 
> > 1. **漏乘系数（最易错）**
> >    当括号前不仅有符号还有数字（如系数不为 $\pm 1$）时，去括号时该数字必须**乘到括号内的每一项**，不能漏乘。
> >    * ❌ 错误：$3(x - 2) = 3x - 2$
> >    * 正确：$3(x - 2) = 3x - 6$
> > 
> > 2. **漏变符号（符号不彻底）**
> >    当括号前是“$-$”号时，去括号后原括号内的**所有项**都要变号，不能只变第一项而漏掉后面的项。
> >    * ❌ 错误：$-(a - b + c) = -a - b + c$
> >    * 正确：$-(a - b + c) = -a + b - c$
> > 
> > 3. **项数变化或字母丢失**
> >    去括号本质是乘法分配律的应用，去括号后**多项式的项数应当保持不变**。在计算时要小心不要漏掉变量或常数项。
> > 
> > > [!tip] 记忆小口诀
> > > **去括号，看符号：**
> > > 是 **“ $+$ ”** 号，不变号；
> > > 是 **“ $-$ ”** 号，全变号；
> > > 数字在外**都要乘**，一个不落才算对。
