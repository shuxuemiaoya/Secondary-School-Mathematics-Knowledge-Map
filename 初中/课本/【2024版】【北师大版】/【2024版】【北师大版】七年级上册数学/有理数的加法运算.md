>> [!abstract]  [[概念/有理数加法法则]]
>> 同号两数相加，取相同的符号，并把绝对值相加。
>> 异号两数相加，绝对值相等时和为 $0$；绝对值不等时，取绝对值较大的数的符号，并用较大的绝对值减较小的绝对值。
>> 一个数同 $0$ 相加，仍得这个数。

> [!example]- **例 1** 计算
> 1. $180 + (-10)$；
> 2. $(-10) + (-1)$；
> 3. $5 + (-5)$；
> 4. $0 + (-2)$。
>
> > [!abstract]- 解
> > 1. $180 + (-10) = +(180-10) = 170$；
> > 2. $(-10) + (-1) = -(10+1) = -11$；
> > 3. $5 + (-5) = 0$；
> > 4. $0 + (-2) = -2$。
>
> 你能说出每一步运算的依据吗？
