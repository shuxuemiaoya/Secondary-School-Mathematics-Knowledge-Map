# 9 待定系数法

本单元主要讨论整系数的四次多项式．一个整系数多项式如果能分解为两个有理系数的因式的乘积，那么也一定能分解为两个整系数的因式的积．所以，我们只需要讨论它有无整系数的因式就可以了．

# 9.1 二次因式

例 1 分解因式: $x^{4} + x^{3} + 2x^{2} - x + 3$ .

解 原式的有理根只可能为 $\pm 1, \pm 3$ , 但是这四个数都不能使原式为 0，所以原式没有有理根，因而也没有（有理系数的）的一次因式.

我们设想 $x^{4} + x^{3} + 2x^{2} - x + 3$ . 可以分成两个整系数的两个整系数的二次因式由于原式是首1的(首项系数为1)，两个因式也应当是首1的，于是设

$$
\begin{array}{l} x ^ {4} + x ^ {3} + 2 x ^ {2} - x + 3 \\ = (x ^ {2} + a x + b) (x ^ {2} + c x + d), (1) \\ \end{array}
$$

其中整系数 a, b, c, d 有待我们去确定.

比较（1）式两边 $x^{3},x^{2},x$ 的系数与常数项，得

$$
\left\{ \begin{array}{l} a + c = 1 \\ b + d + a c = 2 \\ b c + a d = - 1 \\ b d = 3 \end{array} \right.
$$

这样的方程组，一般来说是不容易解的，不过，忘了 $a, d$ 是整数，根据这一点，从（5）可以得出 $\left\{ \begin{array}{l} b = 1, \\ d = 3 \end{array} \right.$ 或 $\left\{ \begin{array}{l} b = -1 \\ d = -3 \end{array} \right.$ ，当然也可能是 $\left\{ \begin{array}{l} b = 3 \\ d = 1 \end{array} \right.$ 或 $\left\{ \begin{array}{l} b = -3 \\ d = -1 \end{array} \right.$ 在这个例子中由于因式的次序无关紧要，我们可以认为只要有 $\left\{ \begin{array}{l} b = 1, \\ d = 3 \end{array} \right.$ 或 $\left\{ \begin{array}{l} b = -1 \\ d = -3 \end{array} \right.$ ，两种情况.

将或 b=1, d=3 带入（4），得：

$$
c + 3 a = - 1, \tag {$3^{\prime$}}
$$

将（3）与（2）相减得

$$
2 a = - 2,
$$

于是

$$
a = - 1,
$$

再由（2）得，

$$
c = 2,
$$

在一组数中 $(a=-1,b=1,c=2,d=3)$ 不仅适合（2）、（4）、（5）而且适合(3)，因此

$$
\begin{array}{l} x ^ {4} + x ^ {3} + 2 x ^ {2} - x + 3 \\ = (x ^ {2} - x + 1) (x ^ {2} + 2 x + 3) \\ \end{array}
$$

将 b = -1, d = -3 带入（4），得

$$
- c - 3 a = - 1,
$$

将（3”）与（2）相加得

$$
\begin{array}{l} 2 a = 0 \\ a = 0, \\ c = 1 \\ \end{array}
$$

再由（2）得，

这一组数 $(a=0,b=-1,c=1,d=-3)$ 虽然适合（2），（4），（5），却不适合（3）因而

$$
x ^ {4} + x ^ {3} + 2 x ^ {2} - x + 3 \neq (x ^ {2} - 1) (x ^ {2} + x - 3).
$$

事实上，分解式是唯一的，找出一组满足方程组的数，就可以分解因式（6）.考虑没有其他的解纯熟多余，毫无必要.

例 2 分解式 $2x^{4}-x^{3}+6x^{2}-x+6$ .

$$
2 x ^ {4} - x ^ {3} + 6 x ^ {2} - x + 6 = (2 x ^ {2} + a x + b) (x ^ {2} + c x + d),
$$

比较两边 $x^{3},x^{2},x$ 的系数及常数项，得：

$$
\left\{ \begin{array}{l} 2 c + a = - 1, \\ 2 d + b + a c = 6, \\ a d + b c = - 1 \\ b d = 6 \end{array} \right.

# 9.2 既约的情况

例 3 $x^{4}-x^{2}+1$ 是否能分解成两个整系数的二次因式的乘积?

解 我们知道 $x^{4} - x^{2} + 1 = (x^{2} + x + 1)(x^{2} - x + 1)$ , 而 $x^{4} - x^{2} + 1$ 却不能分解成两个整系数的二次因式的乘积. 因为, $x^{4} - x^{2} + 1$ 能够分解, 那么一定分解为

$$
(x ^ {2} + a x + 1) (x ^ {2} + b x + 1)
$$

或 $(x^{2} + ax - 1)(x^{2} + bx - 1),$

比较 $x^{3}$ 与 $x^{2}$ 的系数可得

$$
\left\{ \begin{array}{l} a + b = 0 \\ a b \pm 2 = - 1 \end{array} \right.
$$

由（11）得 $b = -a$ ，带入（12）得

$$
a ^ {2} = \pm 2 + 1,
$$

即 $a^{2}=3$ 或 $a^{2}=-1,$

没有整数 a 能满足这两个方程，所以 $x^{4}-x^{2}+1$ 不能分解成两个系数的二次因式的积（从而也不能分解成两个有理系数的二次因式的积）

例 4 $x^{6}-x^{3}-1$ 是否分解成为两个整系数的三次因式的积?

解 设 $x^{6} - x^{3} - 1 = (x^{3} + ax^{2} + bx + 1)(x^{3} + cx^{2} + dx - 1)$ 比较 $x^{5}, x^{3}$ 及 $x$ 的系数，得

$$
\left\{ \begin{array}{l} a + c = 0, \\ a d + b c = 1 \\ b - d = 0 \end{array} \right.
$$

由第一方程与第三个方程可得

$$
c = - a, d = b
$$

再把他们带入第二个方程中，得

$$
a b - a b = 1,
$$

矛盾.

所以， $x^{6}-x^{3}-1$ 不可能分解为两个整系数的三次因式的积.

# 小结

整系数的四次多项式，如果没有有理根，那么它就没有整系数的一次因式.这时，我们应当用待定系数的二次因式.即假定它等于整系数的二次因式的积，建立一组方程（用比较等式两边系数等方法）来确定这两个因式有整数的系数，如果这组方程无整数解，那么这个四次因式就没有整系数的二次因式.

高次的多项式也可以用类似的办法处理.

待定系数法还可以应用于其他场合，例如本书的第10单元将要讲到.
